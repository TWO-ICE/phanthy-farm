# 为什么皮肤有时候很好很嫩滑，而有时候特别粗糙干燥呢？

****


你有出现过这种情况吗？

皮肤有时候特别好特别嫩滑


而有时候特别粗糙干燥？


造成这种现象可能有下面几个原因：


1**环境**


有这样1个现象

冬天的时候宝宝的脸容易干燥皴裂，而夏天不会


why？为什么呢


很显然，和**天气干燥**程度有关


夏天时一般空气不干燥

再加上皮肤容易出汗

因而皮肤最外层皮肤不会干燥就不会发生皲裂粗糙起皮等现象


而冬天正好相反

一来皮肤不怎么出汗

二来空气相对干燥，皮肤外层水分流失加剧

皮肤就容易出现干燥紧绷起皮甚至皲裂


2**荷尔蒙**


第2个原因你可能没想到

皮肤忽而嫩滑忽而粗糙可能和体内**荷尔蒙波动**有关!


对于生育期女性来说

每个月体内的3大主要激素都会出现剧烈波动


雌激素、孕激素、雄激素


看下图


![图片](https://mmbiz.qpic.cn/mmbiz_png/GpQXWbgR4452IKKys5ianBcibPwnBSNRNf3SMWTEdb1sXJS94AtBMibACyxFDqvlS6YeGZOziajzhahr8UoUhFb3Gg/640?wx_fmt=png)


一般来说，雌激素升高时会让皮肤状态更好（嫩滑）

于是有些人就感受到了皮肤状态的周期性的变化


极端的表现就是


一些人生理期前容易长粉刺痘痘


3**使用**


最后一个原因，你可能绝对不会想到

你使用的产品！


有些成分会让皮肤变得嫩滑（比如去角质成分）


但会让皮肤变得粗糙干燥的成分表面上看似乎没有，但实际使用时却可能会发生。


比如下面这么几类


1）去角质成分

虽然刚开始使用让皮肤变得嫩滑了，但皮肤变薄后，锁水能力变差，可能就会出现皮肤容易变干变得粗糙


2）某些酯类成分（油）

虽然刚开始使用会吸收进入皮肤浅层，让皮肤变得嫩滑，但一段时间后，可能会导致皮肤细胞分化出现问题，容易出现起皮肤干燥现象。


一些人的唇炎就是这么形成的。


3）卸妆成分

一般来说，卸妆后皮肤会显得嫩滑一些。

但是频繁卸妆后，皮肤变薄、锁水能力变差，然后皮肤也容易出现干燥粗糙


4**总结**

好了，给今儿的内容作个小结

有些人皮肤状态会出现过山车一样的变化

时而很好很嫩滑，时而粗糙干燥


这是多种可能原因造成的：环境湿度的变化、使用的某些产品、卸妆（过度清洁）等。


而要想避免出现这种情况很简单

**选安心度高的产品、减少化妆卸妆**、做好基础保湿。

也就是回到了这句话


护肤过度了，皮肤反而会出问题。
