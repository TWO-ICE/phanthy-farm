# 用淡斑霜之惊喜，意外收获了一脸...

今儿要说一个案例


![图片](https://mmbiz.qpic.cn/mmbiz_png/GpQXWbgR444l8zzBkkhpwnV1Oz1ug4Gu3tico3V8yrgVaibHGTL3vh1HFpg4aIHQd0HIdrXccOsiaib5OrQpEJFLicA/640?wx_fmt=png)


我们来梳理一下

1）用了朋友推荐的 **淡斑霜**

2）半月后长了一个个 **米粒豆**


她是一个老粉了，知道这是过敏

因为因果关系太明显了

因为用淡斑霜，所以长了米粒豆


她急切的想知道，到底是什么成分引起的？


1**成分**


来看一下她发过来的成分


![图片](https://mmbiz.qpic.cn/mmbiz_png/GpQXWbgR444l8zzBkkhpwnV1Oz1ug4GuVAD3zjpXnfZJtGJrbKLVPmSCicjUbuFFQVfBWG99VoSkDDXk4RYe2uw/640?wx_fmt=png)


很遗憾，我不能告诉她是哪一个成分引起的


我经常说的一句话：

对皮肤有“功效”的成分多少都有副作用


所以，那些具有祛斑 “功效”的成分嫌疑最大

我用红框把那些成分标了出来

熊果苷、当归根提取物、桑树皮提取物、芍药根提取物、白苏叶提取物、白芨提取物... 光果甘草根提取物


它们有明确的淡斑效果吗？


不确定，也许有那么一点，也许没有


也许对少数人有点用，


但对多数人一定没有用

很显然，


如果有效，一定首先以药物的形式出现

而不是出现在没有疗效的护肤品身上。


2**接触性**


但她还抱有一线希望

想知道是否和她现在用的护肤品犯冲？是否还能继续使用？


很遗憾，


我只能告诉她停用


这不是成分间犯冲的问题

而是淡斑霜里的成分进入皮肤后

产生了一系列刺激反应

最终导致皮肤长了很多米粒豆


这可以算作是接触性皮炎

而恢复的方法就是

停用刺激源

停用淡斑霜，皮肤才能变好。


还有一点，我经常强调的

斑，是无法根除的

一旦长出来，就在皮肤里扎根了


她可能也知道


但为了淡斑（变美）


总想去试试


也许，有些弯路一定要走一下才能更深刻的理解...
