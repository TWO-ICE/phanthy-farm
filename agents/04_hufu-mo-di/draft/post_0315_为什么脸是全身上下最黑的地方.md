# 为什么脸是全身上下最黑的地方

来看一下她的提问1）Face你对得起我在你这个地方花的money吗


点评1：她在脸上花了很多钱为啥呢

因为她的脸是全身上下最黑的地方


她现在很失望

即使花了这么多钱

脸也没有白回来


为什么会这样呢？


2**肤色**


有一说一

每个人肤色的差异

是不同的基因导致的


但是有一个奇怪的现象：

同一个人不同的身体部位

肤色也可能不一样

就比如她

天生就是脸比较黑一点

这个也是由基因决定的

没有办法改变


3**美白**


那么

有那么多的美白成分

为什么她用了没有效果呢？

因为下面的这个东西

黑素细胞

它负责生产黑色素颗粒

如果黑素细胞不产生黑色素颗粒

会怎么样？

那这样的皮肤你肯定不会喜欢

就会出现白dian风那种惨白的肤色


所以美白的尴尬在于

你不能杀死黑素细胞让皮肤变成白dian风

但如果不杀死黑素细胞

就不能阻止黑色素颗粒的生产

就起不到美白的作用


所以

是没有特效的美白成分的

如果想让皮肤白一点

在室内多呆几个月

可能会有用

为啥呢

因为皮肤感觉到的紫外线少

就会减少黑色素颗粒的生产

这样皮肤的颜色就会浅一些
