# 先锋说唱歌手连麻Swimming加盟环球音乐

7月24日，全球领先的音乐娱乐公司——环球音乐中国宣布先锋说唱歌手连麻Swimming正式加盟。双方的合作从连麻Swimming大受好评的全新专辑《邻家小丈夫》开始，未来，连麻Swimming的艺人经纪事务也将与环球音乐达成多元合作关系。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/e85sPh5iaL9gv2Q9bEbuOEyNlWfg13xaic7tX4PwUeOrds4urp3OWibu0PbDqOWDuicibWGtQUQCjVYvadbZNiaPtOzw/640?wx_fmt=jpeg&from=appmsg)


连麻Swimming是近年嘻哈音乐圈备受称赞的新锐Rapper，凭借对嘻哈音乐的理解和本土化的融合，国际化的说唱技术及强烈的个人态度，自出道以来就备受业内关注。连麻Swimming在2017年凭借首张专辑《Wake Up》正式出道，随后通过不断摸索迅速确认了自己标志性的Mumble Rap风格。他的音乐，就像他的名字一样，以独树一帜的风格和作品连续麻痹乐迷的神经，给乐迷带来绝佳的听感体验。2020年，连麻Swimming参加湖南卫视举办的音乐综艺节目《说唱听我的》，凭借其独一无二的腔调，流畅顺滑的flow迅速进入大众视野，成为夺冠热门选手。在节目中，连麻Swimming凭借一曲走心说唱作品《丢人吗》，引发无数听众的共鸣。2022年，连麻Swimming发布单曲《谭Sir》，歌曲一经发布，在网易云音乐平台五分钟内收获评论999+，在抖音平台短时间内收获20万次播放。同年，连麻Swimming发布单曲《数钱的女孩》，歌名话题 #数钱的女孩 累计收获抖音平台5450万次播放，歌曲MV收获全网播放量1200万+。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/e85sPh5iaL9gv2Q9bEbuOEyNlWfg13xaicRK15QQ49GIu4GybDAMKWNOsz5O5bZQt6iatL9q4YbUPbLLkBbyJ94fQ/640?wx_fmt=jpeg&from=appmsg)


连麻Swimming最新专辑《邻家小丈夫》于5月18日由环球音乐中国发行，专辑中连麻Swimming化身双重身份，A面，是在伴奏带上用说唱腾云驾雾、泥沼中绽放的街头艺术家。B面，是现实中肩负生活与情感责任、砥砺前行的“邻家小丈夫”。在环球音乐的助力下，这张专辑取得了突破性的成功，无论从作品品质还是市场成绩而言都获得了广泛的认可，**首月全平台播放量破5000万。 **环球音乐集团大中华区艺人发展与泛娱乐开发副总裁鹿鸣表示：“嘻哈是当下最受国内年轻群体喜爱的音乐类型之一。我们欣喜地看到，中国本土的新锐rapper们，近年来在技艺层面不断精进的同时，植根本土文化，敢于自我表达，在艺术性和人文性方面开辟了中文说唱的新浪潮，而**连麻Swimming正是这一趋势中非常有标志性的音乐人，他开创了中文说唱新的腔调和表达。**”作为全球领先的音乐娱乐公司，环球音乐在中国始终秉承推动多样化音乐风格发展的策略，致力于将新生代中国音乐人和音乐文化推向世界。未来，环球音乐将更加坚定地支持本土原创音乐，为中文嘻哈音乐注入国际视野和全球资源，成为世界Hip-hop版图中不可或缺的名字。*本文图源网络，如侵权联系删改
