# 权志龙，一人撑起万亿韩元估值

作者 |  范志辉


娱乐行业从来不缺“顶流神话”。


2023年，权志龙结束与YG娱乐长达17年的合作，签约名不见经传的小公司Galaxy Corporation。当时没人想到，这份合约会在短短两年内彻底改写这家公司的命运。


根据韩媒报道，援引Galaxy对外披露的审计资料与融资文件，公司在2025年实现合并营收2989亿韩元，同比增长618%；其中经纪业务收入2695亿韩元，同比增长859%；营业利润125亿韩元，实现扭亏为盈。公司估值也从不足5000亿韩元直接翻倍突破1万亿，正式跻身独角兽行列。


而这一切，几乎全靠一个人——权志龙。


![图片](https://mmbiz.qpic.cn/mmbiz_png/sP99TpzRiaoJdA0boSXMKyzibLugyZCEvycKoQW5Oan35aeho5TT3KUAtFCsuRYkBZKn7PyeHLBEOHlDdWH4c2Ag/640?wx_fmt=png&tp=webp)


一个人，撑起一家公司


先看一个数字：权志龙去年从公司拿到的结算金，预计超过600亿韩元，约合人民币2.7个亿人民币。


注意，这只是结算金。他还有170多首歌的版权费没算进去。如果都加上，奔着700亿韩元去了。


你可能对这个数字没什么感觉，我换个说法：在权志龙未开展活动的时期，Galaxy Corporation一年付出去的结算费用（即艺人分成款）也就8亿到25亿韩元。而在去年，这个数字是714亿，涨了30多倍。扣除法律、宣传代理等相关费用后，权志龙的实际结算金预估超过650 亿韩元。


![图片](https://mmbiz.qpic.cn/mmbiz_png/BhPDyYCib8r9dgdQ6V3U9dOsbQS14e96aN72gTE0ZG52n83FOg8icMTydaWPvPMOwwvJgV95zfKQbrXnZEegbakgichhnZ0EY5icpHCJVicXrYD4/640?wx_fmt=png&tp=webp)


去年上半年，Galaxy Corporation几乎可以说是以权志龙为核心的“一人公司”。尽管下半年陆续签下宋康昊、金钟国等艺人，但这些艺人的分成占比并不高。业内人士透露：“权志龙与其他艺人的收益规模，据说差距超过100 倍。”


再来看这家公司的营收构成。


去年，Galaxy Corporation的合并营收达 2989 亿韩元，同比增长618%；其中直接体现权志龙巡演成果的经纪业务营收达2695 亿韩元，同比增长 859%，直接助力公司成功扭亏为盈。


也就是说，超过90%的收入，都来自权志龙一个人。


去年，他发行了个人正规三辑《Übermensch》后，发售首日销量突破60万张，刷新个人纪录，全年累计销量突破100万张。但专辑只是开胃菜，真正的主菜是那轮横跨全球的世界巡演。


![图片](https://mmbiz.qpic.cn/mmbiz_png/BhPDyYCib8r8ooHicoIehNwuRj9Qia775HnboYR2zXp9FqfOia8C7bquia8jDF9gxYF9GhrghMOPM8wia94lAhzJNF1CGk47Djtfg5zEGCibvTP5Ww/640?wx_fmt=png&tp=webp)


从高阳综合运动场出发，一路杀到东京、大阪、澳门、悉尼、台北、吉隆坡、雅加达、纽约、拉斯维加斯、洛杉矶、巴黎等全球12个国家与地区，17个城市，39场演出，82.5万人次观众。Billboard Boxscore的数据显示，光是前22场就赚了7180万美元（约960亿韩元）；高阳站两天6.8万人，门票收入120亿韩元；美国纽瓦克站一场就干了约2710万美元（约360亿韩元）。


综合来看，整轮巡演仅门票收入预计便达到约1800亿至1900亿韩元。若叠加周边商品销售、快闪店收益，行业普遍预计巡演相关总收入规模或达1500亿至2000亿韩元以上，创下韩国Solo歌手巡演收益新高。


世界巡演的大获成功，也大幅推高了Galaxy Corporation的业绩，成功获得了资本市场的认可。


而某种程度上，这确实是娱乐圈现实版的“一人公司“。


![图片](https://mmbiz.qpic.cn/mmbiz_png/sP99TpzRiaoJdA0boSXMKyzibLugyZCEvycKoQW5Oan35aeho5TT3KUAtFCsuRYkBZKn7PyeHLBEOHlDdWH4c2Ag/640?wx_fmt=png&tp=webp)


“一人公司”的前景与隐忧


说实话，在签下权志龙之前，至少内娱，没几个人知道Galaxy Corporation是干嘛的。


这家公司2019年才成立，注册资本仅为100万韩元，通过外包制作综艺节目，例如2020年TV朝鲜的《Ava Dream》、以及后来的《两天一夜》、《团结一致》和《Physical 100》，在业内崭露头角。


目前，公司主打“娱乐科技”概念，想靠AI和机器人技术搞点新花样。但几年下来，业务不温不火，2023年还亏了188亿韩元，在竞争激烈的韩国娱乐圈里基本是个“小透明”。


![图片](https://mmbiz.qpic.cn/mmbiz_png/BhPDyYCib8ricvvx0taxkwe91nMDBLnT2x2QZtp24PamURjYA9DXoQC8L29HVH8gQ8FYtCRPoTuCKYQMVS7w4olKMgiaAM5yngmr5EMcG6G73U/640?wx_fmt=png&from=appmsg&tp=webp)


权志龙一来，一切都变了。


2023年，在权志龙刚加盟前，公司估值大概5000亿韩元。到2025年底Pre-IPO融资时，已经突破1万亿韩元，跻身独角兽企业行列。投资方里，不仅有韩国投资证券、新韩风险投资、Nvestor等本土机构，还有台湾的半导体公司威刚，以及周杰伦旗下香港上市公司巨星传奇——两个顶级IP背后的资本，就这么握了手。


据悉，自2019年至今，Galaxy迄今为止已累计获得来自31家投资机构的1900亿韩元普通股投资。


同时，公司对赴美上市持开放态度，计划在今年下半年上市。今年 3 月，纳斯达克副主席与纽约证券交易所副主席相继到访 Galaxy Corporation总部，实地了解公司增长战略，并就其在美国资本市场上市的可行性等进行交流，引发行业关注。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/BhPDyYCib8ric8xF9SHDuCiciaibm9kj3uOsTxFOxa3DGiaTP0hibyjLnkTg06J3OPKCia6ne9dw16FGUDWkDXmNFbmsjvIDN8LXE5y0icpiakicDdoSgo/640?wx_fmt=jpeg&from=appmsg&tp=webp)


不过市场也预测，其进军美国上市仍需时日。


核心原因在于公司营收过度依赖权志龙，加上主打的 “娱乐科技（Enter-tech）” 业务尚未取得明显成果。毕竟，虽然Galaxy Corporation 主打结合AI与机器人技术的娱乐科技定位，但从审计报告来看，相关营收几乎为零。业内人士表示：“尽管公司持续提出结合 AI 与机器人技术的娱乐科技愿景，但想要拿出具体成果，仍需要相当长的时间。”


显然，Galaxy Corporation自己也知道“把所有鸡蛋放一个篮子里”的风险。


一方面，公司先是以股权深度绑定艺人，成为利益共同体。去年6月，也就是在年底融资之前，权志龙便从其经纪公司获得了200亿韩元作为签约费。其中，100亿韩元是以股票期权的形式发放，股权比例估计超过2%。而在融资后，其股权价值已经暴涨到200亿韩元。


![图片](https://mmbiz.qpic.cn/mmbiz_png/BhPDyYCib8r8jkCa2sy1ic5t4UkicibEgl0azYolHCibJa8lvMn6jibrZ1ibFBqu1RYacEH1AjAiaeSgkcanTPGHQzU0UGXkEtVNVEk3GaW6ia9GjBpA/640?wx_fmt=png&from=appmsg&tp=webp)


这一招还是有效的。作为股东，2024年5月， 权志龙把“G-Dragon”和“GD”两个商标从YG娱乐转到自己名下，又转给Galaxy Corporation。 现在公司既是他的经纪人，也是他IP的合法持有者。这种“艺人即股东”的深度绑定，既保证了双方利益一致，也让权志龙从“打工人”变成了“资本”本身。


另一方面，Galaxy Corporation 也在积极推进 IP 多元化布局。继去年签下宋康昊与金钟国之后，今年又引进了歌手泰民等艺人；就在几天前，公司还被曝出正在争取“水弹女王”权恩妃的加盟，但最终细节协调出现分歧，转会宣告告吹。同时，在美国与香港设立新法人，并在美国、日本、中国和迪拜设有分支机构，加速拓展海外市场。


Galaxy Corporation CEO崔勇浩将自己的核心经营理念总结为“今天、明天、后天”战略——“今天”的四大业务模块包括IP、媒体、商务和技术；“明天”主要是发展AI和机器人业务；而“后天”则是指宇宙航空领域的业务。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/BhPDyYCib8r9N9OZIpuhI3zCbTMbaaBfwcqJTbYRF7Ls10HVzHPEFlkuRSZQORmA98c7P75TQ0st16bGG8aqu1NibUfW2dmqiaSLkxH7K3apFQ/640?wx_fmt=png&tp=webp)


目前，Galaxy Corporation已在运用AR、VR、全息等技术的内容制作和机器人技术研究及应用等方面取得了成果，并将相关技术应用于多项业务中。吸引超过25万名观众的权志龙的“Übermensch”媒体艺术全球巡展，便是其代表案例。


不难看出，公司的打法是先用超级IP拉起估值，再实现多元业务布局，逐步降低单核依赖。 但至少当下来看，现在手里最值钱的资产，依然是权志龙本人，且他本人短期内看起来并不打算停下脚步。


而Galaxy Corporation要做的，就是在权志龙这棵大树依然枝繁叶茂的时候，抓紧时间，种下更多的种子。


![图片](https://mmbiz.qpic.cn/mmbiz_png/sP99TpzRiaoJdA0boSXMKyzibLugyZCEvycKoQW5Oan35aeho5TT3KUAtFCsuRYkBZKn7PyeHLBEOHlDdWH4c2Ag/640?wx_fmt=png&tp=webp)


结语


作为毋庸置疑的“一人公司”， 权志龙用39场演出、82.5万观演人次，证明了个人IP的价值能有多高。


但这个故事的另一面是：当一家公司超过90%的收入都绑在一个人身上时，它究竟是拥有了一座金矿，还是走上了一条钢丝？


毕竟，资本从来不押注浪漫，它押注的是现金流与可复制性。接下来，Galaxy 要证明的，是它能否在这一引擎之外，建立真正可持续的商业体系。


一个人可以撑起一家公司，但真正的考验，是公司能否走出“一人”。
