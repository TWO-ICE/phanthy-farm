# 出道19年再回初舞台，李宇春的C位之谜竟是……

1月26日，《我想和你唱》第五季如约开播。李宇春作为首期派对来宾登台，见证了来自世界各地的网友演绎《无价之姐》、与三十位粉丝弹琴演唱《再不疯狂我们就老了》、与三位粉丝并肩合唱《今天有朵云爱我》。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/e85sPh5iaL9huKWWhMTkaafaBXpDnhxVh7IxxcwLFJh2CQUOb5vxRHPXHicSJpcGgVlSqhELJkv0BSWnTTrXzrjQ/640?wx_fmt=jpeg&from=appmsg)

19年前，李宇春从湖南卫视的舞台上走出去，在全民瞩目下开启自己的音乐生涯；19年后，李宇春又回到湖南卫视的舞台上，已然从开创先河的民选偶像成长为蜚声国际的顶流艺人。在这期节目中，有带领全家爱上李宇春的妈妈，有2005年见证李宇春出道的交警，也有在理发馆里唱歌的夫妻。当他们毫无保留地向春春倾吐自己十余年如一日的爱意，李宇春一路走来的蜕变与成长，被这些玉米们的故事，打上了坐标。

**与鲜活的人生**

**并肩合唱**

在第五季的首个合唱舞台，李宇春与三十位玉米一同弹唱《再不疯狂我们就老了》。当歌曲进入到副歌部分，台下的乐迷都不约而同地站起身来，一边蹦跳合唱，一边鼓掌呐喊。身处观众席的汪涵为之深深动容，这一刻让他响起了2005年属于《超级女声》的夏天。同样是是湖南卫视的舞台上，同样是这般热烈的氛围中，不同的是，那时的李宇春还处于20岁出头的年纪，稍显青涩地在呐喊声中进入乐坛。那一年的诸凡艺刚刚5岁，在妈妈的陪伴下见证了李宇春正式出道的历史性时刻。如今，她已成为长沙解放西的一名交警，会伴着“平行的画 DI DI DA，下个路口再见吧”的旋律，编了一套指挥交通的交警手势操。那一年的张婉婷也爱上了李宇春，这些年来春春的歌声陪伴她走过了人生的低谷，陪伴她结婚生子，走入人生的全新阶段。如今，她带领着全家人都成为“玉米”，将自己爱人写下的歌词赠与同好。那一年的青春理发店里，中年夫妻唐姐和樊哥叫上左邻右舍，一起为电视中的成都女娃李宇春打Call。自那时起，理发店就成了青春练歌房，唐姐和樊哥总是得闲就唱起春春的歌。如今，他们在舞台上激动地手足无措，一次次地告诉春春“你就像我们家的女儿一样，你是我的骄傲”。那一刻，当这些玉米站在舞台上成为李宇春的“歌搭子”时，他们的喜爱翻开一个新的篇章，为记忆打上一个新的锚点，当下的温暖与治愈，感动着台上台下、屏幕内外每一个人。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/e85sPh5iaL9huKWWhMTkaafaBXpDnhxVhUS21ibBD7to45eLADmgdSjNImoQCRLkugGjwd2p6jzA8GlQSQ13SxJw/640?wx_fmt=jpeg&from=appmsg)

正如李宇春所说，“你们就像星星幕上的星星一样，可能不是每一颗都最闪亮，但是一抬头，就在我身旁。”走过19年，李宇春从湖南台的舞台走向国际顶级秀场，又再次回到这些深爱着她的人身边，看着他们激动的神态，真挚而亲切的目光，听他们讲述与自己有关的故事，她也随之变得自在而松弛。她会将话筒随机递给台下的乐迷，自然而然地为她唱和声；她会对着舞台上的偶像许美静星星眼，回忆起自己高中时候躲在宿舍里偷偷听磁带的日子；她会展示自己的四川话，打趣式地替唐姐和樊哥证明，他们真的与自己合唱了。这也正是《我想和你唱》的魅力所在。让不曾被时光消弭的热爱，变得更加滚烫；让曾被时光掩盖的温暖，吹去浮尘，再次回到心底最柔软的地方。而这份感动，不仅在玉米与李宇春之间传递，也在李宇春与自己的偶像许美静之间传递。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/e85sPh5iaL9huKWWhMTkaafaBXpDnhxVhy1Og12dwoNpD3rK56eZE2w5dGb0UrdCeCKmoF4U5ric3mYlLgkZsQKA/640?wx_fmt=jpeg&from=appmsg)

当晚，阔别荧幕已久的许美静也来到了舞台上。一开始，她稍微有些拘谨和收敛，i人属性明显，但在唱罢《都是夜归人》后，歌迷悉数走到她身边，将热爱娓娓道来；唱完《遗憾》后，台下的刘维动情表白道，“如果你唱歌的时候，你还快乐的话，那就继续唱下去。但如果你想要去享受生活，喜欢你的人还是会支持你，哪怕那是我们的遗憾”。

李宇春也回忆说，她读高中的时候，会在宿舍熄灯以后听许美静的磁带。如果有一天忘记给随身听充电，她还会轻轻咬电池，然后在仅剩的电量中听着许美静的歌声一点点慢下来。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/e85sPh5iaL9huKWWhMTkaafaBXpDnhxVhbcKsgSYEJaHtn7oJF4bN091ubSqvwxVnlpqvUvvsh7UzjRWJWKVs9Q/640?wx_fmt=jpeg&from=appmsg)

播出当晚，李宇春也在微博上回忆道“当她的声音在演播厅响起的时候，感觉时间像是静止了，如梦。那是无比感动而幸福的一刻，也是我最为珍贵的一段校园时光……”不难看出，《我想和你唱》的精髓正在于给人安全感与幸福感，以歌曲为线索，为每一个身处其中的人打造一处温馨与治愈的堡垒，重新感受歌曲中的情绪，重新回忆与之相关的故事，正是人间烟火气，才最抚凡人心。

**从想唱就唱**

**到我想和你唱**

在《我想和你唱》第五季首期节目上线前，互联网上有一个热门的讨论，为何李宇春总在各类活动中稳居C位。在相关话题下，有人回忆起2005年那个万人空巷的夏天以及众人奔走相告的“超女拉票”，李宇春以超350万的现象级票数，引发了《时代周刊》、BBC、NBC的关注；有人回忆起李宇春以先锋的态度与优越的外形获得了时尚圈的青睐，不仅在国内是顶流，国际时尚圈也向她敞开怀抱；有人回忆起李宇春是中国数字音乐史上首位拥有3张殿堂金钻唱片的歌手。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/e85sPh5iaL9huKWWhMTkaafaBXpDnhxVhHZEsjMDQ3sEzcicEYf7FbmARRxbS7ZwOhDia0OAl9qhnHC9Ks6wt3t5Q/640?wx_fmt=png&from=appmsg)

这些头衔和数据共同串联成一个版本的李宇春，她是新锐的、先锋的、高级的，甚至是有一些距离感的；但有意思的是，在《我想和你唱》的舞台上又讲述了另一个版本的李宇春，她是鲜活的、温暖的、让人感到治愈的，仿若回家聚会的感觉。两个版本的李宇春相遇，一边她是华语乐坛时代变革、新旧文化碰撞、东西文化交流的重要符号，另一边她的作品和态度也激励着许多人的生活，将所有加在她身上的符号都具体成一个个动人的故事。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/e85sPh5iaL9huKWWhMTkaafaBXpDnhxVhseKBx8K9dv9ribjEttqP1icfDjIXodicv1ofnyKy2zGbl4FLOcEmTON3Q/640?wx_fmt=jpeg&from=appmsg)

从开创先河的“民选偶像”到蜚声国际的“潮流icon”，她在华语乐坛的剧变与机遇中不断蜕变与成长，《再不疯狂我们就老了》、《野蛮生长》、《无价之姐》等等作品，已经跃升成为一代人的宣言，成为许多年轻人身体力行的生活态度。但在《我想和你唱》的舞台上，这些歌曲的内涵都变得更直观、更丰盈。也许正是有《再不疯狂我们就老了》，才会有青春理发店中的老板和老板娘旁若无人地自在唱歌，享受生活中分分秒秒的快乐；也许正是有《野蛮生长》，才会有被李宇春启发音乐生涯开始创作的年轻人，不计较得失地自在创作，追寻心之所向；也许正是有《无价之姐》，才会有许多女生不再内耗，肯定自己的美丽与价值。如前面所说，与喜爱自己十几年的“歌搭子”玩在一起，李宇春在舞台上呈现出来的状态也不同以往。她不再是可望不可即的顶流，她也和歌迷一样，会对自己喜欢的偶像露出星星眼、为i变e，听着自己喜爱的歌也会放空大脑。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/e85sPh5iaL9huKWWhMTkaafaBXpDnhxVhebyDqNfouddctMmTPu4H7eUrKHQB7TaAUCiaWX3EMsXgMm2h9KzcpKQ/640?wx_fmt=jpeg&from=appmsg)

在合唱时，李宇春和玉米们不再有明确的界限，而是成为一个共同体，为了共同完成一首作品而相互配合、各有分工。有时互为和声，让歌曲显得更有层次，有时也会相互补强，让歌曲更加饱满。在充满温馨和享受的舞台上，所有人一起完成了一首新的作品演绎，打开了另一种表演方式的可能性。从想唱就唱，到我想和你唱，这种通过合唱来重温回忆的方式，演化成对彼时记忆的一种新的感慨。同时，这种感慨也赋予了《我想和你唱》更深的文化内涵和情感意义。明星的音乐作品原本只是普通人记忆中的一个符号，而亲身互动让彼时的记忆有了全新的、不一样的价值。这种富有积极意义的记忆重构让歌曲中的故事，也随之愈发动人起来。

**结语**

2016年，《我想和你唱》横空出世。节目创新地实现了传统媒体与新媒体、移动终端与电视媒体以及明星与素人的互动，一时之间赢得大众与业内的广泛关注。如今，节目来到了第五季，节目创新的并不只是一种音乐真人秀的制作和展演模式，更是真人秀音综中的社会价值与情感价值。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/e85sPh5iaL9huKWWhMTkaafaBXpDnhxVhPzqqibfY9UU9UPaZP8zAJSuWnK8SaxTVvVF7E14Sia6eIcmaJ4v24lNA/640?wx_fmt=jpeg&from=appmsg)

一方面，这一季的节目将目光投向了更广泛的人群，让更多不同地区、不同经历的歌迷都有机会参与到合唱中来，节目组也走到歌迷的生活中，了解他们的成长环境和职业背景，让歌曲不断扩大情感场域，在与“歌搭子”的合作中找到归属感和认同感。另一方面，节目将音乐的力量发挥到了极致。通过合唱的形式，歌迷不仅能依据自己的理解，对音乐作品进行全新的演绎，进行差异化的自我表达与情感释放，还能在温馨与治愈的氛围中，结识“歌搭子”，在共同歌手的召唤下，从“陌生人”转变为“自己人”，展现音乐的召唤力。正因如此，这一季《我想和你唱》以合唱的方式将音乐的魅力和力量传递到更多圈层，让人们真正体会到了“与其遥望，不如合唱”的意义。
