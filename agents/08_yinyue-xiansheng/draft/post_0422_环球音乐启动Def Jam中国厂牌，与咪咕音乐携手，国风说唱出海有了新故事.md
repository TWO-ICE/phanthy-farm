# 环球音乐启动Def Jam中国厂牌，与咪咕音乐携手，国风说唱出海有了新故事

作者 | 范志辉


当环球音乐宣布在成都正式启动 Def Jam 中国厂牌时，这个消息引发的讨论远远超过了一次常规的厂牌发布。


原因很简单——Def Jam几乎完整参与了说唱音乐从街头文化、地下亚文化，走向全球主流音乐工业的全过程。而当这样一个具有高度象征意义的厂牌，选择落户成都，标志着这一说唱音乐领域殿堂级厂牌正式落地中国说唱音乐之都。同时，环球音乐还宣布与咪咕音乐达成战略合作，联合打造业内首个国风说唱IP。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/e85sPh5iaL9jroGqaiaGRMyibs7UxvJgFw3BtlXFo4cvGSIBkVjOwJka09XlSQPWp0ic3iaqibGbibRhgBbYSyET92jvQ/640?wx_fmt=jpeg&from=appmsg&tp=webp)


从左至右：徐毅、亚当 ・ 格兰奈特


这一系列动作共同指向的，已经不只是厂牌布局，而是一场关于华语说唱如何融入全球版图的大胆实验。在全球音乐产业进入高度碎片化与类型竞争的当下，中国音乐如何被世界理解，早已不是“能不能出海”的问题，而是“以什么身份进入全球叙事”的问题。


Def Jam 中国的出现，恰恰提供了一个极具样本意义的观察窗口。


![图片](https://mmbiz.qpic.cn/mmbiz_png/sP99TpzRiaoJdA0boSXMKyzibLugyZCEvycKoQW5Oan35aeho5TT3KUAtFCsuRYkBZKn7PyeHLBEOHlDdWH4c2Ag/640?wx_fmt=png&tp=webp)


Def Jam为何落户成都？


Def Jam所代表的，从来不只是一个厂牌。


创立于1984年的 Def Jam，是全球说唱音乐史上最具标志性的厂牌之一。它的历史，几乎与 Hip-Hop 从边缘文化走向主流文化的过程高度重合。


在说唱尚未被主流社会理解的年代，Def Jam 选择站在街头与社区一侧，让音乐成为真实生活经验的直接表达；而当说唱逐渐进入商业体系，Def Jam 又在制作、传播与艺人体系的层面，帮助这种表达完成工业化升级，却始终没有抽空其文化内核。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/e85sPh5iaL9jroGqaiaGRMyibs7UxvJgFw3FAP3RwTxSRKIeCS3ha5z3MU4iaMZ7Q47D2ICCZsJvBAhMOqMJWMj5NQ/640?wx_fmt=png&from=appmsg&tp=webp)


Def Jam 创始人 Russell Simmons 和 Rick Rubin，以及早期核心成员George Drakoulias


这也决定了 Def Jam 与“制造流行”的厂牌逻辑截然不同。从LL Cool J、Public Enemy 到 Jay-Z、Kanye West，Def Jam 孵化的巨星们持续定义着说唱音乐的审美与边界，其全球发行网络覆盖欧美、日韩等核心音乐市场，成为连接本土创意与国际舞台的关键桥梁。


而此次选择将Def Jam中国厂牌落户成都，则与这个城市的文化底蕴、产业基础、政策支持密不可分。


成都之于中文说唱，并非简单的产业聚集，而是一种长期形成的文化共生关系。从早期地下说唱的自然生长，到逐渐形成稳定的创作者社群、厂牌结构与现场演出生态，成都的说唱并不是被综艺节目或资本“催熟”的结果，而是在城市生活与青年文化中自然沉淀。而这座城市所具备的松弛感、叙事感与强烈的生活气息，与说唱所强调的真实表达高度契合。


正如知名rapper王以太所说， 成都一个说唱的修罗场，你如果能在这里闯出名堂的话，那你在全国就更有可能闯出名堂。 一切的一切，其实回到根源来说，就是有前辈去铺路，然后一代又一代的跟上，才有了今天这么一个局面。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/e85sPh5iaL9jroGqaiaGRMyibs7UxvJgFw3HpIvQmuRzVQBiagm72RdhdXHUicmSmDpDFUQsYcnAgUCHHjOqiaX9AqSQ/640?wx_fmt=jpeg&from=appmsg&tp=webp)


从产业层面看，成都近年来在音乐产业、现场演出、文旅融合等方面的持续投入，也为国际厂牌的长期运营提供了现实基础；从政策与环境层面看，成都对原创内容与青年文化的包容度，使其成为承载 Def Jam 中国的重要土壤。


换句话说，成都为街头文化、现场演出与创意社群的交汇提供了沃土，是Def Jam中国的天然之选。


Def Jam唱片主席暨首席执行官通吉·巴洛贡（Tunji Balogun） 也在发布会上表示：“Def Jam始终立足于最本土的声音——那些直抵自身社群、母语与生活现实的艺术家。Def Jam中国将延续这一传统，将本土文化置于音乐核心。 我们的目标并非复制过往的成功模式，而是支持中国艺术家以自己的方式定义说唱，让他们保持真实、现代，又深植于本土文化。 ”


随着Def Jam中国的发布，厂牌还宣布任命三位中国知名rapper谢帝、王以太与邓典果DDG担任“Def Jam中国特邀召集人”，以更好地激活这座城市深厚的说唱文化与社群。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/e85sPh5iaL9jroGqaiaGRMyibs7UxvJgFw3wNqXCKY8BLSsyMerxpEyMOaCS2TgFosoFo7S4abOhPkeibGa5pej1Hg/640?wx_fmt=jpeg&from=appmsg&tp=webp)


从左至右：许雯静、邓典果DDG、谢帝、亚当·格兰奈特、徐毅、王以太


这三位音乐人本身就来自成都的说唱土壤，也在各自的发展路径中完成了从地下到主流的跨越。他们的角色，并不是被塑造成厂牌符号，而是作为“连接者”，参与发掘、关注并扶持来自中国各地的新生力量，共同参与建设Def Jam中国的说唱音乐生态。


从创作支持、行业资源对接，到全球发行、海外演出与法务支持，Def Jam无疑将以其 品牌传承与全球网络赋能中文说唱， 更像是在为中文说唱补齐“基础设施”。 这种长期主义的策略，在当下快节奏的音乐市场中，显得尤为稀缺。


![图片](https://mmbiz.qpic.cn/mmbiz_png/sP99TpzRiaoJdA0boSXMKyzibLugyZCEvycKoQW5Oan35aeho5TT3KUAtFCsuRYkBZKn7PyeHLBEOHlDdWH4c2Ag/640?wx_fmt=png&tp=webp)


国风说唱出海，有了新故事


如果说 Def Jam 的到来解决的是国际语境的问题，那么与“音乐国家队”咪咕音乐的合作，则补齐了系统能力的另一半。


据悉，双方联合推出的全球首个国风说唱IP，并非一次简单的内容合作，而是将 以中国文化为内核、以海外发行为通路、以数字科技为支撑、以文旅融合为路径，共同搭建音乐产业生态链。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/e85sPh5iaL9jroGqaiaGRMyibs7UxvJgFw3JTia2wEDtz5VEQzez1RaPMeguD0KVYdict3be9z4Sg80m4K4LfxaLfWA/640?wx_fmt=jpeg&from=appmsg&tp=webp)


从左至右：朱泓、徐毅


那么，国风说唱为何两大音乐巨头的突破口？


首先，是 受众基础的成熟 。 随着古韵国风成为年轻人眼中的“顶流审美”，国风音乐正逐步从圈层潮流走向市场主流， 已经不再是小众标签，而是一种具备规模效应与情感认同的内容方向。对许多年轻人而言，国风不只是音乐风格，更是一种文化身份的表达。


其次，是 风格层面的不可替代性 。真正有生命力的国风说唱，并不是对传统元素的简单拼贴，而是通过东方美学、文化符号与叙事方式，对说唱这一表达形式进行重构。这种重构，使其在全球说唱语境中具备足够的差异度。


放眼全球音乐版图，拉美有Reggaeton、韩国有 K-Pop、非洲 有Afrobeats ，它们之所以能够被世界记住，并不是因为更“国际化”，而恰恰是在国际化的外衣下，保留了足够本土的特质。中国同样需要一个能够被世界识别的声音体系，而国风说唱，正在成为最具潜力的方向之一。


而环球音乐与咪咕音乐合作的真正价值，还在于其指向的是一次行业层面的升级，即从“输出作品”转向“输出类型”。 这意味着，“国风说唱”不再只是零散的创作现象，而是被放入一套完整的产业逻辑中进行培育：从内容开发、平台分发、市场传播，到演艺IP、综艺IP乃至街头文化与周边衍生。


正如环球音乐大中华区主席暨首席执行官徐毅 在发布会上所说 ：“环球音乐将 Def Jam 引入成都，并不是把海外模式简单复制到中国，而是希望借助 Def Jam 成熟的国际创意、制作、传播体系，支持本土音乐人持续创作与成长，让最中国、最成都的声音，被世界听见、被世界喜爱。


我们希望能够为行业提供一个服务性的平台，无论你是独立音乐人还是刚刚起步的厂牌，无论你是寻求全球发行还是海外演出机会，也许你需要寻找一个合作的制作人，甚至只是想请一个专业的法务提供建议……Def Jam都愿意去匹配、提供服务。”


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/e85sPh5iaL9jroGqaiaGRMyibs7UxvJgFw3mjvKoYPMicSyXeDmh275mKaUC1cjibX34BjK9Eo0ibMbXexYOnwQoQSHg/640?wx_fmt=jpeg&from=appmsg&tp=webp)


由此可见，环球音乐正在做的，是希望聚合各方资源，致力于打造一个国风说唱平台，将“国风说唱”塑造为独特的创意类型，并推动其进入全球说唱音乐版图，形成有国际传播力、影响力的带着“东方美学”特色的国风音乐。


环球音乐集团市场发展执行副总裁亚当 ・ 格兰奈特 也提到：“中国是全球最具活力、最重要的音乐市场之一，新一代艺术家正持续影 响着本土乃至全球文化。Def Jam中国的成立，再次印证了我们对这一市场的长期投入，我们相信中国的说唱音乐文化必将在全球音乐场景中扮演更重要的角色。”


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/e85sPh5iaL9jroGqaiaGRMyibs7UxvJgFw3E9AOwE0MKWZTAQOExvv9YwxbaC7ibqgVXE9Y15vAZfa7JApecwR4iclA/640?wx_fmt=jpeg&from=appmsg&tp=webp)


环球音乐集团市场发展执行副总裁亚当 ・ 格兰奈特


未来，环球音乐与咪咕音乐将在 音乐内容开发、人才发掘与项目孵化、市场营销与音乐发行、现场演出，以及周边授权商品与以街头文化驱动的创意表达形式等多元领域展开合作 ，还将联合打造国风说唱演艺、综艺 IP等系列高品质国风说唱内容，共同将“国风说唱”塑造为独特的创意类型，推动“华流”成为“顶流”。


对于华语音乐而言，这种类型化输出，远比单点爆红更具战略意义。它意味着，华流不再依赖偶然成功，而是开始具备可复制、可扩展、可持续的国际传播路径。


![图片](https://mmbiz.qpic.cn/mmbiz_png/sP99TpzRiaoJdA0boSXMKyzibLugyZCEvycKoQW5Oan35aeho5TT3KUAtFCsuRYkBZKn7PyeHLBEOHlDdWH4c2Ag/640?wx_fmt=png&tp=webp)


结语


当下，中国音乐出海正迎来历史性机遇。


此次Def Jam中国落地成都，并非简单的国际厂牌入华，而是一次关于本土文化如何被全球理解、中国说唱如何从“被观看”走向“被认可”、华语音乐如何建立国际语境的极好尝试。而当“国风说唱”不再被视为一种小众实验，而是被当作一种全球性的创意类型来专业运营时，“华流”才真正拥有了成为“顶流”的可能性。


我们也相信，用最当代的流行音乐表达形式，传递最中国的文化，讲好最本土的故事，这才是最酷的，这才是“顶流审美”。
