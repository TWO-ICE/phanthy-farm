年终岁末，各大平台纷纷开启了一年来的回望和盘点。

在2024 快手音乐生态大会上，十二、曾惜与Franky弗兰奇、金润吉四位音乐人依次登台，诠释了一场专属于不同季节的寻乐环游秀。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/e85sPh5iaL9iazPWWPiaEibw0ADJeduSblbibVhYiapgMeg0YY2D56GXkjqnpTsQ33Aw9zR0xDj4GkyOujbT9jjofrSA/640?wx_fmt=jpeg&from=appmsg)


十二演唱了《心动反应》，来自快手音乐与讯飞音乐的联袂打造，像是在春夏感受恋爱的心跳，欢快而甜蜜，在快手的整个宣推期间，歌曲相关视频的站内累计播放量超过20亿次；曾惜与Franky弗兰奇将经典老歌《甜蜜蜜》重新演绎为说唱版，带着秋日的惆怅与多情，在过去一年，这首作品多次位列热歌榜单；金润吉带来重磅打造的《慢慢离开你》，是快手音乐的重磅自制，属于冬季恋爱的深情，发行后单月使用量新增63万，歌曲相关视频的站内累计播放量超过13亿次。    


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/e85sPh5iaL9iazPWWPiaEibw0ADJeduSblbibU37CjaibrJyLHnib9Fx0mqAIQmhLfwDeOHnaia8w8ns2VoBU11lHcFibRw/640?wx_fmt=png&from=appmsg)


这三首歌曲均来自于快手的年度企划寻「乐」环游记。通过自制、重制、合制等多种形式，快手将音乐业务的上下游打通，开放歌曲合作，让行业见证了快手音乐生态的无限潜力。

**体量、增量与声量**

“是我太过放纵你，也只能怠慢了自己。我一次一次的，想我有多么爱你。”

这首由怪阿姨演唱的《放纵L》在刚刚过去的2024年中记录了无数快手用户的故事。分手的挣扎、失恋的痛苦以及人生的片刻失意，多条百万点赞、千万观看量的视频作品带动这首歌全面出圈。不仅在登上快手热榜10余次，相关视频日播峰值近1.7亿次，而且快手也带火了站外歌曲收听，《放纵L》登上了流媒体热歌榜TOP1，截至2024年10月，累计上榜次数高达214次。

作为一个窗口，《放纵L》让行业看到快手的平台能力。从《2024快手音乐生态内容报告》来看，**以“π计划”为依托，快手音乐逐步构建起有体量、有增量、有声量的音乐宣推生态。**

从体量来看，过去一年间，快手音乐视频创作者数量同比增长21%，音乐类短视频数量同比增长42%，音乐短视频播放量同比增长45%。音乐创作规模不断攀升，为音乐宣发提供了强大的基本盘，是新的热点音乐强大的动力引擎。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/e85sPh5iaL9iazPWWPiaEibw0ADJeduSblbibusnRJunooLWWLZIgU2ssatADu6RO3tzkB5ibJicgYX3ibJdNND1R0TsAQ/640?wx_fmt=png&from=appmsg)


在2024快手音乐生态大会上，快手内容运营部负责人黄咪咪介绍到，在音乐创作规模不断攀升的基础上，**快手音乐“投入了大量成本建设我们自己本身音乐达人社群”，“推动创作人更好的触达、更加短链的达人裂变和传播方式，进而加强快手整体的歌曲宣推优势”。**

毫无疑问，达人社群的精准助力已经成为快手音乐宣推的护城河。据了解，快手音乐创建了达人社群，制定了专属达人风格标签树，将达人类型分为13个常用一级标签，23个二级标签，持续提升歌曲触达目标人群的精准度。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/e85sPh5iaL9iazPWWPiaEibw0ADJeduSblbibwFQO0JTQW3wGXibretMhZ24Nm7bUubKfrH0Q9bq7ibAm1SH6ItgWLoyQ/640?wx_fmt=jpeg&from=appmsg)


此外，快手还通过接单频次、主页信息、粉丝画像、账号健康度等信息，进一步精细化地呈现达人价值，并通过进入反作弊风控系统，剔除机刷数据的风险，让版权方的权益持续得到保障。    

当大量达人和普通用户在快手上使用音乐进行创作，这一趋势带动了相关歌曲在平台上的收入。与此同时，伴随着歌曲热度的提升，商业合作方的关注也随之被吸引，进一步帮歌曲实现了商业收入上的转化。

由此，快手音乐宣发生态上的优势也得到体现，即版权收益有“增量”。

**在2024年，快手平台上有收入的版权方数量同比增长超23%，为48家版权公司促成137首歌曲的商业化场景合作，价值总金额达1590万元。**


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/e85sPh5iaL9iazPWWPiaEibw0ADJeduSblbib424ZIR81libsf9tso3uUpib9icvBqgswO9icSldTGgagm7WqUWgy1FHH1w/640?wx_fmt=jpeg)


而“声量”则是快手音乐在多类型音乐宣推中沉淀出的爆款特质，那些在歌词上能够引发共鸣、展现出温馨治愈类的时代情绪、歌曲内容具备故事感的作品，总能在快手用户的情绪共振中，持续破圈。此外，在快手上中长视频盘点号、故事类账号的消费优势显著，歌曲本身的故事耦合视频内容，顺利完成了强回流的歌曲宣推链路打造。    

在今年，《不要慌太阳下山有月光》就以温馨治愈的故事感席卷平台。可以说，歌词的灵感本就来源于网友的故事，旋律以简单的吉他伴奏为主，引发用户在视频评论区分享自己的感想和经历，带动了自发创作作品。如此一来，《不要慌太阳下山有月光》从站内火到站外，至2024年10月累计登上流媒体平台榜单的次数高达156次。        


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/e85sPh5iaL9iazPWWPiaEibw0ADJeduSblbibrQ1Eqiby2mJX7NLh0SyRZ3fWbtDhfHwVG9dR5ouM8q7PL1RUjGgImRg/640?wx_fmt=png&from=appmsg)


在快手日益繁荣的音乐生态中，2023年下半年上线的“π计划”无疑发挥了重要作用。

**“当前快手音乐的业务涵盖了歌曲制作、歌曲宣推、歌曲变现，完整的音乐产业上中下游链路。”**快手音乐“π计划”业务的工作人员告诉音乐先声，“‘π计划’对整体生态起到了承上启下的关键作用，‘承上’主要是在歌曲诞生后，结合歌曲的特色和快手平台自身的音乐内容优势，做针对性策划运营，确保歌曲能快速提升平台乃至全网热度，这也为‘启下’打下坚实基础，即歌曲的发行和商业等渠道的变现。”

经过2024年一整年的不断尝试，“π计划”沉淀快手平台的推歌经验，将平台的体量、增量和声量不断反哺到内容方，实现“让大家从爱看到想看，从想看到想听，将流量转化到歌曲本身。”

**合作共赢，**

**爆款挖掘进入3.0时代**

作为刚刚发布一年有余的宣推计划，“π计划”交出了一份颇为亮眼的年度答卷。

在持续释放的宣发势能以外，“π计划”与业内伙伴的联合宣推，成为快手音乐生态中的关键和亮点。整个2024年，**“π计划”联合宣推歌曲累计发布视频数量超5400万，期间歌曲累积视频播放量450亿，点赞量达14亿次。**


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/e85sPh5iaL9iazPWWPiaEibw0ADJeduSblbibIM30UKBO0hTsb3ymibMn8tpmwbymIwZiayan8DNVfiajoUjUB56iaIPtEw/640?wx_fmt=jpeg&from=appmsg)


岳云鹏的《西楼儿女》堪称是2024年最具传唱度的歌曲之一，也是快手上用户使用最多的歌曲之一。在此次生态大会上，《西楼儿女》背后的版权方海葵音乐集团也获得了快手年度最佳合作方和快手年度“π计划”共赢合作方两大奖项。

“我们与快手合作已经有四、五年了，一直有音乐人和作品的输送。”海葵音乐集团渠道部总监郝思嘉告诉音乐先声，“2023年年底，快手开始做'π计划'，让我们感受到快手在这个音乐生态上的决心和他们创新能力。由平台携手音乐产出方，打造音乐爆款，丰富音乐内容生态。”


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/e85sPh5iaL9iazPWWPiaEibw0ADJeduSblbibVRxkngTkCdsYLiceENMQITHjhl1CNIIibZ83vUibXRJAwv5JnhKR2cGzQ/640?wx_fmt=jpeg&from=appmsg)


在郝思嘉看来，**“π计划”最重要的优势在于它强大的承载力和包容度，“艺人向、偏流行或者偏独立的歌曲都有涉及，推广模式比较多元，为不同类型音乐作品提供更广阔的推广空间。”**因此，海葵音乐集团在过去一年见与“π计划”联合推广歌曲十余首，快手站内使用量将近2000万，话题播放量超过30亿次，部分歌曲流媒体的单日播放数据超百万级。

今年，昌禾文化旗下的歌曲《苹果香》也在快手上走红，这种现象级爆火，让昌禾文化看到了平台的宣推潜力。

据昌禾文化创始人张金俊透露，一开始团队并不看好这首作品，是歌曲统筹人的坚持才让他们将这首歌上线发布。然而，**令所有人感到意外的是，这首歌在快手上涌现出大量丰富的玩法，在用户的自发传播中呈现极强的歌曲生命力。**

“在《苹果香》的推广中，有达人的翻唱、达人舞蹈、童声版的翻唱，持续让这首歌更出圈，一度走到了海外。”张金俊回忆到，“快手平台上一直在不断出新内容、新视频，版本出了几十个甚至上百个，每个人演绎风格不同，使歌曲一直保持热度。”后来，在“π计划”的助力下，昌禾文化旗下的《望故乡》等歌曲成功爆火出圈。

事实上，过去一年，快手先后上线了特色DJ摇、氛围慢动作、转场卡点、古风变装等互动性玩法，让歌曲在互动中激发爆款潜力。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/e85sPh5iaL9iazPWWPiaEibw0ADJeduSblbiboADxpXKsoC0wx9wMXxDt9BTRxbbY4TxzdnCH9zI2ZIY0xYxpfBCNow/640?wx_fmt=jpeg&from=appmsg)


不难发现，这种互动性的优势在于一旦歌曲形成了广泛的影响力，即便版权方和平台不再追加宣发投入，用户自发创作也会带动歌曲的持续传播，形成长效的影响力。   

同时，“π计划”也在过去的一年间持续加码音乐宣推的资源支持。**过去一年间，快手为音乐宣推投入了超过13亿的曝光，歌曲宣推现金投入与流量曝光对应价值超3000万。**目前，“π计划”集中音乐分区Banner、专属音乐聚合页、音乐榜单、搜索音乐卡片魔表/模板等站内优势资源，给好音乐更多机会走向受众。

快手音乐宣推体系化、产品化的设计，大大解决了版权方在歌曲冷启时的痛点。“如果没有平台合作，我很难在前期时候找到针对点。”张金俊表示，在与快手“π计划”合作的过程中，版权方与平台共同策划的宣推策略，“而‘π计划’很快就能落地执行，给到热点、粉条、匹配达人等等宣推资源。”          

而在歌曲冷启之后，“π计划”还通过高效的数据驱动和紧密的项目合作，帮助版权方持续推红爆款。郝思嘉介绍到，“π计划”与海葵音乐的合作机制中，快手与版权方会在歌曲宣推方向和效果上持续“互通有无”，保障歌曲热度的提升。“我们会看流媒体平台上的歌曲播放情况，反馈给“π计划”后，他们很快就能做出评估，决定我们是否要追加资源。”            


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/e85sPh5iaL9iazPWWPiaEibw0ADJeduSblbibUGfScKeDtLZQHHwlQPkwFFcIksFFr2PoGYtdyAOhtUomibGaZz7p2icA/640?wx_fmt=jpeg&from=appmsg)


可以说，2024年的深入探索和布局，让行业看到快手音乐与音乐行业密切联动的决心，以及进一步完善、优化、发展平台音乐内容生态的信心。**在2025年，“π计划”将平台与内容方的合作迭代至3.0时代，从营销策划到流量投放，从达人挖掘到定投征稿，全方位赋能内容方。**

据快手工作人员向音乐先声透露：**“2025年的'π计划'主要会在四个方向上有进一步变化。**


首先，合作模式进入3.0时代，我们会结合业务生态中的更多可能，与内容方做更紧密的合作绑定；第二，在现金和流量上进一步加码，同时开放更多站内资源为'π计划'的发展赋能；第三，开放歌曲源头合作，从制作层面联手行业优质项目及内容方，让更多歌曲有优渥的培育土壤；第四，活动形式不再拘泥于线上，同时向线下探索，为歌曲的后链路变现创造更多可能。”


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/e85sPh5iaL9iazPWWPiaEibw0ADJeduSblbibQkc8Y0eVTP3RicbQxJnSgbJzaRvRFSgWtlVzabYiacR0WMl4KPndAcXg/640?wx_fmt=jpeg&from=appmsg)

在《2024快手音乐生态报告》中，“π计划”也明确了未来发展的方向：依托平台庞大的资源，通过歌曲重制、歌曲合制、音乐微综、音乐节、线上IP活动等形式与版权方共建合作。

延续着“π计划”真诚的态度、创新的精神和强大的执行力，与音乐人和合作伙伴并肩前行，探索音乐产业更具活力的未来。

**结语**

眺望数字音乐行业的未来，音乐与短视频的持续合作是必然的趋势。          

一方面，短视频将是音乐传播最为重要的助推器，另一方面，音乐行业也为短视频平台提供了丰富且优质的内容资源。在这一趋势下，两者势必要相互渗透、彼此赋能，才能撬动行业内更大的市场优势。    

只有版权和渠道双方深度合作，在合作过程中共同策划推广方案、根据用户数据反馈及时调整策略等，才能实现资源的最优配置，使音乐作品在市场中获得更好的反响，进而推动整个音乐产业的繁荣发展，在未来的市场竞争中占据更为有利的地位。

从“π计划”到快手音乐生态的打法，正让我们见证了B端的互惠共赢，才能带动C端的长期繁荣。
