# 樱桃克拉芙缇 —— 法式复古甜品，新手友好度满分

> 克拉芙缇（Clafoutis）是法国中部利穆赞地区的传统甜品。
> 最经典的做法是用整颗黑樱桃（不去了）——法国人说"樱桃核在烘焙时会释放杏仁的香气"。
> Q 做了去核版（方便吃），但如果你想追求"正宗"，**留着核**。

---

## 为什么推荐新手做这个

- **不需要分蛋**（不需要打发蛋白）
- **不需要烤箱温度计**（180°C 烤 35 分钟，就这么简单）
- **不需要水浴法**（不像芝士蛋糕那样容易开裂）
- **面糊只要搅拌到没颗粒就行**（没有"搅拌过度"这回事）
- **总共 4 步**：和面糊 → 放樱桃 → 进烤箱 → 出炉

**Q 说过一句很残忍的话**：如果你连克拉芙缇都做失败，那烘焙这条路可能不适合你。

## 食材清单（6 人份，9 寸派盘）

| 食材 | 用量 | 备注 |
|---|---|---|
| 新鲜樱桃 | 300g（去核后）| 也可以用冷冻樱桃 |
| 全蛋 | 3 个 | 常温 |
| 细砂糖 | 80g | |
| 牛奶 | 200ml | 全脂 |
| 淡奶油 | 100ml | 让口感更浓郁 |
| 中筋面粉 | 60g | |
| 香草精 | 1 茶匙 | |
| 黄油（融化） | 30g | 刷模具用 |
| 糖粉 | 适量 | 最后撒表面 |

**食材替换**：
- 没有樱桃 → 用蓝莓/树莓/切片桃子都行（克拉芙缇对水果很包容）
- 没有淡奶油 → 全用牛奶也行（300ml 总量不变），口感会偏轻

## 步骤

### 第一步：准备樱桃

新鲜樱桃洗净，**去核**（用去核器或筷子从顶部捅下去）。

如果用冷冻樱桃：提前 30 分钟从冷冻取出，**不要完全解冻**——半冻状态最好（太软的樱桃烤完会塌）。

**小技巧**：去核的时候在砧板上放一个小瓶子，瓶口对准樱桃底部——核会直接掉进瓶子里，不乱飞。

### 第二步：和面糊

碗中打入 3 个蛋，加入砂糖，**用打蛋器搅拌到糖大致融化**（不需要打发，搅拌 1 分钟就行）。

加入牛奶、淡奶油、香草精，搅拌均匀。

**筛入面粉**，搅拌到没有颗粒。**面糊应该是稀的**——比煎饼面糊还要稀一点，像淡奶油的流动性。

**为什么要筛面粉？** 直接倒面粉会结块——搅拌到颗粒消失至少要 3 分钟。筛入的话 30 秒就匀了。

### 第三步：组装

烤箱预热 **180°C**。

派盘刷一层融化黄油（底部和侧面都要刷到，这样烤完不粘）。

把去核樱桃均匀铺在派盘底部——**不需要排列得整整齐齐**，随意铺就好。

把面糊**缓缓倒入**派盘，倒到 8-9 分满（不要倒满，烤的时候会膨胀）。

### 第四步：烘烤

放入预热好的烤箱，**180°C 烤 35 分钟**。

**25 分钟时**：打开烤箱看一眼——表面应该开始微微上色（金黄色）。

**35 分钟时**：用牙签插入中心——**抽出来干净就是熟了**。如果还有面糊粘着，再烤 5 分钟。

**出炉后的状态**：克拉芙缇刚出炉时会"鼓起来"（像充了气）——**这是正常的**。放 5 分钟后它会自动"瘪下去"，这是它的经典样子。

## 口感描述

**切面**：像蛋挞和布丁的混合体——**外圈烤得微焦（焦糖香），中心是嫩滑的蛋奶冻**。

**入口**：蛋奶的甜香先到——**比布丁更扎实，比蛋糕更湿润**。然后是樱桃的酸甜——**咬到樱桃的瞬间会有一个"果汁爆开"的小惊喜**。

**收尾**：樱桃皮微微的涩味——**这个涩味是"法式"的来源**，它把整个甜品的甜度拉回来，不会腻。

**建议搭配**：一杯不加糖的红茶。茶的单宁 + 克拉芙缇的甜 = **完美的下午茶**。

## 常见问题

**Q：为什么中间没熟/太湿？**
A：烤箱温度偏低。每个烤箱实际温度不一样——**买个烤箱温度计**（十几块钱），确认实际温度和设定温度是否一致。

**Q：为什么烤完太干？**
A：烤太久了。克拉芙缇的理想状态是"外圈凝固、中心微微晃动"——**出炉时中心晃一下模具，中间应该还有轻微的颤动**。

**Q：可以提前做吗？**
A：可以。冷藏放一晚，第二天吃口感更好（面糊和樱桃的味道会融合得更充分）。**吃之前烤箱 150°C 热 5 分钟**。
