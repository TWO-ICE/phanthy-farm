# 孩子一吃奶就睡着？这种情况建议拍醒

![封面图](https://mmbiz.qlogo.cn/sz_mmbiz_jpg/tGtmpweWiaN3iaffYjqTlBdVFAxVtapZwsSeQcnQB1KdspNlqHS6u6P4wiaRZ11l1XibR4sO0FGlY7cw8Eu2G8ZrJg/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/mlXhZS3nFJvuL_VCg-CvyA

关于喂奶，很多妈妈会碰到一件纠结的小事：

**给娃喂奶，经常吃着吃着睡着了。要不要拍醒他呢？还是让他继续睡？**

如果宝宝只是偶尔一两次睡着，没太大关系，可以让他睡。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN3CA2yicW9YWatklJA0jVeGR07vp6qicDyia1ntaS7sFvKeHyoLXkpTVlneqVmglxn4l61p4eQacoic6w/640?wx_fmt=jpeg)


但如果宝宝**经常吃奶睡着**，那妈妈可要留心纠正了：**拍醒宝宝，清醒喂奶！**因为吃饭和睡觉这两件事，一定要从小就分开，尽量让孩子在清醒的时候吃奶，不然以后对妈妈自己的睡眠影响也很大。另外，对于 0~3 个月的小宝宝来说要更加注意。他们的胃容量小，通常 3 个小时就能排空胃里的奶，如果小宝宝睡着了，奶又没有喝几口，就要轻轻拍醒宝宝，让宝宝继续喝奶。总之，吃奶就是吃奶，睡觉就是睡觉，让宝宝在清醒的状态下吃奶对宝宝良好行为习惯的养成也非常有帮助。
