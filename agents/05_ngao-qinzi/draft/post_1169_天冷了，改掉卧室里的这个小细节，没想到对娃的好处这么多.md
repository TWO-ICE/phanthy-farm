# 天冷了，改掉卧室里的这个小细节，没想到对娃的好处这么多

![封面图](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN37NTicgQOyKnMqh8xqWLvkkyGED0pn7hwR2mXdUKfmC63eQcKwMViabeXWbOODiaqPMM9vnqQ5agWOA/0?wx_fmt=jpeg)

“医生，孩子最近流了好几次鼻血，这是怎么回事呀？”

前段时间，在宁波的一家医院，一位妈妈抱着孩子问医生，细看怀里宝宝的指甲缝里还有残留的血迹。那天早上妈妈醒来后，发现孩子鼻孔周围有已经干了的血迹，当时不以为然，**直到后来宝宝又流鼻血，而且血迹范围变大，才着急抱着孩子上医院。**

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/nuqSmia8OqoYvvcDIBBibltrgPgfAIDTmZ9r4BzNlEpVnnzbOxl0dSYEpKVKTOy495zicT9W133uQmDE3ftfqWrxg/640?wx_fmt=jpeg&wx_co=1)

检查后发现娃鼻腔的黎氏区黏膜受损，医生细问下，才知道原来是孩子睡着的时候，**感觉鼻子干痒，就一直抠鼻子，鼻腔黏膜损伤，**所以就流鼻血了。我们也收到过一些妈妈的留言，自从天气冷了，家里的“熊孩子”总是控制不住自己，经常抠出一鼻子血。**当妈的看着是又气又心疼。**

![图片](https://mmbiz.qpic.cn/mmbiz_gif/nuqSmia8OqoYzico5pAS35rzg7Wz0YcveOgia8WlLwwNclGvz9plVwHibgbw1ia7aRkbgB0gobtnvOJKrWcyQZDpM4Q/640?wx_fmt=gif)

其实啊，鼻出血在孩子们身上还是挺常见的，尤其是这个季节。**那到底为啥娃容易流鼻血呢？**


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN37NTicgQOyKnMqh8xqWLvkkSia3btHwSGnibMGewCmb98zIHsIRlJSZA0cSff4sLaAPbEuTJpWJe2AQ/640?wx_fmt=png&from=appmsg&wx_co=1)


鼻腔里的毛细血管丰富又脆弱，特别是小孩子。娃老是抠鼻子，锋利的指甲划过娇嫩的鼻腔，**鼻粘膜慢慢地变薄，**所以可能稍微碰一碰，就容易破裂出血。


![图片](https://mmbiz.qpic.cn/mmbiz_gif/nuqSmia8OqoYzico5pAS35rzg7Wz0YcveOXwqbnsR8l8VNeOrvWCsNicXByIyL9H2deRib1wVJvTM25VWKa2pmVg2A/640?wx_fmt=gif)


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN37NTicgQOyKnMqh8xqWLvkkZzIXzYOGp7ib9NKBzleBNT6rn9f8t1ZCRVZrA2bcMCpOLNtnj34hAKA/640?wx_fmt=png&from=appmsg&wx_co=1)

排除了外伤的可能性，娃的鼻子出血，也可能是因为他生病了！

![图片](https://mmbiz.qpic.cn/mmbiz_gif/nuqSmia8OqoYzico5pAS35rzg7Wz0YcveOqS5qRFIvqH8dx1nic26eIgicOoZhUaOBmCWkYzK8qpZeaxCelOUJFu3g/640?wx_fmt=gif)

比如孩子患有过敏性鼻炎，凝血功能障碍，血小板减少症等等，或者吃过某些抗过敏，抗凝，抗血小板药物等，也会容易鼻出血。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN37NTicgQOyKnMqh8xqWLvkkP1tnP1PibguUYfV7ibia7QqicsdY7aeQQ8AF2ibMj2cAAogIUYFibL1khoKg/640?wx_fmt=png&from=appmsg&wx_co=1)


其实，这个季节鼻出血，最可能就是因为空气太干了。最近很多地方都有“断崖式”的降温，天气又干又冷，呼吸的时候，**干燥的空气会带走鼻腔黏膜上的水分，**就会感觉鼻子干干的。

![图片](https://mmbiz.qpic.cn/mmbiz_gif/nuqSmia8OqoYzico5pAS35rzg7Wz0YcveOQJJia36reN4vAP7xy167B6oHCziaVpu0kfu5CnT1ia5ok9yEuPibshTKvQ/640?wx_fmt=gif)

气温再下降，空调、暖气也要开起来了。天气本来就干，开了这些真的更是“雪上加霜”。在不通风的室内，**湿度很低。**别说小孩了，大人待久了都觉得嘴唇，鼻腔发干，真的太缺水了。

![图片](https://mmbiz.qpic.cn/mmbiz_png/nuqSmia8OqoYzico5pAS35rzg7Wz0YcveO1OAMNsuiahRfw7CyLlU7p5icDTibODYc39hG7IIqyIoFX2IjiaWpe6cgyA/640?wx_fmt=png&wx_co=1)

![图片](https://mmbiz.qpic.cn/mmbiz_png/nuqSmia8OqoYzico5pAS35rzg7Wz0YcveOXIXQADlUJbYarhFjY3G1dOMtas4uaDtSJHUfFDQNY2wcwoHXUKcMZQ/640?wx_fmt=png&wx_co=1)
