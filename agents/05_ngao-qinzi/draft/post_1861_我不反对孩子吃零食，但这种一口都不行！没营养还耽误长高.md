# 我不反对孩子吃零食，但这种一口都不行！没营养还耽误长高

![封面图](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN3EGiaJkqdzRdPIcO7uhFkwQawc4bKbcuDXibyVHibyibzpI7fQPo4xTmAH94Af9TIRzicOvribE2AkNd4w/0?wx_fmt=jpeg)

姐妹们，想跟你们分享一件让我很欣慰的事——**最近，发糕在吃饭上突然有了很大的进步！**

之前发糕经常闹着不吃饭、就想吃零食，没想到现在饭量明显变大，而且每顿都愿意吃蔬菜了~


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN3EGiaJkqdzRdPIcO7uhFkwQLzDia2kvia7PUpyMnvJRG5HHtQbttJkdvAQgff9XljAXSlzFuQq5JLDA/640?from=appmsg&wx_fmt=jpeg)


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN3EGiaJkqdzRdPIcO7uhFkwQDFic2ibibLbv3gyNicy6wCcH200QPJOEtXyWpSBtzm2HOuU1MfsAeSWictw/640?from=appmsg&wx_fmt=jpeg)

全家人的眉头都舒展了一些，实在太不容易了！（虽然也不知道能好多久吧……）

可能有些朋友会奇怪：**咦？发糕不是一直吃饭挺省心的么？**

NoNoNo！那是他小时候~


![图片](https://mmbiz.qpic.cn/sz_mmbiz_gif/tGtmpweWiaN3EGiaJkqdzRdPIcO7uhFkwQyKPIgoQXZYia3I1iaEyPIEqqjx8wtoJ2lgSLVoVWX0aYgs4OGbfQMnzg/640?from=appmsg&wx_fmt=gif)


早两年呢，发糕确实是个吃货，吃饭不用大人操心。但慢慢他就变了，尤其是上幼儿园后，**主打一个和食物过不去**！

好不容易给他准备了营养均衡的饭菜，只等来一句“**我什么都不想吃~**”；让他喝杯奶，他就小口小口抿，半天水位都不下降；蔬菜更是老大难，我好不容易喂进去一片，他还要把菜杆子吐出来！


![图片](https://mmbiz.qpic.cn/mmbiz_gif/2EaFkYu8ISuKNpbp2q056RcSEuglaNYTHicSCGJyOPgNIPpgicaB3rwZicFQiaAW7cEnvIObiaJS3BOibD714Gjwns6w/640?wx_fmt=gif)


很想和这位留言的姐妹隔空握手，同款娃啊有没有！


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN3EGiaJkqdzRdPIcO7uhFkwQzyZYK2oiaBAkTkAtfreck4zHjXFbE44AwD4Qxc1PibClwHxIJuX3e6Ig/640?from=appmsg&wx_fmt=jpeg)


说实话，这种“娃不好好吃饭”的状态还是挺让人焦虑的。去年我和威廉好几次夜聊，都在愁这个事。

但认真反思后我发现，**很多时候孩子不想吃饭，大人是有一定责任的。**

比如我喜欢去买咖啡，有时候带着发糕，就会很随手地给他也投喂一块蛋糕；比如我一直的观念比较“佛”，不太会强迫他一定要吃什么，还真没有严肃地管教他“必须吃菜”这件事。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN3EGiaJkqdzRdPIcO7uhFkwQMVtJrHSzj8FEs2AboAyncY6vUXDARGeVTc4JPRYaiaKcZxc7aT42vEw/640?from=appmsg&wx_fmt=jpeg)


发糕不像哥哥，经常打网球、骑车什么的，**运动消耗没有那么大**。一块高热量的蛋糕送进肚，晚饭当然不想吃。而如果总是由着他不吃菜，时间久了，肠道菌群就会越来越不习惯蔬菜的味道，**形成“挑食”的恶性循环**。

知道问题出在哪了，我决定一个一个解决：给发糕的零食减量，蛋糕甜品先不吃了；饭前至少 3 小时不给他吃水果（尤其是活动量不大的日子），先吃正餐再吃别的……


![图片](https://mmbiz.qpic.cn/sz_mmbiz_gif/tGtmpweWiaN3EGiaJkqdzRdPIcO7uhFkwQUhlZWLP6TCRCWV1CqloD2WF0BR5qqP4e7kq75ia5juIOk3Ij5ibwarOQ/640?from=appmsg&wx_fmt=gif)


其实，**只要我们大人忍住不投喂，孩子的饭量问题还是很好解决的。**因为会饿是本能，发糕如果真的一下午不吃点心，晚饭还是可以吃很多的。

至于吃蔬菜这一点，我的态度变强硬了不少。我会跟他严肃地说清楚，每顿必须吃几口蔬菜，而且不能吐出来！（除非是噎住呛住）

发糕当然也会不情愿，为了让他更好接受，我会**多给他一些种类做选择**。比如“这 3 种蔬菜，你选一个吃一点”、“你要吃带杆的、还是吃不带杆的？”


![图片](https://mmbiz.qpic.cn/sz_mmbiz_gif/tGtmpweWiaN3EGiaJkqdzRdPIcO7uhFkwQrWJK5EOy0P4PcthOkBaibkG6cZfDZy4qtzhvK0O7NEASSHOwsSoDGYg/640?from=appmsg&wx_fmt=gif)


给出选择后，发糕可能会“讨价还价”，比如他会说“我要吃不带杆的，然后把里面的胡萝卜挑掉”。这些我觉得都没问题，可以配合。

我还花了不少心思来跟他解释**为什么必须吃蔬菜**，比如肠道里的小精灵（菌群）有了蔬菜才能好好生长等等。


想跟小孩子讲明白这些道理并不容易，除了有耐心，还要抓住一些**“可教时刻”**。

有次发糕因为蔬菜吃得少，拉便便的时候一直喊“屁股痛痛~”（3 岁的他还不知道这叫便秘）。糕爸就和发糕说：“不吃蔬菜拉便便就会屁股痛哦。”

他明显更听得进去，后面几天每次喂蔬菜，都乖乖地吃了。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN3EGiaJkqdzRdPIcO7uhFkwQDmbNuL83Y1guqcgQmIg29BE4Bda59SBBfY5IpPxP36BHrXMu8ia2CCw/640?from=appmsg&wx_fmt=jpeg)


我跟糕爸复盘时，还发现了一个重要原因。

大家都知道饮食会影响生长发育，其实反过来也成立。**当孩子不在“猛长期”，身体需要的能量没有那么多时，饮食也会随之进入“平台期”。**

发糕这次就很典型，去年很长时间他的衣服尺码都没变化。但今年过完年回来，我们团队小伙伴们一见到他，就说发糕长高了（我仔细一看，他的衣服裤子确实有点短了）。


然后，好像一夜之间他就过了这个**“平台期”**，不用大人催，就可以吃很多了。

跟其他妈妈一聊才发现，大家的娃都有过这个阶段。“7 岁前一直是饭渣，但好像啥也没干，有天孩子突然就很能吃了！”有个同事甚至感叹，还真是“猛长期”的力量啊。

其实年糕小时候也这样，后来差不多到了中班，吃饭就突然变好了。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN1Rwsf3ricfXn6oKbJWMibvCzO5uqX9FGprNE4LgxwyIdE9bJ47WFrAia832ANOgDPpo5JEibvc5oMoTw/640?wx_fmt=png)


**“娃不好好吃饭”**是很多妈妈都会面对的难题，除了做饭半小时娃只吃几口的气愤，还有担心娃会营养不良的烦躁……很理解，我也这样。

但仔细想想，娃吃的真有那么少吗？现在这个时代，**哪有饿到的小孩，只有急坏的老母亲~**

还是放平心态，多做咱们能做的部分，相信你家娃的“猛长期”也迟早会来~
