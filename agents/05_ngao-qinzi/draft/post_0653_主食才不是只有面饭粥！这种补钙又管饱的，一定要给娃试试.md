# 主食才不是只有面饭粥！这种补钙又管饱的，一定要给娃试试

![封面图](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN1HhJ7DwhxlPkNZiaeC249ew8qXEzQY2Ny7H1DchkcWr724iaBGU7Ypx4znS6kibliaK6Qdf69gDOlK4g/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/_5Zb_mTiXTTIzjxcJApVEA

土豆无论是在南方还是北方，超市还是菜市场，都是非常普遍的食材。
大家都习惯把土豆当蔬菜，实际上称土豆为主食，完全没毛病。**主食才不是只有面饭粥，土豆、紫薯、山药、芋头这些淀粉含量很高的食物，都可以部分替代主食**。今天给大家安利一道**燕麦土豆小饼**，10 个月左右的宝宝就能吃，给娃锻炼手指精细动作，完全 OK。

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/FF2OYjRxqc0aw8FfkJFs34I6Sk3o5icXbtmXDLLUHuKFJ9LyGCFMmubA5FicuLJ4u0wt3ILjDqicS9hrZafyDuSxg/640?wx_fmt=jpeg)

而且，像这样和燕麦一起做成小饼，就是一道非常不错的主食，还可以补充维生素和膳食纤维。**辅食小课堂：**即食燕麦一般超市都能买到。超市卖的燕麦种类太多了，哪种才是适合宝宝的呢？教你一招快速辨别：配料表成分**只有燕麦一种**，不需要加其他的糖啊什么的来提味。冲泡方法**可免煮**（用热牛奶或热水冲泡即可）

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/FF2OYjRxqc0aw8FfkJFs34I6Sk3o5icXbyruW0UotuTeeXvtUuhnZL2IUWJ5FC3lHBTe2I7hOSDKukL1wu0lFWQ/640?wx_fmt=jpeg)

△即食麦片的配料表和食用方法小饼里还加了虾皮，提鲜又补钙，如果家里没有虾皮，放一些紫菜同样会更加鲜美哦。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN1HhJ7DwhxlPkNZiaeC249ewdpicdqMwRARg4m4BpNaCQzia8ExLdLAa1s7kaQrcXUYSiaibkiaMkQWb72w/640?wx_fmt=png)


**菜名：**燕麦土豆泥小饼 

**月龄：**10m+**食材****：**即食燕麦 15g、土豆 80g、鸡蛋 1 个、胡萝卜 30g、虾皮 1g、面粉 30g**辅料：**葱末、配方奶、食用油适量**工具：**不粘锅、普通锅


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN1HhJ7DwhxlPkNZiaeC249ew8MbCsYpq3YQeX5icsibh1W6tlic1hAjo3cZjFkY7T0QyAnec2NicR9hITA/640?wx_fmt=png)

1.食材准备：

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/FF2OYjRxqc0aw8FfkJFs34I6Sk3o5icXbkaICw9cq8PClv7guVY98KFOarjia2iapuhSqa702ibVlM0Ujmpyy3l81A/640?wx_fmt=jpeg)

2.土豆、胡萝卜去皮切丁放入蒸锅中蒸熟备用；


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/FF2OYjRxqc0aw8FfkJFs34I6Sk3o5icXbnOtHKVL21QtZ3uOXFSG8NFfDmXOjHCqrwib9ZdegtI1s6mTQMhOicTfA/640?wx_fmt=jpeg)

3.将蒸好的土豆取出放入研磨碗中研磨成泥（或用勺子捣成泥），如果太干可以加入适量牛奶调和一下；

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/FF2OYjRxqc0aw8FfkJFs34I6Sk3o5icXbFCMibIRXWXqachTq1XciaakricrPZsWtGpzZppzrePX7rWbDZGRqpSBfw/640?wx_fmt=jpeg)

4.蒸好的胡萝卜取出切碎，虾皮放入清水中浸泡好然后切碎备用；

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/FF2OYjRxqc0aw8FfkJFs34I6Sk3o5icXbGNpFibNPYINBczbj7rmGlwpSH2QmfcegjicU0bGykoSs9cmkZueia3d1Q/640?wx_fmt=jpeg)

5.  把胡萝卜、虾皮碎、即食燕麦、鸡蛋、面粉一起加入土豆泥中，搅拌均匀；

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/FF2OYjRxqc0aw8FfkJFs34I6Sk3o5icXby4z2UahL3gDzlsm6cRX8eF4A6Sce6lfuA4iajudU6mxsA4K91LLsDHQ/640?wx_fmt=jpeg)

6.手上蘸点水，取适量拌好的馅料，搓成小饼，摆在盘中；

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/FF2OYjRxqc0aw8FfkJFs34I6Sk3o5icXbFibSiaDdZyS8IUQ8fpicl4z1Lue9uQvYRqlvHDsfR0Bia90PM6F7e3vBqw/640?wx_fmt=jpeg)

7.平底锅刷一层食用油，放入小饼，小火煎，可以加一点水盖上锅盖；

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/FF2OYjRxqc0aw8FfkJFs34I6Sk3o5icXbmf9ke7icgS1xCaL6FoSYDlJia7za9UTujNZia2KDPX6jEpSCXrFibygjxg/640?wx_fmt=jpeg)

8.煎至小饼两面金黄即可。

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/FF2OYjRxqc0aw8FfkJFs34I6Sk3o5icXbS6zQN8VljlNCvrwvFYLUDpoFJver0yGwaHs2icxRfhj32sda76IiaCibw/640?wx_fmt=jpeg)
