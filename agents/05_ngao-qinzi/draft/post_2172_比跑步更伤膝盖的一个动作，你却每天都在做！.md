# 比跑步更伤膝盖的一个动作，你却每天都在做！

之前咱们陆陆续续给大家分享了不少运动攻略：爬山、骑行、跳操…… 留言区大家问得最多的就是：


![图片](https://mmbiz.qpic.cn/sz_mmbiz_gif/FF2OYjRxqc39Q5WRwlyRX4yIQTiajxTgbs8Mtag6RuPLLukTXPrOmEQB4SWRMWtvfaVws919EudSkXovGACTtmw/640?wx_fmt=gif&from=appmsg&tp=webp)


理解理解！ 用编辑部@慧慧的话来说：“毕竟咱运动是为了健康+减肥，而不是变成一个膝 盖总是隐隐作痛的胖子 

![图片](https://res.wx.qq.com/t/wx_fed/we-emoji/res/v1.3.10/assets/newemoji/Hurt.png)

 ”


那么，像跑步、骑车、爬山这些运动，到底对膝盖有没有损伤？有哪些膝盖友好的运动？


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/FF2OYjRxqc39Q5WRwlyRX4yIQTiajxTgbKUs6iabPQLmRbNPRaXuHm9MklsR8lXPCNCL59jUX2f8Y5OInb1AIClw/640?wx_fmt=png&from=appmsg&tp=webp)


来啦！今天就跟大家好好聊聊这个话题。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/FF2OYjRxqc39Q5WRwlyRX4yIQTiajxTgbQnn3icwp3Npo4XAjz2nx1tlhsPzD2hvwj0NUcCfuWJpm62TuA8B5rWg/640?wx_fmt=png&from=appmsg&tp=webp)


首先说真的，大家能重视对膝盖的保护，还是值得点个赞的。


因为膝盖（也叫膝关节）可以说是人体内 结构最复杂、负重也最大 的关节，支撑着我们大半个身体的重量。


而且根据咱们的不同的日常活动，膝盖受到的压力还会更重：


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/FF2OYjRxqc39Q5WRwlyRX4yIQTiajxTgb6xNDiaNKoDnJTXsicrnC7NiaDO0kRGbz48KpUgvz2kFh95drEAichP4Plg/640?wx_fmt=png&from=appmsg&tp=webp)


咱们简单换算一下：一个体重 55kg 的女性，蹲着的时候，膝盖需要承受的重量是 440kg，也就是 880 斤！想想都“亚历山大”。


而且扎心的是， 膝关节中的关节软骨是个“消耗品”，使用时间越长，磨损也会越大 ——这也是为什么，很多中老年人都会存在膝关节炎 OA（骨关节炎）等问题。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/FF2OYjRxqc39Q5WRwlyRX4yIQTiajxTgbabZWWzqMQyASFUkFvqNhtLA8VTicvyewL9YzBrYjj1NIdcLus6icT1zQ/640?wx_fmt=png&from=appmsg&tp=webp)


此外，出于生理因素、雌激素水平变化、孕期体重增长、穿高跟鞋等等原因， 女性膝关节 OA （骨关节炎）的患病和发病风险远高于男性。


所以姐妹们，保护膝盖真的值得咱们重视一下，会显著影响到咱们日后的生活品质啊！


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/FF2OYjRxqc39Q5WRwlyRX4yIQTiajxTgbxBHibYKduL2icnic88rPplicDh8Ebx49PQydFjusPDLCyiceoJsuh2D0mjg/640?wx_fmt=png&from=appmsg&tp=webp)


那么，怎么保护膝盖呢？


既然跑步、爬楼梯这些行为对膝盖压力这么大，难道最好的方式，是躺平？？？


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/FF2OYjRxqc39Q5WRwlyRX4yIQTiajxTgblvtz7mU5WKW1wqZ9QHFFs3picU4iaPPufqAicbUjac3ibwJvyWIRicg6g1w/640?wx_fmt=png&from=appmsg&tp=webp)


还真不是。


平躺虽然对膝关节压力小，但躺多了，也有个很严重的“副作用”： 肌肉会慢慢萎缩。


要知道，咱们平时想要膝关节少受点力，需要仰仗膝关节附近的【肌肉】多出力，帮着分担 重量。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/FF2OYjRxqc39Q5WRwlyRX4yIQTiajxTgb5A0eb0DKWjRBrootE5SZkuibkvqagSmicSebjrnMBy2XJbIxHGSfMo6g/640?wx_fmt=png&from=appmsg&tp=webp)


同时，运动量太少也会导致关节滑液循环减慢，长期下来容易引起关节软骨营养不良，运动时更容易损伤。


之前就有研究证实： 比起有跑步习惯的普通人，久坐不动人群发生关节炎的几率高了近 3 倍！


美国医学权威期刊《骨科与运动物理治疗杂志》曾发表一项研究，对比了久坐不动人群、竞技跑步人群、业余休闲跑人群的髋关节和膝关节骨性关节炎的发生率。


结果发现：竞技跑步者的关节炎发生率为 13.3%，
久坐不动人群的关节炎发生率为 10.2%，而健身跑步者的关节炎发生率仅为 3.5%。


所以，想要膝盖更耐造，运动真的少不了。


不仅能刺激关节滑液的分泌和循环，也有助于保持健康的体重—— 对于体重超重 / 肥胖人群，【减轻体重】是缓解关节疼痛、改善关节功能的首选治疗方式。


但具体选什么运动，的确需要好好挑一挑 （以下是一般人群健康建议，严重膝关节损伤需要遵医嘱哦） ：


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/FF2OYjRxqc39Q5WRwlyRX4yIQTiajxTgb8OxsyUKTzoWVliaZ08UucfPzQiaichP5nQJibPia0H55GLpxFtKibouZFrXw/640?wx_fmt=png&from=appmsg&tp=webp)


中国骨关节炎诊疗指南（2021 年版）中提出： 推荐以有氧运动、肌肉力量训练和水上运动为主的运动锻炼。


游泳就很适合膝盖损伤人群。 一来，可以科学减重，二来游泳时膝关节不负重，不会损伤关节软骨。


建议仰泳和自由泳，如果是习惯蛙泳的话，时间不要太长。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/FF2OYjRxqc39Q5WRwlyRX4yIQTiajxTgbueoN2GddnHqib3SaicLh674hTB6aReXXJkfAsjSYgHrQPoaVmP2w6GqQ/640?wx_fmt=png&from=appmsg&tp=webp)


跟跑步相比， 骑车对膝盖也更友好，也更适合大体重人群。


因为骑行过程中，身体大部分的重量会被坐骨分散掉，膝盖承受的压力更小。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/FF2OYjRxqc1MjPgkLC3l91hQf565Hyq96bCfpF4B1R4ic3xUFENfPR6WcfBejCfibnfiaAm3YFlOLtarQfrRSBERg/640?wx_fmt=jpeg&wx_co=1&tp=webp)


但是一定要注意： 骑行前要先调整好座椅高度 ——高度过低，膝关节弯曲角度过大，会增加关节压力，容易导致膝盖疼痛。


座椅太高也会影响发力，有安全隐患，也容易导致腰酸。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/FF2OYjRxqc39Q5WRwlyRX4yIQTiajxTgb4BCqo8xSicIicaHJkgoxpEj0Ljdxf9kwYftqcauH1SR9g4njzaZnC8Cg/640?wx_fmt=png&from=appmsg&tp=webp)


▲正确高度：一只脚蹬到最低点时，


脚掌可以踩实踏板，腿呈直线


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/FF2OYjRxqc39Q5WRwlyRX4yIQTiajxTgbz2jgIdog95wjFt9xQAtv2w7NmfvH6sd6HyUwbx2eicnDKDCbbDTHlVg/640?wx_fmt=png&from=appmsg&tp=webp)


对于体重正常人群，也可以考虑慢跑/快走的运动方式 （ BMI＞25，建议减轻体重再进行跑步等运动，以减轻膝关节压力） 。


但是一定要注意：


穿轻便有弹性的跑鞋，落地时脚中部着地 ，会减少对膝关节的冲击。


另外，运动前记得热身，跑步时也要循序渐进，不追求一下子跑太多的公里数，1 周跑 2-3 次即可。


像下面这几种运动呢，对于膝盖的冲击力会大一些。 如果 平时容易膝盖不舒服 的人群，可以适当减少：


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/FF2OYjRxqc39Q5WRwlyRX4yIQTiajxTgbj63ZXZkLNSRFl63XzZjP6Qd1FmlYOk5FGrqX0WLdmcUvxzLUsTx0JQ/640?wx_fmt=png&from=appmsg&tp=webp)


很多姐妹喜欢跳绳，好上手，掉秤也快。


但这类跳跃运动，对膝盖的冲击力会比较大——尤其是在水泥地跳绳，下落时没有缓冲，就更容易损伤膝盖了 （小孩子体重轻，相对会好一些） 。


所以，如果是膝盖不舒服的姐妹，可以尽量减少这类跳跃运动，同时跳绳的时候要注意， 选择 塑胶地面 ，或者在地上 铺一张瑜伽垫 ，能够增加缓冲。


跳的时候， 膝盖稍稍弯曲，脚前掌先落地 ，也能帮助起到缓冲的作用。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/FF2OYjRxqc39Q5WRwlyRX4yIQTiajxTgbKrj2x4lfDDGM3ch9XpwZhVwMAoQCmiaCJaAUQnAv43UTI20g024MJMQ/640?wx_fmt=png&from=appmsg&tp=webp)


爬山的好处很多，对眼睛好，也能增加体能。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/FF2OYjRxqc39Q5WRwlyRX4yIQTiajxTgbok6Ex7xLdLReicricoWUlrsAnXMM8pTEFmE0zIqShYUuuGtXku6ImVew/640?wx_fmt=jpeg&from=appmsg&tp=webp)


但如果姿势不正确的话，对膝盖的压力也会更大。


而且很多人不知道的是， 下山比上山更容易伤膝盖 ——因为下山时速度比较快，有些人还会选择跑跳下山，膝盖承受地面的反冲力就更大了。


想要减轻冲击力，建议首先不要背太多东西，减少负重。


上山时，身体重心向前，全脚掌着地后再迈另一只脚。


下山时，重心稍微向后，也可以选择侧身下山/借助登山杖，比较省力。
