# 我不阻止娃喝饮料，但这种绝对不行！被曝细菌严重超标，很多家长都在买

![封面图](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN1XGCVmCe2Yia9WSCIgWKbPXNodMvGW80q30Sc2MUJ4saicP4PJ70lHgPVAPvGvW8DICmpElicsibvemQ/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/UyHANjM6n-iHxvLd_R2qDQ

之前热搜上有个话题，看得人慌兮兮的——


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/FF2OYjRxqc1Bfsyw0YTgupdj4L7MK7QKaBibvQAciaHyjAVksY7J4OicKdqjnVJ9BR0BZhN9yxOJwruSJg5PCMpMQ/640)


起因是有人吐槽：买了一个开好口的椰子，喝了之后先是狂吐，第二天凌晨开始又高烧不退、最后发展成去急诊挂水。

一石激起千层浪，不少网友纷纷表示，自己也有类似的翻车经历，身边甚至有人因此危及生命（注：真实性有待考证）。


![图片](https://mmbiz.qpic.cn/mmbiz_png/FF2OYjRxqc1Bfsyw0YTgupdj4L7MK7QKIQB9IVH3ftiaP5ib4Lz5VzwLull2FhHYzHYpkyVSib7GXVruDcMj62iaHg/640)


其实，咱们买整颗的椰子喝，无非是图个“新鲜”。而**这种不知道放了多久的预开口椰子，已经和新鲜不沾边了，倒是会沦为细菌繁殖的温床。**

所以咱们还是建议，想喝新鲜椰子，最好现买现开。

或者超市也有卖盒装的椰子水，挑**成分确实只有椰子水**的，喝起来味道也差不多👇


![图片](https://mmbiz.qpic.cn/mmbiz_png/FF2OYjRxqc2uLLBUulfvsWWSopEaad3UnibwFKYM4QeicDPOmMSiaXe80S3QWBao2qT18k7LyAsz2CCa4SBChteLg/640)


平时带娃出门多，难免有娃想喝饮料。

今天就给大家盘点下**相对比较健康**的饮料，**孩子大了偶尔喝喝，也不用有什么心理负担**（毕竟永远只喝白开水也不现实不是？）

再说了，和娃一起去超市、便利店选选饮料，也是增进亲子感情的机会嘛！


![图片](https://mmbiz.qpic.cn/mmbiz_png/FF2OYjRxqc2uLLBUulfvsWWSopEaad3UbXOS0iczPOAdCaE9ILkUSTZuGKicVeOqYa7clVMHmnFjFOvCBRsNNbJw/640)

NFC 是 Not From Concentrate（非浓缩还原）的缩写，水果原汁经过杀菌后直接灌装，**配料只有果汁**。


![图片](https://mmbiz.qpic.cn/mmbiz_png/FF2OYjRxqc2uLLBUulfvsWWSopEaad3UufzXe3FJMGV8OXbSgdagNv0fLFvLXswUfJN8hT1b2o9e0IhiahlUEibA/640)


由于果汁含量是 100%，喝起来和鲜榨果汁差不多，小瓶装孩子喝着也方便。

但是要注意，NFC 果汁的保质期一般比较短，建议随买随喝，喝不完的要放冰箱。


![图片](https://mmbiz.qpic.cn/mmbiz_png/FF2OYjRxqc2uLLBUulfvsWWSopEaad3UFb1LtvuwAr0qwicfvNWxLAKNKOIvvD0K6ibbaA53jQC3INjDem9XHDDQ/640)

比 NFC 果汁多了一步，先从水果原汁里去掉大半的水分变成浓缩汁，再把这部分水补回来。

有点类似于先把木耳做成干木耳，再把干木耳用水泡开，和原来也没啥区别。


![图片](https://mmbiz.qpic.cn/mmbiz_png/FF2OYjRxqc1Bfsyw0YTgupdj4L7MK7QKkKdngNtBagjlNhlZRnFonFzwnWHw4OEgGUy4SQS5HcUBUNia2W8wCkA/640)


体现在配料表里，一般会有**水+浓缩果汁** 2 项，但还是相当于 100% 纯果汁啦。

当然啦，无论是 NFC 果汁还是复原果汁，糖含量都不低，喝的话要注意适量哦~


![图片](https://mmbiz.qpic.cn/mmbiz_png/FF2OYjRxqc2uLLBUulfvsWWSopEaad3UMrfVKibicR49FVKnnJ9UIsCM5ZdCAdKHibQXvuocvYia00npoNURZt31Rw/640)

可乐过口时那种酥酥麻麻的触电感，喝完再打上一串嗝——可以说是必不可少的降燥仪式！

不过众所周知，可乐不适合给娃喝，而近些年爆火的 0 糖汽水就是不错的替代品。


![图片](https://mmbiz.qpic.cn/mmbiz_png/FF2OYjRxqc2uLLBUulfvsWWSopEaad3UWibYbectycx5kZIFkWb9HAnDgEIPfZF8stcfv87U4KpEj0UzzPYe5bg/640)


从成分上看，确实**没有添加糖，用的都是代糖**，虽然喝着也蛮甜的，但比糖还是要健康很多，偶尔让娃过过瘾也不赖。


![图片](https://mmbiz.qpic.cn/mmbiz_png/FF2OYjRxqc2uLLBUulfvsWWSopEaad3Uia2G3pwicMOv5It7nvVQFgnqXS4Ku5NECXNLpianS1XiakibGic5KpcVXCww/640)

0 糖汽水喝着虽然爽，但毕竟没什么营养。而 0 糖酸奶就不一样了，还能帮孩子补充**钙**和**优质蛋白**。


![图片](https://mmbiz.qpic.cn/mmbiz_png/FF2OYjRxqc2uLLBUulfvsWWSopEaad3U8XlWaHFbb0oKT0iaOAbIxSkyyPy4gdJAs2ysqb9kRgcVicFzibCvbfjQw/640)


啥也不加的纯酸奶，虽然健康，但对大孩子来说味道也很难接受。

孩子不喝的话，再健康也没意义，这种代糖酸奶，至少要比那些添加糖很多的酸奶要强。


![图片](https://mmbiz.qpic.cn/mmbiz_png/FF2OYjRxqc2uLLBUulfvsWWSopEaad3UrSO7hEGgibH5tibgMzNgYFbKVQBhMtfg2U12Uuvhblc3EzIO4GhKwlhA/640)

植物奶只是样子像奶，并没有真的奶。

不过和奶一样，不加糖也能喝出特殊的醇香味，还能补充一点**植物蛋白**。


![图片](https://mmbiz.qpic.cn/mmbiz_png/FF2OYjRxqc2uLLBUulfvsWWSopEaad3Uy6tInAl780TuHW8alPod91dJb95RgKaYQUW5sibEGruhVmxSsZctaBQ/640)


要是牛奶喝腻了，偶尔拿来换换口味也不错。

**如果想追求更高的营养价值，可以选择豆奶**，因为大豆蛋白的氨基酸构成和人体更接近，属于优质蛋白。

对牛奶蛋白过敏、或者乳糖不耐受的孩子来说，豆奶也很友好。

喝的话，也是尽量选择这种**无添加的纯豆奶**，其实就和豆浆差不多。


![图片](https://mmbiz.qpic.cn/mmbiz_png/FF2OYjRxqc2uLLBUulfvsWWSopEaad3U3tqbT5LnhNwH0Gjd3zJKzaIT9vOAHCLuRVzRAZUzrjbojq1FSoKpcQ/640)
