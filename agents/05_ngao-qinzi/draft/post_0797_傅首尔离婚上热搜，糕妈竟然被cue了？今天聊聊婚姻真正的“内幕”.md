# 傅首尔离婚上热搜，糕妈竟然被cue了？今天聊聊婚姻真正的“内幕”

大家好，我是糕妈。《再见爱人》最近讨论度挺高，看到傅首尔和老刘这一对，很多人把他们婚姻出问题的原因归结于**「女强男弱」**。有些小伙伴就 cue 我来聊聊我的看法，说有些自媒体写到了我，还把我跟糕爸当成了女强男弱的典型。我？？？姐妹们，首先声明下，我们家肯定不是这种命题。从我认识糕爸以来，他就是个智商肌肉都在线、学习能力超强、内核又强又稳的「人间清醒」。**「弱」的困惑和体验，他大概从来没有过**。讲真的，跟这种「天选卷王」生活在一起，我不自卑就已经很不错了。

∧ 在健身上很「卷」的糕爸

今天，我想借这个机会跟姐妹们好好聊聊，我对婚姻中强与弱的理解。


![图片](https://mmbiz.qpic.cn/mmbiz_png/eNysDu3qI3fO2WfeSfGszBApKtmiagA2DyXU59zX6S7rVVCGPOTlE5T1CJorqOtEcibZjQiaPOTgeTibKCYW2U3I7A/640?wx_fmt=png)


先问一个关键问题：**所谓婚姻中的「强」，你们都是怎么定义的**？

工作能力强，很会赚钱？还是职位体面，受人尊重？确实，这些都是一个维度的衡量标准，也是从小到大社会灌输给我们的东西。我们就这样顺理成章的接受了。但这些都是外在秩序。在我看来，**真正的「强」来自于内心，来自于直面真实的勇气**。说出来你可能不信，曾经的我一度找不到自信，活在糕爸的阴影之下。结婚头几年，糕爸在工作上非常进取，晋升速度很快，30  岁就升到了 500 强企业总监。他的世界越来越大，我真心为他高兴。

![图片](https://mmbiz.qpic.cn/mmbiz_png/eNysDu3qI3fO2WfeSfGszBApKtmiagA2DsGSR7GhMToicDicGTJ5dkic6ys4w4hBMzmkeg8Du4oF5rOgbmbpw8CILw/640?wx_fmt=png)

但与此同时，他的优秀却成了我的阴影。这个阴影并不是他强加给我的，是我自己甘愿躲进去的。当时我还不具备强大的自我，没有勇气站在阳光下暴露自己的懦弱和无知，于是躲在他的影子里，成了我逃避人生课题的方式。然而逃避没有用，**假装问题不存在，并不能真正解决问题**。人生就是这样，哪怕亲密如夫妻，也无法替对方完成所有事。**有些路，你注定得自己走出来**。所以，当我鼓起勇气走出阴影，下定决心去改变自己生活的那一刻，我就再也不弱了。

![图片](https://mmbiz.qpic.cn/mmbiz_png/eNysDu3qI3fO2WfeSfGszBApKtmiagA2D0uWrvA4ATPyKLul5Eic2R22RZW1CImb9ja28Cg4mm6crMAZUNMMPgVQ/640?wx_fmt=png)

当我为了让年糕睡个好觉，埋头苦读、寻找解决方法时，我强大了一点；当我为了帮助更多妈妈，独自上外网查阅文献、熬夜运营公众号时，我强大了一点；当我愿意走出舒适圈，卖掉房子、离开当下安稳的生活，选择一条荆棘丛生的创业之路时，我强大了一点。在这趟旅程中遇到的所有事，大到战略决策、公司转型，小到一次演讲、一次出镜，都是挑战，却也磨砺得我愈发有韧性。

![图片](https://mmbiz.qpic.cn/mmbiz_png/eNysDu3qI3fO2WfeSfGszBApKtmiagA2D4m7Yy09eo9FVWG4lsuE7GNqVjKSsNguHZD4SosP6n03F9cMug7SpGg/640?wx_fmt=png)

我渐渐也成为了一个强者，但不是因为挣了更多钱，而是因为我有了直面生活的勇气。


![图片](https://mmbiz.qpic.cn/mmbiz_png/eNysDu3qI3fO2WfeSfGszBApKtmiagA2DV9UDoXAnXwTe7tmcpSbOicicwSluYEq84ZyY7muwWqFfp1c2mI0mBm8A/640?wx_fmt=png)


再一个，都说**「势均力敌的婚姻」是最理想的**。事实上，人生那么长，要在每个阶段都刚刚好「势均」是不现实的。哪怕千挑万选一个门当户对的伴侣，无论家境、事业、外表，当下看起来啥啥都般配。这种**短暂的平衡也会被时代变迁、个人机遇、不同的人生选择所打破**。

![图片](https://mmbiz.qpic.cn/mmbiz_png/eNysDu3qI3fO2WfeSfGszBApKtmiagA2DNxic0XL6M6fOJY9ZicWoIJKPMAZxfkU0wSKwOGDzknYGlSibg3vicKDicGg/640?wx_fmt=png)

还是举我们家的例子吧。以前糕爸的收入比我高很多，他是意气风发的外企总监，我是没有什么收入的新手妈妈；之后我做了自媒体，开始有了一点名气；再后来他辞职和我一起创业。这个过程中，两个人的发展并不是匀速的，有时候你跑得快，有时候我跑得快，这都是很正常的。**好的婚姻之所以给人坚实的安全感，并不是因为它永远都有激情，而是双方都有一起爬上山顶的决心**。快的那个人，愿意停下来等一等慢的那个人，有时候还得花力气拉 ta 一把；慢的那个人，感受到伴侣的帮助与爱后，也愿意加把劲儿走出困境。

![图片](https://mmbiz.qpic.cn/mmbiz_png/eNysDu3qI3fO2WfeSfGszBApKtmiagA2DxpjxGDC7FnmYBQhiariaK2agC0Sy8TgDAUrBoa6uV2ofgfCRp3kUMgew/640?wx_fmt=png)

∧ 徒步时互帮互助的我俩，被小伙伴抓拍到了~

从我的「人生导师」糕爸身上，我学习着他的「普通又自信」，他的活在当下，他稳定的内核。同样的，糕爸现在作为一个新手博主，也要向我学习内容创作的经验。**互相扶持、互相帮助，这才是人生的合伙人**。在这种动态平衡中，夫妻双方愿意共同成长，朝着同样的目标前进，才能将亲密关系这支舞，跳得愈发默契协调。

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/eNysDu3qI3fO2WfeSfGszBApKtmiagA2DFt4mo9uP6zb26Sib2aGnzVhUyaNQof5IVNYKhhXvsLqz0EL8fO3x5HQ/640?wx_fmt=jpeg)


![图片](https://mmbiz.qpic.cn/mmbiz_png/eNysDu3qI3fO2WfeSfGszBApKtmiagA2DkgqUKjBfeaE95581hQbIic0x6Xe1ddo02ecPLia0NBAYmLVLTg5SX6ag/640?wx_fmt=png)


最后我想说，无论是「男强女弱」还是「女强男弱」，这种标签都是来自外部视角。

如果伴侣事业好、会挣钱当然很好，但那并不能决定一个家庭的幸福程度。因为**家是讲爱与尊重的地方，不是拼强弱的地方**。如果就因为比自己的伴侣「强」，回家就要当大爷，摆出一副高高在上的姿态让家人痛苦，这份「强」又有什么意义呢？李安那句“作为父亲和丈夫的尊重，要自己去赚”，大抵是这个意思。

![图片](https://mmbiz.qpic.cn/mmbiz_png/eNysDu3qI3fO2WfeSfGszBApKtmiagA2DX9ukQiaNKkf8kPNWu0dWiaS4pJic3qZZYiahNaY75AtsZlAmPia7LA9cr8Q/640?wx_fmt=png)

不管你在外面是谁，回到家里，我们就是家人，在一张桌子上吃饭，讲讲家长里短。**外面的风光和落寞都留在外面，家里不讲社会等级，讲的是爱和尊重**。糕爸在外面管理着几百人的公司，但进了家门，那些光芒和权威就都被关到门外了。在我们的小家中，他就是位普通的父亲，要给年糕辅导作业、陪发糕玩耍、当俩娃的「剥虾工」。

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/eNysDu3qI3fO2WfeSfGszBApKtmiagA2DRKTFsNxXRnP67THJtQMcGDOZBb4emNjPBQdLAmCkUUKrEUpKvqsEsQ/640?wx_fmt=jpeg)

在我面前，他也只是位普通的直男老公，出去玩要帮全家提行李，给我拍美照，事情没做好也要承受来自我的不爽。同样地，我在外面是母婴博主，是女企业家，每天风风火火日程表排满。但回到家里，我会卸下自己的一身铠甲，回归到妻子和妈妈的角色中。会被糕爸笨拙的「直男式情话」感动，遇到困难也渴望被保护，不必什么事都独自承担。都是些很细微的日常，但让我们感到安稳踏实的，不正是生活中这一个个的小确幸吗？

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/eNysDu3qI3fO2WfeSfGszBApKtmiagA2DRDF2LzTLibvbXJVIFuzFEAic7MMtpHiawYzDKqVAN8icg5HWU9EsiagNAdA/640?wx_fmt=jpeg)

更何况，人生海海，起起伏伏，谁能保证自己是永远的强者？**所以越是强的一方，越要忘记自己是强的一方**。大抵上，你很难永远是强的那一方。当外面的世界瞬息万变，让人捉摸不透时，我们就是彼此最坚实的依靠。这些是我对女强男弱婚姻的看法，姐妹们怎么看待女强男弱呢？可以在留言区分享自己的看法或故事~
