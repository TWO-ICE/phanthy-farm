# 剥完橘子摸这个东西，真的会爆炸！快转给家人，让娃远离

最近正是吃橘子的好时节，甜美又多汁还能补充维生素。

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/nuqSmia8OqoYicekVYzY20NqHmLJZZBfYNJ54F9COWnwN3iccQlh4f4ju8lyzB3ZLiapTQEPDWPTW1MZIe8JzM7edA/640?wx_fmt=jpeg)


但之前有个热搜，看了让人吓了一大跳：**剥完橘子再去摸气球，居然会！爆！炸！**

![图片](https://mmbiz.qpic.cn/mmbiz_png/nuqSmia8OqoYicekVYzY20NqHmLJZZBfYNcT6vxAfqbOxkGY7BgETajO15Y29a2XqpAhQoOWuLg8LE8icwOaDYxCw/640?wx_fmt=png)

大家看到这里都开始纳闷：啊？橘子是水果，气球是玩具，八竿子打不着的这两个东西，碰到一起怎么会爆炸呢？

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/nuqSmia8OqoYicekVYzY20NqHmLJZZBfYNRkaHY7iaxPdVibriaicolEsias97lUUQJNAhJBXhK32AEg9Bk36SHx50TOQ/640?wx_fmt=jpeg)


乍一看很奇怪，但这还真不是谣言，是真的!
对此，消防员叔叔也做过一个实验

![图片](https://mmbiz.qpic.cn/mmbiz_png/b96CibCt70iaajvl7fD4ZCicMcjhXMp1v6UibM134tIsO1j5yqHyNhh9arj090oAL7zGhRJRq6cFqFOlDZMleLl4pw/640?wx_fmt=png)

可以看到，只不过是橘子皮轻轻挤出来的几滴汁水，前后两三秒钟，气球就发生了爆炸，这个杀伤力不容小觑喔。

![图片](https://mmbiz.qpic.cn/mmbiz_gif/nuqSmia8OqoYicekVYzY20NqHmLJZZBfYNib8VWianUibKmgFOiaE9JpwuxxvRp2pUIj06In5hxEu0btMN3lsBaVL4Bg/640?wx_fmt=gif)


那到底为啥会这样呢？原来橘子皮中含有**丰富的芳香烃类化合物**，会溶解制作气球的橡胶。只要用手轻轻挤一下，或者在剥橘子皮的过程中，这类芳香烃类化合物就会喷出来，一碰到气球的时候，接触的地方被溶解，气球就爆炸了。既然这样，和橘子属于同一种类的**橙子、柚子、柠檬、小金桔**也能引爆气球吗？

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/nuqSmia8OqoYicekVYzY20NqHmLJZZBfYNQQluWh17NZLnGAzLsSICy8K1gHk4FPmnDQRPgeHgGzvo35O25wlzcQ/640?wx_fmt=jpeg)


**答案是肯定！**柑橘类水果皮里都是含有芳香烃物质的，遇上气球，**都是非常危险的。**所以爸爸妈妈们要注意，最近带娃去秋游、去派对，**吃完柑橘类的水果之后，千万不要马上去碰气球哦。**不然“嘭”的一声，容易吓到小朋友！一定要记得洗干净手！也希望小朋友们都能吃得开心、玩得开心~
