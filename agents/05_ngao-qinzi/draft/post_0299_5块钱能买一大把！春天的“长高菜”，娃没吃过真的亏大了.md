# 5块钱能买一大把！春天的“长高菜”，娃没吃过真的亏大了

江浙沪的春天，菜市场里随处可见各种时令春菜。**春笋、香椿、豌豆、芦笋、马兰头**……一样样嫩得都能掐出水。

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/rrVVklPTzRBTSBcib7r4zebG1pWCVh9yWxkcswibkbMvjgLVypKbtoNibZrrfkqhnaqwVSvKOACqp6BCerh8mo7zw/640?wx_fmt=jpeg)


很多人都爱赶早去菜市场，买点春菜给家人们尝尝鲜。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/rrVVklPTzRBTSBcib7r4zebG1pWCVh9yWcbens9XzYGnlq24Z0dg3hkmupavMH6niaUcyw7GiarlibEldkzhnXkPQw/640?wx_fmt=jpeg)


像香椿，前段时间价格一路狂飙，**云南当地的采购价格，贵的时候都要 300~400 元****一公斤**。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/rrVVklPTzRBTSBcib7r4zebG1pWCVh9yWHjic8eZicIAt8pLEiaLUibbEjFVaKY4fyVdtKN1zzVebr6TVkrZsluyt3w/640?wx_fmt=jpeg)


杭州本地的菜市场，也是贵得离谱，糕爸说家里老人因为香椿太贵没舍得买。👇


![图片](https://mmbiz.qpic.cn/mmbiz_gif/rrVVklPTzRBTSBcib7r4zebG1pWCVh9yWkDnUs2YOnApcjtTkxGsN3ecnpdFN0LZquBicDTRhtLuGwZHibfOm5qEg/640?wx_fmt=gif)


不过，最近香椿已经大降价了，糕妈果断买了一把，给一家子做一份**香椿酱拌面**。


![图片](https://mmbiz.qpic.cn/mmbiz_gif/rrVVklPTzRBTSBcib7r4zebG1pWCVh9yWnb1ibpFGpREcgNZNH5rUicKhXMU75fyxBiaPmiaS3icOa8pS7fAgh9rTbibw/640?wx_fmt=gif)


▲一把有 2 两，到手 13.9 元，确实便宜了很多。

除了香椿酱拌面，糕妈还做了一桌子的时令春菜：**腌笃鲜、清蒸鳜鱼、五花肉菜饭、水芹菜炒牛肉**。


![图片](https://mmbiz.qpic.cn/mmbiz_gif/rrVVklPTzRBTSBcib7r4zebG1pWCVh9yWJn4Rvnl3qPZaWbnaJxevNoicvsgNkq8ibDwquqiaIfiaQoBN2eHznKYPEw/640?wx_fmt=gif)


水芹菜是年糕哥哥很喜欢的蔬菜，搭配牛里脊做了炒菜，大家很快就光盘了。

五花肉菜饭搭配时令的豌豆，吃货发糕忍不住伸长了小脑袋要吃。


![图片](https://mmbiz.qpic.cn/mmbiz_gif/rrVVklPTzRBTSBcib7r4zebG1pWCVh9yWic9Klvga8O0VbLJfYFYqQV7TLK1Lib1YFvZnyMKareeYTvH2AKt9EvhA/640?wx_fmt=gif)


不仅有春菜，糕妈这次做拌面，年糕发糕也特别爱吃，因为用的不是挂面，而是更健康的**燕麦面**。

燕麦面热水泡一泡就能吃，口感还和意面有点像，营养也很不错。（老粉都知道，年糕发糕都很爱吃意面。）
