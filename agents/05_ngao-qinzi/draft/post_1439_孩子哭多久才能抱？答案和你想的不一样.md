# 孩子哭多久才能抱？答案和你想的不一样

每次亲戚朋友欢聚一堂，家里那个软软糯糯的小宝宝妥妥滴成为焦点。

“哇——”聊得正嗨时，宝宝突然哭起来，听不得的几个大人迅速冲过去，抱起哄：**“宝宝不哭，宝宝乖哦！”**


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN3zy2KHWYoaxyV7CkfgeGc1SdiafSUxRaicdt5eSwuiah7127hYoEzseiaUQf03uvmNJ7UyklgrsBZBww/640?wx_fmt=jpeg)


这时，另一拨“过来人”就要抵达现场，开始围攻了：**“宝宝不能多抱，以后会变‘坏’的！”****“要让宝宝哭一会儿再抱，这样才会乖。”**这……听起来无力反驳啊。于是，以后当娃再次啼哭的时候，无论多么撕心裂肺、多么煎熬，老妈妈都竭力忍住。可是，娃要花好久才能安抚好自己不说，小小的身子还时不时抽泣，真是心疼死了！不少老母亲也有同样的困惑——


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/rrVVklPTzRCoR3pf3AZVtAhknlO6NI2HsGDX6b9yDibxZYld6efu5dIDQSmONmwaOCriaU4YHWXt1GXmiboojIJYg/640?wx_fmt=jpeg)


哭声免疫法真的靠谱吗？孩子哭得没力气、自己睡着了真的好吗？孩子哭了马上抱真的会宠坏他吗？


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/rrVVklPTzRCh8jPibBe86V61KsTxsgVBiaPCrOSpDUxibLq2YO8EiajxfXUcC51Tfpk2J6XZWib9fVjMHlT4LlyJXjg/640?wx_fmt=jpeg)


**美国儿科学会**提到：“当宝宝哭泣时，及时回应他们的哭声并不会宠坏他，这也不是溺爱。”

**澳洲悉尼儿童医院**是这样说的：“如果小宝宝在情绪烦躁时得到家长的细心安抚，他们并不会养成习惯或者被宠坏。当宝宝哭泣时，最好的办法就是紧紧把他抱在怀里安抚他。”

**牛津大学医院**认为：“放任宝宝哭而不进行安抚，不仅可能会饿到他，而且会让孩子体内的应激激素一直处于高水平状态，对健康不利。”

看看，权威机构都发话了，妈妈们还纠结个啥？不要压抑自己的天性，快快去把大哭的宝宝抱起来吧！


不过，搞明白宝宝为啥哭，帮他解决问题，才是重中之重。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/rrVVklPTzRCh8jPibBe86V61KsTxsgVBiaxHqPaq6nPWNia54W9hicoTdFWupicyprTb1tgHMicq3murzNnXjYRkjyOg/640?wx_fmt=jpeg)

通过少抱、甚至不抱孩子来达到让孩子学会独立自主、防止被宠坏的那套观点不仅早已过时，还会有碍孩子的健康发育。
多抱抱宝宝，无论对宝宝还是妈妈来说，都是大有裨益的👇：**•抱得多多，安全感满满**当宝宝饿了困了，他们知道通过大哭能够唤来妈妈。妈妈温暖的怀抱里，有美味的食物，有熟悉的摇篮曲，宝宝感到好安心！当宝宝觉得害怕、孤独，他们知道大哭向妈妈求助，妈妈一定会用温柔的语调和温暖的怀抱把自己紧紧抱住。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN3zy2KHWYoaxyV7CkfgeGc1QhibEIo9lUeoyFfibTdiaq98g4OlwSJxAN37FV5UcG5IRN67F9KblFibQw/640?wx_fmt=jpeg)


就是这一件件小事，让宝宝依赖妈妈、信任妈妈。他开始慢慢懂得，只要妈妈在，宝宝什么都不怕，妈妈会为他解决一切。**这就是安全感的来源。**

而放任宝宝哭泣不管，即使只有五分钟，都可能会增**加宝宝的焦虑感**，长此以往，亲子间的关系也会遭到破坏。**•抱得多多，触觉发育棒棒**当宝宝还在肚子里时，触觉已经开始发育了。刚出生的小宝宝皮肤是非常敏感的，而和妈妈肌肤相贴，能**极大促进宝宝的触觉发育**，对**大脑发育**也有好处哦！

有研究发现，温柔的爱抚对宝宝来说就是天然的镇静剂和止痛剂，能让他体内的**压力激素水平大大降低**。抱着宝宝，爱抚宝宝，这就是妈妈想做并且应该做的事，为什么要因为别人的一句话，而忍住呢？

**•抱得多多，妈妈产奶更顺畅**看着怀中依偎的这团小东西，闻着他的浓浓奶香，哪个当妈的不享受这个时刻？多和宝宝亲密接触，能够让妈妈心情更舒畅。只有当妈的心情倍儿爽，**乳汁才会分泌更顺畅，奶水质量也会更高。**一旦妈妈过分压抑自己的情绪，内心焦虑、煎熬，乳汁也会向宝宝传递这种情绪，而且泌乳量可能还会下降。依糕妈所见呢，产后妈妈们已经很虚弱了，抱孩子这事爸爸应该要分担下才好哦。

说了这么多，你，还愿意躲起来看宝宝哭吗？别再纠结多抱宝宝会把他惯坏了。宝宝能被乖乖抱在怀里的日子并不长，珍惜并享受这段最亲密的时光吧！

再过两年，孩子像泥鳅一样就是不愿安分待在你怀里，你会无比怀念这段亲密时光的！
