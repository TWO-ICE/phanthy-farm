# 短短几秒，3岁男孩被电梯夹断脚趾！这个鞋子让人后怕，很多家长都在买

热情似火的盛夏到了，洞洞鞋也重出江湖了。作为这些年最流行的夏日神器，**洞洞鞋百搭、轻便，穿在脚上有软软的「踩屎感」**，许多大人孩子都喜欢。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/2EaFkYu8ISsXsm4ORtXRQKvm8icoEPeiafqSS66iaEcuTp5IKyicAuDnHN6Ff78FNtJE8dv8jj1BlVfzYwnOzf0O2w/640?wx_fmt=jpeg&from=appmsg)


可成年人穿也就罢了，**给娃穿千万要当心！**尤其是在到户外，简直是「危险重重」。

前两年就出过这么一则新闻，长沙一名 3 岁男孩在搭乘扶梯时，脚上的洞洞鞋被卷入，顺带着连男孩的脚也被卷了进去！

救出后消防员发现，**孩子脚趾的一半已经没有了，就连神经和骨头也被卡断……**


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/2EaFkYu8ISsXsm4ORtXRQKvm8icoEPeiafiahG0V2309vVTpxT3RibyfnjuJgAXia9w0Jx6usWQotpegJGJibs5icA1Jg/640?wx_fmt=jpeg&from=appmsg)


图源：湖南都市频道

诸如此类的危险新闻还有许多，央视还专门邀请了消防员进行「洞洞鞋过电梯」的试验。

消防员首先将一只洞洞鞋贴在扶梯侧面，**这时鞋子与扶梯的侧面产生了很大的摩擦力。**

演示人员直言：“鞋子就像被吸附到这个挡板上一样”。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_gif/2EaFkYu8ISsXsm4ORtXRQKvm8icoEPeiafLn0FAGd4cRYLxpj9DumVl4c2QEquJgwZnlUHf8dxTBTBEOHyUQxnTw/640?wx_fmt=gif&from=appmsg)

接着，消防员将洞洞鞋放在梯级侧面，随着电梯行进，鞋子被挤压变形。

几乎是一瞬间，这双洞洞鞋就被电梯侧边的缝隙吸了进去。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_gif/2EaFkYu8ISsXsm4ORtXRQKvm8icoEPeiafmrFwokYxJug3NPjgu36PeoDVFcaDujx3iad8d40oTAprfuyawfPLHCA/640?wx_fmt=gif&from=appmsg)

成年人或许有能力第一时间反应过来，但如果是调皮爱玩、坐电梯不专心的娃呢？想想真是后怕。

为了杜绝诸如此类的事故发生，有些商场甚至已经贴上了**「洞洞鞋请勿乘坐」**的提醒标识。

除了安全问题，像洞洞鞋一类太软太宽松的鞋子，还有一个很致命的缺点——

那就是根本无法固定孩子的小脚。

脚脚在鞋子里滑来滑去容易摔倒不说，还不利于腿型和脚骨骼的发育。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/2EaFkYu8ISsXsm4ORtXRQKvm8icoEPeiafQ3ny5JMD8wB3usI4krjSND7Wec518mzKugOVSle1ZxEEE8PCVE1weQ/640?wx_fmt=jpeg&from=appmsg)


此外，洞洞鞋由于没有足够的鞋跟固定，宝宝走路时往往会用脚趾抓地，长时间下来容易导致脚趾肌腱炎。

严重的甚至可能**引起脚趾变形、指甲问题、老茧等。**

而且大部分的洞洞鞋材质都是塑料或橡胶，虽看着有一个个的洞，**但却不吸汗不透气。**

宝宝稚嫩的脚闷久了，过敏、皮炎、脚气等问题都很容易找上门来。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/2EaFkYu8ISsXsm4ORtXRQKvm8icoEPeiafcJiaOquWbCWsLUReeMI0P5En1z0W3QzQ9cTXDWPibtwh2iau5TqtJCRcw/640?wx_fmt=png&from=appmsg)


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/2EaFkYu8ISsXsm4ORtXRQKvm8icoEPeiafQtX7wqxQCqk63Ao7EBib23u8NwiamjMqt48Zwcd8C1HPM4nKGtA2OTyg/640?wx_fmt=png&from=appmsg)


露趾的凉鞋，**建议学龄前的娃还是别穿了。**

幼儿园的孩子最喜欢你追我赶、跑跳玩耍，走路也不会仔细看路，**常常发生踢脚碰撞的情况。**

这时候如果鞋头没有足够的保护，很容易发生脚趾受伤、甚至指甲整个掀翻的情况。

还有**被踩、被砸、被划伤**的可能性...那滋味，想想都觉着疼。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/2EaFkYu8ISsXsm4ORtXRQKvm8icoEPeiafSicHBpkpHMsA4sFFBrG4IxRQicvQtZLWso8ibgico3VwYnibdWl3iamRvOfA/640?wx_fmt=jpeg&from=appmsg)


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/2EaFkYu8ISsXsm4ORtXRQKvm8icoEPeiafzsrnALCcWw1mEJwKCYgG9KlmKYwiaxOALiaFIrL1p9rEjswiaY2Fg4WLQ/640?wx_fmt=png&from=appmsg)


**人字拖鞋底普遍偏薄，减震能力差。**穿着时脚感仿佛跟地面直接接触一般，能明显感觉到地面传来的震动力。

更糟糕的是，爱跑跑跳跳的孩子还很难抓住鞋子。一不小心，拖鞋飞出去了，自己也摔了个大跟头。

虽然透气凉快，**但这种感觉就跟「裸奔」没什么两样。**同一时间，小脚也暴露在了马路、台阶、电梯、人流拥挤的环境中，非常容易受伤！

所以学龄前的孩子，在家洗澡或偶尔穿穿没问题，出门还是建议别穿了。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/2EaFkYu8ISsXsm4ORtXRQKvm8icoEPeiaf8SLxaVcxsOICm5XdmUSibCAEsiaBs0CJoUia1dF0vm1dMkXIJoftHanjw/640?wx_fmt=jpeg&from=appmsg)

那么，适合娃穿的凉鞋究竟应该怎么挑选呢？


今天就来教大家一个**「挑童鞋三步攻略」**，屡试不爽，保管挑到一双你和娃都满意的好鞋子！


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/2EaFkYu8ISsXsm4ORtXRQKvm8icoEPeiafPImZbNFrwWcRsibBaicZKmyibmlcn1fXrFdib8icesjeO2zm9kTfvicvL8ew/640?wx_fmt=png&from=appmsg)


鞋面和内里最好选择皮革和帆布面料。至于塑料、橡胶等不透气的材质，最好避免。

鞋底以牛津和橡胶鞋底为宜，既防滑又耐磨，而且弹性也好，宝宝走起路来更舒服。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/2EaFkYu8ISsXsm4ORtXRQKvm8icoEPeiaf04pOw3jzBu1b0uzNvtK6vMIHLgl503afwYI0z6qCAJyFicAwFMdGV3w/640?wx_fmt=png&from=appmsg)


这个部分其实是老生常谈了，让我们再来复习下「一折、二捏、三拧、四按」的原则。

**🌟一折****：**对折一下鞋底，弯曲的地方应在**鞋底前部三分之一处；**

**🌟二捏****：**用手捏一下鞋子的后跟部位，**必须有足够的硬度、承托力；**

**🌟三拧****：**拧一拧鞋身，**弯折灵活**，但是不要太软，**且回弹性要好；**

**🌟四按****：**按一下**鞋子内部前掌部位，不能太软**。太软容易影响足弓发育，也会使原本学习控制平衡的小朋友，更加容易摔倒。

看完了怎么挑，咱们再来看看现在有哪些正在流行的凉鞋款式，既能满足呵护娃小脚的需求，还能轻薄透气不闷汗。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/2EaFkYu8ISsXsm4ORtXRQKvm8icoEPeiafbzuLIicrlN5k1ZL79PnW7HJtz6eic7L4xcW43aSibzCnWbEvv6acQecAQ/640?wx_fmt=png&from=appmsg)


**运动凉鞋顾名思义，就是在运动的基础上添加了一些凉爽元素。**

比如脚背上的镂空，能最大程度让空气自由流通，使脚部热量和湿气迅速排出鞋外，有效防止鞋子捂汗和异味的问题。

同时，它也会兼顾运动的安全性。包鞋头、包脚跟、绑带、魔术贴等元素，都能帮助牢牢固定孩子的小脚，减少外力带来的伤害。

夏天当然要玩水呀！

打水仗、吹泡泡机、去小溪里翻螃蟹、捞小鱼、捉虾米...这些快乐的事情，没有哪个娃能不爱！

可带孩子玩水，总免不了一个烦心的问题——鞋子进水后湿哒、不透气，还会变沉变重。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/2EaFkYu8ISsXsm4ORtXRQKvm8icoEPeiafZ7ibJq2SVicEoo5nQLlExI7fXDFWBrLcwQibDGlVb5L3M0JnF0EmzNXtA/640?wx_fmt=jpeg&from=appmsg)


但溯溪鞋却不会。它既能像凉鞋一样四面透气、透水，又能如运动鞋一般**舒适、保护脚趾。**

不仅自重轻，穿着没什么负担，就算鞋子全部湿掉，也不会笨重。

防滑性能强大的橡胶鞋底，即便有水的地方也不用担心打滑，可以稳稳的踏过，**很适合夏天娃户外水边玩耍穿。**

网眼鞋也可以说是夏天必入。

它的包裹性很好，能够牢牢护住孩子的小脚丫。适量的透气孔又能帮助散发汗液和热气，远离闷热潮湿。

从款式上来说，**它很百搭随性**。因为没有太强的运动感，所以女孩子用它来配小裙子也可以。**平时上学、出门旅游、轻量化运动都很合适。**

实用性就更得好好夸夸了。夏天可以单穿，加上袜子还能舒舒服服度过一个春秋。对于会过日子的妈妈们来说，简直不要太香了！
