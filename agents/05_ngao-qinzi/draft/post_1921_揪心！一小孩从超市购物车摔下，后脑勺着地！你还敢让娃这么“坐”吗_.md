# 揪心！一小孩从超市购物车摔下，后脑勺着地！你还敢让娃这么“坐”吗?

![封面图](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN3QdwepHJnMg8wRMkWmzDktYg1IJ51yJALG8pHMibj5ibGyJtNs49WICyulPAxWca7c77uYmkGf3qYQ/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/nDXzllzEimKcePhqrLMcLw

大家爱带娃逛超市吗？别说，现在超市都配备了儿童可坐的购物推车，大人省力，孩子也喜欢，还蛮方便的！东西也买了、娃也放电了。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN3QdwepHJnMg8wRMkWmzDktBJiahDqacnUZ3MOLzUS25SGrUQpBLd4iaQibkQmib453AQXwbcrxpuJyFQ/640?wx_fmt=jpeg)

▲糕妈和糕爸也喜欢带娃去逛超市

但前两天，一则视频疯传，揪起了不少父母的心！


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN3QdwepHJnMg8wRMkWmzDktMlmVkhBlkcjbnU1tHcBDsSb8oYhcJDMouLQE3UyUzaZOsOtlHkcJxA/640?wx_fmt=png)


事件大概就是：一个妈妈带娃在某知名商超里买东西。这家超市的推车特别大，然后推车本身也配备了儿童可坐的座椅、并有一根安全系带。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_gif/tGtmpweWiaN3QdwepHJnMg8wRMkWmzDkthyzictwJ2dA7uce7aO2EVU7wUxe9NU6CEhcic9XlcEb0IBOgP5c6sHsg/640?wx_fmt=gif)


但从这个视频看，**娃比较大了，是站在推车里的。**

视频里的妈妈拿了一件饮料后，还没等娃站定，就着急忙慌地拉了车准备走，**由于惯性，娃直接跌落，并且后脑勺着地。**妈妈和众人赶紧上前查看。

现在就媒体的消息看，据说妈妈调看了监控后便离开，娃应该无大碍。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN3QdwepHJnMg8wRMkWmzDktcsDAI4gP1u1Dr3YCDhIXg1NAZ4jrJMNTKuh2IicABfqgiaxxyPjH2iaVQ/640?wx_fmt=png)


但怎么说呢，这件事本身还是非常危险的，那可是**后脑勺着地**，万一有个什么闪失，真的追悔莫及。

很多人在视频底下批评家长：孩子妈真的没注意好，这么着急就拖车走。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN3QdwepHJnMg8wRMkWmzDkt9AHG5tsAn3O86Lnxs6hiaqgAfGb6wfxF0jVZV4gcPAHZPrzicoOJP9hw/640?wx_fmt=png)


咱们也仔细看了下，那个地方是冷库，孩子妈可能也是怕娃冻到了，一着急就出大岔子，她应该也非常后悔的。


不管怎么说，问题的关键还是：**不应该让娃站在推车里面，**本来就不是个固定的东西，而且围栏高度也完全不够，一动很容易翻下去。


孩子大了，最好还是“走着”逛哈，**小宝宝坐推车规定的专属座椅，且用安全带绑好，而且大人要做好紧密看护，**像糕爸之前带发糕在超市买东西，看到非常感兴趣的商品，也尽量是车不离手。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_gif/tGtmpweWiaN3QdwepHJnMg8wRMkWmzDktiaic4Y0z33trTpEmac333FBalwQbyW8vJxGtIX78KxLoDfgbzt1IicLaQ/640?wx_fmt=gif)


你说万一被别的推车撞到或者溜坡滑走，那也很不安全。

同样需要注意的，还有**自行车的儿童座椅，最好给娃佩戴安全帽、或安装专业的自行车安全座椅，还要系好安全带。**这次糕爸糕妈五一去旅游，租借自行车带娃骑行，这方面也算做的比较规范了。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN3QdwepHJnMg8wRMkWmzDktyRJaVFnLSclem4LuIYVWs7yJibSNiab2F847ibw78ZuaDP39bI87AT68Q/640?wx_fmt=jpeg)
