# 糟蹋卵巢第一名，
竟是这个不起眼的小动作！
很多妈妈每天都在做……


卵巢好了，女人显年轻？
这句话，还是蛮有科学道理的。

卵巢卵巢，顾名思义，是产生卵子的地方，是女性的生殖腺。

这个巢位于子宫两侧，它们通过附着在子宫上的韧带固定在适当的位置，图片已置顶在留言区。

成熟后的卵巢大约相当于一个扁扁的西梅的大小。
它除了保护卵子、排卵以供受精之外，还有一些重要的功能，比如释放雌性生殖激素（雌激素和孕激素）。

雌激素能帮助身体形成一些女性特征，比如细嫩光滑的皮肤、乳房、和较大的臀部，并且有助于生殖周期的形成；孕激素嘛，自然和备孕怀孕、内分泌等都有直接关系啦。

所以你看，卵巢对咱们女人的健康、容颜、身材、生殖，都特别重要。
不注意卵巢的健康，敷再贵的护肤品都没用！
下面这 3 件糟蹋卵巢的事情，别再做啦——

【❌久坐，不爱动！】
每天花6小时或更长时间坐着的女性，比每天花费少于3小时坐着的女性患卵巢癌的风险高43％，浸润性乳腺癌的风险高10％！
所以坐久了就应该起身活动活动，上班的去倒个水，在家的叠个衣服，或者和娃一起多互动一下，对卵巢都是极好的。

【❌抽烟或被动吸烟】
抽烟或被动吸的二手烟，都是卵巢“杀手”，会导致较高的不孕风险、较低的生殖力、较低的体外人工受孕（IVF）的成功率、还有自然流产率会增加。
很多妈妈自己不抽烟，但身边的人制造了二手、三手烟，危害并不比一手烟弱，对卵巢功能的危害都挺大。

【❌去美容院瞎折腾】
一些资质不全的美容院，对自家的卵巢保养项目，总是吹的天花乱坠，什么按摩刺激、精油疗法样样来、还有拿个灯给你照来照去的。
卵巢的位置在身体深处，体表根本就摸不到卵巢，效果又从何谈起呢？
没有任何研究表明按摩对卵巢有作用，硬是一顿猛按，也许还按出事情！

除此之外，遗传因素、化学试剂、某些药物作用也会增大卵巢疾病的概率。

尤其值得提的，还有经常熬夜、饮食不健康（过度节食或者暴饮暴食）、情绪波动大这些，都引起人体激素紊乱、破坏健康的行为，对于卵巢的伤害基本也是立竿见影……

再来说说保养卵巢，其实嘛特别简单，做到下面这些就好——

✅好的生活和作息习惯
✅注意饮食均衡和营养
✅多注意活动活动身体
✅别接受不明保养项目，瞎折腾！

坚持下去，你的卵巢、你的整体健康水平，都会上升很多啦~
