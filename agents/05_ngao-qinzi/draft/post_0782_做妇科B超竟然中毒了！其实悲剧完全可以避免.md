**经腹 B 超 v.s.阴道 B 超**


针对女性子宫、附件、盆腔的检查中，妇科 B 超是最常见的方式，主要有经腹 B 超和阴道 B 超两种，**经腹 B 超就是大家最常见、最传统的那种。**

在适用人群上，二者也有区别，一般阴道 B 超只用在有性生活经验的女性中，在检查前医生会问“有没有结婚啊？”，就是这个原因。

没有性生活经验的女性，也可以选择经肛门的 B 超来进行妇科 B 超的检查，同样也是不用憋尿的。

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/FF2OYjRxqc0xV3nS7Ew7h31fafn9mkmlWvKic33Pb1iclfGECCxLCsOov1vibq5LrGWPFg3tplDFia5LTzM5GHWv9Q/640?wx_fmt=jpeg)


2. 阴道 B 超会不会很难受？

首先，阴道 B 超的探头并不粗；另外，套在探头上面的安全套本身也有润滑剂，能起到润滑作用。

还有，是否难受和医生的操作关系比较大，可以在检查前告诉医生自己怕疼，让医生轻一点。

**在检查的时候注意放轻松，不要太紧张，也可以减轻不舒服的感觉。**


3. 怀孕了可以做阴道 B 超吗？

**在孕早期，**阴道 B 超由于更接近子宫，能更早地发现胎心和排除宫外孕，**相比经腹 B 超更有优势。**

一般来说，超声医生的操作都会很轻柔，不需要担心探头会刺激子宫。**国内外的指南，都没有把早孕期列为阴道 B 超的禁忌症。**

怀孕中晚期的时候，B 超要看的东西（胎儿、胎盘等）已经到了腹腔，这时候就是经腹 B 超看得更清楚了。


4. 阴道 B 超辐射大吗？

我们说的辐射，一般是指电离辐射，这类辐射会导致畸形。但 B 超这种检查手段，**是没有电离辐射的，它利用的是超声波。**

既然没有辐射，就谈不上哪种辐射更大了。

**已经有研究证明，孕早期的阴道 B 超是不会对胎儿有影响的。**
