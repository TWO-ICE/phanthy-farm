# 娃在幼儿园真实的一天，竟然是这样子的！看完开始同情老师……

![封面图](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN2Gm0ea0rOAkicTlkMviaKoMoGJSgNEQCwhsYbagOaWGaicypk19vzbOzDScqCOYHOErTqic5jicicrsxZg/0?wx_fmt=jpeg)

经常有人说，小孩子嘛，不会说谎的。但只有咱这些有娃的才知道，比起说谎，他们那一张张小嘴叭叭叭**胡说八道**起来，才更要命！之前看到一个**幼儿园老师的吐槽**，简直笑到财从四面八方来哈哈哈哈哈：小朋友丢了一块橡皮，竟然没有选择第一时间询问老师，而是用自己的电话手表就报了个警。大班的果然不一样，懂得珍惜维护自己的权益了！谁懂啊，警察、老师、校长、小朋友……齐刷刷大眼瞪小眼的场景，稍微联想一下，脚趾都抠出三室一厅了。

别以为这就是极限了，这条视频的评论区炸出了一堆家长和老师，说出来的故事，真是一个比一个更离谱——

小朋友被蚊子咬了个包，结果你猜怎么着，欸，蚊子是老师养的！这老师还怪全能的，居然连蚊子这种小东西都养得清楚明白。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/rrVVklPTzRDCa3Gw9OXLmmwdYIAa8D3ySwgr3QPqFfRSN9Pb8cKYZt7msrxlrhsxbBFzPa0xUTSicpDAFoicynKg/640?wx_fmt=png)

前有老师养蚊子，后有班上小伙伴替蚊子“背锅”。


蚊子：听我说，谢谢你……

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/rrVVklPTzRDCa3Gw9OXLmmwdYIAa8D3ydJSyM8f9J1jsbibNdCfPnAwqX8nr8mc2DeHFkRVbVK1J03VOnFlW1bA/640?wx_fmt=png)

上幼儿园第一天，孩子放学回家委屈巴巴，说每次老师不理他，每次问老师问题，老师都要他等一下……老师：下次在我的律师来之前，我不会说一句话！


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/rrVVklPTzRDCa3Gw9OXLmmwdYIAa8D3y6eeUahqs9TH2ntoIMyc7yYVyxvxDzYgM0WTI7OQ4YgR2RoiaYVKd2WQ/640?wx_fmt=png)

而且真的很想感慨一下：小孩子真的挺会一件小事，脑补出一个宇宙的。老师鼓励性夸了两句，孩子自信 buff 叠满：“老师说我可以跳级了。”

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/rrVVklPTzRDCa3Gw9OXLmmwdYIAa8D3y91AJkJzkNbE4ssyEtHY8gI5l00BO949ynUKUCF8okSKKibmWMbFziamA/640?wx_fmt=png)

小同桌给自己送了吃的，机灵的小脑瓜一转动：“她指定是惦记我，想和我谈恋爱了。”这敏锐的危机意识，是个当爱豆的料（不是）


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/rrVVklPTzRDCa3Gw9OXLmmwdYIAa8D3yhQe5AVqmop0BfQGrAJ26udyhMibBl60cIia8gciawic1W0XUDLHaM9jHBQ/640?wx_fmt=jpeg)

但怎么说呢，脑洞大点也不是什么大问题，毕竟小朋友的简单直接，有时候更吓人。上课上着上着，突然准备翻窗子，一问原因：“他挡我了”（该说不说，校长有点儿没眼力见了哈）这要没被老师及时当众拦下询问，回家又是一个版本：“妈妈，今天课堂上怪蜀黍挡着我不让上厕所……”
