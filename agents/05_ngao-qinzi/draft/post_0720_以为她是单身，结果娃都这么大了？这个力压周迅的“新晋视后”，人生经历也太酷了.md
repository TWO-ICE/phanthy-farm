# 以为她是单身，结果娃都这么大了？这个力压周迅的“新晋视后”，人生经历也太酷了

**01**这段时间，相信很多人都被“热依扎”这个名字刷过屏。36 岁，打败周迅、闫妮、童谣等实力演员，成为最年轻的飞天奖视后，获奖时对手真心为她鼓掌，连孙俪都在台下为她流泪。

![图片](https://mmbiz.qpic.cn/mmbiz_gif/nuqSmia8OqoZqFNoFvN6NvKCf4WJ2AXdSXdodmiaskGb2j9XZibNgKjxOCeXEdBKLvsib2CKyz58ItDicWhbTYcQ8XQ/640?wx_fmt=gif)

这么多 buff 叠在同一个人身上，很难不让人好奇，这个热依扎到底是谁呢？为啥获个奖能让嬛嬛哭成这样？点进去一看，才发现，诶，确实还挺眼熟的。
这不是《甄嬛传》里，那个生性冷淡的“拽妃”叶澜依嘛！

![图片](https://mmbiz.qpic.cn/mmbiz_gif/nuqSmia8OqoZqFNoFvN6NvKCf4WJ2AXdS71HL48iba51YQDNDXXKCHLpiaKztHwjwDOtZK8oAq1pk1jQiblWTpNSow/640?wx_fmt=gif)

也是《长安十二时辰》中，忠心耿耿、明艳果敢的侍女檀棋。

![图片](https://mmbiz.qpic.cn/mmbiz_gif/nuqSmia8OqoZqFNoFvN6NvKCf4WJ2AXdS3iaXg17Xla6X7vh9I21ibyWibWUvOSyxjzTL6Xm2Tt5t0bNX649libPjRg/640?wx_fmt=gif)

更是《山海情》里，温柔、坚韧、有力量的劳动妇女李水花。她一笑，却把观众给弄哭的经典名场面↓

![图片](https://mmbiz.qpic.cn/mmbiz_gif/nuqSmia8OqoZqFNoFvN6NvKCf4WJ2AXdSNBo3vBNvia0X2ZjYwOHZRQ0Zp5vCMzXv6HDb5SIgzfnAY7DvXXPSejw/640?wx_fmt=gif)

真的是妥妥的剧抛脸啊！尤其是水花这个角色，被她塑造得很丰满、真实，**就像是从村里拉了个姑娘过来拍戏那般自然接地气**。

![图片](https://mmbiz.qpic.cn/mmbiz_gif/nuqSmia8OqoZqFNoFvN6NvKCf4WJ2AXdSicnh7ggwhk7wa48REhrq2Wt9jaH8Jx8ibWSibRDES04eqmia8WGE2eJuEA/640?wx_fmt=gif)

不过演员演好戏、拿奖，不是很正常的事嘛，为啥她能引起全网热议？如果单看奖项本身，这确实没那么值得讨论，但你要是结合她的人生经历来看，就会觉得：**嗯，有被这姐的“翻盘人生”爽到！**


**02**在演戏上，热依扎其实算不上天赋型选手。刚出道时演了不少丫鬟角色，**直到 25 岁才出演到第一个能被观众记住的角色，还是配角**，而同期女演员早已成为当红小花。

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/nuqSmia8OqoZqFNoFvN6NvKCf4WJ2AXdSSxyx5r50fWygwVgjqSrUlzSTJknibic3DI3iakJesPfdGbyfRgHbdIFLw/640?wx_fmt=jpeg)


25 岁，对女演员来说年龄其实不小了，按理她应该要着急了吧？她偏不，依旧在自己看好但不火的剧本里打转，甚至**为了演好一个角色，****拒绝所有通告**，进行了为期一年的疯狂训练，看原著、唐朝史书，练习骑马、跳舞、武术......

![图片](https://mmbiz.qpic.cn/mmbiz_gif/nuqSmia8OqoZqFNoFvN6NvKCf4WJ2AXdS0t7rIu5iaEribZUCvibdBgoUXTJKygOblWIepO4PT3ET1sSIEveHh42Og/640?wx_fmt=gif)

停戏一年，没有曝光度，这对于一个女演员来说影响真的挺大的，很容易就再也查无此人了。幸好，她用超高的角色完成度，打了一个漂亮的翻身仗，也小火了一把。但关注度高了，一言一行总是会被人放大、揣测。2019 年，她如往常一样穿了件自己喜欢的衣服出现在机场，**却被网友骂上热搜，认为她“有伤风化”，用身材博出位**。

![图片](https://mmbiz.qpic.cn/mmbiz_png/nuqSmia8OqoZqFNoFvN6NvKCf4WJ2AXdSg2IbvMD37VvW84xFEP92ibw0vULCc3Ro8jh0uJoXMVHNic0Fz5IutBwA/640?wx_fmt=png)

对此，姐姐的回应也是很敢了：他们怎么说对我不会有影响。


![图片](https://mmbiz.qpic.cn/mmbiz_gif/nuqSmia8OqoZqFNoFvN6NvKCf4WJ2AXdSj2zLYBoIiaG87ibs2W01AtibX7VhJicspykCXicnVEvM72Yjkiavdia9MFNyw/640?wx_fmt=gif)


不理智网友的谩骂攻击依旧在继续，而她也如自己所说的那样，**并不受外界影响，依旧为自己的人生做着很酷很飒的选择**：突然官宣生女、哺乳期在条件艰苦的剧组拍戏数月......

![图片](https://mmbiz.qpic.cn/mmbiz_png/nuqSmia8OqoZqFNoFvN6NvKCf4WJ2AXdSuiaqsNzgfuW2d7JatYbF7RhcQeUTeibtzgiaVptagGUMW85sUj09qnELA/640?wx_fmt=png)

曾经因为争议对她有偏见的人，这次都被她的演技折服了。

![图片](https://mmbiz.qpic.cn/mmbiz_png/nuqSmia8OqoZqFNoFvN6NvKCf4WJ2AXdSWRibOx0xtg76rHhAtpgHFHdQibnTGt0bNF3lgiasiaicYqRSqDtH5mFrBrA/640?wx_fmt=png)

她也因此，成为去年呼声最高的白玉兰奖获得者，但谁也没想到，她会与这个奖失之交臂。一时间，热依扎没拿到最佳女主角成为全网意难平。

![图片](https://mmbiz.qpic.cn/mmbiz_png/nuqSmia8Oqoam6mecjvicbPOkjvkY9HTUoSfYZ6bOhqOXKiaFafadFFH3SdyLibAmkeczX6LBJltl0HQLciaeJQYCyw/640?wx_fmt=png)

但她自己倒是看得很开，用一以贯之的人生态度来解释就是：**有些东西，你早晚会有的，只是比别人慢一点。不用去羡慕别人，不用着急，凭你自己的能力会得到的。**

![图片](https://mmbiz.qpic.cn/mmbiz_png/nuqSmia8OqoZqFNoFvN6NvKCf4WJ2AXdS6IiaXxDQVXONbva2SqdGrSGkzh3Eg479ibk4kbALM1qv25mfLbAO7riaQ/640?wx_fmt=png)

而今天，她真的做到了。

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/nuqSmia8OqoZqFNoFvN6NvKCf4WJ2AXdSicAXY1ImlKx4uiczu2iboDomEhEYmlfs68vYmWRHPgpKWKR3p9RibyIr9g/640?wx_fmt=jpeg)


不被外界所影响，脚踏实地，一步一步朝着自己的目标前进，虽然成果可能会慢一点，但凭借自己的能力最终都会得到的。在大部分人都浮躁的当下，能有这样的觉悟，实在可贵。**03**热依扎获奖更让人共情的一点，还在于妈妈这个身份。前面说到了，她是在哺乳期拍摄的《山海情》这部剧，咱们当过妈的都知道，这时期兼顾带娃和工作有多不容易。而且这部剧的导演追求自然真实，大棚里的蘑菇都是演员们亲手种出来的，拍摄时又臭又热，很多演员都撑不住，但**在里面呆的时间最长的热依扎，却从未有过怨言**。

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/nuqSmia8Oqoam6mecjvicbPOkjvkY9HTUoialD5pF21vgFY2pAiaeLoQnYyBG7Faunalwt2laCEftb42iafhTMtaVKA/640?wx_fmt=jpeg)


作为一个新手妈妈，她珍惜每一个给自己的工作机会，感激每一份遇到的善意。**甚至，在飞天奖的颁奖台上，将获奖的光环分享给了另一位女性——跟着她去戈壁滩上照顾孩子的月嫂。**

![图片](https://mmbiz.qpic.cn/mmbiz_png/nuqSmia8OqoZqFNoFvN6NvKCf4WJ2AXdSA5D9G0gh3wTVR4KhEgtxuEibxjGU1Wyia9HtKsZG2XNvh3CTY32mhvWg/640?wx_fmt=png)

在很多采访中，她都会为哺乳期的女性发声，用自己的经历告诉大家，**妈妈并不会因为有了孩子工作就做得不好了，她们甚至能完成得更好**，请多给妈妈一些机会。

![图片](https://mmbiz.qpic.cn/mmbiz_gif/nuqSmia8OqoZqFNoFvN6NvKCf4WJ2AXdSWfuGSoc8OOPdZv9TQOzRG2u1sWhevdLZkWG8UEqTeFuiccZ3DALXreA/640?wx_fmt=gif)

她还曾经在微博上分享过自己的背奶日常。荒野中、火车上、化妆间、汽车上......都可能是她吸奶的场所。

![图片](https://mmbiz.qpic.cn/mmbiz_png/nuqSmia8OqoZqFNoFvN6NvKCf4WJ2AXdSMVjOsp7EICjt3PiabG7M1SJgctgwbO0uAic2uGQe516ichFSgvPU20uPA/640?wx_fmt=png)

对此，有人不解，质疑她过度强调为人母的不易，在贩卖人设；有人辱骂，认为她不分场所吸奶，不得体、丢人。这些人怎么想，热依扎并不在意，她分享照片的初衷，只是想告诉大家，**哺乳、吸奶并不是什么羞耻，哺乳室的不完善才是。**

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/nuqSmia8OqoZqFNoFvN6NvKCf4WJ2AXdSibQSdSLz7MUiaFuNJB7YumYR4FS7HOxrYdm4UYznjr3WaOkicicbkKqTlQ/640?wx_fmt=jpeg)


她做这些，只是想以一个公众人物的影响力，**向社会宣传哺乳期的不易，让妈妈群体获得更多理解与帮助**。

![图片](https://mmbiz.qpic.cn/mmbiz_gif/nuqSmia8OqoZqFNoFvN6NvKCf4WJ2AXdSTzmlgsJEXZN7bLjKK0kY7icAvNb83qQvn5qkR0YshIYiaxA5Pr0SMLKw/640?wx_fmt=gif)

比起女明星当妈，热依扎其实更接近于普通人当妈的状态，有处理哺乳期与工作的辛酸，也有陪娃共同成长的小确幸。比如，当看到孩子努力地学习翻身，翻不过去了也要翻，不会哭也不会闹，就好像看到了婴幼儿期的自己，感叹自己原来也有过这么好的时候。

![图片](https://mmbiz.qpic.cn/mmbiz_gif/nuqSmia8OqoZqFNoFvN6NvKCf4WJ2AXdSERILCRo72ETjWibHweo4icxwrI8xHNOia3pXIH4jpViaptOX6VLRQW8Gyg/640?wx_fmt=gif)

又比如，活了三十多年，突然不知道人生是为了什么，而孩子给了自己人生一个重启的意义。

![图片](https://mmbiz.qpic.cn/mmbiz_gif/nuqSmia8OqoZqFNoFvN6NvKCf4WJ2AXdSvvXlPhBcnDticPDxYcno4NKlvAZwfPlkib3icf9NdxfRiadezHFfTAwjoA/640?wx_fmt=gif)

不管是育儿过程中的艰辛，还是乐趣，她都能大方与你分享，就像身边能遇到的知心姐姐一般亲切。


可能有人会觉得，她做得好完美，工作有成绩，孩子又带得好，我好像很难办到。没关系啊，每个人都有自己的课题，不必去羡慕别人，只要把自己这套题做好，就已经能有很多收获了。**如果她的一些言行与经历，给到了你治愈与力量，那这就是热依扎这样的女性被更多人看到的意义。**（文中图片来源于网络）**参考资****料**:
