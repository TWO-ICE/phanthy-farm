# 《甄嬛传》都没捧红她，36岁却靠“卖惨”冲上热搜！细节曝光后，无数妈妈狠狠共情了

电视剧虽然没捧红她，但一次「卖惨」的采访却让她冲上了热搜。

在某节目中她分享到，生完孩子去剧组面试时，**突然“觉得自己好丢脸”。**


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/nuqSmia8OqoZWVqV7tzYF8TgEQcFl2BX95TXoK4n7KibD49icc3Ro7nARM6sjxkc54IqvJlef0sYE7my5veY9kEew/640?wx_fmt=jpeg)

因为不自信，心里积压了许多外人不知道的压力。每一次工作前都会提前半个小时做准备，生怕成为别人的麻烦。

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/nuqSmia8OqoZWVqV7tzYF8TgEQcFl2BX9AEco4ytMkNFoTpCr0wXmkHV6wvRdZQnuyAAqTNuEjZsb2zYPMYiaRHQ/640?wx_fmt=jpeg)

真正进组后也有许多不易，比如带娃一起拍摄、边拍边喂奶等等。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/2EaFkYu8ISvyJSOj50icrl8zQC09D5IMDJSy8p7qYC2R2ibTuL5q0ckyMLJdq0B7oXib4d7fZjGWcdM1ornuYOJDw/640?wx_fmt=jpeg&from=appmsg)

视频一出，妈妈们都狠狠共情了。明星况且如此，更何况我们普通人？

先前也有许多姐妹在后台留下了她们找工作的故事。

**很大段，很真挚，同样也很令人鼻尖一酸。**


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/2EaFkYu8ISvyJSOj50icrl8zQC09D5IMDMgx3nukxuvhLo4B6ppRxdw24hnia3qW8NjzcAz1UIliaSHLDx8cJnibicg/640?wx_fmt=png&from=appmsg)

出去找工作没人带娃，可在家又没「地位」；害怕被拒绝、被讽刺、受挫丧失自信心，但更怕花别人钱花得没有底气……

这些都是妈妈们常有的担忧和焦虑。

**今天我们采访到了 3 位再就业的妈妈，一块听听她们的故事，或许能给你一些鼓励和方向。**

**把喜欢变成****职业**

**还收获了志同道合的朋友**


**@莹莹，4 岁女孩妈妈****在家钩毛线，做鞋袜包包小摆件**

**每个收入 20~300 元不等**


娃大概 3 个月的时候，一次偶然机会在网上刷到了毛线钩织的小鞋子，当时内心一下就被击中了。

结果一问价格，好家伙！居然要近 200 块？**算算几块钱的毛线成本，还不如自己动手呢！**

说干就干，我连夜从网上买了基础的 DIY 工具包，然后对照着视频，一针一线的学习着，**结果就一发不可收拾的开启了我的钩织之路……**

甚至还会带着上学校炫耀：你们看，这是我妈做的！就连幼儿园老师都来要链接……😂

**开心之余，我也从中发现了小商机。**索性抱着试试看的态度，在母婴群里发了自己的成果，没想到群友们纷纷抢着下单。

一来二去，我的钩织小铺便成了。卖些成品，也接图定制，单个售价在 20~300 元不等。

每天送完娃去学校或等她睡着后，我就在客厅打开平板，摆点小零食，勾着毛线追着剧，这副业做得简直美滋滋！

**02**

**门槛低、成本低**

**从爱吃水果变成「卖水果的」**


**@萍萍，两个孩子妈妈****开过婴儿洗浴店**

**现在是社区水果日用品团购的团长**


说起做社区团购的契机，其实还挺不好意思的。最大的原因就是——我们一家人都太爱吃了！

祖孙三代 8 口人，各个都是水果迷，每个月光这方面的开销就要小几千元。

**但我们住的小区又是新楼盘，周边没什么配套，零星几家水果店卖的贵还不新鲜。**

于是全职在家的我一合计：要不搞个社区团购？

起初只是几个相熟的邻居组个微信群，每周我会自驾去边上的农贸市场批发水果，顺带给大伙带一箱，赚个油钱。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/2EaFkYu8ISvyJSOj50icrl8zQC09D5IMDZhb7iaHGNWbty0Lv6zrCdAM9FqwHuWMROW20oJrySnhn7ibD6z3t0Xog/640?wx_fmt=jpeg&from=appmsg)


渐渐地群里人数越来越多，需求也越来越广。

**从团草莓车厘子，到买米、买油、买洗浴用品...看着生意日渐红火，想要扩张的心也蠢蠢欲动。**

通过摆摊试吃、扫码进群领水果、拉新用户送红包、买就送鸡蛋等方式，我迅速组建了第一个 500 人团购微信群。

同时也物色了小区一楼一间出租房，正式作为小生意的「落脚点和提货点」。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/2EaFkYu8ISvyJSOj50icrl8zQC09D5IMDxK7MS5qkgOCvNA8AWMI9GThouaXMDbKzPhMGPonzXiaqumpKphoF2Rg/640?wx_fmt=jpeg&from=appmsg)


客源稳定后，能够谈到的源头供应商便越来越多了。现在我还开展了超商代购、集体订花送花等各项业务，**邻居得到了方便和品质好的物品，我也赚到了一些小钱。**

并且时间上还挺自由的，白天可以接送娃上下学，周末过节也可以闭店出去玩，多劳多得，少劳也轻松哈哈~

**03**

**利用亲人现有资源**

**拓展自己的小生意**


**@阿离，二胎孕晚期****曾是母婴公司编辑/编导**

**现通过互联网送盒饭**


全职带娃的第二年，也是我比较迷茫的一年。意外怀上了二胎，先生又意外失了业。两个待业青年加上两个嗷嗷待哺的娃，家庭的重担一下子沉了起来。

起初我们也考虑过社区团购、邻里小吃等创业点子，但昂贵的租金、人力，从 0 开始的勇气，好像都欠缺那么一点点。

直到某天朋友的一番话将我们彻底点醒：**为什么一定要自己找店面？线上不行吗？你妈妈那里不行吗？**


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/2EaFkYu8ISvyJSOj50icrl8zQC09D5IMD2Qic5FUt1s23zIOzZS9Fby4eye0Z7shP2Y2EVQBJFAwHumCl6DuAZmg/640?wx_fmt=jpeg&from=appmsg)


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/2EaFkYu8ISvyJSOj50icrl8zQC09D5IMDTBfy3wzhFCamaNUucQabia9zc7YJApicMlpLv1TcaQN7kibx0tAn6jxNg/640?wx_fmt=jpeg&from=appmsg)

仿佛一语惊醒梦中人般。是呀，打从我小时候起，父母就经营着餐馆的生意。门店的租金很贵，一年辛苦到头也攒不了太多钱。

**我大可以在它的基础上，开展周边企业送餐服务。**一来发挥自己互联网从业者的思维优势，二来也给家里增加些客源，减轻成本压力。

说做就做，当时正值夏季高温天，周边的上班族都懒得出门。于是很快一传十、十传百，第一个微信群一下子就满了。

大家都知道，“嘿，楼下味道还不错的衢州餐馆现在可以送饭上门了。”

**菜品现买现炒不预制、有实体门店、卫生干净、定价合理、送餐快、还能直达公司门口，这些都成了我们特有的优势。**

最多时候一天做了 100 份工作餐，且没有影响线下堂食的正常运行。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/2EaFkYu8ISvyJSOj50icrl8zQC09D5IMDTdCouopAXnbHiaNjFt4nNtiamtHuoFoDqKBWUORek5ukCIia8NvPCjNNQ/640?wx_fmt=jpeg&from=appmsg)


**但眼下看似顺利的背后，依旧有许多困境。**

首先是进入孕晚期的我，明显身体和心力上吃不消了。渐渐放手后，又每日提心吊胆，生怕哪个环节出现纰漏；

其次就是「竞争对手」也越来越多，有噱头更足的西厨减脂餐，有价格更实惠的自选餐厅套餐...

在这个风雨飘摇的创业时代，未来的路怎么走，仍然需要许多思考和变通。

**不过能像如今这样和家人一起，脚踏实地的赚钱，我觉得很亲切、很踏实、也很幸运。**

听完妈妈的就业故事，大家是不是也有了些蠢蠢欲动的新想法？但对未知的未来，同样有一丝担忧和害怕？

诚然家庭的牵绊、工作的空窗期，这些都是阻挠全职妈妈重回职场的障碍。

**但只要你愿意张开双手，踏出「那一步」，相信同样能闯出一番属于自己的别有天地。**

就像那句话说的：“种一棵树最好的时间是十年前，其次是现在。”

**人生是旷野，而不是轨道。重新出发，任何时间都不算晚。**
