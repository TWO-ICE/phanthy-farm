# 怀孕时酱油吃多，宝宝皮肤会变黑？

![封面图](https://mmbiz.qlogo.cn/sz_mmbiz_jpg/tGtmpweWiaN3LQYBYFhRgEKHztLKXMsCqZibII1jIYOuvibAHNXLkGHmZIqxdzvibicpyRhdy6C948lcdJQK1W0oLmw/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/1-ZI6ONIcMSNRt1KrpvZow

都说怀孕辛苦，在糕妈看来，最辛苦的，就是孕期不能随心所欲吃东西了！（吃货本性暴露……）民间常说：**酱油烧的菜要少吃，吃多了宝宝皮肤黑。**

说真的，酱油也太冤枉了吧！因为**孩子皮肤黑不黑，最重要的因素就两个：****一个是先天的基因**，就是你和老公的肤色；**另一个就是后天的光照**，太阳晒多了当然就黑。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/z7kZjMoQ3yGDXe0fia8icN4K3Wc6Gf1iaH8N4AxicUB1GReKdtVmt4vCslnYXQ9Ruoxtbd0Y9PlhNkBVsDDQDBm31Q/640?wx_fmt=jpeg)


**所以这跟酱油没什么关系。不过有些食物，对宝宝的皮肤还真有好处，孕妈妈可以多吃：****1、富含维生素 A/C/E，它们都有抗氧化的作用**。

例如胡萝卜、红薯、南瓜；西蓝花、菠菜等深色果蔬富含 VA；猕猴桃、柑橘、枣、大白菜等富含 VC；坚果、全谷物类则富含 VE。

**2、富含 Omega-3 多不饱和脂肪酸，**不仅能延缓皮肤老化，还对大脑、眼睛好。例如三文鱼、鳕鱼、亚麻籽油、核桃等。

**3、富含大豆异黄酮，**具有抗氧化、抗炎症功能。例如大豆、豆浆、豆腐等。

要吃的丰富，对孕妈妈和胎儿都有好处。
