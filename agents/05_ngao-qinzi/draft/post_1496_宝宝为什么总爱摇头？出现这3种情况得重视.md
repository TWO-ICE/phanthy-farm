# 宝宝为什么总爱摇头？出现这3种情况得重视

发现宝宝有音乐天赋，是从摇头开始的。人家不仅清醒时摇，吃奶时摇，快睡时也要摇，甚至睡觉时也会摇……

有时像街口吹口哨遛狗的大爷，有时简直像要 rap——频率之快，幅度之大，不瞒你说，糕妈有次试着自己摇了几把，速度还没娃快呢，都晕到不行！


![图片](https://mmbiz.qpic.cn/mmbiz_gif/rrVVklPTzRBs9fDGr6d6JbBJlZziaGstia5bnb7oM66mbdrTJ3RFscJs5ia1gxxGAEuPNMnmRYsQQrmRvh7wpuiczA/640?wx_fmt=gif)


所以动不动就社会摇的宝宝，一直摇头不难受吗？会把自己晃悠笨吗？


**担心可能是多余的！**
随着宝宝身体各部位肌肉的发育，他们**逐渐学会控制自己不同的身体部位。**


摇头，那可是**宝宝能逐渐控制自己头颈部的肌肉后 get 到的新技能。**

所以，他们才会乐此不疲 ！来看看宝宝“动次打次”时的心理活动吧：

**●  吃奶时摇头**

宝宝试图想要衔住乳头时，他们会通过前后左右摇头，来锁定乳头方向。

衔住乳头后，有些宝宝还会继续摇头，这是表达自己的兴奋：“耶，聪明如我，终于吃上奶了！”

**●  胀气时摇头**

在宝宝大运动还不是那么灵活的时候，肠胃在同期也容易胀气不适。

他们就会通过抬腿、甩头等一系列动作来释放“压力”，进行自我调节。

所以，有时候会发现宝宝连续摇头后突然放屁，或者舒服的笑笑，然后继续安然入睡。

**●  入睡前摇头**

宝宝可体贴妈妈了。

当他们感到疲倦，想要呼噜噜时，会通过摇头进行自我安抚。摇头有助于他们慢慢变得平静，然后甜甜入梦。

当然，也有可能是宝宝把自己给晃晕了——**但不需要担心，这很正常。**

**●  玩耍时摇头**


有些宝宝被逗得很开心时，可能会边大笑边摇头；或者模仿你曾经摇头的动作。宝宝用摇头在告诉你：“我很开心哦，我很能干呢！”


**哪种摇头要警惕？**
当然了，有很少一部分宝宝，摇头可能真是因为**生病了。**
**状况一：**

摇头的同时，宝宝还会拉扯耳朵，并且看起来不太舒服。同时出现精神不振、发烧、耳朵流液体等症状——**可能是耳部感染。**


**状况二：**

摇头时，同时出现多汗、枕秃、易惊醒、骨骼生长畸形等情况，要**警惕缺钙缺维生素 D 的可能。**


**状况三：**

宝宝摇头幅度很大、很频繁，似乎看起来想伤害自己。若是加上宝宝平时就对家人的逗引没啥反应，不会使用眼神来进行交流；甚至生长发育无法达到这个月龄的标准——**宝宝可能出现了比较严重的问题，比如自闭症。**

还有些情况啊，比如**宝宝觉得热了、头上或耳朵有湿疹之类的，**也容易出现摇头的情况。


![图片](https://mmbiz.qpic.cn/mmbiz_gif/rrVVklPTzRBs9fDGr6d6JbBJlZziaGstia6IenO3Z2UWs3MkpSnkEv7HSNZ2GpsrWDZJ2RYTh2S4KvzkxwictKIwQ/640?wx_fmt=gif)

总而言之呢，如果只是单纯摇摇头，没有出现其他异常症状，娃的精神状态也棒棒的，一般不用担心。

如果出现上述情况，一定要马上带宝宝去医院，绝对不要耽误。有时候，我们还可以相信自己当妈的直觉，宝宝怎么看就是不对劲，那就别纠结，赶紧找专业医生排查下吧！
