# 娃没礼貌，总是使唤大人？糕妈：别急着生气，先试试这几招

![封面图](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN3dlGkXGSBYN8LQeibojawj9K3RHLicAcEGk4JGvKZ6cMialHKLomO0CcYuWibFfWIGFDNCqx441a2njA/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/StObPyAjrTKmup0RjEG_Zw

姐妹们，晚上好，我是糕妈。

想问大家：你们家娃跟大人说话时，会不会也有这种 “小霸道”现象——


*我要那个小车！*

*把我的水拿一下！*

*我的水杯呢？我要的不是这个！*

很多姐妹听到娃说这些话，就会升起一股无名火，觉得这孩子真是“欠收拾”——**怎么天天把大人当丫鬟似的，命令、使唤！？**

说真的，我遇到这种情况也很恼！但仔细想想也能理解：

现在家里宝贝少，老人照顾得细致，递零食、剥橘子都赶在娃开口前，说话也没特意教过“分寸感”；

我们自己忙起来，有时候也会随口跟家人说“把××递我”“××给我拿过来”，娃看在眼里、听在耳里，自然也会跟着做。

**这类小命令真不是娃故意“没礼貌”，只是他还没学会“怎么好好表达需求”**。现在去引导、纠正，改起来也是很容易的~


**0****1****压压火！**

**别和娃“情绪对抗”**


生气，不仅解决不了问题，还给娃又做了一次错误的沟通示范——作为大人都没有好好说话，那孩子就更不知道怎么办了。

回忆起来，发发对着我喊：“把我水拿一下”的时候，我第一反应也是“你怎么这么跟妈妈说话”。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/2EaFkYu8ISuu0Xp8wRbI48VZHO7XyEXLmtic9cgSibbEFl4r1ZiaIRsp6FJpvicMIxAF0IpdFxlYLpyB7SdF7HXpiaw/640?wx_fmt=jpeg&from=appmsg)

但觉察到了自己的情绪，也很快意识到：急眼并不能解决问题啊！


于是尽量压住了自己的火气，跟他说：**“我听到你说想喝水，但你的语气让我不太舒服。”**

先让孩子知道“我的需求被听见了”，再轻轻点出“语气的问题”，娃反而更容易接受、也愿意改变。

毕竟很多时候，娃也不是故意要“凶”，只是不知道怎么说才对。


**0****2****慢慢来！**

**亲身示范比说教管用**


光说“你的语气让人不舒服”“你要礼貌一点”，娃可能听不懂，还得清清楚楚教他“具体怎么说”。

比如这样示范：**“你可以说，妈妈请帮我拿一下水，谢谢。” **


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/2EaFkYu8ISuu0Xp8wRbI48VZHO7XyEXLVP2sCeyhA97mwhPgAYbXfKujbpWyX8E3laiaicBuH6rahWjq470GNYdA/640?wx_fmt=jpeg&from=appmsg)

如果娃照这个说了，我会把水拿给他，我会说：“好的可以的，谢谢你这么有礼貌。”把它正向强化。

如果他没有听进去，我也就会装作没有听到他的需求，我会用实际行动告诉他，好好说话，才能达到你的目的。

孩子都很聪明，他知道“好好说话能更快达到目的”，自然就愿意学。


**0****2****一起努力！**

**全家人共同创造好氛围**


最后我想说的是，潜移默化的环境塑造，更重要。

娃的 “说话方式”，很多时候就是家里大人的 “镜子”。

可以观察一下，家里大人之间，老人之间，是不是也经常有这种命令式、反问式的沟通，因为孩子很多时候都是在模仿大人的行为。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/2EaFkYu8ISuu0Xp8wRbI48VZHO7XyEXL1fnVDj3BLjy9NAkPY7wKNQsCyECLAMSOhzuNaL5q19gqEYTLV6nHtg/640?wx_fmt=jpeg&from=appmsg)

我们家会比较重视这件事，**平时会把“请、谢谢”挂在嘴边。**


比如：奶奶做了一大桌子菜，我们开饭前会先说“谢谢奶奶”；比如糕爸为我做了什么事情，我会说：“亲爱的，谢谢你帮我搞定。”

很多时候，我们总习惯把最客气的一面留给陌生人，面对最亲近的家人时，却少了点耐心和尊重。

但其实**好好说话不是“客套”，而是让家人知道“你的付出我看见，你的好我记着”，这样大家才会更有动力为家庭付出爱。**


![图片](https://mmbiz.qpic.cn/sz_mmbiz_gif/2EaFkYu8ISuu0Xp8wRbI48VZHO7XyEXLf7sK2bQSfRPfpSGvfSqJswepIyL7R4fYFYj1WYvN45zyTBibF4e7lDQ/640?wx_fmt=gif&from=appmsg)

养娃，不是期待他可以变成时刻八面玲珑的完美小孩，而是陪着他，一起慢慢学会“好好表达”“好好爱人”。

你们家娃有没有过这种“小命令” 的时刻呀？是怎么引导的？欢迎评论区一起聊聊～
