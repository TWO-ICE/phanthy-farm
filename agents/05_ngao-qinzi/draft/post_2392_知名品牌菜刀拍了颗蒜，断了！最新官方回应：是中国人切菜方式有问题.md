# 知名品牌菜刀拍了颗蒜，断了！最新官方回应：是中国人切菜方式有问题

![封面图](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN1EzTxtjEIubwDAnfDufgkE5RZbvNfiaQFIU4qzKgno6f8ZQQoRJYuQMbXnhQI21iaRiccia099QpTxWQ/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/W0hWWd1PM5_Im-g81mUXMQ

99 块的菜刀能用多久？前两天，张小泉菜刀“拍蒜断刀”的话题引起了编辑部妈妈们的讨论。

广东的王女士用刚买不久的张小泉菜刀拍蒜后，菜刀居然断了！

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/FF2OYjRxqc1zq2Mgyh5hnW29VF4yclLayWumWFxpibdLiau0Df5N3qicib2c5hTxeGibUXwia331SvSZadrI669RG02A/640?wx_fmt=jpeg)

说起来，大家应该都有过用菜刀拍蒜的经历，但是，把菜刀拍断，实属罕见。上周五这个话题冲上热搜后，张小泉给出了回应：常规刀具可以拍蒜，对于一些有专门用途的、硬度较高的刀具，不建议用来横拍大蒜、黄瓜等，**刀的硬度越高越脆，也越容易在磕碰和重力拍打下断裂。**正巧，王女士购买的这把，就是硬度较高的不锈钢材质。本以为过了个周末，这件事的热度过去了。不料张小泉总经理早年间的一段采访，又再一次把“不能拍蒜的菜刀”送上了热搜，一番言论还惹怒了网友。在采访中，他说道：**“你学了几十年的切菜方式是错的，所有的米其林厨师都不是这样切的。”**


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/FF2OYjRxqc1zq2Mgyh5hnW29VF4yclLaHljgAJ5HDs2Frvafm0tiayhof74XVBoSKX1MDMhM8bic9ky1EcpHuYiaA/640?wx_fmt=jpeg)


听了是不是很生气？似乎在质疑咱们。事实上，这段言论并非对“断刀”问题的回应，更没有要“教育”用户的意思，作为菜系最多的国家，其实自古我们就有各种厨具。

另一派更加开明的网友就直接表示，厨房道具确实可以向精细化发展。
