什么菜最值得囤？**01 备一些耐储存的新鲜蔬菜**

大白菜，包菜（卷心菜）、花菜、西兰花、胡萝卜、白萝卜、冬瓜、莲藕等这些蔬菜，都比较能放。

紫薯、红薯、山药这些也有维生素，可以买一些。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/FF2OYjRxqc2cuMGRicVZCy3KQlG2Aml8stetX3nQhZ8ygSaFdIxbQWt4GuPBy7dsaKtw9WehSVfHgibict34kRWLw/640?wx_fmt=jpeg)


**02 试一试冷冻蔬菜**

蔬菜冷冻以后，营养流失可以忽略不计。

可以在超市买冷冻好的豌豆、玉米粒、胡萝卜粒等，也可以自己弄。这样下次做饭的时候，省去了洗洗切切的时间，效率更高。


![图片](https://mmbiz.qpic.cn/mmbiz_png/FF2OYjRxqc2cuMGRicVZCy3KQlG2Aml8sQWlULcAh1o4447J6pMScAt3HpraNJ6er95JIR5iaOt2DiboWPXLiauicxQ/640?wx_fmt=jpeg)

**03 别忘了蔬菜干制品**

香菇、木耳、笋、海带、黄花菜、裙带菜、干豆角、花菜干、笋干这些蔬菜，都是可以买干制品的。有些蔬菜晒干以后，比新鲜的时候还好吃。吃之前，用水泡发一下就好，非常方便。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/rrVVklPTzRBk8XSy1AqjDxo8sRdZXTb2fWnYO0Wv5OhzbAczD91nA73kphE4jx3lgammNEn5EjicFGkRy0v6cZw/640?wx_fmt=jpeg)


**04 家里有成品蔬菜泥、果泥的，也可以让娃消耗掉**

成品蔬菜泥、果泥的维生素、矿物质也很丰富，家里如果有存货的话，这个时候可以拿出来救救急，还省了买菜、洗菜、烧菜的麻烦。

不同蔬菜，怎么保存更新鲜？平时一天买一次菜，绿叶菜当天吃完，也不需要特别的保鲜处理。但最近这段时间，很多妈妈都是好几天买一次菜，蔬菜怎么保存更新鲜？能存储多久？


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/FF2OYjRxqc2cuMGRicVZCy3KQlG2Aml8sttLibsud5AKdbtwkNyRCUmvZxvcRuYUOAVjSGoaDf251fxqLKfWMibQg/640?wx_fmt=jpeg)


请大家记住这一点，**所有的菜买回来后，先摘掉腐败的部位，不要切、不要洗！！！**如果买回来的时候蔬菜表面有水分的话，可以先晾干或擦干。

**01 绿叶菜的保鲜**

● 青菜、菠菜、娃娃菜、空心菜、花菜、西兰花、圆白菜等


**☞ 放冰箱冷藏**

摘掉腐败的叶子 → 用保鲜膜/保鲜袋装好 → 放冰箱冷藏，这样处理之后，起码能放 3 天。（注意：绿叶菜不要贴近冰箱内壁，避免冻伤）

**☞ 真空大法**

如果你们那绿叶菜比较难买，或是想要保鲜效果更好的话，可以用下面这个真空大法。只要一个保鲜袋、一盆水，在家就能真空包装食物！**具体方法：**

准备一盆水，将蔬菜放到保鲜袋或密封袋中。


![图片](https://mmbiz.qpic.cn/mmbiz_gif/FF2OYjRxqc2cuMGRicVZCy3KQlG2Aml8s0z7YRzTDLSYnzxIdCsH3NvdkmXkwarJrW3ibZNAuNiclcAnWNQjP2LHw/640?wx_fmt=gif)

再慢慢将保鲜袋浸入水中，注意口朝上，让水压逼出保鲜袋中的空气，最后系起袋口就行。


![图片](https://mmbiz.qpic.cn/mmbiz_gif/FF2OYjRxqc2cuMGRicVZCy3KQlG2Aml8sJpMt0oVp0ovP20kb9dzA0FjlrNolcaicw7cCS5CwSq6qV6laQu0RFXA/640?wx_fmt=gif)

**02 根茎类蔬菜**

**● 南瓜、紫薯、红薯、山药、土豆、芋头：**这些放阴凉干燥地方就可以，大概能放上 15 天到 1 个月。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/FF2OYjRxqc2cuMGRicVZCy3KQlG2Aml8sd7Uia3vV6kw8eIs9dJbxNgu5EslNN3xU6rBFFtzkbl8GWym7kKQu9SA/640?wx_fmt=jpeg)


**● 莲藕、芦笋、莴苣、茭白、胡萝卜、白萝卜：**这些可以放外面，当然啦，放冰箱的话，能储存更久，一般能放 1~2 周。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/FF2OYjRxqc2cuMGRicVZCy3KQlG2Aml8sQGRBv25OpPIzvd7C2gMh4aZRpjGcPCa1fWJfRwKCIR4c7Cap0DHynw/640?wx_fmt=jpeg)


**03 茄果、瓜类蔬菜**

**● 茄子、番茄、秋葵、甜椒、黄瓜、南瓜、西葫芦等：**这些蔬菜比较「怕冷」，不建议放冰箱，放阴凉干燥的地方就可以。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/FF2OYjRxqc2cuMGRicVZCy3KQlG2Aml8svZVQ1EyhFlrjWDQibSOAx3ibAfAOyGhvFjR6LIPeCM79qGOGjABAibylg/640?wx_fmt=jpeg)


就拿西红柿来说，西红柿的内部组织在冰箱的低温下容易被破坏，变得软烂，同时西红柿本身的新鲜味会丢失大半，口感风味都大打折扣了。

**04 新鲜的菌菇类**

**● 香菇、平菇、杏鲍菇等：**放在通风处先把水分晾干一些 → 用保鲜膜/保鲜袋装好 → 伞柄朝上装入纸袋子（不然有可能会压坏、塌掉） → 放冰箱冷藏。

**05 配菜类**

**●大蒜、洋葱、生姜：**阴凉处存放即可。这些蔬菜在冰箱中久存，会变软、变味、腐坏加剧，大蒜还会在冰箱里发芽呢。


**● 香菜、小葱：**建议放阴凉处。如果想保存的时间再久一点，也可以放冰箱。

具体方法：用厨房纸巾包起来 → 装入保鲜袋或用保鲜膜包裹 → 放冰箱冷藏。

新鲜菜难买，如何保证维生素？都说蔬菜水果非常重要，那如果家里蔬菜短缺了，怎么办？

除了常规的保鲜办法，如果你那边菜很难买到，还可以用下面这几招：

**1. 焯水后沥干再冷冻。**


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/FF2OYjRxqc2cuMGRicVZCy3KQlG2Aml8sozo1cnOmUu45HS9EHNzjK9NPrGaOxfkDVJzKsupWhUxthFZ8alAslw/640?wx_fmt=jpeg)


**2. 做成饺子馅、馄饨馅、蔬菜肉丸子，再冷冻。**

**3. 给小龄宝宝吃的话，可以做成蔬菜泥，冷冻起来~**

蔬菜水果主要提供维生素，矿物质，膳食纤维，植物化学物等。其实大部分营养，肉、蛋、奶、谷物、坚果、豆类、植物油里面有的。

和蔬菜水果关系比较密切的就是维生素 C ，叶酸和维生素 K ，大家最熟悉的维生素 C 基本只存在蔬菜水果中。所以长时间吃不到新鲜蔬菜水果，必要的时候，可以摄入补剂。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/FF2OYjRxqc2cuMGRicVZCy3KQlG2Aml8slYbCycjLo9S6dzFcFxWD2smNSpzDVttd9vAIDI3mCqF6Vv5ibibdYOtA/640?wx_fmt=jpeg)


待在家出不去，又没事干，家长们发动了各种技能。这不，朋友圈都有妈妈开始自己发豆芽了，绿豆一把，三天就可以吃到维 C 了。

**☟ 发豆芽的方法 ☟**

黄豆、黑豆、豌豆、绿豆先浸泡一夜，再放在阴凉处，每天喷一次水，几天之后，豆芽就长出来了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/FF2OYjRxqc2cuMGRicVZCy3KQlG2Aml8suSeDBBSflLhj9E0VDV72VI2nFVFaBIibPO5PltPUq3pUuLB5ojldBPQ/640?wx_fmt=jpeg)
