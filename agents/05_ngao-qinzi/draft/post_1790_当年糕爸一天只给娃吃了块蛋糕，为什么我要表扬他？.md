# 当年糕爸一天只给娃吃了块蛋糕，为什么我要表扬他？

三八妇女节，当了妈之后的我们，可不需要什么太花哨的礼物，要是当爹的，能让我们彻底放假，好好带上一天娃就可以。


糕爸自从开了视频号，开始分享带娃日常，就一直有妈妈催我出篇“调教老公指南”，或者让糕爸给各位爸爸开篇教学。

四舍五入就是1000个赞啊朋友们，人气分分钟要碾压我的感觉~


但是不管怎么说，言出必行，向来是我的优点之一。

所以我也真的很努力的帮你们问了“带娃感想”、“婚姻看法”，这些大家最关心的问题。

现在，让我们一起来回顾一下，大型采访翻车现场：

对带娃，直男真的都没什么天然感知。


**年糕一岁前，对带娃这件事，糕爸也是会各种逃避的**——平时就在书房睡，时不时过来欣赏儿子这个可爱的“小生物”；心情好的时候，偶尔陪他玩一下。

然后就……跟万千爸爸一样，隐身了。


![图片](https://mmbiz.qpic.cn/mmbiz_gif/rS1D8dH2xmAiaSpzdQtIZuicibXZicUELYYu4NVtyGS7yz4Svd5BH6ufanGZyWicjOSxibD47venqjVYsnoZNuRRYQ6A/640?wx_fmt=gif)


**为啥比起妈妈，爸爸对进入角色，总是好像慢半拍？**

作为一枚医学生，我很清楚，确实有一点很关键，那就是：**催产素**。

关于这个，可是有研究证明的（真的不是在帮爸爸们甩锅！）：

生产和喂奶的过程，刺激了催产素的分泌，才让妈妈们母爱爆棚；因为爆棚的母爱，让妈妈和孩子有了更多的亲密接触，又再次促进了催产素的分泌。

催产素还因此获得了一个可爱的名字：“拥抱激素”。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN0REpCT4DLOlUPVO0c9icOUibO0Dgm6b1py9aoIX7jxVhfrhIicvI2fQjaJsOCsyLkwTgzRfPKU2tsyw/640?wx_fmt=jpeg)


所以，作为没有先天优势的爸爸，就更**需要多带娃来弥补了**是不是？


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/rS1D8dH2xmAiaSpzdQtIZuicibXZicUELYYuLfafyP6wQZnlL3aW5lbJLfrnToPHicicJJQPEicfUVGLiaUAceYvsTV0gA/640?wx_fmt=jpeg)


曾经的糕爸，也是很排斥带孩子的：尿了要怎么搞、要吃饭怎么办、一会要喝水一会要穿衣的……


别看他是育儿博主的老公，和其他千万个老公一样，都是带娃“天然呆”。


![图片](https://mmbiz.qpic.cn/mmbiz_gif/rS1D8dH2xmAiaSpzdQtIZuicibXZicUELYYu4NVtyGS7yz4Svd5BH6ufanGZyWicjOSxibD47venqjVYsnoZNuRRYQ6A/640?wx_fmt=gif)


那么现在的问题是：**怎么才能让爸爸愿意、甚至喜欢带娃？**

解开这个千古难题，我只做了三件事（得意）——


**第一个法则：在他心情好的时候，让他做喜欢的事情。**

最最开始的时候，咱们期望不要过高。

就一定要非常明确地给他“布置任务”，让他慢慢参与到带娃这件事里来。比如让他帮忙抱一下孩子、换个尿不湿、陪娃玩十几分钟。

这些事情，都很小，看起来难度不大，不会产生畏难情绪，重要的是让他在参与带娃的过程中，建立起带娃信心和责任感。

**最忌讳的就是“我有这么多事要做，你也不帮帮我！”**说重点、切要害，需要他干什么，清楚地讲出来！

慢慢的，他找到了当爹的感觉，当时年糕也大一点了，我就经常在掐准了他情绪、时间都OK的情况下，云淡风轻地，让糕爸陪年糕读半小时科普书、玩1小时滑行车……


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/rS1D8dH2xmAiaSpzdQtIZuicibXZicUELYYuzVoqDmicByqPbmaBLn8Gf48WhKEHiaVmNDoofWfasM5VrYUfPv4cn26Q/640?wx_fmt=jpeg)


总之，给他的活，尽量都是他兴趣范围内的——这个时候，要善于发挥男人的长项：**玩**。

糕爸自己也说了，带娃就是：**“跟他一起玩，跟他一起玩我也觉得挺开心的。”**

说到这里，有的妈妈可能有意见了，凭什么我带娃苦哈哈，还要想法子让爸爸这么开心？想想就不服！

亲啊，咱把眼光放长远，看大局。我们想要的，是一个长期会带娃、享受带娃的爸爸。**那么开始的时候，就一定要好好栽培不是？**栽培好了，受益的是全家人啊！


![图片](https://mmbiz.qpic.cn/mmbiz_gif/rS1D8dH2xmAiaSpzdQtIZuicibXZicUELYYu4NVtyGS7yz4Svd5BH6ufanGZyWicjOSxibD47venqjVYsnoZNuRRYQ6A/640?wx_fmt=gif)


那么，糕爸是从什么时候开始，完成了“带娃达人”的飞跃呢？

**关键在于第二件事：我在旅行中学会放手。**

有一年，我们一家去德国（那时候年糕才 3 岁），当时我有两天的拍摄工作，没时间管孩子。糕爸第一次面临“被迫”全天候独自带娃的局面。

说实话，一开始我还是挺不放心的：他一个人行不行啊？年糕能不能吃好、会不会想妈妈啊？

……

一边担心，一边又不断安慰自己：不用担心，娃是他亲生的、亲生的……

晚上，当糕爸带着满脸都是大写开心的年糕，出现在我面前时，我忍不住冲上去，给了他一个大大的拥抱。

糕爸第一次全天候独自带娃，完成！


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/rS1D8dH2xmAiaSpzdQtIZuicibXZicUELYYu91TkraSmNZEZT51873j2eYpOIrlhdfeL2N9x0KCgYJxAhaQde4Itiaw/640?wx_fmt=jpeg)


回去的路上，我一路追问各种细节。


糕爸竟然一个人带着年糕，开车去了法兰克福，还带年糕去逛了博物馆。

年糕吃的怎么样呀？

糕爸气定神闲地说：就在博物馆的Café吃的，我点了咖啡和汉堡，他就吃了一块蛋糕。

好的，心梗，忍住。

我继续用追问赞美糕爸：年糕这一路没有尿裤子，你很厉害呀。

这时候，糕爸更加得意地说，他要上厕所自己会讲啊，小孩子跟着我很乖呀。

好的，请继续保持这种“错觉”。

我见糕爸都是“报喜不报忧”，转问年糕：今天跟爸爸过得怎么样？

年糕说：**很好啊！**就开始滔滔不绝跟爸爸聊，今天看到的恐龙化石了。

最后，糕爸很得意地自我总结到：**带孩子，没什么难的。**

好吧，一个直男，在异国他乡，第一次独自带娃，能有如此成绩，就让他骄傲一小会儿吧。

第三件事，我到现在还持之以恒、不断勉励自己在做的——**少叨叨、多表扬****。**

想让老公挑起带娃大业，最重要的，就是学会“闭嘴”。

咱们很多妈妈（包括有时候我自己），总是会一边抱怨老公不带娃、一边又在人家好不容易带一次娃时，指指点点。

爸爸那点可怜的积极性，一下子就磨没了，后来就变成了：反正我也带不好，你自己带吧。

所以想让老公帮忙带娃，当妈的一定要心大一点。

至于多表扬，那可是激励爸爸带娃的“超级武器”。

林先生表面上总是说“哎呀，你不要这么没有原则的表扬我，我做的也不算多”，实际上非常受用！哈哈，而且，夸着夸着，就真的做到了！


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/rS1D8dH2xmAiaSpzdQtIZuicibXZicUELYYuevb8rpNxYpf6GspqsA3z3UiaicmPevc6peicfNzQsncAjLWhic8QWJNRibw/640?wx_fmt=jpeg)


**在孩子面前，我也经常不遗余力地赞美糕爸，他自然也成为了糕爸的迷弟。**

经常把“我爸爸怎么怎么样”、“我要是长到爸爸这么高，就可以怎么怎么样了”挂在嘴边。爸爸当然很受用啊。

并且，随着娃长大，求知欲的爆炸式增长，糕爸终于发现，满肚子的汽车、武器、机械知识，在孩子那里，找到了最完美的安放。

平时他想跟我聊这些话题，我是拒绝的。现在不仅有个眼神单纯、又闪烁着蜜汁崇拜的小可爱，盼着和他聊；他还能打着儿子喜欢的名义，买各种自己喜欢的汽车杂志、模型、遥控车……

他当然带娃带得非常开心~

所以，老公能带娃，最开心的是我吗？No！

**带娃本来就是我们共同的责任，他带娃可不是帮我带的。**

真正从带娃中收获满满的，反而是糕爸。

作为一枚钢铁直男，糕爸之前并不细腻，追求的是理性生活，是一切从简。

说起过什么节日、纪念日，挂在嘴边的都是：瞎折腾什么啊，简单点不好么。

但是现在陪着孩子们长大的过程，让他用一种更柔软的触觉，去重新感知了生活和世界。

他开始在工作之外慢下来，一边看孩子们成长，一边反思自己性格中需要提升的部分；开始和我一起，认真地张罗圣诞节、强调生活中的仪式感；也渐渐变成了一个更细腻、更有爱、更有幸福能力的人。

后来发糕出生了，他从月子里就开始充分参与带娃，超级奶爸之路，一发不可收拾。

带娃这个事，绝对是越带越有感情、越带越有羁绊~
