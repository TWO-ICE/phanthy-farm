# 3根香蕉不如一勺它！天热了这样吃，补水又通便

![封面图](https://mmbiz.qlogo.cn/sz_mmbiz_jpg/tGtmpweWiaN2FRjlSMsobr9Bdt8afTb13FPUjPjB6gbyZWSCicut44s8AM09teH1gviceJic1OVaMZyYTibx4AxibP0Q/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/b8pW-SV0jPnB-I6WYOPDxw

今天给大家带来两道清爽小食——**奶豌豆泥+****豌豆糕**，绿绿的是不是还挺讨喜的~

小宝宝可以当辅食，大宝宝可以当零食，大人可以当甜点。

![图片](https://mmbiz.qpic.cn/mmbiz_gif/FF2OYjRxqc3xnHUActmb8ibZjQGSyLDmp8lQtIrc9G9pLeCUEu51MwF8qV26p7gPYRwXSWmGsoCqIlqDOgeChEQ/640?wx_fmt=gif)

它们的主打食材是豌豆，甜甜的味道，非常受小吃货们的喜爱。豌豆菜市场就能买到，你也可以买冰冻的豌豆，营养相差不大。

![图片](https://mmbiz.qpic.cn/mmbiz_gif/FF2OYjRxqc3xnHUActmb8ibZjQGSyLDmpQJaUXnDftalpbt5ibQE1PU1ERI83Yibrd67aT0Tdo3f1icRCiaqKqhicPicQ/640?wx_fmt=gif)

而且**豌豆的通便、防便秘效果很好，没准吃 3 根香蕉都不如一勺它**呢。想给娃通便的话，就别吃香蕉了，这个咱们很早就科普过了，老粉儿们一定记得吧**☟**


![图片](https://mmbiz.qpic.cn/mmbiz_png/FF2OYjRxqc3eCyVHEiaVeDSCs10XOZHvN2RW03lRbibStXECibk03sUciaSzZrxdsNbAlWjabsTCcQklSYDlwZMTibA/640?wx_fmt=png)

那些未熟透、有点生的香蕉，鞣质含量高，不仅不治便秘，还可能抑制肠道蠕动，造成便秘。只有熟透了、表面发黑、非常软的才有一定通便效果。宝宝便秘的时候，就吃西兰花、胡萝卜、菠菜，豌豆等**富含膳食纤维的蔬菜。**

![图片](https://mmbiz.qpic.cn/mmbiz_gif/FF2OYjRxqc3xnHUActmb8ibZjQGSyLDmpmwRic98MmYicy24HInb3icpcSvkRP27l22vanKjfW4L4zwpn0fobTA2yw/640?wx_fmt=gif)


![图片](https://mmbiz.qpic.cn/mmbiz_png/FF2OYjRxqc3eCyVHEiaVeDSCs10XOZHvN9Cf6EJTcmtVDmmFiaLwKs2qtrDo2ulVsXCAAH7D6xibZHdZW8gdNQElw/640?wx_fmt=png)

但咱总不能为了通便，给娃吃快烂掉的香蕉吧。那就来点豌豆吧，通便、补水、补钙又补维生素，安排！如果宝宝不爱喝水，来点豌豆泥补水也挺好，就别总逼着娃喝水啦。

![图片](https://mmbiz.qpic.cn/mmbiz_gif/FF2OYjRxqc3xnHUActmb8ibZjQGSyLDmpROD0f9YWM8n8Cnre1ubRtX0koiaVocfy9vzI821oFVYgyibGPHicj6R7A/640?wx_fmt=gif)

这道奶香豌豆泥只需要豌豆、配方奶和淀粉三种食材，一蒸一煮，超简单！再手残的妈妈也能学的会。大家快做起来吧~


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/FF2OYjRxqc3eCyVHEiaVeDSCs10XOZHvNQ8wglK7Pia8cholRVicxcLEzkQ0ALN9dlPY1Fiag8cFhnicosjOG3G1oVQ/640?wx_fmt=jpeg)
