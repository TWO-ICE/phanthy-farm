# 没生病没发烧，3岁男童突然确诊肾病！医生提醒：孩子尿完别急着冲，关键时刻能救命

![封面图](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN3h9zE4GwFgsG0UzrjYS2OTITLFl7icx5XB139E5VKkEgmN8b3hk7aaxczWDp6ur7RsIqEqtMXkr3g/0?wx_fmt=jpeg)

当妈后，谁还没在娃的尿盆前，当过几次「特聘观察员」呢？

编辑部 @阿铭，今早就被儿子小马桶里的那泡“浓茶”给拦住了。

“昨天水没少喝啊……”她顺手就搜起了“孩子尿黄是怎么回事”。弹出的页面从“缺水”开始，几行下来就跳到了“肝肾问题”、“横纹肌溶解”这些吓人的词。

**大数据也看穿了她的焦虑，紧接着就推来一位妈妈发的帖子：** 一个 3 岁男孩持续尿黄、泡沫多，家长一开始只当是上火，没太在意，结果就查出了小儿肾病综合征！


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN3h9zE4GwFgsG0UzrjYS2OTiaoWsWGBbKlbccTReKCu5aTGPftl6hg1hL6dNs0KY01FFpxjNrrqhgw/640?wx_fmt=jpeg&from=appmsg)

越看心里越发毛，她甚至开始回忆最近有没有惹娃不高兴，导致他“郁结于肾”。（是的，我们当妈的就擅长这种逻辑缥缈的推理**🙃**）

好在午睡后，她让儿子多喝了半杯水。没多久，娃的尿色就回归了“清澈山泉”。

得，虚惊一场。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN3JBRyT6zJInUW47QPLjUViaSeIwM4jBMndth0qALxjaNHaNZwEb86KQl7TqPYJALcCRyjk6xsjriaA/640?wx_fmt=jpeg&from=appmsg)

不光是 @阿铭 会这样，她在妈妈群里随口一提，才发现大家的“孩子尿尿观察日记”里，都记着同样的操心：

**尿里泡沫多冲不干净、尿出过吓人的粉红色、尿味重得熏人……**

这么一看，娃的尿，真就是一份身体发布的「每日健康简报」。那怎么从**它的颜色、状态、气味里，快速分清“没事”和“得留心”？**

尿黄、味大？先多喝水！ 泡泡多？先观察！

**可疑状况**
颜色或气味出现异常，先排查食物和药物。
