# “为什么妈妈的下面会流血？还长了很多毛？”这样回答不尴尬，还不怕ta出去乱说

有个朋友最近说了个哭笑不得的事：****读小班的娃有一次突然问：**“为什么妈妈的下面会流血，还长了很多毛？”**

尴尬到能原地用脚抠出一套三室一厅！她和老公都不知道该怎么回答，只好敷衍地跟他讲：**“等你长大就知道了。”**

本来也没当回事儿，谁曾想孩子没得到答案很不死心，第二天在饭桌上当着爷爷奶奶的面又问了一次，可把我这位朋友尴尬坏了！


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/z7kZjMoQ3yEKm9ShYlPHFUDKbZia3SWrdXdaqUNhq4nDtD0h6fPLdkibuSYYgadVwB8xZysibv2ko3kW7nib8uryOA/640?wx_fmt=jpeg&wx_co=1)


翻翻我们的后台留言，关于这个话题该怎么和孩子说的疑惑，家长一直都有：


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/FF2OYjRxqc3DbWUfBkHNv1zjQHe3TJBwGibfmRZ4OKTwaMPW5GAghbN8KMHz0ZHfVPRUoeicsh8Nke3iaJffedHKQ/640?wx_fmt=jpeg)


倒不是因为觉得月经羞耻什么的，而是，上不知天文，下不晓地理的老母亲，实在是不知道，怎么跟宝宝解释这件事……

其实啊，这件事并没有标准答案。我们采访了身边很多有经验的妈妈，答案也各不相同。

从这些妈妈的故事，可以看出来。不少妈妈在面对这件事的时候，总是想**通过代指、别称来掩盖这件事**。但是，这样遮遮掩掩，反而会让宝宝**好奇、害怕、担忧**，衍生出各种古怪的幻想或谣言。

就像上个世纪，缺少性教育的女生们，经常会凑在一起八卦各种*“听说长大了屁屁会流血”“听说某某某上厕所时流了好多血肯定是怀孕了”*之类的传闻，引起更多人的恐慌。

而当父母能够坦然面对这件事情的时候，孩子也就没什么顾虑，会认识到这只是一个非常普通的生理现象。

总之，家长们应该让宝宝认识到，**月经和尿尿、便便一样，****只是一种生理现象而已。**不用害怕，更不用羞耻。当宝宝习惯了这个现象，就不会再担忧、害怕，以后遇到其他小伙伴出现月经时，也不会嘲笑和躲避，反而会给予更多的温暖和帮助。
