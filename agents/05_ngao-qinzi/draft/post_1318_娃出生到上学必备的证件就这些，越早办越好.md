# 娃出生到上学必备的证件就这些，越早办越好

宝宝出生后，**哪些证件需要及时办理？先办哪些比较好？**作为过来人，糕妈今天就给大家整理了**从娃出生到上学必办的 5 个证件，**一起往下看吧

![图片](https://mmbiz.qpic.cn/mmbiz_png/b96CibCt70iaajvl7fD4ZCicMcjhXMp1v6UibM134tIsO1j5yqHyNhh9arj090oAL7zGhRJRq6cFqFOlDZMleLl4pw/640?wx_fmt=png)

（PS: 因为每个地方可能不太一样，大家在办证之前，建议先咨询一下当地的工作人员哦）


**出生证明**

![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN0ibJx9zXNPzyfUVuGvTE88icBnwTpoLaE2veRnbicZwP5T3g8rUkib2AZQuh8iaYeOwCtkCt4yAdKNq7A/640?wx_fmt=jpeg)


**出生证明**是宝宝的第一个证，后面不管是办户口、医保，还是入园、入小学，或者迁户口、办签证、出入境都会用到。万一弄丢了，补办时需要提供当时生产医院的签发记录存根、住院病历、分娩记录、首次签发登记表复印件等等，比较繁琐，所以平时要妥善保管呀。

需要注意的是，《出生医学证明》**一经签发不得变更**。如果超过 1 年还没有办出生证明，就需要宝宝、宝爸、宝妈三方做亲子鉴定了。


**身份证**

![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN0ibJx9zXNPzyfUVuGvTE88icCdbCXJel98cZM6Bmcbjh1f0N7zCJlOaC3KhniaIkUJ5ZGJMxPAibCsYQ/640?wx_fmt=jpeg)


出生后就能办，不过刚出生的宝宝取指纹和拍照有点难度，一般家长会在娃 3 月龄后办。

有身份证出行会方便些，不用带户口本或出生证明了；而且娃的指纹会存到公安数据库，帮助防走丢。
**预防接种证明**

![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN0ibJx9zXNPzyfUVuGvTE88iclxZmUdBb8mKBO5R4f3IibS0yxia6hdXC9N2XLvhxq8TEJhCK4xaPeTUg/640?wx_fmt=jpeg)


**预防接种证**是儿童入托、入园、入学的必备凭证。打疫苗的时间忘了，报名入园的时候会查验。每次打完疫苗，记得保管好，别弄丢了。


**户口本**

![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN0ibJx9zXNPzyfUVuGvTE88icVicXgnibYvKg2hY4Wscdw8bOPNC58IGkS0WUnpuqpTBiacr1WwC10y79Q/640?wx_fmt=jpeg)


给娃办理入园入学，都会看落户时间。

像杭州的小学新生录取，通常会提到一表生、二表生、三表生。一表生中最优先录取的是：孩子户籍、爸爸妈妈户籍、学区房的房子一致。

同是一表生，落户时间晚可能会被调剂或借读。

另外，娃出生**三个月内**上了户口，就可以办理医保了。


**社保卡**

![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN0ibJx9zXNPzyfUVuGvTE88ic2v516xhHjTOUia3Qo9RJya6icj65UyXUV207KEhVWCSZRWQMGOrL3QWg/640?wx_fmt=jpeg)


**社保卡**建议娃出生** 3 个月内**就办掉。

3 个月后再办，就只有等到次月或次年才开始享受医保待遇。而且办卡之前的费用也不能报销。如果宝宝出生后，你家移居到其他城市了，也别忘了办社保卡。
