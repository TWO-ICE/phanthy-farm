# 请马上停止给娃用！“网红玩具”被曝伤肝脏还影响生殖系统，很多幼儿园娃都在玩

“
拼豆

这个儿童手工玩具最近真的很火：五颜六色的小豆子，按图案一颗颗拼好，再用小熨斗加热固定，就能做出一个可爱的成品。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/sbXcibV5Z3r6EZyMcttsGfBIGdtc7KibxKLwUFFt7BPlayqoibPfNjVyVV6aJSY6ibOOewV6awGLqQjd7Lnicj5LqVZ8JJN1SScVE4WYmffFk38Q/640?wx_fmt=jpeg&from=appmsg&tp=webp)


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sbXcibV5Z3r5E1oIHuR0Q0Oqu2apjpldMSuzB1hUPib4k0nI1Cr4pdtloGRhBWhu8nicXI7sF67kCdI7GHc1HmMicaTtycStSDhDgOJxhjY9pfI/640?wx_fmt=jpeg&from=appmsg&tp=webp)


图片来源：小红书


别说孩子喜欢，很多大人也觉得解压，网上随便一搜，销量都很高。


但看起来只是 “ 拼一拼、烫一烫 ” 的小玩具，最近却接连出事，看得人后背发凉。


今年 3 月，贵阳一名小女孩在玩拼豆时， 在熨烫环节发生了触电事故， 最后没能救回来。


![图片](https://mmbiz.qpic.cn/mmbiz_png/sbXcibV5Z3r7SyfWT0OfhJftkCTZBJL8ldxLUyptHRC6c2SmbyWby60NjYibYR3AuZJfW2L4zJia4GwhKUVoibm8WEKQibhGhUJcvqicwb9dsMiae4/640?wx_fmt=png&from=appmsg&tp=webp)


前阵子，山西运城也有一个小女孩，在熨烫拼豆时遇到 熨斗突然起火 ，火花四溅，孩子虽然赶紧拔了电源，但手还是被烫伤了。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_gif/sbXcibV5Z3r7N95nTYRrzB92BlSaYZw4v8zOsIibX5ADnr2nIj3EbECgIe77feFL0GDpCiacBB5ibgeKVmia6ic59XcpQK7Wgv9OMiaB35vuiaps30E/640?wx_fmt=gif&from=appmsg&tp=webp)


很多妈妈看到这里，第一反应估计都一样： 不就是个手工玩具吗，怎么会这么危险？


因为最危险的不是 “ 拼 ” ，而是最后的 “ 烫 ” 。


有些拼豆套装里配的小熨斗，直接接 220V 家用插座。但按照儿童电玩具相关安全要求，玩具供电电压不应超过 24V 。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/J06hTQibibib5UWW6JAvfL5LOuC02QvibkRdRqrqJVyrj0hEy6DlhfmFo9GcmBdXJXbQKL9kl6p91XvL6ZzCq16sDz9WAWpZfh0ZejUXQcjbQXs/640?wx_fmt=jpeg&from=appmsg&tp=webp)


更让人捏把汗的是，这类加热设备里，不少连基本的产品信息都没有，妥妥的三无产品。


除了烫伤、起火、漏电风险，一些劣质拼豆在加热过程中， 还可能释放有害气体。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sbXcibV5Z3r4t8exFvzetZOKAPfA62Uo0hUI6ZQZkjrl4LibeLRS3WiaTB1Lv04nDcPBViaJvxiaicib52SficzevXLrDpHicH8r0q4jmibQQPI7VQoTQ/640?wx_fmt=jpeg&from=appmsg&tp=webp)


说起来，拼豆虽然不是很多幼儿园娃家里的常见玩具，但 幼儿园娃平时更常接触的那些玩具里，藏着的隐患，并不比拼豆少。


有些是太小了，容易误吞； 

 有些是看着无害，其实成分不明； 

 还有些是本身玩起来的时候，特别容易出事。


我们整理了几类比较常见的，姐妹们可以一起看看，家里有没有。 👇


![图片](https://mmbiz.qpic.cn/mmbiz_png/sbXcibV5Z3r5gaN85LhyyUClk7uJUOCu0iakV5FiccG3oDbcW37lI0MGpAOjPC16zUa5BNe7LCa5QJ7wJZsobcAazjlSLuBicqb6XOQEgm7D8PQ/640?wx_fmt=png&from=appmsg&tp=webp)


这种长得像糖豆一样的小珠子，很多娃一看到就走不动路。圆溜溜、亮晶晶，还会 “ 啪 ” 一下吸在一起。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sbXcibV5Z3r5cXfQzaqfxgyziack5KKibpFMulUjFKgtrVLm8OexAE55WpCt39UnRJc6ibTVDDrVcibyBs84NrQkibgdM69qKkJlicGziau29ebrr10/640?wx_fmt=jpeg&from=appmsg&tp=webp)

这些年，孩子误吞磁力珠的新闻一直没断过，这类磁珠一旦误吞，风险比普通珠子大得多。

这种贴纸，真的太容易让人放松警惕了。卡通图案、亮晶晶的颜色，几块钱一大叠，很多幼儿园娃都特别喜欢。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN2hKweeUZsFhnv9xndyIg189QrWmUEx0nAwSwZvbb3W26Cmiab6dqtIIiadeibP0GpXfK1bV9Ywg0nmg/640?wx_fmt=png&from=appmsg&tp=webp)

据新华网报道，这种水晶泥 之所以能这么扯来扯去的， 就是因为里头加了硼砂。 娃接触以后， 可能会皮肤过min；如果长期接触，还可能通过皮肤吸收到体内 ！


更可怕的是，之前央视抽检的“史莱姆”水晶泥里，所有的样本硼砂量都超标，有的甚至 超标了 3 倍！


![图片](https://mmbiz.qpic.cn/mmbiz_gif/sbXcibV5Z3r7c2JiajR3RzYtib8wkvBmgJjicP5LWyB6NDJk7t50gxD7jtzGRZFvNWBXrflpke6eRFHibZs4lXw9rGunMjBQibucJq4SJGn4icGY3w/640?wx_fmt=gif&from=appmsg&tp=webp)


硼砂如果吸收到体内，长期蓄积可能会 损害肝脏肾脏、生殖系统、神经系统 等等， 危害相当大。


安全起见，大家要给娃买水晶泥的话，要认准 有产品名、厂名和厂址，检测过硼含量的， 玩完以后也要记得用 肥皂或者洗手液 洗干净。
