# 糕妈：不做完美妈妈后，我治愈了我自己

![封面图](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN3xibLlqz42KtgIBDmUDPTbtVx0LB29vK044RVeD9aObS1x5iaB0oH2ezwubtUToXQS1RtxAtCS0CIw/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/q5y14a5UUId0R8x8V3QcaA

当妈之后，做自己的时间越来越少了。

仿佛妈妈们在生了孩子之后，总是会把自己放在最后考虑，牺牲自己去满足孩子的需要。但是你们心里，会不会有一个声音在一直呐喊：**我也是一个独立的个体，我想要变成更好的自己！**或许应该拿出时间来，倾听自己内心的需要，先做好自己，再做好妈妈，这才是我们作为女性的人生最为重要的课题。
