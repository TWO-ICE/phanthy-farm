# 正大光明出轨，却被富豪老公宠上天？聊天记录曝光，网友竟然也选择原谅她！

![封面图](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN39QBdJl2Su96kqlhB3Z782m22nxmupFgdbbf27MibXvnibsiaASGsaGPjXcRPEviasjUllxRbehZm4uQ/0?wx_fmt=jpeg)

真是没想到，今年在热搜上提供最多情绪价值的，居然都是老一辈的艺人。

前有英子 5 旬老太守国门，后有庆奶 74 忙着谈恋爱。

![图片](https://mmbiz.qpic.cn/mmbiz_png/nuqSmia8OqobE9optcD7QFsDFFD5sUarqdXEc6zj6Y8ZLaBNk6v2e3ibiadhIa2RCuLgjnPouTfISltqW5icuHKibOg/640?wx_fmt=png&from=appmsg)


先给还没吃瓜的姐妹简单科普下：就是刘晓庆 50 多岁的前男友最近突然爆料，她在已婚状态时谈了不止一个男友。他去找她闹，就被分手拉黑一条龙服务。5 年了，知三当三的他还是没走出情伤，就曝光聊天记录来威胁。

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/nuqSmia8OqobE9optcD7QFsDFFD5sUarqII4pou4AfYqvKtoZYZkJqZQ5ymmy484sUs7SbruK8O9uQIicadvVvVw/640?wx_fmt=jpeg&from=appmsg)

**以为这事儿大家多少会骂几句，结果点进评论区傻眼了。**网友早已经完成了「去其糟粕，取其精华」的过程，总结出一个大女人哲理：“不要有年龄焦虑、容貌焦虑，保持健康良好的心态，日子想过成什么样就能过成什么样！看看人家刘姐姐！”

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/nuqSmia8OqobE9optcD7QFsDFFD5sUarq0iadCmqKM0EaHzstJjicIX5JeHaNM1v2tbWrhKeNs5vLdlsEzbdcBGpA/640?wx_fmt=jpeg&from=appmsg)


总之私生活是一团糟，但翻看她这些年起起伏伏的经历会发现：晓庆这丫头，**一直都很野**。


犹记得前几年，说起刘晓庆这个名字，互联网上还是一片群嘲。

理由嘛，看图很直观👇

![图片](https://mmbiz.qpic.cn/mmbiz_png/nuqSmia8OqobE9optcD7QFsDFFD5sUarqgXjJsQlfia0aZ72lvSFc9fib0mVNhjZPRLLYqVAUoFIibI9OOCkicJvHpw/640?wx_fmt=png&from=appmsg)

虽然六七十岁的年纪能保养成这样确实难得，但看到比她还小二十多岁的男演员宠溺地喊着「傻丫头」时，真的蛮冲击的。可面对群嘲，庆奶的回应自洽：“其实对于一个演员来讲，不存在装嫩和装老。我在很小的时候就演老年慈禧，从来就没有人说我装老，现在就说装嫩。”

![图片](https://mmbiz.qpic.cn/mmbiz_png/nuqSmia8OqobE9optcD7QFsDFFD5sUarqCML5MDxrIlMicxfVtae0ffdpvB4Ds7eKXhpnnwibdgbdiaEGBLia3libp7g/640?wx_fmt=png&from=appmsg)

如果多瞅几眼她的演出表会发现，她也不是执着于装嫩，更像是**戏瘾大、自信，觉得没有自己不能演的角色**。比如，她曾在**一部剧里饰演七个角色**。反串过男性，也扮过丑，如果有外星人找她演，她也是愿意的。

![图片](https://mmbiz.qpic.cn/mmbiz_png/nuqSmia8OqobE9optcD7QFsDFFD5sUarqj4ibtNYyBTYMsjjNmY1dyA4miciauKibtYyAUmRaG8dAmB6x3xUicTvuSsA/640?wx_fmt=png&from=appmsg)


精神状态也很超前。提起年龄：“你看法国人 78 岁在谈恋爱，美国人 78 岁还在选总统，那我们还有什么好说的呢？其实现在正是年华。”

![图片](https://mmbiz.qpic.cn/mmbiz_png/nuqSmia8OqobE9optcD7QFsDFFD5sUarq6sXFmbxg7ThPjtbYfUto6croibicayjI4WXo02NuVYl4dFEqQry1iaUIg/640?wx_fmt=png&from=appmsg)

不是自欺欺人，她是真挺爱活的。歌词里都只敢写「向天再借五百年」，她不，她要向天再借一万年。

![图片](https://mmbiz.qpic.cn/mmbiz_png/nuqSmia8OqobE9optcD7QFsDFFD5sUarqJWJEMjOqjKDfbKYzYI9sAmrpUfJsOmTkQUqojakGV6PnKTMTf6AibRA/640?wx_fmt=png&from=appmsg)

谈到生死，她说「只要不死，都是小事」。

![图片](https://mmbiz.qpic.cn/mmbiz_png/nuqSmia8OqobE9optcD7QFsDFFD5sUarqNYNXA6evUj4sFVgtfKsI2oFdszujVupTn4X31OIxJcsicVdibAC1clvw/640?wx_fmt=png&from=appmsg)

五十来岁被关进小黑屋。为了保持身材和皮肤紧致，她在只有几平米的地方每天跑 8000 多步，无论冬夏都洗冷水澡。

![图片](https://mmbiz.qpic.cn/mmbiz_png/nuqSmia8OqobE9optcD7QFsDFFD5sUarqiazffibnMRXIN5gpvxP51ZrGwXLKaBl4icrZH6CYib1aiaXVQxvia0H1GwLw/640?wx_fmt=png&from=appmsg)

还很求上进。**不仅顺便把英文给学了，连摘棉花都要争第一。**难怪她妈形容她：就是吃💩，也要吃尖尖上的。

![图片](https://mmbiz.qpic.cn/mmbiz_png/nuqSmia8OqobE9optcD7QFsDFFD5sUarqqW8xH6ibW7uqhf10BW8ibJcJ5cqVb4DjzrbIRT4Q042NPsoytTMTH4Yg/640?wx_fmt=png&from=appmsg)

而且自我意识很强，绝不内耗。“夸我的我就看，不夸我的就略过。”

![图片](https://mmbiz.qpic.cn/mmbiz_png/nuqSmia8OqobE9optcD7QFsDFFD5sUarqI2GDjdufnBBo0nnfgRgmVdxgswiaSuiapIQ1jLzyuL53KtdtwTiaqnKNg/640?wx_fmt=png&from=appmsg)

说到女人这个身份，她无比认同，下辈子还要做。和第四任老公王晓玉在旧金山登记结婚时，工作人员问她要不要改夫姓，她立马拒绝：“我可不想有一天拿奥斯卡奖，名字不是刘晓庆，而是王晓庆。”

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/nuqSmia8OqobE9optcD7QFsDFFD5sUarqg0JKXtyVicMrw9WgjunECN5CndKr6k6lk4zsxsiaZd48A9yBKOG8f7lQ/640?wx_fmt=jpeg)

关于生孩子，她和老一辈盛行的观念相悖。“我绝不认为，生孩子是你生命的延续。她是她的生命，我是我的生命。”

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/nuqSmia8OqobE9optcD7QFsDFFD5sUarqGibZs3LjzvK4A6IsFtGicGF87zpDBnGFrBLdTTRDuN5sF6oTbvp9KMmw/640?wx_fmt=jpeg&from=appmsg)

长期以来，「优雅地老去」被认为是对女性最大的褒奖。但她不：**“我为什么要优雅地老去，我可以张牙舞爪地老去吗？”**

![图片](https://mmbiz.qpic.cn/mmbiz_png/nuqSmia8OqobE9optcD7QFsDFFD5sUarqWlLQiauqMYSnuztLDmP0mIfIlDrUDDQ94icpTvoZsPBlIJPQKYpmXx2Q/640?wx_fmt=png&from=appmsg)


**年近六十还能嫁豪门，很多人都觉得她多幸运，不能再嘚瑟。**她在自传里直接就反驳：“什么叫嫁入豪门？我经济上不依靠别人，精神上不依赖别人，事业上不仰仗别人，**我这里才是彻头彻尾的豪门**。”

![图片](https://mmbiz.qpic.cn/mmbiz_png/nuqSmia8OqobE9optcD7QFsDFFD5sUarqG1ZrItwAYGuZZkMWnz5hib6WfeN7uickzpcAQQRBZAtNKSByeslkdYaA/640?wx_fmt=png&from=appmsg)

在她的社交平台上，还能看到许多不定期放送的大女人金句：“征服世界的不是只有男人。”

![图片](https://mmbiz.qpic.cn/mmbiz_png/nuqSmia8OqobE9optcD7QFsDFFD5sUarqj7xiaxOar2Ff4eiaJ6YdxDTWHVcjnS9ct41IyhLWXibxBFP1SRcibDIp2A/640?wx_fmt=png&from=appmsg)

70 多岁了，还能有如此旺盛的生命力，难怪让无数网友感慨：**要么她演武则天呢！感觉自己都黄土埋半截了，生生让晓庆这丫头给拔了出来。**

![图片](https://mmbiz.qpic.cn/mmbiz_png/nuqSmia8OqobE9optcD7QFsDFFD5sUarqbtWh3TyzQZpCZzwI0fxUp5PL3ypJLgEXbamoJP6wyRQDvR9bRxkYicQ/640?wx_fmt=png&from=appmsg)


诶别说，这几年气血旺盛，搅动热搜的奶奶辈还真不少。

有平台胆子也是大，居然把她们一个个都搜罗起来，弄出了一档旅游综艺。预告的嘉宾除了庆奶，还有**向太陈岚**、**蔡明**、**斯琴高娃**、**张兰**、**张蔷**.......每划过一个名字，心就得跟着抖三抖。

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/nuqSmia8OqobE9optcD7QFsDFFD5sUarqPz4hpEZ4YkCX0agZLjSORo0wqatOF0Y4A4kRxPgPLEm78I1dNpFXCw/640?wx_fmt=jpeg&from=appmsg)

还没播，网友就已经开始担心起参加节目的小辈了：这一把，生死局。这哪里是「带着奶奶去旅行」，分明是「武则天团综」嘛，不得分分钟打起来？

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/nuqSmia8OqobE9optcD7QFsDFFD5sUarqDQOia2mtXWJkNyrAkZUAAO0aIMAW2OP2O7oibib9r0ItUOia19icULPfTtQ/640?wx_fmt=jpeg&from=appmsg)


还真不一定。大家印象中的蔡明，是那个说着「都是千年的狐狸，你给我演什么聊斋」的毒舌老太太，狗路过都得怼两句。

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/nuqSmia8OqobE9optcD7QFsDFFD5sUarqc3w2ql41p7zIyRqUPkezzSBwicxyHkq1O1rk2WibFGwgAH4yg7Cnr7Iw/640?wx_fmt=jpeg&from=appmsg)

其实，她一直走在冲浪前线，非常接地气。和咱一样爱看直播，并且“直播间买了一堆狗粮，到了发现家里没有狗。”

![图片](https://mmbiz.qpic.cn/mmbiz_gif/nuqSmia8OqobE9optcD7QFsDFFD5sUarq4deWHe6IaroNGJ3UOCIgODrhSMjOjLL0Rskqn88dfPz1SrQI7mZPpA/640?wx_fmt=gif&from=appmsg)


还在该退休的年纪，化名菜菜子当起了虚拟偶像，和年轻人打成一片。

![图片](https://mmbiz.qpic.cn/mmbiz_gif/nuqSmia8OqobE9optcD7QFsDFFD5sUarqUKnjeuVIM42PFpnhib6gK95SJUHPbBdQzXG0SRXdCr8iapyPdwMPWichQ/640?wx_fmt=gif&from=appmsg)

**虽然年纪大，但绝对不会摆出长辈的架势教你做人。**

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/nuqSmia8OqobE9optcD7QFsDFFD5sUarq3ib0iavgYxYib5KLjuIjablPZV6qcEC1TGorN1cUNK5wHV12T2S5S6bJw/640?wx_fmt=jpeg&from=appmsg)

都觉得向太不好惹，但翻看社交平台，其实她还蛮看得开的。前段时间向佐被全网嘲演技。

![图片](https://mmbiz.qpic.cn/mmbiz_gif/nuqSmia8OqobE9optcD7QFsDFFD5sUarqHkMI919p3nbyxWQR7zuYbCdwXDecfxhwLDjE3ayfiah4YDP24LuKMJA/640?wx_fmt=gif&from=appmsg)


名场面——向佐摸鼻梁+扇耳光。

网友直接在评论区开问。她跟着一块笑，“你们私信发我他的表情包，我晚上做梦都笑醒。”

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/nuqSmia8OqobE9optcD7QFsDFFD5sUarqnoia3bbSJoblBcgibKgcCyflKmvrq4iaL3VdcwSYwMh6v8Xmj5RQ1sqXA/640?wx_fmt=jpeg&from=appmsg)

还**不止一次点赞过网友对郭碧婷的现状评价**，儿子被说也不生气。“有钱，有儿女，有通情达理的公婆，臭老公远离，日子太滋润了。”

![图片](https://mmbiz.qpic.cn/mmbiz_png/nuqSmia8OqobE9optcD7QFsDFFD5sUarqcFZhHM5z9ZoRibuqRdLKhf1vCqVLvWpQticsHcUBRWv8EuquFzibSmzUQ/640?wx_fmt=png&from=appmsg)
