# 正式被全国禁止！这种牛奶别再给娃喝了，耽误长高还可能性早熟

![封面图](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN0FzrsCy0rRTGeTKrRNpxTdmTbiae7jnknjETgO7MtP7iczeMG9LE8vQCWna1ib2cH7kyNscE0RO7BibQ/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/zbKs1anMzksg9mDH1Cr-kg

姐妹们，从 9. 16 开始，国标《灭菌乳》新规就正式启用了，**复原乳在常温纯牛奶中被全面禁止👇**


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/rrVVklPTzRA0k6z6cvCnjwufma6rgkVD7Q5Os3VibnPtsetwmqEKqEaovKa6bMmRQdaGxFo0icib3mYlrfxwianInQ/640?from=appmsg)

简单来说，**复原乳**其实就是**奶粉+水。**它经过反复加工，维生素、活性酶等营养成分会有所损失。

那这次标准实施后，纯牛奶必须 100% 以生牛乳（直接挤出的鲜奶）为原料，也就意味着更纯更好！


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/2EaFkYu8ISvicTlv69eRGrgP1ibpibfP0ibiciczp7Dfn674FqvvCrlicEyeSmBdnFf0MYHO3SFKhXP3dQiafx2VJUNzgw/640?wx_fmt=png&from=appmsg)

但作为一款“经济适用奶”，复原乳依旧可以合法使用在其他乳品里，比如旺 X 牛奶等。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/2EaFkYu8ISvicTlv69eRGrgP1ibpibfP0ibicQLB7FPM2da1OJrocjhgxGLaUk9Ss2lg0RyTnWwkJTW7HGj8IoqbvOg/640?wx_fmt=png&from=appmsg)


所以今天，我们就为大家来盘点产品上标有「奶」或成分中添加「奶」的产品。

**它们偶尔喝喝还行，但千万别指望能代替牛奶的营养，还要警惕糖分超标**（4～6岁每天的“坏糖”限额约 19g）。

可能会导致一系列与糖有关的问题，**比如肥胖、龋齿、糖尿病、性早熟等等。**


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/2EaFkYu8ISvicTlv69eRGrgP1ibpibfP0ibicSbMbyCb2ZWFaKcf11FKm6FGQBnLNicfIWicgJcsiaiaibdzqw928NKaniaNQ/640?wx_fmt=png&from=appmsg)

新规发布后，买牛奶认准 GB 25190 和 GB 19645，准没错。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/2EaFkYu8ISvicTlv69eRGrgP1ibpibfP0ibicUFLOXfKLXMRs0PCVjDB3DticWUoaQIic5vT68ZJgRzSFJ1u31UXW8lnA/640?wx_fmt=png&from=appmsg)

还有一些产品上标着「奶」或「牛乳」，但并不是真牛奶，营养成分也大打折扣👇

**❌旺仔 X 奶**


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/2EaFkYu8ISvicTlv69eRGrgP1ibpibfP0ibicuK4kXBnA4pgXV0yOxTAzSib6fUZLA0tel6qwyNicaeSRbl8WW2BPVp6g/640?wx_fmt=png&from=appmsg)

🤔执行标准：GB 25191 调制乳

😱配料：复原乳、水、白砂糖、食品添加剂等

明确标注了复原乳，虽然不影响钙含量和蛋白质，但糖含量高，两大瓶就超过“坏糖”限额。


**❌早餐奶**


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/2EaFkYu8ISvicTlv69eRGrgP1ibpibfP0ibicA2EdtZiaTBJMJXbng5CNVACUHo0QRkcE0s8hOWRiaKgAAKl5W8b7jXhQ/640?wx_fmt=png&from=appmsg)

🤔执行标准：GB 25191 调制乳

😱配料：生牛乳、水、白砂糖、核桃粉、维D、食品添加剂等

虽然加了些营养强化剂，但因为加了糖和其他添加剂，营养成分也是大打折扣啦。

**❌生椰牛乳**


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/2EaFkYu8ISvicTlv69eRGrgP1ibpibfP0ibicicbgthiaHPJjY8r1ciaszvZObb8FkmIuf2qcZ22G5bmGS3sA9T6Jz05qA/640?wx_fmt=png&from=appmsg)

🤔执行标准：GB 21732 含乳饮料

😱配料：水、鲜椰肉汁、白砂糖、全脂奶粉、酪蛋白酸钠等

排在第二位的鲜椰肉汁也就才6%，奶含量不必多说了，感觉就像在糖水里加了一勺奶粉。


**❌AD X 奶**


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/2EaFkYu8ISvicTlv69eRGrgP1ibpibfP0ibicpKCTQxwP0kZNWFCRDV31SZDCoibGOlONP3vXccg0v8guYElbW33hK5g/640?wx_fmt=png&from=appmsg)

🤔执行标准：GB/T 21732 含乳饮料

😱配料：水、白砂糖、全脂乳粉、脱脂乳粉、果葡糖浆等

维A和维D聊胜于无，钙含量也不高，只有60mg/100mg（牛奶通常有120mg/100ml）！


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/2EaFkYu8ISvicTlv69eRGrgP1ibpibfP0ibic3mKTNEKZ0vdnJ9HhKB6q4s9ocnzxy1sCl2BJyM8TZIzUuTgjx8fVIg/640?wx_fmt=png&from=appmsg)

还有一些产品，虽然里面加了奶，但本质上还是饮料！

** 含乳饮料=水+糖+乳制品（牛乳或奶粉）**

很多人都被它们“健康”的外表骗了——

**❌酸酸乳**


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/2EaFkYu8ISvicTlv69eRGrgP1ibpibfP0ibickPbgK10DjU2thbdXR9Ov6Abkth78U9TVNqlP7wToEyKpddlUPmTdBQ/640?wx_fmt=png&from=appmsg)

🤔执行标准：GB 7101 饮料

😱配料：水、生牛乳、果葡糖浆、白砂糖、乳清蛋白粉、苹果汁等

看执行标准就知道了，纯饮料！可能就是酸酸甜甜能开胃？就别指望能有其它营养了。


**❌营养 X 线**


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/2EaFkYu8ISvicTlv69eRGrgP1ibpibfP0ibicb0efBWO5licNASwdr3dpymYh7B2n1F9MDQCg0VN7oEFTfrmrDVIAoKA/640?wx_fmt=png&from=appmsg)

🤔执行标准：GB/T 21732 含乳饮料

😱配料：水、白砂糖、全脂乳粉、食品添加剂、苹果汁、脱脂乳粉等

外包装标注牛奶含量≥30%，但是看着配料表里白砂糖排在第二位......大家自行判断吧！


**❌乳酸菌饮品**


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/2EaFkYu8ISvicTlv69eRGrgP1ibpibfP0ibicw9rB2iaCMB8hnf6Q1pEiaqsTibbuWfwzRQgo1zbRStOd3VTuWySt8vnSg/640?wx_fmt=png&from=appmsg)

🤔执行标准：GB/T 21732 含乳饮料

😱配料：水、白砂糖、脱脂乳粉、食用葡萄糖、食用香精、副干酪乳酪杆菌

《消费者报道》曾测出它一瓶含糖量约50.1g，而WHO推荐的成人“坏糖”限额也就25g/天！
