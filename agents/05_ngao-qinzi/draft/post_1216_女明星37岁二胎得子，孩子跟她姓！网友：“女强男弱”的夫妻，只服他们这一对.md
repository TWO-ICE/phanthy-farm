# 女明星37岁二胎得子，孩子跟她姓！网友：“女强男弱”的夫妻，只服他们这一对

之前有一个视频把编辑部妈妈们给可爱到了：

演员万茜正准备跟同剧演员连线直播，女儿小跑进来奶声奶气地跟妈妈说要背古诗。然后当妈的就只能放下工作，听小姑娘抑扬顿挫地背古诗，声音萌化了。万茜的状态也跟平时镜头下专业、清冷的模样完全不同。

![图片](https://mmbiz.qpic.cn/mmbiz_gif/z7kZjMoQ3yHbM2ia97LPXknKEdZtqrTibMxYeIPyFH7lQicxjmHLSU57bcz21Homia3bial2SFEXiczlYPIHLyfplkhQ/640?wx_fmt=gif)

看看这不值钱的笑容，谁能想到她曾经是个既不想结婚，也不想生孩子，只想拼事业的文艺青年啊！但如今的万茜，不光有不错的演艺事业，更有幸福安稳的家庭。有妈妈在线虚心求教：万茜老师是怎么做到事业家庭两手抓的？
其实，哪有什么两手抓，**已婚人士还能心无旁骛地****拼事业，常常是有另一个人在后方解决家庭的后顾之忧**。接受采访的时候万茜说过，当她需要工作的时候，老公会自然地减少自己的工作量，把家里的一切都搞好。光这一句，就足够让太多妈妈羡慕了。**

![图片](https://mmbiz.qpic.cn/mmbiz_gif/z7kZjMoQ3yHbM2ia97LPXknKEdZtqrTibME063PiaMl77vDx2ibiahib3NBqFicvibZs4mAARjRW7CictEMxmgE4fVibM6ibQ/640?wx_fmt=gif)

**和万茜类似的，还有戚薇李承铉夫妇。前些年，这两人是出了名的“女主外，男主内”。李承铉带女儿上综艺，小到扎辫子、吃饭、陪玩，大到孩子的性格培养，就没有他搞不定的。这才有了那几年，戚薇事业的突飞猛进。**

![图片](https://mmbiz.qpic.cn/mmbiz_gif/z7kZjMoQ3yF7m6PVlQon2hAsIbsI62ZAgetNNlU7e7hiaMiczUP9VI3Pia3ibcFwyoV2O5KzibuKAAfoZRHmQ0rNjHA/640?wx_fmt=gif)

**李承铉在采访中说过：男人的事业生命线会比女性要长，我可以在家陪孩子几年，再重新开启事业，但戚薇为了生女儿已经把最黄金的时间付出掉了……而在李承铉遭遇“全职困境”的时候，戚薇也会告诉他：“你在家照顾宝宝，我可以追求自己的梦想，我反而要感谢你。”去年，戚薇李承铉还喜得二胎，而且根据之前直播的说法，这个娃还会跟戚薇姓！

![图片](https://mmbiz.qpic.cn/mmbiz_png/z7kZjMoQ3yHbM2ia97LPXknKEdZtqrTibMzvjDRLIDxFnbwbvick7FKteO9ErZaLFjXjJkA7OuLt3ZjebD8EoW6Yw/640?wx_fmt=png)


此前李承铉火速官宣了几部综艺，还在披哥上卖力演出。让人不能不感叹，夫妻俩的角色转换也是异常丝滑~从这两对的例子不难看出，**现在越来越多的夫妻不再局限于传统观念中的家庭分工模式**。谁赚钱，谁带娃，有了更灵活的选择。越来越明确的共识是：婚姻是一个整体，不管角色如何变化，能把日子过好才是家庭的大目标！但其实我们也很好奇，普通人也会遇到和明星类似的家庭分工问题，大家是怎么处理的呢？会不会有角色上的困扰？今天就请妈妈们来聊聊。


![图片](https://mmbiz.qpic.cn/mmbiz_png/z7kZjMoQ3yHbM2ia97LPXknKEdZtqrTibMmHQdNd0GXpEuyfS0QSyARFZ7j1gHAZv6cy1YKZyyUW9uAfhhicfy4jQ/640?wx_fmt=png)


我家“男主内，女主外”的家庭分工，最开始是无奈之举。娃刚出生还不满一个月，我婆婆就被查出来癌症晚期。我跟老公都是单亲家庭，就想着他辞职来照顾婆婆，不要让自己留下遗憾。那段时间真的非常辛苦，又要照顾孩子，又要照顾老人，晚上我给娃喂奶的时候他也会起来扶着我的腰，喂完再去洗吸奶器......后来产假结束后我要上班，老公要承担的家务就更多了。但他对这一切都接受良好。毕竟上海找一个育儿嫂就要 1w+ ，家庭的小账算下来，他也相当于挣钱了！再加上我家是男宝宝，爸爸作为育儿主力军有不少好处，孩子小小年纪就跟着爸爸做家务，是个小暖男~

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/z7kZjMoQ3yHbM2ia97LPXknKEdZtqrTibMN7iapHMw4be1jfOVZbY0OP0vSdNglklibOoZn2LTshts9e8Jfnewic7ow/640?wx_fmt=jpeg)


今年娃就要上幼儿园了，我老公也打算找工作上班，我们马上就是双职工家庭啦！我觉得家庭分工需要充足的沟通和理解，**不要有谁做多、谁做少的心理，大家都参与进来，为我们的小家做贡献，就是件好事儿~**


![图片](https://mmbiz.qpic.cn/mmbiz_png/xSYcibCDmz67ya9RBFX6icJwVF1iasIbgL2qMNXBHLptFM5Jhd4ZwtGWMSD1Dg6ibXy9ICtf5jQHiaDuf8eOr1XkjWQ/640?wx_fmt=png)


我和老公都是做生意的，但疫情期间，他的小公司一下子运转不下去了。而我是医疗行业，反而爆单忙到飞起。我 70% 客户都在国外，很多时候开会都要半夜，还要跑工厂、催原料、跟订单，太累了。

而家里还有两个娃，每天要接送。老大正是陪作业都要人命的时候；老二当时上幼儿园、今年刚上小学，每天也很能刷存在感。当时我们两人就商量，索性就**让他把业务暂停，在家带娃一段时间。**这样我可以尽量挣钱，没那么多后顾之忧。到现在，我们家这种运营模式持续两年半了，除了老公偶尔抱怨需要我安抚，其他一切都还好。而且一个自称学霸的男人，当他全身心在家带娃，就特别想证明自己。我家**老大的成绩非常明显地变好了，老公实在是功不可没，我每天都想夸他。**最近我又接到一个国外的订单，如果签证没问题，年内就能出去签约了。这种能放心出去挣钱的感觉还挺爽的，我自己很希望把现在的家庭模式继续下去，但是还没问男人怎么想，哈哈~


![图片](https://mmbiz.qpic.cn/mmbiz_png/xSYcibCDmz67ya9RBFX6icJwVF1iasIbgL2aXjmsR6w1icMxnxJCbfR14JAJoEVGgdSxpCNoe9ZYmV1D8dsg9htu7A/640?wx_fmt=png)

我和老公都是小县城出身，婚后就一起去了广州打拼，但因为孕期反应太大，我只好辞职。后来孩子出生，一家人在广州的开销越来越大，只是读一学期幼儿园就花掉了几万块积蓄。所以尽管孩子在幼儿园表现得很好，我们还是做了一个艰难的决定——**两地分居：我回家带娃降低生活成本，他在广州打工赚取家用。**回家 3 年后，我们都觉得这种分工方式很适合我们家现在的状态，就决定要二胎。当然了，一个人带两个娃有很快乐的时候，也有着说不出的心酸和无助，尤其是带俩娃出门的时候，真的很难。但这些心酸都会在我老公回家的时候被抚平，每次一家人团聚的时候，他都会主动带娃，给我和娃买衣服、买吃的，自己却连鞋子烂了都舍不得买一双。在我觉得心情不好需要看书充充电的时候，他也二话不说就是支持。

![图片](https://mmbiz.qpic.cn/mmbiz_png/z7kZjMoQ3yHbM2ia97LPXknKEdZtqrTibMaNPDmYR2qPCsK5YXa0mm2b2Noq67RTelIM6ZSjvMTdibdXxlP7tiaVLQ/640?wx_fmt=png)

这些举动，让我一直支撑到了今天，让我觉得两地分居不可怕，做全职妈妈更不可怕，这只是万千个家庭中稍微特殊一些的家庭分工罢了。在这样的分工下维持一个较好的家庭氛围，有两个小秘诀：**一是不要有太多的负能量，二是把队友教得好**。两年前，我也找到了一份工作，可以一边上班一边照顾家里，在我们共同的努力和坚持下，现在买了房，我老公也可以不那么累，回家的次数也变多了，一切都在往好处发展。

![图片](https://mmbiz.qpic.cn/mmbiz_png/xSYcibCDmz67ya9RBFX6icJwVF1iasIbgL2jsUicxYweLcnhfI7rLTwqSntP6YxyyHTotGM7ftz83wHo8DsQKlgG8Q/640?wx_fmt=png)


我**本来是没有全职打算的**，但是跟婆婆合不来，产假结束后老人家就闹着要回老家，原公司也不大乐意让我回工作岗位，那段时间真是水逆，各种事情交织在一起，只好在家全职带娃。最开始我也会忐忑，担心全职日子不好过，但老公从没说过“只会花钱”这样的话，婚后**买房买车也只写我的名字。**后来我慢慢调整好了自己的状态，想明白了不管是带娃还是上班，都有自己必须要承受的压力，这份分工也没有谁更有用的区别。最重要的是两个人互相理解，共同努力。我现在就是把带娃当成了属于我的“工作”，看育儿书、学习育儿知识......当然我偶尔也会“摸鱼”，吃喜欢吃的，买想买的，奖励自己小礼物，还跟老公说他应该发我年终奖哈哈哈。现在我家的状态就是达到了平衡点，他对我做家务带孩子要求不高，我对他上班赚钱要求也不高。既然家庭分工是两个人共同的决定，那么**互相体谅、一起承担结果才是唯一正确的解决方案。****

看完这些家庭分工的故事，姐妹们有没有发现，虽然分工模式各有不同，但有一个共同点，那就是——**一起决定，共同承担。**而这背后，有需要很多的沟通和理解。姐妹们，你们的家庭分工是怎么样的呢？会有矛盾发生吗？你又是如何解决的呢？欢迎大家在评论区讲出你的故事，给大家更多的家庭分工参考和夫妻相处之道~
