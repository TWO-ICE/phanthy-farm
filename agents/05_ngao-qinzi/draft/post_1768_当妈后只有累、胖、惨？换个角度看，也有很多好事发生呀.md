# 当妈后只有累、胖、惨？换个角度看，也有很多好事发生呀

![封面图](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN2GtoXmYnEjYeicZXC3X1PDBeMB3bNWCUYP5wbKjcOey4j0QGe9BCZq9FynPz64IibzPsCvZibqwzK6Q/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/s6vXPoZrZDo6Zfoxf5D7_Q

说起当妈后的辛苦，姐妹们可能几天几夜都聊不完，从十月怀胎到一朝分娩，之后还有漫长的带娃时光。

自从生了娃，不少妈妈觉得自己变胖了、身材走样了、头发一掉一大把；觉不够睡，脾气也变差了；每天绕着娃转，一点自己的时间都没有~


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN2GtoXmYnEjYeicZXC3X1PDBAfCJ3uHh01sibwNY9doImJ0GMOs0YcqDSjQW8fb7Y3skNypzqa8DlOw/640?wx_fmt=png)

**难道，当妈后带来的就只有苦恼和麻烦吗？**

其实，不谈这些问题，仔细想想，好像有孩子后，自己也有一些**值得开心的变化~**

生理上，有的妈妈会发现，自己好像比以前**长高了**，**皮肤**出痘痘少了，**生理期**也不再像以前那样没有规律。

心态上，也**更加包容了**，那样艰难的生产过程都挺过来了，还有什么过不去的坎呢？

本来还怕养孩子，但有了人类幼崽后，看着宝宝笑，自己也忍不住笑起来，每天更是沉迷吸娃！


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN2GtoXmYnEjYeicZXC3X1PDBuML0cM4htxuNfOQsGoQKSMqB9z9zViae4UoD4picPhOYYVXx1piahomvg/640?wx_fmt=jpeg)


有了孩子后，**你觉得自己身上发生了积极变化呢？**也许是心理上的，也许是生理上的。
