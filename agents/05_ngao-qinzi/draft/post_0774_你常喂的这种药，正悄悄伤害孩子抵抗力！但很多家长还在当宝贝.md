# 你常喂的这种药，正悄悄伤害孩子抵抗力！但很多家长还在当宝贝

最近天气慢慢变冷，生病的小朋友真的非常多，每年这个时候，学校里就会出现一堆**支原体肺炎病患**。很多家长为了“有备无患”，专门囤治疗支原体的特效药“阿奇霉素”，后来又有新闻说“支原体耐药，阿奇霉素不管用”，又一窝蜂的去买“多西环素”。还有一些长辈，因为杭州这些消炎药不好买，专门从老家带了各种各样的消炎药，娃一生病，就赶紧吃上。除了流行的支原体肺炎，**一生病就吃抗生素**的情况，在孩子**拉肚子**的时候也很常见，尤其是这个季节容易感染**轮状、诺如**病毒，家长自用消炎药虽然是出于关心，但往往就是好心办了坏事。下面 3 个典型的误区，看看你有没有犯过：
**误区一****盲目乱吃消炎药**消炎药不是治病的万能药。孩子常见的感冒和拉肚子，消炎药可能起不到作用。有些人觉得，感冒、咳嗽、拉肚子，就是身体有炎症，吃点“消炎药”好得快！可是，孩子急性腹泻的**最常见原因是病毒感染**，而所谓的消炎药（大部分的抗生素），一般是针对细菌的，**对病毒无效****。******还有**咳嗽等上呼吸道感染，也多是病毒导致的，抗生素也没用**。抗生素吃多了，对孩子健康，还有反作用！肠道里本身生活着正常菌群，其中有益菌（益生菌）多、有害菌（致病菌）少。健康、平衡的菌群，是孩子肠道健康的基础。但我们吃抗生素的时候，药物可分不清好坏，**致病菌、益生菌它都杀**。

![图片](https://mmbiz.qpic.cn/mmbiz_png/eNysDu3qI3duZSLWHGRHicSlSOT4VUoAzDks6BsibibFerCqKAPYlTqpqe6iaYZkzLLHicQhkL0IyiaENMfJ2vgndjXw/640?wx_fmt=png)

一下子就把平衡的菌群生态给破坏掉了，恢复起来很困难，有些娃还可能会因为抗生素，导致肠道菌群紊乱，成了难治性腹泻。说起**肠道益生菌，不仅关乎肠道健康，更关乎整个机体的免疫力**。肠道是体内非常重要的“免疫练兵场”，里面各种好的坏的细菌，是体内免疫系统练兵的好机会。各种免疫细胞、免疫因子、益生菌和致病菌进行不断的斗争，**从而使肠道菌群达到动态平衡**。

![图片](https://mmbiz.qpic.cn/mmbiz_png/eNysDu3qI3duZSLWHGRHicSlSOT4VUoAzosOZjePkNaQap78RibjIqdfW7hjjNhLHob0rdIXb6Q9TacoTZfgx96A/640?wx_fmt=png)

这个平衡非常关键，免疫系统弱了，各种致病菌就会趁虚而入，引起拉肚子、肚子痛等等问题。经常听到有人说“消炎药吃多了会吃疲掉，以后更容易生病”，很可能就是扰乱了菌群平衡，从而影响到整体免疫力！所以说啊，**别乱给娃吃抗生素，抗生素要在医生指导下使用。**
**误区二****一拉肚子就止泻**很多妈妈看到娃拉肚子，就想赶紧止泻，只要不再拉，就好了。这种想法也是错误的。拉肚子，或者说急性腹泻，很多都是病毒、细菌感染导致的。而**拉肚子这个行为本身，属于身体的自我保护机制**：有害物质来了，肠子蠕动加快，赶紧把刺激肠道的东西、致病的病毒、细菌，通过大便排出去，腹泻也会跟着缓解。

![图片](https://mmbiz.qpic.cn/mmbiz_png/eNysDu3qI3duZSLWHGRHicSlSOT4VUoAzibHvgeCcbbNOibzNyATV9UrMyKayu1hvgDEYibFf11RV57AhIWbP4m12Q/640?wx_fmt=png)

很多止泻药，是通过抑制肠子蠕动来起作用的，看起来是不拉了。致病菌、刺激性物质都憋在肚子里面，反而更加难受。**很多孩子吃了止泻药以后确实不拉了，但一直说肚子疼，就是这个道理**。腹泻时，比止泻更重要的，是做好**防脱水**工作。可以给孩子喝**口服补液盐**，帮助补充丢失的水分和盐分。

![图片](https://mmbiz.qpic.cn/mmbiz_png/eNysDu3qI3duZSLWHGRHicSlSOT4VUoAzqjoONbeFmAMkUZnicobg7eziafSiaicbovDho7uibDvsc5sGFBL4ac8NicjA/640?wx_fmt=png)

如果孩子脱水严重，补液盐也喝不进去，那要抓紧时间去医院处理。
**误区三****益生菌“万能”随便吃**现在各种益生菌产品越来越多，让不少妈妈很心动：🤔以前吃过消炎药，估计杀了不少益生菌，赶紧吃点补补。益生菌虽然对肠道健康非常重要，但不是万能的，肠道菌群是个非常非常复杂的体系。现在我们对它的研究还十分浅显，有成熟制剂的益生菌，和我们肠道里面的益生菌比起来，简直是九牛一毛。要补益生菌，也要仔细挑选，尤其要**注意益生菌的种类和数量**。想要从嘴巴里吃进去，一直到肠道还能保持活性，对产品当中的益生菌数量有要求：**每克食品级益生菌应含有不少于 1 亿活菌**。**3 岁以下孩子要看好菌株号**，菌株号要在下面的表格范围内。

另外，选择益生菌也要看配料表， 尽量选择没有添加糖，配方尽可能纯净的益生菌产品。在这里也提醒各位妈妈，想要孩子少生病，还是靠日常重视饮食卫生、饭前洗手、出门注意防护等等细节，减少感染各种致病菌、病毒的机会，才是健康身体的基础。点击上方卡片关注，了解更多育儿知识👆‍
