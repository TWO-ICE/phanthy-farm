# 最脏水果排名第一？给娃吃真的得小心，快看看你家有没有

![封面图](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN3omTRRrtv1yoHVgSD65sgUqe3W0MfHxzXqJZPPq2iavC6FgvIxGiaxvf0LtusLTRlB7gBkoT6Bjn0Q/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/CFZWt1kUtDc19Q_Px3Bx2g

每天中午，同事 C 姐都会趁着吃饭时间，给家里买菜、买水果，可以直接送上门，老人能省心不少。然后前两天，她看到桑葚上市了，想给女儿买一盒尝尝鲜，没想到比草莓还贵。

**折算下来，一斤桑葚要 45，比草莓贵，还是特价的**👇


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/rrVVklPTzRAlRyj3ct9rCG7ojCM7M0DL0lTfbWJIJ3J6SN6NQQoZBUP0afIJwl1lemYS8ryrzdsH2NugnWdZyA/640?wx_fmt=jpeg)


另外一位同事也吐槽说，之前在奶茶店看到有桑葚奶茶，就买了一瓶，没想到要 30 来块。 


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/rrVVklPTzRAlRyj3ct9rCG7ojCM7M0DLhkwZ2jeV3icenM50whtxR0YrPwjTialQicsibOYb4fykh4SKvQ6KwfQ2xA/640?wx_fmt=jpeg)


南方地区长大的姐妹，对桑葚的印象大概都是——**这不是小时候直接路边摘着吃的水果嘛？**怎么现在的身价，都快赶超草莓、蓝莓了。

所以，今天咱就来和大家唠唠，看看它是不是有啥独特之处，一起吃个明白。


这么贵，难道是营养价值高？
"45 元一斤的桑葚，和橘子、苹果比，是真的贵。不过，敢卖这个价，和营养价值并没有多大关系。


因为单论营养成分，它也就算中等水平。


![图片](https://mmbiz.qpic.cn/mmbiz_png/rrVVklPTzRAlRyj3ct9rCG7ojCM7M0DLh5vcwYZwUoDGUUGxHd5ocIycetEppl0T3ibpoOo7YmKg7KhQ4RyBtkQ/640?wx_fmt=png)


好在桑葚清甜无籽，还一口爆汁，对老人、孕妇、孩子比较友好，应季的时候，买一两盒尝尝鲜还是不错的。

**如果是给娃吃，一定要穿上罩衣哦。不然，汁水溅到衣服上，就有点费妈了。**


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/rrVVklPTzRAlRyj3ct9rCG7ojCM7M0DLu2icKlqOOtFU73hX19lBgiajqDwadr8AHgt4SH1sqwJwxicercePojMGg/640?wx_fmt=jpeg)


桑葚贵，难道是还没到季节？
"大家都知道，应季的水果更便宜。

那你知道吗？**桑葚大批量上市的时间，其实是五一小长假前后，现在根本不是它的季节。**


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/rrVVklPTzRAlRyj3ct9rCG7ojCM7M0DLWsyfNXCDk0UoicJ5d5eob010hEjWlc6OCDiajYxqjDoQxf2dHSQcDfYQ/640?wx_fmt=jpeg)


最近市面上的桑葚，主要产自温暖的**广东**，种植面积不多，价格自然贵了。

而且，桑葚没有外皮，熟了很容易坏掉，运输损耗大，网购基本都要寄顺丰，成本就“蹭蹭蹭”上去了。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/rrVVklPTzRAlRyj3ct9rCG7ojCM7M0DLfyoy87Wqd0R2OfQXpSlqXgRcftozgdBCP4ayCKz7H0F6D5dDY2IVyA/640?wx_fmt=jpeg)


所以，产地之外的小伙伴想吃，自然要“破费”一些。

现在，大家大概也理解了吧。最近桑葚贵，主要还是因为没到时候，以及果子太娇嫩了！

大家愿意为它买单，主要是图个新鲜、健康，同时吃桑葚又保留着一份童年的趣事回忆。


表面坑坑洼洼的，洗得干净吗？
"之前，有妈妈留言问：桑葚怎么洗？


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/rrVVklPTzRAlRyj3ct9rCG7ojCM7M0DLbt8nV5b3pDBwLTjOZ8jP9snnN5ia719kIPdFiadoEhkLw85LKoaKEM6A/640?wx_fmt=jpeg)


我们搜了下，不少说得用面粉、盐水泡了才能吃。桑葚属于浆果，本来就很娇嫩，再这样一顿操作，果子都被洗烂了。

那该怎么洗呢？

其实，**只要是正规渠道（比如超市、外卖平台）买的水果**，包括桑葚、草莓、蓝莓、覆盆子之类的娇嫩水果，**一般清水冲洗就足够了**。

实在觉得桑葚里可能有脏东西，也可以选择一颗颗冲洗。


![图片](https://mmbiz.qpic.cn/mmbiz_gif/rrVVklPTzRAlRyj3ct9rCG7ojCM7M0DLQQI6qbTjA6IefHFTMPYmdibv5PfnCl3gjj4jIXwKYQkbCms5ice3c3ZA/640?wx_fmt=gif)


（如果用水也洗不干净，那用很贵的果蔬清洗剂，也不一定保证更干净。）

✨**最后，给大家推荐一个让桑葚变好吃、更营养的方法——****拌酸奶**。


![图片](https://mmbiz.qpic.cn/mmbiz_gif/rrVVklPTzRAlRyj3ct9rCG7ojCM7M0DLYdUyJDsepSe5GecgT1Kf84k6hQXDOro2ZIE1mp4RoknJu7E4PUnUnA/640?wx_fmt=gif)


![图片](https://mmbiz.qpic.cn/mmbiz_gif/rrVVklPTzRAlRyj3ct9rCG7ojCM7M0DLCicAIr6YvOXpftCfIrNKLyzD3DpfPM7F7Mj51wR4G8ichU0x8YgftANw/640?wx_fmt=gif)


其实，不光是桑葚，香蕉、草莓、橘子、葡萄等等水果，也适合用来拌酸奶。

不仅可以让酸奶口感变好、娃喜欢吃，而且水果中的维生素、膳食纤维，酸奶里的钙、蛋白质，也统统被宝宝吃进了肚子。


![图片](https://mmbiz.qpic.cn/mmbiz_png/rrVVklPTzRAlRyj3ct9rCG7ojCM7M0DLxmmJrcKJKvEOfTY7XPcAesSZskdHpqbYVS70zPUK1pzdwbiafAic8hnw/640?wx_fmt=png)
