# 儿童玩具黑名单来了！看完一身冷汗，家里有的赶紧扔

![封面图](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN3oViagtcp3wdTYPicNiaBqIILWas7H6101IdRZgRyEgQ5fNpeq9XqicK1GLdVsIScdeuO1ZpZojUG60A/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/ISmMzjTxLlupYaAEyqK5YQ

玩具，不管多大的孩子都需要。好的玩具既能让孩子快乐，也能释放天性，培养创造力、专注力。不过呢，这些东西孩子天天都要接触，有没有什么安全隐患？

确实，儿童玩具里**特别受孩子欢迎、但是存在风险**的还真不少。

今天咱们就给大家盘一盘，顺便科普下买玩具时的**“四要三不要”选择标准**，大家一定要做好笔记哦！


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/z7kZjMoQ3yE6iaPv0tkRpPqOOsBQj1bbjYeHbZrCXGFxMtPnOvM4jv4EXA2KSrE3AQSbP7libRGsg2p1z6UjdJXw/640?wx_fmt=jpeg)


（*这里的平衡车指的是电动平衡车）

电动平衡车现在越来越普遍了，因为拉风又有趣很受孩子们的青睐。

这不，小区楼下随手一拍，就拍到了两个踩着电动平衡车的孩子。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/z7kZjMoQ3yE6iaPv0tkRpPqOOsBQj1bbjkCzibRBR9ZxGia0aruddXMd0GEic94heVwaAIeceIafSicwTl7YGnowchw/640?wx_fmt=jpeg)


但是，对于平衡能力和应急处理能力还不太好的孩子来说，电动平衡车存在的隐患实在太大了。

之前就有新闻报道过，有孩子因为骑电动平衡车掌控不好速度摔伤了——


![图片](https://mmbiz.qpic.cn/mmbiz_png/z7kZjMoQ3yH9eBA95YBsD0DhW4j84Af2YHbz0TvQ6LOswnf350M3kldMgm9tSZqlPATia7bbic7ibaHWDvRiblDwfQ/640?wx_fmt=jpeg)


所幸伤得不深。及时送医就诊后，医生为她清洗了伤口，涂抹了药膏，相信很快会痊愈。

但即便如此，家长还是很自责，觉得没有督促孩子戴好头盔等安全护具，低估了骑电动平衡车的危险性，让娃受了伤，想想就后怕。

其实搜搜某宝，很多电动平衡车都标注了最低使用年龄——8 岁。这样不适龄的玩具给小朋友玩，安全风险还真蛮高的。 


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/rrVVklPTzRDwjhKJiblgtgKhJEJqj3kGbxfBDVBibtrL6cbwiaCibpEn9GKI7K0I1PeqSAwgzqWewPjQF5EVA2TW6Q/640?wx_fmt=jpeg)

**家族主要成员：****橡胶气球、塑料气球、氢气球等**

摩擦、硬物触碰、遇到酒精类液体都会让气球爆炸，很多宝宝们也因此会被吓得不轻。

会飞的氢气球更是可怕，氢气遇到火会剧烈燃烧爆炸；如果孩子不小心误吸了气球碎片，还可能会堵住气管，引起窒息。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/z7kZjMoQ3yFdvSJ4dbRcPEzPiah2zK7hFZwVbiaALlrDGbbjlKsic06muVapqzwNGK5sLcIxjuviafxYnhTZC8boKw/640?wx_fmt=jpeg)


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/rrVVklPTzRDwjhKJiblgtgKhJEJqj3kGbPny6Gk3yx1iaLrFaKzKrwfvtgqpEPCprl8rkZtsOEJTtPbicgxQpkdQQ/640?wx_fmt=jpeg)


**家族主要成员：****溜溜球、带牵引绳玩具、玩具戒指**

带绳子的玩具、尺寸不合适的儿童首饰，很容易勒住、割伤孩子的手指、手腕，影响血液循环导致坏死；万一缠绕在脖子上，后果不堪设想。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/z7kZjMoQ3yFdvSJ4dbRcPEzPiah2zK7hFXB2R8OYavWgA9K67iafz6oqBNiaGu6qyiaxqyVAvKkULj4WOXjvTYBgFA/640?wx_fmt=jpeg)


除了这些玩具会伤人之外，小体积玩具、膨胀玩具很容易被幼儿误吞，发生危险。

劣质毛绒玩具可能会导致孩子对填充物过敏，劣质塑料玩具散发的有毒化学物质，还会影响孩子身体健康。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/rrVVklPTzRDwjhKJiblgtgKhJEJqj3kGbGicYGmHCRoGe5glvYKq08qFUloOSeFG9vG8gD5jQztn4RI5zQS4lucg/640?wx_fmt=jpeg)


这款磁力珠玩具是玩具里很受欢迎的“网红”，可对孩子来说真不算是一款安全的玩具。


![图片](https://mmbiz.qpic.cn/mmbiz_png/nuqSmia8OqobSrnG6xcL3BOSP8pgLgUOBrcibia3noXKQkQmJrvAqu9sTISqh9P8P1F45reM7PPZzWHFjlMckPIrQ/640?wx_fmt=jpeg)


**这种磁铁玩具被誉为“磁王”，****它还有很多名字，巴克珠、巴克球、磁力球。**很多颗巴克球能依靠自身强大的吸力，凹出各种想要的 3D 造型。

加上“开发智力、刺激左右脑、提升动手能力”的一大堆噱头，还真挺让人动心的。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/nuqSmia8OqoaCUXmmru5wrFeWthfR0bpZ5QPZuY6URQ9kS9GvX3Ij4XTO3b7G7R3AlfRWAjA6R1asribPtriah11w/640?wx_fmt=jpeg)


因为小颗粒的外形酷似巧克力，加上夺目的颜色，不少孩子会把它当成糖果，隐患也就这样埋下了。

如果孩子吞下一个以上的小型高功率磁铁，粘在肠道或其他消化组织上的磁铁就可能会导致内伤，甚至死亡。还可能对幼儿造成**窒息危险**。

之前有一个读者妈妈家的娃就误吞了一颗，吓得孩子大哭，一家人也急得连夜带娃去拍了个 X 光。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/nuqSmia8OqoaCUXmmru5wrFeWthfR0bpZu2D7m6MzCIjonXIHPMvKlNuxRGUqTxW60sHoibEYR5qXiblibkhJHcf6g/640?wx_fmt=jpeg)


其实很多磁铁类玩具都存在被孩子误吞或吸入的安全隐患。所以如果玩具**含有细小的磁性零件，家长一定要经常检查、及时更换。**


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/rrVVklPTzRDwjhKJiblgtgKhJEJqj3kGbnXC178jicoyHaTzKicvLfnjxtXgDdUKI9ZZtnkL1zibLQ4ibJiclnSjIPPw/640?wx_fmt=jpeg)

还有之前非常火的一款水弹枪，也非常危险。
2018 年 3 月，河南一男孩趴在窗户上玩水弹枪，打中了邻居的脸。导致邻居左脸红肿。

为什么这么危险的水弹枪会成为孩子们喜欢的“网红”？ 

卖水弹枪的老板是这么说的：


![图片](https://mmbiz.qpic.cn/mmbiz_png/z7kZjMoQ3yFdvSJ4dbRcPEzPiah2zK7hFLtBLx2QYfyxZnskp0zVoDI7hx4SqPxqZkhoxr6jfibrSzSXnnQ6ibzDw/640?wx_fmt=png)


这种水弹枪使用的子弹是小颗粒状的，在水中浸泡两、三小时后，小颗粒会膨胀变大。然后就可以当做子弹。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/z7kZjMoQ3yFdvSJ4dbRcPEzPiah2zK7hF9hhwIYpXY65O8aF9e7a9pE7mFUUHqFVebayRPO5CfvqTfxAjJJxfAA/640?wx_fmt=jpeg)


因为是用水泡大的，所以捏起来软软的，而且遇到物体就会破裂，所以压根没有杀伤力。 


![图片](https://mmbiz.qpic.cn/mmbiz_png/z7kZjMoQ3yFdvSJ4dbRcPEzPiah2zK7hFzc9JeUB6lYFKgiaSkGiaibE4HB86HZdo1JiaMGBdJto7luic5uDUdp4jq8Q/640?wx_fmt=png)


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/z7kZjMoQ3yFO45iaYNhk8TibvFra3BDtvqtfAYAWrh9rngicqbCAaYwpIOicMBy5aWia7fTWUzcIsqzLJgAMCXgEgkA/640?wx_fmt=jpeg)


听起来似乎很有道理啊，而且男孩子玩个枪也挺正常不是？反正子弹很安全，让孩子玩玩也没啥关系。

然而这种碰到物体就会破裂的水弹真的很安全吗？专业人员的测试结果让很多人都大吃一惊。

在距离一米处击打鸡蛋，第一弹就已经轻而易举将鸡蛋击碎。


![图片](https://mmbiz.qpic.cn/mmbiz_gif/z7kZjMoQ3yFO45iaYNhk8TibvFra3BDtvqJiaHBTmpAApq7IeIb4XG2JmcEcLawSc7uEqAe2ydFk5vz0zrjxsukFQ/640?wx_fmt=gif)


接着，专业人员用水弹枪射击苹果。结果苹果几乎快被打烂了。


![图片](https://mmbiz.qpic.cn/mmbiz_gif/z7kZjMoQ3yFO45iaYNhk8TibvFra3BDtvqLGRibX17gXLxd6QrcBGH6A4XMSicZIgXic7dEgcBTuLlI2TibEE2vcse7w/640?wx_fmt=gif)


最后，专业人员测试了纸箱，被击穿简直是分分钟的事儿。


![图片](https://mmbiz.qpic.cn/mmbiz_gif/z7kZjMoQ3yFO45iaYNhk8TibvFra3BDtvqZ10m7az22NWzWxUI0YLRp1P0BOX0zIdxssaXDRicam4CRfcCOZ6AEDA/640?wx_fmt=gif)


原来这看似软软糯糯的小玩意儿威力却大得惊人。

而且水弹枪一秒钟能射出十发子弹！看到这儿，妈妈们还会觉得这仅仅只是一件普通的儿童玩具吗？ 

其实 2015 年，国家质检总局缺陷产品管理中心就提醒过，大家要注意水弹枪的“四宗罪”——

- 弹射的力量过大，会误伤他人；


- 误吞水弹可能会引起身体器官感染，甚至因为膨胀而引发窒息；


- 子弹仓和枪体的连接部分缝隙过大，可能会夹伤孩子手指；


- 部分厂家都没标明水弹枪的使用年龄下限。 


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/rrVVklPTzRDwjhKJiblgtgKhJEJqj3kGb3hXu4ia6FicM76meHIicVuNibdniby47aIrtJ4Kiczia0cLHbQMRttIL3yQKQ/640?wx_fmt=jpeg)


除了水弹枪这种有直接杀伤力的玩具，**“水晶泥”**也是种会引起不适、中毒的“毒玩具”：手感冰凉柔软，像果冻一样鲜艳晶莹，又好看又好玩，孩子们都特别喜欢。 


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/z7kZjMoQ3yHiaumeWldTficxK0VzJaelL99KNchibN0IZ6vJ7Vyg1egZDibeNytWl7rsA88Oame9jNB0AThRh2zBnQ/640?wx_fmt=jpeg)


但这样的高颜值里面，含有毒性很强的硼砂。

皮肤接触、吸入它的挥发物都会对人体有害；要是不小心接触伤口或被孩子意外误食，就可能引起中毒，对消化系统、神经系统和生殖系统都会有影响。 


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/rrVVklPTzRDwjhKJiblgtgKhJEJqj3kGbDlN979GWLmNdh7GicYqcfNZgdCdqdiau4GvImXTH2KTPGoRP6vcVoNqQ/640?wx_fmt=jpeg)

**家族主要成员：****摇摇车等带电玩具器械、劣质电池玩具、电人玩具等**

这些玩具一旦漏电，可能会烫伤孩子，甚至危及生命。劣质电池类玩具可能会引发电池爆炸，纽扣电池还可能被误吞。

而电人玩具基本上都是三无产品，瞬间电量释放巨大，让人有触电感觉。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/z7kZjMoQ3yFdvSJ4dbRcPEzPiah2zK7hFtpsf17pUnnKzlrcnEKeepxib1iaPWu5ZTtZgN6Jjmj6PFKNTYLj1hT8g/640?wx_fmt=jpeg)


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/rrVVklPTzRDwjhKJiblgtgKhJEJqj3kGbFwCtz8NyqOZNQIPoOA3SQP8bgtUPMzeQSDQtuTSj1aU0qEoCNokdXA/640?wx_fmt=jpeg)


原来玩具挑不对，能有这么多闹心事儿。给孩子挑选一款既安全又好玩的玩具，还真得费点心：


**注意**● 阅读玩具标签，根据年龄选择合适的玩具。

● 购买时认准有质量认证的大品牌。

● 孩子能明白如何驾驭玩具。

● 购买无毒玩具，请注意玩具中是否含有镉、铅、汞、砷等有毒化学物质。

**✘** 不给孩子玩带有小零件、尖锐边角的、发射性（例如飞镖、弹弓等）、含有玻璃或者刚性塑料部分的玩具。

**✘ **二手玩具慎重玩，材料可能会过于老旧，不安全也不健康。

**✘ **街边小摊的“三无”玩具不考虑。

除了选对玩具，日常对玩具的检查养护和定期清洁消毒也尤为重要。妈妈们应该及时修理或者扔掉家中破损的玩具。

**比如木制玩具不应该出现木刺、裂缝，颜色鲜艳的油漆类玩具磨损要扔掉，防止暴露的铅或木屑伤害孩子，钢铁类玩具请确保没有生锈。**


![图片](https://mmbiz.qpic.cn/mmbiz_gif/z7kZjMoQ3yFO45iaYNhk8TibvFra3BDtvqQtiavfA1HySdSQQAKa39SskQD0LzKFg8pzLx6a8IzRnsfaPMXNevU6A/640?wx_fmt=gif)

爱玩是孩子们的天性，家长们千万别因为劣质的玩具就索性啥都不给孩子玩了。

同时，妈妈们也可以找找家里的那些“开放式玩具”，比如锅碗瓢盆、塑料容器、纸箱、 肥皂盒都可以作为宝宝很好的玩具。
