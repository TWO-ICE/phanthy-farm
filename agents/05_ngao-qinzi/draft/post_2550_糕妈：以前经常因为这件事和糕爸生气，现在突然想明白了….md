# 糕妈：以前经常因为这件事和糕爸生气，现在突然想明白了…

![封面图](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN1cWYWFLwz6jgdDUVzArWTF50ibm3hic6E9Yh6pd3icTlayicLTZVeicEjbdWXyGOByxAwq4icib2kg8sxkw/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/tZkdgMofXDNIOoh18yeTag

大家好，我是糕妈，今天又是姐妹聊天局！

我们家现在基本分成两派：

我和发糕是“文科生”，感性、热烈，内心戏很多，情绪像坐过山车；

糕爸和年糕是“理科生”，平和、内敛，什么都......“还可以”、“一般”、“听你的”。

你们大概能想象，这两种性格撞在一起是什么画面。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN1cWYWFLwz6jgdDUVzArWTFNOBiaS6jEQtjxXTkqlwP1oa4wHaaHqaMq8AP4R0v45Qc9bhKFn178RQ/640?wx_fmt=jpeg&from=appmsg)

年轻的时候，我总觉得糕爸不解风情，我一腔热情给出去，他像团棉花，让我有种一拳落空的无力感。

后来又生了个“小威廉”年糕。随着他逐步迈入青春期，经常一脸平静地反问我：“妈妈，可是这有什么用呢？” 

我：

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN1cWYWFLwz6jgdDUVzArWTFBM0eejVIsBpiaicdiaBF7RSibdTZHuP0KZWQxcDxZiaCQfNcDvayJ8sAzxg/640?wx_fmt=png&from=appmsg)


我自小就情绪张力比较大，大喜大悲起起落落。

以前经常陷在负面情绪里出不来，悲伤的、自责的、羞愧的......我很难自己踩下刹车，要等到被别的事打断，或是惹我生气的人（通常是糕爸）“跪”得彻底，才能结束这场悲伤。

否则就觉得“我还没有气好，还没有完成我的悲伤”。

**四十不惑，我慢慢意识到，负面情绪本身并不吓人，像感冒，常常会来，来了会走。**

重要的是别陷进“负面思维”的雪球里，越滚越重。悲伤会汇成一条小河，把人拖得喘不过气。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN1cWYWFLwz6jgdDUVzArWTFR1KhYA7DiajVSSG6ic7nHMHJS9m6eIImlh5vYeTxx2KqJIIKm0icvsnlA/640?wx_fmt=jpeg&from=appmsg)

**说来也奇妙，这个道理，是家里的“理科生”点醒我的。**

之前和大家分享过的，糕爸非常轻巧地收拾了我一直没有勇气开始的、已经堆在角落里两个星期的杂物。

那一瞬间他真的有在发光！

同时我也在想，为什么我不能那么轻易地做到？可能就是脑袋里绕的路太多了，脚就迈不开了。

**面对这堆东西，我的脑回路是这样的⬇️**

“这堆东西好烦→收拾完得两小时→两小时后太晚了，不能陪孩子/看书/运动了→不想收拾→不收拾也得收拾→我好累→算了明天再说吧→可是明天还有明天的事啊→这日子什么时候是个头...”

**糕爸的脑回路是这样的⬇️**

“这东西要不要收拾——>要——>那动手吧”

没有多余的纠结，就是那么的简单。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN1cWYWFLwz6jgdDUVzArWTFYMeQNu1sd2J4uERI9f6QHH3HVnlN1A6EoYYyQmxibGiaQ41uQ8krVFTw/640?wx_fmt=jpeg&from=appmsg)

类似的事情也发生在我和年糕的对话里。有天晚上，我杵在动感单车边，年糕路过问：“妈妈，你鞋都换好了，怎么还不上去？”

我说：“有点犹豫，好累，觉得有点骑不动。”

他接了一句：“那你就少骑一会儿嘛。”

我：💡！

那一刻我懂了，文科生做的是主观题，情绪铺陈、内心戏全都要写满；

理科生做的是应用题，逻辑清晰、步骤分明，答不出也先写个“解”，总能拿到一分。

**而理科生们教会我的是：事情可以一步一步做，路可以一步一步走。**

动起来，比想完美更重要。
