# “儿大避母”几岁开始？多大不能亲亲抱抱？很多家长还是错的

**男孩子的性教育问题**让不少姐妹头大，经常有人问我们：

“妈妈要不要跟儿子保持一些”界限，几岁开始不能给儿子洗澡了？

到了青春期，还能和儿子拥抱吗？

男孩子的性教育要如何开始？和女孩子有什么不一样吗？”

我们请到了青少年教育专家——出了好几本书的方刚老师，他不仅有很多干货，多年的工作经验也使他更懂儿童心理。

有困惑的妈妈，不妨来听听方刚老师的科普。

很多姐妹都关心的「儿大避母」，方刚老师告诉我们，性教育并没有男女之分，没必要“男孩要爸爸来，女孩要妈妈来”。

拿给男孩洗澡这个问题举例，什么时候该停止呢？**每个孩子都有自己独特的发展规律，没有标准答案。**

关键也**不是看年龄，而是看感受**，父母、孩子有任何一方觉得不舒服了，就要停止了。

孩子小的时候，亲子共浴其实比较有利于性教育，这个场景很自然。

但孩子大了，**就会不好意思和妈妈一起洗澡，这就是停止亲子共浴的时机。如果妈妈觉得会尴尬了，也可以停止。**

还有一些传统观念，比如**「男孩不吃亏」不教育也行，这也是非常错误的价值观，男性同样可能会成为性侵害的受害者**，而且这种观点会培养非常错误的性别观念，影响到孩子一生对女性的态度，甚至亲密关系。

**性教育不分性别**，不论男孩、女孩，都应该了解自己和异性的身体，学会保护自己，为自己的行为负责。


方刚老师提倡的**不要把性教育特殊化、神秘化**，和教语言、算术、科学知识那样自然对待，相信他的观点，能给我们很大的启发。

男孩子青春期来的比女孩子更加隐蔽，很多家长往往是孩子变声了，才意识到「哦，青春期了」，其实男孩子青春期启动的标志是「睾丸增大」。


![图片](https://mmbiz.qpic.cn/mmbiz_png/eNysDu3qI3dCqWlGjdsic0icQOD6fvGGPL7OlmFJyfZPZemGXCxAtq2Pj4RtvsSReW6ibsuuoP00aXAR9GrxldXRg/640?wx_fmt=png&from=appmsg)


**对孩子的教育，不能等到发育了才开始，应该是提前的。**

通常 9 岁、10 岁的时候，就应该让他知道，到了五、六年级，身体可能会出现什么变化，让孩子接受这些变化，不要为一些正常的生理现象感到羞耻。


说起来简单，很多家长在操作上就遇到了问题，比如就有妈妈问我，男孩子的睾丸增大，我怎么看出来啊？要不要他爸爸洗澡的时候，帮忙看下？


我想说，**性教育一定要自然，不刻意**。

如果爸爸跟儿子有一起洗澡的习惯，愿意沟通这些事情，那可以。要是没有这些前提，爸爸突然要求跟儿子一起洗澡，是不是也太奇怪了？


大部分时候，和孩子就事论事讨论问题，是比较好的教育时机，就拿我们家的事来举例好了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/7QRTvkK2qC63c02mKcsfAaJ8sNcicTvg22UkHHibvKiasFS9FS6E4FeV0Dibe7as7h4tm8p7EfNfI06adlGbL2icYjw/640?wx_fmt=png)

幼儿园大班的时候，我们发现孩子有自慰的行为，老师也发现了。

我就跟他聊了一下，主要提醒他这件事的**「私密性」**，要自己关起门来做。聊过之后，在我们面前，没有再发生过这样的行为。

到了小学高年级的时候，无意间看到他在沙发上蹭，其实这也是一种自慰的行为。就在散步的时候告诉他说自慰要注意安全，不要伤害自己的身体。

在我们家，这种话题从来都不是禁忌话题，聊起来是很自然的。

如果没有这种基础，我建议家长先看书，了解一下相关的知识，再跟孩子沟通。（推荐书目放在文末）

**我们跟孩子沟通时，心态要平和、语气要正常**，家长做不到的话，也不需要强行沟通，**让孩子看相关的书，自己学习，效果也不会差。**

在实际工作当中，有家长会困惑：三、四年级的男孩子，还「傻乎乎」的啥都不懂，有必要教吗？看起来孩子很单纯，讲这些会不会把孩子「带坏」了？

我想说，这样的家长，太不了解自己的孩子，也太不了解性教育了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/eNysDu3qI3dCqWlGjdsic0icQOD6fvGGPLnRHf8Nm88TeGsgibDb7hD7As5V7lfiaessPiak6bxfKIsJUYp6kEE5GoQ/640?wx_fmt=png&from=appmsg)


完整的性教育，**生理知识、性行为仅占很小的比重**，更重要的是**情感、责任、价值观**的教育，**学会保护自己，掌握自己身体的主导权，为自己的行为负责。**

我们每年都会举办猫头鹰教育营，**生理知识的讲解只是其中一部分。**

我们还会花很多时间，用情景剧的形式，让孩子学会掌握身体的自主权，比如“被人（特别是熟人）骚扰了如何应对，如何求助？恋爱中，对方想要亲密行为，你不想要，怎么拒绝？”

通过这些练习，给孩子赋能，让他们有做决定、且为行动负责的能力。


![图片](https://mmbiz.qpic.cn/mmbiz_png/eNysDu3qI3dCqWlGjdsic0icQOD6fvGGPLJrrNPpTY8jlPrhazialmFDxYiaicvbH9YhVD4tTTU5KP7NdmSfmEBGBOQ/640?wx_fmt=png&from=appmsg)


心智发育过程中，孩子天然地会对身体和性产生好奇。

他们两、三岁的时候，可能会问**“我从哪里来呀？”**这时候“从妈妈肚子里生出来的”也许就够了。

但更大一些，他们就会琢磨**“我是怎么进去的？”**，那就要讲一下精子、卵子、受精卵、性交过程这些知识了。

**你不说，他们也会从其他地方知道。**

在我们的性教育营中，小学员跟我们说，几乎班里所有的男生五年级就看过 se qing 片了，只是不告诉家长而已。

**未成年禁止看 se qing 制品**，但互联网的存在使得 se qing 制品的传播防不胜防。

**简单的「禁止看」已经没有用了**，我们能做的是价值观上进行引导，告诉孩子可能给他们带来的伤害，不要把se qing 制品当成教科书。

有一次，我们全家一起看《让子弹飞》，里面有女性被性侵的镜头，当时我就跟儿子说「真是土匪行为」，这就是价值观的教育。

有些家长会把性教育当做「守贞教育」，让孩子学会防范性侵害，杜绝性行为就可以了，但这种教育，往往会适得其反。

早些年，美国有些流派就是以这种「守贞教育」为主，结果发现，越禁止、青少年越好奇，未成年怀孕、性传播疾病变多了。

反观开放的教育模式，以荷兰为例。

我去过那边的一个性教育展览，展厅内大大方方摆着各种性交姿势的小玩偶，关键是还有小学生和我一起参观，当时我都震惊了。

但荷兰的**初次性行为发生年龄，是全世界范围内最晚的**。

为什么？因为他们不仅仅教授知识，还有情感、责任、价值观的教育。

荷兰的青少年，从确定恋爱关系，到发生纳入式性行为，平均的时间是 3 年。（大家可以诚实地回想一下自己的经历，判断这个时间是长还是短。）

再说，我们性教育，是为了推迟孩子发生性行为的时间吗？当然不是，而是教会他/她判断风险、有勇气做决定、负责任的能力。

这种能力，也会帮助他/她长大后更好地处理两性关系。
