# 直男老公送的情人节礼物，竟让我成了全公司的笑话

![封面图](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN1b8WW5zFnPUmMnuEPiblsecIG6X42TTZBx5Xr1gAaHgU2sCialI4QAj0tTuoRax9icHL8biaUCK0oiamg/0?wx_fmt=jpeg)

今天情人节，姐妹们过得还好吗？

朋友圈里可以说是“热闹非凡”，有疯狂撒糖秀恩爱的、有吐槽老公太直男的、还有单身狗看热闹吃狗粮的……看着那些如胶似漆的小夫妻，已经见惯各种大场面的编辑部姐妹们纷纷表示：根本不羡慕甚至还有点想笑。

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/nuqSmia8OqoYgicoyNmlvXdcO2fpZCfr8Gs1VCZPWXbDNsu8cibGTiaH63WHUsBDoHIjjIJ4cS5ARux5VR2F24JlKg/640?wx_fmt=jpeg)


因为我们早已看透朋友圈营造的各种“恩爱假象”。要知道，想要一个直男送的礼物合心意，比冬奥会上拿奖还要难。就连糕妈也没能幸免，早年间收到过糕爸送的淘宝爆款永生花、夜光瓶、以及各种杯子……（每年送完就失忆？）


![图片](https://mmbiz.qpic.cn/mmbiz_png/nuqSmia8OqoYgicoyNmlvXdcO2fpZCfr8GqT472BWOd5XMsx1faQvXtIdfsFLFUug65SXxnfm0gGN5A8Rfqag3icA/640?wx_fmt=png)


编辑部来来老公更绝，给她准备了一个大惊喜——**价值 318 元吐着舌头的菜狗**。

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/nuqSmia8OqoZP92rDvIWvibuf7QjPic1A1DCKPIqakToZscEBblya4HicKGHYucwGXHXokUfao7HLRYibh5ODNiamPiag/640?wx_fmt=jpeg)


而且老公非常骄傲地告诉来来：**这只菜狗是要排队预约才能买到的限定版，**一般人根本买不到~

甚至还买了菜狗的衍生周边“可以吃的菜狗”……合理怀疑他在暗示些什么。

![图片](https://mmbiz.qpic.cn/mmbiz_png/nuqSmia8OqoYeK2Prq7JCTebibvyo5lDu9uzibYlVUXsdjbYkODduyQm6mibTo5AoECFnUnDa9aofLB6uaYKmw7D0g/640?wx_fmt=png)


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/nuqSmia8OqoYeK2Prq7JCTebibvyo5lDu9Ykp5zArwVIosYe5N9DQPaicfDUSK44v4icgrNmD81zrnkfDlMc36icfMw/640?wx_fmt=jpeg)


没想到丹丹竟然还表示羡慕：“我老公送了我一把很丑的淘宝定制木梳，上面刻着：**不忘初心**。不知道的还以为是公司刚发的企业文化宣传品…”

编辑部菁媛的老公听说某大牌口红很流行，兴高采烈带回来一支。谁知道一打开是金光闪闪的死亡芭比粉，差点气晕过去

**@猪猪妈：**

我和老公**约定每年纪念日送玫瑰**，按照在一起的年份递增数量。

这本来是一件非常浪漫的事，谁曾想我老公迷上了养多肉……

有一年他为了给自己买多肉，居然以纪念日送我玫瑰的理由**给自己买了 50 株沙漠玫瑰苗**，**大晚上一个人蹶在地上给“花”换土**。

从那以后再没收到过玫瑰花，某人说因为家里有长盛不衰的沙漠玫瑰了。

我……我谢谢你嗷！


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/nuqSmia8OqobSDiaiaPx7ib8n6RvPOS7PJ4V1BrudRYicKicKV5NfmDQw9s2icocazgJMyHU8ORXaAqUWmxPVy3j10skw/640?wx_fmt=jpeg)


**@小小 zhao：**

我收到过来自老公的最“无奈”的礼物——**淘宝爆款肥皂花**。

拿到手的那一刻，我就想把它扔进垃圾桶，奈何当时刚刚确定关系，不好意思做得“太绝”……


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/nuqSmia8OqobSDiaiaPx7ib8n6RvPOS7PJ4V37FcbNQqrkuo5cnDwdibIF8sIdias4AehAxNUpzXE5v37n28PcBRtgHA/640?wx_fmt=jpeg)


这又让我联想起我家老房子里的塑料花，那是我爸妈那个年代结婚时的纪念品，**我觉得那些塑料花都比这个肥皂花高级得多**……

从此以后在情人节、妇女节、520、生日等多个可以收礼物的日子里，我都会想起这一大盒点缀着小熊的肥皂玫瑰花，并亲切地提醒某人：

**答应我，千万别再买“让女友感动到哭的礼物”了好吗？**

**@杨静：**

遥想当年青葱岁月，老公还是男朋友的时候，**我学化学，他学机械。**

我们恋爱没多久，在一个阳光明媚的午后，我正在宿舍睡觉，他打电话让我下楼，说是有惊喜给我。

我满怀憧憬的下楼，看着他神秘兮兮的从包里掏出来一把锤子……
