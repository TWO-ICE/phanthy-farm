# 买不到美林娃还发烧了？儿科医生教的这一招，关键时刻也有大作用

前两天，咱们发了一篇**【婴幼儿、孕哺期退热药用法大全】**，评论区好多妈妈说：跑了好些个药店，都买不到美林、泰诺林。

打开朋友圈，小某书，也有很多家长在求购娃的退热药。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN28x6XQPfvXK8oM84Dbf4G4LT4GhLXLn8R5zs266j3wIml9O2znrE3uPOxCTYG6ZqF3xuUuZVaPFQ/640?wx_fmt=jpeg)


的确啊，在当下这个特殊时期，有娃家庭药箱里没有一瓶美林/泰诺林，当家长的，实在是太难安心了！不过实在买不到的话，大家也先不要太焦虑。**并不是宝宝一发烧，就要立马吃退烧药的。**发烧是咱们身体里的免疫系统在跟病毒战斗，并不是什么坏事。咱们给娃吃退烧药的目的，也不是为了“治病”，而是为了让娃舒服一点。如果宝宝温度在 39℃ 以下，而且精神状态比较好，能吃能睡能玩，咱们也可以先通过一些**正确的护理方式**，让宝宝感觉更舒适。**0****1****体温上升期：要保暖**

大家应该大多都体会过，发烧有时会有这么一段时间，明明量出来体温比平时高，但自己却觉得很冷，甚至冷到有些打颤。这在医学上被称为**体温上升期**。在这个阶段宝宝可能**手脚冰冷，伴有畏寒、寒颤**等表现，这时候就不适合给孩子物理降温了。可以适当地给孩子**增加衣物**，**搓热**或用**温水浸泡手脚**。

**0****2****体温持续期：不能捂！******

体温持续期也叫**“高热期**”，宝宝**手脚暖和或发烫**，**浑身发热。**这个时候，咱们千万千万不能捂汗！杭州市儿童医院呼吸内科吴素玲主任也说：孩子发烧送到医院，门诊第一步就是**给孩子脱衣服**。因为孩子的中枢发育不完善，调节温度的能力很差，**脱衣服是最直接的物理降温方式。**等孩子体温降下来了，再一件件穿回去。如果是家里有暖气的家庭，宝宝高热期还需要适当地**调低室温**（温度24~26℃），不要过热。另外，宝宝发烧时，身体的新陈代谢加快，皮肤出汗增多，体内水分的消耗也会增加。咱们可以**少量多次**地给孩子补充一些液体，如母乳、温水、米汤等等，不仅有助于发汗降温，也能预防宝宝脱水。除了上面说的这些，吴主任还给出了一些特别实操的物理降温方法——**✓** **额头**敷凉毛巾，而且毛巾要经常翻面；

**✓** 用温水擦拭身上大血管经过的部位，也就是**脖子、腋窝、肘窝、大腿根**（腹股沟）等部位，帮助孩子散热。

当然啦，以上所说的物理退烧方式，都以**孩子的反应**为第一原则。


比如说，如果温水擦浴时孩子表现出哭闹、不适，那么咱们还是及时打住——以孩子的舒适为主。

最后还想提醒大家：

如果宝宝体温**超过了 39℃**，咱们通过物理降温的方法，依然没办法降低体温，宝宝状态也没有表现出好转，那么还是建议吃退烧药。家里没药的话，可以去医院开，医院还是有药的~

另外，如果孩子**持续发热超过 3 天**依然不见好转，**3 个月内小宝宝发热的，只要发烧就及时送医，**也建议及时就医，寻求医生的帮助。

祝大家遇事不慌、安稳度过这段时间！
