# 生了2个男孩，家里还能保持整洁？全靠糕爸这3个懒人收纳法

养娃之后，家里明显变得拥挤起来，东西多了不说，有时候想找个什么，也得翻箱倒柜找很久。

@菁菁家就是这样，家里人已经习惯了用纸巾擦这擦那，有时候随手拿过来一用，结果第二次找，就不知道丢哪里去了。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN2kLUQ07d28eiaKCfh1CaaNeUqlNXXIIXdcdLFKF2yv6ZMZeEn5Rcgtib6shPaxkURxtFdRpTFecspQ/640?wx_fmt=jpeg)

更别说娃随手塞的绘本、拼插的玩具，还有各种零零碎碎的东西。想用的时候找不到，不需要了又发现它冒出来了：

![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN2kLUQ07d28eiaKCfh1CaaNe3ZyKoKFCsngKWliaQ7kcqHCfHAIWpHFKwVKYoZiaWb8ibczA7pm5QqBJA/640?wx_fmt=jpeg)

买收纳神器吧，单个看着还挺便宜，可要是多买几个，就不见得划算了。而且考虑到家里的空间，各种收纳神器，可能也没有想象中的那么好用：要不停的打开、关上、再打开，一个动作得重复好几遍，反而更累了。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_gif/tGtmpweWiaN2kLUQ07d28eiaKCfh1CaaNeichKGZmOWhdw1MJFU5BhpOS5McLOJaw6FTLqQXXInQZ7QAoWZCNjtjg/640?wx_fmt=gif)

那有没有什么方便快捷、节省时间，还不会把家里整得乱七八糟的好方法？糕 • 空间管理师 • 爸，可是很有发言权：

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN2kLUQ07d28eiaKCfh1CaaNegl0BPraamibRsgepK5ibND3THn23rECzCxXd5fjV9EsR7KWYm9rkLVNw/640?wx_fmt=png)

上一次他跟大家分享了 5S 管理的第一个 S ：整理，获得了妈妈们的一致好评：

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN2kLUQ07d28eiaKCfh1CaaNeyiaibvlEbsPy9SmkIyhZBVJZMpbbGqEdJfQ4cXrgnFW8gLLSyiasvCOHA/640?wx_fmt=png)

所以我们趁热打铁，请糕爸继续讲讲第二个 S ：整顿。也就是**通过高效但轻松的方法，让家庭空间变得整洁有序。**至于到底怎么整？下面就交给糕爸吧！也可以拉到文末，直接看视频哦~

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN0vIWu4ncel7kiagkYXpneaZJY0sBkbKftUDnmpEpTdRnXYQ3MrqXHZhomnEia3NM1vds88YobKzL4g/640?wx_fmt=png)

哈喽大家好，我是糕爸。第一期的整理，是教大家“东西怎么扔”，那么今天的整顿，其实就是解决**“东西怎么放”**的问题，让家里**变得更好、更有序**。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN2kLUQ07d28eiaKCfh1CaaNeI2D1rldhHxwWytcY6eJnrNX0oHnaiaECJUvPBshibxHKKTEB3v2kc03g/640?wx_fmt=png)

家是做什么的？不就是放松嘛。所以说，做收纳的究极目标，就是实现不做收纳**让自己少干点儿，留下富余时间给自己**。我们家的经验呢，就是**把家里使用频率最高的东西，放在最黄金的位置**。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN2kLUQ07d28eiaKCfh1CaaNensrTiaRSXDd7iaia4Kj9mKicaMFsiadx5vwQYvtDibs8BkSPp3OeVXeJkQLg/640?wx_fmt=png)

家里最热闹、最常用的地方，一般就是**客厅或者餐厅**。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN2kLUQ07d28eiaKCfh1CaaNeP334Kn3S1pAmqOpIEEk3JQficsENQAnh8QlzR96udhV2XSEhXw923LQ/640?wx_fmt=png)

所以像是饮水机、纸巾、牛奶这些，**每个人都会经常用到的东西，放在餐厅或客厅，就能省下很多跑腿时间**。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN2kLUQ07d28eiaKCfh1CaaNeJuNoSqR7F66J3fNaATRkQd1FrolxdQuRPXNC2SEiaVxN8Tf045MmBicQ/640?wx_fmt=png)

除了水平的距离，垂直线上的也很关键。因为这关系着，我们是不是经常需要弯腰、垫脚拿东西。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_gif/tGtmpweWiaN2kLUQ07d28eiaKCfh1CaaNeRMon8evmYgRmoQqOgPqV5cYmMbAwhK4UXOjhxjaRicwHtYu0MIFXesw/640?wx_fmt=gif)

**站直了伸手能够直接拿的，就是最佳位置**。想想带娃就已经腰痛手酸了，其他时候，还是别折磨自己了。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN2kLUQ07d28eiaKCfh1CaaNemuWlsNeTAqcbWic0icYdPpDmprf3F75XyGWyaauKbScrObyVkDDIEibTw/640?wx_fmt=png)

东西多了，还有个麻烦事儿就是找东西。尤其是纸巾、水杯这些，经常是跟着人走，然后就不知道落在那个房间了。我们家的经验是，把这个东西固定下来。比如说纸巾，我家是每个房间都固定在墙上或者柜子下：


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN2kLUQ07d28eiaKCfh1CaaNebrGtibSIEVCI1X0Pcic5MDm5Eib2uxe6UbBFiblK3VdtU3EEyOmGJYlUdw/640?wx_fmt=jpeg)


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN2kLUQ07d28eiaKCfh1CaaNedNhevALPoK7wYFc9N56J6sXxu4ic7EYibUvFW3LsJYbeUO0f6E9ZatWw/640?wx_fmt=jpeg)

不用到处找纸巾，也不占据桌面空间，像发糕现在都会自己直接拿了。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN2kLUQ07d28eiaKCfh1CaaNexaT34gTCc0arqz3FK2aPILrOes5w1S3LCahDZd3doBYeZ2FhOYbnUw/640?wx_fmt=png)


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN2kLUQ07d28eiaKCfh1CaaNeMtTXwYu1iauYrJYslS0z0ibSibxpS3RyLiaiaM3OcvuV6eYfLkYuE3wx2HQ/640?wx_fmt=png)

收纳，其实我家也用得很多，**但为了收纳而收纳，那是真的没必要**。你看，过度收纳的话，光拿个玩具就要走 8 步：

![图片](https://mmbiz.qpic.cn/sz_mmbiz_gif/tGtmpweWiaN2kLUQ07d28eiaKCfh1CaaNeBibkEBicDCF3D2fLIu4licaLypekjrKo9sdq0njw9dxmiaUDSvJJNDyynQ/640?wx_fmt=gif)

要是摊上个不爱收拾玩具的娃，咱们自己还得重复一遍，相当于走了 16 步，想想都觉得累。但如果换个方式，直接把玩具放在透明盒子里、或者是柜子底部，直接就简化成了 3 步：

![图片](https://mmbiz.qpic.cn/sz_mmbiz_gif/tGtmpweWiaN2kLUQ07d28eiaKCfh1CaaNe6yic9hN4qvMSShqu9b2K0BBFxs5VSdwibia4K2peTwgj4v7dicWWL0KKOA/640?wx_fmt=gif)

是不是就省事儿多了？**好的小工具，确实是能够让我们省心**。除了上面说的纸巾收纳盒，最近为了吃鸡蛋买的小酱油瓶，用起来就很爽。平时我喜欢吃鸡蛋沾酱油，还得去厨房倒。现在直接买了个能控制量的小酱油瓶摆在餐桌上，用不了多少钱还能一步到位。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN2kLUQ07d28eiaKCfh1CaaNeeRw8wQZ3KNDcUFZ58d59GS71AMBNicNREKBUtnq9HTM3Mxb7SkcbCJw/640?wx_fmt=png)


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN2kLUQ07d28eiaKCfh1CaaNexweqmh7WmK5xk0Heh8kIo7Yjia3nKNoxSkerFot07IJibKM6bb9Zc0Qg/640?wx_fmt=png)
