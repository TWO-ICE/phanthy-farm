# 糕妈：刺激长高还对眼睛好，4岁后多带孩子做这项运动！我整整坚持5年了，有点累但很值得

如果问哪项运动能让糕家全体嗨起来？那骑行必须当选！


老粉都知道，发发小时候，就经常坐在爸妈自行车的后座。转眼间， 米米也加入了糕家骑行队。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_gif/icCA4cZUvDztQ6eXhybwbjszlrLl9ceXFBuItpGrC9nuibsN91ShibfibxDXOCWy9QxqlL8UJuwO5kYwdceZKKibnJPa7yKHhc3iblucugfNaYsbU/640?wx_fmt=gif&from=appmsg&tp=webp)


不得不说，骑行这项运动，真的很香，尤其是在杭州这座骑行友好城市！


骑行所需要的平衡、判断、手脚配合， 其实 锻炼的是大脑感统。 带娃骑一圈，比外面几百块一节的课程来得实在。


而且 骑行能充分拉伸骨骼、刺激骨骼生长，助力孩子长高 。


其次，骑车等于给眼睛做保养。 因为自然光下，娃的视线远近切换，刺激多巴胺，抑制眼轴增长。


最关键的是， 骑车还能锻炼抗挫力和专注力。 亲子骑行的过程中，你会发现，娃可能没你想的那么脆弱。


![图片](https://mmbiz.qpic.cn/mmbiz_png/icCA4cZUvDztQc6ulBSUwX6ibyXoVNNFPSYJp49MiaNLGfH84vL6ATplM6CcJvk9IGK90OrKfoXnxD57NeH9Ziac1mMf7w8ia1lSh6uicSA4PAjGs/640?wx_fmt=png&from=appmsg&tp=webp)


所以， 娃骑的是车，养的是脑、眼、胆。


骑行对咱老母亲也友好，几公里下来，等于有氧＋力量，既练了心肺，还塑造了腿部线条 （糕妈自己也是骑行爱好者） 。

骑行小贴士


✅ 整个绿道中间位置有 2 座爬坡桥，但是坡度不大。低龄可以骑行到中间折返，这样骑行全程就 5km 了～

推荐 2 条经典路线 ，可以根据体力而定，都能绕回起点。


🗺️小圈（3km）： 从花海出发→云杉映波→昙山访石→下穿过云泉桥→途径灵龙路→回到花海。全程平路，2 岁娃骑平衡车都毫无压力。


🗺️大圈（8km）： 强推！作为官方推荐的路线，依旧从花海出发→莼乡寻味→九曲梅韵→海棠荣春→昙山访石→云杉映波→铜鉴湖花海。

🚴交通方式&租车：


想租车的话，建议地铁出行。 16 号线 到 “八百里站”，B1 或 C 口出，步行可达租车点。


导航到“八百里饭店” ，饭店后侧有好几家租山地自行车的店。 价位比景区那边划算， 一般 40-60 元/天 （景区周边可能要 80 元） 。

🚴交通方式&租车：


起点秀水广场有大型地下停车场，车位充足， 停车费 2 元/小时，20 元封顶。或者导航定位到“秀水广场”，搜周边“停车场”也可以。


如果只想骑一小段或轻装出行，推荐小红车， 经济实惠，使用“叮嗒出行” App 或支付宝小程序即可扫码租车。


如果想骑得更顺畅省力，租一辆专业山地车会更舒服。同样可以定位“秀水广场”，搜周边租车。


骑行小贴士


✅ 来回 30km 对耐力有要求，建议出发前给娃打好“预防针”，把折返点当作目标。


✅带足水和能量零食。虽然三潭驿站有贩卖机，但前后间隔较远。建议还是自备。另外，防晒依旧不能忘！


✅建议早上 8-9 点从秀水广场出发，骑到上江埠大桥大概 1.5-2 小时 （边骑边玩） ，返程再花 1.5 小时左右，中午前后就能结束，避开正午暴晒。


✅如果娃体力有限，也可以骑到三潭驿站就折返，来回约 16-18 km，难度降到中级，风景一样很美。


✅下桥或过隧道时要减速，隧道里光线偏暗，开启车灯
（或带上小闪灯）
更安全。

亲子骑行的话，还是建议选山地车， 避震、舒适度都更好，也能适应各种路况。有的店也是可以租到带儿童座椅的车，但是没有那么普及，记得提前打个电话问一下。


如果 对车没有什么要求的话，租共享单车也可以。


但12周岁以下是不能自己骑的，这点要注意哦～现在也有一些专门的亲子车，不过需要碰运气。


杭州的共享小红车还不错， 打开小程序“叮嗒出行”，直接就可以看附近有没有亲子车，前 2 个小时还免费。
