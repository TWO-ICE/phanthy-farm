日子过得真快啊，今天已经是立秋啦~

夏天的暑气渐渐消散，水果摊的水果们也更丰富多样了。相信不少妈妈都有站在水果摊前发愁：**这么多水果，哪个营养最好？**这也想吃，那也想吃，孩子一天能吃多少呢？

糕妈研究了当下比较受欢迎，基本上各地都能买到的** 10 种水果**，从营养的角度来看，它们还真是各有千秋，我们一起来研究看看吧！


![图片](https://mmbiz.qpic.cn/mmbiz_png/FF2OYjRxqc3YzKRDjI5D3UERhib6O4SCEvIPNm1U1s7ichxe8bWF1dsEptrBjHdV9F3o7sunwNmQhicyicicoicwBbHw/640?wx_fmt=png)


**👑**** ****水果营养排行榜 ****👑 **

一般来说，大家看重水果的营养价值主要是**维生素 C、膳食纤维，还有钾、胡萝卜素等。**

在这些营养价值方面，每种水果的表现如何呢？我们以每 100g 为单位，来让它们 PK 一下。

**维生素C榜 **


维生素 C 大家都很熟悉了，它是一种非常重要的**抗氧化剂**，对维持我们的**免疫力**有非常关键的作用。

而且它很脆弱，加热容易破坏，相比蔬菜来说，不需要加热就可以**生吃**的水果，是维生素 C 非常重要的来源。


![图片](https://mmbiz.qpic.cn/mmbiz_png/FF2OYjRxqc3YzKRDjI5D3UERhib6O4SCEGibFoR7AgmA8CEarZ7wtCxE1azXz0uBiciaXw56Zk9Xm41Fu9sSDJKs3w/640?wx_fmt=png)


在印象中，大家会觉得酸酸的橘子一定是含维生素 C 最高的水果，是不是没想到其貌不扬的**冬枣**，居然是个维 C 小天才。

**胡萝卜素榜**

胡萝卜素可以在身体里转化成维生素 A，是**对眼睛健康有益处**的营养素。对儿童来说，除了胡萝卜、南瓜等蔬菜，部分水果也是胡萝卜素的来源。


![图片](https://mmbiz.qpic.cn/mmbiz_png/FF2OYjRxqc3YzKRDjI5D3UERhib6O4SCEIHm5vtbR4uhNZG2kk17C9uXCDYibUr2BS23gKkqJBicF5reJ68YU61nw/640?wx_fmt=png)


**膳食纤维榜**

膳食纤维大家都听过，它是一种不能被我们肠道吸收，但非常有用的东西。对儿童来说，**它的益处主要在于肠道健康**。


![图片](https://mmbiz.qpic.cn/mmbiz_png/FF2OYjRxqc3YzKRDjI5D3UERhib6O4SCEFDpDEic57LbYlwgf54ujVibsGtE3NpibpEAhRhrMRzsEsAo7dj9uhemRA/640?wx_fmt=png)


我们常说的膳食纤维能通便，主要是**不溶性膳食纤维**的功劳。这些不溶性膳食纤维，可以增加大便的体积，一路下来也能像网子一样，不断的网住肠道里面废物。

膳食纤维多了，大便就会变松、变软，变得好排泄，宝宝排便就不费劲了。 

**钾排行榜**** **

钾是我们人体所需的**重要矿物质**，我国居民的饮食中，钾元素是普遍不足的，这对血压控制非常不利。

如果从小就能注意保证饮食中的钾摄入，对成年后养成健康的饮食习惯，也非常有帮助。

**水果蔬菜是饮食中重要的钾来源。** 


![图片](https://mmbiz.qpic.cn/mmbiz_png/FF2OYjRxqc3YzKRDjI5D3UERhib6O4SCE0GYLDwMCibaRMMtqp5IMRvL2tIWFmiaTz73icUtiaaL6OYqQ0GwTGDznyw/640?wx_fmt=png)


**搭配吃营养更全面**每种水果都有自己擅长的特色，没有绝对的“多吃XX好”的说法，在给宝宝吃水果的时候，不必专注一种水果。

当然，我们也不用每天都强求吃好几种水果来保证营养全面，只要**一周**左右的时间里面，孩子的**水果多样、全面均衡**，就很好了。

我们可以根据水果的特点，每天以一种水果为主，来给宝宝来进行水果搭配。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/FF2OYjRxqc3YzKRDjI5D3UERhib6O4SCEtbTBEILibXfP81ia9kVgbQu9wFA3ddh2tOX5uicMZTP0EMN1F8mbtekmA/640?wx_fmt=jpeg)


其实宝宝每天需要的水果并不多，为了不浪费，我们也可以根据水果的个头、家里有几口人来进行选择：

- 个头比较大、一个人吃不完的柚子、甜瓜，可以趁家里人多的时候一起吃；


- 个头中等的香蕉、苹果、橘子、火龙果、猕猴桃这种，大点的宝宝每天吃一个，小宝宝根据情况和妈妈分享一个。


- 像冬枣这种个头小好携带的，可以出去玩的时候带着，当做随时随地的维 C 加油站。 


是不是感觉自己是水果营养专家了？赶紧去水果店，看看都有啥，给娃搭配一下这几天的水果菜单吧！
