# 男孩咳嗽老不好，罪魁祸首竟是它？！医生提醒：早期发现很关键，很多孩子都被耽误了！

妈妈们，你们是不是也纳闷：为什么孩子老是“感冒”，咳咳咳，几个礼拜都不见好？

要当心是不是“过敏性鼻炎”！之前就有娃反复咳嗽，一查竟是鼻子过敏引起的👇


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN1kxF7kZW1s6ufgwcickhvOAAVaE5P72Nd3SjnMrWSwKTG6dNjUp0Bzlj1TrKl7zDNYEicC8INbqibwg/640?wx_fmt=jpeg&from=appmsg)

过敏性鼻炎可不止鼻塞、流鼻涕这么简单，鼻涕倒流可能会引起咳嗽[1]，睡不好、注意力不集中，也可能是它的锅[1-2]。

****如有相关症状，请及时就医，切勿自行诊断。*

再次提醒大家，过敏性鼻炎近些年越来越普遍[5]，孩子出现鼻塞、鼻涕、打喷嚏的时候，不要理所当然地认为是感冒，还要警惕过敏性鼻炎的可能。

及时就医、确诊，在医生指导下规范治疗，科学用药，不随意停药，帮娃平稳度发作期，不让过敏性鼻炎影响到孩子的生长发育和长期健康💗。

****本内容仅用于健康科普，不能替代专业医疗建议。个体情况存在差异，请务必在医生指导下规范用药。如出现相关症状，请及时就医并遵循医生指导，规范治疗。*
