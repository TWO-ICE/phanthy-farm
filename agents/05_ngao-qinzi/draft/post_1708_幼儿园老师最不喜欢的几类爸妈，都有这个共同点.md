# 幼儿园老师最不喜欢的几类爸妈，都有这个共同点

![封面图](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN3vY22yqbIXPYc43fBiceVD5AGib0DJgeO2VDFHcLYHIicDN9ptibgA71PX4A6at9UmRkG2jdT4mTShcw/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/DEHaI1NktGGEn9v5Q1ZOFQ

转眼，已经开学大半个月了。还是有很多宝贝，每天上学都像渡劫一样艰难。

看着娃痛哭流涕的样子，老母亲真心疼呀！偶尔也会怀疑老师“是不是对孩子怎么了？”......

之前，就有幼儿园出了这么一件事，闹得家长和老师都很不愉快：

![图片](https://mmbiz.qpic.cn/mmbiz_png/rS1D8dH2xmAQe0Q0jKbBHVPjIvicf2LbUSHriajT7Mj6FA4EAxNIboByOTzCnkIqiaiaLFXla4PrRsvIxXDEgMpboA/640?wx_fmt=jpeg)

都是当家长的，大家的心情我们很理解，无非就是想确定孩子在幼儿园里，有得到老师稳妥的照料。**不过，这种对老师的不信任做法，并不是很好的沟通方式。**试想，如果总是对老师充满了怀疑、揣测和不信任，老师又怎么敢放手鼓励孩子去尝试、去冒险、去犯错，去用一个适合孩子的方式，让他获得成长呢？


![图片](https://mmbiz.qpic.cn/sz_mmbiz_gif/tGtmpweWiaN3vY22yqbIXPYc43fBiceVD5oyaDgDxGZZIXUpROy6iar7uBJHdNRdTWRA6ibA9ucFJ83crTQgMXpCgQ/640?wx_fmt=gif&from=appmsg)

我们采访了一些幼儿园老师，如果你和老师更好的沟通、想让孩子在幼儿园适应的更快、更顺利，这些坑尽量别踩——


![图片](https://mmbiz.qpic.cn/sz_mmbiz_gif/tGtmpweWiaN3vY22yqbIXPYc43fBiceVD5VibTtyOnoIUW1Mpgf4DrKSZOPx30xLDmUXgIE3icM2mQOHzhdYaTTpKA/640?wx_fmt=gif&from=appmsg)

**不信任老师**

我们的老朋友资深幼师丽丽老师，跟我们讲过这么一个故事：一位妈妈，在有孩子后，放弃了家里的生意，一门心思都扑在养娃上。几年下来，光育儿的书，她就买了大几十本。**可对养育孩子格外重视的她，这几年却没少跟身边人闹矛盾，连保姆都换了好几个。**到了入园的年纪，她和老公千挑万选，给女儿选了一家国际双语幼儿园。可孩子入园半个月后，突然有一天被告知尿湿了裤子，她的第一反应就是：怎么可能？我家孩子 2 岁就会上厕所了！


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN3vY22yqbIXPYc43fBiceVD5JYp5C3zbE06TXrk5wvHA60qF1N2OYicH4FQoCMia7cbbPcm5DsNPH35g/640?wx_fmt=jpeg&from=appmsg)

**她觉得自己已经给孩子做好了所有的准备，所以问题一定出在幼儿园身上，搞得老师也不敢对她女儿说什么、管什么。**结果整个入园适应过程，变得非常艰难，她也考虑过换班、考虑过转园，但可想而知结果如何。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_gif/tGtmpweWiaN3vY22yqbIXPYc43fBiceVD5VibTtyOnoIUW1Mpgf4DrKSZOPx30xLDmUXgIE3icM2mQOHzhdYaTTpKA/640?wx_fmt=gif&from=appmsg)

**频繁影响老师正常工作**

每年幼儿园开学，门口都是这个画风：花式“偷看”、默默流泪、久久不愿离去，或干脆直接陪孩子待教室里不走……

老师好说歹说，好不容易把家长劝走。

可有些不放心的家长，一会儿一个微信询问孩子情况；老师刚发完孩子很乖正在吃饭的照片，又要求老师传孩子的睡觉视频；老师有时候忙起来回晚了，还在微信上发脾气。

还有的，直接化身名侦探柯南。老师发的每一张照片和视频，都能被这些家长找出破绽：我家娃看起来好像没精神？怎么一个人在做，老师都不帮忙？


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN3vY22yqbIXPYc43fBiceVD5VhhkFuEd1uRib7ccX41yBMicTgVicrVrmhlQgDicCYP97exvHIG2EyM4Mg/640?wx_fmt=jpeg&from=appmsg)


甚至老师发一段孩子们在玩橡皮泥的视频，都有家长会问：是打架了吗？我听见视频最后，好像有我们家孩子在叫的声音啊……逼得老师再次上传其乐融融的画面才肯相信。**还有一些家长，就****像一个习惯了发号施令的领导，常常会在群里对老师提出各种各样的要求**：

*“我们家的还不太会吃饭，老师你多照看一下”**“关注下 XX，让他多喝点水”**“让他站到人群中间去，小动作少做一点”。*隔着屏幕，都能听到老师内心崩溃的声音。  


![图片](https://mmbiz.qpic.cn/sz_mmbiz_gif/tGtmpweWiaN3vY22yqbIXPYc43fBiceVD5VibTtyOnoIUW1Mpgf4DrKSZOPx30xLDmUXgIE3icM2mQOHzhdYaTTpKA/640?wx_fmt=gif&from=appmsg)

**不遵守幼儿园规章秩序**

除了沉浸在焦虑中不能自拔的家长，还有一类特别佛系神经大条的家长，也同样让老师们脑壳疼。**这些爸妈会觉得：****不就是个幼儿园么？去不去都行。**于是不管是孩子生病了、出去玩了、还是有别的情况，经常连个招呼都不打，就带着孩子“失踪”了。还有一些爸妈，看某段时间流感高发，担心孩子生病，便自作主张不让孩子去幼儿园，更要命的是，他们根本不打招呼。更别说，幼儿园里组织的各种活动，老师更是找不到人。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN3vY22yqbIXPYc43fBiceVD5Moskib2ibPqVnsKmAr2mLZjAup3eGLvMtCUwsXxWuqgTdvv5KiaKPx6Xg/640?wx_fmt=jpeg&from=appmsg)


这个现象太常见，所以很多幼儿园的新生入园会上，老师们会单独把“请假问题”拿出来说。
**其实想想，如果现在给孩子养成自由散漫的习惯，读小学了，还能说不去就不去吗？****到时候，孩子改不过来，可就麻烦了！**


![图片](https://mmbiz.qpic.cn/sz_mmbiz_gif/tGtmpweWiaN3vY22yqbIXPYc43fBiceVD5VibTtyOnoIUW1Mpgf4DrKSZOPx30xLDmUXgIE3icM2mQOHzhdYaTTpKA/640?wx_fmt=gif&from=appmsg)

**隐瞒孩子的病情**

**比起上面那些，最让老师心塞的，就是孩子生病了家长“瞒而不报”。**尤其孩子明明得了重感冒、手足口这样有快速传染性的疾病，有些家长自己觉得不严重、孩子在家也没人带，就抱着“能多送一天是一天，不要紧”这种侥幸心理。结果不是病情突然扩散，整个班的小朋友都被传染了；就是孩子突然发病，老师急急拨打家长的电话，又被叫去接孩子送医。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN3vY22yqbIXPYc43fBiceVD5iaToJ2I2HlvgsOtyiczpnkXxlj4jKD7z5qp90Ze9MGAR9sJZ1DG3s2yA/640?wx_fmt=jpeg&from=appmsg)


仔细想想，这种做法对自己、孩子和整个幼儿园都一点没好处，何必呢？在幼儿园折腾这么一次，老师会怎么看孩子？别的同学家长会怎么看孩子？而孩子完全与这些无关，都是家长的决定啊。**其实啊，人和人之间的关系都是相互的。**咱们平时对老师的态度和配合，老师都看在眼里记在心里，那对她来说都是一种情感支持，获得更多情感支持的老师，才能给孩子带来更好的影响。你身边有这类特点的家长吗？你怎么看待家长和老师沟通这件事呢？评论区一起来聊聊吧~
