# 突发！3岁男孩家中溺亡，这个不起眼的隐患，很多家长都没注意到

![封面图](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN2vdgqWkE1bhkltCFlicI3OUK61FzBggKick3DRNxHN4ZtuuQ6yZvkK9GxoJ9ZTwaKlqHkQa9Jd3DLQ/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/j6vYI3wk31Vmyt0FA3CQiQ

今天，编辑部的妈妈们看到了一则让人痛心的热搜——

**3 岁男孩疑似在家中溺亡**，当时孩子爸爸在给 1 岁女儿喂饭，儿子独自在浴室泡澡，却发生了不幸。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN2vdgqWkE1bhkltCFlicI3OUZ1CTI9KBmMHUPRFNdYf5ylrficj1EmQOvcXdusyutoibobBxibdj5h8HA/640?wx_fmt=png&from=appmsg)


图片来源 @看看新闻医院也表示，**这种在家里不慎溺水的孩子，每年都会接到几例。**除了浴缸、水桶，甚至还有在金鱼缸里溺水不幸去世的。哎......看完后真的说不出的难受。孩子会到处跑之后，确实是更要小心！

这个年龄段的娃，往往好奇心很重，胆子也很大，自救能力却等于0。一个不小心，ta 就在哪磕了碰了、或者摸了啥不该摸的、吃了啥不该吃的了。

而且，早就有研究显示，**我们的家其实是意外的“第一高发地”：****近半数**（46.34%）**儿童青少年伤害是在家里发生的**。

尤其是 **1~4 岁**的宝宝，伤害死亡占比最高（33%）。

家长的看护固然重要，但毕竟我们没法时刻盯着娃的一举一动，所以一定要**把家里的隐匿危险都揪出来，提前做好防护！**

****今天咱做的这篇科普，简单明了，**建议发给家人群一起避坑！**
