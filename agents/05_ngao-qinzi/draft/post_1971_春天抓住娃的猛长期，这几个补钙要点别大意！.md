# 春天抓住娃的猛长期，这几个补钙要点别大意！

关于钙的问题咱一直没和大家好好聊过，但妈妈们对于钙可真的有太多疑问了：

*宝宝出牙晚、夜醒频繁、爱出汗、xxx 是不是缺钙了？*

*宝宝补钙该怎么补？*

*骨密度低了要不要补钙？*

*……*

咱们把大家最关心的问题都整合好了，今天直接邀请了浙江大学医学院附属儿童医院的李文豪主治医师，来详细讲讲缺钙的问题。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN2HyrO9xJiaa1SWTdUnsFkeFJUsCQ2d5wyJ0dDDllNagFFgT6CE4icS6QPugribHyggGNucpyFlhz8gg/640?wx_fmt=jpeg)


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN3fRdDkfk3fH6w1lKaPVKxMYWrib4VKicHdMtARD7dZYzM3s05zT0tsKLpNaZt74ZkN2ZTHDLDiaxE4g/640?wx_fmt=png)

说到缺钙这件事，李医生要先给大家都定定心，一般来说奶量够、饮食营养均衡、生长发育都正常，宝宝是很少会缺钙的。

因为啊，咱们的人体是一个精密设计的“仪器”，它是有很强的调节能力的。

一旦有低钙的情况，身体会迅速启动钙调节系统，这时候只要钙摄入够了，情况就会得到改善，缺钙的症状就会消失。

实际上缺钙风险比较大的是这几类宝宝：


![图片](https://mmbiz.qpic.cn/mmbiz_png/b96CibCt70iaajvl7fD4ZCicMcjhXMp1v6Utt8DU66CHNfyC8ovRKafSfcEc5lmQ7SrVltfEyHLY27Ax7EmRxLlUQ/640?wx_fmt=png)

** 钙来源不足的**，比如奶喝不够，辅食也吃得不好；


![图片](https://mmbiz.qpic.cn/mmbiz_png/b96CibCt70iaajvl7fD4ZCicMcjhXMp1v6Utt8DU66CHNfyC8ovRKafSfcEc5lmQ7SrVltfEyHLY27Ax7EmRxLlUQ/640?wx_fmt=png)

 **生长发育比较快的**，这类娃长得快，骨生长也快，钙的需求就更大；


![图片](https://mmbiz.qpic.cn/mmbiz_png/b96CibCt70iaajvl7fD4ZCicMcjhXMp1v6Utt8DU66CHNfyC8ovRKafSfcEc5lmQ7SrVltfEyHLY27Ax7EmRxLlUQ/640?wx_fmt=png)

 **自身有疾病影响的**，比如胃肠道疾病、肝胆疾病、肾脏疾病等，会影响体内钙的代谢。

如果你观察到宝宝有前面列出的情况，好像有“缺钙”风险时，可以从下面的程度表进行对照——


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN3QypgBldP2mwY5L9UsClA1XJnCFfnb5kpBAxV3JNkrqCCMGaYFX3FuJpDrWhdSLh5JhJ5I02KduQ/640?wx_fmt=png)


但是，光看表象来判断并不靠谱，很多表现也不是缺钙是独有的。

比如宝宝出汗多，有可能是热了；大运动发展期也会导致夜醒频繁。如果有疑虑的话，还是应该寻求医生的帮助。

总的来说，缺不缺钙还是和摄入多少有很大的关系，**只要吃够了、合理补充维生素 D，一般不会有太大问题**。

因此，与其担心娃到底缺不缺，倒不如**多从源头，保障娃的钙摄入和吸收**，做好 3 个关口的保障。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN3fRdDkfk3fH6w1lKaPVKxMic6HECS7FnUH956opqstMekggDiaoMGS3MpbwIqznw8MH0Cc4rCt25jw/640?wx_fmt=png)


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN3fRdDkfk3fH6w1lKaPVKxM9FWj35n62s7TYxUkTQwia561p1gxn7aHm2xhtlaN6jTHdbKJp0icbriag/640?wx_fmt=png)


我们需要的钙全部都是经口摄入的，宝宝长得快，对钙的需求大，但同时吸收率也高。

所以，从日常饮食中就把钙吃够，是最靠谱的补钙方法。（如果是母乳宝宝，妈妈也要注意钙的补充哦。）


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN3QypgBldP2mwY5L9UsClA1tBVlDCNsgdyEdk9F3DBIfRobly1h35cd7z5h7MBWhM5jf0N4FgAic2w/640?wx_fmt=png)


这里要提醒一下大家，越来越多的人都开始倡导多吃粗粮，但意外的是**高膳食纤维会影响钙的吸收**，对于小宝宝来说，粗粮还是要适量吃。

另外部分绿叶蔬菜虽然也富含钙，但是吸收效率比较低，可以作为额外钙补充。

至于真正缺钙的宝宝，要不要用钙剂、具体补多少，建议还是咨询医生来判断。

市面上常见的补钙产品大概就是葡萄糖酸钙、碳酸钙、醋酸钙、磷酸钙等等，而且有颗粒剂、片剂及液体剂型，好多爸爸妈妈挑选的时候都晕头转向，不知道给娃选哪种。

其实，大家不用想得这么复杂，给小宝宝选钙剂可以重点关注一下这三个方面：


![图片](https://mmbiz.qpic.cn/mmbiz_png/b96CibCt70iaajvl7fD4ZCicMcjhXMp1v6Utt8DU66CHNfyC8ovRKafSfcEc5lmQ7SrVltfEyHLY27Ax7EmRxLlUQ/640?wx_fmt=png)

 **方便宝宝服用的**，小宝宝优先选择颗粒剂、液体剂型，3 岁以后片剂也可以食用；


![图片](https://mmbiz.qpic.cn/mmbiz_png/b96CibCt70iaajvl7fD4ZCicMcjhXMp1v6Utt8DU66CHNfyC8ovRKafSfcEc5lmQ7SrVltfEyHLY27Ax7EmRxLlUQ/640?wx_fmt=png)

 **注意含钙量**，可以看产品包装上的标注；


![图片](https://mmbiz.qpic.cn/mmbiz_png/b96CibCt70iaajvl7fD4ZCicMcjhXMp1v6Utt8DU66CHNfyC8ovRKafSfcEc5lmQ7SrVltfEyHLY27Ax7EmRxLlUQ/640?wx_fmt=png)

 **口感要好**，毕竟宝宝肯吃也是很要紧的。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN3QypgBldP2mwY5L9UsClA1D597aibrbOhd1icAYicX36uwEUE7jSjpiaV2eoMyJfDlFr2fS4uKCOWQibg/640?wx_fmt=png)


守好了第一关，就确保了宝宝钙元素的充足供应，那接下来就需要保证吃进去的钙能在体内正常代谢了。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN3fRdDkfk3fH6w1lKaPVKxMePnLFa9XGPto3oqYIKPg2tkRvO0bhHVlWuibdPf1aCvDnTPFNBKoW2A/640?wx_fmt=png)


钙在人体中的代谢是由多个器官参与的，像小肠、肾脏这些会吸收一部分，多余的钙就会储存到骨骼中，如果钙不足了，骨骼中的钙就会及时进行供应。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_gif/tGtmpweWiaN3QypgBldP2mwY5L9UsClA1L2TvA1J31RT8SjtbSYoKCEpZYISHV8hxvvmMNxCTUX1Ga3htoZFdYg/640?wx_fmt=gif)


对于健康的宝宝，钙是可以在体内正常运行代谢的。一旦生病了，影响了某一部分机能，这种平衡就会打破。

打个比方，像有长期腹泻、肝肾功能异常的宝宝，体内的钙吸收就会大打折扣，家长日常应该多留意是否有钙缺乏的问题。

单靠足够摄入，和健康的身体来维持运转其实还不够，最重要的还需要让吃进去的钙被宝宝吸收进去。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN3fRdDkfk3fH6w1lKaPVKxM5qxBPDibZAymMAuSEOqzjqMCYzjEqAkHSWuACd3JXeG2Bm8ZwrwMugg/640?wx_fmt=png)


维生素 D 对钙的吸收很重要。因此，很多时候我们谈到缺钙，实际上是指“营养性佝偻病”，这往往是缺乏维生素 D 导致的。

要想真正让钙元素通过小肠吸收，进入血液，被送到骨头中，就必须搭乘维生素 D 这趟列车。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN3QypgBldP2mwY5L9UsClA1ibwGg5TicIYMJDtEiae6fTqBPpIic4WShfbk235yvgO4qUFaicxNicVFJK8w/640?wx_fmt=png)


如果维生素 D 摄入不足，那吃再多的钙都是浪费。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN3QypgBldP2mwY5L9UsClA1MPJCEibpSSiczscEPibiclewK2onyVSVZ8UfkCCpMCTOsibibAjTa3Vpfw2w/640?wx_fmt=png)


可惜的是，维生素 D 单靠晒太阳和饮食补充其实都不太现实。

晒太阳确实能补充部分维生素 D，但要晒够真的挺难的，要受到纬度、肤色、着装、光照时间和时长等等各种因素影响，万一操作不当还容易晒伤。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN3QypgBldP2mwY5L9UsClA11dY5Zrr9rCPorLdUjib5HxUJHX3baCF3yDNEZj0p4HODvEOcB271tJA/640?wx_fmt=png)


至于食补，宝宝每天可能要吃这么多才行，这显然扛不住。而且富含维生素 D 的天然食物种类非常有限。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN3QypgBldP2mwY5L9UsClA1ufw0sTs75O2kkvlgNggxBM96UZR4ibayELHaLlicwnPn7lFVncoBErYQ/640?wx_fmt=png)


因此，吃维生素 D 补充剂是最为靠谱的，从出生数天内按这个剂量补就够了：


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN3QypgBldP2mwY5L9UsClA1X72gnyl7iaUlfS2pQTu7WNm5J4nGW0wphUnTQr7XlUolHsAYib95fDmg/640?wx_fmt=png)


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN3fRdDkfk3fH6w1lKaPVKxMmD9DPbeCNCx9MRnQhRPpKWRSnSh6AAYP8iayTl2FzQsicNmUWczeMMOw/640?wx_fmt=png)

目前来说并没有一个简单直接的方法可以快速判断宝宝是否缺钙了。

要是你观察到了宝宝出现了缺钙的“可疑症状”，并且 Ta 日常饮食中也没有摄入足够的钙，或者有其他疾病影响，一定要及时就医，让医生来整体评估，而不是自己给 Ta 诊断，并随意补钙。

我们常听说骨密度检查，其实啊，这项检查一般用于骨质疏松高风险人群，比如中老年人。**生长发育正常的健康儿童，一般都不需要常规开展骨密度。**

但是，对于有钙缺乏风险的宝宝，比如：生长速度快、奶量不足、营养状况差等，或者有经常骨折、骨骼畸形等情况，就医时就可能会需要做骨密度检测啦。

如果你家娃做了骨密度，显示缺钙，也不要太着急。骨密度的检测结果会受很多因素影响，并不是判定孩子缺钙的金标准。

到底是不是缺钙、要不要补钙，**医生还会根据宝宝的饮食营养、运动、影响钙吸收的因素分析以及一些血液检查等，结合临床经验进行一个综合性的评估和建议。**


∨最后，还是想跟爸爸妈妈们说几句，养孩子虽然很难，但还是希望大家能放下一点焦虑。

咱们能做的就是了解宝宝的需求，保证 Ta 吃够、吃对，不乱补乱吃，大部分宝宝的生长发育都是不会有问题的。

如果观察到宝宝有任何的不适，切忌自己在家瞎判断，徒增焦虑，寻求医生的帮助才是最稳妥的。参考资料：
