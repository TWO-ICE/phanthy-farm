# 糕妈：抛下3个儿子，和糕爸单独去了趟......

前阵子度过了非常美好的一天～


我和糕爸单独去了趟上海，一个娃都没带。


说出来理直气壮，其实是借了工作的光。活动排在傍晚，白天那几个小时就成了我俩“偷来”的小约会。


![图片](https://mmbiz.qpic.cn/mmbiz_png/Zm9D1tlicZFERJs8qJYJicvKWC8PnbXbIXgcw2HMTCOVbqqFw9hm3IZ6MbNibm36M7D59StXziaRYJVh8kglvCfy5h4UtChiaDw0L42D2eCSg0p4/640?wx_fmt=png&from=appmsg&tp=webp)


早上从杭州自驾出发，我俩还有点不习惯。毕竟，每次都是带一车的儿子。


糕爸一上车就说：“我们好久没单独绑在一起了诶～”


是的，以前都是一个人出差当天往返，另一个留家里看娃。像两班倒的同事，交接完各自上岗，像这样“在同一空间里的物理连接”真的不算多。


车上那两个多小时，我没看手机，糕爸也没听音频，就只是聊天。从家里的事聊到工作上的事，越聊越深入。


糕爸还拉着我立了个 flag：以后每周至少要散步两次，单独吃饭一次，哪怕就半小时。
