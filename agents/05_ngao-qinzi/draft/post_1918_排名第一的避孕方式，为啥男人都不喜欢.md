# 排名第一的避孕方式，为啥男人都不喜欢

![封面图](https://mmbiz.qlogo.cn/sz_mmbiz_jpg/tGtmpweWiaN0GHUibzvl6Dnib47tibts3mjheSTTicMNMCvv6UtVMgsibErCa6AAQD9FWxmRF7EqrcNey2ianwbiazibwng/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/Gaa7RezTF2T3HTuA7KE2hw

说到避孕，现在很多靠谱点的避孕方法，比如吃药、上环、皮埋这些，大部分是针对女方的。


![图片](https://mmbiz.qpic.cn/mmbiz_png/rrVVklPTzRCvribNAkRAvr2jiaiatfBia3ibkteNDPjLnmoriczGbRREpo1iaZndYicNVrF7Un0xjPePevN44Q3ZO0Jnjg/640?wx_fmt=png)


但有一样是男方可以做的——**戴套**。

套套除了避孕成功率高（ 98% ），还有很多优点：


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/rrVVklPTzRCvribNAkRAvr2jiaiatfBia3ibkOZ1eSRRsmOZAF50yuCwKLeohCnHVztlJuTrLnKUXbUm3LANd535WUg/640?wx_fmt=jpeg)


之前，有个妈妈在我们留言区强势安利了套套：


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN2YyRSSGOgCiaznslLdU4WCahwJ1YTeSfs2iaBXKAibEvkhWFlDNibiaXh3y4dBib1M3XIvNzHicTFpZxhNQ/640?wx_fmt=png)


可能有人会说，男的不是还可以结扎吗？

确实，愿意为老婆去结扎的男人也有，但更多是像下面这位说的这样…...


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN2YyRSSGOgCiaznslLdU4WCaPQoYf2FyibibYuynoXlZAIp55b9CMVMFDzeKL0Aib37BlsguRFmOOoXzg/640?wx_fmt=png)


是的，别说结扎了，戴套很多男人都不！愿！意！

**为了不戴套，理由有一套。**下面我们就来好好扒一扒。

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/rrVVklPTzRCvribNAkRAvr2jiaiatfBia3ibkMLHiaLSaKyRiclHA80ryUK0ABnPzU3Z0BXh3B9H1GuVsc3FWFdDp8rNw/640?wx_fmt=jpeg)

当然了，有些时候还真不是男方不愿意戴，比如这位妈妈就自曝：


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN2YyRSSGOgCiaznslLdU4WCaF5nL4cl5MART4eFwOFDr1kb7r7e3RI4FETZJe2ws0Ypsgkds1RhSwQ/640?wx_fmt=png)


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/rrVVklPTzRCvribNAkRAvr2jiaiatfBia3ibkYKOoCV2WgZibJpv8CicKBianukfSuoiaiaRemSp6g4qQKuXvQPYqsZk4BLg/640?wx_fmt=jpeg)


不过，也有妈妈会提出质疑——**我们明明戴了套的呀，怎么还能“中奖”？**


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN2YyRSSGOgCiaznslLdU4WCaeltBcZxaPpDHP1ibMyVKmLCQ0LotW5icLWQB8W9B800Rw4JGXib737iakA/640?wx_fmt=png)


确实，在现实中，即使男方戴了套，还是会有 18% ~ 22% 的女性怀孕。

原因也很简单——**戴了，但没戴对：**

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/rrVVklPTzRCvribNAkRAvr2jiaiatfBia3ibkRUaDFMZqsp8y2D1DtOrXaoPE1OM4hVkXvFt82jrCicA1jMsXxWoZVJg/640?wx_fmt=jpeg)

所以，**一定要正确戴套，不然戴了也可能白戴呀。**

而且，戴套是个需要长期坚持的事，**不能有侥幸心理。**


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN2YyRSSGOgCiaznslLdU4WCagpcOfgbT3cZ2F8XIbicgk4keVRx9ia3D3C4gsCFtxGduUniaC4PI8ic9Bw/640?wx_fmt=png)

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/rrVVklPTzRCvribNAkRAvr2jiaiatfBia3ibkiajzTS5UbaUC3iaibmha3NMYRq1WIDkT5k6SSbRTICaGGh26ukECooF9w/640?wx_fmt=jpeg)
