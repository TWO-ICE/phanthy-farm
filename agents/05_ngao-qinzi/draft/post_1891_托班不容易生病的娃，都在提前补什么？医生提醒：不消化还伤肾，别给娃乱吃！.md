# 托班不容易生病的娃，都在提前补什么？医生提醒：不消化还伤肾，别给娃乱吃！

最近，很多妈妈都在担心孩子入托入园后容易被交叉感染怎么办？**有什么办法提高抵抗力吗？**


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/2EaFkYu8IStYj7MrLq98pQ3iawmImMIbhcIO4kgHTzJJqPugQQGK1kEhbBOoibDcJNibPejfpEibibp90fFNQpvhSSA/640?wx_fmt=png)

谈到这个话题，总少不了**乳铁蛋白、牛初乳、益生菌、维生素**的身影，哦对了，还有处方药——**免疫调节剂**（脾氨肽、细菌溶解产物等）。

每次看到妈妈们说有用，咱这心里总是忍不住心动，想着要不要给自己娃来一点。但一看价格，嚯，都不便宜。

那，它们到底有没有用？是不是智商税？今天，我们就来好好聊一聊~


**乳铁蛋白**

可能有用，但不建议单独买


**乳铁蛋白**一直是咱们留言区的热词，很多妈妈会问：乳铁蛋白粉怎么样，可以买吗？


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/2EaFkYu8IStYj7MrLq98pQ3iawmImMIbhl9FApNaRGIsCJbBvTVibicqIBZses9KZ8gXkloRXIVHq5PiagVB93rr2g/640?wx_fmt=png)


咱先说结论——**乳铁蛋白**（LF）**确实能让娃少生病！**

中国营养学会妇幼营养分会的《乳铁蛋白婴幼儿健康效应专家共识》中就指出：


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN0TLkAXDu69NIia19pmpRnDVA1MVhVo2EHg4vcAtwYV6lyXnf7k6LCvsQJO7zZdVoP02xk0bibYmkSw/640?wx_fmt=png)


腹泻、呼吸道疾病、贫血、生长发育……这些可都是咱老妈子最困扰的婴幼儿常见问题啊！甚至还有一些研究认为，乳铁蛋白**可能**对预防或辅助治疗新冠有益（仅理论猜测，目前还缺乏证据）。

明明是个好东西，为啥总有人 diss 呢？

**这和一些不良商家的恶意营销有关**。他们利用家长们“保护宝宝”的恐慌、抓住“提高免疫力”的痛点，无限放大乳铁蛋白的功效，进而推销各式各样的高价产品，比如乳铁蛋白调制乳粉、乳铁蛋白粉等。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN0TLkAXDu69NIia19pmpRnDVE8jcztPuf0ia0CBkT6Mq6Y9icn5icyQVoPGQUia5ZicUBHTrIoGqWKaqUJQ/640?wx_fmt=png)


就拿上图举例，要知道，乳清蛋白和乳铁蛋白的原料**进****价****相差好几百倍！**

披着乳铁蛋白的皮卖出高价，本质可能只是普通蛋白粉，**盲目食用还会给娃造成消化和肾脏负担**。这些产品才是真的不靠谱、“智商税”！

事实上，国家允许添加乳铁蛋白的食品，只有婴幼儿配方奶粉、调制乳、发酵乳和含乳饮料。所以，**如果奶粉里有乳铁蛋白，那确实是个加分项**。

至于那些蛋白粉、固体饮料？真的不建议给宝宝吃了！（确实容易生病，需要单独补的，记得找医生开~）


**牛初乳**

对小牛有用，对孩子不确定


早在 2012 年，卫生部就已明确指出——“婴幼儿配方食品中不得添加牛初乳以及用牛初乳为原料生产的乳制品。”


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN0TLkAXDu69NIia19pmpRnDV0HzquwoEd7j35n8StrlguwRpia44xpswSBzroJeibXy9E9Qjz7ZqC0Yg/640?wx_fmt=png)


这条规定曾被称为“牛初乳禁令”，免疫之王“牛初乳”自此走下神坛。但不得不说，这个“禁”字其实不是很准确。

国家只是**“禁止在婴幼儿配方食品**（也就是婴幼儿奶粉）**中添加”，并非“禁止在食品中添加”**。一些奶贝、奶片、牛乳棒里加点牛初乳，还是可以的，当零食偶尔吃吃也没毛病。（1 岁以内的孩子不要吃）

可提高免疫力？还是别冒这个险了！

**牛初乳是给刚出生的小牛牛提高免疫力的，对人体未必有效。而且牛初乳成分复杂，长期食用是否安全？**这都得打个大大的问号~


**益生菌**

腹泻时可以吃


目前，益生菌被证实有明确作用的只有——

**预防或缓解急性腹泻，以及应用抗生素引起的腹泻。**

至于下面这些功效，更多的是因人而异，还没有特别确凿的临床证据。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/2EaFkYu8IStYj7MrLq98pQ3iawmImMIbhR8pAdse0RZtxrX2WtiawnekbDL8C41bsMib1qbu2FehMbwzib6VNsxQsw/640?wx_fmt=png)


有些产品会宣传说，添加了益生菌，宝宝吃了少生病。

这个就有点玄学了。实际上，添加的益生菌，不管是种类还是数量，和我们身体里存在的比，都太少了！能在肠道存活下来、改善腹泻就已经很不容易了，还要在其他地方发挥健康作用？属实有点难为“菌”了~

所以，妈妈们，**益生菌是挺好，****孩子平时拉肚子情况比较多的，建议大家可以备着点。**但咱就别指望吃它能提高免疫力、包治百病了哈。


**维生素C**

食补就够了，高价维C慎吃


不少家庭的药箱里，都会囤着维 C 补剂、 泡腾片，连药店的人都说吃这些可以提高免疫力。

我们也不否认，**适量的维 C 补充对身体有益**，但是，过犹不及。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN0TLkAXDu69NIia19pmpRnDV1Pd3jA7OLM08BWUVKopPOJe5vxib68N0SFic9FpeEVGxx1HUkPYPkW3g/640?wx_fmt=png)


**1~6 岁的娃，每天的维 C 推荐摄入量是 40~50mg。**吃 1 颗冬枣或者 1 个猕猴桃基本就够了，再加上其他蔬菜水果，大多都有富余~


**富含维生素C的常见食材**

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN0TLkAXDu69NIia19pmpRnDVuFibltwJw3f6Q2iaRQeluddqrddfb54MjoDkde1iagadO6hNV8bAt9Ocg/640?wx_fmt=png)


注：维生素 C 是水溶性维生素，且遇热不稳定，长时间泡洗、高温烹饪都会导致部分流失。

而像下图这种泡腾片，每片维 C 含量高达 1g（1000mg），**实在超标太多！**大人吃吃就算了，真心不建议给小孩子吃。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN0TLkAXDu69NIia19pmpRnDV98ncj6HibibGSpvVaKQiaYYAFHDaGyMt2IMZEQeBMk0XaL5GvfH1z0BVA/640?wx_fmt=png)

**免疫调节剂**

有用，但你家孩子不一定需要


如果你家娃总是呼吸道感染（感冒、鼻炎、扁桃体发炎等等），每年超过 6、7 次（肺炎超过 2 次），医生可能会建议你试试——**免疫调节剂**。

儿科医生目前常用的免疫调节剂主要是：细菌溶解产物、脾氨肽和匹多莫德。其中，**细菌溶解产物的推荐等级是最高的。**


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN0TLkAXDu69NIia19pmpRnDV4snMIqvJ0BEkl3H0t0jjoQFPslxceMcAxLzia4HtG6YicaNFsTrK7Cxg/640?wx_fmt=png)


▲《儿童反复上呼吸道感染临床诊治管理专家共识》中指出：细菌溶解产物能有效预防儿童反复上呼吸道感染。

细菌溶解产物，其实是好几种常见呼吸道细菌溶解后的口服冻干粉，原理有点像打疫苗。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN0TLkAXDu69NIia19pmpRnDVPxZsVcnpRDxsW58xia5icIx1iagEfwUWkIrW8TibTPib0GhpanLibMScIxvg/640?wx_fmt=png)


▲ 药品说明书

浙江大学医学院附属第二医院过敏科副主任汪慧英教授还曾形象地把细菌溶解产物，比喻成**“玩泥巴”**：


![图片](https://mmbiz.qpic.cn/mmbiz_png/7QRTvkK2qC63c02mKcsfAaJ8sNcicTvg22UkHHibvKiasFS9FS6E4FeV0Dibe7as7h4tm8p7EfNfI06adlGbL2icYjw/640?wx_fmt=png)

就像以前，很多小孩子都会玩泥巴，微生物暴露多，免疫系统经过训练，会快速成熟发展。现代生活中，大家的微生物暴露都减少了，**因为接触到的微生物较少，免疫成熟会进展地很慢，这其实也是过敏、哮喘等疾病增多的原因之一**。

细菌溶解物通过灭活病原微生物，使免疫系统接触更多病原，促进免疫系统成熟，显著提升免疫球蛋白水平，减少感染的机会。

不过，免疫调节剂的争议也比较大，比如它是口服的，进入消化道后为什么能对呼吸道起作用？会不会引起免疫紊乱、增加过敏风险……这些都还需要更多有力的高质量证据。

总之，既然是药，就不能随便乱吃。**反复感染、免疫异常的孩子可以遵医嘱使用，咱好好的娃，不建议尝试哈~**
