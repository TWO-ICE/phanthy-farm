说怎么正确吃之前，咱先来讲讲 **3 个饮食误区，避避雷。**


![图片](https://mmbiz.qpic.cn/mmbiz_png/rrVVklPTzRBBvibWL84bLJI3V7JXcnu2IHzgTqNF93ic2iaytLMOkOrP2ic120g3mrwRG6n2sfkgibqnuvI9r8eicUuw/640?wx_fmt=png)


常给我们审稿的医生说，家长问他最多就是**“发烧能不能吃鸡蛋？”**

某度上有一种说法是这样的：“鸡蛋中蛋白质含量较高，发烧时食用，易增加身体的基础代谢率，不但不能使体温降低，反而会增加身体热量，不利于病情的恢复。”

实际上，**发烧是个消耗能量的过程**，新陈代谢会加快，身体中的蛋白质分解加速，**鸡蛋就是最物美价廉的优质蛋白来源之一**，发烧胃口不好的时候，来一碗炖得嫩嫩的鸡蛋羹多香啊。


![图片](https://mmbiz.qpic.cn/mmbiz_png/rrVVklPTzRBBvibWL84bLJI3V7JXcnu2I7Ig2Aj2QcmDXqRzhEZqSqO1iaicCa6dnNh9DtuVEdg2A3EUqPB8ddQRQ/640?wx_fmt=png)

**

![图片](https://mmbiz.qpic.cn/mmbiz_png/rrVVklPTzRBBvibWL84bLJI3V7JXcnu2IgoibWA4Wr2tvD01rGlnv7jchL1Tic0uDia3maqqGS8wF539mkPrM90xQw/640?wx_fmt=png)

「阳」了之后，有些人会腹泻。

**如果腹泻严重，首先要口服补液盐，而不是吃益生菌，它不救急。**


![图片](https://mmbiz.qpic.cn/mmbiz_png/rrVVklPTzRBBvibWL84bLJI3V7JXcnu2IhFNW3mY3F92UiberUcY4t20d3xEMmF2IKysc2ibLpSdwG6kqgT0DtO4w/640?wx_fmt=png)


实在想买益生菌，也要选真正对腹泻有效的特定菌种益生菌。（不建议盲目购买，益生菌的坑很多。）

另外，腹泻时如果实在没胃口，**短时间内不吃东西问题不大，但要保证水分的补充**，饮用一些清流质，如米汤、去渣果汁、藕粉、糖水冲蛋等；恢复好一些之后，可以**少食多餐**，吃一些清淡易消化的半流质食物，比如米糊、稀一些的肉粥。


![图片](https://mmbiz.qpic.cn/mmbiz_png/rrVVklPTzRBBvibWL84bLJI3V7JXcnu2InibDcxViaibksE2vQXznnckvDLRDnGuBsqnRlgRcPdS2jkE45FDiaFZiceQ/640?wx_fmt=png)

▲同事「阳」之后说吃不下东西

出现这种情况，可能是**帮助吞咽的肌肉变弱**了，下面几个方法可以更好帮助吃饭。

嗓子不舒服、胃口差的时候，一碗热腾腾的粥确实更好入口。往粥里加一些鸡肉、海鲜、蔬菜、香菇，营养也均衡。


![图片](https://mmbiz.qpic.cn/mmbiz_png/rrVVklPTzRBBvibWL84bLJI3V7JXcnu2IaFRia1BYB3FdYQEKe3ms82YfTlp1iaz1NibicdzM1Z2lviaO34RrrCW780Q/640?wx_fmt=png)


▲有啥放啥，肉、蔬菜、主食，可各加 1、2 样

除了粥，煮得软烂一些的**面疙瘩汤、汤面**也可以吃。


![图片](https://mmbiz.qpic.cn/mmbiz_png/rrVVklPTzRBBvibWL84bLJI3V7JXcnu2IVL8NFRXdUayaofsj0dVkCgaRaIKVvgiayHqhB5IdEel7ibvPgFvzPBeQ/640?wx_fmt=png)


油麦菜、芹菜等**不好煮烂的蔬菜可以少吃**，会非常剌嗓子。（实在喜欢吃的话，切碎一些。）

更推荐吃容易炖软烂的蔬菜，**直接选买菜 App 上，“蔬菜-茄瓜类”这个分类里的菜**。

番茄、西葫芦、黄瓜、茄子、南瓜、花菜、西兰花等，茄瓜分类下的菜，往往都可以煮得偏软烂。👇


![图片](https://mmbiz.qpic.cn/mmbiz_png/rrVVklPTzRBBvibWL84bLJI3V7JXcnu2IWyPMic43vH0cF69Z4ibMjNFATxrT7dwWnA9KZhMm72an0YGaoLnrpN9g/640?wx_fmt=png)


有了它们，煮粥炖汤的时候，再加点鸡蛋（打散的蛋花或者荷包蛋都行），或者加点切碎的虾仁，营养就比较均衡了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/rrVVklPTzRBBvibWL84bLJI3V7JXcnu2ISvQHFkdItxkaibRQ9lv22SIe3P3HeMQRWtSUibcP9tyt6NrbQngdJLVw/640?wx_fmt=png)


![图片](https://mmbiz.qpic.cn/mmbiz_png/rrVVklPTzRBBvibWL84bLJI3V7JXcnu2IaIvkOKwPN4kbicZHkNztOEFpWszkOP5ptP6daS2HV7ZrkN4gjjd8Wag/640?wx_fmt=png)

发烧难受的时候，“多喝热水”真的有用！可以带走多余热量，更舒服。（尽量 65℃ 以下的温水就好哦，千万别喝烫嘴的水。）

但水喝多了上厕所次数也会增加，**水溶性维生素**（VC、B 族维生素等）**就会随尿液排走**。

所以，下面这些可以多吃。👇


![图片](https://mmbiz.qpic.cn/mmbiz_gif/rrVVklPTzRBBvibWL84bLJI3V7JXcnu2IqoOygqAcbRkukqxbtGX5RZibHAlF9dyiaK6dFrTTJLxswIcVbobVk12g/640?wx_fmt=png)


补充维 C 吃新鲜水果基本就够了，没必要买维 C 泡腾片，更没必要抢柠檬。（柠檬维 C 含量只有 22mg/100g，还不如橙子、橘子！）

**最后，有 3 点特别提醒：**

① 有胃口的话，**碳水可以多吃一些**。长时间发烧会消耗体力，**吃不够碳水身体会拆东墙补西墙**，把蛋白质、脂肪也消耗掉，人就更虚了。

② 一次吃掉完整的一餐很吃力，可以**少食多餐**，对肠胃负担也小一些。

③ 发热期间，**食品卫生一定要注意**，避免进食**不洁、生食、酒精**等食品。
