# 全家中毒进医院，查出原因后妈妈气炸了！厨房的这样东西，很多有娃家庭都没用对

![封面图](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN36NpTY3V5WmYxITPxKXR68NH3Ej0icM4DicHrNsIRuqKbXhqw0RZOEMIoQYcQyO6m5r1d7G4ua4GVw/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/9pQ7b7bnjDlkev00JV_jUA

姐妹们，你家的抹布是什么材质的？有几条？

咱编辑部的@丽姐 说，她回家发现老家厨房看上去挺干净的，但洗碗用的是一块旧海绵擦，擦台面的是婆婆用娃穿不下的棉 T 恤剪的布头。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/rrVVklPTzRArv5CicXrdoEqvH67M836e1Etn5qNEicxAFC8yv1vBYPpbDoZqzFAianGFfBuPsFIXTG8nFnzbNHovQ/640?wx_fmt=jpeg)


像海绵擦，之前被曝甲醛超标，但价格便宜又好买到，很多家庭都还在用。（如果严格遵循生产标准是不会甲醛超标的，但实际情况是，大多数人没法知道它的生产情况，所以要谨慎购买。）


![图片](https://mmbiz.qpic.cn/mmbiz_png/rrVVklPTzRB5tV0zZanjgxQ2UUuInGicSGpOygsjO8SN2YH9rMyA4cb6tLRxWP1qjEn8JGAeEUFz2arSibHqnia2A/640?wx_fmt=png)


而老人的“自制抹布”是省钱、环保，但这种布真的很难清洗，还会越擦越脏——

棉布用久了不仅会掉毛，沾的碗筷上到处都是；油污很难洗，用几天就油腻腻的了，更别提咱看不见的细菌、病毒……

另外，千万别**擦桌子、洗碗、擦餐具都用同一条抹布**，擦到哪脏到哪。

之前央视就报道过：北京一位阿姨用抹布擦过鱼后，又擦了黄瓜，黄瓜做成凉拌菜，没想到当晚全家人开始上吐下泻。


![图片](https://mmbiz.qpic.cn/mmbiz_gif/rrVVklPTzRB5tV0zZanjgxQ2UUuInGicSJYog003Fu7CH1CyZNQ3VEn5tHaOfiaVoNV2AvxtJRmznfLQ70DCd12w/640?wx_fmt=gif)


谁家厨房都有 2、3 条抹布，但很多人都没用对！家里孩子和老人的肠胃还娇嫩一些，吃进肚子、和咱全家人健康息息相关的东西，咱真的要特别关注！


![图片](https://mmbiz.qpic.cn/mmbiz_png/rrVVklPTzRB5tV0zZanjgxQ2UUuInGicSPlT3lWw04I2n1g2ic7N4YzU82ECauaRq3NIhwic9uiby6LEibrCMMdllGw/640?wx_fmt=png)


《中国家庭厨房卫生调查白皮书》显示：一块洗碗布中的细菌总数，最高达约 5000 亿个，还含有**大肠杆菌、金黄色葡萄球菌、沙门氏菌**等 19 种致病菌。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/rrVVklPTzRBQYD69c3t50U7FawPlvpAnHJRK2FEG6Qe4icvbfSN04uU77Svvciayheqb0rV1ForZar4xS4xGYib0w/640?wx_fmt=jpeg)


很多家庭都是老一辈在用厨房，不少老人都觉得“棉”是最好的材质。


![图片](https://mmbiz.qpic.cn/mmbiz_png/rrVVklPTzRB5tV0zZanjgxQ2UUuInGicS6xqVb2wd7I6BPHlrOysN9mWWYfY5yTHjusKMcUIFI1X6c29dCZaBEQ/640?wx_fmt=png)


确实，棉抹布**吸水性好**，灶台上的水一擦就没，这是因为棉纤维是中空的结构（可以把它想象成吸管）。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/rrVVklPTzRB5tV0zZanjgxQ2UUuInGicSBlupHGmqC7HaH4mNpwm2sUA9dgZ6RaqItavfbP2TVjRS4hQlcv1LfA/640?wx_fmt=jpeg)


（棉纤维结构）


图片来源：参考资料[3]

但**吸水性好也意味着不容易干**。厨房里不仅潮湿，还有污水、油渍、食物残渣，对细菌来说，简直就是繁衍的乐园。（用久了之后，棉纤维还会发硬、断裂，变得掉絮、发臭、吸水性大打折扣。）


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/rrVVklPTzRArv5CicXrdoEqvH67M836e14CXZibicusz8rcmaQbX6J0TDyvaHNuJs5NZjicWjHwicLoMSkm3AlSgeicA/640?wx_fmt=jpeg)


同事婆婆喜欢把旧物改成抹布


如果你家用的是棉抹布，记得**一定要注意消毒、勤更换**。

还有**海绵洗碗布**，虽然好起泡，清洁效率高，但用过就知道，用很大的力气去挤、捏，也会残留下水分、油渍甚至是饭菜残渣。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/rrVVklPTzRB5tV0zZanjgxQ2UUuInGicSkcub7pEBkxnIGdo4V0hm4omqRY9HTibJ9DAB8shiavbpo0iaVX09xzCjw/640?wx_fmt=jpeg)


（同事家的海绵洗碗布，上面常年有饭菜残渣）

你发现了么？上面两种抹布都会因为**「不容易干」**容易滋生病菌。

想让抹布干净卫生，最重要的一点就是能**「快速干燥」**，不给微生物留成长的机会！

我们测过非常多款抹布，最后也找到了几款好用且性价比高的。

不过在介绍之前，必须先提醒大家：

**抹布一定要及时清洗，定期消毒****，1 个月左右就换新；尽量做到专布专用**，擦碗的布就别用来擦桌子擦灶台了！

**木浆海绵**这几年特别火，它主要由木头、竹、麻等天然木纤维，通过特定工艺制成。

相比普通海绵，它的孔洞更大、通风更好，水分也能更快挤干/晾干，不易滋生细菌。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/rrVVklPTzRBQYD69c3t50U7FawPlvpAnb6mDOyibWK4FOQqg5iaIa5dVuK8EPBic1UJPabSLibnHtKDrmh3NpHlphQ/640?wx_fmt=jpeg)


我们实测：湿透的普通海绵和木浆海绵，放在同一个台面上，**8 小时后木浆海绵几乎全干，而普通海绵却可以轻松拧出水。**

左：普通海绵 🆚 右：木浆海绵


![图片](https://mmbiz.qpic.cn/mmbiz_gif/rrVVklPTzRBQYD69c3t50U7FawPlvpAnJqIagTN1SOEJH0TNdhbWhx9sdUNeaQLxibFOIbWEMZMHq6ha2wYFhxQ/640?wx_fmt=gif)


![图片](https://mmbiz.qpic.cn/mmbiz_gif/rrVVklPTzRBQYD69c3t50U7FawPlvpAnEzcDqQ2HhDOjnSAqlO0nicDL86Bu4tsAvMU5IBfd0WBrJfiaJPgZ394A/640?wx_fmt=gif)


另外，木浆海绵的材质也决定了它**不亲油、易清洗**的特性，用它来擦洗油腻的碗碟非常合适。


![图片](https://mmbiz.qpic.cn/mmbiz_gif/rrVVklPTzRB5tV0zZanjgxQ2UUuInGicSiaJR2hh0JwRpCZWXdiaU1S1KoTicickLhhKbZJB5M1LwfVncnNZm1tgdlA/640?wx_fmt=gif)


不过，木浆海绵的摩擦力比较小，黏腻的顽固污垢直接用它就很难弄干净。


![图片](https://mmbiz.qpic.cn/mmbiz_png/rrVVklPTzRArv5CicXrdoEqvH67M836e1pCAovVUZHIZ8MMurMAIo6OnsHXeRiaPgt5nxk2L23FjicYEiaPSGzMTUg/640?wx_fmt=png)


鱼鳞抹布的材质是**「超细纤维」**，它的直径大约是头发丝的二百分之一。

因为很细，纤维之间存在大量的微细空隙，所以布与灰尘和油污的接触面积也就更大，清洁的效果就更好。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/rrVVklPTzRB5tV0zZanjgxQ2UUuInGicS4aI19dyBaGWMxcCfyhhiaVLaKYbvYK6icJxzeeCBr7k3l0rthqP3uU0w/640?wx_fmt=jpeg)


玻璃、镜面这类光滑的材质很适合用鱼鳞抹布擦，不仅锃亮，还干得快，很多专业保洁、餐厅酒吧都在用。

擦玻璃杯，一擦变新👇🏻


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/rrVVklPTzRB5tV0zZanjgxQ2UUuInGicSk4Yfib4cUyZOBF1srnM8KEO2gc42RoFiagu1SD40iatycXTCpMSibychrg/640?wx_fmt=jpeg)


擦水龙头，瞬间锃亮👇🏻


![图片](https://mmbiz.qpic.cn/mmbiz_gif/FF2OYjRxqc165YPwOUObeE0c3Q2EzJ13wH5eWFJhwEqzMMcuf54IJfbEcPRloWcrjicxQcTJUib1Fhb81TThhJNw/640?wx_fmt=gif)


虽然可以把东西擦拭得很干净，但鱼鳞抹布的**吸水性比棉抹布差**，需要擦干水分的时候不建议用它。


![图片](https://mmbiz.qpic.cn/mmbiz_png/rrVVklPTzRArv5CicXrdoEqvH67M836e17PA2y4SANlTUTaeLnWe990yOOjSnBYcRZT2NicZ63bIoWceBWtO8qEA/640?wx_fmt=png)


和常见的钢丝球不一样，这款的钢丝特别细，不容易擦坏灶具表面。（不粘锅内壁还是不能用的！）


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/rrVVklPTzRArv5CicXrdoEqvH67M836e1zCwv4HQzrnJbAaBLDCQ5R7yscPia3hDpVx26vvChVM9Yz8ebm5BCKEA/640?wx_fmt=jpeg)


细钢丝，不容易划坏物体表面

更方便的是，它自带了清洁粉，清洗锅底、油烟机上的那些陈年旧渍的效果贼好！


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/rrVVklPTzRArv5CicXrdoEqvH67M836e1B2QWSZw5bPUzYlmib5PVlicxIpgHZDuTzKNXyXNqLvcoCvptaAGN1nicA/640?wx_fmt=jpeg)


虽然是一次性的，单片价格也小贵（差不多 2.5 元/块），但一块能擦 3~4 个锅底，有刚需的话入手还是不错的。

Ps：用的时候千万记得要戴手套，否则容易伤到手；另外，这款我们买的是德国原版 plazotta 家的 ，PDD 上有类似同款，但是效果没原版好。


![图片](https://mmbiz.qpic.cn/mmbiz_png/rrVVklPTzRArv5CicXrdoEqvH67M836e1aczpOdsHYY2fsicYMedONjkqqicic4nRg0pYG9qcpc70GK2vicLpJdM9Ng/640?wx_fmt=png)


这款的摩擦力和起泡力都很强，有点像丝瓜络，但更加结实耐用。


![图片](https://mmbiz.qpic.cn/mmbiz_gif/rrVVklPTzRArv5CicXrdoEqvH67M836e1m3zibGek1rVHvnice4BWltdY1BwibggABy1s19CQ5ybibYWeojSTu5vMYA/640?wx_fmt=gif)


虽然吸水性差，但用来**洗碗、洗瓜果效果很好**。蘸点水就能轻松擦掉锅盖上的顽固油垢。👇


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/rrVVklPTzRArv5CicXrdoEqvH67M836e1d8bxtQDE9Jm2bhPWXsVHhcFViaTogz5KQkPp7AowrAOicne6EwrCV2ZQ/640?wx_fmt=jpeg)

平时，孩子吃完饭，粘着油渍和剩菜残渣的餐椅也可以用它擦，跟拿去浴室整个冲洗比，简直是事半功倍！

**「一次性抹布」**一般是用无纺布做的，韧性、厚度都比纸巾更高。擦很脏的东西，就它会更方便。

**吸水性、摩擦力**都不错，但不容易起泡，用它洗碗会有点奢侈，擦洗菜池、灶台的水渍油渍更适合。


![图片](https://mmbiz.qpic.cn/mmbiz_gif/rrVVklPTzRArv5CicXrdoEqvH67M836e1NCZO6BAQibxIatMiac7zibRhHAicBld9Cdv6vibScdZP5ahiaqDjtzNbgc2Q/640?wx_fmt=gif)

以上提到的几种抹布，各有优缺点和适用场景。洗碗用木浆棉，擦厨电用鱼鳞抹布，擦光滑器皿的顽固污垢用渔网布，擦锅底用细钢丝，擦灶台用湿巾/一次性抹布……

让它们**各司其职**，把自身的优点最大化，我们提高了家务效率，卫生情况也更加有保障！
