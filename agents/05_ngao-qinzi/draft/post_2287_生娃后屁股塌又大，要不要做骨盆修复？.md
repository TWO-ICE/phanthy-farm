# 生娃后屁股塌又大，要不要做骨盆修复？

除了**变大、变塌**外，还有许多妈妈表示，除了有些疼痛、肿胀等情况，裤子穿不上也很揪心。面对大家急切想要恢复的心情，美容院也针对产后的妈妈们，推出各种**“骨盆修复”**疗程。那，产后骨盆修复真的有必要吗？是不是骗人的？今天，糕妈就来和大家好好唠一唠。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN2cK1zIe55ojico7KibjxUkEmts2u2unwrmfdCbJHkeIqMvOTdknRg7vHJFFPu84psGEP9Y17RiccGVw/640?wx_fmt=jpeg)

在生完孩子后，骨盆确实被“撑大”了一些，胯部往外突了一点点。


但其实，这并不是骨盆的整个骨头变形了，而是骨盆左右两块骨头在前面连接的地方**被撑开**了。

这个连接的地方我们称之为**“耻骨联合****”，**手沿着肚脐那条线往下摸，摸到一个硬硬的地方，就是耻骨联合啦。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/rrVVklPTzRAja8nusJfjKicE4vRjq7WF6oRVL5I0ibicwjPeeKRvMPA660Vic1wRK2M6d6ZcCDh4QUUnNfEteDToicw/640?wx_fmt=jpeg)


这个缝隙里面并没有骨头，而是纤维软骨连接。

在怀孕过程中，身体分泌的激素水平变化让这个地方变松弛，以便在分娩时可以适度地撑开，增大骨盆的内径，这样宝宝的脑袋才能顺利通过。

有的孕妇，在**妊娠后期就会发生耻骨联合分离，**出现症状并持续到产后，主要表现为疼痛，严重者甚至影响行走等日常活动。

**不过，大多数人在产后 3~8 个月后，就会自行恢复，并不需额外做些什么。**

对于大多数宝妈来说，**即使不去美容院做“骨盆修复”，骨盆也会恢复原样。**


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN2cK1zIe55ojico7KibjxUkEmicBJoYFkq24nsRWha656v5TRoLFxMKRwYaeWBEl3na9ukV85Fr5krFQ/640?wx_fmt=jpeg)

一般来说，耻骨联合轻微分离并不会出现什么不舒服的症状，但如果分离过大，就可能引起**疼痛、炎症、肿胀**，甚至**影响走路、翻身、上厕所**等症状。

因此，只要宝妈的耻骨联合处**出现不舒服的症状**，就应该及时去看医生，通过拍片或 B 超检查看看耻骨联合分离的情况。一般来说，分离在**10mm 以内都是正常的**；

分离超过了 10mm，优先采取保守治疗；

分离超过了 25mm，需要根据情况，咨询医生是否需要手术干预。但手术毕竟有创伤，因此有些人即使分离超过 25mm，医生可能也会建议她先保守治疗试试。所谓的**保守治疗**，也就是**使用骨盆束带，同时加强肌肉锻炼**，也会给予一些**止痛消肿**等对症治疗。另外，按摩、冷/热敷、侧卧等让宝妈觉得能缓解症状的办法都可以尝试。所以说啊，一些美容院推荐购买的骨盆束带并不是在骗人，这确实对耻骨联合的恢复有帮助；但是真到了要做“骨盆修复”的地步，建议还是要在医生指导下进行！

耻骨联合分离比较严重的宝妈，尤其是还准备要二胎的，每隔一段时间都需要拍片子检查恢复的情况。

如果耻骨在恢复的过程中错位、上下对不齐，那就麻烦啦。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN2cK1zIe55ojico7KibjxUkEmprNygC2T1u0PiaRJjMJFvMRppCibGz45ibg8WcFv9PNibqOx1e9s53yNQw/640?wx_fmt=jpeg)

耻骨联合分离是每个宝妈都会经历的，但尾骨骨折只有一部分宝妈会遇到。


尾骨骨折真的就比较难受了，坐着也痛，站着也痛，还会影响排便。

如果真的出现尾骨骨折的情况，有些人吃点止痛药（要医生开哦，尤其是哺乳期的话）、卧床休息 8 周左右就好了，而有些人可能就需要手术切除尾骨了。

所以，生娃后尾骨处一直不适的妈妈，一定要及时去看医生。**参考文献：**
