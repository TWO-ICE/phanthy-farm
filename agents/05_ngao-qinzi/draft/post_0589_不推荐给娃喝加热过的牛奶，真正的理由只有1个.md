# 不推荐给娃喝加热过的牛奶，真正的理由只有1个

![封面图](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN2nQic3xnA6VvicTlmAibscxx7aMlyIBMbrTd0jwzPByxcIib8YsbSvh79aFyowZPG3qFOzRUCicwBuZ0Q/0?wx_fmt=jpeg)

天冷了，不少妈妈留言问怎么给娃热牛奶的问题。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/FF2OYjRxqc2NsRkNaWjvpCKMVImIAl09h1YicJKicjRFUoAIyuHhSRMV3V9kA0E3WFCOaiclsohdHyW7MhObXzEMg/640?wx_fmt=jpeg)

到底用哪些方法加热牛奶，营养才不会流失呢？今天给大家一次说清楚，戳视频看看吧~


![图片](https://mmbiz.qpic.cn/mmbiz_png/nuqSmia8OqobpLJM0ExJxSPcbh0ibB6D5I4NBntImzSVAoRW97MWg47zoka5EJJdpoIetyibgKdibrHk8ic9PrSLZLQ/640?wx_fmt=png)

 小贴士：视频播放有声音，如果孩子睡着了，建议戴上耳机或调低音量再看。除了加热牛奶的问题，现在食物中的“科技与狠活”，大家的讨论度也很高。

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/FF2OYjRxqc2NsRkNaWjvpCKMVImIAl09UKLKYJNCwoiagIw35c2fufbrlN5TiaLamUCDI6VMk2SVvrecWpcicCwWQ/640?wx_fmt=jpeg)

之前很火的“海克斯科技”，提到过早餐店**随手买到的草莓奶——既没有草莓也没有奶！**博主分分钟用各种各样的添加剂混合制作出来了👇


![图片](https://mmbiz.qpic.cn/mmbiz_gif/2EaFkYu8ISsqLdRD6ibLG68oRNBovUd5wW4yq8GYXqB6zHozudSP3lt9k3GOT8knwX2nPawThFEh9I2aBSsyD8Q/640?wx_fmt=gif)


咱们的老粉应该都知道，这些所谓的草莓奶、核桃奶、可可奶、早餐奶，都不是什么正经牛奶，一口下去满满的糖和香精。

长期饮用非但不能给娃提供优质的营养，还可能增加肥胖、挑食、龋齿的风险，影响孩子的生长发育。

之前还有更“可怕”的新闻，新手妈妈被母婴店推荐买了一款“奶粉”，**给孩子喝了半年，反而严重缺钙，还确诊了佝偻病！**


![图片](https://mmbiz.qpic.cn/mmbiz_png/2EaFkYu8ISsqLdRD6ibLG68oRNBovUd5wRWQq3G2gUQJbV0N4Vo4XXq46mLokUnu5htVjgMdcgbg9sMUSgIUtpw/640?wx_fmt=png)

▲图片来自湖南都市频道医生检查了宝宝的奶粉才发现，这款“奶粉”虽然名叫“蛋白粉”，冲泡出来也有奶香，其实生产商罐体小字写着**“蛋****白固体饮料”**。配料表上都没有生牛乳，根本不是什么牛奶！


![图片](https://mmbiz.qpic.cn/mmbiz_png/2EaFkYu8ISsqLdRD6ibLG68oRNBovUd5wbbJxMnmuzgHzTwLyy9r0oOBK5jwsTmFHV8GVcXjNSAkFbffIU46CZQ/640?wx_fmt=png)


▲图片来自湖南都市频道

其实，给孩子选牛奶很简单。一般来说，正规渠道购买的，**选择配料表有且只有****“****生牛乳****”的一般不会错。**

除了加各种添加剂的“假奶”，现在市面上又出现了各种听不懂的新卖点，什么高钙奶、超滤牛奶、娟姗奶、水牛奶，五花八门什么都有。👇


![图片](https://mmbiz.qpic.cn/mmbiz_png/2EaFkYu8ISsqLdRD6ibLG68oRNBovUd5wAUpd895r9zklicT6JcbV16KAYUwia8RRLuKiaEMR8gNlmdhpFm2M0M6Cw/640?wx_fmt=png)

这么新多概念，到底值不值得多花钱呢？除了“生牛乳”这个标准之外，**如果咱们想给娃挑更好的奶，该选哪些呢？**今天就来和大家全部讲清楚。

妈妈们放心食用，全程硬核科普，保证绿色无广~


![图片](https://mmbiz.qpic.cn/mmbiz_png/FF2OYjRxqc3vWXRe9GdiaiaqjJ4mGFezSvdKy6RdDdAtJ6LG0h9qQibxibJ3lAuFs4KDLbUParBamLpaFX0PpiaXFibQ/640?wx_fmt=png)


![图片](https://mmbiz.qpic.cn/mmbiz_png/2EaFkYu8ISsqLdRD6ibLG68oRNBovUd5wcaHZ09x3ibTKYKFINWJib76mMibTcmYONB7Xrxnj38zuS96AEibXdZw0gA/640?wx_fmt=png)


蛋白质和钙，是咱们喝牛奶主要摄取的营养物质。

要选蛋白质和钙含量高的奶，方法很简单，直接看营养成分表就可以了。

一般来说，**蛋白质含量 >2.9g/100g、钙含量 >100mg/100g**，就是含量不错的了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/2EaFkYu8ISsqLdRD6ibLG68oRNBovUd5w1ndxtvPWKheaYy5XvybiaYqHH19eficMHibqlzpdlOyHlB5VDBEdcm91Q/640?wx_fmt=png)

▲成分表优秀的奶蛋白质和钙含量可达 3.6g/100g 和 120mg/100g 以上。

不同产地/品种的牛，产的奶中营养物质会有差异。此外，通过特殊工艺，比如运用**超滤技术**、**添加营养强化剂**，也可以达到提升蛋白质、钙或其他营养元素的目的。

这类营养密度更高的牛奶，**更适合胃口小的宝宝**，保证吃得少也能摄入相对多的营养。


![图片](https://mmbiz.qpic.cn/mmbiz_png/2EaFkYu8ISsqLdRD6ibLG68oRNBovUd5w68w8icorc6aRlhSFQ70UuNbS049ia2dzUJzcEEB6w5FlyRkMHLz0y0Ig/640?wx_fmt=png)

▲左图为超滤牛奶，右图为高钙牛奶。


![图片](https://mmbiz.qpic.cn/mmbiz_png/2EaFkYu8ISsqLdRD6ibLG68oRNBovUd5w2eqehSStSwl1nYuHhrBpMSe0IQfExkGX1y4ds9ibrJ0JDl57ef0ltkg/640?wx_fmt=png)


![图片](https://mmbiz.qpic.cn/mmbiz_png/2EaFkYu8ISsqLdRD6ibLG68oRNBovUd5wX3nk5fibIQOe00kTf7pia8eGzOrniaEJzSXWMaLVYSYudud0ZBiaU6QWqw/640?wx_fmt=png)


牛奶之所以被公认为“营养好”，不仅是因为它含蛋白质、钙、脂肪、碳水化合物，还有各种你想不到的营养：


![图片](https://mmbiz.qpic.cn/mmbiz_png/2EaFkYu8ISsqLdRD6ibLG68oRNBovUd5w2Aticiatqs4MneeXAhFaaypq1FRcnDvfkCMfia0uGLpQwBZiclrKDibl6eA/640?wx_fmt=png)


但并不是所有牛奶都能把上面这些营养保留下来。刚挤出来的牛奶营养成分是最全的，奈何里面除了营养，细菌也各种各样。（所以妈妈们千万别给娃买那些刚挤出来的生奶啊！）

所以需要经过杀菌这一道工序把细菌含量降下来。这道工序同时决定了牛奶中营养能保留多少，尤其是牛奶中的活性物质和部分的维生素。

一般来说，超市冷鲜柜里卖的**低温奶**（巴氏杀菌奶等），会比常温（超高温灭菌奶）保留的**活性物质更多，不过价格也会相应更高**。


![图片](https://mmbiz.qpic.cn/mmbiz_png/2EaFkYu8ISsqLdRD6ibLG68oRNBovUd5wXgINaWTiaZYnfEsAqFLNUksFYLkB5HEanDn0xEurJXpF4SiaxJ1ibqkPw/640?wx_fmt=png)

▲低温奶和常温奶，在一般大型超市里都能找到。

提醒妈妈们一下：有一些商家也会把本可以常温保存的超高温灭菌奶放在冰柜里卖，以此抬高价格，妈妈们选购时擦亮双眼，**瓶身注明“巴氏杀菌”才是低温奶**哦~

![图片](https://mmbiz.qpic.cn/mmbiz_png/2EaFkYu8ISsqLdRD6ibLG68oRNBovUd5w0GXibbicum4Gj14ZwnlnE8PUw5fia73vDxwezR7HqGuhuOO3dhibD7ib62A/640?wx_fmt=png)

▲选购低温奶时，妈妈们可以挑明确写有“巴氏杀菌”的奶。不过现在市面上也有一些新一代巴氏杀菌奶，可能会标有“超瞬时杀菌”等字样，它们也是“真”低温奶。

![图片](https://mmbiz.qpic.cn/mmbiz_png/2EaFkYu8ISsqLdRD6ibLG68oRNBovUd5wkiaUXrVewian9XrPibiavCF9XEXjeicf9Ip6WfwYTjNymYuqNaib44xUlnibA/640?wx_fmt=png)


![图片](https://mmbiz.qpic.cn/mmbiz_png/2EaFkYu8ISsqLdRD6ibLG68oRNBovUd5w6vzbgpGqBGsbgyibPxLbNrDsgGurrSiah5vd0h1DjibXGT8sgl8ibbG3CQ/640?wx_fmt=png)


牛奶的营养非常全面，价格又相对实惠，是宝宝成长期性价比超高的口粮。

但有些妈妈却不敢给娃喝，因为有的娃喝了牛奶容易肚子不舒服。

除了一小部分娃肠道比较敏感，牛奶中这两种东西会让特定的宝宝拉肚子——

**乳糖：**乳糖是奶制品中特有的碳水化合物。但是当宝宝肠道里的乳糖酶缺失或不够时，摄入大量乳糖就会造成腹泻、胀气等症状。这类宝宝可以试试市面上的 0 乳糖牛奶。


![图片](https://mmbiz.qpic.cn/mmbiz_png/2EaFkYu8ISshuhXbNxBP8kqRt5ibqosAoYzpfQoZy7tPaciczKiakbOaA7iaQsWFLRRI0E6coKyaGvyMPXthawdWrA/640?wx_fmt=png)


**蛋白质：**另一类宝宝喝牛奶不舒服是因为对蛋白质过敏，可能的症状有湿疹、腹泻、气喘、呕吐等。其中一部分宝宝是对牛奶中的 A1β 酪蛋白过敏，可以试试市面上含 A2β 酪蛋白牛奶。（但 A2β 酪蛋白并不一定对所有牛奶过敏的宝宝都有用哦~）


![图片](https://mmbiz.qpic.cn/mmbiz_png/2EaFkYu8ISsqLdRD6ibLG68oRNBovUd5wdPIFYDmMroHGlXNkF1q2hkoS6ocGbibnddZDqmy8icLwBZYo3AHibQbsw/640?wx_fmt=png)

▲左图为无乳糖牛奶，右图为 A2β 酪蛋白牛奶。


![图片](https://mmbiz.qpic.cn/mmbiz_png/2EaFkYu8ISsqLdRD6ibLG68oRNBovUd5wA2wK75PMqaoERRpyUoPpGtpVNZTVREaLOXblITciaexuXLMHkNVqETA/640?wx_fmt=png)


![图片](https://mmbiz.qpic.cn/mmbiz_png/2EaFkYu8ISsqLdRD6ibLG68oRNBovUd5w3BpHMWk9lkTBONM5rtibl2jrbfU2ZAcib2vAUUluISp46Hcse82UK8wQ/640?wx_fmt=png)


常常有妈妈会问，宝宝不爱喝奶怎么办，多吃其他的乳制品（比如酸奶、奶酪）是一个方法，也可能是因为宝宝试过的牛奶不好喝。

同样是纯奶，味道差别还是挺大的。

味道不同，一是因为牛的品种不同。

除了**最常见的奶牛荷斯坦牛**，市面上还有**娟姗牛**、**水牛**产的奶。


![图片](https://mmbiz.qpic.cn/mmbiz_png/2EaFkYu8ISsqLdRD6ibLG68oRNBovUd5wcV3PqfKiaPV8vw85PEgEdxZ1BSnfYB1Wg0ndXdKbDtmIbHAmNQzhnOA/640?wx_fmt=png)

▲从左至右分别是：荷斯坦牛、娟姗牛和水牛。

编辑部尝过这类奶的妈妈说，味道确实不太一样，口味更清甜，奶香更浓郁，大家感兴趣的可以买来试试~


![图片](https://mmbiz.qpic.cn/mmbiz_png/2EaFkYu8ISsqLdRD6ibLG68oRNBovUd5wUo4uD52icDjXtVNZ8FZ8YASV2WyjenbO7OxtGqqVDlIYfLfm5NdqjJQ/640?wx_fmt=png)

▲左图为娟姗奶，右图为水牛奶。除了品种不同，养殖的地方不同、饲料不同（比如谷饲或草饲），产的奶的香味、口感，甚至颜色都会有差异。

这两年一些**地方品牌的小众奶**纷纷出了圈，除了新疆奶，云南、青海、贵州等很多地区都有特色的地方奶品牌。


![图片](https://mmbiz.qpic.cn/mmbiz_png/2EaFkYu8ISsqLdRD6ibLG68oRNBovUd5w7u2H68VpkOlzNEhrqZ54qyBxUqv9jf72AdibWicNj3Ustf2PNBLEg4Qw/640?wx_fmt=png)

▲来自新疆和千岛湖的奶。

不过，悄悄地说，我们发现，那些口感好的奶**脂肪含量往往也很高**，想要控制体重的妈妈们要小心这些“牛奶刺客”哦~


![图片](https://mmbiz.qpic.cn/mmbiz_png/2EaFkYu8ISsqLdRD6ibLG68oRNBovUd5wdeDshVssf710kQuick6h8kBJ9zaRGfLD7OFIeFNicq2gfRq7I0R46bxA/640?wx_fmt=png)

▲某品牌水牛奶的脂肪含量有 4.0g/100g，大家可以拿家里普通的纯牛奶比较一下。


![图片](https://mmbiz.qpic.cn/mmbiz_png/2EaFkYu8ISsqLdRD6ibLG68oRNBovUd5w2kKHXeZAtUR2lrZRJlnIswDBoCFUkrD949FSuaWAIoZDt9GRicGsX0A/640?wx_fmt=png)


市面上的牛奶花样越来越多，厂家能不断更迭技术，给宝贝们带来营养更好的美味当然是好事。不过，作为一个普通妈妈，**我们的希望不过是挑到安全、健康、孩子爱喝的几种奶，换着买就够了。**那 10mg 钙含量的区别，倒也不是最重要的了~

大家平时都是怎么挑牛奶的呢？有什么娃特别喜欢的牛奶种类吗？欢迎评论区一起聊聊吧~
