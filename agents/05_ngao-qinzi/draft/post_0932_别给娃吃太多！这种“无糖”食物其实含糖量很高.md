# 别给娃吃太多！这种“无糖”食物其实含糖量很高

![封面图](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN3WhPibKu7d7IcKcdeQO5iaicRNuQbHyjkicgn1opAV14KUM2dZSibMkVUqw9eALwqba9mckBTBZ8cm3fg/0?wx_fmt=jpeg)

各位新手爸妈，今天是**世界糖尿病****日**，新闻和微博热搜上挂了好多科普！不过大家可能都忽略了一点：觉得糖尿病是老年病，和咱孩子没啥关系。

这还真是大误区哦~前不久微博上就有一则**“2岁宝宝确诊糖尿病”**的新闻。是不是吓一跳！怎么？小宝宝也会得糖尿病？

![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN3WhPibKu7d7IcKcdeQO5iaicRDic7ue704yticz5zOjmFvR1IcUdo4ok3WXUhe7qmkStkGKUBGYocJia5A/640?wx_fmt=jpeg)

可能不少姐妹的第一反应都是，是不是糖吃多了导致的？自己平时一心软就让孩子多吃了点糖，会不会也有事啊？****

想先让大家放宽心，新闻里这个宝宝年龄太小且发病重，考虑应该是** 1 型糖尿病。**目前医学界对于病因还没有定论，可能是和自身免疫、遗传等因素有关，和糖的关系不大。**吃糖顶多是加重了结果，让血糖高的症状显现了出来。**

但大家也别忘了，糖尿病还有** 2 型**呢，这种病可就跟糖有点关系了。比如**糖吃多了容易胖，营养过剩会大大增加以后患糖尿病的概率。**而这些年，儿童糖尿病里 2 型糖尿病的发病率已经明显增加了。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN3WhPibKu7d7IcKcdeQO5iaicR2sLCLqcMq80icCsNNOmp9CoSVKspPicicktgER70ke1LG20CqZkAbw9icg/640?wx_fmt=png)


吃糖太多肯定不是啥好事，但糖的**甜蜜诱惑**，连大人都很难把持住，更不用说孩子了。随着娃慢慢长大，接触的口味越来越多，还有小区其他家长的分享、亲戚朋友带着买等等，很难做到完全避免所有糖。****

那作为家长，我们更需要把握的是，**哪些是好糖，适量控制不用担心；哪些糖吃多了对娃健康不好**。尽量用“好糖”替代“坏糖”，减少孩子整体的糖摄入量。

接下来，咱就和大家唠一唠，怎样给娃**“有效控糖”**~（文末还有**好糖坏糖对照表**，可以先收藏，下次给娃买吃的拿出来对照看看）👇


![图片](https://mmbiz.qpic.cn/mmbiz_png/rrVVklPTzRAahicfjHnJAvUurQby8yFCSuobFJmsd8quJlUZGnfHKmqcLIsWkbrzWxsfcSdadmGOmsEhRnHUsag/640?wx_fmt=png)


不少商家都会宣传【无糖】，显示自己卖的东西健康。

但其实根据国标规定，只要**糖含量 ≤0.5g /100g（mL）**，就可以叫**【无糖】**了，类似的说法还有**【不含糖】【零糖】【0 糖】【0% 糖】【没有糖】【100% 不含糖】**。

在营养成分表中，糖含量也可以标注为 0👇


![图片](https://mmbiz.qpic.cn/mmbiz_png/rrVVklPTzRAahicfjHnJAvUurQby8yFCSqNxJrrvcwcIraLoksj6FQ9kFAaKtLbHnOTZbntZ4l7krAQzUvH3Vkg/640?wx_fmt=png)


虽说这样低的糖含量，确实不用太在意。但有些商家利用消费者的不了解、故意用这些说法进行诱导，又是另外一回事了。

类似的还有【0 蔗糖】，也有一部分是商家玩的“文字游戏”。因为蔗糖只是添加糖里的一种，**不含蔗糖，不代表不含其他的糖**。

当然了，不少标注【无糖】【0 蔗糖】的食品，也确实做到了没有添加糖。


![图片](https://mmbiz.qpic.cn/mmbiz_png/rrVVklPTzRAahicfjHnJAvUurQby8yFCS8rvtxnWDX5CEKT4PMSjXibFJDJCErI9jcLwXQjiag1C9cD5dlbbUcRjg/640?wx_fmt=png)

上面提到的 “坏糖”，当然要尽量让孩子少碰。

美国儿科学会（AAP）建议，2 岁以内的宝宝要远离有“坏糖”的食品，英国国家医疗服务体系（NHS）网站更是把这个标准提高到了 4 岁。

但话说得轻巧，当了妈就知道，现实中要做到这些，真的太难了。

除了它俩，还有一类 **“低聚糖”**，和前面提到的抗性糊精、*β*-环状糊精一样，都属于**膳食纤维**的范畴，是名副其实的“好糖”。

名字大多遵循**“低聚 X 糖”**的格式，也有些比较特殊👇


![图片](https://mmbiz.qpic.cn/mmbiz_png/rrVVklPTzRAahicfjHnJAvUurQby8yFCSjnupAsq7vRjvEsL2M8Yhl9u9iayfRHTtzrB0jLpFPD4r4Pbb6Z5VibVw/640?wx_fmt=png)


在它们之中，还有些被冠以另一个大家熟悉的名字——**“益生元”**。


![图片](https://mmbiz.qpic.cn/mmbiz_png/rrVVklPTzRAahicfjHnJAvUurQby8yFCSqsVUdhMUgI37Jcic647dewxxj3RQAywQicLEnBA9QHQWWJhl7AVrayaQ/640?wx_fmt=png)


另外，一些不容易被人体消化的**多聚糖**，比如**聚葡萄糖**，也属于“好糖”哦。（PS：“好糖”虽好，但也要适量吃，一次吃太多容易引发胀气）


![图片](https://mmbiz.qpic.cn/mmbiz_png/rrVVklPTzRAahicfjHnJAvUurQby8yFCSyOQl3lul7PE9IH0gHcQyiaQmVZKXUaxnK2rxicA4IkkrVBnMnzbUWqWQ/640?wx_fmt=png)


大家熟悉的**木糖醇、赤藓糖醇、异麦芽酮糖醇（艾素糖）**，它们都属于**“糖醇”**，算是糖的亲戚，但不属于糖。

糖醇很难被人体吸收，如果一次吃太多，容易引起腹胀、腹泻。

有些糖醇能帮助预防蛀牙，所以在牙膏的成分里会看到它们。


![图片](https://mmbiz.qpic.cn/mmbiz_png/rrVVklPTzRAahicfjHnJAvUurQby8yFCSLuic1dCYyVXHiaZUTpkXgVmVL8iaH32cMS1pRn6bQspwgZsZ9Acwgq9rQ/640?wx_fmt=png)


往大了说，糖醇属于**甜味剂**的一种，它还有个大家更熟悉的名字——**代糖**，现在风很大，经常用来代替白砂糖。

**糕妈说：**

年糕刚刚添加辅食的时候，我就像一个精密的计算器，严格控制着他的糖分摄入：

先把蔬菜吃完，才能吃水果；从来不给果汁，也从来不在辅食里加糖；酸奶只买绝对无糖的……

然后呢？到了 3 岁这一年，他口齿伶俐地对我说，“妈妈，我最喜欢甜的味道”。

我终于认清了一个现实：**全世界的孩子都爱吃甜食，我的孩子也不例外**。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/rrVVklPTzRAahicfjHnJAvUurQby8yFCSib2DlxFVDkQlfHkfWklMWHULibpP6WJVV5EVomzmiaxC9CIEibRmicuUUaA/640?wx_fmt=jpeg)


无论一开始吃的是什么，无论我如何引导口味，如何尽力将他隔离在非甜食地带，年糕对甜食的热情根本挡不住。

于是，我默默给自己、给全家定了一个准则：**不放纵、不严禁**。

我也想告诉大家：**不用因为给孩子吃了点 “坏糖”，就觉得自己成了“坏妈妈”**。

毕竟，哪个孩子不吃糖呢？
