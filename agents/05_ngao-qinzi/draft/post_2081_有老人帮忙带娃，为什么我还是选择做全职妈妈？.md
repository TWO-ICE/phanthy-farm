# 有老人帮忙带娃，为什么我还是选择做全职妈妈？

![封面图](https://mmbiz.qlogo.cn/sz_mmbiz_jpg/tGtmpweWiaN1OQSfP0Rfj7mFWHjU2JdiabYauFKRUxlmD0U8LuWawSvibWHp6j2S7ZoV6xNtMNM8NYWicVWwhCqOZA/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/wl5wGQiG7SYDMQKAtLhvjA

**全职妈妈 or 回归职场？**这是妈妈们在产假休满之后都会纠结的问题。

阳妈也是其中一员，现在她已经全职 3 年了。

全职的生活显然没有那么容易，面对着亲妈的责怪、朋友的不理解、自己的迷惘，到底该怎么做才能处理好这一切呢？

今天，就让阳妈聊一聊她的全职经历。作者：阳妈，3 年前辞职带娃，带着阳宝旅行的过程中，把爱好发展成了事业，现是一位旅行作家。

在我决定全职后，除了阳爸，全世界的人对我这种行为都不能理解。
先是在小区楼下遛娃的老人，他们知道我不上班后的那种惊讶，**好像亲妈是最不应该带孩子****的人**。友人在得知我全职后，苦口婆心**“哪有这么年轻就不工作的”“小心和社会脱节”。**

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/nuqSmia8OqoYwXq4AqgxbI4WcSicGWw5K5KR3qjRaOmDGct4C87v98cvoV3xxhEddRB0PSmDFtu14kO4WUVNC2mg/640?wx_fmt=jpeg)

接着家里人挨个劝我复工：*谁带不是带，孩子吃好睡好就行，妈妈带不见得比老人带得好。**年轻人嘛，就应该有个稳定工作，哪怕收入微薄，哪怕工作不是自己喜欢的。*短短一年时间，被介绍了好几份工作。这些都不足以让我心生困扰，只是我妈数次的话让我没忍住心伤。妈妈感叹，曾经优秀的女儿被圈进了家事的琐碎和无望的未来里，**读了多年的书，最后选择了当家庭主****妇**。我多次解释只是想要全身心的陪伴阳宝这几年，未来有自己的打算，仍无济于事。妈妈的担心，也是对我的不信任。遇到这些阻碍后，本来信心满满的我变得很沮丧，觉得自己为了孩子，为了这个家做出了牺牲，于是经常和阳爸抱怨。阳爸没有责怪我，一边努力做全家人的思想工作，一边给我加油鼓劲，**选择全身心陪伴孩子的童年，这件事本身并没有错**。阳爸用行动，让我从容了许多。

《奇葩说》有一期讨论过这个问题，**高学历女生做全职太太是浪费吗****？**
当时艺人寇乃馨这样说：“你们认为什么样的人能当全职太太？不读书的么？学习差的么？没能力的么？特别笨的人么？我们应该给所有的全职太太道歉。国家栽培人才是让我们做有用的人，高学历能力强的人看似应该承担难度较高的工作，社会的误解在于我们一贯赋予**全职太太的标签：****低学历、平庸、邋遢、世俗**。实际上，全职太太的难度并不低于职场女性，她背负着养小孩、顾老公、维持家庭和睦的责任，她更是成功男人的幕后推手，成功时的报警器，低落时的心灵支柱，全家人亲密关系的粘合剂，身兼数职运筹帷幄，**只有有能力的人才能做好一个全职太****太**。”她的这段话很打动我。

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/nuqSmia8OqoYwXq4AqgxbI4WcSicGWw5K5icTKYFRUwYeNrGib4SsWvU9LpLxAvltvXAVCNoIibtiaQY0Vk30etTqjzg/640?wx_fmt=jpeg)

没生娃之前，我也曾对全职妈妈抱有偏见，觉得那是丧失自我的表现。当时还信誓旦旦地表示，有了孩子之后，一定要工作家庭两不误。
我知道是难的，但我想是能的。显然这样的想法太过天真，**孩子出生第一年所面临的种种慌乱，让我连自己都没有心力去****打****理**。这时我才明白，女性在成全自我和做个好妈妈之间总在自我撕裂。**

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/nuqSmia8OqoYwXq4AqgxbI4WcSicGWw5K5QBKEEaor3AxE64Qkz7178rmSd7z2CYEics0jQljwib7fr7afNibBibRyrg/640?wx_fmt=jpeg)

**每个家庭都面临着不同的问题，家里老人无法帮忙带孩子、不放心保姆养育、经济条件无法承担保姆费用等等。这个时候，家庭的选择往往是舍弃妈妈的工作，这是一个残酷又自然的现实。那场辩论中，女作家柏邦妮说出了每个妈妈们的心声：*“我们中国女人累不累呢？其实是非常累的，因为女人出去工作了，但男人并没有回归家庭。我们的事业女性，如果还有一个家庭的话，等于打了两份工，（所以）你要尊重，你要感谢。”*


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN1OQSfP0Rfj7mFWHjU2JdiabJe3eNeSKWG3YN2OPVWXkvgBHvCNJscurOzY9VR9abzxiauLhbx0WdIA/640?wx_fmt=png)


人生处处在舍得之间，失去一些，便是得到另一些。
选择全职之后的我，一路的成长也显而易见。从初为人母的慌张焦虑，到欣然享受陪伴孩子，我不仅是照料者，也是观察者。顺应大运动发展、理解婴语、捕获孩子的情绪......就像余光中先生所说：人的一生有一个半童年。一个童年在自己小时候，而半个童年在自己孩子的小时候。**阳宝就带着我经历了早已没有了记忆的童年，他带着我进入了一个全新的世界。****

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/nuqSmia8OqoYwXq4AqgxbI4WcSicGWw5K5eMnMPJHAmVuodkOkvTLaWBIVotQAmuJq7iabm4tzJu9F4FjMibic8GyTQ/640?wx_fmt=jpeg)

**当然我不是完美妈妈。这一路走来，也经历了许多困苦、焦虑，犯下了不少错误，可是孩子从来没有责备，全是接纳。时时感受他无条件的爱和信任，也让我对母亲这个角色越来越得心应手。尤其在阳宝一岁以后，他让我的全职时光变得更加多彩。**我们做彼此都喜欢的事情，亲子游戏，共读绘本，外出游玩，每一天都很充实。**

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/nuqSmia8OqoYwXq4AqgxbI4WcSicGWw5K5A0VSpuoBS7DnlX8ic58rpDnoakBehrzVWbYe2GbrLxpDYx46stibYv3Q/640?wx_fmt=jpeg)

多出的大量时间也可以做自己喜欢的事情，旅行、看书、写字、育儿，从一个圈跳到了另一个圈，认识了许多优秀的全职妈妈，从她们身上学到了许多。更重要的是，全职后我们和长辈关系很和睦，很多家庭头疼的婆媳矛盾，在我家几乎没有出现过。他们不会对我们的生活方式指手画脚，育儿理念也都以我为主。**很难说，全职是一种牺牲还是一种收获。****

《中国社科院相关部门发布首份二胎家庭亲子关系报告》

看完这份数据，我还是蛮震惊的。想用自己的亲身经历告诉大家，即使全职这条路看起来没有那么糟糕，也**不要盲目自信，毕竟****这份工作并不轻松。**
你的工作对象是孩子，一年 365 天，每天 24 小时你需要随叫随到，总有处理不完的事情和做不完的家务，连病都不敢生，每天像陀螺一样，转个不停，依旧觉得时间不够。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/nuqSmia8OqoYwXq4AqgxbI4WcSicGWw5K5WDmnwcPfVp6x1ZvU3r1KZyKrlfTphnuuXZDib5XBfPqMTdeNx2Muarg/640?wx_fmt=jpeg)

除了体力上，心理和意志也面临巨大的挑战。
“经济不独立、放弃自我、坐享其成”，外人总是对全职妈妈抱有着误解。特别是和你同龄的人已经做到了经理、总监，事业风生水起的时候，心里或多或少会有一些落差感。**同样是职场，全职妈妈这份工作的价值并没有那么容易评****定。****

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/nuqSmia8OqoYwXq4AqgxbI4WcSicGWw5K5VHC09p2f3bRmAacBajqmY049qsjOML7ufXnajRKAI49KDaSunKpAYg/640?wx_fmt=jpeg)

**全职这条路上，没有应该或是不应该。不是做了就没有遗憾，也不是不做就会后悔。**不是只有全职，才能当一位好妈妈；也不是全职了，你就是位好妈妈**。千万不要让全不全职这件事变成对孩子、对自己的绑架。只有想清楚这一点，几年的全职时光才能既给了孩子更成全了自己。最后，用马东老师的话共勉吧。

“在人生的大尺度上，

没有浪费这个概念。我们经常会说，我跟那个人谈了三年恋爱，结果他是个王八蛋。回想起来，我人生是浪费的但你怎么假设你的人生没有那三年？你怎么假设你的人生不会浪费在另外一个王八蛋身上？你还常说，我找了一份烂工作那是一个烂公司我在那个公司工作了四年，我是浪费了我的四年，你怎么知道？所以在人生尺度上，没有浪费这件事。如果人生没有浪费，我们怎么说高学历女生做全职太太，是一种浪费呢？在这个尺度上，不是浪费，甚至‘浪费’这两个字都无从谈起。”


![图片](https://mmbiz.qpic.cn/mmbiz_png/z7kZjMoQ3yFLKRyWrA62tSbYnsSufDuMI41bUib3kwCQTG3J0o4cRziagH1SGCIR8dkFSg1Q3k2d9y8sXcicsiby8Q/640?wx_fmt=png)

其实无论全职还是工作，**作为妈妈我们都很容易对自己和生活不满意。**美剧《大小谎言》里的几位妈妈就是这样：女强人觉得自己对不起孩子、对不起家人；全职妈妈就觉得自己是个只能在家带孩子的、一无是处的家庭妇女。这个时候怎么办呢？我觉得，**最重要的是，妈妈们一定要学会和自己和解。**这个“和解”就是**不要和别人去比**，全职妈妈比收入、职场妈妈比陪孩子的时间，都只能让自己更拧巴。 全职妈妈就一定会和社会脱节吗？职场妈妈就一定带不好娃吗？回想自己过去几年的经历，我觉得我全职的那段时间，并不会觉得因此就落后了多少；现在工作很忙，我也并不认为自己就没有带好孩子、需要对他心存愧疚。**生活不是竞赛、也没有对错，你只要找到自己最重要的事情，把它做了就好了****。** 至于别人说什么，其实并不重要。
