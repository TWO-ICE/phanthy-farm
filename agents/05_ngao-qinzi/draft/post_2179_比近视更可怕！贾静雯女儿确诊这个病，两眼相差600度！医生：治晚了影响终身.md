# 比近视更可怕！贾静雯女儿确诊这个病，两眼相差600度！医生：治晚了影响终身

姐妹们，你家娃的视力还好吗？现在大家普遍都比较关注近视、散光，但 **6 岁前更值得关注的问题其实是——弱视！**贾静雯之前就晒出：从小有着一双灵动大眼的女儿咘咘，5 岁时竟查出有先天性弱视，而且小姑娘自己完全没感觉，好在没有错过 **3~6 岁的黄金治疗期**。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/FF2OYjRxqc0v98bheywqICD90ysBpQwfnVicVRxtTeelrRkxc8ibvvkWku77wdhVovjU4gl9Etlj0nTX8LeYnCVw/640?wx_fmt=jpeg&from=appmsg)

是的，**弱视比较难发现，但大部分可以治愈，年龄越小、发现越早，治疗效果越好**。今天就来跟大家详细说说：*弱视到底是怎么回事，和近视的区别在哪？**如果孩子有弱视，如何尽早发现和治疗？**
*

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/FF2OYjRxqc0v98bheywqICD90ysBpQwfZptmpQwnib0yCJdy9F6oXLkYO2Mdg2nvrciciaBvI1en3DbyYRdibAyYmw/640?wx_fmt=png&from=appmsg)

从某种程度上说，**弱视要比近视更危险**。近视的孩子，视觉发育是正常的，只是因为眼球结构发生改变，导致看不清东西，但戴上眼镜就能看清了。而**弱视的本质是大脑视觉中枢发育异常**，把眼睛看到的东西给“屏蔽”了，戴再好的眼镜，视力也不会马上恢复正常。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/FF2OYjRxqc0v98bheywqICD90ysBpQwfAOlswhN5pHnOeCdznEuvcWy4oBjMVb73BwHBZcl25sMKwZ0WmFmc9Q/640?wx_fmt=png&from=appmsg)


但反过来说，不管任何年龄，近视一旦发生，就没办法治好了；而弱视则不同，**3~6 岁的治愈率能达到 80 % 以上**。偏偏弱视隐藏得比较深——**因为****弱视的孩子可能从来没看到过“真正”的世界是什么样**，会以为自己一直以来看到的就是“正常”的。尤其是**单眼弱视**的孩子，因为另一只眼睛是正常的，更不会有太大感觉。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/FF2OYjRxqc0v98bheywqICD90ysBpQwfP4oRwTLT3gM1ZfDXbcRRfwsic7WSFj7z4Uf0z2S4ZWwicicFanYDbXHNw/640?wx_fmt=png&from=appmsg)


随着年龄增长，弱视的症状可能会逐渐显现——比如**对空间距离判断不准**，容易磕碰、撞东西，甚至影响日常走路活动；长期依赖另一侧“好眼”，更容易**视觉疲劳、头痛**......但等到有这些表现的时候，往往已经错过了最佳治疗时机，对以后考驾照、选择职业等等都会有影响。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/FF2OYjRxqc0v98bheywqICD90ysBpQwfQHBnkpu6NMRV66g2tYAoP2bxLrsB3j2YmxLPILNKLw1fXPibFEbnCKQ/640?wx_fmt=png&from=appmsg)

引起弱视的病因，比如高度远视、散光等，大多和基因有关，**无法直接预防，关键在于早发现、早治疗**。筛查弱视最简单的办法是看视力表，**满足下面 3 条中的任意一条就要去医院检查了**：

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/FF2OYjRxqc0v98bheywqICD90ysBpQwfaXudThdTURyqdmuuqEjo3ia9ZHLYxgvALC7xLKQicDmHxHmTFxe3Xibfg/640?wx_fmt=png&from=appmsg)


不过咱们同事*@稻壳* 用自己的血泪教训告诉大家：**不能太相信孩子的视力表检查结果**：“
小时候查视力阴差阳错测了 2 次右眼。后面不想暴露自己看不清，眼罩故意不挡严，就这样**到了 10 岁才被发现左眼弱视**。这么多年我一直都是用右眼看东西，从 1.2 的视力一路被拖累降到了 0.5。
”


总的来说，光测视力有可能不靠谱。除了幼儿园、学校里的常规体检，还是建议**定期带娃做全面的视力筛查**（一般 3 岁内在社区儿保就可以），**有可疑异常及时到眼科专科就诊**，必要时散瞳验光，确定是否有弱视。存在弱视的孩子，背后往往是由**斜视、高度远视、散光或者其他眼病**引起的，彼此之间还可能叠加。比如据贾静雯透露，咘咘双眼有 600 度的视差，大概率应该属于**屈光参差性弱视**。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/FF2OYjRxqc0v98bheywqICD90ysBpQwfsfcFR7AuMUmAcy1LrgHTeL4NuXb35Q3ZJyDS1th4e1XdoWmlcyzr6A/640?wx_fmt=png&from=appmsg)


虽然弱视无法直接预防，但**如果能赶在发展出弱视之前，尽早发现这些病因，并且及时进行干预，也是有可能避免弱视的发生的**。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/FF2OYjRxqc0v98bheywqICD90ysBpQwf03XqpictfT1xTmofzIKhTKsEvCyzGf2B4dKbGuN6bGDLm2xnoBHW5Cw/640?wx_fmt=png&from=appmsg)

除了比较严重的弱视（比如形觉剥夺性弱视）可能需要手术治疗外，其他大部分弱视的治疗，还是得交给时间。治疗方法可以简单总结为——**配眼镜、戴眼罩、滴眼药、玩游戏**。**✅配眼镜**和近视一样，弱视治疗也需要戴眼镜，目的是**矫正屈光不正**，也就是解决引发弱视的高度远视、散光等问题。**✅戴眼罩、滴眼药**如果孩子是单眼弱视，往往会越来越依赖另一只“好眼”，让弱视眼越来越“弱”。所以在配镜的基础上，还需要其他手段来**“强迫”孩子锻炼弱视眼**，比较常用的有：

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/FF2OYjRxqc0v98bheywqICD90ysBpQwfheN2CrRtoGAyfBwWk89t6XlIWLUibzWU8U0yXo0g2F6R90lcKZDTtnw/640?wx_fmt=png&from=appmsg)


使用遮盖疗法的孩子，**最常遇到的问题是被其他小朋友嘲笑“独眼龙”“海盗”**，导致不愿意继续戴眼罩了。咱们需要跟孩子讲好：现在戴眼罩，是为了以后不变成真正的“独眼龙”；同时最好和老师打声招呼，向同学们解释清楚，遇到开不合适玩笑的孩子及时制止。**✅玩游戏**想要让弱视眼追上发育进度，有时候只靠日常用眼可能还不够，需要适当**“加练”**。比如有一种做法是戴上眼罩，仅靠弱视眼串珠子。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/FF2OYjRxqc0v98bheywqICD90ysBpQwfIQoVUtTVibMHIlotGZD1452ruCMsoC48zZcBQAb3ibBeSwdQ2Bx81v5w/640?wx_fmt=jpeg&from=appmsg)

但天天这样下来，孩子很容易腻，可以把弱视眼的锻炼融入到孩子的日常活动中：比如**描红本、看书、写字、画画，甚至适当看看电子产品**都是可以的。不管用的是哪种方法，都需要**遵医嘱定期随访复查**，千万不能懒。因为镜片度数、遮盖时间、用药方案等等，都需要根据孩子的情况，适时进行调整。另外要特别提醒大家的是：**弱视治好以后，是有可能复发的**，至少要往后再跟踪观察 2~3 年，不能掉以轻心。
