# 富含优质蛋白还补DHA，这样做鳕鱼，宝宝超爱吃！

![封面图](https://mmbiz.qlogo.cn/sz_mmbiz_jpg/tGtmpweWiaN2BQMhfYrpEwISRQUCpIgO4sZPLUoUSH9672NpBxmCXIF6gnjUDsL7q5icribAVNJR8R6AEzV9ttPFg/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/1V8dhOZtt9ibh5Kv7IN3Sg

好多妈妈表示给娃做鳕鱼，除了蒸煮也想不出别的花样了，而且娃根本不给面子，吃两口就不吃了。
都知道鳕鱼挺贵的，要是买回来直接蒸煮，娃不爱吃就太可惜了。

后来想了一个招，娃吃到连渣都不剩！

**加点天然调味品，比如西红柿，就能掩盖住鱼腥味，酸酸甜甜超好吃。**是不是超简单？


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/FF2OYjRxqc3RVfiaMAuAP61hibl2Y0pGrEVhS0ajgvcp1ewsTPxt5Dy7a2m7uOPag9F4BDACpPPKSg0TaAbdmEwQ/640?wx_fmt=jpeg)


清蒸、水煮当然更好，但是偶尔煎一下，也是让娃吃得多样化的一个路子嘛。

赶紧看看怎么做**茄汁鳕鱼**吧~


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/FF2OYjRxqc3RVfiaMAuAP61hibl2Y0pGrEUR9wSN3tzyBxnALbcRZm9XoVPD5RAiav1F3s7iaC8WxTmxMdP9zyZhIw/640?wx_fmt=jpeg)


**菜名：**茄汁鳕鱼

**月龄：10m+**

**食材****：**鳕鱼50g、西红柿半个

**辅料：**食用油少量

**工具：**料理棒/研磨碗、普通锅


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/FF2OYjRxqc3RVfiaMAuAP61hibl2Y0pGrEaicDgIiaUApRVicEvAwYDjZsyBA5Y5sT0t4z3hu22lXHs182NrsfY5wAg/640?wx_fmt=jpeg)


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/FF2OYjRxqc3RVfiaMAuAP61hibl2Y0pGrE9DS5aumRNc11ncx1Vk0lvhLLIXZFw2gTV7suNHz1de7Dz4V2ibuk4MA/640?wx_fmt=jpeg)


1. 食材准备：


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/FF2OYjRxqc3RVfiaMAuAP61hibl2Y0pGrEa16NJcBswcBhHcIVUh0BCliaotg05XqKbf4eLEpRicxxFraez7NyzjVw/640?wx_fmt=jpeg)


2. 鳕鱼洗净后，去皮去刺，用3片柠檬腌制去腥；


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/FF2OYjRxqc3RVfiaMAuAP61hibl2Y0pGrEaS0v0SMHPGLtbmWKeW8q8wDes5Bzlq4TfenQV6N9qYjyVEHmKCRppQ/640?wx_fmt=jpeg)


3. 将鳕鱼切碎；


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/FF2OYjRxqc3RVfiaMAuAP61hibl2Y0pGrEcMnFHGgoW2PEgF6CdvjJUUhDgCQdSOyhibMMGlKiaxnszdbLDwoxq1ug/640?wx_fmt=jpeg)


4. 西红柿洗净后，去皮，切碎（可用料理棒/研磨碗）；


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/FF2OYjRxqc3RVfiaMAuAP61hibl2Y0pGrEcrj2A8zU24RVv9NnItTC9gYcH3Q9jOzhjaDWAKkT809gG3wTdXEzGA/640?wx_fmt=jpeg)


5. 热锅内放少量油，加入鳕鱼片，小火煎至两面发黄；


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/FF2OYjRxqc3RVfiaMAuAP61hibl2Y0pGrE2zPFuoricF1AzUrqjpo9m03ia01libfwlbn4RJ0ULkDmHa2tQAu2ctOuw/640?wx_fmt=jpeg)


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/FF2OYjRxqc3RVfiaMAuAP61hibl2Y0pGrE9XsoUkV2Vw937rlBrxdLaJGiaVPclLiajfF3ia4bZrPYYI9dsllFkicGwg/640?wx_fmt=jpeg)


6. 再将西红柿倒入锅中，至西红柿软烂后即可出锅。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/FF2OYjRxqc3RVfiaMAuAP61hibl2Y0pGrEGVtxMgriaCk3R4oYsT0sYxS4q4wj7icYtAu5qIKKOFFhJtR1lY4Y8uFQ/640?wx_fmt=jpeg)


![图片](https://mmbiz.qpic.cn/mmbiz_gif/FF2OYjRxqc3RVfiaMAuAP61hibl2Y0pGrEq2PhmWXoD6J92HW8KaUtAKJVwxFXYZhDpxpUbpTbCbs3KxIqKEXTpw/640?wx_fmt=gif)


完成啦~
