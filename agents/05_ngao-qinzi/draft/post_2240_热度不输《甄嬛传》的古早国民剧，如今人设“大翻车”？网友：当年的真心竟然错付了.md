# 热度不输《甄嬛传》的古早国民剧，如今人设“大翻车”？网友：当年的真心竟然错付了

![封面图](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN3dPtMYS760VKgwNgkXneyy6PjAt8ue1lPEW2OetaFTZdhGiasEiaUbzhUjSibsELicmjXHzvNeu1CdhA/0?wx_fmt=jpeg)

姐妹们这些年是不是网上看剧比较多，甚至最近还迷上了微短剧？

除了追新剧之外，大家偶尔会翻出之前的经典重温吗？编辑部不少妈妈说非常怀念从前一到春节前后电视台经典轮播的日子。


![图片](https://mmbiz.qpic.cn/mmbiz_png/nuqSmia8OqobnRZmRrLEpXLVu3IHYfV07xCDO5vgF3dsAwO4XERamBWabviaMGyWCHmaQuKic4x7Mv2cLOVhLw4mA/640?wx_fmt=png&from=appmsg)


不过，毕竟咱们长大了，看待事物的角度也不同了。**有些剧当年看得津津有味，也没觉得有任何不妥，现在想想，不少剧情真是相当狗血.....**

但，能把狗血泼到观众心里，让咱们欲罢不能、心甘情愿承认自己就是土狗，怎么不算一种本事呢？

咱们今天就来盘点一下几部让人欲罢不能的古早狗血剧，说不定就有妈妈们看过甚至到现在还超爱的，一起来看看吧！


![图片](https://mmbiz.qpic.cn/mmbiz_png/nuqSmia8OqobnRZmRrLEpXLVu3IHYfV071rdaYUSFcGjaFxaSPax1oCiaqxicyAiaDK3tbib7yKXb558w4S72Frib4eA/640?wx_fmt=png&from=appmsg)

**《情深深雨濛濛》**说起狗血，琼瑶的作品必须当仁不让、榜上有名。22 年前相当火爆的《情深深雨濛濛》，现在光是主演合体就能勾起不少妈妈的回忆杀。

![图片](https://mmbiz.qpic.cn/mmbiz_gif/nuqSmia8OqobnRZmRrLEpXLVu3IHYfV07Uyy73T4ia9TUcn8Qhv4bQQKBZRUc6N7b98UZIfKcU40zTmeLQcdcwOA/640?wx_fmt=gif&from=appmsg)

素材来源：封面新闻不管是翻出来重温，还是用着剧里截出来的表情包，《情深深雨濛濛》仿佛从未离我们远去。

![图片](https://mmbiz.qpic.cn/mmbiz_gif/nuqSmia8OqobnRZmRrLEpXLVu3IHYfV07s38XVNxiambSptBTBuTf9icyxUyViboR53wLhKHFEGlMn8OicB8KhvCMNQ/640?wx_fmt=gif&from=appmsg)

**小时候看这部剧，只知儿女情长，现在回看剧中的角色，却有了新的视角和理解。**首先是男主何书桓，从前看他是成熟、稳重、痴情的帅哥一枚，现在才发现原来是爱为两个女人动心的渣男（终究是错付了）。

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/nuqSmia8OqobnRZmRrLEpXLVu3IHYfV071X6Xh7TUdmNsgoB6WhYBiaCGY6RibARyEzWXykyiaOcvLh3mHYj0enxibQ/640?wx_fmt=jpeg&from=appmsg)

“我只是一个平凡的男人，也有男人的弱点”，看到这段发言，再迟钝的鉴渣雷达都要响了吧？

![图片](https://mmbiz.qpic.cn/mmbiz_png/nuqSmia8OqobnRZmRrLEpXLVu3IHYfV07qspVXt1omlZ3EjDcee5f95GUxibarA68ibm5cibEt31J0vKDosic6Id5pw/640?wx_fmt=png&from=appmsg)

而从前印象里冷酷泼辣的女主依萍，虽然后期没逃过“恋爱脑”，但高光也确实不能掩盖，细品一下简直是行走的金句制造机。在爱情上，依萍总体上保持着自我。和书桓产生矛盾时，书桓搬出了依萍曾经的承诺试图让她妥协：“你说过以后你都听我的。”而面对不合理的要求，理智的依萍却不会无脑接受：

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/nuqSmia8OqobnRZmRrLEpXLVu3IHYfV07diaq1LkaxxOfficovDuHg0Q0PhNiaCQ59Tuib5roanUcoiceNqWCqJpENxA/640?wx_fmt=jpeg&from=appmsg)

见两人多次来回中自己都落于下风，书桓又想假借分手逼迫依萍与自己和好，然而依萍依旧敏锐识破他一番发言的核心，直截了当地表达自己的态度：

![图片](https://mmbiz.qpic.cn/mmbiz_png/nuqSmia8OqobnRZmRrLEpXLVu3IHYfV07hPqssLetQS3vFN7fs4F5BwNZ3CRsoNS5ohzkFTZhGs7cvskbjwyMcA/640?wx_fmt=png&from=appmsg)

不仅感情观放到今天来看依旧有不少值得称道的地方，在事业方面，依萍独立自主、职业平等的观念也是遥遥领先：

![图片](https://mmbiz.qpic.cn/mmbiz_png/nuqSmia8OqobnRZmRrLEpXLVu3IHYfV07R5g6RvibqN9Lu2b5lhF7icIRIuCQX1R7wv4dQKW1BW4psUNPQViaK3Wvw/640?wx_fmt=png&from=appmsg)

因女儿在歌舞厅工作觉得有损颜面，曾经用一顿鞭子伺候冒着大雨找来要生活费的依萍的陆振华，这会儿反倒提出以更多生活费换取她马上离开舞厅。而受够了当“伸手阶级”时的卑微和冷遇，如今靠自己获得生活来源的依萍却再不愿接受这份迟来的有条件施舍：

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/nuqSmia8OqobnRZmRrLEpXLVu3IHYfV07cQSDiaGA7VU2IDs9YAiaj0y1zt9saZdxeTxWH63SG4iaPH2uATmicbjxYQ/640?wx_fmt=jpeg&from=appmsg)

同样，面对试图羞辱自己职业的尔豪，她只用一句话就怼得他哑口无言：

![图片](https://mmbiz.qpic.cn/mmbiz_gif/nuqSmia8OqobnRZmRrLEpXLVu3IHYfV07mF4X99By8sCf0a4YY9nE800bhyNXLgvoSUxlJeb0gAGXbibVIYjdGFQ/640?wx_fmt=gif&from=appmsg)

**在爱情里清醒、在事业上独立**，难怪依萍会被封为琼瑶剧三观最正的女主。这样的她，是不是也是今天很多妈妈希望成为的大女主呢？


![图片](https://mmbiz.qpic.cn/mmbiz_png/nuqSmia8OqobnRZmRrLEpXLVu3IHYfV071rdaYUSFcGjaFxaSPax1oCiaqxicyAiaDK3tbib7yKXb558w4S72Frib4eA/640?wx_fmt=png&from=appmsg)

**《回家的诱惑》**既然说到大女主了，那怎么能少了品如（黑化版）？试问在座的妈妈们有谁没看过《回家的诱惑》呢？“为所有爱执着的痛，为所有恨执着的伤……”看《浪姐》时听到“品如”本尊唱起这首战歌，姐妹们的 DNA 是不是也狠狠动了？

![图片](https://mmbiz.qpic.cn/mmbiz_gif/nuqSmia8OqobnRZmRrLEpXLVu3IHYfV07NyEF8Tabp7BXzEEvHrPwdWYTv9Zz8yBkzCicibS4L0FEdQwtQ2daibN8A/640?wx_fmt=gif&from=appmsg)

距离首播十几年了，网友们还乐此不疲地使用着由剧中台词、名场面衍生出的表情包，就连演员本尊都加入了二创。


![图片](https://mmbiz.qpic.cn/mmbiz_gif/OzRk04nQ4sE3sWdNYR4C2kc6Giam7DCKd2dO9Ej3Kibfkc6MGhuBRajyWSrHOJsjicZpj78jH41j208uZSHpgk80Q/640?wx_fmt=gif)

最经典的要数这个灵魂拷问：

![图片](https://mmbiz.qpic.cn/mmbiz_png/nuqSmia8OqobnRZmRrLEpXLVu3IHYfV07zCfX1np9gibLkjAspRwWuOzgZBicBiaT3UBltzbP8fN2SQphYiccIxWjkg/640?wx_fmt=png&from=appmsg)

曾经让人恨得牙痒痒的洪世贤，现在回看简直是“本世纪最清醒渣男”：

![图片](https://mmbiz.qpic.cn/mmbiz_png/nuqSmia8OqobnRZmRrLEpXLVu3IHYfV07EEbeWRN2qxdA8H5MVXdq67nTvlldjPoeIichbovJn2jbsdKXmLWow9g/640?wx_fmt=png&from=appmsg)

抛开这些热梗、回归剧集本身，《回家的诱惑》集齐了**灰姑娘嫁豪门、恶婆婆、闺蜜变小三、重生复仇……**要素简直不能更多、狗血到了极致，却让人欲罢不能。就像不少人不爱看《甄嬛传》中的甘露寺桥段，大家重温《回家的诱惑》往往也是从复仇开始看。品如化身高珊珊华丽回归，甚至比甄嬛回宫黑化还要早一些。**极致的爽文，同样也是极致的享受。**

![图片](https://mmbiz.qpic.cn/mmbiz_gif/nuqSmia8OqobnRZmRrLEpXLVu3IHYfV07OGicnicfm3ibwZgQRico11YWVQ2OoEicXf5wYJEVTHTib1TaBDoWrpjYeMibg/640?wx_fmt=gif&from=appmsg)

与此前家庭剧里频频出现的苦情圣母女主相比，“没有和解，无法原谅，我会笑着看你们每一个人哭”，当年品如这样的复仇黑化女主称得上是鹤立鸡群，让人印象深刻也很合理。


![图片](https://mmbiz.qpic.cn/mmbiz_png/nuqSmia8OqobnRZmRrLEpXLVu3IHYfV071rdaYUSFcGjaFxaSPax1oCiaqxicyAiaDK3tbib7yKXb558w4S72Frib4eA/640?wx_fmt=png&from=appmsg)

**《千山暮雪》**除了《回家的诱惑》外，另一部围绕复仇展开爱恨纠葛的老剧《千山暮雪》，在播出 12 年后的今天被网友们集体考古了。不过，当年沉迷虐恋情深剧情的大家，现在的关注点却在**主角们“美丽的精神状态”**上。

![图片](https://mmbiz.qpic.cn/mmbiz_png/nuqSmia8OqobnRZmRrLEpXLVu3IHYfV074EkJ0Aic7KSYDjmUseThcVYRdDZiaVWkHr2OmeicZu4Yfl408Ta7vGNkQ/640?wx_fmt=png&from=appmsg)


是夜，女主童雪试图与男主莫绍谦和好，却遭到**“肘击癫公”**三连暴击，连带着打碎了床头的古董灯：

![图片](https://mmbiz.qpic.cn/mmbiz_gif/nuqSmia8OqobnRZmRrLEpXLVu3IHYfV07h9lzN4CUFicDpyyc76zxSa3CGfiaLBhH1aoic6W3wQF9HX4SFBmFkq0CA/640?wx_fmt=gif&from=appmsg)

两人吵架时，一个是**桌面清理大师**，另一个是**“退退退”表演艺术家**。

![图片](https://mmbiz.qpic.cn/mmbiz_gif/nuqSmia8OqobnRZmRrLEpXLVu3IHYfV07ymeDfibQEiaNzdhUFMFRQJn4KDic1rhlcV2adytcxGoFxibbaibff0N4tMg/640?wx_fmt=gif&from=appmsg)

这些片段放到今天单独拿出来看，确实离谱中带点搞笑，被大家玩梗嘲上热搜不奇怪。但回到《千山暮雪》首播的 2011 年，不少观众却看得很上头。

![图片](https://mmbiz.qpic.cn/mmbiz_png/nuqSmia8OqobnRZmRrLEpXLVu3IHYfV07q0jN3C5KEIrq3F4pX4BpibbFCmcGJ5QYPhyUPOvOebFjkk428xXAOSQ/640?wx_fmt=png&from=appmsg)

为啥这样一部挺“癫”的剧曾经能红极一时呢？咱们先来简单回顾一下剧情。因遭陷害导致自家公司破产，莫绍谦父亲抱憾离世。为守住家业，莫绍谦不得不与爱慕自己的千金小姐慕咏飞假结婚。但多年来，这段关系始终是慕咏飞一厢情愿。机缘巧合下，莫绍谦遇到了女主童雪并对她产生了好感。

![图片](https://mmbiz.qpic.cn/mmbiz_gif/nuqSmia8OqobnRZmRrLEpXLVu3IHYfV07JoaCYmCSy4NKj66hbreYdVr4BkkCFfLM6ZnQPMksdicRH6pGewGHlTA/640?wx_fmt=gif&from=appmsg)

后来得知正是童雪的父亲出卖机密导致莫氏危机、间接造成父亲去世，愤怒不已的莫绍谦设计威胁让童雪成了自己的“情人”，意图报复上一辈的仇怨，却在过程中爱上了她。

![图片](https://mmbiz.qpic.cn/mmbiz_gif/nuqSmia8OqobnRZmRrLEpXLVu3IHYfV07fa5N4fY3naM9q5VEJUiboia9SxLibn7AhcrInaiaxOQ1wSXGQKmxgTpEIA/640?wx_fmt=gif&from=appmsg)

爱恨交织、夹杂着无数误会与冲突，相信不少妈妈也曾被这样**复杂纠结的虐恋**吸引到。

![图片](https://mmbiz.qpic.cn/mmbiz_png/nuqSmia8OqobnRZmRrLEpXLVu3IHYfV07dsW9mq9CPribdBIbWiaY4vg1zGPjW0oyGYnuso2uvh7y5b0R2TYicXvkw/640?wx_fmt=png&from=appmsg)


除了虐恋，剧中**商战、恩怨反转**等情节也颇具亮点。虐了童雪一段时间后，莫绍谦终于发现，正是当年以拯救者的身份出现、要求他以假结婚来换取莫氏注资的慕咏飞，收买女主父亲，害莫氏破产。

![图片](https://mmbiz.qpic.cn/mmbiz_png/nuqSmia8OqobnRZmRrLEpXLVu3IHYfV07xhYMf746zxAsFw1QwwSOg01yGAQ3ib7ubBpIaWMzlNIjT1CadSCK1Vw/640?wx_fmt=png&from=appmsg)

早在让女主落入自己精心设计的圈套之前，莫绍谦也深陷他人圈套却浑然不觉。某种程度上，他和女主一样也是个可怜人。

![图片](https://mmbiz.qpic.cn/mmbiz_png/nuqSmia8OqobnRZmRrLEpXLVu3IHYfV07X1XFPk9ou0mdicerUUoDDnzABFsTKiblIHiaiaPmndpJdTwQVlmgjUK0YQ/640?wx_fmt=png&from=appmsg)

总体上，《千山暮雪》剧情圆得比较合理，人设带感、演员演技也不错，所以大家看得进去，也会被角色的魅力吸引。莫绍谦一角就一度被称为“霸总天花板”“刘恺威的养老保险”：

![图片](https://mmbiz.qpic.cn/mmbiz_gif/nuqSmia8OqobnRZmRrLEpXLVu3IHYfV07Yib7Gu05TEv8Wz7YNNqib1JibdAKepBITia34ia5evibibRiaNPbqJrPuFex3g/640?wx_fmt=gif&from=appmsg)

在部分网友心中，和他比起来，今年爆火的孟宴臣的魅力都要稍逊一筹。

![图片](https://mmbiz.qpic.cn/mmbiz_png/nuqSmia8OqobnRZmRrLEpXLVu3IHYfV07x2CBPqANYjlxnp1Hr1z4duFhNMzQcia9bm0icos5ialVVw8PXz7jX2jnw/640?wx_fmt=png&from=appmsg)


而女二慕咏飞商场上腹黑清醒、情场中为爱盲目的人物设定颇具反差张力，也让人印象深刻。

**正是人设、演技、剧情在一起发挥作用，才能给大家泼这样一盆至今还在回味的好狗血，让人一边吐槽“好土”、一边欲罢不能。**也是因为现在各方面都在线、值得让人 N 刷的剧属实不多，所以大家才钟爱之前的老剧吧。


![图片](https://mmbiz.qpic.cn/mmbiz_png/nuqSmia8OqobnRZmRrLEpXLVu3IHYfV071rdaYUSFcGjaFxaSPax1oCiaqxicyAiaDK3tbib7yKXb558w4S72Frib4eA/640?wx_fmt=png&from=appmsg)

跟很多妈妈一样，咱们现在回顾一些古早电视剧，也会觉得不少情节不合常理、尺度大不能播、毁三观，部分价值观也不适合当下。比如，《天龙八部》里段誉喜欢的姑娘们都是自己妹妹，最后发现唯独自己不是他爹亲生的；《金粉世家》里多金又专情的金燕西，其实是始乱终弃的寄生虫；《上错花轿嫁对郎》里同年同月生的杜冰雁、李玉湖又同日出嫁，上错了对方的花轿却意外成就了不错的姻缘……不过，**每个时代的作品都不能脱离当时的局限**。随着辨别能力的提升，咱们重温老剧的时候能看出其中的不合理以及落伍之处，但这并不妨碍咱们品味合理、适度的狗血，妈妈说是不是呢？**大家现在还会时常回顾古早影视作品吗？你心目中值得反复回味的剧集是哪一部？印象最深的角色和情节又是什么？欢迎来留言区交流讨论~**部分素材源自网络，如有侵权请联系删除
