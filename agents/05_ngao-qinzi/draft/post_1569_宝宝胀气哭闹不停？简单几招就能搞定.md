# 宝宝胀气哭闹不停？简单几招就能搞定

伺候小宝宝真是难。

睡觉哭，醒了哭，饿了哭，饱了——还是哭！

有没有觉得，很多时候，明明睡够了，奶也喝饱了，大人还轮番上阵逗着哄着，小家伙为啥还是一直用哭声刷存在感。

仔细一观察，发现哼哼唧唧的小家伙肚子鼓鼓的像个小皮球、身子扭来扭去、拳头握的紧紧的、还常伴随吐奶……这不会是生什么病了吧？**淡定淡定，很有可能你家宝宝只是胀气了。**


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/rrVVklPTzRARvsvp2sYxycXIdVoH7RFbCTiaktWibxjKYxFU94OkVPYCm9JPwzMDvTAytjibFFJhHTPunUEcnN5hQ/640?wx_fmt=jpeg)


小宝宝的肚子，真是一不小心就会跑进空气来：**吸奶嘴、喝母乳、哭泣时都有可能中招。**宝宝产生胀气**最主要原因是消化系统还没发育好**。当弱小的消化系统碰见一大团气体来袭，根本无力招架，只能任它们留在宝宝体内了。**哭闹也容易让宝宝吸入过多的空气。**妈妈们要抓住娃饥饿的信号，尽快喂奶。**哺乳姿势不正确**（比如宝宝没有把整个乳头和乳晕含进嘴里，宝宝脸没有正对乳房），容易使宝宝吸入空气。

家长拿奶瓶姿势不正确、奶液没有充满奶瓶嘴的前端、宝宝平躺喝奶瓶，都会加重娃的胀气。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN3ZEhzugRuE0hFQOjxTkOAZXwJ7KLC155z2axll6gej0JBYPxAEkZ7xTXFfRUUibIuCosWffoR58uw/640?wx_fmt=jpeg)


此外，宝宝对妈妈的母乳或者是配方奶中某些**成分不耐受或者是过敏**，或者**吃太多了**，都有可能导致肚子胀气。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/rrVVklPTzRARvsvp2sYxycXIdVoH7RFbfK2AEjoy1oAgjmGLDkwu69jI18tBGKJ9WW3OBOdIC3a5pGQQtF1mlg/640?wx_fmt=jpeg)


在前三个月，宝宝胀气疼痛是很常见的；六到十二个月大的时候，宝宝的辅食越来越丰富，大量不同的食物让宝宝的肠道不习惯，也可能会导致胀气疼。糕妈这里有一些**排气妙招，快学起来吧：****◆****拍拍嗝**每次喂完奶后，给宝宝拍拍嗝。喂奶中途也可以趁着换边，或宝宝自己松开乳头/奶嘴时给他拍一拍。**◆****多趴趴**宝宝多趴趴，好处多到爆！不仅可以预防扁头，还能让跑进宝宝肚里的空气乖乖溜出去呢。有时候抱着拍了很久，手酸腰酸，却还没听到“嗝”一声。把宝宝放下趴一会儿，瞬间就通畅地“嗝”了。

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/rrVVklPTzRARvsvp2sYxycXIdVoH7RFbKIK8OFOF9RMd5vy5vzRcic3Dc1VMibVM4AcOX1IPPjiczspVFDuBpLr1A/640?wx_fmt=jpeg)

**◆****动动腿**我们还可以帮助宝宝做空中自行车，帮助宝宝排气。让宝宝平躺在地垫或者床上，用手帮助宝宝像骑自行车一样来回蹬腿，这样既能帮助排气，还能减轻肚子的不舒服，逗得小主咯咯大笑。

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/rrVVklPTzRArhLxriao9ibPvGsiaEoVFAl53O9ZG15YtiaV2dvw2R6VGNI6OSq5gHJcovK08B7gQozG79E4BdXJtSQ/640?wx_fmt=jpeg)

**◆****按摩小肚子**让宝宝仰躺在地垫或者床上，**两三根手指并拢，轻轻绕着小肚子划圈**。妈妈们还可以创造各种**手势“I”、“L”、“B”型**轻轻按压他的腹部周围，帮助宝宝把空气排出来。**◆****挑对奶嘴**喝奶瓶通常会吞入更多空气。要注意**奶嘴孔的大小**。孔太小，宝宝需要用力吸，容易吞入大量空气。孔太大，宝宝又会因为来不及喝而呛奶。妈妈们可以把奶瓶倒过来，奶嘴朝下，如果奶以每秒1滴左右的速度流出，且几秒后停止滴奶，就是最合适的速度。**◆****这样喂奶**喝奶瓶时，不要让宝宝平躺着，**头部要高于肚子水平**。拿奶瓶时，让**奶液完全充满奶嘴**，这样可以防止吸入空气。另外，每次奶粉冲泡好后，可以**静置会儿再给宝宝喝**。搅拌和摇晃得越厉害，就会产生越多气泡。**◆****注意饮食**最后母乳妈妈也可以留意下，是否吃了容易胀气的食物，如**豆类、洋葱、卷心菜等。**不过，**食物并不是引起胀气的唯一原因**，不必一股脑把这些食物都打入冷宫。哺乳期营养均衡很重要。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN3ZEhzugRuE0hFQOjxTkOAZ3KJKF1yLYbXiawtHK1whAibibMQnxtOUdhy57APQf8lrVH31WpS50icx7A/640?wx_fmt=png)

要是以上方法效果都不明显，宝宝的哭叫持续好几个小时，看上去不适一点都没有缓解，要注意可能是肠绞痛；若此时还伴有高热、呕吐甚至便血，最好到医院看一下。

教了大家这么多方法，快去给家里的小宝贝用起来吧，有时候，听到宝宝一个屁声，都会心满意足呢！
