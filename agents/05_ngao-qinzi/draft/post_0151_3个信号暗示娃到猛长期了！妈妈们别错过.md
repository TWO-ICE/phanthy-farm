# 3个信号暗示娃到猛长期了！妈妈们别错过

很多妈妈应该知道，宝宝的生长发育可不是“按部就班”地一点点长着。有时候长太快了，感觉小衣服立马就穿不了，有时候很缓慢，甚至一两个月都没变重，这都很正常。

尤其是** 1 岁以内**的小宝宝，是体重增长最快的时期，更是会出现**多个“猛长期”**。在娃 1~3 周、6~8 周、3 月、6 月、9 月大的时候更容易出现。


当然，这些时间点并不是绝对的，妈妈们还可以通过宝宝的一些表现来判断他是否处于猛长期。比如接下来咱要讲的**“三大信号“**：可能就暗示着娃到了猛长期👇 


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN38G7rq0zodnDibJ338RPXW7nWTic1QxWfg6JEXOcShhg5FqfTeaOxzo6aTJeR8IqWWia0ga8wMUcibnw/640?wx_fmt=png)

在猛长期，宝宝可能会非常有食欲哦，跟平时比就像个小饿鬼。毕竟生长加速了，代谢很快，需要大量食物来支持。


如果是**母乳喂养**，ta 可能会**吃得比以前久、吃得更频繁。**

比如你平时每 3 个小时喂一次，那你的娃可能现在会每 1~2 个小时就想吃。


![图片](https://mmbiz.qpic.cn/mmbiz_png/2EaFkYu8ISu5PIFw6MsnZmicttvEn1qicxia4nkWTXmlHcsv3oaX0fSfL1CI3axLgvsdxHzics5bic2X5lsibvB1nIIw/640?wx_fmt=png)


糕妈就这样被小发发掏空过，喂上一个半小时的奶是一种怎样的体验？


![图片](https://mmbiz.qpic.cn/mmbiz_png/2EaFkYu8ISuk7qziawZXkKxSJGL04xTgb6URx1OXDgwICzibMibFeLa6qcO8oB0kODS9A4nnoykzibiaLEC4Id74OibQ/640?wx_fmt=png)


抱怨归抱怨，这种时候老母亲还是得尽量满足宝宝需求。

别担心你的奶水会不够，娃吸得越多，就越能**刺激你泌乳来满足娃不断增长的食欲**，保证好你们自己的饮食和饮水就好了。相信自己，千万不要这时候认输了，**随意添加奶粉哦！**

如果是**奶粉喂养**，宝宝喝完一瓶奶后，可能还不满意哦，还想继续喝，那就多给 ta 一瓶。


![图片](https://mmbiz.qpic.cn/mmbiz_png/2EaFkYu8ISu5PIFw6MsnZmicttvEn1qicxibJwLrr4tyYxICqYT7fv1Bs13Oq8lDP8pHBCsY0cQmAo8cKFuib75ibcg/640?wx_fmt=png)


反正 1 岁以内奶是主食，多吃点长身体！另外，如果宝宝已经在吃辅食了，可能也会想多吃奶。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN38G7rq0zodnDibJ338RPXW7lOQ66wMs0DOOUOA2yNJ6CV9jLfbDLxaRMJ8hJCK7WK8HibC9ic5In41g/640?wx_fmt=png)


有一项小型的研究表明，在猛长期，小宝宝可能会在这一两天内**比平时多睡 4 个多小时**。

娃表现得比平时更容易困，晚上醒来少，或者午睡时间变长。

目前还不是很清楚为什么会发生这种情况。不过能确定的是，睡眠时大脑中会**分泌更多生长激素 (HGH)，促进娃生长发育**，就安心让娃多睡睡吧。


![图片](https://mmbiz.qpic.cn/mmbiz_png/2EaFkYu8ISu5PIFw6MsnZmicttvEn1qicxC4t1g9vib8XqmhMUmVicicjrMwNicyetJL0ic7v0WR9ctGhJWQDx8bdfzqg/640?wx_fmt=png)


也有一些反面案例，**某些宝宝在猛长期似乎会更睡不好**，比如晚上会更常醒来，凌晨 2 点、4 点等时间想要吃一顿，或者在白天午睡时醒得也更早。

咱年糕哥哥小时候就是这样！！！刚开始可折腾死糕妈了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/2EaFkYu8ISuk7qziawZXkKxSJGL04xTgbeyZfVwOBUgR96hTiaWL1WAWATRqVYyhDxibrEXCvjOFnMW48uJvgv1mw/640?wx_fmt=png)


但经历了几次也就明白了，应该多满足宝宝的需求，**给予他更舒适的环境**，多留意宝宝的“困点”，比如看到娃变安静、揉眼睛、打哈欠时，就可以准备哄睡啦；睡之前**加长对宝宝的安抚时间**，帮助他放松。


而且这段时间一般就维持几天，当妈的多担待点宝宝吧，想想他可能**正处于一个快速发育的阶段**，心里是不是会感到安慰些呢？


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN38G7rq0zodnDibJ338RPXW7x0vibvDq2Bt1c2DIwqJDrS9ja5k3ugnGFoz35RoPCLN0r1tXSticzxQA/640?wx_fmt=png)


在猛长期，你的宝宝可能会比平时**变得很粘人**，或者**情绪变化大、焦躁**。


比如他想一直被你抱着，如果你想放下，他可能会哭给你看呢。他吃奶时可能也会变得急躁不安。这种时候，妈妈们就多多给你宝宝**拥抱、抚摸**，安抚他的情绪哦。


![图片](https://mmbiz.qpic.cn/mmbiz_png/2EaFkYu8ISu5PIFw6MsnZmicttvEn1qicxDgtXV8klJVCeKKms3gDgnicxNaYUB1kCF6NUTu2CPicicljHeG4I32vaA/640?wx_fmt=png)


目前还不清楚到底是什么导致了娃这些行为变化。可能是猛长期娃本身很容易饿，还睡不好，自然也会影响到情绪。

还有一种理论是，**猛长期往往和宝宝的大运动发展有一定关联**。如果你觉得宝宝看起来很躁动，人家可能是急着想表现呢，想给你一个惊喜——展示他 get 的一项新技能，比如**翻身**或**爬行**之类的。

![图片](https://mmbiz.qpic.cn/mmbiz_gif/ldFaBNSkvHjHB7C85hnZBxEdY7XfdialFSs2sqkhU0hAQGG4vDn1nDOdXUGDicfaJ1rTeQDPNJRciaedicADLANghw/640?wx_fmt=gif)

猛长期的三大信号，你 get 了吗？最后再给大家总结一下：

**1、食欲大增，喝奶量大增**

**2、睡得更多或睡得更少**

**3、情绪波动大、焦躁不安**


除了猛长期，**出牙**、**某些疾病**也会影响宝宝的喂养、睡眠和情绪等变化。如果娃表现得很不正常，比如**极度易怒**或**无精打采的**，**体重也没啥增长**，**大小便出现异常**等情况，建议去咨询下医生哦。

发发经历过好几次猛长期，当时就是没完没了的喝奶，恨不得要长在我身上，容易变得烦躁、变得很粘人，当时我真的很崩溃，脾气也大了很多。

妈妈们别啥都自己扛着，可以多**让家人帮着分担点。**这点糕爸做的就还可以，虽然不能替我喂奶，但是每晚都在服服帖帖的当出气筒。

猛长期虽然很辛苦，但要相信，艰苦的日子很快就会过去的。所谓“猛长”，过完之后你会收获一只**更可爱、更天使、也长大许多的宝宝呀！**
