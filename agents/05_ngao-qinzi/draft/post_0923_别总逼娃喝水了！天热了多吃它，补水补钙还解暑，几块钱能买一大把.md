# 别总逼娃喝水了！天热了多吃它，补水补钙还解暑，几块钱能买一大把

![封面图](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN1Owcrj69gNZ0EGriaSjh4COiakAzpu4Iv7nicImNib9dFUufgDJzS08SCiasMLIicsBf9pl2Q3uiaBGbjibg/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/hsCdm4GxQEZIHhOSVkaRXg

你家娃，最近是不是看起来蔫蔫的？估计是因为天太热，身体的水分和营养被“蒸发”了。 咱都知道，**小孩子的新陈代谢快，夏天更容易出汗，及****时补水补营养很重要**。对于不爱喝水的娃，补水的最佳方式就是**吃瓜**。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_gif/tGtmpweWiaN1Owcrj69gNZ0EGriaSjh4COEp8eN6jBAuxBTuvqDarQ09vfcmArCbR5W471YXgqBWZNyK8ODHJn2w/640?wx_fmt=gif&from=appmsg)

因为，瓜类的水份太高了！随随便便什么瓜，**含水量都在 90% 以上**，这不就约等于直接喝水嘛？

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN0P7aCms23qXfMJsmk5v3HBWRPEqC80SlxvcrQSMRoTF5eoVaaHby9e5ickhVLyXM4bpZSKwczNuyg/640?from=appmsg)

数据来源：《中国食物成分表》（第二版）而且，瓜类天生就**高钾低钠**，适合**夏天出汗后补钾，还不会让娃摄入更多钠。**糕妈家的餐桌，时不时就在吃瓜。不管是生吃还是做菜，味道都蛮好：

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN0P7aCms23qXfMJsmk5v3HB6qRCvwPM19VRtvxJOALPameqcCIjZUvhEkUbl6IfVMj6clavQ0GWDw/640?wx_fmt=png&from=appmsg)

下面就来盘一盘夏天常见的几种瓜，记得收藏哦~

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN0P7aCms23qXfMJsmk5v3HB6fQseVgbuPmq7AePdKJDgSfgcpS1gUIxobib23hzRQofpAplLjKurCA/640?from=appmsg)

夏天最应季的，就是是圆滚滚的大冬瓜啦。**冬瓜的含水量高达 96.6g/100g ，妥妥的补水利器！**

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN0P7aCms23qXfMJsmk5v3HB8S5J9u4lCkr59ec13JmDzgN1GDdYmtlb5aXzKEvI3dXJyIrt994cOQ/640?from=appmsg)

冬瓜简单煮一煮就入口即化，**对咀嚼能力不好的娃太友好****了。******它本身没啥味道，但跟别的食材搭在一起很入味。加海鲜做汤就是满口鲜；切片红烧又是咸香口；蒸着吃还可以当配菜。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN0P7aCms23qXfMJsmk5v3HBm12siaxQ3WDQ3yF5eAicfcyNhEpfr2LB4CzpT0mRl5kdMkakqj4yYRWg/640?from=appmsg)


怕切片冬瓜不好保存？可以试试迷你小冬瓜，只比香蕉大一点，一顿吃完不浪费。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN1Owcrj69gNZ0EGriaSjh4CO1iao1gm4whCJYdsZZE5xkWwQmZtdXq7BeCc3TStRoOzWd1ss4HknHZg/640?wx_fmt=jpeg&from=appmsg)

一个小彩蛋：冬瓜是热量最低的瓜！**每 100g 的热量只有 10 千卡，比大白菜还低，**想减肥的妈妈一定要多吃！

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN0P7aCms23qXfMJsmk5v3HByh8ibaZEVTn2xns0xYxG9UPOHTo97qIqiaWKE71uns9icdabYIBzsuf8w/640?from=appmsg)

丝瓜在夏天的出镜率也是相当高。去年糕家在自家阳台种过丝瓜，一根一根掉在藤蔓上，长得非常快。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN0P7aCms23qXfMJsmk5v3HBU8ADzTjQrYCN99bjZKLxgbXOc5nFDK0Zhs1RTKPAp7HGeWsfFicRAGg/640?wx_fmt=other&from=appmsg)

丝瓜的微量元素很多，其中**钙高达 37mg/100g **，妥妥的瓜中王者。吃起来软中带脆，有点嚼劲但不多。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN0P7aCms23qXfMJsmk5v3HBlYg8GQPGlqicVXMXs6NVCV6s6fk0DnzkwP3mjsc97QYiaGwz3erRRknQ/640?wx_fmt=png&from=appmsg)

娃要是吃腻了绿叶菜，还可以尝尝丝瓜尖！**焯水后凉拌或清炒都好吃，膳食纤维满满~**

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN0P7aCms23qXfMJsmk5v3HBHKpvoWxEFscly1hoHd92lficOk7vIiaQuOPmnTwwicgOn36iaRExtEyJjg/640?from=appmsg)

提醒一下大家，发苦的丝瓜绝对不可以吃。丝瓜发苦，可能是含有碱糖甙生物碱这种有毒物质，**靠清洗、靠煮沸都没法去除，吃到了必须吐出来。**

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN0P7aCms23qXfMJsmk5v3HBjJPZcw7RAnqNhPlyjcwMSLczov0VGJrkic7dB05nxbb7vkn5KAebE8g/640?from=appmsg)

天热了娃想吃凉拌菜？直接来个拍黄瓜，清脆补水，胃口瞬间被打开。上周末，糕爸就领着两娃摘黄瓜吃：

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN0P7aCms23qXfMJsmk5v3HBLwzBaLg8DZA4P6A7z1uaAnB5ibwFwyaExs10zeq9hHsPlr6mMicqic2fA/640?wx_fmt=png&from=appmsg)

**黄瓜的含水量高达 96% ，**出门带根黄瓜，不仅能垫垫肚子，还不用愁娃喝水难！ 不爱喝白开水的宝宝，还可以试试“黄瓜水”。黄瓜切成薄片，加上凉水或冰水，就是一杯低成本的补水小饮料了。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_gif/tGtmpweWiaN0P7aCms23qXfMJsmk5v3HBNiaG8zrerLuAvTNia5N0W0wGgceT45NYOGJjkOiaVvhoHCeDHuLzScjRw/640?wx_fmt=gif&from=appmsg)

除了常见的菜用黄瓜，水果黄瓜也很不错：**涩味更少，口感偏甜；表面也没有扎手的小刺。**小小一根刚好适合娃的胃口！**

![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN0P7aCms23qXfMJsmk5v3HBhzy3iclBupial0ENlGYBF4NFSd86RsusdEUKy35fX5LWf6IYiclebSrDA/640?from=appmsg)

**木瓜的维生素含量有 31g/100g ，维 C 比橙子还丰富！**吃着软嫩细腻又多汁，切一块可以给娃直接当冰淇淋吃。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN0P7aCms23qXfMJsmk5v3HBS22GgLvQibNfJU8cC5zXADL7TH6iauk03ElS2LLt5icZnP7LlftD8thiaw/640?from=appmsg)

**没熟透的青木瓜，口感偏清脆**，很适合加点生菜、鸡蛋、芒果拌成沙拉。给娃当水果骗水的同时，还能顺带吃点蔬菜。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN0P7aCms23qXfMJsmk5v3HBiaDfLqK54Kib2fHAl0LrJekuMWteqicbOpJ0ia5jnIGuphp07xkRo4o2FA/640?from=appmsg)

更神奇的是，木瓜自带一种能**切断肉类纤维的蛋白****酶**，可以让肉变得更细嫩，不爱吃肉的娃可以试试！木瓜还很适合饭后促消化。两广地区常吃的酸嘢，主角就是木瓜，**清爽又解腻！**

![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN0P7aCms23qXfMJsmk5v3HB30icPKbQag6iaElticialXfedfT9ZJoelpEWCOlULnwo16VlX6dDaxYb3g/640?from=appmsg)


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN0P7aCms23qXfMJsmk5v3HBs4CEpaiajt9XbT9PPtfXgf6fhe3CdBEE8s8fnQQk2bpuWzt2tuibgcOA/640?from=appmsg)

哈密瓜作为厚皮甜瓜的一种，**胡萝卜素有 920mg/100g**，在瓜类里算是相当高！多吃一点对眼睛是蛮好~而且它富含钾、钠、镁这些微量元素，维生素 A 和 C ，都是瓜中好手。**

![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN0P7aCms23qXfMJsmk5v3HB0XHHleLjGlb1v2HGfxsyibJp49We4SU2pJeYM4XnR8goP5IJZQanFAA/640?from=appmsg)

**给娃吃，可以选瓤附近的位置，因为越靠近瓤越甜。担心太甜？吃完了喝点水，就不会“甜到齁嗓子”了~

![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN0P7aCms23qXfMJsmk5v3HBRFS5YG6Eb0BicoKfdq1TX24KZLMMAF7fBRZu66nFyUyCALvMvyE7zmQ/640?&wx_fmt=jpeg)

除了哈密瓜，甜瓜家族还有很多瓜适合宝宝吃哦：海南网纹瓜、羊角蜜瓜、玉菇甜瓜......


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/tGtmpweWiaN0P7aCms23qXfMJsmk5v3HBon3843nbBEibR12MCTO03eFt5jNice0OX8dHnwN3GrpRsibB8f8j262tw/640?from=appmsg)

要说瓜类王者，那指定就是西瓜！西瓜虽然吃着甜，但**含糖量只有 5.5g/100g**，比苹果、橙子都要低不少。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN0P7aCms23qXfMJsmk5v3HBlXQVIGouTmtZwfbcNSPLY6aibOicnibmkKic6t6wI6RxtsbRpvdHrEpHOQ/640?from=appmsg)

与其担心因为瓜太甜而蛀牙，不如控制一下量，一次别给娃吃太多！

![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN0P7aCms23qXfMJsmk5v3HBh0FNvFjWaOcx2eQQvnVTJjMCjFha2OOL2RKFiatjXhjaGBKS3gI1V2w/640?wx_fmt=jpeg&from=appmsg)


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN0P7aCms23qXfMJsmk5v3HB2b4NJHgolEowUY2FniapJu1GIxESTXfiaKaBbqoJNe5ibvIibuD8XlhhOw/640?wx_fmt=jpeg&from=appmsg)

西瓜作为常驻冰箱的大户，更关键的问题是保存。要是没法立马吃完，一定要用保鲜膜封好放冰箱冷藏。担心隔夜瓜细菌感染，可以**切除表面1~2cm 再吃**。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/tGtmpweWiaN0P7aCms23qXfMJsmk5v3HBzpmCM7rm0v3QeKxN35uFCicInQVYkWlk3KlWgjoQOPsaW91ZNBmoLFA/640?from=appmsg)
