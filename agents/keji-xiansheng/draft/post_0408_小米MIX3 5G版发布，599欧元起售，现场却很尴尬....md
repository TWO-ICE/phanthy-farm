# 小米MIX3 5G版发布，599欧元起售，现场却很尴尬...

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4YibrExb2afZqia8AoujmQPwfMKjx4GaNgalibVGVNqQvYI2l67UT0bYnE1qDyEUUlzcTOXsEMVHE5Ikw/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/vByVeAC1NlYIzbIw0W0miQ

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YibrExb2afZqia8AoujmQPwfMs8r2CMo6iaGbaeYrnKAiaaplUwp5x5pNP4zf0UGU4mMYyjrM6WAz23YQ/640?wx_fmt=jpeg)


　　

科技先生2月24日讯，小米今日在西班牙巴塞罗那举行发布会，发布了小米MIX3的5G版本以及海外版小米9。

　　

小米MIX3 5G版是全球首批5G商用手机之一，搭载了高通骁龙855处理器，同时整合骁龙X50 5G基带，**但由于5G功耗偏高，尤其是使用了外挂基带，小米MIX3 5G版的电池容量从3300mAh增大至3800mAh。**

　　

小米MIX3 5G版的下载速度最高可达2Gbps，可做到1秒下载一部15分钟的1080P电影(265MB)，或者26首MP3音乐。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YibrExb2afZqia8AoujmQPwfMic2C5GBibZchL2uhow8GujBoQYhT86LsxqYOicP1iahnEtrB4hOSGYGAMQ/640?wx_fmt=jpeg)


　　

小米官方还在现场通过欧洲运营商Orange演示了5G视频通话，并强调这是“真5G”，不是“假5G”。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YibrExb2afZqia8AoujmQPwfMqMbXFoibgicwwTg4hCSHaKYib6DoAYj1AFW1oia5oTsSZ2LcLRKZ9Tb4Vw/640?wx_fmt=jpeg)


　　

小米MIX3 5G版欧洲售价599欧元起(内存/存储不详)，约合人民币4560元，国内何时上市暂未公布。


![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4YibrExb2afZqia8AoujmQPwfM7AKQic1n7olj8egXUPicCM9k77DLHXz2SIaWMHb9SJ0Ykky5TOfSfg3w/640?wx_fmt=png)


　　

科技大V@万能的大熊 对此评论称：**现在高通的5G芯片不支持4G3G要外挂，估计发热可观。而且不支持sa组网，以后基站升级了，就没法用了。看看就行了，不用买，包括其他高通5G产品都一样。**


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YibrExb2afZqia8AoujmQPwfMvvvaibFTEcOpNKXFDO1GrWbgyKfZbqZj8ulBCy3icHIibNU8keGPX2iabA/640?wx_fmt=jpeg)


　　

小米高级副总裁、国际业务负责人王翔援引IDC数据称，2018年小米是全球智能手机市场第四名。此外，小米在西班牙公开市场也达到第一名。


![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4YibrExb2afZqia8AoujmQPwfMVQSjWLxkKsAzn4Fl2R7XZzXiaicr9uicJXV3CWUKVXMrS40jicZU8kGlEA/640?wx_fmt=png)


　　

现场，王翔展示了小米智能家居解决方案，比如手机控制灯光，语音控制电视，甚至开门自动打开窗帘。**但在语音演示中试了三次全部失败，只能在众目睽睽之下放弃演示。**
