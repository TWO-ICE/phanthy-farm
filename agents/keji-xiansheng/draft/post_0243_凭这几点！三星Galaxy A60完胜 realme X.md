# 凭这几点！三星Galaxy A60完胜 realme X

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4Y96w0Hz3FAyBm4b8KyvudYics2jsuJCtLwBfwFEuDYpvQ6ib4t7uTARqYhoXTAW2Oic9Qts8Pl9YS9dw/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/jxLq6jot8PxDMS8xbLpZiA

青春不留白，美好永留存，每一位年轻人都需要一部精美设计的手机，纤薄时尚的设计、出色的拍照能力、聪明的智慧交互是时代青年手机的三大关键要素。


![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4Y96w0Hz3FAyBm4b8KyvudYicoH3EjKFKZjWQnKfVSTX3xtW8ibXkWpwfE13MolSjTAnKpbZ48eqc2QA/640?wx_fmt=png)


近期，OPPO推出了一款realme X新品，售价跟最近火爆的三星Galaxy A60相近，一时间令消费者购机出现选择困难症。事实上，起步定价1499元的这两款手机，设计理念不同，各有千秋。


![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4Y96w0Hz3FAyBm4b8KyvudYic0m66uBDRLL9QaSaKQgElNcufdYtO4TQNeF0kTXE86C7xg0CklYRvxQ/640?wx_fmt=png)


　　

虽然realme X有花哨的弹出式镜头，也在个别元器件参数上做文章，却细节能力不足，有很多蹩脚的设计。相比之下，Galaxy A60配备了很多旗舰机级别的技术，在设计、拍照、AI等领域做到了旗舰机水准。

　　**设计风格不同，Galaxy A60性价比更高**　　

三星Galaxy A60采用跟Galaxy S10系列一样的屏下开孔设计，且是更加成熟的设计方案;而realme X采用旗舰级的升降摄像头，更为接近真全面屏，屏占比为91.2%。从视觉冲击力来看，三星Galaxy A60以91.8%的屏占比险胜realme X，后者下巴较宽，而前者还采用屏幕发声技术(仅限于听通话)。


![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4Y96w0Hz3FAyBm4b8KyvudYic57IHVAz0TZ7uZjfjQnlhvNaPU6l6ejf5ia7TPdia0MRfsA5wcVcTqYRw/640?wx_fmt=png)


　　

除了追求更好的屏幕显示效果，外观设计还越来越看重轻薄化机身和单手握持感。三星Galaxy A60机身厚度仅为7.9mm，比realme X(8.6mm-9.4mm)更为纤薄。同时，前者整机重量为168g，低于后者的191g，加上屏幕尺寸较小，因此更适合握持。


![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4Y96w0Hz3FAyBm4b8KyvudYicvs7d1oyaeMq72vRLa7ibRxUd9tmlljCqVHH3Zh0Zic3vmqrKsXR9aHjA/640?wx_fmt=png)


　　

在配色上，三星Galaxy A60拥有丹宁黑、浅滩蓝、暖阳橙三种配色，更加轻盈、时尚、现代，更加年轻纯净。realme X背部是中心竖向对称设计，有朋克蓝、蒸汽白两种配色选择，配色是偏传统的上一代渐变色，风格不同于Galaxy A60。

　　

在性价比方面，不能打马虎眼，三星电子还专为Online市场推出了GalaxyA60元气版， Galaxy A60 元气版搭载6G+64G存储空间，厂商建议零售价1499元，realme X是4G+64G起步，厂商建议零售价同样为1499元。虽然两款产品售价相同，但运行内存是不同的，显然，三星Galaxy A60元气版的性价比更高、运行效率会更高。如今，三星现在更加务实了，GalaxyA系列是高性价比的产品系列，还会配备很多三星高端旗舰机的新技术，三星在中国市场的产品策略已经发生巨变。

　　**123°超广角镜头是Galaxy A60的良心**　　

手机拍照是一项复杂的工程，摄像头和算法都很重要，单纯使用高像素镜头，效果不大，而关键性的超广角镜头却是直接影响拍照能力的关键要素。


![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4Y96w0Hz3FAyBm4b8KyvudYicwV6m57TfCJEcGdSepeVFJ7uBP0qkfv0YSI7Z2nmSZrEnCuuODE59aA/640?wx_fmt=png)


　　

Galaxy A60采用3200万像素主摄+500万像素景深+800万像素超广角后置三摄组合。鉴于三摄逐步将成为中端机标配，与realme X双摄方案相比，Galaxy A60三摄方案不仅带来曝光度控制和画面细节的提升，拍照功能和玩法也更丰富，更好地捕捉你眼中的真实世界。

　　

无论白天还是黑夜，3200万像素主摄能让你拍出清晰靓丽的照片;500万像素虚化镜头为人像拍摄添彩，随手拍出大片质感和艺术感;尤其800万像素的123°超广角摄像头，这是旗舰级配备，可以拍出更宽广的视界，这是最近一年多的旗舰手机的标配。


![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4Y96w0Hz3FAyBm4b8KyvudYichuoOY1NJ4lL1E9O7LzZru2kJam69nGvW09uhnTzIf2CfxJkTFvQvibA/640?wx_fmt=png)


　　

相比之下，realme X是后置双摄，无广角镜头，只是普通双摄，在拍照能力上无法匹敌Galaxy A60。现在的手机拍照早已过了拼单一镜头像素数的阶段，而是超广角时代、艺术化摄影时代，因此三星Galaxy A60在硬件设计、拍照算法两大方面无疑是全面领先于realme X。

　　

对于年轻人来说，拍照能力是第一要素，三星Galaxy A60优势明显，而realme X弹出镜头设计只是更加花哨、噱头罢了，只是为了屏幕结构的设计做出的妥协。

　　**AI是Galaxy A60的强项，却是realme X的弱项**　　

有人拿高通的675、710两个芯片做文章，却忽视了一点，这两款芯片的性能差异很小，而Galaxy A60采用的675是采用第三代AI引擎的高通芯片。

　　

当然，真正的AI差距在于软件层面，三星Galaxy A60内置了theNew Bixby，新一代Bixby更加聪明，完全是领先于同行业的超级AI助理.Bixby强大之处不仅在于精准语音识别和响应，更在于和操作系统的深度耦合，这是行业最高水准。相比之下，realme X的AI能力却拿不出手来，无论硬件，还是软件，都无法和Galaxy A60的AI能力抗衡，这是一个不争的事实。毕竟三星是全球第一手机厂商，在人工智能方面布局很深，Bixby的领先不是偶然的，这也是OPPO需要奋力追赶的地方。


![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4Y96w0Hz3FAyBm4b8KyvudYicd7RmCkZzBEdLUDvCszUYWCNSpEHLwQrNwFwmXWUTgVzNkEnvrUzLCQ/640?wx_fmt=png)


　　

此外，三星Galaxy A60还支持NFC，而realme X不支持，这可能是OPPO产品设计的一个缺憾。不支持NFC的话，地铁、公交出行的便利度会大打折扣，因为NFC比一些花哨设计更加实用一些。

　　

顺便提一下，三星Galaxy A60搭载了Samsung One UI操作系统，交互体验非常好，界面很清爽，运行速度也很快。realme X碰瓷Galaxy A60，并不是太明智的选择，也许三星很高兴，友商帮着宣传带货了，而OPPO需要找对realme在国内市场的定位和策略。
