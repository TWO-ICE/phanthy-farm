# 美国大面积互联网电信故障，这些海外运营商果断选择华为！

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4Y8k8OQlkQJMtZYDXWwt7euiaTdLyOw5KC9Xsw1MWBpevzAZ3wZiayx3wiazpCAgZ3uwYHarhRvJ9pnew/0?wx_fmt=jpeg)

![图片](https://mmbiz.qpic.cn/mmbiz_gif/P3SqL3Qw4YibTH6HfT3Nz0CialmxoGMzibX9mGBicmAKqfXL3FvxGzDwUFy6Nrb90PVT4ds3TSSPYbEVgcaKIRR0aQ/640?wx_fmt=gif)


据CNBC报道称，美国电信运营商CenturyLink出现了故障，这导致当地不少用户无法上网。牵扯的地区比较多，本次CenturyLink断网持续时间较长。**这次网络中断使华盛顿州西部部分地区的911紧急呼叫服务中断。**Verizon表示，该公司在新墨西哥州的阿尔伯克基和蒙大拿州的部分地区出现了服务中断。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8k8OQlkQJMtZYDXWwt7euiayMRZmxxG93WP5c4PB7NP0VicExqjWXQyg8LVZ6tr7PVX5oeakqiah6pQ/640?wx_fmt=jpeg)


此前据相关报道，由于英国运营商O2遭遇严重的故障，英国多达3200万用户的手机信号完全中断，上网、打电话和发短信都无法实现。**后来被证实是爱立信的问题。另外使用爱立信电信设备的日运营商Softbank近3000万用户手机也遭遇断网，数小时后Softbank方面才恢复正常服务。**O2的网络故障更是持续了近30个小时才恢复。此前O2曾出现过多次网络中断。


**“最近由第三方独立评估机构CFI颁布的报告也显示，华为设备运行的稳定性和可靠性连续三年远远高于行业的水平。”近日华为轮值董事长胡厚崑表示：“我们看到的事实是——华为过去三十年里没有发生过严重的网络事故、没有网络安全隐患、没有任何证据证明华为在做有损于任何国家安全的事情。”**


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8k8OQlkQJMtZYDXWwt7euiaSMbNSALZnBHA7u4Czfr4jS8A5lrpuK46shr1amaG5y0s2EFVicPVLsg/640?wx_fmt=jpeg)


美对华为一再采取行动，试图影响华为在全球范围内的快速发展，但一些海外运营商却相信华为，坚定选择华为。**据《金融时报》报道，英国移动运营商O2将于明年1月测试华为的5G设备，该运营商将在伦敦的200个蜂窝基站部署华为设备。BT/EE和沃达丰均已使用华为设备启动了5G测试，而3公司更与华为就其20亿英镑的5G网络建设达成了协议。**


据韩媒报道，**韩国移动运营商LG U+ CEO兼副董事长Ha Hyun-hwoi明确表示，该公司认为其5G网络基础设施中使用的华为设备并不存在任何安全威胁。**LG U+使用华为的主要原因在于，5G基础设施需要与现有的4G LTE网络设备一起协同构建，而LG U+的LTE网络部分采用了华为设备。LG U+已经建设了5500个5G基站，据称其本土竞争对手们则才建设了不到1000个5G基站。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8k8OQlkQJMtZYDXWwt7euiaGxQEzoY76xDmoMibfuJmsY5Ql01TvntVQ8RUiaUSUsVWTzY8KLLC2rwA/640?wx_fmt=jpeg)


12月13日在米兰举办的沃达丰5G论坛上，**意大利沃达丰首席执行官奥尔多·比西欧（Aldo Bisio）表示，华为是5G网络的最佳合作伙伴，将会继续与华为合作。**华为是一家已经取得巨大市场空间的领军者，这得益于其卓越的技术能力和最佳技能，并充分将这种技能开放给电信运营商。从技术先进性和性能的角度来看，华为无疑是最卓越的供应商之一。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8k8OQlkQJMtZYDXWwt7euiam0CtEIokWGjkLNGI5MOia9AZzDXKQ2ibrVnXFdo7pnGQH69Lakpia0jibg/640?wx_fmt=jpeg)


“不因一时一事的恶性事件、挫折消沉了我们领先世界的锐气。我们会越挫越勇，相反是这些极端不公平事件，把我们逼向了世界第一。”华为轮值董事长郭平说：“沉舟侧畔千帆过，乘风破浪会有时，任何艰难困苦，休想阻挡我们前进的步伐。”相信只要华为在技术研发道路上坚定走下去，未来华为的实力肯定会更强。
