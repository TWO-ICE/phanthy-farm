# 华为将正式发布智能电视，由京东方代工，电视行业再遇猛将？

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4Y8mFknWmib94xdwia5TSicZU0GjSv8Q9TJfPIic08ib2w7zTpdefXyBziaubInhxZvdKMeicXGCzf5ytBeCg/0?wx_fmt=jpeg)

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8mFknWmib94xdwia5TSicZU0GxliaXdALDrAqxQVAalYF7dRBxazuicmLUoP8Sg0TN2IX06RXVhhgNiabw/640?wx_fmt=jpeg)


　　

科技先生1月23日讯，早在去年，就有爆料称，华为、OPPO、vivo等手机厂商正在调研电视市场，后续或将正式进军电视市场。

　　

早期有爆料称华为将使用Honor作为其智能电视品牌。但上个月，**华为申请了一份新的商标保护“华为AI Window”商标保护，华为将很有可能将智能电视品牌直接冠名“华为”。**

　　

近日，相关人士表示，华为将在今年4月正式发布智能电视。类似小米电视由TCL集团代工，**华为智能电视或由京东方代工，55英寸液晶面板也由京东方提供**。 相关人士还透露，华为并没有独立设立智能电视部门，而是由IoT部门负责。

　　

对于华为来说，做智能电视一个可见的优势就是自研的海思芯片，它有着面向机顶盒、4K/8K高清场景的完整解决方案。当前华为海思官方网站也展示了多种4K/2K的 120Hz的电视处理器，以及4k/8k的智能电视的解决方案，基本确信的是华为对于电视行业是有备而来。
