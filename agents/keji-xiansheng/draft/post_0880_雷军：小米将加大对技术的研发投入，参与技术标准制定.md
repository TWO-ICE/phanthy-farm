# 雷军：小米将加大对技术的研发投入，参与技术标准制定

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4Yic2VJFS1jFhpMdicYWMXvfaPe9cjjSPIeFPZiaeJybdTVahnMAPbJ8DCbYHKiad46QOFVWTCXx5osr2g/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/DEHuT_ktCaxx9foOTbk7PQ

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Yic2VJFS1jFhpMdicYWMXvfaPoqHEpJcUgicCiccKaaPicUBZOU92tuy9aklxuS1jMk7SbxN8vuql7O1zA/640?wx_fmt=jpeg)


　　

科技先生4月30日讯，雷军在个人微信公众号宣布，公司今天任命了小米集团技术委员会的18名委员、2名顾问委员会委员以及秘书长，进一步完善了小米的技术组织架构。


此外，雷军表示，将持续加大对技术的研发投入，同时继续提升研发分摊成本的水平。**过去三年，小米研发投入达111亿，2018年投入58亿，较上一年提高83.3%。**

　　

雷军宣布任命时表示，小米将持续加大研发投入，继续提升研发效率，强化预研探索，同时继续提升研发分摊成本的水平。同时今后每年将设立百万元级别的重奖，激励小米的技术人才做出创新突破，以多种形式的奖励，让技术人才获得荣誉和尊重。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Yic2VJFS1jFhpMdicYWMXvfaPxzbT82ICw63TGjRkia4Ccyv58JeIc4XYicicJFRX4a7MwIyZDibkZqCZ8g/640?wx_fmt=jpeg)


　　

在谈到小米成立集团技术委员会将带来哪些变化时，雷军表示，第一，技术委员会最重要的意义就在于，我们在业务管理之外，增加了技术职能的管理；**第二，我们将持续加大对技术的研发投入；**第三、我们将建立起年轻化、高端化、规模化的人才梯队；**第四、我们将更大规模地参与国内外技术标准的制定。**

　　

此外，雷军还表示，将持续扩大技术人才队伍规模，除了北京总部之外，未来计划在南京和武汉，再建两个万人规模的技术研发中心，为小米创业第二阶段做好人才储备。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Yic2VJFS1jFhpMdicYWMXvfaPNpjauhibLuoy1ZmqcLaVsNEgCqZI1cmv6wEvDflUXI8UJdlwBmjuatg/640?wx_fmt=jpeg)


　　

此前，雷军在2018年4月25日的一段采访表示：我自己是做技术的，过去两年手机的研发是我自己管的，我一直在做研发。研发费用的本质不是越多越好，如果越多越好，微软不就成了日不落帝国？**其实，几乎所有的重大创新都是小公司干的，搜索引擎是(规模很小时候的)谷歌干的吧？你看，苹果的研发费用占比很低，微软很高，IBM很高，没用呀。**

　　

雷军：“我不同意华为(研发费用率要持续高于10%)的说法，我觉得是他们不懂研发，(高管)不(亲自)做研发。我们小米所有的创始人都是研发背景，我们干了一辈子研发。
