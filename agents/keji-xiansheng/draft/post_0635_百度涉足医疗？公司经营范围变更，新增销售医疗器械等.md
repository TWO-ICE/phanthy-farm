# 百度涉足医疗？公司经营范围变更，新增销售医疗器械等

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4Yiblrhia6SjDoltUz7bXPcwO1xEibvRUJSW8522IicbTtsFxK9I7jp4gRRICiabAdMwY6PibPS69CFbtlSg/0?wx_fmt=jpeg)

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Yiblrhia6SjDoltUz7bXPcwO1iaI6zZlMnmwDjg3a8DUnpDZmolohmHNkkVLX1xmAibNKxdOI60JgbpyQ/640?wx_fmt=jpeg)


据企查查信息显示，近日，百度在线网络技术(北京)有限公司工商信息发生变更，经营范围新增“销售第三类医疗器械”“销售医疗器械II类”“软件开发”等内容。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Yiblrhia6SjDoltUz7bXPcwO1Rv1mNBWR7PBlx0QysShs5nPuYAsZFicRTj9nibCqqOcbEC9JkdhCxrlQ/640?wx_fmt=jpeg)


对此，百度回应称：


> 百度将向全国500个贫困县医疗点捐赠AI眼底筛查一体机，覆盖5600万眼疾风险人群，但依据国家相关法规要求，需要先在营业执照增加医疗器械经营资质，才可以进行相关硬件的采购及捐赠行为。该产品已在去年百度世界大会进行发布。


目前国家药品监督管理局网站上，关于百度的第二、三类医疗器械经营和生产备案，仍查询不到相关信息。


百度在医疗领域布局已有多年但进展并不顺利。2015年，百度曾发布了在线医疗服务平台“百度医生”，面向患者和医生两端，主打医患双选。但2017年3月，“百度医生”因百度公司业务调整而关闭。
