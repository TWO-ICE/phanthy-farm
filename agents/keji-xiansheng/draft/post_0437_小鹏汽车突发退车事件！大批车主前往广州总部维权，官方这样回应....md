# 小鹏汽车突发退车事件！大批车主前往广州总部维权，官方这样回应...

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4Y8h3kpy0JHAFRcTB35LDqSdhwn8hkI82bAft7oTHQI1ux1qIxT7icPmGiayadufHibpZdj4oIVaAic74w/0?wx_fmt=jpeg)

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8h3kpy0JHAFRcTB35LDqSd1nuB3UJiaP5OI87Qc6gvOt6w5zDGyMqAMNNSjBMx3GOHIyDnwjRedSg/640?wx_fmt=jpeg)


　　

科技先生7月15日讯，近日，小鹏汽车发布了2020款G3车型，然而消息公布之后，不少2019款小鹏G3车主对此感到不满。有老车主发现，2020款小鹏G3续航提升不少，价格却并没有相差很多，部分型号车型甚至更便宜了。**从对比售价来看，续航里程520KM车型的起售价为15.98万元，几乎与2019年款小鹏G3的价格差不多，但续航里程却要多出169KM。**

　　

有车主表示，他以16.28万元的价格，购买了2019款智享版，并于7月4日提了车，**但是在6天以后，小鹏汽车就推出了新款，可以以更低的价格，购买到续航里程更长的新款车。**


![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4Y8h3kpy0JHAFRcTB35LDqSdqECfyQdsm8tHwNls8fj180mzkKSLTUObxfMIRxdzUExXqSut6E8EkQ/640?wx_fmt=png)


　　

在与小鹏汽车沟通的过程中，**这些车主得知，小鹏汽车的工作人员在5月初就得知小鹏汽车即将推出新款，但由于跟公司签署了保密协议，所以并未告知消费者这一信息。**

　　

7月13日，多名车主到上海、广州等地的小鹏汽车城市服务中心维权，希望能退换车或免费升级续航。

　　

根据相关视频，小鹏汽车总部附近停车位上停放着多辆小鹏汽车，不少车辆车身上贴着印有“退车”“谁买谁后悔”“车漆薄如纸”等字眼的纸。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8h3kpy0JHAFRcTB35LDqSdsia6BePiaVdvxibR4WiaNVRialmzGUdDicIanftoRdKHFxsEq7KE5POibsUGg/640?wx_fmt=jpeg)


　　

有些人甚至还没提车，就被告知一样的价格只能选择低续航版。**“如果去年提车，今年出的新款，那大家都理解。****但是，一年内新车变老款、变绝版，谁都接受不了。****”**

　　

对此，小鹏汽车对于老车主给出了相应的补偿条款，但是他们似乎并不买账，纷纷要求退车。


![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4Y8h3kpy0JHAFRcTB35LDqSdFa3g7tiag4L6Fia5fus5Zwh7qF1OaHcrLfcm9sEbGNt3ZCU9afcmu2Yg/640?wx_fmt=png)


　　

而此前因为和巴菲特共进午餐而被人知晓的90后创业者孙宇晨更是在微博表示，个人愿意拿出1000万人民币支持小鹏汽车车主进行维权。他连发两条微博表达对车主向小鹏汽车进行维权的支持，**甚至称个人将“先拿出一千万人民币作为法律起诉保证金”，并将对起诉小鹏汽车的消费者“个人补贴80%法律费用直至官方给出翻译解决方案”。**


![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4Y8h3kpy0JHAFRcTB35LDqSdjjWNzRgtG8m9vHKvwNK9bZ3B4SjNaenkjCGngkzZNm0DDKWAcic12Uw/640?wx_fmt=png)


对于孙宇晨的这番行为，有网友表示对他支持维权的肯定：


![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4Y8h3kpy0JHAFRcTB35LDqSd2nEqJvyQnG8cFecTwcc7Plk9lSu8QbF9R7JAKhHADQUW87Ilg61u1g/640?wx_fmt=png)


　　

目前小鹏汽车为了安抚老车主，给出了补偿方案：小鹏汽车会给G3 2019款的所有个人车主(包括家人)一个道歉和补偿：从即日(7月12日)起，3年之内增换购小鹏汽车任何一款车型时，在享受拟购买新车当期所有促销政策权益的基础上，额外享受10000元专属补贴权益。**对于部分车主提出的更换电池以提高续航，何小鹏称“确实没办法”。**

　　

但是显然这个方案并没有得到消费者的认可，该赔偿方案被部分车主认为是变相推销。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8h3kpy0JHAFRcTB35LDqSdOnlh77IcBibEqpD9P3vlZVa80VVh8RvCOS2BDeqtfmWBvEbpUMllPSw/640?wx_fmt=jpeg)


　　

当被问及“等明年推出新款汽车时，小鹏汽车要怎么避免这样的情况再度发生”时，小鹏汽车的工作人员称，**“任何一款产品都会面临创新和迭代的问题，明年会不会再出现这个问题，要到明年那个节点再去看。****”**


**小鹏汽车今日回应老车主退车事件称：****“7月13日我们已经做了良性沟通，收集了车主们的合理诉求，反馈给高层。****车主们也表示理解，希望双方能够得出一个都能满意并且合理合法的解决方案。****”**


电动汽车观察家邱锴俊表示，车企肯定也是有步骤有计划地推出新车型，关键是小鹏的一线营销人员是否误导消费者。“有的车主说销售人员明确否认近期会推新车型，还可能涨价。这属于营销管理问题。”


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8h3kpy0JHAFRcTB35LDqSdYK68PlibjPTpcEuxCV7mYm6K6HG65K8MiaKnHjZswiajgiciauHShKXU1zg/640?wx_fmt=jpeg)


　　

今年3月，特斯拉在旧金山联邦法院向曹光植提起诉讼，指控其把超过30万个文件和目录以及源代码副本上传到他的iCloud帐户后，于1月3日突然离职，涉嫌窃取特斯拉公司商业机密，并将其带给中国电动汽车初创企业小鹏汽车。

　　

而在3月，小鹏汽车官方回应称：本案件中有很多与事实不相符的描述，并称这种无端指责不会压制创新，未来还会引进更多科技人才。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8h3kpy0JHAFRcTB35LDqSdDT8taBUic6dwf6rWIWvMJ29vOuuENdOMkyqSNprx5oOyV6aibGAcjoXw/640?wx_fmt=jpeg)


　　

近日，据腾讯科技援引外媒报道，**特斯拉前工程师曹光植本周在一份法庭文件中承认，他在2018年末曾向自己的iCloud云账户备份了包含AutoPilot源代码的压缩文件。****而他当时仍在特斯拉工作。**

　　

但曹光植也强调，那时候仍在职为特斯拉工作。后来离职特斯拉时，就已经在删除相关文件。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8h3kpy0JHAFRcTB35LDqSdOfjegCwnKgIkFeCYFHDbS2X1BBdelib7ACjPA0LeYd4VvURzQrghPUA/640?wx_fmt=jpeg)


**曹的律师辩称，曹光植在离开特斯拉之前，已经删除了留存的任何和特斯拉相关的文件。****在他离开特斯拉后，其设备上残留的任何源代码或其他机密信息，都只是“出于疏忽”。**他们还辩称，在离开公司后，曹广志“没有访问、也没有使用任何’Autopilot商业机密’”，也没有向小鹏汽车转移任何信息。

　　

据了解，曹光植在2018年12月13日收到了小鹏发来的录用通知，当时他还在特斯拉任职，他在12月26日前后将其iCloud账户与公司的电脑断开，但是一直到今年1月1日他在特斯拉期间电脑都是保持登陆状态。

　　

**不过，曹光植在法庭文件中并没有承认自己删除了iCloud上的文件，只是说做了大量的工作。**

　　

特斯拉还声称，曹光植2月份在小鹏招募了另一名Autopilot员工。

　　

根据双方的法庭申请，曹光植已经给特斯拉提供了对方所需的数字图像等信息，并允许访问他的Gmail账户进行取证分析，目前分析已在进行中。
