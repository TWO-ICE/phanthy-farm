3、解决生产环境出现的各类问题，提升产品可用性和可维护性；任职要求：1、5年C++以上开发经验，计算机相关专业；

2、深刻理解面向对象编程，熟悉STL等标准库，能够完成高质量编码；

6、具有视频流媒体编程经验者优先。

 

**自动化测试高级工程师-T3以上**

职位描述：

1. 负责计算机视觉领域各类软件产品的测试工作；

2. 制定测试计划、确定测试策略、设计测试用例、缺陷管理、综合评估产品质量风险；

3. 根据产品和项目特点，设计自动化测试方案及对应工具，提高测试效率；

4. 负责实现软件系统的持续集成-持续交付-持续部署全流程闭环。任职要求：1. 计算机及相关专业本科以上学历，3年以上工作经验；

2. 熟悉软件测试理论和方法，具有互联网产品、大型软件系统测试/开发经验；

3. 熟悉Linux操作系统；熟悉自动化测试相关工具及框架；

4. 至少熟练使用Python/C++/Java任意一种编程语言； 

5. 具备较强的分析能力，能够灵活借助各种技术和工具解决问题；

6. 具有良好的团队合作精神和积极主动的沟通意识。

 

**项目管理专家-P4.1-4.2**

职位描述：

1. 方案+客户项目实施负责人，对方案+客户项目的落地实施全流程负责；

2. 对方案+项目结果进行规划和估算，制定总体目标和要求；

3. 对方案+项目过程进行详细计划、分解，具体分解各任务的活动、时间、资源、成本；

4. 预先规划好项目的质量、风险、沟通；

5. 明确项目（任务、工作）的责任人、牵头人、执行人（包括所有项目干系人的责任）；

6. 明确与项目参与方的责任、授权及考核标准；

7. 明确项目成员的评审标准和考核指标；

8. 关注项目成员的能力培养和项目的知识沉淀。任职要求：1. 本科及以上学历，企业管理、物流管理等相关专业毕业，10年以上工作经验；

2. 深刻理解快递、物流行业政策及新商业模式，对快递、物流行业的营运模式也有深入地研究；

3. 具备项目管理经验，有较强的组织能力、谈判能力、资源调度能力、关注实效；

4. 熟悉SWOT分析模型；

5. 优秀的职业操守，认真负责，逻辑性强，具备良好的沟通表达能力和分析判断能力

 

**高级产品经理-T3以上**

职位描述：

1、了解行业动向，结合现状准确寻找市场切入点，为产品研发部门提供开发方向；

2、通过调研和分析准确把握用户需求，完成产品策划、原型设计、体验设计、上线运营；

3、基于市场销售情况，分析、判断各产品的生命周期及后续的跟进措施；任职要求：1、本科及以上学历，3年或以上安防视频智能分析平台类产品经理工作经验，策划过正式上线的产品，参与整个产品周期的工作，拥有公共安全视频大数据类产品经验者优先；

2、对用户体验有深刻理解和认识，能始终从用户角度出发；

3、对数据分析，分析工具有深入理解和经验，并有能力独立深入挖掘数据，发现机会、解决问题；

4、良好的团队领导力和团队协调能力，出色的组织和沟通能力，具有较强的逻辑能力和系统策划能力；

5、熟练使用Axure、PPT、Word、Visio等产品策划工具，熟悉产品线流程图、产品需求文档(PRD)及技术功能描述文档的撰写；

6、对流行商业模式有很强的敏锐度、领悟力强、思维活跃。

 

**人力资源系统研发部负责人-T3.3/T4.1**

职位描述：

1、基于公司系统业务现状，分析并负责系统架构设计及研发工作；

2、负责公司HR产品的产品规划、业务流程梳理、业务设计与验证，详细需求分析，架构设计，研发质量管控，上线运营推广；

3、收集用户反馈，对产品进行持续的改进和优化。任职要求：1、本科及以上学历，计算机或相关专业；

2、有HR系统信息化相关经验；

3、带过至少40人以上团队，有过整体业务流程设计，研发，推广经验；

3、较强的逻辑思维、抽象思维沟通表达能力，能全面准确分析复杂事物，并能用简洁明了的方式描述其中的关系；

4、具有出色的沟通能力、团队协作能力，至少作为第一责任人的身份直接承担或实施过20万人以上集团公司HR系统的经验；

5、有丰富的研发管理经验，熟悉敏捷模式的需求及研发管理工作

6、积极主动，追求卓越，责任心强，结果导向。
