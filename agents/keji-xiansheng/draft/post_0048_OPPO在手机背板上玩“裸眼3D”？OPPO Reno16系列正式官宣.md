# OPPO在手机背板上玩“裸眼3D”？OPPO Reno16系列正式官宣

![封面图](https://mmbiz.qpic.cn/sz_mmbiz_jpg/MIticZoxzAyvoAM2JTk9aUTqZMSxJjMApc5d8wbuEZwoywdg2iaavMlicIicavRyqBoONk9JvujBCUCYW22YvzaicFRA0RAib49oaL7sESmVwmlR4/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/MgWo0gxxf0H-q5K3Y93mJA

今天上午，OPPO正式官宣Reno16系列，其3D悬浮星球的外观效果引发热议。真机背板上，一颗完整的小星球漂浮于玻璃之上，无需任何辅助设备，肉眼就可看到真实的悬浮立体感。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/MIticZoxzAytophLBvpKib5mazib66mEdOLLpusFq4s036D95qibFnic2DdicjMeS8qCY9lHr0zT0ucibj5yZthb3sMtCctDOAQ8gV4VdkN9tbemW0/640?wx_fmt=jpeg&from=appmsg&tp=webp)


悬浮星球背后，是OPPO首创的3D冰透悬浮工艺。其原理是在微纳米尺度下，精密排布数百万个微透镜改变光路，使“碎片化”的微图案在空间中集成聚焦，产生裸眼可见的空间深度与悬浮感，实现真3D悬浮图像的视觉效果。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/MIticZoxzAyudT9QFIkSXIP7KMHicqTwxJZqB30h2IAUKiaH4ttKxGsd3N9XeL4PuasjkFDNoSa5tmfghGf7Z4p8bXVTyV95R50nEZYMHeH6DQ/640?wx_fmt=jpeg&from=appmsg&tp=webp)


这是手机行业首次将真3D悬浮图像做到百万级规模化量产，打破了传统手机后盖的平面视觉局限。据相关技术人员分析，这项工艺的难点在于构建“连续空间成像”——连续视差没有断层，用灯光照射时，星球下方会出现真实的影子，且影子会随光源移动而变化，这使其与其他3D工艺形成了显著区分。


回顾OPPO在外观设计上的探索，Reno系列一直是最具实验性的产品线。从Y2K甜酷美学到温柔人鱼美学，再到Reno15的全息光刻蝴蝶结，每一代都将前沿工艺与潮流美学深度融合。旗舰产品线同样在持续推进外观工艺的边界：Find X8s的极窄边框、Find N5的最薄折叠机身、Find N6的无折痕屏幕，都体现了OPPO在精密制造上的持续投入。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/MIticZoxzAyspR0VpCLibx9Su9RPia7jZQUsQRREkfyPd23HX5CjVOI2ZnzibxowHaq64mjAnGPicogYrW1qKjN1Gme9mcpTVGjOIDQcTrZete40/640?wx_fmt=jpeg&from=appmsg&tp=webp)


从平面到立体，从装饰到情感，OPPO以领先工艺拓展手机外观设计边界。值得注意的是，网友与博主纷纷反馈，Reno16是“史上最难拍”的一部Reno手机，图片与视频都难以还原其3D悬浮效果，感兴趣的朋友可前往线下门店实际体验，感受3D冰透悬浮工艺的独特魅力。
