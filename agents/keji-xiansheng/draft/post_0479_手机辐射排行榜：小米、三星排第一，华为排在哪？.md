# 手机辐射排行榜：小米、三星排第一，华为排在哪？

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4Yibhk8paoy0qlfl3Kj3eqQHHhzwsMSlKjiaVU2AWVBMA3I74YTSG9uL8lJvalRZUXaug754yyzibbYMA/0?wx_fmt=jpeg)

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Yibhk8paoy0qlfl3Kj3eqQHHQxZSPFwq1ePKmibQqRpE84vasj9YdZ8qr4sR1TtlAB8JR6PPHcLhLXQ/640?wx_fmt=jpeg)


科技先生2月11日讯，近日，**德国联邦辐射防护办公室发布了2份关于手机辐射的测试结果榜单**，分别列出了部分型号手机的辐射数值，数值单位为瓦特/千克。榜单分为两份，分别是辐射最高的手机榜单与辐射最低的手机榜单，每个榜单分别有16款手机。

　　

从榜单来看，上榜的手机都是目前热度最高的机型，也就是说使用的人群是非常多的。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Yibhk8paoy0qlfl3Kj3eqQHH1UUOjFgm6m0M5ian3hNecoeJBWxU8enuCObr1ua1B0xzia5Dp5UJcDEA/640?wx_fmt=jpeg)


从上图辐射最高的手机排行榜来看，前三名小米占据了2个席位，分别是小米A1以及小米Max 3，而一加5T排在第二位。**有趣的是，小米在这份榜单中一共有四款手机上榜，其余2款是小米Mix 3、红米Note5。**像国内的华为、魅族、锤子手机等厂商都没有进入该榜单。

　　

同时，德国联邦辐射防护办公室还公布了一份手机辐射最低的榜单。结果从16个排名中，三星有8个型号上榜，霸占了一半的榜单，而且排名都比较靠前。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Yibhk8paoy0qlfl3Kj3eqQHHwgIwE820MwYumoyjc3Yn4l5jMYMER1Hnbk8ElqMEHpQUfxvMSftaYA/640?wx_fmt=jpeg)


对于这两份榜单，还是比较意外的。因为目前全球排名第三的华为，居然没有任何一款手机上榜。


但总体来说，三星手机辐射最低，而小米、一加辐射偏高，不过手机辐射是相对安全的一种辐射，目前没有证据表明手机辐射会对人体造成伤害。
