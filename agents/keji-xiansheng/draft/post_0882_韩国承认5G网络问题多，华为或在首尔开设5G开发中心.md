# 韩国承认5G网络问题多，华为或在首尔开设5G开发中心

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4Yibm43JZ6ibqtbj3VzdtPFyTtsAl3Pib9Hf6WJHZHFrtAXywGv7UBS4YBPIIXE2NrM4ic7Q5C6YfMp57w/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/saIjg2lOfts1miKq6lgk_w

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Yibm43JZ6ibqtbj3VzdtPFyTttH5tQkoTibS8yCZtW0E3aic6PIY2lAYU5gqSkJY2wJ5BBefo3ENfFKNA/640?wx_fmt=jpeg)


　　

本月初，三星在韩国正式发售了Galaxy S10 5G版手机，拉开了5G手机商用的序幕。自此，韩国也成为了全球第一个5G商用的国家，**但据外媒消息，韩国SK电信、韩国电信和LG集团旗下的LG Uplus都公开承认他们的5G网络存在服务品质问题**，另外，一些用户一直抱怨他们的服务不像所宣传的那样快捷和安全。

　　

LG Uplus在周五会议上援引其董事长Ha Hyeon-hoe的话说：“现在是时候集中力量，让我们达到5G网络的最佳品质。”


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Yibm43JZ6ibqtbj3VzdtPFyTtMhib9UBVG2G3iaGR07wNTckZYJYSRpqaGibn2F68f1xSmtG7Toc34mYWQ/640?wx_fmt=jpeg)


　　

华为早些时候表示将设立5G开发中心，并与欧洲、中东和亚洲的本地公司合作，在韩国加速启动5G服务后，**一位未具名的IT人士透露，华为下个月将在首尔开设其全球首个5G服务开发中心。**

　　

据了解，华为在韩国建设的这一5G服务开发中心是专门帮助韩国公司和消费者体验5G，并开发5G相关服务。目前，华为已经向全球40多家电信运营商提供5G设备，并以此为契机向全球推广5G服务。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Yibm43JZ6ibqtbj3VzdtPFyTtuNwgADfQqCP9YN9pH4FGg2M6L1p6Ha5ibia3X5rBbAibyTOh378QFP52A/640?wx_fmt=jpeg)


　　

值得一提的是，其实华为早在2007年就已经进入韩国市场，并开始为韩国的第三大运营商LG U+提供4G设备。**据此前消息，华为在韩国已经是第二大5G设备供应商，目前已有超10万人成功尝鲜5G。**

　　

不过，华为的手机业务也有不少产品是从韩国三星、SK海力士采购，仅去年一年，华为就从这两家公司采购了超过100亿美元的产品。
