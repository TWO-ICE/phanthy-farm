# 华为P30银河样张造假？摄影师公布样张，质疑者道歉！

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4Y8rOeSb4eIffnClzgImo3OBx5Xuz5wkIAkp5K96ep7JBYDpw0ORUEfVuLfS26CBuictkNqGqh6xO8g/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/PcVzqOGGvldoiyTrtE2LZA

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8rOeSb4eIffnClzgImo3OBXhzwv7YrMJeic8vaHyTQziafUADKLianwJzffHibsmvgraibfp6gAawzhTQ/640?wx_fmt=jpeg)


　　

科技先生3月29日讯，3月26日晚上，华为在巴黎发布了P30系列手机。在发布会上，人们印象最深刻的地方还是那让人惊艳的摄影性能，特别是那张拍银河的样张让人大呼不可思议。

　　

**华为余承东也在发布会上表示“ Galaxy can't see the galaxy, but HW can... ”**，这个可以说是发布会上一个特别有意思的点了，就是讽刺三星银河S10+拍不出来银河，但是华为可以。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8rOeSb4eIffnClzgImo3OBRPtPic1f6e31thiaK4jZtEFakPewneEmUwYkFXdEOibOo5o19eM4A3s5w/640?wx_fmt=jpeg)


　　

三星在官方微博上反击华为，配图及文字暗示华为的银河样张是用单反拍了造假的。

　　

**同时，华为展示的银河照样张也引发了一些专业的摄影师怀疑，认为手机不可能拍出这样的照片，暗示样张是单反造假的。**


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8rOeSb4eIffnClzgImo3OBTBlHYD8uCKo0mTYQOdSDlZ2Hib1CAWP49xq1YSFfkCLGm9ibLRKbKOAQ/640?wx_fmt=jpeg)


　　

面对网络上逐渐增多的质疑，这次拍摄P30 Pro样张的摄影师木西AlexanDeng在微博发布了拍照样张，他本人是四川省摄影家协会会员、中国创意摄影展十佳创意摄影师，详细的样张信息可以去他页面查看。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8rOeSb4eIffnClzgImo3OBGpd64zqZhekew0S5sf9iascia7IDGeI7U8P7OYicRUnvBu8IXSxgKHNiaw/640?wx_fmt=jpeg)


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8rOeSb4eIffnClzgImo3OBvRcbxPswf6m9wH5dMUuEIShz0gyLo7FfDANffDBic8U85Jgs4Nfc6rA/640?wx_fmt=jpeg)


　　

经过其他摄影师的检测，确认没有经过后期修改。


![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4Y8rOeSb4eIffnClzgImo3OBYmsicLd8lwPZzfZu3fCSgdCuWEpXbhZURkltwKPzXxlpepN35Lshfdw/640?wx_fmt=png)


　　

**据悉，经过一系列的求证和解释之后，此前质疑该银河样张作假的摄影师已经公开在朋友圈道歉。**


![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4Y8rOeSb4eIffnClzgImo3OByWToq9SqsohmRBNBrs8IaibUIdFp7JoPTHsVAx8CgLxqrckYef5MIEQ/640?wx_fmt=png)


　　

@木西AlexanDENG本人也在朋友圈表示，新事物来了，先学习，了解，再判断，是现代人对这个多样性世界的基本尊重。
