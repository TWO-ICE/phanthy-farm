# Redmi Note7 Pro发布！骁龙675+索尼4800万镜头

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4YicHeXUg0OTGHE8AergDOrrS3z2b8PJ57bH0qwbHibtqIp1xicBt5cZWgjSCLfDm67fnAZSWQDEGUxvQ/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/eYCdWbQrHyzePeKWTfcO-g

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YicHeXUg0OTGHE8AergDOrrScyd5hJABYVjicveWc5unbvhxic4dp2SZ4RPoBpeicUrqEZboDovVl2rMA/640?wx_fmt=jpeg)


科技先生3月18日讯，下午2点，Redmi如约在北京召开了新品发布会，这是Redmi品牌独立出来后的第二次发布会。


开场后，卢伟冰回顾了Redmi红米Note7上市不到一个月突破百万销量的好消息，并表示明天将会发布财报，公布迄今为止小金刚的总销量。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YicHeXUg0OTGHE8AergDOrrSTzkU5dJkzO3q80UVFPVic7Fyd1XQYOWhsbdicTdLFeu7Nbwzcmq4zJSw/640?wx_fmt=jpeg)


　　

外观方面，“Pro”与前代产品Redmi Note7并无区别，正面为6.3英寸水滴全面屏设计，4000毫安时的大电池，支持阳光屏和夜光屏，通过德国莱茵护眼认证。


背后两者也一样，左上角竖排双摄设计，搭载电容式指纹识别，支持红外遥控、3.5毫米耳机接口以及Smart PA大音量外放，机身的配色同样为暮光金、梦幻蓝和亮黑色三种。


![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4YicHeXUg0OTGHE8AergDOrrShlxwIlhA034IrLj4e5FSkoAF3sWHMCR9Uc7ricPKxhGUHG0DcByPXcA/640?wx_fmt=png)


　　

Note7采用三星GM1传感器，AI输出4800万像素，而Redmi Note7 Pro最大的升级无疑是采用了索尼IMX586传感器，这款传感器在小米9上使用过，之前市面上搭载IMX586的手机最低售价为1999元，是小米9 SE。


Redmi Note7 Pro的前置相机依然为1300万像素，支持背景虚化功能，支持小米的各项AI美颜技术，满足日常自拍需求。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YicHeXUg0OTGHE8AergDOrrSPNSd2ZSJ1YAuVWjiargovJumBib0TH3Q2UDWlbicuwhL142Z3KGQTBeLA/640?wx_fmt=jpeg)


　　

处理器方面，由原来的高通骁龙660AIE处理器升级为骁龙675，安兔兔跑分直接飙到了18万分。其采用了与高通骁龙855相同的第四代Kryo架构(675也是除855之外的唯一一款采用该架构的处理器)，加上11nm的工艺制程，CPU性能远超同系列的其它芯片产品，而单核心的运算速度甚至可与高通上代旗舰845媲美。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YicHeXUg0OTGHE8AergDOrrSnn7KMniacosIMMos4PwCuNKxET1v2I8dYUEAINiaeWYticWd0v2zCaKRw/640?wx_fmt=jpeg)


　　


另外，Redmi Note7上需要额外购买的18W快充头这次Note7 Pro也实现了标配，Note7上开创的行业首个18个月超长质保服务得到延续，同时增加整机P2i纳米防水，可以有效的防止雨水淋湿、意外溅水、潮气侵蚀和听筒汗液侵蚀对手机的损害。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YicHeXUg0OTGHE8AergDOrrSkDlmseLnQ8eA5XKBn8CGKdrrdLkCU7s4Hbj62ZRTcLj7uoibDLPuTHg/640?wx_fmt=jpeg)


　　

售价方面，Redmi Note7 Pro 6+128G定价1599元！继续死磕性价比！19日首批用户现货发售。

　　

发布会上，Redmi还带来了一款真正的千元机红米7，搭载全新的骁龙632处理器，是“神U骁龙625”的升级版本。起售价699元。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YicHeXUg0OTGHE8AergDOrrSPMItxKNSrGDuT4eEicoUV73iaCnlnuebPgXPZKVXllwRnsj61iagKNGicQ/640?wx_fmt=jpeg)


　　

同时还发布了两款生态链产品——Redmi AirDots 真无线蓝牙耳机及Redmi全自动波轮洗衣机1A 8kg。

　　

卢伟冰表示，“Redmi就是性价比之王!Redmi的目标不只是要做手机的性价比之王，而是要在每一个用户需要的领域都成为高品质和极致性价比的代名词”。
