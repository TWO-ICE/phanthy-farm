# 权健正式被调查！女大学生卧底权健纪录片曝光

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4Yicib8WTz8BVWyUscicKZ2rlkjG1zZUObgaZa4Jla6hibNHzD07yqbyLyicnH4CGyF49SwhNKbUbjf5jwQ/0?wx_fmt=jpeg)

![图片](https://mmbiz.qpic.cn/mmbiz_gif/P3SqL3Qw4YibTH6HfT3Nz0CialmxoGMzibX9mGBicmAKqfXL3FvxGzDwUFy6Nrb90PVT4ds3TSSPYbEVgcaKIRR0aQ/640?wx_fmt=gif)


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Yicib8WTz8BVWyUscicKZ2rlkj7krzvo8j9K2IPFlnKGRnxUCg0hwkicTyBZTk02rFsqczuJOJT9xmKHA/640?wx_fmt=jpeg)


　　

近日，权健事件闹得沸沸扬扬，而后因涉嫌虚假宣传等违法行为，国家有关部门已介入调查。在这样的风口浪尖上，#女大学生卧底权健#登上热搜，引发关注。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Yicib8WTz8BVWyUscicKZ2rlkjDc64RvveBRNr5XvNBEIbFYKicIN85KBn4kfAXmUehGmcg8X2Dic0TZMw/640?wx_fmt=jpeg)


　　

据悉，女大学生血风(艺名)曾卧底权健拍摄纪录片。她探访权健医院、权健经销商店铺等，参加权健内部很多会议。


血风说，在权健医院住院的病人警惕性都很高，医生护士很少，医院的大多数地方都空着，医疗器械不足。"这里不像是医院，更像是在拍戏。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Yicib8WTz8BVWyUscicKZ2rlkjccvpvxw2jCvibeBX0gChNuFtQuCFBO9KaHbpHf67CUyJGgpHNu0613A/640?wx_fmt=jpeg)


　　

其中，血风在采访一位病人时，对方称用了权健的产品很受益，在权健医院住院便宜，环境还相当地好，如果有会员卡的话还能打8折。对此，血风表示，自己从来都没有见过对方的产品，但知道其中的功效都是虚假的;不懂那些病人为何那么有信心，这些自信都是哪里来的。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Yicib8WTz8BVWyUscicKZ2rlkjSW0LRUH2K3pEsutCKnHMHE9bKSfqd4ZqSGffxfcMErUXwL5IljDFqw/640?wx_fmt=jpeg)


　　

据血风介绍，每次开会四面八方的人都会聚集于此，全国各地的人都会来。他们会议从早上5点钟开，一直到中午1点钟左右才休息吃饭。吃完午饭后又开始开会，一直开到晚上11点左右。那些参加会议的人，一整天就出于被宣传的状态，随即便失去了抵抗能力。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Yicib8WTz8BVWyUscicKZ2rlkjqcGIUgOBiaA4Hl3PZEVd3nibCjrXcL8QDQM249lDsAA743iaXNPJUfGbg/640?wx_fmt=jpeg)


　　

据“权健事件”联合调查组，权健公司涉嫌传销犯罪和涉嫌虚假广告犯罪，公安机关1月1日依法对其涉嫌犯罪行为立案侦查。相关部门依法查处取缔不符合消防安全规定的火疗养生场所、开展集中打击清理整顿保健品乱象专项行动。
