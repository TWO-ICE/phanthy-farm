# 杨元庆怒斥折叠屏：不如联想3年前的产品，还卖那么贵！

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4Y8y4TDn5cYkW9z1tZPTg2G2DCd7dGiaFFRHRrVghdj1lsGpT3E9QwuwhdiajGfLFXyCwG9whwIJo9Pg/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/E1LidjhhCxMzlafc5Fv3Hg

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8y4TDn5cYkW9z1tZPTg2G20BqBmBMoABTb29lnjm5bQpPn2oyn2K1XVdS5KN4vlmX38w4nfmusGw/640?wx_fmt=jpeg)


　　

科技先生2月26日讯，在巴塞罗那世界移动通信大会(MWC2019)上，联想集团董事长兼CEO杨元庆接受了媒体采访，他谈到了联想的移动业务以及今年在巴塞罗那备受关注的5G和折叠屏手机。
　　

杨元庆表示，现在发布的这些折叠屏手机产品都没有超出联想三年前在Techworld上曾经发布的概念折叠屏手机，那是一款可以像手镯一样戴在手上的手机，但这款手机后来并未量产商用。**“关键还都是PPT产品，发布完了就放在玻璃罩里面，也不让人碰。价格也是高高在上，可以买好几个平板电脑了。”**


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8y4TDn5cYkW9z1tZPTg2G2Ajd0SpXhDtGCYv5Vjw8t645Axg8qmC6VJ2xFt6t3cDHeBzeicKoOF4A/640?wx_fmt=jpeg)


　　

“联想发布的产品希望是实实在在的产品，是可以交付的产品，按照我们这个标准，这个时点不觉得(折叠机)具备条件 ，离完美的客户体验，离客户愿意买，离以合适的价格买还有距离的。”**杨元庆称，联想将在今年下半年发布5G手机。**

　　

关于联想5G终端与运营商的合作，杨元庆表示，联想移动业务在中国做得还不好，目前有复苏的迹象。**他表示，中国市场以零售为主导，联想的移动业务表现并不太好；但是在北美、欧洲和拉美这些运营商为主导的市场，联想的表现相对要好一些，特别是北美和拉美。**

　　

在中国市场，杨元庆表示，联想集团对于移动业务还没有盈利的要求，处于投入的阶段。“


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8y4TDn5cYkW9z1tZPTg2G2l5QWukwQrjvEFNWYstKx6GTiaqOicpibxxBxaIapEw9hK5yhpwxEgJlZQ/640?wx_fmt=jpeg)


　　

**“联想肯定是5G手机的领先者之一，但是绝不仅仅是手机。”**杨元庆说，联想在5G方面的布局，大概在四五年前就开始，5G绝不像3G、4G那样大家只盯着终端，联想在5G时代还将在后台设备、智能互联等领域大有作为，因为5G将促进IT和CT进行融合。

　　

**对于像华为这样拥有电脑和手机量大终端产品的厂商，杨元庆表示对于竞争毫无恐惧。**
