# 爱立信局端设备故障，致日本和英国大量手机掉线

据英国金融时报报道，爱立信局端设备问题导致英国和日本的移动网络出现大范围中断，数百万人陷入没有智能手机覆盖的困境。截至当地时间凌晨5点，英国Telefónica拥有的O2网络已经几乎瘫痪，日本的SoftBank也遇到了同样的困难。 SoftBank在日本拥有超过3000万用户，而O2在英国拥有3200万用户以及包括Tesco Mobile和Giffgaff在内的MVNO，后者也使用其网络。

有两位了解情况的消息人士表示，瑞典通信设备制造商爱立信的局端设备是造成大断网的主要原因，不过O2，SoftBank和爱立信都不愿意证实这一消息。

O2在一份声明中表示，与其全球供应商之一的“全球软件问题”导致断线事件发生。同样使用爱立信设备的SoftBank表示正在“检查问题的原因”。

在消息发布时，O2网络仍然有英国的用户报告问题，而SoftBank在停机约5小时后恢复了日本的服务。

停机SoftBank来说是一个大问题，因为SoftBank准备在短短两周内为其移动子公司启动首次公开募股，这将是日本历史上最大的一次IPO，因为外部消息影响，软银的股价周四下跌多达6％。


**科技先生注：**


Telefónica创立于1924年，是西班牙的一家大型跨国电信公司，主要在西班牙本国和拉丁美洲运营。它是世界上最大的固定线路和移动电信公司之一，用户部量居第4，总市场价值居第6。


Telefónica的通过购买当地的电信公司及合作的方式实现其全球化的扩张，其中包括了欧洲的捷克共和国、英国、爱尔兰、德国和马恩岛；拉丁美洲的阿根廷、巴西、智利、佩鲁和波多黎各；还有非洲的摩洛哥。
