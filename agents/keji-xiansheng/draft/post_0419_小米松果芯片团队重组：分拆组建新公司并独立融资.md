# 小米松果芯片团队重组：分拆组建新公司并独立融资

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4Yicj50QBZBhHzTibIrtndHwFym9z7pmlrrI5OzubrHBFSbcstECCkV8VA4uFJDkPDc2dgHQ6icokF9CQ/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/gbRhkVcdRM_YAQbdvYs7rA

今日，小米集团组织部发布组织架构调整邮件，披露为了配合公司AIoT战略加速落地，推动芯片研发业务更快发展，小米旗下的全资子公司松果电子团队进行重组。


经此调整后，小米持有南京大鱼半导体25%股权，团队集体持股75%。部分团队分拆组建新公司南京大鱼半导体。**南京大鱼半导体将专注于半导体领域的AI和IoT芯片与解决方案的技术研发，而松果将继续专注手机SoC芯片研发。**


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Yicj50QBZBhHzTibIrtndHwFyvfuc6LvVTYiaic4eonqxcTLjxwxWPZkmDz0ZRKClxRNSax6gC5jIAYKQ/640?wx_fmt=jpeg)


公开资料显示，松果电子成于2014年，系小米全资子公司，主要从事半导体芯片的研发。2017年2月28日，小米发布了澎湃S1芯片，成为了全球第四家具备手机SoC芯片研发能力的手机品牌。


**但是离澎湃S1发布已经过去2年，至今没有小米澎湃S2的消息。**


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Yicj50QBZBhHzTibIrtndHwFy8Y8tlG4gc0g6O6dONgtq885dN5kv1780IlVSGQohb3QJ97GbnhSC3w/640?wx_fmt=jpeg)


此次小米将松果进行重组，目的也是想支持南京大鱼团队独立融资，使其能接纳更多方面的资金、技术与合作，赢得更快更好的发展。


小米集团董事长兼CEO雷军表示，小米给予大鱼团队控股地位并鼓励独立融资，是小米在研发技术投入领域中持续走向深水区的最新探索。除了对大鱼“扶上马、送一程”之外，对于芯片研发，小米还将在更多维度上进行更大、更多样、更长远的持续投入。
