# 构筑脑科学科研高地  浙江大学与盛趣游戏将共建“传奇创新研究中心”

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4Yich6eFQvkOzpzLdriaicaQUKGERhiaQZ3iaRiaTdfOZSdZ0m6ADLmCmdydAznrZLqdt3EVVoYxibPP2BEVA/0?wx_fmt=jpeg)

8月20日下午3点，浙江大学与盛趣游戏将举行以“脑域无疆 趣寻未来”为主题的“传奇创新研究中心”成立仪式。双方将公布围绕脑科学和人工智能新方向的深入合作，包括在共建“传奇创新研究中心”、科研内容和研究目标设定等方面的具体事宜，以共同推动前沿脑科学发展与应用。成立仪式将在浙江大学紫金港校区圆正启真酒店求是厅举行。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Yich6eFQvkOzpzLdriaicaQUKGcvxwibObXfUdnF6ic8qw46fiatqdNcibHhsXeR1cpBRCcJic1os1PQNM7Cg/640?wx_fmt=jpeg)


“脑-机-脑”融合技术是横跨信息与脑科学、有望产出变革性影响的前沿交叉方向。代表深耦合人机协作的脑机融合已成为下一轮人工智能发展的重要趋势，斯坦福《2030年的人工智能与生活》报告认为人机智能协同是未来主要趋势之一。同时，面向解析脑认知功能神经原理的脑科学受到各国政府高度重视，美、欧、日等相继启动了脑计划。脑机融合为脑认知提供窥探脑结构、发掘脑功能的手段，而后者为前者提供神经机制基础，因此，脑机融合技术是推进两者共进的双向引擎，对该领域的深度探索将有力促进人工智能技术、数字医药等实现新的飞跃，助力人类智慧和社会发展，对教育工作、游戏功能、人机融合等实现迭代升级。此次浙江大学与盛趣游戏的联合合作，就致力于在前沿脑科学与人工智能融合研究几大新方向上，实现前沿突破与产业应用。


浙江大学是一所历史悠久、声誉卓著的高等学府，同时也是特色鲜明、在海内外有较大影响的综合型、研究型、创新型大学，浙江大学注重精研学术和科技创新，建设了一批开放性、国际化的高端学术平台，汇聚了各学科的学者大师和高水平研究团队。“十二五”以来，学校多项科研创新指标保持全国高校前列。2019年底，浙江大学医学院脑科学与脑医学学院正式成立，设立了国内首个“脑科学”本科专业，发展脑科学与脑医学成为浙江大学未来高质量高水平发展的重要增长极。


盛趣游戏是全球领先的网络游戏运营商和发行商，立足“科技赋能文化”的产业定位，以科技为骨、文化为翼，用科技激活文化的精髓，致力于成为一家打造极致互动体验的科技文化企业。在之前的盛趣游戏2020年会上，盛趣游戏董事长王佶在演讲中谈到，通过“脑机接口”，能够让人脑与计算机之间建立起直接的交流和控制通道，通过游戏形式的“数字药物”，能够破译和调节脑神经信号的传输，从而造福患者。盛趣游戏在第三个十年的起点，将继续用行动兑现科技文化的企业定位，打造游戏之外的科技增长引擎。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Yich6eFQvkOzpzLdriaicaQUKGxOrwMA2sDeNJgbeBwHowb1IOshVHaFiaBdbtuJrDMB80rPrb6dsldpA/640?wx_fmt=jpeg)


本次浙江大学与盛趣游戏共建“传奇创新研究中心”，将是从产学研到双研合作模式升级，浙江大学发展脑科学、脑机融合、脑医学的卓越学科生态，与盛趣游戏的研发积累和资金支持，形成研究与研发强强结合，共同推动脑科学拔尖创新人才培养，将成为智能时代的研究高地和产业应用的先锋，引领新的智能时代。
