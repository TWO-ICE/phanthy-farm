# 积极响应北京教委要求 高途课堂等在线教育机构全面公示教师资质

（3月3日消息）近期，北京市教委加强监管，对备案在线教育机构下发通知，要求其根据教育部等六部门《关于规范校外线上培训的实施意见》要求，对从事学科知识培训的人员的资格进行排查，具体要求为全面核查教师资质、按要求公示信息、逐一审核课程。

 

此次整改之后，各大在线教育头部机构均已在官网就“课程备案内容承诺书”内容进行更新。以知名K12在线教育机构高途课堂为例，笔者登录官网，注意到其已增加备案内容承诺公示，内文提及“备案教师182名，授课教师182名，其中持有教师资格证的教师182名，教师资格证符合规范要求，教师资质信息公司完整、准确。”

在2019年的跟谁学年报中，跟谁学公司披露，公司共有主讲老师232人，但此次高途课堂的公示显示，备案及授课老师于2020年为128人，2021年为182人，针对这种情况，上述负责人表示，跟谁学包含两大业务品牌，分别是K12业务的高途课堂，和成人业务的跟谁学。年报披露的老师数量为所有业务老师数量总和，而此次监管部门要求的是K12在线教育机构进行老师的教师资格证公示，成人业务不在范围内。此外，公司对主讲老师的上岗有严格要求，需要经过数月的岗前培训，这部分老师也不在此次公示的授课老师范围内。


 

近年来，教育部印发多个指导性文件，引导在线教育行业健康有序发展。随着国家监管的实施，主流在线教育平台也在积极响应、配合加强从教人员的合规整改。早在2020年9月，北京市教委会公布首批《北京市校外线上培训备案名单》，52家培训机构入选，大米网校、vipkid、高途课堂等机构在列。北京市教委建议，学生和家长注意查看机构作出的承诺公示，公示相关信息可在机构备案业务系统的官网首页、APP或学习平台首页的显著位置进行查看。
