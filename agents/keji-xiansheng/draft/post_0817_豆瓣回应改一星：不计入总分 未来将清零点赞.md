# 豆瓣回应改一星：不计入总分 未来将清零点赞

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4Y8jZbXPsZiaVZomc7icAr3K3fvAVXsE57ibrqMpsjrukZmK91lDypZUsMib2Dzlib0SgW6mqwT80647YUA/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/3FqoDt-WckGzy1YwTLRUbA

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8jZbXPsZiaVZomc7icAr3K3f6PxGAU5DwGCFtbjAiakTbpibTFhzbwpuE8xWPZp0KkgrBYVHrJ43QLZw/640?wx_fmt=jpeg)


　　

科技先生2月12日讯，春节期间大火的国产科幻片《流浪地球》在收获不少观众的点赞和好评之后，也引来了不少争议。**《流浪地球》在豆瓣电影的评分一度高达8.5分，而目前已经跌至7.9分。**


![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4Y8jZbXPsZiaVZomc7icAr3K3flDNCUBl5kbJlricQhxbJGF7a8XTj7o11qU4teiaia8ibfqyPBbZV9c3lFw/640?wx_fmt=png)


　　

与通常电影评分的自然波动不同，《流浪地球》评分的快速变化，引起多方关注，并直接导致豆瓣App被《流浪地球》粉丝打出一星差评。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8jZbXPsZiaVZomc7icAr3K3foiaDTfovvNicJ8m2EchKszeShbbzSJLHkoCz1HXsRR2YHTg8mKluYFyw/640?wx_fmt=jpeg)


　　

针对电影《流浪地球》评分异常，出现“五星短评改一星”的传闻，**豆瓣表示，并不存在“高赞好评被收买改为差评”的情况。**据其工程师统计，昨天确实有一例用户由四星改一星的情况，后来该用户删除了评分。

　　

豆瓣在微博中表示，评分大幅修改属于非正常评分，不会计入总分。为了避免此类事件发生，豆瓣也在紧急优化产品功能，修改评分后，修改前的“有用”(点赞)数据将被清零。

　　

截至2月12日中午，《流浪地球》累计票房已接近24亿。
