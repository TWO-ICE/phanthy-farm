# 共5405件！华为2018年专利申请数全球第一

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4YibZT7D9RIuQpkDaCNzn145PleRcc6RUSdtLakwzPIibMbqzCInVicSwZsiaVB1sPNLrGQ0DfKykWpyFg/0?wx_fmt=jpeg)

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YibZT7D9RIuQpkDaCNzn145PFMgMZ3ttib4xdgXxeYxBCVEV0iaploakVvO6CD8v9ibSEM66Xhb5bFnsg/640?wx_fmt=jpeg)


　　

科技先生3月19日讯，联合国世界知识产权组织周二表示，在2018年的国际专利申请中，华为处于领先地位，并且创造了新的记录。


**2018年，华为向联合国世界知识产权组织提交了5405项专利申请，高于2017年的4024项，成为第一名。**第二名是三菱电气，提交专利申请2812项。第三名是英特尔，提交了2499项专利申请。

　　

WIPO总干事Francis Gurry表示：“从历史上看，这是个重要时刻，也是个非常重要的成果。”


![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4YibZT7D9RIuQpkDaCNzn145PX8QCmWSAOKeHKTFAy35LRu3ibyCE6JAVYfe6qRZd88LrhoVAV9ib9pKw/640?wx_fmt=png)


　　

在上榜的前十名公司中，有六家公司来自亚洲，**除了高居榜首的华为以外，中兴通讯、京东方科技集团、三星电子和LG电子也榜上有名**。两家来自欧洲，两家来自美国。

　　

2018年中国共申请国际专利53345件，同比增长9.1%，在全球排名第二，仅次于美国的56142件，而美国这一数据同比下降0.9%，预计中国将在未来两年后超过美国。
