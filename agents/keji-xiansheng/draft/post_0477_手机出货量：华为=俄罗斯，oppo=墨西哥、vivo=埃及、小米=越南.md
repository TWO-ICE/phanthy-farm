# 手机出货量：华为=俄罗斯，oppo=墨西哥、vivo=埃及、小米=越南

　　随着世界杯结束，大家对足球的热情告一段落，但从冰岛这个国家引起的人口话题，确实非常有趣。对于欧洲的一些小国，人口数量并不多，再联系上手机这个话题，你就会发现，不少手机一年出货量竟然要比某些国家的人口还要多。2017年国内手机的销量已经达到相当大的规模，而未来随着5G网络的到来，手机出货量将会有更大的提升，下面我们就看一下这些手机出货量的有趣数据。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y857FXx2JsDPSk09UF2jugAsd1lxXJSqxTibQs6Iv1RHdd6wcRZf7sOsialyV9ckMkiaTYeicibjnGwicOA/640?wx_fmt=jpeg)

▲2017年手机出货量

　　**华为&荣耀2017年出货量1.53亿台**

　　**俄罗斯人口1.5亿**


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y857FXx2JsDPSk09UF2jugA1Xaz4IJfdlJdicJpVH8eYMrkG901WkD05kNjULvEX2B58zOZn8hf33A/640?wx_fmt=jpeg)

▲

　　华为&荣耀2017年出货量1.53亿台

　　纵观国内几大品牌2017年的销量，我们可以发现，已经有2个品牌破亿，而全球人口破亿的国家也只有13个，而华为和荣耀2017年的出货量是1.53亿台，华为也早前宣布2018年上半年的出货量也达到1亿。而俄罗斯的人口也是1.5亿，如果全个俄罗斯的人都用华为手机，那么就是人手一台了。

　　**OPPO手机****2017年出货量****1.18亿台**

　　**墨西哥人口：1.2亿**


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y857FXx2JsDPSk09UF2jugAuFC3WqhOwteG2u4eibZCibcLuCWdhlocboeDJMyibicgx7ib93pGOuRwDgQ/640?wx_fmt=jpeg)

▲OPPO手机2017年出货量1.18亿台

　　OPPO在2017年的出货量是1.18亿，去年OPPO凭借R9和R9S系列获得了非常大的销量增长，而墨西哥人口也达到了1.2亿得规模，基本上能满足墨西哥全国人民一人一台OPPO手机，当然还差200万，应该2018年的出货能达成这个目标。

　　**vivo手机****2017年出货量****9510万台**

　　**埃及人口：9568万**


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y857FXx2JsDPSk09UF2jugAehXIAa18G3eCSFuovdyhxhZ6x3663KIHZia3HM2yeZGc9WkibUPKcTzA/640?wx_fmt=jpeg)

▲vivo手机2017年出货量9510万台

　　vivo在2017年的出货量达到了9510万台，vivo的出货量已经接近一个亿，估计2018年的出货量将会超过1个亿，而这个数字接近一个埃及的人口，2017年埃及总人口9568万人，如果一人一台vivo手机，还是勉强能平分的。

　　**小米****2017年出货量****9170万台**

　　**越南人口：9200万**


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y857FXx2JsDPSk09UF2jugAGcZbQN9zZg15OGIEjUzQaM0RuXHtU9gb2PcVdNbChqdpIpxicbThedg/640?wx_fmt=jpeg)

▲小米2017年出货量9170万台

　　小米2017年的出货量达到了9170万台，仅次于了vivo的销量，小米不仅在国内市场近年还开拓海外市场，小米的销量增长依然相当强劲，小米近年上市后，预计2018年的总出货量也会增长。小米2017年的出货量刚好能满足整个越南人手一台小米手机，让越南人人人都是“米粉”。

　　**魅族****2017年出货量****2000万**

　　**罗马利亚：1970万**


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y857FXx2JsDPSk09UF2jugAgo2fDoNQb0jTjSHGau1ckQuhEJz8Z7qHZv0fUC7K51empHwsSJMoRA/640?wx_fmt=jpeg)

▲魅族2017年出货量2000万

　　魅族2017年的出货量李楠说是接近2000万台，在魅蓝系列的带动下魅族的出货量连续几年都保持在2000万台左右，而魅族近年推出的魅族15以及即将推出的魅族16，或许让魅族在中高端市场重回大众视线。魅族2017年的出货量能够满足罗马尼亚所有人一人一台魅族手机，让罗马尼亚人成为“煤油”。

　　**一加手机****2017年出货量****：400万**

　　**巴拿马：400万**


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y857FXx2JsDPSk09UF2jugA8ia3zEicm8n88yoAlvl7h16ibt2O8zkCSTLjjEIZU44HJ0ibAIvELIvJDg/640?wx_fmt=jpeg)

▲一加手机2017年出货量：400万

　　一加手机去年凭借一加5和一加5T两款产品卖除了400万台的好成绩，一加手机专注于旗舰产品，在中高端市场能有400万的出货量也是相当难得，可以说手机市场的一匹黑马。而同样在本届世界杯的一匹黑马巴拿马人口也是400万人，也可以让这个国家人手一台一加手机，而且是旗舰的一加手机。

　　**锤子****2017年出货量****340万**

　　**乌拉圭人口：340万**


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y857FXx2JsDPSk09UF2jugAWS1SFWicHYQ9cG5591hV0Wicrt4gUZicd2bJ1Z4b5jkexGoAtNfbHJICw/640?wx_fmt=jpeg)

▲锤子2017年出货量340万

　　锤子2017年的销量达到了340万，去年坚果PRO以及坚果PRO 2两款千元级别的产品带动了锤子的销量，但中高端的产品缺席，一定程度影响了锤子的出货量。锤子全年的出货量340万台，也刚刚能满足乌拉圭340万人人手一台坚果手机。
