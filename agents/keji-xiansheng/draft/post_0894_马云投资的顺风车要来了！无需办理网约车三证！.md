# 马云投资的顺风车要来了！无需办理网约车三证！

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4Y8k8OQlkQJMtZYDXWwt7euia3rPkbmf9gibApyobSv9HfywwmV8YRgWdIWNolaSSXEXbPEDvNgFoibQQ/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/i-AJcmGMPwIl9wiWY8p8Kw

![图片](https://mmbiz.qpic.cn/mmbiz_gif/P3SqL3Qw4YibTH6HfT3Nz0CialmxoGMzibX9mGBicmAKqfXL3FvxGzDwUFy6Nrb90PVT4ds3TSSPYbEVgcaKIRR0aQ/640?wx_fmt=gif)


2018年对于网约车行业来说，绝对称得上具有转折意义的一年，从以往的野蛮生长，到如今的理性管控，网约车正在面临着很多新生事物都必须要面对的成长阵痛。而在今年，顺风车业务的所引发的一连串新闻，更是激起了整个社会对于顺风车这一网约车产品的大讨论，在舆论的重压下，滴滴的顺风车业务无限期停运，至今仍处在安全整治环节当中。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8k8OQlkQJMtZYDXWwt7euiahq5vMXiaO78bI6hD7sK6kWcY8w5AakJhs2PmIQECicibTLhUKibRQBraeA/640?wx_fmt=jpeg)


虽然顺风车以往存在的安全漏洞难以回避，但是站在客观角度上来说，顺风车的市场需求依然存在，而且具有相当一部分的体量。从滴滴顺风车下线一个月过后，网络上关于顺风车业务何时上线的询问就屡见不鲜，期间虽然也有嘀嗒出行推出了顺风车业务，但是终究还是因为用户较少和平台技术缺陷等原因，难以为用户提供和昔日滴滴顺风车一样的便捷服务。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8k8OQlkQJMtZYDXWwt7euiaxOzMKBKAJwNwBwScJhkgm6Jc9tvA00b4z5RnGODq6Sib8OOzdxibny8w/640?wx_fmt=jpeg)


不过嘀嗒没干成的事，也不意味着别的企业干不了，尤其对于一些本就坐拥海量用户的出行企业来说，在滴滴收紧战略的这段时间里趁势而起，也未尝不是一种机会。


近日，由共享单车品牌哈罗单车升级而来的哈啰出行正式宣布将开始招募顺风车主，司机们可通过哈啰出行APP，注册成为认证车主。哈啰出行甚至还在官方平台上自信的表示，“希望你以后不用养车，车来养你”。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8k8OQlkQJMtZYDXWwt7euiaGCJaQWVKtk0sCkHyQPaGMiciciczkW8E8RhaZh5ric6ry1Iqg9x87Hfwicg/640?wx_fmt=jpeg)


根据哈啰出行APP内的车主招募信息显示，想要成为哈啰出行顺风车主条件较为简单，顺风车司机必须有一年以上驾龄，合法拥有所驾驶车辆的所有权，并同意芝麻信用授权和用户协议即可。而对于不少网约车司机需要办理的“三证”（《网络预约出租汽车经营许可证》、《网络预约出租汽车驾驶员证》、《网络预约出租汽车运输证》）则没有做强制性的要求。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8k8OQlkQJMtZYDXWwt7euiacncKobqkeNwJQduR8XyQOLiby2hTF1gOvMK3vv42PJFEViaFLialANDtA/640?wx_fmt=jpeg)


而根据最近官方给出的信息，哈啰出行已经完成了一笔高达40亿元人民币的新一轮融资，在资金链方面应该是十分充足。而由于哈啰出行还背靠阿里巴巴旗下的蚂蚁金服，在数据共享和流量扶持方面也有着先天的优势，而且更重要的是，哈啰已经积攒了超过两亿的共享单车用户，相比较其他入场的网约车玩家，哈啰出行的未来显然更加值得期待。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8k8OQlkQJMtZYDXWwt7euiaqGKUV280uUnLCNuBSI7X57icX5BktA7I0XWRiaibkH76zt5j0NJzaWDmQ/640?wx_fmt=jpeg)


不过有些尴尬的是，之家哈啰出行已经与首汽约车、嘀嗒出行、高德地图等多家出行服务商达成合作如今自己又另立门户做起了自营顺风车业务。昔日的合作伙伴变成竞争对手，原有的共生模式还是否能延续，可能仍需市场的进一步考量。
