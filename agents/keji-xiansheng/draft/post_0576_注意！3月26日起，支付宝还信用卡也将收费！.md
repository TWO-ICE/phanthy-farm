# 注意！3月26日起，支付宝还信用卡也将收费！

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4YibsZ1eAgkoPklLecI19t3YeQ4jCJR7v4eKUyhVuZdnicpcvIyJA3wfVSQ1aeEFdS0hxuN4AAsvYpcg/0?wx_fmt=jpeg)

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YibsZ1eAgkoPklLecI19t3YeLw5R4REkBsnpXGhcwFcssXuK1etBicxThVc2Y2Ho4EepofEqHZUS50Q/640?wx_fmt=jpeg)


　　

科技先生2月21日讯，由于综合成本上升过快，越来越多的机构开始加入信用卡还款收费大军。

　　

今日，支付宝对外发布公告表示，为了持续向用户提供更优质服务，自3月26日起，通过支付宝给信用卡还款将收取服务费。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YibsZ1eAgkoPklLecI19t3YeIfxFZKADw4cZFN8Sqhc9iavtMWicqHhvPhInDOSt5ZnBsKaXrw6nuxBQ/640?wx_fmt=jpeg)


　　

**与其他信用卡还款收费的第三方支付机构不同，支付宝提供了每人每月2000元的免费额度。**

　　

其实，支付宝调整信用卡还款的规则并非业界首例。

　　

2018年8月1日起，微信的信用卡还款功能就进行了调整。除微信理财通铂金、黄金会员以及“爱定投计划”每月成功转入500元及以上的用户可继续享受免费还款外，其余情况通过微信为信用卡还款，每笔将按还款金额的0.1%收取手续费，手续费金额最低0.1元。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YibsZ1eAgkoPklLecI19t3YeLiaQg9uvYUIibrh8f5vjSFiaEkCD3Jlred6GoQZjy8momM2wfApuTYCTg/640?wx_fmt=jpeg)


　　

因为支付宝信用卡还款有2000元的免费额度，所以无论还多少，支付宝都比微信少2元。

　　

有业内人士表示，在任何行业都不存在永恒的免费模式，在一个充分竞争的市场，收费与否，最终是取决于企业提供的服务是否值得消费者为此付费，而收费的高低也会在竞争中趋于合理。
