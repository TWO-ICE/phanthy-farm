# 字节跳动“接盘”锤子科技！员工已开始改签劳动合同

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YicFXcOgCRGbZrU5gNCXsojRicuafjAY7WVU0HkTSP5l5okZ0EFOAVPZVIcFxePLfOKgHUJQzBR2YNg/640?wx_fmt=jpeg)


　　

科技先生1月22日讯，关于锤子科技的传闻从未间断。此前就有不少传闻称锤子手机将要被收购，甚至还有报道称，锤子科技已经申请财产保全，目前法院还冻结了锤子科技450万元存款。

　　

今日据锤子科技内部人士透露，昨天已经接到临时通知，要求改签劳动合同到今日头条的母公司“字节跳动”。**本月初，有媒体报道今日头条有意收购锤子科技部分专利使用权计划，用于探索教育领域相关硬件。**

　　

据锤子科技内部人士告诉凤凰网科技，如此前今日头条对外声明所言，字节跳动看中的是锤子科技的硬件和软件。“我们会签放弃锤子这边的假期、股权什么的，然后再签头条6个月试用期。”该人士表示。

　　

同时他也表达了改签劳动合同之后的担忧，“很有可能就被干掉了”、“反正肯定没有赔偿让你签放弃这些的”。

　　

**字节跳动回应称，收购了锤子科技部分专利使用权，探索教育领域相关业务，因为具体交易涉及保密条款，不便披露。也有锤子员工入职公司，这是正常的人才流动。**


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YicFXcOgCRGbZrU5gNCXsojRibrX8y6DNtGlrCzy9AiaMBmM3IZ7vKDjwGVsLQ2Vwsy5jUEQMwyEiatwA/640?wx_fmt=jpeg)


　　

锤子科技创始人罗永浩在1月15号子弹短信(现改名叫聊天宝)春季发布会上简单回应了锤子科技的近况，称自己其实没有其实外面传说的那么差，近期保持沉默并不是想隐瞒什么，而是要等过了保密期才能公布，希望大家都相互体谅。
