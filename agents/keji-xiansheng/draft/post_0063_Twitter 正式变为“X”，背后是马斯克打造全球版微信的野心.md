# Twitter 正式变为“X”，背后是马斯克打造全球版微信的野心

一夜之间，推特应用上标志性的“小蓝鸟”标志消失成为历史。

近日，推特首席执行官琳达・亚卡里诺发文，宣布推特 Logo 正式改为 X。马斯克亦发文称，X.com 已指向 twitter.com。

从此Twitter告别原有的名称和小蓝鸟形象，平台颜色也已正式更新为黑色。

值得注意的是，推特官方账号也将名字和头像改为了“X”。


![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4Y8dJWmBYcMN6TRBGU0HNlG4AMyOQRJxD2icaNUYOftFTkAEh8XccRyLHVAics72LTE5WA6OylT5frow/640?wx_fmt=png)

这是该公司被亿万富翁埃隆・马斯克收购后的一项重大变革，马斯克希望将 X 打造成一个“超级应用”，提供各种服务和功能。


![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4Y8dJWmBYcMN6TRBGU0HNlG4qzJ7zZxNcdNps0jByVGrYYtgggaZ0ficZP7hRMcXtTFf5tqEUXbXvmA/640?wx_fmt=png)


马斯克此前多次公开称赞过中国的微信，认为“在中国可以活在微信里，它什么都做得到”，并意图打造一个同样的超级APP，而X就是他对这个应用的命名。

换言之，推特品牌标识从过去的小蓝鸟变成字母“X”，在某种程度上意味着马斯克真的要开始打造自己的全球版“微信”了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4Y8dJWmBYcMN6TRBGU0HNlG44alXFpDzDJ0DzibZCWtOYmJJwUseHvsBicmialWica0bWh09EvDAxMiaicJg/640?wx_fmt=png)


马斯克于去年 11 月以 440 亿美元的价格收购了推特，当时他表示，他想要将推特改造成一个可以满足用户各种需求的平台。

马斯克所掌握的商业航天公司名叫SpaceX，特斯拉的一款重要车型为Model X，前不久新成立的有关人工智能的公司叫做xAI，X 是他为这个愿景起的名字，意味着无限可能。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8dJWmBYcMN6TRBGU0HNlG4u0icjRAJpVltdKWm9QZqnrYicyHjInv2SAxETck4ibeNF782HjPXoSpag/640?wx_fmt=jpeg)

小道消息创始人冯大辉老师表示：**冷知识：严格来说，「𝕏」并不是 「X」。Unicode Character 「𝕏」 (U+1D54F)，Unicode Character 「X」 (U+0058)。具体的编码不一样。𝕏 正式的叫法是：Mathematical Double-Struck Capital X。**

不过，在推特小蓝鸟Logo在全球范围内已经拥有较高知名度、辨识度的情况下，推特急匆匆地抛弃如此重要的品牌资产转而换上新Logo，很难说是一次成功的品牌重塑。
