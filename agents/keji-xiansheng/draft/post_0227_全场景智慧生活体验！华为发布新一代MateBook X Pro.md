# 全场景智慧生活体验！华为发布新一代MateBook X Pro

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4YibrExb2afZqia8AoujmQPwfMkcPu2wodzs42eJ5sQ4ETqZlWAXSkhbU0RJoankhtv55icdgRSDErg4w/0?wx_fmt=jpeg)

![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4YibrExb2afZqia8AoujmQPwfMhxJWHaSyX13t08LUNYdgGXPOvms5PFicrAqJlgCVuUoeNuib6qTpcqJQ/640?wx_fmt=png)


　　

科技先生2月24日讯，MWC2018华为发布了第一代HUAWEI MateBook X Pro，以超高的屏占比和隐藏式摄像头迅速成为业界焦点。本次发布会上，华为发布了MateBook产品线两款新品：新款MateBook X Pro以及MateBook 14。


![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4YibrExb2afZqia8AoujmQPwfMDxy3BHPQvmlX3kNTXyDRA4SY6OQ11M8dhNkxFVZP9ibe53HA7kXrBKg/640?wx_fmt=png)


　　

**新一代MateBook X Pro依旧采用全面屏设计，屏占比高达91%，最大亮度高达450尼特，对比度高达1500:1，分辨率达到3K(3000×2000)级别**，引入手机行业的LTPS高清屏幕，显示体验极佳，功耗很低，手机技术完美融合到PC产品中。支持十点触控，高精顺滑触感，防指纹，护眼技术过滤多余蓝光，缓解眼部疲劳。


![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4YibrExb2afZqia8AoujmQPwfMpk86dhKJSvPrITKYhbEu7q6ekiaWBht6ENna2cazicib4jMOHIFPXXAicQ/640?wx_fmt=png)


　　

新一代MateBook X Pro在保持原有成熟外观设计的前提下，进行了硬件性能方面的全面升级。**搭载了英特尔第八代酷睿i7 8565u ，比上一代提升快40%**，NVIDIA® GeForce® MX250显卡，在电池 连网 接口等方面更先进。**电源键和指纹识别二合一**，按压电源键和指纹信息识别同时进行，无需在登陆界面输入密码或者扫描指纹，直达Windows桌面。


![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4YibrExb2afZqia8AoujmQPwfMpWZQfghPj185mftibT707XXWYOSv8CFrmyX0rUrWS3zSPVqJtn4L9dw/640?wx_fmt=png)


　　

之前在MateBook 13上行业首创“一碰传”交互传输技术此次进行了升级，**在原有的基础上还支持了Office文档传输功能，如Word、PPT、Excel、TXT、PDF等文件都可以在PC和手机之间的双向互传。**

　　

首次传输连接配对的步骤缩减至仅4步;传输更便捷，仅需2步即可完成，传输性能升级至30M/S;连接更效率，无需等待无延迟，相比于苹果Airdrop优势明显。全面实现PC和手机端的剪贴板共享，快速实现PC和手机间文件传输。

　　

另外，配备了65W适配器, 轻巧便携，一个充电器支持多种设备、多种规格手机快速充电，减少旅途和外出的负担。
