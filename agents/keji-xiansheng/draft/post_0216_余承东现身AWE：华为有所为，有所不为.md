# 余承东现身AWE：华为有所为，有所不为

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4YibnsrEWMlzRnydSJMcjhqiaPIMDmia6aqzsfsicewfbsUIniaXicBGWicbuUicWYicRTwsoyF5I9DSVu8OTug/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/gLN5PbHfzQnbMKpHYwsNzw

3月14日，AWE2019于上海正式开幕，华为在本次展会上带来了依托HUAWEI HiLink联盟的智能生态产品。同时，还有西门子分体式空气检测仪，遥控大师空调伴侣，空气加湿器等一系列品牌合作产品。

　　


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YibnsrEWMlzRnydSJMcjhqiaPqibSwyLID0gZ6lr1NIibrCgH4K5z4lzsVKB3yE03unp9iaTnib6y4wZo5w/640?wx_fmt=jpeg)


下午，华为在现场举办了一场HUAWEI HiLink生态大会，展示了华为目前的智能生态。在生态大会上，华为消费者业务CEO余承东宣布，“华为IoT生态战略将全面升级为全场景智慧化战略。华为将围绕着HiAI、两大开放平台和三层结构化产品的战略，为行业打造一个丰富多彩的智能家居生态系统。”


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YibnsrEWMlzRnydSJMcjhqiaPPGVJvVxGlx2s0QL9VGcW6yCcyVsJC7wia8T8L4DxOWmOHicTbAUCphTA/640?wx_fmt=jpeg)


余承东表示，未来10年，AI将贯穿所有的硬件设备，家电迎来也将迎来新一轮的升级。但智能家电缺乏统一的控制标准。经过多年积累，华为具备了全面推动家电产业升级。华为将以此为目标研发智能家电的统一控制标准，聚合家庭智能硬件，提供统一的通信技术标准，入口标准，协议标准，这就是华为的全场景智慧化战略。

　　

与此同时，余承东强调，华为做智能家电不为了赚钱，我们永远不做家电智能硬件，只为消费者提供无缝体验便利，我们只做产业的赋能者，不做掠夺者。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YibnsrEWMlzRnydSJMcjhqiaP4ib5llhFCL4s2IfMaHq3vgV3ibOPwgT5eCzWtcfn3wMmYGW91ZlicAd9Q/640?wx_fmt=jpeg)


余承东表示：华为“有所为，有所不为。”“华为永远不做家电产品去竞争。”“像空调、洗衣机，每个都是术业有专攻，华为永远不会碰这些东西。”并通过“1+8+N”明确了华为“有所为，有所不为”的理念。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YibnsrEWMlzRnydSJMcjhqiaPucsP7LSzm3JreCSlZJ4xLcvUEa47bhxanP2ZF5Bg1kjmNUt5UvNulQ/640?wx_fmt=jpeg)


“1+8+N”是华为智能家居生态的三层结构化产品路线，即：“1”代表手机，“8”代表手表、耳机、PC、平板、HD、音箱、眼镜和车机八类产品，“N”代表智能家居、智能办公、运动健康等智能产品。

　　

与友商对比，余承东评价道：“有些厂家做的东西不可能得到大家的支持，因为他自己同时也做家电产品如果华为同时做家电，那这个标准也没人支持，所以我们自己坚决不去做。我们提供Hilink也是提高连接覆盖，其他产业我们不做、也绝不盲目扩张，企业什么都做是做不好的。”


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YibnsrEWMlzRnydSJMcjhqiaPawx8hLMicT8ZZsVfEgZ3FWicYqRSaZ4enSAIdgg0XQTzkIKODubV5PWA/640?wx_fmt=jpeg)


　　

面对业界传言已久的“华为将推出自己的电视产品”，余承东表示，“我们不做家电。现在整个行业已经进入人工智能时代，我们在做智能大屏，也在做AI音箱等，华为自己不想、也不会去做传统家电。但是带屏的音箱，可能具备电视功能，AI大屏也可能具备电视功能。我们正在跟合作伙伴进行探讨，我们自己不想单独去做，也可能跟合作伙伴一起讨论是否提供AI时代带屏音箱，也可能具备电视功能。”

　　

余承东表示，2018年华为+荣耀两个品牌的出货量为2.06亿台，稳居国内第一，全球第三，也就意味着中国每卖出3部手机就有一部是华为手机，而且华为主攻中高端，表现非常优秀。

　　

目前，华为在中国中高端手机市占率34%，年底将达到50%，全球出货量目标是2.5亿至2.6亿台。并表示，在不久的将来，华为HiLink也将如此。
