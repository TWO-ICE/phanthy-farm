# 二手鱼里ZTE中兴CT321G3爆火，白菜价小主机真香还是智商税？

最近在二手平台上闲逛时，一台标价仅 120 到 190 元的 ZTE 中兴 CT321G3 云终端小主机引起了我的注意。这玩意儿在二手鱼上的热度相当诡异，页面上一堆“顶级 IF 红点大奖加持”、“双网口软路由神器”、“弱电箱塞进去刚刚好”的诱人标签，甚至还挂着几千人想要、近十万浏览量的数据。说实话，第一眼看到这描述，我本能的反应是卖家又在收“智商税”，毕竟一分钱一分货是铁律。但这价格实在让人好奇，点开详细页扒了扒参数，发现这居然真的是个被低估的“工业废料”黄金选手，属于那种虽然老了但还能再战三年的硬通货。

先说说这东西到底是个啥。ZTE 中兴 CT321G3，本质上是一台企业级云终端设备，也就是以前公司前台或者网吧里用来无盘上网的那种盒子。它的物理尺寸控制得相当极致，大概就是巴掌大一块，具体数值在 18.5×15×3.5cm 左右。外壳虽然是塑料材质，但别小看这塑料壳，那是经过磨砂处理的工业料，摸起来手感扎实，不像淘宝几十块钱那种山寨亚克力透明盒子，甚至有点粗犷的工业美感。关键一点，这是原装正宫，不是那些搞 DIY 改装出来的拼凑货，内部结构紧凑程度肯定优于散件组装。配置这块，目前市面上流通的版本主要分两种：一是基于 Apollo Lake 架构的赛扬 N3350 双核处理器，二是稍强一点的 N3450 四核处理器。

存储方面比较寒酸，板载了 4GB 内存（这点比较致命，无法升级），硬盘选项要么是自带 16GB 的 eMMC 闪存，要么干脆没硬盘。但这机器的杀手锏在于兼容性，原生支持 Windows 10、Linux，甚至还能刷 iStoreOS、爱快这类玩路由的专用系统。最让玩家高潮的是它自带了两个原生千兆网口，芯片是 Realtek RTL8111，这可比那些插 USB 免驱网卡稳定多了。整机的功耗设计得极低，TDP 热设计功耗只有 4W 到 8W，这什么概念？比你家待机的机箱灯都省电，插电即用，扔在弱电箱里当个 24 小时跑不断的软路由或者轻量服务器简直是为它量身定做的岗位。

聊聊性能这块，很多人一听 N3450 是 2016 年的老 U 就要喷。但咱们得实事求是，这颗芯片虽然年代久远，架构也就是咱们常说的 Goldmont，但对比 J1800、N2800、D2550 这种上古时代的赛扬或者凌动处理器，那简直是降维打击。从主频和架构先进程度来看，N3450 跑个 OpenWrt 旁路由、挂个 AdGuardHome 这种去广告服务，或者跑跑轻量级的 Docker 容器（比如 Home Assistant 之类），完全是力所能及的。它最大的优势是原生 x86_64 架构，这意味着不用折腾 ARM 架构的各种兼容性问题，指令集通吃。而且它自带双千兆网口，这意味着你可以直接把它做成双桥接或者单臂旁路，不用额外花钱买 USB 网卡，也不用担心 USB 带宽和稳定性问题，这对于对网络稳定性有强迫症的玩家来说，绝对是加分项。

再来说说最核心的价格问题。目前二手鱼上的行情是，带 16GB eMMC 硬盘的版本大概 139 元起步，无硬盘的“板砖”版只要 119 元起步，而且这价格还包邮送个 12V 电源。更绝的是，很多卖家还免费帮你刷写 BIOS 开启“来电自启”功能。懂行的都知道，这个功能对于 24 小时运行的设备（如软路由、NAS）有多重要，万一家里停电又来了，设备能自动重启，不用你跑去弱电箱按开关。对比一下目前市面上的同类产品，你随便买个 J4125 的软路由主板都要两三百，还要自己买机箱、电源、风扇，一套下来怎么也得 400 往上，还要忍受 DIY 机箱的散热噪音。所以单看硬件堆料和完成度，这一百多块钱的价格，确实算是“白菜价”里的战斗机，性价比极高。

但是，兄弟们先别急着掏钱下单，咱们得冷静地聊聊它的坑，毕竟一分钱一分货的道理在这里依然适用。首先，这机器最大的硬伤是扩展性几乎为零。它既没有 M.2 接口，也没有 SATA 接口，你也别指望能改装上去。自带的 16GB eMMC 闪存，装个精简版的 Windows 10 或者 Linux 系统都捉襟见肘。系统装完，空间也就剩个几 GB，如果你想装点软件、存点数据，必须依赖 U 盘或者挂载网络存储（SMB/NFS）。其次，N3450 毕竟是低电压、低主频的 U，基础频率才 1.1GHz，睿频顶多 2.2GHz。这意味着它的单核性能很弱，多开几个网页或者跑个稍微大点的程序就容易卡顿。千万别指望它能跑虚拟机或者硬解 4K 高码率视频，那会让它死得很难看。还有一点，虽然卖家吹嘘这是“红点设计奖”得主，我特意去查了下，ZTE CT321 系列确实在 2017 年拿过 IF 设计奖或者红点概念奖，但这主要是针对其作为云终端的工业设计美学，跟性能没半毛钱关系，别被营销话术忽悠了。

很多人肯定会问，这东西能不能当主力 NAS 用？这里必须给大家泼一盆冷水。如果你只是想刷个飞牛 OS（FnOS）同步几个办公文档、搭个 Alist 挂网盘资源，或者做个轻量级的 BT/PT 下载机，那它完全能胜任，毕竟 x86 机器跑这类软件比群晖那种白垃圾还是要良心很多。但如果你是想用它跑 Emby、Jellyfin 这种需要视频转码的服务，特别是涉及到多用户并发访问，或者想挂一大堆 Docker 容器组建家庭影院，那我劝你直接放弃，去看 J4125 起步的机型。N3450 这种核显和 CPU 性力，根本撑不起视频硬解码的压力，强行用只会让你在播放视频时体验卡顿到想砸屏幕。别省这百来块钱去买个以后还要折腾换掉的电子垃圾，那是浪费时间。

那么，119 元的无硬盘版到底值不值得买？这得看你的应用场景和技术储备。如果你手头刚好有闲置的高速 U 盘，或者你有玩机经验，打算通过网络启动（PXE/iPXE）引导系统，那么 119 元拿下这台板载 4G 内存、双网口的主机确实划算。但必须提醒一点，长期作为系统盘运行的 U 盘，寿命是个大问题。U 盘的写入次数有限，作为系统盘会有频繁的读写操作，很容易导致掉盘或损坏，稳定性远不如原生的 eMMC 或者 SSD。所以如果选无硬盘版，建议系统盘最好选用读写寿命长的 Industrial 级 U 盘，或者干脆只把 U 盘做引导盘，系统跑在内存盘里。

从目前整个二手市场的行情来看，这类老旧但稳定的 x86 小主机，在玩家群体里一直有稳定的需求。尤其是对于那些想入门家庭网络改造、想玩软路由 NAS 但预算有限的学生党或者小白用户，这种百元级的设备是最佳的敲门砖。价格压到 120 到 150 元这个区间，属于非常合理的偏低水平。不过，大家购买时也要擦亮眼睛，警惕个别卖家把企业淘汰下来的“出清库存”包装成“捡漏神机”。有些机器可能经过长时间高负荷运行，主板上有暗病或者电容鼓包，甚至可能是翻新机、拆机件。购买时最好问清楚是否有暗病，是否支持无理由退货，别省那几十块钱去当接盘侠。

最后，给想入坑或者已经心动的朋友，总结几句掏心窝子的建议，希望能帮你避开大坑：

1.  如果你的需求非常明确，就是想做软路由、旁路由、跑 AdGuard Home，那么闭眼入无硬盘版（119 元），自己刷个 OpenWrt 或者 iStoreOS，性价比无敌。
2.  如果你需要一点点本地存储，比如存个配置文件、日志，选带 16GB eMMC 的版本，但切记，千万别往里面存重要数据，一旦挂了数据恢复难度极高，把它当个纯系统盘看就行。
3.  千万别指望它干重活，它的定位就是“低功耗专用工具机”，别把它当 PC 用，也别幻想它能跑满千兆宽带的高负载包转发率。
4.  如果你看完了上面所有废话，觉得自己其实根本不需要软路由，平时就刷刷视频打游戏，那么恭喜你，看完不买，直接立省 139 元，这才是最硬核的省钱大法。
