# 二手鱼有人139元卖飞牛圣体，J1900的配置算不算智商税？

今天在二手鱼刷到了J1900迷你超薄小主机，标价139元，我仔细一看原来只是主板的价格，无壳无内存无硬盘无电源。准系统（主板+外壳）要价159元，也可以选购整机，各种价位都有，整体来看价格并不算离谱。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGzL4qLAnibjvia2mpQXqhw0xLmaeogUm5dTyY1jKibtUibaVHeXrgpl9ibJ2cciaDYkAUKnvrUD6SuJrxQ/640?wx_fmt=png)


这款小主机用的是英特尔赛扬J1900处理器，四核四线程，基础频率2.42GHz，虽然是2013年左右的老U了，但胜在低功耗（TDP仅10W），发热量小，拿来跑轻量级服务完全够用。内存插槽支持DDR3笔记本条，最大可扩至8GB；存储方面有mSATA和SATA双接口，意味着你可以同时装系统盘+数据盘，或者直接上一块2.5英寸SSD。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGzL4qLAnibjvia2mpQXqhw0xk06lUPBXnLwKyY2HZVtRC38n1uc2nJgbeBND08ia8p0RiaQ7unkyZYbw/640?wx_fmt=png)


视频输出有VGA和HDMI双口，接老显示器或新电视都没问题。扩展性也不赖：Mini PCIe插槽可以加无线网卡或第二块网卡，USB 2.0虽然慢点，但接个键鼠、U盘也够使。供电兼容12V–19V，用常见的5525接口，家里随便找个旧电源可能就能点亮。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGzL4qLAnibjvia2mpQXqhw0xJhctFMjibB4A1xmu7WXcznEe04YrQScBjZbJf1NdewPIOVia63jYOKFw/640?wx_fmt=png)


尺寸方面，整机含外壳也就185×185×38mm，比一本字典还小，放书架、挂电视后头都不占地儿。外壳还是卖家自己3D打印的，颜色多到离谱：从碳墨黑、棉花白，到糖果粉、熔岩红，甚至还有“肤色”。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGzL4qLAnibjvia2mpQXqhw0xgFZdlmIEaIHtp0KuU3dYeeArcFgBFtSjAXRenmO4veR73gHuiaOw6gA/640?wx_fmt=png)


不过注意，139元那档只是裸板，想要整机得加钱——8G+240G版本要275元，送电源，还白送USB无线网卡（如果爽快下单的话）。默认装的是Windows系统，但卖家明确说“可代刷飞牛、群晖、爱快、巴托塞拉”，对折腾党相当友好。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGzL4qLAnibjvia2mpQXqhw0xD1BVibjXRQ6FR2KCc1hKXXB18QyKZ6lPoy7WibUYvhMEz0llWNfylEQg/640?wx_fmt=png)


说实话，这主机的优势就在于能够低功耗运行飞牛，跑Docker、Alist、Emby都稳；做软路由也行，单网口虽限制了旁路由玩法，但主路由+交换机方案照样能跑；如果你只是想搭个下载机、监控录像机、或者复古游戏模拟器（比如RetroArch跑PS1/N64），它也是性价比之选。毕竟功耗低，7×24开机一个月电费不到十块钱，安静又省钱。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGzL4qLAnibjvia2mpQXqhw0xaP6on3ia9trFSd5t5HD5YFRCXE01UZ5O1K5OIyHbVE4XYkuLObpnC2A/640?wx_fmt=png)


可能有人会问，J1900是不是太老了？确实，它不支持4K硬解，虚拟化性能一般，跑现代Web应用会有点吃力。但如果你的需求只是“轻量服务+低功耗+低成本”，它反而比某些ARM开发板更成熟——x86架构兼容性好，驱动齐全，资料多，小白也能上手。再说了，139元买块能用的工控主板，就算当电子积木玩也不亏。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGzL4qLAnibjvia2mpQXqhw0x2moMQIRziclicU8fhsPHUV8fb2raoA7uRiaQLmE4xWl9p4R3KJLMGFg0Q/640?wx_fmt=png)


那么价格到底香不香？查了下主流电商，全新J1900准系统（带壳无内存硬盘）普遍在200元以上，二手整机8G+120G配置基本要250–300元。二手鱼上139元的裸板，如果自己手头有内存硬盘电源，等于白捡一台可玩性极高的小主机。但如果你啥都没有，算上配件成本（8G DDR3约50元，240G SSD约80元，电源20元），总投入接近290元——这时候就得掂量一下，是否值得为省几十块花时间折腾。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGzL4qLAnibjvia2mpQXqhw0x4XiaoBr5bh0GCVjLrfQCOrg99MoYXEV3DOAQzxTFiaCXyz3AjZKYAqdQ/640?wx_fmt=png)


如果你感兴趣的话，可以在二手鱼搜“J1900 迷你超薄小主机”就行。如果搜不到，试试图片搜索——毕竟这种小众机型上架快、出手也快。要是真没了，别慌，过两天可能又有新卖家挂出来。毕竟在二手鱼，好物如潮水，来得快去得也快，全靠缘分和手速。


 


以下是个人一些掺了水的建议：

1. 手头有配件的，闭眼冲139元裸板。

2. 想一步到位的，直接选275元整机版。

3. 别指望它打游戏或剪视频，用途要匹配。

4. 看完不买，立省275元。
