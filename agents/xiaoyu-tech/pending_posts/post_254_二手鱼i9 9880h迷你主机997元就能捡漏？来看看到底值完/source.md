# 二手鱼i9 9880h迷你主机997元就能捡漏？来看看到底值不值这个价？

老铁们，你们在二手鱼上逛的时候，有没有遇到过那种标价低，配置却又高得离谱的机器？今天我刷到一台标价997元的电竞迷你主机，处理器居然是i9 9880h，还板载了gtx1650显卡，虽然不带内存和硬盘，但这价格确实还挺有诱惑力的。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelzSTyPtx9ricGBytiacXia3RCMk8cqdu5TkAR5GRM7Ft0icL8VzDD4GDlrprQ3ZStOlRYTbNzCSjTIhxxRHicLVcwv1VuIUjWL1Ng4/640?wx_fmt=png)


i9 9880h是移动端的处理器，8核16线程，虽然它是前几年的产物，但放到现在单看CPU跑分依旧能打，大概相当于桌面端的i7 10700。卖家已经给CPU降压100mv，还把TDP从默认的45w解锁到了65w，鲁大妈跑分保底60万，最高能冲到80万。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekA90wgPiclt2To5lV6DbfK3BxhSbqibGd9KsENBGRv7pASoBXyqbCfm1HRZWvrtvztyDp3a1oWlsWD8zja9XBDcX430nialTfVZg/640?wx_fmt=png)


配的gtx1650是板载不可更换的，玩个吃鸡、英雄联盟、原神开中画质都没问题。整机接口齐全，hdmi、type c、千兆网口、usb 3.0都有，还带双频WiFi。体积也就比电视盒子大一圈，放在桌面或挂显示器后面都不占地方。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenIjEV2gyhVgNwtLOxJDYb5zksqIaWpRXNda5z1tUvlONhKjiboGKl3wofCiarmfzoSsv2IicB9MGNpic9tGJTZo1BGW8r7yE79uVw/640?wx_fmt=png)


但这玩意儿的槽点也非常明显。第一，标价997元是不带内存、硬盘和电源的。你需要自己配两条笔记本DDR4内存，一块m.2固态，再加一个19V的电源适配器。算下来实际到手成本大概在1500以上。第二，板载gtx1650是硬伤，它没法升级显卡，未来你想玩新出的3A大作只能整机换掉。还有，i9 9880h哪怕解锁到65w，满载发热依然可观，这种迷你主机的散热模组能不能压住得打个问号。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekvl1aaCNfa6JjFrptPSNKYYrlibHcrTDe1ODQznXBKiaCuIMERfMZQ2xhNaqLsia6cm8TXovfE6p2tqksyXibt2ujOmO7oVpia6LBE/640?wx_fmt=png)


但如果你有1500元左右的预算，大概可以淘到一台i5 10400f加gtx1060 3g的二手台式机，游戏性能更强，显卡还能升级。或者加几百块直接上r5 5600g的整机，核显性能接近gtx750ti，但CPU更现代。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemypjHTsSevVaDrhCL53I0aAgwiaCibFllutoX8vicuFYqvKbtZ7ibPWXhgiby3ZzMDaIJnraeP8vmiaxnCZD1aFuxsvZp5X6OWyhRpM/640?wx_fmt=png)


这台迷你主机的唯一优势就是体积小和那颗i9的名头。i9 9880h的多核性能确实不错，剪个1080p视频、跑虚拟机、做直播推流都够用。如果你是个垃圾佬，手里正好有闲置的笔记本内存和固态，又需要一台不占地方的备用机拿来办公或者玩老游戏，那997元这个底价可以试着聊一聊。但如果你是纯小白，我劝你千万别碰。没有售后、没有技术支持，到手万一翻车，这997元就跟扔进水里一样。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCeljAbeQicn3OdHJnoryhxKKbXkAzznLGAyuJpqKougpUBUQ1KYkzht6ENxgEia2duIby6ByJickmnibdicCiaPoyFgvnzXoTap412ZKM/640?wx_fmt=png)


另外给真想下手的朋友两条建议。第一，一定要让卖家拍实物视频，包括开机进系统、跑个鲁大妈温度测试、所有接口都插一遍。如果卖家拒绝，直接划走。第二，买回来后先不要装硬盘，用U盘进PE系统跑一遍内存测试和CPU压力测试，确认稳定再装系统。卖家说已经降压解锁，但每颗CPU体质不同，万一你的这台蓝屏死机，你连恢复默认设置的能力都没有。总的来说，这台i9迷你主机性能上限不低，但水也很深。理性捡垃圾，别被i9的名头冲昏头。
