# 自带电池还配键鼠一体？这台110块的小主机才是二手鱼里的“邪修”

![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEyqZNianK0kgs6zw3r2ibsvhLak92myPaHq3icpCHrYKE6dd450ibcHF3gBSaGCzQ5rKKuxmgsYs2tpQ/640?wx_fmt=png)


今天在二手鱼刷到了一款带有Intel LOGO的ZXK迷你主机（很奇怪吧），价格110块，成色9新，功能完好。一般人看到这东西都会一脸懵逼表示没见过，虽然它是个冷门的玩意，但在网上还真能查到，2021年入手价在1000多左右，现在拿出来想卖110估计是想会回回血。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEyqZNianK0kgs6zw3r2ibsvhNGqr5067rtFVaGau7Sf6SDN50fITvYjWJPZJU9wFzbibwXlb1tMy3Zg/640?wx_fmt=png)


先说外观：整机巴掌大，塑料壳子但做工不糙，正面贴着个大大的Intel Inside标识。不过我心里直犯嘀咕：这LOGO怕不是贴来唬人的吧？卖家没写详细的配置，但是我在网上能查到，搭载的是Intel Atom Z3735F处理器，属于Bay Trail架构的老古董，四核四线程，主频最高1.83GHz。这种U放在当年都只能算入门级，现在拿来跑Windows 10，只能说“能开机”，别指望流畅办公。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEyqZNianK0kgs6zw3r2ibsvhmPx5ia4o4C48o4VjibK1f8RicDsYtkvhvsWC8zW94aHaiadMA0Q7aCMMIQ/640?wx_fmt=png)


接口方面倒是挺全：HDMI、两个USB-A、一个Type-C、DC电源口，基本满足外接需求。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEyqZNianK0kgs6zw3r2ibsvhmxiaU4JwlsEa2PH0D2EicydalU4hw0SBUcCLQHYAeAOTxE7Rv3icYa3vg/640?wx_fmt=png&from=appmsg)


离谱的是，这小东西居然内置7000mAh电池，还配了个键鼠一体控制器——你没看错，它本质上是个带屏幕输出能力的安卓盒子变种？不过电池估计已经“饿死”，毕竟放了三四年没用。但即便如此，光是这个设计思路，在同类迷你主机里也算独一份。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEyqZNianK0kgs6zw3r2ibsvh7ibbn6zR7ia5Rrtscd7GbM0KrCUH65Yic6re70DTXlZK6Aw17mOIr1Ggw/640?wx_fmt=png)


内存和存储是硬伤：2GB RAM + 32GB eMMC。系统占掉一半空间后，实际可用不到15GB。GPU是Intel HD Graphics Gen7（4EU），性能约等于手机GPU的水平，看个1080P视频勉强撑住，想玩点轻度游戏？建议梦里试试。WIFI模块是RTL8723，只支持2.4GHz频段，连5G WiFi都别想了，网速慢点忍忍吧。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEyqZNianK0kgs6zw3r2ibsvhKUYXK7Le5IOzAazP6ZULQNXehckNsF63xFCfW1MeEuaT4QUQDYdiaIg/640?wx_fmt=png)


可能有人会问：“这玩意能装飞牛OS吗？”理论上可以，但得先确认是否支持x86架构和UEFI启动。Atom Z3735F是x86没错，但很多老设备默认是Legacy BIOS，刷第三方系统有翻车风险。不过如果只是当个轻量NAS或下载机，装个精简版Linux倒还行——前提是你愿意折腾。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEyqZNianK0kgs6zw3r2ibsvhFxraCUeLToYr5OxL2TYXd7N1HuYX8qakUv8E03xtsKFBpMeicksiacJw/640?wx_fmt=png)


那么，和二手鱼上其他百元小主机比呢？比如J1900、N3450这些常见型号，性能普遍强于Z3735F，价格也在150-250之间。但人家通常没电池、没键鼠套件，纯靠外接。这款ZXK虽然性能垫底，但胜在“集成度高”+“配件齐全”，适合想快速搭个临时播放器或演示设备的人。价格挺白菜，性价还行，这个价格还要啥自行车？


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEyqZNianK0kgs6zw3r2ibsvhkpQCWAEuBPVP8WML19U9W5ib5VG9FeUXKxArg63XOiawSXLIxzwicz21w/640?wx_fmt=png)


所以，如果你是以下这类人，或许可以考虑：

1. 喜欢拆机/刷机/折腾老旧硬件的极客玩家；

2. 需要临时接电视放PPT或视频的展会人员；

3. 想低成本试水家庭媒体中心的小白用户；

4. 纯粹收藏冷门迷你主机的数码猎奇党。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEyqZNianK0kgs6zw3r2ibsvhSk1Z0GzIQX7MtciaE9kqeSrMFqmVVR9Ftt84WgPIphicLW04UVMDnwWA/640?wx_fmt=png)


最后提醒一句：别指望它当主力机，连轻办公都吃力。但110块买个能亮屏、能联网、带全套接口的小盒子，可接受。尤其对比现在二手鱼上动辄200+的J4125主机，它赢在“新奇”而非“实用”。觉得这玩意有意思？评论区聊聊你见过最离谱的二手鱼宝贝是啥？老规矩，看完不买，立省110元。
