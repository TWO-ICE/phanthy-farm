# 二手鱼刷到高配低价显示器别冲动，看完这篇再决定是否下单

![封面图](https://mmbiz.qpic.cn/sz_mmbiz_jpg/E9h3abOJCelcjyQHLw1hW8BF8iaIiacjHNux2klmWk14gg0gdHFp5AIRpoIiaqUt3B7B8miaBP4Nd7JWkfkxInuxrSo3ukqDKG6yUamtYBB6EwI/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/yM_ZdumR6SSTmNCywPW3lA

你敢想吗一杯187元，就能在二手鱼里淘到一块标称144Hz的24寸显示器。这价格，属实是上演降维打击了。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelgibAC3CLOKw9Qvv183tXlTiatDtUZJUxs2zNrt3O7RrBtwSAJXc6Joy5J9nE5rVcMFjqpWl7Fpr088OoCSpIibDu0UfJXrpJHBQ/640?wx_fmt=png)


先别急，咱们冷静看看这到底是个啥。卖家描述挺全乎，24寸，144Hz刷新率，IPS面板，分辨率最高2K，接口是单HDMI+DP。从参数纸面上看，该有的基础电竞要素它都沾边，尤其是144Hz这个点，对于从60Hz传统屏过来的朋友，那流畅度的提升感知是明显的。IPS屏色彩和可视角度也比老TN屏强太多，办公看电影更舒服。它还自称全新未拆封，带原包装，甚至顺丰包邮，这架势，仿佛真是哪个仓库清库存的“大善人”。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCem0DicUBReaC2BKZHec8tpzIUwgpFkfcMrzP5l6DDVOia1dCul7xHd1pEWI5yACmaia9Z1MicCiaqBibxTPLCEXyysdiaWSOOTybplXgo/640?wx_fmt=png)


但是，问题就藏在这些美好的描述后面。

第一个致命点，无品牌，这就意味着品质无法保障。

第二个不包完美屏，这意味着屏幕可能有亮点、暗点或坏点，完美主义者真的会崩溃。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelYxWnxowKkRNz9aoVPfGQK5Jy0F7N1DGWib7YKCJ30icdcuex8qicpGnOaD2GTibgVEkAbNqRHG1NyGXWmjOAKDDfZCmpqvUQ0zlQ/640?wx_fmt=png)


那么，它值不值得买？我的看法很分裂。

从“要啥自行车”的角度看，187元，你甚至买不到一块好的二手显示器支架。这个价格，给你一个体验高刷新率、IPS广视角的入门机会，对于预算抠搜到极致的学生党，或者只是想给旧笔记本外接一块副屏处理文档的用户，它似乎是个“能亮就行”的选择。你可以把它扔在宿舍，或者作为炒股看盘的监控屏，用坏了也不心疼，这或许就是它的残值所在。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekIe8HBDPlFQmxLfBngjibGnT6OFl3aGeOCQnAnveeA4bUADibcRS7Xjl13rjCtTIOTmPFpAHMP7cRahMNuI9UX9JMibC1D6NPj90/640?wx_fmt=png)


但从垃圾佬的尊严看，我们需要多问几句。这面板是哪来的？是当年淘汰的库存？还是从电子洋垃圾里拆解翻新的？它的驱动板质量如何，能不能稳定跑满144Hz？色彩会不会偏到姥姥家？寿命能有几个月？这些如果卖家都能统统给出，那还是值得出手的。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenHia8c89M3CMUnBdBOhTLeiaoHibt8iahSgDDNqr45s3CYfNrLxbIH4c5ibt8bebB2KjlkH8FScOeDiaDGejicRJicw0CvJ6COO5ehRTQ/640?wx_fmt=png)


所以，如果你问我会不会买。如果我只是需要一个临时过渡的、对色彩和寿命毫无要求的副屏，或者纯粹想花小钱体验一下高刷是什么感觉，我可能会带着“翻车”觉悟去试试。但如果你指望它当主力电竞屏，或者从事对色彩有要求的工作，我劝你立刻收手，这钱省下来，加点预算买个靠谱品牌的二手，才是真正的“永远可以相信”。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekf9iakicnxXbiaCuMkKxjeP06ehSczXItdMhZiajI9scX2Kr30pUMEt2ibO6rTjGW4liavLibuLhrUFIZXzmFA4fDhJ0DLFA2fte3jp8/640?wx_fmt=png)


给你的建议就一条：如果真动心了，下单前务必用“灵魂拷问”式聊法，把面板型号、具体来源、质保方式（如何保修、多久）问得明明白白，并保留所有聊天记录。收到货，第一时间用在线屏幕检测工具好好测一遍，别忘了拍个开箱视频。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemQ8yej08PlsDXIcoPFR2ENf7utibKVeyRML0c2IXScYbAm4UDibTRg4rIPL1ehqXJL3Z5uLibC0qRf7f9z9M7qzly7LBdZicelNt8/640?wx_fmt=png)


老铁们，你们怎么看这种“价格再创新低”的电子产品？是真正的普惠，还是隐藏的深坑？你在二手鱼里捡到过最离谱的宝贝或者踩过最痛的雷是什么？评论区等你故事，点赞过百，我下次去扒一扒那些“工厂直发”的显卡到底靠不靠谱！
