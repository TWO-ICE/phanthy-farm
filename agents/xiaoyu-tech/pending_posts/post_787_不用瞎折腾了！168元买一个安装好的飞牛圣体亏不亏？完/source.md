# 不用瞎折腾了！168元买一个安装好的飞牛圣体亏不亏？

![封面图](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXEoaibE4Tia7qr3BicAwUOAJicUJCxnRXMSsOVMJMwRYESJTQNnIRnCVmkZm3hzUVfdMZb8ACIerKzWJg/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/DDyiCRBKNtbIT5IV0dBXag

卖家挂的是一款

N2810小主机，已经安装好了飞牛系统，不用自己再瞎折腾了，虽然价格并不是地板价，但好在配件齐全，还省去了装系统的麻烦，我感觉对新手小白非常友好。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEoaibE4Tia7qr3BicAwUOAJicUX2gcbrIBrEy5rYvXFELqbY0DRIQDhlu88knibjsQbeUsib3ib3a7139Xg/640?wx_fmt=png)


配置是Intel N2810四核处理器，没什么性能，但就是有着极致的低功耗。卖家描述“正常运行4-8瓦”，这数据基本靠谱。这意味着它几乎可以7x24小时开机，电费几乎可以忽略不计，这才是它作为入门级NAS最硬的底气。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEoaibE4Tia7qr3BicAwUOAJicUCfvicF5KSwtiaACialSo4qgAeDrUee90CV9ACaYuwtibXgDPP4RjH7gAfQ/640?wx_fmt=png)


4G内存（可扩到8G），120G固态起步，还预留SATA口，能再加一块2.5寸硬盘。VGA+HDMI双显输出，1个USB3.0、4个USB2.0、千兆网口、WiFi、音频口，该有的全有。卖家还送线材、装好系统、提供发票，甚至能选Win7或Win10，这服务比某些新品牌还周到。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEoaibE4Tia7qr3BicAwUOAJicUJYSzeh9OmTnzuVbGvUwicMqpvwYrDQ6gAIFmib8YRT5e4boNd6kiatEUQ/640?wx_fmt=png)


但是咱们必须把丑话说在前头。这价格和产品的来源注定它不完美。 

第一，N2810是2014年的老古董了，性能孱弱，单核能力甚至不如一些现代的手机处理器。你想用它做视频转码、跑复杂的虚拟机？趁早打消念头。

第二，扩展性有限。虽然能加内存和一块硬盘，但整体的升级天花板非常低，这就是个“到此为止”的玩具。

第三，成色和寿命风险。这种批量淘汰的工控机，虽然卖家说“成色很好”，但内部元件，尤其是主板电容的老化情况是未知数。稳定运行一年还是三年，看运气。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEoaibE4Tia7qr3BicAwUOAJicUgZYkusO3hDLHkib1FicSq4fkZLyUHsVnID0ybghZYDFBicpsrC09nT8dQ/640?wx_fmt=png)


所以，它适合谁？我觉得是这几类人： 

纯小白，想花最低成本体验NAS是什么感觉，搞个私人网盘放放电影、备份手机照片。

已经有主力NAS，想弄个备机跑一些常驻的、轻量级的服务，比如下载机。

需要一台超低功耗、常年开机的软路由旁路由或者智能家居网关。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEoaibE4Tia7qr3BicAwUOAJicUCTDBG7v3x8jlu4Upbk7eiah3Nn9icpNhdwrOkMP7zxuKzsadrY0tWBBg/640?wx_fmt=png)


如果你属于以上任何一种，那168元买来玩玩的成本确实很低，一顿饭钱，换几个月的折腾乐趣，不亏。但如果你期待它是一台“全能战士”，那绝对会失望。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEoaibE4Tia7qr3BicAwUOAJicUja6ibqyMR6V0RPA3vEewbvrCr37hFMEnl6rEUJfXpkhe64ESn16QdBw/640?wx_fmt=png)
