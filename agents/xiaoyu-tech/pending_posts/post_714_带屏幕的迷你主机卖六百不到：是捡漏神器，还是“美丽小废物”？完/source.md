# 带屏幕的迷你主机卖六百不到：是捡漏神器，还是“美丽小废物”？

今天在二手鱼刷到了一台标价598元的阿迈奇S1 N100准系统小主机，点进去一看，居然有1万+的浏览，好家伙，这热度比我朋友圈点赞还高。那么这东西值得捡漏吗？咱们一起来看看吧！


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHK8v8CZtlpt6UsZD5YKYTpZnyb1ibibBeZsgQNllsjsP1VDaogdpoRFDOyiapUk1zaAcsEWQtjj8rkQ/640?wx_fmt=png)


先说核心参数：Intel N100处理器，4核4线程，基础频率1GHz，睿频3.4GHz，TDP仅6W，日常功耗7–15W，省电到连电费账单都懒得理你。主板集成双千兆网口，自带WiFi 5 + 蓝牙，接口方面有2个HDMI、2个USB 3.0、1个USB 2.0、一个音频口，扩展性在迷你主机里算挺能打。更骚的是，它有两个M.2插槽：一个支持SATA协议的NGFF，另一个兼容NVMe/PCIe，意味着你可以同时装系统盘和存储盘，搞个简易NAS完全够用。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHK8v8CZtlpt6UsZD5YKYTpg5eyNPZbCCyNoNHR6M3rMVdUMQiaX0s8Z4Fo0Wial7vn6ddkKiaVVoJpw/640?wx_fmt=png)


最让我眼前一亮的，是那个可DIY的LCD小屏+RGB灯条。虽然实用性存疑，但晚上开机时蓝光一闪，仿佛自家路由器突然觉醒了赛博人格，多少有点“科技与狠活”的味道。而且整机采用磁吸快拆设计，不用螺丝刀就能开盖升级，对动手党友好得不像话。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHK8v8CZtlpt6UsZD5YKYTp8A6Np3na5GjbE1t6fS5RWQaIZMuaEcBehJm9MsTt5HzjWs6pL8edhw/640?wx_fmt=png)


不过重点来了：这是“准系统”，也就是说——没内存、没硬盘。卖家倒是贴心地列出了全套升级选项，比如加158元上8GB DDR4 2666内存，再加98元配256GB SATA固态，整套下来大概850元左右。考虑到最近内存价格确实有点“发疯式上涨”，这个加价幅度勉强算合理。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHK8v8CZtlpt6UsZD5YKYTpcTk4vydcaibjGBWFzk7liaDx0lWaukJpLJUZTGjWUrygPbbb7roLX5cw/640?wx_fmt=png)


那么可能有人会问N100性能够用吗？别又是‘电子垃圾’。客观讲，N100不是游戏U，但应付1080P视频硬解、多开网页、轻量Docker、Home Assistant、Alist挂载网盘这些场景绰绰有余。如果你指望它玩《原神》或者剪4K视频，那建议直接出门右转买笔记本。但作为7x24小时开机的软路由或家庭服务器，它安静、低温、低功耗，性价比反而突出。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHK8v8CZtlpt6UsZD5YKYTprTKmzKfaEt04dDE22rgE9X42CuT5kxHAgYBXyciaX0R6CAMSzw8cd3g/640?wx_fmt=png)


当然，这价格也不是毫无水分。598元裸机本身不算离谱，但如果加上16GB内存+512GB NVMe硬盘，总价逼近1100元，这时候就得掂量：是不是不如加点钱上J4125老平台整机，或者等N305新U降价？尤其对于只想当电视盒子用的用户，花近千元搞一台无显卡的小主机，属实有点“杀鸡用激光炮”。


 


以下是个人一些掺了水的建议：

1. 想搭软路由或轻量NAS的，可以冲。

2. 纯办公或影音需求，先算算总成本再下手。

3. 别被RGB和LCD屏幕迷惑，实用主义优先。

4. 看完不买，立省598元。
