# 不舍得上N100，可以看看这台258元的 J1900，价格便宜跑飞牛也够用

最近在二手鱼里看到有个卖家 在卖 飞牛圣体，258元起卖，卖家描述全金属外壳，九新以上成色，尺寸20×20×6cm，重量1.5公斤，做工扎实有分量。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekhRdZohaBPodxeZ8X4n2S9kXoWVKRgNiaxbvaWqP2oRCyHm0eDuJS2ibtIwP1NqnCrnjMOcyEgCmoutwEZq3yC7rjibibiaGpr6W90/640?wx_fmt=png&watermark=1&tp=webp)


配置是J1900四核处理器，4G内存加32G固态系统盘，一个SATA接口可以内置3.5寸或2.5寸机械硬盘。接口也挺全，HDMI、VGA、USB3.0一个、USB2.0四个、千兆网口都有。卖家还送12V5A的DC电源适配器、SATA数据线和供电线、硬盘固定螺丝， 而且还 装好了最新版的飞牛 系统 ，到手插上吃灰的硬盘就能用。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCem4AGGk6Dm9gmweRzqSpQK0Mklw9qce3k4PGsmgoeN7xDO63ia3uRGXzZzwBzTTDbH7f2vPOeibvnXhqI1iaCg92RHMqm82CiaJmXM/640?wx_fmt=png&watermark=1&tp=webp)


J1900垃圾佬们应该都不陌生了，四核四线程，2MB缓存，基频2.0GHz，TDP只有10W，虽然性能不如N100，但是价格便宜还 省电，实测待机功耗低到3W左右，满载也就十来瓦，用来跑飞牛不能说很快，但是完全够用。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelCS02lvW2sZn3lkapiaDawjNDc2A4hdQoxm8TvMyysoKXKKqRPCIvV4GG40qa2T7vUVv6uyC649XZ0hP5bfx5rDhme5RI4t10k/640?wx_fmt=png&watermark=1&tp=webp)


再看价格，卖家给了几个套餐：4+32卖258元；4+64卖278元；8+32卖298元；8+64卖318元。 那 这台机器到底值不值得入手？如果你是纯小白，不想折腾，就想花最少的钱体验一下飞牛系统，拿来做文件备份、照片存储、挂个下载机，那258元的套餐可以入。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekwVgRMe1p22UsZ1FRcseK3yNicKOqkkJj0sibf6tSD3icYjkqRswqrpq5w7mTJjvWwV8AhS8ArLz9BDwJU4b6lpPXAy5EvibOD0a4/640?wx_fmt=png&watermark=1&tp=webp)


建议选4+32的版本就够了，4G内存跑飞牛的基础功能绰绰有余，32G做系统盘足够，省下的钱去买块大容量机械硬盘存数据。要是你有轻度Docker需求，比如跑个alist、qbittorrent、homeassistant，那还是上8+32的套餐吧，298元多花40块换内存翻倍，长期用下来体验会好很多。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekskCqd2mUd4tLEc265djfraytJGibbXiavr1Dlm2xMS9tGnBJN9mWrQuBExJ8yO9vmxwkPGGRWHIEicAGdjYDx2kuyZcicLNWmwlI/640?wx_fmt=png&watermark=1&tp=webp)


另外要说的是 ，这台机器只有一个SATA接口，意味着你只能装一块硬盘。重要数据一定要做好异地备份，别指望拿单盘NAS存什么珍贵资料，万一硬盘挂了哭都没地方哭。最后，J1900不支持视频硬件转码，想拿它当家庭影音服务器的话，播放端设备得自己支持解码，否则CPU直接红温给你看。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemeHbI6OIcWFBRrWFEG9ibxyggjxhXh3UZP96rmulTXpCfJ02ibmhd1oypFLyUBqp3t7wWvpsOM8ObUquppAwqmEcrQUkNY9ODu0/640?wx_fmt=png&watermark=1&tp=webp)


聊了这么多，这台258元的“飞牛圣体”，你觉得是真香还是真坑？有没有已经上车的兄弟，出来说说实际体验怎么样？评论区等着你的故事！
