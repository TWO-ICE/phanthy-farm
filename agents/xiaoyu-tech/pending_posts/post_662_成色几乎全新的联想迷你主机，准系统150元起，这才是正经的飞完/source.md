# 成色几乎全新的联想迷你主机，准系统150元起，这才是正经的飞牛圣体

![封面图](https://mmbiz.qpic.cn/mmbiz_jpg/E9h3abOJCenmAhyy3fHLCEvtXSVzydBjxXh5WglHmicD0IUHrmhJs8tzYDDkwVelE8uBn7sWiaayD9Adsd5hG7OA2WxPoPo2B8ARscZHKGiaRs/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/lcd1pNud0Efps45LBtwFXg

兄弟们，最近二手鱼里的风向是真变了。前两年咱们淘个像样的迷你主机，没个三五百根本下不来。但今天刷到的这玩意儿，真让我有点破防了。联想M715Q，一个正经的大厂迷你主机，准系统直接干到了150块。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemyOvulk9hHwL6X614COeRXj1CpGbHeS7U01iamW7zvUXap7alrg7GqRoJOV5asV1bqMs3RIqAnMyZXgcUNAkeeo9sO9F5x08a0/640?wx_fmt=png)


可能新来的朋友不太熟这机器，这玩意儿当年可是联想商用阵营里的硬货，主打的就是个小巧、稳定、不占地方。搁在七八年前，一套下来也得两三千，当年高高在上的玩意儿，如今成了咱们垃圾佬眼里的香饽饽，妥妥的时代眼泪，但这眼泪流得值啊。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekTAJGgyLMaMTupA8VLic4Z34GIic4ia9jFtGWFBaXIq6zYmF8F2F1WU03QL7k37ys897fk7SicqjFpw4x6OVMchNTkvOjAd4VklIM/640?wx_fmt=png)


先别急着上头，这卖家出的是准系统，150块你就得到一个巴掌大的机箱加上主板，说白了就是毛坯房。你得自己给它配上CPU、内存、硬盘和电源。但妙就妙在，这机器的CPU是桌面级的AM4接口，像卖家套餐里提到的R3 2200GE、R5 2400GE，甚至更老的A10，现在二手价格都非常美丽。花个一百多块钱搞个CPU，几十块钱搞套内存硬盘，总成本压到400以内轻轻松松。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekvWiaySZbhUjquLnqU8fELICZATt350Sbsjm1nkxcRxPpHwiaPPeYbkxFiaV6duhJeQ11ZpsYz2o5nBicAL9xGfHOuYwtIQLLBicibA/640?wx_fmt=png)


它的优势在哪？我觉得最大的优势就是省地方和静音，而且因为是低功耗平台，发热低，风扇基本不怎么转，晚上刷剧、写文档，世界清静。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemFbuU75ZxXTlp3FJfy4FCXcQib8muOzck14J2WKWGPyy1FEs7cRdfjvcOflL6BHwdibYZRia1NicYTzuUQBxouJNsRV9aE2ibicHBJA/640?wx_fmt=png)


最关键的是能装飞牛，飞牛系统对硬件要求不高，正好适合这种小主机做NAS或者家庭媒体中心。它自带了2.5寸硬盘位，你塞个大容量的机械硬盘进去，再配合M.2接口装飞牛系统，功耗低，7x24小时开机也不心疼电费，比那些动不动就上千的成品NAS香太多了。下载电影、备份照片、搭建个私人网盘，这小家伙都能干得漂漂亮亮。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemW5SjypgxHWAaz0UDlHrWx4vVMpqiaGPQOCHBt1iasoLSENmibKESss5BxcGgERQpktia3hBl0atNGfdFMEibHdf3t8orSq1JEsTtI/640?wx_fmt=png)


当然，丑话也得说在前头。这机器的性能天花板就在那摆着，别指望它能玩3A大作。它的显卡性能也就相当于一个亮机卡级别，它的定位就是个出色的办公小帮手、合格的客厅影音机、或者一个低功耗的NAS服务器。另外，这卖家是商家，不是个人自用，但看他发的图，成色确实顶，说是准新机也不过分，这比咱们去赌那些不知道经历过几手、伊拉克成色的洋垃圾要靠谱多了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekzrE66pXELVZ2hWGcpDfMobUdRyF1ibE6VJZnYH5wbyy2hjmZmWWTImxtmtRate2Kj0pAGaSiaCicjX9Kc91Mwdte1jE02noxk98/640?wx_fmt=png)


150块钱买不了吃亏买不了上当，买回去当个玩具，研究研究飞牛，给家里老人做个炒股机，或者给娃上个网课，都绰绰有余。等玩腻了，再挂二手鱼里，估计也亏不了几个钱，残值简直稳如老狗。那么问题来了，如果你只有400块的预算，是会选择这种巴掌大的联想迷你主机，还是会去收那些又大又笨的老古董工作站呢？咱们评论区里聊聊。
