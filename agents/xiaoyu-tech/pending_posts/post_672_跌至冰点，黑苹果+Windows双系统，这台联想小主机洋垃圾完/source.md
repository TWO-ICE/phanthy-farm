# 跌至冰点，黑苹果+Windows双系统，这台联想小主机洋垃圾都破防！

![封面图](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXEusmhqZEXuQXHVQY9DCMibYL9FJbnWYsf96OKnKicGUuWu2a2qpkUH3ImicdXm3MRocQc1g2bx5VQwg/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/EJ2d2B0MFizwNWnwcccipg

最近是不是感觉，想给电脑加块硬盘，钱包都在发抖？存储价格一路看涨，连带新机、整机的价格都让人有点下不去手。这个时候，眼光就该转到一些“老宝贝”身上了。今天聊的这台联想M910Q迷你主机，就是我在二手鱼上扒拉了很久，觉得在当前环境下特别有意思的一个选择。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEusmhqZEXuQXHVQY9DCMibYia0x3pARycMdPzoJzYHheUPwvKsHHn7xLhDrCNuwV4O2TEicdT8AYFFA/640?wx_fmt=png)


先说最敏感的价格：495元，顺丰包邮。这个数字在如今能买到什么？一根像样的1TB NVMe固态？还是一张入门级显卡的零头？但在这里，你得到的是一个完整的、超级迷你主机：i3-7100T处理器、8G DDR4内存、256G西数固态，甚至还帮你改好了黑苹果的Wi-Fi和天线，电源也配齐了。开箱即用，插上显示器就能干活。从价格切入，这几乎是把“试错成本”降到了最低，一顿聚餐的钱，买回来一个功能完备的桌面终端。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEusmhqZEXuQXHVQY9DCMibYYib27Xic1IsEklZ7EhxeXdLdcsiaA4ThoiaA6HGyBwFjcM0psAZEENibndw/640?wx_fmt=png)


它支持6代和7代英特尔CPU，意味着你手里的i5-6500T、i7-6700T这些“老兵”都能继续发光发热，升级空间可观。双硬盘位（M.2 NVMe + 2.5英寸 SATA）在如今存储昂贵的时期是个巨大优势，你可以先用自带的256G装系统，后期再加个大容量的SATA固态存资料，成本可控。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEusmhqZEXuQXHVQY9DCMibYhfA6dYNpBvXiazmyVeo08A0VpRGJrc2mWKdok9VQ3jEgdeJ3hVfvYPw/640?wx_fmt=png)


495元买它，核心买的是一个高集成度的、省空间的解决方案。它的性能足以流畅应对办公、网页浏览、1080P视频播放，甚至轻度PS和黑苹果体验。对比同价位全新产品（可能只能买到性能羸弱的全新迷你主机或平板），或者对比树莓派（现在价格也飞起），它的完整度和性能释放更实在。从残值角度看，这种经典迷你主机在二手市场的价格已经相对稳定，你玩一年半载再出掉，损失很可能远小于一台全新设备跌价的速度。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEusmhqZEXuQXHVQY9DCMibYx0xnoOHibib9yaT33kfGevMXOo7ucKPMVuiajEeTjBLqR0M1372xyxhibg/640?wx_fmt=png)


当然，必须说真话，不吹不黑。它的劣势也很明显：i3-7100T是双核四线程，别指望用它跑大型游戏或重度渲染；这是二手企业设备，外观可能有使用痕迹，需要接受“战损版”的可能；卖家注明“售出不退”，这就非常考验买前沟通和验货视频的仔细程度了。所以，它不适合追求极致性能和新潮设计的用户，而是精准服务于那些需要第二台电脑、给父母孩子上网课、做软路由/家庭服务器、或者就是想低成本体验黑苹果的折腾党。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEusmhqZEXuQXHVQY9DCMibYH7FblmGbZsEWB8iaAcWC6ltkbb1tFtNnuSxZ9zEHlhskwCicwQtyJsfA/640?wx_fmt=png)


说到底，在存储涨价、新品价格高企的背景下，这些从企业和工厂渠道流出的“洋垃圾”或淘汰设备，反而凸显出独特的性价比。它们像是数码世界的“基础建材”，虽然不够光鲜，但足够扎实，给了预算有限的玩家一个务实的选择。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEusmhqZEXuQXHVQY9DCMibY8icyYyIJvITxXf7jAqFMJb3dwB2wMR0hfccib12ibu2XHajA6k5tmhG2A/640?wx_fmt=png&from=appmsg)

你有没有淘过类似的“电子古董”？你觉得在500元价位，是这种品牌迷你主机更划算，还是自己组装的二手ITX更有乐趣？或者，你对黑苹果有兴趣吗？评论区聊聊你的看法吧！
