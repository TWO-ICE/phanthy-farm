# 二手鱼卖家把iPad4魔改成便携屏，标价140元，看的我有点心动

![封面图](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXH7cXtFdj5dMViaopV8PYZDsySBfGz7ibefP4RRiaia9qrg5OMvibyEjfrjA4f8Vf9sXtI0PHI3aswBrcg/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/eLs_dAJ5QwT3Hd7HDcnl_w

今天在二手鱼刷到了一款“iPad 4改的便携屏”，标价140元，还带触控和喇叭。第一眼看到的时候，感觉还真有点意思。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXH7cXtFdj5dMViaopV8PYZDsEhlWmDwI8dUluhicC44kqgroDpHsOK2IMRicuAXloQcbp4cwITlLS8lg/640?wx_fmt=png)


这玩意儿说白了就是把一台老掉牙的iPad 4拆了，只留下屏幕模组，再塞进一个自己找工厂定制的铝壳里，配上驱动板，变成一块能接HDMI信号的便携显示器。卖家强调“做薄便携”，成品厚度仅12mm，比市面上常见的14mm成品还要薄2mm。别小看这2mm，在便携设备的世界里，那可是“薄如蝉翼 vs 厚如砖头”的差距。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXH7cXtFdj5dMViaopV8PYZDsgmIIOyYBpg4DEuw03ARmyfJ2s1G6yRCdCJnWwVFZ8LRh3iceBDf6NKA/640?wx_fmt=png)


参数方面，这块屏用的是原装iPad 4的Retina屏，分辨率2048×1536，9.7英寸，4:3比例，PPI高达264——放到现在，色彩和细腻度其实并不拉胯，尤其适合看文档、画图或者当副屏码字。驱动板有两个Mini HDMI接口（注意是Mini，不是标准HDMI，得转接），支持即插即用，不用额外供电。更骚的是，加100元还能上触控功能，而且“厚度不增加1mm”——这话听着像营销话术，但结合DIY属性，勉强信一回。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXH7cXtFdj5dMViaopV8PYZDs07PF7o7exjhialDiaU4GBYQRU9ibB6pI3CiaUl3PgKeD211mSRl4AWUJDQ/640?wx_fmt=png)


重量没写具体数字，但既然用了铝壳+去掉了电池和主板，估计在400g上下，比一台Switch OLED还轻点，塞包里确实不占地方。喇叭也有，虽然大概率是“能响就行”的水平，但聊胜于无。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXH7cXtFdj5dMViaopV8PYZDsxnic1hZmrW5S1PEHX2DTVlREib8b4nL8rvwbKMfMX05N0dO0ZM5aOPdQ/640?wx_fmt=png)


可能有人会问：“这不就是个电子盆景吗？现在百来块能买全新720p小屏，为啥要折腾老iPad屏？”因为原装Retina屏的观感，确实吊打同价位新屏。很多百元级新便携屏用的是低色域、低亮度的杂牌面板，而iPad 4这块屏哪怕十年了，色彩准确度和可视角度依然能打。如果你对显示素质有执念，又预算有限，它算个冷门解法。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXH7cXtFdj5dMViaopV8PYZDs3NzwjsYtGEUomxCKOxuLmWqEGdLsyoL74364e4lWiaibahyDe9rTH4zg/640?wx_fmt=png)


那么，140元贵不贵？得看你怎么比。目前全新入门级便携屏（比如1080p、15.6寸）普遍在500元以上，7寸小屏也要200+。但如果是纯副屏用途、不碰触控，其实有更便宜的方案——比如某些工包屏+驱动板套件，100出头就能搞定，只是没外壳、要自己折腾。而这款的优势在于“到手即用+超薄+原装屏”，属于省心但小众的选择。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXH7cXtFdj5dMViaopV8PYZDs3A799znmF21a5BGdtEXjYAaicZ2D0I8icQVib9pgr41lMXQWvesNSoUww/640?wx_fmt=png)


不过也得泼点冷水：这毕竟是DIY产品，非批量生产，品控全靠卖家手艺。颜色能定制听起来很酷，但万一你想要“赛博青轴紫”，结果收到“老年健步灰”，也没处说理。另外，140元不含触控，加触控要240元。这个价格区间，其实已经摸到某些二手品牌便携屏的底线了。所以是否值得，完全取决于你对“超薄+原装Retina屏”的执念有多深。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXH7cXtFdj5dMViaopV8PYZDsCJ8VbWciaxFgClsicQygr4OXDibrUAJCAV7icQNI5KYjYVuuibibzunhEg3g/640?wx_fmt=png)


想自己找？很简单，在二手鱼搜“ipad4改便携屏”就行。如果搜不到，可以试试图片搜索——上传类似产品的图，系统有时能扒出同款。要是还是找不到，那大概率是已经卖出或下架了，毕竟这种DIY单品，往往就一两台库存。


 


以下是个人一些掺了水的建议：

1. 只推荐给需要高PPI副屏的用户。

2. 别指望它能当主力显示器，定位是“应急+便携”。

3. 加触控前先想清楚是否真用得上，否则多花100元不如省着。

4. 看完不买，立省140元。
