# 是不是冰点价格？300元捡漏小米的“无头骑士”笔记本亏不亏？

![封面图](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXH66Hsg0vicFyaicRhgIHst01YkwJw1FybkSWXHLunqdjmdCziaIcJ6WgYjR7gpkias5ty3mNwkickQticg/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/eGgi3o_-FRRSN1FKxDtryw

你知道“无头骑士”笔记本吗？屏幕坏了不要紧，拆掉屏幕只用主机部分仍然能继续战斗，这样的“无头骑士”笔记本在二手鱼里很吃香，今天我就淘到了一款小米的“无头骑士”，售价300块，一起来围观一下吧！


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXH66Hsg0vicFyaicRhgIHst01XamJbebtyL3SjXQXWDbbSNnrribNCWEchxdzotdLBr13fEUPCLbV6pA/640?wx_fmt=jpeg)


核心配置是i5-6200U、8G内存、256G固态、还带1G的独显。注意！这不是山寨机，不是杂牌，是正儿八经的小米TM1613——当年打着“高性价比”旗号杀入笔记本市场的那款。  


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXH66Hsg0vicFyaicRhgIHst01wZNIvWvNPW47AibxZg57ZsoFgtacCbKslibXh6kFI4BMcjTPia2SRr5UQ/640?wx_fmt=jpeg)


卖家明确说了：“电池健康忽略不计，插拔没多久就关机”。翻译一下：电池基本报废，只能插电用。但反过来想，如果你把它当台“桌面轻薄机”用呢？放书桌、接显示器、当备用机或孩子上网课设备，其实完全OK。毕竟它不是要你背着跑，而是稳稳当当做生产力工具。  


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXH66Hsg0vicFyaicRhgIHst01bT5SP3J5799R1T9ZSgb56gpakXtyM6u1FDdpAZtmDmth3TL77NMSibQ/640?wx_fmt=png)


性能方面，i5-6200U虽然是六代U，但双核四线程，主频2.3GHz，日常办公、看视频、开几十个网页依然流畅。显卡是NVIDIA 920M1G显存，虽然打不了游戏，但比纯核显强一点，偶尔处理点轻度图像也够用。8G内存+原装256GSSD，系统跑Windows 10毫无压力。  


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXH66Hsg0vicFyaicRhgIHst01JLM6ysibibH1mYH5n7nF7UdyF9JZc9QI4AStNKRI0v8L809SCVic9dfPw/640?wx_fmt=jpeg)


更关键的是——它是金属机身！小米当年为了对标MacBook Air，在做工上下了血本。A面CNC一体成型，质感远超同价位杂牌。屏幕也没划痕，功能正常，说明前任主人挺爱惜。  


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXH66Hsg0vicFyaicRhgIHst0143hn48I6TeRNS9Vz1hnznBlpOTfWAOI8ASwM0xicDc8ohtc6lXjHgOQ/640?wx_fmt=png)


但隐患也有：  

- 电池报废意味着移动性归零，必须插电；  

- 六代平台已停止主流驱动支持，Win11兼容性差；  

- 散热模组老化后可能降频，长期高负载会卡顿；  


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXH66Hsg0vicFyaicRhgIHst01JDe4yQDxyOQRcxfT0bwCy7yeXEwicj56hbvRLQMsPh2yKqzcHAXS0jQ/640?wx_fmt=jpeg)


可话说回来，现在新入门笔记本动辄2500+，而存储产品价格又在涨，相比之下，这台小米本300元的价格，简直是“开启甩货模式”的极致体现。它的残值几乎见底，再跌也跌不到200了，但性能却还能撑两三年基础使用。接个24寸显示器，妥妥的书房主力机。或者刷个Linux，当家庭服务器、下载机、甚至轻量NAS，功耗低又安静。
