# 这台12年前的东芝二合一平板电脑卖196，我差点就信了

今天在二手鱼刷到了一台东芝的 11寸二合一平板电脑，标价196元。点进去一看，好家伙，详情里写得那叫一个天花乱坠——“高性能四代”、“win10/win11通吃”、“超轻超便携”……甚至还扯上了“超魔改小米2平板”这种玄学标签，看得我差点以为这是赛博朋克2077里的装备。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEibZuplW9qYKWAicjezfy6yjXR6jXS9mGVsNEBD6jlbPJadkxhNuTTIwthzyMDqMicPbI0laJfnKLHw/640?wx_fmt=png)


先说配置吧。卖家列得挺细：Intel 四代处理器 4020Y（注意，不是i5/i7那种主流U，而是低电压双核），4GB内存焊死不能换，没装固态硬盘（但可自行加装），带风扇散热（这点倒是比某些无风扇的M系列强点），屏幕是1920×1080的IPS触控屏，但“左右两角略暗”——翻译成人话就是背光不均，属于典型的老化症状。整机重700多克，电池健康度60%，亮屏续航3~5小时，附赠电源，键盘另加35元。


 


乍一看，196元买个能跑Windows系统的11寸触屏设备，好像挺香？毕竟现在随便一个安卓平板都要三四百起步。但冷静下来一琢磨，问题就来了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEibZuplW9qYKWAicjezfy6yjf3mraJ8GRiaaRbxSxdIpCANvoibOb67KO8eKic31Cn4Zb7YcNsKkWmYQQ/640?wx_fmt=png)


首先，这台机器用的是Intel 4020Y，发布于2013年，距今整整12年。性能大致相当于现在的低端赛扬，日常开个Edge、看个B站1080p视频勉强能撑住，但要是想多开几个网页+微信+钉钉，估计风扇会狂转到像拖拉机启动。而且4GB内存还是板载的，没法升级，Win11跑起来大概率卡成PPT。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEibZuplW9qYKWAicjezfy6yjZDwTn0uFKeKibWYVv63FmQEwYY4ymcW0Af9VicF3ia6q2gySy8iaQzGcgQ/640?wx_fmt=png)


其次，没固态硬盘这事很致命。虽然卖家说可以自己加（加128G要30块），但MSATA接口早就淘汰了，现在新盘贵、选择少，二手盘又怕掉速掉盘。你花30块买个老接口SSD，不如直接加点钱上个全新入门级笔记本。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEibZuplW9qYKWAicjezfy6yj3S5egicI9KbpUMwanHicYLGFicT4I4GcYiapzUWK6BozJW4rydDVbdibiasQ/640?wx_fmt=png)


再者，屏幕有背光不均。对强迫症来说，这基本等于“残”。哪怕只是角落发暗，在暗色背景下也会特别扎眼。卖家说“瑕疵特价出”，其实已经暗示了：这机子就是清库存+回血用的。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEibZuplW9qYKWAicjezfy6yjichGSYNSUw4ibicia3IFBpuBvZBvjNiaFJsLP4nJwF6gGLBTu41SwgI7m5Q/640?wx_fmt=png)


那么，2025年这个时间点，196元到底算不算捡漏？查了下近期二手鱼行情：同款东芝普遍挂价在300+，成色好、带SSD的要400往上。所以196元确实算低价，但前提是——你能接受它的所有短板。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEibZuplW9qYKWAicjezfy6yjgaqt899UGnOagL3XjfEWiaG6fMU336OxvrOib2kH5tricgWschOoO49TQ/640?wx_fmt=png)


说到底，这台机器的核心价值不在“性能”，而在“Windows系统+触屏+便携”三件套的组合。如果你恰好需要一台能手写批注PDF、偶尔插U盘导文件、还能当电子相框用的备用机，且预算卡死200元内，那它或许值得试试。但如果你期待“办公主力机”或“学习神器”，那真不如看看2000块以内的国产二手轻薄本。


 


看完觉得有用？评论区聊聊你最近在二手鱼淘到过哪些“看似捡漏实则踩雷”的玩意儿？一起避坑！最后给几点建议：

1. 预算紧、需求极简，可小试。

2. 想当主力机？别，真别。

3. 屏幕瑕疵党慎入，眼不见为净。

4. 看完不买，立省196元。
