# 100多就能组双盘位飞牛NAS？垃圾佬们这次准备出手了吗？

最近常年在二手市场“淘金”的兄弟们，如果不举手示意一下，都对不起你们历经沧桑的钱包。说句掏心窝子的话，现在的 NAS 圈子真是越来越让人看不懂了。你要是想正经八百地组一台“像样”的 NAS，光去找个稍微能入眼的机箱，再配个不再像古董一样的主板，兜里没个三四百块钱基本是别想了。更别提那些前几年被矿渣淹没的工控机盒子，买回来光是折腾各种野生驱动、解决莫名其妙的掉盘问题，就能把你的心态搞崩，稳定性全靠玄学护体。

其实，很多时候我们不是玩不起高端货，而是单纯的觉得“冤”。当你花了大几百甚至上千块，组了一台性能怪兽，最后发现它 99% 的时间只是躺在角落里吃灰，用来存几张照片和几部下不动的高清电影，那种“大炮打蚊子”的性能过剩感，真的很膈应人。NAS 的本质是存储，而不是跑分，这点很多厂商似乎都忘了。

但是，就在昨天，我在二手鱼里瞎逛时，竟然翻到了一台能被称为“价格屠夫”的玩意儿——一台支持双盘位的飞牛轻 NAS 小主机。这东西居然把价格直接干到了 148 元。

说实话，看到这个数字的时候，我第一反应是看错了，或者是那种没有电源的 barebone（准系统）。结果仔细看卖家描述，这居然是准成品配置：双盘位设计，能支持两块 2.5 寸硬盘（无论是机械还是固态都行），而且整机居然采用了被动散热设计。

这里必须得给不懂的朋友科普一下“被动散热”在这个场景下的含金量。这种小主机内部完全没有风扇，CPU 顶盖上直接扣着一根巨大的金属散热鳍片，利用机箱全金属外壳进行热传导。这意味着什么？意味着零噪音。对于那些想把 NAS 放在卧室床头柜，或者塞进书房书架里的玩家来说，这种“全静音”的运行体验，比多两个 USB 接口要香太多了。

咱们来扒一扒这玩意的核心配置。它搭载的是一颗英特尔赛扬 1007U 处理器。没错，就是那个在 2013 年左右发布的“古董”级双核 CPU。这颗芯片功耗极低，性能嘛，用现在的眼光看确实是“弱鸡”。但是，我们不能脱离场景谈性能。

这玩意的定位非常清晰：纯 NAS 或者软路由。如果你拿它去跑 4K 视频转码，那肯定会卡死；但如果你只是把它当成一个 Samba 文件服务器，或者跑个 OpenWrt 给家里的网络做拨号、去广告，那这性能不仅刚刚好，甚至有点过剩。配合 4G 的 DDR3 内存，再预装好飞牛 NAS 系统，基本就是到手通电就能用的状态。卖家的策略也很“鸡贼”，基础套餐是 4G 内存 + 32G 系统盘，只要 148 元。如果你想折腾更多 Docker 容器，加 20 块钱能升到 64G；如果还想让它当个临时 WiFi 热点，再多花 15 块还能加装个无线网卡。

二手鱼里玩这类小主机的群体，有一句名言叫“只谈实用，不谈情怀”。你看这个机器的接口布局，简直是把“实用主义”刻在了脑门上。它同时保留了 HDMI 和 VGA 接口，这看似复古的设计其实大有深意：说明它不仅能当你抽屉里的 NAS，万一哪天你家里主力电脑炸了，或者亲戚家小孩要查资料，这玩意儿插上显示器、键盘鼠标，立马就能变身一台临时的 Linux 或者 Windows 办公电脑（虽然开机速度慢了点）。

虽然它只有四个 USB 2.0 接口，传输速度上限确实不高，但接个打印机共享、插个 U 盘做本地备份完全是绰绰有余。千兆网口是标配，这也是跑满内网读写速度的底线。外壳全金属打造，尺寸只有 19x19x4 cm，还没有一本稍微厚点的高端杂志大，随便找个书架角落就能塞进去，完全没有存在感。

那这东西到底值不值得买？我觉得得分人，非常分人。如果你是那种追求极致性能，张口闭口就要上 N100、J4125，甚至觉得不用 i7 跑 NAS 就没面子的高端玩家，那这台机子你赶紧划走，别看，看了也只会觉得这是电子垃圾。

但如果你是那种家里刚需一个私有云，想低成本体验一下飞牛 OS 的各种玩法，或者手头正好有几块闲置的 2.5 寸硬盘没处扔，那这台小主机绝对是目前二手市场里性价比最高的选择之一，没有之一。

来，我给你们算笔实在的账。现在你去某宝某东，随便买一个能装两块 2.5 寸硬盘的 USB 硬盘底座或者双盘位硬盘盒，只要质量稍微靠谱点，接口不是那种虚标的，价格基本都在 100 块钱往上走。而这台小主机，等于送了你一个硬盘盒的钱，然后额外白送了你一个低功耗 CPU 主板、4G 内存、32G 系统盘、电源适配器，甚至还有预装好的系统。

这哪是买硬件，这简直是“白嫖”服务器。而且这种机器本身就是从工厂生产线或者企业办公环境淘汰下来的，原本的设计初衷就是为了 7x24 小时运行，外壳和内部 PCB 板的做工扎实程度，往往比现在的山寨组装机要好得多。它的二手残值几乎已经跌到了谷底，现在买回去玩一年，明年哪怕当废铁卖了，或者直接送人，亏掉的也就是运费钱。

我的建议是，如果你心动了，下单前一定要想清楚自己的“使用场景”，这决定了你怎么选配置。

如果你只是想把它丢在角落，默默给手机存照片备份，或者当个单纯的下载机挂机，那直接选最基础的 148 元套餐就够了。32G 的 eMMC 或者 SSD 作为系统盘，跑飞牛系统是稳稳当当的，剩下的预算建议全部用来买两块大容量的 2.5 寸机械硬盘或者闲置的 SSD 装上去。

但是，如果你稍微有点折腾的瘾，比如想把它当软路由跑个 iKuai 或 OpenWrt，或者想在这个小机器上跑几个 Docker 容器（比如签到脚本、去广告模块），那我强烈建议花 20 块钱升到 64G 版本。多出来的空间对于 Docker 的日志和镜像存储来说，会从容很多，避免过段时间就被塞满导致崩溃。

千万不要觉得一百多块钱的东西就没有“战斗力”。在这个存储价格飞涨、固态硬盘价格起伏不定的年代，能花小钱把手里闲置的硬盘利用起来，顺便享受一把私有云带来的数据安全和便利，这本身就是一种极客智慧。而且这种小主机最大的杀手锏就是——安静。没有机箱风扇的啸叫，没有 CPU 散热器的嗡嗡声，把它放在电视机旁边的柜子里，或者放在书桌案头，它就像一块安静的砖头，默默为你服务。

如果让现在的你做选择，你会买哪个套餐？是直接拿 148 的入门版开干，把硬盘利用起来再说，还是加钱上带无线网卡的顶配，让它当个多面手？欢迎在评论区聊聊你们的看法，看看这次能不能在二手鱼的垃圾堆里，真的淘到宝。
