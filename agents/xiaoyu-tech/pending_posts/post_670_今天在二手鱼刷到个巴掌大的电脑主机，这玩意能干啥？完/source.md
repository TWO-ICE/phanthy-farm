# 今天在二手鱼刷到个巴掌大的电脑主机，这玩意能干啥？

今天在二手鱼刷到了一台巴掌大的迷你电脑小主机，标价410元，卖家说是“驰为Larkbox”，J4125处理器、6GB内存+128GB SSD，还额外加了一块128GB的SSD。乍一看，这配置好像还能打，但细品之后……emmm，有点微妙。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXH6raFjM09MeZS6e8XKo3Jib05D0jFLWaCibC4ren11QoCTGusibz3qfce3tHnb3pagKsFs5FNFxno9w/640?wx_fmt=png)


先说外观，号称“口袋Win”，放裤兜里走路都不带晃的。机子有使用痕迹，但没到“战损”级别，配了个充电头，其他啥也没有。重点来了：没有RJ45网口，全靠WiFi连网。对某些人来说可能是无伤大雅，但如果你打算拿它跑NAS、刷飞牛、搞软路由，那对不起，得再掏几十块买个USB转网口的小玩意儿。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXH6raFjM09MeZS6e8XKo3JiblPjI2j0CibvOhonNH5pXTk0G3yiatzR5lhEXeTChIUFF9ty7BrGbewqQ/640?wx_fmt=png)


这款驰为Larkbox迷你主机用的是英特尔J4125处理器，4核4线程，基础频率1.7GHz，睿频能到2.7GHz。6GB内存+128GB eMMC存储，还额外塞了块128G SSD——虽然速度别指望多猛，但存点文档、装个轻量系统够用了。尺寸大概10cm见方，，电源配了个小充电头。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXH6raFjM09MeZS6e8XKo3JibJLKkw5FDwSoU7tI0P1RdvktAVCjPeuN36JFOIE3tNbI6zdlWYprewQ/640?wx_fmt=png)


价格方面，410元买这么一台小主机，说实话不算便宜。同价位你都能买到全新N100小主机（比如零刻、铭凡那些），性能强30%以上，接口还齐全——HDMI、USB 3.2、RJ45网口一个不少。甚至有些品牌清仓的J4125整机，带电源、外壳、散热，也才卖300出头。所以这台“口袋机”的溢价，基本全在“体积小”这个点上。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXH6raFjM09MeZS6e8XKo3Jib1ZicPwyLPkbiarxiazuslmkHA1EvoDel5piagX7SMTxqrQ4ibOB3EAOkxYg/640?wx_fmt=png)


可能有人会问这玩意儿到底能干啥？首先可以接电视当HTPC勉强够用；远程桌面办公应急可以；或者……如卖家所说，“公司摸鱼专用”。毕竟体积小，藏键盘底下、塞抽屉里，老板路过都看不出你在跑Windows。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXH6raFjM09MeZS6e8XKo3Jib3qEZjEw2DVIhS6xKhERUwIo7zY8LNBoicRIn1HRPpeuPsJ3wyNCqPxQ/640?wx_fmt=png)


说实话，410元买J4125，性价比只能说……见仁见智。现在二手市场N100小主机也就500出头，性能功耗都更强，还有双网口版本。但如果你就图它尺寸迷你、便携性拉满，那这类“口袋Win主机”确实稀缺。卖家强调“物以稀为贵”倒也没错——毕竟不是所有人都需要它，但对特定人群（比如需要超隐蔽备用机、客厅电视盒子改造党）可能真有点吸引力。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXH6raFjM09MeZS6e8XKo3Jib9IqmiccbZgB7zJ37lKDB6InswibPx1at0HlkBuEFQPiaU7icD4wshwicvCw/640?wx_fmt=png)


以下是个人的一些建议：

1. 别为“小”盲目买单，先想清楚用途。

2. 同价位有更强新机，别被“迷你”冲昏头。

3. 没网口=扩展成本增加，算总账再下手。

4. 看完不买，立省410元。
