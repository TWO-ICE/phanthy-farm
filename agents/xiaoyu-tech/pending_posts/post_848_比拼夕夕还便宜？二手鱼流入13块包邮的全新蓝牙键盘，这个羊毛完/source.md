# 比拼夕夕还便宜？二手鱼流入13块包邮的全新蓝牙键盘，这个羊毛值得一薅

今天在二手鱼刷到了一款标价13元包邮的全新蓝牙键盘，卖家说是实体店退租清仓处理的，颜色有10种，从白色、黑色这种基础款，到青山黛、海棠红这种听起来像口红色号的配色，选择比奶茶店还多。卖家还信誓旦旦说“功能完好”“续航一个月”“反应无延迟”，最关键的是13块还包邮。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGQYhnrrbLocW77ucO6wlI6FTIicGbibPJ6scKev7Iysd5CaxHs4Fm08XTrrrYfecujgeyL7SBRg0FA/640?wx_fmt=png)


先别急着下单，咱得冷静分析下。这款键盘尺寸是10英寸，主打便携，适合iPad、安卓平板、带蓝牙的笔记本甚至手机用。不带接收器，纯靠蓝牙连接，所以你的设备得自带蓝牙功能才行。充电一次号称能用一个月，听起来很香，但实际使用中是否真如卖家所说不得而知。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGQYhnrrbLocW77ucO6wlI6MsEu3ktqCsMkvv27AP5tdKDCdbiaTONLSOmzv3d3YweMtJg0r3GsqLA/640?wx_fmt=png)


参数方面，没提具体芯片型号或按键寿命，但从描述来看，这大概率是市面上常见的薄膜式蓝牙键盘，手感肯定没法跟机械键盘比，敲起来软趴趴的，但胜在安静、轻薄。重量估计不会超过200克，塞进通勤包毫无压力。颜色丰富这点确实加分，尤其对喜欢个性化配件的用户来说，花13块钱换个心情，也算值回票价。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGQYhnrrbLocW77ucO6wlI6miapicbvvyjjB1r5atfCicmUSl2ENP55icErQT5JDNcKibG3YZIsqibFr7wA/640?wx_fmt=png)


老实说13元包邮确实略低一点，但差距并不夸张，拼夕夕、京喜、淘宝上都有类似的产品，只是价格没有二手鱼里的低，但考虑到这是“清仓尾货”，且支持自选颜色、承诺24小时内发货，这个价格算是合理区间内的小惊喜，唯一的缺点就是售后无法保障。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGQYhnrrbLocW77ucO6wlI6PMkxicIicD9e3HQ1AAcRkYRW8Ycm73KBiaaCaFCIFqWRcq3mM6hcDnsCA/640?wx_fmt=png)


所以值不值得冲？得看你需求。如果你只是想给平板配个临时输入工具，或者给孩子上网课用，又或者需要一个备用键盘出差带着，那13块买个全新、包邮、还能挑颜色的，性价还行。但如果你对打字体验有要求，或者打算长期主力使用，建议加点预算上个百元级的，至少轴体和结构更靠谱。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGQYhnrrbLocW77ucO6wlI6SXONSdSZYzjpxtr1MUVF1o5VIO8MpFSwBf0QeBQ8c04dIGUopElrug/640?wx_fmt=png)


以下是个人一些掺了水的建议：

1. 需求明确再下手，别为便宜买不需要的东西。

2. 13元可接受，但别期待高端体验。

3. 优先选支持退换的卖家，避免售后扯皮。

4. 看完不买，立省13元。
