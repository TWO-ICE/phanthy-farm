# 3D打印的3盘位 N3150飞牛圣体，250 元该不该捡漏？

![封面图](https://mmbiz.qpic.cn/sz_mmbiz_jpg/E9h3abOJCenibTDJSknKthfYZq92uTOuPEEC6tIM1SGetX0EBGGzdnUowDlf125phbdyUic0ib1X49ML3wNKNafxnAeRrQSeciaxmdSPEz59CXQ/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/UW0jrL66jNl7UN5q3ttVLw

我刷到个卖家，挂了个飞牛NAS主机，要价250。这数字一看就很吉利，但等我仔细看完那长长的一段卖家描述，才发现这小玩意儿还真有点意思。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekf0wFMeGjQBiba6ibzhIdsP9bnXOdavibMC69cfCLCP8TUnuYxiblXUbd009l6dDmBlQgcn7QIzXUme7MtQhETNCAKZg1POJlPREQ/640?wx_fmt=png)


这台主机的核心是N3150。很多人不待见它，觉得主频才1.6GHz是淘汰货。但兄弟们，这是英特尔14nm工艺的初代尝试，虽然老，但它的TDP功耗只有6W 。比J1900还省电，一年挂机下来电费几乎可以忽略不计。如果你只是想搞个24小时不关机的轻NAS，用来备份手机照片，这U的性能够够的，完全不是那种卡到不能用的电子垃圾 。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekh8ETqh9q0RkUDakKfstSmpZqaK00QkoKviahf5NLZmgicI5BwvnOjpyicT5iak41R6MOktSH6dK9AZeuXlg6Z8m2k9cNtSqVhzCc/640?wx_fmt=png)


卖家这套打包价250，说实话，算下来真没赚钱。我给你们拆解一下：一张N3150 ITX主板二手怎么也得七八十；一条4G DDR3内存现在虽然是白菜价但也得十来块；卖家还带了个64G的msata硬盘，这玩意儿专门用来装系统刚刚好；最难搞的是机箱，这货是3D打印的定制款，支持ITX主板，尺寸才205*186*80mm，去某宝找人打一个外壳加风扇和电源，一百多块是跑不掉的 。这么一算，卖家就是纯纯的回血，这趟车稳得很。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemfZ90jxVdBdCeIRVlibYsmhshoHZO6hF3HP5FOwf2NpFA1M9vKmqAUvhjRxnMYsGbYuozRicsIxRYSlporrze6Yaa2UHiaic5624w/640?wx_fmt=png)


当然，这世上没有完美的捡漏。这机器最大的短板就是那个单千兆网口。如果你是那种喜欢在飞牛里跑虚拟机、搞软路由all in one的大佬，这玩意儿肯定满足不了你。但对于绝大多数人来说，千兆内网跑满113MB/s，看4K原盘拖动进度条完全没压力。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCel9iaoz4Cibrb76allYticDqJB1K8tqJDhzRiaOs59OednSmjFLC9YbF29gs9xvmCxEzPNXXqtYnGVjOf3tSNsfm4ia7jMRGibL6Zpvc/640?wx_fmt=png)


这台机器对于小白来说极度友好。卖家已经预装好了飞牛OS，系统就躺在那个64G的msata里。你到手要做的，只是把手边的旧笔记本拆下来的2.5寸硬盘塞进去拧上螺丝。不管是插3块2.5寸盘组个小钢炮，还是塞一块大容量3.5寸机械盘存电影，对小白来说基本就是零门槛 。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenSiaH9LhRgTnIKJp6Vcf7JjnHxYt74PXjp5tGHQlVGl1rXMRyiadyCT6bcRDgicRfskRIHe6jjNCb7YVEnUsUicpicSLHVhkYciaPac/640?wx_fmt=png)


如果你是刚入坑的垃圾佬，手里正好有几块闲置的笔记本硬盘，想低成本感受一下飞牛的魅力，这台机器绝对是完美的敲门砖。与其花一百多去买那些魔改的电视盒子，不如一步到位上个真x86平台。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelnLbmEMJ6cicBumxBFibbMIwj31Wls8q2liahZmG04Ty7LaI4NyvolkUUDmfw0OfzAClgvoHVkrvOjibh0WMO29oYIXELXCzCJVu0/640?wx_fmt=png)
