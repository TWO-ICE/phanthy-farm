# 车后排没屏幕？150块给你整一套比豪车还豪横的娱乐系统

今天我刷二手鱼的时候，发现有人挂出来一批汽车后排娱乐屏，10.1英寸，带原车支架，已经刷好了安卓系统，2+16内存配置，150块钱包邮非偏远。那些花大几千选装后排电视的豪车车主看到这价格，估计血压能瞬间拉满。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenktlicsh6A4sOzHibgDkjmib9EFoffnRyJC9cms9ribjrEPJ6sfxibE0JRwKbPYMibKWu8rvGibWwUb1ZSZ0YtjcwZZCibMoRLibbC1yRU/640?wx_fmt=png)


10.1英寸，1080P级别，2GB运行内存加16GB存储空间，安卓系统。这个配置放在手机圈确实不够看，老咕噜棒子了。但装在车座上哄孩子、刷抖音、看动画片，完全够用。卖家已经装好了破解版的音视频APP，爱优腾芒的VIP墙直接绕过去了，到手开机就是无限听、无限看。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelH6cDlRXcxQK85rW4Pgb5ZwwSP4j8VgODdYHRSP5ll6CYcZNTqM2lGlhXzWTR648dSjfAqkQPjCfKYlVfoB1JMBnPAWvDFsJI/640?wx_fmt=png)


其实它最大的价值就三个字：免布线。带车载点烟器供电，插上就亮。带原厂支架，往头枕两根金属杆上一扣，拧紧螺丝，不需要拆车内饰，不需要找师傅改装，不需要破线接电，你老婆坐副驾刷剧，孩子坐后排看佩奇，各玩各的，一路清静。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenoZ3OpjkQeO2QIVI6FtjY5UlAa6YRrLKiabD4AlFIKlp6vsyp4XYictppOhsfFes9XqjYW4w9YSHlLzWUvbAxx9odXhUF4WazLc/640?wx_fmt=png)


这东西当年的辉煌是贴在某德国豪华品牌的选装清单里，标价4800元，还得等三个月排产。如今的地位，是躺在二手鱼卖家的纸箱里，150元任挑，库存一千多台。但既然是150块的边角料，坑肯定也有，我今天把话撂这儿，帮你把坑填平再决定冲不冲。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemdJ39zus7Ad4NP0zGjY8qcZicbxap371GnbHfiaNJiaEibb4CQ54Fkiaia4ZoRCxNvTzjQGAVHYrAvd2nicibl7oLjGAI3yBOXWojPAF4/640?wx_fmt=png)


第一，走线是个问题，卖家没细说，但你要自己面对。

点烟器供电听起来简单，可你家点烟器一般在中控台扶手箱附近，电源线要从前排甩到后排，横跨整个车厢地板。如果是自家用车，线就这么明着拉过去，后排乘客腿一伸就踢到，老人上下车容易绊一下。强迫症看了直接血压拉满。我的建议是：如果你动手能力还行，可以买根两三米的扁线，沿着脚垫边缘走暗槽，用理线卡扣固定。如果完全不想折腾，这东西更适合商务车、SUV、或者后排不怎么坐成年人的家庭。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCeklmR0JdPdE3ybVjHLiakdQRKTvb2z1KevtsQ1icdEOUJEZ1FyHSbOj8kkic7oL5DAzmLe2z0c6ic8UaZL8FHpcfklRwBOKC7ibCyI0/640?wx_fmt=png)


第二，2+16是够用，不是好用。

安卓版本卖家没提，盲猜是8.0或者9.0左右。装个抖音、爱奇艺、云视听没问题，别指望它还能同时挂微信、玩游戏、开导航再加直播。这就是个单任务娱乐屏，开机自动播视频，别的功能当赠品。你要是抱着千元平板的使用预期去买，到手肯定骂娘。但如果你清楚这就是个150块的玩具，那它就是真香。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenK4iaozlKluoBw4M97pwFd4CAQcpLvGWOkK5icYuPyRuYNxPIdlNoPhGcFUl6tYTXicXFKsOlUBNRCJ6AnmHehaicdQSrsQibKMUsg/640?wx_fmt=png)


这150块钱，你买到的不只是硬件，是过去几年汽车行业疯狂堆配置留下的遗产。那些豪车选装件，出厂时被捧上天，如今库存清仓，价格腰斩两次，终于落入寻常百姓家。你说它是垃圾接盘侠？我觉得它更像是二手鱼里给预算抠搜又想要体面的人，留的一道窄门。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenmFodjFn9UkaQUd14euPepoDexDb4pBFfsFQeKM637P4z8qLUfMiapzaCG4TcUVr34qBnONbReRa1pEVb0knbcBcwmJHibw3aog/640?wx_fmt=png)
