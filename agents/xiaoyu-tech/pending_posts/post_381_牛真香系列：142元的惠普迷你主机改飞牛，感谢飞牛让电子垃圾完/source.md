# 牛真香系列：142元的惠普迷你主机改飞牛，感谢飞牛让电子垃圾复活

朕没事就爱刷二手鱼，刷得多了总觉得好货都被人捡走了，直到刷到这款惠普Q150迷你主机——142元准系统，看到价格的瞬间眼睛都亮了，这波简直是“瞌睡送枕头——正合我意”。作为常年蹲守二手鱼的捡漏选手，一眼就看出这玩意儿不简单，尤其适合我这种想搞个低成本飞牛NAS的懒人，性价比直接拉满。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGqQGvOhcQAao5FBtsxYicFJFibolZnMb4xS89iaicnRp9iaAsZadoBJdmpSVHEvAbicib6iaz06BKbesWR9A/640?wx_fmt=png)


先说说核心配置，赛扬2955U处理器搭配HD核显，放在2013年刚发布那会儿，这可是移动级处理器里的“潜力股”，当年主打企业和教育市场，紧凑设计+低功耗，妥妥的办公小能手。但放到现在，性能确实不够看，双核双线程1.4GHz，不支持睿频。不过转念一想，142元买个品牌主机，用来刷飞牛NAS专门存照片、挂下载，完全够用，这个价格还要啥自行车？


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGqQGvOhcQAao5FBtsxYicFJvX11w5MHZHZ2uibUOxpEUypWEqk1sVVNRTOicrEf8KxiaEIlzQCJq5a0w/640?wx_fmt=png)


内存和存储部分有点喜忧参半。4G DDR3内存+16G固态，性价还行，可接受范围之内。但缺点也很明显，内存是单卡槽，想升级只能换更大容量的，不能组双通道，有点让人头疼。16G固态更是“小马拉大车”，原装Chrome OS都快占满了，想装其他系统必须换硬盘。好在当年的“高端配置”放到现在，刚好适配飞牛OS的轻量化需求。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGqQGvOhcQAao5FBtsxYicFJ44bibIGaickCVmdZZyNpy25qtIicATLqbj7H4l0FAzmUeCVFwAiatHlUpA/640?wx_fmt=png)


最惊喜的是接口和尺寸设计。125*125*30mm的机身，比巴掌大不了多少，随便塞抽屉、放书架都不占地儿。接口更是丰富到出乎意料：有千兆网口，还带WiFi蓝牙省去额外插模块的麻烦，HDMI+DP双视频输出，4个USB2.0接口加3.5mm音频口，日常连接硬盘、音箱、显示器完全够用。唯一可惜的是USB2.0有点过时，传大文件会慢一些，但作为NAS使用影响不大，毕竟“鱼和熊掌不可兼得”。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGqQGvOhcQAao5FBtsxYicFJWl666g268qb3ITk489AaRjDicrNmibNBevFA900WdJqNNOicyOicjK29mw/640?wx_fmt=png)


电源方面是45W的通用适配器，这款主机当年可是谷歌生态的重要入口，主打高效节能，TDP仅15W，长时间开机当NAS也不心疼电费，比新路由器还省电。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGqQGvOhcQAao5FBtsxYicFJwXprULuhib1awaqo1jwQcZOTE4icdkGveAouR6NONIB8BawF5vsibYKcA/640?wx_fmt=png)


可能有人会问，赛扬2955U的性能这么弱，刷飞牛NAS会不会卡顿？其实完全不用担心，飞牛OS本身就主打轻量化，这款处理器虽然老旧，但应付文件共享、远程下载这些基础功能绰绰有余，即使播放1080P电影也很流畅，入门级NAS需求完全能满足。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGqQGvOhcQAao5FBtsxYicFJjMWc1XBrTrF26U0aK0dcqPwma8pBEO57HGW9IicLtLHPAiaOTUQ575Fg/640?wx_fmt=png)


另外原装Chrome OS在国内用不了，但是支持刷机，现在技术社区已经有成熟的刷机方案，卖家大多也会提前刷好BIOS，到手自己装飞牛OS或者Windows都很简单，跟着教程一步步来，小白也能上手。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGqQGvOhcQAao5FBtsxYicFJC3vvX6ECwM3jaldbEEaPVLs8Vj7nqp5SUWsBSicrBuia1ibnandvIdYDA/640?wx_fmt=png)


142元能捡到这样的品牌迷你主机，真的超出预期。价格挺白菜，优势和缺点都很明显，适合预算有限、喜欢折腾的极客党，或者想低成本尝试NAS的新手。如果你也在二手鱼蹲捡漏，有没有遇到过这种“看似垃圾实则真香”的好物？或者你觉得还有哪些老设备适合刷飞牛？欢迎在评论区分享你的经验～老规矩，看完不买，立省142元。
