# 没人要的宏碁Switch3二合一笔记本，被我218元捡回来当GAL神器

今天在二手鱼刷到了一台宏碁 acer Switch3 平板笔记本电脑，标价218元，还包邮。点开一看，我差点以为自己眼花了——这可不是啥杂牌小作坊的“海鲜特供机”，而是正儿八经的宏碁出品！虽然它停产好几年了，但怎么说也是当年能进大卖场摆在C位的二合一轻薄本。价格挺白菜，配置可接受，这个价格还要啥自行车？


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXE3vwzrmoZ5CNOvBxgqk2IMyAQKaQLqzORtoib2yYTLZnopq4ylicvqcDCKkXqQUltypyibHbwV51gYA/640?wx_fmt=png)


Acer SW312-31-C6RT（也叫Aspire Switch 3）是宏碁2018年1月推出的产品，主打便携办公和触控体验，2021年就悄悄退市了。整机采用可拆卸全尺寸键盘设计，屏幕是一块12英寸IPS触控屏，分辨率1920×1080，支持十点触控，还能用那个165°智慧U型支架自由调节角度——躺床上追剧、地铁上码字都挺顺手。虽说现在看参数不算顶流，但在当年，这种二合一形态+高清触控屏的组合，可是让不少学生党和出差族心动过。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXE3vwzrmoZ5CNOvBxgqk2IMcsd1oyzd7FibIMQ8S5DORicv6oRVaG66mtTicK1pzmlJ5SzEsF00SHPpA/640?wx_fmt=png)


硬件方面，它搭载的是英特尔赛扬双核N3350处理器，基础频率1.1GHz，最高睿频2.4GHz，配上Intel GMA HD核显，内存4GB，存储64GB eMMC。开机就是原装Windows 10系统，不用折腾激活，拿来上网、看视频、处理文档完全没问题。虽然跑不动3A大作，但像《Clannad》《Fate/stay night》这类Galgame，帧数稳得一批。说真的，这配置和体验，真不是那些山寨Win平板能比的——人家好歹是正规军出身，驱动齐全、系统稳定，不像某些“百元神机”连WiFi都连不上。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXE3vwzrmoZ5CNOvBxgqk2IMMI6H4eH0mPjksnVKFv83dD0TwBeF5JSh0uLPqEk8S4F9lPESOX2D4g/640?wx_fmt=png)


接口部分，它配了一个USB Type-C、一个USB 3.0、一个micro HDMI，还有耳机孔和microSD卡槽。扩展性谈不上强，但日常够用。内置4670mAh电池，官方标称续航8小时，实际使用大概能撑5-6小时。重量约1.2kg，加上键盘也不算沉，塞进背包毫无压力。对于经常要临时应急写个PPT、查个资料的人来说，它属于“有总比没有强”的存在。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXE3vwzrmoZ5CNOvBxgqk2IM5jvqj3QfUbhbmYq4GBF4TI0WcFOxjibpHaF94ajdTzQXg6qjHlJgFCA/640?wx_fmt=png)


可能有人会问：“这机器都停产三年多了，现在买回来会不会一堆暗病？”这确实得看成色和卖家。但正因为小众+冷门，反而少被矿老板盯上，多数是个人用户自用淘汰。只要走验货宝、确认无拆无修、电池健康度尚可，218元的风险其实很低。毕竟，它又不是用来挖矿或剪4K视频的。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXE3vwzrmoZ5CNOvBxgqk2IMh8G2JEuFSJ4dRtvWBIvL9WFjgKbYGIuoR8KcU0pc3lpZeqtYqXWqHw/640?wx_fmt=png)


那么能不能当主力机用？老实讲，别指望太高。它适合三类人：一是预算极低的学生党，二是偶尔需要移动办公的打工人，三是——重点来了——Galgame爱好者！这台平板推日系美少女游戏简直一绝：触屏操作方便，屏幕素质尚可，系统原生支持中文，还能装个Steam Link串流主机游戏。有网友甚至说：“这不就是妥妥的GAL神器嘛！”


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXE3vwzrmoZ5CNOvBxgqk2IMnZ9X7UP3JY3sYWiczzsM6oexAjB2yZTxbwPHD8g30rS9UuOib3cvhtaA/640?wx_fmt=png)


当然，缺点也得说清楚：64GB存储太小，装完系统只剩30多GB，建议插张高速TF卡；赛扬处理器多任务一多就卡，别同时开十个Chrome标签；键盘手感一般，打字久了手指会抗议。但它胜在便宜、完整、能跑Windows生态——想装个Office、WPS、甚至轻量级编程环境，都没问题。
