# 450能抄底三星三防平板，懂行的老铁看看值不值？

今天在二手鱼里转悠，看到一个有点意思的平板电脑，型号是三星Galaxy Tab Active3 T577国际版，卖家标价450元。成色98新，屏幕完美，就外壳有点小痕迹。三星在咱们国内的名气虽大不如前，但其技术实力还是不容小觑的，我查了一下，这款平板刚上市的时候大概3000多，现在价格直接腰斩再腰斩，正好适合咱垃圾佬捡漏。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekXTVbqgZoTmH7D6tbqoibQ54S5oTTjjFPKLWHwHG2fquoajqWiaDYNjvyFeDjOpibDQc2GforfMWzvOibx37ugzPWZs2vmxCvZAPE/640?wx_fmt=png&from=appmsg)


配置方面采用的是三星Exynos 9810八核处理器，4GB运行内存，64GB存储空间。这块芯片有四个2.7GHz大核加四个1.7GHz小核。单核性能一度超过骁龙845。当然现在845已经是老古董，但这颗U日常刷剧、上网课还是完全够用的。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenjYaRMgsb5Dt8lT31RVzbJvOm2e9GW4GzRN2ia7aUNjvA5LNmyib2g0gAO7PCteTpkiaJUx9z69y917812uXIa7nNS8NqOAJUP5Y/640?wx_fmt=png&from=appmsg)


屏幕是8寸LCD，1920x1200分辨率，5050毫安电池，官方说是可拆卸设计，甚至支持不装电池直接插电用。这个设计现在看也确实稀罕，大部分平板电池鼓包就只能报废，这玩意儿换个电池又是一条好汉。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenpNmOmeWzXoYHko8GSTOsWPV7kLIOqsXLG3BibQQMgFJDCMHSooAicrwa0OAZohibwgn0qyLq26oKF5ibHicTt3jyGPmmOibvUgDYG4/640?wx_fmt=png&from=appmsg)


另外还支持插SIM卡上网打电话，还能插TF卡扩展1TB。有指纹解锁和面部识别。卖家说是国际版，系统是Android 11。三星当年承诺给三代系统更新，从Android 10升到11再到12或13是没问题的，后续安全补丁就别指望了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemp7sibVZG0iaV39EFJoHfSmNCbnpwiaAStw2heHfjWRdGiatJdppwlQPT9VC963j2C8nKMo0EOqYicG24OWkAVZEIP6QeOThZGSMZE/640?wx_fmt=png&from=appmsg)

我觉得如果只是想找个备用机刷抖音看剧，或者给孩子上网课，或者给老人刷短视频，450块买这个比买同价位杂牌新机强太多了。三星的屏幕素质、做工用料、系统稳定性，不是那些贴牌山寨机能比的。8寸大小刚好，不沉，续航也够用。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemoA6hVVFOR2CiaKzvtpms83peRqURouDoZTavJY7z1TT04ywksX5QQ8atklske1l5IIExdqDJlH2d27Gjex40SdhNkvJvJnc2k/640?wx_fmt=png&from=appmsg)


不过要提醒一句，这玩意儿是2020年的产品，处理器性能摆在那。你要说拿来玩大型游戏，那还是洗洗睡吧。Exynos 9810的GPU是Mali-G72 MP18，跑个王者荣耀没问题，原神就别想了，卡到你怀疑人生。而且卖家说的是国际版，不是国行。国际版的系统更新、本地化服务肯定不如国行，有些国内的软件适配可能会有小问题。但基本功能不受影响。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemYfdmO7x5Ha5dvdriaxOwphBhxjmB9PM03k1om9hXQXvcfotcQdRibtaQ2ibmYITrnJjp8z71kNw0uWFkkMha8HzJOUMVmaRhgIo/640?wx_fmt=png&from=appmsg)


另外还有一个重要信息。这货其实是一款三防平板。具备MIL-STD-810H军规认证，能扛1.5米跌落，IP68级别的防水防尘，扔水里半小时都没事。还有手套模式，戴着厚手套照样能触控。自带的S Pen手写笔也是防水的。这些特性在这个价位段的二手平板里，几乎找不到第二台。不过卖家没说带笔，估计是单机出货，想要笔得自己另外淘。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekyIMPibloceEn6uqyfhdBX5GSy6yZLia1JyzATb8zhpdcFtMekQl0l1vQSBtkn3FXmHGQ2kJQPCl5cIcaibb2gAst2CpIQwKbZCc/640?wx_fmt=png&from=appmsg)


整体来看，450块能买到一台当年3500多块的三防平板，98新成色，屏幕完美，该有的功能都在，我觉得是二手鱼里一个比较值得考虑的选择。当然前提是你对性能要求不高，只是把它当个娱乐备用机或者户外工具板。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemDfb6sclvbiaWoiclYyYNYIEyqrMMOfibdSc36y1BIVrLdo562jh4INpMf2tITqnuZZPsVJCWhuP9krLLTMr8BXdHCslTFxWJ12A/640?wx_fmt=png&from=appmsg)
