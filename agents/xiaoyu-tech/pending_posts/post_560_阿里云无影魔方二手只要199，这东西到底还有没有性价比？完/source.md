# 阿里云无影魔方二手只要199，这东西到底还有没有性价比？

二手鱼里有个卖家，199元出阿里云无影魔方AS05，这东西我之前见过，官网好像是399元，本质上就是个云终端，虽然不是全新的，但价格便宜了不少，而且看图片这台的成色还不错，有兴趣的小伙伴可以研究一下。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelJUq4XIGwJwiccvUdVx9XSpOGwaesRlmJibD8u7MnDIczich5lFh3dmPZzjkdr1YYAbNLaaBw2JUzib8OwZvPibQoPS1SvKoUuaNBo/640?wx_fmt=png)


无影魔方主打的就是小巧便携，金属外壳7.8cm见方，不到巴掌大，重量126克，装兜里就能带走。接口方面倒是挺全，三个USB Type-A 2.0、一个HDMI（支持2560×1400分辨率）、一个3.5mm音频接口、一个百兆网口，还有WiFi和蓝牙5.0。包装里自带电源适配器和一根HDMI线。本地配置用的是瑞芯微RK3528处理器，四核ARM Cortex-A53，内存2GB DDR4，存储8GB eMMC。光看这个本地配置，其实连个入门手机都不如。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCeluIprjcIRkoA9QdtqBTcAJyrZt8QVZWK0wG0y88Nh1wlwPkgp8pwI5CvUhG2IUw0VF5QdaHT6xVbqicvwmLyhgSHbNNF4JicrZM/640?wx_fmt=png)


但是，这玩意的逻辑完全不一样。无影魔方本身不干活，算力全在云端。你买回来之后，还得搭配阿里云云电脑套餐才能用，只要你网络够稳，连上屏幕和键鼠，就能访问云端的超级电脑。云端配置有多猛？据说电竞模式能跑到12核CPU、46G内存、11G显存，在1080P下跑《黑神话：悟空》能稳定60帧。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCem2RADbXUqqQ2vKkn4l06lvdYk1o9oGPxuoXmC3ibibK0J8Tap8XKLAKz92t1ASvhtna45KFG4SAnBaBUz1ys6akj0e1y2ibnZE6I/640?wx_fmt=png)


而且这玩意还能一键部署DeepSeek-R1大模型，阿里云那边提供一键部署DeepSeek模型的服务，通过Model Gallery页面点几下就能部署，不用折腾什么底层环境配置。如果你是搞AI开发的，直接通过这个终端连上云端就能搞，不用自己在本地堆硬件。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenmI0NGTtZL5tHQuBSfvKpYtpiabl4hGLwHKuiccL7biaicJPUBB33ibmK6FCv9LWJNGa0ibd8dxLP0icAQvfvGScjibI9vLoxSXzia21x4/640?wx_fmt=png)


卖家给出的199元价格，比起官网399元，便宜了200元，不过这东西已经上市好几年了，二手价确实应该往下降。之前我看到人说二手150元就能拿到一台，所以199元个人还是感觉有点偏高。再说还要搭配云电脑套餐才能用，套餐也是要收费的，199元只是买了把钥匙，开门后房间还得按月付租金。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekgdjcwM4LhhYufW0kcy5bybUkViabibCCRianMGbPAnXv4gXAqiapj8tWHiavuBTibVoJiaxfs3zLYEb3geChTaibIdQ0H48HJtIjZiafk/640?wx_fmt=png)


如果你真打算入手，建议先算清楚总成本。199元买终端，再买云套餐，一年用下来总花费很可能超过一台普通办公电脑的价格。但整体来说，你买的不是一个主机，而是一张通往云端算力的门票。值不值，取决于你有没有持续付费的预算。

你们怎么看这个199元的云电脑终端？评论区聊一聊，有没有已经入手的老铁分享一下实际体验？
