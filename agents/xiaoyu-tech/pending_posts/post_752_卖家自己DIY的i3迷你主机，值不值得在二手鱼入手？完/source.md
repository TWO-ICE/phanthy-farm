# 卖家自己DIY的i3迷你主机，值不值得在二手鱼入手？

现在这种小主机很吃香，尤其是一些体积小巧、功耗低、接口齐全的机型，放在家里当HTPC、轻办公机甚至软路由都挺合适。最近我在二手鱼刷到一台标价280元自己DIY的迷你小主机，卖家强调颜值高、打小游戏、办公、看电视都没问题。这类机器通常来自淘汰的商用整机或个人拆机重组，出现在二手平台也不奇怪，毕竟很多人折腾完就转手，留下一堆性价比残骸。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEYR4GuAkbn0rXjt80NqrRVf9ZxEAgia0Wjxd0EZXukLOhgkBsTqfVBRGibtwDFYFoClC9Cn4j0z0tQ/640?wx_fmt=png)


这台主机配置是i3-4330T，双核四线程，TDP只有35W。搭配的是H81/B85/Q87那一代的商用板型，稳定性不错但扩展性一般。内存8GB DDR3，对Win7或轻量Linux完全够用。硬盘是朗科120GB的固态，已使用1459小时，折算下来差不多半年多一点，寿命尚可。核显是HD 4600，支持4K硬解，日常影音没问题。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEYR4GuAkbn0rXjt80NqrRVEiaIiba02WGbA8UJrhGaAT2rxHLBXTWARX8OibOicJTecicibnVZ799Qp0Rw/640?wx_fmt=png)


从用途来看，这台机器确实能胜任轻办公、网页浏览、1080P视频播放甚至一些老游戏。如果你打算刷飞牛OS做家庭NAS兼下载机，它也勉强够格，毕竟x86架构兼容性好，只是硬盘位只有一个，没法组阵列。不过要跑Docker或者本地大模型就算了，i3-4330T的性能早已落伍，多任务一多就卡顿。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEYR4GuAkbn0rXjt80NqrRVExxPmoTeROVI8Kmbc4jiaVv7WI8rBnchm4WSaCmbsFicYoffEjzohOTw/640?wx_fmt=png)


可能有人会问80元买这配置是不是智商税？其实不算离谱。目前二手DDR3内存条价格涨了不少，单条4GB都要七八十，8GB成色好的得一百出头。加上一块还能用的120G固态，光这两样成本就快200了。CPU虽然是洋垃圾，但i3-4330T本身功耗低、发热小，在迷你机箱里散热压力不大。整机280元，如果成色如描述，价格还算合理。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEYR4GuAkbn0rXjt80NqrRVfdYWWIicnpiaaLBPH2sQSfHTibG3nPBJIqloj2OXkhXIEkME56Bib5leHw/640?wx_fmt=png)


那么能不能再等等更便宜的？要看你急不急。现在存储涨价，很多老平台整机反而水涨船高。这台机器最大的短板是只有一块小容量SSD，后续升级空间有限。而且Win7系统老旧，安全更新已停，建议重装Win10 或轻量Linux。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEYR4GuAkbn0rXjt80NqrRVdP685RndbNUic81nyuWoUlZEmFde72vONcLOyibS6jibU0LMJaIVOwibEA/640?wx_fmt=png)


对此产品有兴趣的话，可以在二手鱼搜索“自己DIY的迷你小主机”这个关键字就可以找到此产品，如果找不到可以通过图片进行搜索，都搜索不到的话，那可能是此产品已卖出或者是下架了。


 


以下是个人一些掺了水的建议：  

1. 办公影音需求低，可以考虑入手。  

2. 想跑虚拟机或多开服务，别碰。  

3. 务必确认卖家是否提供通电视频。  

4. 看完不买，立省280元。
