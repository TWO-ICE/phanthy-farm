# 有人说惠普T430是天生的飞牛圣体，那么你愿意掏128买它吗？

![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemQeZT1BqibfBbQEZMQXcGh7D0mIpdqkGs8je4Waj20Xl6KOFzOxkuFqdqjNHCtCDQuRExkUpB4LMUvN4YLN7cFa69TBU8Pibhbw/640?wx_fmt=png)


最近二手鱼里有个惠普的飞牛圣体小主机特别的火，型号是惠普T430，产品的浏览量干到12万，两千八百多人点了想要。这热度都快赶上某些新款手机了。要价128元起，那么这价格到底是在捡漏还是交智商税？今天咱们就来盘一盘这个所谓的飞牛圣体。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCek6vxrf85VebNBicIc4V3b07v970VO6naax6fmxRKUpQgS7RK8pwO7HGu7faibF6FRsN48ZpH6nEgeiaW5Khzq2oonBTicZnL442c4/640?wx_fmt=png)


卖家是个7级店铺，所以信誉度要比一些个人卖家靠谱的多，产品描述写的非常详细，也非常多，这里我就提取主要几点和大家分享一下，这机器卖家给分了好几个档，基础款128元，就是个裸机，成色差点，可能还有磕碰，没脚垫。但话说回来，买这个的人，谁在乎那点外观？要的就是里面的芯。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekrqv1wwgUgzTNP4C4dqEKHL1Pz2ummViaCy65TEOiaw8P0yqiazKgz6diamiccMtc340NIB9vDQbZlEh0Qc8HXKvvGbSd2ACqRhgKc/640?wx_fmt=png)


它用的是Intel赛扬 N4000处理器，功耗低，播放视频时才4W不到。最关键的是它能硬解4K，除了av1编码，主流格式通吃。这点比它大哥t530都强，t530反而做不到。接口也给得挺全，HDMI、DP、千兆网口、还有支持一线通的Type-C，一根线连便携屏就能当个小电脑用。对于垃圾佬来说，可玩性直接拉满。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemHnduNKxxox6SOkXC3cpgSeDARHDYHHc9ibdgsJXicp4zNPoCc3K9QwBF6fJWWKHNEnLkU0JBIIBzyPFRGkLWiaqx5dQJMp0a898/640?wx_fmt=png)


当然，重头戏还是刷系统。卖家也门儿清，直接打出了飞牛圣体的旗号。最新版的飞牛1.18在这小盒子上跑得贼流畅。你想存个家庭照片、挂个下载机、甚至搞个影音服务器，它都能轻松胜任。除了飞牛，它还能装达菲做音乐播放器，或者刷个精简版Win10当个轻办公或者看监控的主机。一个128元的小东西，集NAS、播放器、下载机于一身，还要啥自行车？


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekibyQhAdZ6pU5noOI4kstiayywAolEn8eVqWJoN5zEzCjFuQrVibHbxwHQCfWXKdcU7qIU6AAKOBtw6HicLrFxyjeGtR2Micly1oJc/640?wx_fmt=png)


不过咱也得说点大实话。这个价格，注定是要折腾的。首先，成色随缘，卖家也说了，128元的可能没脚垫，外壳有裂痕。其次，内存2GB，硬盘16GB，这配置跑飞牛刚好，想干点别的就得加钱。比如买个转接卡，再配个2230或2240规格的NVMe固态。套餐六加了128G东芝固态要235元，价格虽然还是香，但已经没了那种闭眼入的冲动。另外，它用的是N4000，性能也就那样，别指望它能跑虚拟机或多任务处理。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemiaY02IXczAzhz913aDK6Cj82tRWnV5dB0KPVHPXb0t2icGd1HXquwfe2Udkur7CAfOZDEEo8FKsZsLBFoeJTxXVMyBDOp8EfRA/640?wx_fmt=png)


如果你是纯小白，连系统都不会装，那可以找卖家帮忙。粉丝刷飞牛免费指导，还帮开上电自启，实在懒得动手，加10块钱让卖家给你预装好。这点对新手还是挺友好的。但如果我下单，我可能会选那个158元成色一般的套餐，加上自己手头吃灰的旧硬盘，这才是垃圾佬的正确姿势。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemEB2Tvc1yMV60Ze8Iqr2jXBzICfoD9RibzlhDNviasAicTwlkqf2QTJwFDoDuAkEMTx2bQCmhfIneBZNFuFGWMlzkicpXbgictb25g/640?wx_fmt=png)


另外我还刷到个好东西，二手鱼里有个老铁专门为T430做了一个4盘位纯固态nas机箱，黑白相间的配色还不错，是用3D打印出来的，所以无法避免会有一些层纹和瑕疵，介意的直接划走。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCel7kPn4ibQgzNmBBO1tSnHvTtxDdgveNaWwHpGA1TNTw35xibHC2VLpxobvgJGzaGdtN1zjBCbVeePmr8z4rNWFicn8lpJ8liaD74Y/640?wx_fmt=png)


里面大概就是介个样子，支持4盘位2.5寸纯固态，内部usb供电。也支持4盘位2.5寸机械盘，需额外供电。一个内部usb口可供电一块机械2.5寸盘，或者2块2.5寸固态盘，完美的解决了主机太小没有硬盘位的问题。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemmy8VNhMI29k97mWw7NR5wBRTWy2I8YKzzyzw4icQOPEsYbg3KCwfKwre650TGicUsZLhEMpCicnSSjsjSZzrhYjdicuDX7tIhYDs/640?wx_fmt=png)


最后给想入手的提个醒。这玩意儿是曾经的商用机，稳定性和做工没得说，但别把它当成主力电脑。它的定位就是个玩具，一个让你低成本体验飞牛、折腾达菲、甚至跑跑HomeAssistant的玩具。128元买不了吃亏，但能买到一份折腾的快乐和无限的DIY可能。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekNuES6KhPd2mibwrJUCRvdxvMicICiaZqzmmnEch7VnficYpia3ibicDJIvviafs72h4BOehnFJxJkva8RNK7vhbAuxXiceR5YicSdtE8g4/640?wx_fmt=png)


那么问题来了，面对这个128元起的小铁盒，你会选择哪个套餐？是极限捡漏裸机，还是一步到位加满配置？评论区聊聊你的想法。
