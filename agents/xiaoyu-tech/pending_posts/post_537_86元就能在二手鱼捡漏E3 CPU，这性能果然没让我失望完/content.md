# 86元就能在二手鱼捡漏E3 CPU，这性能果然没让我失望

作为一个常年混迹于各大二手交易平台、且有严重“电子垃圾”收藏癖的数码爱好者，朕的日常大概就是：别人刷妹子图，朕刷电子垃圾；别人种草最新款4090，朕在海鲜市场里甚至能盯着一张十年前的南桥发呆半天。

就在今儿个，朕照例在“二手鱼”上像扫雷一样漫无目的地闲逛，突然被一个挂在角落里的邪门玩意儿给吸引了——一颗标价86元的Intel Xeon E3-1231 v3处理器。

86块是什么概念？大概也就一线城市两顿像样的外卖钱，或者是半包稍微好点的烟钱。但这价格还不是最离谱的，最离谱的是围观数据：居然有6万多双眼睛盯着它，4000多号人蹲在角落里拿号排队等“捡漏”。一颗比乾隆年间还要古老的服务器洋垃圾U，凭什么在2024年还能让人如此上头？今天咱们就撕开这层怀旧滤镜，好好扒一扒这颗传说中的神U，看看它到底还能不能打，还是真的只能拿来盖泡面。

说起这颗E3-1231 v3，那得先把时光倒流回2014年。那年头，Haswell架构横行江湖，而“E3配B85，从此这波我不亏”这句顺口溜，几乎成了所有DIY装机佬的圣经。这颗U当年为什么被称为“性价比之光”？因为它精准地卡位了Intel恶心人的产品线缝隙。

那时候你想买i7-4770？好家伙，价格两千多，贵得离谱。但这颗E3-1231 v3，它本质上就是一颗“无核显版”的i7-4770。同样的4核8线程，同样不输给前辈的3.4GHz基础频率，甚至能睿频到3.8GHz，甚至还极其良心地塞进了8MB的三级缓存。这参数放当年，那就是妥妥的旗舰规格。

为什么它能在那个年代封神？核心逻辑在于“没有核显”。对于玩游戏的人来说，核显就是个食之无味弃之可惜的鸡肋，反正要配独显。Intel把这颗U的核显阉割后，不仅降低了功耗和发热，价格直接下探到i5的水平，却给了i7的性能。这种“精准阉割”带来的性价比，让当年无数预算有限的学生党和网吧老板为之疯狂。

不过现在毕竟是2024年了，这颗曾经的“神U”变成了如今的“老兵”。咱们来仔细盘一盘它的核心家底，看看这86块钱到底花在哪儿了。

首先是那个3.4GHz的基础频率，单核睿频能蹦到3.8GHz。说实话，在现在这个动不动就5.0GHz、6.0GHz的年代，这个频率看着有点像老太太裹脚布——又臭又长。但是，大家别忽略了一个核心指标：多线程。4核8线程的规格，放在今天应付日常的办公软件、挂机下载、甚至修图剪辑，依然是妥妥的“流畅线”。你别说，还真就那么回事儿，单核跑分虽然被现在的12代、13代甚至i3甩得看不见尾，但在多开程序的时候，那8个框框依然能给你一种莫名的安全感。

想玩这颗U，你得先搞定它的“食宿”问题。它用的是LGA 1150接口，这意味着你得去二手市场淘那些几乎绝迹的H81、B85或者是H97主板。这里面的学问就大了：H81虽然是丐版，但供电一般，带这颗U虽然勉强能行，但温度容易压不住；B85是当年的销量之王，ATX大板，供电稳，扩展性尚可，是目前最稳妥的选择；H97作为1150的绝唱，支持一些黑科技，但价格往往会被炒高。

内存方面，只认DDR3。这对咱们来说反而是个好事，因为现在DDR3内存简直就是白菜价，这年头谁手里还没几根淘汰下来的DDR3条子？组个16G双通道，成本可能也就几十块钱。而且Haswell架构对内存频率并不敏感，哪怕是普通的1600MHz频率条子，性能瓶颈也不在内存上。

至于供电和散热，E3-1231 v3的TDP（热设计功耗）官方标称是80W。实测下来，满载功耗其实也就六七十瓦左右。这种级别的热量，随便找个几十块的下压式散热器，甚至是几十块钱的塔式风冷，都能把它压得服服帖帖，甚至可以说是“冻得瑟瑟发抖”。对于预算极其有限，又想体验一下多线程快感的朋友，这86块钱的CPU加上几十块的散热器，就能获得当年的“旗舰”体验，这还要啥自行车？

当然了，朕在这里必须得泼一盆冷水，防止大家脑子一热就无脑冲。这E3-1231 v3虽然是神U，但它绝对不是完美的，甚至可以说坑点不少。

第一个大坑，就是它的“无核显”属性。这既是当年的优点，也是现在的缺点。现在的CPU哪怕是赛扬都有核显，能点亮屏幕就算完成任务。但这颗E3，你必须给它配一张“亮机卡”。哪怕你只拿来办公，你也得插一张GT 710、GT 630甚至是更古董的GT 210。如果还要专门去买显卡，那所谓的“86元神机”成本瞬间就得往上涨一两百。如果你手头正好有闲置的显卡还好，要是没有，这光是为了点亮屏幕就得折腾一番。

第二个大坑，就是平台太老了。1150平台的主板，PCIe标准还是2.0和3.0混用时期（大部分主板PCIe 2.0）。如果你想插现在的NVMe M.2固态硬盘，抱歉，原生是不支持的。除非你买那种带M.2接口的妖板，或者用PCIe转M.2的转接卡，而且还得看主板BIOS支不支持NVMe启动。要是只能用做从盘，那SATA接口的固态硬盘依然是目前最省心的选择。这就导致了一个尴尬的局面：CPU还能战，但硬盘接口、USB速度（很多B85只有USB 3.0，甚至前置还是2.0）都成了巨大的木桶短板。

说白了，这是一套属于“老家伙”的组合理念。除了怀旧或者预算真的压缩到极限的朋友，或者是想给家里的老打印机、老扫描仪配个主机的场景，否则强行上这套平台，体验上的割裂感会非常强。

可能很多年轻的伙计会问：“这老古董还能不能玩现在的吃鸡（PUBG）？能不能打瓦罗兰特（Valorant）？”

朕特意去翻阅了各大论坛和视频平台的老平台实测数据，结论其实挺有意思的。

E3-1231 v3这颗U，它的单核性能其实和现在的i3-8100或者i3-9100F大概在同一个水平线上，甚至某些指令集上还不如9代。但它的优势在于4核8线程。在《CS:GO》或者《英雄联盟》这种对多线程优化逐渐变好、或者主要吃显卡优化的游戏里，只要显卡不是太拉胯（比如配上GTX 1060、GTX 970甚至现在的RX 6500XT），在1080p分辨率下，中低特效跑个100帧上下依然是可玩的。

但是，千万别拿它去挑战最新的3A大作。什么《赛博朋克2077》、《黑神话：悟空》你就别想了。这颗U要么是显卡带不动，要么是CPU瓶颈爆炸，帧数可能连 playable 的标准都达不到。它适合的场景非常明确：腾讯全家桶、Steam上的经典老网游、或者是作为一台NAS主机、软路由、家用下载机。

既然这U缺点一大堆，性能也谈不上神级，那为什么现在的二手市场上，还有那么多人蹲着它？

朕仔细研究了一下社区里那4000多人的“蹲守”心理，大概总结出了这么三类人群：

第一类是“极限升级党”。很多人的老电脑可能是i3-4160或者i5-4590，主板还是B85，内存还是DDR3。如果换平台，那就是主板、CPU、内存全套换，成本得好几千。而这颗E3-1231 v3，直接插上去就能用，开机点亮，性能直接翻倍（相对i3而言），这是成本最低的“再战五年”方案。

第二类是“工作室/多开党”。需要挂机、挂机宝、多开游戏窗口、跑虚拟机。这种应用场景，对单核要求不高，但对线程数有要求，而且对稳定性要求极高。服务器出身（E3本来就是服务器CPU）的它，简直是为此而生，7x24小时不关机都很稳。

第三类，纯粹就是“垃圾佬”的情怀。这颗U承载了太多人的青春记忆，当年买不起，现在白菜价了买回来玩玩，图的就是个乐呵。

不过大家得明白一个道理：性价比是跟价格强相关的。如果这颗U被炒到150甚至200以上，那直接Say Goodbye就行了，因为同价位的i3-9100F或者二手AMD R5 5500甚至3600，在搭配全新主板、DDR4内存的综合体验上，绝对吊打这套古董组合。

说了这么多，水了这么多字，不知道屏幕前有没有当年玩过或者现在手里正好还在用这颗传奇E3-1231 v3的朋友？你们当年是原价入的“洋垃圾”，还是二手回收站里淘来的？

咱们做一个大胆的假设：如果你老婆现在大发慈悲，给你批了8000块的装机预算，你是会毫不犹豫冲最新的RTX 40系+i7/i9组合，还是会偷偷留出800块，在角落里默默组装一台E3 B85的复古机放在床头缅怀青春？

评论区里，咱们聊聊呗。毕竟，老规矩：看完不买，立省86元，又是一个亿的循环！
