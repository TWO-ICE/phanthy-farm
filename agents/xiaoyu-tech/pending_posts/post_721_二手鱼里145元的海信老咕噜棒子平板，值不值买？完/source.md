# 二手鱼里145元的海信老咕噜棒子平板，值不值买？

![封面图](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXFOZrM3QSwjZTb2r626TIIU6fV6V0OfsID2T2SdwQR0YXwrf5CdFrakhUMU3xhxeicSxSTUZyHibJTQ/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/IQVKwEjLWka49S73y_NoDg

你是不是也常在二手鱼上刷到那种“白菜价”数码产品，心动却不敢下手？我最近就刷到了一款145元包邮海信E22平板，它到底值不值得捡漏？作为一个混迹数码圈多年的博主，我今天就用最真实的角度，和你扒一扒它的底细。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFOZrM3QSwjZTb2r626TIIUUfIwcdvIBW2GV1BpLF2QbFicGiaH2fxhme8F3cEevytaibOg8vLoF3bLw/640?wx_fmt=png)


先从价格说起吧。145元能买个10英寸平板确实不贵。在存储芯片价格一路飙升的当下，新平板动不动就标价上千，而这款海信E22却像是一股清流，跌至冰点。为什么这么便宜？无非就是工厂淘汰库存、洋垃圾流入，还有品牌边缘化后的清仓。海信在平板领域本就不是主角，这款2020年出厂的E22，更像是当年试水市场的产物，如今残值所剩无几，反而成了预算党眼中的香饽饽。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFOZrM3QSwjZTb2r626TIIUguGTJYSHdb0dH1gTRjFSJ0E5MzVrpcRz0pFsM6YZAtKFdJG3UYm5Jg/640?wx_fmt=png)


但光便宜没用，咱们得看实用性。它配置是3G运行内存加32G存储，安卓10系统，电池5050mAh，屏幕分辨率1200乘1920。这些参数肯定不算亮眼，但对应145元的价格，它能不能用？能用，但有条件。如果只看剧追番，或者上网课、播广场舞视频，它完全可以胜任。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFOZrM3QSwjZTb2r626TIIUKfFOoP7ZODG68JhUpA2laEBR3paBGOxZdgIicib3Z0VURtyAeHsVJSYg/640?wx_fmt=png)


不过，千万别指望它有多强性能。安卓10系统已经老旧，很多新App兼容性差，3G内存在多任务时根本撑不住，存点照片视频就提示空间不足。也就能干点轻活，但重担挑不起。而且二手来源不明，电池老化、屏幕暗斑这些隐藏风险得留心，海信售后点少，真出问题修起来可能比机器还贵。从性价比角度看，它适合追求极致低价的人，但如果你对数码体验有要求，那加点钱买新款才是明智之举。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFOZrM3QSwjZTb2r626TIIUPGvoAibbYiaktQUtuK7OpuyCL5UNqqxpnbqNaPT3XrajdWMFNBlAZAAw/640?wx_fmt=png)


海信在家电领域名声不错，但平板一直是其软肋，行业里很少听到它的动静。反观其他品牌，苹果、华为平板价格坚挺，存储涨价潮中更是高歌猛进，这让E22这类二手设备显得格外另类。洋垃圾流入和工厂淘汰模式，其实给了我们捡漏机会，但也提醒我们：便宜未必没好货，但好货一定得验清楚。从残值入手，这平板已经便宜到底，再贬值空间不大，可当作消耗品用，用一年半载也回本了。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXFOZrM3QSwjZTb2r626TIIUBAibnSsciaxOdnCUjt1OWribT38ia7UOBrCLXGAsCstNv3I3Lv1ydHmDcw/640?wx_fmt=jpeg)


如果你是需要临时备机的学生、想给长辈添个简单娱乐工具的家庭，或者数码玩家想折腾个低价玩具，它可以试试。但如果是主力学习、工作，或者追求流畅体验，那还是绕道吧。数码产品毕竟一分钱一分货，省钱的同时，也得接受它的局限。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXFOZrM3QSwjZTb2r626TIIUgHIticyrjkOpNV6ZLiafbTrZTEEFdtlVPIia87AY6g2vT3gm0gmdavK2Q/640?wx_fmt=jpeg)
