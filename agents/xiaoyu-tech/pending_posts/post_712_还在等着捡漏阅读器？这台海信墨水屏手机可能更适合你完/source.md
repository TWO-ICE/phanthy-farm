# 还在等着捡漏阅读器？这台海信墨水屏手机可能更适合你

翻到了一个店家，在卖海信A5墨水屏手机，这东西当初火过一阵子，妄想用墨水屏手机实现颠覆性的阅读体验。如今已经有了答案。没颠覆谁，自己倒先被市场颠覆了。不过在二手鱼里，价格却依然坚挺，628元到698元共两种配置，比当初便宜了差不多一半的价格。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCen1dRLFXzG2RHBBv1Y1wQibjpJVeLTQZYGQE8ibMXWXibTlEEOorEDymFSVmic57E16y0ibn8GIDv1UBgUYVV68F7IJfT3IRSmFI5L0/640?wx_fmt=png)


这机器用的骁龙439，搁现在看确实有点拉胯，低配版4+32G千元机都打不过。但这个手机不按套路出牌，买这玩意儿的人，谁是为了打游戏？正经人谁拿墨水屏刷抖音啊？这台机器的正确用法是能打电话的电子书。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekarNgoL3RLdeMLFxbdyE6HMAuGjmfgibGtwMzsSVsHWN22ibaUUPv4czuWLZBaqCecqfxgbIT5DOTtSuibZiaRVK2VMBqJy4eafc0/640?wx_fmt=png)


那更纠结的问题来了，同样的钱，是买它还是买个纯墨水屏阅读器，比如二手Kindle Paperwhite 3或者入门级掌阅？


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCeneP1bB8umuGsNAOtRDxhMQUboJl2dqzC9SWvfoCLYmttsE2ghWpkM4p4f8GUVmJS2JcCM0ca1AUc8d6mgr4CYSQRpc8ibcUOWA/640?wx_fmt=png)


我帮大家分析一下，如果你想要的是纯粹，那就选Kindle。它的屏幕底色更白，字迹更锐利，续航是按周算的，拿在手里就想安静看书，不会有刷朋友圈的冲动。而且二手KP3也就400以内，比A5还便宜。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekOfQsMRe8lnOgcArgydicLay3n8sodA2xklhxMSWBW0dUibREW36q983GMZnibpUqNfO3VsyQhckiabQFCoefsjFibPaXsOQ0hd3BQ/640?wx_fmt=png)


但如果你是像我这样，想培养阅读习惯又离不开微信，或者经常在地铁公交上想看点东西，偶尔还要听个歌。那海信A5就更对味。它的HiFi芯片插上耳机，底噪干净，推力比现在很多蓝牙耳机强。出门揣一个口袋，就相当于带齐了“手机+Kindle+MP3”。它不是一个完美的阅读器，但它是目前最方便的“随身阅读解决方案”。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenAD9r9SpUgAlojtIP74gUZ30B9SJS2A48v6OFrtiaN3cwjfiapfBVxOKmUEcpuyFohgUXj34ia5hciaa3m5mrL7GShtrDp9Mqdl9k/640?wx_fmt=png)


最后给想入手的提两个醒。第一，别指望它能当主力机，它就是你的“戒网瘾”备用机，专注阅读和轻应用。第二，到手一定检查屏幕，墨水屏物理损伤看着特明显，还没法修。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemmecWChFdwTd5yTGIkKSgeYM6QEpVOO796BtDiawlJqAx9WbPbWs3Y0BkH55rEL7BCqxkW4kEU1F0gOX5agzospp4wpqqU604g/640?wx_fmt=png)


你们觉得现在628元买海信A5，是真香还是接盘？用过墨水屏手机或者Kindle的朋友，来评论区聊聊你的真实体验，给后来人指条明路！
