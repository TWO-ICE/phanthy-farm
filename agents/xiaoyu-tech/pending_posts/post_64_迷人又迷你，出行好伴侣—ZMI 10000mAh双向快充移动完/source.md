# 迷人又迷你，出行好伴侣—ZMI 10000mAh双向快充移动电源MINI

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/afNLf2a8eXFlZH5kFItHuhOlAAVYwk10aGMrnrQeE2HFzS0r2beRGrYBYxGVYMGIkqSGSpTATNEEUH0NP2JZnQ/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/hgtZ242tX8KGDxMrTEn5fA

大家好，我是小鱼评测，今天评测的产品是来自ZMI紫米品牌的一款10000mAh双向快充移动电源MINI，型号为QB817。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXFlZH5kFItHuhOlAAVYwk10GGcqqBxicusymk61lcvkDicW2kpMnov8Tic1MQKBGS4IqoaDIbOfFEI5g/640?wx_fmt=jpeg)


提起移动电源，对于我们来说是再熟悉不过了，随着行业的发展，移动电源也早已步入了20000mAh或是30000mAh的阶段，大容量的移动电源用起来固然很爽，但容量越大，体积和重量也就越大，外出携带必然会增加不少的负重感。而ZIM此次推出的这款10000mAh双向快充移动电源MINI，就是专门为便携而打造，除了拥有娇小的身材之外，还有着超高的颜值，那么实际的体验如何呢？还是一起来看一下吧。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXFlZH5kFItHuhOlAAVYwk102lbibGMLMH4CeCrqDG0gYZqUF9M8I6eTSY1WUqdE0p5VX9zhvH9hqSA/640?wx_fmt=jpeg)


可能有些伙伴对ZMI紫米这个品牌还不是很了解，但对于米粉们来说是再熟悉不过了，它是小米生态链最早期的投资企业之一，主要经营各种与充电相关的产品，其中移动电源就是其核心产品之一，几乎每推出一款移动电源都会获得大量用户的青睐，所以在品牌信誉度和产品质量方面，ZMI还是很值得信赖的。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXFlZH5kFItHuhOlAAVYwk10ku7jfpUfZ83f3qDibMaPhAv8hEBbSCMfm0k7cFvC7GSLDPV0XNrpzgA/640?wx_fmt=jpeg)


在包装方面，ZMI
 
一贯延续着简约精致的路线，上粉下蓝的渐变色彩搭配，看上去很有美感，低调的外包装虽然没有任何的花哨元素，但在细节上却下了不少的功夫，正面的白色方框看上去好像没什么特别，但仔细看可以看到方框内有着很多的网格纹路，而且这些纹路都有着真实的触感，摸上去犹如触摸到了真实的移动电源，如此的设计不仅新奇而且也很有内涵。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXFlZH5kFItHuhOlAAVYwk10b6CvczyZkCyIduxWKcaMzkb70eGFk4au5RurpoRwS1nGsQUdgEwDlQ/640?wx_fmt=jpeg)


包装内的配件十分简单，除了移动电源之外，只有一条TYPE-C充电线和一份使用说明，比较贴心的是，移动电源的外面还套有一层防静电的薄膜，既起到了防护作用，又提升了产品的档次。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXFlZH5kFItHuhOlAAVYwk10iaHfbfjuSRp1l1NeYiaeQcEEdjvpxEOUTZ9K6BNOO0iaQ7Lp9sGSPI9bg/640?wx_fmt=jpeg)


从产品的名称就可以得知，这是一款MINI版的移动电源，相比市面上普通的10000mAh移动电源，这款ZMI移动电源的身材则要娇小的多，长宽高仅有90*63.9*24.4mm，即使是女士的小手，也可以做到一手掌握，而这样一款袖珍版的移动电源，很适合随身携带，无论是放在包包内，还是口袋中，都非常的轻松。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXFlZH5kFItHuhOlAAVYwk10a3lyJHY00J6MBuBCLqDQP4hqB5cDmFQ0kichAP5qqicBN1P5eRdqbUSg/640?wx_fmt=jpeg)


至于这款移动电源的外观设计，ZMI也很别出心裁，首先在配色方面，选用了渐变的配色方案，粉与蓝的搭配赋予了移动电源不错的美感，这种淡淡的色系很符合女士们的审美观，官方把这种配色方案命名为沙滩粉，还真是特别的贴切。除此之外，这款移动电源还拥有经典白、深林绿和远峰蓝另外三种不同的配色，适合不同的使用人群。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXFlZH5kFItHuhOlAAVYwk10o8Nj5uBC0yDawgsnjvCbnnlpJrlsl3rpIuD6dxtNiaNoP5SMFTLahww/640?wx_fmt=jpeg)


移动电源的全身都布满了网格式的纹理，和外包装上隐藏的纹理完全相同，但摸在移动电源身上，会明显的感觉这些纹理很有层次感，最重要的是，这种网格式的纹理有着非常不错的防滑效果。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXFlZH5kFItHuhOlAAVYwk10RibickwLDrdlcAXbV3gWnGOTuQEoq4AEicKslKWZ0QZ1RDygvfdTRBAEQ/640?wx_fmt=jpeg)


底部则是这款移动电源的各种参数信息，10000mAh的容量也标示的非常清楚，由于支持双向快充和适配多种快充协议，移动电源的每个接口都有着多种不同的电流和电压，其中输入接口中USB-C的参数为5V/3A和9V/2.5A，Micro-USB的参数为5V/2A和9V/2A，输出的接口中多口的参数为5V/3A，USB-A的参数为5V/2.4A、9V/2.5A和12V/1.85A
 MAX，USB-C的参数为5V/3A、9V/2.5A和12V/1.85A MAX，由此可见这是一款支持两进三出的移动电源。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXFlZH5kFItHuhOlAAVYwk10AlGTx5dqFciaG4vLvCVuDdOibics25QB8ne2hzSg6sia7rgmNNFyeeffOw/640?wx_fmt=jpeg)


移动电源的顶部共配有四个接口，之所以称之为两进三出，是因为TYPE-C接口既支持输入又支持输出，而且无论是输入还是输出，TYPE-C接口的工作效率也是最高的。而除了接口之外，电量指示灯和实体按键也都集成在了一个区域，这里要说的是，通过按键除了可以查看当前电量之外，快速的双击按键还可以开启移动电源的小电流模式，这种模式很适合为蓝牙耳机或是智能手表充电，避免电流过大损坏设备的风险。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXFlZH5kFItHuhOlAAVYwk10cicq9d1Jkb7Dw3KBfB4cDqsCXr7xOfvdiaialjjI34BibOnKGSfrQZVMLg/640?wx_fmt=jpeg)


在实际的充电过程中，这款ZMI移动电源可以适配多种不同品牌的手机、平板等各种电子产品，就以我的小米11手机为例，插上充电线的瞬间，手机立刻就进入了快充模式，手机的电池容量为4600mAh，去掉充电时的衰减，差不多能够提供2次满电的充电次数，如果你使用的是iPhone
 
13手机，这款ZMI移动电源能够提供1.9次的充电次数，所以即使是平时使用手机的频率较高，配合这款ZMI移动电源，让手机持续1整天的续航是毫无问题的。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXFlZH5kFItHuhOlAAVYwk10BpV40ngx6NnJXhvbwRu3zyGS1oNUgPrjjlnKkyUCZWk1BaX5OA6K7g/640?wx_fmt=jpeg)


之前有说过，移动电源上的TYPE-C接口是工作效率最高的，这不仅体现在输出方面，为移动电源自身充电时，使用TYPE-C接口同样也是最快的。当然这也是有前提条件的，若只是使用一般的USB充电，效果自然要大打折扣，建议搭配24W以上功率的充电头，这能够让移动电源快速的满血复活。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXFlZH5kFItHuhOlAAVYwk10EEwQCr70whTePic0p7WfayH7AA8eYkb0fiaiaic49bFynGiaOicms9YS50wA/640?wx_fmt=jpeg)


这款移动电源除了美观和不错的充电效率之外，在安全方面也有着多重的保障，外壳配备的是PC+ABS阻燃材质，内部则使用了高品质的电路芯片，不仅转化效率高，放电时的电压也非常稳定，同时也支持多重电路保护，保证了产品的安全性。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXFlZH5kFItHuhOlAAVYwk10SmB7xFaML2VWQCstibsF3RRDWAyA38qTfJ6dZTytZuxYoDtNNz4tBMA/640?wx_fmt=jpeg)


对于移动电源，可能有的伙伴会在容量和体积方面难以取舍，大容量的移动电源固然是好，但携带起来确实也不太方便，其实移动电源的最终目的，就是为我们的电子设备提供随时的电量供应，但若是不能随身而行，似乎就有些违背了移动电源的初衷。而像这款拥有迷你身材的10000mAh
 
ZMI移动电源，其实就是个不错的选择，10000mAh的容量作为备用能源来说，是完全够用的，而袖珍小巧的身材也正符合了移动电源的初衷，包包和口袋都能成为它的容身之所，让移动电源可以轻松的随身而行。
