# 还未发布就爆火，Redmi K80系列手机将迎来大幅度更新，搭载骁龙8 Gen4，创新硬件令人期待

![封面图](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXFncBNEoQiaBCyQRSbZU9rW7pjozWjiaicKiagz9GpdcxfWs5HN9GOxOiaGpzS3ZcCtP33ibiau2R3gH9jxw/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/1OBpal1HXzT-arhd2e2RVA

近日，博主数码闲聊站为我们带来了一则激动人心的消息——Redmi正在秘密测试全新的K80系列手机。这款备受期待的新机不仅与之前的K70系列有着异曲同工之妙，更是跨越了骁龙8
 Gen3和骁龙8 Gen4两大处理器平台，展现出了Redmi在手机硬件创新上的决心和实力。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXFncBNEoQiaBCyQRSbZU9rW7ac5LpnrnrrDLU5EAvXRzmdIGTJleqziaAtRhUJ0xfCzPE1UH65N95Lw/640?wx_fmt=jpeg&from=appmsg)


据了解，Redmi K80系列手机预计将会采用与Redmi 
K70系列相似的市场策略，但在处理器方面却有着不小的升级。其中，标准版的K80预计将搭载性能强劲的骁龙8 
Gen3处理器，为用户带来流畅无比的使用体验。而更高端的K80 Pro则有望首次采用高通即将在10月推出的新一代旗舰平台——骁龙8 
Gen4。这一处理器的出现，无疑将为Redmi K80 Pro带来更加强劲的性能表现，成为市场上的一款顶级旗舰手机。

![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFncBNEoQiaBCyQRSbZU9rW7S1gta0uA12iaXm8Ticg5A2a7uNfOwQib9T46PwzTmMozQMvnMGKDSqh9A/640?wx_fmt=png&from=appmsg)


值得一提的是，骁龙8 
Gen4处理器采用了先进的台积电3nm工艺制程，并配备了自研Oryon内核，CPU主频更是突破了4GHz。这样的配置让人对K80 
Pro的性能表现充满了期待。而Redmi选择将这款处理器率先应用在K80 Pro上，也足以看出其对于手机硬件创新的重视和决心。

![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFncBNEoQiaBCyQRSbZU9rW7EhQvgzHw6D1NaicPib8qHy5M7G1r2ZxcDiaoVLP8pkVIfiaBiazaDY6jGnw/640?wx_fmt=png&from=appmsg)

然而，令人遗憾的是，据数码闲聊站透露，此次K80系列似乎只有骁龙8 Gen3和骁龙8 
Gen4两个版本，备受期待的K80E版本可能会缺席。在过去的两年中，Redmi曾连续推出了搭载联发科天玑8200和天玑8300-Ultra处理器的K60E和K70E机型，这些机型以其出色的性能和合理的价格赢得了消费者的广泛好评。而这次K80E的缺席，无疑给广大消费者带来了些许遗憾。

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXFncBNEoQiaBCyQRSbZU9rW7L9iaD4tnM3uTQe0tKNwTUehru5Db6m5vABhhJBsMe7dE15Gy1vxiaZgA/640?wx_fmt=jpeg&from=appmsg)

不过，尽管K80E版本缺席，但Redmi 
K80系列依然值得我们期待。据悉，该系列手机将配备超大容量高密度硅负极电池，这一创新技术将为用户带来更长的续航体验，解决了手机使用过程中频繁充电的烦恼。同时，K80系列还将支持2K屏幕，无论是色彩表现还是清晰度都将达到顶级水平。此外，金属中框和玻璃机身等高端配置也将出现在K80系列手机上，让手机的外观更加精美、质感更加出色。

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXFncBNEoQiaBCyQRSbZU9rW7ibmW6T3uricicwvwFFTwP4OtloB5eCwQloUbDu3wlstWeQpMy5FYjicz3g/640?wx_fmt=jpeg&from=appmsg)

预计Redmi 
K80系列最快将在今年年底正式亮相，届时它将成为Redmi新一代“旗舰焊门员”，为消费者带来全新的手机使用体验。无论是性能、续航还是外观，Redmi
 K80系列都将展现出其强大的竞争力。让我们拭目以待，期待Redmi K80系列能在未来的手机市场中大放异彩，为消费者带来更多惊喜和选择。
