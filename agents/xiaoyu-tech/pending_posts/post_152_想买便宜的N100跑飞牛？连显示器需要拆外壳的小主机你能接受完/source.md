# 想买便宜的N100跑飞牛？连显示器需要拆外壳的小主机你能接受吗？

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCencu5iciakBfv5bCqX8czB4iaVLxOrTWzQSDPo4AIBz2luUQ7jvO5SQjUkpIzG4heic2e381Kvn4TtiaP77qoZHBUZmIiapUz4MsdxGk/640?wx_fmt=png&watermark=1&tp=webp)


二手鱼里有个卖家 388 元出这台FOGGIE N100小主机，准系统不带内存硬盘。 说实话N100主机卖这个价确实不算贵，但这也是有原因的，因为主机的 没有视频输出孔位，HDMI接口藏在主板内部，要插必须拆开 外壳 。这种设计普通用户看了估计扭头就走，但 如果你图便宜还要图配置，那这台小主机还真值得研究一下。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelxvlFoayMwBvN6ZBDHzKhcVH2v7qyCRpp2Yeibuic87C6WtS9lm6Dr1QrjlTzbntQoAF8sR3ypIf2qjLTOZkBFBFhN0PSKXvt7c/640?wx_fmt=png&watermark=1&tp=webp)


先过一遍配置，N100 属于 12代 处理器， 4核4线程，最大睿频3.4GHz，TDP只有6W。主板支持DDR4笔记本内存，最高32G，有一个NVMe M.2硬盘插槽，上盖还能再加一块2.5寸SATA盘。网络给的是2.5G网口，两个USB 3.1，外加一个12V电源口。miniPCIE插槽仅支持蓝牙网卡，其他不识别。这些参数放在 388 元价位上，单看扩展性已经够良心了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekYkoeib2TQss9oIVrhouLdxBGn4oI7cnOC6oI7A1vz0iaAnr7BqK7NeO6ThQETLrS996crrsqZlRwl3VEvyXeyBS4xaRHbaibEzA/640?wx_fmt=png&watermark=1&tp=webp)


这台机器最大的争议点就是那个被封死的HDMI。卖家说它更多是检修口，给虚拟机、软路由、飞牛NAS这类场景用的。你想想，一台跑家庭服务器的小主机，装好系统后根本不需要接显示器，全是网页后台管理。那还要视频接口干嘛？省下来的开模成本直接反映在 388 元的价格上。 而且这台主机是 全CNC喷砂外壳，底板厚度4mm，做工放在同价位里绝对是稀罕物。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenF5eXNIVDpZOmiahNDnbHRkWxnJ4e7rQicPn2m7g4a9I6shia3KsM2lkibNrhzf7xTMwOUbwaxbqBJGDZu8x48ZJCRgR5lseXOHXQ/640?wx_fmt=png&watermark=1&tp=webp)


卖家还提到一个bug，第一次上电如果自动开机进不了BIOS，强制按电源键关机再开机就好了。这不是硬件故障，是某些工控板的上电时序问题。另外原装风扇是定速的， 有一些 噪音， 如果放在弱电箱基本无感，要是放室内的话 建议花十来块钱换个PWM风扇解决。这种小毛病对于垃圾佬来说根本不算事，比起那些翻车的问题，这简直是白送级别的宽容度。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekdYqMsOjRUgLOb0AJfbLTlmNeyWKxnnyM6v8ia1KDkvFRYauKGCk5ticoN7Q1dibP7B6dEdeuaUWTwTwu8OAjCNhtEtZoV1oLFoY/640?wx_fmt=png&watermark=1&tp=webp)


现在二手鱼上N100准系统的正常行情在480到550元之间，这台卖 388 元还带全金属外壳和2.5G网口，价格确实被打下来了。但它绝对不是给普通用户当客厅PC用的。你想啊，每次调试系统都要拆外壳插HDMI，用两次你就想把它扔沟里 了 。它的真正战场是弱电箱、储物间角落或者电视柜下面，插电接网线，装好飞牛或者PVE，然后一辈子不用再看屏幕。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCempcKSU1uhkjbtmUsRGKVzelMG3sEj2dj0OYiboboLR0fA3nRzRwfvLOcYsNhlsS1nmHCuazCThicQwwSpKDSkSxcECqE7GKhoLQ/640?wx_fmt=png&watermark=1&tp=webp)


如果你真的打算下单，有两点细节提醒你。第一，卖家卖的是准系统，内存和硬盘需要自己配。8G 基本 就够了，NVMe固态用便宜的就行，反正跑NAS和软路由不挑盘。第二，这台机器不适合当主力电脑或者HTPC，它的HDMI接口只是调试用。如果你幻想接电视看4K，或者接显示器写文档，趁早放弃，你会被那个拆壳插线的操作折磨疯。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenUictcHicZkEdIg5hR0o9h5TMVL48Mv0nzhz1E2aUyMkJ4MfMKicic7lWK6Vz4SbKQJ6ck1VLlghZiaUqGbJJ34CJypTKic4z0JYHUE/640?wx_fmt=png&watermark=1&tp=webp)


对于正在折腾飞牛、软路由或者轻量级虚拟化的朋友， 388 元买到全CNC工艺加2.5G网口加双盘位的小主机，这个价格和做工基本没有对手。但如果你只是被外观吸引，或者觉得N100便宜想拿来当普通电脑用，那你大概率会成为接盘侠。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemBRoKwU6HVvpmWy3Q4icIQlsr2FKicPH368qhtkE7KVIXzxn4x0QY5TBbqoMNo0d7Pr7E4jwjefpmmLwZoj23I6o5HkamBHayR4/640?wx_fmt=png&watermark=1&tp=webp)


二手鱼里这种特殊定位的工控小主机其实不少，但能把做工和价格做到这个份上的不多见。卖家说这批货不会再有了，也不知道真假。你们觉得这种无头小主机实用吗？或者已经在用N100跑什么好玩的服务？评论区等你分享。
