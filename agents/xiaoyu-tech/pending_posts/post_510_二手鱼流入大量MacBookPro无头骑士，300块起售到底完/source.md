# 二手鱼流入大量MacBookPro无头骑士，300块起售到底值不值得捡漏？

今天在二手鱼刷到了苹果A1502下半部主机，也就是圈内人戏称的“无头骑士”。乍一看，这名字挺中二，但点进去才发现，原来就是把MacBook Pro拆了屏幕、只留底壳（带键盘、触控板、电池和主板）拿来当迷你主机卖。标价从300元到650元不等，配置跨度从2013年i5到2015年i7，内存4G到16G，硬盘清一色128G。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGQYhnrrbLocW77ucO6wlI6egc6JlgHGJuuX8WnKcNwwTd2giakhwZXzhDovSyScUX8Kob9BujgCog/640?wx_fmt=png)


先说参数。这批“无头骑士”基本都是Retina屏时代的13寸MacBook Pro（型号A1502），年份集中在2013–2015年。处理器从Haswell架构的i5-4258U（2.4GHz）一路到Broadwell的i7-5557U（3.1GHz），内存多为焊死不可升级的4G或8G，硬盘是原装PCIe接口的SSD——注意，不是SATA，读写速度确实比同期Windows本快不少。接口方面有雷电2、USB 3.0、HDMI（部分需转接）、耳机孔，支持Wi-Fi 5和蓝牙4.0。系统最高可升到macOS Catalina（10.15.7），再往上就官方封杀，别指望跑Monterey。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGQYhnrrbLocW77ucO6wlI63jUVk9awCfzN4wc0A2CJpKlcl9eIEaH4bcc135UTjH9ncugIBo993A/640?wx_fmt=png)


卖家强调“不拆件、不动件、原装机”，还提到支持4K@60Hz输出、隔空投送、接力这些生态功能。听起来很美好，但这配置放到现在，怕不是要天天跟卡顿斗智斗勇。举个例子：你用它开个微信多开+钉钉+浏览器，再切个腾讯会议，4G内存版本基本就原地升天；8G的也好不到哪去，系统后台一更新，风扇呼呼转得像拖拉机。更别说128G硬盘，装完系统只剩一半空间。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGQYhnrrbLocW77ucO6wlI6f3OqZeXNwTqqQAZtZZ6OFl9L9Cp7YEz3n345cpXYRF9EzHZRZF7rWQ/640?wx_fmt=png)


价格方面，300元起确实“挺白菜”，但得看对比对象。同价位你能在二手鱼淘到2018年的Intel NUC，或者加100块拿下带i5-8250U+8G+256G的联想小新Air主机。它们虽然没macOS，但Windows 11轻办公完全够用，还能打打小游戏。而“无头骑士”除了macOS情怀和低功耗，性能早已掉队——尤其是4G内存那款，开个浏览器标签页都能卡成PPT。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGQYhnrrbLocW77ucO6wlI6aQyXc42ppwR5j0cjwpp11TWicA90Zv1Zm1PgYicibEpeuIkXzBmQjwScw/640?wx_fmt=png)


可能有人会问那我拿来当下载机或者NAS总行吧？理论上可以，但效率不高。这机器功耗虽低，但性能太弱，挂PT或迅雷离线下载速度远不如百元安卓盒子，更别提群晖这类专业设备了。而且macOS后台限制多，长期开机稳定性也不如Linux小主机。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGQYhnrrbLocW77ucO6wlI6OhYwcjWg931ZmRt2Ribvn9gzM91UZ7YcpeG3EJ7tePHhc3Oj25eSB1g/640?wx_fmt=png)


那么能不能装Windows当普通电脑用？能，但体验打折。虽然A1502支持Boot Camp装Windows 10，但驱动不全，Wi-Fi、声卡、触控板经常出问题。加上屏幕都没了，你还得外接键鼠显示器，折腾半天，还不如加点钱买台正经二手小主机。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGQYhnrrbLocW77ucO6wlI6Ric6l817lEclq8vAxcnxc0xIse12wjQazxvY6Efcrqp9hzeviaSFS34g/640?wx_fmt=png)


以下是个人一些掺了水的建议：

1. 非Mac用户别碰，生态门槛高。

2. 办公需求优先考虑新一点的Windows小主机。

3. 4G内存版本实用性很低，不推荐。

4. 看完不买，立省300元。
