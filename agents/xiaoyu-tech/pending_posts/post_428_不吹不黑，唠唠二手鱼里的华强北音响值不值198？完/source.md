# 不吹不黑，唠唠二手鱼里的华强北音响值不值198？

今天在二手鱼刷到了一款“华强北哈曼卡顿LP90 Pro升级版”蓝牙音响，点进去一看，价格挺白菜——198块还包顺丰，某宝同款起码260起。我寻思着，这玩意儿不会又是那种“音质靠脑补、灯光靠滤镜”的电子垃圾吧？但转念一想，当年LP90可是被无数人称为“千元以下无对手”的神机，如今Pro版据说连顶盖都换了全透明穹顶，看着确实有点东西。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGic4E9EBjibj7uYEl7YLicQiaHKyGtP1PMbtthIvHvqDrUEnUicXJdMATJhpjjrAyF8AeHNLbeNicic0RGQ/640?wx_fmt=png)


先说说外观。这款LP90 Pro最明显的改动就是顶部那个全透明防尘盖，不再是上一代被人吐槽“塑料感爆棚”的磨砂黑盖子。现在这个穹顶透亮得像琉璃4，底下还有17种RGB渐变灯效，水波纹+节奏同步闪烁，晚上开灯模式放首《加州旅馆》，氛围感直接拉满。机身用的是鎏金帆布纹理，摸起来不廉价，底部加了橡胶垫，放桌上稳当不滑。尺寸208×208×256mm，重量1.9公斤，不算轻，但也不至于搬不动。整体做工在百元价位里，算是“可接受”级别——毕竟你不能指望它跟正品哈曼卡顿一样精致，但这个价格还要啥自行车？


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGic4E9EBjibj7uYEl7YLicQiaHqPXLsLic63ucnia9X6H5iaicgTCiaWn79uVH8azySYJbK1TTbpmWiaBcWVEA/640?wx_fmt=png)


再聊聊核心：音质。官方参数写得很猛——5个发声单元，1个130mm下沉式低音炮 + 4个15W中高音喇叭，总功率120W，支持三分频和360度杜比环绕。蓝牙5.4连接快、延迟低，手机隔两堵墙还能连着，偶尔断连的情况几乎没有。另外还支持TF卡、USB、AUX线，甚至TWS双机互联——家里要是有两台，还能组个立体声。续航标称8-10小时，中等音量能撑9小时左右，电池8000mAh，充一次电够周末露营用了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGic4E9EBjibj7uYEl7YLicQiaHia8ckECvkfP0Y7po9VC0RuKulYCUiaeNiaIubYVVyrbnRrFLU8GJ9QvLg/640?wx_fmt=png)


当然，也不是没缺点。比如灯光虽然炫，但没法单独关闭，想纯听歌还得忍受闪来闪去的RGB；再比如低音虽足，但在极低频段（比如电子乐的sub-bass）还是有点力不从心，毕竟物理尺寸摆在那儿。另外，虽然标称“琉璃4同款设计”，但仔细看细节，比如接缝处理、按键手感，还是能看出是华强北的“致敬之作”。不过话说回来，198块买个能打能唱还能发光的桌面音响，还要啥真·哈曼卡顿？


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGic4E9EBjibj7uYEl7YLicQiaHADuCJGB8UmbcjhAUtDZJzrOAPVrsHl1w6L1So2RS4Hps65c6mJDoXA/640?wx_fmt=png)


可能有人会问：“这玩意儿是不是山寨货？靠谱吗？”答：确实是华强北出品，但属于高仿里的顶配款，不是那种几十块的杂牌。卖家是L7级店铺，支持七天无理由（前提是别撕膜），还有一年保修。只要当面验货、录开箱视频，基本没啥大雷。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGic4E9EBjibj7uYEl7YLicQiaHibm7W4IvvmhZyhH0jwsnAyLM874fiarc9CGzZar1T3LHm0hPiaoRuEeGw/640?wx_fmt=png)


可能又有人问：“25块钱的音响都能听个响，这198的到底值不值？”值不值看你的需求，说实话华强北这几年卷出了新高度。LP90 Pro在二手鱼上已经5万浏览、2483人想要，说明不是我一个人觉得香。比起那些贴牌杂牌，它至少在调音、用料、功能整合上花了心思，属于“性价还行”的典型代表。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGic4E9EBjibj7uYEl7YLicQiaHGL0hWagYk4JkIFKDppLAR4aOsvqLLzwrCM8azhf2B2fTfpzhw6Infg/640?wx_fmt=png)


你若是对这款音响感兴趣的话，可以在二手与上搜搜“LP90 Pro”或者“华强北琉璃4”，说不定就能捡个漏。另外，如果你预算百元内，对音质有点追求又不想“斥巨资”，这款音响确实值得一试。当然，二手鱼淘货永远记得：录开箱视频！先试听！别撕膜！老规矩，看完不买，立省198元。
