# 这次来波大的，闲鱼淘1000+的“洋垃圾”平板，算不算捡对漏？

若要盘点闲鱼上那些让理工男和数码控欲罢不能的“硬通货”，日本企业退役下来的“洋垃圾”绝对榜上有名。特别是东芝、富士通、NEC 这三家，简直就是这片灰色市场上的“绝代三骄”。它们不仅带着昭和时代的严谨做工，往往还配备着令人咋舌的堆料接口。

今天要深扒的这位主角，正是前段时间我从鱼龙混杂的商家手里淘来的——富士通 Q7311 Windows 平板。说实话，在如今这个新平板动辄四五千、甚至轻薄本都在疯狂砍配置的年代，这款原本属于日本政企高端线的退役设备，刚一上手就给了我一种“穿越时空”的错位感。那种扎实的质感与反主流的接口设计，着实让人眼前一亮。

先聊视觉交互最直接的部分。

翻过来看正面，是一块 13.3 英寸的 IPS 屏幕，分辨率是 1920x1080。很多朋友可能会问：“都 2024 年了，1080P 够用吗？” 实测下来，在 Windows 系统下，这个尺寸的屏幕 100% 缩放显示桌面恰到好处，不用像高分屏那样为了解决字体发糊去瞎折腾兼容性视图。更关键的是，这块屏幕支持 Wacom 技术的手写笔和十点触控。对于经常需要签批文件、或者像我这种开会时有写写画画习惯的人来说，用笔在屏幕上直接划重点、记录灵感，那个跟手度绝对比敲键盘来得痛快。当然，前置摄像头、光线距离感应器这种“良心配置”也没缺席，自动调节屏幕亮度在应对户外或强光室内时非常实用，不至于黑屏一片或者刺眼。

把视线移到中框和背部，这里的设计语言很有意思。你会看到机身中框和后盖衔接处，布满了密密麻麻的开孔。这可不是为了散热效率低而打的补丁，而是典型的“类 Surface”风冷散热设计，利用机身侧边的进风口和内部风扇，将热量从这些缝隙中快速抽出。这证明它虽然长得像平板，但内心还是个要把性能释放出来的 PC。转到背面，配备了一颗 800 万像素的摄像头和单色温闪光灯。我知道有人会吐槽：“手机都一亿像素了，这 800 万能看吗？” 要说拍人像、扫风景，它确实不如手机，但它的场景是“移动办公”。在图书馆拍书上的资料、在办公室拍白板上的会议纪要，或者开个视频会议，这个素质完全够用。这一点，它比那些只有前置摄像头、拍个照还要把举着平板别扭地翻转的 iPad Air 要实用得多。

接下来是这台机器的灵魂所在——接口，这部分简直让人感动到想哭。

现在市面上那些打着“极致轻薄”旗号的所谓超极本，给你留俩全功能 Type-C 就算仁慈了，插个 U 盘都得揣个转接头，不仅麻烦还容易丢。反观这台 Q7311，它简直就是个接口扩充坞。机身两侧不仅藏着两个隐藏式的 Type-C 接口（支持充电和视频输出），甚至还保留了标准的 HDMI 接口、两个 USB-A 接口（一个是高速的 3.2 协议，一个是兼容性更好的 2.0）、3.5mm 耳机孔，甚至是全尺寸的 SD 卡槽！

这意味着什么？意味着你出门不需要带任何扩展坞。去客户公司投屏，直接插 HDMI；摄影师导片子，直接插 SD 卡；甚至想一边用鼠标一边插个加密狗解密文件，两个 USB 口同时伺候都绰绰有余。更令人发指的是，富士通居然还给每个接口都配了防尘橡胶帽！这种为了微小的用户体验而增加成本的细节，在如今这个“能省则省”的消费电子时代，简直就是濒危物种。底部正中央是标准规格的磁吸键盘接口，原装键盘插上去就是一台完整的笔记本。键盘手感虽然比不上 ThinkPad，但应急敲个 Word、做张 Excel 表格，键程和反馈绝对比那些软塌塌的蓝牙键盘强。

但是，凡事都有两面性，这台机器的“硬伤”也在配置上显露无疑。

首先是核心配置。它搭载的是英特尔第十一代酷睿 i3-1125G4 处理器，4 核 8 线程，最高睿频能达到 3.7GHz。基于 10nm 工艺的这代 U，其实日常表现并不弱。打开 Word、PPT，挂十几个 Chrome 标签页，后台挂着微信和 QQ，基本操作非常丝滑。但是，这里有个巨大的坑——它的内存和硬盘是**板载**的！

什么叫板载？就是内存和颗粒直接焊死在主板上，你根本没有插槽去自己升级。市面上流通的版本从低配的 4G+128G 到高配的 8G+512G 都有。我强烈建议，如果你想买，千万别碰 4G 内存版本。在 Windows 11 环境下，4G 内存跑起来会非常吃力，一旦开多了程序，磁盘读写就会飙升。最尴尬的是，当你觉得内存不够用时，你只能眼巴巴看着它，不像普通笔记本那样还能自己买根内存条插上。虽然它可以通过 USB 接口外接高速固态硬盘来缓解存储焦虑，或者用 SD 卡拓展空间，但系统盘和系统内存的瓶颈是无法通过外设解决的。这种“一步到位”的配置模式，对于喜欢折腾的 DIY 玩家来说，简直是一种折磨。

再聊聊续航，这也是官方数据最“感人”的地方。

官方宣传册上写着续航可达 15 小时，这种数据大家看看就好，千万别当真。我实测在亮度 50%、连接 Wi-Fi 办公的状态下，满打满算也就撑 7 个小时左右。这就很尴尬了，如果你要出差一天，中途不充电肯定不够用。厂商测试的可能是在最低亮度、断网、待机混合的情况下的极限数据，而我们要的是真实生产力续航。这方面，Windows 平板相比 ARM 架构的 iPad 或者 Android 平板，功耗控制上确实有着天然的劣势。

市面上还有一种所谓的“高配版”，搭载了 i5-1145G7 处理器，睿频高达 4.4GHz，核显也从普通的 UHD 升级到了 Iris Xe（锐炬 Xe），性能提升确实显著。但我劝你看看价格就算了，这种高配版往往被商家炒到 2000 元以上，这就完全背离了“洋垃圾”追求高性价比的初衷。除非你必须要用它剪视频或跑轻量级 PS，否则为了那点性能提升多花几千块，纯粹是交智商税。

说完了缺点，再聊聊它为什么值得买。

便携性绝对是它的一大杀手锏。13.3 英寸的机身，重量控制在轻薄本范畴，随手往双肩包侧兜或者手提袋里一塞就能走人。对于经常需要跑外勤的销售、经常出去采风的学生，或者需要一个随身“副机”处理邮件的人来说，这种随身携带但插上键盘就能变成全功能 PC 的体验，是非常棒的。

还有一点特别值得庆幸，这机器虽然也是日系，但它的磁吸键盘接口是通用的，或者你可以随意配蓝牙键鼠。不像某些日系“洋垃圾”笔记本，自带日文键盘布局，回车键歪得离谱，右下角还有莫名其妙的一堆假名键，盲打时简直心累。Q7311 这种平板形态，完美避开了日文键盘的尴尬，输入体验完全正常化。

最后聊聊价格和购买建议。

目前 Q7311 的货源基本集中在商家手里，个人一手卖家极少。商家手里的成色参差不齐，屏幕有没有压痕、外壳磨损程度都要看运气。经过我多方比价，最值得入手的版本是 **i3 + 8G 内存 + 256G 硬盘** 的组合，目前的行情大概在 1099 元左右。这个配置能保证 Windows 系统运行得比较体面，256G 的存储装完日常软件和存点文档也勉强够用。至于那些 16G+512G 的顶配，价格飙升到 1500 甚至更高，除非你是特定用途需要大内存，否则性价比极低，不建议作为“捡漏”的首选。

总结一下，作为一款千元左右就能拿下的“洋垃圾”平板，富士通 Q7311 的优缺点都极其鲜明。

它的优点是接口极度丰富（秒杀同价位任何轻薄本）、屏幕尺寸适中支持手写、机身便携且做工扎实。
它的缺点则是板载内存无法升级（买定离手）、续航表现中庸、性能上限有限。

如果你需要一个随时能掏出来处理文档、不需要带转接头、且预算有限的备用机，这台机器绝对能给你带来“捡到宝”的惊喜。但如果你指望它当主力机打游戏、剪 4K 视频，或者希望它能像 iPad 那样待机一整天不充电，那还是洗洗睡吧。

一千块钱买个大牌、带笔、接口全的 Windows 平板，这波到底算不算捡对漏？我想答案已经很清晰了。
