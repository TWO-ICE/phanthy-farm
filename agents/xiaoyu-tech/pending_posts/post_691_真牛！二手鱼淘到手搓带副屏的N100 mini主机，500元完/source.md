# 真牛！二手鱼淘到手搓带副屏的N100 mini主机，500元值不值？

今天在二手鱼刷到了一款N100带监控副屏小主机，标价500元还顺丰包邮。图片看上去感觉很帅，点进去才发现这迷你主机是手搓出来的，3D打印外壳、焊主板、接副屏，整出一台能跑飞牛NAS的小主机。价格挺白菜，配置也说得过去，让我忍不住多翻了几页图。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEAKBCZT6AUdYOcIWcZWccD5q7ibyC2KoWYsqR2rIgumafrwibicobBoqOWS8sIiaddUlfCEiapVlPWtfw/640?wx_fmt=png)


这台机器的核心是Intel N100处理器，四核四线程，基础频率0.8GHz，睿频最高3.4GHz，TDP 6W。虽然性能比不上桌面级CPU，但日常轻量办公、软路由、家庭NAS完全够用。关键是功耗低、发热小，放在家里24小时开着也不心疼电费。配上单条DDR4内存插槽和M.2 NVMe固态接口，扩展性虽不算强，但对入门用户来说已经可接受。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEAKBCZT6AUdYOcIWcZWccDb1U76BR4Q2M758IRPFgoWpjfzPn3Jqkb0aWaP3sPtFM9ibSjphvYfLw/640?wx_fmt=png)


机器本身不带内存和固态，卖家建议搭配8GB+128GB或16GB+256GB使用。我查了下行情，现在8G DDR4笔记本内存条大概140元，256G M.2 NVMe固态260元左右，加起来成本400出头。加上主机本体500元，整套不到900块就能搭个迷你NAS或HTPC，这个价格感觉勉强可以接受，亮点就是它还带一块副屏——屏幕来自“图灵智显家”，支持Windows下直接调用APP显示系统状态，而且在飞牛系统里也能用（需自行研究教程）。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEAKBCZT6AUdYOcIWcZWccDpsus0Us5ub67fX6s394uaX9hIiaGpnybLJkbUxmLXem4OCjZI1rlxtQ/640?wx_fmt=png)


接口方面，机器提供一个千兆网口、一个SATA接口（可用于接2.5寸硬盘扩容）、USB-A和USB-C若干，供电为12V 5.5×2.5mm接口，需自备3A以上电源。注意：不带电源！这点容易踩坑，新手可能以为“包邮”就万事大吉，结果还得额外花三四十买适配器。不过整体布局紧凑，3D打印外壳有简约版可选，选那个还能减50元，算下来主机只要450。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEAKBCZT6AUdYOcIWcZWccDbnnVsIia3NcAzABLbASlZChkqUCuibjZGXnPb7dxy9smSO5P958LsRVQ/640?wx_fmt=png)


可能有人会问这副屏到底有啥用？其实主要是监控用途——显示CPU温度、硬盘状态、网络流量等。装飞牛NAS后，配合社区教程，能实时看存储池健康度。虽然不是刚需，但看着数据跳动确实有种“赛博管家”的爽感，而且不用额外接显示器就能调试，省事。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEAKBCZT6AUdYOcIWcZWccDOs9PU6F6w7kxobXibC9LsnxelC1B1TCJIyMJSarWJOIibteQbicUvZGBw/640?wx_fmt=png)


那么手搓机稳定吗？会不会三天就蓝屏？其实N100本身是低功耗U，发热量极低，被动散热足够。只要内存和固态别买杂牌，日常7×24运行问题不大。卖家用的应该是公版方案主板，稳定性接近市售机型。当然，毕竟不是大厂品控，心理预期要放低点——它值这个价，但别指望它当主力生产力工具。


 


如果你对此感兴趣的话，可以参考下面的几点建议：

1. 完全新手慎入，建议先看飞牛教程。

2. 自备电源+内存+固态，别漏算成本。

3. 能接受“不退不换”，再下单不迟。

4. 看完不买，立省500元。
