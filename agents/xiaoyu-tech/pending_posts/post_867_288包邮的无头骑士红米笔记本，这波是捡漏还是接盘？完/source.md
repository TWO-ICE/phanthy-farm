# 288包邮的无头骑士红米笔记本，这波是捡漏还是接盘？

今天在二手鱼刷到了个挺魔幻的玩意儿：一台标价288元还包邮的红米RedmiBook 14寸笔记本。但仔细一瞅，详情里赫然写着“无头骑士”和“半机”。好家伙，我直接一个好家伙，这年头笔记本也开始玩“身首异处”的戏码了？好奇心驱使下，我点了进去，看看这到底是电子垃圾还是隐藏的性价比之王。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGkLnfVeINhqShibC1joibqZIcQ1v3HZAIkujicbHpXAONZibT28Qq2KFyJwPpES1nqtbQKdL0XRDq7CA/640?wx_fmt=png)


先说说这台机器的基本情况：i3-8145U处理器、4G内存（三星DDR4）、128G固态硬盘（海力士），系统能进，接口正常，但有两个硬伤：一是触摸板失灵，二是BIOS设了密码。卖家很坦诚，照片也实拍，没充电器，但反复强调“包邮包邮包邮”，生怕你没看见。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGkLnfVeINhqShibC1joibqZItauH2jGSacYK6CDCq8SowKaspsQ3B3icRFxGOekO8P56w344AJcqzBg/640?wx_fmt=png)


所谓的“无头骑士”，其实就是只保留主机下半部分（屏幕和上盖没了），只剩键盘、主板、电池那一坨。听起来有点像废品站淘来的，但其实这类半机在DIY圈里早有市场。尤其对只想当小主机用的人来说，拆掉屏幕反而省电又安静，插个HDMI就能当HTPC或者远程办公终端。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGkLnfVeINhqShibC1joibqZI1QtjCUl8zJYY0Hf64krsvjNrtxNO4xQhIkcr5xqseJeuorUiaiazqJeQ/640?wx_fmt=png)


那么问题来了，花288元买这么一台“残血本”，到底划不划算？现在全新J4125小主机才300出头，为啥要买这个老i3？确实，新平台功耗更低、接口更新、支持NVMe，但你要考虑到——这台RedmiBook自带金属机身、电池（哪怕老化）、USB-A/USB-C/HDMI齐全，而且是品牌机，散热和做工比某些杂牌小主机稳。如果你手头刚好缺个临时办公机，或者想练手刷BIOS、装系统，它性价比还行。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGkLnfVeINhqShibC1joibqZIZnlmVaRCwYWeMJ34rTWQly3K9PQGqzF78C6Z7VWbCHgln9agT22JUw/640?wx_fmt=png)


那么BIOS有密码，是不是没法重装系统？不是完全不能，只是麻烦点。你可以把固态拆下来，用硬盘盒接到另一台电脑上装系统，再装回去。或者技术党直接短接主板清除CMOS，甚至刷BIOS去掉密码——当然，这需要一定动手能力。如果只会点“下一步”的用户，建议绕道。


 


最后给几点建议：

1. 别指望它干重活，轻办公尚可。

2. 动手能力弱的慎入，BIOS密码是门槛。

3. 同价位多对比，别被“包邮”冲昏头。

4. 看完不买，立省288元。
