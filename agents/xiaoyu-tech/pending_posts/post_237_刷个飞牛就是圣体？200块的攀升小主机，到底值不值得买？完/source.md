# 刷个飞牛就是圣体？200块的攀升小主机，到底值不值得买？

刷到一个卖攀升J3160的小主机，标价200块钱。配置很简单，J3160处理器、4G内存、120G固态，带VGA和HDMI接口。这玩意现在还能卖200？这是什么世道，就这配置以前100我都不想多看一眼，但我对比搜索了一下，发现200现在居然还是良心价。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekypUj2lqJ2ibOeGiaibVlrZp5eDaIqBdqppTJicXvxpJLCH6PGNQx7UXHREDhLejuo0Qh9XYerHt8Dg133uKRZ3GTxC21rKqNw9BY/640?wx_fmt=png&from=appmsg)


先说这颗J3160，四核四线程，主频1.6GHz，最高能睿频到2.24GHz 。当年这货就是给低功耗工控机准备的，TDP只有6W，待机功耗更是低到3W 。搁十年前，办公勉强能用，现在嘛，性能确实不够看，打开个稍微大点的网页都能卡飞。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenUC4w6ongZdKb2ocMeKiaJflpwrnZVo7LrAwsmHP9J5r99KFP7NDvsstZA8FtkMZ14v0royQmyAXq6modwypaEU0iaic4JgqVMVo/640?wx_fmt=png&from=appmsg)


但它也得看怎么用，以前没人要的垃圾，现在被飞牛系统拯救了，给它装个飞牛，这配置依然够用，4G内存跑个轻量级NAS系统绰绰有余，120G固态当系统盘，剩下的空间存点东西也够用，再不济还能外接硬盘。而且功耗低现在变成了优势，24小时开机当下载机，一年电费都花不了几十块，。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/E9h3abOJCekh4Ak9WzAE9NicUVATsL4icYQYxBAvOc2EJ6JwMhI3LyDkAxIKNlOPalpcyv5kamia1tNF6mg5DYphELKzwYaRZk5zmSTxCoQ260/640?wx_fmt=jpeg&from=appmsg)


现在内存和硬盘价格涨得离谱，DDR3 8G的内存条都快炒到50多块了 。这么一看，4G内存虽然小了点，但好歹是白送的，凑合用呗。120G固态在现在也是小，但对于只装系统的人来说，其实也够用了。卖家给配的是120G固态加4G内存，没给你省到极致，这点还算良心。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekL8LGATGthyZQfDnRb7lxibsceibg4VyhWlg2bACI5cYYVh9zSbbQvQeQwiaTYo3licbtD42BNQDicuduqDibNOYicS3SicbC8P6wwdNY/640?wx_fmt=png&from=appmsg)


接口方面，VGA加HDMI，老显示器新显示器都能接，这点挺实用。四个USB口，接个鼠标键盘，再插个U盘，够了。千兆网口基本是标配，网卡应该是螃蟹的8111，飞牛系统对这卡的兼容性很好，基本不用折腾驱动 。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/E9h3abOJCekj6I8meLPkMgHzluE13cPoCS8Jxeicia1x32Dncj3xKdegKNuI8Hicr9YHQGKYoEjZZKYGW7ABWk3FrC4rg2rA7Y4llNQOUQSB3s/640?wx_fmt=jpeg&from=appmsg)


200块买它到底值不值？如果只看CPU性能，那确实不值，但卖家给的是完整的整机，到手就能用，省去了自己配内存硬盘的麻烦。而且现在DDR3内存和固态都在涨价，你单买这两样可能就快100了 。更关键的是，二手鱼上这类小主机最近明显变多了，主要是因为飞牛系统太火，大家发现这玩意当NAS真好使。需求多了，价格自然就稳住了 。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemCVbbvaYXf78vYuaoQ0FvibQDkXwXrl7Qq3YEO6LBnNZicjyq2EUAGXB5aXlcIyPbwFZBIwwo1cnT3mKS7dQib8MLicxBUlPLJ9ZE/640?wx_fmt=png&from=appmsg)


不过我得说点大实话，这机器也就两个用途最合适。一个是装飞牛当轻NAS，存电影、备份手机照片，完全够用。另一个就是当软路由或者下载机，功耗低噪音小，扔角落里不用管。如果想着用它来办公，哪怕是看个4K视频，我都劝你趁早打消这个念头。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCek7Djq2RP8JXBowye46u7KdeHg6N9nsOt5e6dh3amPMPsic99Syv2KDxLYZKl8ooCtuU9uiaNzBHCv4cSD4cGiaOag5gibibK9Xlz4c/640?wx_fmt=png&from=appmsg)


你要是愿意折腾，可以花时间蹲个更便宜的裸机，自己配内存硬盘。但如果你懒得折腾，就想买回来直接用，那这200块钱也算合理，至少卖家没拿你当大冤种.最后我想问问各位老铁，你们觉得这200块的攀升J3160，到底是真香还是智商税？欢迎在评论区留言，说说你们在二手鱼里捡到过最值的小主机是哪台？
