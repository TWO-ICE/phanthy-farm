# 268元的飞牛圣体，i5五代+4G+128G，值得买吗？

![封面图](https://mmbiz.qpic.cn/sz_mmbiz_jpg/E9h3abOJCemqQrIs25PVbawEuMsCs9fNpqUiabrsIEw68l9ibeBb6wVE22jYicnPwMTSGAJr4xANMpat0okAZNibPzUgSZkW0PjrITAadMC4nu8/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/DwFizxrtA0ebNHHlBn-Z5g

今天在二手鱼里刷到一个卖家，挂出来一台5代i5迷你小主机，268块钱，还带4G内存和128G固态。这价格感觉还可以，用来跑飞牛也完全够用。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCem0yS2HTgvgLZ4UP2WwbcDStdWJxIVxT6seibuNvrmDI3rFvlry9ticEWJJYr2PFia6Wo1UEHET6UJqraA3h47lstkziaQkTcHycXg/640?wx_fmt=png&from=appmsg)


这台机器的核心是i5-5200u，主频2.2GHz，睿频能到2.7GHz，虽然垃圾，但应付一半的日常需求还是可以的，关键它的功耗低，TDP只有15W，所以非常作为飞牛圣体，即使每天24小时开机，电费几乎可以忽略不计。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelicGytCJKI50VU4RicS8NBbtKagsYbnPQ3IxSn57hica1PukMAFrewTl2RJBdSAdwUaNyjCBXzPX515f56bORODfNTCp05GCnpgg/640?wx_fmt=png&from=appmsg)


卖家描述里说背面有划痕、角上有磕碰，这我倒觉得不是问题。二手的东西，只要功能正常，外观有点岁月的痕迹太正常了。反倒是他承诺发货前拍测试视频，这点让我挺有好感，至少说明是个愿意把问题摆在明面上的卖家，翻车的概率能低不少。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCeldBJhS674OW9gMveWyxQmcXTiaBpEouYIqM97wWic7FI01YAv8iaYdLiaqibLjWkQfuWOv9CvVFlG2sPmzy9clyS1STrynRLXic4Hes/640?wx_fmt=png&from=appmsg)


飞牛的x86版本非常成熟，所以和这台主机的适配度更好，装完直接进系统，SMB共享、Docker、相册备份、下载服务，一键搞定。它不需要你懂什么Linux命令行，也不需要你去论坛爬楼找适配教程，对于想入门NAS但又不想花大价钱的人来说，这就是最省心的选择。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenw1heJShkWn7sQaVzJ7Fh8ibwI0bZLOHiaUoeWx5dX4JE4H2StSiaxPO40Q4PB4ibmWQxJy3HMROTcibYeeHvQ3d3JSIdiaL0Fcg4ec/640?wx_fmt=png&from=appmsg)


268元这个价格，包含完整的主机，咱们可以算一下，单纯一个4G笔记本内存条，二手怎么也要四五十；一块128G的固态，再怎么便宜也得五六十；再加上电源适配器、机箱、主板、CPU这些，拆开卖都不止这个价。卖家等于把一套完整能用的主机打包，价格压到了接近废铁回收的水平。估计是卖家图省事不想拆零件单卖，反正对买家来说，确实是个上车的机会。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekRZ97w4M9GKl50woZFnT6UOPfNNRudlpLAqoJADEl5m5icSL0qytghFwpnahCmyzwryaYczasMJq0PfUvFpLqicrLwl0mKJX2iag/640?wx_fmt=png&from=appmsg)


当然，也得说说它的局限。i5-5200u的核显是HD5500，硬解能力有限，对付现在的AV1编码视频是完全没戏的，播放高码率的4K原盘也会吃力。所以它最适合的角色不是HTPC，而是纯后台服务的NAS。你可以把它塞在弱电箱旁边，专门负责跑飞牛系统，做家庭照片备份、挂PT下载、跑点轻量级的Docker服务。影音播放这种任务，交给电视盒子和支持海报墙的播放器去干，各司其职。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCek7JFB5nBiaq988ecBMh2jCUh8mds3Elt4mLhaLZgASV0oXqsAy9RusaHKBZlOxetyDPrPeASrFl4yuFq4FbiaJzbibBoXfF9hbwk/640?wx_fmt=png&from=appmsg)


另外提醒一句，这种小主机内部空间有限，通常只能装一块2.5寸硬盘。如果你手里有大容量机械硬盘，可以考虑把原配的128G固态换成系统盘，再用USB外接硬盘盒挂载仓库盘。虽然速度不如内置，但对于备份照片和存电影来说，完全够用。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenMmCzSmYgPCzq816JVZj7fYpozRXO0a5ZjkIousFkiaib5SvNhD7cc14MCyaFDH7cVRXkrM80tc2lhxRz3d0Z1StxcZfQSLPScs/640?wx_fmt=png&from=appmsg)
