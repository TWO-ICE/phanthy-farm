# 华强北有多牛？顶配“苹果皮”智能手表，二手鱼到手仅166，功能多到数不清

今天在二手鱼刷到了华强北S10智能手表，价格挺白菜啊！166元顶配还包邮，简直是为我这种“预算有限但梦想无限”的选手量身定制。点开详情页，好家伙，功能多到让我怀疑人生：插卡通话、WiFi联网、心率血氧监测、下载APP、甚至还能用作业帮搜题！这哪是手表啊，简直是戴在手腕上的“小手机”，还是那种让家长看了直呼“拿来吧你”的监管神器。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEtJbpMDLv5Yq38nYpPLpr7Dm0FwVSbckoedzJTUuZbTxVu5KyftjjkZFxoQxKbpX0gBeZjE9uvKg/640?wx_fmt=png)


华强北S10的卖点之一是“独立插卡”，支持三网通，能直接打电话、发短信，甚至视频通话。配合2.3英寸的AMOLED屏幕，显示效果居然不糊，滑动也算流畅。但吐槽点来了：这摄像头号称180°旋转，实际拍出来的照片也就是座机的画质，晚上拍照更是“伸手不见五指”。不过想想价格，这个价格还要啥自行车？至少扫码支付、拍黑板作业勉强够用。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEtJbpMDLv5Yq38nYpPLpr71iaAbGjVL6icJ5zoibVMl4fQaenetM28M88UwAIAxBaZtSIicZvzbrolYw/640?wx_fmt=png)


它的“学习功能”更让我笑出鹅叫。卖家说能下载作业帮、大学搜题酱，我当场测试了一下，搜题速度居然比同桌掏手机还快！但缺点是续航捉急：开着WiFi搜题两小时，电量直接掉一半，果然“高性能”和“长续航”在华强北产品里是妥妥的“塑料姐妹花”——表面一体，实际各玩各的。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEtJbpMDLv5Yq38nYpPLpr7yjbfsuLGC4ewgic53ibvMsG2Cz38WDxzDwhl1zibcvejNSwibAMBBluuqA/640?wx_fmt=png)


华强北手表早年被嘲“山寨之王”，但如今迭代到S10，居然能流畅运行微信、抖音，甚至玩消消乐。展讯强芯片+安卓9.0系统，虽然和苹果手表比是“李鬼见李逵”，但日常使用性价还行。尤其对学生党来说，上课禁用模式+定位追踪，简直是家长眼中的“乖孩子滤镜”。不过它的心率血氧监测只能图一乐，真健康焦虑的朋友建议左转专业设备。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEtJbpMDLv5Yq38nYpPLpr7LPkIVmQn9kicl83wXosRVgygxiaHHexeXSdI8aFy4zibHtl7b5o3icT0Hw/640?wx_fmt=png)


可能有人会问：这表能不能替代手机？答：临时应急可接受，但别指望主力机待遇。比如微信消息同步偶尔延迟，灵动岛提醒时灵时不灵，属于“薛定谔的智能”。那么：166元是不是瑕疵品？基本不可能，卖家写的是全新未拆膜这一点没必要撒谎，虽然能够保证全新，但华强北产品品控看运气，介意的慎入。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEtJbpMDLv5Yq38nYpPLpr7icNCHJ72co7fSyPS25npfeMsrF6La1THRDsl6boibZFusTia19XOAIM6g/640?wx_fmt=png)
