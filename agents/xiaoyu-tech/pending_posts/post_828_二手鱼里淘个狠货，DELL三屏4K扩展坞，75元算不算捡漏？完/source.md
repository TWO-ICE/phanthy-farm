# 二手鱼里淘个狠货，DELL三屏4K扩展坞，75元算不算捡漏？

最近想给自己的笔记本电脑弄个扩展双屏，看了一下二手鱼里的扩展坞，感觉靠点谱的都太贵，对比了一下，发现有人挂了个DELL的D6000S扩展坞，标价75块，但是不带电源，成色看起来还行，大伙来看看买这个DELL的扩展坞算不算捡漏？


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenZDNdebrsYpbTTsqgjG405IfOXGJI4XooeO1Go3v7VmmDegjvftnBYf3UzJ5ZhzibBz3kQcSPSWWUrs0ic2zBv6uORkfXbs4mE8/640?wx_fmt=png)


戴尔这个牌子还行，毕竟是大厂，所以品质绝对要比那些山寨的强。而且这款D6000S的接口也挺丰富，不管是Type-C接口还是老旧的USB-A接口，插上就能用。核心在于它用的是DisplayLink协议，能实现单USB口带三台4K显示器。这一点就比较符合我的要求，而且一根线搞定充电、投屏、插U盘、连网线，桌面瞬间清爽。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCennMSc4zl6SUTq0ibhFz5N3gwMibcDKgpZ4SWkoclz4W3ZoOh1j9icGB3icUzN2WFmOwXDrA8DzXcTqhRQaq3iaQ6nIoBhYYCNIw5dw/640?wx_fmt=png)


但话说回来，因为用的是DisplayLink方案，它并不是电脑原生直出的画面，只能应付日常办公、写写文档、看看表格，但对于外接显示器打游戏或者剪视频，就没那么友好了。毕竟是靠软件算出来的，干不了重活。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekISnF62WLVkqMGiaQgJB27betyIDLTv8Y3icRZib9ssjR6ZhqF5kp5ibd5enFFJdIlnvdY8y5Txudbg8EvJMVxlLJpCMM2Dm7pluQ/640?wx_fmt=png)


而且这卖家卖的是单机，不带电源。这玩意儿是吃外接供电的，我看了一下，如果自己去配个电源的话，大概需要45左右，图省心的话，另一家129元带齐线材和电源，当然若是DIY大佬的话，这笔钱就省下了。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekwlFpGAzK3ANWpdrURYobjhvZpS0oReosJ3pcpf2QGTxMz4PJFBibqkmOGxEp6d3aLN0mpmVyYjCVtBDygmtLOQ5orlhNREQ0U/640?wx_fmt=png)


真要下手的话，我大概率会选那个129元带电源和线材的套餐。因为单买75块的主体，自己配电源不仅麻烦，而且原装45W的电源闲鱼上也要四五十，加起来奔着一百二三去了，还不如直接买齐活省心。而且电源这玩意儿参数不对容易烧设备，咱不想为了省几十块钱冒这个险。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenVDf7m8mnWmAZFSUotsU7pDwOlV8sAg2BiaW6o8BESY6DXgwcZe7lCGzQqTicHVczabJonibfrmibibltt1qEh7n4j8OjYKncG9Uqw/640?wx_fmt=png)


最后问你们一句：要是你手里也有一台吃灰的老笔记本，你会愿意花一百出头给它配个这样的扩展坞，让它再战三年吗？评论区聊聊你的想法。
