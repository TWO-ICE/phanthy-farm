# 中端机大乱斗：小米、一加、真我，谁能称王？

> 原文链接：https://mp.weixin.qq.com/s/NkiV0ficZ8W2CRkNeqf_ew

各位数码爱好者，尤其是追求性能与潮流的年轻朋友们，今年的手机市场可谓是精彩纷呈，竞争异常激烈。就在今天清晨，芯片巨头高通官方放出重磅消息，将在3月18日举行新品发布会，预告将带来“全新骁龙旗舰处理器”。不过别急着把你那崭新的手机换成新机，因为这次发布的并不是大家期待的骁龙8 Gen4……而是传闻中的骁龙8s Gen3和骁龙7+ Gen3处理器。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGYIGGrAx1icpsojp5BXiboqnCwciawWRcoZLFic3z4mEINicv4uN0PgHK4Q8YUalUzLG7xfUjngk3A4yA/640?wx_fmt=png&from=appmsg)


在技术规格上，骁龙8s Gen3采用了与骁龙8 Gen3相同的架构，并基于台积电先进的4nm工艺制程打造。它的CPU配置为1个3.01GHz X4大核+4个2.61GHz A720+3个1.84GHz A520组成，而GPU则是Adreno 735，频率高达900MHz以上。另一方面，高通骁龙7+ Gen3同样采用了骁龙8 Gen3同款架构和工艺，包含1个2.9GHz X4大核+4个2.6GHz A720+3个1.9GHz A520，GPU为Adreno 732，频率也在800MHz以上。如果把这些芯片按综合性能排序，我们可以得到这样一个梯队：骁龙8 Gen3＞骁龙8s Gen3＞骁龙7+ Gen3＞骁龙8 Gen2。可以看出，这两颗芯片的市场定位类似于去年的骁龙7+ Gen2，但性能上有了显著提升，目标市场更加细分。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/D62wUeXp6FDRb3SIibpzbxsWfzgJFjuR5icxAZZWGpqwuMm4Y2acpD5iatScZ2gAJJQoZLVGdtaibqh5dS5szGviacA/640?wx_fmt=jpeg&from=appmsg&wx_co=1)

接下来中高端市场的争夺战将异常激烈。例如，小米Civi 4系列将首发搭载骁龙8s Gen3，直接将性能推向极致。目前该系列两款机型已经入网，其中标准版采用直屏，高配版则采用2.7D等深微曲屏，两者均支持1.5K分辨率，并配备护眼技术。

更令人兴奋的是，它们还将搭载5000万像素主摄，甚至下放徕卡影像技术，并配备了5000mAh以上的超大电池加上百瓦级快充。看来，小米是把华为nova12系列视为直接竞争对手了，而且小米Civi 4的高配版本还被标记为“卫星移动终端”，并将采用金属中框+玻璃机身的设计。

Redmi Note13 Turbo也将搭载骁龙8s Gen3，延续了去年的高性能+高性价比策略，继续采用1.5K无塑料支架直屏+塑料中框+玻璃机身的组合。作为竞争对手的一加，也将推出一加Ace 3V进行抗衡。

预计本月下旬就将与消费者见面。一加Ace 3V将采用高通骁龙7+ Gen3处理器，去年的天玑9000因发热和续航问题受到批评，今年一加显然已经做出了改进。最近有网友曝光了疑似这款手机的工程机谍照，其设计给人一种魅族+三星+索尼的混合感觉，白色（或银色）版的颜值相当高，不过机身可能仍然是塑料中框+玻璃材质。此外，一加Ace 3V还将主打长续航，配备了5500mAh的超大容量电池。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/D62wUeXp6FDRb3SIibpzbxsWfzgJFjuR5L9d5SSxLsOSt8pxtDt1nfaDk25ryiaLJy3a3N06hOZJdciaMstoeDDTg/640?wx_fmt=png&from=appmsg&wx_co=1)

真我GT Neo6自然也不会缺席这场中端机盛宴，而且在芯片选择上更是大胆“全都要”：标准版将使用骁龙7+ Gen3，旗舰版则搭载骁龙8s Gen3。一加和小米看到这样的策略可能会感到困惑。真我GT Neo6系列还将在屏幕上进行升级，不仅取消了塑料支架，还采用了144Hz 1.5K LTPO屏幕，支持自适应刷新率，进一步降低功耗。不久前，真我将潜望长焦的价格降至1599元，现在又打算将LTPO技术带入中端机市场，这种激烈的竞争简直让人目不暇接。同时，真我GT Neo6系列同样搭载了5500mAh大容量电池，配合LTPO技术，续航能力预计将非常出色，而且定价可能会回到1开头的价格区间……


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGYIGGrAx1icpsojp5BXiboqnKMico1aqFibleh0eCA9Zs4znk1N4oHXibR7ZR1iavs1Rib7NmP2pwO8m5ibA/640?wx_fmt=png&from=appmsg)


此外，还有传言称iQOO也将加入战局，在iQOO Z9上采用骁龙7+ Gen3处理器，不过遗憾的是LCD屏幕不再出现。iQOO Neo9 SE则会搭载骁龙8s Gen3。这两款手机都将配备超大电池，意图在所有竞争对手中脱颖而出。说不定价格还会低于1999元呢！总之，今年的中端机市场依然精彩纷呈，好戏连连。面对小米、一加、真我和iQOO等品牌的激烈角逐，大家更期待哪个品牌的表现呢？让我们拭目以待吧！
