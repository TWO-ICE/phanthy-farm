# 无线扩展坞88元就能拿下？没错，联想W123无线扩展坞价格跌至冰点

今天在二手鱼里翻到个有意思的 东西 ，联想W123无线桌面扩展坞WiGigDock，卖家标价88元还带45w原装充电器，原装拆机货，难免有些划痕磕碰，卖家也提前说了介意勿扰。这货可是ThinkPad高端本专属配件，官网标价高达1999元，现在 连零头的价格都不到 ，绝对算得上捡漏价。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekK7rgDpvud1XFA2TAVAucaXianRTEPr6zScKAMrD1op5hz55oeQ8YO2oUwBcalDqvoX1Gnu65rTK7ibC8yGo6VXU5AvRbcibUAp8/640?wx_fmt=png&watermark=1&tp=webp)


先说说核心参数，这扩展坞接口相当齐全，2个USB3.0，1个带供电的USB3.0，2个USB2.0，还有千兆网口，DP和HDMI双视频输出，外加一个耳机麦克风二合一接口。它采用英特尔WiGig技术，60GHz频段，理论速度能到7Gbps，室内10米内都能用，这在 当年 可是相当先进的技术，主打就是无线桌面扩展，不用插一堆线就能让轻薄本变身工作站。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemrQd393QE09fBreqrHEXg8ZHw7cdxaqsJmAibby46cCBNqnyy52EQCN23Pv6cP7FniaJib4rOFoZrVfuNiaRMBA8cTT01O9vtXPVY/640?wx_fmt=png&watermark=1&tp=webp)


不过有个硬门槛，必须是带WiGig模块的笔记本才能用，支持的网卡型号就那几个，AC18265、AC18260、AC17265、W13100，适用机型也集中在特定几代ThinkPad，比如X1 Carbon 4-5代、X1 Yoga 1-2代、Yoga 260、X260/X270、T460/T460s到T490这些老型号。如果你的电脑不在这个列表里，那这东西在你手里就是块带接口的砖头，不懂别碰真不是吓唬人。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCel0ibiaBy7rrJuLCQCXkc25NcLlqmibeZ5URTANCKNYKSCjK3miaPHkpjS5MxbQ3brXDbcuRHwAfwGYNYQEVeZESPpiaVygQb4nGMI0/640?wx_fmt=png&watermark=1&tp=webp)


这扩展坞当年是ThinkPad为了推广轻薄本生态推出的旗舰配件，解决了轻薄本接口少和有线连接麻烦的痛点，只是WiGig技术后来没能普及，被USB-C和雷电接口取代，才慢慢变成了老咕噜棒子。现在二手市场大量流入这类拆机货，价格一路走低，成了垃圾佬和老ThinkPad用户的专属福利。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemytic3Geo4iblFeBzMzL2R7MAwRf597ibeVjSiaCvrJKuibQvNdOvJrhpljWXAUjC4T96dZxYs3wt8VJR919ibON9JNWChQauYjZRl4/640?wx_fmt=png&watermark=1&tp=webp)


对比现在二手鱼里的其他扩展坞，有线的Type-C扩展坞全新也就50-100元，二手更便宜，但大多接口没这么全，而且都得插线。这款的核心优势就是无线，对于适配机型用户来说，不用每次插拔一堆线缆，随手拿起笔记本就能走，放回原位自动连接，这体验在当年可是高端商务本的标志，现在88元就能体验到确实难得。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemW9cDNjibg2zq8EyqjQazFIsovTKMQYnqqxJicPaR40RW2DSAAZZ75sYvIDQ6w58Iia4sibSNFpKoQ2sWDhOkde5tYbbcEZgRUXhE/640?wx_fmt=png&watermark=1&tp=webp)


这个扩展坞 对于适配用户来说性价比极高，要是你刚好有符合条件的老ThinkPad，又想提升桌面整洁度和使用便利性，这波可以冲。但如果你是小白，电脑又不支持WiGig，那还是老实选有线扩展坞，不用瞎折腾了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCek0PAsCUWdv8zG8iayReyJEvuYUo9FT10sID0lnYbbfEUmXFdTHuhzA1rbVszXVfSJnCVrgqhgqd2vDUGSibQHBSaUE5zCssJU0c/640?wx_fmt=png&watermark=1&tp=webp)


另外，如果 不需要那个45w电源， 二手鱼里 最低71元 也 能拿下，这个价格更诱人。但得想清楚，没有电源的话，扩展坞上那个带供电的USB3.0口就没法用，没法给移动硬盘这类设备供电，这点要权衡好。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemibcnOMW6gOMgYic2GsGh1uQayfZ3lbu6oYiaIibIfl9X6WNMiaOv3ONBaCZiaKU48QW1FLb7Doicm61icdJEUrx2sT8icEY7DjRmicPhaE/640?wx_fmt=png&watermark=1&tp=webp)
