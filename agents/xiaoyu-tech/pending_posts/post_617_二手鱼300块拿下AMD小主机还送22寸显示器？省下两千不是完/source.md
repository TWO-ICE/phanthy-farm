# 二手鱼300块拿下AMD小主机还送22寸显示器？省下两千不是梦

![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEYR4GuAkbn0rXjt80NqrRVdV7yXibIVwT1eNkzpUnDRA2nMRIK4m2iaKLZvtXWaRicT1lbdzm2e5XhQ/640?wx_fmt=png)


今天在二手鱼发现一台卖家自己DIY的主机，而且还连显示器一起卖，要价300块，但是需要自提，我看了一下，配置还行。卖家写的是AMD A8-8600P四核处理器，没睿频，配了8G内存和128G固态硬盘，还带双频WiFi和两个小喇叭。整套东西体积不大，说是适合办公、看视频、玩点小游戏，放客厅接电视也挺合适。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEYR4GuAkbn0rXjt80NqrRVpduibI8kh5ibwm92OsQul0nPH9CYTzWFq0CsvHlKSYWIKNWsRDfiaQ5nA/640?wx_fmt=png)


这颗A8-8600P其实是好几年前的老U了，功耗很低，性能放在今天只能说勉强够用。日常开个浏览器、处理文档、看个高清视频基本没问题，但要是想跑点稍微吃资源的软件，比如视频剪辑或者大型办公套件，估计会有点卡。不过对于纯粹用来刷网页、看剧、给孩子上网课的家庭用户来说，倒不至于完全不能用。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEYR4GuAkbn0rXjt80NqrRVVYgibAwlaENGKyWmIxXwuSH51uMoKG8ibIth26iaepM310fef9Pl6kJNw/640?wx_fmt=png)


128G的固态现在确实有点小，装完系统可能就剩六七十G可用空间。如果打算装一堆软件或者存点本地电影，很快就会告急。好在它支持加装硬盘，自己动手的话成本也不高。8G内存算是这台机子的亮点之一，比很多同价位洋垃圾主机常见的4G强不少，至少多开几个网页不会立马卡死。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEYR4GuAkbn0rXjt80NqrRVfz0LvoWfX5pH0HN28KsvCbvdpyJn5Hia3RUAGsflc4pn34bu4r7ibliag/640?wx_fmt=png)


可能有人会问，这配置能刷飞牛吗？能是能但体验一般。飞牛这类轻量级系统对硬件要求不高，A8配8G内存跑起来不算吃力，做软路由或简易NAS勉强可以，但别指望它扛住多人高负载访问。另外，双频WiFi在老机器里算加分项，省了额外买USB网卡的麻烦。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEYR4GuAkbn0rXjt80NqrRV9kBfByDzqGuelGicia02ia7QQ1WdBJIE30FbxGbeHABvE4p90L0wRfC8g/640?wx_fmt=png)


那么问题来了，300块值不值？目前市面上全新入门级迷你主机都要五六百起步，还未必送显示器。22寸显示器单独买二手也得一两百，这么看整套打包300元似乎不算离谱。但要注意，A8平台已经彻底淘汰，驱动和兼容性后续可能没人维护，万一出问题修起来也麻烦，唯一遗憾的是卖家要求自提，不过这也并不是不可商量的，可以和卖家商讨一下自付邮费。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEYR4GuAkbn0rXjt80NqrRVia5Oy5jITBuibC22wweFSkQNC8XQ4BFUnVbltlmX5P082xUxhPAJCylw/640?wx_fmt=png)


如果你只是临时需要一台备用机，或者给老人孩子弄个看视频的设备，这套组合确实能省事省钱。但要是对流畅度、存储空间或未来扩展有要求，那大概率会后悔。尤其现在固态价格涨了不少，128G实在有点抠搜。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEYR4GuAkbn0rXjt80NqrRVEJrV2d5WwYictjeWDR1TBEOCrnf3mH8iarBX5Fuuxdl7ueB1GR84jOAw/640?wx_fmt=png)


对此产品有兴趣的话，可以在二手鱼搜索“迷你主机加22显示器”这个关键字就可以找到此产品，如果找不到可以通过图片进行搜索，都搜索不到的话，那可能是此产品已卖出或者是下架了。


 


以下是个人一些掺了水的建议：  

1. 用途明确再下手，别图便宜买回去吃灰  

2. 自提前最好现场开机测试，确认能进系统  

3. 留意电源是否原装，二手电源隐患不小  

4. 看完不买，立省300元
