# 轻量化与客制化的组合—雷柏最强续航无线键鼠套装实测

![封面图](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXHbicbvAicuQlbvoJKmFHP5CsfZNqDpxLzu6cWz7fu6icp9Fbs6e936SZQQwI6nU6QeUshyK7eo2GAicg/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/wDwRFYfB-RZlwWHI7lXnxA

每天坐到电脑前，你有没有想过：手里的键鼠到底是在帮你，还是在拖后腿？线缆缠绕、电量焦虑、延迟卡顿、手感不适……这些看似微小的摩擦点，其实在悄悄消耗你的专注力和操作节奏。尤其当你正处在一局关键对战，或是深夜赶稿的紧要关头，一套真正“无感”的外设，往往比参数表上的数字更重要。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXHbicbvAicuQlbvoJKmFHP5CsBw8pPKN1MMPcj5q3K4pQQBXAEn7LkfSQ5lRwnZleftGdF8o6tAwCOQ/640?wx_fmt=jpeg&from=appmsg)


雷柏这次推出的 VT9 MAX 与 V700DIY-98 长续航版最强续航无线键鼠套装，试图用一套完整的无线解决方案，把那些日常使用中的“小麻烦”一一抹平。它不靠炫技堆料博眼球，而是从握持的弧度、按键的回弹、连接的稳定性，甚至电量提示的方式这些细节入手，让工具真正退居幕后，让你只管操作，剩下的交给它。此外，统一A Hub驱动，实现键盘鼠标的深度个性化联代设置，给你更多的DIY空间。


产品开箱：细节里的诚意


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXHbicbvAicuQlbvoJKmFHP5CsDfdfSbb0NuGR48mtiaHEElNE2zc4m6DWkYBHicXKcIKMRmgHCPQIiaWsw/640?wx_fmt=jpeg&from=appmsg)


我手中的这款VT9 MAX鼠标是紫色的款式，官方命名为“电驭紫”，外包装延续了雷柏电竞系列的风格，翻开后第一眼看到的就是这只名为“电驭紫”的鼠标本体。这个紫色非常亮眼，也让鼠标有着很高的辨识度，而且在光线下也不会显得艳俗，属于耐看型。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXHbicbvAicuQlbvoJKmFHP5CsGy8KGk5dpI4FpbPjIJMK4lRCoZlkuVkw6GvKeGf7aobzh8TTOtDrtw/640?wx_fmt=jpeg&from=appmsg)


VT9 MAX是一款右手对称鼠标，第一感觉是修身。相比前代，它的腰线收得更紧，对于中大手的抓握非常友好。拇指和小指摆放的侧裙区域做了内凹处理，并覆盖了亲肤防滑涂层，防滑效果不错，汗手玩家友好。左右主按键的凹槽弧线引导明确，手指放上去很自然。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXHbicbvAicuQlbvoJKmFHP5CsxEEfyd0FywiaaeXXfFY6uUjibh7Bh6X7E1TUNd25IMzJmFRw2bAE5bEw/640?wx_fmt=jpeg&from=appmsg)


翻过来，最大的亮点是约53克的重量，上手非常轻。特氟龙脚贴面积很大，标称含量很高，后续在垫子上滑动应该会很顺。底部除了开关和DIY按键，还有一个模块化接口，用来扩展无线充电或触点充电底座。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXHbicbvAicuQlbvoJKmFHP5CsoPxWEicj7Lw8RRzDE0PJKWHtHQSS8uGCDAgw3FKAFxib65GibmPrzMnbQ/640?wx_fmt=jpeg&from=appmsg)


在性能方面也有着很多亮眼的地方，全球首发的Nordic 54系列芯片，原相3950 Ultimate定制传感器、DPI精细调、玻璃桌面照常跑、原生双8K回报率+8K按键扫描率，响应快到指哪打哪。而且VT9 MAX可不是“一招鲜”的鼠标，它还内置了六种性能模式，从职业电竞到日常摸鱼全覆盖。打游戏时切到狂暴竞技模式，8K回报率+2万帧扫描全开，响应快到离谱；排位累了换均衡模式，性能和续航平衡；办公时直接切办公模式，功耗拉低，1K回报率下续航直接飙到750小时。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXHbicbvAicuQlbvoJKmFHP5CsnAFviaoLdfDrJDI1r9NQCU5VYdjLCA5RLricOicpEiaDycR6ricuzxFg6icA/640?wx_fmt=jpeg&from=appmsg)


配件考虑得也相当周全，除了8K数据线和黑色防滑贴纸，还附送了高纯度铁氟龙材质的备用脚贴，能明显提升滑动的顺滑感。而鼠标的接收器更是升级为带有指示灯的nano 8K款，支持电量显示和DPI挡位显示，唯一的小遗憾是无线充电底座需另购，若能标配体验会更完整。


V700DIY-98长续航版键盘：实用主义的客制化


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXHbicbvAicuQlbvoJKmFHP5Cs0hyzICSJ1x27L61rptrKYa1h0aqWSX9JsEr9A5gC8bJgCVGCZh4vdw/640?wx_fmt=jpeg&from=appmsg)


这款键盘官方的命名是“初号骑士”，黑灰绿的键帽拼色方案很醒目，有种工业风与活力混搭的感觉，辨识度很高。整体布局采用98%配列，保留了数字小键盘和方向键，但比全尺寸键盘短了一截，给鼠标挪出了更多操作空间，是桌面空间优化党的好选择。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXHbicbvAicuQlbvoJKmFHP5Cscy87M5MybBkVBZ7j7NLTgz66RuJICibx7q5hribkZdeJxrv4jGmMbjFA/640?wx_fmt=jpeg&from=appmsg)


轴体搭载的是凯华定制的弹白轴，线性手感。按压下去感觉顺滑跟手，触发力度适中，回弹也挺跟手，属于兼顾游戏和长时间打字的类型。大键位调校得不错，没有明显的钢丝音。全键支持热插拔，轴座兼容性广，后期折腾的余地很大。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXHbicbvAicuQlbvoJKmFHP5CsJB1uINyj4YYSAo6DQRyGSadlz4w03d98B8FThyqibz2ictQzFYUtA0Cg/640?wx_fmt=jpeg&from=appmsg)


键盘背部采用了Gasket结构和浅绿的配色，键盘内部拥有7层消音填充，让按键触感有一定的软弹度，敲击声音也比较集中纯粹，没有空腔音。同时键盘内置10000mAh的电池，出厂模式下开启RGB灯效可以续航约160–180小时，关闭灯效的话续航可达1700小时，连续多个月不用充电，这一点还是非常友好的。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXHbicbvAicuQlbvoJKmFHP5CseQHAxgicskHpKpucGia8Noib8JZWnEmUicW5icMGARb4eGUGyacGYRBO2sg/640?wx_fmt=jpeg&from=appmsg)


另外我还发现一个细节，背面两段式脚撑有三种高度可调，这样可以让键盘适配多种不同的使用习惯，同时在背部的左右边缘处还设计了两个灯条，开启后会让键盘的灯效更具美感。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXHbicbvAicuQlbvoJKmFHP5Cs7QIQsyFIJOABEXB8Xd0rlYq8plWEJ09rdss1unet0ahLjcHbYXob9A/640?wx_fmt=jpeg&from=appmsg)


正面RGB灯效设计的也很有特色，灯光亮度适中，字符透光清晰。右上角的“时空幻境仓”是个巧妙设计，磁吸盖下既是2.4G接收器收纳仓，前面的灯带还能根据颜色提示键盘剩余电量，解决了无线键盘电量“盲猜”的尴尬。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXHbicbvAicuQlbvoJKmFHP5CsdUd9ichSRt55zpgulGXuMGpXwpyic0KFHXc1ABrHXIw9d0Xiap60qeMOA/640?wx_fmt=jpeg&from=appmsg)


键盘的开关和有线接口位于键盘左侧，通过波动按钮开始实现在蓝牙5.0、2.4G和有线之间快速切换，蓝牙模式最多连接5台设备。而在使用有线模式时，需先把开关波到中间，之后连接线缆，就可以正常使用或者是为键盘进行充电了。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXHbicbvAicuQlbvoJKmFHP5Csw0c6oK7HFmRlXwhiakHRkENibZVnib1UvkO2WgALpK8OjRicapTnj99uJg/640?wx_fmt=jpeg&from=appmsg)


从开箱的初步印象来看，这套键鼠套装的目标非常明确：为追求无线自由、在意续航，且手掌尺寸偏中小型的电竞玩家，尤其对FPS玩家更为友好。鼠标的轻量化和修身模具，明显是为抓握和指握优化；键盘的紧凑布局、长续航和客制化潜力，则满足了实用党和爱折腾玩家的双重需求。性能参数纸面很强，但实际如何，我们往下拆解和体验。


CF游戏体验：轻如无物，快如闪电


![图片](https://mmbiz.qpic.cn/mmbiz_gif/afNLf2a8eXHbicbvAicuQlbvoJKmFHP5CsysMYY0QC7iaUWr0f9fh2Tb8bibyjlsDSoFysryERkOiaw557ZNDJTlRcw/640?wx_fmt=gif&from=appmsg)


打《穿越火线》时，VT9 MAX这53克的超轻手感真成了我手的延伸。急停瞬间稳如磐石，甩枪拉枪几乎零延迟——原相3950传感器在2400DPI下指哪打哪。侧腰内凹设计让拇指牢牢卡住，快速提拉不打滑；炎龙加持跟手王，“8828”电竞鼠标跟手丝滑新标准，原生8K回报率下+8K按键扫描率开火响应快得离谱，对面刚露头，我枪已经响了。旁边V700DIY-98长续航版键盘安静陪衬，弹白轴轻触即发，WASD移动跟手不拖沓，配合默契得像老搭档。


![图片](https://mmbiz.qpic.cn/mmbiz_gif/afNLf2a8eXHbicbvAicuQlbvoJKmFHP5CsPMA25CXSqmGndicg5arNBYwpoCK4bpF7jKSuVibH6NGpXlcPwlRdqbvQ/640?wx_fmt=gif&from=appmsg)


键盘在这场对决里也没掉链子。V700DIY-98长续航版用的弹白轴，1.5mm触发行程刚刚好，不轻飘也不肉，蹲跳、切枪、扔闪雷一套操作跟手又利落，全键无冲让组合键同时按下去也丝毫不打架。98%配列省了点空间，却给鼠标留出大片“战场”，右手滑动毫无局促感，手腕微动，就能立马跟上节奏，丝滑衔接，一点不卡顿。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXHbicbvAicuQlbvoJKmFHP5CsMDvKVYqia3ew5XXBw8ZQK1Viam034rVx0Kolnsxxo2apkGs6LfCGOVJA/640?wx_fmt=jpeg&from=appmsg)


这套键鼠组合在《穿越火线》里的表现还是很不错的。当然，如果你玩的是《CS2》《无畏契约》或者是《三角洲行动》这类FPS游戏也同样适配。这其中VT9 MAX鼠标的高回报率、低延迟和稳定追踪，配上V700DIY-98长续航版键盘的快速触发与可靠输入，构成了“快、准、稳”的底层体验。它不靠花哨噱头，而是用扎实的无线性能和人体工学设计，让每一次开镜、压枪、走位都更从容。对FPS玩家来说，这是一套真正能打又能扛的高性价比装备。


A Hub：一套驱动，全盘掌控


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHbicbvAicuQlbvoJKmFHP5Cso40elY0YSMDXptfoCd4oGHZC3RHOOOLkd9icqicGqbmxjUr9NO1le9cw/640?wx_fmt=png&from=appmsg)


雷柏这套键鼠最大的隐藏彩蛋，其实是那个叫 A Hub 的驱动软件。以前键盘一个软件、鼠标一个软件，调设置像在打游击；现在装一个 A Hub，键盘灯光、鼠标 DPI、宏命令、固件升级全在一个界面里搞定。


![图片](https://mmbiz.qpic.cn/mmbiz_gif/afNLf2a8eXHbicbvAicuQlbvoJKmFHP5Css1wsib8NrAiaMxp08JicBhVFichvwrqpmhl31th2eU2tDQz8yIkmxLZlog/640?wx_fmt=gif&from=appmsg)


更爽的是，它支持配置文件随应用自动切换，比如我一开《穿越火线》，鼠标自动切到8K回报率+狂暴模式，键盘宏也加载好投掷物快捷键；关掉游戏切回办公，立马降回低功耗模式。不用手动调，省心又高效。


![图片](https://mmbiz.qpic.cn/mmbiz_gif/afNLf2a8eXHbicbvAicuQlbvoJKmFHP5CsZbNIh5ZX4bribftQ95ibK8xWFHrbhwHAxG1nePVoDdkmAR1o5yZfBDng/640?wx_fmt=gif&from=appmsg)


A Hub 不光好用，还特别耐造。它同时兼容 Windows、macOS 甚至网页端，换系统也不怕配置白搭。而且雷柏真敢开放 OTA 固件升级，VT9 MAX 的“炎龙”性能模式、按键扫描率调节这些高级功能，都是后期通过驱动推出来的。这意味着你今天买的键鼠，半年后还能通过软件“变强”。键盘和鼠标在 A Hub 里深度联动，真正做到了“1+1＞2”，不是简单配对，而是生态协同。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXHbicbvAicuQlbvoJKmFHP5CsJzQicuQRyqMIYExVIGZayMGMwbNibmTo1pKyia0CuJHbApYKnn0HFvStg/640?wx_fmt=jpeg&from=appmsg)


通过以上的体验，感觉这套无线键鼠并没有靠堆参数博眼球，而是精准抓住了办公党+FPS玩家的核心痛点：要无线自由，不要续航焦虑；要跟手性能，不要复杂折腾。53克轻鼠+1700小时长续航键盘，配合自研V+Wireless 2.0和A Hub统一驱动，实现了低延迟、高稳定、易切换的真实体验。无论是《穿越火线》里的快节奏刚枪，还是日常多设备高效办公，它都能稳稳接住。500元出头的价位，做到这种完成度，确实值得放进你的外设清单。
