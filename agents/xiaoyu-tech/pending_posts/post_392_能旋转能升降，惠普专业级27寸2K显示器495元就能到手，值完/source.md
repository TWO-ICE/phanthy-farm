# 能旋转能升降，惠普专业级27寸2K显示器495元就能到手，值得买吗?

刷二手鱼的时候，看到个卖495块的惠普E273q，27寸2K IPS屏，感觉性价比还行，唯一的缺陷是不支持144Hz，因为不是电竞款，所以刷新了只有60Hz，但正常使用毫无问题，有兴趣的可以研究一下。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemYkRQ7p2mXwhLhxpTEmA9N4mPyw9KAWUUo22WDNbSib7CR0eEzrMb1RlQZHNDX43aGzChG5CrVrrE1kpIDhyiaQoNy2C7VL0uEY/640?wx_fmt=png&from=appmsg)


这台显示器是惠普的EliteDisplay系列，曾经的专业商用，主打的是稳定、色彩准、接口全 。27寸2K分辨率，2560x1440，放在现在依然是办公、作图的甜点尺寸。IPS面板，可视角度和色彩表现比那些低端TN屏强太多了 。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCek8UicUzFPTVSnXJdCSyK4dAvK8hY2MjqNweNobyrzjQacwxQnSDkY4hhQa9Y2cIoo9w19kzSQQIqUtevTHF9tDtOK5bC5P247w/640?wx_fmt=png&from=appmsg)


关键是接口。卖家说支持VGA、HDMI、DP，还有Type-C 。Type-C这东西在二手显示器里就是加分项，直接连笔记本能充电能传画面，省一个扩展坞的钱。对于用轻薄本或者MacBook的朋友来说，这就很实用了。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCek5rs2bbSqYxNWO6pVBkicNwk4kZx6qW25zBGp8u551pJxdXcaFvlAFVc4xa8M5rblvQVgB2kQZWomYlsnBo6MymkpzDbzUyJic0/640?wx_fmt=png&from=appmsg)


60Hz刷新率，这是它争议最大的地方。玩FPS游戏的可能会嫌弃，毕竟现在高刷屏遍地走。我查了下，真正一线品牌、27寸、2K、IPS、带Type-C，把这几个条件往上一摆，495块这个价格，能选的其实没几个 。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemvgaDHo55AorP3Bd7z9kylDK6chlWtezXqd6rzU4picPMGz7qJmoiczBypxrIF3D4zL9nMEBg3hxOENqPc6XCc0q98lqvibmWzcQ/640?wx_fmt=png&from=appmsg)


如果你就是日常办公、写代码、修图、剪视频，那60Hz完全够用。甚至做设计的话，IPS屏的色彩准确度比那些所谓的“电竞高刷”重要多了 。如果用来做副屏，Type-C一线连的便利性也是实打实的，并且这还是一款支持升降+旋转的显示器，用起来非常爽。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCen5H1MKQu4FGUBV0TBxKMNQEiaxEiaEpJz5t7YEDhqnSHnImqK0sQESN2VnedteJ2bPowzNcza73U5J1ibEUpgslMmq0IKnnP7NeY/640?wx_fmt=png&from=appmsg)


卖家描述里写得很实在，功能完好无维修，轻微使用痕迹。底座线材都在，外地发货会打包严实还保价，发货前拍视频确认。这种卖法在二手鱼里算靠谱了，至少人家把丑话说前面，不是那种伊拉克成色糊弄人的。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemXpa2jq6V18n87ibyYDZ424MqfqhlOZkibovQuIJpL2Y4Ky9q78RMC23Z9jDH4P9F0omTo75nSXr1UnaByrlXWvcpAdSxp2Sq4Y/640?wx_fmt=png&from=appmsg)


如果你想出手的话，可以参考以下两点建议，一是接口。这个卖家说功能完好，但Type-C接口的供电和数据传输最好收货时马上测一下，这是最容易出问题的环节。二是屏幕老化。IPS屏用久了可能有轻微泛黄，纯白背景下留意一下。卖家既然支持发货前视频确认，那就让他点亮屏幕给你看，别怕麻烦。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekSmibPblSAq7OnHllpEbHicl5YaHQs22qfk3qNTHUn8y4v050VryFX5THt9klvOFPyNgaeO0Vmgw74Bx9iaN74BaiaN2hicS7Uw8Zg/640?wx_fmt=png&from=appmsg)
