# 158元能买到23寸屏的联想一体机？网友：拆机卖配件瞬间回本

这几天我在二手鱼里闲逛，看到一台型号是B50r1的联想一体机，这玩意是23寸的屏幕，没想到卖家只挂了158块，一体机是2011年5月产的，绝对的老咕噜棒子。但仔细看看配置，又觉得有点意思。唯一遗憾的是仅限自提，可惜我不是保定涞水县的，不然绝对拿下，因为拆机卖绝对都能回本。

配置是Pentium双核E6600的处理器，原装2G内存，卖家给升到了4G，还加了块120G的固态硬盘，它还带一张AMD Radeon HD 5450的独立显卡，虽然是亮机卡，但比集成显卡还是强点，看个高清视频、玩玩老2D游戏，问题不大。

23寸的大屏，放在当年可是一体机里的巨幕了，现在拿回家看个剧，也比抱着个14寸笔记本舒服。我特意查了一下，它的音响居然是JBL的，这点在当年可是联想高端机的卖点。而且光驱、摄像头、键鼠全套都是标配，拿回家插上电，理论上就能直接开机，系统还是情怀满满的Win7。

说实话158元的配置根本就不用奢望太多，连个好点的飞牛圣体都买不来，但现在却能买到一台23寸的一体机，这价格就是扔沟里的价格，摔了、坏了，都不心疼。它的价值在哪？我给你们分析分析。

第一，作为一台纯粹的上网机，给家里老人小孩的专用视频机。刷刷短视频，聊聊微信，给孩子上个网课，它完全能胜任。4G内存配固态，开机速度也不会太慢。

第二，它的残值非常高。23寸的屏幕、那块带JBL音响的主板、甚至DVD刻录机，随便拆开单卖配件，这158块钱的成本也早就回来了。如果你懂点电脑，甚至可以把它改造成一台家用监控服务器或者怀旧游戏模拟器。

不过，也得给想捡漏的老铁们提个醒，这种老机器有几个坑千万别踩。一个是千万别指望它干重活，网页也别开太多，会卡。还有就是电源适配器和内部电容都是十多年前的老家伙了，如果动手能力不强，买回来听个响就行，别拿去干大事。最后要说的是，卖家在保定涞水县，只支持自提，异地的小伙伴就别想了，这大块头有20斤重，运费都快赶上机器钱了。

那么问题来了，如果这机器在你家附近自提，你会不会花这一百多块钱，把它带回家折腾一番？咱们评论区里聊聊。
