# 二手鱼刷到了90块的华为升腾C92迷你主机，这玩意儿刷个飞牛当NAS不香吗？

今天在二手鱼刷到了一台标价90元的华为升腾C92瘦客户机。等等，华为出过这种小主机？后来一查，原来是升腾（Sugon）品牌，和华为没关系，纯属名字撞车。不过这台小方盒子确实挺有意思，配置不高不低，价格更是白菜得离谱，浏览量16万，2697人想要，看来不是我一个人在盯着它。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHBaYJ2ZuVRHxoSq8bqkUYiaeFZX87npPdiaNvA0jTGzzricKECLnibUj1PM3h99yyxANhPsrDylU1HWg/640?wx_fmt=png)


这台C92的配置单看着有点复古：Intel J1800双核CPU，主频2.41GHz，DDR3L内存可选2~8GB，MSATA硬盘从8GB到64GB不等。接口方面倒是挺全：1个USB 3.0、5个USB 2.0、一个Intel千兆网口，视频输出是DVI+DP组合。整机尺寸131.5×167.5×32mm，重量525克，功耗实测5W左右，BIOS没锁，支持U盘启动（开机按F12），还能来电自启——这些细节对折腾党来说，简直是送分题。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHBaYJ2ZuVRHxoSq8bqkUYiaemBt5rNBSibSy85jdvF6XbRvJHGF1CGPEiaAk4Jh2geCgl6TwfhEBoiaQ/640?wx_fmt=png)


卖家还贴心列出了各种配件加价项：要mini-PCIe插槽+5元，原装电源+15元，底座+3元，DVI转VGA或HDMI各+5元。默认装的是Win7系统，但也可以帮忙预装iKuai、OpenWrt、iStoreOS甚至飞牛NAS系统。成色8-9新，整机签收后质保90天，运费6元起，不包邮。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHBaYJ2ZuVRHxoSq8bqkUYiaLMDYUFTbiaTxRpSsepYekicR25YNvCN2Zq0tOTMpdq2H5fWqCtNicxrKQ/640?wx_fmt=png)


乍一看，这价格简直离谱，90块买台能跑系统的电脑主机？但冷静下来想想，J1800可是2013年的老U了，性能大概相当于现在低端手机芯片的水平。日常办公就不用像了，最多也就能当NAS用，但别指望多快。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHBaYJ2ZuVRHxoSq8bqkUYia2vKx2454IMAVV1Cqic1G1wIiaV3M9BcctVlcOUnOgjOJRTaWlbrWl9SQ/640?wx_fmt=png)


不过话说回来，如果你只是想搭个轻量级软路由、下载机、或者给老人小孩弄个上网专用机，这玩意儿的性价比其实“可接受”。尤其现在不少NAS系统对硬件要求极低，尤其是当前爆火的飞牛这些都能跑起来，功耗又低，放家里24小时开着电费几乎忽略不计。而且BIOS无锁、支持自启、接口够多，扩展性虽然有限，但基础需求都能覆盖。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHBaYJ2ZuVRHxoSq8bqkUYiak2GUVqWibib0MShC1JByOYWdLN6IYekIYdksLLQeSVkAL7BKwfSZmPpQ/640?wx_fmt=png)


那么问题来了，90块不含电源内存硬盘，加起来都快150了。没错，整套配齐大概150-200元。但你要知道，全新入门迷你主机起步价基本300+，而C92的优势在于功耗极低、接口丰富、系统自由度高。它不是性能选手，而是“工具型选手”——就像你不会拿螺丝刀切菜，但修眼镜时它就是神器。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHBaYJ2ZuVRHxoSq8bqkUYiaO4S2LdvVfaVAY8ibG4Uo21an44aNNm1jH1icVuia5fgz2PTBRBiaPPUxng/640?wx_fmt=png)


再理性点说，这台机器的价格优势，只对特定人群成立：比如喜欢DIY的极客、预算极其有限的学生党、或者只想搭个低功耗服务节点的家庭用户。如果你期待它能流畅剪视频、打游戏、甚至多开网页，那真不如把钱省下来买杯奶茶——至少喝完心情好。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHBaYJ2ZuVRHxoSq8bqkUYia8GIt9h41SLb4Dvtic2LkJPqVRClTcI5QtjbwplPESjahLicLzykZTtbw/640?wx_fmt=png)


以下是个人一些掺了水的建议：

1. 别指望它当主力机，但当“数字劳工”很称职。

2. 务必确认卖家提供实拍图和通电视频。

3. 内存至少上4G，硬盘建议外接USB SSD。

4. 看完不买，立省198元。
