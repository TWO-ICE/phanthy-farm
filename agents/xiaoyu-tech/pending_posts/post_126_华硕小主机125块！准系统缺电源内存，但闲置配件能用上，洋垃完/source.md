# 华硕小主机125块！准系统缺电源内存，但闲置配件能用上，洋垃圾冲不冲？

![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXF5I2KYqibKsicZ51RJtz385f2wyPPry8NREeQ8LyZTpR4vTACjgYHSyb2B55KibyhIyeiaqluEVvLMIg/640?wx_fmt=png)


前阵子刷到有人吐槽 “300 多块的飞牛嫌贵，200 多还问能不能再砍”，我当时还跟着乐：现在大家买东西是真会算账！结果昨天刷闲鱼，直接刷到个更离谱的 ——100多块的华硕小主机！家人们，我当时手里的奶茶都停了，就想问句：阁下看到这价格，又作何感想？


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXF5I2KYqibKsicZ51RJtz385f6qcVeYvl3Ygg1uOb63U3KEWFmzic1Iqqeg1kSezfH8Iba5eU6uWw96Q/640?wx_fmt=png)


先把话说清楚，这机器型号是华硕 CN60 2955U，闲鱼二手价特实在：125块是准系统，啥意思？就是没电源、没内存、没硬盘，纯一个 “空壳子”；要是嫌麻烦，也有 225块的套餐，含电源、8G 内存加 128G M.2 固态。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXF5I2KYqibKsicZ51RJtz385fl7lM8UhaHicJZhIsspYWwFDAXGcq8ojKpAHd3kn0DhoKZSermUZTBAQ/640?wx_fmt=png)


但听我一句劝，感兴趣的小伙伴直接冲准系统就行！谁家里抽屉没躺着几根闲置的内存条、几块旧硬盘啊？我家电视柜抽屉里还塞着当年换电脑剩下的 4G 内存和 64G 固态呢，拿出来插上就能用，何必多花那百十来块买套餐？这不纯纯给商家送钱嘛！


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXF5I2KYqibKsicZ51RJtz385fJxyytVzOehfSKHuJZxmnw8mwx4mXWcc7fJygWDCLt9VicBW8jAIjRjQ/640?wx_fmt=png)


不过先说好，这机器跟之前那些 “洋垃圾 chromebook” 是一个路子 —— 全是漂洋过海来的进口货，说难听点就是 “洋垃圾”。但有一说一，颜值倒还行，方方正正的小方块，摆桌面不占地方，比那些杂牌小主机看着规整。原来出厂装的是 Chrome OS（就是谷歌那操作系统），后来有人琢磨出刷 “兔子 bios”，刷完就能装飞牛 OS 了。我当时还搜了搜教程，看着不算难，就是得耐点心，毕竟折腾 “洋垃圾” 嘛，不就是图个动手的乐子？


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXF5I2KYqibKsicZ51RJtz385f0N1OHVialRS5cE3UXLblXhraUouKHvRNdP4HZgfBkezsGibbn1bX3wiaQ/640?wx_fmt=png)


再说说配置，搭载的是英特尔 2955U 处理器，听着挺唬人，其实是个 “老将” 了。我特意查了下参数，22nm 制程的 Haswell 架构，双核双线程 —— 现在随便一个入门级处理器都四核起步了，这配置放现在，真不是我夸张，狗看了都摇头！基础主频才 1.4GHz，还不支持睿频加速，性能上限摆在那儿，别指望它能跑大程序，顶多就是 “稳”，不会忽快忽慢。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXF5I2KYqibKsicZ51RJtz385fN7u59BgaCsbcqxeBNJ04tvJo5NicZRdv4koAtEgxx5NvxKN7UWT02jA/640?wx_fmt=png)


但优点也不是没有：TDP 功耗才 10W，属于低功耗系列，平时用着不费电，放家里当备用机不心疼；还兼容 DDR3L 内存，最高支持 1600MHz 频率，正好我那闲置内存就是这规格，完美适配。核显是 Intel HD Graphics，动态频率 200MHz 到 1GHz，日常开个 Word、Excel，或者用浏览器刷网页、看个 1080P 视频，完全够用，要是想玩游戏？还是算了吧，连小游戏都费劲。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXF5I2KYqibKsicZ51RJtz385fYmn7vyDkCGYSib5aUnjiaMlo3GTKwbxQ9jsv4xqULtaLYicrD52vicziajw/640?wx_fmt=png)


接口方面倒挺良心，毕竟是华硕出品，比那些三四线小厂靠谱多了。内置 WiFi6，连无线比老款快不少；千兆网口也安排上了，插网线更稳定；还支持 HDMI+DP 双视频输出，想接双屏办公也没问题；4 个 USB3.0 接口，插个鼠标、键盘、U 盘，完全够用，不用再额外买集线器。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXF5I2KYqibKsicZ51RJtz385fRaqia5IQdUg2BXQr1hCdgVJDTwZwjeGVoKgaKE7EQxcVd3yweEtKQicg/640?wx_fmt=png)


但有个槽点我必须吐：这机器居然不支持 2.5 英寸硬盘！只能插一块 M.2（NGFF）2242 硬盘，要是想存更多东西，要么用 USB 接移动硬盘，要么花钱买硬盘柜，多出来的成本算下来，也没比买新主机省多少。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXF5I2KYqibKsicZ51RJtz385f3CoQJ4ibvIhT9s3qdzlGRC40NUXG77g5Ujxsp8dYibeFwCiaHUQREQOlg/640?wx_fmt=png)


对了，类似的机器还有戴尔 Z01V 2955U，配置大差不差，无非就是换了个品牌 logo，价格也没差多少。这种 “洋垃圾” 小主机，对老玩家来说真不够看 —— 毕竟谁手里没几台能折腾的机器？但对刚入坑的小白来说，125块钱就能体验一把 NAS 的魅力，折腾坏了也不心疼，倒也算个不错的入门选择。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXF5I2KYqibKsicZ51RJtz385f86u3lb5kyVZ9jnwY4ZDBWjkYr9zicIadDtK2QslYItnibiajycVbMhGag/640?wx_fmt=png)


看到这里你觉得要不要冲？毕竟125块钱真不贵，折腾好了能当办公备用机，折腾坏了也不心疼。但一想到它是 “洋垃圾”，又怕用不了多久就出问题。家人们，你们觉得这125块的华硕小主机值得冲吗？要是你们，会选准系统还是套餐？评论区来唠唠！
