# 性价比贼高，400多的矿卡能对标RX5700？我在考虑要不要赌一把？

现在随便一张能跑4K 120Hz的正经显卡，即使是二手没个千把块根本拿不下。但相比之下，矿卡就便宜得多了，我就刷到一张魔改的AMD BC160显卡，卖家虽然没说，但基本上都是计算卡，也就是矿卡，466元包邮到家，性能对标RX5700。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelpOJLvpGB7KicQBjicFZfkWia62txjM1xsia9MfricNn5Mo8ooxIodKz7k5ia0MtJe6iaBFeVUu12piadurhnQEU1sqFQDp1ibjpkAnPz4/640?wx_fmt=png)


BC160卡同样是8G显存，据说鲁大妈能跑分30多万分，跟RX5700掰手腕没问题。显存带宽是它亲爹，比5700还猛，高分辨率下有奇效。最关键的是，它真能带4K 120Hz显示器，前提是得打上RID的25.3.1驱动，但苹果的不行。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenibT2QM5oFk5vauhIiboIYMKnMp3QPtJ2gsUiaBYP1fm3CEDmXeiaxrI55aJhoF4s8PJ30Y9IsKxc9TDCRFhBgvApOWnMSgusEL2E/640?wx_fmt=png)


这卡本质是矿卡，没有官方保修，驱动得自己折腾特定版本，而且接口都是DIY的minidp接口，需要使用特定的转接线。卖家说原厂无拆无修，成色超级新，但这毕竟是计算卡改民用，稳定性存疑？另外，它主打的是4K高刷显示输出，游戏性能就是5700水平，与3060Ti还有些差距。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekJDQiaJibIWGSls9hvFh15JEjvPibvUS6iaLo96DQAdko0ia4yIflpkMqjXY4JibQib7Z4xZo0kn0pVa3OfSZiaaKCpq6SgolPMJS9q78/640?wx_fmt=png)


那么466元到底值不值得捡？我的看法是，如果你是喜欢折腾的垃圾佬，手头有闲置电源，愿意花时间研究驱动，这卡性价比炸裂。同价位你在二手鱼只能买到RX580 8G或者GTX1060 6G，性能被它甩一条街。但如果你是小白，只想插上就用，千万别碰。买回去点不亮或者闪屏，你连怎么骂人都找不到门路。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCem1iaKYbdt8hw6fhop8ic0kjcnJZyBHX5zwJjt9oPBp8p2LnPmcppcumpxlnqiat4cRwoVSxspKmNLsCCQSo3SSnpyFh82NxV6KicA/640?wx_fmt=png)


给想上车的老铁两条实在建议。第一，务必确认卖家的minidp接口补焊工艺，买达而稳的合金款线材，别省那十几块钱，否则4K 144Hz容易翻车。第二，这卡更适合当副卡或者客厅影音机，拿来跑渲染或AI推理也行，但别指望它战未来。一旦驱动停止更新，它就是块砖。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenhzOWfs1ZIPnxsFV5CXfJfL1L52Bic3QQgg7NAt0XJmMmHLKhTLb4nuSl7kasxkJLublSHiaoZQ6cEKtB3DQ7kQMownGDUSZGuM/640?wx_fmt=png)


同类产品里，RX5700二手鱼还要700左右，而且普遍矿过。这BC160只要466，性能持平，显存带宽更大，散热还安静，确实算降维打击。不过数量不多，卖家说成色新，估计是工厂流出的淘汰货。想体验4K高刷又不想吃土的，可以赌一把。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelZ2HYNlvGpfPcBn44d7eOcJdMkyeBGIic0zKqxbt1vXlUoU0jKejmoYkkRV0ZfAIGqXAiaAQY4icLgNQnwwibTSicJagXgoREpsgGU/640?wx_fmt=png)
