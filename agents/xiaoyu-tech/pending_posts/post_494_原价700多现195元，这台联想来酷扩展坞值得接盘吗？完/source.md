# 原价700多现195元，这台联想来酷扩展坞值得接盘吗？

二手鱼里刷到一台联想来酷17合1桌面扩展坞，标价195元还送全新鼠标或大号鼠标垫。卖家说这台扩展坞21年11月买的，22年3月就开始吃灰，原因是没有支持双Type-C全功能的电脑，没法充分使用。现在测试过，除了网口、耳机孔和TF卡没测，其他接口全部正常。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCek6AwAibic4ZqSXvibUlKoDyHJkhBvM5P449mjaOOrQeOhQftiaGhHTySicLFNoPd1Qsga5hibKLkO2icZYlUTKSSxibbMHJZibXZwaJFeY/640?wx_fmt=png&watermark=1&tp=webp)


先说说核心配置，这台扩展坞实打实17个接口，3个USB3.0、2个USB2.0，还有HDMI、DP、千兆网口、SD卡槽、Type-C接口，甚至支持M2 SATA硬盘扩展，4个视频接口最多能连两个屏幕，支持4K@60Hz输出，当年原价要700多，现在195元相当于直接腰斩还多。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemC0DsScTibEEK93rKljDWiaArp3p7uxG37YzhRUjWHNRzjy4YO6aGbibibIk4sib6Via6EeB3QicvFV3PSoeiaW2fLVbaNCOBy8gibwM4k/640?wx_fmt=png&watermark=1&tp=webp)


对比现在二手鱼的行情，同类17合1扩展坞全新还要600多，就算是二手，其他品牌也基本在250元以上。联想自家的扩展坞，比如异能者系列，大多是4合1、6合1，价格也要99到269元，这台17合1的接口数量直接碾压同类，性价比看着确实诱人。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekenkCzQaiaDpZJ3MrIAia91SBFQ2eMFE6bib67Iia7Ac9VxiaUSBx77t2seOJywHjPRZaSrxSkL0nicWbVAoustKJaokfdaj23tUtw0/640?wx_fmt=png&watermark=1&tp=webp)


它的亮点很突出，M2 SATA硬盘扩展是很多同价位扩展坞没有的功能，对于需要额外存储的用户来说特别实用，相当于买扩展坞送了个硬盘扩展位。双屏4K输出也能满足办公党、设计师的需求，轻薄本用户再也不用为接口不够用发愁。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekASCicTWJsKutbWoSJ2LwQreePvEatOc52KoqxVDW2wOiciaz8k3roJiaZZ1gK8FCw7ib30PC3RgYlmEMY0MJbN3EzYrmQ1GfTFicCk/640?wx_fmt=png&watermark=1&tp=webp)


但缺点也不能忽视，扩展坞吃灰三年，虽然卖家说其他接口正常，但长期闲置可能会有接口接触不良的隐患，后续使用可能会出现小问题。另外它的USB-A接口只能满足基础充电，没法支持快充，要是想给手机、平板快速充电，还得额外插充电器。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelNZSdPJ3GTcgxtfBCicq1dELWc9vbIgwb7f5agic396gyia1u5S6g3YC33a1ocxhs3Qh2gyXicKt8L3Zw6XWRe5tIpqmxnmUeLrzo/640?wx_fmt=png&watermark=1&tp=webp)


如果你是经常需要连接多个外设、双屏办公的轻薄本用户，这台195元的扩展坞很合适，能省不少钱。但要是只是偶尔用一两个接口，没必要花195元，二手鱼里几十块的简单扩展坞就足够，不用瞎折腾。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCem4AuFzbMHANUCyzWDZ7Cp9NUqwO30Nl4hGUd6AGDq1OR26vbbIAiawjjTbaNk6qhibqDtbAO2fxBibsW9V6SEJX6xAicy1ibD5GLH4/640?wx_fmt=png&watermark=1&tp=webp)


现在二手鱼里确实有很多扩展坞流入，但像这种全接口、价格又这么低的并不多。有没有用过这款联想来酷扩展坞的老铁，说说实际使用体验？195元这个价格你们觉得值不值，评论区聊聊你们在二手鱼捡过最香的扩展坞是什么，点赞转发给身边需要的朋友，避免他们花冤枉钱。
