# 二手鱼E5-2680v4处理器售价52元带1年质保，这个漏能捡吗？

朕没事就爱刷二手鱼，今天划拉着个"传家宝"——E5-2680v4处理器标价52元还带1年店保，这价格还不到一包烟的钱。作为一个资深垃圾佬，必须帮大伙扒扒这玩意儿到底是不是真香警告。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHK0etGichf7uvib0xdZeicYe3ARthzVtkj6nOZQMYxNetQXJWYyggqnyWahMpgyV0OFjXOTacenqY7A/640?wx_fmt=png)


先看这U的简历：14核28线程的豪华阵容，基础频率2.4GHz，睿频能冲到3.3GHz。当年这可是要价上万块的服务器CPU，现在直接和白菜帮子一个价。还有35MB三级缓存放在现在也不算落伍，配合四通道DDR4内存，搞个多开虚拟机或者挂机渲染还是能打的。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHK0etGichf7uvib0xdZeicYe30whibbfLnoNJTdYBJv6j4iaI7xIbh1hbWnzKsRbMx7a3cYCG267n8IVg/640?wx_fmt=png)


不过咱也得保持人间清醒。这货诞生于2016年，用的是14nm工艺，虽然比现在的处理器年长几岁，但好在是V4版比前几代成熟不少。120W的TDP需要注意散热配置，建议配个双塔散热器压着。另外E5-2680v4需要搭配X99主板和DDR4内存，这两件套下来可不便宜，价格可能比两个卧槽还贵。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHK0etGichf7uvib0xdZeicYe3Q0jYEzibsuhRicFh2VicgibHULBQPiaKOl1RRaUVIg67Yd81Laic2ccAzRlw/640?wx_fmt=png)


那么这U能打游戏吗？其实玩个《英雄联盟》还行，但遇到吃单核性能的3A大作就原地躺平。毕竟服务器U的设计理念是多任务并行，单核性能确实不如同代消费级CPU。如果你还纠结52元还带保修，能靠谱吗？我翻遍全网发现这U在二手市场流通量巨大，基本都是退役服务器拆机件。店家敢给保修大概率是批量测试过的，只要不是人为损坏，正常用一年应该问题不大。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHK0etGichf7uvib0xdZeicYe3rAl4BqnNOIq8MeFxJbDgg4ALS0AeibbNmwbg5majdcRRv6rXBUqicOxg/640?wx_fmt=png)


这处理器其实特别适合预算有限的视频剪辑初学者，或者需要搭建家庭实验室的程序猿。14个物理核心做编译测试比普通电脑快不少，挂个私服、跑个深度学习模型也比用主力机折腾更省心。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHK0etGichf7uvib0xdZeicYe320Z9luHIxmXl46B62wzGTY5wD8obQibtSsx2AMrRCfpb8ibE71T51L9Q/640?wx_fmt=png)


E5-2680v4 CPU看似不贵，而且性能也不错，但是X99平台的主板和DDR4内存的价格却是CPU的好几倍，这就有点倒反天罡了，如果只想低价捡漏一款性价比高的CPU，这款E5-2680v4 还是不太值得推荐的。那么问题来了，你还知道有哪些CPU的性价比比较高呢？欢迎在评论区分享——反正我也不看。老规矩，看完不买，立省52元。
