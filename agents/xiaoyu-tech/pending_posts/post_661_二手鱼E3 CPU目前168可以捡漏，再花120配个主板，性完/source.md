# 二手鱼E3 CPU目前168可以捡漏，再花120配个主板，性能依然能打

朕没事就爱刷二手鱼，半夜睡不着刷，摸鱼摸累了也刷，看那些挂着“九成新”实则伊拉克成色的配件，比看剧还上头。直到前几天刷到个眼熟的型号——E3-1285v4，有8千多个小伙伴围观过，标价168块，这价格直接勾起我的好奇心——毕竟服务器U的名声摆在那儿。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGDLjAoQZYk84V8JM1ic9ynylkEjKnlBzrjyWqUicDPkvkMlC2HEa2ZcHTTCfwJdEJ6rqxhCnZKEMMg/640?wx_fmt=png)


这颗U是Broadwell架构的，跟现在的新U比算是爷爷辈，但架不住14nm制程打底，比老款22nm的E3凉快太多。功耗才95W，就算塞小机箱里，随便配个几十块的散热器都能压住，完全不用担心里程碑式积热，这点对装机新手太友好了。而且服务器出身的底子摆在这儿，稳定得像老黄牛，据说挂虚拟机几天不关机都不卡顿，低延迟的优势玩网游也合适。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGDLjAoQZYk84V8JM1ic9ynyvfNZrJfichS034ibM5Zz8d1SeicoSzw9cLCU6BiaSic9zC5y4wBICsOCbicg/640?wx_fmt=png)


核心规格是4核8线程，主频3.5GHz，睿频可达3.8GHz，别小看这参数，单核性能相当能打，之前看评测说比i7-4790K还强点。8MB三级缓存加持，多任务切换时反应很利索，不像有些老U开俩网页就卡成PPT。还支持ECC内存，虽然普通用户用不上这服务器级功能，但侧面说明它的稳定性不是吹的，简直是CPU界的“old but gold”。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGDLjAoQZYk84V8JM1ic9ynyicuDMTXpRYPRem7YUqYCY4M1DkNUbflI388pYbvIiaEmUrSom2tFO0ng/640?wx_fmt=png)


不过缺点也得唠明白，不然容易误导人。这货挑主板挑得厉害，普通8系主板比如B85、H81根本不认，必须魔改BIOS才行，新手要是没点基础，很容易踩坑。而且内存兼容性也玄学，试过好几款内存，就镁光和三星颗粒的能稳定运行，其他牌子要么点不亮，要么频繁蓝屏，挑内存像选妃似的麻烦。另外黑苹果支援不行，想用苹果系统的可以直接pass了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGDLjAoQZYk84V8JM1ic9ynyj0Jibh70V5qQFMVyMbwiaiaBhYOib2Qw1E9rpxqgv8VYenePaYRSobvNMA/640?wx_fmt=png)


可能有人会问，这U搭配什么主板，价格多少？主板首选H97或Z97，二手鱼上靠谱的大概120块左右，一套下来也就一包烟钱，性价能打。要是碰到华擎这类主板得注意，内存兼容性烂得出名，建议选其他牌子。鲁大师跑分嘛，CPU大概25万分，核显还能跑6万，应付LOL、DNF这类网游完全够了，日常办公更是不在话下，这个价格还要啥自行车？


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGDLjAoQZYk84V8JM1ic9ynyIXAbWlI2jx8kPM5QhnvgrVErx0PL7SGicZbGeDT88Z0icAAQw6D7sLdw/640?wx_fmt=png)


说实话，这颗U特别适合预算有限的过渡用户，或者想装台备用机的人，价格挺白菜，性能也可接受。唯一要注意的就是装机前多做功课，别买到没魔改的主板，不然CPU再便宜也是块废铁。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGDLjAoQZYk84V8JM1ic9ynyGicHOiaMOcSqxAdeC2BTRu1xS9S9hAn6DCKyRqD6ib0bURozVOMaVBdXw/640?wx_fmt=png)
