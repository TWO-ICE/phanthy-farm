# 居然比官网便宜这么多？188元拿下小米电动工具箱值不值？

二手鱼里 刷到 有卖家188元出小米米家电动工具箱，外包装仅拆封或者试用过， 成色基本都是 95到99新，还包邮。 这个工具箱目前小米的 官网 上还在售卖，价格是 279元， 二手鱼 这里直接少了91块，比官网差不多便宜一半，来看看 这价格到底能不能冲？


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemNwTc54DoRicCwhZsxEaX95tnQCBPpbASicZnrB8QqBxmAkVA0WB8qcK04GrJkgiauzplv5EP5bKXiaeNawNkc1ugAgq9icibtmiaNek/640?wx_fmt=png&watermark=1&tp=webp)


米家这套工具箱尺寸 是 297x230x70mm，净重2.46公斤，拎在手里挺有分量。配件 非常 全乎，有 自锁卷尺、美工刀、18个短批头、多功能尖嘴钳、延长杆、4个长批头、羊角锤、活动扳手、橡胶锤套、万向软轴、内六角扳手套组，连收纳盒和说明书都齐了。日常家里修个柜子、装个家具、拧拧螺丝，这套基本覆盖了。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenf0g4phjjvBxF0rQR5Tn7hLS9NygFT7eTVbyKiayRwGciblVEb1AJpjZzycm4PTInDIcLVGuLX0cwPNqUbiazjqkeYiaLrPxh0xMc/640?wx_fmt=png&watermark=1&tp=webp)


核心是那把电动直柄螺丝刀，电动模式最大扭矩4N·m，手动模式能到8N·m，批头型号是C6.3通用规格。Type-C充电接口算是跟上时代了，充满要180分钟，充电参数5V==1A，速度不算快但胜在方便。 而且 卖家说产品在保、 还支持 全国联保。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenIENCjhYKklhDvAYZxNMBIo9L09GQbbv0n25KaFgC1CYM7fqBNCgAwGLqDGmaKBXOdzkQIDvmySLTsibgCDUw5kRpSre7xtMY8/640?wx_fmt=png&watermark=1&tp=webp)


小米家的产品有个特点，设计感在线，收纳逻辑清晰。工具箱打开，每个工具都有自己的卡槽，不会乱晃。不像早年那些杂牌工具箱，打开盖子工具滚一地。材质上手感不廉价，羊角锤握柄防滑，活动扳手调节顺滑，这些细节是加分项，算是把家用工具箱从工地风拉到了家居美学级别，现在二手鱼里188元能拿到几乎全新的，对于不想花原价但又想要品质的人来说，确实是个诱惑。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCengficqzpULxtQNnPksF9rHKNjWziaXtvKIib4DvJfqdU0ZYflLtqCQPdicveDjl3MAk9ZFw6g6UroG9RYGMpWkib01dWHTCTPFD0WQ/640?wx_fmt=png&watermark=1&tp=webp)


另外需要注意的是 ，电动 螺丝刀的 扭力 只有 4N·m，对付精密螺丝、小家电拆解足够，但你真要打膨胀螺丝、拧大号自攻钉进硬木板，这个扭矩会吃力，手动模式8N·m也只能说勉强 。 还有 充电时间 是 3小时 左右 ，Type-C接口虽好，但5V1A 是 不能用快充头暴力充电 的，只能 老老实实用普通充电头或者插电脑USB口，不然容易伤电池。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelXiayptBjMQ6NBEpaYnJ3YvZjOgbtfFkE8auUdyqRMABhaiagjLpicgq8hKRAnWoQakSxpgzUqbyN7MTnvYM0XpImqDjsZgIcQng/640?wx_fmt=png&watermark=1&tp=webp)


如果你不在意成色，我还刷到一个卖家，最低178元也能买到，不过没有包装，但是带京东自营电子发票全国联保，1到30天发货。全新未拆的卖238元，比官网便宜 。 188元的这个卖家说小米仓安排发货、无瑕疵，还包邮，冲着省心可以选它。178元那个便宜10块但没包装， 而且是 1到30天发货， 如果不急用话178的省10块也挺香，所以在哪买还是你自己决定吧。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemeGibmuibJAI2ibzwxju5xHwcujibibYjghMvkXFSibf3LOGNPAVYWbic1eswFFq1ro5phU0vGxU3zX1H9LDibwiaEtDp4IZLOxEMGdUVk/640?wx_fmt=png&watermark=1&tp=webp)


同类产品在二手鱼里，100到200元价位段，你能买到博世的手动套装，但没电动功能。威克士的电动螺丝刀单把就要1 35 往上，还不带这么多配件。小米这套把电动功能加全套手动工具打包，188元的价格 我感觉 性价比确实 不错 。当然它 也有 劣势，电动部分扭力偏家用，专业师傅看不上，但普通家庭一年用个十几次完全够。和 官网 279元的价格比，现在二手鱼里这个成色这个价，折损率算合理的。
