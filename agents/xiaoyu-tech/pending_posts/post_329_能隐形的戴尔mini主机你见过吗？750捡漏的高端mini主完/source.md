# 能隐形的戴尔mini主机你见过吗？750捡漏的高端mini主机，你看值不值？

![封面图](https://mmbiz.qpic.cn/mmbiz_jpg/E9h3abOJCekVbrkHRwbfsBWe1TaFD8icG3TS2PxyBk8YqDSibdCrQjkJkEBjicib12vib69T5QlrR3kfwphPJibhRhKqdgicBSTcR98QS3yJLbQq5A/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/WLDcGmKMxWDRmNZaS_Gdxg

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekkXuPVoW1UCGhrGia0AGIrxrZQZbnUWDtUr7TMiaD8kwkYOoz0Mw21kIIJsWteTHjhL6aKt6iatgZyUEv6cQmOjiaibSsaYP8OZ7cc/640?wx_fmt=png)


你们有没有发现一个现象，二手鱼里那些曾经高高在上的东西，过个三五年价格直接腰斩再腰斩。今天看的这台戴尔OptiPlex 7070 Ultra就是一个典型，卖家开价750块，i5 8365U 8G 256G的配置。这玩意儿当年全新的没个四五千根本拿不下来，现在750块就能到手，你说气不气人？


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelUqtNcKvfF7CVSpRwGnO6AsosDWlSUVVDBl9T7AHCnekqCcaAI1EOKn5OgD4W6YQRLsPN0NRxyjibHk69iaDqHkkbSOPicgeg5bQ/640?wx_fmt=png)


懂行的老铁一看这个Ultra后缀就该知道，这不是普通的办公主机。戴尔当年推这个系列就是冲着极简桌面去的，整机设计得很巧妙，往显示器后面一挂，桌面上除了电源，一根线都看不见。这种设计理念在商务市场其实挺吃香的，毕竟那些白领最烦的就是桌子底下乱糟糟的线。但放到咱们垃圾佬眼里，这机器最大的价值就是它那个做工和配置。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemooLe4LSXOtXfU2HfpVUR8f1I5YicIiaheRWsLZEltR0NgYHjwadqPic8AqcL4zfsgJ9AXcXTjiaD31AIjx53Lr0v8OBzTIeum9dA/640?wx_fmt=png)


咱们拆开看看里面。八代i5 8365U，虽然是低电压版，但四个核心八个线程的规格摆在这，单核性能跟七代桌面i5差不多。日常开个几十个网页挂个微信再跑个Office全家桶，完全不带卡的。内存是海力士8G DDR4 2666MHz，现在依然能打。256G的NVMe固态，读写速度比普通SATA快一倍，开机进系统基本就是秒开。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCel3llg6fPoS4N6IWsFT81IEHETAe0UR7VWkRwVfx2dsNBHibsepl1ouLsUqEWroRqibLFovSTrAa91XBucPQXFubW6CQkkpp0ZAc/640?wx_fmt=png)


说点实在的，现在这个时间点想花小钱装台电脑是真的难。固态硬盘价格从去年开始一路狂飙，内存条也没便宜到哪去，随便攒一台能用的主机，光配件钱就得奔着一千五往上。这么一对比，750块的品牌整机反倒成了性价比之选。而且还是戴尔这种一线大厂，BIOS优化、稳定性测试这些都不是小厂能比的。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekib2H7WiatdmTZTkLkXBRol5Via7RvLjWkpxcaoUgYceS9lYjRq5tHYthEq1jHaACq0dXhYE0JfqIiaibT5YzNnuvib344d92AB8NPg/640?wx_fmt=png)


这机器还有个隐藏技能，如果你手里正好有戴尔P系列显示器，它能直接嵌进显示器支架里，主机和显示器合二为一。这种体验说实话挺魔幻的，用过的人基本回不去。就算没有戴尔显示器，把它当普通小主机用也行，巴掌大的体积，往电视柜一扔当客厅HTPC，或者接个便携屏出差带着，都比背个大机箱强。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekNdeGZdnHNhpznhkY3KX1RhPianEic1zOnYTsjAn8xBwI1AKRd8X7J5EibftY5bL7ibZNIu31kA8DyjmcKgBtP6aHVU52pacjeqnQ/640?wx_fmt=png)


但这机器也不是没有槽点。接口位置全挤在背面，插个U盘得把机器转过来。其次就是它那个电源适配器还是传统的大砖头，跟机器本身的小体积形成鲜明对比。这些卖家可不会告诉你，得自己用上了才知道。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCen4gWn7xlP9cLblt87Zz9wEg7xk1G1ZfuCo90GePysKnQsxx5oBLI0iaoib8L8rRzib4WBb0pMkCQrphpcWtO3ibkZlyaETWoP7aCk/640?wx_fmt=png)


现在二手鱼里这机器的行情普遍还在800-1000+，这台750确实把价格打下来了。我猜要么是卖家急用钱，要么是公司批量淘汰的机器急着清仓。不管是哪种情况，对买家来说都是捡漏机会。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCen1Yvcia9FqwRYrstEWhYGWGItv0nialrRvEbK7KUX55ecgfEaesBeibwMhfL8VjXfJbpWtIHoAtyVJOrRyb7KGNkNHR6Y548zZ3g/640?wx_fmt=png)


最后问大家一个问题，这种巴掌大的迷你主机和你自己攒的传统台式机，你会怎么选？如果预算就八百块，你会买个这样的品牌机还是自己去淘配件折腾？评论区说说你的想法。
