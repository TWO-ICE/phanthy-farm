# 二手鱼挖到 E5-2680v4，14 核 28 线程，预算 60 + 闭眼冲！

今天在二手鱼闲逛的时候，意外刷新到了一颗英特尔至强 E5-2680 v4 的处理器。标价 64 元，而且老板还大度地承诺包邮，甚至附赠一包硅脂。这就很有意思了，再看看商品描述，卖家特意注明鲁大师跑分 48 万起步，并且给出了“二十天内任何质量问题包来回运费”的售后承诺。作为一个在二手鱼摸爬滚打多年的老油条，这种低价好货我也算见得多了，但在这个价位段，能把配置、价格和售后保障做得如此“良心”的，确实是凤毛麟角。要知道，在二手硬件圈子里，这种配置往往意味着“要么是传家宝，要么是炸弹”，但这波操作，怎么看都像是遇到了一位清仓回血的好心人。

先来盘一盘这颗 U 的核心硬参数。14 核 28 线程的规格，放在几年前，那绝对是服务器领域的“王炸”配置。大家要清楚，这颗 U 的本职工作是驻守在企业的机房里，当年作为“机房顶流”，它的身价可是高达数千甚至上万元人民币的。谁能想到，时过境迁，曾经的贵如今沦落到白菜价，这电子产品的贬值速度简直比过山车还刺激，真可谓是长江后浪推前浪，前浪死在沙滩上变成了白菜秧。

这 14 个物理核心意味着什么？意味着它的多任务处理能力直接拉满。对于普通家用 CPU 来说，开几个虚拟机可能就已经风扇狂转、系统卡顿了，但这颗 U 面对同时开启十几个虚拟机，或者挂着一堆游戏脚本、游戏账号多开，都能表现得从容不迫。这就好比一个是家用小轿车，一个是重型载货卡车，拉货能力完全不是一个量级。而 28 个线程更是让多任务调度如丝般顺滑，系统资源分配压力骤减，比那些只有 4 核 8 线程的普通家用“小身板”强了不是一星半点，简直就是生产力工具的物理外挂。

再聊聊频率。基础主频 2.4GHz，动态加速频率能冲到 3.3GHz。实事求是地说，这个参数放在服务器 CPU 里绝对算不上拔尖，甚至有点保守，但对于我们的家用场景来说，完全是够用的，甚至可以说是绰绰有余。

这里面的逻辑很简单：日常办公、浏览网页、看视频时，CPU 主要工作在基础主频上，2.4GHz 的状态虽然不算高频，但胜在稳定，此时电压和功耗都控制得比较好，机器运行起来低噪又安静。而当你需要进行重载运算，比如处理大文件压缩、运行大型程序或者渲染时，3.3GHz 的睿频能及时顶上，提供爆发性的算力支持，处理起来也不会拖后腿。

不过，有一说一，它的短板也非常明显。作为一颗老旧架构的服务器 U，它的单核性能确实被现在的新工艺 U 甩开了一大截。如果你拿它玩《CS:GO》、《英雄联盟》这类极度吃单核主频和高帧率的竞技游戏，可能会感到有些吃力，帧数不如同价位的现代桌面 CPU 稳定。这也是老服务器 U 的通病，毕竟术业有专攻，它是为了并行计算而生的，不是为单线程高爆发设计的，所以不能指望它样样精通，游戏玩家对此要有心理准备。

缓存和总线规格才是这颗 U 真正的“隐藏大杀器”。它配备了 35MB 的 L3 缓存，这个容量堪称“超大仓库”。在 CPU 运行时，大容量 L3 缓存能临时存储海量的指令和数据，大大减少了 CPU 频繁去内存里“搬运数据”的交互延迟。不管你是渲染 4K 视频，还是运行超大型工业软件，都能明显感觉到数据加载更跟手，减少那种“转圈圈”等待的焦虑。

而 QPI 9.6GT/s 的总线规格，则是它高效协调多颗核心或者外部数据的保证。这种高速稳定的总线设计，保证了多任务并发时数据通道的畅通，不会出现数据堵车的现象。鲁大师跑分能稳定在 48-50 万，这个分数虽然不能代表绝对性能，但在娱乐榜上也能吊打不少入门级的新款 U 了。用来做剪辑编码、代码编译等生产力工具，性价比确实还要啥自行车呢？

当然，热设计功耗 120W 是它绕不开的小缺点，属于名副其实的“耗电大户”。这就意味着你不能随便给它找个几十块钱的下压式散热器就完事了，必须要搭配一个靠谱的双塔风冷，比如那种 4 热管、6 热管的主流塔式散热器，稍微好一点的水冷也可以。如果不散热到位，夏天很容易因为过热而降频，导致性能剧烈波动。

不过，令人安心的是，店家承诺二十天内有任何质量问题包来回运费。这点在二手硬件交易中太重要了，毕竟二手产品最怕“落地捡损”，有这个售后保障，相当于给我们吃了一颗定心丸。对于预算有限的朋友，几十块钱买个散热器压住它，总比后期因为过热死机折腾半天强，在这个价格面前，功耗大一点似乎也能容忍了。

回顾历史，这颗 CPU 当年的首发价超过了 3000 美元，折合人民币两万多，而现在只要一包烟钱就能买到，堪称电子产品贬值界的“跳水冠军”。虽然它的绝对单核性能和最新的 i9 相比被甩开了十八条街，但在多核吞吐能力上，它依然能战平现在的主流 i5-10400 甚至 i5-11400。对于囊中羞涩的学生党装机、需要高强度多开的工作室，或者像我这样纯粹想折腾、体验“捡垃圾”乐趣的图吧老哥来说，这简直就是为爱发电的最佳选择。

那么，入手这颗 U 到底需要注意什么坑？这里必须给新手泼一盆冷水。首先，你不能指望把它插在家用的 LGA 115x 或 LGA 1200 主板上，它必须搭配 X99 服务器主板或者寨板，而且必须使用 DDR4 内存（注意是 ECC REG 内存最好，虽然普通 DDR4 也能用但看脸）。这“两座大山”的成本可能比 CPU 本身还要贵。新手入手前一定要算好总账，别为了捡 60 块钱的芝麻，丢了买主板和内存的西瓜。

其次，要确认主板 BIOS 的兼容性。这颗 U 是 Broadwell 架构，虽然 X99 主板原生支持，但很多杂牌板子的 BIOS 版本老旧，容易出现不识别或者点不亮的情况。建议选购那些商家标明“即插即用”或者 C612 芯片组以上的服务器拆机主板，虽然体积大（通常是 E-ATX 架构），但稳定性比百元寨板强太多，避免出现各种玄学问题。

最近在贴吧看到有不少硬核玩家，用它搭配一张同样是“捡垃圾”捡来的矿卡（比如 RX 580 或 P106），组出了一套千元的游戏主机。实际测试下来，跑《赛博朋克 2077》这种 3A 大作都能在中画质下保持流畅运行，这在以前是想都不敢想的事情。虽然有功耗高、单核弱的小缺点，但在极致的性价比面前，这些完全可以归类为“瑕不掩瑜”。这绝对是一款适合有特定需求、懂折腾、预算极度敏感的用户的“真香”U。
