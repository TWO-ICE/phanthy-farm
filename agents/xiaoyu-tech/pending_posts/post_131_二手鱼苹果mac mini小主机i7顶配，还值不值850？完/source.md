今天在二手鱼刷到了一台苹果Mac mini小主机，标价850元，配置写着“i7顶配+16G内存+256G固态”，型号MD388。点进去一看，卖家描述得挺实在：功能完好、无维修、成色不错、支持验货，还能自提或邮寄。那么这玩意到底还值不值850呢？


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHibAMO6h0I6JjoOiciaX1ViboZWO2Se6kCaQ5EvTXWvMn9hJpLzUhv4JXricMG6rRUbmicKL8cia4EibuENw/640?wx_fmt=png&from=appmsg)

先说说这台机器的基本参数。它搭载的是Intel Core i7-3720QM处理器，四核心八线程，主频2.6GHz，睿频最高3.6GHz。虽然已经是2012年的老U了，但放在轻办公、影音娱乐甚至轻度剪辑场景里，依然能打。配上16GB DDR3内存和256GB SATA固态硬盘，日常使用完全不会卡顿。而且这代Mac mini用的是标准SATA接口，意味着硬盘可以自己动手升级，甚至加装第二块硬盘（需拆机），比后面那些焊死存储的机型友好太多。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHibAMO6h0I6JjoOiciaX1ViboZ5mPGfwiawIjVwvyHzrZb5nxMicxlcbp9Buny87EahI8iaLtb8cvTgzgsQ/640?wx_fmt=png)


接口方面，这台MD388属实是“接口狂魔”。背面有4个USB 3.0（注意不是USB-C）、1个HDMI、1个千兆网口、1个雷电1、1个FireWire 800火线口、SD卡槽，还有光纤音频输入输出。对想搭HTPC（家庭影院电脑）或者NAS替代方案的人来说，这些接口简直是天选之子。自带Wi-Fi、蓝牙、内置喇叭，连GPS都有（虽然基本用不上）。关键是，它还能装Windows 10双系统，Boot Camp官方支持到这代，折腾党狂喜。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHibAMO6h0I6JjoOiciaX1ViboZbme1kwZicyIcglcEgiajE5icASKicNR0GG3AYUHuZBVv9yTxA8J1PaDgicA/640?wx_fmt=png)


当然，缺点也得摆上台面。首先，这机子已经13岁了，主板电容老化风险存在；其次，虽然能升级到macOS Monterey（通过OpenCore Legacy Patcher），但原生最高只支持到High Sierra，后续系统全靠社区补丁，稳定性见仁见智。另外，散热风扇在高负载下会有点噪音，不过日常浏览网页、看视频基本静音。再者，雷电1速度只有10Gbps，远不如现在雷电4的40Gbps，外接高速设备会受限。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHibAMO6h0I6JjoOiciaX1ViboZbUrjhpTqONt3ia1RR4E61KMMyLY5c2u2gz2uXJ4vlwf5SP8ZBrsKcKA/640?wx_fmt=png)


对比二手鱼上同类产品，同配置的MD388普遍挂价在950–1200元之间，有些甚至标到1500还写“急出骨折价”。而这位卖家850元包邮（部分地区可自提），还附带购买记录和序列号可查，属于明显低于市场均价。不过建议砍到750，毕竟二手电子产品“今天汉显，明天汉不显”。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHibAMO6h0I6JjoOiciaX1ViboZCPkvxN93ROic0WaspkiblYMWOibQw3uprXArNxh5f9FfE3qpLA8YeyFhw/640?wx_fmt=png)


可能有人会问：“这么老的Mac mini还能干啥？是不是只能当电子垃圾？”那还真不是。它跑Final Cut Pro X剪1080p视频没问题，Xcode开发编译小项目也够用，做Home Assistant、Plex媒体服务器更是绰绰有余。拿来当客厅HTPC接电视，Apple TV的功能它都能干，还能装Windows玩怀旧游戏，一机多用不香吗？


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHibAMO6h0I6JjoOiciaX1ViboZs9A9kMAzBiaFklk7VEM7KviaonJrEL0m85aqMKZxFRkHDoSVpzqMFiaMw/640?wx_fmt=png)


那么会不会是翻新机或者组装机？MD388这代结构复杂，民间几乎没人仿制。只要序列号能在苹果官网查到激活日期、配置匹配，且卖家提供实拍图（特别是底部螺丝、接口细节），基本可排除山寨。再加上支持验货宝，风险可控。 

如果你想出手的话可以参考下面的几点建议：

1. 优先选标注无拆修的卖家  

2. 必须要求通电验机视频  

3. 预留200预算升级硬盘  

4. 适合码农/轻剪辑党入手  


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHibAMO6h0I6JjoOiciaX1ViboZpmSSyjVpg0zZvYrbjhk0MPFGQMEkFdibwZScYqs0rQH9roxqLSvPtTw/640?wx_fmt=png)


如果你正好缺一台安静、小巧、接口多的桌面主机，又不介意它“年纪大”，那850元的MD388确实值得蹲一蹲。当然，要是你追求M系列芯片的能效比，那还是洗洗睡吧——毕竟“老将虽老，尚能饭”，但别指望它跑AI大模型。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHibAMO6h0I6JjoOiciaX1ViboZZyHYNriaKpr4UuiaSlz3VXOQxSsCXjRfXFxO3eBWfS1mRFMicLPnzwyXw/640?wx_fmt=png)


觉得这台机子靠谱？不妨去二手鱼搜搜“Mac mini MD388 i7 16g”，看看有没有同款好价。最后扯句闲篇：你们觉得这种老钢炮现在还能干啥骚操作？评论区等各位秀脑洞～ 老规矩，看完不买，立省850元。
