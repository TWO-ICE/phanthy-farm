# 别只盯着飞牛圣体了，这台228元的海尔mini主机更实在

固态硬盘和机械硬盘的价格依然坚挺，本来想组个NAS装飞牛系统的心都被浇灭了。所以打算另辟期间，找那种自带硬盘、价格又便宜的小主机来过渡一下，毕竟能省一点是一点。最近刷到了这个海尔云悦mini2，卖家报价228元，还带4G内存和500G硬盘，这价格瞬间就让人精神了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelKY014fL8C1HB6Fw6cjMS9vcyCOzMZ7qbYb41nU3pzT9Dtqr7spzQ31KST3FB2UAl0vicObKqtKzdqYIYcnKfSlA6sPhz9WLic4/640?wx_fmt=png)


这台海尔云悦mini2可以说是标准的“老咕噜棒子”配置了。处理器是英特尔的J1900，四核四线程，功耗10W，性能虽然拉跨，但跑飞牛够用，最重要的是功耗低省电。卖家默认给装的是Windows 7 系统，带4G DDR3内存和500G机械硬盘，接口倒是挺全乎，HDMI和VGA都有，千兆网口也是标配，还有USB3.0。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekQLNxbOgtoe4dITO3t9yBx09s4fyjoD2ic2icNibnxcL1ma3YfYtTPYdw2oQpH5JPyGFoKIHveKOSed5jt3E6UVtpCbRDWSEC97g/640?wx_fmt=png)


很多人看到J1900可能扭头就走了，觉得这玩意太古老。但咱们得看看价格，228元，现在连一条全新的16G内存都买不到，它能给你一套完整的、带Windows 7系统的电脑，还要啥自行车？除了刷飞牛系统之外，做个简单的炒股机，或者放在店里做个收银、播放广告的机器，完全没问题。甚至拿它刷个开源系统，当个软路由或者下载机，24小时开机，一个月也用不了几度电。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCen172g9VFicDToibA7pzYdvrAEFELdVibA26tVTo7tSjhczjghwkjABfOP2r5z1D1x8vwV8JfESswVt5bFHQD02rybnMR8ibicr06MY/640?wx_fmt=png)


很多人为了找所谓的飞牛圣体，花两三百买个只有主板的准系统，还得自己加内存、买电源、配硬盘，一套下来奔着四五百去了。回头再看这台海尔，接口齐全，该有的都有了，到手就能用。虽然它的扩展性不如那些可以内置多块硬盘的机器，但如果你是新手，只是想体验一下，或者只需要简单的文件共享、挂个BT下载，这台机器反而更省心，不用瞎折腾了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCem76uWAFFhoQRlytByJsGicaRjecoBceT5OmCPr6hS9zvHHYhsW3ibIKK3ibSEHicUyrOgl9iagpdtKGmH4VzuDvFq1YByb9sYLOMqs/640?wx_fmt=png)


当然也得说说它的缺点。J1900这颗U的性能确实不强，任务多难免会卡。另外标配的500G机械硬盘是速度瓶颈，开机和打开软件会慢一些。如果有闲置的固态硬盘，或者是花个几十块，哪怕64G的，体验都会好非常多，机械硬盘拿来当仓库存电影就好。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCeldAVQ47ZcbiaosrE2ZpLlSvfnVz5oiaibanXiaOensC4SxMpb1XSy0icoDxRffcKFSoTwT9jgD54n0LiarCpOsCh9EEnj56jhMicZzkI/640?wx_fmt=png)


现在的二手鱼里，想用200多块钱买台电脑，选择其实不少。但大部分都是各种叫不上名字的杂牌工控机，或者外壳伊拉克成色的古董。像海尔这种国内大品牌的迷你主机，外观起码干净利索，做工和用料也让人放心一点。在这个价位，它不一定性能最强，但肯定是最稳妥、最不容易翻车的选择之一。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelR65oFOc4cU24Gc8QGeOndeHmttBQVycLCHwlGIGvLQ2qGRkq7UrliazsdiaYwz6sMePOGm57libkrL3ZXqJGIblj6EibxpcwiareI/640?wx_fmt=png)


你们觉得这种两百来块钱的迷你主机，除了当下载机和简单的办公，还能开发出什么新玩法？有没有已经入手J1900的小伙伴，来聊聊你的使用感受，给大家一个参考！
