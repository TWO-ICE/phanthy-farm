# 1万多人点了想要，这台950块的Switch OLED到底有什么魔力？

最近

刷到了一个爆款游戏机，950块的Switch OLED，这台机器是OLED版日版，内存给到了512G，成色标注几乎全新，带原包装。产品页面的数据挺吓人，17万浏览，1万人点了想要。这个热度在二手鱼上不算常见，说明价格确实捅到大众心理价位了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenVxrNv447oNo3ycR95cdcSKvWTegLySib4gvZ3snEHBJkDSceJybuukpnbDRDBaJ6AibX7pM2wI9VwMWKcrlfz1h6j9vkawnaIY/640?wx_fmt=png)


Switch OLED全新机现在行情在1600到1800之间浮动，512G的存储卡算两百块，一套下来小两千。这台机器950块包顺丰，相当于半价。如果卖家描述属实，这个价格确实是把二手Switch的价格打下来了。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenAQgPoNsiaicTp6OajzqE2deMnFKBmanqF4IicovBEJy42xZKPUf8KD8QzicdkWlQUF6hJDFaj0bAuHMQf0glWfsVIobWuPI55Hkk/640?wx_fmt=png)


但我得说句实话，二手鱼买东西不能只看价格。这台机器最让我意外的不是950块的标价，而是卖家给的售后政策。主机保修两年，手柄保修一年，还支持描述不符包邮退。更狠的是写了句话：不玩了包回收。这几个字的分量，经常蹲二手的人都懂。敢说这话的卖家，基本对自己的货很有底气。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenYDot7Mdz5hicFWkh3qlmTwyHGp7lSH1lTXeiaCgF63FT8e7sUDvfHS2YnKg6rpKGqgbO7OyKdhDbrk4NCzoJLnoOrhfibbcOOBw/640?wx_fmt=png)


机器的配置方面，五码合一，原装配件齐全，日版机器不需要折腾电源直插。卖家还贴了膜，送了收纳包保护壳摇杆帽这些小件。关注下单还送全网资源和游戏安装，指定游戏可以装满了再发货。对于不想折腾的新手来说，到手就能玩这个点确实省心。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenWnUlKiaRCvshWwHRsls23iaVv3zQsy9603GKp59of29RZhBdCbQBbJPRq3YyXrkJHF4GUyFGeh9YoEjiakQalzmGZbnMQSiaIDhg/640?wx_fmt=png)


当然该挑的毛病一个不能少。这是二手机器，所以不管成色多新都改变不了它被使用过的事实。OLED屏幕虽然有烧屏风险，但Switch的使用强度一般问题不大。JoyCon手柄的漂移问题在二手机器上依然存在，卖家保修一年算是给了缓冲期。另外512G的存储卡是啥牌子得问清楚，有些杂牌卡读写速度跟不上会影响体验。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemKgM2sv64captMtDJoJBKS0TTA2gzWUYI7JY2kSADUJjWBTO1FE94pWwunaQDqQ30DGlHgicWI9Em88OpC6Cicsfhwz4KUibyTuA/640?wx_fmt=png)


从Switch的生命周期来看，这台机器已经走过了巅峰期。但我反而觉得，现在这个时间点入手OLED版挺合适。游戏库足够丰富，破解？不需要，正版数字版打折的时候也不贵。而且OLED屏幕的效果确实比普通版好太多，玩旷野之息或者朱紫的时候，色彩表现完全不是一个级别。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelaYX39zSmvtA3ht5dAoABS2uribBMV2qOWsq3pGcrGS42ZLFDcOkJ3NuBkLlwGjPkg2JSjwVneINEwLAVjBD1kYhicReMz3QHHE/640?wx_fmt=png)


最后说点真心话。二手鱼里这台机器的性价比确实能打，950块买不到吃亏。但捡漏的前提是卖家靠谱，这家零差评的含金量比啥都重要。收到货后当着快递员面检查，有问题直接拒签，该走的流程走完，大概率能安全下车。
