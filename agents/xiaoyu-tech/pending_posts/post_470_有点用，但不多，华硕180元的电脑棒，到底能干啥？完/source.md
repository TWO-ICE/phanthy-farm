# 有点用，但不多，华硕180元的电脑棒，到底能干啥？

![封面图](https://mmbiz.qpic.cn/sz_mmbiz_jpg/E9h3abOJCekXOuGePORFqwWHMxOibxjHPwbs7nwuLVxSS1Wiafy3yNicurEL7wxQah2wvSPJaqaKIueo2HNKKIscbCPxjU2wiaTgXg8ic2nEoibQI/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/YJ3uHfkvpRLURfowx952wA

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCen4NSrVUa7HL4qLiaZ8MRtQEcQibwTgqf13bfOicXrzjnzojDQdwDyEHpEgtciaIMhdqwvFArn0xJalmkPQlSy6XeUIwmUAhnTYS0k/640?wx_fmt=png)


最近刷二手鱼，看到有人挂出一台华硕TS10微型电脑棒，只要180元还包邮。这东西当年可是正经的火了一阵子，最大的优点就是便携，虽然它长得像个大号U盘，但却是个完整的电脑主机，今天咱们就来盘盘这个180元的小玩意儿。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCel1UEzS2ibvRl57rabjdfRhzfUvPfe0ibIzd7O1dnG5Rj1p3MdWtYeoIib8eQ9GcgkTaEca8VBEIxXA5k0BSibLYIc8TFguPOvxvcU/640?wx_fmt=png)


先看配置：英特尔Atom x5-Z8350处理器，四核1.44GHz，2GB内存，32GB硬盘（海力士的），集成显卡，自带无线网卡。这套参数放现在，连入门级手机都打不过，当年主要用在廉价平板和迷你PC上，性能也就勉强能跑个Windows 10轻量应用，多开几个网页都卡。2G内存更是捉襟见肘，装完系统可能就剩几百兆了。32G硬盘存不了几部电影，装几个软件就满了。所以这货注定干不了重活。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemDsqQ7eYkRria0LrA8iaicENtNxOjicZGEZaFJexVnMUh3dwOdS07ncnZa3T8YbEhEXojpzj4GJpOMMw5Bicaic369AM311JxQ3picu4/640?wx_fmt=png)


但话说回来，180元你要啥自行车？它的优势在于体积小巧，功耗极低，而且华硕的做工还算靠谱。所以这玩意儿真正的归宿，不是当主力电脑，而是折腾党手里的玩具。比如刷个Linux当软路由，跑点轻量服务；或者装个精简版Windows当下载机，挂个百度网盘啥的；再或者接电视上当安卓盒子用，看个在线视频还是可以的。甚至有人拿它当代码学习机，给孩子练练Python入门，毕竟坏了不心疼。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelmiaKpQR5URWYACjKrian2602OfuJiawo4OJKGibUdSMzBjNPz3XD4TrjgUjwNKRz7yfqO9pFCCugLuYpBZ83U20VE81pDhgNTZics/640?wx_fmt=png)


当然缺点也很明显：性能太弱，开机可能都得等两分钟。散热是个问题，这么小的机身被动散热，长时间运行容易降频。扩展性基本为零，就一个USB口，想接硬盘得靠HUB。而且32G存储现在装个Win10都够呛，更别说后续更新了。所以如果你是奔着办公、玩游戏、剪视频去的，赶紧绕道，这货会让你怀疑人生。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekUCgR3tlKS7JIodhL1vmxH4OEPib6sibBLB5qJHhNUPUw0icDW1rJCqoF1YoqE6dPpz9x86HDvhLiaeyiajt6ZZtQicDrVSHibHXHUQE/640?wx_fmt=png)


那什么人适合买呢？我觉得有三类：一是喜欢折腾的垃圾佬，花小钱体验不同系统，装个软路由；二是需要一台低功耗下载机，挂机下电影，功耗比路由器还低；三是给孩子当编程入门机，装个Linux学命令行，坏了也不心疼。但如果你是普通用户，想看电视或者轻度办公，我建议你加几十块买个二手电视盒子，体验可能更好，或者直接加钱上正经迷你主机。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCek3x4VUzFEEwL9MxVIicnO1WH5HCGKeicXj6Dj6Wia2JxhCRs59fjMgxAVFL3Dv0rFFBXQxxnEOZrqslzZyPftJ8BIUMqwJH6GtSA/640?wx_fmt=png)


最后给点建议：买之前一定想清楚用途，别看着便宜就冲动下单。二手鱼上这种小主机很多是洋垃圾或者工厂淘汰的，成色和质量参差不齐，最好让卖家发实物图，确认能正常开机。另外，这价格可能还能小刀。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCen7Kbs9U5MTdboic6OF3JHlOGZSknwRtJickPUBwcal3s7TKeIqq6F4ibTVaNvibZjzgUZ17H3pZ7VBicoWfJSpn3DKjzjrZfZ96460/640?wx_fmt=png)


如果你正好有闲置的显示器或者电视，又喜欢折腾，180元买回来玩玩倒是不错。但如果你指望它解决实际需求，那大概率会吃灰。你会花180元买这种迷你电脑棒吗？买回来准备干啥？评论区聊聊你的想法。
