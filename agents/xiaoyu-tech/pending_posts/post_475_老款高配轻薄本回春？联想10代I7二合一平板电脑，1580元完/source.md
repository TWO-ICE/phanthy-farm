# 老款高配轻薄本回春？联想10代I7二合一平板电脑，1580元捡漏还是踩坑？

![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGyWQtBskNU2Qr0HZwn42MmiaHY6SqOmAOmaO97GQTKIhVVImZm0HFfP9icibt9AG5vnbXvMedCibic8RA/640?wx_fmt=png&from=appmsg)

在二手鱼刷到一台标价1580元的联想二合一电脑，配置单拉出来还挺体面，i7-1065G7、16GB内存、512GB固态、14英寸4K触控屏，还带手写笔和360度翻转设计。这配置感觉还不错，产品是2020年前后上市的，当时正值二合一商务本的小高峰，如今三年多过去，性能虽不再顶尖，但日常使用依然能打。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGyWQtBskNU2Qr0HZwn42MmY5V4szwoeBufZMjyRY2ZjhZLEoUVJlShlRvlGyVicgmzAzkhLI17Rjg/640?wx_fmt=png)


这台机器的型号是联想的Yoga C940，处理器是i7-1065G7四核八线程，集成Iris Plus核显，配合16GB内存和512GB NVMe固态，办公毫无压力，甚至轻度PS修图都足够流畅。4K分辨率的IPS触控屏不仅色彩细腻，还支持手写笔输入，对于需要批注PDF、做笔记或偶尔画画的用户来说，实用性远超普通笔记本。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGyWQtBskNU2Qr0HZwn42MmekB5o1BHa7yT5ItUapueJRTL24cKOIgdhkv09PCRdYIvREy1u8rE5A/640?wx_fmt=png)


不过高分辨率也带来一些隐性成本。4K屏幕在Windows系统下若未做好缩放适配，部分老旧软件界面会显得过小或模糊。此外，这类高分屏对续航压力较大，而i7-1065G7本身功耗控制虽优于前代，但搭配4K屏后，实际使用中电池撑不过5小时是常态。如果用户主要在固定场所使用，插电办公倒无妨，但若真如卖家所说“出差带着方便”，那得提前接受频繁充电的现实。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGyWQtBskNU2Qr0HZwn42MmRogeCicUBvtAbMIsMvI1CcaIJMbwb4FaAh2J2ZdYbCQNAlFBQQuQyMQ/640?wx_fmt=png)


目前全新入门级轻薄本普遍搭载12代或更新的酷睿处理器，16GB+512GB配置起售价多在4000元以上。而存储市场近期确有涨价趋势，512GB PCIe 3.0固态硬盘单独购买已接近300元，16GB DDR4内存条也要400元左右。单从硬件残值看，1580元的价格似乎不算离谱。但必须考虑的是，这款机器已停产多年，后续维修依赖第三方配件，且无法享受官方保修。若未来主板或屏幕出问题，维修成本可能接近甚至超过购机价。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGyWQtBskNU2Qr0HZwn42Mm1FmvQTMjU3OCEj3ich3aKt1DvWSqWghgaLkzBm1oUEDjjsGxYCUtfDw/640?wx_fmt=png)


可能有人会问，这机子还能用几年？这取决于用途。如果只是上网、看视频、处理文档，再战两三年没问题。但若涉及视频剪辑、大型软件或多任务重度使用，十代处理器的多核性能已明显落后于当前主流水平。那么它是不是智商税？未必。只要价格合理、功能完整，老设备也能发挥余热，关键看是否匹配你的需求。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGyWQtBskNU2Qr0HZwn42Mm64rB5W2RXfKWHQwVQ5A6xCHhCveMGtdw7iabjcO2jKuOBVSx2FjfqRQ/640?wx_fmt=png)


其实这类二合一电脑的实际用途其实很明确。比如学生用来记电子笔记、教师做课件批注、自由职业者移动办公，甚至作为厨房食谱查看器或客厅媒体中心都很合适。相比全新iPad加键盘套的组合，它运行完整Windows系统，兼容性更广，文件管理也更自由。当然，如果你追求极致轻薄或长续航，它显然不是最优解。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGyWQtBskNU2Qr0HZwn42MmbmAsXflaW7W2X73HUicDYSm9BQ6ITIvb229DZXpJxtx2mbMmiaSSL49w/640?wx_fmt=png)


对此产品有兴趣的话，可以在二手鱼搜索“联想银色触摸屏超轻薄360度旋转平板二合一电脑”这个关键字就可以找到此产品，如果找不到可以通过图片进行搜索，都搜索不到的话，那可能是此产品已卖出或者是下架了。


 


以下是个人一些掺了水的建议：

1. 办公学习够用，别指望高性能。

2. 外壳瑕疵可接受，重点验机功能。

3. 对比同价位新机，权衡保修与性能。

4. 看完不买，立省1580元。
