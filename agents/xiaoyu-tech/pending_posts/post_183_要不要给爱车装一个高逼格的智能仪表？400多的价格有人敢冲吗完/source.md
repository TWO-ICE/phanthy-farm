# 要不要给爱车装一个高逼格的智能仪表？400多的价格有人敢冲吗？

今天逛二手鱼的时候，发现个稀罕物，一个卖家在出全新车载仪表，标价428元。第一眼看到还以为是智能手表改装的，说实话这价格可不便宜，但这东西也确实不简单，是个纯纯C++裸机开发的嵌入式仪表，主打一个性能拉跨？不对，是主打一个快、稳、低功耗！


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekUoDLkrctkybp2G1fgGSjzNbTaye7BvFVcRmqvPxgE9icALR5ZPfYZkoGC7P351xicU4QPdEkJHAgbXmia1HEcLnfG6YIDQR4nlQ/640?wx_fmt=png&from=appmsg)


我仔细扒了扒卖家的描述，这仪表规格还挺硬核。480×480的高清分辨率，电容触摸屏，尺寸73×73×17mm，圆形的屏幕看上去非常有个性。它内置了GPS和北斗双定位系统，还有加速度传感器和气压传感器。所以它能显示车辆姿态、速度、海拔、气压、航向，还能记录行驶轨迹和海拔变化曲线。如果你喜欢跑山或者自驾游，这简直是神器。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenblCiaCGT8S4eUr61TibaHCDUaPEgxqrV68exFGVoriaDuMYo6pe1JSlPm7ib1BE9vMAXK0ct1IyTpdfib9OShYTEPdcaNW86sgGv8/640?wx_fmt=png&from=appmsg)


更绝的是它内置了全国离线地图，文件总大小8GB，存在内存卡里，而且支持远程升级。这可不是那种简单的路口指示，而是四级地图，能显示详细的街道名称。地图是基于OpenStreetMap开源全球地图，卖家说相同比例下比百度高德显示内容更丰富更详细。导航这块它不走寻常路，通过蓝牙连接手机小程序设置好路线发送到设备，后面就全靠它内部计算，不再依赖手机和网络了。说白了，进山没信号也不怕迷路。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelsQhWn2DX5e2TVNiasK4Bnb9og6XpcloAFE8icYT2ky8yUvYhaDjwq0VEeJc0uKc6S1OwZK3d13X4qgoUhDiaiavianSPLibl4dVFUg/640?wx_fmt=png&from=appmsg)


不过别急着下单，我得把丑话说在前头。这玩意不是安卓系统，没有CarPlay功能，不能安装软件，不能装百度高德导航，没有倒车影像和行车记录仪功能。它就是一块纯纯的专业车载仪表加离线导航仪。卖家也明确说了，它没有电池，必须插电使用，而且不防水，户外雨天不建议用。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekr43l4sV1X45OrohFib50DQWIc3QJLdwRPiacYew4x3qHmGGB5ZjSiag9nQZsnkNxFhiavUG8oCVicECbOQb751yaibicMckVDOuicmuE/640?wx_fmt=png&from=appmsg)


如果你是个纯粹主义者，或者开的是老车，想把仪表台改造成拉力赛风格，只需要最稳定可靠的行车数据和离线导航，那这玩意就是为你量身定做的。C++裸机开发意味着没有安卓系统的底层卡顿，开机速度、响应速度绝对秒杀同价位安卓机。想想看，几百块钱就能给你的老伙计增加一套专业级的数据记录和离线导航系统，还能当姿态仪玩，这不比花大几百去加装一堆花里胡哨却不实用的功能强吗？


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelkKNpaxzHPhKfVebF7NvnDpZxUeGozlfxIv8vkqbhTc6YNB7sia4ldhAI6ecZNMQujtibOq2Gu6pJlM3Or1k2v4xKhle9zvqlY8/640?wx_fmt=png&from=appmsg)


这块仪表优缺点极其分明，更像是个给玩家准备的玩具而非大众消费品。如果你下单，建议先确认自己的车有没有合适的ACC电源或USB供电口，以及安装位置是否方便。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelwnAsITbbDpTssibtFKXZzfeKlI0JzzlbMT3AqjucaA2plLKrdW24LYhKX9ibQQjUKoWqg3o5UwBIviadIPD9MbKN4icYwYgLvf3E/640?wx_fmt=png&from=appmsg)


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenxI4JjH5YfU5YE6mHrug8H5dLXBMPVxthSSYIoclhJeUQ4VeHQom9RnZztApO8D3ibCDKWaktn0k9h0sCibYxYdibOTzMKiaEwJJA/640?wx_fmt=png&from=appmsg)


另外，虽然它支持1/4标准螺纹支架，但仪表台开孔安装直径73mm，这个尺寸比较特殊，提前做好安装方案再下手。
