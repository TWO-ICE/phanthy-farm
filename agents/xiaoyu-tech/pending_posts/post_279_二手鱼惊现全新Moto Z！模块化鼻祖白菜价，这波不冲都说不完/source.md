# 二手鱼惊现全新Moto Z！模块化鼻祖白菜价，这波不冲都说不过去

今天在二手鱼刷到了一款摩托罗拉Moto Z（型号XT1650），标价290元，还是全新未拆封的库存机。说实话，看到价格那一瞬间我差点以为自己眼花了——这玩意儿当年可是顶着“模块化先锋”的光环登场的，现在居然白菜价躺平在海鲜市场？那么这波漏该不该捡呢？


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXE3vwzrmoZ5CNOvBxgqk2IMc8gOLpXxOIklicURrf2aWFcVcXVjdwQZyTkMpBbhfXtic0lhKn6MQeAA/640?wx_fmt=png)


作为第一个吃“模块化手机”螃蟹的老大哥品牌，摩托罗拉当年确实下了血本。Moto Z系列主打“超薄+模块扩展”，机身厚度仅5.2mm，号称全球最薄智能手机之一。整机采用航空级铝合金打造，拿在手里既有分量又不显笨重。屏幕是5.5英寸2K AMOLED，色彩表现放在今天也不算落伍。搭载高通骁龙820处理器，4GB RAM + 32GB 存储，还支持microSD卡扩展——这套配置在2016年妥妥旗舰水准，哪怕放到现在跑个日常应用也完全够用。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXE3vwzrmoZ5CNOvBxgqk2IMgiba3zYRzR9aw9FEes7sEArnEU4lHbq1dyGjHICjoVewPp97jGBl55w/640?wx_fmt=png)


可能有人会问：“这手机都停产好多年了，还能在国内正常使用吗？”答案是可以的。这款是国际版XT1650，支持移动和联通的4G网络（不支持电信），单卡设计。日常打电话、刷短视频、用微信都没问题。系统方面虽然官方只更新到Android 8左右，但民间有开发者做了适配，刷个LineageOS之类的也能继续战几年。不过别指望它能装最新版《原神》就是了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXE3vwzrmoZ5CNOvBxgqk2IMZ1N2lGGicTibDrRoRQuFyVqUriaiaInzQPCTliaLVK1TMIH3Q7kHfib8cibdg/640?wx_fmt=png)


再说说模块化这个核心卖点。Moto Z背部有16个磁吸触点，配合官方推出的Moto Mods配件，能秒变哈苏相机、JBL音响、投影仪甚至电池背夹。想象一下，把手机往相机模块上一贴，立刻拥有一台带物理快门的拍照设备——这玩法在当年真挺酷的。可惜摩托罗拉没开源Mod接口，第三方开发受限，导致生态没做起来。要是当时搞成类似Arduino那样的开放平台，说不定现在我们就能看到游戏手柄、血糖仪甚至无人机控制模块了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXE3vwzrmoZ5CNOvBxgqk2IMAzAzwg1yakAamQzOv6mBlykQfT1QOths5T8LzR9fP894aGBwnhcgdQ/640?wx_fmt=png)


那么，为什么这么有创意的产品最后没火起来？我觉得原因挺复杂。一方面，模块本身价格不便宜，一个官方相机Mod就要上千块，相当于再买一台中端机；另一方面，手机厂商后来纷纷转向“一体化设计”，追求防水防尘和结构强度，模块化反而成了累赘。再加上苹果三星牢牢把控高端市场，摩托罗拉这种小众创新很难突围。说白了，不是产品不好，而是生不逢时。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXE3vwzrmoZ5CNOvBxgqk2IMcJ48qUka8Ux80xric87vP2QKPHGzMLhicyejdTk08nMiaHK3ruxDGVXOg/640?wx_fmt=png)


参数方面再细说几句：前置指纹识别反应灵敏，背面无开孔设计让整机看起来非常干净；2600mAh电池确实偏小，但搭配TurboPower快充，15分钟能充进8小时用量；智能显示功能也很实用——抬手就亮屏看时间，不用按电源键。这些细节说明摩托罗拉在用户体验上下了功夫，不是光靠噱头。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXE3vwzrmoZ5CNOvBxgqk2IMLS6xxhPPBGwhTmlnHCRUfP8Vl7icyMf7wibJ8zCd1Ng3lqAbjmkP8Agw/640?wx_fmt=png)


现在这批290元的库存机，据卖家说是“全新仅拆封”，配件齐全，连塑封膜都还在。虽然系统版本老、售后无保障，但拿来当备用机、玩机收藏或者折腾Mod实验，简直不要太值。尤其对喜欢捣鼓硬件的极客来说，这价格等于白送。可接受，真的可接受。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXE3vwzrmoZ5CNOvBxgqk2IMjSmwcmtToo4ygLNJIGSv7BO6PMyEIBPTzFPrSamFeflfThRsPwyVew/640?wx_fmt=png)


最后唠两句：模块化手机或许是个失败的商业尝试，但它代表了一种敢于打破常规的探索精神。在如今千篇一律的全面屏时代，回看Moto Z那种“手机+乐高”的思路，反而觉得有点浪漫。如果你也怀念那个手机还能自由组合的年代，不妨去二手鱼搜搜看。老规矩，看完不买，立省290元。
