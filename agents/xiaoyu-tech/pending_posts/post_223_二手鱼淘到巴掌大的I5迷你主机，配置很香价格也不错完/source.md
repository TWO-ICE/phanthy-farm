# 二手鱼淘到巴掌大的I5迷你主机，配置很香价格也不错

今天在二手鱼刷到了一款巴掌大小的迷你主机，标价249元起，处理器是I5 7Y54或M3 7Y30，板载8G内存，配置很香，价格也不错。话说这玩意不会是电子垃圾吧？但瞅着那“i5”的标，又觉得“有枣没枣打三竿子”，看看又不花钱。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHvrrTA679X47QgrHibicRUROf0CXTZH8yhKl7ciavCx0Jo6Dr7RRIDZHag0PKbaphJ7ibU4piayPKDGwA/640?wx_fmt=png)


先说核心参数。这台小主机用的是Intel第七代超低功耗U系列处理器，I5 7Y54基础频率1.2GHz，睿频可达3.1GHz；M3 7Y30稍弱一点，但日常轻办公、跑个Linux系统或者做软路由完全够用。TDP只有4.5W，发热极低，配合HD615核显，硬解1080p视频毫无压力。对比那些还在卖J1900、J4125甚至N5100的卖家，这性能属实有点“降维打击”的意思了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHvrrTA679X47QgrHibicRUROJuoo5Qp85MZU07euXHOdmuh9iasyfEtt7Utz0LXicpAcvd8RlP4HlztA/640?wx_fmt=png)


内存方面，板载8GB双通道LPDDR3，焊死在主板上，没法升级。不过好消息是，板子上还有两个空焊盘——理论上能加焊到16GB，但对普通用户来说基本等于“纸上谈兵”。硬盘得自备一块M.2 SATA协议的2280固态，注意不是NVMe！这点新手容易踩坑。供电也得自己解决：要么用圆孔DC 12V（5.5×2.5mm），要么Type-C PD电源（需支持12V输出）。所以别光看主机便宜，加上电源+硬盘，实际成本大概要再加100块左右。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHvrrTA679X47QgrHibicRUROkjyaavA7vk87omQBbicoXZicRGhAG9hLJjqn9pEekMSwwZ43nwtx2Z9Q/640?wx_fmt=png)


接口倒是挺全：一个全功能Type-C、mini HDMI、USB 3.0、TF卡槽、3.5mm音频口，甚至还有一个EDP屏接口——据说能驱动ROG那块7寸120Hz小屏，DIY玩家狂喜。网卡是Intel 3165，带Wi-Fi 5和蓝牙4.2，虽然不算新，但稳定够用。有人可能想组NAS？可以，但千兆网口是瓶颈。不过可以去拼夕夕花几十块买了USB转2.5G网卡，或者接SATA扩展坞搞多盘位，硬生生把这小盒子玩成黑群晖。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHvrrTA679X47QgrHibicRUROHrbeUI1HP2fiafyVGVOGaZ9iaUEjcMr6wT80OS6Hy3YMDqmBcRthWA0w/640?wx_fmt=png)


那么，外壳做工咋样？实话实说：别抱太高期待。毕竟是用拆机笔记本主板DIY出来的，塑料壳子毛边、缝隙不均、贴纸歪斜都很常见。卖家自己都写明了：“两百多的玩具，只够材料费，亏人工费的东西，没法打磨外壳。”你要追求MacBook级别的质感，建议出门右转买全新。但如果你只是想要个安静、省电、能跑服务的小主机，这瑕疵完全可以接受。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHvrrTA679X47QgrHibicRUROa4ibbopmPYI8uyxhxyQ4PxYX99sA3Yk85ialVyQtXIdWliblLicGibTyRDw/640?wx_fmt=png)


可能有人会问这玩意儿和J4125/N100比有啥优势？CPU单核性能强不少，尤其适合需要一定计算力的场景，比如Docker容器、轻量虚拟机、甚至挂个Emby转码。而J系/N系赛扬主打多核低负载，适合纯NAS或软路由。两者定位不同，但同价位下，I5 7Y54的综合体验确实更“香”。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHvrrTA679X47QgrHibicRUROklOj6fkSacj4lFTfMSy3ib4DNRRkS4qeGtWFM5SC4j9hiaCgZ9icZeiaeQ/640?wx_fmt=png)


也可能有人担心“二手U会不会寿命短？”其实这类低功耗U本来就是为笔记本设计的，即便拆机件，只要没暗病，用个三五年问题不大。而且整机才两百多，就算挂了也不心疼——这个价格还要啥自行车？


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHvrrTA679X47QgrHibicRUROorzmMlms4vXsJ97xv14JSnBJDWVYP7L3GyMKtq6HOd3UO8L2cYdSfg/640?wx_fmt=png)


目前二手鱼上类似配置的迷你主机，J4125 8G版本普遍卖220-260元，N100要280往上，而带I5 7Y54的几乎清一色275元左右。考虑到它更强的CPU和核显，多花二三十块换来的性能提升，值。

如果你对此有兴趣的话，可以参考下面几条建议：

1. 想搭轻量NAS或软路由？它够用，但别指望高性能。

2. 要玩黑群晖/飞牛OS？建议加USB-SATA扩展，硬盘另配。

3. 追求静音低功耗？这U TDP仅4.5W，风扇都可被动散热。

4. 看完不买，立省275元。
