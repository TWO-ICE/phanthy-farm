# H3C的老咕噜棒子秒变全能神器！125元捡漏的H3C C100主机亏不亏？

现在一包烟钱，就能买一台能亮机、能解码、还能7x24小时开机的电脑了？二手鱼里有人125元价格，出一台迷你主机，品牌是H3C的，型号是 C100。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelXUZ0351LlcOHDUdsHg4rEqPwoHNYGX1M09DGygxqSCdvia1ZN0NlaUO1R6Ivib51mq8rw98DJxb7QRxq6UdKSHQiczsTGibuiaI1E/640?wx_fmt=png)


处理器是刚才说的Atom Z8350，四核四线程，性能嘛，非常垃圾，但不用担心，它的战场不在这里。内存2GB，存储是16GB的eMMC，接口是它的亮点，千兆网口、HDMI、VGA，尤其是足足6个USB口（混合了2.0和3.0），扩展性在这个价位堪称豪华。卖家宣称整机功耗仅4W左右，如果属实，那常年开机的电费成本几乎可以忽略不计。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekID3X0HZpHbURticiawXj3fYCYZAZU68drYwcFLhAMBKP6JrmV7hD9s8UzRyewbFQ3shELlkoab4797BsKgbh0ibgT6j6amjEdsk/640?wx_fmt=png)


它的优点和缺点都同样鲜明。优势就在于极致的性价比和超低功耗，买来纯粹为了折腾和实现特定功能，是非常合格的“实验平台”。卖家提供的玩法指南很全，刷iStoreOS或爱快做软路由，优化网络；刷达菲系统变成一台无损音乐播放器，讨好耳朵；刷Linux玩Docker，部署下载器或智能家居应用；甚至装回原厂系统当个超省电的下载存储小盒子。一机多玩，可塑性很强，这正是它吸引人的地方。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelSfibJRIwXmiaY0BEIhGq6vM0DiaAz73DRrXA5fNaZl2gcRPicD3x5CgbvjjicPbibt3khUVkDczibrpla3Xjg2ictiavDxFBbQPMxy9bI/640?wx_fmt=png)


但是，它的缺点也很硬核。Z8350的性能非常有限，2GB内存和16GB存储是最大的瓶颈，意味着你几乎不能同时运行多个稍吃资源的服务，装完系统可能就没剩多少空间了。它不适合作为主力设备，甚至作为轻办公主机都会很吃力，网页开多了都卡。它的价值完全在于“专机专用”，当一个安静的工具。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenpKJgtwkLEbISIbmYNVwNK7U4T6BK873sric65LZThfzFEzEhKP7haITozL0iatwS1Tvby2QxLfNouZ7qpCOUbPghKjw3lDxjf0/640?wx_fmt=png)


所以，给想入手的朋友一点实在建议。只是需一个纯粹的下载机、音乐播放终端，那它可以考虑。其次，务必让卖家刷好系统并配好电源，自己折腾寻找适配的固件、解决驱动问题，对于新手可能是噩梦，125元买的是玩具，不是麻烦。最后，管理好心理预期，它就是一台125元的电子设备，用残值的眼光看待它，只要它能稳定完成你赋予的一两项任务，就是血赚。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCek2ics7Q4gL0HK6PHdicnqbPJpumZMZ0giayiaWYbPdZSXDOjA1r9fr6GQcicJBfNoYZo527DgVClMkmfibyvGvMJ1wTL345af3xSt2E/640?wx_fmt=png)


哦，对了，很多人一定想知道能不能刷最近很火的飞牛。我查了一下，FN OS对X86设备有兼容列表，但Z8350这类低功耗老平台的驱动支持是个问题。虽然有极客成功移植的案例，但过程绝不轻松，需要自己编译内核、找驱动，属于高阶玩法。对于绝大多数想省心的朋友，我不建议将“能刷飞牛”作为购买它的主要理由，用它玩转卖家提到的那几个成熟系统，已经足够有趣了。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemrZKjru8yauqKRepznOhh00VD7xE7ryk5TrtTyE3TStb5Ngs1sh3icvgjdyvKvGVp88lFBrIBNRukHNvXLHvgCANSibQ5UHTSsk/640?wx_fmt=png)


说到底，125元买的是一段折腾的乐趣，一个满足特定需求的解决方案，也是对电子设备生命末期价值的一次探索。它像一颗螺丝钉，虽然不起眼，但正好能拧紧某个松动的角落。你会为这样的“电子螺丝刀”买单吗？或者，你在二手鱼里还淘到过什么更不可思议的宝贝？评论区聊聊你的捡漏故事吧！
