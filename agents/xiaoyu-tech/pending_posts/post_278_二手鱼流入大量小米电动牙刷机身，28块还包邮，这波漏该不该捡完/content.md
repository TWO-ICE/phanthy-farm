# 二手鱼流入大量小米电动牙刷机身，28块还包邮，这波漏该不该捡？

最近这阵子，如果你经常逛闲鱼，大概率会被那种铺天盖地的“小米电动牙刷机身”给刷屏。那种感觉就像是所有的库存都在一夜之间涌了出来，清一色的小米米家T302型号，图片摆得整整齐齐，价格却统一得让人心里发慌——28块钱，还给你包邮。

这些卖家手里的存货量看着非常吓人，动不动就挂着“大量现货”、“随机发货”的牌子。文案也是出奇的一致：“原装正品，功能完好，动力强劲，续航无虞”。这就让人不得不犯嘀咕：这到底是哪来的神仙货源？难道小米的仓库漏水了？

但不管来源如何，摆在咱们面前的现实问题是：当市面上正规的全新机还得卖上一百多块的时候，这28块钱的“单机身”，到底是不是个值得捡的大漏？买回来能不能用？会不会是个坑？今天咱们就把这个“28块钱的快感”放在解剖台上，从里到外掰扯清楚，看看这波羊毛到底该不该薅。

### 先看看这玩意儿本身值多少钱

咱们先不说二手，单看这台小米米家T302的“出厂身价”。哪怕是在现在的官网货架上，它依然还在售，标价139元。在如今电动牙刷市场极度卷、两三千的声波牙刷和几百块的国货神仙打架的环境下，这款T302确实算不上什么高端货，它连个智能APP连接都没有，甚至连彩屏都欠奉。

但是，你要知道它是小米。在百元这个档位，小米从来都是“守门员”级别的角色。

它的核心参数其实一点都不落伍：每分钟31,000次的震动频率，这是声波牙刷的标准及格线，甚至比某些杂牌宣称的几万次还要实在；机身内置了四种清洁模式，不管是早上刚醒来需要温柔的“轻柔模式”，还是昨晚吃了顿火锅需要强力去污的“强力模式”，它都给你安排得明明白白。

更关键的是它的接口和续航。在这个很多产品还在用老式圆孔充电器的时候，它用上了Type-C接口，这意味着你出门不用多带一根线，直接用手机充电线就能搞。而官方标称的65天续航，虽然听起来没那么夸张，但对于一个没有内置锂电池的老模具来说，这已经是“充一次电，扔那儿两个月不用管”的省心水平了。

所以，从产品底子看，这并不是那种电子垃圾，它是一个正儿八经的、经过了市场验证的、参数合格的日用电子产品。

### 28块钱，你买到的是什么？又失去了什么？

好了，咱们回到正题。这28块钱包邮，到底给你留下了什么，又砍掉了什么？

卖家说得很清楚，这仅仅是个“机身”。也就是说，当你满怀期待地拆开快递那个破破烂烂的纸箱子时，里面只有一根光秃秃的牙刷杆子。

第一，没有原装底座。官方原装那个漂亮的、能感应充电的底座是没有的。这带来的直接后果就是，你得找个地方放它，或者每次充电时都得把它插在USB口上，那种“随手一放即充”的仪式感荡然无存。

第二，没有刷头。这才是最要命的。牙刷没有刷头，就像汽车没有轮子。你收到货后，第一件事不是去刷牙，而是得赶紧去下单买刷头。在你收到刷头的那几天里，你只能对着这根塑料杆子发呆。

第三，所谓的“随机发货”和“成色不一”。这是二手交易的潜台词了。虽然是所谓“原装正品”，大概率也是从各种渠道回收来的拆机货。机身颜色不保，你想要个骚粉色可能给你发个冷冰冰的深蓝色；外壳成色更是玄学，大概率会有细微的划痕，或者那些怎么也擦不掉的污渍。对于那种有“洁癖”、看着一点划痕就难受的朋友，这简直是精神折磨。

第四，也是最隐蔽的坑：二手马达的不确定性。电动牙刷的核心是那个高频震动马达。这种几十块钱的拆机货，没人给你做质保。你可能会遇到那种“空转异响”的情况，一开机手里拿的不是牙刷，是个电钻，嗡嗡嗡地震得手麻，或者震动轴发生了偏移，刷头装上去歪歪扭扭。这些风险，都是你为了省那100块钱必须要承担的代价。

### 但是，28块钱确实也就是一杯奶茶钱

说了这么多缺点，为什么我还是觉得这玩意儿有点香？

咱们换个场景想想。28块钱，现在的物价，甚至买不到两杯像样的奶茶，也就够吃一顿稍微好点的盖浇饭，或者买张电影票还得选个早场特价。

在这个价格语境下，这根牙刷机身就突然变得合理起来了。

如果你不仅仅把它当作主力牙刷，而是把它定义为一个“旅行备用机”或者“吃灰神器”，那它的性价比就无敌了。出差带个几百块的戴森或者飞利浦，丢了心疼，放在洗漱包里还占地儿。但这根28块钱的小米T302，随便往包里一塞，Type-C线一充，丢了都不带哭的。

更有意思的是，如果你懂点闲鱼的套路，去跟卖家聊一聊，问问“打包几个能不能便宜”，你会发现这东西还有水分。很多人反映，如果一次买两三个，或者甚至买五六个凑个单，价格还能压到20块钱左右。瞬间还能再省8块，20块钱买个震动棒——哦不，电动牙刷，还要什么自行车？

哪怕是买回来不是为了刷牙，就是为了拆开看看里面的磁悬浮马达是怎么工作的，或者给家里的小孩当个“过家家”的玩具（别真塞嘴里，这震动力对小孩牙齿不好），这20块钱花的娱乐属性都拉满了。

### 真正的隐形成本：刷头才是吞金兽

这时候可能有朋友会说：“那我还是想当主力牙刷用，28买个机身，再配个刷头，岂不是美滋滋？”

别急，咱们来算一笔账。电动牙刷界有个不成文的定律：机身可以便宜卖，甚至可以倒贴送，但刷头才是真正的“利润奶牛”和“消耗大头”。

你拿到了这个28块钱的机身，转身去搜“米家T302刷头”，你会发现一个新的世界。

如果你不介意非原装，也就是俗称的“通用刷头”或者“替代刷头”，价格确实非常感人。闲鱼上最低能报到16块钱5只。这个价格，白送都没人亏。卖家往往会把文案写得天花乱坠：“全新未拆封”、“真空独立包装”、“杜邦刷毛”、“高磨圆率”。但咱们心里得有数，16块钱5只，平均一只3块2，还要包运费、包装、人工，这刷毛能是啥高级货？

这种非原装刷头，实际体验通常是两个极端：要么是刷毛硬得像钢丝球，刷完牙龈出血三天；要么是植毛技术不行，用一周就开始“炸毛”，中间高两边低，刷得牙齿酸软。所谓的“磨圆率”，在这种廉价刷头上基本就是个玄学，用显微镜看大概率都是刀片般的切角。

那如果你是个原厂党，非要买原装刷头呢？那恭喜你，你将进入另一个价格体系。

我在闲鱼上扒拉了一下，所谓的“原装拆机刷头”，价格大概在30块钱左右，而且通常是不包邮的。要是去官方渠道或者旗舰店买全新的原装刷头，那价格简直是“刺客”级别——69块钱一盒，里面只有3只。

来，咱们现在做一道数学题：
**“穷人才做选择”方案：** 机身28元 + 非原装刷头16元（5只） = 44元。
这意味着，你花44块钱，拥有了一整套电动牙刷，加上5个可能有点扎肉的刷头，如果不勤快刷牙，勉强够你用大半年。

**“追求原厂体验”方案：** 机身28元 + 拆机原装刷头30元（约数） = 58元。
这还没算运费。而如果你想用全新的原装刷头，那成本直接飙升。

这时候，44块钱的“拼装机”似乎还凑合？但这真的就是省钱的终极方案吗？

### 对比官方：有时候“拼凑”并不比“买新”划算

咱们必须得看看官方现在的动作。小米作为一个懂得营销的公司，他们深知清库存和打价格战的套路。

目前小米官方渠道也在搞活动。原价139元的T302，现在虽然没直接降价到99，但是它的赠品策略非常凶猛。经常会送价值69元的“牙膏+漱口水+牙线棒”的豪华礼盒。而且，重点是，原装的盒子里，本身就自带4个刷头和一个那个感应充电底座。

咱们来算笔更宏观的账。

如果你走官方渠道，花139元，你得到的是：
1.  全新的、没划痕的、有保修的机身。
2.  4只正儿八经的原装刷头（价值不菲）。
3.  一个放在洗手台上看着很舒心的无线充电底座。
4.  各种凑数的洗护用品赠品。

如果你走闲鱼“拼装”路线，为了达到类似的体验，你需要：
1.  28元的二手机身。
2.  假设你想用原装刷头，哪怕你去买最便宜的拆机原装刷头，凑齐4只也要花个30-40块钱。
3.  你还是没有充电底座（这玩意儿单买也不便宜）。
4.  你没有官方保修，明天坏了就是手里的一块砖头。

这么一比，官方的那个139元，虽然看着比28贵了111块钱，但它包含的服务和配件价值，其实完全把那111块钱给填平了。多花的钱，买的是“省心”和“正常”。

### 灵魂拷问：你是要“体验”还是要“工具”？

说到最后，这28块钱的机身到底该不该买？其实不是个数学题，是个“用户画像”题。

如果你的场景是：我刚毕业，手头紧，想体验一下电动牙刷是啥感觉，不在乎刷毛硬一点，不在乎机身有划痕，甚至不在乎它能不能撑过这个冬天。那么，44块钱（机身+杂牌刷头）的闲鱼拼装机，绝对是你人生路上的好伴侣。它用最低的成本，帮你完成了从手动刷牙到电动刷牙的跨越。就算哪天坏了，你扔了都不带心疼的，大不了再花28买个机身。

或者，你的场景是：我已经有个很好的电动牙刷了，但我经常出差，或者我想在公司备一个，防着哪天加班回家太晚懒得刷牙用——哦不，是为了方便在公司午饭后清洁。那28块钱的机身，哪怕配个便宜刷头，扔在公司也不心疼，丢了就丢了，这就是它的价值。

但是，如果你是个对生活品质有要求，每天早晚雷打不动要刷牙两分钟，对牙龈呵护很看重，甚至对洗手台摆设的颜值都有要求的人。

**听句劝，别折腾这28块钱了。**

二手马达潜在的噪音风险，杂牌刷头对牙龈不可逆的物理伤害，以及没有底座乱拉线的杂乱感，这些隐形的不爽，迟早会把你那省下来的100块钱给反噬回去。这时候，哪怕官方贵一点，哪怕你蹲个打折买新的，那个全新的、质保内的、刷头靠谱的官方正品，才是对你口腔健康最负责任的选择。

归根结底，这是一场关于“需求”的博弈。28块钱买个机身，捡的是“漏”，也是“雷”。你是愿意为了省钱去承担组装和风险，还是愿意为了省心直接买单？看着屏幕上那些28元还包邮的链接，你是点击“立即购买”，还是直接划走？这恐怕得看你最近的余额，以及你对那几根刷毛的挑剔程度了。

在这个万物皆可二手的时代，有些漏捡了是锦上添花，有些漏捡了可能就是给自己添堵。至于这小米T302的机身，你是想当个备用机折腾一下，还是想正经刷牙，心里应该有数了吧？
