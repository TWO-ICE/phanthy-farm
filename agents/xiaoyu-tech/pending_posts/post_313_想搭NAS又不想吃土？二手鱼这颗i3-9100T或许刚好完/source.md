# 想搭NAS又不想吃土？二手鱼这颗i3-9100T或许刚好

今天在二手鱼刷到了一款I3-9100T CPU，129块还包邮，顺手点进去一看，成色几乎全新，下单送硅胶还有一年质保，话说就这个U的性能完全碾压各种飞牛圣体，再淘个H310主板和DD4内存，用不上500就能窜出来一台NAS小霸王主机，性价比没得说。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGUeeyibgryNaKDMJVJGFGiaMTC2viaOucKx8YeTibMVKRZWxHKe9n9EhGNwGRRnwLbicW0U5X2h3l31lQ/640?wx_fmt=png)


 


先说说这颗U的基本参数：Intel Core i3-9100T，属于第九代Coffee Lake架构，4核4线程，基础频率3.1GHz，最大睿频3.7GHz，TDP只有35W，比标准版i3-9100的65W低了一半还不止。对于搞NAS、软路由、轻量级HTPC或者工控小主机的朋友来说，这个功耗简直是“省电又安静，睡觉不吵人”。虽然没有超线程，但日常办公、网页浏览、影音播放完全够用，甚至跑个轻量虚拟机也不虚。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGUeeyibgryNaKDMJVJGFGiaM2F1Sq3MZlWwGb6JNYJwqCibmEdRAO0F6I2SWXefQJywlAWic9X6Tbia8Q/640?wx_fmt=png)


再聊聊它的内存支持。i3-9100T原生支持DDR4-2400，双通道模式下带宽翻倍，搭配两条8GB内存条跑起来毫无压力。卖家页面也特别标注了“双通道正常”，说明主板兼容性没问题。不过得提醒一句，这U只支持到第9代芯片组（比如B365、H310这些），如果你手头是Z790主板，那可真是“牛头不对马嘴——插都插不进去”。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGUeeyibgryNaKDMJVJGFGiaMCvia3uNtoBkMRQURRZMUNvYAnicotlYEcXzTPHZhNC5TL5nPPoFFBfkw/640?wx_fmt=png)


说到优势，除了低功耗和稳定性，这颗U还有一个隐藏buff：它是正式版（非ES/QS工程样品），意味着体质靠谱、寿命长，不像某些拆机片动不动就蓝屏死机。而且卖家还贴心地送硅胶、包好包装发货，甚至提供一年质保——在这个价位段，还能要啥自行车？缺点嘛，当然也有：不能超频、无超线程、核显性能一般（UHD 630），玩不了游戏，剪视频也吃力，但谁指望129块买个生产力怪兽呢？


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGUeeyibgryNaKDMJVJGFGiaMEYvcvjnuUB9qlxju5qniaRanfe5fqUzVzrxn4VFib4tzVpgMwOwoyibyQ/640?wx_fmt=png)


可能有人会问这U是拆机件，会不会寿命快到头了？看成色和来源。卖家明确写了“功能完好无维修”“成色如图”，且是批量库存拆机件，并非从报废电脑里抠出来的。加上Intel CPU本身寿命普遍较长，正常使用三五年问题不大，更何况35W低负载下发热小，老化更慢。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGUeeyibgryNaKDMJVJGFGiaMTmn8ufbxgfibnxjre7Mib8UZsstMCEC85lUVUMqNic5DbQfNl0IpzibkKg/640?wx_fmt=png)


那么129块是不是有坑？会不会是假货？目前二手鱼上假Intel CPU极少（造假成本高、风险大），多数是翻新或ES片冒充正式版。但这位卖家强调是“正式版”，并附实物图，中通包邮+一年质保，基本排除骗局可能。真要不放心，收货后用CPU-Z验个ID就行，几秒钟的事。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGUeeyibgryNaKDMJVJGFGiaMJ2rs0LjawRkv8MS7BHufI8Fkib7icgGxKwoicib2TC9ia2n2URRqd1NeWMw/640?wx_fmt=png)


其实这类老平台U在二手鱼一直有稳定需求，尤其适合折腾党拿来搭低成本服务器、飞牛下载机、或者给爸妈装个安静不卡的上网机。129元的价格，比某些品牌整机里的J系列赛扬还便宜，性能却强出一大截，性价比确实可接受。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGUeeyibgryNaKDMJVJGFGiaMzAeOAXJSxByUBUH5bLPpibFkz2phZDmc8DqfiaMHBJ6uzNe6yXFicF43g/640?wx_fmt=png)


如果你正好缺一颗低功耗、稳定、便宜的Intel四核U，不妨去搜搜看。记得对比几家，看看评价和发货速度。别光看图，多问一句“是否测试过双通道”“有没有暗病”，毕竟二手交易，细节决定体验。最后，欢迎在评论区聊聊：你用过i3-9100T吗？拿来干啥了？有没有翻车经历？一起避坑，一起捡漏。老规矩，看完不买，立省129元。
