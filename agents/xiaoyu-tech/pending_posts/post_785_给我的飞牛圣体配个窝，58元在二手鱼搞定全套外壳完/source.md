# 给我的飞牛圣体配个窝，58元在二手鱼搞定全套外壳

今天在二手鱼刷到了一款ITX小机箱，标价才50块还带200W电源，点进去一看，好家伙，成色基本九成新，无生锈、无灰尘、无翻新，描述里连着三个“无”，看得我心头一紧——这年头还能找到这种状态的二手ITX机箱？关键是尺寸刚好能塞进我那套飞牛圣体，价格亲民，简直像白捡。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXHN4RLgUG7ytvu5iakqAMZC3FkhwbicoxM5YfUcib1RsvibibTuh2RPPWzGstEsPYz4c4GMiclZHD9EDlNg/640?wx_fmt=jpeg)


这款机箱型号是QuickPC ITX 8L，体积比A4纸略大一点，具体尺寸是厚9.4cm、高29cm、长29.5cm，属于标准的小身材大容量选手。别看它小，内部结构还挺合理：支持17×17到19×20cm以内的主板，也就是说Mini-ITX和部分Thin Mini-ITX都能装。对于想搞低功耗HTPC或者NAS的用户来说，简直是“小钢炮”本炮。不过要注意的是，超过19×20cm的板子就别硬塞了，不然容易“主板变折纸”。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHN4RLgUG7ytvu5iakqAMZC3VtUia6Ydfj6fF64fXyq6IkWLIbNf6eGiabBMjD3egnOicict7ZD10owLoA/640?wx_fmt=png)


接口方面，前面板配了两个USB 3.0，日常插U盘、移动硬盘完全够用。机箱内置一个2.5英寸和一个3.5英寸硬盘架，做双盘NAS或者轻量级服务器绰绰有余。卖家提供了两种套餐：单机箱15元，电源30元（200W），打包一起40元不包邮。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHN4RLgUG7ytvu5iakqAMZC39QZb3ibuKkibUxpb5rWoJlkEGLCvLKhjsnpIokJtPoeSERX3XZU39TYg/640?wx_fmt=png)


我选的是机箱+电源组合，加上运费18元，总共58元拿下。虽然电源功率不高，但对于NAS主机这类低功耗CPU+核显平台完全够用。如果你打算上独显，那建议另配更高瓦数的SFX电源。另外，机箱表面有轻微掉漆和划痕，但不影响使用，毕竟二手嘛，这个价格还要啥自行车？


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHN4RLgUG7ytvu5iakqAMZC3Uv4Z7lY3A1nkH6iaiafuibZB4ZPRmpmCcibCqsqZqyyDFODLw0rO0j1cvQ/640?wx_fmt=png)


对比二手鱼上其他同类ITX机箱，普遍价格在80–150元之间，带电源的基本都要百元起步。而这款40元包机箱电源，成色又干净，实属“漏中之王”。当然缺点也有：体积虽小但散热一般，没风扇位，全靠被动散热；扩展性也有限，只能装一块3.5寸盘，对多盘位用户不太友好。但如果你只是要个安静、小巧、能跑飞牛OS的壳子，它真香。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHN4RLgUG7ytvu5iakqAMZC3uCLr18t29XZbdOOCfEYevZmNnrgAdX4hFxGyFSB24qn1bt2TQ62LKQ/640?wx_fmt=png)


如果你也在找便宜靠谱的小机箱，不妨去二手鱼搜“QuickPC ITX 8L”，以下是一点建议：

1. 预算50元内想组ITX小主机？闭眼入。

2. 别指望高性能，但家用NAS/软路由/下载机足够。

3. 务必提前沟通是否含电源，避免误会。

4. 看完不买，立省58元。
