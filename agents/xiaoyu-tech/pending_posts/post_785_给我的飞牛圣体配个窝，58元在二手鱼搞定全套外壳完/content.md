# 给我的飞牛圣体配个窝，58元在二手鱼搞定全套外壳

作为一名长期混迹于二手电子市场的垃圾佬，我深知“捡漏”这个词背后隐藏着多少成色不明的雷区和翻车事故。但也正是因为这种不确定性，才让每一次闲鱼刷屏都像是在开盲盒。就在今天，原本只是漫无目的地在那片“电子坟场”里溜达，一款标价50元还自带200W电源的ITX机箱突然闯进了视野。

点进详情页的那一刻，我不禁倒吸一口凉气。卖家在描述里极其自信地连用了三个“无”——无生锈、无灰尘、无翻新。这在二手段位里简直就是“白捡”的代名词。要知道，在这个价位段，大部分机箱不是被烟熏黄了就是锈迹斑斑，能做到这种“三无”状态的，简直比在相亲市场找对象还难。这成色，保守估计也得是九成新，关键尺寸还完美适配我手里那套闲置已久的“飞牛圣体”。既然价格亲民到这种地步，还要什么自行车？下单！

在这个盒子面前，我们先不谈情怀，只谈物理属性。这款机箱的具体型号是QuickPC ITX 8L。这里的“8L”指的是容积，听起来可能没什么概念，这么说吧，它的体积也就比一张标准的A4纸大那么一圈，甚至可以说相当紧凑。具体的三维数据是这样的：厚度9.4厘米，高度29厘米，长度29.5厘米。

对于寸土寸金的桌面环境或者客厅摆件来说，这种“小身材大容量”的设定简直是福音。别看它方方正正像个甚至有点像薄饼盒，内部结构设计得却相当有讲究。它在主板兼容性上给出了一个很微妙的范围：支持从17×17厘米的标准Mini-ITX主板，一直向下兼容到19×20厘米的Thin Mini-ITX主板。这意味着什么？意味着你不仅可以用它来装常规的ITX板子，对于那些想搞低功耗HTPC（家庭影院电脑）或者软路由、NAS的用户来说，这也是个完美的容器。不过千万别飘，超过19×20厘米的大板子就别硬塞了，这机箱不是俄罗斯方块，硬塞的结果只能是“主板变折纸”，物理层面的不可抗力谁都救不了。

聊完内部，我们来看看外面的接口。前面的I/O面板虽然算不上豪华，但也绝对够用：配备了两枚USB 3.0接口。在这个年代，虽然USB 3.2甚至Type-C已经开始普及，但对于一个二手几十块钱的小钢炮来说，USB 3.0已经能保证你插U盘、移动硬盘传输数据时不至于看着进度条怀疑人生。

再深入到机箱内部，它的存储扩展设计得非常务实，非常精准地卡在了“够用”和“浪费”的平衡点上。机箱内预设了一个2.5英寸盘位和一个3.5英寸盘位。这个组合非常经典：2.5寸盘位正好塞进去一块SATA SSD做系统盘，保证飞牛OS或者Windows系统秒开；那个3.5寸盘位则是留给机械硬盘的，用来存电影、存照片。对于想要组装双盘位NAS或者轻量级家庭服务器的玩家来说，这套配置简直是“精准打击”。

卖家也是个实在人，直接列出了两种套餐：单机箱只要15元，那个200W的电源单卖30元，但如果打包带走，只要40元（不包邮）。我盯着屏幕稍微算了一笔账，单买机箱不包电源还要折腾，不如直接打包。于是果断选择了机箱加电源的组合，加上18元运费，总共58元落地。

这里得重点聊聊那个200W电源。很多硬件发烧友看到200W可能会嗤之以鼻：“这点功率能干啥？”其实这是一种思维误区。对于NAS主机、软路由或者HTPC这类低功耗平台，我们通常使用的都是低TDP的CPU（比如J4125、i3这类）搭配核显，整机的满载功耗往往连60W都不到。这种负载下，200W的电源不仅绰绰有余，甚至能工作在电源转化率最高的区间，既省电又安静。当然，如果你想在这个小盒子里塞一张RTX 4060或者别的独显，那确实需要另配高瓦数的SFX电源，或者干脆换个机箱，毕竟那是另一个维度的需求了。

至于外观，收到的货确实如描述所说，表面有些许掉漆和细微划痕。但对于我们这种实用主义者来说，只要结构不变形，板材不生锈，掉点漆算什么？那是岁月的馈赠。把它塞进电视柜后面或者书桌角落，谁会盯着那点漆面看？在这个价位面前，所有的外观瑕疵都是可以被原谅的。

为了验证这58元到底花得值不值，我又去二手鱼上逛了一圈，做了一个简单的市场调研。目前同类别的二手ITX机箱，哪怕是最山寨的杂牌，价格普遍也都在80到150元之间。如果你想要那种带侧透玻璃、设计稍微有点模样的，基本百元起步只是门槛，还得是不带电源的“裸箱”。相比之下，这款QuickPC 40元包机箱加电源，且成色干净无锈，绝对是当之无愧的“漏中之王”。

当然，作为一篇客观的评测，我必须得把它的短板也摊开来说。首先，受限于体积和成本，它的散热能力确实很一般。机箱内部没有专门的风扇位，除了电源自带的小风扇，基本全靠自然对流散热。如果你的CPU发热量巨大，或者那个3.5寸硬盘是块高转速的“火炉”，那么夏天时机箱内部温度可能会让你有点焦虑。其次，扩展性确实有限，只有一个3.5寸位，对于想搞RAID 5或者动辄七八块硬盘的NAS玩家来说，这盒子显然不够用。但，如果你只是像我一样，需要一个安静、小巧、能跑飞牛OS、放在角落里吃灰下载的壳子，它真的是“真香”警告。

最后，如果你也被我说得心动，准备去二手鱼淘一个，我有几条肺腑建议想分享给你：

1.  **预算控制**：如果你的预算在50元以内，且想组一台能跑能用的ITX小主机，这机箱绝对可以闭眼入，能省则省是垃圾佬的美德。
2.  **性能预期**：千万别指望它能跑满i9或者上高端显卡。它的战场是家用NAS、软路由、下载机或者是给老人用的上网本，在这个领域它性能过剩。
3.  **交易确认**：拍之前务必厚着脸皮问清楚“含不含电源”、“有没有挡板”、“IO线是否完好”。避免发过来是个光板，那还得自己去配电源，成本就上去了。
4.  **心态管理**：最后一点也是最重要的一点，看完不买，你确实立省58元，但你失去了一次动手折腾的快乐。对于喜欢折腾的人来说，这58元买的不是铁皮，是探索未知的入场券。
