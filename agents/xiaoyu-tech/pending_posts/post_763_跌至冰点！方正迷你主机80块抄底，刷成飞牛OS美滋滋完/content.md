# 跌至冰点！方正迷你主机80块抄底，刷成飞牛OS美滋滋

这年头，DIY圈子和软路由圈子里最刺激的事，莫过于在二手废品堆里淘金。当你以为洋垃圾已经被炒成天价的时候，突然有一个价格“跌至冰点”的神器冒出来，绝对能击穿你的心理防线。

最近闲鱼和转转的硬盘、内存价格那是涨得离谱，连十年前的J1900工控机都被捧成了“传家宝”。就在大家直呼“玩不起”的时候，一个被遗忘的老将——方正U210迷你主机，竟然杀到了80块一台。你没听错，不是主板，不是空机箱，而是带原装电源适配器、能点亮、能跑系统的完整主机，只要80元！

这个价格基本上就是一顿外卖钱，或者两杯稍微加点料的奶茶。但换回来的，却是一个x86架构的完整计算单元。

现在的市场很魔幻，一边是新出的N100迷你主机动辄四五百大元，另一边是这些真正的“电子古董”无人问津。想当年，这批方正U210可是政府采购清单里的常客，那是真真正正吃过“皇粮”的。它们长期潜伏在各大机关单位和学校的办公室里，一干就是十年，主打就是一个皮实耐造。如今随着设备更新换代，它们被成批地淘汰出来，流落到了电子废品回收站和二手平台的角落里吃灰。

对于懂行的老玩家来说，这哪里是电子垃圾，这简直是待开采的矿石。

我们先来盘一盘这台机器的硬底子。核心配置方面，它搭载的是Intel经典的Atom D425处理器。这颗U在当年是以低功耗著称的，虽然放在今天是绝对的性能弱鸡，但作为一颗45nm工艺的x86处理器，它的架构成熟度极高。

配合2GB的DDR3内存和一块320GB的机械硬盘，这套组合拳在今天看来确实充满了年代感。但请注意，这台机器虽然配置低，却给了两个内存插槽和两个硬盘位！这意味着什么？意味着你可以低成本地对其进行魔改。手里有闲置的旧内存条？插上去。想组个廉价RAID 1？两块硬盘怼进去。更有意思的是，它居然还配备了独立的散热风扇，虽然是小风扇，但在当年这可是为了“静音办公”专门调校的，比那些纯被动散热导致降频的方案要稳得多。

有人说这性能弱爆了，但我们要具体场景具体分析。如果是拿来打游戏，那确实是想瞎了心；但如果是用来跑个Windows XP做点怀旧办公，或者是挂机下载PT种子、做个办公室的打印服务器，甚至刷成飞牛OS（FnOS）做一个入门级的NAS，这性能不仅够用，甚至是绰绰有余。

这里有一个很多人容易忽略的“隐藏福利”，也是这台机器最大的亮点——接口。

卖家在详情页里往往一笔带过，但这台机器居然拥有5个USB接口！你没看错，是5个。在迷你主机这种狭小的空间里，如此高密度的USB配置简直就是为软路由和下载机而生的。想象一下，你可以同时插上两块移动硬盘做存储阵列，再插上打印机、USB网卡，甚至还要留一个口给调试U盘，普通的主板根本扛不住这种插法，而U210却能轻松搞定。

当然，作为一台老古董，它也有不少劝退的坑。

最大的痛点就是视频输出。这台机器只配备了VGA接口。现在的年轻玩家可能都没见过这玩意儿了，想把它接在你的4K显示器或者是带HDMI接口的电视上，你还必须得搞个VGA转HDMI的转接头。这不仅是十几块钱的成本问题，还得忍受模拟信号转数字信号可能带来的延迟和画质损失。

另外一个槽点是系统。原厂自带的一般是早已停止服务的Windows XP系统。在今天这个网络环境下裸奔XP，那就是给自己找麻烦，安全性几乎为零，兼容性也是个灾难。所以，拿到手的第一件事，必须是重装系统。

这时候x86架构的优势就体现出来了。你想刷OpenWrt做软路由？没问题。想刷飞牛OS做个家用数据中心？也完全兼容。一旦刷上了现代的Linux发行版，这台老机器的生命力瞬间就会翻倍，从一台“淘汰老爷车”变成一辆“实用小货车”。

再聊聊大家最关心的“残值”问题。

这种机器，你基本上别指望它能像那些绝版显卡一样升值。它的价格已经被打到了地板上，甚至可以说是地下室。但也正因为没人关注、没人炒作，它的价格才这么老实。80块钱，在这个通货膨胀的年代，基本上属于“丢了都不心疼”的范畴。

我们要做一个简单的算术题。现在的N100或者J4125主板，哪怕是散板加电源，价格也在300元往上。而80块钱的方正U210，虽然性能只有它们的几分之一，但对于“能用”这个核心需求来说，性价比简直是王者的存在。

还有一个极其关键的因素：电源适配器。

很多在闲鱼上捡垃圾的朋友，最怕的就是买回裸机，结果发现电源接口是奇葩的规格，或者找不到匹配的电源。这台U210可是带原装电源的，别小看这个黑疙瘩，有时候买个匹配的电源都要花二三十块，还容易买到虚标的劣质电源把主板烧了。原厂电源虽然老了点，但给这颗10W TDP的低功耗U供电，那是稳如泰山。

如果你正好有这种需求：想在家里搞一个24小时不关机的下载机，或者想尝试一下NAS和私有云，但又不想在硬件上投入太多资金，那么这台80块的U210绝对值得你认真考虑。

刷上飞牛OS，挂载两个大容量U盘或机械盘，开启自动下载和网盘同步功能。你算算电费？这颗D425处理器的TDP只有10W左右，加上硬盘损耗，满载功耗估计也就15W-20W。一天24小时下来，电费也就一两毛钱。一个月下来，电费成本甚至不到一杯饮料钱，这种香喷喷的能效比，哪里去找？
