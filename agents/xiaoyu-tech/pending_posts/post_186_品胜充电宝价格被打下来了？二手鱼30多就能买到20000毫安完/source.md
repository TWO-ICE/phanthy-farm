# 品胜充电宝价格被打下来了？二手鱼30多就能买到20000毫安带22.5W快充

二手鱼里看到有卖家挂出35.8元的品胜20000毫安充电宝，还带22.5W快充。 带有 3C认证可登机，型号 是 TS - D346， 有 黑白两色可选，保证正品防伪码可查， 还说 假一赔十。 看了一下卖家的展示图，发现背景里满满都是品胜的充电宝，看来货源很充足，那么到底值不值得出手呢？


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenScxftarwIic52ibbygzTcqrOGia88Y8otkUZiaHkpuiazb4zYMGMo0ibJ6tTom7wZzhHF64icBVk5wMYgtK5X0ZwicfcuSmbrDRWbHGU/640?wx_fmt=png&watermark=1&tp=webp)


品胜算不上顶级大牌，但在移动电源领域好歹也是正规军，比那些没听过的杂牌强太多了。20000毫安的实际容量，按照目前主流转换效率算，给iPhone15 Pro充满3次半没问题，给安卓旗舰也能充2次多。22.5W快充虽然比不上现在动辄65W甚至100W的旗舰充电宝，但应对日常出门应急完全够用了。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemCSIh2e8JNtbPfH3HJz7qsLnf5GNRiaueatOqOFDpWNEbeRvaoKgia1ribM1uTAxjyPerMMtmtd484IPXpQWZsLJ5e6atzEc5VIE/640?wx_fmt=png&watermark=1&tp=webp)


卖家 这款充电宝有 3 个 输入2 个 输出，可以用Micro USB、Type C或者Lightning线给它充电，兼容性做得不错。两个输出口同时充两台设备，出门不用抢充电口。最实用的还是那句可以登机，20000毫安是民航允许的容量上限，出差党或者旅游党拿着它过安检不会有任何麻烦。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenatltJjFiaprOvxkQErZFEeeMkGG2vJ7cnroEJ0PyoQbTEXn3mSUlP9pg0QOw4x3XTMZncZU4AfTJ5aXOawzsoDgMTwghUib5kY/640?wx_fmt=png&watermark=1&tp=webp)


但 这种低价充电宝最怕电芯老化，20000毫安标的容量可能用久了有衰减。 如果要买 最好让卖家拍个实拍图，看看外壳有没有鼓包或者划痕严重的情况。品胜官方防伪码倒是能查真伪，但卖家是否真给发带码的货，只能赌他人品了。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemp3T5OIrTb6icNI3bVI5rXGsMnV5sxlBiaKCADrFo6wfGMrdiarcVCjib5Oz75weF5SzlmtSkr5RR6RsavBib312MaG3x8RcuAiaMVs/640?wx_fmt=png&watermark=1&tp=webp)


另外 ，22.5W快充协议主要支持华为的SCP和通用的PD3.0，如果是小米的33W私有协议或者vivo的FlashCharge，这个充电宝就喂不饱你的手机，只能跑普通10W 左右的 速度。下单前确认下自己手机的协议，别冲着快充去结果买回来才发现跑不动。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekaCqNM2P0VuO8RsbXFRtXDiaiceLqa5ic2EKciayCaibiamlPuZK1cqIiaTo2PHIZBkI7ITDckE5PQhWssFPks08BAqsWaUFFlxH4ybQ/640?wx_fmt=png&watermark=1&tp=webp)


对比一下同价位的其他选择，二手鱼里这个价位段大多是些杂牌或者山寨货，容量虚标严重，有的甚至拿5000毫安标20000毫安。品胜至少是个有十几年历史的牌子，当年MP3、MP4时代它的充电器和电池就是很多人的首选。如今虽然被小米、罗马仕这些品牌抢了不少市场，但品胜的产品稳定性和安全性一直在线，至少不会出现充电爆炸这种恶性问题。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekpjpCvF3KrcHBWpDzIy7VmC9BkET7ibEs6qlgocpO0zuOzQ78CM4eoA0iaXlze1POia7zI2NxYSCXLlrEZ7GAlGQFiaI08cxBVZvw/640?wx_fmt=png&watermark=1&tp=webp)


品胜同系列还有一款10000毫安的充电宝，价格在26元左右，除了容量减半之外，其他参数包括22.5W快充、3输入2输出都一模一样。如果你不是重度用户，平时只是上班通勤或者短途出门，10000毫安更轻便，26元的价格也更划算。比在外面租充电宝划算太多了，现在随便扫个共享充电宝，一小时就是4到6块，充两次就够买这个充电宝了，而且租来的充电宝还经常还不上，白白扣你99元押金。
