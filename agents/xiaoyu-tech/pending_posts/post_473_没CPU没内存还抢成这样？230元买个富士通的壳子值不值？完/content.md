# 没CPU没内存还抢成这样？230元买个富士通的壳子值不值？

今天在二手海鲜市场闲逛的时候，无意间刷到了一个颇为火爆的listing。原装富士通8代9代迷你NAS小主机，标价只要230元。这价格倒是还没什么，毕竟在这个神奇的平台上，什么价格都有。但关键在于详情页里的描述写得天花乱坠：“批发原装”、“军工品质”、“支持三硬盘”。我扫了一眼数据，居然有1000多人设置了“想要”，浏览量更是飙到了8万。这不禁让我心里犯嘀咕：这玩意儿真有这么香？还是说又是商家精心包装的一个“图便宜踩大坑”的套路？

毕竟，对于咱们这种折腾数码硬件的玩家来说，230元买个小机箱似乎也不算离谱，但要是买个“废铁”回家，那心态可就崩了。

咱们先从最直观的外观聊起。这富士通的小主机机箱，确实把工业设计玩到了极致。它真的很小巧，大概就比你家桌面上那个普通的烟灰缸大上一圈而已。黑白配色可选，走的是那种非常纯粹的极简工业风，摆在桌面上既不突兀，还挺有那种老牌外企的严谨范儿。

最让我惊喜的不是大小，而是它的电源设计。很多同级别的迷你主机或者小钢炮，往往为了压缩体积，会把电源外置，搞成一个巨大的“板砖”适配器，不仅丑，还占插座。但这台富士通直接内置了电源，这意味着你只需要一根普通的电源线就能搞定，桌面整洁度直接拉满。而且这卖家还算讲究，哪怕是卖个“准系统”，也送了纯铜电源线、CPU硅脂，甚至还有一个光驱位的硬盘架。配件的诚意算是给足了。

不过，这时候请先收起你的钱包，别高兴得太早。这里有个巨大的坑需要注意：默认230元卖的是“准系统”。通俗点说，这就是个“裸奔”的壳子加主板——没CPU、没内存、没硬盘、甚至连WiFi模块都没有。这东西非常适合那种手里囤了一堆旧配件不知道怎么用的朋友来折腾。但如果你是个纯小白，手里啥存货都没有，那你得做好加钱上“整机套餐”的准备，否则买回来连个BIOS都进不去，那就是妥妥的摆设。

接下来咱们拆开看看核心配置，这才是这230元到底值不值的关键。这块主板用的是Intel经典的H310芯片组。对于老玩家来说，H310可是当年的神U座驾。它支持8代和9代的低压桌面CPU，也就是那些带T后缀的型号，比如i3-8100T或者i5-8500T。为什么要强调带T？因为这是低功耗版本，TDP（热设计功耗）通常控制在35W甚至更低，这对于小机箱的散热压力来说是生死攸关的。

内存插槽方面，很有意思，它用的是两条笔记本DDR4插槽。这意味着你可以直接把旧笔记本拆下来的内存条插上去用，最大支持到64GB（32G×2）。对于想拿它做个轻量级NAS或者软路由的用户来说，32GB甚至64GB的内存容量完全是过剩的，跑Docker容器、虚拟机都绰绰有余。

硬盘扩展性才是这台机器真正的“杀手锏”，也是为什么标题说它能卖成这样的原因。通常这么小的机箱，能塞进去两块硬盘就算不错了，但这台机器居然设计了“三盘位”：
1个M.2 NVMe接口，可以直接插高速固态，做系统盘或者缓存盘那是飞快；
1个标准的2.5寸SATA接口，这是主力存储位；
最绝的是，它送的光驱位硬盘架，让你能在原本光驱的位置再硬塞进一块2.5寸盘。
这种“三盘位”设计，在一个比烟灰缸大不了多少的机身里实现，确实少见。对于想组个NAS存电影、照片，再跑个系统的玩家来说，扩展性直接拉满了。

再看看屁股后面的接口，简直是“亿”点也不少。它提供了4个USB 3.0和4个USB 2.0，这数量甚至比很多全尺寸的ATX主板还多，接打印机、摄像头、U盘啥的完全不用愁接口不够用。千兆网口是标配，跑NAS带宽不用担心瓶颈。音频输入输出、显示输出是DVI加DP的组合，虽然不如HDMI普及，但转接头也很便宜，支持双屏输出对于办公炒股党来说非常实用。

显卡方面，它用的是CPU自带的UHD 630核显。这块显卡虽然跑不动《黑神话：悟空》，但日常办公、看4K视频、甚至剪剪简单的vlog是没有任何问题的。另外，机内还预留了一个M.2插槽，可以用来加装无线网卡。卖家报价WIFI5套装加30元，WIFI6套装加70元。说实话，这个溢价还算合理，毕竟现买一个Intel的AX200网卡也得这个价。

可能看到这，还是有朋友会问：“230块钱连个CPU都没有，我买回来不是废铁一块？”没错，如果你把它当成一台能用的电脑，它确实是废铁。但是，咱们换个角度算笔账。如果你手头正好有淘汰下来的8代、9代低压U，或者旧笔记本拆下来的两条DDR4内存，再加上闲置的SATA SSD。那么，你只需要花230元，就能得到一个：富士通原厂机箱 + 供电稳定的H310主板 + 内置电源 + 能塞三块硬盘的扩展笼子。这组合只要230元，简直就是白菜价。

尤其是拿来跑飞牛（FnOS）、OpenWrt、TrueNAS这类系统，这种配置的性价比简直是无敌的。它的x86架构保证了极好的兼容性，比那些ARM开发板强太多了。

那么，跟海鲜市场上其他的迷你主机比，它到底处于什么段位？咱们横向对比一下。市面上最常见的J4125或者J5040小主机，虽然整机只要300多块钱，而且带CPU带内存，看似很划算。但那些都是基于Intel凌动或者赛扬架构的，CPU性能非常弱，也就是个勉强能看网页的水平。而且扩展性极差，通常只能插一块硬盘，甚至很多还不支持内存升级。

反观这款富士通准系统，虽然门槛高，需要你自己配配件，但它基于标准的桌面平台，性能上限极高，扩展灵活。加上富士通毕竟是日本老牌大厂，这种机箱原本就是给商用甚至工控环境设计的，做工扎实，用料考究，长期24小时开机运行的稳定性，绝对不是那种山寨小作坊能比的。

当然，它的缺点也很明显。体积虽小，但受限于物理空间，散热只能说“一般般”。如果你强行塞进去一颗不带的CPU或者高功耗型号，高负载下风扇的噪音可能会有点大，甚至像直升机起飞。而且因为不带WiFi和预装系统，对新手上手确实有不小的门槛，甚至连系统安装都要折腾一番。

最后咱们聊聊行情。目前二手市场上，同类型的这种准系统，普遍挂价都在250元到350元之间。230元这个价格，绝对属于偏低的那一档，如果不急用，捡漏的概率很大。如果你想买整机，比如卖家配好的i3-8100T加8G内存加256G固态，卖649元，对比一下全新动辄上千的NUC或者品牌迷你PC，这性价比也是可以接受的。

那么，总结一下购买建议：

第一，如果你是手里正好有一堆旧配件不知道怎么处理的“垃圾佬”，230元冲这个准系统绝对超值，变废为宝的最佳方案。
第二，如果你啥配件都没有，又想体验一下折腾的乐趣，建议直接上i3套餐，600块出头，买个能稳定用的主力机。
第三，千万别贪便宜去买那些没品牌的杂牌或者山寨板子，富士通这种商用机的底子，用个三五年基本没问题。
第四，如果你看完这通分析，觉得没兴趣了，那恭喜你，成功立省230元，这才是最省钱的攻略。
