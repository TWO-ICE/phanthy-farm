# 二手鱼流入大量联想M710q小主机，准系统180元起值得接盘吗？

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenUYlo9kAXx0hDq7IbTOu8RfFeQM4GFxGUOKz0O3MhVKg1Aeib6lANcNWE6LsicvRO5XefqQ4oDe2oYbo4vy6vCLN2nNCPdNLWgM/640?wx_fmt=png&watermark=1&tp=webp)


二手鱼里刷到一批联想M710q迷你小主机，标价180元起，卖家说新到货几百台，成色都很新。这款是准系统主机，不含cpu、内存、硬盘等配件，支持6到7代低压和标压台式机处理器，免费魔改后还能上8代、9代和志强cpu，有铜芯和全铝两种散热版本。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenGEkovL7sUwMnMics0iccvtHjSyGibkDeseiafVVfV9rsmpzgCeu2sVKKaIpnXrQ9wkIH0ICqL8IhAYMpClSuWEKfx8B71nGwPIXM/640?wx_fmt=png&watermark=1&tp=webp)


先说说核心亮点，这台迷你主机最吸引人的就是可免费魔改，这是很多同价位迷你主机没有的优势。魔改后能升级更高代CPU，可玩性拉满，而且待机不到10瓦，低功耗很适合当 飞牛 nas主机、软路由或工控电脑，也能装win系统当办公主机。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemotQQPPvNZq1tVb5q02tB9W2PY3iaQJ1CbCIRKpYichYRJlfDK6jM4H5yiaDKtOzb2NFgB14MOG8GIEgeL6E5Qyfxq4ibLxr06AaY/640?wx_fmt=png&watermark=1&tp=webp)


接口也很实用，配备HDMI、DisplayPort视频接口和多个USB3.1接口，能满足日常办公和扩展需求。同类迷你准系统主机，比如戴尔、惠普的同年代产品，价格基本在230元以上，而且大多不支持免费魔改。就算是更便宜的AMD四核小主机，性能和稳定性远不如联想M710q，可玩性也差很多。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemakAM6rUcbXdic7b2TMu3oj01KBnNgY11tfjLia7RBIMiamVGiaibfuicmODGqIYq1vhzLiaSehXrDVgEiaA7K5q1ByEBsQMtfqib6TSwI/640?wx_fmt=png&watermark=1&tp=webp)


但缺点也很明显，准系统不含任何配件，想要正常使用，加电源、内存、硬盘等配件， 后期自己还需要投入几百块 ，算下来总价并不低。而且魔改有翻车风险，卖家标注魔改后非质量问题不退，风险需要自己承担。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenE7ajO7bIE78Rxh9v3I5iaA9mLXJiboicKaibHmlScCPibjE258bXSAhwKGfNsF4oGd5UUEiabwBodSA1wfqgVNtrTtyibibyTN82fRqs/640?wx_fmt=png&watermark=1&tp=webp)


卖家给了几个成品配置套餐，最便宜的是配置一：i3-6100T + 4G内存 + 128G固态，配65W电源 + 蓝牙WiFi。如果你是拿来纯办公或上网课看视频， 这 一档完全够用。如果你是准备跑软路由或者装飞牛NAS做家用服务器，建议选带T后缀的低功耗CPU直接捡准系统自己回来攒，功耗下来之后24小时开机不心疼。如果是想折腾黑苹果或者PVE搞All in one，那就挑个i5-8500或者直接上i7-8700配135W电源，散热到位的话这配置再战个三年问题不大。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemGmHCLnc2OfQMGicRyW8wPsIVpsn3AFFsEOy6EvWbUyiawXvphC87DpC2eFtMCibdtEStgX3IIs37y3rlCnOy4WiaeBPStsW4tPVI/640?wx_fmt=png&watermark=1&tp=webp)


如果是懂行的垃圾佬，想折腾魔改，下单前一定要让卖家发魔改测试视频，确认魔改后的稳定性，避免收到货后出现无法开机的问题。毕竟卖家说非质量问题不退，提前确认能减少麻烦。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelT5xhypYrjWC3NM89Pv57hUnV2EJQLEZM5I6EjEwvGg5THkBOrSNKIftCgRzlscACbFfWbT4RFuJe7oKIbJqnGEKViaBTphvKU/640?wx_fmt=png&watermark=1&tp=webp)


现在二手鱼里确实有大量这类迷你主机流入，180元起的价格看似很香，但也要理性捡垃圾。有没有用过这款联想M710q的老铁，说说实际使用体验？你们觉得180元起的准系统值不值，评论区聊聊你们在二手鱼捡过最香的迷你主机是什么，点赞转发给身边预算紧张的朋友。
