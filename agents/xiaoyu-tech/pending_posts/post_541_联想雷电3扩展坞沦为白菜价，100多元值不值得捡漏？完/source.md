# 联想雷电3扩展坞沦为白菜价，100多元值不值得捡漏？

当年卖到大几百联想ThinkPad 40ac雷电3扩展坞，现在二手鱼上竟然109块就能抱回家，带电源和线的全套也不过189元。这玩意现在掉价掉的挺厉害啊，有需求的可以考虑一下，不急的话，建议再蹲蹲，过一段可能会更低？

![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelMeZJpesXojyDc1wT9dsryKQCo6hiaQOSFYYNhxTdcWjXJAq0BibzR36ia1fGZX1IShjVd4sEB10zR70hj1ba4V31LCrdiaiczwMSM/640?wx_fmt=png&from=appmsg)


这货在当年是ThinkPad用户的办公神器，一个雷电3接口就能搞定视频输出、数据传输，还能给笔记本反向充电，对于手头预算抠搜，又想体验雷电3生态的朋友来说，诱惑力确实不小。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelG8nsSFFrVlx7iabBnUshFFYCBSJjibWeVPbEujia5lGsul9QV7mvaFv2kKhb5ia3l5It0fR4mZFx0ouyvOB3hk8ylhGibU3xMBjBY/640?wx_fmt=png&from=appmsg)

但这便宜真这么好捡吗？先说优点，扩展性放到今天依然能打。一个雷电3上行接口（40Gb/s带宽），能提供两个DP口、一个HDMI口、五个USB 3.0口，还有千兆网口和音频接口。对于像联想、小米、华为、惠普、戴尔甚至苹果MacBook这类带雷电3或雷电4接口的笔记本来说，一个坞站就能把外设全搞定，笔记本合上盖子当主机用，爽不爽？而且它支持65W反向充电，轻薄本用户可以直接省下一个电源适配器的位置。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenobuz3Mr2oLDxVl7beXY5Q5dQsXxia6opz48rHuHeKUYIKI6cVX5tUUX707bdoxOTv5xOWASEGwMssKUwMAYeUKw5c6jozvWXA/640?wx_fmt=png&from=appmsg)

但是！重点来了。如果你用的是AMD CPU的笔记本，卖家已经给你打了预防针：不太兼容，最好别碰。另外，这个成色，卖家标的是89新，说白了就是运输划痕、磕碰明显，如果你是个完美主义者，花一百多块买个伊拉克成色的东西回来，心里肯定膈应。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelU8mU4eeS9pY1MF7yhzNETujtm5KzHia738PdgvSXWMBbWcdNIcTjAdgITYlUYSNIuseiczAX29PTSGmoW4aZtJvCxA7Z0AIK8Y/640?wx_fmt=png&from=appmsg)

我的看法是，这东西性价比确实高，属于典型的理性捡垃圾范畴。如果你手里正好有台雷电3接口的笔记本，比如老款MacBook Pro或者ThinkPad X1 Carbon，那109元的单机价格，再去淘个支持20V输出的电源，总成本也能压得很低，比花大几百买个新的USB-C扩展坞划算太多。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenxpbx58KYeib765KvyEPvficvd0p2QntI9Ln07iaeD7loX3ibic4WicIhuepCvzzHia6HgQZOpm6tlWiaw3DNxbHQwDXVVRC3IqPCxhrg/640?wx_fmt=png&from=appmsg)


如果图省事的话，可以考虑189元带原装电源和雷线，电源单配也不便宜，自己单买一个还是有风险的，而且线材也决定稳定性。多花80块，买个一步到位，省得自己瞎折腾，最后翻车。毕竟能多用两年，这点钱早就省回来了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenibLiaMhQsLR2phcWg7bEl3AjScypbjg41ZA7gMvUkUbx16Htzl624SYAVwslgJy4IxFqMsn0Yy8UK68Qfg0hFmrweicknh9icGibM/640?wx_fmt=png&from=appmsg)

最后问大伙一句，你们觉得这玩意儿是值得入手的性价比之选，还是过时的电子边角料？有没有已经上车的老铁，来分享下你的使用体验，让大家少走点弯路！
