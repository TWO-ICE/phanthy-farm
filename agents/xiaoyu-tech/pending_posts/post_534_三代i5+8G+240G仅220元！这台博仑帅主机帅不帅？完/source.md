# 三代i5+8G+240G仅220元！这台博仑帅主机帅不帅？

> 原文链接：https://mp.weixin.qq.com/s/GtK4jmVB6j4zz8DMEnMubg

看到一台标价220元起的i5迷你电脑，品牌是博仑帅，我查了一下，博仑帅在多年前的企业采购和行业定制市场，它可是个熟面孔，主打的就是一个稳定耐用。眼前这台机器，搭载了英特尔第三代酷睿i5-3320M处理器，双核四线程，标配8G DDR3内存和一块240G的固态硬盘。是的，你没看错，是三代i5，在十三、十四代酷睿满天飞的今天，它的辈分确实够老。但关键就在于，这套220元的主机，到底有没有它的生存空间？


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenfCyu2ibd9WNt1vQHgxfMLohdrpPTJSsAV3iaMa7jaF12V7cmZVz2QLZ6mbZNJO3Teq95fvbgXcMrjzO0xwM42TwGveOU7NxMg4/640?wx_fmt=png)


我们先说大实话，聊缺点。i5-3320M的性能，放在今天，也就堪堪应对最基础的文字办公、网页浏览和在线影音。你想用它打游戏、做视频剪辑？那还是“不用瞎折腾了”。处理日常巡逻绰绰有余，正面攻坚就别指望了。另外，从卖家图看“少了个盖子”，介意外观的朋友可能得纠结一下。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCeldteKRiaTQbonjiaiac9X7qWdLOL0RehxV3O3ibl6ibsSkQSz5DVVu8uSWTzPOtH01kt7qicVHMSI4s2KHLb2LfDhrnzy9XRlK0JSLg/640?wx_fmt=png)


那它的优点呢？恰恰就藏在它的“老”和“便宜”里。首先，8G内存加240G固态这个搭配，对于Win7或轻量级Win10系统来说，是保证流畅度的黄金组合，开关机、打开软件不会有那种机械硬盘的拖沓感。两个SATA接口和一个无线网卡接口，给了它一定的扩展可能性。最关键的是价格，220元，在如今随便一个像样点的路由器都得好几百的环境下，这台能运行完整Windows系统的电脑，性价比还算不错。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekhDuanjugibCCruU4LjG4zGibiavgEP347L5GyJMmdoNmrB5wdicRvPXcW5tjXcIHsEQErqZdFPsBPIwBqLiaOffHowV34HPPVYngk/640?wx_fmt=png)


那么问题来了，这机器最适合做什么用？看新闻、炒股，放在客厅接电视当作一台高清视频播放器，或者作为孩子的网课备用机都行。甚至能刷飞牛、群晖当NAS，而且功耗也不高，作为入门级的家庭存储中心或下载机，它完全能胜任。这就是它的核心价值：用极低的成本，解决一个特定的、轻量级的计算需求。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenvtFS2XvA8zP9IwLzV6fdOc7jtpXpSYP8dc20QCT6wFrjAaMtclSzTKOicE8xFZ78LXzTTwpyUuyiczh5Xo5Mq2iby148HCknCE0/640?wx_fmt=png)


有的人可能感觉220不算地板价，我们掰开来看，一块差不多的240G二手固态大概50元，8G DDR3内存条约60元，i5-3320M的板U套（含小型主板）市场价大概在100-130元，再加上机箱电源。你自己凑齐一套，价格很可能超过220元，还要耗费时间精力去组装测试。所以，对于怕麻烦的普通用户来说，这个价位买这么一台到手即用的整机，显然是更“省力”的选择。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelk9yIBGqAZBpkyeWia81ShCWlkiaQZuiaZdXmofhUv9xa8LfbZicFg130RM8iblp27Tic8v5oEThNqS70jic1P1MFnbyueKFlEyrrlag/640?wx_fmt=png)


所以，到底该不该出手？我的建议是，先想清楚你的需求。如果你需要一台主力电脑，那请果断划走，它不适合你。但如果你正为“预算抠搜”的副屏、监控显示、或者需要一个24小时开机的下载工具而发愁，那么这台博仑帅，可能就是那个“垃圾佬”眼中的性价比答案。在下单前，一定和卖家确认好具体配置版本、成色细节以及接口是否全好。
