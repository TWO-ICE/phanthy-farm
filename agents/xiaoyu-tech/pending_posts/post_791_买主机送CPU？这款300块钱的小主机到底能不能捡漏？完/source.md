# 买主机送CPU？这款300块钱的小主机到底能不能捡漏？

最近二手鱼里突然冒出来好多这种巴掌大的小主机，价格一个比一个狠。今天刷到的这个卖家更是拼了，准系统报价不高也就算了，居然直接白送一颗i3-7100的CPU。豁出去了这是？三百来块钱，还包了原装电源，这操作让垃圾佬们都有点顶不住了。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemaAcvTO8L30m8Bb10Xw13psWVick7TMU5YRAepuCkkGib8rDKxiaAsnyibkeMkb7WRkCnUCiaw3icnbp6YkJiaprsDpP0Kd07r2CZS6c/640?wx_fmt=png)


咱们来看看这到底是个什么稀罕物。卖家手里这台S1迷你主机，三围只有19*19*9.5厘米，标准的ITX结构但又要更迷你一些。支持六七代甚至八代的标压CPU，不过上八代得自己刷BIOS，这点得心里有数。五相供电在这个体量的板子上算够用了，最关键的是那个可插拔的BIOS芯片，万一刷黑了不用编程器也能救回来，对爱折腾的人来说简直是福音。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekk1an6icKIpODqWtsEoiaCylURoaTgDjQsKrxAxM9sRQiaNP7f5byXn8nXR8frGSgyqKqrmPqwOKZyay3icZzkicN1vuXIL77sJ5w8/640?wx_fmt=png)


内存情况卖家没说，推测用的应该是DDR4内存，主板上还有2个SATA接口，接个2.5寸的笔记本硬盘或者固态当仓库盘完全没问题，另外主板上还集成了无线网卡，支持WiFi联网，这一点还是非常有好友的。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenibsMCz6nmVE2UzlIncicqoR7NDDvEn5Vgt5hUJb7anhiaJArf8mWriarRHGHibhsCSEiaFic0fYViama0UtgYGy4y7Xl8z3X0IDxloEU/640?wx_fmt=png)


当然，弊端也不是没有，这种小主机虽然价格被打下来了，但性能放在今天确实属于老咕噜棒子级别。它的正确归宿应该是后台，比如刷个软路由当主路由，或者挂在电视后面当电视盒子用。当然，也非常适合刷成飞牛系统，因为是X86架构，刷飞牛也完全没压力，装个影视仓再挂一块大硬盘，家庭影音中心就有了。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekicAsGtHhqXrHzwcR7ZzXy8MfNVh9oE1Sh3FWS8UgOBRzE9aLoeibBU1zQXOvwqicKMHQV1jKhIfEc0Mcql0WwOQtqEchcbz5soA/640?wx_fmt=png)


可能有人会纠结送的i3-7100有点拉跨，我感觉可以跟卖家商量，不要CPU能不能再便宜个三十块，然后自己花七八十淘个i5-6500T或者i5-7500T，35W的功耗发热小很多，性能还能翻一番。这样整机下来也就三百出头，配个8G内存加个128G的固态，跑个黑群晖或者飞牛，体验感直接拉满。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenqfIG3IUWDdiazU2QJzGhsF4Xdfu0WKw1UYu5PPIu7Qzto8C4MQKSFKygYQD9KYHfk7ydZsicjibhWCy0Aiaib9vjAe1m3k4RGE6qI/640?wx_fmt=png)


你觉得这种小主机买回家还能干点啥？是软路由还是游戏机模拟器？评论区聊聊，理性捡垃圾，快乐不踩坑。
