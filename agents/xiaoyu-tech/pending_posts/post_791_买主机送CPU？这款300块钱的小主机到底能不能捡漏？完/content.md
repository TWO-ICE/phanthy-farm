# 买主机送CPU？这款300块钱的小主机到底能不能捡漏？

最近在二手市场闲逛，真有一种“乱花渐欲迷人眼”的感觉。不知道是不是企业大规模淘汰办公设备的原因，那一池子“电子废墟”里突然冒出来好多巴掌大的迷你主机。这帮卖家现在的定价策略也是一个比一个狠，仿佛都在比谁能把价格压到地板缝里去。

今天刷到的这个玩意儿，卖家更是直接把桌子掀了。一台准系统小主机，报价本来就低得离谱，结果文案里赫然写着“白送一颗i3-7100的CPU”。这就很意思了，这是豁出去了要清仓回血吗？三百来块钱的打包价，甚至还包了个看起来成色还不错的原装电源适配器，这操作简直是把咱们这群热衷于“捡垃圾”的数码拾荒者们架在火上烤——让人顶不住啊。

咱们先别急着下单，冷静下来扒一皮，看看这到底是个什么稀罕物，还是只有两分热度的电子垃圾。

卖家手里这台S1迷你主机，从形态上讲，属于那种标准的“方块”设计。三围尺寸控制在19厘米见方，厚度大概9.5厘米。这体积是什么概念？比一本稍微厚点的大号杂志大不了多少，在桌面上的占地面积比一个普通外卖盒还小。虽然本质上它也是基于ITX结构逻辑设计的，但因为高度被压缩了，所以你根本别想往里塞那种标准高度的风扇，一切都必须为了“瘦”让路。

再聊聊核心的板子规格。这块主板的设计思路其实挺有意思，它跨度非常大，Intel的第六代、第七代酷睿处理器都能原生支持，甚至你想上八代也不是不行，不过得自己动手刷BIOS。这里稍微科普一下背景，Intel在八代酷睿（Coffee Lake）的时候，终于良心发现把核心数量从“2核4线程”提升到了“4核4线程”甚至更多，性能有个质的飞跃，所以上八代U是这台小主机的终极奥义。不过刷BIOS有风险，新手容易变砖，这时候这块主板的一个隐藏优点就浮出水面了——它居然采用了可插拔的BIOS芯片。这对喜欢折腾的人来说简直就是福音，万一刷黑了，不用花钱买编程器，淘宝几块钱买个预刷好的芯片换上去就能救活，这种“留后门”的设计在廉价准系统里确实少见。

供电方面，这就别指望有啥奢华的数字供电模块了，典型的五相供电设计。在这个体积和价位下，五相供电属于“够用且良心”的水平。只要你不往里塞那种130W TDP的次世代旗舰U，带个35W或者65W的常规CPU，这套供电系统稳如泰山。

至于内存和硬盘，卖家详情里没细说，但看这板子的布局基本能猜个八九不离十。内存插槽肯定是笔记本用的DDR4 SO-DIMM，大家手头如果有旧本本拆下来的内存条正好能废物利用。主板下方预留了2个SATA接口，这位置设计得挺巧妙，接一块2.5寸的笔记本机械硬盘或者SATA固态硬盘绰绰有余，当个仓库盘完全没问题。

另外一个小细节值得点赞，主板上居然原生集成了无线网卡模块。很多廉价准系统为了省钱，WiFi模块都是能省则省，还得你自己再去掏钱买半高网卡。这台机器直接支持WiFi联网，对想把主机塞在电视柜后面或者弱电箱里当路由器用的朋友来说，这简直是省去了拉网线的烦恼，非常友好。

当然，咱们得实事求是，这种小主机虽然价格被打下来了，但放在2024年的今天，它的性能确实属于“老咕噜棒子”级别。如果卖家送的那颗i3-7100（双核四线程）还插在上面，你指望它能流畅运行《黑神话：悟空》那纯属想多了。就算装个Windows 11，开几个网页可能都能让你感受到卡顿的复古美学。

所以，这台机器的正确归宿根本不是当你的主力游戏机，而是隐藏在后台默默干活的“服务器”。

首先，它非常适合刷成软路由。市面上性能好点的软路由动辄六七百，而这台机器三百块就能搞定，还是x86架构，性能吊打那些基于ARM架构的几百块钱的路由器。刷个OpenWrt或者iStoreOS，配合多网口，哪怕全家千兆光纤跑满也毫无压力。

其次，它可以挂在电视后面当个顶配版的电视盒子。普通的安卓电视盒子用两年就卡，而这玩意儿装个Windows，配合KODI或者Plex，解码能力杠杠的。

最推荐的玩法，其实是把它打造成家庭NAS。因为它是x86架构，不像那种ARM的群晖/Docker受限大，你想刷飞牛（FnOS）系统也好，黑群晖也好，甚至是装个Unraid，都完全没有压力。只要再花几十块钱买两块16GB的内存条插上（如果有32GB那就更强了），再挂上一块4T的大机械硬盘，家庭影音中心就齐活了。你在客厅看电视，它在柜子里默默吐出电影，这种体验感确实真香。

这时候肯定有朋友要纠结：卖家送的那个i3-7100性能太拉胯，怎么办？

我的建议是，别嫌弃，利用它作为谈判筹码。你可以直接私信卖家：“CPU我不想要，能不能再便宜个三十块？”一般来说，这种卖家也是从成堆的电子垃圾里拆出来的，CPU对他来说就是赠品。你把这三十块省下来，然后再自己去海鲜市场淘一颗i5-6500T或者i5-7500T。

这里为什么要特意提带“T”后缀的U？因为这是专门为低功耗场景设计的，热设计功耗（TDP）只有35W。相比之下，不带T的桌面版CPU虽然便宜，但发热量那是蹭蹭往上涨，在这个体积极小的机箱里，散热风扇会像直升机起飞一样响。而35W的i5，发热控制得极好，风扇甚至能停转，性能上i5-7500T又是四核，相比i3-7100的物理核心翻了一番，跑分能直接提升一大截。

这么一算账：主机260（砍价后）+ CPU 60 + 内存（旧物利用）+ 固态（库存货），整机成本控制在三百出头。用它来跑个Docker，挂个下载，存点照片，体验感绝对能把几百块的商业级成品NAS按在地上摩擦。

总的来说，三百块钱买不来吃亏，也买不来上当，买到的是折腾的快乐。你觉得这种小主机买回家还能干点啥？是软路由还是游戏机模拟器？或者单纯当个打印服务器？理性捡垃圾，快乐不踩坑。
