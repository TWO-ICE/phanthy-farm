# 旧手机别扔别去换脸盆，二手鱼49元魔改成游戏机、机顶盒不香吗？

不用的旧手机你是怎么处理的？卖了，心疼那点10元的残值；留着，每次看到都觉得自己当年脑子进水花三千。别急，二手鱼里那些专门捡“电子边角料”的大佬，49元的手工费给你手机改掌机、改机顶盒、改便携屏，你出机器，他出技术和亚克力壳子，一包烟钱让电子垃圾原地复活。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemqBL6EyvFqxOib3p2hmhfTG4YbUzLhAOtp4duKaic0cyiaG2lhWR4mlKOibTRLXW1TnMvITNOWibbFD0n7qUE7sdOstNfNSwnjHoRE/640?wx_fmt=png)


这不是什么高科技。十年前那些骁龙801、麒麟960，如今跑原神是痴心妄想，但跑个GBA模拟器、当个电视盒子看B站，性能完全溢出。当年这些机器好歹也是旗舰，屏幕素质、做工用料都不差，只是被新系统、新App逼退役了。现在49元给它换个赛道，等于给退休老头安排了个看门岗亭，发挥余热。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelrvklVkUAJJ6J0paj5vCdK2tyMCicvUdTfCUw9UCpNZrSApKtdfiaoOdJBqjd3eRJMLr4yJsNgpduc1CeDenrlFGxS5fVibUvAjs/640?wx_fmt=png)


店家卖的其实就是个手工活。你把自己的手机主板或者整机寄过去，他给你设计一套亚克力外壳，颜色你挑，透明黑、奶白、橙红都行，螺丝固定，该开的孔一个不少。49元是改造费，外壳材料费另算，整套下来大多不过百。你要是手里有小米4、三星S5、一加3这种“老咕噜棒子”，改出来的掌机握持感比几十块的寨机扎实多了，屏幕还是当年顶配LCD。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelMjgrrq0nUPmBdVKcVJxY0wT7fEXyc0ibrDtA58RZmj2PV5myFTGrqkgBOkHc6ZVJFZtgZJH49C6oqOkk7FRn0CFvjQ4j9wQ20/640?wx_fmt=png)


说点实在的优缺点。

优点是价格确实没得喷。现在随便一个开源掌机起步三百，配置还打不过你七年前的旧手机。电视盒子更要命，正经牌子两百起步，预装广告多到能把你妈气出高血压。你自己旧手机改盒子，没广告，硬件你门儿清，49元买个系统干净、还能插卡扩容的播放器，性价比属于降维打击。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCennd5icevnuy86dZtMEFibzECmz3JFedggoUjichE1I7Uhe8s2Eh6pcA2cJyNz4PiahvyM2ms2YuqUH9e6JF4TbbT9vtp6seFK4FTo/640?wx_fmt=png)


缺点是门槛。你需要自己拆机吗？大部分情况不需要，整机寄过去就行，但店家明确说了：不退不换，不包邮，别催单。手工亚克力壳子不可能有原厂模具那种严丝合缝，边缘有点毛刺、螺丝孔对不齐都是常态。店家标题里直接写着“完美主义者勿拍”，这不是脾气大，是提前给你打预防针。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelnIxJpyHfjKLFlxUZVXwfiaYDKxx21p5jaNxGFePP53OwCSkSHDEWJQR3JEiamLRIwDia10KgHvt8Hc4qSANClsALiaVAfiakNPrCM/640?wx_fmt=png)


还有一点，49元只是改一种功能。你想让它既是游戏机又是机顶盒？加钱，或者自己插拔。这就引出个实际问题：你手里到底有没有适合魔改的闲置机器？


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelnmsbjn17BrQ8ZsDHMvYGr3C766EicM4bxhKuK4RbbONqpeTRETTKnQEvp4QU91MQnZ8QiaU4cboLdnXDbcMkuVeMP38wfia0xJc/640?wx_fmt=png)


我刷他页面时心里算了一笔账。如果我只是想躺床上玩《拳皇97》《超级玛丽》，那我选49元改掌机套餐。如果我想把卧室老电视变智能，那就改机顶盒，49元加个红外接收头，遥控器都能适配。要是你手里有台屏幕完好的旧平板，甚至可以改便携屏，接Switch当副屏，一套下来不到两百，比淘那些洋垃圾便携屏稳多了。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekR5IL1rjerz87AZc0avekeuueosT9IDlqIlVpNyRfgPjR28er381Nqjc9XZnicQ9a42mbTY8dia5GQkb5VZq8Uug0r56PY4B1LU/640?wx_fmt=png)


但有一个坑你必须自己掂量。你寄过去的手机，店家只负责改外观、接线，不修主板。如果寄之前电池已经鼓包、充电口接触不良，到手大概率还是坏。别指望49元能帮你修好旧疾，它只是给健康主板换个房子住。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelq9lKTrSfDE0Mb8rgcqwmiar3NZ5ia57icnzWOcqqjb5ckBCCjBerVib4MUDibWic24ic8xWXibtFb2J6eTTR6wOXxU9yUKkwGQgwPmZM/640?wx_fmt=png)


你会不会也翻出那台卡到想砸墙的老机器，想想当年用它刷过的贴吧、追过的剧、熬过的夜？它没坏，只是老了。49元，给它个体面，也给自己个新玩具。评论区聊聊吧——你抽屉里那台手机，打算改游戏机，还是改机顶盒？
