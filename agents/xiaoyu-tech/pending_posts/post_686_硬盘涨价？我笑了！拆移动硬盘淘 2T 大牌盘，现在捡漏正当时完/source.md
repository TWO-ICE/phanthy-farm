# 硬盘涨价？我笑了！拆移动硬盘淘 2T 大牌盘，现在捡漏正当时

最近老听人喊“硬盘又涨价了”“2T机械盘都快买不起了”，我每次都在旁边憋笑——不是硬盘真的贵到离谱，是你们找错地方了啊！买贵了纯属没找对路子，其实想花小钱淘到正经硬盘，办法超简单，今天就把我压箱底的捡漏招儿甩出来，省得你们再当冤大头。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXF5I2KYqibKsicZ51RJtz385ftDFdVicicOvcXgvPFgJpBtia2goudcRtCYD8DJI3ZiaZnCDV5VCt1BkztQ/640?wx_fmt=png)


先给你们甩个鱼塘搜货暗号：“移动硬盘2T全新未拆封”别一看到“移动硬盘”就划走，听我把话说完，不然你得亏到拍大腿！你们要是还按老一套搜“机械硬盘”，那价格能把人吓退——全新的动辄一百大几，二手的更别说了，谁知道是不是被人用工具改了写入量的“矿盘”？用两天就掉盘，找卖家维权都找不到，纯纯交智商税！


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXF5I2KYqibKsicZ51RJtz385fVricz31QdDRydR5wCIbpicKfWa9aq8sNPwGhL3a06whq1hEokhkaSBOw/640?wx_fmt=png)


这时候肯定有人要杠：“我要买机械硬盘存数据，你让我搜移动硬盘？脑子没瓦特吧？”哎哎哎，别着急骂，咱先掰扯掰扯——移动硬盘不就是“一个塑料盒子+一块硬盘”吗？哪有那么多弯弯绕绕！它本质就是个带便携壳的硬盘，你把那层塑料壳拆开，里面露出来的正经机械硬盘，才是咱们要捡的漏！是不是突然恍然大悟？之前怎么就没想着这茬儿！


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXF5I2KYqibKsicZ51RJtz385fMIjhOlAQHuhib0Q5RSAgPB0ZBXSbC2Jx0jiaxvBz74CUibBalrrbhWvnw/640?wx_fmt=png)


再说说价格，你们自己看那些“全新未拆封”的移动硬盘，连一次数据都没写过，跟现在市面上疯涨的机械硬盘比，价格差了快一半！懂行的一看就知道赚了，不懂的我再给你算笔账：正常2T机械硬盘，即使在闲鱼上怎么也得一百六往上，这移动硬盘拆开才一百多一点，等于白捡了个硬盘盒，以后想外接用还能装回去，这不香吗？


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXF5I2KYqibKsicZ51RJtz385fsykvI0JqQFXHgjCARjjhtuia6glyWMKUxXN6OLic3acYye1jMl1ke2xQ/640?wx_fmt=png)


而且价格还能再砍！但记住了，只找“个人转让”的，商家的千万别碰！那些个人卖家，大多就是临时存个文件、备份个手机照片，用完就出，硬盘根本没怎么用，价格还好谈。上次我跟一个小姐姐砍价，从120砍到100，她还顺带送了我个全新的硬盘包，说“放家里占地方，一起给你得了”，那叫一个香到飞起！


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXF5I2KYqibKsicZ51RJtz385fibiblRfdCWALynWShM2fmteapL9J2gh9M6EYRpjwr4xsibYo4nen8Jzdg/640?wx_fmt=png)


不过有俩事儿得提醒你们：一是尽量往大品牌靠，希捷、西数、铠侠这些牌子优先选。我拆过好几个移动硬盘，里面全是它们自家的机械盘，质量比那些杂牌子靠谱多了，至少不用担心是翻新盘。二是有个小遗憾——拆开移动硬盘，里面都是2.5寸的盘，没有3.5寸的大容量款。但这算啥啊？现在2.5寸大牌盘价格这么香，比买那些不知道来源的3.5寸盘省了不少钱，还不用担心供电问题，这不值吗？


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXF5I2KYqibKsicZ51RJtz385fot1OLIJCt0nR5AjwRbbc7BMic02hfc3w3f7utHoyicsnIdn5jl3zfSuA/640?wx_fmt=png)


关键是现在商家和二手贩子还没反应过来，没人炒这种“拆移动硬盘”的路子，这可是黄金捡漏期！等再过阵子他们发现了，肯定得把移动硬盘价格也炒上去，到时候再想买就没这价了。有需求的小伙伴赶紧冲，手慢无，到时候别来跟我哭“没抢到”啊——我可提前把话放这了！
