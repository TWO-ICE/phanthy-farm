# 500元能抄底华硕i7迷你主机？无内存带500G硬盘，这价格能不能冲？

最近二手鱼里刷到不少迷你主机，大几百的价格看着都挺香，但真正值得买的真不多。但今天看到这台500块的华硕VM65迷你主机还有点意思，卖家还配的是i7处理器，忍不住点进去好好研究了一番。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemUhvhzNkIic4Ue2bjElMHCVLuRJMicpibicLTVgwHHzPkkcgaKc5tGD332Ugxf4nDvwCsLvj2cGs3egE0CeFqhXsVhhKf0Uo7G0QY/640?wx_fmt=png)


先说说这台机器的硬实力，处理器是i7-7500U，机身尺寸只有190×190×56毫米，金属加拉丝工艺，质感挺扎实。卖家给配了500GB硬盘，不过没有内存，需要自己买DDR4笔记本内存条插上。卖家没说有没有独显版本，但即便只是核显版，接口也够丰富了。6个USB接口，其中还带USB 3.1高速接口，DP加HDMI双视频输出，能接三台显示器。SD卡槽、有线网口、音频口一应俱全。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCek3POm8JTt8NUTx1DgjXcnbydDm2eq1GASHB6N19rj6zA1lMXkJic7l8WVEUic2F6b4URo9m8QjLNEK8TfksR1xx9pqLNRAaPauQ/640?wx_fmt=png)


让我觉得最实用的反而是两个细节。一个是内置喇叭，声音效果还不错，连接显示器不需要额外接音箱。另一个是扩展能力，支持双笔记本硬盘或者一块3.5寸大硬盘，当下载机或者飞牛NAS太合适了。这两点很多迷你主机还真没有。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekekKmquiaSVLGNAiaohQP9eLSdHdVZribtcQED7SmUQtHpWNB1Lys1Ll72jMVDtH4YJc7BvePWU1QUrAzW3YbiaYPOZAibhjicc2buc/640?wx_fmt=png)


说完了亮点，也得说说不好的地方。i7-7500U放在今天性能确实拉跨了，别看挂着i7的名头，它本质上就是个低功耗移动处理器，如果你拿它当主力机，开个浏览器再开个微信就有点喘了，打开稍微大一点的网页都能明显感觉到卡顿。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenrdmt5lvozQ36nYgb9iapBlL9EhDRd0CZEozP4ibiboiavH33HUkdrMZaibicCHvnsgaw1wMnahf1nul02XmKwoRlp0E3tvmQF29Tw0/640?wx_fmt=png)


核显是Intel HD Graphics 620，玩个十年前的老游戏还行，大型3D游戏就别想了。这台机器适合的场景很明确：轻量办公、看视频、做文件服务器、装黑群晖或者飞牛。用来当电视机顶盒或者客厅下载机都挺安逸的。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelZe67w5hzENeGciaQOFDYu2VQ6qS8QDlRH3g075RiaubaRE76JA0gQcX9p8RibwjH6cOGoMNdFCZqoS3jianDF5n5BGnicKibPEeK0c/640?wx_fmt=png)


值不值得买呢？500块的报价本身不高，但别忘了还得花几十块买根内存条，加起来600左右。现在二手鱼里同样五六百块，运气好能买到性能更强的八代低压i5机型。老平台的核显解码能力和新平台差距明显，要是你打算用它看4K视频或者硬解HEVC，得提前做好功课。
