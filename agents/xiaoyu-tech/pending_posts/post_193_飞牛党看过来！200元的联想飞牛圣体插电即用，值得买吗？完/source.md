# 飞牛党看过来！200元的联想飞牛圣体插电即用，值得买吗？

发现没，最近二手鱼里的飞牛圣体是真多啊。我刷到了一台联想m3600c的小主机，标价200块，卖家说软路由、飞牛都能用。说实话，一开始我觉得这价格有点飘，毕竟二手鱼里那些百元以内的飞牛准系统多的是，但这台机器点进去看了详情，我还真有点动心了。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemaw7mzkGWdQIOXUDCgBUHYztSDd1zaoIBzCWF0BuDDxxVASMjEZo36rojuE9UMicjRP5aJJYGrzSXKibaNMiaTwbqd2g2KOHdtUk/640?wx_fmt=png)


主机是联想m3600c，这玩意儿是正儿八经的瘦客户机，属于是企业用机，比那些DIY拼凑的要强得多，而且小巧、不占地方。这种机器别看是已经淘汰了，虽然跑Windows非常吃力，但刷成飞牛还是依然能够稳定运行的。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekWq8fhFm4icbrcvIHAffe4iabWakPTibLVYPlKgNctKic6knDOMRJkiay8MDRVCoEFaqxsic0CCj15kLP8IviaPntSpRfC4QOdSXOZnM/640?wx_fmt=png)


配置看一眼就大概知道它的定位了。CPU是集成的N3000，4G内存，32G固态硬盘。性能拉胯毫无疑问，它主打的就是低功耗和静音，被动铜管散热的设计，电费几乎可以忽略不计。接口方面倒是挺全乎，两个DP口能接显示器，四个COM口对于玩工控的老铁来说是刚需，还有四个USB3.0和一个老式的PS2口。这接口丰富程度，用来做软路由或者装个飞牛当轻量NAS，绰绰有余。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenJ7GgpdsDjWX0fOOrKcl4icC3pHHw3g6WTvvQjbJuq7MZTJT4ZoKWBYxbR3W16jibXLh7YNgZcC1QCd7wHMZibfve6uT25t8H87k/640?wx_fmt=png)


现在市面上存储产品价格一路看涨，想自己动手组一台像样的NAS，光是硬盘钱就得抠搜半天。这台联想小主机直接给了你一个非常低门槛的解决方案。200块钱买回去，插上电源和网线，装个飞牛系统就能开始折腾了，到手就能用，省下的时间和精力，比那几十块钱差价值多了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekWdQpsCqdsSDsUa4Yic7MLMRt14tofPgPhbAjpCkRgWZMT8yVibmDiaibN4oGLziaZn5ehtRoSmSU2ATygNcicv1UAa2DWZG4NCwamg/640?wx_fmt=png)


当然，话要说回来，这玩意儿也不是没有缺点。原配的32G固态太小了，也就是装个系统，虽然主板上有2.5寸硬盘接口，但卖家说没有硬盘架。如果你想加装硬盘的话，就要自己搞定了。当然通过USB口挂载也是可以的。这点对于想把它当主力NAS用的老铁来说，确实是个硬伤。另外，N3000这颗U的性能摆在那里，你就别指望它跑什么虚拟机或者搞什么硬解了，老老实实当个文件存储器或者轻量级的影音服务器，它完全能胜任，但要想让它干重活，那确实是为难它了。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCeneicia0ibygTAfqv58eyoaBKuG7SegpicmyHDDicvt6s3a7KXFlKyvlfCP64wxTjmc1VVib6rrfljxFfsp2iaN83GAuy2LOkUMTjfzGI/640?wx_fmt=png)


有两点建议给想入手的老铁们。

第一，买之前想清楚你到底要拿它干什么。如果只是装个飞牛系统，当个备份相册、同步文档的私人云盘，或者跑个软路由当家里的网络核心，这台机器200块闭着眼睛入，绝对比你花更多的钱去折腾那些配件不齐的准系统要省心。

第二，别对它的扩展性抱有太高期望。原装没硬盘位，你要是手里有闲置的2.5寸盘想塞进去，得自己想办法用胶带固定或者直接放外面，强迫症患者可能接受不了。想清楚这两点，再下手也不迟。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCek4LQJClec1a8yr1w0VQEZRiacNZfm9tewP171s87XlQN86icsoxTEWYuBwia4anewPtR1DIznDib0TyeWYWiavc4oBV3LmMX9xqtico/640?wx_fmt=png)


不得不说，这两年二手市场里的这些洋垃圾和工厂淘汰货，确实把很多数码玩具的价格给打了下来。以前玩NAS，没个千八百的预算都不敢想，现在200块就能搞个飞牛圣体回来尝尝鲜，哪怕是买回来玩两天觉得不合适再挂出去，也亏不了几个钱。这大概就是二手数码的魅力所在，花小钱办大事，还能体验折腾的乐趣。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekiaWbQlJhPt6ia7IZlgTemIbbh2SDMLg20QHcXqiaTOGuDibqu88LGW4Tp1R6IMYiaG4JibQA2BQZNbfPKKAFiculr7iaScAOWXIVU3Fs/640?wx_fmt=png)


老铁们，你们觉得这台200块的联想m3600c算不算得上是真正的飞牛圣体？如果你们手里有类似的预算，是会选这种完整的到手即用小主机，还是会去买那些更便宜的准系统自己回来拼人品？来评论区聊聊，看看大家都是怎么想的。
