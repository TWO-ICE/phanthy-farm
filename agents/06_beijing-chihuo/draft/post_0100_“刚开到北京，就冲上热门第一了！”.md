 “桂林人在北京的天堂” 

/ “桂林30年老店”来京


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/Yib3uQQKMFGLMmkh0ic5ROXjsvfibkjOyVyBqKib1xThBygV1pkjYMpeibo74LCkBKC7UTQE6m2BU8iaRXZiaUic2pjacg/640?wx_fmt=jpeg&from=appmsg)

- “桂林米粉”这个品类最早起源于广西兴安，后靠硬实力（好滋味在里头）风靡各地，光是在桂林，每家店的口味也是各具特色~ 
- 其中，广西桂林的【板板车米粉店】是一家做了30多年的老米粉店了，今年还评上了当地的必吃榜餐厅。前阵子看到北京丰台区的角门儿附近，也冒出了一家“板板车小吃店”，经考察，果真是一对来自桂林的夫妻开过来的！

/ 北京桂林米粉热门榜第①名


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/Yib3uQQKMFGLMmkh0ic5ROXjsvfibkjOyVyIJUD87aNOPhH8OcTKbXWRuTjPSZiacC5B1QaTZSC2GlaZzK5nyPhIHQ/640?wx_fmt=jpeg&from=appmsg)


![图片](https://mmbiz.qpic.cn/sz_mmbiz_gif/Yib3uQQKMFGKuzxyozAzK2gTdUicSs5Dx0AmNAcD9kWX6UI31HoUFNVLhcSVcSNuzfGynGicU8vyZibWFPxtcjS7MQ/640?wx_fmt=gif&from=appmsg)


![图片](https://mmbiz.qpic.cn/sz_mmbiz_gif/Yib3uQQKMFGLMmkh0ic5ROXjsvfibkjOyVy1whuZnocQvRic121GHnfgct7j09XWabPqYNQaAc9YibzuZORoOjNQ8SQ/640?wx_fmt=gif&from=appmsg)

- 这家店的出现直接弥补了北京好吃的桂林米粉店的缺位。开业以来，据说全北京的桂林老乡都去吃过了hhhh。口碑也很好，被评友们亲切地称为“桂林人在北京的天堂！”~

/ “三两，锅烧的。”


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/Yib3uQQKMFGLMmkh0ic5ROXjsvfibkjOyVyz6AsocukyLL1wicpz4CZ8qSj3lMFAPXV8mWw9qnHJXYTKNhqNhWkYDQ/640?wx_fmt=jpeg&from=appmsg)


- 店刚开不久就已经有来吃过好多次老客人了，点餐要来后厨档口这边给老板说，粉人的语言颇为简洁：“三两、锅烧的。”，老板：“好！”。看菜单跟桂林当地的粉店如出一辙，品类简单，几种卤菜粉+几种汤菜粉，再有一些可以单独加的肉系配料。

/ 精彩的小料台

- 再一个判断指标就是看自助小料台！他家有北京粉店少见的辣海带丝，还有自制的葱头辣椒和家乡剁椒。辣椒也分正常辣和魔鬼辣两个辣度...（慎加啊！）


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/Yib3uQQKMFGJG9J6SoLHxYGU4iaICJKzE8FOTwEc3p6kzlfcOsFlXukhckmePibHiau2leCKOkujicKPAuicsBk2SuMg/640?wx_fmt=png&from=appmsg)

 招牌是这碗“三拼粉” 


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/Yib3uQQKMFGKuzxyozAzK2gTdUicSs5Dx0glsEicPhPiaEaibV1TF2dm6xv3yOAV7ZjPH0EG0LUg4pdNo6rsWT9V3rg/640?wx_fmt=jpeg&from=appmsg)


- 第一次来推荐尝尝招牌的【三拼粉】，二两粉的20元，三两粉的22元。桂林米粉默认是没汤的，干拌款，如果想加汤可以跟店员说，拿到后厨给加，可秒变汤粉。推荐大家先吃吃干拌的，再去加汤，一次吃两款~

/ 香浓卤水

![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/Yib3uQQKMFGKuzxyozAzK2gTdUicSs5Dx0TEn2Hr7Fyssr4eTibc1zJiay3fmgTg6uumsibcLDAGBdHX1sL00oCb2mw/640?wx_fmt=jpeg&from=appmsg)

- 干拌味道的关键来自于“卤水”，就是米粉上挂的这层汁，每家有自己的作法。他家的卤水挺香的，猪油味略重，拌匀之后也不咸。档口上还贴了“粉淡了 找阿姨”的提示，口重的朋友们可以再去加卤水~

/ 脆皮锅烧

![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/Yib3uQQKMFGKuzxyozAzK2gTdUicSs5Dx056TURHKcH4WvZfzjntukA3tOCIwyCXj9TFK5JJFalnLjy2qHj52eiaw/640?wx_fmt=jpeg&from=appmsg)


- 三拼里面配置了三种肉：锅烧+叉烧+牛肉。丰富的肉量足以支撑咱们吃完一整碗粉~

![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/Yib3uQQKMFGKuzxyozAzK2gTdUicSs5Dx0ZokGs45OeLrM3wlqxk6KeVcXz67Eorec8Wa2rHSLFVn46oSrQkMcJA/640?wx_fmt=jpeg&from=appmsg)

- 【锅烧】其实就是炸好的脆皮猪颈肉，切片。他家锅烧真的很精彩，看了一圈大家基本上也是零差评。猪皮部分炸出脆壳，口感十分酥脆，吃起来贼香。尤其配上米粉和各种小料，一点都不腻，满口油香+肉香~

/ 爽滑湿粉

![图片](https://mmbiz.qpic.cn/sz_mmbiz_gif/Yib3uQQKMFGKuzxyozAzK2gTdUicSs5Dx0KJISJSNd0rtfLjvSoCML1fo3X49zk6k0C9qgPzIPaD9rdiaWNzHTqxA/640?wx_fmt=gif&from=appmsg)

- 米粉虽不比桂林当地现做的鲜粉，但这湿粉的口感在北京也是头部了。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/Yib3uQQKMFGKuzxyozAzK2gTdUicSs5Dx04aXvToaLg0ok5EEyjhGE7kkOmvibmwUpMgCzfJjoVwr1mH1W84YwW2w/640?wx_fmt=jpeg&from=appmsg)

- 米粉入口爽滑，微弹，就是硬粉爱好者可能会觉得有点偏软，可在点单环节直接跟老板说：粉煮硬点~
/ 甄选小料

![图片](https://mmbiz.qpic.cn/sz_mmbiz_gif/Yib3uQQKMFGKuzxyozAzK2gTdUicSs5Dx0BhIe4uZm1j25ChdQjt7K2osebqsO4ao1YWKt7I1svvyeH0vCAFzpOA/640?wx_fmt=gif&from=appmsg)


![图片](https://mmbiz.qpic.cn/sz_mmbiz_gif/Yib3uQQKMFGKuzxyozAzK2gTdUicSs5Dx0IziayUDrRkA2SxIEvuNLMSltnTBwkD6Qcb1BgTibRuBWNUAL651ppjWg/640?wx_fmt=gif&from=appmsg)


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/Yib3uQQKMFGKuzxyozAzK2gTdUicSs5Dx0pZL0s9YH9V8HARqEDhBl24ALsVLxar6tCemdhJd6aicxasXsQkmE8aw/640?wx_fmt=jpeg&from=appmsg)

- 正宗桂林米粉的调味其实都是由食客自己掌控的，叫号取到自己的粉碗，就可以来自助小料台大展身手了！酸豆角、萝卜丁、辣海带、酸笋，这些是增加风味的，可以每样都来点儿。辣椒就要谨慎了，店里自制的泡椒和葱头辣椒，辣度都不低，还有魔鬼辣椒油！要一点点地加~


![图片](https://mmbiz.qpic.cn/sz_mmbiz_gif/Yib3uQQKMFGKuzxyozAzK2gTdUicSs5Dx02bMy0ibrv429qEbRr1Dk2bacvzvISu9LXdLX0pnuxjSjE9Uo4iaiaBoUw/640?wx_fmt=gif&from=appmsg)

- 调配好后上桌尽快拌匀，尽享第一口浓郁丝滑！

/ 有切粉！


![图片](https://mmbiz.qpic.cn/sz_mmbiz_gif/Yib3uQQKMFGKuzxyozAzK2gTdUicSs5Dx0yyWpEabSn33G09LvTFJzMzZ3HHsCQuABibHbP6cmUaichS9fJO1TKjfA/640?wx_fmt=gif&from=appmsg)

- 摄影师钟哥是湖南人，看到店里有【切粉】的时候眼睛都亮了，大喊：我吃这个！切粉的口感更软一些，嗦起来也更爽快~


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/Yib3uQQKMFGJG9J6SoLHxYGU4iaICJKzE8NicFUHWv4Q5cpQn11cMOibGeMDeSVycCyO5bCnPWAjSqdF7ydF3icTfqA/640?wx_fmt=png&from=appmsg)

 多孔吸汁的“广西猪皮” 


![图片](https://mmbiz.qpic.cn/sz_mmbiz_gif/Yib3uQQKMFGKuzxyozAzK2gTdUicSs5Dx0sBu2v3ib6Y08CgG7dt7viaAh3Ln6QT63bsickBtSAgYicFb2PdDicmRAYbQ/640?wx_fmt=gif&from=appmsg)


![图片](https://mmbiz.qpic.cn/sz_mmbiz_gif/Yib3uQQKMFGKuzxyozAzK2gTdUicSs5Dx0dNQxKohNMibsbcsQQFYJ5GxXNh7oia2piaicAcVRd0UZjaEkicgPed1oiaGw/640?wx_fmt=gif&from=appmsg)

- 后厨的大锅里还煮着卤腐竹、兰花干、牛肉丸和猪皮！咕嘟咕嘟的声音惹人食欲。【猪皮 6元】非常多孔吸汁，味道咸鲜，可以加一份~


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/Yib3uQQKMFGKuzxyozAzK2gTdUicSs5Dx0lqtdLic1sYzbsX3jbwa5hU2Gtiav4TJOFkmrKNrDsz0CxMtSyxTEhGGg/640?wx_fmt=jpeg&from=appmsg)

- 卤腐竹非常大片，入口柔软极了，豆香浓浓。这些配料跟桂林米粉的味型不太一样，推荐不拌入粉中，试试单独品鉴~

- 值得注意的是，店门口还有个做“糯米汉堡包”的小档口。中午12点左右，木制蒸锅里逐渐冒出阵阵热气，再过个10几分钟就能买了！这糯米饭团也是很local的口味，看加的料就知道了！糯米上还会抹一层绿豆沙~ 绿豆沙不甜，纯纯提供沙沙的口感和豆子的清新香气。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/Yib3uQQKMFGKuzxyozAzK2gTdUicSs5Dx059sG3j99QAQ0x44PzhW5GLAEtia7UE3Unn19TbJAf9PSJlbbgCavsiaQ/640?wx_fmt=jpeg&from=appmsg)

![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/Yib3uQQKMFGKuzxyozAzK2gTdUicSs5Dx0eZY3dDPZQWd2Z55ZTMCicRQIW1OBicB0MhyYWnhaCKT4nK3Mt1ytx7Ag/640?wx_fmt=jpeg&from=appmsg)

- 饭团整体优秀，糯米油润，口感糯而韧（偏硬）。酸豆角、绿豆沙、藕丁、豆腐丝、辣椒、薄脆花... 这些配料的口感和味型各异，在嘴里mix后令人胃口大开，想要持续咀嚼~


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/Yib3uQQKMFGKuzxyozAzK2gTdUicSs5Dx0HUX0LFuH7oOXgicjYc4MlTg7vekYopicP66kwgfwMQmLoKsIGNgjIslg/640?wx_fmt=jpeg&from=appmsg)

- 店里还提供免费的冰红糖水，很解辣！如果米粉辣椒放多了，这便是你的救赎。有时还能赶上免费的绿豆沙或小米粥，全看你到店的时机了~
