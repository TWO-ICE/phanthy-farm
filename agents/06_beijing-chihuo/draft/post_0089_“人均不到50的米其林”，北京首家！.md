台湾厨师的小吃店

 连续5年登上米其林

 “终于开到北京了！” 

 

![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/Yib3uQQKMFGIDNib8M8VyhhAQl71IxSibtwiaPsCkqyl7LUzn8WvB5dI7ZJxaxsrJQ6Q4FciabCWAGT6DwicuP1DEHNQ/640?wx_fmt=jpeg&from=appmsg&tp=webp)


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/Yib3uQQKMFGJqZVJicc57vS2YZQ3sQ48VG3fcKfY7ibibNLeOxic9sRvvTJYT2WzENmIlO6S9oUATxEFe6l1SXuSBJw/640?wx_fmt=png&from=appmsg)

 · 来自香港的米其林品牌 · 
/ 北京首家开在海淀


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/Yib3uQQKMFGJYWPV4eIr04GHibnS0jiajwAhHKpTdnv6ic7szEGhz1aRcmgpV0psMdglVkBtU7X7A8eZ01SicvU4vLg/640?wx_fmt=jpeg&from=appmsg)


“一位名叫阿元的台湾厨师在香港开的餐饮店。”，经过10几年的打磨，如今已是2021-2025连续五年被米其林必比登推荐的台湾小吃品牌。多年间他家也是持续北上，最近终于在北京开了第一家店！位置就在咱们海淀区包罗万象的大商场——世纪金源里~

/ 集合吧！台湾小吃


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/Yib3uQQKMFGJYWPV4eIr04GHibnS0jiajwAbl8MH2EVYCM9XPvFqdvJPN5EGTUz2umlD0zHziahzER2plz32HdZiaXQ/640?wx_fmt=jpeg&from=appmsg)


店里光是招牌的卤肉饭就有5-6种，还有大肠包小肠、蚵仔煎、白菜鲁、盐酥鸡、炸大鸡排、鸭血豆腐、大肠面线、卤味拼盘等等台湾小吃，连饮品都是超台式的红茶跟珍奶！

/ 刚开就人气十足


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/Yib3uQQKMFGJYWPV4eIr04GHibnS0jiajwAdXqEVudJiaRibgzUqKUG0DOezqsr71O2BlrLKicibfBicHnVBG6bvpEv1rA/640?wx_fmt=jpeg&from=appmsg)

虽然开在商场里，店内的灯牌也拗足了气氛！营造出一种很古早很市井的小吃街滤镜。他家是中午11:00开始营业，基本临近12点时就要等位了，想不排队吃要趁早。好多家长会带孩子来吃他家，可能因为台湾小吃基本不辣，口味适合全家~


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/Yib3uQQKMFGJqZVJicc57vS2YZQ3sQ48VGXIFSYDwlhqchT4rA8EMXSPrjkK8UMc2bHXy8uuoOtEa6sPd2kHqvjA/640?wx_fmt=png&from=appmsg)

 · 炼成一碗“国民卤肉饭” · 
/ “基操版”足矣见真章


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/Yib3uQQKMFGJYWPV4eIr04GHibnS0jiajwAcX6xPwUyhkSHZCkhYEPTkJz7y8Z5rJMT2zZvIdzPic0pr3ibng2hkdIQ/640?wx_fmt=jpeg&from=appmsg)

在他家一众卤肉饭中，第一次来还是建议先吃最基础款的【慢煮阿元卤肉饭 21元】，足矣感受卤肉的质地和味道。除此之外还有香肠卤肉饭、享瘦瘦瘦卤肉饭、元气满满卤肉饭（有虾仁&蚵仔）、皮蛋噜噜饭（有皮蛋&油条酥）......

/ 6小时低温慢煮


![图片](https://mmbiz.qpic.cn/sz_mmbiz_gif/Yib3uQQKMFGJYWPV4eIr04GHibnS0jiajwAaB4DQwYErKSyEibpViboDIOjiaHhluWjibeicCMuggfUA7RJISicT7lkdHOA/640?wx_fmt=gif&from=appmsg)

他家卤肉主打一个6小时慢煮工艺，让肉汁和酱油香锁在肉里。说是这样可以避免形成入味不均or缺乏香味的碎肉。卤肉汤汁不够的话也能再找店员免费加~


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/Yib3uQQKMFGJYWPV4eIr04GHibnS0jiajwA2SwY0k4BCRH5520Z8ZpbicMUG43ndib9tlibTmZf8whJdcpv62UzCVcjA/640?wx_fmt=jpeg&from=appmsg)

一大口卤肉饭进嘴，的确过瘾，卤汁微微粘嘴，猪肉的油脂香也很明显，还有台湾小吃最重要的那股甜味儿hhhh。当天米饭的嚼劲也挺刚好的，略硬于卤肉。

/ “香肠好甜...！”

![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/Yib3uQQKMFGKVOXPaoNjJKMztMJ2mWo86tgwvYFHWShIAzIdtvxF48PzpkbePrcfW1Hm99NQh83TKwVfJ6kzmCg/640?wx_fmt=jpeg&from=appmsg)


![图片](https://mmbiz.qpic.cn/sz_mmbiz_gif/Yib3uQQKMFGKVOXPaoNjJKMztMJ2mWo863WW1P8ByhVRt9T4ScKsCNGpkiaCibBXia0ylZLDYaM4HQiaiaovZHf4LwsQ/640?wx_fmt=gif&from=appmsg)

【香肠卤肉饭】里的香肠甜度很高，几乎只有甜味和酒香，不知道大家吃不吃得惯。吃不惯的话可以加桌上的辣椒酱！

/ 尝鲜友好的小碗装


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/Yib3uQQKMFGJYWPV4eIr04GHibnS0jiajwAdPbsv0mNEOFKtkaHlD8ojTmZXk6icEauosGdiblYTd6vgsGTQjHriaDlw/640?wx_fmt=jpeg&from=appmsg)

阿元卤肉饭还有小份，小份里没有青菜，价格是16元。图可直观感受大小对比~


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/Yib3uQQKMFGJqZVJicc57vS2YZQ3sQ48VGQr1lDDfORDFUAhUDtYQfQN30qHqTJiaWLn08W5TmIayQ4af3yEHoOlg/640?wx_fmt=png&from=appmsg)

 · 还原度很高的台湾小吃们 · 
/ 鲜甜的大肠面线


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/Yib3uQQKMFGKVOXPaoNjJKMztMJ2mWo86vrz4palA3A00W18CuH1FIzV75S7o8Jibp2Vwt9WDPJaTt7gy52mqJfg/640?wx_fmt=jpeg&from=appmsg)

【西门町蚵仔大肠面线 23元】是令人欣喜的鲜美的甜咸口儿！上面的大肠好吃，蚵仔们虽然鼓鼓的看似肥美，但不够新鲜，吃起来腥且发苦。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_gif/Yib3uQQKMFGKVOXPaoNjJKMztMJ2mWo86bgjj62Tia0icynjhjH6W3HlLkfSGgCfSiaZR7LHlYgxMia5PoL9HtQsY5w/640?wx_fmt=gif&from=appmsg)


![图片](https://mmbiz.qpic.cn/sz_mmbiz_gif/Yib3uQQKMFGKVOXPaoNjJKMztMJ2mWo86ehpX1cMLxHXichrjrDickA6GwTvpvGFC579dsObU3jcBY2HgRiabE7JdA/640?wx_fmt=gif&from=appmsg)


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/Yib3uQQKMFGKVOXPaoNjJKMztMJ2mWo863vBt6WEJ8CiaQ3N6hhXayf8iafspTzY91bWjQhwAIULUvfQPvsLut8Yg/640?wx_fmt=jpeg&from=appmsg)

好在避开蚵仔的话，面线和卤汁的好味道不受影响。这个不建议加辣椒，吃原味最能体会那种仿佛在湿粘空气中吹着海风的惬意感~

/ 甜香肠真正的“战场”


![图片](https://mmbiz.qpic.cn/sz_mmbiz_gif/Yib3uQQKMFGKVOXPaoNjJKMztMJ2mWo86OibVQSQVJhxrcU0s0DQ8r6gyNQvzbPaSTlDtHIBnhw5JJTF3Box5okQ/640?wx_fmt=gif&from=appmsg)


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/Yib3uQQKMFGKVOXPaoNjJKMztMJ2mWo86DRoiathxGg8ASqdlRh2CJjAGRhERDtcbghibw0hptpJ6ibpeHNYvUvRVA/640?wx_fmt=jpeg&from=appmsg)

【逢甲大肠包小肠 28元】是多少人台湾小吃的启蒙选手！这个香肠是他家卤肉饭里的同款，但跟糯米搭配成小吃模样，可接受度就高了不少呢~ 之所以叫“大肠包小肠”，是因为糯米外面也是一层肠衣，剖开里面夹了煮软的花生、酸菜、蒜片和爽脆黄瓜丝。好想每天来一个当早饭啊...谁懂...

/ “一股中药汤子味儿...！”


![图片](https://mmbiz.qpic.cn/sz_mmbiz_gif/Yib3uQQKMFGKVOXPaoNjJKMztMJ2mWo86nleGt2QLOgTDDJBYbbVNJXRe2ncadz0sBowia3STkV27e9IT6Fh03Wg/640?wx_fmt=gif&from=appmsg)


![图片](https://mmbiz.qpic.cn/sz_mmbiz_gif/Yib3uQQKMFGKVOXPaoNjJKMztMJ2mWo86At3YkqhHnBiaq6ZAbldNMmFJECnURQXHRc1uZE7kzqbVYmBVlvX7BVg/640?wx_fmt=gif&from=appmsg)

【麻辣鸭血豆腐 6元】可选加不加香菜，上桌小小一碗，两块儿鸭血+两块儿豆腐，下铺一点粉丝。对于爱吃台湾鸭血豆腐火锅的朋友们来说，这碗可以说是解馋了，就是那股中药味的麻辣汤底！鸭血和豆腐都很入味儿~

/ 炸物大乱斗！


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/Yib3uQQKMFGKVOXPaoNjJKMztMJ2mWo86V38nQy8nzdTxW6HH2uUUibH1T9CTh6QbleGGXnaqKsfg1kg4qulNM9w/640?wx_fmt=jpeg&from=appmsg)

【士林豪大大鸡排 36元】可选甘梅味or辣味的撒粉，趁热吃鸡排厚厚嫩嫩，有那种满嘴油滋滋的满足感。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/Yib3uQQKMFGKVOXPaoNjJKMztMJ2mWo862P18P2Dia3fKmdoEDmY6xJU5s734NyUjicm38W4bs5np2E5YqS0drbQg/640?wx_fmt=jpeg&from=appmsg)

鸡排侧面能看出汁水，厚而不柴啊朋友们！


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/Yib3uQQKMFGKVOXPaoNjJKMztMJ2mWo86Wbx1CaibNNWZIlaY65539M7aWiaNia77AcOwkcIQuc1gXPeEuhTVwQiadA/640?wx_fmt=jpeg&from=appmsg)


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/Yib3uQQKMFGKVOXPaoNjJKMztMJ2mWo861WQAZNmCopD8qByYiarsgz4T1zKo0koA3OktAouWNteHy1PvpNUkKicA/640?wx_fmt=jpeg&from=appmsg)


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/Yib3uQQKMFGKVOXPaoNjJKMztMJ2mWo86Z0hxB2w2QE1ayP3ZlqYBMAlVvAic3Rmf6YRht01Y2YCR4aFUyiaFxpDA/640?wx_fmt=jpeg&from=appmsg)


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/Yib3uQQKMFGKVOXPaoNjJKMztMJ2mWo862xLj1DgC1P7PiaDJe8fmIMNlDKTLbiax7TBBoichW0I7ZjvnbqyQQFezA/640?wx_fmt=jpeg&from=appmsg)

爱吃炸物的可以来一份【台式小吃乱拼】，集齐米血糕（猪血）、咸酥鸡、甜不辣、西蓝花、香菇和玉米，荤素主食一站式炸齐。米血糕吃着干爽酥脆，甜不辣也是那种地地道道“薯角形状”的，咸酥鸡很大块儿，都可以蘸椒盐或番茄酱吃~

/ 别错过台式红茶和珍奶


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/Yib3uQQKMFGKVOXPaoNjJKMztMJ2mWo86DGO2bE4qxeCAtEeJmyudey9nJ2Yhv5N3xicoMSe2cNgbhiaaoc6u1Hsg/640?wx_fmt=jpeg&from=appmsg)


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/Yib3uQQKMFGKVOXPaoNjJKMztMJ2mWo86XTuPibKqicFnTunGjnEQfu5YXnkMC4cUOSiaiaE1ajAJ0PxJEcCib65LfBA/640?wx_fmt=jpeg&from=appmsg)


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/Yib3uQQKMFGKVOXPaoNjJKMztMJ2mWo86HvvH86XvicI39uFPbZz4fqVJSmybJePRTFutbZhicfQRicN6lGHiabibgiag/640?wx_fmt=jpeg&from=appmsg)

来他家吃饭主打一个小而美，适合逛街逛累了来充充能。卤肉饭和油炸小吃们推荐搭配【卤肉时蔬 12元】一起，不然吃多了还真有点腻。必不可少的还有【古早味茉莉珍珠奶茶 15元】和【古早味红茶 10元】，都要半糖，茶味非常香浓，一喝就回到了手拿1000cc大杯红茶逛夜市的夏日时光~


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/Yib3uQQKMFGKVOXPaoNjJKMztMJ2mWo86K1LN9tH6BKCODblm836gw3nzop7HrQcgD1Hiat2sjFtRqPjiaSn0DhfA/640?wx_fmt=jpeg&from=appmsg)

其实店里还有非常多种类的台湾小吃：包括在康熙来了里看过的鸡卤饭（鸡肉版卤肉饭）！以及蚵仔煎、苦瓜墨鱼丸汤、香酥红糟肉、白菜鲁...由于胃容量有限，这次都没来得及尝试，不知道阿元会不会再喊蒜蒜去吃一顿呢（坐等.jpg）~
