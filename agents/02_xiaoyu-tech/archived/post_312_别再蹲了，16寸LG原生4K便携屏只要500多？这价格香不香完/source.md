# 别再蹲了，16寸LG原生4K便携屏只要500多？这价格香不香？

![封面图](https://mmbiz.qpic.cn/mmbiz_jpg/E9h3abOJCemvLFkCvrpFBg0lQJ4KzqPI8w0OibVFXvYsTYzCVicODvld03mvHuF5KxE7Znoiaxm7Ta9ibKrWHZSgWtnWiah4s6iaKDfiaLPEF4mfFE/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/Fkn2hIR8YYgsKIy9hdHQrg

说实话，最近这几年数码产品的价格走势，看得人有点恍惚。尤其是屏幕这东西，以前4K分辨率那是专业用户的专属，随便一个便携屏都得奔着两三千去。但现在你再看看二手鱼，风向完全变了。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCek3C3sjwV5Rl7keQqaIXX3ic8FFjqYOFSv6uvl6DYejeTsILYuut112H9lDtibl7nsqyFPb03ZGYWv6Odt6E1lufLRzz3yNQAd7E/640?wx_fmt=png)


前两天刷到一个卖家，挂出来16寸4K 60Hz便携屏，价格530块。我第一反应是这卖家是不是多打了个零，或者是那种专门坑人的组装垃圾屏。但点进去仔细翻了翻，发现事情没那么简单。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCencdvDia6iaPxbFWibzhPzZNCGTKnYgFntibxMCZAIGnFn7fwibbQ1PFECCJ8GBaELibJyI4dHAXTXasLSticEibs0E3lpZhQIRibu4EsLQ/640?wx_fmt=png)


这块屏用的是LG的LP160UQ1-SPB1面板。老玩家听到这个型号应该会有点印象，卖家说ThinkPad X1隐士和这款屏是同款，当年配这个屏幕的笔记本，价格直接起飞，普通人根本舍不得下手。现在倒好，这块屏幕被单独拿出来做成便携显示器，价格直接腰斩再腰斩，五百来块钱就能拿下。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCem8gMvufk8yLrfevT8vpxrdUibtrxjmBfrGI7N4c908O2ky3oIeYQPQ6BsaZBIdxVYx3sRruVS7ZSGSBuLIcTDTvSJ80nErZiaBY/640?wx_fmt=png)


参数给得很足，16寸，4K分辨率，600nit亮度，100% DCI-P3色域，还是雾面屏不反光。两个全功能Type-C口支持一线通，插Switch插笔记本都很方便。IPS面板可视角度也没问题。说实话这个配置放在两年前，二手鱼上怎么也得卖个一千二三。现在五百块就能搞定，确实有点离谱。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenUznKGFDYWJJEeyKuIeQia6AhDOicJybew5DiayAKkf7IINvLpOMCzePTY0ibGIkVxFEvwsSgNT9AtibSAaVTbiaZkuBkKMp7srktEk/640?wx_fmt=png)


但咱们也得想明白，为什么价格能打到这么低。卖家说是工厂直发，全新屏，剩下十几台便宜处理。结合13万浏览量四千多人想要的数据来看，这批货大概率是工厂的尾货或者库存清仓。说白了就是厂家手里压了一批货，不想继续占仓库，干脆低价甩了回笼资金。这种事在数码圈其实挺常见的，只是这次轮到便携屏了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenD0CTvQ4Ziau86FnVjiaNLPQSoh86fAyRW0qcSss0nILQv6GER1z3oU4EHgYMibKOp0nNBFSXKaWp7d4f1oRWzPma8haBmKIWZZk/640?wx_fmt=png)


对咱们普通用户来说，这其实是好事。530块钱买个4K副屏，拿来搞设计剪视频，或者给笔记本当扩展屏，体验直接起飞。哪怕是当Switch的外接屏玩3A游戏，显示效果也比原装屏幕强太多。而且卖家给两年质保，七天质量问题包换，说明还是有底气的，不是那种卖完就跑的一锤子买卖。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekLpT226CYiaDOrGXbhEM60zniatrnFgHJf7Dbflfyjicqp30jVqz4CfEu7TyuUicWducpQkOVISPFUKiaLtYG1fYQvQyzMUibKC1b1M/640?wx_fmt=png)


当然也得说几句实话。这个价格就别指望做工有多精致了，外壳大概率是通用公模，质感肯定比不上大品牌几千块的产品。另外60Hz刷新率对FPS玩家来说可能差点意思，但如果你是搞创作或者看电影玩3A，那完全够用。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCel6sVejN3SefhpF2zxTxfmb6MaSLGyLegsAPOkpDh1TfNxKpEMJFT6CIVt94VzKGicqt9WOb3floTaxyUmoRx53vpAdc0OmGWWQ/640?wx_fmt=png)


所以总结下来，这台530块的16寸4K便携屏，适合什么人？预算有限又想体验4K画质的学生党，需要便携副屏的移动办公族，还有想给Switch配个高画质外接屏的游戏玩家。不适合那些对做工有极致要求的完美主义者，或者追求高刷电竞体验的硬核FPS玩家。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelGlQBrpR55g16Ge6uNrEJdnqrZ3VR4wJnRGzRuRkgFUeqcaa2aPibIiaDRIXC5TGGWEy2hq25iaBrOGmGUdVCpRA12HPg1XopBHM/640?wx_fmt=png)


最后想问问各位，你们现在用的副屏是什么分辨率？花了多少钱？如果给你五百块预算，你会选择升级屏幕还是添点别的装备？评论区聊聊。
