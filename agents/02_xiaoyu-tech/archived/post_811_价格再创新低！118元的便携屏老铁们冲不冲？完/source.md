# 价格再创新低！118元的便携屏老铁们冲不冲？

![封面图](https://mmbiz.qpic.cn/sz_mmbiz_jpg/E9h3abOJCekUysynQIPv8iagYHMWHoicgGdzZKymw8SlNnxL5rLfIEmurPibricJRwku80DHqULmOIEQp0hwlzuhUq4E3m8RuLFn6tsIAlFSrlc/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/i0i9t35vpMVL1U7p2dKkoA

今天刷到一个15.6寸的便携屏，居然只卖118元，这价格在几年前，连块好点的手机屏幕都买不到吧？现在没想到已经跌倒100元附近了，也就一包烟的价格，搞一个当做显示器或者是手机的副屏都能支持。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekFs76Xp43sOOGZgVjdbyQbKeaOmopVdDuNPx8T3Pqan7u7OX04FEXCmgN4zRAdbUDv9vP8GichledCDgn8cSW1SFGaK2Hic8LcI/640?wx_fmt=png)


先说配置。15.6英寸，分辨率1360×768，也就是常说的HD屏。别指望它有多细腻，但日常看看文档、刷刷网页、当个副屏扩展完全够用。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemwicETB1rmaPvapEvcI3xKd78afiaQ3r0wu3aTwAibUSA8RPwGGG9RzR86Oyr58IbSvaPjySOYTyKNNzNMFR75Bmm7BxeRZNL7Gs/640?wx_fmt=png)


接口方面，卖家明确写了有HDMI，但从图上看，还有Type-C、两个Micro USB、OSD调节纽、音频口。不过声音输出没提，估计是个哑巴屏。成色说是“不错”，但没品牌信息，三星京东方都不用想了，但话又说回来，118元你还想人家给你上原装LG？大概率都是二手拆机屏，可能卖家自己都懒得看是啥牌子的。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekhBkFbhElkm4p5PhYd02KiabkEOpVibv0HAuP85dUQJz8ACtXuxZsoxUHlOJ0vDWG2HcuYeR44NqOCT5vVmVaJsTAfMJywhJruM/640?wx_fmt=png)


这也不能奢求太高，毕竟价格在这摆着呢。118元是什么概念？两顿外卖钱就能搞来一个第二屏幕好像也不算亏。学生党拿它连Switch打游戏，打工人出差时接笔记本开双屏，租房族不想买大显示器又想提升效率，它都能顶上。虽然分辨率低、色彩一般、亮度可能拉胯，但你要的是能用，不是惊艳。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenPTg3qXjoYAXtCw2iaHsaMNVgjboVhISSb0WRAic9686iagM59BiaHLDctUMtGtF72Duh8SrGFOvBC5SnIvtqwLC1oEvuGT2Rsias0/640?wx_fmt=png)


不过得提醒一句，卖家写了“售出不退不换”，所以在买之前一定要问明白。建议你私聊时重点问三件事：是否支持Type-C一线通？有没有背光均匀？能不能外放声音？如果对方含糊其辞，直接划走。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenknfAXr53aUnwuF9PNGZQfEhH3pic0yxcFTqjVehguAJWhWffS5tvvN2BIzwLTgLBjzoFEFfoCzFlEMY5ribialk3ZIxLh0plTdI/640?wx_fmt=png)


另外，别被便携两个字迷惑。15.6寸其实不小，厚度和重量未必轻。如果你真要移动使用，最好确认是否带保护壳、是否内置电池，不过从描述看，大概率没有，得靠外部供电。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelv0YnTUwBFQt3Odr2uzf5P6mVvIWpwv7mBhg2DBKzvibNhQTvCMY90a0EMu1V6lLxeOqjyePSsnKpRo62ezeVpKD2NBFVE2dvs/640?wx_fmt=png)
