# 二手鱼里果然都是大佬，30块捡漏接口超多的惠普扩展坞靠谱吗？

![封面图](https://mmbiz.qpic.cn/mmbiz_jpg/E9h3abOJCelXVDwXQhXt2QosorCHIZ2iaQAPevFviciaXkl7bwSZianyiabMJZfYiagMFoDspicRPCS6Tj72cPO3Wxh1MvSBicw7xIA0heSNMwqn6HY/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/pae1T9On1ucsMrWdm2UqYQ

兄弟们，你们有没有这种时候，笔记本摆在桌子上，想接个显示器发现接口不够，想插个U盘还得跟鼠标抢那个唯一的USB口？去网上一搜，一个新款的扩展坞动不动就一两百，甚至更贵，感觉这钱花得有点冤，毕竟咱这电脑可能也就值个几千块。但电脑接口不够用这事儿，又实实在在影响咱干活，咋整？


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemXVc2K8sdfReiaekxrcPO7eNKwfxbmqRYptyib3VFV3lB1WE4kovI9gk9ibVPzw6SKfibFBejfwgvayeGX1p0gmoMHylfW4eQI8cY/640?wx_fmt=png)


二手鱼里捡漏你想过吗？最近冒出来的一批老咕噜棒子，惠普的3005pr USB 3.0扩展坞。价格？说出来你可能不信，30块钱，也就一包好点的烟钱。卖家说手里有12台，打包出，保正常使用，全是裸机。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCem0H8PUsiaCUgKlo4Wpa3fXEIkIQic4mBu0ste2CfeJPZfboY1F0IEaibtVDYHiaoyAziciaEqHoiaiaK6QMbHt3yslDia6qEb9wbib2ZxX4/640?wx_fmt=png)


咱们先别急着喷垃圾佬又捡破烂了，这玩意儿到底有没有用，咱们得掰扯掰扯。这东西别看它其貌不扬，成色方面你就别指望跟新的一样闪闪发光了。但它的接口，放到今天来看，对于绝大多数办公党来说，依然是妥妥的够用。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelOf5ibqcFViaRSaPB1UD6ic5VRr64xyIJfxQ1et0G55y9FkMxEgbicWXppzFfOicpQ0L58H9MmaLJwUuIQsfu1kChc7icrck4XcI5ss/640?wx_fmt=png)


它身上都有啥？一个DP口，一个HDMI口，然后是两个USB 3.0和四个USB 2.0接口，鼠标键盘这种对速度没要求的插2.0上，U盘、移动硬盘这种需要读写速度的插3.0上，够你插满一桌子的外设了。还有一个音频口，连个音响耳机啥的也方便。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemCGe7mDeDorZU3zgPRhrbOiabB8K8EibicwjIOPITiaeTmVGia0K3ZHNJua5pm1KXepEPYuA0WzaQvY9pVGDjVplcUUBxMCI2KaQeA/640?wx_fmt=png)


最关键的是，这东西即插即用，不管是Windows本还是Macbook，插上就能识别，完全不用你费劲吧啦地去装什么驱动，对于咱们这种电脑半吊子选手来说，简直是福音。你想想，你只需要花30块钱，就能让你那接口稀缺的笔记本瞬间变成一台功能齐全的台式机工作站，这性价比，是不是一下子就上来了？


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelHK2VFUsQwkw8cxl05p38RWL9I8YJRVfpQN5QZMCH4m5A2icClqj1KFeiaqFNrmAtSL7fIic81he3mLSBnlnSwMgibUs7QIqZvBJk/640?wx_fmt=png)


当然，咱们也得客观地说，这玩意儿的缺点也很明显。

第一，它是个“裸机”，卖家不给配电源线。它自己工作需要外接供电，你得自己想办法搞一个电源适配器。这算是个小小的门槛，不过如果你家里有那种老旧路由器的电源，或者花十几块钱在网上淘一个，也能解决。

第二，它的外观绝对算不上精致，妥妥的工业风，外壳划痕掉漆肯定少不了，对于追求完美的同学来说，可能看着有点难受。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenB2Lp3j32GsuTrrX1vsITuG3HMKRCRZ6kFw4vlVTdZ9wicWeF7fS51r0zh4QLiaW0w7lQspD83hEyKbHylib5LjO9sKOdJ3mldyY/640?wx_fmt=png)


那么这玩意儿到底值不值得入手？我的看法是，如果你符合下面这几种情况，那它简直就是为你量身定做的宝贝：预算抠搜，不想在扩展坞上花太多冤枉钱；电脑接口少得可怜，严重影响日常办公效率；主要需求就是接显示器、键鼠、网线这些基础外设。那这30块钱，你花得绝对物超所值，甚至可以说是跌至冰点价的神器。但如果你追求的是最新最快的传输速度，或者需要用它来给你的笔记本充电，那这玩意儿可能就不太适合你了，你得去看那些更贵的、支持PD快充的型号。
