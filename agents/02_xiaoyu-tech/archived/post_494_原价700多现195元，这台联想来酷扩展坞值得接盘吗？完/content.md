# 原价700多现195元，这台联想来酷扩展坞值得接盘吗？

最近在海鲜市场蹲点时，刷到了一个挺有意思的“电子废品”——联想来酷（Lecoo）的17合1桌面扩展坞。卖家标价195元，态度还挺豪爽，表示下单就送一个全新的鼠标或者大号鼠标垫。

打听了一下这玩意儿的来历，卖家说是2021年11月入手的，结果到了2022年3月就开始吃灰闲置至今。至于吃灰的原因，听起来既心酸又普遍：手里没有支持“双Type-C全功能”的电脑，买了之后发现自己根本没法压榨这台扩展坞的全部性能，用着用着就腻了，干脆扔一边吃灰。卖家倒是实诚，提前声明说千兆网口、3.5mm耳机孔和TF卡槽因为手头没有相应的测试设备没测，剩下的USB、视频输出口等核心功能全部试过，都是好的。

面对这种“断崖式降价”的大厂配件，我的第一反应不是捡漏，而是警惕。咱们先扒开来看看这台扩展坞的底子到底有多厚。

看参数，这台机器确实是当年的“堆料狂魔”。所谓的“17合1”并不是营销噱头，接口多得能逼死强迫症。它配备了3个USB 3.0接口和2个USB 2.0接口，视频输出方面给足了HDMI和DP（DisplayPort），甚至还有传统的千兆网口、SD卡槽和Type-C上下行接口。

最骚的是，它竟然还支持M.2 SATA硬盘扩展。这意味着它不仅仅是个扩展坞，本质上还是一个加了USB集线器功能的移动硬盘盒。在视频能力上，它拥有4个视频接口（虽然具体是三HDMI一DP还是其他组合要看实物图，但官方描述是支持多屏），最大支持4K@60Hz输出。要知道，在2021年，想要买到一台支持双4K 60Hz输出的扩展坞，不管是联想自家的ThinkPad系列，还是贝尔金、绿联的高端线，价格基本都是往600元以上走的。这台机器当年的原价挂着700多块的标签，现在195元，相当于直接打了个“骨折”，价格还要再往下砍一截。

把这台联想来酷放到现在的二手市场环境里对比，优势就更明显了。

目前海鲜市场上，同样是17合1这种变态堆料规格的扩展坞，哪怕是杂牌或者不知名品牌，全新未拆封的也要卖到600多。如果是联想、惠普（HP）这种大厂的原装货，更是溢价严重。哪怕是二手的，其他品牌同规格的普遍报价也在250元到300元之间。

再看联想自家的产品线，现在的联想异能者系列扩展坞，大多是实用主义的4合1、6合1配置，价格从99元到269元不等。虽然便携性强，但接口数量完全被这台来酷17合1碾压。对于桌面用户来说，多出来的这几个USB口和视频口，往往决定了你是需要插拔线材，还是能一劳永逸地“即插即用”。从性价比的角度看，这台机器的“接口单价”简直低到了尘埃里。

既然聊到了堆料，这台扩展坞最核心的亮点必须得好好盘一盘——也就是那个M.2 SATA硬盘扩展位。

现在市面上99%的扩展坞，不管是100块的还是500块的，都只提供SD/TF读卡器。想接硬盘？可以，外接移动硬盘或者通过USB口接。但这台联想来酷直接在肚子里塞了一个M.2插槽，虽然只支持SATA协议的固态硬盘（不支持NVMe协议的高速盘），但这依然是一个极具杀伤力的功能。对于很多老旧笔记本用户来说，这相当于花买扩展坞的钱，白嫖了一个价值几十块的USB移动硬盘盒。只要手里有闲置的旧固态硬盘，往里一插，立马就能多出几百G的存储空间，用来做Time Machine备份或者作为单纯的下载盘，再合适不过。

此外，它的双屏4K输出能力也是很多“全功能”扩展坞才有的素质。很多便宜的扩展坞虽然号称支持双屏，但往往只能双1080P，或者单4K@30Hz，那种刷新率看久了眼睛会瞎。这台机器支持4K@60Hz，对于设计师、剪辑师或者喜欢多屏挂机看股票、写代码的办公党来说，这才是真正的生产力工具。轻薄本恨只有两个C口的痛点，在这台机器面前基本被治好了。

不过，作为编辑，我必须得泼一盆冷水。这毕竟是一台“吃灰三年”的电子产品。

虽然卖家信誓旦旦说接口正常，但电子产品这东西，不怕用就怕放。长期闲置在潮湿或不通风的环境中，内部的电子元件容易氧化，特别是这种高集成的HUB主控芯片，长期不通电可能会导致引脚接触不良。最直接的隐患就是，你可能刚买回来用着挺好，插拔个十次八次，某个USB口就开始“甚至无法识别”。这种“暗病”是二手配件最大的赌博成本。

另外，它的充电能力也是个大坑。卖家明确提到USB-A接口只能满足基础充电。这在硬件术语里意味着它大概率不支持BC 1.2快充协议，或者给到的电流只有5V/0.9A甚至更低。如果你打算把手机插在上面一边传数据一边充电，基本上只会“不增反降”。更别提给iPad或者支持快充的平板补电了，那是想都别想，电量掉得比平时还快。要想快充，你还是得老老实实把原装充电头插到电脑或者扩展坞的供电口上，这玩意儿的USB口仅仅是“能用”，而不是“好用”。

那么，这台195元的“巨无霸”到底适合谁？

如果你是一个重度桌面用户，日常工作需要连接机械键盘、鼠标、U盘、移动硬盘，同时还需要外接两个显示器（一个HDMI一个DP），手里又刚好有闲置的SATA固态硬盘，那这台扩展坞简直是为你量身定做的。195元买回来，往桌上一扔，就能把轻薄本瞬间变身成全能台式机，这笔账绝对划算。

但反过来说，如果你只是偶尔需要插个U盘传个文件，或者一年也就用一次SD卡读照片，那我强烈建议你别折腾。去海鲜市场花20块钱买个不知名的USB小集线器，或者十几块钱的Type-C转HDMI转接头，足够你用了。买一个17合1的庞然大物回家，只为了用两个接口，这不仅仅是钱的问题，还是桌面空间的浪费。而且这种复杂的二手老设备，接口越多，坏的概率就越大，维护成本也越高。

目前海鲜市场上确实流入了大量公司淘汰或个人回流的扩展坞，但像这种“联想原厂”、“17合1”、“硬盘位”三合一的奇葩产品确实少见。这价格，这配置，哪怕是翻车率有20%，对于懂折腾的人来说，可能也值得一试。
