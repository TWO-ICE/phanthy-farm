# 二手鱼280元能拿下京东方画屏，网友：改成壁画能以假乱真

在二手鱼里泡久了，有时候真的会碰到一些让人走不动道的稀罕物。今天刷到个好玩意，就是京东方那款画屏E1S。有人挂280元，还带实木边框，说是在京东买的，成色不错，就有点轻微使用痕迹。说实话，这价格一出来，我是有点坐不住的，因为这玩意儿当年上市的时候，可是要两千多块啊。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelQPoYZrgXBEaMOdbVvg9hibD0hkd75UCrXkSBb5pP61MResicaSM7ibHyEB02BicibrwQHibVIgxVcY01gZK6fOSKmTQEtY0YZufVKA/640?wx_fmt=png&from=appmsg)


可能有朋友不太了解这画屏是个啥，乍一看以为就是个电子相框或者带框的显示器。其实这是京东方当年推出的类纸护眼屏，主打的就是给孩子上网课、看动画片用。它不像普通显示器那样刺眼，集合了低蓝光、无频闪、防眩光这几项技术，说白了，就是想让屏幕看起来更接近纸质书的感觉。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemYlrDCdTXh8v1KCfs7o229Ur9JiaibRsymqn7RQd88icicIq290C9QhbTE21U05bBxgcrOQKEkdmR0o4KMJqPibxWAfENEvtPGwNDA/640?wx_fmt=png&from=appmsg)


回到这台280元的E1S。21.5英寸的屏幕，分辨率是1920x1080，虽然不是啥高刷电竞屏，但看个网课、追个剧绝对是绰绰有余的。而且它有个隐藏属性，就是带实木边框，这设计放在家里当个电子相框，哪怕是不开机的时候，也比你桌上放个塑料壳的显示器有质感多了。卖家说支持手机平板投屏，操作也简单，这就解决了大部分人怕麻烦的问题。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCek7lldrtoStoEQnOtbOO6JZb64fDsO8nl8k1JywicVBbcsz7IicjSQiaOdFyokOjutaLpShKicjzrupNThdFLOuIYtLkMl7jD46ibyE/640?wx_fmt=png&from=appmsg)


当然，这E1S毕竟是老型号了，它的接口可能没有现在的显示器那么全，虽然有HDMI和USB接口，但刷新率只有60Hz。它最大的价值在于“护眼”和“外观”。而且你想想，现在去市场买个差不多的二手显示器也得两三百吧，而且屏幕没有护眼技术？边框也绝对不是木制的。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemm4pTuFSIsweOicAzK0eWI1N8lShrbGKId6jnaPWYCcVbneAsjYOGV44QWuIQFzc4t67cpPP9MQk7P9qYqwicB4mnzPkL2QiaJ0U/640?wx_fmt=png&from=appmsg)


另外这玩意的玩法还挺多，除了常规的投屏之外，还支持安装第三方APP，不过貌似得耍点手段，如果你是小白的话，我还刷到了一位大神，提供技术，但收费50，之后就可以自己上传照片，让它变成一副壁画，或者是贴在墙上的播放器。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekWzs9BgS4TWN9QzWwwxTJYs2zefk5byicvWAp3XcmywpIibp3KUqVnIoJLWyG8H422LMKq3VYAZMVLrmv40WWnRA7FdoZyeIF74/640?wx_fmt=png&from=appmsg)


对于想入手的兄弟，我有个建议，最好去问卖家要一下开机点亮后的照片，看看有没有坏点或者屏幕老化发黄的情况。毕竟这种类纸屏要是出问题了，咱们自己可修不了。如果你家正好有孩子需要上网课，或者你想找个性价比高的护眼显示器，这台280元的画屏E1S，我觉得完全可以冲一下。
