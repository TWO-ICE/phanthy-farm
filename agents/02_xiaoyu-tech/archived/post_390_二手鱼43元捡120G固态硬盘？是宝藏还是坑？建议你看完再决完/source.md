# 二手鱼43元捡120G固态硬盘？是宝藏还是坑？建议你看完再决定是否下单

虽然说在二手鱼上买硬盘

和内存有很大的风险，但这价格也太便宜了，而且卖家说没有确认收货前不满意包退，这还真让我有点动心，如果你也心动的话，建议你看完这篇再决定是否下单。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXF5m18uBujIY1WBy5fmooGf4Uok9iaLsQKFOIDfria6IVsxdoP0NbrvnkjdPCsNKJpDic7ploChJcCHA/640?wx_fmt=png)


卖家说有几百个拆机120G 128G固态硬盘，标价43到65元不等，还送SATA线、预装系统、一个月质保，连19年老店的招牌都挂出来了。成色看着还行，而且有19万的浏览量，2万人点了想要，这阵仗搞得我差点以为自己错过了什么隐藏福利。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXF5m18uBujIY1WBy5fmooGfZjxx0x62ibz0O2rcpTgx3ZPAWkD1nUxZ3WQlubJt7e57kCLjHg5ClSQ/640?wx_fmt=png)


先说说这玩意儿现在还能干啥。120G容量放今天确实不大，但拿来装个轻量系统、做个老旧笔记本的提速盘、或者当个专用下载盘完全够用。比如家里那台十年前的老电脑，机械硬盘咔咔响，换成这种小容量固态，开机速度立马起飞。要是你只是用来刷刷网页、看看视频、跑个办公软件，120G其实绰绰有余。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXF5m18uBujIY1WBy5fmooGfibSvia7oWIoIJL0TzUlDOEcqGficaXS0icTsrxWG7XjBrrZbyJU9PIQHuA/640?wx_fmt=png)


参数方面，这些盘基本都是SATA接口，走的是6.0Gb/s的传输协议，读写速度大概在500MB/s上下，跟现在主流NVMe固态没法比，但比机械硬盘快好几倍。而且卖家强调全盘进系统测试过，健康值正常，读写没问题。不过要注意，这些都是拆机盘，来源可能是淘汰的台式机或笔记本，寿命和剩余写入量没法精确掌握。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXF5m18uBujIY1WBy5fmooGfxVk9icFfAMic6wDdrOQXGxTeQUeJmctvL9c632OlX4GvSYNDzUkJh5nQ/640?wx_fmt=png)


另外，系统已经给你装好了，分C盘50G、D盘剩下的空间，4K对齐也做了，启动模式是UEFI加GUID分区。这点挺贴心，尤其对不太会装系统的用户来说，插上就能用。但有个大前提：首次开机不能断电，否则系统安装中断就废了。而且卖家明确说了，系统问题不退换，毕竟卖盘几乎没利润。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXF5m18uBujIY1WBy5fmooGfY5rBRscZgO5tjGEHxbGsmJmFYqC3Bxpia6wf6FO3fsgeh45TeibL3cvQ/640?wx_fmt=png)


说到品牌，全是随机发，三星、金士顿、闪迪、威刚都有可能，也可能是一些杂牌。好处是大厂拆机盘质量相对稳，坏处是你不知道下一块是不是翻新贴牌货。虽然卖家承诺人工测试、损坏率低，但二手存储产品天然带点赌成分，这点得认。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXF5m18uBujIY1WBy5fmooGfib6BDm7oT0VLUvoH2etrEVXQdKz8ia1sYu2dKktibA2DvTvqxM24eYpPg/640?wx_fmt=png)


可能有人会问，现在硬盘的价格疯涨，但是花43元买个寿命未知的二手固态硬盘是不是智商税呢？其实不算。考虑到它预装系统、送线、还有短期质保，价格确实压得很低。但你要清楚，这是清库存的拆机件，不是全新品，别拿它跟三年质保的新盘比稳定性。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXF5m18uBujIY1WBy5fmooGfOSuegQibM4fZKdaQbmPlnva8YnvxnfZScIL5OqpzKw6Tv4bMMHtaEVw/640?wx_fmt=png)


那么如果电脑比较老，只支持SATA接口，又不想花大钱升级，这盘值得冲吗？这个看你的需求。如果你图省事、预算紧、用途简单，它性价比不错。但要是你打算存重要资料、长期高强度使用，建议多花点钱买新盘更安心。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXF5m18uBujIY1WBy5fmooGfeNb1VZSpR6LemuXy0rutSFKZwqFo0sFClVzNeASBosAx9A9KqNmHSw/640?wx_fmt=png)


对此产品有兴趣的话，可以在二手鱼搜索“几百个拆机120G 128G固态硬盘”这个关键字就可以找到此产品，如果找不到可以通过图片进行搜索，都搜索不到的话，那可能是此产品已卖出或者是下架了。


 


以下是个人一些掺了水的建议：  

1. 老电脑提速可考虑入手  

2. 别拿来存毕业论文或全家福  

3. 首次通电务必耐心等系统装完  

4. 看完不买，立省43元
