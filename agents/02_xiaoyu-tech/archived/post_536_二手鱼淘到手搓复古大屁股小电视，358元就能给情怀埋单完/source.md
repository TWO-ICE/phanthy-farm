# 二手鱼淘到手搓复古大屁股小电视，358元就能给情怀埋单

今天在二手鱼刷到了一款“复古DIY网络小电视”，标价358元，点进去一看，好家伙，11万人围观，840人标记“想要”。这玩意儿长得跟上世纪90年代老电视一个模子刻出来的——大粗黑边框、后头鼓个包，活脱脱就是小时候奶奶家那台“雪花屏”电视机的迷你复刻版。但你别被它的复古外表骗了，内里可是塞了现代科技，而且确实可以看电视节目。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHN4RLgUG7ytvu5iakqAMZC3unyOqlBeNz5coMe7IMTh2coSe5Yiaic07ZlOkqjHLbGxnPJFCap0DwMg/640?wx_fmt=png)


 


先说说核心配置。这台小电视内置的是“方正乐家盒子主板”，熟悉电视盒子的老玩家应该秒懂——这不就是当年大家折腾刷机、装Kodi、跑直播源的主力板子嘛？虽然不是什么高端芯片，但应付在线视频、本地播放完全够用。而且它支持Wi-Fi连接，有无线网络就能直接看内容，省去了接网线的麻烦。对于想搞个桌面小屏放B站、看监控或者当电子相框的人来说，这套方案确实可接受。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHN4RLgUG7ytvu5iakqAMZC3wTjaJA9xibSSuLic4avKCxDBdeptHjP4ZJEEVtERUfKuI32ECcEKdOTg/640?wx_fmt=png)


再来看接口布局。所有接口都集中在机身底部靠后的位置：1个HDMI、1个RJ45网口、1个USB、1个3.5mm音频输出，再加上DC电源接口。麻雀虽小五脏俱全，基本能满足日常外接需求。比如你可以插U盘播本地视频，或者用HDMI连游戏机，甚至当个小显示器用。不过3.5寸屏幕确实太小了，坐远点字都看不清，建议放在书桌或床头近距离使用，眼神不好慎入。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHN4RLgUG7ytvu5iakqAMZC3VQRkcuHnzOZFJBa1fowEcbU6pZE58kjlP3CS87uZ0CWgoJicaGtAnIg/640?wx_fmt=png)


外壳是3D打印+手工组装的，这点卖家也坦白说了：“难免有不尽人意的瑕疵之处，追求完美者慎拍！”我翻了下实拍图，确实能看到层纹和接缝，塑料感明显，但反而有种手工DIY的粗粝美感。毕竟这不是工业量产货，而是个人爱好者一单一做出来的作品。比起那些冷冰冰的塑料壳智能音箱，这种带点“人味儿”的小物件，反而更让人愿意收藏把玩。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHN4RLgUG7ytvu5iakqAMZC3Jd1vSuHm4HwoPMaCsIRhiclCibyPKGDE2WEQ6oUVU7GX4ScXl04zANtw/640?wx_fmt=png)


配件方面，除了主机本体，还配了专用电源适配器和一个红外遥控器——对，就是那种老式电视用的长条遥控，按键手感清脆，还能换电池。这点很加分！很多DIY项目为了省成本会砍掉遥控，结果用户只能靠手机APP操作，体验大打折扣。而这位卖家显然考虑到了怀旧体验的完整性。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHN4RLgUG7ytvu5iakqAMZC3hvwHa4R7TrY5PUHLxibKBzas6EpialJftwNdEiaTmib5TYvTdFUgmAb0NQ/640?wx_fmt=png)


可能有人会问这主板能刷别的系统吗？方正乐家盒子主板基于ARM架构，社区里有不少刷机教程，可以刷CoreELEC、Armbian甚至轻量Linux，只要你敢折腾，玩法比原厂固件丰富得多。不过新手建议先用默认系统，稳定省心。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHN4RLgUG7ytvu5iakqAMZC31JSd0icSMkU3Etb4jzDBk5sgKX5spEICyl2LoLIZSoyd4iaI9Kmq9UBA/640?wx_fmt=png)


缺点也不是没有，就是3.5寸屏确实太小了，但定位本就不是主屏观影。它更适合当桌面摆件、信息展示屏、复古装饰品，或者接模拟器玩红白机。如果你指望它当副屏看剧，那建议至少5寸起步。

总结一下：

1. 想怀旧又爱折腾的玩家，闭眼入。

2. 追求完美做工或高清大屏的，绕道。

3. 预算300-400元想搞个有趣小设备，值。

4. 看完不买，立省358元。
