# 别扔，这种淘汰下来的小主机，可以打造成家庭NAS

最近在浏览二手交易平台时，一个不起眼的品类突然在推送流里多了起来，让我这种对“电子垃圾”有着天然嗅觉的人瞬间来了精神。这是一批批批流出的杰拓（Giada）OPS小主机，典型的工业范儿设计：通体全金属拉丝外壳，顶边还有一个方便提拉的把手，机身两侧预留了标准的机柜螺丝孔位。这造型不用多想，光看那磨损极轻的金属漆面，就知道它们刚从写字楼机房或教室黑板旁的机柜里被“优化”下来。

这批货的配置清单很有意思：属于那个年代“老当益壮”的Intel第四代平台，具体型号是i5-4570，搭配8GB双通道笔记本内存和120GB的固态硬盘。整机打包卖370块，如果是只要主机不含内存硬盘的“准系统”，报价甚至低到了230元人民币。

看到这里，估计有些朋友已经准备划走了，心想都2024年了，谁还玩这种十年前的古董？但这正是我想和大家探讨的误区。虽然从纸面参数看，这是十年的老平台，但我们要透过现象看本质。i5-4570这颗U，放在当年可是中端市场的“神U”代表，基于成熟的Haswell架构，四核四线程，基准主频就能跑到3.2GHz。在x86架构的世界里，这颗芯片的算力对于家庭场景下的绝大多数任务依然是过剩的。

你可以把它的应用场景想象得更具体一点：用它来跑Office全家桶做文档、接4K电视看高码率的蓝光原盘电影、开一两个轻量级的虚拟机跑Windows XP玩怀旧游戏，甚至是作为家庭网络的核心枢纽跑软路由、搭建HomeAssistant智能家居中枢，它都能提供丝般顺滑的体验。更别提这种 OPS 规格的设备，原本就是为大屏数字标牌设计的，讲究的是7x24小时不关机，其全金属机身本身就是一块巨大的散热鳍片，散热调教极其扎实，远比现在市面上那些为了省钱而采用塑料外壳、仅仅靠小风扇带热量的几百块杂牌迷你主机要耐操得多。

再来看看这个让人很难拒绝的价格逻辑。目前的DIY硬件市场正处于一种微妙的“通胀”状态：全新入门级的NUC或者迷你主机，价格动辄就要千元起步；DDR4内存条的价格从谷底爬升，SSD固态硬盘也因为原厂减产而悄悄涨价，就连二手的机械硬盘都开始有惜售的苗头。在这种大环境下，一台测试完好、通电即用、自带原装电源的准系统，只要230元，这基本上已经触碰到了电子废品回收的底线——或者说，这完全是在“开启甩货模式”。

卖家通常会特别标注是“某学校/公司机房新鲜拆机，共十几台，通电测试完再发货”。这句话里藏着两个关键信息：第一，这大概率不是那种从个人手里倒手的翻新烂货，没有私人的折腾史；第二，这是批量淘汰的资产，意味着成色统一，且大概率因为常年锁在机柜里吃灰，外观甚至比用过半年的个人笔记本还要新。

当然，我也必须把丑话说在前头，客观聊聊它的局限性。毕竟这是十年前的老平台，你不能用最新的眼光去审视它。它没有现在主流的M.2 NVMe固态硬盘接口，意味着你的硬盘读写速度上限被SATA III锁死；USB 3.0接口的数量可能非常有限，通常前面板有一个，后面板有两个，接多了U盘还得买个Hub；核显也就是那个年代的Intel HD Graphics 4600，如果你想用它来玩3A大作或者跑AI炼丹，那确实是在为难它。

但是，它的优势恰恰在于它的“老旧”所带来的稳定性。它的体积控制得非常克制，三围大概只有20×18×4.3cm，这个尺寸意味着你可以轻松把它塞进电视柜的缝隙里，挂在显示器背面当HTPC（家庭影院电脑），或者甚至直接用膨胀螺丝挂在墙上当个广告机播放菜谱。给爸妈当个只会开微信和浏览器的上网机，更是绰绰有余，完全不用担心他们会下错软件把系统搞崩，因为这配置就算中毒了也跑不起来。

更关键的一点，我想引入一个“残值逻辑”的概念。你花230元买来的，不是那种所谓的“未来科技”，也不是这就“战未来”的旗舰产品，而是一台“当下就能用的纯粹生产力工具”。我们可以算一笔账，就算你把它用坏了，或者半年后觉得玩腻了想升级，折旧后的损失可能也就相当于去海底捞吃顿普通火锅的钱。这个试错成本，在极客圈子里简直是可以忽略不计的。而如果你拿着同样的230元预算去二手市场淘笔记本，大概率只能买到2010年之前的商务本，屏幕泛黄、键盘打油、风扇嗡嗡响，体验完全是两个维度。

这也是我为什么觉得这台“小铁疙瘩”是搭建家庭文件服务器的绝佳选择的原因。如果你最近在研究NAS（网络附属存储），不管是群晖、TrueNAS还是国产新秀飞牛OS（FnOS），这种OPS主机都能完美适配。它原生支持x86架构，不像树莓派那样还得折腾ARM的兼容性问题；它有SATA接口可以接机械盘，也有USB口可以接移动硬盘做冷备份；它的功耗极低，挂在家里24小时开机，一个月电费可能也就几块钱。

所以，与其花大价钱去买那些所谓的“NAS专用”硬件，不如花230元捡个这种企业级淘汰下来的“垃圾”。它可能没有光鲜的外表，没有炫酷的RGB灯光，但它能帮你以最低的成本，搭建起一个属于自己的数字家庭堡垒。

你会怎么用它？是做成软路由拨号，还是做成电影服务器，或者是下载机？留言区聊聊你的脑洞！
