# i3配8G只要120块？捡漏这台宏碁迷你主机不亏吧？

今天刷到一台宏碁迷你主机，i3 2120处理器，8G DDR3内存，带原装电源，支持VGA和DVI。就这一堆东西，标价120元。虽说这套主机的配置不高，但120元的价格还真值得一看。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemWS1SEGDibmSrQeEE4gwPlibLibhOBUju1MvO4srTBboBgf1ibNPRdyiciapXrkScR45e94ajazuX2M58ibKrYnVKEWCPomPc2Sia3aUc/640?wx_fmt=png&from=appmsg)


看外形这台主机应该是宏碁的L480机型，处理器是i3 2120，双核四线程，主频3.3GHz。现在这颗U二手也就值个10块。但它带了8GB的DDR3内存，虽说是两条4G组合，但买这两个根，二手鱼上差不多60到70元。另外还给了一个原装电源，接口支持VGA和DVI。卖家说之前跑NAS用的，成色正常，功能都好。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCennicTNVIxXtvAlEqbYFXwwonwKptPKW8MKxe0ia6PkYwUVd3zwTytey69zKkMyar11TXOJUBicBa75zKqfV2EwfyFO95by4cpjXw/640?wx_fmt=png&from=appmsg)


重点来了，卖家没提硬盘。按这个120元的打包价分析，大概率不带硬盘。咱自己算笔账：i3 2120散片约10元，两条4G DDR3内存约70元，宏碁原装电源加迷你主板，最少也得50元，仅这些配件的价格就超过120了，如果单独去淘这些配件，运费都不止这个数。所以单纯从零件残值看，没踩坑，甚至有点小便宜。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCeklHbibdty5Nj29ScHiaGFhH45mCiaQiayIo9UG96MfsqSUwSjhGKPTVLCMicjA5jXy1sQjrT9V8xZfcyzEAkuBwWuGfp81TAqOSY0Y/640?wx_fmt=png&from=appmsg)


但得说真话。这台机器的短板非常明显。i3 2120的核显是HD Graphics 2000，解码能力放到现在基本等于残废。看B站1080P弹幕一多就掉帧，4K想都别想。接口只有VGA和DVI，接HDMI显示器得用转接头，而且最高输出分辨率也就1920x1200左右。另外它用的是DDR3内存，最大支持16G，现在DDR4都快淘汰了，DDR3更是老咕噜棒子级别。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenP89rIyu6jwpayW7aJFMnJ1yBnn00HGicAqvRGYQhU0CD1XAPp8Hth5ia5tNOLm0Xqpc0SULiaPe2UUjibUszssGxFtUlssfyDc9I/640?wx_fmt=png&from=appmsg)


这玩意最适合做飞牛圣体，飞牛对硬件要求极低，这颗i3 2120完全够跑轻量级NAS，装个OMV或者TrueNAS SCALE也勉强能转。但注意，你没硬盘。自己再花七八十块淘一块二手500G机械盘或者120G小固态，整机投入两百元出头。做文件共享、下载机、打印服务器，甚至跑个HomeAssistant智能家居网关，功耗也就二三十瓦，扔在弱电箱里不心疼。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenDmbZb4uFwbHZq04c9puPQVNpD11R5jwwyyxc3DHmt8wPvTXiag0gz9ibz627Ob4Gicw4agicQbNjzUprsGjxA4Bicaccf2MibxWXQo/640?wx_fmt=png&from=appmsg)


如果你想入手，我的建议有两条。第一，下单前一定问清楚卖家有没有硬盘架和SATA数据线。这种迷你主机的硬盘位通常只支持2.5寸盘，而且老机器线缆容易丢，自己配的话又得花几块钱还麻烦。第二，别指望它跑Windows 10或11，老老实实装个飞牛或者黑群晖，体验会好很多。如果你自己不会折腾系统，那这120元还是省下来买杯奶茶更实在。
