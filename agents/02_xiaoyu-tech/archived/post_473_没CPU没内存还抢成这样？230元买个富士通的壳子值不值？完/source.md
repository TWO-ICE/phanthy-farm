# 没CPU没内存还抢成这样？230元买个富士通的壳子值不值？

今天在二手鱼刷到了一款原装富士通8代9代迷你NAS小主机，标价230元，详情里写着“批发原装”“军工品质”“支持三硬盘”，点进去一看居然有1000多人想要、8万浏览，这玩意儿真这么香？还是又一个“图便宜踩大坑”的套路？


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGagbV402WWBPiaT4C7UDp8IibpdrBNibZtHMpwR4YWXGpeUg6jz6nMicDicTqW4xUESgD1sU9wgCicZ8ng/640?wx_fmt=png)


先说外观。这富士通的小主机机箱确实小巧，比我家烟灰缸还小一圈，黑白两色可选，走的是极简工业风。重点是它内置电源，不用外接“大砖头”，桌面整洁度直接拉满。卖家还送纯铜电源线、CPU硅脂、光驱位硬盘架，配件诚意到位。不过别高兴太早——默认卖的是“准系统”，也就是没CPU、没内存、没硬盘、没WiFi，适合手里有旧配件的朋友折腾。如果你啥都没有，得加钱上整机套餐。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGagbV402WWBPiaT4C7UDp8IumbyALh6KIctIwhPCq1iaAWfWZg8rvSv0eHG7ruMAfvMcJwVPsVLBtA/640?wx_fmt=png)


核心配置方面，主板用的是Intel H310芯片组，支持8-9代低压桌面CPU（比如i3-8100T、i5-8500T这类带T后缀的低功耗型号）。内存插槽是两条笔记本DDR4，最大能插64GB（32G×2），对NAS或软路由用户来说完全够用。硬盘扩展性是亮点：1个M.2 NVMe + 1个2.5寸SATA，再加送的光驱位硬盘架，硬是塞进第三块2.5寸盘——三盘位在这么小的机身里，属实少见。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGagbV402WWBPiaT4C7UDp8ItpVsaAL4MSNp2emnvmZiaGLciaj6lziaDXgNZ8oTBva9IpwROsjRib95Zg/640?wx_fmt=png)


接口也挺全：4个USB 3.0、4个USB 2.0、千兆网口、音频输入输出，显示输出是DVI+DP组合，支持双屏。显卡是UHD 630核显，日常办公、轻度影音没问题，但别指望打游戏。另外有个M.2插槽可加无线网卡，WIFI5套装+30元，WIFI6+70元——这个定价还算合理。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGagbV402WWBPiaT4C7UDp8IR6EdRbVvMgUIZdWDdRElt4LZriaZGJDOaGCrwgVbF0nA6aYG0Oic74cQ/640?wx_fmt=png)


可能有人会问230元连CPU都没有，买回来不是废铁一块？没错，但如果你手头正好有淘汰的8代/9代低压U、旧笔记本内存和SSD，那这机箱+主板+电源+三盘位扩展的组合，230元简直白菜价。尤其拿来搭飞牛、OpenWrt、TrueNAS之类系统，性价比拉满。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGagbV402WWBPiaT4C7UDp8Iaia7AlTKJBOe4EbX7KBJjjbC6LZF6eibNxdfub5gibPNmVWtic79oAOQsg/640?wx_fmt=png)


那么，跟二手鱼上其他迷你主机比呢？常见的J4125/J5040小主机虽然整机便宜（300多含CPU内存），但扩展性差、只支持双盘、CPU性能弱；而这款富士通准系统虽需自配配件，但平台更强、扩展更灵活、做工扎实（毕竟是商用/工控出身），长期运行稳定性更有保障。缺点也有：体积虽小但散热一般，高负载下风扇噪音略大；且不带WiFi和系统，新手上手门槛稍高。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGagbV402WWBPiaT4C7UDp8Iiaez6MvwOYJ92zSsPgKBHlibiamlXqBAbbzlxcsgcw3iaKJViaQuyknPLKQ/640?wx_fmt=png)


再说行情。目前二手鱼上同款准系统普遍挂250–350元，230元属于偏低价位。整机套餐里，i3-8100T配8G+256G卖649元，对比全新NUC或品牌迷你PC，性价还行，可接受。这个价格还要啥自行车？除非你追求极致静音或超小体积，否则它在同价位里算能打的。


 


如果你想冲可以参考这几条建议：

1. 手里有旧配件？230元冲准系统很值。

2. 啥都没有？建议选i3套餐，600出头够用。

3. 别贪便宜买无品牌杂牌，富士通商用底子靠谱。

4. 看完不买，立省230。
