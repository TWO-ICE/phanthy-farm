# 389元在二手鱼买小米保险柜，C级锁芯加指纹开锁，实用党冲不冲？

今天在二手鱼里发现一个重磅产品，有多重呢？大约30斤左右，这货就是小米米家智能保险柜，卖家标价389元，但这只是引流的价格，实际根据成色不同，共有389到549四个档位，如果你也对这东西感兴趣，可以一起来了解一下。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenILvqukcpdOCe2epp1hl0RFmX8EiaKyl7RGJPFeq0MR3uFGoibWrvSZRmOrf2pWYryqxHrz0xXFQBMgbiawdzEOaDH6OynxH4icr0/640?wx_fmt=png)


这批小米米家智能保管箱是30CM版的，尺寸30×40×30厘米，放床头柜旁边或者塞进衣柜角落都挺合适。内置C级防盗锁芯，门板采用Q235实心钢板，箱门做三重钢板结构，还配了一根19mm粗的实心锁闩。传统那种几百块的便宜保险柜，锁芯大多还在A级B级晃悠，这款一上来就直接拉满了，官方标的重量大概14公斤，不过不用担心邮费，卖家包邮。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekrOR9jLAVicXC5L1TInttds4QiauyTPCa4VTpZ9jv8z2Jnh4rBUfEyP2p9NAr4TcsFfViavdGz66soNx7j3aZVJ9ouj5ypuO1urA/640?wx_fmt=png)


查了一下官方数据，它一共支持六种解锁方式：指纹、密码、一次性临时密码、蓝牙、物理钥匙，还有双重验证。指纹用的是瑞典算法，官方数据识别率接近99.2%，速度不到0.5秒。我见过很多同价位的二手保险柜，指纹识别慢得让人着急，手上稍微有点汗就拒之门外。这款的配置在这个价位段确实有点降维打击的意思。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelHPOxP2QCKEMxxvGMPOTFCkcLmF77SSM6Nq03OicicblZUVDnfO8uTElUuoF6ibYhwdvSicFGfaNlRicnjKN7aJ4oAibMM1b67VJFHg/640?wx_fmt=png)


最让人心动的是它支持米家生态。这货不是传统保险柜的傻大黑粗，它支持Wi-Fi和蓝牙双连接。装上米家APP后，谁什么时候开过箱子、有没有异常震动、门有没有关好、低电量提醒，通通都能推送到你手机上。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCel81Ant03393iahVo1fJgp5kj4slVRvkFoYXJeL8sqaU1YohZykVUEJFeD1TtBznTOcfVfSVLPs2Q3YFw3FfbuASCHDLc2awVdg/640?wx_fmt=png)


还有一个胁迫指纹功能，万一遇到紧急情况，用特定手指开锁，它会悄悄报警，这个设计挺走心。另外，它用了低功耗通讯技术，据说续航可以撑一年左右，还有一个USB-C应急供电口，万一真没电了，拿个充电宝也能救急。关门也很省事，轻推到闭合状态保持一秒，听到提示音就自动锁上。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemQAqTP9aYn5dsLBicjibic52skdKRk9LqA3OicHnMbfEkjfjnDxhXQXs6ADtUP1f4UFnoz7WdeThjgZNtg8drbHmDEz29wD85emc8/640?wx_fmt=png)


卖家给了四个成色档位。389元这档是9成新，功能全好但外观有明显磕碰。如果你是对外观不那么讲究的实用党，或者买来直接塞进柜子里眼不见为净，这个最划算。不到400块钱，C级锁芯和智能功能一样不少，性价比确实炸裂。当然，价位越高自然是成色越好，如果对外观有要求的可以加钱。但说实话，保险柜不是用来把玩的手办，核心价值在于安全防护，除非你是强迫症或者买来送礼，否则没必要追求外观。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCen3lbIF3XMGkR8kSzuQiapPBaE2dub1DiawicfmFu4BaSq0n2QtI4oGxICasuEI0WibtT01Xu0ibFQoH24yhcMEx0qD77fugdibpCczs/640?wx_fmt=png)


这玩意儿有几个地方得提前说清楚。首先，重量将近30斤，卖家明确写了偏远地区不包邮，所以你家要是不在包邮的范围内，下单前最好先问问邮费。其次，到货后第一时间检查功能是否正常，指纹识别、密码输入、蓝牙连接这些都得试一遍，建议开箱过程全程录像，万一有问题也好说话。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCeneaBiaCF8oc8yczdPenLePxbZicR1ly2JWicNibpQ9M3qMp2nVlr5yGrq1CN0YzuF6R0giaal1L6tHsL5ysCB5CMvgPGgt0csDZw4U/640?wx_fmt=png)


另外我在给你两条实在建议。第一，别被“指纹密码电子锁C级”这个描述冲昏头，C级指的是锁芯等级，不是整个保险柜的防撬等级，这俩概念要分清。第二，如果你只是用来放房产证、户口本、备用金这类非应急物品，389元的磕碰版完全够用，多花的钱买的是外观，不是安全性。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemZKp0d8DJ9d5WJrEqEfLTqVwL9dyE93iaKx9oZlMTslB4vfvdEl8OhiaQIq3epLrT1B0TQ7H238Cibtl7RIz6Uw2ib4O1TehoANAw/640?wx_fmt=png)


如果你家里确实需要一个小型保险柜来存放贵重证件或备用金，389元这一档我觉得可以上车。在这个价位，想找到同级别配置的对手基本没有。当然，如果你指望它能防专业小偷，那可能需要重新评估。保险柜说到底只是个延迟工具，真正遇到专业盗窃也只能争取点时间。但对绝大多数家庭来说，防君子不防小人，足够用了。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCek2ibloQGsmkib9JqvqCW18NpbYibMIPB3icYA1EGQuwl7ZiarKhYnjFwmPwFP7f3xtgOH6Z7mlUTSeSziczxdiaVMaEMaK3Zdb4p5eQo/640?wx_fmt=png)


说实话这款米家保险柜在二手鱼里的标价并不是最便宜的，但是那些低价位的全部都是要求自提或运费自理。这款虽然贵一些，但可以包邮，其实也这也是羊毛出在羊身上，如果你愿意自己出邮费，完全也可以去看看那些价格稍低的。
