# 外星人不坑穷人，800元的4代i7+16G内存+980显卡，可以捡漏吗？

![封面图](https://mmbiz.qpic.cn/sz_mmbiz_jpg/E9h3abOJCeltw5ibPbj8aickZeT8Go21lr408m5csQsexB6bHgcrpagVPCKbh3vmTKl9V2ZErHhMDnFrla9a1kub9ZzWzL9Bibt2W3px6pZicKE/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/TSi9abSPZM7XJBuHi5Vi8g

一台17寸外星人游戏本，卖家自己贴了绿膜，i7处理器，GTX980M独显，只要800块。看到这个价格的时候我愣了一下，不是因为它太便宜，而是突然意识到，现在的电子产品，原来已经贬值到这个地步了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemuLWr0PWZibS5LoCicUFcgIfrNdia0Kicm8UlafedKGcibS32icjr2ejQ1GzH5ialtcIticibFqsm2kFrNOPm28jnadH58YtNG7DDOIvZs/640?wx_fmt=png)


先看配置，i7 4710HQ处理器，16G内存，500G固态，GTX980 4G独显，17.3寸1080P屏。这套组合放当年绝对是天花板级的配置了，但放在今天，它确实有点跟不上时代了。不过你得想明白一件事，他的价格只有800块。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekKzaUfcC2AGiaqc3qCauHQUibfL2CEa5N0LBZUmplAjrjTQky0rqAd1Ntl3ULY3oJzmYCAktBYVz78bV4HeWI47RaNiay6GrrTzM/640?wx_fmt=png)


和同价位的其他笔记本比，800块在二手鱼里能买到的基本都是以前的办公本，i5处理器集成显卡那种，玩个LOL都费劲。这台外星人好歹是当年旗舰，GTX980的性能放在今天玩个CF、DNF、中低画质吃鸡还是能打的。如果你预算抠搜又想体验一把游戏本的快乐，这玩意儿确实是个选择。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemZpExq9R0nhuz2cC4ibslgJN8ZwibdYnjgaAJbichaCvrhZC5ibepSvd6HoL7JUWKOiaa9qrBjKg3yrK0gqdbibu49qyzIZCtM4pgicA/640?wx_fmt=png)


但问题也来了，第一，这货太重了。17寸的机身加上电源适配器，背着它出门基本等于负重训练，适合当台式机用，不适合移动办公。第二，功耗高发热大，玩游戏风扇起飞是常态，续航就别指望了，插电是它的宿命。第三，卖家只支持自提，这其实是个双刃剑，好处是你能当面验机避免翻车，坏处是外地买家只能干瞪眼或者只能加钱让卖家发货。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelEtwPf0Zc5w7d3PaA1fOvLUAXR9icp3lQsUiafBzQkNYd7RP7Js7mu1gHHF4gciboTMIIblNkgqAewLaOhjibiaIDrTf1NOJ32cGVI/640?wx_fmt=png)


如果你是那种手里预算抠搜的学生党，宿舍里缺个能打游戏的家伙什，这台机器还真能考虑。800块买个17寸大屏，晚上熄灯了躺在床上看电影，那沉浸感比你们那些13寸的小本子强太多了。周末室友开黑打LOL，你掏出这台大外星人，键盘灯一亮，气场直接拉满。虽然帧数比不上现在那些动辄上万的新款，但流畅运行绝对没问题。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemtRA5LgC1Z4rSibgPu9QjiaB9cDWYPzbKGcBbibmvpRbTtxkibTibRD3WbgfQO2Pic6BbficZVuPLRiaN3EPxqkCId0ce83S494B4p5MU/640?wx_fmt=png)


最后说句掏心窝子的话，这种老机器买回来，心态得放平。别指望它能战未来五年，就当花800块买个玩具，体验一下当年买不起的信仰。玩腻了再挂出去，说不定还能原价出掉，亏不了多少。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemDqkMXfOhKzFZ5pceH9zZUAP8ibyELSrjeFLMVQfQmscEIeDOyv6oicXu4LUmFkiasnrRVjgt1B97Ic92UW11ty3eq9tDH5oSyHU/640?wx_fmt=png)


你们觉得800块的17寸大外星人，到底是真香还是真坑？如果是你，会为了这个大屏和信仰冲一把吗？评论区见！
