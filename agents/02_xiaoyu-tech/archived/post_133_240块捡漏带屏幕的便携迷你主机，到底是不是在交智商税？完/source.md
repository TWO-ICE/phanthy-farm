# 240块捡漏带屏幕的便携迷你主机，到底是不是在交智商税？

今天刷到了一台缝合怪很有意思，是一台集成了微型迷你电脑主机、一体机、平板电脑属性于一身的“三不像”小玩意儿，牌子是“HQisQnse”，反正我是没听说过。卖家直接打出了240元的价格。看配置的话根本不值这个价，但好处是带屏幕、支持触控、小巧便携。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekicwc248buzLibldweE53bTgUiaaXKYia6HB0sFHZzjQe155lQWiaD3Vorvkq8YqemmmLS8Z6NkGSQZhYIPo19953vEjyibChOvQ3JU/640?wx_fmt=png&from=appmsg)


这玩意其实就是淘汰下来的那种工业级一体机，长得像个厚实的小显示器，里面其实是个迷你机箱。核心配置是英特尔i3三代处理器，搭配4G内存和32G固态，或者加50块能上120G固态。屏幕分辨率只有800*600，也就是大家常说的4比3方屏，放在现在的桌面上，满满都是复古感。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCendzc5pFticgiaCka7vU9ZmIQJLowPNUhQpmiak5A8pib4f6wjEM5FIAibUibNK32xvSAz2jlBa4q6HCTOicAFeEp5U5BYIGS4ickgRwJk/640?wx_fmt=png&from=appmsg)


首先i3三代这颗U就是入门级的，如果跑Win10系统，处理一下文档，它还是能勉强胜任的。4G内存真的有点捉襟见肘，如果拿它当个简单的下载机，倒是刚刚好。卖家说了内存最大支持8G，固态也能换大点的，算是留了点升级的后路。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelicCEpeCGNH4rRzrZcdGd4yBxiaSChwjbicu67b755d1Es6fDm01q5S4ex132mGia1PGXiaaKZ6olKNicPVACZNDyDhy0SLatKzI9V0/640?wx_fmt=png&from=appmsg)


不过要说它最让人纠结的地方，绝对是这块屏幕。800*600的分辨率，看宽屏电影上下会有大黑边，画面精细度也完全没法跟现在的手机比。但如果你的需求只是监控显示器，或者拿来做软路由的命令行界面，甚至是想搞个复古游戏机玩模拟器，这种方屏反而有种别样的味道。卖家也提供了加50块升级触摸功能的选项，如果拿来当控制面板用，交互体验会直接上了一个台阶。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelIVNQUXZAWHXYo691wIvich1QuBO6pK1ZxSrCGmwEdqRyic8XT3boNFr1kRtyuRSuJm7oJ8SrHEgIW5WiccxjTq8eTvrJnTvbAj8/640?wx_fmt=png&from=appmsg)


说实话，如果把预算拉到300多块，在二手鱼里其实也能淘到一些6代甚至7代的酷睿小主机，虽然不带屏幕，但性能比这个i3三代强了好几个档次。所以这台240块的机器，优势不在于性能，而在于它“拎包入住”的便利性。买回去接上电源线就能用，不用再单独配显示器，特别省桌面空间。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenEY2Wlic35CONXPuOvTALW7BjOKdgbtNtibmmeLqoxP55K7pmasJTOP7iaumc2pq1Gkr6oCdxuVwulu7AypzdGH3gcuTBgibtNQYE/640?wx_fmt=png&from=appmsg)


如果你是资深垃圾佬，手里正好缺个折腾软路由或NAS的显示终端，那这东西还是有一定的可玩性，240块钱买个带屏的机箱，怎么算都不亏。但如果你是奔着当主力电脑，或者想体验流畅的Windows操作，那我劝你千万别碰，这种老平台加上低速固态，开机速度和使用流畅度会让你瞬间回到十年前，那种卡顿感可能会让你直接想把它扔沟里。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCel3f1gHV9eZPtvRjWryibMibPMrWfKuvrgmVxibyOumx0pHMLCliaIoVdYmxj95tXsfa0PTYOx4gOnzMe1ib2UWldpFlVqzYQrmpuWI/640?wx_fmt=png&from=appmsg)


最后给想下手的兄弟们几条实在的建议。千万别选32G固态的版本，系统装完就没空间了，加那50块上120G绝对是最值的投资。那个加20的无线网卡，如果机器放的位置不方便拉网线，还是加上吧，省得以后还要挂个USB网卡。至于加50块升级触摸，就看你的具体场景了，如果只是摆在那当个固定显示，其实用处不大。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemvpBg0f1ARrQKZlhqvkaXDh5EsU2lzYMTOgvcqRhDiasvq6Y8JZKUSfFcVSL3VVr22sGYRyGtibFeiaRWU9lbWSrnd0d4GiczFsTo/640?wx_fmt=png&from=appmsg)


这种机器的定位其实很清晰，就是给那些预算极其紧张，或者有特定折腾需求的玩家准备的。它没有现在那些千元小主机的光鲜，但在200多块这个价位，能给你一台完整的带屏电脑，也算是在如今这个魔幻的二手市场里，给垃圾佬们留了一口饭吃。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCeleUxnawQ5VickHwhRx84nmzanz8FiaU1uiaic3HOpHiaiaIYAmVrCvzsVWXmVqV9S1v5xfzk12Xw6gPOkEgmglmFkQLXQfK0JpiaFAibc/640?wx_fmt=png&from=appmsg)


你觉得这240块的电子古董是宝藏还是智商税？如果是你，会选带触摸的版本还是省下那50块？欢迎在评论区聊聊你的看法。
