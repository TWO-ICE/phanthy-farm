# 倒车影像屏能刷成安卓平板？海康的屏幕还有这样的操作？

![封面图](https://mmbiz.qpic.cn/mmbiz_jpg/E9h3abOJCelMibGicZIDFpXibNLPzSHbda81Tr7YgWQRGElhibyHqqiaPM7pwibsZ8MU3uUQJRFs8tj6lAiaicrfoEak3MQCYPBwjFLVEId59K2SMdQ/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/_wyYvc2yqSEfEFZxZ8eyDw

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelzz2u2RicUXYGYGpbicA5XZNv75tWNs9HnveiaQhfUPoISRGpeCfX80ibvztMoyZjz7eoIh3libRp8ygCgstgAsvriaiaOQjDIj48xxc/640?wx_fmt=png&from=appmsg)


二手鱼里刷到个稀罕物，海康威视的安卓智能屏，卖家标价59.9元起。你没看错，一包烟钱就能搞到一块海康的7寸高清触摸屏，而且它还能刷机，刷机后变成安卓系统，还能插U盘。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenicb7icd7kGYaX04nneEnxYqoeJ55KHp9IaJfXkGu6iaM6Gia3AyyRpwPlx6ib6rxXODH7FuoSw5dINr5YWLwG3pH9lS2Wr4GkLSyk/640?wx_fmt=png&from=appmsg)


屏幕的型号AE-AFE90，1024*600的分辨率，7寸IPS素质，金属外壳，分量压手，做工扎实。海康出品，懂的都懂，工业级用料，而且是全新未拆封，配件齐全，连原装支架和线材都有。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekMmr3RlPic2l9klicR8SxwpSlzqsEicCA5DcK9noGJsADsjaoibK5opQejfKdVxxgzVwdqLXZPCb3ZKnIfnicyskFkKDRRYow4qRLE/640?wx_fmt=png&from=appmsg)


默认59.9元是原厂系统，支持模拟信号输入。你可以直接把它当倒车影像显示屏，接个CCD摄像头，12V或24V的车都能用。卡车、房车、老款轿车，随便装。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekcClpSKZeibXzrkkY9kNiaklOXxiaVNy14ga1oD86Sjib3nTBSMFic7Tv1IJIiaXXiaWOYzDlq7yC7zw3skFDfCpn9UYp0LYfP46fFpw/640?wx_fmt=png&from=appmsg)


如果愿意加20块，也就是79.9元，卖家帮你刷好安卓系统。刷完之后就厉害了，能装APP，能插U盘，接上有线网还能上网。有买家已经提供了教程，接个micro转USB的转接线，扩展性一下子就打开了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelsoOUTBnRduG3KTquek3MC2Cib1OesbttNGo7jOI1HopGNNYL0nbK3wRyWrn8iceQ8jqGfTlh3XBB0WFQgY0GE0UmaD6xDenNg8/640?wx_fmt=png&from=appmsg)


但别急着下单，这玩意儿不是到手就能爽用的。首先，原厂系统功能很单一，就是个显示器和信号接收器。你想把它当智能平板玩，必须刷机。卖家提供两种选择：自己刷，他免费给方法；或者加20代刷。建议直接加钱刷好，省得折腾。自己刷需要数据线和一点技术基础，不是小白能轻松搞定的。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekFuFt6L6lrCpKy65YJQ2wT5ic1vv9NF1sKpmYicQ2NZPI4nt9rZGkE6J2LKmKaibDkxM6QDx7U5yvD6uaHpuT6nDrLDlcAoFF5rM/640?wx_fmt=png&from=appmsg)


其次，分辨率1024*600，放在如今确实有点不够看了。看个导航、倒车影像完全够用，但你想拿它刷抖音看视频，颗粒感会比较明显。另外，它没有电池，需要外接12V电源。车上用没问题，拿回家玩得自己配个电源适配器。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekzoPSlFsU5LIkyEVAhnMicjt1wO33tvaIn93anRzLeaU9Q2wzIUQh3BqPt2rHMricf2VrTK9iclekIec7CYWlFjLuGNFNxpQ2IP8/640?wx_fmt=png&from=appmsg)


59.9的价格其实还真不算高，就算你玩不转，扔了也不心疼。但如果能用起来，那性价比就炸裂了。比如你有个老车，没有倒车影像，花几十块搞定，比去汽配城省好几百。或者你是个垃圾佬，就爱折腾这类洋垃圾、工厂淘汰货，这绝对是个稀罕玩具。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemlSk5kDHicORepoaHuCrEtnKf0zwE5MEGg7aNT3GJWxYaArlEt1EzcmJIicew4jiblhatrQkqffFdesJicKyC0INBq5B3RopVhZto/640?wx_fmt=png&from=appmsg)


我的建议是，如果你是动手能力强的人，或者身边有个懂安卓刷机的朋友，闭眼入刷好系统的版本，79.9元买不了吃亏。如果你就是个纯小白，连U盘装软件都费劲，那还是别碰了。另外，买之前想清楚用途。当车载辅助屏，完美。当主力平板，别做梦了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenvlXLHoMscIw8B2OnehecWJW49CXnc7pMtfy8bujQH6a0POV1Tr4ujYYibU3NibAQnu81shxG8QArVDt2j6KKdEvOQZLo8pNygM/640?wx_fmt=png&from=appmsg)
