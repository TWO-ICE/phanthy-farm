# 二手鱼i3-7100跌到19.9？350左右就能装出一套能用的主机

就在今天，我在二手鱼闲逛的时候，被一个价格标签彻底给震惊到了——一颗 i3-7100 的处理器，卖家居然挂出了 19.9 元的“白菜价”。

要知道，这可不是那种来路不明、可能是从电子垃圾堆里刨出来的“工程样品”或者打磨芯片。卖家在详情页里写得清清楚楚：这是正儿八经的拆机件，也就是从品牌机或者升级淘汰下来的原版 CPU。主频稳稳地跑在 3.9GHz，自带英特尔经典的 HD 630 核显。更重要的是，卖家信誓旦旦地承诺“无维修、功能正常”，插上就能点亮，专门用来办公、打字、看视频，或者给家里的老机器升级。卖家甚至还贴出了跑分数据：更新完驱动后，核显跑分能有 6 万左右，CPU 跑分在 20 万上下。

说实话，如果这颗处理器卖 50 块钱，我可能只会划过去看都不看一眼，毕竟现在的 CPU 市场卷得厉害。但定价若是 19.9 元，性质就完全变了。这是一颗英特尔 i3 系列的处理器，还是 Kaby Lake 架构的 7 代产品，比那些被炒上天的老旧赛扬、奔腾，或者甚至比某些不仅贵而且翻车率极高的“洋垃圾” CPU 要靠谱得多。

想当年，i3-7100 也是很多入门级组装机和网吧机型的首选。那时候单颗处理器的价格也要好几百，主打的就是一个“稳定耐用，用个五年七年不坏”。不像现在某些流通的所谓“服务器洋垃圾”，不仅针脚容易被磨损，而且体质参差不齐，动不动就黑屏重启。

我们来盘一盘这个老家伙的核心参数。3.9GHz 的主频，虽然不支持睿频加速，但在日常高频响应下反而显得更稳定。双核心四线程的设计，放在今天确实有点寒酸，但搭配那个年代经典的 HD 630 核显，应付基础任务还是有一套的。卖家提到的那个跑分，我特意去查了一下实测数据，基本属实。鲁大师 CPU 跑分 20 万左右，这个成绩确实吊打同价位的古董级赛扬和奔腾。至于核显 6 万跑分，听起来不多，但实际上意味着它能够流畅解码 1080P 甚至部分 4K 视频，应付 Word、Excel 等办公软件毫无压力，甚至如果你不追求画质，玩玩《英雄联盟》这种轻度网游也不是不可以。

当然了，作为一款发布多年、早就进入生命末期的产品，它的缺点是非常明显的，我们必须得清醒地认识到。

首先，性能确实是跟不上主流了。现在的软件体积越来越大，浏览器动辄占用几个 G 内存，双核四线程在多开任务时会显得捉襟见肘。如果你指望它能流畅运行《赛博朋克 2077》或者《黑神话：悟空》这种 3A 大作，那大概率是会让你失望的，哪怕你给它插上一张 RTX 4090，这颗双核 CPU 也会成为巨大的瓶颈，直接把显卡性能拖到泥土里。它只能勉强应付一些老游戏或者对配置要求极低的独立游戏。

其次，平台太老了。这玩意儿只支持 DDR4 内存（而且频率支持有限），并且只能搭配 H110、B150 这种几百年前的老主板。这些主板大多是二手甚至三手的，供电模块老化也是个隐患，而且没有什么升级空间。你买了它，基本就是这就定格了，想换高性能 CPU？那连主板都得一起换。

但话说回来，它的优点太突出了——极致的便宜。对于仅仅需要一台“能亮机、能上网、能打文档”的电脑的用户来说，这就是神一般的存在。

如果你刚好手头预算极度紧张，或者是刚上大学的学生党、给家里老人只看新闻视频的朋友装机，这套方案可以说是目前市面上性价比的天花板。我可以给大家仔细算一笔账，看看这 350 块钱到底能凑出一台什么样的主机。

我们的核心就是这颗 **i3-7100，预算控制在 20 元**。这颗 CPU 的发热量很低，对散热器要求也不高。

接下来是 **主板**。我们肯定不能去买新的，要去淘一块二手的 H110 主板。这种板子在二手市场上多如牛毛，成色好坏不一，大概价格在 **100 元** 左右就能拿下来。购买时最好找那种包 SES 后的商家，省去自己刷 BIOS 的麻烦。

内存方面，选一根 **DDR4 8G 内存**。现在二手 DDR4 内存的价格已经崩盘了，一根普通的 8G 内存条，也就 **150 元** 左右。8G 内存对于 Windows 10 或 Windows 11 的日常运行是底线，虽然不能让你多开几十个网页，但保证系统不卡顿是足够的。

硬盘是决定老电脑体验的关键。千万别用机械硬盘做系统盘，一定要来个 **120G 的 SATA 固态硬盘**。这种小容量固态现在也是白菜价，**50 元** 就能买到一个杂牌或者二线品牌的全新盘。虽然容量小，但装个系统加几个常用软件绰绰有余，开机速度能提升到十几秒。

最后是电源和机箱。电源别贪便宜买炸弹，买个二三线品牌的 **300W 额定电源**，**30 元** 应该能搞定。机箱就更随意了，甚至几十块的鞋盒子也能用，这里我们算它 **50 元** 吧（含机箱风扇）。

把所有这些加起来：20（CPU） + 100（主板） + 150（内存） + 50（硬盘） + 80（电源机箱）= **400 元左右**。如果你手里有旧机箱电源，或者能蹲到更便宜的散件，把成本压缩到 **350 元** 甚至更低是完全可行的。

这一套配置用来办公、看视频、刷刷淘宝、看抖音网页版，那是完全够用的。对比现在市面上动辄两三千的新品牌入门主机，这价格直接省了一半都不止。

不过，这里有个极其重要的细节需要提醒大家，这也是二手交易的坑所在——**运费**。

卖家挂 19.9 元，往往是不包邮的。现在的快递费，发快递最便宜也要个几块钱，有的偏远地区甚至更贵。如果这颗 CPU 加上运费要超过 25 元，那我建议你直接划走，别犹豫。因为我刚才看了一下，其他同款的 i3-7100，有不少卖家标价 25 元直接包邮的。算下来，25 元包邮显然比 19.9 元加 6 元运费要划算得多。我们在捡垃圾的时候，主打的就是“精打细算”，一分冤枉钱都不要多花。与其为了那几块钱的差价去跟卖家扯皮，不如直接买个省心的。

另外，入手二手处理器有几条“保命法则”一定要记住。

第一，看图要仔细。千万别只看封面图就下单。一定要在私聊里让卖家发 **CPU 针脚的特写**。这玩意儿最怕针脚弯曲或者氧化。如果针脚歪了一根，你回去插不进主板，到时候卖家说是你弄坏的，那就是哑巴吃黄连。到手后如果不亮，先排查主板和电源，别第一时间就把 CPU 标记坏了。

第二，心态要放平。HD 630 核显再强，它也只是个亮机卡。别指望它能跑大型游戏，甚至别指望它能流畅剪辑 4K 视频。如果你真的有游戏需求，与其给这颗双核 CPU 配一张几百块的独立显卡（比如 GTX 960 之类的），造成“小马拉大车”的性能浪费，真的不如咬咬牙加点钱，换个 i5-7500 或者 i5-8400 这种四核处理器，体验会有质的飞跃。

毕竟，CPU 是电脑的大脑，大脑转不动，四肢（显卡）再发达也没用。

这颗 19.9 元的 i3-7100，就像是一碗路边的猪脚饭，虽然没有米其林牛排那么精致，但在你饿肚子的时候，它绝对能让你吃饱，甚至觉得味道还不错。对于预算只有几百块钱，又急需一台电脑的人来说，这绝对是当下最值得考虑的捡漏方案之一。

至于值不值得入手？如果你有折腾的乐趣，或者正好缺个备用机，闭眼冲没问题；但如果你是电脑小白，连插针脚都要找人帮忙，那还是多花点钱买个整机吧，毕竟时间成本也是成本。
