# 三代i5飞牛圣体小主机只卖248元，带两个SATA口够不够回本？

在如今这个数码硬件通胀严重的时代，248元能干点什么？在二手鱼（闲鱼）的茫茫大海里，这个价格可能只能买到一张不定好坏的显卡，或者半条有些年头的DDR4内存条。但现在的市场就是这么魔幻，你真的可以花不到250块钱，抱回家一台不仅能点亮屏幕，而且五脏俱全的迷你电脑。这里头的主角是一颗经典的第三代酷睿i5处理器——i5-3320M，搭配4G内存、120G固态硬盘，甚至连无线网卡和蓝牙都给你配齐了，电源适配器也都在箱子里，到手就是一台即插即用的完整主机。要知道现在内存涨得有多离谱，随便一条像样的8G DDR4内存条都要卖到两百多大洋，相比之下，这台老当益壮的小主机，反倒成了某种意义上的“性价比屠夫”，给预算有限的玩家提供了一个低成本折腾硬件的入场券。

咱们得先聊聊这颗心脏。这颗i5-3320M虽然现在是“古董”级别的存在，但当年也是移动端的明星产品。它采用双核四线程设计，基础主频2.6GHz，睿频加速最高能摸到3.3GHz。这个参数放在2024年跑Windows 10或者Windows 11，虽然不能说是丝般顺滑，但也绝对算不上电子垃圾，日常的轻办公、看网页、甚至简单的视频剪辑都能勉强应付。但是，这台机器的正确打开方式绝不是为了跑Windows系统。它的真正圣体在于作为一台服务器：跑飞牛（FNOS）系统、做个7x24小时挂机的下载机、或者搭建一个小型的家庭媒体中心，这对它来说完全是小菜一碟。更绝的是它的功耗控制，作为一颗移动端改良的U，其TDP（热设计功耗）仅为35W。这意味着即便你把它挂在路由器旁边一个月不关机，它吃掉的电费可能还不如你开一次空调多，这种“细水长流”的特性正是作为家用服务器最核心的素质。

很多玩过迷你主机（比如瘦客户机）的朋友可能都有个痛点：很多廉价二手小主机为了节省成本，默认都只给你留了RJ45有线网口。如果你家路由器在客厅，想把机器放卧室当NAS用，还得自己再去买个USB无线网卡，不仅占了一个宝贵的USB口，而且那种杂牌USB网卡经常出现发热掉线、速度瓶颈的问题。而这台机器的模具虽然老，却良心地内置了无线网卡模块，甚至还附带了蓝牙功能。这个看似不起眼的配置，直接把它的摆位自由度拉满了。你不需要非得把它塞在路由器旁边的弱电箱里，也不用在桌子底下拖长长的网线，只要是个有WiFi覆盖的角落，比如书架顶层、电视柜背面，它都能安安静静地工作。

对于想折腾NAS（网络附属存储）的玩家来说，这台机器最大的杀手锏其实藏在机身内部——它居然提供了两个SATA接口。千万别小看这两个接口，在很多同价位的竞品（比如某些只有单SATA或者只能用USB转接的板子）面前，这就是“回本”的关键。除了原机自带的那个120G固态硬盘位，你还可以额外加装一块标准的2.5英寸硬盘，无论是大容量的机械硬盘（HDD）还是额外的固态硬盘（SSD）都支持。这就意味着你可以搭建一套完美的“系统+仓库”分离架构：用那块120G的固态硬盘专门跑飞牛系统，保证系统启动和软件运行的速度，然后把两块SATA硬盘接上大容量机械盘，专门用来存电影、照片和备份资料。这种物理隔离不仅能防止数据互相干扰，最重要的是，万一哪天系统崩了需要重装，你的数据盘完全可以拔出来插到别的电脑上接着读，安全性比那种单硬盘位的机器高了一个维度。

装上飞牛系统（或者其他类群晖的NAS系统）后，这台老爷机的潜能就被彻底释放了。SMB多协议文件共享让它在家庭局域网里充当中央仓库，你在电视上看片、在手机上看备份照片，速度都能跑满千兆网口的极限。想挂PT（Private Tracker）或者玩迅雷离线？i5-3320M虽然老了，但跑个下载工具绰绰有余，甚至还能抗住几个轻量级的Docker容器，比如跑个Home Assistant智能中枢、或者AdGuard Home去广告过滤。对于飞牛这种对硬件要求极其友好的轻量级NAS系统而言，这套配置属于“黄金搭档”：既没有浪费高端CPU的性能，又刚好能满足流畅运行的底线，完全不卡顿。

当然，咱们也得实话实说，248元的代价肯定是有取舍的。这台机器最大的短板在图形性能上。三代i5集成的HD 4000核显，在当年那是“神卡”级别的，能跑个街霸4，但在如今的高清视频编码面前就显得力不从心了。指望它硬解4K视频基本是天方夜谭，软解的话CPU又会上天，所以如果你打算把它直接接在4K电视上当个HTPC（家庭影院电脑），看那种几十GB的高码率蓝光原盘，那大概率会卡成PPT。它的定位必须非常明确：做后台服务，专门负责那些不需要显示器输出的脏活累活，比如NAS存储、BT下载、代码编译等。至于自带的4G内存，跑飞牛系统底座是没问题的，但如果你像我一样贪心，想同时开十几个Docker容器，那系统肯定会报警，这时候机身预留的那个额外内存插槽就成了救命稻草。反正DDR3笔记本内存现在白菜价，几十块钱捡一条8G插上，直接起飞。

说到硬盘，这里有个非常实际的使用建议。这台机器自带的120G固态硬盘，读写速度虽然比不上现在的NVMe协议的高速固态，但跑个系统绰绰有余。不过，这120G拿来存照片、电影那是捉襟见肘的。这时候，那两个SATA口的价值就体现出来了。强烈建议大家去买块企业级的2.5英寸机械硬盘，或者便宜点的SATA固态塞进去。把飞牛系统的下载路径、共享文件夹统统映射到这块后来加的“仓库盘”上。系统盘只负责跑程序，数据盘只负责存数据，这种分流策略不仅能让系统运行更稳定，后期万一要换机器，只需要把这块SATA硬盘拆下来带走，数据迁移极其方便。

最后来聊聊这个价格的心路历程。248元，带内存、带硬盘、带无线网卡，还给你留了两个SATA口和一个内存槽，这在几年前是不可想象的“垃圾”，但在硬件价格全面起飞的今天，却变成了一种极具诱惑力的“玩具”。它可能不是性能最强的，也不是外观最炫的，但它给了所有人一个以极低成本踏入NAS和服务器大门的机会。不用动辄几千块买群晖，也不用担心功耗爆炸，248块钱买个“练手神机”，折腾明白了就算将来升级新平台，这台机器依然可以作为一个优秀的下载机或者备份机继续发光发热。那么问题来了，面对这样一台“电子垃圾”变废为宝的机会，你是会立刻下单，还是觉得这种老旧平台依然不值得浪费电费？如果你也有类似的折腾经历，或者觉得这个价格还能买到更好的方案，咱们评论区见。
