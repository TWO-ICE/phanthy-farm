# 200多元买到“真香”鼠标,雷柏VT9PRO无线游戏鼠标,你想试一试吗

![封面图](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXG7tWZNSzpjHsDA5pf0URBAwyiaicml9icz6pt0sSkViapjjFjFdticX0WWbLoic6UfpnML1M43uoR4N3zA/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/nZks8vTxYhlTJVnrT4z5_w

平时玩游戏你用的是什么样的鼠标呢？对于一些游戏初学者来说，可能还感觉不到游戏鼠标的重要性，但随着游戏的深入，你会发现想要在游戏中取胜，拼的不仅是手速和技巧，鼠标的急速响应和精准的定位也是至关重要的因素，所以想要体验到更多的游戏乐趣，一款好用的游戏鼠标是必不可少的。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXG7tWZNSzpjHsDA5pf0URBAvW3N6SfciaP1AtgibviaFrY9Geg7HNricWIJvEVxq63M3UA1ERIu6s9M6A/640?wx_fmt=jpeg)


很多人选购游戏鼠标都会认为越贵的鼠标越好，用价格来衡量产品的好坏其实并不准确，也许你花上千块钱买到手的鼠标，手感和性能与百元鼠标相差无几，那么有哪些鼠标的性价比比较高呢？笔者最近花了200多元买到了一款雷柏品牌的“真香”游戏鼠标，型号为VT9PRO，下面就通过实际体验和大家分享一下，看看这款鼠标到底值不值得你入手。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXG7tWZNSzpjHsDA5pf0URBAwicL1DbNfjHBwLTauKMxnnveEn5eWysCIia31TT4YibxaRN4rRicFg1IYg/640?wx_fmt=jpeg)


首先从开箱开始说起，雷柏VT9PRO游戏鼠标的包装设计的还不错，封面简洁大方，超大号的字体和鼠标实物展示图特别的显眼，从外包装上还可以看出，雷柏VT9PRO是一款双模版的鼠标，支持有线模式和2.4G无线模式。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXG7tWZNSzpjHsDA5pf0URBAXb3aiam0mz9vFve74hwZ0L1bnnv5rTE3A748uu1MUXynZ3hMfE0V6wQ/640?wx_fmt=jpeg)


拆包之后，发现雷柏VT9PRO的配件还是挺丰富的，除了鼠标之外，还为鼠标配备了备用的脚贴、侧裙贴和按键防滑贴，还有1条伞绳USB线，1个USB转接器，1份快速指南，另外还有一个2.4G接收器，出厂时已装填在鼠标底部收纳仓里。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXG7tWZNSzpjHsDA5pf0URBAMRq6iaPjFCo9d13TBIQzFpO4mele3NQzAwx3sz7zfibiadYb9NAf0jeMA/640?wx_fmt=jpeg)


上手雷柏VT9PRO游戏鼠标给我的第一感觉是非常轻盈，鼠标整体机身的重量只有68g左右，握在手中滑动基本感觉不到任何的负重感，鼠标的尺寸是124.9*67.1*40.2mm，是一款适合中大手型的鼠标，支持抓握和趴握，鼠标表面采用的是带有防滑磨砂工艺的塑料材质，从整体外观来看，这款鼠标设计的还不错，尤其是中间V字型的镜面分割线，让鼠标看上去很有特点。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXG7tWZNSzpjHsDA5pf0URBAUeIWD5vrtLCKxd7b8NDlP6dslIJm6dPRobRk9E6eAQJcvM8O9U0ajA/640?wx_fmt=jpeg)


雷柏VT9PRO游戏鼠标采用的是对称式的设计，虽然说不限制左/右手使用，但在鼠标左侧配备了两个按键，所以更倾向于右手使用。除了这两个按键之外，鼠标机身上还有五个独立按键和一个滚轮，作为一款游戏鼠标，雷柏为鼠标上所有的按键，都提供了自定义功能，通过驱动我们可以对按键的功能进行随意的更改。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXG7tWZNSzpjHsDA5pf0URBAAHeXXaZhBLmDE9iccTOJYmR0CjS4xzE5siauVdVAPANny5qmAhoiaWPdg/640?wx_fmt=jpeg)


鼠标底部的设计也很值得一提，对于游戏鼠标来说，特氟龙的脚垫基本属于标配，这一点雷柏自然也毫不吝啬，不仅配备了五个区域的特氟龙脚垫，还另外单独提供了一套备用贴，这一点还是非常人性化的。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXG7tWZNSzpjHsDA5pf0URBAP0SAZ9VNibibsxmbVtQ4W4XVhl2AVRiaJkzJVpqWaib2LiavjW2SMnMvHZQ/640?wx_fmt=jpeg)


底部中心区域有鼠标的光学系统、开关键和DIY独立键，打开下面盖板，里面还隐藏着2.4G无线接收器的磁吸收纳仓，这里我注意到有一个细节，收纳仓磁吸力度掌握的非常好，既能够稳稳的吸附住接收器，又可以很轻松的取出的接收器。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXG7tWZNSzpjHsDA5pf0URBAk0KDlLjy1gMkTAgBGXsh2ia1aT0M8urZRlwe8roiaADqoyE5WgDvaiclg/640?wx_fmt=jpeg)


另外雷柏VT9PRO游戏鼠标还有一个让别人特别眼红的功能，就是它居然支持无线充电，购买专用的无线充电模块，就可以替换掉收纳仓的盖板，这样从此就可以告别插线充电的烦恼了。即使你没有购买无线充电模块，本机自带的800毫安电池续航也很给力，3小时左右就可以全部充满，可连续使用160小时左右，差不多能用1个月左右的时间。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXG7tWZNSzpjHsDA5pf0URBAttIs8YHrb97FPjN6gB9dP5jMXTMlgKjS99MwMOgJIlDCx8eiaiaEI66w/640?wx_fmt=jpeg)


除了无线充电功能之外，鼠标的接收器也可以购买升级版的4K接收器，4K接收器拥有4KHz/2KHz/1KHz的回报率，可以让鼠标平滑的跟手，让移动更为准确，而且响应速度也会更快，支持0.25ms/0.5ms/1ms响应速度，如果你喜欢玩射击类游戏的话，4K接收器很值得入手。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXG7tWZNSzpjHsDA5pf0URBAicAibVvzrnD27yLsHxw7YTibBKFtNvXUfM7WunRZQwibMq3k79FQVzMVrQ/640?wx_fmt=jpeg)


之前说过，雷柏VT9PRO是一款双模的游戏鼠标，除了支持2.4G无线模式之外，在鼠标的顶部配备了TYPE-C接口，使用USB线缆与电脑连接，既可以为鼠标充电，也可以同时作为有线鼠标来使用。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXG7tWZNSzpjHsDA5pf0URBAGiaNJgyXSwFNWOohzrQPPEiaM0UQZUa8rLDH8cn0pIN4O1zYVoNtZUFw/640?wx_fmt=jpeg)


这里需要单独介绍的是，雷柏VT9PRO的 USB线缆很特别，伞绳工艺的设计不仅很坚韧而且重量非常的轻，在有线模式下，滑动鼠标的时候没有任何的束缚感，两端的插头也采用了镀金接口，具有抗氧化耐腐蚀的能力，而且还配备了收纳扎带，让线缆在不用的时候更便于收纳。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXG7tWZNSzpjHsDA5pf0URBA25O0esCicPBjU53EUDsb8z8Og5iaoVEsFtBic2U7iaia5pSV8GIxVMsNC4w/640?wx_fmt=jpeg)


考虑到很多玩家的机箱会放在电脑桌的下面，为避免影响到鼠标与接收器之间的信号传输，雷柏VT9PRO可以通过1.8米的USB线缆与转接器进行组合，实现把电脑端的USB口延长到桌面上，可以让鼠标与接收器之间零障碍连接，从而让信号传输更为稳定，这一点雷柏想的还真是挺周全的。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXG7tWZNSzpjHsDA5pf0URBALzDdB3ZhLdenlD8Lc6aWQ8Nxx28ZRqeWibmlOwvtjxMuWHmh2P7IbicQ/640?wx_fmt=jpeg)


在我们看不见的鼠标内部，雷柏还为这款VT9PRO加持了很多的硬核配置，首先在光学系统方面，配备了原相高定版的3395电竞游戏光学引擎，能够为鼠标提供精准的轨迹定位，无论是细微的动作还是高速的滑动，都能够精准的把控。同时支持11档静默高度的调节，精确到0.1，专业竞技很值得入手。DPI的灵敏度最小可以定位到50，最大可以定位到26000，追踪速度能够达到650IPS，瞬间加速可以达到50G，如果搭配4K接收器的话，鼠标的性能还会再度提升一个档次。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXG7tWZNSzpjHsDA5pf0URBAodibBzbp58qzcGz6CJ19SU1cmACrdB9ZGicntWkibKnibLtd76sYvpzOTg/640?wx_fmt=jpeg)


在无线传输方面，雷柏VT9PRO专门为管理无线传输配备了智能芯片，并应用V+WIRELLESS无线游戏技术，可以实现1毫秒响应的无线信号传输，其实速度完全可以和有线模式相媲美，让我们在不影响鼠标性能的前提下，摆脱了线缆的束缚。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXG7tWZNSzpjHsDA5pf0URBASPibmdC9IoenibTicQUziaAGyj4wN3M3qFZTxRzerDLia7Ew4MQ0AYDEj6w/640?wx_fmt=jpeg)


为了能够带来更好的体验，雷柏VT9PRO在按键方面融入了C+click分离式按键预压技术，分别对左右主按键校调、单个主按键前中后段校调和抓握趴握指握方式校调，实现按键手感一致性独立校调，同时还对按键触发的回弹进行了独立校调，能够实现轻快点击触发、清脆回弹反馈、减少按键空行程和消除按键空腔音，搭配欧姆龙5000万次轻脆微动开关和电竞型100万次的刻度滚轮，让这款鼠标的拥有了非常不错手感和性能。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXG7tWZNSzpjHsDA5pf0URBAMNyicuTLBh7qIFMrhGV7BjRJV2eTD5VFzNLibfJE2ghWKFC5QHB27AGA/640?wx_fmt=jpeg)


‍‍‍前面有提到，雷柏VT9PRO游戏鼠标所有的按键都支持自定义编程，我数了一下，算上底部红色的DIY键，一共可以自定义10组按键，我们可以通过鼠标的驱动程序来对按键进行修改，具体的操作方式也简单易懂。去雷柏官网就可以下载到对应的驱动程序，可以看到驱动中的功能非常丰富，参数设置、DPI设置、宏编辑、云同步等功能一应俱全，轻松满足玩家们的各种设置需求。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXG7tWZNSzpjHsDA5pf0URBAvrXdwbDUPIT39wSdc2OoYSshOBWm3woCMP4obDm77vbrMl9tOMdzWw/640?wx_fmt=jpeg)


在实际的游戏体验中，我首先玩了几局《英雄联盟》，分别选了女警、卡特和亚索，其中让我印象最为深刻的是使用卡特对局的时候，打出了五杀的战绩，风骚的走位和飘逸的身法让对方无法捉摸，在进退之间总轻松带走对方人头。而雷柏VT9PRO游戏鼠标确实为我带来了不少的助力，鼠标在滑动的时候特别平滑跟手，尤其是在锁定敌方的时候，总能够精准的定位到敌方的人物，让我的每个技能都弹无虚发。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXG7tWZNSzpjHsDA5pf0URBAJqA0QfhWYJurLZX3QImMBqVU7liclmI1cAibQMfRxncickmuiaXM0Y5tLA/640?wx_fmt=jpeg)


在《绝地求生》的游戏体验中也同样表现的十分出色，在遇敌射击和开镜远狙的时候，雷柏VT9PRO游戏鼠标无论是瞬间的快速连击，还是开镜状态下微调锁定，都有着不错的表现，回报率设置成1000Hz让我想到哪，鼠标就会跟到哪，轻松的就能锁定到敌方，让我的瞄准水平都提高了不少。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXG7tWZNSzpjHsDA5pf0URBAcgOAqMLA0rR68YibLB3Y9NDPibnaSy3EgFkHxMuRw0Pk2icZ5icJywlJCA/640?wx_fmt=jpeg)


而像《CS:GO》这种纯射击类游戏，对于鼠标的要求也是最高的，快速的视角切换，需要鼠标的滑动特别迅速，不同的枪械也有着不同的射击技巧，点射、连射、压枪都非常考验鼠标的性能和操作的手法，而雷柏VT9PRO游戏鼠标的超快响应速度、强大的DPI设置和10组自定义组合按键，大大地提高了我的游戏水平。俗话说，工欲善其事必先利其器，这一点用在雷柏VT9PRO游戏鼠标身上，我感觉特别的合适。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXG7tWZNSzpjHsDA5pf0URBAx5gxPEddgKAZZO5RoNWY0ZemPodUcu2SIdvp4Pvpnm0ys5uJYedRQQ/640?wx_fmt=jpeg)


游戏体验过后，发觉雷柏VT9PRO轻量化的游戏鼠标用起来确实非常的省力，经过以上多款游戏的体验，总游戏时长超过了2小时以上，而我的手腕并没有感觉到任何的疲劳感。另外，我一直使用的是无线模式进行游戏，体验也同样不错，没有出现过延迟和卡顿的情况，有着不输于有线鼠标的响应速度，稍显遗憾的是这款鼠标并没有配备灯效。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXG7tWZNSzpjHsDA5pf0URBATsiaEbemw80vfxiaKhhzBwVW4XWHAEXJeYEibibrLVlBoicGicgUnLnXwbaQ/640?wx_fmt=jpeg)


最后要说的是，这款雷柏VT9PRO游戏鼠标的综合表现非常不错，它有着舒适的手感、具备强大的性能，支持自定义10组按键，同时还支持升级无线充电和4K接收器，而它的售价却只有200元左右，可以说是一款性价比超高的游戏鼠标，如果你还在为不知道买什么样的游戏鼠标而发愁，那么这款雷柏VT9PRO游戏鼠标还是很值得推荐的。
