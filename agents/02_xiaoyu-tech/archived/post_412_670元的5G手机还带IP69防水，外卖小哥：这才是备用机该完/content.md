# 670元的5G手机还带IP69防水，外卖小哥：这才是备用机该有的样子

最近在二手平台“海鲜市场”闲逛时，真让我淘到了一台有点意思的“怪咖”机型。这就是OPPO A5 5G，8GB+128GB的存储配置，卖家挂出的价格只要670元。在这个连个像样的新手机壳都买不到的价位段，这台机子居然给出了5G网络，最炸裂的是，卖家在描述里还很自信地亮出了一个甚至很多五六千元的旗舰机都不敢奢谈的硬核指标：IP69级防水。

说实话，看到这个参数的第一眼，我是有点怀疑人生的。但仔细盘了盘它的配置底色，你会发现这不仅仅是个噱头。

先拆解一下这台机子的“五脏六腑”。它搭载的是高通第一代骁龙6处理器。在如今动辄骁龙8系“火龙”横行的年代，这颗芯片看似不起眼，实则是千元机以下的“能效之王”。虽然你肯定不能指望它能满帧跑原神，但对于日常高频使用的应用——刷抖音短视频、回复微信工作群、甚至高德地图全程语音导航，它都能提供极其流畅且温控极佳的体验。

屏幕方面，它给到了一块6.67英寸的LCD大屏，在这个OLED横行、到处都是低频PWM调光伤眼的时代，LCD党狂喜。更难得的是，这块屏幕支持120Hz高刷新率，滑动时的跟手感比同价位的60Hz屏幕强了不止一个身位。而且官方标称其峰值亮度能达到1000尼特，这意味着即便是在正午烈日下的户外送餐，或者是工地强烈阳光直射的环境下，你依然能清晰地看清屏幕上的导航信息和订单详情，不用再像看普通手机那样手遮挡着屏幕找角度。

续航更是这台机子的杀手锏。电池给到了惊人的6500毫安时，配合本身功耗就极低的骁龙6芯片，这台手机的续航表现堪称“续航怪兽”。重度使用一天，或者中轻度使用两天完全不在话下。充电方面支持45W快充，虽然不能跟动辄120W的百瓦快充相比，但在这么大的电池容量面前，45W是一个平衡体积与回血速度的黄金比例，尤其是考虑到它低廉的价格，这个充电配置绝对算得上良心。

至于影像系统，后置5000万像素主摄，前置800万像素。这里必须得泼一盆冷水：它的拍照水平基本停留在“扫码级”。光线充足时记录一下生活发个朋友圈尚可，一旦到了夜景或者想拍点艺术大片，那就别抱任何幻想了。但话说回来，买这个价位手机的人，谁又是冲着摄影去的呢？

接下来得好好唠唠这个“不讲武德”的IP69防水。

在手机界，IP68已经是旗舰机的防水天花板了，意味着手机能在一定深度的静水中浸泡。而IP69则是另一个维度的防护，它通常出现在三防手机或者工业特种设备上，代表能抵抗高温、高压的水流喷射。通俗点说，拿着IP68手机你可能不敢在水龙头下直接冲洗，怕水压破坏密封性，但这台IP69的手机，你可以放心地拿去对着水龙头冲，甚至脏了直接扔进洗衣机里滚两圈（当然不建议这么干，主要是它真能扛住）。

这种原本属于工业级的防护能力下放到一台670元的民用手机上，确实有点“降维打击”的味道。

再看看卖家的描述，挺实在。这台机子还在保期内，外观除了充电口位置有轻微磕碰外，其他地方成色在99新左右，功能性全好，并且通过了平台官方的360验机检测。670元包邮发顺丰，价格还能稍微刀一刀。

我们去对比一下这个价位的其他行情。在二手市场，670元通常只能买到成色一般的红米Note系列旧款，或者是屏幕有瑕疵、电池衰减严重的老旗舰。那些机子，要么完全没有防水，一碰水就废；要么续航尿崩，出门必须带充电宝。相比之下，这台OPPO A5 5G的核心优势非常鲜明：6000mAh级别的超大电池、工业级的耐造防水、再加上成熟的5G网络，形成了一个极强的实用主义三角。

那么，这台手机到底适合谁？

如果你是一名外卖骑手、快递小哥，或者是经常跑工地、搞装修的朋友，这台手机简直就是为你量身定做的“生产力工具”。你可以把它挂在电动车把手上，突如其来的暴雨不用手忙脚乱地找雨衣遮盖手机，身上流汗或者路面溅水根本不用放在心上。手机脏了？直接水龙头冲洗干净。6500毫安的电池，支撑你从早送到晚的接单、导航、通话，中间完全不用补电。对于家里的老人，这也是完美的备用机，8+128G的配置装个微信、刷刷抖音完全够用，耐摔防水，怎么造都不心疼。

但如果你想把它当主力机，天天用它打王者和吃鸡，或者对拍照有极致的追求，那我劝你赶紧绕道。这就是个严重的“偏科生”，它的技能点全点在了续航和生存能力上，其他方面仅仅是及格线徘徊。

从现在的行情来看，670元这个价位属于合理偏低。卖家承诺在保且有360验机背书，这对于不太懂二手手机水深水浅的小白用户来说，是一层很重要的安全网。如果你决定下手，我的建议是可以尝试把价格砍到600-650元之间。下单前一定要让卖家拍好详细的开箱视频，确认屏幕无暗病。最关键的一点，要详细询问磕碰的具体位置，确认磕碰有没有伤及机身的防水胶圈——这是这台手机赖以生存的根基。这两点搞明白了，这台手机基本就不会翻车。

其实现在的二手市场，这种“偏科”的宝藏机型越来越多。大家消费越来越理性，不再盲目追求跑分参数，而是开始审视自己到底需要什么。像这种670元还带6000毫安大电池和IP69防水的手机，放在两年前，你敢相信它会存在吗？

为了极致的续航和在户外恶劣环境下的生存能力，牺牲掉极致的游戏性能和花哨的影像功能，这笔账，其实算得很划算。你会为了这样的实用主义选择这台“备用机”吗？或者你在二手市场里还淘到过什么更奇葩、更极致的偏科神机？
