# 远程开机+远程控制，向日葵开机插座C1Pro让你随时掌控远端的电脑

![封面图](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXHs8wjFl3DwBFP3VPNMlQIN2xLUJQXrK2Vdeo04EMtvDA6IxRTjwsOia8ou1PppsWcY6icqcZOSWPbQ/0?wx_fmt=jpeg)

对于依赖电脑办公的人来说，随时掌握家里或公司的电脑是很有必要的，而向日葵开机插座C1Pro绝对称得上是一款辅助神器，它是专为电脑主机设计的插座，通过它可以实现断电状态下的电脑远程开机，结合向日葵远程控制软件，可以完美实现对远程电脑的实时掌控。接下来就和大家一起分享一下，看看这款小小的插座是如何实现远程控制功能的。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXHs8wjFl3DwBFP3VPNMlQINglLONehpPFYhTa4wmTWREgIcxFYqRaw0dNd0AYeeibVELPicd5bXWOYg/640?wx_fmt=jpeg&from=appmsg)


向日葵开机插座C1Pro给人的第一印象是非常的小，作为一个经常接触各种电子产品的我来说，这款开机插座是我见过最小的一款，比市面上常见的智能插座更小一圈，它的尺寸只有59.5*39*30mm，整体的身材非常纤细。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXHs8wjFl3DwBFP3VPNMlQINg33Xz6bRZPtPBeg6fY9L76qXgR2tCoY4aW5TocoNicRk8ZZSoWicsSeg/640?wx_fmt=jpeg&from=appmsg)


这样小巧的身材优势也很明显，如果插在插线板上，它不会占用太多的空间，也不会影响左右两侧其他孔位的使用。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXHs8wjFl3DwBFP3VPNMlQIN6COIicAZhvXX7TNvdIstvK6raTMhicFUhuKBYtL2mHZfYdTPQE7HtzVA/640?wx_fmt=jpeg&from=appmsg)


在外观方面，向日葵开机插座C1Pro采用亮黑色设计，椭圆形的机身精致小巧，外壳采用耐高温的V0级阻燃PC材质，安全可靠。正面配备了一组国标五孔插口，每个插口都配有安全阀门，最大功率为2500W，可承载10A的电流。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXHs8wjFl3DwBFP3VPNMlQIND5gMPZSgB5H1RtaDFwTOJ2sMuiagN9ZBuBJn3G1Wh9Iia5PYafO4gmHQ/640?wx_fmt=jpeg&from=appmsg)


向日葵开机插座C1Pro的内部采用一体化铜带工艺，能够在保证安全的前提下提供更好的性能。插座还配有一个实体开关按键，单击即可实现开启和关闭电源的功能，长按还可以恢复初始化设置。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXHs8wjFl3DwBFP3VPNMlQIN5W1c2k2zH4UCEYKnhVqHns2iacriaHxQfrHbmgiapM6HVuHicDzof1c4Hg/640?wx_fmt=jpeg&from=appmsg)


插座的背部配备了一个标准的三相插头，在使用时，我们需要把向日葵开机插座C1Pro插到带电的墙壁插座或插线板上，才能正常使用。

首次使用，需要进行联网的配置，这里要说的是，向日葵开机插座C1Pro不支持在5G频段下使用，如果你手机所处的wifi环境是5G频段，需把网络更换到2.4G频段下才能正常连接。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXHs8wjFl3DwBFP3VPNMlQIN2favARibXglAKAdugx7kSh8ibBG8rIMeCvlzAM0mN74RMQicS8vwJseQg/640?wx_fmt=jpeg&from=appmsg)


在体验这款插座的远程控制功能之前，还需要提前做一些准备工作，首先需要下载向日葵远程控制APP来对插座进行网络配置，添加成功后还要与电脑主机进行绑定，这些操作安装提示的步骤就能轻松完成，完全没有任何的上手难度。

绑定完成之后，需要把电脑主机的电源插头，插在向日葵开机插座C1Pro上，并为电脑安装PC版的向日葵远程控制软件，最后还需要对电脑主板的BIOS进行更改，开启BIOS中的电源唤醒功能，这一步对新手来说，可能会稍显复杂，不过官网有详细的操作说明指引。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXHs8wjFl3DwBFP3VPNMlQINocHILV7JgVk0gUJFcrZjo8X1D1qsJcTiaMbLDtKcLThTraBx6icOichGA/640?wx_fmt=jpeg&from=appmsg)


至于如何开启BIOS中的电源唤醒功能，这个操作其实并不统一，因为主板品牌不同，BIOS的界面和操作方式都不相同，就以我公司的联想品牌电脑为例，BIOS中的操作步骤是Power—After
 Power Loss 设置为：Power 
On。如果你实在弄不懂如何操作，还有一个终极办法，就是去联系向日葵插座的官方客服，他们会很耐心的帮你解决。


![图片](https://mmbiz.qpic.cn/mmbiz_gif/afNLf2a8eXHs8wjFl3DwBFP3VPNMlQINULqVNzOMrOOoIeoGpwOR5tcg6at5yqyCL5sR2JUuBAmibLqQGialcZog/640?wx_fmt=gif&from=appmsg)


一切准备工作就绪，接下来就是见证奇迹出现的时刻。首先关闭开机插座和电脑，让电脑处于关机状态，模拟远程开机时的操作。接下来在向日葵手机APP中，选择之前绑定的电脑，点击开启按钮，1秒钟之后，会听到插座发出“啪”的一声，同时开机插座的电源灯也会亮起，随之电脑也会立即通电开机，原来远程开机居然这么简单。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXHs8wjFl3DwBFP3VPNMlQINApFHpqAibfvNC9PF7YJLBpKlHcDQnjIWOdy4G91t2Q44BLXFoOibGNxA/640?wx_fmt=jpeg&from=appmsg)


电脑开机之后，我们就可以通过向日葵远程控制软件，对于电脑进行操控了，这里不得不说向日葵远程控制软件非常的强大，不仅可以远程控制电脑传输各种资料，甚至还可以远程玩游戏，实用性非常强。


![图片](https://mmbiz.qpic.cn/mmbiz_gif/afNLf2a8eXHs8wjFl3DwBFP3VPNMlQINPwBVuF7MX61POPef7ia1DYOcNnbibm9C4M3xeMRKQriabznZbAabXbCpw/640?wx_fmt=gif&from=appmsg)


另外我还发现一个有意思的地方，使用向日葵开机插座C1Pro的关机方式很特别，可能很多人的印象还停留在先远程手动关闭系统，再关闭插座的电源的常规操作。但使用向日葵开机插座C1Pro只需要在手机APP中选择关机这一步即可，向日葵会首先自动关闭远程控制的电脑，之后根据设定的延时时间，再自动关闭插座的电源，两个步骤一键就可完成，这个功能还是很人性化的。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXHs8wjFl3DwBFP3VPNMlQIN2DU8cG46N4L1ibseibld3BiaU2MX182RiclDJmClic9Nia9nJcW1UzzMR3JQ/640?wx_fmt=jpeg&from=appmsg)


除了配合APP延时关机的功能之外，向日葵开机插座C1Pro本身还支持APP手动控制开关，具有倒计时、定时和断电记忆等功能，即使你没有电脑，也可以把它当做一个常规的智能插座来使用，用来控制家中的电器同样也很实用，这也让插座有了更多的使用空间。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXHs8wjFl3DwBFP3VPNMlQINO0yAJESr1HGDzBcoXBpvbgKibhscsTJd8QoUsxHTTQfzoqJiaQukKiavQ/640?wx_fmt=jpeg&from=appmsg)


经过一段时间的使用，感觉这款向日葵开机插座C1Pro真的是太实用了，以后无论是家里的电脑还是公司的电脑，想要调取里面的资料时，都不用再去求人帮忙开机了，只需在APP中点击开机，电脑就会自动打开，让我无论身处何地，都能对我的电脑进行实时掌控，这种感觉真的是无比踏实。而满足这一切的只是一个小小的开机插座，甚至价格也才几十块，如果你的工作对于电脑特别依赖，那么我想这款向日葵开机插座C1Pro绝对是你最佳的辅助工具。
