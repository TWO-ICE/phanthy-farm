# 油腻大叔也能变回小鲜肉，珂岸的洁面套装你要不要也来体验一下

![封面图](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXE9ge17IvzXtVvomFSaTJWtpNbwRljjseVsj4wGVNGSO77rF0BkPdexc2X7UxxYoEibxfN2aGkSVag/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/2oAjWgkTtSaVvnDv--1fQA

男人过了30岁，油脂的分泌就开始变得旺盛起来，而所谓的“油腻大叔”也是因此而来。就以我自己为例，每次洗脸的时候，脸上都会有一层油脂，如果只是单纯水洗的话，根本无法洗净，虽然用香皂或洗面奶能够暂时洗掉油脂，但过后皮肤总会出现干涩、紧绷等问题，这让我意识到香皂和洗面奶其实并不是万能的，针对油腻的问题，需要选择一套男士专用的洁面套装才行。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXE9ge17IvzXtVvomFSaTJWt6ZmnlcDHaTANagGu3OnYx3Rbrib6287U8gqNqp033tJt0paVBjWPvdg/640?wx_fmt=jpeg)


这让本来从不关注洁面和护肤产品的我，也不得不来一场有针对性的恶补，最终选择了这套由华熙生物推出的珂岸氨基酸洁面慕斯和珂岸物理吸盘洁面炭泥。从官方的产品详情页来看，这套洁面产品是专门为油腻的人士而准备的，针对控油和洁面有着非常显著的效果，并且温和无刺激。那么实际的使用效果到底如何呢？还是来一起体验一下吧。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXE9ge17IvzXtVvomFSaTJWtfW7AeqDoucGcWU1TxBbhb3eyXeKkCeAlricrZENcSzKc2pOxX77LUHg/640?wx_fmt=jpeg)


在外观设计方面，两款产品有着明显的区别，氨基酸洁面慕斯采用的是透明的瓶体和按压式的取液方式，容量为100ml，而物理吸盘洁面炭泥则采用传统的挤压方式，容量为100g，两款产品虽然都是用于洁面和控油，但功效和用法稍有不同。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXE9ge17IvzXtVvomFSaTJWtDJ7mFYvkhtdNqKc9cOE57DvwtBDKPvlXWUt71N1pwF111xZQFGRhBA/640?wx_fmt=jpeg)


物理吸盘洁面炭泥的作用主要是用于清洁面部，其实从产品的名称就能够看出，它可以像吸盘一样，可以把皮肤上深层次的杂质都吸附出来，内含硅藻土、毛竹炭、高岭土和备长炭，对于毛孔深处的油脂有着超强的吸附性，善于拯救你的面部“大油田”，与氨基酸洁面慕斯交替使用，可以实现对面部皮肤的深度清洁和控油补水。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXE9ge17IvzXtVvomFSaTJWtyqNbCdcwGeTDytIdDPsV1Qdib2WTsnjvX8uia4nIpWbicw3LVfjl4spTg/640?wx_fmt=jpeg)


氨基酸洁面慕斯主要的作用其实就是控油，内含大豆发酵滤液、洗去型玻尿酸和多种去油保湿的成分，能够在控油的同时牢牢的锁住水分，这对于油性皮肤，或者脸上的油脂分泌的比较旺盛人士都非常的适用。最重要的一点就是温和无刺激，洗完之后能够让脸部保持水润有弹性，不会出现干涩紧绷的问题。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXE9ge17IvzXtVvomFSaTJWtYJic0vgtL8SvEMMIXLFTgTgNZxDicjH994pricIs9dS3UxZlfPnsiamibqw/640?wx_fmt=jpeg)


在实际的体验中，我首先尝试了物理吸盘洁面炭泥，它与一般洗面奶的使用方式是一样的，加水揉搓起泡后涂抹在脸上即可，与众不同的是物理吸盘洁面炭泥的颜色是呈灰色的状态，挤出来之后确实与泥巴有些相似。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXE9ge17IvzXtVvomFSaTJWtHibsNYkN9sRbV6nRqhYiaic5eukIicBiclBM114fbjnMEueyrK8bpxXjRWg/640?wx_fmt=jpeg)


物理吸盘洁面炭泥涂抹在脸上的感觉很润滑，使用的时候只需反复地在脸上打圈揉搓，之后用清水冲洗干净即可。需要说明的是，物理吸盘洁面炭泥冲洗起来还是比较省力的 ，不像某些洁面产品需要多次地反复冲洗才行，一番操作下来大概用了2分钟左右，不会占用太多的洗漱时间。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXE9ge17IvzXtVvomFSaTJWthiaIxkQQ3JCEtIhvGPeINjJtVDI2opzQS5rdffYAqY9xjjLkn7tPNNA/640?wx_fmt=jpeg)


擦拭干净之后，我来说一说体验过后的感觉，首先要说的是物理吸盘洁面炭泥清洁的能力很强，洗过之后可以感觉到面部特别的清爽，这种感觉要比用香皂或洗面奶更为舒适一些。另外一点就是去油的效果非常明显，之前脸上油光满面的“大油田”消失不见了，没有了油光的“滋润”，好像感觉自己都变得年轻了不少。所以总体来说，这款物理吸盘洁面炭泥的效果还是不错的，适合周护理，长期使用会破坏皮肤屏障。官方的建议是可以与洁面慕斯交替使用，根据肤质每周使用1-2次即可。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXE9ge17IvzXtVvomFSaTJWt6QzUvicbORriaIFib9mTNtTD7ySrricYiajkh706UT7VeNOX7jD96V6NZtw/640?wx_fmt=jpeg)


再来看一下氨基酸洁面慕斯，这款洁面慕斯用起来还是非常方便的，只要轻轻一按，泵出来的就是慕斯质地的泡沫，省去了揉搓打沫的麻烦，直接就可以涂抹在脸上，这要比香皂和洗面奶用起来更加方便。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXE9ge17IvzXtVvomFSaTJWtOnXWSr5jWkhzxyNOMFH4Khkx833iaxewkBFpvJjbmS0icoPXYQYv7ScQ/640?wx_fmt=jpeg)


氨基酸洁面慕斯最具特色的是含有大豆发酵滤液，打在脸上的泡沫很丰富，闻上去会有一点淡淡的清香，不会刺激皮肤。至于洗后的效果，我感觉还是非常不错的，脸部的皮肤感觉很细腻润滑，擦干之后完全没有紧绷干涩的感觉，而且还感觉这种大豆洁面的效果特别温和，可以长久的保持脸部水润有弹性，大大的改善了脸部油脂分泌旺盛的问题。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXE9ge17IvzXtVvomFSaTJWtvficN2xvptlrxu502E2d1AMpSxc9uuZmr9Esb9cCQvqRia6ftPjbjXXw/640?wx_fmt=jpeg)


在我看来，物理吸盘洁面炭泥的侧重点在于清洁方面
 
，而氨基酸洁面慕斯的长处则是大豆洁面的温和控油保湿效果，以氨基酸洁面慕斯为主，物理吸盘洁面炭泥为辅，二者交替使用，不仅能够深度清洁毛孔，同时也会保持面部水润，拒绝油腻的出现。如果你也一位油腻大叔，或者你的脸上也总是油光闪闪，那么这套由华熙生物推出的珂岸洁面套装，还是很值得一试的
