# 130元的品胜扩展坞价格还能聊？双HDMI+DP+M.2接口，你感觉如何？

![封面图](https://mmbiz.qpic.cn/mmbiz_jpg/E9h3abOJCennQudqUXZClhW7Xyiaic6ibX7rafh6ic9oUt3R87DnsUGEWjiakltlTBcsZhRB1FoQKKbUXmYakp3UzGRciaCUShrJpC7FAWDwG82z0/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/auK7Kv8-uI6vdGTWVUAjRQ

在二手鱼里看到了一 款品胜 的 扩展坞，卖家标价130元，描述说没咋使用几乎全新还有原包装，接口齐全配件也都在，价格还能聊 （ 这个是重点 ） 。对比现在全新的同级别扩展坞普遍300元以上，甚至品胜自家十二合一 扩展坞 还卖 400左右 ，这个价格确实让人有点心动。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenL97VGFPEL5dMnlBft6HglmqQosjqvLddZopAoRYoAwd8nRuic20CZMLCwB9Kre3MOBSeBcb1iaPicarItSYnjWL4xW3icNjMibibTc/640?wx_fmt=png&watermark=1&tp=webp)


这款扩展坞是深空灰铝壳材质，拿在手里有分量还利于散热，Type-C 3.1输入接口兼容性广。核心配置很能打，100W PD供电足够给大多数轻薄本反向充电，不用再额外插电源。视频输出有两个HDMI和一个DP，主口支持4K@60Hz，副口4K@30Hz，多屏办公或者影音娱乐都够用。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekADpHO8x2Dlp5tjLXOHavAPlLgmw00U2byHEPviaN92XPRYWrg7jgMbWav4YL3hyjZfFe4CLJwjv6sF17WkPjG929AciafcKnG8/640?wx_fmt=png&watermark=1&tp=webp)


高速接口方面有两个10Gbps的USB3.1和两个5Gbps的USB3.0，还有USB-C数据口和千兆网口，3.5mm音频接口也没落下。最特别的是带M.2硬盘位，兼容PCIE/NVMe和SATA两种协议，直接读写固态硬盘的功能在同价位扩展坞里很少见，这是它的一大亮点。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekT00CuiaPVbIhJ9PxRWRK242I2SSVSolFbbEy5t8lLs7KGN6oPB2piapQOMryFrzpu1lkpz5PyOFtKWFO8lRZLgicVibJQAda4OOU/640?wx_fmt=png&watermark=1&tp=webp)


这款产品最 特别 是，它居然自带了一个支持PCIE/SATA协议的M.2固态硬盘读写插槽。简单来说，它不仅是一个拓展坞，更是一个移动硬盘盒。很多垃圾佬为了装个系统盘或者备份数据，还得专门花大几十块钱去买个铝合金的硬盘盒。现在花了130块钱，不仅能拓展接口，还把移动高速硬盘的归宿也给解决了，算盘打得确实响。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenT4INKSYccqsRwZ9LTqOXOFRmGXaCsc86ITD5LibMY2WQFEDdbSprjgxvwXa9VFcEqXicTupSowGTXrcbQPuzm3FhdQicLZxkzns/640?wx_fmt=png&watermark=1&tp=webp)


不过讲真，虽然理念很好，但由于M.2硬盘涉及NVMe和SATA两种不同的协议，目前硬盘盒普遍还是会存在挑盘的情况。所以如果真的打算出手，建议下单之前问问卖家，到底支持哪种协议的硬盘，免得自己家里闲置的固态硬盘插上不识别，最后只能蹲在楼道里吐槽。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCen5EQFY06ibdPDy8x5WFZic2M0xOOSEBhmUSdhWQWYUcReJIxoYxRbCAFOcVKibm30TBIMMB85e4kibRcWj5yRicT8ZYXJlInRglyN8/640?wx_fmt=png&watermark=1&tp=webp)


但是缺点也必 有， 品胜毕竟不是专门搞芯片级拓展坞的绝对一线大厂，在视频信号稳定性和发热控制上，可能会存在一些小Bug。比如高负载情况下外壳比较烫手，或者某些Linux系统的驱动需要折腾一下。再加上现在的二手鱼里面水深火热，这种脱胎于USB 3.1时代的标准，面对雷电4和雷电5这些新角色，其实传输带宽并没有特别明显的优势。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekIM9jjpSIJmRhhu7qibiavOicM6ydibFYUsjWgznNFR4a6C39WrJlS55fEpicxUAnEVhPnmd71GMTcWFQECbh4yprhBBbGoaOmCuP8/640?wx_fmt=png&watermark=1&tp=webp)


那么 到底值不值得接盘？ 这个要看最后的成交价，卖家说价格还能聊，我感觉如果要是100左右能够拿下还是很赚的，省下来的钱可以买 一根品质好点的100W的Type-C充电线。如果你对手里的笔记本接口少一直深恶痛绝，又恰好需要给老旧的SATA固态硬盘或者NVMe固态找一个固定的新家，那这 款扩展坞 绝对值得出手，不用再瞎折腾了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenVjsIQAgA0OYQiaEibXKB9XheIUArjdrTiat5bVS0xVzH08IVByZ9Qtr4eWsSvibPOWs5PIK9OmhUgo8mmKqKr0NIQv8iby7bbFIWs/640?wx_fmt=png&watermark=1&tp=webp)
