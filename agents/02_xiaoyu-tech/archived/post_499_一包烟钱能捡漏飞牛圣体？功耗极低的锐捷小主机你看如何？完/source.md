# 一包烟钱能捡漏飞牛圣体？功耗极低的锐捷小主机你看如何？

![封面图](https://mmbiz.qpic.cn/sz_mmbiz_jpg/E9h3abOJCenDU3pibAM1oaDoDKZK0aSFk55PtOBJMUx3Sbgdruu2zTD9Q3MlM0jlKxvcibCWg6K8ckOdImab7ag8UZRkJibDwrLcmgBRibgsD7I/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/T0mty5gJUtPlgtq9iu4kmA

还有人在折腾这种老咕噜棒子吗？ 最近刷二手鱼，发现一款锐捷的Rian310w小主机，价格从278到365不等，清一色的奔腾7100U。那么这种七代酷睿架构的老将，到底还能不能打？是不是买回来就只能仍沟里？


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemuibjAb6aB5sYTLrxAVOE8Ea1eia9D9icD3UxfF0TYVTtvsaHlgFUwZibcJ4GduqK8vTsibGx2UOFyyb1xPgXzJxBN9tCIPiafiaL8P0/640?wx_fmt=png)


锐捷的Rian310w小主机的核心就三点：七代奔腾7100U（双核四线程）、4G内存、有的带256G固态。功耗超级低，卖家说6-15W，实测待机可能也就几瓦，这是它最大的本钱。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemcztJHbk96HOqyvZnlMH3o1eicCzo3b2WjSednibx2x7ZoToo4U4nPDKBNR0VMbrXwTyyEQkXuibia0UeiajvyEILrCXzPX6oUxpSw/640?wx_fmt=png)


你说用它当主力办公机？说实话，确实勉强，但它的赛道根本不在这里！你想想，一包烟钱的成本，能干嘛？


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenb8gxNo1YxbwbGHVWccley2hf2GkG8DRBoBxlPZSPTibpPboAYfJRHUmLBXOdJd5CuYuLnS8CGKuOCWibtsym9rLP0Pa318WpKI/640?wx_fmt=png)


首先它绝对是合格的4K高清播放器，7100U的核显硬解4K HEVC毫无压力。再一个就是软路由/轻量级家庭服务器。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenau3BmhBnvcqJPDM8Mpia5kGAfMMia408awU51mSialPYO0FeMQk2OBKLTC87FryQnb8aN8UibKk26QUChY2HAxrG0SplLEw3E48g/640?wx_fmt=png)


这么低的功耗，7x24小时开机跑个旁路由、做个下载机、或者搭建飞牛、威联通这类轻NAS系统，电费几乎可以忽略不计。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCendM0Z2a3XAMo6QqOKogLPa15Z5jNM30bhyA0h3BGqzMno3AWGuTrZLBEqLCicfsdkAKgWtpHCFQFUczkicabOv92icw00KrwrTvU/640?wx_fmt=png)


没错，很多人一定关心能不能刷飞牛，从硬件看，X86架构，网卡是英特尔的，兼容性很好，理论上刷机跑飞牛这类NAS系统是没问题的，社区里也有成功案例，但需要你稍微有点动手折腾的能力，这才是“垃圾佬”的乐趣所在。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCensnHQrX2iaP6TI8XPiajk3ZibD2DagIBo4ldFXMarCp5afn3aNoNz7iatxvf0HQWrj500jUkib89XhhsvbufibaicR6aIrXNV8yQQgv8/640?wx_fmt=png)


锐捷的Rian310w做工确实有大厂余韵，接口也给得大方，六个USB，双视频输出。但你也别想得太美，卖家说送WiFi蓝牙模块，但电源和支架可能要另配，这算小坑。内存只有单条4G，扩展性一般。最关键的是，这套平台已经没有任何未来可言，就是一个纯粹的功能性工具。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenmvYJV6lQoTicr4SibibljxocRUuicAcdoL0RxTEslrEXr4RVYwAFiaaqtewu0hRPdHEYoOibu2RiccRRU46ianPaPfEibGhwic8FAo4W2E/640?wx_fmt=png)


所以它适合预算抠搜，但就想搞个24小时不关机的下载机或旁路由的朋友；或者是想给老电视找个极致性价比4K播放器的朋友；也适单纯想花小钱体验折腾软路由、轻NAS乐趣的“手残党”入门练习机。如果你符合以上任何一点，那这价格，真的可以“果断出手”。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCek0ELupjWXm6SIeNAsexqiaZmiaZeNrjSVgWuW1ycISfzib4mcg4qNxejgWv3beWEbxJsJUibbzV8ohZLeASNWuBFENGAhhcUcQbAY/640?wx_fmt=png)
