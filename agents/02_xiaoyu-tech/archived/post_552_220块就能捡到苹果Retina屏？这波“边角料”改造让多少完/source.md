# 220块就能捡到苹果Retina屏？这波“边角料”改造让多少显示器破防了？

你有没有想过，那些被淘汰下来的老iPad，它的心脏也许停了，但那双明亮的“眼睛”还能重新看见世界？最近在二手鱼里闲逛，我可真是开了眼，居然有人把iPad的屏幕拆下来，改装成一台便携显示器，只卖220元。这价格，简直跟买块好点的钢化膜差不多了，这操作，够不够极客？够不够“垃圾佬”？


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHGibBSsiawYXOjOwIibwPCnBtk5Dp0fxrRziacwC8H57UicMDMlKfRiar2TmnfScMfSB9HYJnacN2ibybpw/640?wx_fmt=png)


咱们先盘盘这东西到底是个啥。简单说，就是卖家把iPad上那块完好的Retina显示屏拆下来，配上驱动板和外壳，“变废为宝”。核心参数很直给：9.7英寸，原生2K分辨率（2048*1536），IPS面板，100% sRGB色域。就这屏幕素质，别说220元，就算放在几年前原机身上，那也是第一梯队的显示效果，色彩和细腻度吊打一众同价位入门显示器。如今，它脱离了iPad的身体，通过HDMI或Type-C接口，就能给你的Switch、PS4、电脑笔记本当个副屏，或者给树莓派当个显示终端。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHGibBSsiawYXOjOwIibwPCnBtib4gdSxXeIoLa2epDslyibqqz6krGDdbAQ9aYHEMho5rNTsgd7ibeoELw/640?wx_fmt=png)


它的优势太明显了。第一，价格无敌。220元，在如今随便一个国产杂牌便携屏都要四五百的年代，这简直是“价格大跳水”。第二，屏幕底子极好。苹果对屏幕的调教和用料，你永远可以相信，那种通透感和色彩，是很多低价新品无法比拟的。第三，创意和实用性结合。DIY的3D打印外壳，厚度控制在1厘米，重量只有240克，比一瓶矿泉水还轻，自带支架，还贴心地加了双喇叭。用充电宝就能供电，揣包里带走毫无压力。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHGibBSsiawYXOjOwIibwPCnBtNhy3ptb5kHhibmriajvdw9juhUJm0VfibBW5ZDWEUaIxfpGMBBjAhHHUg/640?wx_fmt=png)


但是，咱也得把丑话说在前头。首先，这不是官方产品，是个人手工改装。意味着外壳的做工和质感，别奢求能和品牌货比，可能有“毛边感”。其次，没有触摸功能，它就是一块纯粹的“显示板”。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHGibBSsiawYXOjOwIibwPCnBtgpI3SOBkiaphsGIEs2QbFiaR8KAtsgUtuOL970hPYx257WvgbKvyaTOA/640?wx_fmt=png)


最后，也是最重要的，售后基本靠卖家良心，屏幕本身虽然号称无瑕疵，但运输风险和使用寿命，都得自己承担一部分。这就像淘金，你可能用“一包烟钱”捡到宝，也可能买个教训。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHGibBSsiawYXOjOwIibwPCnBtoOSjfVnM7Ux4XhxDhE4kIGG9lbcejQYj14BiaicURTMBCJHUecnUQSiaA/640?wx_fmt=png)


给你的建议是，想清楚你要它干嘛。如果你需要一个稳定可靠、有完美售后、功能全面的生产力工具，那请绕道，加钱买品牌货。但如果你是个喜欢折腾的玩家，有个明确的、简单的扩展显示需求（比如显示监控画面、当游戏机副屏），并且能接受它的“非正规军”身份，那这220元，可能会给你带来远超价格的快乐。下单前，务必和卖家沟通好颜色、屏幕检测细节，并做好心理建设。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHGibBSsiawYXOjOwIibwPCnBtD8G6IiaDc6O2rbO0Acmtt9eAl8HxDYXrpHibKQrQ4JBy8xwVHepGGonA/640?wx_fmt=png)
