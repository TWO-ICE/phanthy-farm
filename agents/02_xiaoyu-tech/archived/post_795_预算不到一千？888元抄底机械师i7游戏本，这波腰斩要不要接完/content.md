# 预算不到一千？888元抄底机械师i7游戏本，这波腰斩要不要接盘？

最近在各大二手平台"蹲坑"的时候，一台笔记本电脑的价格直接把我的CPU给干烧了——机械师T58-D，挂出来的价格竟然只要888元。

在这个连好点的手机都动辄两三千的年代，888元买到一台酷睿i7处理器、还带着独显的笔记本，这听起来简直就像是哪个平行宇宙的促销广告。咱们先别急着喷是不是骗局，把配置单摊开来看：这机器搭载了i7-7700HQ处理器，GTX 1050显卡，8GB内存，存储方面更是搞了个128G固态加1T机械的"混搭"组合。放在千元以内的预算里看，这配置简直就是那条街最靓的仔，性价比高得让人甚至有点怀疑人生。

先给不太了解这几年硬件行情的老弟们科普一下这堆"电子古董"的含金量。

这颗i7-7700HQ，虽然现在看着是"7代老马桶"，但在当年它可是移动端的高性能代表。四核八线程，基础频率2.8GHz，睿频加速最高能干到3.8GHz。这是什么概念？这意味着在处理日常Office全家桶、挂着十几个网页后台、甚至打开4K高清视频看电影的时候，它依然能保持那种"你说啥我都能秒开"的流畅感。虽然比起现在的12代、13代i7在单核和多核上都有代差，但凡是讲究个"够用"，这颗老i7的45W功耗释放，依然能吊打现在市面上那些主打轻薄但极其拉胯的低压i3或者赛扬处理器。

再看看显卡，GTX 1050 4GB显存版本。这可是英伟达 Pascal 架构时代的常青树，说是当年入门级游戏本的"标配卡皇"也不为过。虽说你要拿它跑《黑神话：悟空》那是纯属想多了，但你要是想怀旧一下《英雄联盟》、《CS:GO》、《DOTA2》这种主流网游，或者降画质跑个老一点的3A大作比如《GTA 5》、《刺客信条：起源》，它依然能给你一个稳稳的60帧。对于只是想下班回家躺着打两把游戏的兄弟来说，这就是从"能玩"到"玩得爽"的分水岭。而且4GB的大显存相比后来出的1050 Ti（显存小）或者一些低端核显，在应对高材质贴图时不容易爆显存，这才是关键。

存储方面，128G固态+1T机械硬盘，这个组合在今天看来竟然异常合理。现在很多新笔记本为了省钱只给个512G固态，存几个游戏就满了。而1T的机械硬盘虽然慢点，但用来当"仓库"，存几百G的岛国动作片或者是学习资料，那叫一个安心。屏幕是15.5英寸的友达面板，1080P分辨率，60Hz刷新率。虽然不是什么高刷电竞屏，色域估计也就是45% NTSC的水平，但看电影、做表格足够了。

最离谱的是电池健康度。卖家截图显示健康度高达98.1%。各位要知道，这可是老游戏本啊！游戏本的电池通常在两年后就会因为长期插电使用和高热环境而废掉一半，这台机器竟然还能保持这种状态，简直就像是刚出厂一样。拔掉电源，如果不跑大游戏，纯办公上网估计能撑两三个小时，这在二手古董里简直就是奇迹般的"战神"配置。

当然，如果你是个喜欢折腾的硬核玩家，或者预算实在卡得死，卖家还挂了一个788元的版本。但这个版本，我强烈建议大家避雷。为什么？因为它屏幕是破损的，而且去掉了1T机械硬盘，只留了单256G固态。

咱们来算笔账：差价100块。你去网上找一个二手的15.6英寸笔记本屏幕，哪怕是最烂的国产屏，也要一百多块，还不算你动手拆机换屏的风险和时间成本。再说了，对于这种老机器，1T机械硬盘的价值远超100块，现在的机械硬盘也不便宜了，而且是已经装好、测试好的。为了省这100块，买回来一个屏幕裂开、存储捉襟见肘的残次品，绝对是捡了芝麻丢了西瓜。所以，888元这款，绝对是首选，这就是多花一百块买回来一个"正常使用"的体验，划算得一塌糊涂。

但是，咱们作为成年人，都知道"天上不会掉馅饼"这个道理。888元，价格低得这么离谱，背后有没有深不见底的大坑？

仔细看卖家的描述，只有冷冰冰的一行字：8G+128G+1TB，GTX1050。文案全是"办公备用无敌"、"性价比高"这种车轱辘话。至于这台机器的成色到底咋样？有没有磕碰？有没有进过水？主板有没有修过？散热风扇是不是像直升机起飞一样响？这些关键信息，卖家只字未提。

这种"描述极简"的 listing，通常只有两种可能：要么是商家太懒，不想写；要么就是这就是个"雷"，商家故意不说，等你问了再编，或者干脆骗一个是一个。

要知道，机械师这个品牌当年的定位就是"高性价比"也就是俗称的"公模游戏本"。这类机器通常都有一个通病：散热压不住。i7-7700HQ发热量不小，加上GTX 1050，如果散热模组的硅脂干了、风扇轴承坏了，这机器一开机就能煎鸡蛋。到时候玩几分钟游戏就因为过热降频，卡成PPT，那你这888元买回来的就不是游戏本，而是个发热板。

所以，如果你真动了心，准备掏这888元，千万别手软，下单前必须给卖家来一套"灵魂拷问"。

第一，必须发实拍视频。别看那几张精修的网图，你要看的是现在这台机器的真实状态。让卖家给你拍一段从按开机键到进入桌面的完整视频，看看开机黑屏有没有白斑或者闪烁，听听风扇转起来的声音是不是正常，有没有异响。

第二，进系统看设备管理器。让卖家打开设备管理器，看看有没有黄色的感叹号。如果有，说明驱动没装好或者硬件有识别问题，那绝对不能要。顺便让他跑个鲁大师或者CPU-Z，看看硬件配置是不是被"掉包"了，有些黑心商家会把i7换成i5，或者把1050换成960M忽悠小白。

第三，屏幕和键盘测试。这是最容易出问题的地方。让卖家把纯黑、纯白图片打开看看，屏幕有没有明显的坏点、漏光，特别是四个边角区域。键盘让他把WASD这几个常用键以及回车、空格按一遍，看看有没有回弹失效或者连击。毕竟老游戏本的键盘是最容易喝进水的。

第四，接口测试。USB接口有没有松动？HDMI口能不能正常输出声音和画面？网口插线能不能识别？这些细节虽然琐碎，但买回来要是发现USB全废了，那你连个鼠标都用不了，那不就成了纯纯的"大冤种"了吗？

最后说一句，888元确实是个很诱人的价格，毕竟现在去网吧包个夜都要几十块，这相当于十几天的包夜费买一台能玩网游能办公的电脑。但电子产品水深火热，如果你是个纯小白，不懂怎么验机，或者卖家回答问题支支吾吾，那这笔钱咱还是攥在手里比较稳。
