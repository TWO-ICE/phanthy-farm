# 预算不到一千？888元抄底机械师i7游戏本，这波腰斩要不要接盘？

看到了一台让人心里直痒痒的笔记本电脑，型号是机械师T58-D，卖家挂价888元，配置i7-7700HQ、GTX1050显卡、8G内存、128G固态加1T机械硬盘。这个价格，这个配置组合，感觉是千元以内性价比非常高的一款本子。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCen80VRzJWpbgjVfjiclRgH4QLztl8cU0wkYItS4JYBAq0BbsgoCfHHkYjIDbo1oH8OOozAJKwpXoPQKqjsFUEcnu1bfdQsbUqSo/640?wx_fmt=png)


来看具体配置，处理器是英特尔酷睿i7-7700HQ，四核八线程，2.8GHz基础频率睿频能到3.8GHz，日常办公、看4K视频或者是玩不吃配置的游戏是毫无问题的，显卡是英伟达GTX 1050 4GB显存，属于当年入门级游戏卡的标配。内存是8GB DDR4 ，硬盘128GB固态加1TB机械，屏幕是15.5英寸友达面板，分辨率1080P 60Hz，电池健康度98.1%，这在老机里极为罕见，拔掉电源能撑两三个小时。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemicyKb1WkfAuKBH5BUlfsDszD1HD3Or9svic9HEkxdK0ic7vADCpjje8Yt0EQNd6c6Eqiaua0mvNKC748nD7ryyoMtDC7P8ZCnGkc/640?wx_fmt=png)


如果不介意瑕疵的话，还有一款788也能买到，只是这款屏幕上有破损，而且硬盘只有单256固态，没有机械硬盘。所以总体来看，个人感觉还是888元的这款性价比更高一些，毕竟也就差个100块钱，买一个屏幕完好带1T硬盘的绝对更划算。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenYtp3oVwfAnmB6SPDFzicgx3e6D3hUhYw2BXvkwwDHX1uXpjlUcBXLhISOGd3LZjicCJzaObTQxO7icbbkI3HOy3Bwic3x0xibtbu0/640?wx_fmt=png)


但低价背后有没有坑？卖家描述只写了8+128+1TB和GTX1050，然后说办公备用无敌、性价比高，其他信息一概没有。没有实物图，没有说成色，没有说有没有拆修过，没有说散热怎么样。这些都是潜在的雷点。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemBCD5L6MKkGwjHZlFv7qib8IUAOrfxwkzKal924HX66lzbSMsD8RQkoCsiao3Pf4tVFUqs2JibhcCvIQrkdHJeib3WfZ5EL7fib7Lw/640?wx_fmt=png)


所以如果你想下单的话，下单前一定让卖家拍一段开机视频，进系统看看设备管理器里所有驱动是不是都正常，屏幕有没有坏点或者明显的漏光，键盘每个键按一遍，每个USB接口插个U盘试试。别嫌麻烦，花888元也是钱，别到时候买回来是个半残废。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenD27N5Sua8jV49IRKKQMYv7IYYPESv4ZVNnQjUHXgibphVE6chzuNvZRA3m5swG4480JgrtlT8zbsXe9BQeQ9w04wt4fEM31KY/640?wx_fmt=png)
