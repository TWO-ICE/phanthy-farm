# 86元就能在二手鱼捡漏E3 CPU，这性能果然没让我失望

朕没事就爱刷二手鱼，今天刷到一个邪门玩意儿——E3-1231 v3 CPU，售价86元，价格虽然不贵，也就半包烟的钱。但出奇的是这货居然有6万多人浏览过，4000多人蹲在角落里等鸽子。一颗乾隆年间的服务器CPU，凭什么啊？今天咱就好好扒一扒这个传说中的神U。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHK0etGichf7uvib0xdZeicYe3UhMqgiaCib062hXfeGiaasREicWd7ib9blH6icTyKCRfd6f7ujvB4RGZYpgw/640?wx_fmt=png)


E3-1231 v3是2014年发布的，属于Haswell架构。当年它有个外号叫“i7的性能，i5的价格”，因为它4核8线程，基础频率3.4GHz，能睿频到3.8GHz，还带着8MB三级缓存。最关键的是，它没有核显，所以当年配一块B85主板加个独显，是很多垃圾佬的性价比神机方案。现在嘛，它属于“老兵不死，只是逐渐凋零”，在二手市场依然活跃。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHK0etGichf7uvib0xdZeicYe3oy0iaKmPVSfcTKkLVEXRoDsNxI2Tics4zBzWiaMV3waNyC8gKwpTN516g/640?wx_fmt=png)


具体说说参数，3.4G的基础频率，单核能跑到3.8G，对付大部分网游和日常应用还是so easy的。它需要搭配LGA 1150接口的主板，比如H81、B85、H97这些。内存只能用DDR3，现在DDR3的条子价格挺白菜，组16G双通道成本也不高。它的TDP是80W，不算高，用个几十块的风冷就能压住。性价还行，对于预算极其有限，又想体验一下多线程的人来说，这个价格还要啥自行车。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHK0etGichf7uvib0xdZeicYe3EXNibdWb2uV3UPrOmUUHGQMdW1Svnvkr8bYuWRhFM6ibqmuIVl2pSAkw/640?wx_fmt=png)


当然了，这E3-1231 v3也不是完美无缺。最大的坑就是它没有集成显卡！你必须得配一张亮机卡，哪怕是最丐版的GT 710也行，不然点不亮。而且平台太老了，PCIe是3.0的，不支持M.2 NVMe固态（除非主板有转接卡），内存频率最高到1600MHz。说白了，它是一套“老家伙”的组合理念，适合怀旧或者极限预算装机的朋友。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHK0etGichf7uvib0xdZeicYe31EersFBACLWHhib5j2GZiahLSiaufIuugtPGFG4H1oibEHqJyVyE7fdvjA/640?wx_fmt=png)


可能有人会问：“这老E3-1231 v3现在还能带动我的吃鸡吗？” 我在网上查了资料，根据一些老平台的测试，E3-1231 v3配个GTX 1060或同级别的卡，在1080p低特效下玩玩《CS:GO》、《英雄联盟》这类游戏还是可接受的。但你想让它挑战最新的3A大作全高特效？那属实是会非常吃力。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHK0etGichf7uvib0xdZeicYe3a5dTeFKJXTgIV4ZaiajMhXsB8PY333thYQjHNHnicOJ0dTBF0ZGWBuOw/640?wx_fmt=png)


是不是很好奇“为什么现在还有这么多人蹲它？” 我研究了一下社区讨论，发现原因有几个：一是很多老平台升级，比如从i3/i5升级到它，不用换主板内存，成本最低；二是一些工作室需要多开程序或虚拟机，它的8线程还有点用处；三是纯粹的情怀，毕竟是一代经典。不过大家蹲的都是好价，如果价格被炒高了，那直接Say Goodbye就行了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHK0etGichf7uvib0xdZeicYe36JettpBm994DUkSuMiaOdD6npGbkVnO4GdFlQza4qeDjRWCpn9XUe3Q/640?wx_fmt=png)


水了这么多，不知道有没有同样玩过或者正在蹲这颗传奇E3-1231 v3的朋友？你们当时是多少米入手的？如果现在你老婆给你8000的装机预算，你还会不会上E3-1231 v3，评论区里唠唠呗。老规矩，看完不买，立省86元。
