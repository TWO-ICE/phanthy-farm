# 卖家不讲武德！惠普雷电3扩展坞88元起卖，到底能不能捡？

![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCeltjWB4S5EF5gNo0LauFeicusCPHNEbcIjcDLibRP7jFCWmF3aNzhy2b4MSX7zR8nj4WEuudKJicicHHiagDuAptV0ZQc2kpxgJvf90/640?wx_fmt=png)


二手鱼最近有批货挺有意思，惠普G2雷电3扩展坞，价格从88到228元，当年卖一千多的东西。这玩意儿型号HSN-IX01，Thunderbolt Dock 230W G2，是惠普给工作站配的旗舰扩展坞。雷电3芯片，230W供电，一根线就能解决所有问题。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemE5NGjzPerx0a3ibE7Hw7wXvF2WR5djhX0AWLDkl5DV2VVqT46oyNo3pR8PxRmY7F5T7yicbf64BtkiayBSKVLy3AQWgk6tibicwfU/640?wx_fmt=png)


接口给得确实足。正面一个USB-C方便临时插拔手机U盘，侧边有音频口和一个供电USB-A，背面两个DP、一个VGA、一个原生雷电口还能继续串联设备、两个USB 3.0、一个千兆网口。大多数人能想到的需求它都能覆盖，不需要再挂一堆转接头。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCeljFYBhfoSicWPCbwnUCplDoPXRGtDaNGpcibOetzMXGu6woMGYoIgfia8pJQBglk71hBjO0DggSSqfibMB2bpFLeqVOiaCUnDJ9uvg/640?wx_fmt=png)


供电是亮点。230W总功率，意味着游戏本能用，移动工作站也能用。很多轻薄本原装适配器才65W，接上去反而富余太多。双路雷电口的设计也有意思，可以菊花链串联设备，适合有多块显示器或者高速存储的用户。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemowZubnIicwTkiaGej8BGXThJsaU6VOjkaRyt9nYzbeFQAp9yGgpg1GQaO24vxsHa5VK5xkEv1j3P1SR83omm2uia1NkvGJM5qJQ/640?wx_fmt=png)


但缺点也有，线是焊死的不可分离，长度70厘米左右。主机放远了或者显示器离得远，这根线就尴尬了。想加延长线？雷电对线材要求极高，普通线要么不能用要么降速。成色默认89新，实际到手可能有划痕、磕碰、logo磨损。毕竟是批量淘汰的设备，用了三年，外观很难统一标准。介意的建议直接找卖家要实物图，别指望盲盒能开出完美成色。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemMqxaWarw76e4Qk9sjDcg4ibQoZZfwBFNaTMTBMoZErHfscjWu0fJkicNia0QK3wEobv2jRFYJgKGsp6gUTxGcbaNqQibdBIiaKAicQ/640?wx_fmt=png)


Mac用户要特别注意。Intel版MacBook一般没问题，M系列芯片的Mac兼容性看人品。有人功能全正常，有人直接翻车。买之前最好搜一下同款机型案例，或者直接问卖家有没有人测试过。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelCWqPkK83PETlvN6dHtwcJBfBmAKDj4BlSsANM93hSRt4B3DmvBPNjbpnoQficYuAZltddtljO6nRVSQkn4G4WVOFomgd8Zlx4/640?wx_fmt=png)


卖家给了三个套餐。单主机128元，适合手里有220V电源的老手自己折腾。但说实话，这种扩展坞对电源要求高，自己配个原装的成本不低，折腾下来可能比买套餐还贵。主机加120瓦电源188元，这个性价比最高。120W电源够喂饱绝大多数轻薄本和全能本，不管是办公还是轻度剪辑都够用。没必要为了多40瓦多花冤枉钱。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelepzpytY5Qh68VhGjBHdNxEibnNZl14hwIFziaOrC1ibeib9kIMGOqXx6McovF97U5g8fSR6FQSIaa48UddwzUrvAcrFiczMseJD7o/640?wx_fmt=png)


最后是主机加230瓦双线228元，给移动工作站或者强迫症准备的。如果你用的是那种板砖级电源的性能本，或者想一步到位，这个套餐更适合你。230W供电基本通杀所有笔记本了。88元其实是G2音频模块的价格，也是忽悠我点进来的套路，非特殊需求可以忽略。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelETE3BkpLbnRe6RaIr5xnYGfAkiaKppN9sYIGSmdtQbDVzm4AFJAFmFKEn0745hXwZ3CVWlfVXd7MiaYBba7czFP7M53lIwlgAI/640?wx_fmt=png)


如果只是为了多几个USB口，几十块的普通扩展坞就够了。如果只是外接一个显示器，一百多的Type-C扩展坞也能实现。需要同时跑4K显示器、高速固态硬盘、千兆网络，还要给笔记本供电，同时桌面还要整洁，这才用得上雷电3。需求决定购买，别为了便宜而买。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemzvoWp9vVM2r8PqZibqA3wibKiatia0pv3mnpL3WHjaCcZQDx5WPOAoqZnl4hyjdWjNKvDqj5CyUtf5ia8L5P0ibicuHeHypY6IicPr7M/640?wx_fmt=png)


最后说句实在的。二手鱼买东西，省的钱是你的信息差收益，但你也得承担没有售后、可能翻车的风险。这个对冲划不划算，自己心里有数。产品本身值这个价，但值不值的前提是：你需要它，你知道怎么用，你接受它的成色。
