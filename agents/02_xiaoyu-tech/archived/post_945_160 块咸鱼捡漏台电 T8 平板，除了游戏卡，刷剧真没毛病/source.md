# 160 块咸鱼捡漏台电 T8 平板，除了游戏卡，刷剧真没毛病

![封面图](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXF8iakibz7hts4piaMSGRKpUYnuricx6X9AqdfodJXaBA4jcxpZGE4tqtjTHnm9bAsGy7hpb6rSXVwVgQ/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/nGKsgK56535M1PIjiJoJxw

最近想整个备用平板刷剧，预算就两百块，所以只能蹲闲鱼捡漏。逛了三天，最后160 块拿下台电 T8，不是知道算不算捡到漏！

先说说这屏幕，8.4 英寸握手里刚好，不像大平板揣兜费劲。关键是 2K 高分屏，分辨率 2560x1600，看剧画质真顶，比我之前 720P 的清楚太多，连演员睫毛都能看见。不过老机子难免有小毛病，偶尔会有残影，好在不影响看剧，就当岁月留的小印记。

核心是联发科 MT8176 处理器，

想当年虽然

这芯片在平板圈

算不上最高端

，但是也算中流砥柱，现在嘛…… 开视频 APP 还行，想玩大点的游戏比乌龟爬还慢，卡得画面蹦迪，我果断只用来刷剧，不跟它较劲。

4G 内存 + 64G 存储，备用机刚好够。装了微信、三大视频 APP，还能存两部电影，再多就不行了。当年台电也算平板界有姓名的，现在这配置只能当备用机，落差还挺明显。

5400mAh 电池是真能打，充满刷剧四五个小时不用插电，比现在一些小屏平板还耐用。就是老电池掉电不均匀，有时半天不掉一格，有时突然掉得快，跟过山车似的，但 160 块这续航，我知足了。

1300+800 万像素摄像头就是聋子的耳朵 —— 摆设，拍照模糊得像蒙了层纱，也就扫码付款能用。不过谁会拿老平板当相机呢，这点瑕疵忽略不计。

Type-C 接口必须夸，现在数据线大多是 Type-C 的，不用特意备专用线，出门带一根就行，比老 Micro-USB 方便多了。

160 块捡这台台电 T8，我觉得血赚。你们有没有过闲鱼捡漏的经历？或者有其他性价比高的老平板推荐？评论区跟我聊聊呗！
