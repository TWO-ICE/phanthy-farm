# 飞牛主机价格大跳水，150元搞定整套飞牛圣体，捡漏的垃圾佬在哪？

![封面图](https://mmbiz.qpic.cn/sz_mmbiz_jpg/E9h3abOJCelGu2yt3IGw4uXWJcfEefgHicicpEz9aWdSicP8625ibALwat2m9dZlZDDRRicmdU21mcZjVFfunGEeccGqGhSBZnv26ziawByf3rygk/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/RdYec04i8NYUC-5zvXVL7Q

昨晚照例刷二手鱼，看到个标题写着，飞牛神器，新到一批克莱默小主机，点进去价格150元还带电源，这年头150也就2包烟的钱，现在居然能买台正经品牌的迷你电脑，而且配置还给齐了。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemwATvZjia8G1Fq5RtziahtN7qPyA4NUKKR6ycibTKHvZye7DyJOrTgfO9EKibSaT38aOkAWf2ICbd6ytJh3B9iaUI9I4uUj9eWicaDY/640?wx_fmt=png)


如果你也是那种喜欢在二手鱼里淘边角料的垃圾佬，应该能懂这种兴奋，不是因为捡了多大便宜，是这种价格被打下来了的快感，像极了当年一百块包邮收惠普800G1，现在连克莱默这种专业影音设备都开始甩货了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCek6tUYibr31pyJibAc37wq4H0DQh96RmXYHibZWDiaR9wLxklRicXrklB6ibWU280eSQJhFkBB4USAZib1BxJ2sIyEhKUM7cnXgbt3M1c/640?wx_fmt=png)


这台机器型号KRAMER，N3010U处理器，铝合金外壳，分量压手，巴掌大，接口倒是很全，千兆网口，AC3168无线，4GDDR3内存，板载32G存储，已经装好了Win10精简版，到手就能点亮的程度，原装电源也是标配，卖家还送了挂架。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCen7icogo7aibtiaKU3zuhoIwtBAicdr6RATNdGDHAdM8NOTM1IwSv4fDicPRiaxYkroYO9Thic0HLmU4hTqUokVicNVE6HUyHfziaR7QEQw/640?wx_fmt=png)


当年这一套下来至少两千起步，现在150元，等于残值被腰斩两次，N3010U这颗处理器确实老了点，但它的强项从来不是跑分，而是低功耗，刷飞牛系统，装完待机只有几瓦，完全可以扔角落里365天不关机。而且150元包电源包内存包硬盘，就算你只把它当个下载机，插个闲置2.5寸机械盘，跑QBittorrent，远程挂机，都远比用旧电脑省电，也比路由器USB共享稳定太多。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCen0PWKFFqygf9mKicShibhA47icuoILjFGP1F4njYibTdtp7TIodtVJ8VmeqSd8ZB1j0QFHp6KX12tPzwicKGGnhfsiagZUzicicPFmiaMU/640?wx_fmt=png)


当然缺点也要讲清楚，板载32G装完系统只剩20G左右，装飞牛没问题，但想存片必须加硬盘，主板上有一个20pin的SATA一体线接口，支持扩展2.5寸硬盘，原厂不带线，得自己买，十几块钱，动手能力弱的可能会觉得麻烦。另一个是内存小了点，跑Windows肯定慢，但4G跑飞牛足够，但你不可能拿它开十几个Docker。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemLo1BRUuqEwW9TCshNuL73iajHEXhwLafjgIjPmeibjAT0dLJb9r9ELquyibn5iaRmeYJicxJZEmcjYVM836Vo2lcffR9icXhf6mRIQ/640?wx_fmt=png)


最后说说如果你要拿它装机，怎么配最划算，主机150元已含电源，二手鱼上120G，2.5寸固态大概50元，1T机械盘150元左右，如果单纯做飞牛系统盘，32G其实够用，数据存外接，但强迫症想全内置，建议收个120G固态，读写快，无噪音，总投入200元，一台正经NAS就有了。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenEnRmSzciabJ85bJNvNJ9U9bNzQib3A1Qw65pTRNaicCZVPYCgS4gWX7c62XNrZq54LVUq7vic6WuviaqyBpsR4qicjFjUIPibbZ5Q1Q/640?wx_fmt=png)


要是想玩得再极致一点，还可以买根转msata的转接板，把硬盘塞进后盖挂孔里，整机依然小巧，桌面清爽，这才是垃圾佬的终极形态，不用瞎折腾了，几百块买成品NAS当然省事，但自己动手从一堆洋垃圾里挑出这台机器，接上硬盘，装系统，调试共享文件夹，最后在手机上流畅播放4K，那种成就感，比花钱买更上头


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekr1TWUG76sf9dhDPoKY4KwgfXbaMibPawg2iayItnQt5hUsRHWLjpficiciaRBzSdLzK3N1UOg3lsgKQr72OFE5AKaRfaFVWgcOKp4/640?wx_fmt=png)


你觉得150元买个飞牛圣体值不值，如果是你，会把它放家里当NAS，还是挂办公室做打印服务器，或者干脆刷个安卓看电视，留言区聊聊，别让我一个人纠结
