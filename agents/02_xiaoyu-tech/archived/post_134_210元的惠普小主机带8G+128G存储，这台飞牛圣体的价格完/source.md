# 210元的惠普小主机带8G+128G存储，这台飞牛圣体的价格香不香？

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCel0I1kmFdDDcphmlpW473XFr2IuIHoibIamSuicU8qAgcW3yMIdic5opZEvQFHWnYicytWHNZsToTNC78K5ByAz6JCoDxcezWT1VNw/640?wx_fmt=png&from=appmsg)


二手鱼刷到个性价比狠货，惠普的迷你主机，2957U处理器，8G内存，128G固态，只要210元。卖家说成色自定义垃圾，划痕较多。我仔细看了一下，几乎没什么划痕，而且已经装好Win10打好驱动，带电源到手就能用。如果我说这是一台飞牛圣体，谁赞成，谁反对？


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemSLLeBxptoe1rVECdtAc6xpmmmepE0II7Nc4JiapGXmRlF1u1jfkbYDUIqaqKJe2XNSJucB6G62gxm6ajN8QMy9ltia8q1SoR7M/640?wx_fmt=png&from=appmsg)


核心配置是赛扬2957U双核处理器，主频1.4GHz，没有睿频，TDP只有15W。办公性能很弱，但它的优势是低功耗，加上惠普这个小主机的做工和散热设计，24小时开机完全不用考虑电费问题，所以非常适合跑飞牛系统。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenMzDC0JA7cl21ulnH7KGdPSmpHoicibNayE1OOAbqwMmmWZibG4oRLxWoiaLDIr1ckD7EXvLshaAgFerjud7VhKick6qJ0CLZDrsnw/640?wx_fmt=png&from=appmsg)


8G内存是这台机器最大的亮点，现在内存涨成这样，一条8G DDR3L二手都要一百多，这台直接给你配齐了双通道4G×2，跑飞牛系统或者轻量级应用完全够用，甚至多开几个Docker容器，也能带动。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelRicaR49OPwsj0Q4tDA5p1Vj0F2F0GwRicF2tyPtRYJLEXsY3ZFlTfblv7xEa2D2WWGib16C5PYeZafuqIWP51sXkVYwkB68Cic18/640?wx_fmt=png&from=appmsg)


硬盘是128G的SK800固态，型号听起来像是国产小厂出品，但胜在是固态，装系统、开应用的速度比机械硬盘快多了。卖家已经装好Win10打好驱动，到手就能进桌面，对于不想玩飞牛的人来说，也能正常使用，省了不少事。而且还带HDMI和DP接口，真是屌爆了。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekwLr5IavyCAs6qIA2vjdcjpVrcg0FVz9y8xC4oKHUqcibuCzC5oED8jTN3auOqz7wHneh51jAlz4WXOyr0XC9tCoOYaOjZic6fs/640?wx_fmt=png&from=appmsg)


但是我还是比较建议刷成飞牛系统的，装好之后SMB共享一开，全家桶照片备份直接搞定，电视、手机、平板都能直接访问硬盘里的电影。8G内存的优势在这里就体现出来了，跑飞牛系统本身只占一小部分，剩下的内存可以开几个Docker容器，什么qBittorrent、Jellyfin、homeassistant都能安排上。赛扬2957U虽然性能弱，但对于这些轻量级服务来说，完全能扛得住。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenicDJd1EkNL6gEEAlzQa5g9DHlSoPCO9Bc2hxKicUsnqVWmaMZalrVf6s0BySVWoDAGoeicswwiby1J9JOEwic6ITLz54hCW47W82c/640?wx_fmt=png&from=appmsg)


网络方面，瑞昱RTL8168千兆网卡是标配，跑满家庭宽带没问题。无线模块是Broadcom BCM943142Y，支持蓝牙和WiFi，摆位灵活很多，不用非得贴着路由器放。集成核显支持4K显示输出，虽然赛扬的性能跑4K视频会卡，但作为NAS系统接个显示器做初始设置是够用的。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCen70y4NqAE1jyvYCsxf1Jynicn6fjazsqiatNfPSFXgTm3LHymQNFfRRkcPdYnjr6U9Bs0wOgXCSQlJxOhiaeKQ7icHNTpAGXptP0c/640?wx_fmt=png&from=appmsg)


短板也很明显，赛扬2957U的性能确实弱，所以卡是免不了的，如果要跑Jellyfin实时转码，或者同时跑多个吃CPU的容器，它会直接卡死。另外卖家说了成色垃圾，划痕较多，但通过展示图来看，并没有看到台明显的划痕，当然你要是介意的话，直接绕行，这种机器本来就是塞在角落或者电视柜里吃灰的，外观其实无所谓，功能正常才是重点。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelVfOnWSiaF7kv57j1HLwJSx0NHsFsmjwwovo1b8QUj2ZfRkILnBPST9a7N5Cxwa6Q48Vu9eTnxx3KibAhJ6SegxRBUiaJPgI6x1E/640?wx_fmt=png&from=appmsg)


最后说说价格。210元带8G内存+128G固态+电源，还是惠普品牌机，这价格在现在的二手市场里确实少见。拆开算，8G内存值一百多，128G固态值四五十，电源和机箱算下来等于白送。卖家还贴心地装好了Win10和驱动，到手就能用，对于想入门飞牛系统又不想折腾硬件的人来说，算是省心之选。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekz4IJX45j7DWSPOJgJ4FAHX3MfsOpc5Uwibf5B8mUV9VSQOqfuHSJ6FwK8Q2CHJpfJTErdQKquvQgZibW4aHNXeH1RXp5GyIeIo/640?wx_fmt=png&from=appmsg)
