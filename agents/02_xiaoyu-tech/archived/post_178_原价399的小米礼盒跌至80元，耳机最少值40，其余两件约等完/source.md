# 原价399的小米礼盒跌至80元，耳机最少值40，其余两件约等于白送？

在二手鱼里看到一款小米尊享探索礼盒，标价80元，卖家描述是全新仅拆外包装检查，耳机、背包、水杯三件套均未拆未使用。很多人刷到都会心动，毕竟80元能买到三件小米定制产品，到底值不值得出手，今天就跟大家好好唠唠。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCeme0uAHvPuluoLAyFKdicbxhtR2wuIMGy7xW6cUQxrGqibn1GLJF2Jr75ZbwwfGM58NmdAqdmBDsQw7c6BFDpjCd18eBQjP0nviaM/640?wx_fmt=png&watermark=1&tp=webp)


当初这个礼盒的价格是399元，如今线上已经买不到了 ，一般都是线下小米之家买小米旗舰手机时赠送的，当年也是不少米粉心心念的稀罕物。不像现在，随着二手市场的流通，大量礼盒流入二手鱼，价格才被打下来，跌到了80元这个冰点。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelmTicBs2gbP7tJAhuD6k1IucS3ra01P3rtVt8rzDmYF0URURt9MfmIPvlicnVRPbudcGGr3fD4OyV6QJMtVjqqYCevDJLvky56Q/640?wx_fmt=png&watermark=1&tp=webp)


礼盒里的三件产品都是小米定制款， 也有人 收了礼盒会把耳机留着自用，剩下的背包和水杯单独卖，最低也要44元。这样算下来，耳机 的残值 大概值40元左右，背包和水杯各20元上下，三件加起来刚好80元，相当于花一份钱买三件，性价比拉满。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemSVMQeE5JTaA2F55ribjmgURxDlqP1VbP1ZvPpR9cYMViaxw1Rglr1vyvoEB3cNyKhAQXeY9LhPMicDWf53B5e379j9cwNwjjb7c/640?wx_fmt=png&watermark=1&tp=webp)


再说说这三件产品的实用性，耳机是Xiaomi Air4 SE，日常通勤、刷视频、接电话完全够用，比市面上40元左右的杂牌耳机质感好太多，毕竟是小米定制，品控有保障。背包是可收纳双肩运动款，出门健身、短途出行都合适，折叠起来不占地方，比普通运动背包更省心。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekDhRS1cVo4YSurqgCqFJAjaaIIIeAqpibQMtulGSC6VAaLzEaM4IDszrgAv6SPpRTqIn0oZsgZ3U2rbxla5ZqFric2akPlFLMC8/640?wx_fmt=png&watermark=1&tp=webp)


白色吸管杯也是颜值在线，日常喝水、带出门都好看，材质也放心，比市面上20元左右的杂牌吸管杯更耐用。不过也要客观说，这三件都是基础款，没有太多复杂功能，追求高端体验的朋友，可能会觉得不够用。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemsRjictrdYBl8zrYUPukIAEu88GGbBjODqwsMsqVhQYOJpc972MNGk5bWwN5RLx5oNUWPVkOktAPs1odiab2TKmFpS8ABLEJ8Ko/640?wx_fmt=png&watermark=1&tp=webp)


给大家两个实用建议，毕竟买二手最怕踩坑。如果卖家不包邮，一定要跟卖家协商去掉盒子，礼盒本身很大，超过了快递首重，去掉盒子能省十几元快递费，不然加上运费，性价比就打折扣了，别花冤枉钱。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemQyhungZC3lnlZ8HJoeFH5ibE5dL0VypYkchibYG8JsGias6Q19yAcMBYlcJsHrQwfXHvVVk6UB4r5Xy4H8PYj9ichhZiaDm9yxCEQ/640?wx_fmt=png&watermark=1&tp=webp)


另外，下单前一定要让卖家拍细节图，确认耳机、背包、水杯真的都是未拆未使用，避免遇到老六，把用过的产品换进去，到时候翻车就不划算了。毕竟二手鱼里都是大佬，小心驶得万年船。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekxXeFnAbCDMNh4eibbkk8RDmSRiaic97NwCI2XQx3ia0o4mEVPhz86Hzle0Ut7LjNOicxVNPTpa1AEDxA1Bov0yROMgeIou7DKx3a8/640?wx_fmt=png&watermark=1&tp=webp)


对比当下的二手行情，80元能买到三件全新未拆的小米定制产品，确实很有优势。现在单独买一个全新未拆的Xiaomi Air4 SE耳机就要40多可以下不来，再加上背包和水杯，80元感觉不亏，而且还都是小米的定制款，很适合预算紧张的米粉。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemMKzf2dESg8kd9nID3GI9SWOGXowc4JrKenLIkx1sgyUaoDyVlOibP6OCjseRo7DPXBpXcwqCaP2ibGCAO2Kfic0KA8I5t1lyPqs/640?wx_fmt=png&watermark=1&tp=webp)
