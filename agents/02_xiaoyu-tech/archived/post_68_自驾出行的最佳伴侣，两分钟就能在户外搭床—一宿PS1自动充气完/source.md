# 自驾出行的最佳伴侣，两分钟就能在户外搭床—一宿PS1自动充气床

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/afNLf2a8eXEmMTA5DDXY0PzuK8LsPSmy2o0ZvkUd51NvnTKYZFsfNPRpcj78K6iaQtQc6Ngaia0HGibYVic7rP2QNg/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/s8VR180nNsRTFZcfpp7aCA

又到了春暖花开的季节，相信很多人也会和我一样，会在空闲的时候带上家人或朋友，自驾出行去踏青、野餐，这其中自然少不了各种随行的装备。以往在户外休息的时候，通常都会选择在帐篷里，虽然在里面能够遮风挡雨，但也存在着憋闷和地面过硬的弊端。那么除了帐篷之外，还有哪些适合的装备呢？最近我就被自动充气床种草了，感觉躺在充气床上肯定要比趴在帐篷里舒服的多，所以在网上下单了一款一宿品牌的自动充气床，那么这种自动充气床到底实不实用呢？还是一起来看一下吧。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXEmMTA5DDXY0PzuK8LsPSmyUdP0Z42rlvDbLwn59hpswgOsNHKttcO3nmnUf6KrLJjmIWWzplFnrA/640?wx_fmt=jpeg)


拆开快递包装，可以看到厂家是把充气床打包好之后，装进收纳袋中一起发过来的，这个收纳袋的质量还不错，白色的面料搭配棕色的托底，看上去不仅十分精致还富有运动的气息。另外比较显眼的就是收纳袋上一宿的LOGO字样，可能有的伙伴对于宿这个多音字不知道该怎么念，所以厂商很贴心的附上了拼音，这样我们就不会再念错了。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXEmMTA5DDXY0PzuK8LsPSmyPFn2iayibvKw0y9YWf8DRLhiaxIQe27TpV8EjldrzqaicgJ3DWzDibVd3ZA/640?wx_fmt=jpeg)


对于户外装备来说，产品的便携性是非常重要的一项指标，一宿PS1自动充气床在这方面做的还不错。收纳后的充气床体积非常小，与一张A4纸的大小差不多，随机赠送的这个收纳袋也很实用，配备了提手和松紧扣，想要出行的时候，可以拎起就走。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXEmMTA5DDXY0PzuK8LsPSmyb8RVufbiapXIVhE6iciaicD3ENCPNuNW8jlHhsefHuZj7gGkvFV93MicT5A/640?wx_fmt=jpeg)


收纳袋中除了装有充气床之外，其余的配件也全在其中，里面包括了一份使用说明、一条充电线和两个补丁片。补丁片的作用很好理解，如果不小心刺破了充气床，只要开口不是很大，都可以用补丁片快速的修补。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXEmMTA5DDXY0PzuK8LsPSmyuwBjROx6tARahyRShMr3bBy5xKC1aDVicGbom4PlFeV45lW15DNhUrA/640?wx_fmt=jpeg)


打开收纳袋，可以看到充气床被卷成了一团，并用一个弹力带捆扎，拆包的时候可以感觉到充气床的材质非常厚实，主要的材质是涤纶和PVC，整体的重量在2公斤左右，由于充气床支持自动充气的功能，所以充气床内还集成了气泵。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXEmMTA5DDXY0PzuK8LsPSmyGllLBTL2CsxWia1YOPJUam9xkTMMWJTR0kk50cGrDgCPZUYKzjzYsibw/640?wx_fmt=jpeg)


一宿PS1自动充气床展开之后的长度为185cm、宽为80cm，与我家的单人床的尺寸相差无几，80cm的宽度其实要比市面上很多的同类产品更宽一些，这也是我为什么选择这款充气床的原因之一，更宽的尺寸趟在上面也有着更大的活动范围，所以不至于轻微的翻身就会从床上滑落。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXEmMTA5DDXY0PzuK8LsPSmyMpu28HfVOSPx9VJvFDaDjQKPmJy6WXFeE1lItCV0HvWORtea17Sc9A/640?wx_fmt=jpeg)


至于充气方面，一宿PS1自动充气床采用的是一键充气的设计方案，只需按一下充气泵上这个橙色的开关，充气床就会立刻开始充气，需要注意的是，在充气的时候要打开旁边的进气阀门，如此简单的操作还是非常人性化的。


![图片](https://mmbiz.qpic.cn/mmbiz_gif/afNLf2a8eXEmMTA5DDXY0PzuK8LsPSmyGrLh565WPr5kpmSs8lc5pTysWSOcPWrhTuNqcq1licyiaWC1WHzNaC7w/640?wx_fmt=gif)


一宿PS1搭载的是自家独创的AirVorTech电动充气泵 ，通过这款高效的充气泵，可以在100秒左右的时间就能够把充气床完全充满。为此，我也特意进行的测试，在完全充满的时候，时间还真是在100秒左右，这个充气速度还是很值得点赞的。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXEmMTA5DDXY0PzuK8LsPSmy3WnlfLzaKuta7oEop6EibAvGn217w4Xk3MllvgtTWEvZ1v43ficTpcFA/640?wx_fmt=jpeg)


完全充满后，可以看到一宿PS1自动充气床整体的造型并不是一个平板，而是成高低不平的曲线型设计，头部凸起区域的高度为50cm，腿部低矮的区域为25cm左右，这样在躺在上面的时候，充气床能够很好的与我们身体贴合，并且对头部和颈部起到了一定的支撑效果，带来更舒适的卧姿。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXEmMTA5DDXY0PzuK8LsPSmyeHTx0wkOrM8pyoKGQGAT4KD5FK84yicGj4nan55Dl2iae5zz8AJicfaMg/640?wx_fmt=jpeg)


前面有提到，一宿PS1自动充气床采用的是涤纶和PVC的材质，这种材质特性是防刮耐磨，同时也比较亲肤，并且在此基础上一宿还对面料进行了加厚处理，不仅能够完全隔绝地面的潮湿寒冷，而且还不惧环境的恶劣，即使是在满是岩石地面上使用，也不会轻易的损坏。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXEmMTA5DDXY0PzuK8LsPSmyzgotSzfy1P3ntGhictdG2khQfASpwzTANjmpMWzbnGSPHnT1ibcIa9lA/640?wx_fmt=jpeg)


另外要说的是，一宿PS1自动充气床全身没有任何的接缝，采用了一体成型的设计，这样的设计可以使充气床拥有更大的承重能力，最大的承重可达150kg，像我这种75kg的身体躺在上面非常的稳定，重心处也没有塌陷，而且还有着不错的回弹性。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXEmMTA5DDXY0PzuK8LsPSmyE14HDNiayzQ6gB3cYNJDIlTNCC0Z57YALcJ2pxWyeic4sDwKrjv8hyicQ/640?wx_fmt=jpeg)


在体验的过程中，我还发现了一宿PS1自动充气床的另一处非常人性化的地方，就是在充气泵的旁边配备了充电接口，支持micro USB输出和type-A输入，内置了2600mAh的电池，除了可以为自动充气泵提供电量之外，还可以当做备用电源，虽然容量并不是很高，但作为救急之用还是毫无问题的。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXEmMTA5DDXY0PzuK8LsPSmyx8mngPzBDDvoe0FgGEfgHIdich1gicbhjn1vDKvYiaRa9vplRtwQ3wx7A/640?wx_fmt=jpeg)


在一些小细节方面，一宿PS1自动充气床的设计也很贴心，比如在侧面配备了拉带，可以很方便的对充气床进行拖拽；增加了地钉环也是非常实用的设计，固定好之后，即使再大的风也不用担心充气床会被吹跑。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXEmMTA5DDXY0PzuK8LsPSmya9SUybUuibCVR2puYiafZMfVcD2qPabn0bLB1ibSrtghmg7Q8vRS6PLxg/640?wx_fmt=jpeg)


一宿PS1自动充气床除了在充气方面的优势，在放气的过程中也考虑的十分周全，相比一般充气床放气慢的弊端，一宿PS1自动充气床专门配备了放气阀门，放弃阀门和进气口同时打开放气，可以迅速的排出充气床中的气体，大大地加快了回收速度。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXEmMTA5DDXY0PzuK8LsPSmyz3EME2iaQcKVCfV4Zp1RNjgemVJ4kwDMKlHlsAug2vkrNDibHd8ujZsg/640?wx_fmt=jpeg)


一番体验下来，感觉这款一宿PS1自动充气床还是非常不错的，不仅体积小、携带方便，而且还拥有牢固材质和加宽的设计，当然最让我感到满意的就是一键自动充气的功能，让充气的过程变得非常的省力。如此多的优势，也赋予了这款充气床更多的使用场景，除了适合在户外出行时使用之外，在办公室午休、出门团建，甚至是当做医院的陪护床也都完全可以胜任，如果你也想体验一下自动充气床所带来的便捷之处，那么这款一宿PS1自动充气床还是很值得推荐的。
