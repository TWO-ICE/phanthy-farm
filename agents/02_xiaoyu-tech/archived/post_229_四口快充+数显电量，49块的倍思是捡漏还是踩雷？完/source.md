# 四口快充+数显电量，49块的倍思是捡漏还是踩雷？

最近刷到了倍思20000毫安充电宝，价格写着49-65，49元应该可以拿下，而且有2万人浏览，超过1500多人想要，看这热度应该是有很多兄弟都冲了，不过话说回来，这价格倒是不贵，如果你也感兴趣的话，可以在鱼塘里搜索“全新倍思22.5W快充充电宝”


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFP7cMkRicvpYzDWia1CtUJsgY3If2XCJ9EcrLfcOsfx8Pl78AibUNaic7FRRcPlqUJBPngC7JkOUA4pw/640?wx_fmt=png)


老规矩先说参数吧，官方标的是22.5W快充，自带Type-C和Lightning双接口，还能四设备同时充。你没看错，四个！一边给iPhone续命，一边给安卓回血，再插个耳机、手表，全家电子设备都能安排得明明白白。而且还有LED数显电量，不用靠猜“它到底还剩多少电”，这点比某些只会亮红灯的祖传充电宝强太多了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFP7cMkRicvpYzDWia1CtUJsgIe2ialaWq1svRNqsvsWD4TfcDOek5raDPjIvX3DClGZo0Tfaquoq6Gw/640?wx_fmt=png)


体积方面，虽然塞了20000毫安的大电池，但官方说“轻薄小巧”。我寻思着，这词儿用得有点玄学——毕竟20000毫安的家伙，再怎么轻也得有个分量吧？不过比起那些砖头一样的老款，这款确实算便携了，塞进背包侧袋没问题。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFP7cMkRicvpYzDWia1CtUJsg7RuMcd3xVX4IorBf6YrHn4qI7qCTPVyVGuicfibDBDvtkia6x4LLKzChw/640?wx_fmt=png)


颜色有白、紫、蓝、黑四种，审美在线，卖家说全新正品，还强调有3C认证，可以上飞机高铁。但问题来了——配图里压根没看到3C标志啊！这就有点让人犯嘀咕了。你说你有，行，那你拍个清晰点的认证标签行不行？不然我带着它去坐高铁，安检大哥一拦：“同学，这玩意儿没3C，不能带。”那场面，简直社死现场plus版。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFP7cMkRicvpYzDWia1CtUJsgYlKXjBfEAPEMyGAJqflYj97gf6RYDcmHRE4ib8N32ib5SZlvNP2cDKSw/640?wx_fmt=png)

49块能买到20000毫安的倍思，听着就有点“天上掉馅饼”的味道。不是我不相信，而是闲鱼上太多“全新未拆封，其实是翻新机”的套路了。有些卖家嘴上说着“支持验货”，等你真问细节，立马装失联。所以要是真想下手，一定得私聊确认3C认证有没有、包装盒全不全、发票能不能提供。别嫌麻烦，这个价格还要啥自行车？但至少得要个安心吧！


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFP7cMkRicvpYzDWia1CtUJsgPXKf235cwE9P3a9AgbFPSBr53icvLCqzN3MdiaJiaTovcwsL67bU4EdzQ/640?wx_fmt=png)


另外吐槽一句，倍思这牌子其实还行，不算一线大牌，但也不至于是杂牌。以前用过他们家的数据线，质量过得去，没用三天就断芯。所以这次充电宝如果真是正品，那性价比确实可接受。22.5W快充虽然比不上现在动不动100W的旗舰，但日常通勤、短途旅行完全够用。毕竟我又不是要去珠峰直播，要那么猛的功率干啥？


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFP7cMkRicvpYzDWia1CtUJsgBLJhnsvmktQqReuHcmos9icp24g3CnZy8azBKoOQVgibG9iaoOYBn3mRg/640?wx_fmt=png)


再说说接口设计。Type-C + Lightning 双输入，意味着苹果用户不用额外带转接头就能直接充，这点很贴心。输出口也够多，两个USB-A加一个Type-C，反正四口同时输出是实打实的。不过友情提醒：四口全开的时候，功率肯定会分流，别指望每个口都跑满22.5W，那不科学，物理定律不允许。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFP7cMkRicvpYzDWia1CtUJsguxO9RIZ7qAGCNKfrkmGSb3GtmvAAotPP6fJvt2EDHq7ll0UZzaNz0A/640?wx_fmt=png)


最后再唠叨一句：49块买个20000毫安、带快充、还能上高铁的充电宝，听起来很美。但美不美，得看是不是真的。建议大家别光看图下单，一定要和卖家对清楚3C认证的事儿。不然买回来只能在家当应急灯用，出门？门都没有。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFP7cMkRicvpYzDWia1CtUJsg9UhuRCr0XiaP1LcNBU6u1nBtHtXskAYAqc7aba266FzrdYRt194MSicQ/640?wx_fmt=png)


所以，这玩意儿值不值得冲？如果你愿意花十分钟跟卖家确认清楚细节，那这个价格还挺香。要是懒得问，那就……祝你好运，希望你收到的不是“倍思·青春版·高仿Pro Max”。最后，看完不买，立省49。
