# 是个能亮的主机就敢叫飞牛圣体，真当垃圾佬这么好骗？

现在的二手市场，尤其是那个鱼龙混杂的闲鱼，简直是魔幻现实主义的大型现场。只要你胆子够大，手指头在搜索框里敲下“飞牛”这两个字，映入眼帘的景象能让你对自己二十年来建立的计算机认知产生严重的自我怀疑。

只要你愿意看，你能看到十几年前发热量堪比电炉子的奔腾四处理器，被卖家心安理得地标记为“飞牛圣体”；你能看到那些从银行淘汰下来的、噪音大得像拖拉机一样的老旧柜员机，也被冠以同样的名号；更离谱的是，有些甚至连散热风扇都转不动、早就应该进电子垃圾回收站的远古Atom板子，居然也敢贴个这标签出来招摇撞骗。看到这些，我真的忍不住想对着屏幕骂一句：现在是不是只要是台能开机通电的玩意儿，都能被封个“圣体”了？按照这个标准，我家床底下吃灰十年的那个奔腾双核老台式机，是不是得拿出来开个光，直接封神算作“太上老君”了？

这种乱象，真的不仅仅是搞笑，它是在透支大家对“软路由”和“NAS”这些极客玩法的信任。

但在这一堆电子垃圾里，偶尔也会出现那么一两个清流，或者说，是那种“虽然我不行，但我坦荡荡”的典型。就比如我今天无意中刷到的这台小机器。讲道理，看到它的第一眼，我是服气的。全金属的机身，一看就是工控领域的常青树——搭载J1800处理器，配了2G内存和16G的硬盘，售价只要88块。这价格，低到让我甚至有点想给卖家点个赞。在这个动不动就把情怀炒到天上的市场里，这卖家至少没把这块板子吹成是穿越回来的未来科技，实诚得让人感动。

咱们来拆解一下这台88块的“玩具”。卖家提供了好几种配置，核心主要就是J1900和J1800这两兄弟。对于熟悉捡垃圾圈子的朋友来说，这两款代号叫“Bay Trail”的处理器简直就是那个年代的回忆杀。这是英特尔早在2013年左右推出的22纳米工艺产品，主打一个低功耗，TDP（热设计功耗）仅仅只有4.5W。

什么概念？这就意味着这玩意儿基本不需要什么暴力散热，无风扇静音设计完全可以hold住。它的体积控制得极其变态，10厘米见方，厚度也就3厘米，往路由器旁边一放，你根本分不清哪个是负责上网的，哪个是负责存数据的。接口方面倒是给足了诚意：千兆网口是标配，搞了个VGA和Mini HDMI双输出，甚至还支持TF卡槽扩展，甚至机身居然还预留了SIM卡槽——虽然对于咱们家庭用户来说，这玩意儿基本就是个然并卵的装饰，放在那儿也就是看看，但不得不说，工控板子的扩展性确实有点意思。

卖家在文案里还挺嚣张，直言这配置全面超越华为CT6100那种老掉牙的光猫路由。这话说得虽然狂，但细想一下倒也没毛病。毕竟CT6100那类设备，本质上是运营商定制的大路货，闪存和内存都被锁死了，而这台J1800虽然也是个老古董，但起码架构是开放的，装个飞牛OS做个纯粹的下载机，或者挂个轻量级的NAS服务，理论上是绰绰有余的。

但是，咱们得把问题落到实地：它真的配叫那个被吹得神乎其神的“飞牛圣体”吗？

这里我要泼一盆冷水了。所谓的“圣体”，在垃圾佬的词典里，往往意味着某种完美的平衡——性能刚好够用、功耗低到感人、价格便宜到甚至不用还要什么自行车。但这台J1800，充其量只能说是“刚刚跨过了能用的门槛”。它的性能非常局限。

你要是买回去，仅仅装个飞牛OS，插个移动硬盘备份一下手机里的老照片，或者挂个BT任务深夜下点动作片，那它确实能兢兢业业地干活。但你要是贪心，想让它跑虚拟机、搞硬解转码、甚至多开几个高负载的Docker容器（比如群晖的Drive或者复杂的Home Assistant智能家居中枢），那这老旧的Bay Trail架构分分钟就能教做人。它的指令集执行效率和内存带宽，跟现在动不动就几GHz的酷睿或者N100比起来，简直就是自行车碰上了火箭。它更像是给完全不懂的小白拿来练手的入门级玩具，离那个被神话的“圣体”境界，中间还差着十万八千里的算力鸿沟。

当然，我并不是非要一棍子打死所有的工控机。毕竟每个人的需求不一样，钱包的厚度也不一样。如果你现在的预算极度有限，手里就捏着一百来块钱，就是单纯地想低成本体验一下“飞牛OS”到底长什么样，或者就是想折腾一个不插显示器的纯粹下载机，那这台机器确实是全宇宙最低的门槛了。

我们算一笔账：88块钱买主机，去垃圾堆里淘个二手的2.5英寸机械盘或者固态盘，再花8块8买个二手的12V电源适配器，一百块钱出头，你真的就拥有一台物理意义上的NAS。功耗方面，全天开机也就4.5W，相比之下，如果你用那种老旧的台式机做NAS，一年下来的电费差价都够你吃十几顿烧烤了。把它塞在电视柜角落或者路由器旁边，安静无感，只需要它做一个简单的“数据仓库”，它完全能胜任这份枯燥的工作。

所以，对于想入手的朋友，我建议你把两个核心问题想清楚，这决定了你是买回一个工具，还是买回一个电子垃圾桶。

第一，你买NAS到底是为了什么？是图个新鲜，还是真的有刚需？如果你的需求仅仅是“照片备份”和“PT下载”，那选个J1900或者J1800配个4G内存的版本（一定要上4G，2G跑现在的NAS系统真的很捉急）是完全够用的。但如果你脑子里想的是搭建家庭影院、自动洗照片、多用户协作，那我强烈建议你咬咬牙，把预算翻倍，直接上J4125或者N100这种现代平台。别为了省这几百块钱，买了垃圾回去，结果卡得心态爆炸，最后还得含泪升级，那是给自己找罪受。

第二，千万别被“飞牛圣体”这四个字洗了脑。这年头什么词儿火就容易被滥用，任何机器都有它的物理极限，铁律就是“一分钱一分货”。认清自己的需求，比盲目跟风某个网络流行梗重要得多。J1800就是J1800，它是个优秀的低功耗下载机，但它不是万能的神。

现在的飞牛OS确实火得一塌糊涂，火到什么程度？随便一个卖工控机的商家，只要手里的板子能点亮，就敢往上面贴个“飞牛专用”的标签。这种乱象说实话挺败好感的。真正让飞牛出圈的，本该是它优秀的易用性、对老硬件的兼容性以及那个友好的中文界面，而不是让一群无良商家把垃圾重新包装成“传家宝”卖给不懂行的小白。

我们在捡垃圾的道路上，要保持一种清醒的极客精神。理性看待所谓的“神机”，按需上车，才是垃圾佬的自我修养。

最后，我想问大家一个问题，你在闲鱼上见过最离谱的“飞牛圣体”是什么？是把奔腾4说成“高性能服务器”，还是把单核酷睿包装成“软路由之王？欢迎在评论区晒出来，让大家一起乐呵乐呵，避避雷！
