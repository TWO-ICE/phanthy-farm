# 预算2000块想干三角洲，这台败家之眼到底能不能行？

这两天在二手市场蹲守，想找台能舒舒服服跑《三角洲部队》的游戏本，这想法在很多人看来可能有点“痴人说梦”。毕竟现在的游戏本价格飘得离谱，稍微看得上眼的都得五六千起步。我的目光原本一直聚焦在联想拯救者R720这种“常青树”身上，觉得这货皮实、耐造，是当年的神机。但问题是，这机器在二手市场太抢手，价格被炒得有点畸形，成色稍微好点的都要价不菲，而且还得拼运气捡漏。

结果就在昨天，大数据竟然给我推了一台让人看了直流口水的机器——华硕ROG玩家国度。要知道，这可是当年让无数大学生“吃土”都要冲的“败家之眼”。卖家挂出的标价直接让我瞳孔地震：1980元。这价格比我看的那台R720还要便宜一点，最离谱的是，R720通常也就搭载个GTX 1060，而这台ROG直接给到了GTX 1070。这就好比你想买个代步车，结果发现劳斯莱斯只卖五菱宏光的价格，不管是品牌信仰还是硬件堆料，这性价比简直就是“降维打击”。虽然还没付款，但心里的天平已经开始倾斜了，咱们今天就彻底盘一盘，这台老旗舰到底是不是那个“绝世漏”。

先来看看这台机器的底子。型号是GFX72VSK，这名字一听就是当年ROG系列里的重型坦克。它配备了一块17.3英寸的大屏幕，在这个14寸甚至13寸笔记本满天飞的时代，17寸的巨无霸已经成了稀缺物种。想当年这机器刚上市的时候，售价那是妥妥的1万8起步，属于妥妥的土豪玩具。

外观方面，整机采用了全金属机身，拿在手里那种冰凉的压手感是现在的塑料机身比不了的。A面那个标志性的大眼睛Logo，通电之后是会发光的，晚上一开，整间屋子的氛围感瞬间拉满，这就是那个年代独有的“赛博朋克”审美。键盘也是经典的红色背光，虽然现在看不如RGB彩灯花哨，但这种单红色的骚气，反而更符合纯粹玩家的调性。卖家描述这机器的成色“非常好”，这一点在二手老本里确实难得，毕竟这东西当年买回来可能都在桌子上当“台式机”用，没啥颠簸。不过，卖家也实话实说了一个极其劝退的缺点：这玩意儿又大又重，根本不适合随身携带，除非你每天去健身房就是为了练背。

这就引出了这台机器最核心的竞争力——配置。虽然时间来到了2024年，但你敢信，1980元能买到什么配置？

首先是CPU，i7-7700，四核八线程。我知道这时候肯定有“参数党”要跳出来说：“七代U太老了，效率低，智商税。”兄弟们，看配置要看场景。对于1080P分辨率下的《三角洲部队》或者主流网游来说，四核八线程至今依然没过时。这颗U的主频不低，单核性能尚可，配合当年的桌面级散热的模具，长时间运行的稳定性吊打现在很多为了轻薄而牺牲性能的低压U。

最让人惊掉下巴的是显卡——GTX 1070 8GB。这可是当年的次旗舰卡！放在2000元这个价位段，这简直就是在送。你要知道，现在很多四五千的新轻薄本，甚至所谓的全能本，核显或者入门级独显跟这张1070比起来，简直就是挠痒痒。在1080P分辨率下，不开光追，开中高画质跑《三角洲》，这卡依然能打得有来有回，帧数表现绝对在“可玩”这条线以上。更别说跟那些二手鱼里常见的 GTX 1060 3G、GTX 1650 这种“智商检测卡”相比，1070完全是跨时代的碾压。

内存方面，这机器给到了16G，对于玩游戏来说绰绰有余。最关键的是，这机器居然有四个内存插槽！你没听错，是四个。这意味着如果你以后想折腾，完全可以自己加到32G甚至64G，把它变成一台移动工作站。这种扩展空间，现在的笔记本想都别想，基本都是板载焊死给你两个插槽意思一下。

硬盘组合是256G固态加500G机械。说实话，256G固态放现在是捉襟见肘的，但这在二手老本里根本不算事儿。现在的固态白菜价，你去二手鱼或者拼夕夕上花顿饭钱就能买个大容量NVMe固态插上，体验立马翻倍。这种可维护性，也是老旗舰的一大乐趣。

咱们来做个横向对比。1980元这个预算，在二手市场里通常能淘到什么？大概率是些二三线品牌的“寨板”，或者是那种用了七八年的ThinkPad商务本，核显亮机卡，想玩3A大作基本靠做梦。能摸到GTX 1060的都算是运气爆棚，而且往往还是那种散热缩水、模具公版的“大磨盘”式笔记本。

而这台华硕ROG，虽然也是老平台，但当年的“败家之眼”做工用料确实扎实。七代i7虽然老了点，但架不住显卡底子好。1070显卡在DX11或者DX12游戏里依然有一战之力。这种用当年的顶级旗舰去打现在的入门级垃圾，那种“田忌赛马”的爽感是实打实的。从性价比的角度来看，这确实有点欺负人。

不过，咱们不能光看优点，毕竟“一分钱一分货”是永恒的真理，这么便宜肯定有硬伤。

这台机器最大的槽点，也是它被称为“重型坦克”的原因——重。裸机重量就在4公斤以上，这是什么概念？两瓶大瓶装可乐的重量。再加上那个像砖头一样的电源适配器，整机旅行重量直接突破5公斤。如果你是学生党，每天需要背着它穿梭在宿舍和教室之间，或者你是打工人，需要每天挤地铁通勤，那我强烈劝退。背这玩意儿出差，搬家一次你就想把它扔了，它是真的能帮你练出麒麟臂。

其次，作为老平台的通病，功耗控制绝对是灾难级的。七代酷睿加1070这个组合，满载功耗能轻松突破百瓦。这意味着什么？意味着风扇噪音起飞，散热风扇的声音大得像直升机起飞。而且因为工艺制程落后（14nm），现在的能效比完全没法看。满载跑游戏两小时，不插电的话电池电量基本就是“自杀式”下跌，大概率坚持不了一小时就自动关机了。所以这机器基本就是个“伪笔记本”，使用场景必须固定在插电的桌面上，别指望它能像现代超极本那样待机一整天。

所以综合来看，这笔交易到底值不值得下叉？

如果你的预算死死卡在两千块，你的需求就是一台能稳稳当当打游戏的大屏笔记本，而且你对便携性完全不在乎，平时就把它扔在宿舍或者家里当个台式机用，偶尔挪动一下也不嫌累，那这台玩家国度绝对能打。在两千元这个价位，它的游戏性能、屏幕观感、键盘手感，绝对是独一档的存在，那种老旗舰的质感确实不是现在的廉价塑料本可比的。

但反过来，如果你需要频繁带它出门，你对风扇噪音特别敏感，或者你对续航有哪怕一丁点的要求，那千万别碰。这时候哪怕降级买个轻便点的1060本，或者加钱上个新平台的入门级游戏本，体验可能都会更好。

最后，这事儿还得大家帮我参谋参谋。两千块预算淘游戏本，到底是选这种老当益壮的“旗舰化石”，还是硬着头皮加钱上新平台？这波“捡漏”到底是真香还是入坑？评论区里咱们聊聊看法。
