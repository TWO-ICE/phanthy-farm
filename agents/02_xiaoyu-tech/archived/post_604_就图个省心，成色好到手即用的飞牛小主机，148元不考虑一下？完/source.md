# 就图个省心，成色好到手即用的飞牛小主机，148元不考虑一下？

![封面图](https://mmbiz.qpic.cn/sz_mmbiz_jpg/E9h3abOJCenU20BgjwkzjulnzqXsVIBW4zfZBCTvBLHsDU27XCks7yQsfz1Lr1RXBEAZDjRes5twUbNlib30X6ibyDTH2SyWowPLBZxyV9JoA/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/xMbwH4YB5hTqc-v7zl0qrg

到手就能用的飞牛小主机，全套配置到手价148元，说实话这个价格并不是地板价，但也并没有高的离谱，主要是我看卖家主机的成色还不错，虽然咱看的是二手货，但谁不想能淘到个外壳崭新的主机呢？


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemx0uIqRMo103Vffgb5QWnJ7yjwoEVyt77DyZoU09GQS2pLyLbcWxgGPZAO2ulWejmib1fQ7B81yX9ohk8ypkNjPJrmleIjOjGo/640?wx_fmt=png)


卖家说主机已经刷好了飞牛系统，核心是1037U处理器，4G内存，64G固态，还带12V3A电源，没什么性能，装Windows就不用想了，它不是那块料。优点就是功率低省电，适合24小时开机，和家里的路由器的耗电量没什么区别。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekUMsU9ocZBo9Tr4vz32RDEvp98HxGBib4WVVgAbdHiceC73rbNUJ2GyfnmMicLZicS6jNGQV1LBAPfljVWD4Ony021MiblnhdChQoI/640?wx_fmt=png)


有人嫌弃它老咕噜棒子，觉得这配置连开机都费劲。但实际用过就知道，飞牛OS对这代老平台优化得相当到位。日常文件备份、家庭影音、挂个下载机，4G内存完全跑得起来。你要是想折腾，两个SATA接口还能塞一块2.5寸机械盘，当个冷备仓库也够用。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCen6rD95toQmpxAkVLsfYmicUcuabA7Lao37C1EDbEfLvGicOe4xnwPa5zwtcI6KOCxlHcaUkbgztiaiatlKM9wxZkHV1n8IfBZ7v3g/640?wx_fmt=png)


重点是什么？是148元。这个价格放在今天，连个像样的路由器都买不到。隔壁某品牌新出的入门NAS单机身就敢标699，还得另配硬盘。这边直接整机带电源，系统刷好，插网线就能用。放在三年前，这种配置至少得三百往上，现在直接腰斩两次，跌至冰点。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelHbZVzk0Y8iadibt6JtJwCKk6Z6eUJeEQScZMTRia3SDUMRvukL3w7VMGIGb9FQA3r7iasxeUL1ibfeROWNpLQBXhKdCI2QosmwMU0/640?wx_fmt=png)


当然，丑话要说在前头。这机器不是拿来生产力的，别指望用它剪视频跑虚拟机。它的定位就是一个安静待在电视柜角落、24小时不关机的小副机。功耗低到什么程度？一年电费撑死三四十块，接口方面，HDMI和VGA都有，应急当个备用电脑也不是不行。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekG6GzJP7NZUVRt8lqtk5mFiaCoLcvseQsreiaibH7Juk0jzI56WwbBibVGxjPqJjCmPfiaaMibHfdXTXLfm9uFl5r22SCnFRClSJCME/640?wx_fmt=png)


另外有个细节值得说。这套机器用的是DC电源适配器，不是那种笨重的内置电源，体积只有19*19*4厘米，随手塞进弱电箱毫无压力。全被动散热，零噪音，对租房党和卧室党极度友好。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCel6pupYPDNojoO5sm2DdQ8OWPagjIqaIvYgmgscbDOP8LK2OUtKeCdN7mTOYPjKibGH4ObSI8z4gYCTbT2MlHiacc14G7gM85OSA/640?wx_fmt=png)


这台148元飞牛小主机，注定不是给追求顶配的人准备的。它是给那些手里有块闲置2.5寸盘、想低成本体验NAS、或者单纯想搭个内网穿透服务的预算抠搜党一个试错的机会。就算买回去吃灰，转手亏也亏不到哪去。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCek4IcMn5um29vU5iciaLlo5rA4ic7zwc9z8n9BqDSvaJjPPez5cdJkpvG2blL3xiabq9JlicJbvK6tZ5icjFmSGMhxoS59X08IKP1icBs/640?wx_fmt=png)


最后建议再和卖家小刀砍价，说不定还能省下来20块。你觉得这种老平台NAS，到底是洋垃圾还是真香机？如果是你，会拿它来跑飞牛、OpenWrt，还是塞进角落当旁路由？评论区聊聊，我一个个看。
