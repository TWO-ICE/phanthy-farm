# 小米出高达摄像头了？36元给摄像头配个机甲外壳，帅爆了！

最近在二手鱼里瞎逛，差点以为走错了片场，以为小米出高达摄像头了，仔细一看原来是有人在卖小米摄像头DIY的外壳，本来想划走，再一看价格，36块，还不贵，但是能给家里的摄像头换个皮肤，看起来挺好玩的。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCek3RNHTZU6Mp6fcjdJlCKAlk6uss8ibHHFUtxYyBzycQgKJuoAwPicibTD53PYwxuYTFWcKGH3gh5ehFMSZiauzBiadrAD2lt0PPp50/640?wx_fmt=png&from=appmsg)


这东西不是那种粗制滥造的贴纸，也不是什么官方联名的高价货。它就是一个3D打印的小米摄像头外壳，但造型是妥妥的机甲风格，高达味儿很正。卖家说得很直白，所见即所得，而且头部能随着摄像头一起转动。你想想，平时家里的摄像头就是个白乎乎的塑料球，跟个大眼珠子似的。这玩意儿一套上去，瞬间就变高达的监视器了，感觉看家的格调都上去了。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemfsaXk5UPG9MwukFJygOhFzmltBdRNQ1Ol2TJMqh6OiaL9zJGibdoLibDGmgN4y8gnPuPOs6qq2fQMEjIQTK4OalnPkeoZljAHBA/640?wx_fmt=png&from=appmsg)


咱们来盘盘这36块钱到底花得值不值。它适配的是小米云台2代、3代、4代，还有2K版和C700这些型号。这就挺关键了，小米云台版本来在二手鱼就是硬通货，百来块收一个，再花36块买个壳，总价不到200，你就拥有了一个画质不错还能远程操控的高达风格监控，这事儿听着就带劲。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCeklu967RuefZz4kEaedsNye2pCuguab0E8d7u8pMw0hhTibszBesTW3Eyhe5R1q7IJq8ED4rYfAibnp2fSMGnKQttM9R4QV9O38A/640?wx_fmt=png&from=appmsg)


不过咱也得说点实在的。毕竟是3D打印的，不是官方开模量产的东西。卖家自己也在描述里打预防针了，表面有层纹和一些瑕疵，介意的话慎拍。这其实就是这种小众定制产品的常态，追求完美无瑕的肯定接受不了，但如果你是冲着这个独一无二的造型去的，那点层纹反而成了手工感的一部分。另外，36元只是基础色的价格，想要武器盾牌还得加5块，全套配齐也就一杯奶茶钱。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenVC8MXQDgY8HgUP7p4yUzvqFzk8HKyrfBhuLIcRtjQwYIPTIiajxVKLDPCvCZATu6MltU3mHZH5nLlicgKibicoP6PzWzFfLqHhIo/640?wx_fmt=png&from=appmsg)


现在二手鱼上的摄像头交易量很大，各种成色的都有。但像这种能给设备“换皮肤”的配件，却非常新奇。它卖的不是摄像头本身，而是一种情绪价值。你花30多块钱，买的不是一个单纯的外壳，是让家里那个冷冰冰的监控设备有了灵魂。特别是对于咱们这种数码爱好者，能动手给设备搞点个性化改造，本身就有种满足感。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemicfAYFjXKYAqo9uwh6G7CJeCdGsoonc2ibbdCF0LcCuPl0ubJck58fGIoVyCSXVQqGxmkic8VnGKnbLjNgMRSYeNWVjyJQ4ibSHA/640?wx_fmt=png&from=appmsg)


另外，我又拓展搜索了一下，发现做这东西的商家还不少，而且各式各样全有，价格普遍也就是30多块钱左右，而且这种外壳还支持壁挂和顶挂，安装方式很灵活。唯一的建议就是，下单前一定确认好自己摄像头的型号，因为不同代的云台版尺寸有细微差别，别买回来装不上就尴尬了。另外，毕竟是定制产品，不支持退换，心里那点小纠结得提前想清楚。
