# 华为M3老平板改直供电当车机， 380 元的改装机到底靠不靠谱？

![封面图](https://mmbiz.qpic.cn/mmbiz_jpg/E9h3abOJCekEPWviaIP7th3Wd0XLzHCJjSR6F2PB5C0Ily23vTAgIv0TBaIMoqjsKo0xsFwj7qtBDklib4n6WkeBCmfKtfIjGkelroKZzaC3Y/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/oHjObB6y_gCHqWtdCMJAPg

在二手鱼里逛的时候看到一台改装好的华为 M3 平板，卖家标价 380 元起，高配版 64G 的要 480 元，专门改成了直供电车载导航用， 这东西还真 勾起了我的兴趣。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelqibIz5NKkgTBFpadqKUdic9cicOSHKmlGbK6IHTNF2qLDA7D64gJf4XiaD8SBmjdNRnZqSVsUgOTia6a48a1K49VaFvKu7rJMCTIg/640?wx_fmt=png&watermark=1&tp=webp)


这 玩意的本质 是 8.4 寸的华为 M3 平板 ，屏幕是 2.5K 超清分辨率，亮度足够，卖家说太阳底下也看得清楚，这点对车载使用很重要。处理器是麒麟 950，4GB 内存搭配 32G 或 64G 存储，当年可是华为的旗舰芯片，放在现在跑导航和音乐软件完全够用，毕竟导航软件对性能要求不算高。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCel8eiaDVWoLwmGOxUXbPibx2AUicNKzXSNbhq2SGASn6Xk4kbdExaxwNtSJCTMt2PxeOJxlZSrQ0xkko4s2WSA1WF1THpjO5hb4sA/640?wx_fmt=png&watermark=1&tp=webp)


最关键的是改装部分，卖家把内置电池彻底移除了，换成了 Type-C 快充直供电接口，还加装了专业降压稳压模块。这样一来，通电自动开机，断电就关机，完美适配车载使用场景，最大的好处是彻底解决了车内高温导致电池鼓包漏液甚至起火的隐患，长期驻车使用也放心。接口还支持 PD QC FCP AFC 多种快充协议，9V 12V 都能兼容，直接接车上 12V 电源比如 ACC 也没问题。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekMiaiby3iaScicu6y0tptou4RFicCgl1J0BPY8F3VVz6p6NIiaOJ75iaRN4u1yblv6EugmnvKX4XH960svn8va3XXib2h0j1WuiaoVKbg8/640?wx_fmt=png&watermark=1&tp=webp)


软件方面也刷好了氢桌面画中画版，开机自动分屏，打开导航地图的同时音乐软件会自动播放，这个功能在开车时特别实用，不用手动切换应用。背面还加装了球头夹，方便固定在车内，不需要也可以不加，很灵活。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCeniakicYZeQaQSl6Q205TF9WdHz5zJI43P7BFbxPNFalKviaV71yq6fLD92sMHPiboSMhs7uvcZOGsNTib0VkXNPnfhJxIUfW6u2wMc/640?wx_fmt=png&watermark=1&tp=webp)


华为 M3 当年的定位 是影音旗舰平板，和哈曼卡顿合作调音，音质表现不错，2K 屏在当时也是顶级配置。如今作为普通平板可能已经不够用，但改成车载导航后，它的优势反而凸显出来，屏幕素质和处理器性能都比很多廉价车机强。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelcpJH1JVSHHo9oZcgicqNpeGxD8bgwzWQhvTXU0RyM1icGLrLjicosJ9VV6mh8DUjpiaKTj6YmwxtvqdXMYDYwzqRMnV26FbMXmMM/640?wx_fmt=png&watermark=1&tp=webp)


380 元的价格比买新的车载导航便宜太多，优势 也 很明显，极致安全无电池风险，即插即用不用操心充电，还能当行车监控和娱乐中心用，安装前后记录仪 APP 或者流媒体后视镜软件都可以。对比同价位的二手平板，很少有专门为车载场景做这么彻底改装的，性价比确实突出。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenPYQ7uR5vFd3HYXqDRMYfAkY0wgliaSibhdtdH1tyicBLFzicibRlBRZrqqlc1JFFcwjoS9ERTuSYgN10q5eEicbTj22ZdFgoQG1wAk/640?wx_fmt=png&watermark=1&tp=webp)


但也有要注意的地方，首先这是 2016 年的老机器，系统是安卓 6.0，虽然能装常用导航软件，但后续升级支持可能有限，部分新功能可能用不了。其次直供电改装需要专业安装，自己动手能力不强的话，最好找师傅帮忙接线，避免线路问题影响使用甚至安全。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelOmXaia8McmJ8rsv3eQhgNm0EEjydgATVOumqbIOTG6sWhibNcI9v2dvcDJFXZ5XBObJq0tpNuZKqxqtFwPnwFSxbVDkSSAKCA8/640?wx_fmt=png&watermark=1&tp=webp)


如果想要下单的话， 给两条选购建议，一是优先选 64G 版本，虽然贵 100 元，但车载使用中安装导航离线地图和音乐软件后，存储空间会更充裕，不用频繁清理。二是收货时一定要测试供电稳定性，在不同电压下都能正常工作才稳妥，避免行车中出现死机重启的情况。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekdicriaicUu1wBTOhCwI8ib0icf7JTK1LqRM4TGUS5ibfuwFRrz3FOGv1ZwKdAXXY4QFXkELibiaicibAfFw1iaYH3mHIiagjtTyW4FH3Th0k/640?wx_fmt=png&watermark=1&tp=webp)
