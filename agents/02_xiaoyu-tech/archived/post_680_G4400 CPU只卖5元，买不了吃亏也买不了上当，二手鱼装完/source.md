# G4400 CPU只卖5元，买不了吃亏也买不了上当，二手鱼装机淘一个美滋滋

> 原文链接：https://mp.weixin.qq.com/s/5CwWYscVUXk9LravcBQohQ

朕没事就爱刷二手鱼，昨天刷着刷着突然眼睛一亮 —— 英特尔 G4400 处理器，只卖 5 块钱！这价钱应该是买不了吃亏，也买不了上当吧？”


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXG1oS9U6vwRKqVx4f1RUtG1a3luuaWKP791c0iaPDYnpAALN62gxtIhawciaDAe1qMGxW6w43ibCAu9g/640?wx_fmt=png)


先跟你们唠唠这 CPU 的基本情况，这东西100%全是拆机件，市面上压根没全新的，毕竟是 2015 年的老伙计了。但话说回来，5 块钱买个能干活的 CPU，这价格还要啥自行车？就算用坏了也不心疼，总比买个全新的入门级 CPU 划算多了。不过得提前说，拆机件没官方质保，全靠自己的运气，所以买之前一定得让卖家发测试视频，别光图便宜踩坑。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXG1oS9U6vwRKqVx4f1RUtG1hVDh6MMQfvB715z0IyCMkZ5lZ7zkwq6iaUbF2sExSdAtGdjV91OJsPA/640?wx_fmt=png)


再说说它的架构，用的是当年主流的 Skylake 架构，在入门级市场也算小有名气。优势嘛，就是架构成熟，对老主板的兼容性贼好，不像现在的新 CPU，挑主板挑得跟选对象似的，得看接口、看芯片组。但劣势也很明显，毕竟是快十年的老物件了，想拿它玩新游戏、跑设计软件，那真是擀面杖吹火 —— 一窍不通，也就只能对付点轻量活儿，比如开个网页、写个文档啥的。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXG1oS9U6vwRKqVx4f1RUtG1ia2FEq7iahWCET5cRcBstcFlITYaGS2a4tj58QemSazbliaNdLvMsXbWw/640?wx_fmt=png)


核心参数这块儿，它是双核双线程，主频 3.30GHz，还有 3MB 的缓存。别看核心数少，对付日常办公真够用了。我之前帮朋友装老主机用的就是它，他说开 WPS、聊微信、看在线视频，一点不卡，。但要是想同时开十几个网页加视频会议，它就有点力不从心了，毕竟双核跟现在的八核比，差得不是一星半点。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXG1oS9U6vwRKqVx4f1RUtG1V9BJxUsUVPLg6SgTOOe2p2oUJOtML1FzMLsYsVcRgXhspIYiaID0MRw/640?wx_fmt=png)


可能有网友关心CPU容易坏吗？一般来说这东西不容易坏，但也不能把话说死，因为拆机件跟开盲盒似的，全看运气。但我观察了下，大部分卖家都会标注 “测试正常”“稳定运行”，毕竟坏的也没人敢卖。我自己的那片用了10年了没出啥问题，而且 CPU 这玩意儿只要不超频、不摔不磕，一般都挺耐造，翻车概率跟中彩票似的低。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXG1oS9U6vwRKqVx4f1RUtG1YWlq3oXnxITZISwCZyyMptW9f7ahL670to25CBXx7jjKRQwCHz4IdA/640?wx_fmt=png)


如果你想自己装个老爷机，需要选择 LGA1151 接口的主板，它适配 Skylake 平台，比如 H110、B150、Z170 这些。别想着插在 B360、H410 上，根本不兼容。建议买的时候问问卖家有没有配套主板，有时候能一起收，价格还能再砍砍，更划算。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXG1oS9U6vwRKqVx4f1RUtG1gKCc27nBAae6WqibvUc1uJlmrfHSiaEvyHRiaTibE5rU9w6icf98JS3ULuA/640?wx_fmt=png)


说个有意思的，之前我还看到别人把CUP做成钥匙链吗？” 哈哈，这脑洞真是没谁了！理论上可行，CPU 金属壳子结实，穿个孔挂钥匙上还挺个性，回头朋友问 “你这钥匙链啥牌子？”，你说 “英特尔牌 CPU，5 块钱淘的”，多有面儿！就是有点沉，挂久了钥匙串可能会断，还容易刮花，当个摆件还行，当钥匙链还是算了，别到时候钥匙没丢 CPU 丢了，那就得不偿失了。

你们在二手鱼还淘到过啥离谱好东西？比如几块钱的配件、几十块的数码产品，都来评论区说说，让我也学学经验，说不定下次我就照着你们的攻略去捡漏了！
