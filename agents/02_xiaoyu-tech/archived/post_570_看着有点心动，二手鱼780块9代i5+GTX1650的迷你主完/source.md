# 看着有点心动，二手鱼780块9代i5+GTX1650的迷你主机，该不该冲？

今天在二手鱼刷到了一款迷你主机，价格780元，直接给我整破防了——i5-9300H+GTX1650 4G独显，全铝合金机箱，这配置放现在新机里起码三千起步，虽然售价是不包含内存和硬盘，但性能的确是不容小觑，这个价格值不值得冲呢？


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHibAMO6h0I6JjoOiciaX1ViboZPRCseoMD3VYu1pfGiaYwC9Q5P6bITtziaiaovqNwlWMYQm3y9O2wYiccaw/640?wx_fmt=png)


机器是全铝合金机箱，尺寸约26×23×6cm，比A4纸略大一点，放在桌上不占地。成色8.5成新，有些许划痕和使用痕迹，但没磕碰变形，结构完整。金属壳除了结实耐造之外，散热性能也要比塑料的强不少。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHibAMO6h0I6JjoOiciaX1ViboZL7AkLnSGEySygznpyunOibsqGxlWGqxRPlHoP3fo2DAwafEkv1MibpZw/640?wx_fmt=png)


核心配置是i5-9300H（四核八线程，2.4–4.1GHz）+ GTX1650 4G GDDR5。虽然是移动版U，但性能对付日常办公、轻剪辑、玩《CS2》《原神》这类游戏完全够用。GTX1650在1080P中低画质下基本能稳60帧，属于“能玩”级别。对比二手鱼上一堆核显小主机，它直接板载独显，省去了另买显卡的麻烦和兼容风险，这点很实在。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHibAMO6h0I6JjoOiciaX1ViboZicTXTkbnlc1MSo182gXiazKzL400NJiciaQf2qibyfW8SD65KddYKwVOOibg/640?wx_fmt=png)


不过内存和硬盘得自备：支持笔记本DDR4 SO-DIMM（最高32GB），硬盘有两个位置——一个M.2 NVMe，一个2.5寸SATA。电源需另配150W 12V（5.5×2.5mm接口），二手鱼上50块左右能搞定。虽然不算“开箱即用”，但扩展性反而更灵活。只是现在内存和固态价格涨了2–3倍，装机成本比去年高了不少，下手前得算清楚账。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHibAMO6h0I6JjoOiciaX1ViboZRRmGpIMPEGcA9nE9gMYRYMICggoiaNgWAL2fibF4N0VTlrdGdjFBbP8w/640?wx_fmt=png)


接口方面还算丰富：两个HDMI、6个USB（含4个3.0）、千兆网口、音频口，还有个Type-C——但仅支持数据传输，不能视频输出！这点挺坑，想一线通连显示器的用户得绕道。不过考虑到价格，也算情有可原，“瑕不掩瑜”吧。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHibAMO6h0I6JjoOiciaX1ViboZpM2wVAoy3Xg6icL2CtKoVBpUatqRy78UCfGq2ceV7DVPt9clIr5Kqdw/640?wx_fmt=png)


鲁大师实测可以达到55W+？玩《原神》这里游戏是没问题的，但别指望开最高画质。1080P分辨率下，调至中低画质并开启FSR质量档位，平均帧率约55-60帧，基本流畅。如果追求高画质，建议调低特效，特别是阴影质量和抗锯齿选项。不过要注意的是，随着游戏版本更新和地图复杂度增加（比如新出的"层岩巨渊"地图），帧数可能会有所下降，这时候可能需要进一步降低画质设置。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHibAMO6h0I6JjoOiciaX1ViboZG7Pwb6l6sgbOYMiaib8d0PGWRfWbIgBGwNtANzhsdzy33tFmYrTdOP4g/640?wx_fmt=png)


结合当前内存硬盘价格疯涨的现实，给几点建议：

1. 固态和内存先比价，别冲动下单

2. Type-C不能视频输出，别抱幻想

3. CPU焊死不能升级，想好再买

4. 电源务必选足150W，别省那几十块


 


这机器适合预算有限、愿意动手、主要玩网游或办公的用户。如果你图省事或追求高画质3A大作，那还是绕道吧。看完觉得有用？评论区聊聊你捡过最香的二手鱼漏是啥？老规矩，看完不买，立省780元。
