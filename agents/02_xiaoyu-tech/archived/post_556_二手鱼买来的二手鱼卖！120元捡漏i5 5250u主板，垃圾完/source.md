# 二手鱼买来的二手鱼卖！120元捡漏i5 5250u主板，垃圾佬的春天来了？

![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEGlRhDGxMGzNhEnurSsPcia0vkicdJYnkJcibJVYCIkStCpABFE611ia5dbnTJFEWDAmRlH503dNMvfA/640?wx_fmt=png)


我今天在二手鱼里刷到个东西，可能能解决你的烦恼，也可能让你直呼“这都行”。其中一套是飞牛NAS全铝小主机，还有一个是标价120元的主板，主板是卖家之前在二手鱼里淘来的，还附上了订单截图，这次等于是再次售卖。之前我一直以为二手鱼里卖的都是二手货，看来我还是太单纯了，人家卖的不只是二手的，也可能是N手的。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekGpTZnfl2meSRReKv829FszXRq3fyrdMqbRufzZslrIXxch2fSEmNE6Y2YLyYoxXXeZia7pe9bLEmCAibEf7q0qMibowY6VCD2qs/640?wx_fmt=png&from=appmsg)

先别激动，咱们冷静看看货。卖家描述挺实在，搬家清仓，分两件卖。一件是准系统，全铝机箱颜值确实在线，能塞一个3.5寸大硬盘。里面塞着AMD FX7500的处理器，8G内存，一块128G的三星msata固态，还带了双网卡和电源。这一套288元。另一件是个主板，英特尔i5 5250u的，单独120元。打包全带走360，卖家说爽快还送点小配件。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEGlRhDGxMGzNhEnurSsPciaS34TZcbZMibGW5mQ5ia016NialGydebOmskVGIvtjIUpmyxeKN3SvKiamg/640?wx_fmt=png)


核心参数就这些，AMD FX7500，i5 5250u，8G内存，128G固态，这在以前就是就是典型的电子垃圾。但在当下这个机械硬盘和固态硬盘价格都还在高位盘旋的年头，这种老将出马，反而有了点别样的性价比。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEGlRhDGxMGzNhEnurSsPciaias7gf9tUicdicPSAfcGamMpJOIgqwwQJgR3jMuiblvWxDzFXsI6qfiaJSQ/640?wx_fmt=png)


它的优势在哪？第一，价格是真“破防了”。288元甚至120元，对于一台能运行NAS系统的小主机来说，成本几乎可以忽略不计，电费也低。全铝机箱散热和质感比那些塑料玩具强太多。第二，对于只是想弄个局域网文件共享，或者备份手机照片的轻度用户，这性能真的够用了。你不用为那些用不上的高端功能付费。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEGlRhDGxMGzNhEnurSsPciaibniawvJnVJ6Xxr4WMZeHXv8yRLIncYichPzPc0zmh2LOxGqGrGGDofZA/640?wx_fmt=png)


但是，槽点也无比鲜明。卖家写得明明白白：需要自己装系统，不提供任何技术指导，售出不退。这三点，直接把所有怕麻烦、零基础的小白用户拒之门外了。AMD FX7500这U是妥妥的入门级，别指望它同时干很多重活。i5 5250u那套可能稳定性稍好，但同样面临驱动、系统兼容这些折腾事。这就是纯粹的“垃圾佬快乐机”，乐趣在于折腾的过程，而不是即开即用的结果。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEGlRhDGxMGzNhEnurSsPciaqTFJwfMjkxKWovT3I1omOVVqazicfM9cZ9L3A90icsZnYrIqnXDMCFTQ/640?wx_fmt=png&from=appmsg)

所以，给想冲的朋友一点真心建议。如果你预算抠搜到极致，又有一定的动手能力，喜欢研究软路由、黑群晖、飞牛这类系统，那么这个120元的板子或288的套装，绝对是个有趣的玩具，性价比爆表。但如果你想要的是省心、稳定、随取随用的家庭数据中心，那我劝你捂紧钱包，加点预算去看看品牌成品。对于卖家描述的“送内存硬盘”，别抱太大增值期望，就当是锦上添花的小赠品。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEGlRhDGxMGzNhEnurSsPciatv7tncu02w0tds0eZjS1x3HfqdL2icuZrKEFxqABCU4NibGuQ0ZMHI9w/640?wx_fmt=png)
