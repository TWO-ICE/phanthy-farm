# 预算紧张还想上2K大屏？二手鱼里400元的红米27寸了解一下！

![封面图](https://mmbiz.qpic.cn/mmbiz_jpg/E9h3abOJCek18ZoGR00XVmq0zqGkEpbOdPCn8FkUUWdqe9JPUBzGZKpXlamW3VX4RNlM72NDhCia4Wf9vuqibHK5rvFU4QLFr9RSsVAhibboXM/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/YClq4XKAfbol_In3muX0DA

二手鱼里真的有漏可以捡吗？我给大家扒一台最近看 的 Redmi 27寸2K显示器，标价400元。卖家描述里说成色95新，屏幕显示正常无坏点，功能完好，连HDMI线和电源线以及包装盒都齐全，看起来是个人一手自用淘汰的设备，如果有需求， 这个价格 感觉还是挺划算的 。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCek4zRTfura4lqEAdVpGzjPjoSDVFw2mW5UicbFKUt4Tfk2WkhLOpWmpw1S2zJb5ibDMHcSpaOPyMia3hn1Utib7uR9n6sJaKUEMcGo/640?wx_fmt=png&watermark=1&tp=webp)


型号是 红米 的 RMMNT27NQ，应该 是2021年上架的， 当年 同价位27寸显示器大多还停留在1080P的水准。这块IPS硬屏刷新率虽然只有60Hz，但色域覆盖和可视角度都是冲着实用来定制的，300cd/㎡的亮度加上低蓝光护眼认证，日常办公盯着看一天确实没那么容易眼睛酸。三微边设计和7.5mm超薄机身放在当下的审美体系里依然很能打，摆在桌面上丝毫不掉价。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCeksfx9aibiaiaP5tNqKdtA91Av9PxL0k9cfy0n337ub4d0jDibNmAQYLESo8kSZqDZpWGiaR116Qp1UKUA3JFfdY2ZI6ovrZcMxY5DA/640?wx_fmt=png&watermark=1&tp=webp)


写这种显示器最怕商家或者不懂行的瞎吹，但我们做二手内容追求的就是真实。这机器的优缺点非常分明。先看好的地方。400块拿下一台27寸2K的IPS显示器，这个综合性价比在当前二手市场中几乎没有对手。你可以打开二手鱼看下同价位还有啥，多半是24寸1080P的旧机器，甚至是老掉牙的TN面板，观感完全没法比。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenomNpxwLqldLe2aSkJh5aiaV6l4jMyvAaK9sxzOZJo4HPydt1C6RZd9g1vML4lD5CH89agMOzlnZeX1esQ5V3m6m1mXDkCk704/640?wx_fmt=png&watermark=1&tp=webp)


接下来说说槽点，这也是400块定价的逻辑所在。这机器的刷新率只有60Hz。如果你是纯办公族，60Hz完全够用。但如果你是个忠实的FPS射击游戏玩家，用60Hz玩CS或者使命召唤，那流畅度真的没法跟高刷比。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCek9H88Mk6WFad0IcticKty9r7IP0SnEKvdjAPVtxHZIiby1G2libYRdGSG85Kde36j2In4qPokUjckGRlwibNmLC6xficGqWTVpj2lE/640?wx_fmt=png&watermark=1&tp=webp)


如果你是为了打游戏买个守门机器，不如把预算加到五六百元档去收AOC的高刷款，或者加几百去收一台二手的红米G27Q电竞款。另外这机器的接口虽然够用但不够新，HDMI是1.4版本的，意味着只能跑到2K 60Hz的信号上限，接PS5或者XSX也没法开启更高刷新率的输入。VGA接口更是纯粹的显示器遗产，对现代苹果M芯片或新装的高性能PC用户来说就是个摆设。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenibbySlBGeeAxbsicYcOQV5RbvysYv8P99ebl30iaMziblMQicaeaCc7ichFLqcicVAKIgI1DaZvUNu23UepQiaevCzNhBJftziaqMKvsw/640?wx_fmt=png&watermark=1&tp=webp)


另外，红米显示器的品控一直中规中矩，虽然卖家说外观95新、屏幕无坏点，但二手屏最怕暗病，比如轻微漏光、接口接触不良，这些卖家可能不会主动提及。而且现在二手鱼里不乏老六，故意隐瞒屏幕问题，一不小心就成了接盘侠。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCeloicRR2boaZ7PBa74Ke2nxNw9yTRKu9W0gickQWks0Ib8SJBtpdtsnib3gBjOET0QevWfV5wibUPWoWquSfESWxuA8RkYGkzLebuw/640?wx_fmt=png&watermark=1&tp=webp)


要是想入手，一定要让卖家拍全屏纯色测试视频，重点看白、黑、红、绿、蓝五种颜色，检查有没有坏点、亮点和漏光。还要让卖家拍接口测试视频，确保HDMI和VGA接口都能正常使用，避免收到货后出现接口失灵的情况。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelsGAX2MeQFP7moHCfaU2lMBh3PGbODCP1JyKMFPz8LicmI1vIgdSgkCnWXm8473TXKBkmEWYzxYPlleWX7J6MtNFHUpJhvUict8/640?wx_fmt=png&watermark=1&tp=webp)
