# 这才是DIY的乐趣！58元的墨水屏日历，能当冰箱贴+电子相册？

前两天在闲鱼上“冲浪”挖宝，本来是想淘个便宜的数码配件，结果硬是被一款只要58块钱的DIY墨水屏日历给“硬控”了。

这玩意儿看着不起眼，其实就是个裸露着电路板的小方块，但细琢磨一下，它简直就是现在这种充满焦虑的互联网时代里的一股清流。价格定在58元这个档位，说实话，在这个动不动就搞“消费升级”的年代，算是相当接地气了。虽然便宜，但博主并没有在功能上疯狂阉割：时钟、日历、待办事项，甚至还塞进了一个电子相册的功能，实现了经典的“三合一”。

要搞懂这玩意儿为什么能火，咱们得先扒开它的皮囊看看骨头。驱动这小东西的是一颗DA14585芯片，懂行的朋友一听就知道，这可是Dialog（现已被Renesas收购）家的超低功耗蓝牙芯片，主打的就是一个“省电”。配合一颗1100毫安时的电池，这续航能力直接起飞，跟那些一天一充的智能手表完全不是一个维度的生物。

更绝的是它的配件逻辑：居然给配了个支架，还内置了三颗强磁铁。这意味着什么？意味着它既可以是摆在桌上、给你增加一点点赛博朋克氛围感的桌搭神器，也能“啪”的一下吸在冰箱门上，瞬间变身成厨房里的生活小助手。你想啊，做饭的时候随手看一眼时间，或者把菜谱传上去显示，这比用手机去翻那些油腻腻的菜谱APP要优雅太多了。

说实话，这类小众DIY电子产品，并不是什么新鲜物种。

早在四五年前，这种墨水屏日历在极客圈和Geek圈子里就火过一阵子。那时候大家都想摆脱手机的控制，于是各种墨水屏、单色屏的项目层出不穷。但那时候的坑位太高了，一个成品的墨水屏日历，在众筹网站上动辄就要三四百块；哪怕你不想买成品，想自己动手，光是去买那个4.2寸的墨水屏模组，可能就要掏出去一百多大洋。

为什么现在58块钱就能买到？这背后的逻辑其实是典型的“技术贬值+供应链溢出”。

随着电子制造业的快速迭代，工厂淘汰下来的旧方案、洋垃圾里拆出来的元器件大量流入市场，再加上闲鱼上总有那么一批“三分钟热度”的手工党——买了一堆零件，焊了两个电容，突然不想做了，于是只能含泪清仓。这种“半成品”或“元器件包”的甩货，直接把市场价格打了下来。58元虽然可能不是全网地板价，但在这个“只要自己动手，就能省下几百块”的逻辑下，它的性价比可以说是直接拉满了。

当然，咱们也得聊聊这种纯DIY产品的“B面”。

既然是手工DIY，或者是小作坊出来的东西，你就不能指望它有苹果那种工业模具的精致感。大部分外壳是用3D打印出来的，如果是FDM工艺打印，你甚至能在侧面上看到那一层一层的纹理，接缝处有点毛刺或者公差也是常有的事。

至于品控，那更是玄学。卖家是良心卖家，还是焊盘都快冷焊了才发货的糊弄学大师，全凭运气。如果你是那种连手机膜都要贴得和听筒完全对齐、强迫症晚期患者，看见一点点瑕疵都要抓心挠肝的朋友，那我劝你“慎拍”。这玩意儿不仅是买产品，更是在买一种“不完美的美学”。

但反过来想，58块钱，在今天可能也就够吃两顿稍微好点的外卖，或者买两杯星巴克。用这点钱，换个能让你在那儿折腾一下午、刷机、换图、甚至自己改代码的小玩意儿，这种可玩性带来的情绪价值，其实是远超商品本身价格的。这就是DIY的乐趣——你参与了这个东西的生命周期，而不只是个单纯的消费者。

更宏观一点看，现在的二手硬件市场其实挺割裂的。

你去看看，传统的存储和显示类二手产品，价格都在回涨。eMMC闪存芯片、TFT液晶屏，甚至那些老掉牙的Kindle阅读器，最近都有被炒起来的趋势。大家都在囤货，都在炒情怀，唯独这种冷门的、需要点动手能力的DIY套件，还在加速清仓，仿佛在抵御消费主义的围剿。

为什么会这样？因为在大众眼里，这东西“不实用”。

大众需要的是什么？是能刷抖音的超大屏，是能打高帧率游戏的显卡。而对我们这些喜欢桌面美学、厌倦了蓝光轰炸的人来说，这个被大众嫌弃的“废物”，恰恰是最温柔的存在。

它没有背光，没有刺眼的LED白光，也没有60Hz甚至120Hz刷新率带来的视觉残留和焦虑感。它就像一张真实的纸，静静地待在那里。你想知道日期？扫一眼。想看天气？扫一眼。它不会给你推送红点通知，不会打断你的工作流，也不会在半夜亮起屏幕打扰你的睡眠。这种“低科技”带来的“高逼格”，在全是RGB灯效的桌面上，简直就是一股泥石流。

而且，这玩意儿的可玩性确实强过一般的成品相框。

咱们可以随便找张喜欢的照片，黑白灰阶的照片传上去，那种颗粒感和复古胶片的味道一下就出来了。把它放在办公桌角落，时不时瞄一眼，比那些花里胡哨、光污染严重的RGB灯带要耐看一万倍。

还有那个磁吸设计，真的要吹爆。它让这个设备打破了“桌面”的物理限制。你可以把它吸在厨房的冰箱上看菜谱，毕竟墨水屏不怕油烟，也不像手机屏幕那样沾了指纹就脏得要死；你也可以把它吸在床头柜上，当作明天的行程提醒。这种灵活性，是那些插着电线的笨笨显示器没法比的。

所以，最后想和大家探讨一下：在这个万物皆可智能的时代，你会为这样一个小而美的、功能可能有点原始的数码手作物买单吗？还是觉得它完全不如一个手机屏来得实用？

或者，在你的想象中，理想的桌面信息屏应该长什么样？是极客风的墨水屏，还是全面屏的小彩电？欢迎在评论区咱们好好聊聊。
