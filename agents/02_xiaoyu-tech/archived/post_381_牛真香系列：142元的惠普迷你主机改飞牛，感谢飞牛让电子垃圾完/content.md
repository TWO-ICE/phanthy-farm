# 牛真香系列：142元的惠普迷你主机改飞牛，感谢飞牛让电子垃圾复活

咱们数码圈里有一句名言：“电子垃圾不分贵贱，用得好了就是传家宝。”

作为一个常年混迹于闲鱼二手市场的“捡垃圾”资深选手，我的日常就是在这个庞大的电子废品回收站里淘金。说实话，好东西总是稍纵即逝，往往眼疾手快的大佬们早就把像样的成色扫荡一空了。但就在前几天，一个极其不起眼的 listing 瞄进了我的视线——惠普 Q150 迷你主机，标价 142 元，而且是准系统（不含硬盘内存的裸机）。

看到这个数字的瞬间，我的多巴胺分泌瞬间拉满，这简直就是“瞌睡来了有人递枕头”。作为一个一直想搞个飞牛 NAS（FnOS）但又不想在硬件上投入太多成本的“极简主义懒人”，这玩意儿简直是为我量身定做的。142 元买个大品牌的迷你主机，这性价比，还要什么自行车？

咱们得先扒一扒这小东西的底细，看看它到底能不能担得起“NAS 极佳性价比方案”这个大任。

这货的核心心脏是一颗赛扬 2955U 处理器。如果咱们把时光机倒回 2013 年，这颗芯片还是有些含金量的。它基于 Haswell 架构，22nm 制程工艺，当年的主打卖点就是低功耗和够用的性能，主要用于企业和教育市场的瘦客户机。虽然它没有睿频加速，主频只有 1.4GHz，双核双线程的规格在如今动不动就 16 核 32 线程的跑分软件面前只能算是个“弟弟”。

但是，咱们得辩证地看问题。捡垃圾的乐趣不就在于“够用就好”吗？对于咱们这种只想存点家庭照片、挂个 PT 下载、偶尔通过 Jellyfin 看个 1080P 电影的低需求用户来说，这颗 CPU 的性能不仅“刚刚好”，而且其低功耗的特性简直是 NAS 的绝配。别忘了，这可是 Intel 的正统架构，比那些烂大街的 ARM 开发板在指令集兼容性上强太多了，跑 Docker 或者折腾点服务端软件完全没有压力。

接下来聊聊这台机器的“软肋”，也是很多人纠结的地方：内存和存储。

原厂配置通常是 4G DDR3 内存加上 16G 的固态硬盘。这配置放到现在，确实有点“小马拉大车”的尴尬。16G 的固态，光是装个原版的 Chrome OS 都快塞满了，更别提咱们还要刷入飞牛 OS。不过，这就是“准系统”的魅力——你可以低成本魔改。

但是这里有个坑得提醒大家，这主板的内存槽只有一个，也就是说你不能像普通台式机那样插两根组双通道。想升级？只能买一根大容量的 DDR3L 笔记本内存换上去。好在现在 DDR3 内存白菜价，几十块就能搞到 8G 甚至 16G。至于硬盘，SATA 接口随便买个 120G 或者 256G 的二手 SSD 就能起飞。虽然前期需要加个百来块的预算，但总比直接买动辄上千的成品 NAS 要香太多了。这就像买了套毛坯房，虽然得自己装修，但省下来的房贷利息足够你买全套进口家电了。

让我感到最惊喜的，反而是这台机器的物理设计。

惠普 Q150 的机身尺寸只有 125*125*30mm，这什么概念？比成人的手掌大不了多少，大概就是两包香烟叠在一起的厚度。这意味着你可以极其隐蔽地把它塞进电视柜的缝隙、书架的角落，甚至是直接用双面胶贴在路由器旁边。对于不想让家里到处都是电线和机箱的“极简风”家庭来说，这种体积简直是完美的。

更夸张的是接口的丰富程度。你以为这小机器会砍掉接口？错！它居然给了一个千兆有线网口，这对于 NAS 来说是“生命线”，意味着内网传输速度能跑满 125MB/s 的理论带宽，远比那些只有百兆网口或者只能靠 WiFi 传输的垃圾盒子强一万倍。除此之外，它还自带 WiFi 和蓝牙模块，省去了你插 USB 网卡或者蓝牙适配器的麻烦。

视频输出方面，HDMI 和 DP 双接口，让你不仅能把它当 NAS，还能把它连上家里闲置的显示器当个下载机甚至副屏机用。虽然 4 个 USB 2.0 接口在传大文件时速度感人，但在 NAS 的使用场景下，这些 USB 口足够你接个 UPS 不间断电源、或者偶尔插个 U 盘导入数据了。这就是典型的“鱼与熊掌不可兼得”，在这个价位下，我们要的是千兆网口这个核心，USB 速度慢点就当它不存在吧。

说到这儿，肯定有环保卫士要关心电费问题。

这台机器原配的是一颗 45W 的电源适配器，但这只是上限。实际上，赛扬 2955U 的 TDP（热设计功耗）仅为 15W。这是什么概念？比那种动辄 100W 的台式机显卡省电太多了，甚至比你家那个高性能的路由器还要省电。NAS 的特性就是 24 小时挂机，如果功耗太大，一年的电费都能买半个主机了。但这台小主机，即便挂一个月，电费可能也就几块钱，完全可以忽略不计。这就是老旧低功耗架构在现代 NAS 场景下的独特优势——它的存在感极低，既不占空间，也不费电。

这时候又有人要抬杠了：“赛扬这么弱鸡，刷飞牛 OS 会不会卡成 PPT？”

这里我要为飞牛 OS 说句公道话，顺便科普一下。飞牛 OS 本身就是基于 Linux 定制的轻量级 NAS 系统，它根本不需要你有什么强大的 3D 性能，更不会像 Windows 那样后台全是冗余进程。NAS 追求的是稳定的 I/O 吞吐和文件管理能力。对于双核四线程的处理器来说，处理 Samba 文件共享、FTP 传输、BT 下载这些基础任务，简直是杀鸡用牛刀。实测下来，用它播放本地的高码率 1080P 电影，CPU 占用率甚至都很难爆满。所以，别用跑 Windows 的思维来衡量运行 Linux 的 NAS，这完全是两个维度的东西。

还有一个好消息是刷机的门槛。

这机器当年是作为 Chrome OS 设备出厂的，咱们都知道那个系统在国内没法用。但是，技术圈的极客们早就把它摸透了。现在网上有非常成熟的刷写 BIOS 教程，甚至很多闲鱼卖家都贴心地帮你把 BIOS 刷好了，解除了 Boot Guard，开启了 Legacy 启动模式。你买到手，只需要拿个 U 盘做个 PE 启动盘，或者直接用 Ventoy 装个飞牛 OS 的镜像，全程就像装普通 Windows 一样点点鼠标。这对新手来说，最大的障碍已经被清除了，剩下的就是享受折腾的乐趣。

咱们来总结一下这波操作。

142 元的投入，换来一个支持千兆网络、体积小巧、功耗极低、性能尚可的品牌主机（再算上升级内存硬盘的 100-200 元，总成本也就 300 元上下）。它没有花哨的 LCD 屏幕，没有那种动辄 5 盘位的高大上外观，但它完美解决了“低成本数据存储”的核心痛点。

它非常适合预算有限的学生党、刚入门想试试 NAS 水深浅的极客，或者单纯想给家里老照片找个归宿的普通人。在这个消费主义盛行的年代，能花 142 元复活一台 2013 年的设备，让它继续在自己的岗位上发光发热，这本身不就是一种浪漫吗？

如果你也在二手平台蹲守，不妨多关注一下这类老牌的迷你主机（比如戴尔 3050、联想 Q150 等）。虽然它们是别人眼里的“电子垃圾”，但在懂行的人手里，那就是通往数字自由的钥匙。

至于问我还要不要买？老规矩，看完不买，立省 142 元，虽然我觉得这钱是真省不下来，毕竟——它真挺香的。
