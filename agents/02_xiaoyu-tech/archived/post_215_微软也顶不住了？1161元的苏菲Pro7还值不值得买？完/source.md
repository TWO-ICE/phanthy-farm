# 微软也顶不住了？1161元的苏菲Pro7还值不值得买？

![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelaicrFYpzXFD22rWdN84pMVZpU5UtdRhrp1icmORMWBb3ia77ia2eicztB8kMJTNKvOfNfl6icHHeFwmjlU1XXBUIQl640U8oZswYmQ/640?wx_fmt=png)


二手鱼上有人挂出一台Surface Pro7，95新，标价1161元。卖家描述无磕碰，细微划痕，轻微使用痕迹，屏幕触控完美。i5-1035G4处理器，8G内存，128G硬盘，电池健康度92%，支持Type-C快充。还特意注明标价单主机，键盘充电器要私聊另算。看的我有点心动，这个价，到底能不能冲？


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelu8oiaQSQE3VK41OgDicH6JdT0LljYiaEJPuYh0XWNeWPJwWf6HvXSHwTsxFuBicWqLyobialLbcCiazDE5bRCoSUwjsrNZCzyTJiaGI/640?wx_fmt=png)


我看了一下鲁大妈给的参数信息，i5-1035G4处理器，8GB内存，128GB固态，12.3英寸LG屏，支持WiFi 5和蓝牙。电池健康度92%，苏菲的这套组合算不上猛，但也不算电子垃圾，对于办公或家用来说，还是有用武之地的。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekibJVanXcSSyAfWnsUQ9MkoKoiaZEI7aVJTvUzNr89OYPyKHiaVLbpHDs2dRic6IVdNSe6FOhaMObLG03rb4xzZsIGhibOHsTgGetQ/640?wx_fmt=png)


我先说一下优点，这块屏幕素质很高。12.3英寸3:2比例，分辨率2736x1824，看文档比16:9的笔记本舒服太多，竖起来刷网页接近A4纸的感觉。机身做工也挺扎实。镁合金外壳，无风扇设计，拿在手里很整洁，没有廉价塑料的咯吱声。另外还支持Type-C快充和SD卡扩展。128G硬盘不够用插一张256G的SD卡，存电影和照片绰绰有余。而且它是Windows系统，能跑exe软件。这一点是iPad和安卓平板永远做不到的，你装个老版Photoshop、CAD看图、甚至轻量编程都没问题。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelujbmt7ELpA7LibdrVPib2zGp4vIs2TQvbNicgkPmXPgh7PktVnqhCNiaQibBPAI3P4HuuRInOia5t68PlM8awV1O1O3icJdI1yXlDDA/640?wx_fmt=png)


再说一下缺点，这个i5-1035G4虽然是四核，但性能大概相当于桌面级的i3-7100，性能一般，而且8GB内存容易吃紧。硬盘128G装完系统和常用软件，剩个七八十G，存不了几个大文件。而且Surface Pro7的固态是BGA封装，无法更换，你买回来就得做好容量焦虑的准备。另外，这个英特尔AVStream Camera显卡显存只有128MB，别指望它打游戏，它适合的就是轻办公、写写稿子、看看HDR视频。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelKSYn3jQjyVqjbib4sXKa5zic99AaLS20ibMtDPgtxDuhicI0689gWRZS1UgiahWA64DzDUvtF6Oib6q9miaLGBWb6kcBaPn2Nx9XBBk/640?wx_fmt=png)


如果你买来当主力机用，一定要慎重。8+128用来处理工作流，可能体验不是那么顺畅。但如果你正好缺一台备用机，放在床头追剧、出差时改个PPT、给孩子上网课，那这个价格很香。尤其是你已经有主力台式机或笔记本，只需要一个轻便的第二屏，这台Pro7比任何安卓平板都实用。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCeketMuMYpcPicBf50n928ZuicniaLvbCMDBRctib9c8vjicEvPET8Mibmf9WRy82iaJCJWic4siatpOSlnIBias8ib8QRiase6icb82czuhpyyc/640?wx_fmt=png)


另外原装苏菲键盘二手价在100左右，充电器也要几十块。卖家说需要私聊，也就意味着需要加钱，而且再加上运费到付，实际到手成本可能接近1300元。这个价格你要考虑清楚。另外建议到手后第一时间用电池检测软件跑两遍，92%的健康度如果是真实数据，正常用三年没问题。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenibU8K0w7pl61COgpCRemWRiaKGwzPnXkaf4gqjasric0OKw01t0mJkqxWngKicZ3Z69gWicLngDWKmicC2yabk5IUXN9mEpsQdZk2Q/640?wx_fmt=png)


最后说一句，微软的Surface系列一直被称为“贵族玩具”，当年顶配的苏菲Pro7首发价上万，如今沦落到千元机，不是因为它烂，而是因为英特尔10代低压U确实老了。但1161元买一台屏幕好、系统自由、做工精致的二合一，放在当前的二手市场里，它依然是一个值得放进购物车的选项。
