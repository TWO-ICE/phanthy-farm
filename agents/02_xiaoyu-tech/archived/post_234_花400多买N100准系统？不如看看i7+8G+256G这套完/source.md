# 花400多买N100准系统？不如看看i7+8G+256G这套配置值不值？

![封面图](https://mmbiz.qpic.cn/mmbiz_jpg/E9h3abOJCenfrfBoufMJicORqT31icPfvVDVcr1RbXWky3JUl3Us2Xz4SyCcYPAf1Oq5qMOVCoELu8TMdjPCoYuVl1Iy8eFD1l2LiaKWse4L5I/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/4oYSmFMVQJ_sXvX5-gYTKA

二手鱼里看到一台飞牛nuc小主机，配置是i7+8g+256g，标价405元。带无线wifi和千兆有线网卡，家用办公客厅台式mini小主机都合适，还能当工控机软路由htpc nas，上网课炒股办公都可以。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemZh4UgAwDIicDibXeQ8cyrk62LoIdQwT5Mt7AvIa91mkc2pavXz3Kzunypjjahrm4I5x81A2WshqPt6wV3oXxesQialia03ZmxaWg/640?wx_fmt=png&watermark=1&tp=webp)


CPU用的是酷睿i7 4500U，板U一体的设计，最大功耗15瓦，日常用也就5瓦左右。这颗U虽然老，但支持AES指令、硬件直通和虚拟化技术，性能比J4125、N4100、J3160那些赛扬低压U强出一截。卖家描述里提到能当软路由、HTPC、NAS，这方向确实没跑偏。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenkQU7HKPntowJibSPOtzgTygVr8vxegLmzFFJ7TLZiaFcNQj2yTpE9Xb9H8mYNcobqUmRUfxe6HJgRj5AjdfBaR1jxkwtbKh0lQ/640?wx_fmt=png&watermark=1&tp=webp)


尺寸只有12.5厘米见方，比成人手掌大不了多少。接口给得挺全：四个USB3.0、两个USB2.0、一个HDMI、一个VGA、一个千兆网口，还有音频输入输出。主板上有DDR3内存插槽，仅支持笔记本低压条，一个msata硬盘口，还有一个可以接2.5寸SATA硬盘的接口。扩展性在这个体积里算良心了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelhtWfrjCoZtbiaffO3xTwUKiaOCkUQwiaqWpia5hYSAPsCTkTicRs2gqicvZWbzlfRykU0CMd6H3osXxaB8AeYgRdpERovSuk1xymkk/640?wx_fmt=png&watermark=1&tp=webp)


优点 是 功耗真的低，7x24小时开着当下载机或者家庭服务器，电费几乎忽略不计。 而且还 支持VT-D和VT-X，拿来玩虚拟机或者软路由非常合适，这比很多同价位的工控机强。 另外 体积 很 小，塞在弱电箱或者显示器后面完全不占地。405元的价格包含内存和硬盘，到手装个系统就能用，省去自己淘配件的时间。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemnvjnxicU9yLZbsWmNjOibj8neNXl1wfnodMmmdSYPQYkMH5qoAnLoRW8UxTOQbONLb2GDBRiat48icVeqyvqicwzicTHEBVyV5HRib0/640?wx_fmt=png&watermark=1&tp=webp)


槽点 当然也有， DDR3内存插槽只有一个，意味着没法组双通道，而且内存频率上限低。msata接口现在有点过时，好硬盘不好找，SATA接口倒是能接2.5寸盘，但得自己配线和支架。千兆网口只有一个，想做链路聚合或者软路由主路由的话，单网口是个硬伤。另外i7 4500U虽然标着i7，但毕竟是第四代架构，单核性能放到现在只能说够用，别指望它能跑什么重型编译或者多开虚拟机。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemzFEPexibNcZEC11kscbTWGrgNFG8gOaicQ3ugrCnrfBRPdh5WoibATtc9PZvaZb1Wq7qDKqqvwEtwa8KWd0zoun1Fiakviaho75WE/640?wx_fmt=png&watermark=1&tp=webp)


跟二手鱼里同价位的产品比，405元这个区间，你能买到J4125的小主机裸机，不带内存硬盘，或者买到N5105的准系统但品相一般。这台飞牛NUC送了8G内存和256G硬盘，算下来主机本身也就三百出头。对比那些五六百块的N100小主机，性能肯定比不过，但价格直接腰斩。如果你只是需要一台轻度办公、上网课、当下载机或者跑个轻量NAS，这台完全够用。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemepLuzBCzjdfxMSmYicwjxoIeYSlJEk1SSuAj6fl1WZEDQMiclScnU2ibmOpTwYUWSADg5q9jrjwH3K6XiaaRQFo0GE56WmSqydJU/640?wx_fmt=png&watermark=1&tp=webp)


如果想入手的话，收到后 建议跑个MemTest和硬盘健康检测，有问题及时沟通。如果你打算长期当NAS或者软路由用，买个USB转千兆网口做扩展，单网口做旁路由还行，做主路由确实有点憋屈。另外注意散热，这种小机身主动风扇噪音不大，但夏天长时间高负载可能会热，放通风位置就好。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenBumhTQFe4Pdnb1JgoPgG3VIGwibIQVVcUVRkgypAibw6jMA7iaSnYjeJp12dapYd1wt4oicVPXOVf1kgMEkNZweib5lnibvGIicE4yc/640?wx_fmt=png&watermark=1&tp=webp)


这台小机器的定位很清晰，不是给追求性能的人准备的，而是给那些想低成本体验软路由、NAS、虚拟机，或者家里缺个不关机的低功耗主机的朋友。当年i7 4500U的机器怎么也得四五千，如今405元就能抱回家，残值基本跌到地板价了。你会花405块买这台老古董当玩具吗？或者你有更划算的捡漏经历？评论区聊聊。
