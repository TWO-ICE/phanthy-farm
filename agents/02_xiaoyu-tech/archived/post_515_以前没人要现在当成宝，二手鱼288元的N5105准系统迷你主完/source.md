# 以前没人要现在当成宝，二手鱼288元的N5105准系统迷你主机，是捡漏还是坑？

今天在二手鱼刷到了一款标价288元的N5105主机，标题写得挺直白：“N5105主机 小电脑 迷你电脑 低功耗”，还特意标注了“支持飞牛”“x86架构”“HTPC”。老实说这，这个价格，在如今存储价格飞涨的背景下，确实有点抓人眼球，忍不住点进去琢磨了半天。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGzL4qLAnibjvia2mpQXqhw0xGJrtSYcpuWBEQPFicOV2gFoKLVcvFuaFIeYo6KB7UEAWT4N72XH9fKg/640?wx_fmt=png)


这款机器用的是英特尔赛扬N5105处理器，10nm工艺，4核4线程，基础频率2.0GHz，睿频最高2.9GHz。核显是UHD Graphics 24EU，支持4K60Hz硬解，对H.265/VP9等主流编码都有不错的硬件解码能力。对于轻量NAS、软路由、HTPC或者刷飞牛这类轻量虚拟化场景来说，性能勉强够用。不过要注意，它只有一个DDR4笔记本内存插槽，最大支持16GB（部分主板可能限制为8GB），而且内存和硬盘都需要自备——卖家明确写了“无内存无硬盘”。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGzL4qLAnibjvia2mpQXqhw0xWZrCGgbGuFdOaNWqXribUhbThtzDibvr2KYIev3A9bslbW1p0ic8GjV7g/640?wx_fmt=png)


整机尺寸约15.6×15×7.8厘米，重量1.8公斤，全金属外壳，被动散热设计，意味着运行时完全静音，但也限制了长时间高负载下的稳定性。接口方面，除了一个千兆网口、一个M.2 NVMe插槽外，供电采用12V Type-C，支持PD供电，这点对桌面整洁党比较友好。机器还能进BIOS，说明没有锁启动项，刷系统自由度较高。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGzL4qLAnibjvia2mpQXqhw0x3EnFLiahNP8UEWmrf55iaO3pjNnuo3BZ2WWOKOmTnWazJC3hGMGKhPSQ/640?wx_fmt=png)


不过问题也摆在明面上：288元只是裸机价格，不含内存和硬盘。按2025年底的行情，一条8GB DDR4笔记本内存至少要200元出头，一块256GB NVMe固态也要150元左右。加起来整套成本轻松突破600元。如果你手头刚好有闲置配件，那确实划算；如果从零配起，性价比就大打折扣了。尤其现在存储价格暴涨，DRAM同比涨幅超170%，这时候买裸机反而可能被“配件税”反杀。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGzL4qLAnibjvia2mpQXqhw0xD1BVibjXRQ6FR2KCc1hKXXB18QyKZ6lPoy7WibUYvhMEz0llWNfylEQg/640?wx_fmt=png)


可能有人会问这机器能刷飞牛吗？N5105是x86架构，飞牛官方镜像支持良好，加上千兆网口和低功耗特性，拿来跑Docker、轻量虚拟机或作为家庭媒体中心完全可行。但别指望它扛住多路转码或高强度下载任务——毕竟只有4核且TDP仅10W。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGzL4qLAnibjvia2mpQXqhw0xebvQrcIFJvAt1I7baIthRpzF9icDicyib2PMKbPTC8aZTibCicy4ic5H47Zg/640?wx_fmt=png)


那么值不值得买？关键看你有没有现成的内存和SSD。如果有，288元拿下一台全金属、被动散热、支持4K输出的小主机，用来做HTPC、轻NAS或开发测试机，算得上小捡漏。如果没有，光配件就得花掉三四百，整体体验可能还不如加点钱买台二手i5小主机。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGzL4qLAnibjvia2mpQXqhw0x4fMn8QRw6cjXBJRPrdOdkDXWnq2rSaMLU4c8ggKJzLGTakCQYWaw0A/640?wx_fmt=png)


对此产品有兴趣的话，可以在二手鱼搜索“N5105主机”这个关键字就可以找到此产品，如果找不到可以通过图片进行搜索，都搜索不到的话，那可能是此产品已卖出或者是下架了。


 


以下是个人一些掺了水的建议：

1. 手头有内存硬盘再考虑入手。

2. 别指望它当主力机，定位要清晰。

3. 配件成本已超主机，算总账再下单。

4. 看完不买，立省288元。
