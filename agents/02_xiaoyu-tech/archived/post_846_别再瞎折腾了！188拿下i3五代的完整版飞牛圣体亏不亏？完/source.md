# 别再瞎折腾了！188拿下i3五代的完整版飞牛圣体亏不亏？

![封面图](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXHGibBSsiawYXOjOwIibwPCnBtNPLU1ibUEcUea6hfhqtdiaSgkNzbV4FEtiaXXR27pqB5yOVicPe4Rm1frw/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/vrQM_J1L_Hur2r8XuzMI7A

今天刷到个完整版的飞牛圣体，看得我直挠头，标价188元还包邮的i3-5010U迷你主机。一顿外卖钱，就能买台电脑？这到底是电子垃圾还是性价比神机？我琢磨了半天，觉得这事儿值得唠一唠。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHGibBSsiawYXOjOwIibwPCnBtL2TYSCr4JBqERdZMxDcRdRQ6pRUJ7dM4pUMehEluE0C1mrnnGXrApA/640?wx_fmt=png)


先看卖家描述，擎联云终端，巴掌大小。核心是i3-5010U，五代酷睿的双核四线程，搭配4G DDR3内存和128G固态。集成HD5000显卡，接口给了VGA和HDMI，系统预装Win7。成色几乎全新，功能正常，还带电源。说白了，这就是一台内存硬盘齐全的完整版的主机，到手插电就能用。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHGibBSsiawYXOjOwIibwPCnBtndnKP1aa5iaHCgyKb7yxI22nibp5GLagibXMITfpOwBHI4D5oFHaiagiaDA/640?wx_fmt=png)


它的优势，明晃晃就两个字，便宜。188元包邮，体积是最大亮点，真就巴掌大，不占地方。功耗极低，安静无声，摆在哪都行。拿来干点啥呢？我觉得它最清晰的定位，就是一台纯粹的“显示设备驱动终端”。比如，插在客厅老电视或者显示器后面，专门用来播放本地4K视频，或者刷成飞牛系统，当个下载机，24小时开着也不心疼电费。当成一个打印服务器或者简单的监控录像存储端，也勉强够用。某种意义上，它完成了从“电脑”到“家电”的蜕变。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHGibBSsiawYXOjOwIibwPCnBt9UCx0buMVqQk3hZOVe2Pp93bgOJyf5440Wicjg0Es6Fgjhl0LIoYmkQ/640?wx_fmt=png)


它的劣势和风险，同样突出。首先，性能是硬伤。i3-5010U应对任何稍微需要点算力的任务都会很吃力，比如你想同时开几个网页再加个微信，可能就会卡顿。4G内存是致命短板，win7系统本身就要占去不少，几乎告别多任务。128G固态，装完系统也就剩那么点，现在的软件体积你懂的。但是你要是把它刷成飞牛系统，或者是当个下载机，以上的劣势瞬间消失。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHGibBSsiawYXOjOwIibwPCnBtOf3ibt9fO0LpJjbc8ib059Wxyiccj8ur1wicZDqrM6kV0QCge8dOGRDdxw/640?wx_fmt=png)


如果你是一个清晰的“垃圾佬”，明确知道自己要拿它来完成某个单一、轻量的任务，并且有基本的排查故障能力，那188元买来玩玩，亏也亏不到哪去，甚至会觉得真值。但如果你是个电脑小白，期待它是一台“全能小主机”，能流畅办公、能娱乐，那我劝你赶紧划走，这绝对会是你痛苦的开始。加几百预算，市场上会有更靠谱的老款迷你主机可选。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHGibBSsiawYXOjOwIibwPCnBtRicltiacgEka8DlywTqibnAF8QuC06gQgU3KertzbRSeia7gW4fC9IIm2g/640?wx_fmt=png)


如果是你，你会用这188元，去赌一个这样功能局限的迷你主机，还是宁愿再加点预算，寻找更均衡的老款呢？或者，你手里有没有类似的“电子牛马”还在服役？评论区聊聊你的想法吧，让我看看二手鱼里到底藏了多少大神。
