# 买N100预算不足？不如看看N95的AOC小苔藓，最少能省100块

在二手鱼里看到一台AOC小苔藓M3迷你主机，卖家标价400元，不带内存和硬盘，说是华硕品质，平时很少用成色挺好，全套配件都在，还包邮 。 说实话400块的N95主机并不算捡漏价，但是卖家写了价格可聊，这就给了我们发挥的空间，这款主机如果能砍到350元以下，我觉得还是可以考虑一下的。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekdXOicHw8FaFAFgrfhqQTmleNls2cPGoYiadrk8KhTcohxvE2SV4ua3y7AF7ia0FhlVU88mtTasibDWNqjQAVyJtS2sC1slGN7cSs/640?wx_fmt=png&watermark=1&tp=webp)


先看看 主机配置，处理器是赛扬N95，睿频3.4GHz，UHD核显，支持DDR4内存，双存储位可插m.2和sata固态硬盘，接口方面HDMI VGA USB网口齐全，支持壁挂安装。对比同价位拼装N95工业版，这台AOC小苔藓的稳定性和散热确实是卖点，卖家强调的不吵这点在迷你主机里很重要。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelU0I2MrCYYgJGfLDqFWPqISBl2fQl6l9yUr2tUxicv8UPEx7J09e9oUORE5MCeqvw8eb4QOV5XlzPFcdoS6FJMgcAVnYuIxEAk/640?wx_fmt=png&watermark=1&tp=webp)


和N100主机比起来 N95 的准系统价格比N100便宜不少，现在二手鱼里N100准系统普遍500元以上，全新更是要600多。而且接口更全，VGA接口对老显示器用户友好，双存储位扩展灵活，AOC的做工比很多杂牌N100更靠谱。当然劣势也突出，N95是16EU核显比N100的24EU弱，性能上限低一些，多任务处理和轻度娱乐能力稍逊，功耗控制也不如N100的6W TDP。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemic71dU1VkrDCWeDxUdJCjsLsGh7cVPduuP50qQj3uSyyuhlHjOoeQtXtE24Hm6EGNeRH4UhyYBXWTGZFT00hjAISqtOmChh4E/640?wx_fmt=png&watermark=1&tp=webp)


如果想装飞牛系统当NAS用，这台主机有不少可探讨的地方。N95低功耗适合长时间开机，双存储位能满足基础存储需求，千兆网口传输没问题。但要注意N95性能有限，跑复杂的飞牛应用可能吃力，没有双网口对软路由功能有影响，得额外加USB网卡，这点不如部分N100机型。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenNlgOZlWTLafmlQBawia88Wbg1xNwSKr2dgwzB0RBbaQlNEkLhclkBcUgLle8Na3jPWx6ardyJkQzbsEVruofqyu6Yib4JdARKE/640?wx_fmt=png&watermark=1&tp=webp)


这款主机刚出时也是千元级的热门款，主打小巧稳定的办公体验， 如果能350元左右拿下， 格确实很有吸引力。但要注意两个细节，一是不带内存硬盘，算上8G DDR4内存和256G m.2固态，总成本要再加300多，预算紧张的朋友得算清楚。二是N95性能有限，别指望它玩游戏，顶多看看视频办办公，强行多任务容易翻车。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenXrOsVdHg58Y21vSJNZc488uHTGsHscwJxEzTxWE7RBz3XEYeClp891CBMxrDnLydSBYMBhS5brIoM4qkprAFNUpDBeXY6Cx8/640?wx_fmt=png&watermark=1&tp=webp)


如果你要下单，建议先多问问成色细节，有没有维修史，电源适配器是否原装。用途上，办公和软路由是最佳选择，装飞牛系统当轻量NAS也可行，不建议用来做主力机跑大型软件。垃圾佬们应该会喜欢这种可折腾的机型，预算有限又想捡漏的朋友可以考虑。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCek7oY3Sb0NmG1JDcB3uBnXPKUVibWWRUOva26GwgHUF2xzw1RQDf38QZomA2IwbUe1C2cZiaNQl6qXVvbqRnzic0pZVm8diclsknVM/640?wx_fmt=png&watermark=1&tp=webp)
