# 二手鱼淘到120块的Kindle Touch墨水屏阅读器，这价格亏不亏？

![封面图](https://mmbiz.qpic.cn/mmbiz_jpg/E9h3abOJCek0uoS9NVTSyibNGXcvvic1mtr9e0zRqu7PkChMyiahe3X8dxccWZJ5eUqib2c89XZicaq3g23bWz3SfjyiaDnILniazjmHgNbcKoeQtM/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/3HrUCS_X0A0om6ECOIyjbQ

你上一次静下心来读一本电子书，是什么时候？如果告诉你，现在只需要一顿外卖的钱，就能买到一个纯粹的阅读工具，你会心动吗？二手鱼里看到有人挂了一台亚马逊的Kindle Touch，标价120还包邮。好家伙，这价格简直跌至冰点，让我这个老数码爱好者都愣了一下。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCek0k0ibTD8bQq8vMMeGsfL9JYVpJ2mMDnPr1tDeocrRYyNEMVHFRrhTkIbfjwqUqIKRUJjlibhlcQQo6tgIF8pmVjLKZKOPcTicN8/640?wx_fmt=png)


仔细看看描述，墨水屏、6寸触摸、带语音朗读，还能放音乐，成色说是有轻微使用痕迹。这玩意儿，可是有些年头了。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekribz2CluSEn6qlq6ic78QNA5Z6zJMUDGPulfarU9A13WQibuySqbAdcRbBibO1zHqtVVuKRI2rCxmVxDZExsQia67zicoyGSh41VDo/640?wx_fmt=png)


先摆参数，咱说重点。Kindle Touch，2011年上市的“老咕噜棒子”了。核心就三点：6英寸E Ink珍珠屏、红外线触摸、以及4GB的存储空间。对，你没看错，是4GB，在动辄128G起步的今天，它显得格外复古。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelFSYTEs9v9BndlDrmeDRyvq3oaTtNbtGnGFU0uUXyCYYibBfkFZk6JsibHc4YxPv4icGoIx2lnIK10sNiccRk8Mn6sC3I49axjNicc/640?wx_fmt=png)


优势在哪？首先，它极致的纯粹。除了看书、听书，顶多听听MP3，它干不了别的。没有微信，没有推送，没有眼花缭乱的各种App。这种“功能残缺”，对需要专注阅读的人来说，反而是福音。墨水屏在自然光下的舒适感，依然是手机和平板无法比拟的，真护眼。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCek7icTtBLEWzSBYJiczNIplOS7nGVEWNbFff2D6S9XP8IeBicsloSlGFCibsniaOR221335GGamQVb62KbDnbcfhOQSLUIGTM9k1r0s/640?wx_fmt=png)


其次，物理翻页键的保留，搭配触摸，操作有种复古的踏实感。超长的续航，充一次电能用好几个星期，毫无电量焦虑。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemzcZmmhgEWrib2Cr46WzVkI6JudD3RuicrZWeKsYDJX05OYkXuYEJjTwLBVTDFRyIV033j4hlmscyFgQy7O1RTqooogQDaZx6iaU/640?wx_fmt=png)


最后，也是最重要的，就是这120块的价格。一杯咖啡钱，就能体验一下当年风靡一时的电子书阅读器是什么感觉。就算买来真的只用了几次，扔在床头或者送给孩子，也完全不心疼。这残值，已经低到不能再低了。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenRbKktsiaOxHFNtC8ydPXoAeQ1of238YSgFLYckk2sOdhic4RvPE7G1EQ0h2vXHiccaVkaAL1icYR707YxMc7T78rGdpXFibq03GoY/640?wx_fmt=png)


但是，咱们也得把丑话说在前面。它的缺点和它的优点一样鲜明。反应慢，翻页有残影，这是老墨水屏的通病，你得习惯它的节奏。功能太单一，传书需要用数据线连电脑，或者用邮箱推送，对习惯了无线传输的现代人来说，有点麻烦。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekb1DEib9gXOna0yKtjC9P5p1l6v4Kjmox4bFADniaJA2VTWJ0OKCeMuqmvuHiabJaBGOZRFvoaYnT2ucNuMsGBA09VXJzkF09NrQ/640?wx_fmt=png)


最最关键的一点，电池状态是盲盒。十年左右的机器，电池效率是个大问题。描述里没提，你得主动去问卖家续航还能坚持多久。如果电池老化严重，那体验会大打折扣。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelyDATLhoMxN4B9ybyiaUXaQGQrnkiaMc9icwC8JGn6gwD7H0icwQqsB6ChEChEN5IiblkOdZkZYMy3SPEeLNPJMjic0wUqr2hG3AEm8/640?wx_fmt=png)


所以，给真想入手的朋友一点建议。

第一，下单前，一定，一定要和卖家确认电池的实际使用时间。别不好意思问，这是你的核心权益。

第二，问清楚配件，是否带原装数据线。这种老接口的线，现在不一定好找。

第三，也是最重要的，想清楚你要它干嘛。如果你追求极致的阅读沉浸感，预算又极其有限，它能满足你。但如果你希望它反应飞快、传输方便、还能看看漫画，那它可能真的会让你嫌弃，最终“扔沟里”。
