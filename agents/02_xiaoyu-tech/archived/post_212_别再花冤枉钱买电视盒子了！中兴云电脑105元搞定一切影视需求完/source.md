# 别再花冤枉钱买电视盒子了！中兴云电脑105元搞定一切影视需求

最近有粉丝让我帮找一个合适的电视盒，我看了一下二手鱼里的电视盒真是风云变幻，好多以前高攀不起的玩意儿，现在价格都跌到了冰点。今天刷到这个盒子，让我这垃圾佬都忍不住多看两眼。啥东西？中兴云电脑盒子W132D，价格98-105块，还包邮？这特么不就是一包烟钱、一顿快餐钱吗？


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelLFXY1HDIicBD79ItibyicN3Ke11rGjrLqxk3PvgiagTSx9t6r2PgB4EKXd7lLDPD83y2WQchXXvfcyKiazr590txaiaeOreryib594o/640?wx_fmt=png)


这玩意儿的出身可不简单，它可不是那种几十块钱的山寨电视盒子。中兴是正儿八经的通信大厂。这东西以前是给企业做云电脑终端用的。说白了，它本身没啥运算能力，就是通过网络连接到远端强大的服务器，让显示器和键鼠能操作云端的电脑。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCeliaVnjLkT8J0wagAdPLia8hUlTyqWbvOauibK6UdwhBBq8dy6LPdWEWwobGlxPKrcXjG3WupeAyIClniaqfZB9mx41FyVoNVgDRKI/640?wx_fmt=png)


处理器是瑞芯微的RK3528，四核A53，主频1.8GHz，配上2+32G的内存组合。看起来虽然挺寒酸，但放在电视盒子或者轻量级小主机上，绝对是够用的。接口方面那叫一个齐全，一个USB 3.0加三个USB 2.0，插U盘、键盘鼠标完全够用，还有有线网口、HDMI、Type-C供电口，甚至支持双频WiFi和蓝牙。最关键的是，这玩意儿的功耗只有2W，一年365天开着也用不了几度电。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelUDNovq9dTqRpKr2XrY7icX10cpvR4UTCbqPWkIO9DWpUv1ERIc9EaQPR7dHhq11QIWCU3vYJkzQkDkQameMqUfCPJJmoEDibWY/640?wx_fmt=png)


卖家给了两个套餐。套餐一98块，就是原汁原味的云电脑系统，但那个需要你有企业的账号才能用，对咱普通老百姓来说，拿回来就是个半砖，除了当个高级摆件没啥用。所以我个人建议，直接加7块钱上套餐二，105块的。这个卖家已经帮你刷好了安卓9系统，还装了个当贝桌面，开机就能直接当电视盒子用，看个直播、追个剧，或者接个移动硬盘当本地播放器，那体验绝对是丝滑的。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekZvVYMQCTpoBISzKXNiauBtKmoDriaAZxPzZtrr2r0pYibdpYKy0CicsmVZwafAAuTYfqqjLfVlJ9icWPFMaZlWziaj4vcMhYbljJ6k/640?wx_fmt=png)


现在随便买个牌子的电视盒子，配置差不多的不得一百五往上？这玩意儿才105块，性能不差，接口更全，还是大厂做工。你买个遥控器没准还能砸核桃，这中兴的盒子，用料绝对扎实。而且它这个小机身，带Type-C口，55克的重量，你甚至可以把它塞在显示器后面，搞个便携屏，就是一套极简的桌面娱乐系统。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelhvonC2H77xao0ibC0ADtSCsZUXTFoKYSHGy8OibchHTxEIGicq1FiapNIEibaNHEPhCtCfjvnBvZVqyBJKQ8eIpnSwOy3iabiaUo6DE/640?wx_fmt=png)


当然，咱也得把丑话说在前头。这玩意儿毕竟是从云电脑转型过来的，虽然刷了安卓，但系统优化肯定比不上那些专门做电视盒子的厂商，可能有些冷门应用会有兼容性问题。另外，2+32G的配置，现在看也就是入门水平，别指望装一堆大型游戏，它的核心任务就是安安稳稳看电视、当个播放器。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCek23kh5rLiaEtYFsUI7o1U7przxuk4H9U586otEick8yPM8qfrjSkHsfKibDZgtlaSRKZ5g6xkA0nLSuCpMJNictUM22PS5icTCicfc4/640?wx_fmt=png)


所以，如果你想弄个屏幕看电视，或者家里老人用的老电视想智能化，又不想折腾复杂的操作，那这105块钱花得绝对值。如果你是个喜欢折腾的垃圾佬，买回来刷个游戏系统当个怀旧模拟器，那也是妥妥的性价比之王。但如果你期望它能有几千块电脑的性能，那趁早别碰，免得说我是坑小白。
