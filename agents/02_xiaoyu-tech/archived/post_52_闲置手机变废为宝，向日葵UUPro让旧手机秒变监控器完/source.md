# 闲置手机变废为宝，向日葵UUPro让旧手机秒变监控器

![封面图](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXFl4zAH8DeaLccXjKHAlNrvUNSZ886AaTMibyLibxaTV03oZCQLKCm1gYxUoXranWdvIb5TSFswia6MQ/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/-0OtxNIHiMWmPoHvWcR7fQ

大家好，我是小鱼评测，今天评测的产品很有意思，是来自向日葵品牌的一款手机远程控制设备—向日葵UUPro。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXFl4zAH8DeaLccXjKHAlNrvNeLX2Z8gicO7ibeAfIpiaeLmR7TIT1ZOPZw3WZX5ibYqcMDdwT9m7pm42A/640?wx_fmt=jpeg)


如今的手机更新换代速度非常的快，那么我们总去买新手机，淘汰下来的旧手机你会怎么处理呢？一般来说，无外乎这几种情况，卖二手、送人或者是闲置一段时间后扔掉，但向日葵UUPro手机远程控制设备，却能够让旧手机继续发挥余热，它不仅能够实现远程控制手机的功能，用于解决父母长辈们无法熟练操作手机的痛点，而且还能够远程开启手机的摄像头，让手机秒变为远程监控器。如此强大的功能令我感到非常的好奇，那么实际的体验如何，还是一起来看一下吧。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXFl4zAH8DeaLccXjKHAlNrveaq1JwRCriaOU14oHfFl2SMIFKS39YKWuGpGibDSmrkSASD0icVOwpBwg/640?wx_fmt=jpeg)


首先还是先从包装说起，黑色的外包装盒设计的非常简约，这样一款神奇的设备，身材却并不是很大，即使是附带了外包装盒，也还不如手机的尺寸大。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXFl4zAH8DeaLccXjKHAlNrvfRx9AhcibG2ejUy0H9LWD8Vo1Kv05ehY7jad7LujQmKktyNmyic2Wcmw/640?wx_fmt=jpeg)


包装盒内的配置也非常的简单，黑色圆润的四方体，就是向日葵UUPro远程控制设备，除此之外，还配有一条充电线、一张提示卡和一份使用说明。一般来说，配件越少，设备的上手难度也就越小，这款产品如此简单的配件，想必上手也应该非常轻松。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXFl4zAH8DeaLccXjKHAlNrvpqTo2699RxicBXSk4NsEuyibgKnwLK0DxfRwUJvFUHILMt1Qrqzf3Vfg/640?wx_fmt=jpeg)


向日葵UUPro的机身设计的非常低调，机身的尺寸仅有45mm，厚度仅10mm，如果是第一次见到它的人，根本看不出它的用处，也绝想不到这会是一款远程控制手机的设备。别看身材不大，机身内的配置还挺全面，通过亮起的指示灯就能看出，这里面居然配备了充电电池。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXFl4zAH8DeaLccXjKHAlNrvDMHoDonYujCt0QTMdMVcKZFv42ydmQb2HCRNSFSI9lHDjIA7dFjMBw/640?wx_fmt=jpeg)


除了指示灯之外，在机身的另一侧还还配备了一个实体按键和一个TYPE-C充电接口，实体按键的功能也非常简单，主要是显示当前的状态和重置设备。内置的电池容量为110mAh，满电的情况下可以提供约48小时的续航时间，所以如果需要长时间连续使用的话，建议每天都要为其充电。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXFl4zAH8DeaLccXjKHAlNrveH1IzJMTaZaeeiaxKialNLR8vibGSj1bZ1Avdg1xekmOy36jQMJNlPvRw/640?wx_fmt=jpeg)


至于向日葵UUPro的背面，则没有什么太过出奇的地方，只是一些设备的参数和产品的相关信息。以上就是这款向日葵UUPro在外观方面的展示，是不是感觉非常的简单，除了一个按键之外，完全没有需要我们操作的地方。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXFl4zAH8DeaLccXjKHAlNrvxxP342VVS7WTES672IcqsblQSshB5nJXrDdvl6FcZs3bWDA9JXythg/640?wx_fmt=jpeg)


其实向日葵UUPro的神奇的地方并不是通过外观展示出来的，而是能够配合向日葵强大的远程控制系统，实现对手机进行全面的控制。当然，前期的准备工作是不能少的，具体的连接方法的很简单只需三步即可，首先就是下载控制软件，用旧手机扫描使用说明中的二维码就可以下载，之后在手机蓝牙中搜索向日葵UUPro设备并与其连接，最后打开下载好的向日葵客户端，登录之后并对远程控制的请求进行授权即可。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXFl4zAH8DeaLccXjKHAlNrv9J4cPj8nice5jxPUocib7mXLrWBic9x9BmNf8wtUXibdhrtKKKD2KDR9RA/640?wx_fmt=jpeg)


这里要说明的是，使用这款向日葵UUPro远程控制设备的时候，是无需对手机进行root的，支持安卓7.0以上和苹果IOS
 
13.0以上的系统，并且还支持跨平台控制，也就是说，我们不仅可以用手机来控制闲置的手机，还可以用PC电脑和平板电脑来控制，这样的多平台的操作可以说非常的便利。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXFl4zAH8DeaLccXjKHAlNrvtOax6OtIGWT2glxOPkQkl1CO3ng0LAmj8m22bh8HG63EsRNJOLVhMg/640?wx_fmt=jpeg)


做好了前期的准备，我打算让我闲置的小米6手机再次发挥余热，在登录向日葵客户端之后，系统针对被控手机给出了四项功能，分别是桌面控制、桌面观看、摄像头和远程文件，其中摄像头和远程文件的图标带有特权字样的标签，应该是有什么特殊的功能，而桌面控制和桌面观看的功能，顾名思义应该就是用来操控手机和查看被控手机的屏幕。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXFl4zAH8DeaLccXjKHAlNrvVDHZ8TicdWGxic3W0ZZHs8boEhltq2kj31oVHmKmUAXDluPq9qkSPjaQ/640?wx_fmt=jpeg)


![图片](https://mmbiz.qpic.cn/mmbiz_gif/afNLf2a8eXFl4zAH8DeaLccXjKHAlNrvAh7Deibhb5HibQXZlrfZDiaD06LfUyFlJC03kEU5H8D0vtLqAL68lSL0A/640?wx_fmt=gif)


在实际的体验中，我首先选择了桌面控制的功能，通过这项功能可以对被控手机进行任何的操作，各种滑屏、下拉等手势也完全可以识别，打开各种软件和摄像头也没有任何问题，操作被控手机方式与操作自己的手机几乎是完全相同。通过这项功能，父母或亲属再来找我调试手机，就不用亲自上门了，这种远程操控的体验，绝对要比微信视频那种指导式的操作更为便捷。这里需要提及的是，选择桌面控制或者是桌面观看的功能，系统会对被控手机发出一个控制请求的弹窗，只有被控手机点击确认之后才能够进行远程控制。


![图片](https://mmbiz.qpic.cn/mmbiz_gif/afNLf2a8eXFl4zAH8DeaLccXjKHAlNrvfrLv6QjS4Vbib8h50K9g8Bw6iatMtxq7tVBDJiaHcEvNHvBicBaFcF13bQ/640?wx_fmt=gif)


![图片](https://mmbiz.qpic.cn/mmbiz_gif/afNLf2a8eXFl4zAH8DeaLccXjKHAlNrvwMVv7QNsStO4glBRuLfRuzCm0hfTibOrw3fZcXTn2Pnmb7YDkAY443A/640?wx_fmt=gif)


之前有说过，向日葵UUPro能够把手机变为监控器，只要点击带有特权字样的摄像头功能，就可以远程开启被控手机的摄像头。我原本以为也是发出请求，对方点击同意才可以。但在实际体验中却让我感到了震惊，因为远程开启被控手机摄像头的功能，是不需要对方确认的，并且即使是被控手机处于锁屏状态，也同样可以控制，控制期间被控手机的屏幕也不会亮起，即使被控手机处于使用状态，也同样可以开启摄像头，也就是说，开启手机的摄像头是在后台静默进行，被控手机是无法察觉到的。这样一来，手机就真的被变为了监控器，而且还能够进行前置和后置的摄像头切换、画面翻转、画面镜像、截屏和录像的操作。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXFl4zAH8DeaLccXjKHAlNrviaLJupUZfGicJaHgicTPHzhUrLQNsFeiaNmu33oZjkrCF1HK1hElbNdyPA/640?wx_fmt=jpeg)


而同为特权的远程文件功能也同样强大，这项功能主要是可以远程访问被控手机的文件系统，可以看到被控手机中的照片、视频等所有文件，并且支持上传下载，可以随时把选定的文件上传或下载到手机中，而这些操作也同样是在后台静默状态下完成。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXFl4zAH8DeaLccXjKHAlNrvibicae3BvJRYvpibWicc7xDXb7oiaMbdnt7JrLib1jPdufUL2sS3FAugBujA/640?wx_fmt=jpeg)


除了使用手机控制之外，我针对电脑端的操控也进行了体验，电脑与手机在功能方面没有任何的区别，桌面控制、桌面观看、开启摄像头、远程文件，这些功能与在手机端的操作是完全一样的，唯一不同的就是把手机端的触摸操作变成了鼠标操作。其实这两种控制方式也都各有所长，用电脑来控制手机的方式要更为灵活，同时也不影响电脑上的其他工作，而用手机去控制，则更为顺手，总体来说区别不大。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXFl4zAH8DeaLccXjKHAlNrvPuiaG8huF1Zll4q6ItA3gGZIhjNibEpCjoBslSiblW4dUibXFfHWVb0HGQ/640?wx_fmt=jpeg)


最后再来说一下关于隐私的方面，通过以上的体验可以确定的是，被控端的手机在主控端手机面前，是毫无隐私可言的。那么有的伙伴可能就会担心，如果别人送给自己的手机，安装了这些东西，那么是不是也同样有泄露隐私的风险呢？这一点其实是完全不用担心的，我总结了一下，只有符合以下两点的要求，手机才会被控制。其一，被控端手机必须与向日葵UUPro处于蓝牙连接状态；其二，被控端手机必须运行了向日葵远程控制软件。只有同时满足了这两项要求，才能够进行远程控制。所以只要关闭手机蓝牙，或者检查手机中是否安装了控制软件，就可以完全避免隐私泄露的风险。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXFl4zAH8DeaLccXjKHAlNrv3T8tZWO3TBImNGxZyS7icS8k4IpmSX5sCk4q3ia6rFJQmicpRfRD2YLuA/640?wx_fmt=jpeg)


由此可见，这款向日葵UUPro手机远程控制设备的功能还是非常强大的，有了它，真的能够让你那些闲置的手机再次的被利用起来，既能够远程操控闲置的手机，又能够把手机变为远程的监控器。如果你还不舍得处理掉你闲置的手机，那么不如搭配上这款向日葵UUPro，让你的闲置手机继续的发挥余热吧。关于闲置手机如何能够再次被利用起来，你还有哪些的新玩法呢？不如在留言区和大家一起分享一下吧！
