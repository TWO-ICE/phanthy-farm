# 610块的联想墨水屏电子书阅读器，是真香还是智商税？

> 原文链接：https://mp.weixin.qq.com/s/1epG8Vfy-fORy2s8iHVlOw

![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXE7Tes4CVp8mpeeBkwmqtutEicrT2duoKf8jZRx2TAa03uTArvLKibLaPW38q0JkpF69Pic8oQPC3MoA/640?wx_fmt=png)


看小说，或者是给孩子学习，这款不伤眼睛的墨水屏电子阅读器还不错，价格比一些垃圾平板要稍贵一些，标价610元，但牌子是联想的，卖家描述得挺实在：10.3英寸柔性墨水屏，4096级压感手写笔，4GB运行内存加64GB存储，系统干净没装乱七八糟的推广软件。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXE7Tes4CVp8mpeeBkwmqtutc74o2QydRChMicq8XOCP1Mrhx7LDNDlicZK2uTUCsJ92vck1LOAdBCvA/640?wx_fmt=png)


10.3英寸的屏幕分辨率达到227PPI，日常看PDF、漫画或者教材基本够用，文字显示清晰，长时间盯着也不会像LCD那样刺眼。加上是柔性屏，摔了也不容易碎，对家里有娃或者自己手滑的人来说算是个加分项。处理器用的是瑞芯微RK3566，虽然不是旗舰芯，但跑个电子书、记笔记完全没问题，毕竟墨水屏刷新率本来就不高，性能过剩反而浪费。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXE7Tes4CVp8mpeeBkwmqtutT8OecZQTxeIick1wshSIW027VHibygO6QpT6jlIsf8eqObibJia6mBj2Vw/640?wx_fmt=png)


不过卖家没提电池健康度，也没附电源适配器，这就有点让人犹豫。610元听着便宜，但如果到手发现续航缩水一半，还得额外花几十块配充电头，那性价比就打折扣了。而且现在64GB存储的U盘都要七八十块，这机器自带大存储确实值点钱，但对比全新入门级电纸书，比如某些国产品牌600出头的新机，二手联想的优势就没那么明显了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXE7Tes4CVp8mpeeBkwmqtutTPPr8TpX77n1jenxak0Ymia0UTGiavSCsDPJOaicnSia7je4HPjxiczSM1g/640?wx_fmt=png)


可能有人会问，这玩意儿和普通平板比到底强在哪？答案很简单：护眼。孩子上网课如果老盯着发光屏，眼睛干涩疲劳是常态。墨水屏靠环境光反射成像，原理接近纸质书，适合长时间阅读。另外它还能当手写笔记本来用，配合压感笔做批注、画草图都挺顺手，学生党或自由职业者或许能挖出更多用途。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXE7Tes4CVp8mpeeBkwmqtutibY7TBxRM0hB3M7AVacIZb5nTWibGh4ibWeek6o61nGNic24KHAh5u8QOg/640?wx_fmt=png)


那么联想SmartPaper现在值得入手吗？如果你主要用来读文字类内容，偶尔写写画画，又不想花一千多买新款，那610元这台成色不错的二手货可以考虑。但要是你指望它流畅看视频、装一堆应用，那就别想了，墨水屏天生不适合干这些活。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXE7Tes4CVp8mpeeBkwmqtutN3s7NtISp6MCicyLEMWq0HX7iclWiawtM1qO8r6WHGfnmb3beEcYOAMpA/640?wx_fmt=png)


对此产品有兴趣的话，可以在二手鱼搜索“联想smartpaper墨水屏电子阅读器”这个关键字就可以找到此产品，如果找不到可以通过图片进行搜索，都搜索不到的话，那可能是此产品已卖出或者是下架了。


 


以下是个人一些掺了水的建议：  

1. 别光看价格低，先问清楚电池和配件情况。  

2. 如果主要用于孩子学习，优先选带背光的型号。  

3. 对比下全新入门款，别为品牌多花冤枉钱。  

4. 看完不买，立省610元。
