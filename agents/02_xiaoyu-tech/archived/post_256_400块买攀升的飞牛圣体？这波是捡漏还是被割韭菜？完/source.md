# 400块买攀升的飞牛圣体？这波是捡漏还是被割韭菜？

![封面图](https://mmbiz.qpic.cn/mmbiz_jpg/E9h3abOJCekng7RobuY5409B3F69I2bGuKaMvmIunPjtiabAou1Ufqtsz0ibRy3UgmiaJ1ibt4L71YJiajvzolwRHXOfze3hJKUhuQA98dIv6YVY/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/Gt3xtPWzWip6agwONq1Bog

今天刷二手鱼，看到有个卖家挂出来的这货，我承认，我有点心动了。攀升N5105小主机，板载6G内存，卖家还管它叫“飞牛圣体”。关键是价格，只要400块。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekoGfMTL3tweIHlXhcozR7J1nged3QxNYDicGAG5BNYzvlVu7W5gfGLWic3KubiabUBkozacKicZnkacHscGNjHRVcd4KwZQMuKXOM/640?wx_fmt=png)


攀升这牌子虽说不是一线，但也算是个知名品牌吧。N5105处理器对于刷飞牛来说正好，10W TDP非常省电， 性能大概和桌面端的四代i5打个平手 。日常跑个软路由、轻量NAS、甚至装个虚拟机跑点小服务，完全够用了。这U最大的魅力不是跑分，而是它能硬解4K，玩转Jellyfin或者Plex转码，妥妥的影音小钢炮 。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenx12qYCB6EMf7YLxUSMuYBnvNAV7ZYJ1y52MfwibEiawDEQxD14W80KSAxrL6ZNyDxdt87X1kA8XJib5DWCeic2XgydY90QcyibLIg/640?wx_fmt=png)


再看看这卖家的升级配置。板载6G内存，正好卡在飞牛NAS或者OpenWrt软路由的舒适区，不浪费。最骚的操作是这个“重新设计的外壳”，背部不仅能插双协议的M.2硬盘，还能塞进去一块2.5寸的笔记本硬盘。这意味着你花400块买个准系统，加上手头闲置的旧硬盘，立马就能组一台双盘位的NAS或者全能型的家庭网关。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCek7cxcvud6RM9DA5Yia5Aydhx00yKOQoicIFq5ibwuJia09mUtyxQAwFxUp0ZRb07CiaQEwn6hOplEWTMibLrM8I9fJ9If2iab8etr9m4/640?wx_fmt=png)


很多老铁可能不知道，去年这种类似的工控机或者手搓机，准系统还得400多呢，加个内存和外壳轻松上到七八百 。现在二手鱼这行情，硬盘涨价，内存看涨，400块能买到这种带定制外壳、板载内存、还预留了双盘位扩展的小主机，性价比确实有点不讲武德了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCek97eiawCeW9oG3HrMyibhkOSZDgLZH6y16ZicbUsXCyW4uKgbpqHrXcibK9kianr9xMyk23UzsBBLs5icNVIicFhopTuMEcR8R1rlXFU/640?wx_fmt=png)


但话又说回来，这世上没有白捡的便宜。这机器虽然被卖家吹成“飞牛圣体”，但它也有几个硬伤，你必须得知道。


 


第一，性能瓶颈。N5105终究只是颗赛扬，跑飞牛NAS那确实是“圣体”，因为飞牛轻量化做得很好。但你要是想在它上面跑ESXi再虚拟出Windows系统，或者当成主力电脑用，那还是趁早放弃。它的单核性能比较弱，多开几个网页都会感到吃力 。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekva4fX5oLAno3U2pib8W9UWwRuhpMjdWbd8Tlzj9b38WVDvvydd5MNibADIfSMpYcXv3BPribpEFUKXlSiaVGdeYxfVz7r9JfQ5uc/640?wx_fmt=png)


第二，散热问题。N5105这玩意满载功耗不低，如果长时间高负载运行，比如连续挂PT下载或者转码，原装的被动散热可能会压不住。虽然卖家“重新设计了外壳”，但散热效果还得打个问号，后期可能需要自己加个小风扇对着吹 。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemYic7KkibjpniaImFoUqfKkFyqwrwtSSJOibJJaqy2bDaSeTKReVksQDBicQWguc94uicceEqUL9210LwzRvfPR7UTZg98sysHqia21U/640?wx_fmt=png)


如果你本身就是个爱折腾的玩家，家里已经有闲置的硬盘，想把家里的网络搞得再专业点，或者想低成本体验一下飞牛NAS的魅力，那这台机器，简直就是为你量身定做的。400块，买不了吃亏买不了上当，哪怕最后玩腻了，拆了外壳，这主板和U在二手市场也还能值回300多块，残值率极高。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCel3WpbjnmiabY2Mt94bbFAhOibUCqOcZv8ACiaK0fvibySeibAn2CIic7xubxXxhAAjTI7LPXTr5l3ZZWU9eEYlljbTcH52pK2EqeXIE/640?wx_fmt=png)


但如果你只想买个电脑回家，插上电就能用，或者想给老人小孩当网课机，那我劝你直接关掉。这东西不是给你用的，它是给那些喜欢折腾、享受自己动手解决问题的“垃圾佬”准备的。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCem9wf9j5YdfVRpshtTqTEM6XxjDBIc5bV5ia7g8mINswjYn7KSyLjuBWIQd2L4ib9PrPg6Qs9ykGWwOPxNr2UL0Y52S7mPafPggs/640?wx_fmt=png)


话说回来，你们觉得这台400块的N5105小主机，是当年那个引领“垃圾佬”风潮的神器，还是即将被N100、N150彻底淘汰的过渡品？评论区聊聊你们的看法，顺便说说，如果你是卖家，这外壳你准备印个什么图案？
