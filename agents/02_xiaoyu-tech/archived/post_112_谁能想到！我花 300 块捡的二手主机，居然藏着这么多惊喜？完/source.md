# 谁能想到！我花 300 块捡的二手主机，居然藏着这么多惊喜？

![封面图](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXHMuIxBBdibhSjC48Ch0jC5eCZWpiaNAVRoIBIHnIF7NiaaoOmhibOhFZx8kTgOiaelec8nn8uybOrw20Q/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/dOCcXbBYfO_cI-oZpdbpWQ

我手里的十代英特尔 i3-10100 处理器闲置了近两个月，一直在寻觅合适的准系统，不想让这颗 CPU 继续 “吃灰”。此前在二手交易平台反复筛选，却总是碰壁，遇到的商品要么价格离谱，要么配件不全。直到前些天，一台联想准系统小主机的出现，瞬间吸引了我的目光。

![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHMuIxBBdibhSjC48Ch0jC5eK8cWCYPgQbgTMK5I6cDS2FmjA31z8MzD4APwPHIvjcsBumLCzpahPA/640?wx_fmt=png)


先报下 “暗号”：联想 510s-07IMB，听说是联想给企业做的机型，这出身就比那些杂牌子靠谱点。再看价格，320 到 380 块浮动，关键是量大管饱！随便挑随便捡，运气好点 300 块就能拿下，还自带电源机箱一体 —— 我当时掐了自己一把，确认不是做梦！300 块钱啊，现在连个像样的空机箱都买不来，这直接给你把电源和机箱焊一块儿了，这不纯纯血赚吗？我甚至还怀疑卖家是不是标错价了，反复确认了三遍才敢往下看。

![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHMuIxBBdibhSjC48Ch0jC5eicFic8sgsuWsX7bChUMepU1GSkXSrRt38J3HaZZibEx1SzsznZnPPZV8Q/640?wx_fmt=png)


再说说这机子的 “颜值和实力”。首先是质量，联想家的东西，再差也比那些三四线小作坊的机箱强吧？那些杂牌子机箱，摸着跟纸糊的似的，一搬就晃悠，生怕下一秒散架，这联想的机子掂着就扎实，外壳虽然没多花里胡哨，但胜在耐造。前面板更绝，四个 USB 口居然都是 USB3.2 Gen1 协议的，比那些还在用 2.0 的老古董快多了，插个 U 盘传文件不用等半天，旁边还带了音频接口和麦克风接口，不用再绕到后面去插耳机，这点真的戳中我这种懒人了。最惊喜的是成色，大多是公司淘汰下来的，看着跟新的一样，估计之前用的人都没怎么造，比那些个人手里用得油光锃亮、还藏着暗病的强太多了。

![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHMuIxBBdibhSjC48Ch0jC5evznauxTfn3GLNtcylAhR4jqtQRY8zdfb3nJGaLK9hMtOKmk1mBc90Q/640?wx_fmt=png)


尺寸方面也没啥可挑的，说不上多小巧，但也绝不占地方，典型的办公系列准系统。我那桌面本来就堆满了杂物，要是整个大机箱，估计得把显示器挪到地上，这机子放桌子底下或者显示器旁边刚好，不占地儿还不显眼，完美适配我这种 “桌面乱葬岗” 选手。

![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHMuIxBBdibhSjC48Ch0jC5eKQdVmiaWn2psicIciaNhN9dETYSDGfCBNrS8lKksYpe6RwvhpE1okiaGdA/640?wx_fmt=png)


重点说说硬件适配，毕竟我是奔着用 i3-10100 来的。这机子标配 180W 电源适配器，我一开始还担心功率不够，怕带不动我的 CPU，特意去查了半天参数，结果发现居然能完美适配十代酷睿 i3、i5！瞬间就放心了，省得我再额外花钱换电源，这波又省了一笔。

![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHMuIxBBdibhSjC48Ch0jC5evpwZPRWLRticALarK8Ivj2RyrPB5TRZs8qVM86ia5Wr12lIibPDj4Jvmg/640?wx_fmt=png&from=appmsg)


后背的接口也很实在，一个 HDMI 接口加一个 VGA 接口，不管你是新显示器还是老掉牙的 CRT 显示器都能用上，不用再买转接头凑活；还有一个千兆网口，网速有保障，四个 USB 接口分了俩 2.0 和俩 3.2 Gen1，插鼠标键盘、外接硬盘啥的完全够，不用跟前面板抢接口，这点太贴心了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHMuIxBBdibhSjC48Ch0jC5enb0xeGv4sx9lBnmHQagPnm9SpBCia0G0ZbmhhQW8Iia1G3FcwxP0xdtQ/640?wx_fmt=png)


更意外的是，这小主机居然还能装独立刀卡！不用升级电源就能上，比如惠普 RX6400 4G D6 那种单槽半高刀卡，塞进去刚好。本来我还以为只能用 CPU 核显，偶尔想玩个轻度游戏或者做个简单设计都费劲，现在有了这操作，直接解锁新功能，不用再攒钱买大主机，简直是意外之喜！


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHMuIxBBdibhSjC48Ch0jC5e946XricuYiaAMk7meutblWY3ibmSW4c9yvTrD50IJJ0KduApliaMbOh29A/640?wx_fmt=png&from=appmsg)

最让我这种 “硬盘党” 狂喜的是硬盘位配置！机子自带一个 3.5 寸硬盘位和两个 SATA 接口，稍微魔改一下就能塞进两块 3.5 寸机械硬盘，关键是还自带 SATA 硬盘独立供电口，一拖二供电完全没问题，不用再额外买电源模块。我手里堆了俩 1TB 的机械硬盘，之前一直没地方用，现在好了，装个 M.2 固态当系统盘，再挂俩机械盘存电影、照片，完美解决存储焦虑！


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHMuIxBBdibhSjC48Ch0jC5eia5GZvib7jF7Qu3y0sS0mXwkudV9qg6jYgwY5ERpicQopVVXPfbibIJ2ibA/640?wx_fmt=png&from=appmsg)

至于 CPU 搭配，除了我手里的 i3-10100，还能上 i3-10300、i5 这些十代处理器，以后想升级也方便，不用换主板。有人说这配置能整台飞牛 NAS 玩，我琢磨了一下确实可行，但功耗会跟着飙高，我这种就想整个办公兼轻度娱乐主机的人，还是老老实实用 i3 得了，毕竟 300 来块的准系统，能有这扩展性，还要啥自行车啊！

![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHMuIxBBdibhSjC48Ch0jC5e6sMSenWYw8ZQTs6BX4M9P341kGC7MHiaicvPAVricvJRVN4S1iao2mwb9w/640?wx_fmt=png)


现在我已经下单了，就等机子到了组装起来，让我那闲置的 i3 终于有个家。说真的，现在电子产品溢价这么严重，能蹲到这种性价比拉满的准系统，我都觉得自己赚翻了，要是你们手里也有闲置 CPU，真的可以去闲鱼搜搜这款，不过记得擦亮眼睛，别买到返修货就行！
