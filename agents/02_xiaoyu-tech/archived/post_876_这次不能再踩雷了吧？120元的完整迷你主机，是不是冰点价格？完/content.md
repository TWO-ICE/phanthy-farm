# 这次不能再踩雷了吧？120元的完整迷你主机，是不是冰点价格？

就在闲鱼这方江湖里，总有一些让人摸不着头脑的清仓操作。这几天，有卖家一口气挂出了22台i3-4xxx系列的迷你整机，打包价直接干到了120元，而且还包邮到家。

咱们先别急着喊“真香”，先来看看这120块钱到底到底给你配了个什么全家桶。这可不是那种只有主板和机壳的“准系统”坑货，也不是从电子垃圾堆里扒拉出来的零件山。这是一台真正意义上的“完整主机”：内存条给你插好了，不管是SATA接口还是Msata接口的硬盘位，卖家都给你安排了明明白白，甚至连千兆网卡、HDMI加VGA的视频输出双接口都一应俱全。就连那个大水牛的散热风扇都给你装在机箱里了——虽然卖家也极其诚实在备注里打了个预防针：这原装散热器压i3虽然够了，但如果想安稳度夏，建议自己动手换把好点的风扇。

说实话，看到这儿，很多人心里的第一反应可能是：“这都什么年代的电子垃圾了？”

确实，这就得聊聊这台机器的“核心资产”了。i3四代，放在今天是妥妥的“古董级”U，这是2013年的技术架构。在摩尔定律疯狂迭代了十年的今天，看着它确实有种穿越感。但是，咱们得讲道理，这颗老心脏能不能跳动？答案是肯定的，它依然能比较流畅地跑起Windows 10系统。

咱们来个具体的场景画像：你把它接上显示器，打开B站刷个720P的视频，那是完全不带卡顿的；如果你要开钉钉打卡、微信聊天，甚至同时打开十几个Excel表格做做财务报表，这颗老i3也能稳稳地扛住，不见得会比你那个动不动就降频的低压轻薄本体验差。这是什么概念？这说明虽然它老了，但x86架构的基本盘还在，对于日常的轻办公和流媒体解码，它的性能余量依然是过剩的。

这就是它的定位所在——它不是给你用来跑3A大作的，它是来解决具体问题的。

这时候它的应用场景就清晰起来了。比如你想在家里搭个24小时不关机的下载机，挂着迅雷或者百度网盘，这机器的功耗控制在几瓦到十几瓦，比那些动辄几百瓦的游戏主机省电太多；或者给家里老人弄个纯粹的上网卡，看看新闻，聊聊QQ，甚至给孩子当个专用的网课终端，杜绝了偷玩游戏的可能，因为它根本玩不动。再进阶一点，对于极客用户，拿来折腾个轻量级的NAS（网络附加存储），跑个OpenWrt软路由，或者刷个Linux当个服务器，这反而是比树莓派性价比高得多的选择。

最核心的杀手锏还是价格，120块钱啊！

咱们来拆解一下这个120块钱的含金量。现在的硬件市场行情，你去二手市场淘一块像样的256G M.2固态硬盘，怎么也得100块朝上吧？人家这台机器，直接送你一块32G的M.2或者SATA硬盘，虽然容量小，但作为启动盘或者纯系统盘，它是完全合格的。这就等于硬盘几乎是白送。内存方面，标配4G DDR3，确实看着有点捉襟见肘，毕竟现在的浏览器个个都是“吃内存怪兽”，Chrome随便开几个标签页就能把内存吞干。但这问题好解决，现在二手的DDR3内存白菜价，加一条8G的也就几十块钱。算笔账：120元主机 + 30元内存 = 150元。再加个你自己闲置的电源适配器（这事儿后面细说），你就拥有了一台安静、省电、体积只有巴掌大的小主机。

这就值不值？非常值。

当然，咱们不能光报喜不报忧，既然是120元的“冰点价”，肯定是有代价的，这世界上没有免费的午餐。

首先，它的短板非常明显。这台机器大概率是没WiFi、没蓝牙的，这意味着你只能用网线连接，或者自己花十几块钱买个USB无线网卡插上去。其次，它大概率是不带电源适配器的，你需要自己找一个12V的电源适配器，这在家里闲置的电子垃圾堆里大概率能找到，但如果买新的，又得增加十几二十块的隐形成本。

再者，散热是个硬伤。这种迷你机箱内部空间极其狭小，风道设计基本靠“哼”，虽然卖家说了能跑，但夏天一来，高频降频是免不了的，想折腾它，还得动手改造风道或者换低压低噪的散热风扇。

最后，性能真的别指望打什么游戏了。核显HD 4400是当年的那个亮机卡，玩玩《英雄联盟》可能还得调低画质，现在的《黑神话：悟空》或者吃鸡之类的，你就别想了，连启动器可能都打不开。

但是，如果你回到“120元”这个原点，还要什么自行车呢？它存在的意义不是为了让你用得“爽”，而是为了让你在特定场景下用得“值”。

我们来横向对比一下现在市面上所谓的“新平台”。很多人会纠结：我是不是加点钱上J4125或者N5105的主机？确实，J4125这类的赛扬处理器，架构更新，支持4K硬解，性能肯定比这老i3要现代得多。但是，J4125的准系统主机，怎么着也得卖到200元甚至300元以上。对于仅仅是个“刷剧、写文档、挂机”的需求来说，多出来的这一两百块预算，是不是一种性能过剩？

甚至和树莓派比一比。树莓派4B，单板机还得几百块，还得自己买壳子、买卡、配电源，折腾一圈下来成本奔着五六百去了，而且ARM架构的软件兼容性，在遇到一些特定的x86软件时，还得折腾一番环境。这台120元的x86机器，插上电就能装Windows，这便利性就是降维打击。

所以，结论很清晰：如果你家里正好有闲置的显示器，或者你想给父母、孩子弄一个简单的上网终端，同时手里又正好囤积着几块笔记本硬盘和旧的电源适配器，这台120元的“古董”主机，可能是2024年下半年最务实的百元级选择。它够便宜，坏了不心疼，性能刚好够用，这就是电子垃圾回收利用的最高境界——让它在不该退休的年纪，再发光发热几年。

那么，现在的难题交给你了：面对这样一台只要120元的完整主机，你会选择下单捡个漏吗？还是觉得既然折腾，不如加点钱上J4125/N5105这种新平台一步到位？欢迎在评论区聊聊你的看法！如果你觉得这价格真香，不妨点个赞；如果你觉得这纯属智商税，也请留下你的反驳理由。
