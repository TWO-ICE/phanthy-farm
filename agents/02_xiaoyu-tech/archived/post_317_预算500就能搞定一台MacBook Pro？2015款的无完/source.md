# 预算500就能搞定一台MacBook Pro？2015款的无头骑士应该是最优选择

![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemV1YHQGF4ITgJz221n8ict4vajlGEyQS56RzKNHRGHmS2oqyibjSLX0PicepD9g6Ku9qIppfUcIsLuazamAQelMJyiakOUTPAvXrs/640?wx_fmt=png)


有粉丝私信我，预算500左右，想体验苹果系统的生态，问我怎么搞？刚好之前刷到了2015款的苹果15寸MacBook Pro，只要518块钱，这在500块的价位区间里，性价比是妥妥的高。虽然光剩个带键盘、触摸板和主机的底座，但丝毫不会影响到正常使用，接上屏幕就是一台正经的MacBook。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekJTTfOmQu7WyrdjMKiaDwj81QDIPOcM6nDn4tC9viafzCyibEMrJ9OuEqU7PHI2pStUIebkR9ic1exeDgq8QvgicjhzUqLRlxHOcSQ/640?wx_fmt=png)


这机器当年可是两万级别的生产力工具，现在沦为了白菜价。卖家手里这批货，型号是A1398，具体配置是LQ2，i7-2.2GHz的处理器，16G的内存，这个内存组合放到现在，说实话一点也不落伍，甚至比现在很多五六千的新款笔记本标配的8G内存还要厚道。硬盘有128G和256G两个版本，差价两百块。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCen6tLL0bh85rQk7UdJgNee73Ht2ymticwBfzLgfPBskUaNGlfS525xT16RAjhNGc4Hs9ibkctGZodYOq0tfs2x4oy3nK8upPMBKc/640?wx_fmt=png)


这玩意儿的核心玩法，就是外接显示器。它自带HDMI接口，支持4K 60Hz输出，接上家里的电视或者显示器，立马变身一台性能尚可的台式主机。16寸的大屏没了，换来的是极致的性价比。你想想，五百来块钱，你能买到一台能流畅剪辑1080P视频、日常办公毫无压力、还能体验苹果隔空投送、自带音响和触摸板的完整苹果主机。它甚至还能装双系统，偶尔玩个老游戏也问题不大。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemFDHib03421Lv4eB9sDM1iaWgdzguwKk02TAuaV76OJz1hnicjrcHywDGxg8IJMT1ibo26cTFDnhasQNZzpEC9oWhdSxib2FJyzFMo/640?wx_fmt=png)


当然，缺点得给你掰扯清楚了，不能坑人。首先，没屏幕，意味着你家里必须得有现成的显示器，不然还得额外投入。其次，128G的闪存确实有点不够看，装几个软件就红了，建议要么加钱上256G，要么就得习惯挂着移动硬盘。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelqCdViaWt1oRHHDibdgdICNibjicwRiaIlCLxINecal3pFcsoDyLSE7RjCicvSKAjaV0Nehf6QiaDqtfqJZ6WhO1icjbfZu58BgfjvzEw/640?wx_fmt=png)


再一个，这是2015年的老古董了，接口是雷电2和USB3.0，传输速度跟现在的雷电4、USB4没法比，电池虽然卖家说能用三四个小时，但你得做好它随时可能衰减得更厉害的心理准备。主板保三个月，其他配件只保一个月，这基本就等于告诉你有一定概率要拼人品。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelqJuv0S4TU0xSNV7KqkuknJg9lqDqaUuHRbYfrc42yzQYWV3CJG9icnpbVUAk52WkbNaB7VNpP37nhmXiaw4jHAT0fSZwY4kqVg/640?wx_fmt=png)


如果是我，我会选那个718块钱256G的版本。五百块都花了，不差这两百，省得后面天天为硬盘空间发愁。买回来就放客厅，接上电视，当个家庭媒体中心，或者给家里老人孩子上网课、看视频，再或者自己当个写稿子的备用机，都挺合适。它的价值不在于多强大，而在于用极低的成本，让你体验到了MacOS的生态和苹果硬件的精致感。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekCdtc5MhbdIlhJN3MjpugsSxCyLkkaVVibfrWZF2xTF2wktExm5TvZC3y1HB4WmTrmeJiahBl81QmbXF1eONicDY6TwdMR4TuIZE/640?wx_fmt=png)


这东西说白了，它适合那些手里有闲置显示器、预算抠搜、又愿意稍微折腾一下的垃圾佬。不适合纯小白，买回去万一出点问题，你连找谁修都不知道。二手鱼里买东西，尤其是这种“边角料”，心态要放平，别指望它是完美的，把它当成个大玩具，心态就对了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenbdLJpYyN3abfCkG59xGxV99PBf22f1syUJq91ysgibKs1ibzn1ol9fPvx8CNB9UATNzPkFw1vtMGSY5ibcI7voBD0quDdeEicd0w/640?wx_fmt=png)


最后问一嘴，假如你手里正好有台闲置的显示器，你会不会花五百块搞这么个玩意儿回来玩玩？评论区聊聊。
