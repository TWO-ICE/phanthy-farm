# 东芝NVMe固态二手鱼75就能拿下，这价格还要啥新盘？

![封面图](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXFRnicbjOoVav9mX9ib2g7rcBQfHusqF1HAtZFNw9icX5QzCCEm3iaee0umia6TMicPG8ozGwiaElwicx8RBg/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/aqjBr6EnepwjgN7d-CdmSQ

朕没事就爱刷二手鱼，每天不翻两页总觉得少点啥。不是说硬盘内存都在猛涨么，最近刷到个好东西，发现不是新盘买不起，是拆机盘更有性价比。

不知道你们发现没，海鲜市场最近突然冒出来一大批东芝拆机盘，全是 256G 的 NVMe 固态硬盘，听说是从服务器上拆下来的。成色新得能反光，这波不薅一把，我都对不起自己天天刷二手的手！


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFRnicbjOoVav9mX9ib2g7rcBAB4aibbXoKwPuZdPuGszRicHxIJ4FV2cBUtdafsetdeYVlrEtwmodkcg/640?wx_fmt=png)


75 到 80 块就能拿下你信不信，you see see，服务器拆机盘这性价比还行吧？现在硬盘盒、内存都跟坐火箭似的涨价，能薅到大品牌的好盘，那真是打着灯笼都难找，这个价格还要啥自行车！


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFRnicbjOoVav9mX9ib2g7rcB5qzLy8jAvaagr4JyWs4u8OiayOibokUZAHY7JPibn4VLiaRNPDFesmQGaA/640?wx_fmt=png)


说起来这盘型号是 KBG40ZNS256G，是东芝铠侠出的 M.2 2230 规格 NVMe 盘，别看它小巧，核心参数那是拉满了。PCIe Gen3 x4 的高速接口，256GB 容量，读取速度能飙到 2200MB/s，妥妥的轻薄本和掌机扩容神器！之前不少人觉得 256G 太小，都拆下来换大容量的，所以才流到鱼塘里这么多，也算是歪打正着给我们捡漏了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFRnicbjOoVav9mX9ib2g7rcBIhOzInjMPSkzc5nBBj7jmtps71N9PKwBicalbfz4ibhjaDegHyWwCg8w/640?wx_fmt=png)


我还看了别人的实测数据，写入速度高达 1904.68MB/s，读取速度也有 1085.61MB/s，这速度日常用完全可接受，没毛病。有粉丝朋友之前跟我说，他 65 块就拿下了，现在没办法，新盘一涨价，二手盘也跟着小涨了点，75 到 80 块也能接受，总比买新的划算多了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFRnicbjOoVav9mX9ib2g7rcBPfhDRSMEGKyzAiaEib4yia6ic9GnlMlpaBDCVoQe5qCMCOJvfBNWibOicVGg/640?wx_fmt=png)


可能有人觉得 256G 不够用，装个系统不是绰绰有余嘛！像办公机、NAS 当系统盘，那是完全够用，别指望它存多少大文件，术业有专攻不是？不过有个小提醒，它不是传统的 2280 系列规格，要是给台式机用，可能还得花 1 块钱买个延长配件。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFRnicbjOoVav9mX9ib2g7rcB65DUGMmnXJh8pOIgzzruPZ2gAicQGK3kicyfLuN5iboc4YwLQmeOZdQDg/640?wx_fmt=png)


还有啊，买这种拆机盘可得擦亮眼睛，记得选通电时间少、通电次数少的，哪怕贵个 5 块 8 块也值，千万别贪小便宜买旧盘，到时候用两天坏了，哭都没地方哭。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFRnicbjOoVav9mX9ib2g7rcBAmiaaTMjOCxicmGKFXVdbUesfGbyHQm3NibNlm4icsib3iaMicu0SaCE4bqicg/640?wx_fmt=png)


不过说真的，都怪我消息发太晚，好多好货都被抢光了！听说圈内有些大佬，直接囤了几千块的货，我瞅着这架势，怕不是想当二道贩子赚差价，也太会算了吧！现在库存是真不多了，就剩零星几件，手速快的宝子赶紧冲，希望还能跟上尾巴的车，别等没了又来问我哪儿买，那我可真没办法了，总不能变个盘出来给你吧！
