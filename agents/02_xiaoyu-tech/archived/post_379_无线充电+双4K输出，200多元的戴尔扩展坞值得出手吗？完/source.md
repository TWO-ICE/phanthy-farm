# 无线充电+双4K输出，200多元的戴尔扩展坞值得出手吗？

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekfhkH44g7iaQ5C318OkUoTcWurFhw8ZsDiaEDopkkZT6XuD9biawuo1apGT9Ia0yuEBaVYicE90PibXFS6sANfaUWenDibV3CsSXaT8/640?wx_fmt=png&watermark=1&tp=webp)


在二手鱼里看到了 一款支持无线充电的 戴尔扩展坞，卖家 很有意思，产品 标价223元， 但在描述里 说扩展坞加原装电源一套价 是 215元。 遇到这种标价不统一的，通常我们只看最低价，而且即使是按223元的价格来看，这一套戴尔的 扩展坞加原装电源 也是很有性价比的 。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemCN3Zzib7kVmHWQDaWeqY6NeDfr4G9daxz9y6DFCT4Aj7bwKKibvOC2OF9eRERFic4dMH0Md8OwFwB3eCyHibzicuPawiaPaf7hAjWg/640?wx_fmt=png&watermark=1&tp=webp)


产品的 型号 是HD22Q，核心亮点 是 把扩展坞和无线充电功能做在了一起， 这在 同类产品里 还是很少见的 。接口配置相当 丰富 ，1个DisplayPort1.4、1个HDMI2.1，支持单屏8K 30Hz或者双屏4K 60Hz输出，对于办公党外接双屏的需求完全能满足。还有4个USB3.2 Gen1 TypeA、1个带PD3.0的USB3.2 Gen2 TypeC，加上千兆网口，日常连接外设绰绰有余。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelwjSwN7puIAjQy2g1TKic9HDeCwb7iaXnAK6TaRHGvbUwXM48KGib4G2gh8gTxDbU5QWYYRJ4Tbxcv09NKqTMuOhtp8r4vTozxicM/640?wx_fmt=png&watermark=1&tp=webp)


最实用的是它的双充电能力，TypeC接口支持90W PD供电，能直接给笔记本充电，省去额外电源适配器的麻烦。同时还带无线充电功能，适配苹果安卓手机，床头放一个，手机随手一放就能充电，笔记本接上去也能供电，桌面能整洁不少。卖家说机器有轻微使用痕迹，功能正常，实物拍摄还包邮，这点倒是挺实在。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemnEx9HEO0ic7Kd45fXmMIwiaU9X4633MRdP5g6uiaQvnjXqJU1Ob5FRBia4kVuIicrnEFzfGgHflrflwia3B9N7o5djRp85BomdksFg/640?wx_fmt=png&watermark=1&tp=webp)


215元一套带原装130W电源，对比全新价确实血赚。如果不在乎成色，或者自己有适配电源， 目前二手鱼 最低120元也能买到同款，这个价格买个带无线充电的90W PD扩展坞，性价比直接拉满。对比同价位其他扩展坞，要么接口少，要么没有无线充电，要么PD功率不足，这款K21A的综合配置优势很明显。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenDiaYj07OJLE0UtdLdeF1X1C9OIdhwDXloIcteSyumic2HCG378sey2mG3iaqPQVOjKAuEqib8LotXQficfWd9HT00TliaA0Ak052qQ/640?wx_fmt=png&watermark=1&tp=webp)


当然缺点也得说清楚，作为老款产品，它没有现在新款扩展坞的轻薄便携，重量0.8kg，外出携带不算方便。另外轻微使用痕迹是避免不了的，介意外观的老铁们得谨慎。还有二手闲置物品售出不退不换，下手前一定要让卖家发详细测试视频，别买到故障机当接盘侠。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekibrVOfgH9KAZCRIycTOly4Z3eFYfOro1hvpTotNQbOfvWzyFKfk73kWzRbNT6rBuMRibiaFQohS73QOD9nDVdnfmxaia3KGzicN5I/640?wx_fmt=png&watermark=1&tp=webp)


如果你是 预算紧张又需要多接口扩展和无线充电的办公党，这套215元的套餐很值得入手，一步到位解决桌面扩展和充电问题。如果只是临时用用或者已有电源，120元的裸机版本更划算，能省不少冤枉钱。但如果你追求极致便携或者需要雷电4高速传输，这款老咕噜棒子可能就不太适合，不用瞎折腾了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekHbjocpoa6Uk8Dnt9ueg6tcLPicux2Rib9Oesycoak08vrCub2Y27wSOTuYINOj2s3EdF7XaI2VzzpBWEia4g4YFmksDWGjxFBag/640?wx_fmt=png&watermark=1&tp=webp)


你们觉得215元拿下这套戴尔双充电坞站值不值，有没有用过同款的老铁来说说实际体验，或者你们在二手鱼里还淘到过哪些性价比爆棚的数码产品，评论区分享一下，让大家也学学怎么在鱼里淘金。
