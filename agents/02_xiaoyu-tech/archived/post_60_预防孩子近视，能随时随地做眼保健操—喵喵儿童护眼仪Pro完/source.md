# 预防孩子近视，能随时随地做眼保健操—喵喵儿童护眼仪Pro

![封面图](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXFrypTl8hNFIYOZEjTqNC7tySUico3ujMEcHXbSvmJgfODbQkrr3wGQhzY7xmehhrCCWibqYp5viaKnw/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/grnxKK2EhYFK2azUh2jbzg

如今的孩子早已不像我们当初，只依靠书本和课堂上的讲解来获得知识，通过手机、电脑、电视进行网上授课，现在似乎也成为了学习的一部分，这些多元化的教学虽然丰富了孩子们的学识，但也带来了一些弊端，最直接的就是对于视力的影响，如果不注意正确的坐姿和用眼健康，很容易就会出现眼睛近视的问题。而作为家长，虽然知道健康的视力尤为重要，但又不能时时刻刻的陪在孩子身边进行监督提醒，那么有哪些方法能够保护孩子眼睛呢？


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXFrypTl8hNFIYOZEjTqNC7tXpiaWJ09jSictf8xvIhx2gXjnxq8N7icL1okmWNANRNsMxnKmpf8BRouA/640?wx_fmt=jpeg)


最近，我在网上下单了一款喵喵儿童护眼仪Pro，这是一款由知名眼科专家邓宇晴专业推荐，专门为儿童设计的护眼仪。它能够精准的定位四大穴位进行按摩，佩戴之后可以舒缓眼部疲劳，还可以配合叶黄素眼贴来使用，并且易收纳便于随身携带。那么实际的使用效果到底如何呢，还是一起来看看吧。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXFrypTl8hNFIYOZEjTqNC7tyHPB72Nbr8aic6RDAHGuP62YKsibR6yTHOPktLbGsnOGKpX9uuemnNPQ/640?wx_fmt=jpeg)


由于家中是女娃，我选择的这款喵喵儿童护眼仪Pro是粉色系的款式，可以看到产品外包装不大，采用的是抽拉式的长方体包装盒，包装设计的也十分简洁，正面除了产品的展示图之外，下面还标注出了多项主要功能。另外，为了能够达到最佳的舒缓效果，我还下单了叶黄素护眼贴，一盒7片，都单独装在了黄色包装盒内。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXFrypTl8hNFIYOZEjTqNC7tb9HUc4icPIWnic8tZLczsSz9cTh6yaeCFUFzDnvcyvLhBUJuF44r7IBg/640?wx_fmt=jpeg)


包装内的配件一目了然，除了粉色的按摩眼罩之外，还有一个粉色的控制器，一份使用说明、一条tpye-c充电线和一个绒布收纳袋。这里可以看到，眼罩和控制器是采用了分离式的设计，个人感觉这样的设计还是很人性化的，对于充电和使用都很方便，收纳袋配置也很贴心，折叠好的护眼仪刚好能放到收纳袋中，既避免了弄脏也便于随身携带。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXFrypTl8hNFIYOZEjTqNC7t3x9hxfIUpvia8V1jNfnCTZwdj0M6ia4o0A2VQZYSCNnsVLibBWfb6zEww/640?wx_fmt=jpeg)


首先来看一下这款护眼仪的眼罩部分，由于这是一款儿童专用的护眼仪，它的大小是按照6-15岁儿童的脸型来设计的，尺寸要比普通成人的眼罩稍小一些，整体选用的是亲肤抑菌的材质，摸上去的手感非常柔软，并且内外都具有耐脏防水的效果，便于日常清洁。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXFrypTl8hNFIYOZEjTqNC7thvq0LB0BWRmLDSvicgqDib8lWZCY2KcoMOib1iakayAyv0kym0ze7Dlf9g/640?wx_fmt=jpeg)


考虑到佩戴的舒适性，护眼仪的背部并没有采用卡扣式的佩戴方式，而是通过两条魔术带粘贴进行固定的，配置虽然很简单，但却非常的实用，魔术带不仅弹性十足，而且也同样很柔软，戴上之后不会勒头，仰卧状态也不会有硌头的感觉。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXFrypTl8hNFIYOZEjTqNC7tIibzuQV9FdmzX3QF0HlmMTuyEepFkg5O383njx7oAjbicdw6Mp6SrMkA/640?wx_fmt=jpeg)


护眼仪的内侧则是这款产品的核心部分，可以很明显的看到中心的区域是向内凹陷的，周围有八个凸起的圆点分散在四周。带上护眼仪之后，这些圆点的位置分别对应攒竹穴、太阳穴、睛明穴和四白穴，这四个穴位就是我们做眼保健操所按摩的穴位，护眼仪在工作的时候会通过振动的方式，来实现对穴位的按摩，解决了孩子找不准穴位和手按力度不均的问题。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXFrypTl8hNFIYOZEjTqNC7txnH87NgPyqmFPCAqspVACJQYOamHaAmSvtEtXvdYWHcCnLmQ6GLLhA/640?wx_fmt=jpeg)


中心内陷的区域正好是对应眼睛的位置，这个区域也是护眼仪的热敷区，也是放置叶黄素眼贴的位置，凹陷的设计不会压迫孩子的眼球，同时还可以让护眼仪对双眼实现360°全方位的包裹，实现笼罩式的热敷效果，能让叶黄素眼贴所释放的营养物质，更加充分的被眼睛吸收。只需要20分钟，就能让眼睛吸饱营养，护眼效果1+1＞2。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXFrypTl8hNFIYOZEjTqNC7ttPZsrcDO1FCQcMibeuiaNe5kzUXRBosibPIax0tIRURaMDW6EfZEApryA/640?wx_fmt=jpeg)


和我们常见的护眼仪不一样，喵喵儿童护眼仪Pro采用的是磁吸式的分离设计，眼罩部分具有按摩和热敷的效果，而控制器则负责提供电力和发送指令，别看这个控制器的身材很小，功能却很强大，它内置了790mAh的电池，若是按照每次按摩5分钟来计算，差不多能用12次左右的续航。另外，它还支持与喵喵机手机APP互联，通过手机可以解锁护眼仪更多的功能。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXFrypTl8hNFIYOZEjTqNC7tCmuMUPmtKrgrLbOutO5ySP167qicHnv0hSJV0ia9HBpwC5oL7kfV7ibgg/640?wx_fmt=jpeg)


至于APP的操作，其实非常简单，长按开启控制器之后，在APP中立刻就能匹配连接。连接成功后可以看到，所有的功能都集成在了“护眼”的板块中，通过APP我们可以调节音量和按摩力度的大小，开启或关闭热敷和按摩的功能，还可以选择眼保健操或睡眠模式，在睡眠模式下还提供了很多可以点播的内容。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXFrypTl8hNFIYOZEjTqNC7t9Cic4E18pnlHlXff9O7gvATM1wB3sAiaPdzFWw8VaiadI1USNFbV6q7vQ/640?wx_fmt=jpeg)


在实际的体验中，这款喵喵儿童护眼仪Pro佩戴起来非常方便，重量也非常的轻盈，全身只有80g左右。我女儿说戴上之后有种软软的感觉，一点也不勒头，而且也没有负重感，无论是坐着戴，还是仰卧的姿势，戴上去的感觉都很舒适。长按控制器开机之后，护眼仪默认就会开启眼保健操模式，同时播放眼保健操的音乐，短按一下可以切换到睡眠模式，每种模式做完之后，还会发出滴的一声，然后自动关机。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXFrypTl8hNFIYOZEjTqNC7tlcGD0AZd8QKfK2EUX6NaibJuB6XCK0WFMhwoyRLr42EJbUibvA4c1FiaQ/640?wx_fmt=jpeg)


很多低年级的小朋友，眼保健操做的并不规范，很难理解穴位和按摩的力度，使用这款喵喵儿童护眼仪Pro则解决了这些弊端，护眼仪内侧八颗震子正好对应了按摩眼睛的四大穴位，不仅定位精准，而且经过多次的佩戴，孩子现在无需使用护眼仪，也能够准确的找到对应的穴位。对于按摩的力度，喵喵儿童护眼仪Pro支持两种力度的调节，根据孩子的耐受程度，可以选择适合自己的档位。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXFrypTl8hNFIYOZEjTqNC7tYMdBCuHj5N3dChwDmib9aDoA1HkiaHcviaDbThovt9bKIBdz2skiaaqoyw/640?wx_fmt=jpeg)


对于我来说，最在意的是孩子在长时间用眼之后，能不能快速的缓解眼部的疲劳，以前的常用的做法就是让孩子望向远方几分钟，让眼睛慢地放松。但通过搭配叶黄素眼贴，使用喵喵儿童护眼仪Pro热敷过后，孩子给我的反馈是很舒服，她说她喜欢热敷时暖暖的感觉，能让眼睛周围的肌肉变得很轻松，尤其是上完网课之后那种眼睛干涩的问题，很快就能彻底的缓解。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXFrypTl8hNFIYOZEjTqNC7t6fIe7S5BDYLenOgtKxtzXicCJuau8eiamakfwMnAtMUfpsQs9p4CFiaQQ/640?wx_fmt=jpeg)


另外要说的是，喵喵儿童护眼仪Pro的睡眠模式也很实用，在晚上入睡前佩戴好护眼仪，通过手机APP，能够播放助眠音乐，或者是收听睡前故事，这对于家长来说，绝对是一款哄娃入睡的神器。这里还要提及的是，APP中内容非常丰富，它集成了聪明学系统，除了助眠音乐和睡前故事之外，还有海量听学内容，所以它不仅可以助眠，还能在放松眼睛的同时，收听到一些有助于学习的内容，丰富孩子的知识储量。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXFrypTl8hNFIYOZEjTqNC7tJCKnWn0NYLxHybQIUaPD2HCvEWVLGQDT64oduXGmxEuCfDlaUK9mkw/640?wx_fmt=jpeg)


在体验了一段时间之后，孩子对于这款喵喵儿童护眼仪Pro的评价很高，首先它教会了孩子眼保健操的正确做法，即使在学校没有佩戴护眼仪的时候，也能够准确的找到穴位。另外就是按摩和热敷时的感觉确实起到了放松眼部的效果，尤其是搭配叶黄素眼贴，效果尤为明显，再一个就是基于APP的强大功能，赋予了护眼仪更多的功能，让它不仅仅具有护眼的功能，还能成为一个助眠神器、一个听学帮手。这样一款一举多得的喵喵儿童护眼仪Pro，你觉得它怎么样呢？
