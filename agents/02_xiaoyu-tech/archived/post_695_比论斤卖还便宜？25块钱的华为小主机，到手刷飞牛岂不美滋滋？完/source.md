# 比论斤卖还便宜？25块钱的华为小主机，到手刷飞牛岂不美滋滋？

今天在二手鱼刷到了一款标价25元的华为小主机，描述里写着“单位退下100多台，懂行出，充数顶帐”，还附带一句“发货前给开机视频，没售后”。好家伙，典型的“清仓甩卖+自求多福”组合拳。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXF46IsY6rrQtFT5NMnNbkshHADVz0HuJkh3ZGQDLTw5fFibFZuhHBeWibyPibICR5hCic54JLrVOUiaPbg/640?wx_fmt=png)


先说说这东西到底是个啥。华为CT3200和CT3100其实是早年运营商定制的瘦客户机，主打远程桌面、云办公场景。硬件配置嘛，查了一圈资料：搭载的是Intel Atom D2550双核处理器（1.86GHz）、2GB DDR3内存、16GB SSD（部分型号可能为机械硬盘或eMMC），接口方面有VGA、USB 2.0若干、千兆网口，部分版本支持WiFi和蓝牙（看具体批次）。系统原装一般是Linux或定制版Windows Embedded，但因为是x86架构，理论上可以刷各种轻量级系统——比如飞牛（fnOS）、OpenWrt、PVE，甚至跑个Debian当软路由或者NAS都勉强能用。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXF46IsY6rrQtFT5NMnNbkshxIKZjHYr8eCicPUYa1EoOEs9IXHXMKabIMNLmibKnC1mqbuKyk91fYGA/640?wx_fmt=png)


乍一看，25块钱买个能开机的小主机，性价比爆表，但别急，咱得冷静分析。首先，这玩意儿性能确实很“复古”——Atom D2550是2011年前后的产物，功耗低但性能弱，其次16GB存储空间几乎等于“裸奔”，装个系统就剩不下多少余粮。再者，没有官方售后，万一收到就是板砖一块，只能自认倒霉。卖家那句“没售后”写得明明白白，属于“爱买不买，买了别哭”的硬核风格。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXF46IsY6rrQtFT5NMnNbkshhjNF3iaD0dvIEDo75pjkmicIicHOhu7C7aUQBMlBTenntGV2K7KuLyibTQ/640?wx_fmt=png)


不过话说回来，25元的价格确实离谱地低。正常情况下，这类瘦客户机在二手市场成交价多在50-100元区间，尤其带电源、成色好的。如果真能25元拿下，哪怕当电子垃圾拆零件（比如拆个千兆网口模块、小机箱、电源适配器），也不算亏。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXF46IsY6rrQtFT5NMnNbksh2iclRPOQyqMnkfTLjxpCb14Jibry1iczmq5xOMVt5mbcoxbib6nZSxZia9g/640?wx_fmt=png)


更何况，对于喜欢折腾的极客来说，它体积小巧、功耗极低（整机约10W左右），挂墙上当7x24小时运行的监控主机、下载机、或者家庭自动化中枢，倒也说得过去。拿它刷飞牛系统做轻量NAS，虽然跑不满千兆，但传个文档、备份手机照片完全够用；也可以改造成打印服务器或者广告机，属于“废物利用天花板”了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXF46IsY6rrQtFT5NMnNbkshUXmwcFRpcu2OzOOuNRXp1Q9Bz5CoRCVQ0US3N23ASiaWGNjlGKmsnpQ/640?wx_fmt=png)


如果你感兴趣的话建议在二手鱼搜索关键词“华为CT3200 CT3100网络计算机”，如果文字搜不到，试试用图片反搜——上传一张同类机型图，平台有时能匹配相似商品。要是还是找不到，大概率是刚上架就被秒了，或者已下架，毕竟这种低价好货流通极快。


 


以下是个人一些掺了水的建议：

1. 折腾党可冲，实用党绕道。

2. 别指望性能，图个低价玩玩。

3. 务必要求开机视频，防坑第一。

4. 看完不买，立省25元。
