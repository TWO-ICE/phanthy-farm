# 二手鱼惊现720元全新惠普“韭菜盒子”主机，到底能不能捡？

![封面图](https://mmbiz.qpic.cn/mmbiz_jpg/E9h3abOJCeneW8XryBoDMokDu84XY3Kaw29IQoSqZeBueqd3VuE1tm5Q8yykMomF80GIHCXGspwiaqt6DgcGhfdicKoSERHMRhiantsgZo5FMA/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/CyYJhMPtFIeQsC7uicrD5w

刷到了一台惠普的小主机，标价720块，我以为又是哪个工厂流出来的洋垃圾边角料，结果点进去一看，好家伙，全新带原厂包装，还有两年官方质保，惠普mini pro 400 G9准系统。这价格说句实在话，这个价位买个准系统，说白了就是个空壳子，价格真的不算便宜。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemicwaKtK0H4lpYHicXIXiaTRBibsWBWoB9IibXnUR6y0vCkYZyibFl0yW4McKNvHibSdE3xvIwYWibVyQzhUlBt7608SoP6wjyMjVs3jQ/640?wx_fmt=png&from=appmsg)


咱们来捋一捋，720块钱买到了什么？一个17.5厘米见方、3.5厘米厚的小铁盒子，1.4公斤重，接口倒是挺全乎，VGA、HDMI、DP加起来四个视频口，还有Type-C，五个USB，有线网口和无线网卡位置也都预留好了。做工是惠普商用机的那股扎实劲儿，这点没得黑。但问题是，这玩意儿它不能开机啊。你得自己配CPU、内存、硬盘、电源，这一套下来，稍微像点样子的配置，奔着两千多甚至三千就去了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekYCGIibwSxyPwMDm3Dtaia2YCOfslst8jF46dicO6OHPzdfv4tk5cyWv0TWf2zu4Q65YyVxsS6xMPZiaFicDgKYx9H7te182Q8Dbib0/640?wx_fmt=png&from=appmsg)


720块钱在二手鱼里能淘到什么？能淘到一套成色不错的戴尔或联想的小主机整机，比如M720q或者M93p这种，配个i5-8500T，8G内存，256G固态，拿回来插电就能用，还能黑苹果、软路由随便折腾。甚至加点钱都能摸到一些二手的笔记本了。所以单看准系统这个价格，它确实没有那种让你闭眼冲的冲动。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemSM8icmXsKPd91zBQ0GBWkTibBCUCUv7D7hTgh66npibC3emK3zfr2yoKYA3jIfCcohCIbLlMv0uoojrUeLjC0IDUsRj0MOVxSbg/640?wx_fmt=png&from=appmsg)

但为什么我说它是同型号的地板价？因为你去搜一下就知道了，其他家在卖的400 G9准系统，哪怕是二手的，普遍也在八九百甚至上千。它这个720块的全新带保，确实是比较良心的价格了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenH78IH0341CIbB574HruacuGppicUIbGrdOesicgD3phkmibnzE9wCAHqVgvmnZ70rnQfHQDIztWOQOticibCVjC5e1vWlhbENWZ1c/640?wx_fmt=png&from=appmsg)


这里面的逻辑是这样的：如果你手里正好有闲置的12代、13代低压CPU，比如从报废笔记本上拆下来的，或者你有渠道能搞到便宜的ES版CPU，手头还有DDR4内存和M.2固态，那这720块钱简直就是为你量身定做的快乐。你可以用极低的成本，拼出一台性能在线、接口丰富、体积小巧、还有官方兜底的主力机。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemCyOP5sAJ0aHodKkfN7iadUpWKc8mGtxPiaScZOu7lv1DISwfP5JUtTL0k8c1mbhCtD8968jFhCc4Pd98ESZlrtPiaW9y3vqTicSg/640?wx_fmt=png&from=appmsg)


另外他还能刷飞牛，而且可玩性非常高。这种Intel平台的小主机，驱动兼容性出了名的好，不管是飞牛私有云系统，还是PVE、Unraid这些虚拟机平台，或者是当成软路由、HTPC、HomeAssistant智能家居中枢，都能完美驾驭。UHD770核芯显卡的转码能力也够用，挂个影音服务器绰绰有余。对于爱折腾的垃圾佬来说，它就是一个能装进包里的百宝箱。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelTYHmTDIvvGrsCbpnoAyZPPNcG9WTQKvAic3wiahKkZQTOicT88zFChgOLwuI4r2YCma6UcMp7jDtVG2FPjYd3k2YtdhWsbfAVPU/640?wx_fmt=png&from=appmsg)


最后提两个建议。

- 如果你是纯小白，想买回来当主力电脑用，建议直接放弃这个准系统选项，转而去买那些已经配好内存硬盘的整机，或者直接去二手鱼蹲一套品牌二手整机，省心省力，不用瞎折腾了。
- 如果你是冲着刷飞牛或者玩虚拟机的，建议提前算好成本，CPU选个T系列的功耗低，内存直接上16G起步，硬盘弄个大容量的，这一套配下来虽然比买成品贵，但乐趣和自由度是成品给不了的。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelm1sx81iaQH2wNw2wZYsRcnlZ2Ciad6GxpPffsu9G2JJqVGxaicz6nHwNibf9zQjBKicuibvgUIx8UABvxSXO0rbX9ryD0DWrxLVJjc/640?wx_fmt=png&from=appmsg)


这台720块的惠普准系统，你是选择盘它还是直接划走？手头有闲置配件的朋友们，评论区聊聊你们都打算给它装点啥？
