# 挖到宝了！45块钱包邮的海康录像机，+150送1T硬盘，这波冲不冲？

前两天在二手鱼里闲逛，本来是想看看有没有便宜的摄像头，结果刷着刷着，看到一台海康威视的硬盘录像机，45块钱包邮。这个价格要比市面上的低很多，卖家描述写得也挺实在：用了一年，成色一般，但机器性能很好，支持萤石云，能接400万像素的摄像头。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/E9h3abOJCen99LIQsNPGUc527YibFgtnwCkOKZmHZlhRVLlba3ss5k6Legp7aDbYHDemy0ibDyiboxicVdRRSlpXZ2XnB5msDWb4cKbPuXD0icsw/640?wx_fmt=jpeg&from=appmsg)


这台机器是海康威视的DS-7804N-F1，四路硬盘录像机，最大支持400万像素的摄像头，H.265编码也兼容，最让我心动的是，它支持萤石云，绑个APP就能手机远程查看，随时随地看看家门口、店里的情况，这功能很实用。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCel3j7dxD6b7AVxI2LrITNCEIPRXDr249rZhTMe13Kuqq6jEZiaHKcFjXh6q0bnukfh0yCHywia8jE9eOY7CfQicF1YZjWv1m1yTdU/640?wx_fmt=png&from=appmsg)


卖家说用了不到一年，成色一般，但性能没问题。后配的是小米1.5A电源适配器，已经恢复出厂设置了，还送一根高清视频线。这种一看就是个人卖家手里的东西，往往比那些批量翻新的靠谱多了，至少你能感觉到他是真的在用，不是倒腾机器的贩子。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenUib4Kic22b7kTElvQXggKjVhrX7VU7PvFo4JU1jP6xqDvuyhcpSAHs7zicMVwedP6RbNGsjIu7SDCoauRqF0U3M3tLicjiaDfow2o/640?wx_fmt=png&from=appmsg)


这里纠结的是，卖家说加150带一块西数海康威视的1TB监控盘。我特意去查了一下现在二手硬盘的行情，1T机械盘市面上普遍就在150块左右，所以这里并没有坑小白，而且这块盘是他自己机器上一直用的，通电时间清楚，有没有坏道也门儿清，不像去市场上淘，你永远不知道上家拿它干了什么，所以带上这块硬盘也是值得考虑的。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCel1nf4DRicun1clR1mWbaSmLqsudGnZeyiaw2fK6iaeDicAWibrEWpwIJ8IBicFelHIphMTAgWj15X4hDOcsYgfApEeMYjv1KLBrciahA/640?wx_fmt=png&from=appmsg)


当然，这东西也不是十全十美。四路的主机，最多接四个摄像头，家里房子大或者想做全屋监控的，肯定不够用。解码能力虽然能撑起400万像素，但毕竟是上一代的产品，想追求那种秒级响应、智能识别的，还是得加钱上新的。但话说回来，对于大部分人来说，看个门口、看个院子、看个仓库，四个头完全够了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekdlBrh3gwA3GgYiaLY84HMia5hjr9Sjk7UJxeqIcfz214dW8NIrAbacOcL38f90yNqAOYVr3nw6Ty2ydVSI2gG5JIuXiaibDWQIdA/640?wx_fmt=png&from=appmsg)


我觉得在二手鱼里淘东西，最大的乐趣就是这种“挖宝”的感觉。有时候不是东西多贵，而是它刚好是你需要的，价格又刚好合适，这种恰到好处的相遇，最让人开心。
