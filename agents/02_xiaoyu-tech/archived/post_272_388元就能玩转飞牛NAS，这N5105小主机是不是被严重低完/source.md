# 388元就能玩转飞牛NAS，这N5105小主机是不是被严重低估了？

最近在二手鱼里发现有一批N5105的迷你主机，准系统388元起，看了以下卖家的展示图，感觉这主机还不错，包装盒配件齐全，基本就是新机，虽然不是内存和硬盘，但388元的价格并不算离谱，有兴趣的话可以研究一下。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemwWtZ785s2IAUzZlsibAhWEKRgSlRdsp4gHVLAymvd1rgCiaaQ2VNDaM6UgC3GgOTJ7RZ4icwoKicsz4dY44eereMhPrvwxtBaic7A/640?wx_fmt=png&from=appmsg)


卖家说主机的型号是GK3 Pro，核心就是英特尔N5105，4核4线程，最大睿频2.9GHz。这U在移动端里不算啥，但放到这种小盒子里，就是妥妥的“能耗比之王”。待机功率就4到7瓦，一年到头开着，电费也就是个零头。而且它自带一个CPU风扇，解决了N系列被动散热容易降频的老毛病，这点必须给个好评。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekF9Injr90vnzXMoibpah3ZA0X4eLQYcFbxjIsrMg9kopXcnKlwZwSjFngCrhfvlKa93IpVMJcH0yjZ0F1qxQdWIho0JS8maGbM/640?wx_fmt=png&from=appmsg)


接口方面，一个千兆网口，两个HDMI加一个VGA，你能想到的老显示器它都能接。还有两个USB 3.0和两个2.0，插个U盘、接个键鼠完全够用。虽然只有一个DDR4笔记本内存插槽，但给了两个硬盘位：一个M.2接口，还有一个2.5寸SATA硬盘位，甚至把硬盘线都给你配好了。回家随便找根闲置的8G内存条，再插上个淘汰下来的老固态，一套完美的双盘位飞牛NAS就齐活了。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenb3t59k8aaK3bicUtnOFTxicGib2K6FJYOlbnMicjY9ZOfmqOUsicKGTfbUjMVONkCZgxddye1B85QWLYZptfxicWJ10sJ9oYicPvJ4o/640?wx_fmt=png&from=appmsg)


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCen7o3qMeZjywACo0glORtODHPGYicCmgyAiaAeQHBcM32vBzkWJ9wTIqwPXUgz2p3sQakKalM0fcJJUUBcUW4zm9CusDWJh2Nh6k/640?wx_fmt=png&from=appmsg)


这机器到底值不值得冲？咱们得从两个角度看。先说优势。388元买一个能稳定运行飞牛的物理机，性价比还是挺高的。卖家还提供了丰富的加装选项，虽然内存条的价格因为最近涨价变得有点“变态”，但你自己去二手鱼淘一根8G的DDR4，也就百来块钱，比卖家的258元良心不少。而且卖家能帮刷各种系统，对于不想折腾的小白来说，到手即用确实省心。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemCOO9DsJ8dPsDr4iasibYxOiadv4yUaLONx8QqFbwr6fViag3PXSibcy3ib4BeAlBciaQXGVRjsG9MsIehV1v5jrvDpPDrAQZpn3y2iac/640?wx_fmt=png&from=appmsg)


再说说它的槽点。最大的硬伤就是那个千兆网口。如今家里宽带动不动就千兆甚至两千兆，一个千兆口做软路由，物理上限就被卡死了，想玩链路聚合也没戏。如果你单纯想把它当成一个旁路由或者NAS，那完全够用，但要是想让它当家里的主路由拨号，那就算N5105性能再强，这网口也是个瓶颈。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenPiaibFsyHl0MKPmqBCjzSXuAn3hpOvwdk8B4v1n1V7ZwWxr9GmZjpC5oZAnk5ad6b7RTFNfcZUDG3o6kMK8byqXn1CDhta3lzk/640?wx_fmt=png&from=appmsg)


我觉得这台机器的受众非常精准。它不是给追求极致性能的玩家准备的，而是给那些想要一台低功耗、24小时开机的玩具的人准备的。如果我要买，肯定不会选它加内存和硬盘的套餐，因为溢价太高。我会直接388元拿下准系统，然后去别的摊位淘一根8G内存和一块256G的NVMe固态，加起来600左右，一台完美的小主机就落地了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCek5WFSviaPSiayrgF265BK4nOeeR5oZHAgrfRn4BtNoJ9fljanUEHTCI7oAIk4RicTjIc0OdarEc2xoySwIR9dy0CqRW44BccDt2c/640?wx_fmt=png&from=appmsg)


最后想问一嘴，这波388元的准系统，你是打算入手当个NAS圣体，还是想整回去给家里的旧电脑做个替身？或者你也在关注那只会聊天的“龙虾”？评论区聊起来，让我看看有多少老铁正在准备出手！
