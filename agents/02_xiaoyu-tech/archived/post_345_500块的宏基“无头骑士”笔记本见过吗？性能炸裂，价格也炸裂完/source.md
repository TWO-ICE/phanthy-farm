# 500块的宏基“无头骑士”笔记本见过吗？性能炸裂，价格也炸裂

笔记本的下半身，除了压泡面，还能干嘛？我在二手鱼刷到个神奇玩意儿：有人500块在卖宏碁Acer One 14的“下半身”，就是不带屏幕的那部分，让你接个显示器当小主机用。所以说二手鱼里，永远都会有你想象不到的玩意。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHaOnQNIneFJrx8fvXHXibY2GbVXHgxhIfW6Vtmibswb80icJ7kHDAODVey7FhlUu5ZZuANBHF0zuHxQ/640?wx_fmt=png)


先看看这500块你能买到什么。核心是一颗英特尔第十代酷睿i5 1035G1处理器，四核八线程，基础办公、看个4K视频都还能扛得住。接口才是它的亮点，居然给了两个DDR4内存插槽，一个M.2硬盘位，HDMI、Type-C、三个USB-A、网线口、SD卡槽全都有。这扩展性，比很多迷你主机都大方。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHaOnQNIneFJrx8fvXHXibY2BNoSoAV13HbFgpr4ZGGSJqw5WsV4rQfDr1ysMOUlibuDswOKibY6kpCg/640?wx_fmt=png)


宏碁One 14当年是主流价位段的办公本，如今500块买个十代i5的“准系统”，性价比听起来确实很炸裂。但是，先别急着喊“真香”。咱们得聊聊它到底适合谁。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHaOnQNIneFJrx8fvXHXibY2FXvfGTb4LvOlQDF3TuibXdChQbE6bPsHL5HGQnvicdnKzJvDVNLeTQ8g/640?wx_fmt=png)


如果你预算极度紧张，想在宿舍搞个能写论文、刷网页、看剧的固定据点；或者你想给家里老人组个炒股机、网页浏览终端；又或者你是个喜欢折腾的DIY玩家，想弄个超便宜的软路由、家庭服务器试试手。那它，可能真是个不错的选择。500块，还要啥自行车？


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHaOnQNIneFJrx8fvXHXibY2MgrPtwJwJgjNn79nSic3xm84AicxXGbKczeClxQhM1su5FOxichBz3vtw/640?wx_fmt=png)


但如果你指望它打游戏、做重度剪辑，那趁早放弃。它的性能定位就是日常轻办公，而且集成显卡性能很一般。最关键的是，你得接受它作为“残骸”的现状。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHaOnQNIneFJrx8fvXHXibY2ygHNNDenuETMia27Gd7I45ee7XzTPwVATaq3vtOicEftnlNrMYc9Qc3Q/640?wx_fmt=png)


卖家描述很直白，但也隐藏了一些关键信息，我帮你拎出来，介意以下几点的话，建议慎重考虑：

内置电池寿命如何没说，很可能已被取出或已报废，这意味着你必须一直插着电源适配器使用，断电即关机。重装系统有坑。一般无头其实开机可能不显示BIOS界面。它只是个“光主机”。你需要自备内存、硬盘、充电器，这又是一笔成本。一套8G内存加256G固态，再加个充电器，二手市场再掏个一两百很正常。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHaOnQNIneFJrx8fvXHXibY2B0HFjfoQxYheBAdjffagrTr3icacYTdKW53xNSjJb7YhBU1F2GA4iaHg/640?wx_fmt=png)


把它当主机的弊端也很明显：首先它并不“迷你”，还是笔记本底座的尺寸和造型，摆放要占地方。其次，所有接口都在一侧或后方，接线管理可能有点乱。所以，这500块花得值不值？完全取决于你的需求和使用场景。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHaOnQNIneFJrx8fvXHXibY2tBhKpRBRpzk3ZEMEpqgzLoZ2yyGgCj3Ngf3ZkazXoqFVxMHeBQo4iaA/640?wx_fmt=png)


如果我要下单，我会把它塞在显示器后面，就像挂这个mini主机一样。另外配个8G内存和一块便宜的固态，专门用来做文档处理、挂下载任务，或者当成家里的第二台备机。它的结局，很可能是在某个角落默默服役几年，然后因为某个零件损坏而彻底报废，残值几乎为零。但这过程里，它已经榨干了最后一丝价值。
