# 不是新固态硬盘买不起，而是二手拆机的更有性价比，256G固态卖115块香不香？

![封面图](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXFJPEuRYFNicMXBKjuU2SG6vUSo3MBskMEuk5hIwPIh0VUw3H51QEBUrLkBocdrnrAycCMpxozkPdA/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/axjW6rHckTzjE-GJiQj7-g

都知道现在存储产品的价格在疯涨，之前看新闻上说100条内存就能在上海换到房，真实离谱到家了。而硬盘的价格也同样是水涨船高，但对于垃圾佬来说并没有太大影响，因为不是新的买不起，而是二手的更有性价比，这不就在二手鱼里看到了一批二手的固态硬盘。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFJPEuRYFNicMXBKjuU2SG6vpCsZnZibB2bsticLLH2Iure7Zp0HyIlPWIkibTHVVtS9OHSGv3u2Z1WtA/640?wx_fmt=png)


卖家挂的是“拆机品牌256G NGFF M.2固态硬盘SATA协议”，标价115元，还送螺丝和螺丝刀。乍一看挺实惠，但得先搞清楚几个关键点。首先，它用的是M.2 2280尺寸，这个规格现在绝大多数主板都支持，不管是老笔记本还是新台式机，基本都能插。其次，协议是SATA，不是NVMe。这点特别重要，很多人一看到M.2就以为是高速盘，其实SATA协议的M.2速度上限也就550MB/s左右，跟普通2.5英寸SATA固态差不多。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFJPEuRYFNicMXBKjuU2SG6vwhqJMx6licRfPN0VDOS349rlRuz8rRX3fuaTYzNP2ibibPsoOqBPTvQ2g/640?wx_fmt=png)


从品牌来看，海力士、东芝、镁光、西数、建兴、金士顿这些大厂都有可能随机发。虽然说是“品牌”，但毕竟是拆机件，来源可能是淘汰的办公本或者翻新机，寿命和写入量没法查。不过卖家承诺“包点亮”，还给一个月质保，这在二手鱼里算比较良心了。至少不是那种“售出不退、坏了自认倒霉”的套路。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFJPEuRYFNicMXBKjuU2SG6vnp09bKVHKic8rowOQSb94gtulPiaVokT8T5HXiaSunBzP9rYVg0FCDm1A/640?wx_fmt=png)


这类盘现在还能干啥？装个轻量级系统完全没问题，比如用来跑老旧办公软件、做下载机、当家庭NAS的缓存盘，或者给老电脑提速。如果你只是想把十年前的笔记本从机械硬盘升级成固态，那它确实够用。但要是拿来频繁读写大文件，那就别指望了，SATA协议本身就是瓶颈。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFJPEuRYFNicMXBKjuU2SG6vWibdVxjxqC15oAeNHzNzSgncUWiaELUHzjORWOZBUwECTIiaPyNaLtI8Q/640?wx_fmt=png)


可能有人会问115元买256G是不是太贵？毕竟新盘现在200出头也能买到国产SATA固态。但你要知道，新盘有三年质保，而这个只有一个月。优势在于它是大厂颗粒，稳定性理论上比某些杂牌新盘强，但风险也在于它是二手，没人知道前任主人写了多少TB。所以值不值，全看你敢不敢赌这一个月内不出问题。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFJPEuRYFNicMXBKjuU2SG6vib8icqkULFrrOGm7bppJ8Trf7UmBdxCR94klaibKt5VTufGazhz76a67A/640?wx_fmt=png)


那么能不能当主力盘用？建议别。万一数据没备份，一个月后突然掉盘，哭都来不及。它更适合当临时系统盘、测试盘，或者给不重要的设备用。比如刷个软路由、做个树莓派扩展，坏了也不心疼。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFJPEuRYFNicMXBKjuU2SG6vYqNIEN0Iicib0VGe0nZ034171v2y46eYdQLiaTyLgkz9RnPJNH4oALpVg/640?wx_fmt=png)


对此产品有兴趣的话，可以在二手鱼搜索“拆机品牌256g ngff m.2固态硬盘”这个关键字就可以找到此产品，如果找不到可以通过图片进行搜索，都搜索不到的话，那可能是此产品已卖出或者是下架了。


 


以下是个人一些掺了水的建议：  

1. 老电脑升级可考虑，新机别碰。  

2. 别存重要数据，当消耗品用。  

3. 有备份习惯的人更适合入手。  

4. 看完不买，立省115元。
