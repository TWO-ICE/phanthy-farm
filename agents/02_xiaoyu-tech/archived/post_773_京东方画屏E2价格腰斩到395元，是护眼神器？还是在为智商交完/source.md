# 京东方画屏E2价格腰斩到395元，是护眼神器？还是在为智商交税？

![封面图](https://mmbiz.qpic.cn/sz_mmbiz_jpg/E9h3abOJCenkUPT5mFJ3lUNiagNtOpTKVAp9aickc0qqmKKElACzeiafphlC4wuv7oYbL9NJZHgTCtoCgXuCJYAHIGkcFKw0NpicXpqbOwicQPlA/0?wx_fmt=jpeg)

![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelcz9Mef57022bPAH52laNliad9xibfKa8fhBHNUVc5TYFx5fZzWK1N9XD794gn7s5133m1Az1Jg3F8Txicyd83MhagOY2LacCGNk/640?wx_fmt=png)


二手鱼里刷到一台京东方画屏E2，卖家标价395元，带遥控器和电源线，型号21A800，21.5英寸类纸护眼屏，支持投屏和安装第三方软件。说实话400块都能买到27寸的显示器了，那这个京东方的护眼屏还值得买吗？


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelyBSrdwosUB34Kc67lgqlrQ4jocTnOLcH6RdvYXhOSDicD69HQQChOlib1VUSFc7Licuib8vfGlFqkiaQGmibDqgN4MQnzfXEn9KvVg/640?wx_fmt=png)


这玩意是京东方首款医工融合的类纸护眼网课学习屏，当时电商平台售价在一千五到两千二之间。现在二手鱼395元，差不多是原价的四分之一。同期二手鱼上27英寸普通显示器，戴尔大概399元，惠普老款甚至90到140元就能拿下。画屏E2比普通二手显示器贵了这么多，贵的这部分就是它的护眼技术溢价。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenTMpia5Uf6VFXkMGiaicmziczrVKp3RgT6n4y6IT1HIQeGyShmS1VrrtGCLHichmIoFg9Xyiabn5Eo0iaQa9UwAsA4slBvulQwlTo980/640?wx_fmt=png)


硬件配置方面是21.5英寸1920x1080分辨率，ADSDS面板，亮度200尼特以上，可视角度178度，内置音箱，支持横竖屏切换。接口有HDMI、USB、MicroUSB、网线口和耳机口。处理器1.5GHz四核配1G+8G存储，卖家说能安装软件，应该是破解过。重量3.2千克，背面有75x75毫米壁挂孔。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekQ9Bsl1usqT3n4ic9quyN5koTuicqibOnmWnqibDSKZtic9RzzQ4OVncQ7gackDeflnqcwSTkpOdRmOTx5RTwiaG4CKg8S0EiaibL8h1c/640?wx_fmt=png)


这玩意的短板挺明显，屏幕不带触控，处理器和存储配置比较低，如果你就是当普通显示器用，那同价位戴尔或者百元出头的惠普老款，论性能论流畅度甚至可能更靠谱。但如果你看重的就是类纸护眼的体验，或者想给家里孩子弄个护眼网课设备，甚至打算花一百多配个升降支架改成“闺蜜机”玩玩，那395元的价格确实是把原来一千五的东西打下来了。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenUGmoicwt4iaWCKgGQhRgwLlox5vDBqNwGSezaQDm0B6FVZO8PcJsiajKAbNcNLUtLbIiagibZMgzhEmNlDMQq2TRBXrutGPE97ibXg/640?wx_fmt=png)


有几个细节值得注意。卖家说可以安装第三方软件，但官方系统本身有限制，所以这款肯定是已经刷好的。还有机器有使用痕迹和划痕，屏幕是磨砂雾面处理，防眩光效果好但确实容易落灰。接口只有一个HDMI，想同时接电脑和电视盒子不太方便。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenaWGJuC1dUL8F0NNctkZibbgFMV7zYpPwgecwKSaDtc5N61jYquHEfUgaBbuENxYEUEKSPqZtibAd73WFhxXMu0lkafI4vfvibtM/640?wx_fmt=png)
