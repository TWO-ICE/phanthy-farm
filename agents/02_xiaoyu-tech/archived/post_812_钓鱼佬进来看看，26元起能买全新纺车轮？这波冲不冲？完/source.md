# 钓鱼佬进来看看，26元起能买全新纺车轮？这波冲不冲？

> 原文链接：https://mp.weixin.qq.com/s/G2LFRJ-mt2MNEnWhlQ3rqg

最近刷二手鱼总被钓鱼佬的帖子刷屏，点开一看差点笑出声，小高尔夫纺车轮居然跌到26元起！要知道这货当年可是入门级神轮，原价90多的时候新手都抢着买，现在价格直接腰斩两次，连老钓友都直呼看不懂。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenLfibO0YZK8v7SpRCibSMt2CPOjml2L70OaSGVibicMvSSgCYqAb41htu2KjMEA0NgWInial4xkBQKAecWt2h5L52APOldKiazTreGE/640?wx_fmt=png)


先说这配置到底值不值？13-1封闭式防水轴承听着就专业，实测下雨天甩竿也没卡顿。斜口金属线杯出线顺得像德芙巧克力，5.2:1高转速比收线快得飞起，左右手互换设计对左撇子太友好。最狠的是8公斤刹车力，钓5斤左右的鲤鱼完全不虚，加粗导线环更是杜绝了炸线尴尬。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelmaUNlVJMibUlhiaYJPMOE1obmB9XS7m5mDXQ1ibDPmrnHwdZYTu5Cp7DsDsKutWV4Ria0uYNuGeYdeFRiaiawLUBHhsEt5xBe7ibiabQ/640?wx_fmt=png)


不过金属党要失望了，线杯是金属的但部分配件用了工程塑料。不过换个角度想，260克的重量比全金属款轻了近三分之一，持竿一天胳膊也不酸。深线杯从1000到7000型号全齐，浅线杯1500/2500适合玩微物路亚，这阵容比某些品牌单型号卖还全。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemDtPJdmh9C3dibJ6y3oaADrcAuGhICGP2WX3rhkAUo9icSh8QTTuib3CDs4DmPqRITQPdT5X5aM0xEFN9CWvNX5RU1xtB3JEPNo4/640?wx_fmt=png)


当年这牌子可是和达亿瓦掰手腕的存在，现在沦落到清仓价确实唏嘘。但换个思路，二十多块买个备用轮不香吗？新手练手摔坏了不心疼，老炮备个不同线杯型号也实用。C3000型号装0.8号PE线能缠150米，钓个鲫鱼鲤鱼完全够用。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemrXB2jqNFIicRlmSW44uLjbw2fXIxtjeawCoic0jDQtqSezXmsu3lV3FMAHr86oZ08qr5zWL9KtCs0ibsCbjtLv4IdTTcpTHfjag/640?wx_fmt=png)


如果下单话，我感觉C3000深线杯比较划算。周末去郊区野河钓鲫鱼，主线1.2子线0.6，配个吃铅1.5克的芦苇漂，这配置钓小个体鱼简直降维打击。要是玩路亚就选浅口C1500，装1号PE线甩小亮片，马口白条能钓到手软。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekZhBBJqr9xJ5ZLVOxsdjR3tKLdTLpPQoGc6z2WURHPduEibhjJRtlUHvNZlVswFNFyZHeMRQMNNaGQjm5M5tRVUoKxyJgnx6NI/640?wx_fmt=png)


最后说句大实话，这价格要是买到翻新货就亏大了。建议下单前让卖家拍线杯内侧钢印和轴承特写，全新未拆封的轴承应该泛着金属光泽，线杯钢印清晰无磨损。收到货先空转摇臂，顺畅无异响再确认收货。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemia4TLGc3n81eglwsvQubQ5RPCD7YkNSLoiaPKRtuU0bpTsKssODfNWXl1n6msUFDvQhjWhyk8don3FtblFaAtpp7AiapkZ1y6Tw/640?wx_fmt=png)
