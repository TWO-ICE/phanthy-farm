# 二手鱼H3C的飞牛NAS圣体标价90块？价格确实不贵，适合新手小白

今天在二手鱼刷到了一台标价90元的H3C小主机，卖家说是飞牛NAS圣体迷你小主机，而且还写着现货800台，貌似量大管饱，还是甩卖价。那么问题来了，这玩意适不适合咱们普通人捡漏呢？


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEpbjWaYRNCm85y9X30JjYfyuib2oPriclVZe9ZjcGeHYLW64xplrlxeLJSfKbHHicbtMdUTxeAdia5Yw/640?wx_fmt=png)


先说说这机器的基本配置。它用的是Intel Z8350四核处理器，2GB内存 + 16GB eMMC闪存，接口方面挺齐全：HDMI+VGA双视频输出、千兆网口、4个USB 2.0、2个USB 3.0，还有一个SD卡槽。整机功耗据说只有4瓦左右，插电就自动开机，BIOS没设密码，预装了个精简版Win10系统，还能免费代刷飞牛系统。拍下还送12V/1.5A电源。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEpbjWaYRNCm85y9X30JjYfVzsnGibARDVVGBSKKtMNyiaY0NPEQyic1ibrVg3dpWzibdXeZ66rETcda7Q/640?wx_fmt=png)


乍一看，这配置放2025年确实不算高。Z8350是2016年前后的低功耗U，性能大致相当于入门级赛扬，跑轻量NAS、软路由或者音乐数播勉强够用。2GB内存对现代系统来说有点捉襟见肘，但如果你只是用来做文件共享、远程下载或者挂个Alist，倒也不是完全不能接受。16GB eMMC虽然不大，但装个飞牛OS或OpenWrt绰绰有余。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEpbjWaYRNCm85y9X30JjYft94KVTniabC67niayf6nbJibedJrohCohs9mCeTLNa57GLkJUIhuRJEUg/640?wx_fmt=png)


不过，重点来了：价格。90块含电源，我翻了翻近期成交记录，类似成色的Z8350小主机普遍在120–180元之间浮动，带4GB内存的版本甚至要200出头。这么一对比，90元确实显得“异常便宜”。但也要警惕——有些卖家会把“整机”拆成“主板+壳子+旧电源”拼凑，实际到手可能风扇异响、接口氧化，或者eMMC寿命所剩无几。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEpbjWaYRNCm85y9X30JjYfuibA8GoyhFuxpjFmb64kJcooNxbQVO0xlEWlyUTcBs918hibE8YSRxSA/640?wx_fmt=png)


可能有人会问这机器能当主力NAS用吗？如果你只是备份手机照片、存点电影文档，偶尔刮削一下影视库，那它能胜任。但别指望跑Docker全家桶、虚拟机或者多人并发访问——2GB内存+老U，真扛不住。另外，USB 3.0外接硬盘虽能跑满千兆内网，但前提是你的路由器和客户端也得跟得上，不然就是“高速路修好了，但你骑的是共享单车”。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEpbjWaYRNCm85y9X30JjYfOMsyF0bWKPpU13jeqMo504TdNibJMnUibM7HcX2F8nzia4bZ7DHGbBJiaw/640?wx_fmt=png)


那么这玩意值不值得冲呢？这得看你需求。如果你是技术小白，只想插电即用、图形界面操作，那飞牛系统确实友好；但若你打算折腾OpenWrt做旁路由，或者想长期7×24小时运行，建议至少确认卖家是否提供通电测试视频，以及eMMC健康度。毕竟90块虽便宜，但时间成本和后续折腾精力也是成本。


 


以下是个人一些掺了水的建议：

1. 别拿它当主力存储设备，数据无价。

2. 内存太小，后期升级空间几乎为零。

3. 90元可试水，但别囤货，小心变“电子垃圾收藏家”。

4. 看完不买，立省90元。
