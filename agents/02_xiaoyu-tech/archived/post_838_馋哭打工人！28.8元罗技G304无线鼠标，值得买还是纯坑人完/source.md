# 馋哭打工人！28.8元罗技G304无线鼠标，值得买还是纯坑人？

朕没事就爱刷二手鱼，最近首页疯狂给我推28.8元包邮的"全新罗技G304"。作为常年捡垃圾的老司机，第一反应就是：这价格怕不是卖鼠标模型吧？要知道京东同款现在还卖174元，六分之一的价格买大牌游戏鼠标，怎么听都像天方夜谭。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFKfQEA9m7UOFvTDToicLd1Xo4KoicEqNsqcrJ3WAJgh96tsBibQFOh0h9PseUeMj6tPgJrzxZFjCyFA/640?wx_fmt=png)


仔细研究卖家描述发现几个疑点：所有商品图都刻意避开SN码特写，号称"海外版"却拿不出关单凭证，最诡异的是统一强调"无驱动"。但卖家解释是海外版与国行渠道不同，而且产品的包装盒确实全是英文没有汉字，一时让我无法分辨真假，但这种种迹象让我忍不住想起那句歇后语——吕布骑狗，可疑得很。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFKfQEA9m7UOFvTDToicLd1XfAuUVxctXvkXLAqhDIdqSGlYbLMslykCMGfRoeYwPC5WyQkXrJmySw/640?wx_fmt=png)


不过参数确实让人眼馋：HERO传感器、1ms响应速度、6个可编程按键，纸面数据吊打现在百元内的国产鼠标。有网友晒出实测报告，DPI精度和无线延迟确实接近正品水平。如果真是工厂流出的瑕疵品或海外渠道货，那这波简直是秦始皇摸电门——赢麻了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFKfQEA9m7UOFvTDToicLd1XgLAQ0S29q9OicRKfWXcRMicdWuSsRWiawK56byKtEYwZIb38ia9knaw78g/640?wx_fmt=png)


关于值不值得买，得拆成两种情况说：先说一下值得买的理由：首先是这个鼠标的售价，这个价格你还要啥自行车，就算当普通办公鼠标都血赚，另外就算买到的是假货，但罗技的模具手感是没得说，至今仍是业界标杆。所以管他什么海外版还是国行版，能用就行，如果运气好真如卖家所说是海外版，那是真香啊对不对？


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFKfQEA9m7UOFvTDToicLd1XO9Z7qmp9z83TBMtibBSTNTSbFpTY9Cmx6qfMctwBaKbOxQyEke99cUA/640?wx_fmt=png)


再说说劝退的理由：这货有可能是翻新组装的，微动寿命看人品，那么自然就没有官方保修，坏了自己修或直接变电子垃圾，而且驱动兼容性约等于开盲盒，部分功能可能阉割，像是自定义按键的功能想都不要想，所以值不值得买完全看你的需求。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFKfQEA9m7UOFvTDToicLd1X3N22FEL7QNqYIjqvk01p2aPuE251qt6RcibxWdoTPHyRT7lMLtDoDZQ/640?wx_fmt=png)


现在二手鱼上这些超低价G304，很像当年的华强北AirPods——明知道有猫腻，还是让人心痒痒。如果你愿意用28.8元赌一把，建议优先选支持七天无理由的卖家，到手第一时间测传感器偏移和按键寿命。毕竟这年头，卖家说"海外版"的潜台词可能是"海外飘来的版本"。老规矩，看完不买，立省28.8元。
