# 还在纠结部署龙虾？二手鱼成品“虾壳”主机开卖，599起开始割韭菜

![封面图](https://mmbiz.qpic.cn/mmbiz_jpg/E9h3abOJCelCQicbzcYu4oud4ic01bQ7rGLgtooV7TkZKFV3XMxseTCulOCNf0H81PbIoRVGYlpf3NaBnAQiahP3dK4UqJQDF3mHo6axZYJVjg/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/Ym9g-VmXY7Y10yiTSrmQvQ

最近如果你还没听说过OpenClaw这只小龙虾，那真有点跟不上节奏了。腾讯大厦门口排长队免费装龙虾的新闻刚刷屏，这边二手鱼里就已经有人把现成的龙虾主机挂出来了。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCem29bZsA8DdmcDja4r6oP44lgUV5GFCkGeyeQP7Arb89gq8Dg7XoiaS5MJUiaACnXiczwdoeMwy1ErqkfAEehwxjasNJbltVqVYiaI/640?wx_fmt=png)


联想ThinkCentre M73，这玩意儿搁两年前就是标准的电子咸菜，i3四代处理器，8G内存，120G固态，放在垃圾佬眼里也就是个几十块钱的料。但现在不一样了，卖家给它部署上了OpenClaw，省去了小白用户不会操作的麻烦，所以身价瞬间飙升。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemaNxKGhfAMwZiaX0icypjvBkKPib518IaUeJmr5AhqWyiariaFuoicwkzj5DbibDPA0XQMhfOXFs0wGwTHkVMPklHCJRrOtaaRa9lOic4/640?wx_fmt=png&from=appmsg)

咱先别急着喷人家割韭菜，这波操作其实挺有说法的。OpenClaw这玩意儿火是真火，但部署门槛也是真的高，要配Node.js环境，要在命令行里折腾，还要打通各种API权限，普通人对着教程搞一天都可能跑不通。我看了一下找人远程装一次都得一两百，上门装更是三百起步。这么一算，这台599元的小主机，等于硬件加部署打包卖给你，但卖家还明说了只负责硬件售后，软件不管。这话翻译过来就是：我给你装好了，能用多久看你自己。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekOUUVP3lLvctGYxphOLnFz6T25iaFyocOctoMYNh1hfBicWs0Qkmiaf0HWFvOmU9RlrUOeJnUCk4E0o6jYpXmX4jDloq98yicxBOE/640?wx_fmt=png)


看看配置，低配版i3+8g+120g带WiFi卖599，高配i5+8g+250g卖799。这价格搁平时也就买个入门级的电视盒子，但也算是正经的x86小主机，接口齐全，USB3.0、VGA、DP都有，体积就巴掌大，塞在显示器后面完全隐形。装个OpenClaw当AI管家，每天自动给你整理文件、抓取资讯、发邮件，确实有点意思。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemeuqzAZaB3MMO6QOgia40TPrxgoObIsficTAGk6x2PmakMZrD5ibZqRYbPS3LRY9KCoNrIgkDECeZGSpa7PXTuhV4ApNv8ziarG2Y/640?wx_fmt=png)


但咱也得把丑话说在前头。这机器毕竟是十年前的老古董，性能跑个OpenClaw是够用，但日后不用了，想要跑Windows就有点费劲了。而且OpenClaw这东西需要给系统权限，万一装了什么有问题的技能包，或者配置不当暴露在公网上，那风险也是实打实的。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenmnVcU7lRMHgV28jm1PsBOZw5MWPRsr844DceiarkPtr7PGMHR3pzwj2RV3C74EubvaTYic5aY2AgvqNaZlYso1icI9AoMZFdAdM/640?wx_fmt=png)


还有个坑得提醒一下，卖家只管硬件售后，不提供软件支持。也就是说，如果哪天OpenClaw崩了，或者你想加个新技能不会弄，人家是不管的。这就得看你自己的动手能力了，起码得会用命令行，能看懂报错信息。啥都不懂就想买个回去自动赚钱的，趁早歇着，这玩意儿不是印钞机。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelniapJsrjmian81ZFG5lVfohYkRUk9A3uicqZnWxewJyTh1ZGvyaKJVQhz5ibewYCAd8ya63CEBMQEfLW5KswuYiaqaiaMqFercKn2E/640?wx_fmt=png)


从目前来看，这种预装OpenClaw的小主机会火？OpenClaw这波热潮已经把需求炸出来了，很多人就是图个省事，不想自己折腾部署。与其花几百找人远程装，不如直接买个现成的，硬件还能落手里。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCendobdUD2opQzAibVCUuhLjRkAKvIOTdG7a0MjHLs1h7LH7GTQFiacP5tnCm3I3N9A0Gb5Kiad9ibJygb9G4icoshz1uuYnp5dkqo9c/640?wx_fmt=png)


但动则500甚至1000+的价格我感觉现在有点割韭菜的节奏，如果你手头已经有了一台不用的旧电脑，或者你本身就是个喜欢折腾的垃圾佬，那这笔钱确实可以不花。另外，部署龙虾对于硬件来说并没有太高的需求，CPU有个2核，内存4GB以上，硬盘留出20GB空间，装上Docker就能跑 。随便翻翻家里吃灰的老笔记本，或者花个一两百淘个迷你主机，都能满足。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemX8X4RiaRF8wpbDfC1rOr1YJTLK8etRQMrsEgDbGWEiaN7LhwhO8hJJV8J7AsT3zygsPOyunHpCVocsROxqe0Xpjckgfhxlpzqo/640?wx_fmt=png)


如果你真想入手，建议选799的i5版，多俩核跑任务流畅不少，250G硬盘也能多装点技能。拿回去先别急着上主力机，拿台闲置显示器试试水，跑通了再考虑让它接管日常工作。最后问大伙一句，你会花599买一台替你干活的AI小主机吗？评论区聊聊。
