# 贾老板“下周回国”的全新未拆封手机，我62块就拿下了！

![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHK0etGichf7uvib0xdZeicYe36XslYO54f4AlShx7aAhnSDTsssgUiaZZvfq3pM0ib9kDHJZKbIKXnQ1Q/640?wx_fmt=png)


朕没事就爱刷二手鱼，每天睡前不翻个半小时都睡不着，没想到还真让我挖到宝——贾老板的乐视Y1 Pro+居然在二手鱼卖62块，也就半包烟的钱，还是全新未拆封！这价格挺白菜的，那么62块买个正规品牌手机值不值呢？


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHK0etGichf7uvib0xdZeicYe35jtHI4micQzjmAgl8eIeiaTQaaeiak9KcX9JTia7ItozcWZPvt35XgTuPg/640?wx_fmt=png)


这款乐视Y1 Pro+当年2022年发布时起售价499元，搭载的是紫光展锐虎贲T610处理器，在4G入门机型里不算顶尖，但也算是矮子里面拔将军——凑合能打。日常聊微信、刷抖音、看电子书完全够用，打开APP基本不会卡顿，but要是想玩大型手游，那就够呛了，处理器性能确实有点拉胯。不过话说回来，62块钱本来就是奔着备用机或者长辈机去的，性能够用就行，要求不能太高。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHK0etGichf7uvib0xdZeicYe3wmaLJ1CicJrFJ2vYx62upaibJ4PYapwL80EwGzEc7sRrPJK38zuvsfoQ/640?wx_fmt=png)


屏幕方面是6.5英寸的LCD刘海屏，分辨率1560×720，60Hz刷新率。可能有人觉得这个配置现在看太落后，但实际用起来完全不影响，刷短视频、追剧的时候，屏幕尺寸够大，看着比小屏手机爽太多。而且LCD屏护眼，阳光下屏幕亮度也还行，不会瞎眼，给长辈用再合适不过。唯一的小缺点就是没有高刷屏，滑动起来没有现在的旗舰机丝滑，但作为百元机，这表现已经可接受了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHK0etGichf7uvib0xdZeicYe3kNHQoopHZoNibDCeZMOo8BTs86Y4gicZ6PhVXiaT7S5CZCNJnHbsia4MDQ/640?wx_fmt=png)


电池方面，它给到了一块4000mAh的电池，配了个10W的充电头。充电速度嘛，堪称“养生级”，充满电得俩钟头，慢得我能泡个脚再看部电影。但反过来想，它的续航倒是挺扎实，正常轻度使用，撑一天问题不大，避免了“电量焦虑症”。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHK0etGichf7uvib0xdZeicYe3GjepiclQnWiaGGCjp46Tre4icN9zWqdKluqnvp3AgI9mwyBwG2VsnBX7A/640?wx_fmt=png)


存储提供4GB+128GB和6GB+64GB两种组合，推荐4GB+128GB的版本，存储空间更大，装微信、抖音、支付宝这些常用APP完全够，还能存点照片和视频，不用老是清理内存。6GB+64GB的版本运行内存稍大，但存储有点紧张，要是装几个大型APP就满了，实用性不如前者。不过不管哪个版本，日常使用都没问题，毕竟也没人会用它存太多东西。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHK0etGichf7uvib0xdZeicYe3TTD7lvzyETicPFWSUMmgOapNVtQqQ8WtxhONRUg0HV0ORbTKric9FZbQ/640?wx_fmt=png)


它的优势还挺实在，除了价格白菜，系统也很简洁，原生安卓界面，没有乱七八糟的广告弹窗，用着清净，这一点比很多千元机都强，现在不少手机一打开就弹广告，关都关不掉，太影响体验了。而且作为正规品牌，售后虽然不如一线品牌方便，但基本的保障还是有的，比买那些杂牌老人机靠谱多了，性价比真的还行。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHK0etGichf7uvib0xdZeicYe3nluqYQVMghw5nsmISV84cUSicsTq6Jf8Gl3lLCicCc6IruOEU8wiaPAGg/640?wx_fmt=png)


当然劣势也不能回避，除了处理器性能一般，它还是4G手机，现在5G都普及了，但4G手机现在还能用，日常上网、打电话、发微信都不受影响，而且5G套餐费用比4G贵，对于长辈或者只是用来当备用机的人来说，4G完全够用，没必要追求5G。另外，它的拍照功能也比较基础，只能满足扫码和简单记录，想拍高清照片就别指望了，但这个价格，能有这配置已经很良心了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHK0etGichf7uvib0xdZeicYe3ewxHWNUUTSXwutUd3BQNtrb5y0JxHF8Il3R78dKrn3qNTk1x47bKdA/640?wx_fmt=png)


水了这么多，你们觉得这62块花得值不值？有没有在二手鱼上捡过更离谱的漏？欢迎在评论区分享你们的“捡漏神话”或者“踩坑经历”，让我也开开眼！最后，老规矩，看完不买，立省62元。
