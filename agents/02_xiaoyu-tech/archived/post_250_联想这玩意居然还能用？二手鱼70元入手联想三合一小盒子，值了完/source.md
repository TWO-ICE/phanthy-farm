# 联想这玩意居然还能用？二手鱼70元入手联想三合一小盒子，值了！

今天在二手鱼刷到了一个冷门但有点意思的小设备——联想无线数据共享器，型号WP6018。标价70块，全新未拆封，价格挺白菜。点进去一看描述：“支持U盘、移动硬盘、SD卡无线共享”，这不就是传说中“不用插线就能读U盘”的手机扩容神器么？只要给设备插个1TB移动硬盘上去，等于随身带了个私人云盘，手机秒变“无限存储”。这个价格还要啥自行车？


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGic4E9EBjibj7uYEl7YLicQiaHv9gqe0ibMKeHqPEicTDhpM2MukSsxicFgpniaG2eZtxULvKYZianj5hu6iaw/640?wx_fmt=png)


这款联想WP6018其实是十多年前的老产品了，当年主打商旅人群，官方叫法是“无线数据共享器”，听着高大上，其实就是个带电池的便携路由器。参数方面，支持IEEE 802.11a/b/g/n标准，最高无线速率300Mbps。别笑，这在2013年前后算主流配置了，出差住酒店拉根网线，它就能变出Wi-Fi供多人使用。更关键的是，它自带4000mAh电池，不仅能当路由用，还能应急给手机充电，妥妥的一机两用。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGic4E9EBjibj7uYEl7YLicQiaHkmibTXYVFhPLr7Nz2h4s5pQbbHxRu6dy3jZfg080tnuB82EibmPfAGTw/640?wx_fmt=png)


再说说它的核心功能：USB存储共享。机器侧面有个标准USB接口，插上U盘或移动硬盘后，通过浏览器或配套App就能在手机、平板上无线访问文件。比如你存了几十部电影、上千张照片在1TB硬盘里，插上它，躺床上就能用手机看，不用再忍受64G手机的存储焦虑。虽然传输速度受限于USB 2.0和300Mbps无线带宽，传文档、看1080p视频完全够用。对于不想花大钱买高配手机的人来说，这招“曲线救国”简直妙。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGic4E9EBjibj7uYEl7YLicQiaHgOW187r1Kibud45vZzGHkPsicu9EPIF3cDDIlXLiccI4MtCyTqgKCpNQw/640?wx_fmt=png)


当然，缺点也得摆明白。首先，它不是千兆设备，不支持5G WiFi，有线口是百兆，无线最高300Mbps，大文件传输时确实会慢一些。放今天连入门级新路由都比不过。其次，系统老旧，没有现代路由器常见的家长控制、Mesh组网、APP远程管理等功能，设置界面还是那种蓝底白字的网页风，第一次配网得有点耐心。而且联想早就停产，固件更新？想多了。但话说回来，70块钱买个全新未拆封的多功能小盒子，还要啥完美体验？拿来当备用热点、旅行伴侣，或者临时文件服务器，完全可接受。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGic4E9EBjibj7uYEl7YLicQiaHlH1lJc1v0urQVASK64lzn6C9dxX9RWic8TXAU5tThicFJPCibibmXvDjQw/640?wx_fmt=png)


可能有人会问：“这玩意现在还能连上新款手机吗？会不会兼容性翻车？”这一点其实不用担心，目前市面上的新手机都能正常连接Wi-Fi和访问共享文件。只要你的网络不需要复杂认证，它基本能胜任。只是App可能得自己搜旧版APK，或者直接用手机浏览器访问管理页面，虽然复古但管用。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGic4E9EBjibj7uYEl7YLicQiaHfAdXiahK1Zm3anxKnPZWMDXicHs5ZoYVZ1Aicc2GTalcYJjiauhjgoiaYuQ/640?wx_fmt=png)


那么，现在入手这款老设备真的值得吗？如果是经常出差需要临时搭建网络，或者手机存储常年告急的朋友，那它绝对物超所值，70 元买路由器 + 移动电源 + 无线存储，性价比直接拉满。但如果追求千兆速率和大容量充电宝，那它可能满足不了你的需求，毕竟是早期产品，性能有时代局限性，买之前得想清楚自己的核心需求。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGic4E9EBjibj7uYEl7YLicQiaHTacMKRkfCefkrLhuNvZevexLHQ5ueAPDiavePg9S8C1ia6Wj6B6jyRdg/640?wx_fmt=png)


如果你正被手机存储不够折磨，又不想换新手机，不妨试试这款。插个二手1TB移动硬盘，组合起来成本不到一百，却能实现“类云盘”体验。感兴趣的朋友可以搜“联想WP6018”或“无线数据共享器”，记得认准“全新未拆封”和带USB口的描述。
