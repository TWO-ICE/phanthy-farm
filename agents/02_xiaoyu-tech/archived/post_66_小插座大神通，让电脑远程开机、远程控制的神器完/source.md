# 小插座大神通，让电脑远程开机、远程控制的神器

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/afNLf2a8eXGibm41jKLbMRVWX2xSAreljPad4EPribnmYQvk9HFxHKJEud37FpTSnhGndYjYKpTYrgc2Rt54bQUg/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/T0S4NiVxACye9sExyqxAPA

大家好，我是小鱼评测，今天评测的产品是来自向日葵的一款智能开机插座，型号为C2（计电量版）。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXGibm41jKLbMRVWX2xSAreljATKickWGFAovtqulsTViaHuOqTXQmOU8KVIoXt9njWS0xzmusT6thwHw/640?wx_fmt=jpeg)


从产品的名称就能够看出，这是一款专门针对电脑主机来使用的插座，核心功能就是通过这款开机插座，可以把断电状态下的电脑主机远程开机，并且可以与向日葵远程控制软件无缝衔接，实现远程开机+远程控制一步完成。这对于很多依靠电脑办公的人士来说，是一个非常实用的产品，即使出门在外，也可以做到随时操控公司或是家中的电脑。那么真实的使用体验到底如何呢？还是来一起看一下吧。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXGibm41jKLbMRVWX2xSAreljMoJnXML2231cGqyL0d6s1xv5bfUSUQ0y9VuneZfvoOD5krEunsibuqw/640?wx_fmt=jpeg)


首先来看一下外观方面，这款向日葵开机插座给我的第一印象还不错，亮黑色的外观看上去很精致，身材也非常的娇小，尺寸只有44mm*55mm*51mm，这要比市面上常见的智能插座小上一圈，如此样袖珍的身材可以节省不少的空间，插到插线板上不会影响到周围的孔位，这个设计还是非常人性化的。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXGibm41jKLbMRVWX2xSAreljjE13rVibhyvqDx28BFKHf0Cty08bCR2duV29MZPMsDjFYpuqKvowia0Q/640?wx_fmt=jpeg)


在材质方面，这款向日葵开机插座的外壳使用的是V0级的阻燃PC，这种阻燃的PC材质被广泛的应用于各种电器开关，特点就是耐高温，即使是700摄氏度以上的高温，也不会出现燃烧的情况。其实只要是正规的品牌，品质都会有所保障，所以这一点对于向日葵开机插座来说，是完全不用担心的。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXGibm41jKLbMRVWX2xSAreljFb9lzPv0icDyMA8OHicL514xxcZRjt3gXn8ViaTPntbwdl7xrxkB5icCnw/640?wx_fmt=jpeg)


向日葵开机插座整体只配备了一组国标的五孔插口，为了安全每个插口都配有安全阀门，最大功率为2500W，可承载10A的电流。值得一提的是，这款向日葵开机插座的内部使用的是一体化铜带工艺的技术，能够在保证安全的前提下，提供更好的性能，所以即使连接了多台电脑，也完全能够胜任。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXGibm41jKLbMRVWX2xSAreljZ7CriaiaqgHHvvcibDXENHkE1FnsKRWqpDZpWO9WhiafuzIljgqzlrJsiag/640?wx_fmt=jpeg)


开机插座的机身上还配有一个实体开关按键，单击一下可以实现开启电源和关闭电源的功能。另外，按键长按5秒，还会对插座进行初始化的操作。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXGibm41jKLbMRVWX2xSAreljtPTQujRn8ngeibfZ43W69nNmmdMT3aDE0a7qPULkNLQm1E49MDOgghw/640?wx_fmt=jpeg)


在实际的使用中，只要把开机插座插在插线板上即可，如果想要实现远程开机的功能，还要把电脑主机的电源线插到开机插座上。通过实拍图可以看到，迷你身材的向日葵开机插座，确实非常的节省空间，插在插线板上完全不会影响到周围孔位的使用。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGibm41jKLbMRVWX2xSAreljBnBuPfmkm37iaTYbRvyH5FBG2SSKADEYMyCKKlZ6VUxrC1rXVbjPPOQ/640?wx_fmt=png)


之后还需要更改电脑主机BIOS中关于电源的设置，由于电脑主机的品牌不同，所以BOIS中的设置也各不相同。这里就以我的华硕品牌主机为例，在BIOS里的高级设置中，把断电恢复后电源状态的菜单，设置为电源开启的选项就可以了。这样我们在远程打开插座的开关之后，电脑主机就会自动开机了。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXGibm41jKLbMRVWX2xSArelj0HLIaSKQcWW0GyrZP9tuwdXcybhCkOiaGqmibWRuC3TLW3HgoZd1n2sA/640?wx_fmt=jpeg)


接下来需要做的就是，在手机中下载向日葵APP，按照提示注册登录之后，还需要对开机插座和电脑进行添加绑定，这些操作非常的简单，使用说明中也给出了详细的步骤，这里就不再多说了。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXGibm41jKLbMRVWX2xSArelj4joibLwJoQAcibMey8ibQkIsxhuxRybyCCBlzRLicfNuPjoqDDZJQWUHoQ/640?wx_fmt=jpeg)


在APP的界面中，向日葵远程控制软件其实分为两个部分，其一是对智能硬件进行管理，在这个界面中，开机插座的所有功能一目了然，除了可以手动点击开启或关闭电源之外，这里面包含了基础的倒计时和定时功能，还可以进行设备的绑定和解绑，并加入了电量统计功能。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXGibm41jKLbMRVWX2xSAreljZsjyOvRWQIrHaPsfpQCwEA1O3q3kqW3cleUfooFe3t9riaRSIevdR0Q/640?wx_fmt=jpeg)


值得一提的是，这款开机插座的电量统计功能内容很丰富，不仅可以统计电量，实时的电流情况、当前的功耗情况、当日的用电时长和开关设备的次数，都用非常明确的记录，并提供了用电日志，日志中开机插座每天的工作状态也都历历在目。由此可见，这个计电功能还是非常强大的。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXGibm41jKLbMRVWX2xSAreljIJlaGI9OtgVDuMlUtxNiaEaPNwFibpDp5pv2Bjhn4tcx8zn5Od7frGnQ/640?wx_fmt=jpeg)


至于APP的另一项功能，自然就是对远程电脑的管理和控制，这一点对于我来说是非常的熟悉了，在没有安装开机插座之前，我就一直使用向日葵软件对电脑进行远程控制，用起来还是非常方便的，尤其是里面的虚拟鼠标，设计的很有特色，基本与使用实体鼠标的操作没什么区别，左右键、滑轮、框选都能够完美实现。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXGibm41jKLbMRVWX2xSArelj6anGNAib0p4Uic4ic8icDv6WSN6Dlw88EzLUGEIG5iaE1ZGtVUXDM6gfTBw/640?wx_fmt=jpeg)


在使用的时候，还发现了开机插座几个非常实用的功能，一个是插座具有断电记忆的功能，如果在使用期间突然断电，那么在来电之后，插座会恢复到断电之前的状态，这一点还是很人性化的。再一个就是，开机插座支持延时关闭的功能，通过管理界面，可设置在电脑关机之后，延时关闭插座电源，里面提供了多种时间条件的选择。因为电脑在关机的时候，是需要一些时间的，这样延时断电的设置，可以保证电脑完全关闭之后，才关闭电源，保障了电脑主机的安全。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXGibm41jKLbMRVWX2xSAreljDG97jTmm1w43Sqo3dI4lGVVZVFVJskmaNv7IhWV50JfPicNAGgGH1Zg/640?wx_fmt=jpeg)


从以上这两个功能可以看出，向日葵开机插座作为电脑专属的开机设备，可以让自己随时掌控远端电脑内的资料，不会再被电源关闭的问题所束缚，一步就能实现远程开机和远程控制，让操作变的更加的简单方便。即使你不需要远程开机的功能，也完全可以把它当做一个普通的智能插座来使用，电量统计、定时、倒计时也都是非常实用的功能。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXGibm41jKLbMRVWX2xSAreljRUeWFpogGfuAUEcFicAu7uLyX6HGADSciazWJGeke565DjyC5UiblzukA/640?wx_fmt=jpeg)


最后再说一下这款开机插座的售价，从目前来看，这款向日葵开机插座C2计电量版的价格还不足50元，比起目前很火爆的小米、华为等智能插座，价格相差无几，甚至还要更便宜一些。如果你想打造智能家居系统，那么小米、华为等，带有联动功能智能插座的确要更为适合，但如果你想远程控制电脑，实现远程开机，那么这款向日葵开机插座可以说是当下的不二之选。
