# 300块的飞牛圣体带1T硬盘，配置J1900+8G+64G固态，合适吗？

最近在二手鱼上看到一台Sinoc小主机，300块钱打包出。卖家给的信息很直接：Q1900M主板，8GDDR3内存，64GCrucialM4固态，1T的希捷ST1000DM010机械盘，还装好了飞牛NAS系统。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenxcwNBIgTl94zs0BLuupeibXRTMibldbyPbt3Swtva1nv539bY67UWBO92k7JNl6h582vMOBY9MUKfo0evY0wE1dBZ6qwSOr4Lc/640?wx_fmt=png)


先说说这个Q1900M主板，它其实是板载了一颗赛扬J1900四核处理器。别看这U是老古董，TDP才10瓦，功耗控制得相当漂亮。另外，还搭配了一条8G内存，还有1T机械盘和64G固态，从系统到配件都齐全，属于是到手就能用。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenopYtm5Jofn6UVqUoZXicicqzEuKXWQD3KRPcjN1oCKCeAbXX5Jm4DHiaJyUg177W20DBLwMbKtnX4caTbLpQYlw02AsFfCbXqCA/640?wx_fmt=png)


再看硬盘组合，64G的CrucialM4固态，读写速度在现在看虽然不咋地，但做个系统盘绰绰有余。那块1T的希捷ST1000DM010，得重点夸一下。懂行的都知道，这是块CMR垂直盘，不是现在市面上那些坑人的叠瓦盘。卖家选这块盘，明显是做过功课的，不是随手塞一块垃圾进来。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelVhJ2MgYuEeuKZ3nwX0OwibIZJibPXjXQfX4x8xBlonQibwXJnxqoicTD7iam9eU3KVSHThwfHuf7XVTgiaCGxpIKXbIlJsIUXkPIBU/640?wx_fmt=png)


这300块钱，咱们拆开算笔账。8G内存现在二手行情差不多60-70块，1T的CMR机械盘怎么也得七八十，这俩加一起就已经快150了。那块主板虽然老，但带CPU带板载，放二手鱼上也能卖个百来块钱。这么一算，剩下的固态和机箱电源，基本就等于白送。而且卖家还多干了一件事儿，给你把飞牛系统装好了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemLaTB8ov5JyA5q8jCV7ZvS09N3nzttgqSqCxiatcibsQhMt1loeahGaJyn2jxwZtMtgfsnn23T1XLrI5TVfkxFelu2YqtZkt9eE/640?wx_fmt=png)


不过这台机器的缺点也特别明显，最大的问题是扩展性。主板只有两个SATAII接口，你想多挂几块硬盘，没门儿。而且那个PCI-Ex16插槽，实际上只有x1的速度，接个千兆网卡还行，想上阵列卡基本是做梦。如果你是那种喜欢折腾、想往里面塞四块硬盘跑PT的人，这机器趁早放弃，它满足不了你。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekjkB3c0u7ulYhAicDQicTKibhACgouk0o3DZsJuwM9jricSzoQJDeAvXwJaGJLQoycnyHric45GtSiaLMPqVONI4zuAsICtj4xjBnFw/640?wx_fmt=png)


那这台机器到底值不值得买？我觉得得看你怎么用。如果你手里正好缺一台24小时开机的文件服务器，想低成本体验一下飞牛系统，那300块这个价，还真挑不出什么大毛病。尤其是现在内存涨价的大环境下，这价格能拿到带1T盘的全套机器，确实少见。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemzJOlIO9XsyhnDenMNXvH4DvTkcWad8Daf8uWaDyHd6ibSQianFgAktN3TKkJticONGicJc1hSrDIX2XCy7PbnXMBbhd8H04iaY64k/640?wx_fmt=png)


但如果你是抱着捡漏高性能神机的心态来的，那还是别碰了。它就是个老咕噜棒子，性能摆在那里，主打的就是一个实用。千万别指望它能干超出它能力范围的事儿。最后有个小建议，下单前一定找卖家要一下两块硬盘的健康图。机械盘看有没有坏道和重映射，固态看健康度和通电时间。毕竟这俩才是机器的核心价值，万一拿到手硬盘寿命到头了，那这300块就真的打水漂了。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenxQ2W7ibC6b36jgD0DHILsfnLecSM1QIOm7ZyWiaTmoqiaTs9Bib5n1UZmwstc1D8tw1XxiahhT7DiaGQRsP0YGdLKiaBdvtEgtYQnyM/640?wx_fmt=png)
