# 二手鱼流入vivo新品礼盒25元还包邮，vivo是来发福利的吗？

二手鱼里刷到 了 vivo 的一款新品 礼盒，25元包邮，卖家说全新未拆封正品礼盒装，里面是一把折叠伞加一个充电小风扇。 这款礼盒也叫vivo多巴胺系列礼盒。说实话 25块钱包邮，这价格基本上就是邮费加个打包辛苦费了，东西相当于白送。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemrQP2JWl9MuXd9dJuRCVESBWtHubxentzVAhvhl1LlD9p8FtUIg5jsiaOHCebV7KzRKicwtys3QuiapOhSiaGP09h51JYiarWawoew/640?wx_fmt=png&watermark=1&tp=webp)


先看雨伞，白色10K大伞面，550mm的尺寸，一个人撑绝对宽敞，两个人挤挤也没问题。伞布是100%聚酯纤维，外白内黑的设计，黑色涂层通常意味着防晒能力不错。夏天最怕什么？出门五分钟晒成非洲鸡，这把伞好歹能挡挡紫外线。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekia1SSbPnotp7gZl3FkwuxXKhKLKwM828FutLz6PKK5E3Cywic4NaNliaic60rRuKD48phZruhSInM0icGfic54Esjp5zjKYB9txZsk/640?wx_fmt=png&watermark=1&tp=webp)


再说那个小风扇，ABS材质白色外观，带充电线和挂绳， 手柄上还带一个屏幕，吹风的风扇基本上都是类似那种暴力风扇，风力非强强劲，整体小巧， 便携性没问题。你想想，大热天等公交、挤地铁、户外溜达的时候，从包里掏出来对着脸吹， 瞬间就能带来凉感 。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemtWIxZtKzVKe1dZMC4t6HibJ1ibf2hPz7Tf0zEica5a3Nvow0eiaOiaMmxHfq9eN4iaElyqktpnFEIic41t9F0Lzy8IQRFiagTkPzaKQ4/640?wx_fmt=png&watermark=1&tp=webp)


不过我得说句实在话，vivo主业是做手机的，这些周边产品说白了就是品牌赠品或者积分兑换的库存。当年买手机送一套你可能觉得挺有意思，现在单独拿出来卖， 你 别指望有什么黑科技。雨伞就是普通晴雨伞，风扇就是普通手持风扇，没有负离子没有无叶设计，就是能用、好看、实用这个水平。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelB9IvGyiaZiaDI627BiciaXIMaDf7SfBzxDUBibZliaHmrFkXfpJgPr3WLiaUo7L5d7fiaAfPPX21ibtDmxmDAwxxasydcBo4jdYGvWp2Y/640?wx_fmt=png&watermark=1&tp=webp)


那这25元值不值得出手？我觉得要看你怎么用。 现在正好是夏天， 如果你缺把遮阳伞，又想要个小风扇，那这价格闭着眼睛买，两杯奶茶钱而已。拆开算，伞值15，风扇值10，邮费还得七八块，卖家基本不赚钱，纯粹清库存。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCembK35g88icPY4KzM9icaGMWbP3XI04MsUkn28iaKBuchx7OAfoGF8GRwcSiaadhgjGbyJahvazHIiab6QcHwMIIPTic2HyQHRzbwnnQ/640?wx_fmt=png&watermark=1&tp=webp)


同类产品一把杂牌晴雨伞差不多15到20元，一个手持风扇10到15元，加起来怎么也要30元左右。vivo这套好歹是个品牌，包装也体面，送人或者自用都不丢人。现在二手市场里这种品牌周边特别多，什么华为小米vivo的礼盒，都是当年买手机送的，很多人用不上就低价甩卖。再加上今年夏天来得早，防晒降温的东西需求大，25元这个价格 我感觉不会踩坑 。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelEQ3sicehtK3uQVkmp1WBTA1okkpTFS8PaIenAOiabrPyuOl8CQdUIg5r9icAf9YErNFTCpcwqIeTWRpcDJqE8zDhRQMAsLhia1ow/640?wx_fmt=png&watermark=1&tp=webp)


但你也要想想，这玩意儿买了之后放哪？如果你平时出门连包都懒得背，那伞和风扇就是累赘。如果你经常骑车或者开车，伞用不上，风扇也只能放办公室。只有当你的生活场景是步行通勤、挤公交地铁、户外活动比较多时，这两样东西才能发挥真正作用。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekA0nxJetgXwclXvXoAOosUltIW5mLiau0PY0ABkKSseiaISicAfA22OGjk6xUEjUY701ibA7Xj9qciaCRib4APDh3E8fOmPSLzrLVmE/640?wx_fmt=png&watermark=1&tp=webp)


整体看下来，这套vivo多巴胺礼盒价格没毛病，实用性强，颜值也在线。缺点就是别对它有过高期待，就是个生活小物件。25元买不了吃亏买不了上当，但下单前最好问问卖家实物有没有瑕疵，风扇能不能正常充电。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelyYjQzGTUZsAKs4nheVrPib5lricD5iaaaBCaWmNwbE8ocfs88FruBQF5Kz3rBuYOIMRGSJL4dUjeI4x3kiboAaia8eTLhgj4G2laU/640?wx_fmt=png&watermark=1&tp=webp)


如果你要买，建议先私聊确认细节，毕竟二手鱼里“全新未拆封”有时候也需要打个问号。你们觉得25元买这个值不值？或者你们在二手鱼里还淘到过什么更奇葩的周边产品？评论区聊聊，我看看谁的运气更好。
