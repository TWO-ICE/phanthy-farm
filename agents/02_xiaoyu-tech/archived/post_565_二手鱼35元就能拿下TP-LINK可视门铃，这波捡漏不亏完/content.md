# 二手鱼35元就能拿下TP-LINK可视门铃，这波捡漏不亏

平日里闲下来，我就总爱在“二手鱼”平台上游荡，这倒不是因为我有什么非要不可的刚需清单，纯粹是迷恋那种“大海淘金”的快感。这年头，谁还没个捡漏的心呢？没想到，这种闲情逸致最近还真让我撞上了大运——一台成色不错的TP-LINK“和家亲”无线智能可视门铃，标价居然只要35块。要知道，在安防圈子里，这玩意儿当年可是正儿八经的“轻奢品”，商超里动辄卖三四百，现在这价格连一包好点的烟钱都不到，这种极致的性价比，对于喜欢折腾电子垃圾或者租房党来说，简直就是无法抗拒的诱惑。

回想两三年前，智能可视门铃这东西在市场上还带着一种“高科技”的光环。尤其是TP-LINK这种做网络设备起家的老牌大厂，旗下的产品向来以皮实耐操著称。当年这款CT3DB型号刚推向市场的时候，线下数码门店的标价那是相当硬气，普遍都在300元以上，就连网上旗舰店在大促期间的到手价，往往也得咬咬牙掏出200多大洋。那时候它可是安防界当之不愧的“小贵价选手”。谁能想到，风水轮流转，时过境迁之后，这位昔日的“贵族”居然沦落到在二手鱼上卖个白菜价，这种巨大的心理落差，简直比坐过山车还要刺激。

既然花了这35块钱，咱们就得好好盘一盘这东西到底值不值。先来看看它的核心硬件配置，这可是当年卖300块的底气所在。它搭载了一颗300万像素的摄像头，传感器用的是1/2.7英寸的Progressive Scan CMOS。在参数党眼里，这个规格搁在今天其实依然能打。要知道，市面上很多入门级的门铃还停留在720P或者1080P徘徊，300万像素意味着更细腻的解析力。当年宣传的时候主打的就是“高清抓拍”，实际体验下来也确实不虚。如果在实际场景中应用，哪怕是门口快递盒子上那细小的物流单号，或者是访客身上的穿戴细节，都能拍得一清二楚。这对于安全防范至关重要——小偷要是敢在门口晃悠，那这清晰度简直相当于在他脸上强行贴了个“我是小偷”的标签，留存证据完全够用。至于15FPS的帧率，虽然不算电影级的24帧或60帧，但对于监控这种静态画面为主的场景来说，15帧足够流畅，完全不会出现那种让人难受的卡顿或者拖影现象，保证关键时刻不掉链子。

再来说说它的夜视能力，这可是门铃这种户外设备的“灵魂”。很多人担心楼道没灯或者半夜太黑拍不清，这款门铃当年的一大卖点就是红外夜视。官方参数是5米的红外探测距离，咱们按实际场景算，绝大多数出租屋或者老旧小区的楼道，纵深也就那么几米，这覆盖范围简直是绰绰有余。我们总听说小偷专挑半夜下手，利用楼道光线昏暗做掩护，普通监控这时候往往只能拍个黑影。但有了这个主动红外夜视功能，哪怕是在伸手不见五指的深夜，它也能自动切换模式，把入侵者的轮廓拍得明明白白。而且它不仅仅是个冷冰冰的监控探头，它还保留了最原始也最实用的门铃功能。有人按门铃，手机APP能实时推送提醒，哪怕你身在千里之外出差，也能像接电话一样接通。这种“远程面对面”的体验，在几年前可是妥妥的“智能生活”代表配置，如今花35块钱就能复活这种体验，确实有点穿越时空的感觉。

双向语音功能这块，也值得单独拎出来夸一夸。这东西内置了高灵敏度的拾音器，官方给出的拾音距离是5米。这在实际生活中非常实用，比如遇到快递员送件，你正好在洗澡或者在另一个房间赶工，不用湿手或者跑腿去开门，直接掏出手机就能远程沟通：“放门口就行，谢谢！”这甚至都不是最爽的，最爽的是用来“防身”。如果你发现门口有个鬼鬼祟祟的人在徘徊，形迹可疑，这时候直接打开麦克风，冷不防远程吼一嗓子：“哥们，干嘛呢？”保管他能吓得一激灵拔腿就跑。这种来自“未知空间”的声音威慑力，比单纯无声的监控画面要管用得多，心理战往往比物理防御更有效。

当然了，世上没有完美的产品，尤其是在二手市场，便宜必然有便宜的道理。这个门铃的坑点也得实打实地跟大家交代清楚，避免大家买回去踩雷。首先，这是典型的运营商定制款。什么叫运营商定制？就是当年办宽带或者办套餐送的“赠品”，这种产品在软件层面上有锁区限制，它不像普通零售版那样可以连接通用的智能家居APP，它必须绑定对应的“小翼管家”或者运营商指定的APP才能用。这对于喜欢折腾HomeAssistant或者其他智能家居生态的朋友来说，可能是个小遗憾，生态兼容性相对较差。另外一个比较明显的短板是续航。虽然它塞进去了一块5200mAh的锂电池，规格看着挺大，但你要知道，可视门铃这种设备是全天候待机的。如果设置了高灵敏度的移动侦测，或者楼道人流量特别大，这块电池的撑死续航也就十来天。对于懒人来说，半个月拆下来充一次电确实有点烦。不过，凡事都有解法，对于租房党或者动手能力强的人来说，十几天充一次电也不是什么大麻烦，更有大神直接改了线路，接上USB常供电，直接一劳永逸地解决了续航焦虑，把它变成了一个有线门铃，这样体验就上去了。

复盘一下，35块钱的预算，当年卖三五百的硬件配置，功能涵盖高清监控、红外夜视、远程对讲，怎么看都是捡了个大漏。眼瞅着春节就要到了，俗话说“年关难过，小偷冲业绩”，每到这个时候，治安隐患总会多那么几分。租房党或者住在老旧小区的朋友，本身的安保设施就比较薄弱，单元门常坏、楼道灯常暗。这种时候，花一杯奶茶钱，整这么一个带威慑力的电子哨兵往门口一挂，哪怕它只是亮个红灯、响个铃声，对于心怀不轨的人来说也是一种心理施压，这安全感本身就是无价的。毕竟，花小钱办大事，这可是消费主义的终极奥义。
