# 二手鱼235元就能带走N3150双千兆小主机，这飞牛圣体稳定的很

今天在闲鱼（俗称“二手鱼”）这个巨大的电子垃圾回收站里冲浪时，还真让我筛到了一根有点意思的“金条”。一台配置为Intel N3150处理器、4G内存加64G mSATA固态的小主机，标价235元，卖家甚至还大方地包了邮。看了一眼卖家的晒图，机器外壳虽然免不了有些岁月的磨痕，但整体成色还算周正，没有那种被暴力摔过的惨状。在如今这个动辄“矿卡”满天飞、新机价格飘上天的行情下，这个价格简直让我产生了错觉——仿佛卖家不是在卖电脑，而是在清仓自家吃灰的旧砖头。

这就很有意思了。想当年，这玩意儿在工控圈和嵌入式领域也是个正儿八经的“角儿”，如今沦落到白菜价甩卖，简直就像是在旧货市场的角落里翻出了一块还能走字的劳力士。对于咱们这种喜欢折腾NAS、软路由或者家庭服务器的玩家来说，这种价格的老平台，往往有着不可替代的“垃圾佬”浪漫。

咱们先来扒一扒这台小主机的“老底”。这台机器的心脏是Intel经典的N3150处理器， Braswell架构，四核四线程设计。虽然主频只有1.6GHz，睿频最高也就冲到2.08GHz，但在当年，这可是低功耗阵营的扛把子。这里得给不熟悉硬件的朋友补个课：衡量这类CPU好坏，不光看跑分，更要看TDP（热设计功耗）。N3150的TDP只有惊人的6W。这是个什么概念？也就相当于你手里那个旧手机亮屏运行时的功耗。

正因为功耗极低，这机器的散热设计可以做得非常极简——它压根就没有风扇。全靠那一坨厚实的金属机身进行被动散热，热量直接传导到外壳上散发掉。这意味着什么？意味着24小时开机挂机，你几乎听不到一丝电流声。对于想放在卧室做下载机或者客厅做HTPC（家庭影院电脑）的朋友来说，这种“隐形”的静音体验，远比那些风扇嗡嗡响的性能怪兽要舒服得多。

再来看看这台机器的“排泄”能力，也就是接口扩展性。虽然机身尺寸只有巴掌大（约17×13×3.7cm），重量也仅为0.7kg，但它的接口配置在如今看来依然显得非常“硬核”。它塞进了两个千兆网口，而且都是Realtek RTL8111这种在Linux/Windows下驱动最稳的芯片。这点非常关键，很多小白玩软路由翻车，就是因为碰到了螃蟹网卡（Realtek 8125之类）驱动适配问题，而8111这种老牌网卡，在OpenWrt、群晖、飞牛OS等系统里简直是“即插即用”的代名词。有了这两个网口，你可以轻松把它配置成软路由，或者做链路聚合，甚至充当AIO（All-in-One）主机的管理口。

存储方面，它提供了一个标准的SATA接口，可以接一块2.5寸的机械硬盘或者固态硬盘，同时还有一个mSATA插槽用来装系统盘。虽然mSATA现在不如M.2流行，但在二手市场里，廉价的mSATA固态还是很好捡漏的。至于内存，它只有一条DDR3L的低电压笔记本内存插槽，最大支持8GB。对于NAS和软路由来说，8GB已经绰绰有余，甚至可以说是奢侈了。还有一个比较有意思的细节是它带有一个mini PCIe槽位，虽然通常不能直接插WiFi模块（因为协议和针脚定义问题），但买一个几十块钱的转接卡，就能变成USB口或者专门用来装Intel的无线网卡，用来当AP（无线接入点）也是别有一番风味。供电方面则是标准的12V 5.5×2.5mm圆口，随便找一个旧路由器的电源适配器就能亮机，卖家那个加13块钱买12V3A电源的建议纯属友情价，不坑，但你自己有的话直接插上就能用。

聊到N3150，就不得不提它在圈子里的地位。这款CPU发布于2015年左右，是x86架构在低功耗领域的里程碑产品。那时候它主要占据着迷你PC、瘦客户机和工控控制器的市场。之所以到现在还能被津津乐道，是因为它几乎是“稳定性”和“兼容性”的代名词。现在的J4125、N5105甚至N100虽然在性能上可以把它吊起来打，跑分甩它几条街，但在咱们这些折腾NAS的“飞牛”圈子里，N3150依然被封为“飞牛圣体”。

为什么叫“飞牛圣体”？这还得从飞牛系统（fnOS）说起。这是一个基于Linux开发的私有云NAS系统，界面漂亮，功能偏向影音和下载。在这个社区里，大家发现老一辈的N3150虽然算力平平，但胜在架构成熟，几乎所有外设驱动都是开箱即用，不容易出现莫名其妙的死机或者掉盘现象。而且因为它太便宜了，买回来坏了都不心疼，这种“低成本试错”的属性，让它成为了新手练手的最佳沙袋。相比之下，那些新款J4125主板，价格动辄三四百，一旦翻新出问题，那真是肉疼。

可能有人会打个大大的问号：“这都多少年前的电子古董了，跑现在的NAS系统不会卡成PPT吗？”其实大可不必担心。飞牛系统对硬件的门槛出奇的低，官方推荐配置就是4G内存起步。N3150虽然老了，但它是正统x86架构，不是那种魔改的ARM。这意味着你在安装系统时，不用担心兼容性问题，官方镜像基本秒认。

在具体的场景应用中，把它当成一个纯下载机是性价比最高的选择。无论是用迅雷、Aria2还是qBittorrent下载4K电影，N3150的CPU占用率都能控制在非常舒适的区间。如果你想把它当成家庭影音库，挂个SMB或者NFS协议给电视盒子推流，解码压力主要在播放端，小主机只负责存取硬盘数据，这点读写速度对它来说简直是洒洒水。甚至你想做内网穿透（比如frpc、zerotier），跑在后台也是稳如老狗。

至于大家最关心的软路由性能，这事儿得辩证地看。双千兆网口做软路由，物理条件是具备了，但N3150的性能极限就在那里摆着。对于家里还在用百兆宽带，或者普通的千兆宽带（300M-500M下行），它跑OpenWrt配合科学上网插件，是可以轻松跑满的。

但是，这里有个重要的知识点：如果你的家庭宽带是运营商那种超千兆（比如2000M下行），或者你打算开启非常复杂的科学上网插件（比如大量的分流规则、广告过滤名单、甚至是解密SSL），N3150的单核性能确实会有些捉襟见肘。毕竟它的单核主频只有2.08GHz，处理高并发数据包时CPU一跑满，网速自然会下降。不过，如果你只是单纯的内网iptables转发，或者做一个旁路由网关，它的性能绝对是过剩的。而且别忘了它的核心优势：功耗只有5-6瓦。这跟那些动辄50W甚至100W的性能怪兽软路由相比，一年下来省下的电费，可能都够你再买一台N3150了。

最后，作为一个在垃圾堆里摸爬滚打多年的老司机，必须得给各位新入坑的朋友泼一盆冷水：这种老工控机的水，比你想象的要深。虽然N3150主板本身很皮实，但因为大多来自企业淘汰下来的设备，有些机器可能常年24小时运行在恶劣的工业环境中，主板上的电容可能已经鼓包，或者SATA接口因为频繁插拔导致接触不良（虚焊）。

更有甚者，有些无良卖家会把那些有暗病的主板刷上漆，或者把焊死的内存颗粒冒充可插拔内存条卖给你。所以，在点击“立即购买”之前，有几个硬性指标必须跟卖家确认清楚：能不能亮机？进入BIOS会不会自动重启？硬盘有没有坏道？两个网口是否都能识别？最稳妥的办法，是直接让卖家拍一段视频：从按下开机键开始，到进入系统界面，最后用测速软件跑一下网速。

如果这些都能通过，那235元的价格，还要什么自行车？这不仅仅是一个入门级NAS的开端，更是一张通往极客世界的低成本门票。只要机器能点亮，接口全活，这个价格买入完全是可以接受的，甚至可以说买到就是赚到。

如果你也想在闲鱼上蹲这种性价比神机，不妨把关键词设置得精准一点：“N3150”、“双千兆”、“无风扇”、“4+64”。说不定下一块被你捡漏的宝贝，就在某个角落里等着你。当然，按照咱们“垃圾佬”的一贯宗旨：看完不买，等于白赚，立省235元也是一种快乐嘛。
