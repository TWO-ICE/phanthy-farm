今天在二手鱼刷到了一款N100 mini小主机，标价396元，还带一块小屏幕（需加50元），外壳是3D打印的，有三种款式可选，颜色还能自由定制。点进去一看，成色几乎全新，卖家描述得也挺实在——裸机不含内存硬盘，电源要+10元送12V3A适配器，包邮非偏远地区，支持自提。行吧，价格挺白菜，先看看参数再说。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHvrrTA679X47QgrHibicRURO8zyibbvACibTjxaWvaqSeTBpkoeIN2vPyrVcJsljQibibMLjLNLZW9QpCA/640?wx_fmt=png)


这款小主机用的是Intel N100处理器，属于Alder Lake-N系列，4核4线程，基础频率0.8GHz，睿频最高3.4GHz，TDP仅6W。虽然不支持超线程，但日常刷个飞牛NAS、跑个轻量Docker、挂个PT或者当个软路由完全够用。指令集方面支持SSE4.1/4.2、AVX2，还有VT-x/VT-d虚拟化和AES-NI加密，安全性与兼容性都不拉胯。说白了，这就是一台低功耗“传家宝”级别的准系统，性能虽不炸裂，但胜在省电又安静。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHvrrTA679X47QgrHibicRUROKE442Z0K6eI5hqdoBF0nfAEDe3j328jibkHtHRJsWibn2ugq7OLWHAMw/640?wx_fmt=png)


扩展性这块，它支持NVMe/NGFF M.2固态 + 2.5寸SATA硬盘双盘位，2.5寸硬盘位已经配好了SATA数据线和电源线，这点很贴心。内存方面是单条DDR4笔记本插槽，官方支持最大16GB（实测有人上32GB但不稳定，卖家也明确写了“更大没试过，不保证”）。接口配置为USB3.0×2 + USB2.0×2、千兆网口，日常接键鼠、U盘、移动硬盘毫无压力。另外主板预留了支架孔位，方便加装小屏幕——当然，屏幕得另掏50块。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHvrrTA679X47QgrHibicRUROyutw2icB1kKbaxvLLKhia48LAjWPvVm1XBkyufJmibNwPiagWGXI9iaGAaw/640?wx_fmt=png)


外壳是3D打印的，质感肯定没法跟金属机箱比，但胜在个性。三种款式可选，颜色还能按自己喜好调，DIY味儿十足。说实话，这种“手搓主机”在二手鱼最近冒出来不少，基本都是用公模N100主板，配上爱好者自己打的壳子，再挂出来卖。比起品牌整机动辄五六百的价格，396元（含屏幕）确实算中规中矩，甚至略香。毕竟现在N100整机在二手鱼普遍要450往上，有些还缺硬盘位或内存插槽。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHvrrTA679X47QgrHibicRURO5vy1VWFhTd1xS7NUChFHUtr1A6jsT7x1gQ4uF41Do1Bcz3Un7jUNUg/640?wx_fmt=png)


当然缺点也有：毕竟是裸机，内存硬盘得自购，加上8GB内存+256GB SSD，整套下来大概500出头；3D打印壳散热一般，长时间高负载可能有点热；而且因为是个人组装，售后全靠卖家良心，不像大厂有保修。不过话说回来，“这个价格还要啥自行车”？能稳定跑NAS、HTPC、软路由，已经值回票价。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHvrrTA679X47QgrHibicRUROtE6K7VlHglVdDR99JtP9qZ1NUNZK2oibdNdh0wKYvtPspJERSAc7p2w/640?wx_fmt=png)


可能有人会问这机子能跑飞牛NAS吗？完全可以。双盘位+千兆网口+N100的硬解能力，刷飞牛、OpenWrt、PVE都稳得很，社区教程一堆，小白也能上手。而且从参数看，6W低功耗和4核配置，刷飞牛NAS或轻量服务足够，但如果你要跑重型虚拟机，可能得加钱上更高级U。二手鱼上类似配置的NAS专用机往往更贵，所以这台算是“性价比之选”。


 


如果你想入手的话可以参考下面的几条建议：

1. 想搭轻量NAS？这机子够用。

2. 预算卡500内？闭眼入不吃亏。

3. 追求颜值质感？建议加钱买品牌。

4. 看完不买，立省396元。
