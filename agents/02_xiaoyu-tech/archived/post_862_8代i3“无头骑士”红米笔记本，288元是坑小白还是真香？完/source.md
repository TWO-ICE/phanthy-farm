# 8代i3“无头骑士”红米笔记本，288元是坑小白还是真香？

![封面图](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXEYxeVle3UFzgaEJHbHP09RWl4CSkqRwk4QQLk55QeFib6UYRiaicLdebldia2MwmYicO7dYgrAmsFjIFA/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/DMDY8XROtHl8DYKJ6jA9Vg

居然还能看到288块包邮的笔记本？而且还是红米牌的。没错，就是在二手鱼里刷到的。一台RedmiBook 14，i3 8代处理器，4+128G配置，但注意是“无头骑士”。啥叫无头骑士？就是屏幕没了，只剩下主机下半身了。那么这价格值得入手吗？一起看看这到底是个啥情况。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEYxeVle3UFzgaEJHbHP09R05QRyqPbc4khk7tibHuTaxWlHV0gETkFlryEM9J2TZv43rrT7uDCGng/640?wx_fmt=png)


处理器是Intel i3 8145U，双核四线程，性能只能说一般般，4G内存和128G SATA固态，在今天是绝对的“入门级”，或者说“勉强能用级”。但它的核心卖点就一个字：**便宜**。288元，还包邮，这价格在很多地方可能真的就是一两条烟，或者两三顿外卖的钱。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEYxeVle3UFzgaEJHbHP09R2Os6lofib97lhDXxon1xfL33bTksGCybmHq1E4odjK9XoH5srK7dDxw/640?wx_fmt=png)


这台机器标注了两个问题：触摸板失灵，BIOS有密码。对于想拿来当迷你主机用的人来说，触摸板失灵基本可以忽略，反正都是外接键鼠。BIOS密码这个，据我所知通常给主板CMOS电池放个电就能解决，算是个动手小门槛。接口正常是个好消息，意味着它作为一台小主机的扩展基础还在。卖家没提电池状态，这是个建议和卖家沟通，如果电池完全报废，那它的移动属性就彻底归零了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEYxeVle3UFzgaEJHbHP09RmolfDSbG4ZmT8CpCHmNzgKmCibEcaic4mTLQoiat8HTlS35v041Feu28Q/640?wx_fmt=png)


那么，288元买它图啥？如果你手头恰好有块闲置的笔记本屏幕或者便携屏，那它瞬间就能变身成一整套超低成本办公娱乐机。写写文档，处理下表格，看看网页视频，甚至接电视当个播放器，它的性能是够用的。它更像是一块“电子边角料”，但偏偏有人能把它做成一道不错的“家常菜”。这很符合二手鱼里“垃圾佬”们的快乐哲学：用极低的成本，满足一个具体而微小的需求。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEYxeVle3UFzgaEJHbHP09RZlYduia6icbUjRsStoLMytzUqODUXdxNlEsia268YkOpd6IArBUcCQy6w/640?wx_fmt=png)


所以，建议来了。如果你不是一个喜欢折腾、对电脑基础知识几乎为零的小白，那我劝你**不懂别碰**。这明显是给特定人群准备的玩具。但如果你是个有点动手能力，想组个超低预算下载机、客厅播放器，或者给孩子练练打字的基础电脑，那它确实提供了一个匪夷所思的低价选项。
