# 二手鱼里的惠普迷你主机火了，不吹不黑，78块捡个NAS主机还是挺划算的

今天在闲鱼上“海鲜市场”闲逛的时候，大数据竟然给我推了个标价78元的硬通货。定睛一看，居然是一台基于惠普T420迷你电脑改装的飞牛OS NAS小主机。

老实说，看到“78元”这个数字，第一反应是这要么是骗子，要么就是电子垃圾收破烂的价。再往下翻详情页，发现卖家描述得相当详尽：“非偏远地区包邮”、“到货插电即用”、“成色9成新”。甚至还提供了一个选配套餐：要是觉得自带的不够用，再加16块钱就能把硬盘盒和WiFi网卡带走。算笔账，即便选了套餐，总价也不过百元上下。这种价格在现在的数码硬件市场里，连买个像样的充电头都费劲，居然能买到一台能跑系统的x86架构小主机？

这不禁让人好奇，这到底是个什么成色的机器，能让卖家打着“白菜价NAS”的旗号在闲鱼上吆喝。

先扒一扒这台机器的“底裤”。它的原身是惠普T420，这是一台经典的商用迷你主机，当年在企业办公室里也是默默奉献的主力军。它搭载的处理器是AMD的GX-209JA，听起来名字挺生僻，实际上这是一颗非常古老的低功耗嵌入式CPU，双核双线程，主频仅仅1.5GHz。

现在动不动就是3GHz、4GHz的时代，1.5GHz可能会被笑话，但它的优势在于极低的功耗。这颗U基于“美洲猫”架构，虽然算力跑分不高，但应付轻量级数据吞吐还是绰绰有余。机器板载了2GB内存，而且是焊死在主板上的，这意味着你没有任何升级内存的可能，这也是它最大的硬伤之一。存储方面，它使用一个8GB的USB接口固态盘作为系统盘（好在是可以自行拆卸更换的）。除此之外，它还配备了千兆有线网口，支持中文BIOS，最关键的是支持通电自启和定时开机功能。

整机功耗官方标称只有5瓦，这是什么概念？大概就是连续运行24小时，耗电量也就跟床头灯差不多，而且它是被动散热或者低速风扇静音运行。体积更是极致小巧，大概就一本厚的新华字典那么大，藏在路由器后面或者电视柜角落里几乎隐形。

卖家似乎为了证明这机器不是砖头，还特意录了演示视频。视频里，飞牛系统（FNOS）跑得相当欢快。演示内容包括手机相册自动备份、文件上传下载，以及最考验磁盘吞吐的4K蓝光视频播放。视频中显示，播放一个35GB大小的蓝光原盘文件时，随意拖动进度条，画面响应迅速，没有出现卡顿。

考虑到这颗1.5GHz的老古董CPU，这个表现确实有点“反向虚标”的意思，属于超出预期的惊喜。这也侧面说明了飞牛系统的优化策略——它主打轻量级、本地化部署，对硬件资源占用极低，而且核心功能都支持离线运行。这种把十年前的老商务机挖掘出来改造成NAS的做法，简直就是数码界的“废物利用”典范。

很多人看到2GB内存和8GB存储，第一反应是“这能干啥？连个微信都跑不起来吧”。

确实，如果你指望它能跑Windows 10或者Windows 11，那还是趁早洗洗睡吧，别说Win10了，连纯净版Win7跑起来都得把虚拟内存用到爆。但是，作为一台家庭专用的NAS（网络附加存储），它的定位非常精准。

想一想家庭NAS的核心需求是什么？不是跑分，不是多开，而是24小时不关机、低功耗、稳定存储。用这东西做个照片备份中心，把你手机里几万张珍贵照片存进去；或者做一个家庭电影库，把下载好的4K电影扔进去，通过电视或者平板随时播放；甚至挂个BT下载任务，几天几夜下点冷门资源。

这些任务对于操作系统来说，只要是个稳定的Linux内核就能胜任。尤其如果你家里正好闲置着几个旧的2.5英寸移动硬盘，直接插在这个小主机背后的USB口上，它瞬间就变成了你的“私有云服务器”。相比于某宝上那些两三百块钱的智能盒子，不仅系统里全是广告，而且数据都在厂家云端，这种物理上掌握在自己手里的设备，安全感完全是维度的差异。

那么，78元这个价格到底是不是“坑”？我特意去查了一下2025年当下的二手行情。

不带系统、没有任何配件的惠普T420“裸板”，在各大二手平台的均价普遍在100元到130元之间。而且买回来的只是个裸机，你还得自己去官网找BIOS固件，自己折腾写盘工具，自己配置系统引导，对于没有Linux基础的小白来说，这中间折腾的时间成本可能远超那几十块钱的差价。

反观这一台，78元虽然便宜，但卖家其实是个技术流。他不仅预装好了正版的飞牛系统（省去了新手最头疼的“刷成砖”风险），还附带了电源适配器（虽然不是惠普原厂的，但实测电压电流匹配，可用），甚至连通电自启的BIOS设置都帮你调好了。最绝的是还送教学视频，这服务意识，简直比某些大厂的售后还贴心。这不仅仅是卖硬件，简直是在卖“技术解决方案”。

不过，咱们还得理性泼一盆冷水，避免大家冲昏头脑盲目下单。

2GB的运行内存在今天是实打实的硬伤。虽然现在的飞牛系统吃内存不多，但如果未来系统大版本更新，或者你在后台挂了太多的Docker容器（比如去广告插件、监控抓图等），内存爆满会导致系统卡死甚至无法启动。另外，那个8GB的USB系统盘也实在太小气了，飞牛系统本身就要占掉一部分，剩下的空间装点缓存日志很快就满了。所以，建议到手之后，立刻去买个64GB甚至128GB的USB 3.0接口的固态U盘或者迷你SSD换上去。现在国产的64G固态U盘也就十几块钱，这点投资千万别省，否则系统盘红了灯哭都来不及。

再者，AMD GX-209JA这颗U的性能上限就在那摆着。它能流畅播放35GB的4K蓝光片，是因为那是“硬解码”或者“源码输出”，大部分工作是由你播放端的电视或解码器完成的。别指望它能充当“转码服务器”，如果你在外地用4G网络访问家里的NAS，想让它把画质从4K压缩到720P再传给你，那这CPU基本会当场罢工。它更适合“局域网内轻度单人使用”，如果是全家五口人同时往里传照片、同时看不同的电影，那这可怜的百兆网口和低频CPU大概率会排队报错。

值得玩味的是，最近在飞牛的官方社区里，这种用T420老机器玩“白菜价NAS”的风气越来越盛。相关的讨论帖热度极高，甚至成了入门NAS玩家的“毕业设计”。有网友调侃道：“这U跑得比我家路由器还安静，一年电费也就两杯奶茶钱，挂在墙上吃灰都不心疼。”

还有人算了一笔极致的账：主机78元，加装WiFi网卡10元，买个USB硬盘盒6元，再买个国产64G U盘30元，总价124元。这就搞定了能自动备份照片、能看电影的私有云。这年头，124元在一线城市可能也就够吃顿稍微好点的肯德基全家桶，“这个价格还要啥自行车？”

不过，回归理性决策。如果你家里已经有一台闲置的旧笔记本、淘汰的台式机，或者手里已经有了N1盒子、贝壳之类的东西，那这台78元的机器确实没必要“重复上车”。数码产品虽然便宜，但买回来吃灰也是浪费资源。

但对于那些刚刚对NAS产生兴趣，想低成本试水，又不想去研究复杂的Linux命令行、不想折腾驱动冲突、不想配置复杂网络设置的“小白”用户来说，这台“开箱即用”的飞牛小主机，绝对是个省心的选项。

特别是对于在校大学生、租房党，或者是想给远在老家的父母搭建一个简单相册备份设备的孝顺儿女，这台机器的性价比真的能打。毕竟，丢了自己不心疼，坏了也不心疼，搬家往兜里一揣就能带走，这种灵活性是传统大体积NAS无法比拟的。

最后，如果你看完这篇文章心里长草了，我有几条“掺了水”的实诚建议：

第一，别指望它有什么高性能，把它当成一个高级点的“智能U盘”或者“单盘位NAS”，心态就平和了。只要不折腾复杂的虚拟化，日常轻NAS任务绝对够用。

第二，到手务必第一时间换个稍微大点的系统盘，8G实在太局促，这是系统稳定运行的基础。

第三，如果你手头已经有了类似功能的设备（比如刷了OpenWrt的老路由器），千万别为了凑热闹再买一个，电子产品买来不用就是电子垃圾。

第四，看完如果不买，那你直接立省78元，这是最划算的买卖！
