# 二手鱼刷到了90块的华为升腾C92迷你主机，这玩意儿刷个飞牛当NAS不香吗？

今天在闲鱼上“扫楼”的时候，一个标价90元的帖子差点让我以为眼花了。标题赫然写着“华为升腾C92迷你主机”。等等，华为什么时候出过这种长得像插座一样的玩意儿？还要命的是只要90块？带着疑惑点进去一看，原来是场误会。这“华为”指的是那个做瘦客户机的升腾（Sugon），和做手机的那个华为半毛钱关系没有，纯属名字撞车，蹭了波热度。但这都不重要，重点是这个小方盒子的配置和价格，实在有点让人挪不动步。90块钱买台能点亮、能跑系统的主机，这白菜价是不是也太离谱了？看看底部的数据，浏览量已经冲到了16万，居然有2697个人点了“想要”。看来，被这种“电子垃圾”魅力吸引的，绝对不止我一个。

咱们先别急着冲，冷静下来拆解一下这玩意儿的成色。这台C92虽然挂着迷你主机的名头，但本质上是一台标准的办公瘦客户机。先看心脏：Intel Celeron J1800。老玩家应该对这颗U不陌生，这是2013年发布的“Bay Trail”架构产物，双核双线程，主频2.41GHz。放在今天，它的性能大概相当于十年前的低端笔记本，或者现在百元级安卓手机的芯片水平。也就是能亮机、能跑Office，勉强应付一下轻量级网页浏览，你要是想用它来剪视频、打游戏，那基本属于想瞎了心。但作为NAS或者软路由，这老U有个得天独厚的优势：省电。基于22nm制程，TDP（热设计功耗）极低，这就意味着它发热量小，非常适合24小时开机挂着不掉链子。

再来看身板。整机尺寸131.5×167.5×32mm，大概就是两盒扑克牌摞起来的大小，重量仅为525克，也就是一斤多一点。这体积塞在弱电箱里、塞在路由器旁边，甚至用双面胶贴在桌子背面都毫无压力。接口方面，这老古董倒是出奇的良心：1个USB 3.0接口（虽然蓝色的是3.0，但在这个年代能有就不容易，外接移动硬盘跑满百兆网问题不大），5个USB 2.0接口（接键盘鼠标打印机够了），1个Intel千兆网口（这是作为NAS/软路由的灵魂，Realtek的烂网卡往往坑死人，Intel的网卡稳定性就是定海神针）。视频输出给了DVI+DP的组合，虽然现在HDMI是主流，但DP转个线也能凑合用，而且它居然还支持双屏输出，这点确实没想到。

对于咱们这种喜欢折腾的玩家来说，这台机器最性感的地方其实不在CPU，而在BIOS。卖家描述里明确写了：BIOS没锁，支持U盘启动（开机按F12），还能来电自启。这三点简直是“神级”加分项。BIOS没锁意味着你可以刷入第三方BIOS或者调整底层参数；F12选U盘启动意味着重装系统、PE维护极其方便，不用折腾BIOS设置；而“来电自启”功能，这对于作为NAS或下载机使用来说太关键了。一旦家里断电再来电，机器能自动开机，不需要人跑去按开关，这才是真正家用服务器的标配。

不过，天下没有免费的午餐，90块钱肯定买不到全套。卖家玩的是典型的“模块化打包”战术。主机只是个空壳，你要想用，得加钱。电源要+15元（原装12V适配器），底座+3元（竖着放省地方），如果要mini-PCIe插槽（虽然这机器大概率没全高卡，但预留了接口）+5元，DVI转VGA或HDMI转接头各+5元。这一顿操作下来，如果你的内存和硬盘也要从卖家那买，总价很容易就超标。

这里要重点说说内存和硬盘的坑。这机器用的是DDR3L（低电压版）内存，频率通常在1333或1600MHz。现在DDR3虽然便宜，但你也得手里有存货，或者去二手市场几块钱一根买下来。硬盘方面，它支持mSATA接口。注意，这个接口比较老了，速度远不如现在的M.2 NVMe协议固态，但跑个SATA 2.0的速度还是有的。对于NAS这种主要受限于网络带宽的应用，硬盘速度其实不是瓶颈。卖家默认只给8GB到64GB的小容量，装个系统就满了，所以数据存储肯定得依赖后面那堆USB接口挂移动硬盘。

价格方面，咱们来算笔账。裸机90元，加上电源15元，运费6元，如果卖家不包内存硬盘，你自己去闲鱼淘一根4G DDR3L内存（约10元）和一个64G的mSATA固态（约25元），整套下来大概在150元左右。即使你咬咬牙让卖家配齐内存硬盘，总价大概率也会在200元以内。200元能买到什么？一个像样的机械键盘都不止这个钱。所以在性价比这块，只要你的需求不是“性能”，它确实是无敌的。

这机器能干什么？卖家其实也给出了明确的路径：刷飞牛NAS、OpenWrt、iKuai或者iStoreOS。现在国产NAS系统（比如飞牛OS）对硬件要求其实非常低，J1800这种双核处理器跑起来绰绰有余。你可以把它当成一个家庭下载机，挂个迅雷或者qbittorrent，24小时不间断帮你冷下载电影；或者当成一个轻量级媒体服务器，给孩子放点动画片。虽然它的CPU性能弱，解码不了4K高码率视频，但通过SMB协议传输文件给电视播放，那是千兆网口的事，跟CPU关系不大。另外，做一个软路由也是极好的选择，它有双网口吗？原配置似乎只有一个千兆网口，但你可以通过USB转网卡或者PCIe扩展口来实现多网口，把它刷成OpenWrt，全屋科学上网、去广告流控都能交给它。5W左右的功耗，一天24小时开着，也就0.1度电左右，一个月下来电费甚至不够买一瓶可乐，这点对于常年开机的设备来说非常重要。

当然，我必须得泼一盆冷水，防止大家冲动消费。如果你指望这台机器能流畅运行Windows 10/11进行日常办公，或者想给它装个爱奇艺看4K视频，那还是趁早死心。J1800跑Win7也许还能勉强回忆一下过去，跑Win10就能让你感受到什么叫“卡顿的艺术”。它的性能只适合跑Linux核心的系统，比如Debian、Ubuntu Server或者上述的专用NAS/路由系统。

还有几点必须要提醒的避坑指南：
第一，**内存是硬伤**。这机器虽然最高支持8GB内存，但J1800架构太老，内存控制器性能有限。如果你想跑Docker容器，建议至少上4GB内存，2GB内存跑现在轻量级的NAS系统都会捉襟见肘，一旦多开几个插件，OOM（内存溢出）分分钟教你做人。
第二，**散热问题**。虽然是低功耗U，但这小盒子全靠被动散热（或者一个小风扇）如果放在弱电箱这种密闭环境里，夏天热浪滚滚很容易死机。建议还是放在通风良好的地方，或者自己动手给它换个薄一点的固态硬盘，减少内部积热。
第三，**USB接口的稳定性**。五个USB 2.0接口虽然多，但电流供电能力未必足。如果你外接的是那种3.5寸的移动硬盘（需要独立供电），千万别指望主机的USB口能带着跑，很大概率会供电不足导致硬盘咔咔响。这种情况下，必须给移动硬盘接独立供电，或者使用带供电的USB Hub。

最后，咱们来总结一下这90块钱的“华为”到底香不香。
如果你的定位是：想入门NAS但不想花几千块买群晖/威联通，想折腾软路由但不想买几百块的X86软路由，或者家里正好缺一台给打印机做服务器的机子，那么这台C92就是完美的“数字劳工”。它便宜、耐用、静音、省电，坏了也不心疼。它就像一把用了一半的螺丝刀，虽然不能拿来切菜（高性能需求），但拧螺丝（轻量服务）它是一把好手。

但如果你是个数码小白，看这玩意儿便宜就想买来当主力电脑用，那我劝你冷静。买回来装不上系统、卡顿、蓝屏会让你心态爆炸。而且二手电子产品，尤其是这种企业退役下来的洋垃圾，成色参差不齐。虽然卖家写了8-9成新，质保90天，但硬盘有坏道、内存金手指氧化这类小毛病还是得自己做好心理准备。

一句话建议：看完不买，立省100%。如果你真的有上述的折腾需求，这90块的小盒子确实是个性价比极高的玩具；如果你只是觉得“便宜”就下单，那这90块还不如去加两个鸡腿。毕竟，电子垃圾虽香，但吃灰的往往是买回来不会用的那一类。
