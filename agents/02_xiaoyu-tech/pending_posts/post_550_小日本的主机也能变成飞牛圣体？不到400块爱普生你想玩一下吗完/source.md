# 小日本的主机也能变成飞牛圣体？不到400块爱普生你想玩一下吗？

今天刷到个小日本的主机，型号是爱普生st170e，卖家要价398元。没错，就是那个做打印机投影仪的厂家，这是他们家endeavor系列的商用小型电脑，如今估计是大船靠岸了，大量流入到二手鱼里。外观是纯白色的，体积非常小巧，感觉很适合做飞牛圣体或者是软路由。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemDdnu6p0OT0AHkkgNAtRmnicIiaoN5cI6SWm3ibouOeRDVagFZOM1ic2WVFRGU1c4c76Bej2WfDGV6KNzicWgKuUoyzyR8A6SYebro/640?wx_fmt=png)


我研究了一下卖家给的配置，这货用的是笔记本的标压CPU，原配是i3 4100M，还能选i7 4705M。最关键的是，CPU居然是可以更换的！这对于垃圾佬来说，可玩性瞬间就上来了。支持两条三代笔记本内存，还能塞两个2.5英寸的硬盘。接口也齐全，虽然是个老咕噜棒子，但除了打游戏之外，日常工作也可以使用。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenrTZMCCLgzR8FEq24b67lPKAvXDVjHBlVRKKJJXqUBPnNI6X7qE6aOYCicaDVyiaSqEXLdiaN730bFu5ybmTK9saLGDPFSWGQDls/640?wx_fmt=png)


当然，这东西毕竟是N年前的产物，虽然叫迷你主机，但比现在的N100那些小盒子还是要大一圈。性能上，i3-4100M放在今天，也就勉强能办公、看个视频。指望它剪辑视频或者玩大型游戏，那就是想多了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekiaarzJoO7lCz0KlQfS2RA7mH1SCApKtNGgZ98Ay14l1ISfOwt2EqhsPZo5xagrUHLCCH3kZ4Og7ydEeFCibibPA27kevohxkAO8/640?wx_fmt=png)


卖家给出两个套餐。套餐1：i3处理器 + 8G内存+256G固态硬盘+电源，只要389元，还包邮！如果你有更高的需求，套餐2是i7-4705M+16G内存+512G固态，689元。说实话这价格比咱们国内的工控机要稍贵一些，但人家贵的也是有道理的，毕竟是正经的商务机出身，做工更为精良。在我看来，如果价格再降100，性价比立马翻倍。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelbqadfD4saCmZsCQTu37m0LAyppU0Aps5EDCpCO0ANqXjdVDI0Kg91zibsibRJiakoWpNQYria1cmSagQlFicXelmCDuNJbnmXs4IM/640?wx_fmt=png)


卖家说得很明白，这机器适合刷飞牛。如果你一直想体验NAS，但又觉得群晖威联通太贵太复杂，花不到400块钱搞这么一台小主机，插上两块硬盘，刷个飞牛OS，放在家里做个私人云盘，备份照片、电影，或者挂机下载，简直不要太爽。当个软路由也是绰绰有余，性能碾压那些几百块的J1900。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelv4QN1TibXXkHxyVdummYArwjuJNtjRqYSje6JYUicy6HPZdicZicHaUc0sK9M5snL3gAibQGECI0CBNw2XmibyFOlUnMqjCw9lMU4g/640?wx_fmt=png)


如果是刷飞牛的话，建议i3的套餐比较划算，因为i3的功耗比i7低，发热也小，对于这种小机箱更友好。另外有个建议，这货没有标配无线网卡，虽然留了mini PCIE接口可以自己加，但动手前得想清楚，你需不需要Wi-Fi。另外，这种老平台的性能摆在这，别抱有不切实际的幻想，就是个大玩具。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCen4OIMlJpgR2PfXLjF6yl7F3plngIZKSOV1AZtxH09IapLPbAXjTicT7ibYqYRICpH4rhu67UA4aDoCRql648zpHYRMEk2eB6tCs/640?wx_fmt=png)


那么问题来了，你觉的这款小主机是你理想中的飞牛圣体吗？面对这种洋垃圾小主机，你是会果断出手尝个鲜，还是觉得这是在坑小白？评论区聊聊你的看法，让我看看有多少真·垃圾佬！
