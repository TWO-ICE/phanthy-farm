# 牛真香系列，二手鱼 420 元 N100 准系统，刷飞牛血赚不亏

朕没事就爱刷二手鱼，每天睡前不翻半小时，连觉都睡不踏实。要说二手鱼捡漏，最让人惦记的就是“飞牛圣体”级别的迷你主机，N100、N250这些型号以前那叫一个风光，当年刚上市时，是极客党和NAS玩家的梦中情机，凭借低功耗和够用的性能，在圈内火得一塌糊涂，如今虽说不算顶配，但在入门进阶圈里依旧是香饽饽。可这货在二手鱼里堪比大熊猫，少见还价高，想蹲个低价比登天还难，好几次看到标价虚高的，都想吐槽卖家是狮子大开口——漫天要价！直到上周，刷到这款火影炙影N100准系统，420元的价格直接让我眼前一亮，这价格和配置要比很多的飞牛圣体强很多。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGpZU43VVlnWfEvibE5HqJ3yRmSarlaq6VlaDdr98sU5L46IayHiaEWdE4A0Sicu2GsTUeKsibic6va8kA/640?wx_fmt=png)


先说说核心的N100处理器，这可是“飞牛圣体”的标配，当年刚推出时，10nm制程工艺在迷你主机里算是黑科技，Tremont微架构加持下，4核心4线程的配置，基础主频1.1GHz，睿频能冲到3.4GHz，再加上4MB三级缓存，日常刷飞牛OS完全够用，甚至轻度办公处理文档、做表格都不费劲。最绝的是它6W的TDP，省电得像个乖宝宝，集成的UHD核显还支持4K解码和HDR10，偶尔连电视看个电影也丝滑，这性能放在入门级里，性价比真的没话说。唯一的小遗憾就是准系统没内存没硬盘，得自己额外配，但内存+硬盘也就300元左右，总成本可接受，完全不影响它香。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGpZU43VVlnWfEvibE5HqJ3yfiaZqQCCYe4SGV2f427ic52huApvSQMiaHgBjicdh8zLufLmcXCQlQbyHQ/640?wx_fmt=png)


接口配置这块，N100简直是诚意拉满。4个USB接口，外接硬盘、鼠标、键盘绰绰有余，再也不用为接口不够用而抓耳挠腮；2个HDMI接口，双屏办公或者连接电视都方便，家庭影音和办公需求一次性满足。再加上WiFi蓝牙二合一，原装12V3A电源和主动散热风扇，硬件配置没得挑。扩展性也绝了，支持DDR4内存和M.2硬盘位，自己插个16G内存+1T固态，立马变身小钢炮，当年这配置在同价位里堪称王者，如今二手价420元，性价比依旧在线。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGpZU43VVlnWfEvibE5HqJ3yKymhaxaoDMibVZL8MDfAvzbpc83OLgNu69sRypvKcvciawiaVW4Vu32nw/640?wx_fmt=png)


它的优势很明显，价格低、功耗小、扩展性强，适合预算有限的极客党和想低成本入门NAS的玩家。缺点嘛，除了需要自己配内存硬盘，CPU性能属于入门级，但对于目标用户来说，这些都不是事儿，毕竟这个价格没有缺点全是优点。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGpZU43VVlnWfEvibE5HqJ3yAZslZaONtvkdxMvDRZQTnpLE6SgwcANLaPuprnI2TBaiciaZicJKnWibZg/640?wx_fmt=png)


可能有人会问，420元的二手准系统，会不会是翻新机或者有暗病？其实不用担心，这款N100当年出货量不小，个人自用流出的也多，只要仔细核对机身序列号和配件，避开那些评价模糊、交易记录异常的卖家，翻车概率比中彩票还低。二手鱼捡漏虽香，但谨慎点总没错，毕竟谁的钱都不是大风刮来的。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGpZU43VVlnWfEvibE5HqJ3yd6nYs554AmTBrIZuTE0TEarSBxguqZfGFzdjhXZ8pDZgfkehCMaeQw/640?wx_fmt=png)


可能有想知道，这台机器除了刷飞牛和当NAS，还能用来干嘛？日常轻办公完全没问题，处理文档、做表格、看视频都丝滑，甚至偶尔开个简单的设计软件也能应对。而且体积小巧，不占地方，放在家里当下载机或者软路由也很合适，一物多用，性价比直接拉满。当年它就是凭借全能性圈粉，如今二手市场依旧能打，足以见得实力不一般。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGpZU43VVlnWfEvibE5HqJ3yUJPMpzxyS4VgW4MpJbKomSQbBjP6aS8ov5gkia59OlfXV75PpG6akmw/640?wx_fmt=png)


说了这么多，有没有同是飞牛党或者NAS爱好者的朋友？你们在二手鱼捡过最香的漏是什么？有没有入手过N100系列的迷你主机？欢迎在评论区分享你的经历，或者聊聊这款N100值不值得冲！老规矩，看完不买，立省420元。
