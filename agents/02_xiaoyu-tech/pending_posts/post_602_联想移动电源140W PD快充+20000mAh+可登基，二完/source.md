# 联想移动电源140W PD快充+20000mAh+可登基，二手鱼200元捡到宝？

今天在二手鱼刷到了一款全新未拆封的Lenovo ThinkPlus锋行者140W移动电源，标价200元。这个价格感觉还可以，毕竟当年这玩意儿刚上市时，官方售价可是奔着500+去的。而且看详情里面写着带3C认证、国行联保、原厂包装齐全，这可信度还是挺高的，那么一起来看看值不值得出手。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFnhAoWicuPWmnV2pXXKKBcj3PI8M6kzYFWnMD4wbxY9H40QQlbHQbL8pr6Fdkba39XkcNUobZMIXg/640?wx_fmt=png)


先说说这产品的硬参数。它容量是20000mAh，支持最高140W的PD快充输出，这意味着什么？意味着你那台满电只能撑半天的ThinkBook 16+，插上它能边用边回血，甚至还能反向给笔记本供电。除了140W主口，还有65W和30W的输出档位，兼容性拉满。苹果用户也别慌，iPhone、MacBook Air统统吃得下，Type-C、USB-A接口都有，出差不用再塞一堆充电头进包里。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFnhAoWicuPWmnV2pXXKKBcjgJic9ibKQ7R2zcT8v3qQk7Skw46pCUugNQD0hPlsV3tIMaz1qnRsgluQ/640?wx_fmt=png)


体积方面，厚度只有39mm，重量控制得也不错，拿在手里不像块砖，更像是个加厚版的记事本。对于经常飞来飞去的商务人士来说，这点很关键——毕竟航空公司对移动电源有严格限制，而这款明确标注“可上飞机”，还带3C认证，过安检基本不会被拦。比起那些杂牌“大水牛”动不动就因为没认证被扣下，它算是省心又合规。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFnhAoWicuPWmnV2pXXKKBcjAOv7bN92OcHL0yY8SrNlfIeFNJzYiaKoQb4Nv3vu9lqUTv3sKrtxcgA/640?wx_fmt=png)


当然，也不是没有槽点。比如虽然支持140W输入，但包装里只配了一根Type-C线，充电头得自备。如果你手头没有支持140W PD协议的充电器，那快充体验就得打点折扣。另外，20000mAh的容量虽然够用，但面对一些游戏本或者长时间户外使用场景，可能还是略显吃紧。不过话说回来，这个价格还要啥自行车？200块买个全新带保的140W大功率移动电源，已经属于“买到就是赚到”的范畴了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFnhAoWicuPWmnV2pXXKKBcjMxsCFybrwp14Irw7C3sbGtsOeBvlsib5Kth9UVTDpbknclFtARLoEKA/640?wx_fmt=png)


可能有人会问：“二手鱼上的‘全新’是不是翻新机？”看细节就行。卖家如果提供了原封塑膜、完整包装盒、说明书、保修卡，再加上能提供购买记录或电子发票，基本可以排除翻新。尤其这款产品本身销量不算特别大，造假成本高，反而假货少。再加上200元的价格远低于市场二手均价，更像是急出清库存或者送礼多余转手。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFnhAoWicuPWmnV2pXXKKBcj9OsPPiaxPPQbQb9iboNBt1Dmiab4ic67Tbmb9p884KaVnfzVvv26qCCgVQ/640?wx_fmt=png)


如果你正好缺一个能扛能打、合规上飞机、还能给笔记本续命的大功率移动电源，这个价位确实值得考虑。当然，建议私聊时确认是否支持7天无理由（虽然大概率不支持，但问一句不吃亏），顺便看看能不能砍到190——毕竟在二手鱼，不砍价等于白来。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFnhAoWicuPWmnV2pXXKKBcjXj7sLJuBEnzRxMdEHYCWiac7ea4eJK7myRZ3p56T1BxKq24qK9FbEog/640?wx_fmt=png)


最后，想问问大家：你们在二手鱼捡过最值的漏是啥？有没有人也入手过ThinkPlus的配件？评论区聊聊，互相避坑也互相种草。老规矩，看完不买，立省200元。
