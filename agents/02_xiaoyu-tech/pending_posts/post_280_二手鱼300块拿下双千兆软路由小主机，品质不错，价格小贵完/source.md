# 二手鱼300块拿下双千兆软路由小主机，品质不错，价格小贵

今天在二手鱼刷到了一款软路由迷你主机，标价300元，价格虽然比一般的飞牛圣体稍微贵点，但胜在全金属机身，再加上4G 1600 DDR3内存和64G msata固态硬盘，综合算下来其实并没贵太多，有兴趣的小伙伴可以关注一下。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGagbV402WWBPiaT4C7UDp8IXJ0Z59sxNYCfCXWQoVnGa8u42r43fMAQlVxXicqtTAxv7LBFFv2GdOg/640?wx_fmt=png)


卖家说这款型号是畅网微控CW-X86-N3050-P1，CPU用的是Intel N3050。这U吧，在低功耗领域算是老将了，双核双线程，基础频率1.6GHz，爆个Turbo能到2.16GHz。对于软路由来说，日常跑个路由、过滤广告或者轻量级虚拟机，基本够用。在二手鱼上，同价位小主机经常用更老的Atom或赛扬，N3050至少是Braswell架构，能效比还行，但比起现在流行的J4125或N5105，性能就有点“矮子里拔将军”了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGagbV402WWBPiaT4C7UDp8IyjY6yDmcwbUQDqzkM427ia33pvNZlAA9jTHZUYCyeckTEX23gKHDGtQ/640?wx_fmt=png)


内存是4G DDR3 1600，单条配置。对于软路由系统，4G内存其实“够喝一壶”了，跑iStoreOS或OpenWrt绰绰有余，还能留点余量跑Docker容器。不过，DDR3现在算是“老黄瓜刷绿漆”，速度比不上DDR4，但好在便宜稳定。如果后续想升级，这板子通常只有一个内存插槽，扩容得换条子，二手市场找8G DDR3也不贵，但要注意兼容性。对比二手鱼其他软路由主机，有些丐版只配2G内存，这4G算良心了，但若想玩多拨或复杂插件，4G可能就“捉襟见肘”。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGagbV402WWBPiaT4C7UDp8IibgW3KO9HzoEWxS7ZQ9QRNPF7ppoicXEWDg6gibyg6nRLQYPuPUq4JwBQ/640?wx_fmt=png)


硬盘给了64G msata固态，系统盘妥妥的。msata接口现在有点“out of fashion”，但胜在体积小，适合迷你主机。64G空间装个软路由系统后，还能剩不少放配置或插件，但如果想搞ALL-IN-ONE塞虚拟机，那就“小庙供大佛”了。好在可以自己换更大容量的msata盘，二手鱼上128G msata盘几十块就能搞定，算是留了点DIY空间。另外，系统预装了iStoreOS，这系统对新手友好，省去折腾，但若你是老鸟想刷其他系统，也没问题。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGagbV402WWBPiaT4C7UDp8IYT9x60xe7gF44CWz9cC4n3MXCHH97ZGfahOWFCRl1jWbdww80lPaHg/640?wx_fmt=png)


网卡是RTL8111H双千兆网口，这可是软路由的“灵魂”。双口够做WAN和LAN分离，RTL8111H驱动成熟，兼容性不错，但和Intel i210那种高端网卡比，性能和稳定性稍逊，不过日常家用“可接受”。尺寸只有112mm*100mm*37mm，比巴掌大点，摆哪儿都不占地方。接口方面，双USB3.0加HDMI，接个显示器或U盘很方便，但USB口少了点，外设多的话得用Hub。整体做工从实物实拍看还行，金属外壳散热基本够用，而且完全静音是亮点。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGagbV402WWBPiaT4C7UDp8IjYlOuAN29xXRI5acYW6xGwVf9pjibkR04V75icOaxIdyo1V9XWoVdsJw/640?wx_fmt=png)


系统预装iStoreOS，基于OpenWrt，插件丰富，设置简单。卖家强调“实物实拍，所见即所得”，还包邮非偏远，这省了后续扯皮。在二手鱼上，同类软路由主机价格从200到500不等，有的配置更高但成色差，这款300元属于中间档：优点是小巧省电、即买即用；缺点是CPU性能有限、扩展性一般。如果只是轻度上网海淘或去广告，它“这个价格还要啥自行车”，但若想玩虚拟化或高速VPN，可能得加钱上更强配置。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGagbV402WWBPiaT4C7UDp8IO9l7FhD9iaVNoEUmLONxqqzQRkLXeFwMuMsqqrFxB38FYURhJVag0bQ/640?wx_fmt=png)


可能有人会问，这N3050软路由功耗咋样？我自己查了下，网上信息显示待机功耗约6-8瓦，满载不到15瓦，电费“洒洒水啦”，适合24小时开机。那么，另一个问题是，iStoreOS系统好用吗？从论坛反馈看，它界面直观，适合小白，但高级功能得命令行操作，有一定学习曲线。


 


结合当前配置在二手鱼上的行情，给点建议：  

1. 轻度用户可入手，性价比还行。  

2. 重度需求建议加预算。  

3. 注意卖家信誉和实物图。  

4. 看完不买，立省300.
