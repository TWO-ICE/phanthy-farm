# 二手鱼有人卖i5迷你主机，4+64固态到手价155元，这波能冲吗？

今天在二手鱼刷到了一款标价155元的i5-3317U 4+64迷你电脑，外壳上写着“乐玑科技

”不知道是什么鬼？但卖家描述得挺实在——机器成色有使用痕迹但无维修，功能测试正常，还特意说明缺个开关帽。整机重约1kg，体积不到20×20×4厘米，全金属外壳配风扇散热，看起来确实是个紧凑型的小盒子。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGzL4qLAnibjvia2mpQXqhw0xpqGicmNLhxKsWoSCbFic2RRibjL2TLdF4SVHlCZzc4xIpnkhUMwdqib0WA/640?wx_fmt=png)


这款主机搭载的是Intel第三代酷睿i5-3317U处理器，2核4线程，基础频率1.7GHz，最大睿频2.6GHz，TDP仅17W。虽然是2012年前后的低压U，但毕竟是正经i5，支持VT虚拟化，在当年属于轻薄本主流配置。内存方面只配了单条4GB DDR3L笔记本内存，存储则是64GB的mSATA固态，另带一个标准2.5英寸SATA硬盘位——这点很关键，意味着用户可以自行加装一块机械或SSD硬盘，组成双盘系统。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGzL4qLAnibjvia2mpQXqhw0xeMcHBlt5lY1uAJzicugcOGSJec81EfHmAGQEeiaLmJEd2ibK7PGBtZ7Fw/640?wx_fmt=png)


接口方面，它提供了VGA和HDMI双视频输出、一个千兆网口、一个mSATA插槽和一个SATA接口，供电为常见的12V 5.5×2.5mm接口。虽然没有USB 3.0，也没有Wi-Fi模块，但作为有线连接的下载机、HTPC或轻量NAS，基础功能是齐全的。尤其适合跑一些对性能要求不高的Linux系统，比如飞牛fnOS这类国产轻量NAS系统。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGzL4qLAnibjvia2mpQXqhw0xoicHv8kn3ibaDaiaN9JsQr1jZiaNrSRTVmbd8ssndWAyWdzCAzGibtoT8Rg/640?wx_fmt=png)


那么问题来了：2025年还值得买这种十多年前的老平台吗？一方面，当前存储价格普遍上涨，64GB mSATA固态本身已不好找，单独买可能就要七八十元；加上4GB内存和完整主板，155元不含电源的价格看似便宜。但如果算上额外15元电源费用，以及后续可能需要升级内存或加装硬盘的成本，实际投入可能接近200元甚至更高。而市面上同价位的新品迷你主机，虽然性能未必强多少，但至少支持USB 3.0、M.2 NVMe、Wi-Fi 5/6等现代接口和协议。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGzL4qLAnibjvia2mpQXqhw0xD1BVibjXRQ6FR2KCc1hKXXB18QyKZ6lPoy7WibUYvhMEz0llWNfylEQg/640?wx_fmt=png)


可能有人会问这U能跑飞牛系统吗？能是能但体验有限，飞牛对硬件要求不高，i5-3317U完全满足最低门槛，4GB内存勉强够用，但若想开多个Docker容器或多用户访问，就会明显吃力。如果只是做基础文件共享、影音转码（软解）或离线下载，它还能胜任；但别指望它处理4K硬解或高并发任务。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGzL4qLAnibjvia2mpQXqhw0xvw42W5Qs5kmDFS9EgBRfssEtP5LV7UUP4Z3YL4k0UlicV4BhIDrZicOg/640?wx_fmt=png)


也可能有网友担心“是不是智商税”。其实不算智商税，但属于“需求匹配型”产品。如果你手头正好缺一台低功耗、静音、可7×24小时开机的小主机，且愿意折腾老硬件，那它性价比不错。但若你追求即插即用、长期稳定或未来扩展性，那这笔钱不如加一点上更新的J系列或N系列迷你主机。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGzL4qLAnibjvia2mpQXqhw0xIPBibY0brpForicAXo4cCxS2KoxbicHQssMSlvgxqlXdubMjzH6sTZ9Ig/640?wx_fmt=png)


对此产品有兴趣的话，可以在二手鱼搜索“i5-3317U主机”这个关键字就可以找到此产品，如果找不到可以通过图片进行搜索，都搜索不到的话，那可能是此产品已卖出或者是下架了。


 


以下是个人一些掺了水的建议：

1. 老U能用，但别期待高性能。

2. 155元不含电源，实际成本要算清楚。

3. 适合轻量NAS、下载机或备用机场景。

4. 看完不买，立省155元。
