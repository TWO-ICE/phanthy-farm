# 想玩NAS又怕踩坑？这台115元的OECT或许刚刚好

今天在二手鱼刷到了一台网心云OECT主机，标价115元，还带系统预装。坦白说，115元真的有点小贵！要是你懂刷机、会倒腾这些，直接买原装系统的机器就行，海鲜市场上也就75-80元搞定。但如果你是个技术小白，懒得自己动手，那就只能多花点银子了——115元直接全套服务，省心又省力！


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXE3vwzrmoZ5CNOvBxgqk2IMBEgQoiaeUzxrJps6B8AIjd40ibxia6Cm5UEm3cpFYXVZSaxJtW1ypK6RQ/640?wx_fmt=png)


这台机器其实是当年“矿难”后流落民间的产物。网心云OECT原本是用于边缘计算节点的小型设备，后来项目收缩，大量机器流入二手市场。如今它摇身一变，成了DIY玩家眼中的香饽饽。尤其是对想入门NAS又预算有限的朋友来说，这玩意儿简直就是“白菜价里的战斗机”。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXE3vwzrmoZ5CNOvBxgqk2IMTV5w0wpNTQcaskSs8POd4WVRyxejiagQkuJ1YJsdDkat9pC5NyLuang/640?wx_fmt=png)


先聊聊硬件配置：搭载的是瑞芯微RK3566四核处理器，主频最高2.0GHz，搭配4GB内存和8GB eMMC存储。虽然听起来不算顶配，但对于轻量级NAS任务完全够用。更关键的是功耗——整机满载也不过5W左右，待机甚至能压到1W，电费党狂喜。插上电就跑，一个月电费可能还没一瓶矿泉水贵。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXE3vwzrmoZ5CNOvBxgqk2IMalXtic6icsXRr4Ey3zvksorHKugicPiaJNiacjYCfXfGM3hvuPN5X8Da57w/640?wx_fmt=png)


网络方面，标配千兆网口，实测跑满没问题。机身自带一个USB 3.0接口，官方只支持单盘，但社区大佬早就破解出可外接USB HUB，最多能挂五块硬盘。另外，它完美兼容2.5寸SATA固态硬盘，拆开底壳就能直接装，不用额外供电，对桌面整洁党非常友好。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXE3vwzrmoZ5CNOvBxgqk2IM5rKxDU1Q3vDBew7iaA1OEeEyUzoqfRBCCMS94Z7ej2azarbR2oWNnibw/640?wx_fmt=png)


系统玩法更是百花齐放。卖家通常提供三种选择：黑群晖、iStoreOS 或 Armbian。黑群晖适合只想备份照片、文档的懒人；iStoreOS图形界面清爽，插件丰富，还能跑Docker；Armbian则更适合折腾党，命令行一把梭，自由度拉满。更有甚者，连Home Assistant、AdGuard Home都塞进去了——这哪是矿渣，分明是百变小钢炮！


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXE3vwzrmoZ5CNOvBxgqk2IMHn910uVbnUOibOHiaLEALKlQknuf1YOQIwdq4LJaeqoW9QjuGnIDRYzw/640?wx_fmt=png)


可能有人会问：“这机器性能这么弱，能当正经NAS用吗？”这其实要看你的需求。如果你只是用来同步手机照片、存点电影、偶尔远程访问下文件，它绰绰有余。但别指望跑虚拟机、硬解4K或者多人同时高负载访问——那确实强人所难。它不是万能，但在百元价位，能做到稳定、低功耗、可扩展，已经赢麻了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXE3vwzrmoZ5CNOvBxgqk2IMRc2r70LL2rjWrkUZFkJfJfhKsLsHeay0ib4uxFJiaRaLsG4J1f8mzGNw/640?wx_fmt=png)


那么，为什么有人说“增强版才值得买”？因为早期OECT有低配版（2+8G eMMC），性能捉襟见肘，刷系统都卡。而增强版（4+8G）才是主流推荐款。现在二手鱼上基本都是增强版流通，但下单前务必确认配置，别图便宜踩坑。除非你真能50块拿下低配版，否则不如加点钱一步到位。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXE3vwzrmoZ5CNOvBxgqk2IMHV42EAuMR83ber23mbg5jqtM9QyMuVjuPrT9aMTSt80wEpDZlWmAMw/640?wx_fmt=png)


当然，缺点也不是没有。比如散热一般，长时间高负载可能降频；USB供电能力有限，挂多盘得配带外接电源的HUB；还有就是外壳塑料感强，颜值靠3D打印拯救——不过这些对实用党来说，瑕不掩瑜。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXE3vwzrmoZ5CNOvBxgqk2IMLWKyBqe6uWPzaW7j7FmryMmniaIpaPN75ZQXuXJdoxnaOUBErC83YBw/640?wx_fmt=png)


说到底，115元买一台能跑黑群晖、功耗比路由器还低、扩展性还不差的小主机，还要啥自行车？飞牛圣体虽好，奈何钱包不答应。有猫盘的同学当我没说，但对大多数只想简单备份、不想折腾的人来说，这颗白菜，闭眼捡就对了。老规矩，看完不买，立省115元。
