# 二手鱼5块钱买的至强CPU能干啥？炼金？你可能想多了

二手鱼上有人卖英特尔至强XEON 5110处理器，5块钱一个？手里还屯了58个。如果这款处理在垃圾排行榜上排在第二，估计没有哪款处理器能排第一。那么这个垃圾还有啥用呢？有一些大聪明可以会灵光一现，拿来炼金啊，现在黄金都飙到每克1500+了。那么这活值得一干吗？


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXH8X1xANv5iacGbzFicYz8v7WVHUaI01NibBp7CU19Qxic9sdvmP7NOseHAnX3fGTUROBhDkYNDqj06Tw/640?wx_fmt=png)


首先，给结论泼点冷水：兄弟，想靠这个发家致富，咱还是醒醒吧。暂且先不说炼金的事儿，这玩意的性能被几十块的赛扬甩开几条街，纯论实用性，它最大的价值可能就是给你的钥匙扣增加一点“赛博朋克”分量感。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXH8X1xANv5iacGbzFicYz8v7Wg50WrUcxMlyXCiaCkicdYLKpdfxQPdVL8eCVnL94AwQib3QOfIulbdyfA/640?wx_fmt=png)


但是！重点来了。“提取黄金”这事儿，它还真不是都市传说。CPU的针脚和内部芯片底座上，确实会使用极薄层的黄金作为镀层，因为它抗氧化、导电性无敌。一个普通的CPU里黄金含量大概有多少呢？说出来你可能不信，大概只有零点零几克，甚至更少。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXH8X1xANv5iacGbzFicYz8v7WrfKsVjpxLiaKyx8YeDzOco6bbWRRNjbv7ibKXbOJlqXiaepkcEoO7yYsw/640?wx_fmt=png)


一个普通的台式机或服务器CPU，其内部的黄金含量通常在 0.1克到0.3克之间，很多老旧或低端型号甚至低于0.05克，咱们就以0.1克为例，当前的金价就以每克1500元为例，一颗CPU估计能提取出价值1.5元黄金。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXH8X1xANv5iacGbzFicYz8v7WRObGawG2HYficbnXN4ISeiclUSH9biawSibrbNvu2mu1uywx4Giaywp9UuA/640?wx_fmt=png)


你以为这就完了？提取过程极难，需要专业的化学试剂（如王水等强酸）、复杂的提纯工艺和严格的环保处理流程。这个过程危险、有毒、污染环境，且对操作者专业知识要求极高。而且经济上完全不划算：你为了提取价值1元左右的黄金，需要投入的化学品、防护设备、时间和承担的风险，成本可能是其价值的数十倍甚至上百倍。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXH8X1xANv5iacGbzFicYz8v7W4xuNrVtdEiaR1OCd4oj1ibS3rhZo5K5hQ81VSicCokBmWsRKYvSZsuIjA/640?wx_fmt=png)


网上那些酷炫的“芯片炼金”视频，往往需要收集以公斤计的废旧CPU，经过复杂、危险且可能污染环境的强酸化学流程，才能得到一粒比芝麻还小的金疙瘩。你所付出的时间、安全风险和环保成本，早就远远超过那点黄金的价值了。所以，从“残值”角度看，指望它炼金，性价比为负。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXH8X1xANv5iacGbzFicYz8v7Wl8mbEbTQ2qJ3VXc1OmCQicrGObgXD1Ipw3nCDbsOMXialPyuXRspETOQ/640?wx_fmt=png)


那它到底有啥用？我觉得，这5块钱花的是一种“收藏”心态，或者极客的“玩具”心态。如果你是个硬件爱好者，想低成本搭建一个老平台怀旧，或者给小朋友做个硬件识别教具，它倒是个有趣的标本。它的存在，更像是一个时代的注脚，提醒我们数码产品折旧速度有多恐怖。配合当下存储产品价格波动、二手市场风云变幻的背景，这种“论斤卖”的处理器，恰恰是市场最真实的“价格晴雨表”。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXH8X1xANv5iacGbzFicYz8v7WECF8DuSLA11FMGAkoSEadGhMiaqs80YgUt7aWeNp69HXIv2Lh4aKVnQ/640?wx_fmt=png)


所以，如果你刷到那个“58个打包”的链接，别激动。除非你想开个“CPU博物馆”，或者真的有某种特殊的工业回收渠道，否则，为炼金而下单，绝对是笔血亏的买卖。不如花5块钱，买一个科技发展的“化石”放在手里把玩，感慨一下就好。
