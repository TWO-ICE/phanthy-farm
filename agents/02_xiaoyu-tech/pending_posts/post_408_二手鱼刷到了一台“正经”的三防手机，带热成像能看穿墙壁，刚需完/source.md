# 二手鱼刷到了一台“正经”的三防手机，带热成像能看穿墙壁，刚需的老司机可以冲了

今天在二手鱼刷到了一台卡特彼勒CAT S60 FLIR——带热成像技术的三防手机，标价500块。我第一反应是：“这玩意儿不是应该卖几千吗？”点进去一看，卖家描述得挺实在：美国军工级三防、世界第一部自带热成像的手机、高通骁龙617、3GB+32GB存储、支持SD卡扩展到128GB……还列了一堆专业用途：地暖检测、电力工程、汽车维修、电路板检修……好家伙，这不是手机，这是移动红外望远镜吧？


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEpbjWaYRNCm85y9X30JjYfsbYOCNC9LxpbmJYlew0VyVwWGk4Q7pIy0rl1Tdno3waG1Fr515noRg/640?wx_fmt=png)


说实话，看到“热成像”三个字我就有点上头。这功能以前只在电影里见过，消防员拿它找火源，特工用它透视墙体……现在居然塞进了一台手机里？而且只要500块？虽然我知道这手机年头不短了（查了一下，2016年发布的），但就冲这个FLIR热成像模组，感觉已经值回票价。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEpbjWaYRNCm85y9X30JjYfMbD4l13riaszpsPGgH1bibib3cVkBnKBadRTYaJvC5hAj5Wb34hibgJ9tw/640?wx_fmt=png)


参数方面，高通骁龙617放现在确实老掉牙了——八核A53架构，性能大概相当于现在的入门级芯片，日常刷个微信、看个网页勉强够用，但别指望打游戏或多开App。内存3+32G在当年算中规中矩，现在嘛……只能说“能用”。卖家也提醒了：“不太适合下载太多软件app”，这话翻译一下就是：别当主力机用，当工具机刚好。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEpbjWaYRNCm85y9X30JjYf7rWNSWhKjB9zluuDfxU4vicJBtR8oetz6QRCP0RlkAiaxBMH2FJCozUw/640?wx_fmt=png)


网络支持方面有点坑：只支持移动2G/4G、联通3G通话+4G上网。但问题来了——2025年了，国内很多地方2G/3G基站早就退网了。这意味着你可能能上网发信息，但打不了电话。如果你所在城市还在用4G VoLTE，那还好；要是偏远地区或者运营商已关停旧制式，这手机就真成“单向通讯器”了。这点必须提前确认，不然买回来变砖头。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEpbjWaYRNCm85y9X30JjYf0WIu7EeQibCdiaaCNud03qTJ6LXWagsQhB0yelHawFjX0bMc7V4mLkPw/640?wx_fmt=png)


至于三防性能，CAT S60可是正经IP68+MIL-STD-810G认证，防水防尘抗摔，泡水、摔水泥地、零下20度开机都不在话下。加上热成像镜头能测-20℃到120℃的温度分布，搞装修、修暖气、查漏电的朋友确实能派上大用场。红外图像虽然分辨率不高（FLIR Lepton模组，约80×60像素），但识别温差足够了——比如墙里哪根水管漏水、插座是不是过热，一眼就能看出来。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEpbjWaYRNCm85y9X30JjYfY33r59AFW7Gic57k1z76RJ19g232y3btGic7ich7p9AvuSL2p4ySlln7w/640?wx_fmt=png)


这机子全新时卖过5000+，二手市场过去几年普遍在800-1500之间浮动。如今500块出手，算是地板价了。但也要清醒：它不是“性价比神机”，而是“特定场景工具机”。如果你只是想换台日常用的手机，那它连Redmi Note都打不过；但如果你干的是水电暖通、设备维保这类活儿，这价格等于白捡一个专业热像仪（单独买FLIR ONE都要上千）。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEpbjWaYRNCm85y9X30JjYfYiavNDIkNMVYJ5FT0FibQiaib1ibffDIZ6ibRz6wB1icVxAfmgibYBP7OUDILg/640?wx_fmt=png)


可能有人会问这热成像能当夜视仪用吗？不能。它看的是温度差异，不是可见光增强。黑夜里如果没有温差（比如整面墙都是室温），画面就是一片模糊色块，别指望看清人脸。那么能不能连电脑当外接热像头？理论上可以，但需要特定驱动和软件支持，且USB OTG兼容性未知。普通用户别折腾，拿来直接用APP（比如FLIR Tools）最省心。


 


以下是个人一些掺了水的建议：

1. 仅推荐给有热成像刚需的技术人员。

2. 务必确认本地2G/3G网络是否可用。

3. 别指望当主力机，当工具更香。

4. 看完不买，立省500元。
