# 580元就能捡漏惠普的工作站？这便宜到底该不该占？

> 原文链接：https://mp.weixin.qq.com/s/Jnjy2Z5pSQZ6ijWQXuXbLQ

最近二手鱼里的风向又变了，那些动辄几千块钱的高端货突然不香了，反倒是些老咕噜棒子开始冒头。今天

就刷到一个稀罕物，HP/惠普Z2 mini G3/G4小型图形工作站准系统。580元这个价格要比一般的准系统主机贵一些，但这是一台工作站主机，性能比一般的主机要强很多倍。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenlmO8KQLmuO6IlUU2chfG6M0aLOPkcuYTWLwohBAZEibbsMGRYRdMMXROWznXvAJA3BCd9Fzd1udng2lhibvKvDhQOuV4E6PZibY/640?wx_fmt=png)


这玩意以前是专门给设计师、工程师这类高需求人群用的，全新落地怎么也得七八千甚至上万，最大的特点就是小，机箱只有216mm见方，也就比巴掌大一圈，可以挂在显示器后面，瞬间变身一体机 。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelWZGQyYsDbTibhy15nqmArXEK8ePgOO0V5FWn7gJtN4PRiaV2TxtMZaMCVCOgJGdnNN2Q4Z50KwU0rkh7VwJYAWkhBicxqvI7NyI/640?wx_fmt=png)


虽然主机小，但接口非常丰富，G3版本带了四个DP接口，G4是三个DP口，再加上两个Type-C，可以组个多屏炒股或者看监控，最关键的，它用的是笔记本内存，支持两条普通DDR4，还能上ECC内存，这就很“工作站”了。硬盘位支持一个M.2 NVME和一个2.5英寸的，日常使用完全够用。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekP5zdibGcIUjRsgqCfdvZZZ3YsLppOIEoNKfibBv8j0ibRpEHxDu3WawiblW4XZ0RQIR2libhlzuoGTV62h8yuGb09WpX0gDM2JHuA/640?wx_fmt=png)


580元的价格是准系统的售价，只带一张M620的2G独显。看似有点贵，但咱们来算笔账：一个H110或者C236芯片组的定制主板，带个不错的电源板，在二手市场值个200多吧；那个定制的机箱和散热器，做工很扎实，值个100多；M620显卡虽然老，但毕竟是专业卡，看个视频、玩个轻量级游戏没压力，拆卖也值个100多；剩下的就是那个200W的专用电源，怎么也得80。这么一算，光配件拆开卖就差不多500了，这么看确实有点亏，但不多。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemeDQQNm58GIAw3qrdOLz1LQEE7npRhYS3FtIfr8ibmoHUIqia6auNXdHIsBQy4lv8u4FMIOaOuQXPRGh96CntFtQUibXMz0ACoQo/640?wx_fmt=png)


当然买这种机器也很容易踩坑，它的CPU选择比较奇葩。G3用的是至强E3 v5或者6代的i7，这些U虽然便宜，但有的型号需要特殊的BIOS支持。比如卖家给的套餐里，那个1225v5或者1280v5，性能其实跟现在的赛扬比都不一定有优势，但胜在稳定。如果是G4版本，能上CC150甚至九代的9700F，那就舒服多了，但价格也上去了，从1430到2530不等，给人一种鱼和熊掌不可兼得的感觉。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenlHdIxA9Z8ZKE332wUOiaWIX7bbYBhaZYNjJRcV3b4dpJo1ibNCkibeXhHdD7v5J944d8KwygSAOxQ63Jb3WHk6xsvcSqfyjKW8o/640?wx_fmt=png)


如果你相中了这机器，我觉得适合以下的场景：

第一，刷个飞牛当NAS。这机器体积小，功耗相对可控，有两个硬盘位，接口全是高速的，做影音服务器或者备份机比那些几百块钱的矿渣强太多了，性能和稳定性根本不在一个层级。

第二，当个纯粹的低频办公或HTPC。放在客厅接电视，看看4K电影，或者给父母上个网、打个小牌，那稳定性绝对秒杀同价位的任何全新洋垃圾小主机。毕竟人家底子是工作站，7x24小时不关机是基本盘 。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemicqkNnZibvQawA1iczMOxIhT42z3H2RyicibibQxaYBNqFSyyAEw3vV1CJROAwZDkbrFRteQiasF234jictUJCleTMicsQp31m7vI07Uc/640?wx_fmt=png)


另外也有两个问题需要提个醒：

一是散热问题。这种小机器为了塞进工作站级别的芯片，风扇策略通常比较保守，如果换成高功耗的CPU，建议到手后自己调整一下硅脂和风扇曲线，或者干脆买个涡轮风扇架子辅助散热。

二是电源适配器。很多卖家配的是那种大砖头电源，如果你桌面空间紧张，心里得有个准备，或者自己淘个体积小点的氮化镓替代品，不过要注意功率匹配。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCen6VyKpmcaA1BhTYt5EVaK9J2xfZLcWzHp07m8qNYgxebzxQ1eYGElWIjc0RGoweFKp6APO7eg9HotDAzEYDktzHPNE8cibBibjM/640?wx_fmt=png)


如果你人傻钱多的话，花580块钱能买个准系统的工作站玩玩，也是可以考虑的，买回去哪怕就是拆零件玩，也比买那些不知名的小主板有意思。不知道各位老铁，你们觉得这种几百块的“过气工作站”，到底是真香还是智商税？如果是你，会买来刷个飞牛，还是纯粹摆着吃灰？咱们评论区见！
