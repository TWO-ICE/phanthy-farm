# 二手鱼268元的N5105小主机，卖家说“接口丰富”？扯犊子！预留的全是焊点！

今天在二手鱼刷到了个挺扎眼的东西：一台标价268元还包邮的康佳N5105小主机。这价格，第一反应确实是挺白菜，毕竟现在随便买个机箱电源都不止这个数。页面描述写着“全新板子，功能正常，测好发货”，配的图是个简单的3D打印外壳，看着挺素，但一股浓厚的“工控板魔改”风味扑面而来。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFEdW1q5FHbsqnJD4QTJq3yBMJuEB1rNBeOyxq8asfImw2KiauC4dZt3k9wKda9YvEOT8NgRib7SAbw/640?wx_fmt=png)


仔细瞅了瞅参数，这东西有点意思。板子型号SRKGV，用的Intel N5105处理器，8+128的配置。卖家强调其性能对标N100，核显都是24EU。板子尺寸很小，11cm*11cm，带壳也就12cm见方，确实迷你。接口给了HDMI、USB3.1、M.2插槽、DDR4内存槽，还集成了WiFi和蓝牙。电源是12V3A，接口通用。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFEdW1q5FHbsqnJD4QTJq3yzwcExkLDAXfkO8Sfic3QJUndXA9ZSncsia81mZDRt7PuMOibicXgN9cG0A/640?wx_fmt=png)


但是，别急着上头。“可接受”的价格背后，有几个点得掰扯清楚：


 


首先，这严格来说是个“准系统半成品”。卖家明确写了：板子上预留了千兆网口、第二个USB3.1、USB2.0、第二个HDMI、SATA接口及供电、eMMC焊盘等多个接口的插槽位置，但“没补件”。意思是，这些接口的物理座子都没焊上去，你需要自己动手焊接，或者加钱找卖家买他主页“补好了”的版本。这对于没接触过电烙铁的朋友，简直是“眼睛学会了，手说你想多了”。想要一个完整可用的多网口软路由或迷你主机，你得额外付出成本和技术。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFEdW1q5FHbsqnJD4QTJq3yWxvUfQKUsaHj7M8yic5bKibCdgqPCwibDKQCibDhzZia19MlE126mHFHTYA/640?wx_fmt=png)


其次，2025年再看N5105，它的位置有点尴尬。这颗处理器曾是低功耗迷你主机和软路由的热门选择，但如今N100/N200系列在能效比和核显性能上更胜一筹，且成品小主机价格已经大幅下滑。268元买块板加个打印壳，看似便宜，但你需要自备或加购内存、硬盘，还要考虑补齐接口的成本和精力。整套下来，性价比还行，但绝对称不上“神价”。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFEdW1q5FHbsqnJD4QTJq3yVAicM7Ds2evv0qrD6UUTic2f3PAtVzyzUkbb2JEUXVk7PhjqfcnWe6ng/640?wx_fmt=png)


再者，来源和保修是盲盒。所谓“全新板子”，很可能是工控机、瘦客户机等设备的拆机或库存板，流通渠道不明。个人卖家提供“点亮测试”，但长期使用的稳定性和官方保修就别想了。这属于“垃圾佬”的折腾玩具，求稳的用户可能得绕道。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFEdW1q5FHbsqnJD4QTJq3ytqWdlXfDYfCt0oIia5XAmQHLuzMB2hLcDV81aKEAsRkcjrFDgHEPK3w/640?wx_fmt=png)


那么可能有人会问这玩意功耗咋样？做软路由或家庭服务器省电吗？N5105的TDP是10W，整体平台功耗确实不高，比较适合7x24小时开机。这是它目前仍存在市场的一个核心优势。那么卖家说性能对标N100，是真的吗？二者核显规格相同，但N100的CPU架构更新（Alder Lake-N），单核性能强不少，能效更优。N5105多核跑分接近，但综合体验和未来支持度上，N100是更现代的选择。只能说在这个价位段，N5105仍有其存在价值。


 


所以，给正在刷二手鱼、心思活络的你几点建议：


 


1.  明确自身需求。是爱折腾的极客，还是求稳的普通用户？

2.  计算真实成本。板+壳+内存+硬盘+补接口，总价是否仍有优势？

3.  对比当前行情。多看看N100等新平台的准系统价格，权衡性能与预算。

4.  看完不买，立省268元。
