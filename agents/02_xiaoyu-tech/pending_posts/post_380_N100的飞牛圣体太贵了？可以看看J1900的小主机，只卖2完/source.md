# N100的飞牛圣体太贵了？可以看看J1900的小主机，只卖200多香不香？

![封面图](https://mmbiz.qpic.cn/mmbiz_jpg/E9h3abOJCemicUM9ssxJ0g4icicXic7Wk2OWI3Fkicl9fUWK3nGMLAyBxw9d3v6h4ibG3EpviasGicTaibjQ77IMOkzeBdx3l7NtxdtFSZMbblkk34Sc/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/DSUxGUDHwj1BVVCR_An6xw

刷到一个卖家在甩J1900飞牛小主机，一口价218元起， 共分成了四个档， 最高配也才268元。 非准系统，都是完整的主机，而且 卖家已经帮装好了飞牛，到手装上自己吃灰的硬盘就能用， 那这是不是 传说中的捡漏 呢 ？


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCem6nicvpYZMMWYtdsL88QbmgbXOhk9POl790kQaCLWicMuz0D8rd2yiabgxoEyXEbJC4ZIo0yvA6LhZZzg8mKZjjyjaQgZFEuibkFM/640?wx_fmt=png&watermark=1&tp=webp)


这款小主机的核心 是 J1900四核处理器，主频2.0GHz，TDP仅10W，主打节能低功耗。标配4G或8G DDR3内存，32G或64G SSD系统盘， 配置越高价格越贵， 自带一个SATA接口，可内置3.5寸硬盘扩容，满足不同存储需求。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemgUTTEcprWOY0a7cJ8qnYHEr8vhQm8VKBibvC00KZciarn6KYywQ6u619Kricu70FFDKicG5agmk50QtUSMAZdaRNI2G4aG1kEhRI/640?wx_fmt=png&watermark=1&tp=webp)


接口方面 是 亮点，HDMI和VGA双视频接口，既能接新显示器也能适配老设备，两个USB 3.0和两个USB 2.0接口，搭配千兆网口和音频麦克口，日常外接设备完全够用。机身尺寸23 21 6厘米，拍照显大实际小巧，全金属外壳质感不错，也能辅助散热。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelEiaK0UBaCazT58mv42aUfpGQlSx0VM7phx8mn442Lj9d4Ql9vBGxlsJ6kEM0JwfYRfBoveSlFLlVyJkln9NGBmhF9Pvr5hibX0/640?wx_fmt=png&watermark=1&tp=webp)


它的优势很贴合预算紧张的用户和垃圾佬需求，价格跌至冰点，200多元就能入手一台完整的NAS小主机，还送全套配件，省去额外花费。被动散热设计做到完全静音，7x24小时开机也不会有噪音困扰，飞牛轻量化易上手，AI相册分类功能实用，适合新手体验私人云。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCen1XJaM1lpD5dtGCujZIdvJH8AIhteUl4mW0MeaiaCl81XWJmqLI3RG50Io58xH2rgYwj56ITf6cSRCF5qQ3TzYgNC40RTAFu20/640?wx_fmt=png&watermark=1&tp=webp)


弊端也很明显，J1900处理器性能拉跨，毕竟是老旧型号，只能满足基础的文件存储、下载机或软路由需求，无法承担重度办公或影音解码任务。 而且 无质保，后期硬件出现问题只能自行维修，飞牛运行流畅度也会受配置限制。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelPjg4LOlQx8yBHgk7A66A6vhxoEu040HH73a32zRgjcEKVicwck0aG9fqAIjDwib5P3tofa3KlpubUCqMyvHg6QCZl3Flymc8GE/640?wx_fmt=png&watermark=1&tp=webp)


目前 同类 的 J1900小主机大多在120到300元之间，但大多是裸机无配件，像这款配齐配件还预装系统的，218元起的定价 还算 合理。对比299元的联想魔改小主机，它价格更低，接口更全，性价比突出，适合入门新手。 而且 卖家承诺赠送12V5A DC电源适配器、SATA数据线、硬盘供电线和固定螺丝，加5元可配网线或HDMI线，非偏远地区包邮，加8元可发顺丰。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCeklT8vHqLMkVZnbrgt1u5qN7Xibrib3uWVzfrt1Q9OOrVVk6Cm3tWbJYTlQ44OPSjGPUP4JRicbcHoS4s2v81oYwmL2tc3HnfNavU/640?wx_fmt=png&watermark=1&tp=webp)


如果你想 下单，一定要让卖家拍机身细节和开机测试视频，确认 主机好用 避免翻车。如果只是用来当私人云、下载机 的话 ，4 + 32版本完全够用，追求流畅度可选择8 + 64版本，没必要盲目追求高配置浪费钱。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemia4AM4diaicLv52gBN5nIZRdSZRogKSfvyVwE3uUtl3iaVydqKwXg2Y0OiafeBhjRk33dqt8dazgO5DicQl9t52gQnNiaauRh8hbEus/640?wx_fmt=png&watermark=1&tp=webp)


现在很多垃圾佬都喜欢折腾二手小主机，用最低的成本实现实用功能，这款J1900飞牛小主机就是典型的边角料逆袭款。有人觉得它性能拉跨不值得买，也有人觉得预算有限时性价比拉满，大家觉得200多元入手这样一台小主机，用来当NAS还是软路由更合适，评论区说说你的看法。
