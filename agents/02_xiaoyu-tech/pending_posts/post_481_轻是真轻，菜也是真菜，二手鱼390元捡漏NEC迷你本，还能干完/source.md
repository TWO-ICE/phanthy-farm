# 轻是真轻，菜也是真菜，二手鱼390元捡漏NEC迷你本，还能干点啥？

![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEk7Pia0bXEuKO6c8owFPjPk9uMzPaic2CC35lVgNo6w7OxZz1IMt04g9ic1fN7SaibC62eKb5sxoleOg/640?wx_fmt=png)


今天在二手鱼刷到了一台标价390元的NEC超迷你笔记本电脑，第一眼看到价格我差点以为自己眼花了——这玩意儿当年在日本卖23万日元，折合人民币一万二起步，现在居然只要三百九？还包邮？我的CPU都干烧了，赶紧点进去看看是不是卖家手滑多打了个零。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEk7Pia0bXEuKO6c8owFPjPkyqCiab4iajd3lnICP8vHz17nFenD6HVlPvIrqaiaZar3abzZicVdXCMCjQ/640?wx_fmt=png)


点开详情页，发现这台机器确实有点来头。整机重量才800克，12英寸机身塞进1920×1080的IPS屏幕，边框窄得能当尺子用。配置方面，基础款是i5-7Y54（第七代低功耗U）、4GB内存、128GB固态；如果加100块，还能上8GB+256GB版本。官方标称续航7-8小时，轻到女生单手拎着去咖啡馆都不带喘的，出差、上网课、追剧、刷抖音完全够用。跑分七万多，在轻薄本里不算拉胯。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEk7Pia0bXEuKO6c8owFPjPkic9pJkicPAdkiaJSvkxtxr0vpWVbKj7lMnM4N99OOT2Prlvt2SWyyZUDA/640?wx_fmt=png)


乍一看，这配置+这价格，简直“性价比天花板”——但冷静三秒后，我开始琢磨：2025年了，这玩意儿真的香吗？


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEk7Pia0bXEuKO6c8owFPjPk5cs1R2XzEvvgHLajFYibMySAZm03ianJpXfhHZvUaKUkLwp6WpsdPArQ/640?wx_fmt=png)


先说优点：确实轻便，屏幕素质在当年算不错，日常办公、看视频毫无压力。而且NEC做工向来扎实，日本本土品控严，很多机器用了七八年还在服役。加上卖家附赠原装电源、支持包邮，诚意看起来挺足。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEk7Pia0bXEuKO6c8owFPjPkg06KVtoU05zJDdZOcsclG0aZAxiak4icsicJgCBR8ZBee9ug4808F0iaibg/640?wx_fmt=png)


但问题也不少。首先，i5-7Y54虽然是双核四线程，但TDP只有4.5W，性能上限很低。你让它同时开个Chrome+微信+网易云，可能就得缓两秒。其次，4GB内存放在2025年，连Windows 11都跑得吃力，更别说装个Office全家桶了。哪怕升级到8GB版，也别指望它能剪视频或跑PS——顶多是个高级“电子书+浏览器”。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEk7Pia0bXEuKO6c8owFPjPkqpFwdcF46kibBibSx1GVG7aZKNeX0ibtcuPwrMkRMXOWiaufPOjqVXwBFQ/640?wx_fmt=png)


最关键的是价格。390元这个价格确实挺诱人，我在二手鱼搜了一圈，NEC系列的笔记本普遍挂价在500+，成色好、带保修的过千的也有。所以在价格的方面，我感觉还算得上是有漏可捡的。当然，在性能上拉跨是不用怀疑的。所以这台NEC，更像是“情怀党”或“极简主义者”的玩具，而不是主力生产力工具。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEk7Pia0bXEuKO6c8owFPjPkFU4CcXk1CiaJWy0ytYHxgkpsC23qjicx8zNnVNNCZga4Ehib7d92rXfBw/640?wx_fmt=png)


说到底，这台NEC值不值得买，完全看你需求。如果你只是要一个能打字、看网课、偶尔追剧的备用机，且对品牌有执念，390元勉强可接受。但如果你指望它当主力机，或者想“一步到位用几年”，那真不如多加两百，看看其他更现代的机型。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEk7Pia0bXEuKO6c8owFPjPkvXPBfz5wGeptWfsqvdxLEq20olsp3yDZT5V51ZbV5dsG31xerVz65A/640?wx_fmt=png)


看完觉得有用？评论区聊聊你最近在二手鱼淘到过哪些“看似捡漏实则踩雷”的玩意儿？一起避坑！最后给几点建议：

1. 轻便≠全能，低功耗U别期待高性能。

2. 4GB内存2025年已严重不够用。

3. 同价位有更多接口新、系统稳的选择。

4. 看完不买，立省390元。
