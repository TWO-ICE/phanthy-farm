# 二手鱼359元的富士通工作站，可装6个硬盘，刷个飞牛香的很

今天在二手鱼刷到了一台富士通 CELSIUS J580 工作站主机，标价359元，准系统（无CPU内存硬盘），能装6个硬盘，刷个飞牛NAS当存储服务器，简直不要太香。不过，先别急着冲，让我来扒一扒它的底细。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGagbV402WWBPiaT4C7UDp8IzicbeqkA25lkQ4qfQvANCC955hjnjMfF5VNc64JdkhLbaEhIfatEjzQ/640?wx_fmt=png)


这台机器属于富士通专业级工作站系列，型号CELSIUS J580，主板是FUJITSU D3628-A1，搭载Intel C246芯片组，支持LGA1151接口的8代/9代至强E系列和酷睿处理器。原厂设计就预留了全高显卡位，也就是说你塞一块丽台P2000进去完全没问题，不像某些小机箱只能用刀卡将就。做工方面，富士通一贯稳扎稳打，钢板厚实，内部布局规整，虽然外观有点“企业风”——灰扑扑、方方正正，但胜在扎实耐用，不是那种塑料壳一掰就裂的“网红机”。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGagbV402WWBPiaT4C7UDp8INUb1L2CFdKWuonwaqib59Uv6RQmMHutLKtf3ibrC9WmqiaX0qgBZmrXpQ/640?wx_fmt=png)


扩展性这块是真的能打。主板自带5个SATA接口、1个M.2 NVMe插槽，还有两个PCIe插槽（x16全高 + x1）。官方宣传说能装6块硬盘，其实是指前面板3.5英寸仓+内部托架组合，但注意：默认只配了2条SATA线和2个SATA电源口。想真装满6盘？得自己掏钱买硬盘架、SATA延长线、大4pin转SATA电源线。这点有点坑，但考虑到359元的价格，也算情有可原——毕竟“这个价格还要啥自行车”。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGagbV402WWBPiaT4C7UDp8IjxibOo1uJlz2pHcNrgqq3wPnHsf8PSiaR4e2pNPn9ZIjmY3EGOudYVNg/640?wx_fmt=png)


性能方面，搭配至强E-2236（6核12线程，主频3.4GHz）的话，跑C4D、PR、CAD完全不虚，甚至比同价位新装的i5主机还稳。而且至强E系列价格常年“骨折”，比如E-2236散片现在也就300出头，性能对标i7-9700F，但便宜近一半。再加上支持ECC内存（虽非强制），对稳定性要求高的用户来说，简直是捡漏神器。不过核显只有UHD P630，如果不用独显，4K输出倒是够用，但别指望玩3A。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGagbV402WWBPiaT4C7UDp8IPTeKuicvVpib7NOwWw63tpL3IX8sgIp5wcZh3Xu6626ZR3fEWBPtdy7w/640?wx_fmt=png)


对比二手鱼上其他同类型工作站，比如惠普Z系列或戴尔Precision，富士通J580的优势在于体积更紧凑（接近MATX大小）、支持全高显卡、接口丰富（2×DP + DVI + 6×USB3.0 + 2×USB3.1）。缺点也有：电源仅250W，升级高端显卡会受限；光驱位占空间，想改NAS得拆掉；默认未配硬盘托架，DIY成本略增。但综合来看，359元拿下准系统，性价比还是吊打多数同龄二手主机。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGagbV402WWBPiaT4C7UDp8I7XcQbdaF8BEgrOEX3H7icokn1modMqdpbYB07kSujPMqcfZmias7U0DA/640?wx_fmt=png)


可能有人会问这机子能当NAS用吗？当然可以！5个SATA口+M.2系统盘，装飞牛、TrueNAS或UnRAID都行。只要加个千兆交换机，妥妥的家庭数据中心。不过记得自备硬盘架和供电线，不然只能挂两块盘干瞪眼。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGagbV402WWBPiaT4C7UDp8IdPyTyZnAAic28nUwAzW8HmQeibsjXtAtmvYgycVyRiaQDhZVlkVYLhwMA/640?wx_fmt=png)


那么如果要上至强E系列和普通i7有啥区别？简单说：E系列支持ECC内存、vPro远程管理、长时间高负载更稳，游戏性能略低但生产力更强。如果你做渲染、建模、虚拟机，选E系列更合适；纯打游戏？那还是i7香。


 


以下的一点建议：

1. 预算500内想搞NAS或轻度渲染，闭眼入准系统。

2. 想直接用？建议选套餐2或套餐4，省心又稳定。

3. 别贪便宜买杂牌内存硬盘，富士通认硬件较严。

4. 看完不买，立省359元。
