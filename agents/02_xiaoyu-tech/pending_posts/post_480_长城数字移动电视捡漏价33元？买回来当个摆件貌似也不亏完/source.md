# 长城数字移动电视捡漏价33元？买回来当个摆件貌似也不亏

最近刷二手鱼突然刷到个老物件，长城的数字移动电视，标价33元。简单翻了下卖家描述，4G内存，支持扩展卡，有收音机、图片浏览功能，功能完好，主打收藏。说实话在2026年还能见到这种品相还算完整的数字移动电视，确实不容易了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCek05GT3hwuaRkF2YpdYQZTPVibvDNqsCxYPM5thRk3TR1zXcxJldY6glDIbW2qXa1TaxZia5kd5yxB0IicpmrbwFhXWylib9y9DnicQ/640?wx_fmt=png&from=appmsg)


这货当年可是正经的高科技。主打移动电视功能，就是你拿着它可以在公交车上、地铁里看CCTV5的球赛，看股市行情，看晴彩电影。那时候3G网络刚起步，流量贵得要命，这种能免费收看电视的小机器，简直是通勤神器。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenlMnxSladrNQjaS3ME5ATqZq9Tvt3Kl9qmwPKBWNcU2zR2uxRibrrZsibT8HvtXZQeM11eZ0ZhuysiaWZK2plofD8PMPicufJQDOU/640?wx_fmt=png&from=appmsg)


配置了4.3英寸的屏幕，内置2200毫安的大电池，官方说能看8个多小时的电视。支持的格式也全，RMVB、AVI、FLV通吃，还有FM收音机、电子书、秒表，功能放到现在看也不算太简陋。特别值得一提的是，它支持APE和FLAC无损音乐格式，当年很多纯音MP3都不一定有的功能。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenA5C4OcFMYhEN9wtoguiaes4ILXfP2oxEciaueTAKC55XgpZAjs49wHNZoJLRFggbzicdIl0Cn93ApoxLTLpvJpCe0Is4Ujp8ppM/640?wx_fmt=png&from=appmsg)


那么这玩意值不值得买？如果你想买来当主力机看电视，那大概率是要失望的。CMMB信号在国内大部分地区早就停服了，别说33块，就算卖家倒贴你33块，你也搜不到节目。卖家特意提到“适合收藏”，其实已经暗示得很明白了，这东西现在的实用价值大打折扣。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekNumhbMoIrMKhhAJafCyVVqCicY2OB8LwAOXsCN3icQsI8riaMzd82BDsHLV0tPsLHicBrE3d2W7KUDnKrNeg0BIIkZicnXmm1HzG0/640?wx_fmt=png&from=appmsg)


从实用角度看，如果你只是想买个备用MP4听听歌、看看下载好的老剧，那它的价值就另说了。卖家说功能完好，那就意味着它的音频解码、视频播放、收音机这些功能还是能正常用的。33块钱买个4.3寸屏的播放器，带独立外放，还能插TF卡扩容，这性价比放在二手鱼上其实挺能打的。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/E9h3abOJCemgPnUj58dwrIcYY798Yjm3FyGz4m8mRBSOWe49ibGrPsZSrSLk9NlvfJ3tZnC6ZkjYIdetYp0br09P6rccRufrckbHBVBHsesc/640?wx_fmt=jpeg&from=appmsg)


不过我得提醒一下，这机器的屏幕分辨率只有480×272，放现在的眼光看确实有点“大果粒”。而且它用的是Mini USB接口，充电线和数据线现在不太好找，卖家可能也不一定配，下单前最好问清楚。另外卖家说了售出不退，这种老机器内部电池状况也是个未知数，如果电池鼓包或者充不进电，33块钱就当买个摆件了。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCek1nTntIj6wMwOOjduT0I8lgj9TTN76qYpqYW9oU5L9ic2tNiay5maj2n8iaicqqzhBf79faIFvBtZC6fiavzC2VibBK8JFFv5apSma8/640?wx_fmt=png&from=appmsg)


如果你是数码怀旧党，或者想买个便宜的小机器给孩子听听故事、看看动画片，那这波可以冲。但如果你指望它能当个真正的移动电视，那还是趁早打消念头吧。最后问一嘴，你们觉得这种十几年前的老数码，是放在柜子里吃灰当收藏品，还是该让它继续发光发热？评论区聊聊呗，顺便说说你们在二手鱼上淘过最离谱的老物件是啥？
