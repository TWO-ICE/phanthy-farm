# 笑不活了！128 块买了矿卡，装魔改驱动像渡劫，玩游戏却舍不得换！

说真的，那种囊中羞涩又想折腾电脑的痛，只有咱们这些“垃圾佬”自己最懂。我那台老主机简直卡成了 PPT 放映机，开个 Chrome 浏览器都能听到机箱里的风扇发出像是老旧拖拉机一样的哀嚎。手里预算紧巴巴只有两百块，想在显卡圈里找活路，无异于在垃圾堆里找金子。我在那个咸鱼（咱们俗称的小黄鱼）上翻了整整两天，眼睛都看花了，不是遇到把 GTX750Ti 这种电子古董吹成“准全新”卖一百八的奸商，就是遇到那种连牌子都没有的“白板卡”，评论区一片翻车惨叫。

就在我准备放弃治疗的时候，P106-100 这个型号突然闯进了视野。这玩意儿在显卡界的名气不大，但标签极其响亮——“矿霸之心”。本来我是发誓不碰矿卡的，毕竟那是过了水的二手鞋，但看到价格标签的那一刻，我的理智瞬间崩塌了：128 块！居然还带着 6GB 的 GDDR5 显存！贫穷让我失去了所有的判断力，满脑子都是“128 块还要什么自行车”，心想大不了翻车就当给这该死的电子爱好交了一次昂贵的学费。

为了这张卡，我付出的不仅仅是那 128 块钱，简直是拿命在拼。我足足蹲守了一个星期，每天就在小黄鱼上刷那些刚上架的宝贝。跟十几个卖家斗智斗勇，那种感觉就像是在搞情报工作。现在的二手商人都精得跟鬼一样，图片拍得模模糊糊，问深了就回你“调试好发货”。

有个卖家信誓旦旦写着“无拆无修，个人自用”，结果我让他拍一张核心背面的照片，好家伙，风扇轴都歪到姥姥家了，明显是暴力拆解过。我直接拉黑，骂了一句“退退退”算是晦气。最后终于逮着一个看着老实巴交的个人卖家，我像个侦探一样反复盘问：“核心发黄没？显存洗过没？有没有暗病？”发货前我还特意叮嘱裹三层泡泡膜。收到货那天，我手都在抖，拆箱一看，确实积了一层厚灰，像刚从煤窑里爬出来，但擦干净之后，核心镜面没划痕，显存颗粒也没明显的焊补痕迹。这运气，出门估计能捡钱，听圈内人说这卡前两年只要八十多，看来我是抄底抄在了半山腰，但这 128 块的性价比依然香得离谱。

拿到卡先别急着高兴，咱们得先科普下这货的“奇葩身世”。这玩意儿根本不是给我们普通玩家设计的，它当年是 NVIDIA 专门给网吧打造的“计算卡”，你可以把它理解成是一个被阉割了手脚的大力士。

它的核心规格跟当年的甜点之王 GTX1060 6GB 几乎一模一样，1280 个 CUDA 处理核心，192bit 的位宽，6GB 显存。看着参数挺唬人，但这货是个“残疾”版本——它根本没有视频输出接口（VGA、HDMI、DP 全部欠奉）。也就是说，你把它插主板上，屏幕根本不会亮，这就是它的“天生缺陷”。我一开始不懂啊，以为 NVIDIA 驱动一装就能用，结果插上去开机，屏幕黑得跟我的心情一样，设备管理器里飘着个带着黄色叹号的“未知设备”。那一瞬间，我以为 128 块彻底打水漂了，差点没把这破卡给拔下来砸了。

真正的“渡劫”其实是从装驱动开始的。既然官方驱动不认，那就只能走“旁门左道”——刷魔改驱动。这过程简直就是一场对新手极度不友好的 IT 认证考试。

首先，你得进入 BIOS 设置，手动把板载网卡给禁用了，为什么？因为如果不禁用，Windows Update 这个破玩意儿会在你联网的第一时间，强行给你推送一个识别错误的官方驱动，然后你的电脑直接黑屏，让你连安全模式都进不去。接着，你需要用 DDU（Display Driver Uninstaller）这种专业工具，把系统里残留的 N 卡驱动删得干干净净，连渣都不剩。

然后是反复重启，安装那个所谓的“魔改驱动包”。我在 BIOS 界面里看着那些英文选项，眼晕得不行，生怕手一抖把主板给刷砖了。那两个小时里，我全身上下的冷汗都下来了，直到最后一次重启，设备管理器里终于出现了“NVIDIA GeForce GTX 1060 6GB”的字样（虽然它其实是 P106），那一刻我差点没哭出来。这哪是修电脑啊，这简直是在做法请显卡显灵。好在现在的 Windows 系统还算有点智能，虽然装驱动麻烦，但装好后它能自动识别游戏调用这块独立显卡，省去了手动切换的繁琐，算是对我受伤心灵的一点慰藉。

说完折腾，咱们再来聊聊性能。这玩意儿就像个性格古怪的天才，有时候神勇无比，有时候拉胯得让你怀疑人生。

先用娱乐大师跑个分，好家伙，四十二万分的综合成绩，比我以前那块亮机卡强了十倍不止，看着那个圆环跑得飞快，虚荣心得到了极大的满足。跑 3DMark 这种专业压力测试，分数甚至比正经的 GTX1060 3GB 版本还要高出一截，毕竟它有 6GB 显存，显存带宽优势摆在那。

但实测游戏就很有意思了。我作死试了一下当下的硬件杀手《黑神话：悟空》（文中提到的“悟空”），全部拉到最低画质，帧数还是只有可怜的 19 帧，人物走路就像在跳太空步，一顿一顿的。这说明这卡虽然是 Pascal 架构，但面对这种次世代的庞大纹理数据，它的老核心还是力不从心，或者说显存带宽成了瓶颈。

转头我又试了试《刺客信条：奥德赛》，这优化也不咋地，结果居然能稳在 45 帧左右，玩起来意外地流畅。最惊喜的是玩《CS:GO》（现在的 CS2），这种电竞网游对老架构特别友好，帧数直接飙升到一百多，画面丝滑得像德芙巧克力，那种爽感简直把刚才被《悟空》欺负的委屈全补回来了。

不过这货也有个让人肉疼的毛病——功耗虚高。这卡毕竟是矿卡出身，体质一般，我用功耗仪实测了一下，满载功耗能干到 120 瓦，这比同规格的 GTX1060 还要费电。算下来一个月电费得多掏几块钱，对于咱们这种精打细算的垃圾佬来说，这心里多少有点不是滋味。

这里必须给想跟风的朋友提个醒，全是血泪经验：

**第一，AMD 平台千万别碰！** 这货是典型的“Intel 专用妾”。它的魔改驱动原理是借用 Intel 核显的输出端来显示画面，P106 只负责运算，也就是所谓的“核显输出，独显计算”。这机制在 Intel 4 代到 9 代的主板上配合得蜜里调油，但到了 AMD 平台，这俩完全是死对头。我朋友不信邪，拿着锐龙 CPU 强上，折腾了一下午，各种 BIOS 设置改了个遍，最后连 BIOS 都进不去，气得他骂骂咧咧地退货，还亏了十几块运费。

**第二，矿卡就是纯赌博，全看脸。** 虽然我这张卡现在稳如老狗，没蓝屏没花屏，但我那个朋友就没这么好运了。他买回去用了两个月，突然有一天黑屏，强制重启后直接点不亮了。拆开一看，显存位置都烧黄了，PCB 板都翘起来了。矿卡在高强度的环境下日夜不休地挖矿了一年多，核心早已老化，你根本不知道它哪一天会寿终正寝。

虽然吐槽了这么多，但平心而论，128 块钱能给一台被时代淘汰的老电脑续命，让它能在 1080P 分辨率下流畅运行大多数网游和早期的 3A 大作，这性价比简直就是降维打击。在这个显卡价格动不动就三四千的年代，百元级的市场简直是荒漠，P106 这种“残废”卡反而成了唯一的绿洲。

但这玩意儿真心不适合手残党，如果你连 BIOS 都不会进，连驱动安装包都不会解压，千万别买，不然这卡除了能让你气得砸键盘外毫无用处。还有那些追求电脑“永不宕机”的完美主义者，也请绕道走，这种随时可能暴雷的矿卡会让你神经衰弱的。

如果你也是个有闲钱、有闲时间、乐于折腾的垃圾佬，且正好用的是 Intel 的老平台，倒是可以趁着现在价格便宜，淘一张回来玩玩。如果能蹲到八十多块的“神价”，那简直就是血赚。哪怕翻车了，折个几十块卖给收电子废品的，也不至于太心疼。

现在看着机箱里这块脏兮兮的显卡，我的心情极其复杂：一边骂它是个难伺候的废品，装个驱动像是在给它上坟；一边又爱死它带来的性价比，毕竟这是我在有限预算里能给老电脑找的最好的归宿了。

只能说，预算两百以内，这就是唯一的选择，没有之一。下次如果还要碰矿卡，我发誓，我一定先给自己磕三个响头，求个平安无事再下单！
