# 二手鱼688元捡漏华为Nova11 8+256G值不值？

朕没事就爱刷二手鱼，刷得多了总结出个规律：捡漏就像摸奖——全靠眼光，偶尔还得拼点运气。前几天翻到台华为Nova11 8+256G，标价688元，1万多人围观，将近600人正在蹲守。要知道这机器2023年刚发布时，8+256G版本首发价2499元，才两年时间就掉到了一包烟的价格，这落差堪比过山车。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXH1jx2QwV5qmtPz2hdqIuvVD35TLCkheiaTut4pQalCP1ibptnF4pyqeTq2ffFyw6ClFfplTj9A3x4w/640?wx_fmt=png)


这手机最吸引我的地方就是轻薄。官方数据是6.88mm厚度，168g重量。这在现在动不动就半斤机的时代，简直是手机界的"清流"。拿在手里应该很舒服，放裤兜里也不会感觉坠裤子。屏幕是6.7英寸的OLED直屏，支持120Hz刷新率。虽然比不上那些顶级旗舰的屏幕，但日常刷视频、看资讯完全够用，色彩表现也还行。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXH1jx2QwV5qmtPz2hdqIuvVZUhIv3ZTm3pDbjV1O6QdOZUeCfUpcQz0y0IAXLyWtpPHeOGibyoxg2A/640?wx_fmt=png)


性能方面，它搭载的是骁龙778G 4G芯片。懂行的都知道，这处理器当年可是中端神U，性能足够日常使用，玩王者荣耀这类游戏也能应付。不过要提醒的是，这手机不支持5G，如果你所在的地方4G信号不好，那就要慎重考虑了。8+256G的存储组合，对大部分人来说都够用，装个几十个APP，存几千张照片压力不大。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXH1jx2QwV5qmtPz2hdqIuvVryGNw92nqkibfrAtOtwSed7iaFicE040Ou304HQsoPyL0qWaIic2IfCu4Q/640?wx_fmt=png)


拍照是这款机子的亮点之一。后置5000万像素主摄，重点是前置居然给了6000万像素！这配置在当年就是为vlog爱好者准备的。现在很多新机的前置摄像头还在用2000万像素，对比之下华为在这点上确实舍得下本。不过夜景拍摄就别期待太高了，毕竟传感器尺寸摆在那里。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXH1jx2QwV5qmtPz2hdqIuvVoV7Rx6L5U51oxKNxuCLU0R5g97kFzPO0UlwWv1sdXUxAcLsFBD0soA/640?wx_fmt=png)


我在网上查了查这款机的现状，发现两个大家最关心的问题。可能有人会问："为什么现在这么便宜？" 其实主要是因为不支持5G，而且发布已经有一年多，二手行情自然下跌。也可能有想知道："鸿蒙系统用起来卡不卡？" 从用户反馈来看，鸿蒙3.0系统在778G上的优化还不错，日常使用流畅度可以接受，但大型应用多开时还是会有点压力。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXH1jx2QwV5qmtPz2hdqIuvVEpyiaTUpDPzSuvPHSwhhPqWVg2We9F3eGLMnWyroNKVH77D9zlcKw9Q/640?wx_fmt=png)


当年的华为Nova11可是中端市场的热门机型，凭借轻薄设计、出色影像和鸿蒙系统，上市后销量不俗，成为不少年轻用户的首选。如今随着新机迭代，它在二手市场的价格大幅下降，却依然保持着不错的使用体验，成为预算有限用户的性价比之选。688元能买到8+256G大存储、鸿蒙系统、高像素影像的手机，确实算得上捡漏。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXH1jx2QwV5qmtPz2hdqIuvVYb2aS9PWzHbvhspPWfun3IJnDOuyZuookC5xibZWHOFrqsgb1pWLT4A/640?wx_fmt=png)


你们觉得688元拿下这款华为Nova11 8+256G值不值？有没有用过同款的朋友，来分享下你们的使用感受？或者你们在二手鱼上还捡过哪些性价比超高的数码产品？当然，如果对这款机子还有其他疑问，也可以直接问我。老规矩，看完不买，立省688元。
