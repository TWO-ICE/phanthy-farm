# 49元捡漏小鲸随身WiFi，解控不限速还带3000毫安电池，冲不冲？

最近逛二手鱼时，发现有人49元卖小鲸随身wifi，有3万多的浏览量，1200多人想要，还是全新仅拆封，号称去控不限速、无套路，这东西到底能不能捡漏呢？


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelOjtxgdqwicWQic99eia73Sxiaib70ic9iaBcL4lM8UYe8xKYkBkvVDQQ6SZR7cy7TSjyWPqazA8L5MSj4QEp6rZJUvEibUoibFZiaVyqSg/640?wx_fmt=png)


小鲸随身wifi支持WiFi6，芯片用的是ASR方案全新蓝版料，可能很多人对这个芯片不了解，其实ASR芯片主打低功耗，连续插电使用也不会发烫，理论峰值速率能到150Mbps，实测正常网速在20到100Mbps之间，刷视频、聊微信完全够用。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCel1iappEhDWVUuXTfibicAiaCZzpPWmfLcaBwI5lICz0eb3H7TpsjCewJn4hlZ2yfEILmwcvFfmYJ2oDnwlrld4rLCa2WD09uiajEds/640?wx_fmt=png)


设备是全新仅拆封，卖家说是刷机去控的，不用被运营商绑定，单设备自己插卡就行，也能免插卡用小鲸的套餐。电池是全新3000毫安，续航能到10个小时以上，还支持直供电使用，插电就有网，特别适合车载或者办公室长期用。最让人放心的是，它有1年质保和永久售后，这在低价随身wifi里很少见。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelROseKf3a9GUsEfy7UU1icMVSKxaT18aYVSFuvCNxBIXKD0zvMHxKTBkmc5zBJakX2tOB3iadT01dmVEyExEiaqicibMTeg8TaPWvI/640?wx_fmt=png)


它的功能是不错，但缺点也不能忽视。首先网速受当地移动基站信号影响很大，卖家在深圳实测网速不错，但如果在山区或者信号差的地方，网速可能会骤降，这也是所有随身wifi的通病。其次卖家提供的套餐分广东专用和全国通用，广东专用套餐很便宜，29.9元就能用1000g，但出了广东就不能用，不注意很容易买错。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemg5BfKXyK9eGsv78KULiblw6Qor3jrhIEN0rdHuyps5Uiaib1RhbQFyJl548gDdeKk34QibRmrsmMoFM05qqjPxLkxQxhgQZVwayw/640?wx_fmt=png)


如果你想出手的话，给大家两个建议。一是如果经常出省，一定要选全国通用套餐，别贪广东专用套餐的便宜，不然出省后设备就成了摆设；二是下单前一定要问清楚卖家，确认设备确实是去控不限速，最好让卖家发实测网速视频，避免买到虚假宣传的产品。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelkicVnEib0T3WBokceNmynjbW1z4ib6Bib5mbloMjcpRSyhFUf55tV93iaRWKQUewMziclXTa4Af67aRA0cA4dOQHre8EohuHVeCn7s/640?wx_fmt=png)


其实小鲸随身wifi当年也算是随身wifi里的热门机型，主打高性价比和无套路，只是后来随着行业竞争加剧，慢慢淡出了主流视野，现在以49元的价格在二手鱼流通，对于预算紧张的人来说确实很有吸引力。毕竟49元的价格，哪怕只用半年，平均每个月也不到10元，比办手机流量套餐划算多了。
