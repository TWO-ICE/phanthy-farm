# 随时远程开机，时刻掌控多台电脑—向日葵智能插线板P2

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/afNLf2a8eXEX8whaud6GVTwVGichTJ3kpONNBIQ7YiagszJ1lrWEUkzdWxyPtKTaAqnOFbtGx0nLnU2icTibUdQApw/0?wx_fmt=jpeg)

大家好，我是小鱼评测，今天评测的产品是来自向日葵品牌的一款智能插线板，型号为P2。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXEX8whaud6GVTwVGichTJ3kpRySHfN3U6czxXxnE9635WZ31C28UmrzvsP8ibxlOxrGwa7svZRf0qGA/640?wx_fmt=jpeg)


众所周知，向日葵这个品牌的远程控制软件在业内是大名鼎鼎，而向日葵的智能插线板，能够与向日葵远程控制软件相结合，同时实现远程开机和远程控制的功能，这不仅要比市面上其他同类产品更为实用，玩法自然也更为丰富。那么实际的使用情况如何，还是一起来看看吧。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXEX8whaud6GVTwVGichTJ3kphu1rXTuzJReWmosic4uUDPay7sx2fm9CGtIsR1DTIiahzJAn9tiafRnbg/640?wx_fmt=jpeg)


在包装方面，向日葵智能插线板比较低调，长方体的包装整体都使用了全黑的配色，外观也没有任何的花哨设计，仅在正中心印有向日葵的标识和LOGO，并注明了Wi-Fi和USB款的字样。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXEX8whaud6GVTwVGichTJ3kpNNb41oibiajQwQnEGwibXKSvccohrJzgsichtPMZJV24ctgcZAYb4zuXyw/640?wx_fmt=jpeg)


拆开包装后的智能插线板，里面除了使用说明之外没有多余的配件，可以看到向日葵的智能插线板同样也是采用的全黑的配色，面板上共有三组五孔国标插口（S1-S3）和三个USB插口。外壳使用的是阻燃材质，正面采用的是磨砂哑光的设计，四周则是光亮的烤漆设计，整体看上去比较美观，即使作为桌面插线板来用，也不会觉得碍眼。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXEX8whaud6GVTwVGichTJ3kpicOv1NmA6PialourWtCuYJqhiboRlA9G1OYAicN9Xh9YwLuIeZRsJTSWMw/640?wx_fmt=jpeg)


向日葵智能插线板在体积方面与市面上常见的插线板相差无几，长宽高分别为230*40*40*27mm，重约385g，线缆长1.7米左右，面板顶部配有一个带有指示灯的实体按键，底部则标示出插线板的最大功率为2500W。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXEX8whaud6GVTwVGichTJ3kp7IOeatWJhiagNGhLjmbicS0OPaYBsev3koKnNiaicnibmM2yPfXJsNIfeVg/640?wx_fmt=jpeg)


至于插线板的背部则比较简单，四周配备了防滑垫，插线板的各种参数信息也清晰地喷印在背部。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXEX8whaud6GVTwVGichTJ3kpFRQWj8bzsCMDQbibynUDEywD7u3A4vliaV2v2icLdgwuIqsKdymv25asw/640?wx_fmt=jpeg)


通过简单的开箱后，我注意到了几个细节，首先发现这款插线板的线缆明显要比一般的插线板更粗一些，周长可以达到3cm；再一个就是插头采用了不占用空间的扁头式设计，并配有保护套，还有向日葵为每组五口插孔都配备了安全门。通过这些细节，感觉到向日葵的这款插线板在基础配置方面还是很有诚意的。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXEX8whaud6GVTwVGichTJ3kpBSZueiczf0rFszt7MO7hDSS0KSnrENviacoOCC6SgicpPaY1818SxvIXQ/640?wx_fmt=jpeg)


通电之后，每组五孔国标插口都会亮起对应的指示灯，顶部按键中的指示灯，也会根据插线板状态，而呈现出不同的状态。如果是蓝色LED灯快闪，则是初始配置中，白灯常亮为通电状态，蓝色常亮为网络连接正常，蓝色慢闪为无法连接网络。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXEX8whaud6GVTwVGichTJ3kp1upsav7ksYSzZcy3vJc6Rjn2TxfDSXwicZdRZ4ljbUpTzRcKNspWHcQ/640?wx_fmt=jpeg)


另外要说的是，插线板上的三个插孔可以在APP里分别控制开关，但是配备的三个USB口是不支持控制的，插线板在通电的情况下，USB插口也会随之开启供电，且无法进行关闭。每个USB插口的最大的输出为5V/2.1A，总输出功率为15W，输出电流为3.1A，相当于一般的常规充电头，虽然不支持快速充电，但为一些电子产品提供供电则是毫无问题的，且能够节省了不少的空间。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEX8whaud6GVTwVGichTJ3kpj0VDfnG3ULAtRHOtTJIJpuib0FmmcJcvmKHuibLuZ4Wibs2JicaVyqj8FQ/640?wx_fmt=png)


在网络配置方面，需要在手机中下载向日葵APP，注册登录之后，点击添加智能硬件或者扫码连接，并按照APP中的提示配置好网络，即可完成设备的添加。这里需要说明的是，插线板仅支持2.4G的WiFi网络，所以事先要选择好手机的WiFi网络。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXEX8whaud6GVTwVGichTJ3kpxbCEgoWtSnL6BCFjme2cuvxFWsUdKghbjRykJGGgQA3fBrqPRj9qmg/640?wx_fmt=jpeg)


连接成功之后，可以看到APP中的操作界面非常简洁明了，想要远程控制电源插孔的开关只需点击对应的图标即可。另外，对于每个电源插孔，向日葵还配备了绑定主机、倒计时和定时功能，倒计时和定时的操作十分简单，只需设置好对应的时间即可，这里就不再多说了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEX8whaud6GVTwVGichTJ3kp3pHFOdeLibOHO1waFusURyQJGXx3DPgpbQd9UVXPIibhnn1ficBLc9kPA/640?wx_fmt=png)


如果想实现远程开机的操作，还需要把电脑绑定在插线板指定的电源插口，第一步需要做的就是点击APP中的绑定主机，来指定对应的端口；第二步则需要在电脑的BIOS中，配置电源管理中的选项，以华硕主板为例：进入高级（Advanced）——高级电源管理（APM），断电恢复后电源状态 设置为：电源开启。（不同品牌的电脑，设置方式也有所不同），以上两步设置完成之后，就可以实现远程开机的功能了。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXEX8whaud6GVTwVGichTJ3kp8NmEZ4CU8ACVFXwgI8oEHNbmtF3CrZibXumD2AppLIf8picCwtHWy00A/640?wx_fmt=jpeg)


以往，我若是在公司想查看家中电脑里的数据，都是先通知家里人把我的电脑开机，然后打开向日葵远程控制软件，才能够实现远程控制家中的电脑。而使用了这款向日葵智能插线板之后，就完美地解决了想要远程控制电脑，却不能远程开机的痛点。现在只需在手机中点击一下开机的按键，就可以自行把电脑开机，真的是非常方便。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXEX8whaud6GVTwVGichTJ3kpMTtlV5zdTPh4tdhV6DBHQM8aNW3DN8cYz0iagNp4V922S8mIphJjlag/640?wx_fmt=jpeg)


当然，若是没有远程开机的需求，仅作为一款智能插线板来使用的话，这款向日葵智能插线板表现得也很不错，通过倒计时和定时功能，可以对每个国标插口进行单独的配置。就以为电子产品充电为例，我们都知道，很多电子产品在充满电之后，若是继续长时间插电会出现过充的情况，从而引发危险。而通过定时断电的功能，就能够完美地解决过充的问题，这样的配置同样适用于给电动车充电。除此之外，使用倒计时和定时功能，也可以配合加湿器、风扇、夜灯等各种电器使用，这赋予了智能插线板更多的玩法。
