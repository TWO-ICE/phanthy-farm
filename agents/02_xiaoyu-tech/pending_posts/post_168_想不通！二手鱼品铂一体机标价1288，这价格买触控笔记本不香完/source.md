# 想不通！二手鱼品铂一体机标价1288，这价格买触控笔记本不香吗？

今天在二手鱼刷到了品铂X10 PRO一体机，看到1288的标价我直接愣住了。这价格直接上联想小新或者红米NoteBook不香吗？但仔细研究参数后，发现这东西确实有点意思。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGic4E9EBjibj7uYEl7YLicQiaHaV0rsnMVrIgZJJRxqVbaq2iaibO3KlZhSt9lF6FIn5Pgx3CAC62f7G1A/640?wx_fmt=png)


先说说这台机器的配置吧。它搭载的是Intel凌动X5-Z8350处理器，四核四线程，主频最高1.92GHz。这颗U放在2016年前后还算能打，主打低功耗、轻办公，但放到现在……只能说“能开机就是胜利”。集成显卡是Intel HD Graphics 400，玩个扫雷没问题，要是想开个PS或者剪个1080p视频，建议提前烧香。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGic4E9EBjibj7uYEl7YLicQiaHibeN0BC4laiavPqCauOJp1RMopTUjqxbiahN0fBrQwgUygjefIwjOTibZg/640?wx_fmt=png)


内存和存储方面，4GB RAM + 64GB eMMC固态硬盘，属于典型的“入门级配置”。好在它支持TF卡扩展，还能插SATA硬盘（需自行加装），算是给用户留了点折腾空间。系统是Win10 + 安卓5.1双系统切换，听起来很酷，实际用起来安卓版本太老，连微信都装不上最新版，基本只能当摆设。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGic4E9EBjibj7uYEl7YLicQiaH7dw5ZOIvV4hNZusEp8CrFMf3micvGInZ4TQy8gGEwYzNicU0TyYD2VEA/640?wx_fmt=png)


屏幕倒是有点亮点：10.8英寸IPS触摸屏，分辨率1920×1280，像素密度不错，色彩也还行。配合触控功能，拿来当电子相框、厨房菜谱机或者小孩看动画片的小平板，勉强说得过去。不过机身塑料感强，做工一般，拿在手里轻飘飘的，跟现在的千元安卓平板比质感差不少。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGic4E9EBjibj7uYEl7YLicQiaHqhExsU3dic5kxswXkMJ30BibhcToJu2Z7rkzicbC9ARIRfT26rjFpSVibQ/640?wx_fmt=png)


接口方面，1个USB 3.0、3个USB 2.0、1个HDMI、1个网口，还有耳机孔、Wi-Fi、蓝牙、外置天线和内置电池。说实话，接口数量在同类产品里算丰富，特别是那个网口，在如今很多轻薄本都砍掉有线网口的时代，反而显得有点“复古实用主义”。不过USB 2.0速度慢得像蜗牛爬，传个大文件能等到你泡完三杯茶。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGic4E9EBjibj7uYEl7YLicQiaH0qicBZTHgZeXqmJYs9XeVjicl9YjicOYFsBhI7bZEKXJ9RPxjAdyIZ83Q/640?wx_fmt=png)


可能有人会问：“这机子当年很火吗？”还真别说，pipo（品铂）在2015-2017年那会儿算是国产二合一设备里的“性价比代表”，靠着低价+Windows系统+触控屏，吸引了不少学生党和预算有限的用户。那时候淘宝上一堆“媲美Surface”的宣传语，虽然性能差远了，但胜在便宜能用。如今嘛……早被联想、华为、小米这些大厂挤到角落吃灰了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGic4E9EBjibj7uYEl7YLicQiaH6fS08zgMzxjXHXOQibiaruY9vYYerk2zHdibTXy3IfjJtW72WHch0ISrw/640?wx_fmt=png)


那么，有人又要问了：“1288买它值不值？”我的回答是：除非你有特殊需求——比如需要一台带Windows系统的便携触控屏设备，又不想花三千块买Surface Go，否则真没必要。同价位你能买到更新的Chromebook、二手MacBook Air，甚至全新入门级Windows笔记本。这台X10PRO除了“全新未使用”这个心理安慰，硬件早已过时，续航估计也不咋地（凌动平台+老电池），日常体验大概率卡顿。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGic4E9EBjibj7uYEl7YLicQiaHsRbAV6npE7z7YCRSU1Ynvs1OCVEnn6cOpESBHvdNwgkUryWibdtVUEg/640?wx_fmt=png)


当然，如果你纯粹想捡个“电子玩具”玩玩双系统，或者当个固定用途的触控终端（比如智能家居中控、车载导航备用机），那1288或许还能接受。但要说“捡漏”？我看更像是“接盘”。毕竟这配置放现在，连二手回收商都懒得收。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGic4E9EBjibj7uYEl7YLicQiaHOicNMYYFzdJH5Xz5jJ6zNhAlPzbaCqLE113ojfhcSiaiahDy2h47GKEEw/640?wx_fmt=png)


最后说句实在话：这类老款二合一设备，在二手鱼上挂高价的不少，但真正成交的寥寥无几。很多人挂个“全新仅拆封”，以为能卖个情怀价，殊不知市场早就变了。技术迭代太快，情怀撑不起性能短板。 

大家有没有在二手鱼上见过类似的“时代眼泪”？或者你曾经入手过pipo的机器？欢迎评论区聊聊你的经历——是真香还是踩雷？老规矩，看完不买，立省1288元。
