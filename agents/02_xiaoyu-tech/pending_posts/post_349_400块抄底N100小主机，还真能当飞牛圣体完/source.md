# 400块抄底N100小主机，还真能当飞牛圣体

![封面图](https://mmbiz.qpic.cn/sz_mmbiz_jpg/E9h3abOJCelibKBdYsyeZFSV0pibceh6VaOTU3OHALIm3QJic5Bfibxe4knKlZcicCzHryDGZSTsed5rHIt2m2el9RtSfK0Pw70alZNOW178MSec/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/iUsSYrZYHrXvlL-vdVVAuQ

有粉丝问我有没有便宜的N100飞牛圣体推荐一个？我刷二手鱼的时候，还真就瞄到了一个卖家在出N100小主机，准系统的要价400块。带个3D打印的外壳，线材、网卡天线都配好了，咱们来看看，这400块钱的N100小主机是不是智商税。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekGXFTpoUYsjP07qwLwKChh1LEaISST7gqLTFZVnmiaHG8XjmZ0oviayl55VT4ibI4ObocqO9N7TLukhTrdvWSLHhODtZR8iaPF7Bc/640?wx_fmt=png)


先看看这400块你买到的是个啥。首先是带有N100处理器的主板，卖家给的是准系统，意思就是没有内存、硬盘和电源。然后配置一个DDR4内存插槽，一个M.2硬盘位，外加一个SATA接口，3D打印的外壳虽然看着有点DIY的粗糙感，但胜在散热开孔自由，而且轻。接口方面，这种小主机一般就是USB、网口和视频输出，家用基本够。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelqiaekMRm0GgyDicDKWWH9BFjUOYYRmd3S4ia44Gibys3MLB4HWGAevtYpyrBibEOJlIR7lQOY1NB5iaZfLsXcQrsUS9jkoKfkpFSic0/640?wx_fmt=png)


现在二手鱼上，一台配置差不多的N100成品小主机，带8G内存和128G硬盘，怎么也得六百五往上。而准系统单独卖，普遍在450到550之间。这个卖家喊400，还包邮，说实话，已经比很多DIY玩家的成本价还低了。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemNBNsv5MeabybMhXGPPPLfJoMeNicnoO8kneVqaJyZoKTlNbG27n6ia9rycbu6zNsMZ89SmOI0haq1Pia8wevWkm3APnWlb78D9I/640?wx_fmt=png)


你想想，一块N100的板子自己从渠道拿货都要三百大几，加上3D打印外壳和配件，这基本就是回血或者清库存的节奏。不过也得留个心眼，这个价格为啥这么低？是卖家不懂行情，还是外壳有破损，或者是主板有什么暗病？买二手，尤其是这种价格偏离均值的，一定要多问一句。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenEZzeVHbXfyWMN5E6OKRNDPpia2EtvpibS8IndpAn03XUhuVQnySKrUvfHeUweyD53XHVt4pDGswwOJ3vjeNousokE9VMKY2UHw/640?wx_fmt=png)


N100最大的亮点不是性能，而是功耗。它的TDP只有6W，满载也就二十来瓦。所以把它扔在弱电箱里当软路由，或者接个硬盘刷成飞牛NAS，24小时开机，一年电费也就几十块钱。而且它支持Alder Lake-N的解码，看4K视频转码很轻松。卖家提到可以用M.2 SATA的硬盘，这个细节挺良心，因为很多便宜的M.2接口只支持NVMe，能兼容SATA协议就给了垃圾佬更多捡垃圾的空间，手头老笔记本拆下来的固态能直接续命。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekYxGqLjdrHcf2z76UxXobwrHQveoNzeiaqAle6LjYwzYFLowt7mtXXo9gHJuMibJRlUgwVnmYM4ibia20odySFETv3EAUhYUQUKmc/640?wx_fmt=png)


但这玩意有也硬伤，单内存插槽是最大的痛点，意味着你没法组双通道。虽然N100本身就只支持单通道，但只有一个插槽，以后想升级就得把旧的拔掉，没法叠加。还有3D打印的外壳，看着有个性，但耐用性和屏蔽性肯定比不上正规开模的金属或塑料壳，放弱电箱里积灰多了，不知道会不会影响散热。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekeQOCHj8RIubO78ibrAM7NExewHme7CM3kF5j13OChZyEibdJP4ictp620wLfM2NhddEAEobpJibKib8F4TkQ7G88KyDSF6ru1viaRM/640?wx_fmt=png)


给想下手的兄弟们一个建议，到手后先烤机，用甜甜圈和CPU-Z同时跑，看会不会蓝屏死机，特别是检查那个SATA接口和M.2接口是不是都能正常识别硬盘。如果只是当个电视盒子或者飞牛NAS，4G内存加一块淘汰下来的小固态就够用了。如果你打算跑虚拟机或者装Windows当轻度办公机，建议自己配一根16G的DDR4笔记本内存，成本也就二百出头。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCeluwCgYu31jZu48HHaLLb82hzEQMD8evrojNsIkGghfZsvT1v2ic33p494GTPJxY1oNVSXfV02bJ17WW9dicImVpezxle2FictPgg/640?wx_fmt=png)


这台400块的N100准系统，只要确认主板没问题，属于可以无脑入的级别。垃圾佬的本质就是用最低的成本解决最实际的需求。你觉得花400块组个低功耗下载机值不值？或者你手头有更划算的捡漏方案？欢迎在评论区分享你的看法，咱们一起在二手鱼里淘金。
