# 装好飞牛系统卖248元，这波工控机飞牛圣体到底冲不冲？

这两天翻二手鱼眼睛都看直了，发现有个卖家挂了批货，全部是装好了飞牛系统的工控机小主机，主机的品牌是“芯盘存力”，带原装电源和包装盒，售价248元。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekw3QOibB1vwRq1ebCS5A0lPWHOIdosAWXJoUeUDHqztMoibmwOxTTwpwjoPdYlUjq9wzCjxdH2YgLVF7u25ePv7fc64K3e01WSE/640?wx_fmt=png&from=appmsg)


这机器的配置卖家给列出来了，AMD A8-6410处理器，四核，8GB内存，自带一个32G的msata做系统盘，最关键的是有一个SATA口，可以自己加一块3.5寸大硬盘。主机的尺寸只有20厘米见方，比家里的路由器大不了多少。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekstTJ6UFRWKZzQzXWPSvSw4Gw8ph5qbkrp4z1D0uFA1b946Ip9d5lEnxFOlV5SYrU6NxjeIpJn8ibGpcywia9ibBK0YsfnDI92vw/640?wx_fmt=png&from=appmsg)


懂行的兄弟这时候可能要骂了：“这不就是十年前淘汰下来的老咕噜棒子吗？”确实，这A8-6410性能确实拉胯，跟现在的N100、N5105的机器没法比，更别说硬解4K了，但咱们得想清楚，买这玩意儿的目的是啥？


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCen4lic6vxw6GvkxibwokTueneHY58BPvwMs18GicyZQOSW85gBXT8v3z8nLfWua2bSkHIgbaRPWXPH3u9e6t3KLvYe5K7OUtkk0Lk/640?wx_fmt=png&from=appmsg)


这机器的价值，根本不在那个老掉牙的CPU上，而在于那248元里包含的情绪价值和零门槛。你想想，现在的国产飞牛正火，刚出了ARM版，热度高得不行。但大部分人卡在第一步装系统上，怕折腾，怕不会设置。卖家给你装得明明白白的，到手你只需要把自己存的“学习资料”或者家庭照片的硬盘插上，开机，完事儿。这不比买个几百块的品牌NAS回来还要看教程设置半天爽？


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCen8WticyLQDuQPAnnicAs6bUctaW1VYTslrr2OZ5nFggpAWichDel4lPZWDHN1SBIovciaJljYFVDQaDsxsRaRkcpNHA5M2bSA7pWk/640?wx_fmt=png&from=appmsg)


当然，丑话说在前头，这玩意儿有它的硬伤。第一，SATA口只有一个，组不了磁盘阵列，数据安全全靠运气。第二，那个32G的msata是装系统的，你要嫌小想换，得有点动手能力。第三，还是那个老生常谈的问题，性能摆在这，如果你是想跑Docker跑出花来的高阶玩家，这机器不适合你，它会把你急死。它的定位就是个“数字仓库管理员”，不是“全能运动员”。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemVta0sI3v82omSSo50f1fCibn5VHVsuQmdb3icdsHibpMsoGHrXc5ElRUiczWt8N7FIft02H9OLDZZ0qqL6gZVo4EdNqyI04rZJicw/640?wx_fmt=png&from=appmsg)


最后给想下手的兄弟们一点建议。如果你是那种手里有几块淘汰下来的2.5寸或3.5寸硬盘，想给家人整个自动备份照片的地方，或者就想下班回家能随时远程调个文档、看个不是那么高清的片子，这玩意儿就是你的菜。248元，现在连个像样的1T移动硬盘都买不到，但你却能拥有一个属于你自己的、永不泄密的私人云盘。还要啥自行车？


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenxndmib1Gosfa5LRnR3e9ZgcicJtddK6YHhkOYp3q3bFluvCkeia2kzAhPwOVdNSOvQzKoSQl2J5NFkRqr0WvIDtUw5mNjMUsEqQ/640?wx_fmt=png&from=appmsg)


如果你真下单了，回来告诉我，你准备往那个SATA口里，塞进你人生中的哪一段回忆？评论区见！
