# 被淘汰的“老咕噜棒子”如今被当成宝，199元的宏碁小主机买来能干点啥？

![封面图](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXH66Hsg0vicFyaicRhgIHst014rias5PibPVeQAJYjt8eOibLrangM5k5Pr4q8aSJxtcMVpArMN9uE4wbQ/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/SY3OwQWPqNqIE7bqFENmCw

你有没有想过，一台不到500块的小主机，居然能跑Windows、装NAS、还能4K输出？别急着笑，我今天就刷到了一台宏碁CXI3迷你主机，曾经是没人要的老咕噜棒子，没被丢沟里，反而如今又火了一把。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXH66Hsg0vicFyaicRhgIHst01q4TRRHq7UtmsdELibFENtIVd5oggTjuiapdbwxgTnJeRAjlfoYFvcE8g/640?wx_fmt=png)


最近硬盘价格疯涨，新机动辄两三千，而这边呢？宏碁原装CXI3整套配8G+128G，只要474元起！准系统甚至199元就能拿下。这不是价格大跳水，这是直接跳崖了好吗？  


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXH66Hsg0vicFyaicRhgIHst01WKUxu9UPYMFoS31ccZk8lc4StgS1icm6tonCru2bKHCWHrCUYr5GdYg/640?wx_fmt=png)


先说配置：3867U是英特尔第七代低功耗U，双核四线程，主频1.8GHz。性能嘛，轻度办公、刷B站、开几十个网页没问题，但想剪视频或打游戏？省省吧。不过它有个隐藏优势：HD 610核显支持4K 60Hz输出，HDMI + Type-C一线通，接电视当HTPC完全够用。  


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXH66Hsg0vicFyaicRhgIHst01TiaiaYiaX7ibDOfLiby2I8jKhLDVBVzPbLYKQ4D1TctCy5SjxuouNc591FA/640?wx_fmt=png)


更关键的是扩展性！双内存插槽、M.2 2242/2280通用接口、5个USB 3.0、千兆网口……这在同价位迷你主机里几乎找不到对手。卖家说“无修无暗病”，成色轻微磨损，但宏碁做工一向扎实，当年可是企业批量采购的主力机型，稳定性经得起时间考验。  


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXH66Hsg0vicFyaicRhgIHst01icIROMibtPibGicMwkibEaDQHukHVjZ5IrWrpdH1XSsbdxmAlibo9RefAB0A/640?wx_fmt=png)


不过，得提醒你几个坑：  

- 准系统没电源、没内存、没硬盘，C口供电需65W PD头（很多人家里没有）；  

- BIOS虽已定制，但毕竟是老平台，未来Win11支持有限；  

- 核显性能弱，多屏办公会卡顿。  


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXH66Hsg0vicFyaicRhgIHst01au48FjUPaFJbLqw7DfMTqoPhTJx5RX232Vs811WbAMuSPicRQbgDJQg/640?wx_fmt=png&from=appmsg)

但换个角度想：如果你只是要一台挂PT、跑飞牛NAS、或者给孩子上网课的备用机，它简直是“妥协了”之后的最佳选择。而这台主机的残值也几乎见底，再跌也跌不到哪去了。接个老显示器，放书房当下载机+家庭媒体中心，安静又省电。一个月电费不到5块钱，香不香？  


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXH66Hsg0vicFyaicRhgIHst011Q9FiaN5rJjSstaCI8fmJmreunXPj6RiaqkyjT32ohs82iafe39ibk9icHg/640?wx_fmt=png)


话说回来，你觉得这种老平台还有折腾价值吗？还是直接冲新的J系列小主机？评论区聊聊你的看法！顺便问一句：你手上有没有闲置的PD充电头？能65W输出的那种……（懂的来救我）
