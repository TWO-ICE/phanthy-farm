# 是捡漏吗？179元买华硕i5“无头骑士”笔记本，它还能干点啥？

闲鱼这类二手平台上，总有一类奇特的商品让人看了既觉得离谱，又忍不住想点进去看个究竟——比如这款标价179元的华硕i5“无头骑士”半截笔记本。

乍一看这玩意儿，简直就是电子垃圾的代名词。所谓的“无头骑士”，听着挺浪漫，其实就是老款笔记本电脑在经历过屏幕粉碎性骨折、外壳老化脆裂，或者是电池鼓包成“手雷”等一系列惨烈事故后，被卖家强行“去头去尾”留下的残躯。卖家把那些没法用或者卖不上价的部件（屏幕、电池、甚至部分外壳）统统拆掉，只保留最核心的主板、键盘和接口，就像个被剥了皮的怪物。

但从本质上讲，这东西虽然没了显示模块，成了一台物理意义上的“残机”，却并没有失去计算机的灵魂。只要给它接上一台HDMI显示器或者电视机，它就能瞬间复活，变身成一台结构紧凑的迷你主机。这种东西在二手鱼上其实挺常见，属于典型的“废品利用”流派。

咱们来仔细盘盘这台机器的核心家底。它搭载的是英特尔第五代酷睿i5-5200U处理器。很多数码圈的新同学可能对这颗U没什么概念，这是Broadwell架构的老将了，发布时间差不多得追溯到近十年前。虽然岁月不饶人，但这颗双核四线程的处理器主频能达到2.2GHz，睿频甚至能冲到2.7GHz。放在今天，应付一下Word文档编辑、Excel表格处理，或者仅仅是浏览一下网页新闻、B站播放1080P视频，其实还是能跑动的，属于那种“虽然廉颇老矣，但尚能饭”的级别。

**但是，这里有个巨大的痛点：4GB内存。**

在如今这个动辄16GB起步的软件环境下，4GB内存简直就是让这匹老马拉重型卡车。虽然你可以强行装上个轻量级的Linux发行版来压榨性能，但只要你稍微贪心一点，多开几个浏览器标签页，或者后台挂个微信，系统分分钟就会因为内存压力过大而开始疯狂读写虚拟内存，卡顿感让你想砸键盘。而且这机器还不自带硬盘，需要你自己动手买。卖家倒是挺“贴心”，提供了一个加45元配120GB固态硬盘的选项。**说实话，这个加价完全是智商税。** 现在市面上一个普通的120GB/128GB SATA接口固态硬盘，品牌货也就30块钱左右，杂牌甚至更低。与其被卖家收割这45元，不如自己去某宝买一块，既省钱又能体验一下DIY的乐趣。

再来看看这玩意儿的物理状态。这台机器为了“减负”，电池肯定是直接切除了，这就意味着它**必须24小时插着电源使用**，彻底失去了移动性。不过换个角度想，这也算是个优点——彻底杜绝了老旧锂电池老化、鼓包带来的起火爆炸隐患，放在家里跑个下载倒是挺安心。原装的电源适配器倒是配齐了，这点好评不多。

至于键盘，那就别指望有什么品相了。图上清晰可见多个按键的键帽已经随风而去，只剩下光秃秃的键帽柱子。虽然不影响电路通断，还能用，但打字手感绝对是一言难尽，建议你还是配个外接键盘。

接口方面，卖家虽然没细说，但作为当年的商务本，推测至少会有两个USB 3.0接口、一个HDMI视频输出口、一个RJ45网线接口和3.5mm音频口。这阵容基本覆盖了外接显示器、插U盘传数据和有线联网的需求。最让人惊喜的是，这机器还保留着光驱位！对于现在的超极本来说这是复古，但对于极客来说，这是扩展神器。你可以买一个光驱位硬盘架，在这里面加装第二块机械硬盘或者固态硬盘，瞬间组成双存储系统。如果你有想做本地媒体库或者搭建个轻量级NAS（网络附属存储）的想法，这个扩展位绝对算是个意外之喜。

那么，这台179元的残机，买回来到底能干点啥？

如果你是NAS小白，想拿它刷个飞牛OS（FNOS）之类的系统，理论上是可行的，毕竟这U的虚拟化技术支持还算凑合。但现实很骨感：4GB的内存会让多服务并行变得极其痛苦。试想一下，当你同时开启Samba文件共享服务，再拉起几个Docker容器跑跑服务，内存占用率很快就会见顶，系统响应速度会从“还能用”滑向“想摔鼠标”。

**不过，它也不是一无是处。** 如果你把目标定得低一点，单纯把它当做一个**PT下载机**（全天候挂机下载种子），或者配合Kodi、Plex搭建一个专门播放本地电影的**家庭影音中心**，那是完全够用的。把它放在客厅电视柜下面，接上电视，它既能替代那个收费昂贵且功能封闭的机顶盒，又能通过局域网把你下载的片子投到电视上。在这个场景下，它不需要跑太复杂的后台任务，只负责解码播放，i5-5200U集成的HD Graphics 5500核显虽然不强，但硬解1080P视频还是绰绰有余的。

这时候肯定会有“懂王”跳出来说：“这都2024年了，179元买个这破烂，不如多花一百多买个全新的J4125小主机！”

咱们来客观分析一下这个对比。目前市面上300元档位的新小主机，通常搭载的是赛扬J4125或者J4125这类处理器。虽然J4125属于英特尔所谓的“赛扬”低端系列，但它是2019年的产品，工艺更先进（14nm），支持硬件解码4K视频，而且通常出厂就标配8GB内存。相比之下，这台华硕i5-5200U唯一的优势在于单核性能稍微强那么一点点，毕竟是标准电压的酷睿i5。但在综合体验上，J4125的功耗更低（省电）、支持双4K输出（连两个显示器都很爽）、扩展性也更好。

最核心的区别在于**“保命”**。买179元的这台“无头骑士”，你买的是没有任何售后保障的二手残件，今天点亮明天死机是完全可能的概率事件；而买300元的新小主机，至少有一年的官方保修。这多出来的121元（179到300的差价），买的是个“踏实”。

再说说价格。179元，看着确实像是白捡的。但是，各位千万不要忽略了**隐性成本**。

首先，你必须得自己花30块钱买个固态硬盘；其次，你家里得有闲置的显示器、VGA线或HDMI线；如果嫌键盘难用，还得买个十几块的键盘。更关键的是**时间成本**——你需要自己动手装机、自己找系统镜像、自己折腾BIOS、自己调试驱动。对于那些不熟悉电脑硬件的小白来说，这些折腾的时间价值，早就超过了这台机器本身的价格。

现在的存储价格虽然像过山车一样波动，但说实话，直接买一台整机的性价比往往更高。如果你手头正好有一套闲置的外设（显示器键鼠全齐），又恰好是个喜欢折腾老旧硬件、享受Linux装机过程的极客，花179元买这玩意儿当个玩具，那是挺有意思的。但如果你只是想找一台稳定的电脑来办公、上网，那这笔钱不如老老实实存着，等电商大促的时候入手一台全新的入门级笔记本或小主机，至少不会让你在关键时刻掉链子。

如果你对这款华硕i5“无头骑士”有点心动，想看看还在不在，可以直接去“那个海鲜市场”搜索关键字：**“华硕无头骑士半截笔记本”**。如果搜不到同款，也可以尝试用图片搜索功能比对一下。要是怎么搜都搜不到，那很遗憾，说明这台特殊的残机已经被其他懂行的捡漏侠买走了，或者是卖家觉得卖亏了直接下架了。

最后，作为一名在数码圈摸爬滚打多年的编辑，给各位想入坑的朋友几点“掺了水”的实用建议：

1.  **认清定位**：这玩意儿只适合那种**爱折腾、懂一点技术、手里有闲置外设**的玩家。如果你不懂Linux，也不愿意重装系统，千万别碰。
2.  **降低预期**：别指望它能胜任多任务、视频剪辑或者大型游戏场景。它就是一个能跑的x86计算盒子，仅此而已。
3.  **稳重党慎入**：对于追求省心、稳定、不想售后扯皮的用户，直接看300元档位的新小主机，那一年的保修比什么都强。
4.  **省钱真谛**：看完文章如果不买，你就成功立省了179元，这笔钱去吃顿烧烤不香吗？
