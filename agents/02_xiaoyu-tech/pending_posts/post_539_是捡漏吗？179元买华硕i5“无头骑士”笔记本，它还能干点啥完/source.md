# 是捡漏吗？179元买华硕i5“无头骑士”笔记本，它还能干点啥？

![封面图](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXGyWQtBskNU2Qr0HZwn42MmKMYImdjW5nuib9psMGpib89X9bcESJEkTOSHAnicux70a1ho75UPNQQWA/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/YM70WqVaku5iLnOYmm2VTw

![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGyWQtBskNU2Qr0HZwn42Mmyy7CHLQ7rvIZQ0nibibfd5yibfQz5DsnBpeZSDRKe4cHERADMnaOJrRnA/640?wx_fmt=png)


华硕i5无头骑士半截笔记本售价179元。这种东西出现在二手鱼上，其实挺常见。很多老笔记本在屏幕摔坏、外壳老化或者电池鼓包后，整机卖不出去，卖家就把还能用的部分拆出来单独挂，主板、键盘、接口都完好，只是没屏幕，所以叫“无头骑士”。它本质上是一台去掉显示模块的残机，但只要接上显示器或电视，就能当台迷你主机用。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGyWQtBskNU2Qr0HZwn42Mmphqjl9ZmSfjwwwcu1w0MicDiaYayPMgmFv3D9z1pLy7K87pe5COIvqSA/640?wx_fmt=png)


这台机器搭载的是英特尔第五代酷睿i5-5200U处理器，虽然已经是近十年前的架构，但日常办公、网页浏览、1080p视频播放依然能应付，内存4GB这是个明显的短板，如今很多轻量Linux发行版虽能运行，但一旦开几个应用，内存压力就立刻显现。硬盘需自备，卖家提供加45元配120GB固态的选项，但这个加价略高——目前市面上同容量固态盘普遍在30元左右，自己加装更划算。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGyWQtBskNU2Qr0HZwn42MmpHShSaiceibbyCHI6Vx3I2YaEGd78kNoHx9G9eianInkia4rNZ195EcINA/640?wx_fmt=png)


机器本身没有电池，必须插电使用，好处是省去了电池老化带来的安全隐患。原装电源随附，键盘上有多个按键的键帽缺失，接口方面卖家没说，但推测包含至少两个USB 3.0、一个HDMI、一个网口和音频接口，基本能满足外接显示、存储和网络需求。光驱位还能加装第二块硬盘，对想做本地媒体库或轻量NAS的用户来说，算是个小惊喜。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGyWQtBskNU2Qr0HZwn42MmVpf3WtVvctibRib6ZnTBGdBhQZbb0HgT7dMvqU65B6xJG6a05EUbyiaGA/640?wx_fmt=png)


那么它现在能干点啥？刷飞牛系统是可以的，但体验有限。飞牛对硬件门槛不高，可4GB内存会让多服务并行变得吃力，比如同时跑Samba和Docker容器，系统容易卡顿。如果只是用来挂PT下载、播放本地电影、或者当个家庭打印服务器，那完全够用。放在客厅接电视，确实能替代普通机顶盒，还能装Kodi或Plex搭建私人影音中心。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGyWQtBskNU2Qr0HZwn42MmmKP5FhpoKINYdgtzdREhy96f3ozwm6OCVJWDq5cOu3gUehdo7yq25g/640?wx_fmt=png)


可能有人会问这配置比新出的J4125小主机还强吗？其实差不多。J4125虽然是低端U，但功耗更低、支持双4K输出，且新机通常配8GB内存。而这台i5-5200U胜在单核性能稍好，但整体平台老旧，扩展性差。关键在于，179元买的是二手残件，没有任何售后保障，而300元的新小主机至少有一年保修。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGyWQtBskNU2Qr0HZwn42MmfUibJOLso4dcg8epfsZWMz1cTKWH0JcoVjdFxlbgvcxM6ECFcicc3yYQ/640?wx_fmt=png)


价格方面，179元看似便宜，但加上固态、显示器、可能的系统调试时间，隐性成本不低。尤其现在存储价格虽有波动，但整机性价比反而更高。如果你手头正好有闲置显示器，又喜欢折腾老旧硬件，它或许值得试试。但若追求稳定、省心，这笔钱可能更适合存着等促销时入手新设备。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGyWQtBskNU2Qr0HZwn42Mm1KrbV9MAJ10Yw9GQCsHUoibToRzfW9Cw88x1n7MMw5M9dSE7pQmaohQ/640?wx_fmt=png)


对此产品有兴趣的话，可以在二手鱼搜索“华硕无头骑士半截笔记本”这个关键字就可以找到此产品，如果找不到可以通过图片进行搜索，都搜索不到的话，那可能是此产品已卖出或者是下架了。


 


以下是个人一些掺了水的建议：

1. 适合爱折腾的技术玩家。

2. 别指望它胜任多任务场景。

3. 新机300元档位更稳妥。

4. 看完不买，立省179元。
