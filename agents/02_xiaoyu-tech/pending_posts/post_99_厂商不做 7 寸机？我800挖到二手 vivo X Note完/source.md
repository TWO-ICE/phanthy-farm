# 厂商不做 7 寸机？我800挖到二手 vivo X Note 当主力，屏幕续航赢麻了

前阵子有个粉丝找我，说自己用惯了 7 寸巨屏，但现在厂商跟巨屏有仇似的，新机器压根不做这么大的，问我有没有能当主力机的 7 寸二手机。我当时脑子里过了一圈，哎，还真有台压箱底的推荐 ——目前卖800元的vivo X Note！就是 2022 年 4 月发布的那款，没记错的话，这机器绝对是巨屏党最后的倔强。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXF5I2KYqibKsicZ51RJtz385f1h5vv5lws2k9nJu3kCmsPzP2rMAX4ichNQycsn3TQLia78OgtDEibLHqQ/640?wx_fmt=png)


先说说这屏幕，真的能把人香迷糊！7 寸 AMOLED 微曲屏，分辨率直接干到 3080x1440，发光材料还是 LTPO E5，当年 Display Mate 直接给了个 A + 评定，不是吹的，我之前摸过朋友的，那显示效果细腻得很，色彩亮堂还不刺眼，比那些小屏机看着爽太多，巨屏党看了都得说句 “这才对味”。

![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXF5I2KYqibKsicZ51RJtz385fJQF1Vc15w0GtlicWaxdr27yDOWTlCYaBQoobDuCicbLtmo4OH6njjb1A/640?wx_fmt=png)


再聊配置，说起来有点又爱又恨。骁龙 8Gen1 处理器，还有自研的影像芯片 V1，按说性能够顶了吧？但这骁龙 8Gen1，谁用谁知道！当年外号 “小火龙”，夏天用的时候能煎鸡蛋，揣兜里跟揣了个暖手宝似的，烫得你怀疑人生。不过现在入冬了还好，温度降下来了，它那点热量反而刚好能暖手，我甚至都琢磨着，冬天是不是再写几个便宜的骁龙 888 手机推荐，毕竟夏天是真不敢推，怕粉丝骂我坑人。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXF5I2KYqibKsicZ51RJtz385fDCtAHysqOKgqtQWmvwdv2GNh1micH00w4uPfIlOOatLHw1bIqAicysZQ/640?wx_fmt=png)


重点来了！这屏幕比例是 21:10，你们知道这意味着啥不？实际显示面积比那些常规 21:9 的手机大一圈！就拿打开 Excel 表格说吧，纵向能多显示好几行数据，不用老上下滑，对我这种偶尔要处理表格的人来说，简直是救星。而且你们发现没，现在手机厂商净搞虚的，屏幕尺寸看着没降，实际面积却越做越小。比如新出的小米 17 Pro Max，说是 6.9 英寸，显示面积居然还不如 7 年前的小米 MA3（也是 6.9 英寸）！这逻辑跟当年笔记本似的，以前 4:3 或 3:2 的方屏多能装内容啊，后来全改成 16:9/16:10 的宽屏，同等尺寸下面积缩水一大截，真搞不懂厂商咋想的，净整这些花里胡哨的。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXF5I2KYqibKsicZ51RJtz385frgkr6KicvoNx5caJiaPUYEqrv7aFXgXDJjtW0qn5orldianjzQMJ1eoTg/640?wx_fmt=png)


拍照也没拉胯，蔡司全焦段四摄，5000 万像素 GN1 大底主摄，4800 万 IMX598 超广角，还有 1200 万人像镜头和 60 倍潜望式镜头。自研的 V1 芯片还能优化影像，尤其是夜景，我之前看别人拍的样片，暗部细节拉满，噪点还少，比同价位很多二手机强太多。平时拍个风景、人像啥的完全够用，甚至偶尔想拍个远景，60 倍变焦也能凑活，对我这种拍照不追求专业但求够用的人来说，太够了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXF5I2KYqibKsicZ51RJtz385fgMzTJwGytB0m0oL9DmaSMutxoEQzlQWeVADGpmqphcJyhAak3KiarmQ/640?wx_fmt=png)


外观方面，除了亮眼的橙色，还有黑、蓝、灰三种颜色，造型偏商务风，拿着还挺有质感，关键是支持 IP68 防水！这在二手机里可太少见了，偶尔溅点水、淋点雨都不用慌。但我搜二手的时候发现个大坑 —— 除了黑色是玻璃后盖，蓝、灰、橙这三个颜色全是素皮后盖，而且十台有八台两侧都掉皮！你们知道为啥不？这机器净重 216 克，宽度还超了 8 厘米（80.31mm），拿着本来就沉，再戴个壳更坠手，所以很多人都选择裸奔，用久了素皮就磨掉了，这绝对是裸奔久了的通病，想买素皮色的兄弟可得有心理准备。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXF5I2KYqibKsicZ51RJtz385fPHy2zyvcGZlPJXO5lBFiaEYwWeZxxepAnEvOdg5MoLiavvJonick5wbqg/640?wx_fmt=png)


续航是真的顶，机身够大够宽，塞了个 5000mAh 的双电芯电池，用原装 80W 快充，半小时就能充满，应急的时候插上电，刷会儿视频的功夫就满了，太方便了。还支持 50W 无线快充，有无线充电板的话更省事，不用老插线。NFC 和红外也都有，刷门禁、开空调啥的不用再带额外设备，出门揣个手机就行。但唯一的槽点是，居然取消了 3.5mm 耳机孔！我这种喜欢用有线耳机的人太难受了，每次听个歌都得插转接头，麻烦得要死，真搞不懂为啥现在都要取消耳机孔。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXF5I2KYqibKsicZ51RJtz385f1ql4fgT8ZNlYRvRaDfNVTlqTFp6qHniaoXIYOkxic1JkVy0BJCiaiapeicA/640?wx_fmt=png)


存储组合常见的是 12G+256G 和 12G+512G，我找了一圈，12G+512G 的最低原屏单机才 800 块，虽然屏幕有点老化透图，但总比换过屏的强吧？换屏机水太深，指不定哪天就出问题了。带原充的话最低要 800 多，性价比也还行。对了，教你们个辨原屏的小技巧 —— 只要这手机没有屏幕指纹，那绝对是换屏机！用这招能规避一大片坑，别傻乎乎买了换屏机还不知道，到时候哭都没地方哭。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXF5I2KYqibKsicZ51RJtz385fwicTAUzJhgYdibUOlDD7rYicWoyFKbKvrHGQwbgdgvrdgrjgqokjJS7MQ/640?wx_fmt=png)


总的来说vivo X Note 作为 7 寸二手机主力机，除了骁龙 8Gen1 夏天发热、素皮掉皮、没耳机孔这几个小毛病，其他方面真没啥可挑的。屏幕爽、续航强、拍照够用，价格还便宜，巨屏党要是想找个主力机，我觉得可以冲，前提是能接受那些小缺点，毕竟没有完美的机器，对吧？
