# NUC小主机被炒起来了？准系统卖239元，居然还有三千多人想要？

> 原文链接：https://mp.weixin.qq.com/s/BORnq6tLXosq7e3GbI-PWA

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekFyjCdXdOctEic6V6iaibk2Cs6pN8HM9a4zqIfHr4r0q7c8TQO2Th6zibOh7ibs7laiauLT6SCbO7OxestoImBKsribR6y7xqgQvudOE/640?wx_fmt=png&watermark=1&tp=webp)


在二手鱼里刷到一台英特尔NUC J4005迷你主机， 卖家报价 239元，这个价格是准系统而且 还没有电源。说真的，这个价格我觉得并不是很便宜，但点开一看，居然有14万浏览量，3 000多 人想要， 那么这台小主机到底 值不值得出手？


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelGBLm4wSdIsFiaicGuR1LjXibibpHGchicVCm6tTPKBeEez8ySibXxibq4Fgex2GnpI8KcGWUPgtBYnnKpPkPY5IDcQ0g0WFbo4qnMkw/640?wx_fmt=png&watermark=1&tp=webp)


这款主机搭载英特尔J4005处理器，主频2GHz，双核心双线程，功耗只有10W，堪称低功耗典范。核显是Intel UHD Graphics 600，支持4K 60Hz输出，还有千兆网口、AC9462双频无线蓝牙网卡，3.5音频输出支持光纤输出，两个HDMI视频接口，以及2.5寸SATA硬盘接口和DDR4L双内存接口。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemJPhVVKSIKibMsaCjGM8D25UL340cc3yokyjpWA8zevUEmAibfZWbKBWOlicKEgoxdXZ7Hh2RbPxQNOqx7vMfiafdcfd4nJHpp3Mc/640?wx_fmt=png&watermark=1&tp=webp)


客观说，它的亮点还是很突出的。最亮眼的就是低功耗，10W的TDP，常年7x24小时开机，一年电费 还不如一包烟钱 ，对于想做NAS的垃圾佬来说， 确实很友好 。而且接口特别齐全，双HDMI能同时接两台显示器，光纤输出在同价位迷你主机里并不常见，用来做达菲播放器，音质表现 也很 出色。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekhpggYGC9dbURA7gUsgJLTknXaAhL3aAsHsQEJHekY0T37j9icia48nR9gFWMc8MbTOa5x8GFqOnuWmDR7PFKAkGz4p7b2lHMicM/640?wx_fmt=png&watermark=1&tp=webp)


功耗低还有一个好处，就是非常适合刷成飞牛NAS ，飞牛NAS主打轻量化，兼容x86架构设备，这款NUC刚好适配，用来存储数据、远程访问都没问题，新手也能轻松上手。当年这款NUC也是入门迷你主机里的热门款，主打小巧低功耗，只是如今随着新机型迭代，慢慢沦为了垃圾佬的备选。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemcahzWPopUibrpFZE206icMbHN2XfmM0PKN7U23AswQJeAGYlrZEjIMD5Ru4icaliapjsLKNzIZYnbngL6un9V6r6Yv8FbDh9AjNQ/640?wx_fmt=png&watermark=1&tp=webp)


结合当前二手鱼行情，239元的准系统价格其实不算 捡漏 。同价位能买到惠普800G准系统，虽然配置相近，但价格更便宜，甚至还有余量搭配简单配件。而且卖家还有其他套餐，2+120G全套带电源429元，8+250G全套529元，整套安装好Windows10，到手就能用。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekRtqleCSH0Qbtsoica8Ad2xCe9IGebfHCfcSzgXbibZR9g3SkynljVgibgdLkTibufhvmv7A3fnBg8Lc8icgAJD9ia91vJWjF91KhlA/640?wx_fmt=png&watermark=1&tp=webp)


最后补个小槽点，J4005毕竟是Gemini Lake架构的老方案了，放在 今天看 确实是个老古董，不要奢望用它写代码渲染视频。但它胜在低功耗、全功能接口和扎实的品牌做工，装在电视柜下面做个安静的影音中转站，或者刷 成飞牛 ，比那些杂牌工控板稳定太多了


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCel7D2PFgSNbaV2TpbHibnCs6LSCRlI1W9mZE4U4Ej4zuc8ebfkP87dVia6Q1H6s7T8KUmX6WuiaAf0FKb571B0Qia7XynibbM08rUhQ/640?wx_fmt=png&watermark=1&tp=webp)


你会为这套239元的NUC入手吗？计划拿它刷飞牛还是当达菲数播？欢迎评论区聊一聊这台老将到底还值不值。
