# 作业帮智能辅导机—孩子的随身老师，比报补习班还管用

![封面图](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXESwAWOSMg8wqtHT8sAicxDb5RxeBpLx0e4Lh9uMHp1u7SmN18LIuQNFbFibpp0KiaicibmlYVgibnqQ7gA/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/hq7bcYGX7eXvsRFqIOcSPA

曾经的80、90后，如今早已成为了宝爸宝妈，
 
对于“再苦不能苦孩子，再穷不能穷教育”这句话的体会，一定也是越发的深刻，但有很多家长出于各种原因，在辅导孩子学习这方面，往往却是心有余而力不足。为了解决辅导孩子功课的问题，最近作业帮推出了一款智能辅导机，它专门面对小初高K12学生，不仅可以解决家长们没时间辅导、不会辅导的问题，也解决了孩子们在遇到难题的时候，无人可问、无人可教的情况。那么这款作业帮智能辅导机的实际体验如何呢？还是一起来看一下吧。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXESwAWOSMg8wqtHT8sAicxDbWDTg5ysUYIgoey9V3uWoeoucEVPhCaiczdh0d58NRepeuZBcly4rxGA/640?wx_fmt=jpeg)


作业帮智能辅导机的设计非常新奇，它和一般的学习平板完全不同，采用的是类似文具盒折叠翻盖式的设计，这个设计还拿到了国际iF
 
2023年的设计奖。“文具盒”打开后分为屏幕部分和底座部分，屏幕部分就像一款横放的手机，但尺寸要更大一些，达到了6.86英寸，采用的是AG护眼屏，有防眩光、低蓝光和缓解视疲劳的功能。底座部分除了可以起到稳稳的固定作用之外，最大的亮点是里面配备了一只扫描笔，通过扫描笔可以把试题同步扫描到屏幕中，辅导机就会自动给出试题的解析过程。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXESwAWOSMg8wqtHT8sAicxDbbkxyzn4JbgYf8aR3cTE19EohDJR9UYlB0AT6j2ujCtia98YsHdD2rNQ/640?wx_fmt=png)


在内容识别方面，不仅可以通过扫描笔进行输入，作业帮智能辅导机还支持拍照识别，如遇到大篇幅的试题，或整张的试卷，我们可以通过辅导机的后置摄像头把内容拍摄下来，从而更快捷的把内容输入到屏幕中。除了后置摄像头之外，辅导机还配备了一颗前置摄像头，可以用于视频通话，方便家长随时与孩子进行联系。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXESwAWOSMg8wqtHT8sAicxDb2ZP7Mb8ohc5Nfz8DIOaZ5pwIFapNocj6CqvDKp8dzTtUicOsLtquuAQ/640?wx_fmt=jpeg)


既然可以视频通话，那么辅导机会不会像手机一样，成为孩子的游戏机呢。这其实完全不用担心，作业帮智能辅导机专门对系统进行的定制开发，使用的是Linux操作系统，并且完全禁止安装第三方软件，除了一些基础功能的设置，没有任何有关学习之外的功能。而且家长通过APP，还可以对辅导机进行智能管理。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXESwAWOSMg8wqtHT8sAicxDbvcIIFjBCvQIGcXLTIxibLgt2MkVZQ3C9XoqoMzEzlg0NjlpykibdFvkw/640?wx_fmt=jpeg)


可能有的家长会担心，课本和习题册上那么多试题，辅导机都能识别吗？这一点其实完全不用担心，作业帮在此领域有着近10年的深耕，拥有6.6亿以上的超大海量题库，涵盖了小初高全学科的习题，原题的覆盖率超90%，只要是书本上的试题，辅导机都能够识别出来。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXESwAWOSMg8wqtHT8sAicxDbUKNsKEVI9ef64ttg8qIdONqvpibRiaz5vl4PeF2ERLttHVjM7wMthZFw/640?wx_fmt=jpeg)


当然，只能识别并不神奇，其中的关键则是对于试题的解析，作业帮智能辅导机对于解析试题并不是直接给出答案，而是通过思路启发+视频学知识点+举一反三练习的方式进行答疑辅导，让孩子通过一道题，关联出多个知识点，从而学会这一类题的解法。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXESwAWOSMg8wqtHT8sAicxDb3YibHlM8gGVDwDb3CdLcOwIyticjZpESv5HtyX8eIicqKMAIMYMic9MoPw/640?wx_fmt=jpeg)


针对平时知识的薄弱点，作业帮智能辅导机还能进行有针对性的练习，通过AI可以在线生成测评知识图谱，这种形式的知识图谱就像闯关游戏一样，能够培养孩子学习的积极性，从而加强对薄弱知识点的巩固。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXESwAWOSMg8wqtHT8sAicxDbCM0KuaI10OH4hoXuQ6dmSOeHO8MGyQ2grKFXVqQKXeiaRlmK6Ia6y8Q/640?wx_fmt=jpeg)


作为一款全学科的辅导机，作业帮智能辅导机还支持与教材同步学习，不仅可以帮助孩子预习或重温课本上的内容，最大的好处是支持原生朗读，拥有人教版正版版权原版发音，这对于学习语文和英语阅读方面有着巨大的好处。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXESwAWOSMg8wqtHT8sAicxDbdCQ8VOtyBJxtoiay1822EMU0ZUVPD1qPPvibJGUOrCsj7uaNv6rbLfLQ/640?wx_fmt=jpeg)


另外一点要提的是，作业帮智能辅导机还可以作为词典笔来使用，通过扫描笔进行扫一扫，可以解答小中高所有学科的习题，它还包含了词典笔所有的功能，涵盖了古诗、英语、口语、翻译等众多功能。而与普通词典笔不同的是，作业帮智能辅导机这种屏与笔联动的模式，无论是设计方面还是使用方面，都更为好用和便捷。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXESwAWOSMg8wqtHT8sAicxDbvcIIFjBCvQIGcXLTIxibLgt2MkVZQ3C9XoqoMzEzlg0NjlpykibdFvkw/640?wx_fmt=jpeg)


相信很多家长在辅导孩子学习的问题上，都非常的苦恼，不是没时间辅导，就是没能力辅导。作业帮智能辅导机的出现，就像是一位可以随身携带的老师，有了它的存在，不仅解决了辅导孩子功课的问题，也让家长有了更多宽裕的时间，更省去了报补习班的费用。这样一款一举多得的智能辅导机，不知道你是否对它感兴趣呢？
