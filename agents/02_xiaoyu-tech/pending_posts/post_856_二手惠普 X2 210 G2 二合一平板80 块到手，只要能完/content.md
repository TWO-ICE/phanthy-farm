# 二手惠普 X2 210 G2 二合一平板80 块到手，只要能用，这价格还计较啥亏不亏

作为一个整天在闲鱼上“扫垃圾”的老数码玩家，我的手指头早就对那些动辄几千块的旗舰机无感了，反倒是那些几百块、甚至几十块的“电子废品”，总能让我肾上腺素飙升。这地方简直就是现代人的寻宝图，只要你肯花时间蹲守，还真能在垃圾堆里刨出金子来。

前两天我正像往常一样，在筛选栏里把价格区间调到“100元以下”，准备看看有没有什么练手用的折腾物件。结果在一片屏幕碎裂的安卓板和不开机的老笔记本里，一台标价 **80 块** 的惠普 X2 210 G2 突然跳进了我的视野。

80 块？这年头连顿像样的火锅都吃不下来，居然能买一台能通电的二合一电脑？我当时的第一反应是遇到了骗子，要么就是屏幕碎了、主板炸了。点进卖家主页一看，描述写得挺实在：“银行退役机，外观成色战斗，有划痕，测试功能正常。”这行字里最有价值的就是“银行退役”四个字，懂行的都知道，这通常意味着机器虽然被操练过，但内部质量往往比消费级靠谱，毕竟是为批量采购设计的。这哪里是踩了狗屎运，简直是被狗屎运追着喂饭吃！

既然是捡漏，咱就得把它的成色和素质掰开了揉碎了看。这货给配了一块 **10.1 英寸的触控屏**，这个尺寸在二合一设备里属于“黄金手感”，不大不小，单手举着看书或者捧着刷剧刚好。要说遗憾也不是没有，分辨率只有 **1280×800**。

放在 2024 年，这个参数听起来像是上个世纪的古董，确实，你要是贴着脸看，那是妥妥的“大果粒”屏幕，像素点感十足。但咱们得讲辩证法，这玩意儿的使用场景通常是放在桌上当副屏，或者半米远的地方看个网课、看个小说，在这个距离下，它的显示效果完全在可接受范围内。再加上这块屏支持多点触控，配合 Windows 的 Modern 手势，80 块钱还要啥自行车？这素质，哪怕是用来看 720P 的老电影，清晰度也绰绰有余。

当然，光看脸不行，咱们得扒开皮看看骨头。这台机器能卖这么便宜，核心就在于它那颗 **Intel Atom X5 Z8350** 处理器。这是著名的“阿童木”系列，代号 Cherry Trail，那可是 2015-2016 年的产物。

这颗 U 的基础频率只有 1.44GHz，睿频最高能冲到 1.92GHz，听起来参数还行？别逗了，这货典型的“低功耗弱鸡”。它的 TDP 热设计功耗只有 2W，这是什么概念？这意味着它发热量极低，低到完全不需要风扇，全靠机身被动散热。好处非常明显：这台机器永远不会像游戏本那样起飞啸叫，安静得像没开机一样，你就算把它 24 小时挂机当个简易下载机或者 NAS，一年电费都不够买两杯奶茶。

但缺点也是硬伤——性能属实拉胯。这就是那只著名的“涡轮增压器都没装的老爷车”，你指望它跑分？它连打开任务管理器都得犹豫两秒。4GB 的内存加 64GB 的 eMMC 存储组合，在今天看来也是捉襟见肘。装完 Windows 10 系统并打上几个补丁，硬盘里直接就被吃掉了一半空间。你如果要问能不能用？能，但别想太多，这就是个能用，不是好用。

不过，这台机器能让我觉得“真香”，除了价格，还有一个意外的惊喜点：**接口**。这年头很多轻薄本为了轻薄，把接口全砍了，逼着你买转接头。但这台 2016 年的老古董，居然是个“接口大满贯”。

它居然给了你 **USB 2.0**、**USB 3.0**、**Type-C** 甚至还有一个 **HDMI**！这配置简直是“麻雀虽小，五脏俱全”的典范。有 USB 3.0 意味着你插个移动硬盘传文件不用等到天荒地老；有 HDMI 意味着你可以直接插投影仪或者酒店电视，不用再到处找投屏器。

更别提那个 **Type-C 接口还支持 PD 协议快充**。这一点至关重要，意味着你出差不用背着那个傻大黑粗的专用电源砖，带个手机用的氮化镓小充电头就能续命。说到原装电源，卖家配的那个 65W 适配器属实有点夸张，给这么个小身板充 65W，简直就是用高射炮打蚊子，平时放着吃灰就行。论扩展性，这个价位的安卓平板别说 HDMI 了，给你个 3.5mm 耳机孔都得谢主隆恩，所以在这一点上，Windows 阵营的老机器确实厚道。

接下来肯定有人要问灵魂三连：“这玩意儿能装 Windows 10 吗？卡不卡？能干啥？”

回答非常肯定：**必须能！** 这机器原厂出厂就是 Win10 的户籍。至于卡不卡，这得看你怎么定义“流畅”。你指望它剪 4K 视频、玩《黑神话：悟空》？那它能把 CPU 给烧干。但如果你只是老老实实打开浏览器，不开那几十个标签页（现在的浏览器可是吃内存大户），老老实实开一两个网页看看新闻，配合那块 SSD 虽然慢但不掉链子的 eMMC，启动个 WPS 写个文档、改个表格，反应速度绝对是“可接受”级别的。

具体应用场景我都帮你们想好了：给孩子当个**网课专用机**，它有键盘、有触控，比纯粹的大屏幕手机护眼，比笨重的笔记本灵活；或者给家里长辈当个**炒股看盘机**，通达信、同花顺这种软件跑起来毫无压力；甚至就是放在床头当个**影音播放器**，接个移动硬盘躺着看美剧。甚至对于一些极客玩家，把它刷成 Linux 当个服务器终端也是极好的。哪怕就是当成一个能跑 exe 程序的移动备机，这性价比也是无敌的。

最后总结一下这笔交易的账面价值。80 块钱捡漏这台发布于 2016 年的“电子老兵”，我真心觉得这一波血赚不亏。虽然它的铝合金背板可能已经被磨得油光锃亮，充满了岁月的包浆感，虽然它的性能在今天的也就是个计算器水平，但架不住价格实在太香了。80 块钱，在这个连数据线都卖几十块的年代，买一台能跑 Windows、能打字、能上网、有键盘的全功能电脑，这感觉跟白送也没什么区别。

这种老设备玩的就是一个心态，只要它能亮，只要键盘能敲，只要还能连上 WiFi，它就是创造了剩余价值。你们平时在二手鱼上都淘到过什么神仙好物？有没有遇到过比这更离谱的价格捡到过更狠的数码宝贝？或者对这台古董级惠普平板还有什么想问的参数细节，欢迎直接在评论区甩过来，咱们一起交流交流怎么在垃圾堆里淘金，避坑排雷！
