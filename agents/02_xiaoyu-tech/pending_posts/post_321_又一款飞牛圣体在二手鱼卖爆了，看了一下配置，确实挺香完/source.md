# 又一款飞牛圣体在二手鱼卖爆了，看了一下配置，确实挺香

今天在二手鱼刷到了一台标价168元的N2810处理器小主机，点进去一看，好家伙，将近1000人想要，6万浏览——这哪是捡漏，这是抢限量款吧？不过价格挺白菜，配置也还行，让我忍不住多看了几眼。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHN4RLgUG7ytvu5iakqAMZC3pXLoqGeGw9pYkcfu3HbxU36LVZWxia7nL27MQkibBOKMAYiadtu0IM3Nw/640?wx_fmt=png)


这台小主机用的是Intel N2810处理器，四核四线程，主频2.1GHz。虽然放现在连入门级都算不上，但功耗超级低，正常运行只有4-8瓦，比一盏节能灯还省电。尺寸更是离谱，巴掌大一块，放在桌上几乎不占地方。拿来当NAS简直天造地设——安静、省电、体积小，插上电就能跑，完全符合“买得起、养得起、用得久”的三好标准。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHN4RLgUG7ytvu5iakqAMZC3iazsUvBCVlPgxXceIfXJKIYy5NWNhlsq3GJoD7I7H0famlPLEKZBS4A/640?wx_fmt=png)


内存方面，标配4GB DDR3L，官方说可扩展到8GB。硬盘是120GB SATA固态，系统已经装好了飞牛OS，开箱即用。更关键的是，它还预留了一个2.5英寸SATA接口，卖家连专用电源线和数据线都送了，想加块机械盘或大容量SSD完全没问题。对想搭家庭NAS的人来说，这种“到手即插即用+可扩展”的组合，性价比真的可接受。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHN4RLgUG7ytvu5iakqAMZC3WEFeeVpuJ63nFZjic5EZEydoDsAic3v9U9BapP7bkgo42QLx56VhHjOA/640?wx_fmt=png)


 


接口配置也挺全：VGA + HDMI双显示输出，1个USB 3.0 + 4个USB 2.0，千兆网口、Wi-Fi、音频口一个不少。虽然USB 3.0只有一个略显抠门，但考虑到整机才168块，这个价格还要啥自行车？而且千兆网卡对NAS来说至关重要，比那些百兆网口的老古董强太多。Wi-Fi虽然速度不如网线稳，但应急或者临时调试也够用了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHN4RLgUG7ytvu5iakqAMZC3nibLKdAwpJWCbV1Gibc7gLTX4ToibuBM21vRXHU5Fw6K014ESeicqH4uGQ/640?wx_fmt=png)


成色方面，卖家强调是“最新下架”“功能完好”“成色很好”，还配了实拍图。最吸引人的是——已预装飞牛OS系统！这意味着你不用折腾安装，插上网线、接上电源，同一局域网下输入IP就能进管理界面。默认账号root，密码root123，连登录门槛都给你压到最低。对于NAS新手来说，简直是“傻瓜式入门”。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHN4RLgUG7ytvu5iakqAMZC37qDcOegxibbY5N7apbvXPIAiaBGGajqFFYic4WWUWHbKlg9D0rPUfXUZA/640?wx_fmt=png)


那么，缺点有没有？当然有。N2810性能确实弱，硬解4K视频基本别想，多用户并发访问也会卡。而且DDR3L内存现在不好升级，8GB上限也限制了虚拟机或多服务部署。另外，单台不包邮，偏远地区运费可能吃掉“白菜价”的优势。不过，如果你只是用来存照片、电影、做自动备份，那完全够用。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHN4RLgUG7ytvu5iakqAMZC35RaqTxVh1ZSiaQ9oOeHdu8zJCX2TibPhE6yX06SPSIS8wzSUonxvn1dA/640?wx_fmt=png)


对比二手鱼上同类产品，很多老款Atom小主机要么没Wi-Fi，要么只有百兆网口，要么内存焊死不能加。而这台不仅接口齐全、支持扩展，还带系统、数量充足（卖家说有110台），属于“批量清仓价”。同配置的其他卖家普遍要价220-280元，168元确实算地板价了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHN4RLgUG7ytvu5iakqAMZC31ickicpUBoGanD7ba4Nh3ibbdPzVHt6f4a3MGuDJRg38E1P9yg4ZyYqkA/640?wx_fmt=png)


如果你正琢磨着搞个家庭数据中心，又不想花大几千买群晖，这种百元级小主机就是最佳试水选择。性能虽弱，但胜在便宜、完整、即插即用。哪怕玩腻了，168块也不心疼，大不了当个下载宝或者打印机服务器。


 


最后总结了几点给大家做个参考：

1. 预算200内想搭NAS？闭眼入。

2. 别指望高性能，但省电静音真香。

3. 想扩展存储？接口留好了，放心加。

4. 新手建议直接用飞牛OS，省心省力。

5. 看完不买，立省168元。
