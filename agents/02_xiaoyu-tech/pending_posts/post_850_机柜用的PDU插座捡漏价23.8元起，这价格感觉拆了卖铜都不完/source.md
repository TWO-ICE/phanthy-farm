# 机柜用的PDU插座捡漏价23.8元起，这价格感觉拆了卖铜都不亏

![封面图](https://mmbiz.qpic.cn/mmbiz_jpg/E9h3abOJCel8j0eJkLwGEv3icmRNWtlY3QWrZEBtBibbib6PzhBictaIHb5VZryaqoX8rLiayoKT7NoPmfNDZlSCfocNeT6cnDy4bj45H5mOI0SE/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/FwxUiflvWkdzwIB2w8x11A

最近我刷到一批好东西，有个老哥在清仓一批机房里淘汰下来的PDU机柜插座，价格我看挺实惠。8位40孔的无线款，23.8元还给你包邮！带1.8米线的28.8，带3米线的也才32.8。这价格，比市面上的插排便宜了将近一半，而且品质还更高。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenACU4jQWSwvkHyh30yD4Wcbxy7LaZM4iaHibIxDuThvPbwqcSqeCcK8tt2Pwh6S8tOL13j9Ea6ODdMWsqECZBYGllDkp5Qutsibo/640?wx_fmt=png)


卖家说纯铜插座，10A电流，2500W功率，还有正儿八经的3C认证编号。这玩意儿跟咱们平时买的塑料排插比，完全不是一个档次，它内部用的是一体化的铜条，而不是那种用焊锡连接的小细导线。这玩意儿的优势就是接触电阻小，发热低，用个十年八年都不带出毛病的。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelh085htXIt6hCFtWa2XTuZgcfgDVjFSK7NJQibZBxEqdx3D2rJmr4AIgVHe9ar4LichqdjehmKqia5COnebawfTdsvhUkL49vVao/640?wx_fmt=png)


当然，这东西也有它的缺点。首先，它长得就是个长条铁疙瘩，外形比较工业风，没那么精致，放家里桌面上可能有点突兀，更适合藏在电脑桌后面、电视柜下面，或者直接上机架。还有一点卖家没有说，产品有没有防浪涌的功能，这一点需要和卖家进行确认，但话说回来，就算没有的话，对于这个价格根本不算缺点。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelCyjcmib6rLrpt7FmAiaaNJ5BTEicN3MicWhwf9iapZWpqia7BE4enhSwibrDiazh7qNbLib0d4XbI8P3MjjP7ILfS9TMMRpRKIaOPf0Kg/640?wx_fmt=png)


家里电脑主机、显示器、路由器、NAS一大堆，正愁没有一个靠谱的动力中枢，那这个8位插孔的大间距插座简直是为咱们量身定做的。28.8元买个1.8米长、带8个插孔、能扛2500W的纯铜排插，你想想现在的人工和铜价，这卖家基本就是在开启甩货模式，清仓回血了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCek6X6lSER0TQx4HlredwLWXnaKC2rrNHdzB1jzIic9BiaRbIHY6hWb0pyevRiabCVBnXbztG54c1Aulsu4ibSqLF3BMNLFaGr8PUAE/640?wx_fmt=png)


而且相比于市面上的某牛插排，这个PDU的价格至少便宜一半还多，如果你有这个需求，比如刚租了房子，或者想给工作室升级一下供电，花20多块钱搞定8空位的大插排，怎么看都不算亏吧。但如果你是完美主义者，要求包装精美、带独立开关、LED指示灯还能手机控制，那这东西可能不太适合你，它就是个朴实无华的工业品。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemiccexk6dtCNo0ibMjROJfttBZ77Y769trkY2eVSNRn3Rhdic6hxiak6xpLU9tntMVjHtLYDyLh8aqHoHhrKb2AKeJabicxCUIC43o/640?wx_fmt=png)


最后我想问问在座的各位老铁，你会为了这“一包烟钱”的价格，去尝试这种机房淘汰下来的“工业老将”吗？或者说，你现在用的插座，花了多少冤枉钱？咱们评论区见！
