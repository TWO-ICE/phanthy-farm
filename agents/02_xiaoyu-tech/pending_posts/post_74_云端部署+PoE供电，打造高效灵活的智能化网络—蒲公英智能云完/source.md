# 云端部署+PoE供电，打造高效灵活的智能化网络—蒲公英智能云AP

![封面图](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXEo8YYxHUw43zKuVkIzjFGpEcymn4ImkyG4AeVPrsO7sdibcXXoY7npD7hxoN5FFkBia3iauLAjDNibrw/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/lcbwz7wIsjP4KYo329FIrA

我们现今的移动设备和物联网设备，对于灵活便捷的无线网络有着很大的需求，AP作为一种成熟、易用性强、高拓展性的低成本网络连接解决方案，通过其安装便捷、覆盖灵活等特点，能够轻松实现多种设备的连接，满足不同场所的无线网络需求。无论是在企业、酒店、商场还是多层别墅等地方，AP都能够提供可靠且高速的无线网络连接。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXEo8YYxHUw43zKuVkIzjFGpy2Fia8JLEhSaybbbmxoXXkb1Gx8aXPF6tYrzFVibMYncUG3M6fvUGEVg/640?wx_fmt=jpeg)


随着AP产品的不断迭代和升级，贝锐蒲公英推出了一款智能云AP，相比于传统的无线AP，蒲公英智能云AP可以实现远程云部署、云监控、云管理等功能，能够对网络和用户进行智能化的管理，在网络覆盖和信号传送方面，具备更高的性能、更稳定的传输和更安全的网络连接，那么这款AP的实际表现如何，还是一起来看一下吧。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXEo8YYxHUw43zKuVkIzjFGpWnpQg5Tnq7FYJWS0Pv0byucLicUQ1kcQvaBXU8lXxPy2m4G2v5J42LA/640?wx_fmt=jpeg)


蒲公英智能云AP包装设计的非常低调，正面除了LOGO标识之外，几乎没有任何多余的元素，值得注意的是包装盒前方标有“蒲公英企业级智能无线AP”的字样,可以看出这款AP是属于企业级的设备，所以它在性能方面，要比普通家用的设备更为可靠。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXEo8YYxHUw43zKuVkIzjFGpOVWO4YsL1rjm1uVq86jJ2ksMKiaWXib5q2pwO396J5ianDaAB1AErhRag/640?wx_fmt=jpeg)


包装内的配件非常简单，除了蒲公英智能云AP之外，只有一份使用说明、一条网线和一包螺丝。有细心的伙伴可能已经发现，包装内并没有配备电源，这其实是因为蒲公英智能云AP支持PoE供电，如果你有POE路由器，只需要一根网线就可以为蒲公英智能云AP供电，省去了单独供电的麻烦。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXEo8YYxHUw43zKuVkIzjFGpeib62pr4tR83ER8JnqLPOibCIDR4M6CzFEpX9gnwvJibSIMnEF274du0A/640?wx_fmt=jpeg)


当然，蒲公英智能云AP在供电方面是做了两手准备的，除了支持PoE供电之外，在设备的侧边还预留了12V/1.5A的DC电源接口，如果你不满足PoE供电的条件，可以自行搭配电源来使用。除了电源接口之外，侧边还配备了两个千兆网口，其中一个WAN口、一个LAN口，另外还有一个复位按键。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXEo8YYxHUw43zKuVkIzjFGp3wlOS6P6nsicwM7CTzaxYSnLo7vBt8V60eUPicZwqE7cGJiaBJAiaXFvmQ/640?wx_fmt=jpeg)


市面上的AP设备在设计方面，普遍分为面板AP和吸顶AP，考虑到安装的便捷性和更广阔的信号覆盖，蒲公英智能云AP选用了吸顶式的设计。在外观方面蒲公英智能云AP同样走的是简约低调的风格，纯白的配色搭配内方外圆的造型，看上去中规中矩毫不突兀。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXEo8YYxHUw43zKuVkIzjFGpW7NHicpzEeqKeNk0L3FNzTjdiaQibAogHvjYLDUCRtZ2vyMtiay7SMW3Lg/640?wx_fmt=jpeg)


由于是吸顶的安装方式，蒲公英智能云AP的底部配有可拆卸的专用支架，安装和拆卸的时候非常简单，只需要轻轻扭动AP主机就可以固定或是取下，它的整体的尺寸为190*190*40mm，体积并不算很大，安装在棚顶既不突兀也不影响美观。当然，它的安装方式也并不只限于棚顶，如果你不具备吸顶式安装的条件，把它安装在墙壁上或者平放在桌面上也是完全可以的。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEo8YYxHUw43zKuVkIzjFGptKAKLROkwnsTDMOttQHNtTyg39qSt6hlXeHESjmkKpvGI02BrDdHpQ/640?wx_fmt=png)


在配置方面，蒲公英智能云AP与传统的AP稍有不同，但也并不复杂，而且说明书中也给了详细的配置方法，只要把网线接入AP的WAN口，面板指示灯为蓝色之后，登陆https://www.pgybox.com，输入设备的SN码和默认登陆密码就可以进入云管理的界面，然后根据提示把设备和账号进行绑定就可以。绑定成功后可以看到配置界面的功能非常丰富，操作简单明了，和普通路由器的配置相差无几。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEo8YYxHUw43zKuVkIzjFGp29CPAScPzLDC2mWfmun6NIMSulIqWiaRricKc1L2K0qoaA4ravfwMvyA/640?wx_fmt=png)


作为一款企业级的智能云AP，相比传统的AP设备，蒲公英智能云AP在功能方面要更胜一筹，首先它支持企业认证功能，通过企业认证授权，员工可以免密一键联网，并且可以对网络进行实时监控，发现可疑终端可以一键下线拉黑，有效杜绝陌生用户蹭网的问题。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEo8YYxHUw43zKuVkIzjFGpzElof2I7SWO5D5yokJ10LT42icvy6L54UjzSA0zicekll7J1pwl6P4YA/640?wx_fmt=png)


在智能化方面，蒲公英智能云AP可进行云平台集中管理，如果在网络中配备了多台蒲公英智能云AP，通过云平台集中管理可以对AP设备进行批量控制，同时也支持在云端进行部署，一键就可以完成多台设备的部署，操作也十分简单、易懂。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEo8YYxHUw43zKuVkIzjFGpHgFibz6mfCd767PZRbkmff8HlLgWATg6ibafSrLQ3e8ibBjZAqJCkia9yQ/640?wx_fmt=png)


蒲公英智能云AP支持2.4G/5G双频并发和WiFi6网络，无线速率最高可以达到1800Mbps，无线协议支持IEEE
 802.11 
a/b/g/n/ac/ax，每台AP设备理论可接入128个终端，如果所处的环境范围较广，可以选择安装多个AP来实现全信号网络覆盖。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXEo8YYxHUw43zKuVkIzjFGpRAA8Y3hibRqWKQ7WA2tVuAG1BtPuqicHHcibM232GAMPsFMn4YWF42elQ/640?wx_fmt=jpeg)


在安装调试好之后，我通过手机对蒲公英智能云AP进行了测试，首先是信号覆盖方面，我们公司是上下两层楼，大概500平方米左右，之前配备了两台传统AP，在角落和卫生间等区域的信号非常不稳定。在更换了蒲公英智能云AP后，信号强度明显增加了很多，以前的网络死角区域，信号居然变得稳定了，而在AP附近的区域，信号强度更是小于-37dbm，并且传输非常稳定。在网络速率方面，公司是1000兆的对等带宽，在上班期间测得下载的速度在800
 Mbps以上，上传速度在600 Mbps以上，这个速度还是相当不错的，而在下班没人的时候，上传和下载的速度几乎能够跑满。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXEo8YYxHUw43zKuVkIzjFGpTv8PBDry5IIASp1fRHpJuCc7ib49HRGibx779pe20f1cjTVxAy6ntYkA/640?wx_fmt=jpeg)


经过一段时间的体验，感觉这款蒲公英智能云AP还是非常不错的，相比于传统的无线AP，蒲公英智能云AP不仅性能高运行稳定，还具备智能化管理功能，在信号覆盖和传输速率方面也有着很大的优势，而且可以灵活的扩展和进行云端部署，在方便用户联网的同时，也更加便于管理员后台管理，这样一款集多种智能化功能于一身的无线AP，你感觉它怎么样呢？
