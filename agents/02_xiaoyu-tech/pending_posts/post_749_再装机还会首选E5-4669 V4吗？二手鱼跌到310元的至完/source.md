# 再装机还会首选E5-4669 V4吗？二手鱼跌到310元的至强CPU还值得出手吗？

![封面图](https://mmbiz.qpic.cn/mmbiz_jpg/E9h3abOJCeldkaEibNHjUNn0PfmwiaJEjx2MHzXnsmrDMAfde4Z5ONYsZ6fmEdqYAxn1WQ2eDe3q7U05zeoJAj3uDt38X6KosAzzsmkV39RhI/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/Bn1gI5TmDblisMlv8uVgzQ

你是不是也好奇，如今花310元能买到什么性能的CPU？一杯奶茶钱，或许就能摸到当年服务器级别的硬件，这听起来有点梦幻吧。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemkjcbVRkLVX1Py8Z3uaH0LIHT5ibMYXcq5KZZvGXCeuZPSJTfoCJu1WG9ReoibtpDwprtDcLAtibrmmnQwRS4LCF2FJovotcksCg/640?wx_fmt=png)


今天在二手鱼瞎逛，就看到有人挂出英特尔至强E5 4669 V4，标价310元还包邮。第一反应是，这玩意现在这么便宜了？要知道，它曾经是很多人装机的首选，如今却沦落到边角料价格，真是时代变了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenmKMh2URjuOfYGtw8JCHHRS4l418FU7loTn1cOicqMwpKo6NytT36yRpkibJYTdt9kC3iaqgoQWrYgK10f5Al7tJprPDgfuwgmjU/640?wx_fmt=png)


先快速过一下核心参数。E5 4669 V4，22核44线程，基础频率2.2GHz，LGA2011接口，支持DDR4内存。没有核显，需要独显点亮。卖家说功能正常，成色新，自用拆下。听起来挺诱人，但别急着上头。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCendPp2tQ4EKseQbOoKH0DkwIdzYx6Pj8mrflWgwlDxqO8VpLwQKoEiac0eBa0tCfoHbCb1CiaUuFSmMdIFE4ydC0uB0k3ibRvoF9w/640?wx_fmt=png)


它的优势很明显。多核性能放到今天依然能打，如果你搞多开虚拟机、挂机服务、或者搭建小型工作站，这22个物理核心就是廉价生产力。尤其是对比当下某些新品CPU涨价趋势，这种价格确实给了预算抠搜的玩家一条活路。想想看，310元，约等于一包烟钱，就能体验服务器级别的核心数量，难怪垃圾佬们会心动。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekwsJ8AxxDqolyGd5ibqB61ax57FOjja4WAcUR9OtyaruyToXBYPhVSLfjWxz6uF7GYXbH9YTUPpMLFMibgBKNV1DUNkKQJbWsgg/640?wx_fmt=png)


但劣势也同样突出。单核频率低，日常打游戏、办公轻应用可能不如同价位二手酷睿i5流畅。功耗不低，散热得配好点。主板兼容性是个大坑，LGA2011接口的主板现在不好找，新品基本绝迹，只能淘二手服务器板或X99这类主板，而且得仔细查兼容列表，不然点不亮就变废铁。卖家那句“主板兼容性请自查”，其实是甩锅提醒，小白容易踩雷。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekWzv9ibvg1ibGVRHiacJWYlCCBnjdVeZPib6qu0ibbkgSXfDehNDDNNQPumZMkic698KrU9Z0DW2EWZQpXyOjlicN7QrlSSRV2xE4lP8/640?wx_fmt=png)


最后给点实在建议。卖家描述里写着“售出不退不换”，这意味风险自担。所以，下单前一定问清楚测试情况，最好能看实物视频。别光看“性能强劲”就冲动，先想好自己有没有配套主板、内存和散热。不然买回来也是吃灰。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCek0L3CNm7LjgJToxWicDe2zIZujUj8ibYNURzj8FSkScHiapVfO6khx3BLlicEiaibA8OcUHQJwdrBXg0CeaicmIzG5MzR6cgVIRWcDfg/640?wx_fmt=png)


话说回来，这种产品就像榴莲，爱的人当宝，嫌的人当草。有人觉得花小钱办大事，有人觉得折腾半天不如加钱上新平台。你呢，会为了22核妥协平台兼容性吗？评论区聊聊吧，你有没有淘过类似的服务器CPU？是翻车了还是真香？分享你的经验，帮其他老铁避坑！
