# 是捡漏还是交学费？这台189元的优派的3865U小主机会翻车吗？

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCeneWvDlMia9bf3RKeUL8N1jpBplI4WSLbBJuZN8IYR2wAib14HjaSFgomjotH6b7GP4qruVqE3ibOsTjpBLnodkuia8LF7JQ2WnZPo/640?wx_fmt=png)


最近大船又靠岸了，二手鱼里突然冒出一批优派的3865U小主机，准系统直接挂189元起。说实话，看到这个价格，我的第一反应是，这特么不就是又来割韭菜来了吗？这玩意有啥好的，189都够我整一套便宜又好用的J1900了，不比这玩意香吗？


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelJn3WDacpXWLJBNIUVWediaom9ibh2HvyCCRpAQeEr3GIiaNhuXg49cx2EhBvckPQ7HR3ICNsWiaCKDEnROt5G5znWYU5pHhj8RibY/640?wx_fmt=png)


这个优派NMP660，用的还是英特尔那颗经典的3865U处理器，比J1900强点，但不多，双核四线程，放到现在看，性能确实跟“猛”字不沾边，主打一个功耗低。HD610核显，最大的亮点是支持4K输出，内置WiFi蓝牙，千兆网口，USB3.0也都有，最关键的是有个全功能Type-C，既能给主机供电，也能一线通传视频信号，这算是一个加分项吧。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekv6x23hJc3bTh3VDk7QHTJMbNNjr5rc0mnib8VxCZiaibClWI6nJuaHz93NFbpqoEY1PFOAsB4PibiaHgrChmOfDsgHWvOpaKC2JyY/640?wx_fmt=png)


说实在的，机器确实还可以，只是价格比较坑，它的最大用处我感觉就是刷飞牛NAS。这是目前的热门玩法，这机器是双DDR4内存插槽，还有个M2接口，装个飞牛OS，搞个简单的家庭存储中心还是绰绰有余的，功耗还极低，7x24小时开着也不心疼电费。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCen66nCkiacbOZgbOjAQFPeYmAt4Oj7ZeOUEnvMNAaWotWeaUVHtZMr974yLrAanv5bscnH0NSlvRS43tmXY1nh9jLjFph3PDqg4/640?wx_fmt=png)


另外这个机器卖家说默认装精简版Win10，所以用来简单办公，或者给孩子上网课、老人看看新闻炒股，也可以干脆接电视上当个超级电视盒子，看4K视频，比那些电视盒子强多了，它毕竟是个电脑，不过价格要是能压倒150以下，我感觉还是可以接受的，否则不考虑。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemSy7bQ3OTzk6zxEG9Ij0rlpRXCicgDEOhmepSwdFuebxGZ1tCAjYN9WBomxMEdWSpyok7tGfT4ebjP22zI7URdAvGXT3RHrnTU/640?wx_fmt=png)


当然肯定有一些头铁的小伙伴想要出手，卖家给了三个套餐，准系统189元，但没电源，加25块配一个。如果你是个老手，手头有闲置的DDR4内存和M2固态，那闭眼入准系统，可以把省钱最大化。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekfFsIxgsV77TlGxnK9Oh4BdBHQZiczOP7f5iaTGvp4gYIF9lFuHktY8A2MTLaJC3ibP49kpn3mdzyK4CaticGD00gTyY4ZgbO9ibhQ/640?wx_fmt=png)


如果你是纯小白，而且家里有矿，建议直接看第三个套餐，469元带8G内存和128G固态，系统都给你装好，到手插电就用。那个374元的4G内存套餐，说实话不太推荐，现在4G跑Win10有点吃力，多花这95块钱，体验能翻倍。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekiaTXkYvibkbFQia6Mv3SmKmqxfeO3wWbQciaRyA0ffbBuUrk7Sjs67JoDm5Gy8JA6nhmz9s7IRQI60SQE9N0WoVxzMjWNVHwtzOE/640?wx_fmt=png)


所以问题来了，如果你是冲着自己折腾NAS或者客厅影音去的，会花189元买一个准系统吗？还是说会一步到位上8G套餐？评论区聊聊，看看谁的捡漏眼光最毒辣。
