# 野火正点原子韦东山都能用，这85块的显示模块花得值不值？

兄弟们，最近二手鱼里有个东西看得我心痒痒，一块全新的7寸RGB电容触摸屏，正点原子和韦东山联合出品，只要85块钱，还包邮！你没听错，就是那个当年一套下来没个三四百拿不下的高清大屏。这价格，在现在的电子市场里，也就够买两杯咖啡，现在能换回一块专门给Linux开发板配的液晶模块，这事儿你品，你细品。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemBMBK3VqtbiaVHmxZYU6k82Ar3Vic5ibhmWy4EyvjdVCRWUqVuZibHgiaE7eWdpvxgdeick1B523VefOs9Cvxia6zRhvdvicxT81E8DI8/640?wx_fmt=png)


卖家描述东西是全新的，还没拆封，型号是IMX6ULL专用的7寸屏，分辨率1024x600，支持五点电容触摸。最关键的是它的兼容性，正点原子和韦东山家的IMX6ULL板子是即插即用，连野火家的板子稍微改一下分辨率也能支持，RGB接口，50pin和40pin都照顾到了。还白送排线和铜柱。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCembVTXWRvxgH0ukOicYgFdnFLe7iaSCicCuZiay5WMAibRsLb1T6EtSo0ZoQys7f3XsP68krHFM5IFFHKziczqiakq6yTicRIiaOXwAfY7o/640?wx_fmt=png)


咱们客观地说，这玩意儿要是放在两年前，妥妥的学习门槛之一。很多人买了开发板，还得纠结要不要配个好点的屏幕，毕竟用那种几寸的SPI小屏，看代码、调试Qt界面，体验确实差了点意思。现在倒好，价格直接被“打下来了”，腰斩都不止。当年那些因为屏幕预算犹豫没上车Linux的朋友，现在看着这价格估计心里在滴血。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelqhSukJQkU9Ah90mcwvTjYkys6KOsViaQpM5wEYCt02RJpz7NFeZTribez618LCnwkvicVXQsibHvicofoAgQ0h6oG8FHnRojD6Hos/640?wx_fmt=png)


不过话说回来，这屏幕有没有坑？咱们得理性分析。首先，它是RGB接口，不是现在手机上那种MIPI或者eDP，它本身就是给特定开发板设计的，你别想着拿去给树莓派或者电脑当显示器用，那方向就错了。其次，它的核心价值在于“全新”和“兼容性”，85块钱买一块已经绝版或者正在清仓的工规级屏幕，对于正在学习韦东山或正点原子教程的爱好者来说，简直是神助攻。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCel8D83Q8CicXIgB5nyZCFyGk1uNmiarUzRnAODNgXNbX9O6tXh2cHI7colaKZLC4neyZ3tWicMuKdc8XXk3D6eeTF9wocM1nxpsak/640?wx_fmt=png)


我的看法是，这东西没有智商税的成分，因为它就是一块实实在在的工业级液晶模组。如果你手头正好有IMX6ULL的开发板，不管是正点原子还是韦东山的，那这块屏绝对是闭眼入的节奏。85块钱，你甚至不用纠结它是“边角料”还是“工厂淘汰”，因为全新未拆封这个状态，就足够秒杀二手鱼上那些不知道转了几手的旧屏了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemoPtK93DNETicUYIF6haEMRvAibGDmPvHRiatuoic2lQ0A9IDoq2icWDl7eLIpRj9eryU760L7BSFLNiciaCzDJeM0s3LEwQOz0Enpek/640?wx_fmt=png)


当然了，如果你是野火的用户，动手能力又一般，对改分辨率这事儿心里没底，那就得多想想了，别为了省这几十块钱给自己找个麻烦。但如果你愿意折腾，这又何尝不是一以小博大换取大屏体验的机会呢？


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelUhJwSjpPsO924ENzPZo4asBNBN4w3icYEP7VkMfxtUE5MQKwbsqRyOmlbib8ULq7awAGhQbfiboQagibTvBerXu2qcyibAcwJ31A4/640?wx_fmt=png)


最后真心问一句，大家手头吃灰的开发板，都配了个啥屏幕？或者有没有像我一样，一直在等这种“价格再创新低”的配件，好把吃灰的板子再翻出来把玩把玩的？评论区聊聊，咱们一起在“鱼”里淘点真金。
