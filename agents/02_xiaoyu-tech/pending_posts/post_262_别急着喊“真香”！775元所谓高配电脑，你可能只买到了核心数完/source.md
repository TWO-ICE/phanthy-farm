# 别急着喊“真香”！775元所谓高配电脑，你可能只买到了核心数

今天在二手鱼刷到了一台标价775元的高配台式电脑，文案写得比发布会还激情：“秒开机、秒开网页、秒杀一切游戏”，配置单写的也很详细，英特尔X99主板、E5 2673v3十二核处理器、710显卡……价格挺白菜，但心里却有点打鼓——这玩意儿2025年还能打吗？


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFEdW1q5FHbsqnJD4QTJq3yORPxTr6wbvqicwMOpxfpgib41W3CmD1Uz7hSeQps4VOYmiaNsuof9fjow/640?wx_fmt=png)


先说说这套机器的来头：卖家自称是工作室急出，因为“直播带货前期亏了不少钱”，所以把半年前刚买的12台整机打包甩卖，其实这话术懂得都懂，但不管是真是假，卖电脑是真就行。成色99新，原包装都在，还送键盘鼠标，加显示器一套才1080元，听起来确实诱人。而且支持7天试机，个人自用非贩子，语气诚恳，连“保护膜都没撕”。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFEdW1q5FHbsqnJD4QTJq3yYrBXyNNibCpf7M54DHFQI20gZhoJKohN3ukecsPzNAEF4adtecDDibuA/640?wx_fmt=png)


但冷静下来一琢磨，问题就来了。首先，核心配置里的显卡是GTX 710——没错，就是那个被网友戏称为“亮机卡”的入门级老将。虽然文案里写“畅玩腾讯全家桶”，但别忘了，2025年了，《原神》都4.0了，《永劫无间》也早不是当年的优化水平。710甭说高特效，中画质跑60帧都得看运气。所谓“吃鸡无压力”，大概率是指用模拟器挂机那种“吃鸡”。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFEdW1q5FHbsqnJD4QTJq3yaRsnOicj4CtMJUUwibTFdz9IqRiceIm9y4oZvgkrHRzl4DDnicpTPA9C3g/640?wx_fmt=png)


再说CPU，E5-2673 v3确实是12核24线程，但它是服务器U，基于Haswell架构，主频仅2.4GHz，单核性能弱得可怜。虽然多开办公、跑虚拟机还行，但对依赖单核性能的游戏（比如《CS2》《永劫无间》）来说，实际体验可能还不如一颗i5-10400。再加上搭配的是DDR3内存和128G固态——注意，是128G，装个Win10+常用软件基本就满了，想剪视频？得先清缓存。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFEdW1q5FHbsqnJD4QTJq3y1ZHUlibQVzkIia3zibyJu8acg90aYFLxstU5VIz3LCEIGqXw8gIXgADWw/640?wx_fmt=png)


更微妙的是主板：X99平台本身不差，但搭配E5 V3系列本就是“洋垃圾”经典组合，成本低、功耗高、升级空间为零。现在全新i3主机三千块能买到整机，性能碾压这套配置。所以775元买它，图的到底是啥？情怀？还是“看起来核数多”？


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFEdW1q5FHbsqnJD4QTJq3yAzJrFJ6QVbr4LI9ZMUYqbaiczV1U0XzLTrS3snmibD1ib3uMxGOGP5GJA/640?wx_fmt=png)


那么，价格到底香不香？查了下二手鱼近期行情，类似E5+X99+710的整机，普遍标价600–900元，成交价多在650左右。775元不算离谱，但绝对谈不上“捡漏”。尤其考虑到710显卡几乎无游戏价值，这钱不如加200块淘个GTX 1050 Ti的老主机，至少能流畅1080p。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFEdW1q5FHbsqnJD4QTJq3yJNSyrkzvCzaInNSjcSLbMucicxhqzXKICqM6m15numqa7FKa9V7kFFw/640?wx_fmt=png)


可能有人会问：“不是说能跑PS、CAD、剪辑吗？办公总没问题吧？”轻度办公确实够用，PS修图、Office套件、浏览器多开都没问题。但要是真做3D建模或4K视频剪辑，128G固态+DDR3内存+弱单核CPU，渲染时怕是要泡杯茶等半天。所谓“支持Adobe全家桶”，更多是“能打开”，而非“高效流畅”。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFEdW1q5FHbsqnJD4QTJq3yuxgrGHNnabHzVj7f0M0ybJbOEGEVz61d58ZM8gOIZOD07segJz4FaA/640?wx_fmt=png)


那么卖家说的两年保修、7天试机，是不是很靠谱？保修条款听着安心，但注意——这是个人卖家，非店铺。所有的质保都建立在卖家不跑路的前提下，所谓“只换不修”，实际执行全靠自觉。万一快递途中磕碰，或者到手发现电源虚标，维权难度不小。而且“还在保两年”指的是整机？还是个别配件？细节模糊，需提前确认。


 


结合当前二手鱼行情，给几点建议：


 


1. 游戏玩家慎入，710显卡已严重落伍。

2. 办公用户可考虑，但务必确认存储是否够用。

3. 同预算下，建议优先选Intel 8代以上+GTX 10系显卡组合。

4. 看完不买，立省775元。
