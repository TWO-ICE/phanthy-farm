# 399元的MacBook Pro无头骑士了解一下，i5+8G+128G这配置香不香?

各位，如果你在闲鱼或者某个二手电子市场的角落里，看到一台只要399元、却标着"MacBook Pro"字样的机器，先别急着划走，也别急着嘲讽是哪个世纪的出土文物。是的，你没看错，只要一顿火锅钱（甚至可能还不够），你就能把这台曾经身价上万、让无数设计师和程序员魂牵梦绕的苹果神机——2015款13寸MacBook Pro的"无头骑士"版抱回家。

所谓的"无头骑士"，听着哥特，其实就是屏幕坏了或者被卖家为了拆件卖钱而抠掉了，只留了个底座的"残血版"。但千万别以为这是什么只能用来当键盘使用的电子废品，这可是实打实的"五脏俱全"。你花399块买到的，是一颗依然强劲的Intel心脏，是一套完整的主板、声卡、网卡，只要你给它接上一台显示器，哪怕是家里淘汰的老 VGA 屏幕配上个转接头，它瞬间就能满血复活，重新变回那台优雅的 macOS 主机。

咱们先把时间轴拨回到2015年。那时候的苹果还没有那么多"低温锡"争议，模具做工还是被吹上天的"unibody"一体成型。这款A1502型号的机器，当年可是妥妥的高端生产力工具。配置单放到现在看依然不算太寒酸：搭载了第五代 Intel Core i5 双核处理器（通常是i5-5257U），拥有8GB 的 1600MHz DDR3 内存，以及一块 128GB 的 SSD 固态硬盘。虽然现在大家都觉得 M 系列芯片才是主流，但在 x86 架构的领域里，这颗 i5 的日常处理余力依然富余得很。这机器的核心部件——Wi-Fi 网卡（支持 5GHz 频段，网速稳得一批）、蓝牙模块（连接 AirPods 丝滑连）、立体声扬声器（虽然低音一般，但开麦开会清晰度足够）甚至包括那个引以为傲的 Force Touch 触控板，只要主板没修过，通通都能用。

而且，对于爱折腾的朋友来说，这简直是最佳玩具。卖家通常会标榜"ID 已退"，意思是这台机器已经脱离了苹果的 iCloud 锁定监管，没有 Activation Lock 这一类的"软枷锁"。更重要的是，它的 BIOS（或者说 EFI）状态健康，意味着你想装纯净的 macOS，想装黑苹果，甚至想彻底洗白装个 Windows 或者 Linux，全都随心所欲。这种自由度，在如今的苹果自家硬件上是很难体验到的。

这就不得不提那个让人无法拒绝的价格了——399块。

要知道，现在你去苹果官网看一眼，全新的 Mac mini 即使是 M1 芯片的基础款，起售价依然要三四千人民币。而这个价格，仅仅是"无头骑士"售价的十倍。咱们细算一笔账：399元拿下主机，再花个三五十块钱淘个原装 MagSafe 2 的电源适配器（注意一定要买原装或者正规第三方，不然电压不稳容易花屏），总投入控制在500元以内。这是什么概念？这就是对目前入门级台式机市场的"降维打击"。你去拼个一台能跑 macOS 的黑苹果主机，主板、电源、机箱、机箱风扇加起来都不止这个数。

更关键的是现在的市场大环境。最近存储芯片的价格走势就像脱缰的野马，不管是固态硬盘还是内存条，都在悄悄回涨。你想给老电脑升级个 1TB 的 SSD，得花好几百。而这时候，这台自带 8GB 内存 + 128GB SSD 的"无头骑士"，光是拆下来卖零件，可能都不止这个价。在这种背景下，能以"白菜价"淘到一台架构完整、自带存储的主机，简直就是在电子垃圾堆里捡到了宝藏。

当然，咱们有一说一，毒舌一点讲，这机器毕竟已经是近十年前的老古董了。

它的短板非常明显：它是 Intel 架构。自从苹果推出了自研的 M 系列芯片后，Intel 版本的 macOS 更新支持周期明显进入了"晚年生活"。虽然现在最新的 macOS Sonoma 还能勉强装上去（需要一定技术手段，比如 OpenCore 引导），但官方的优化已经大不如前。如果你指望这台机器去跑 Final Cut Pro 剪 4K 视频去渲染特效，或者是去跑大型 3A 游戏的 Crossover 模拟，那我建议你出门左转买 PC。

但是，对于轻量级的生产力场景，它依然是一把好手。Intel Iris 6100 核显虽然跑分不高，但用来驱动编程 IDE（比如 VS Code）、处理 Office 文档、浏览几十个 Chrome 标签页，依然是"丝滑得很"。它的低压处理器发热量极低，那种金属外壳特有的触感，让它非常适合作为家庭服务器使用。比如挂个 PT 下载，跑个 NAS 系统，或者插上硬盘做个 24 小时开机的私有云盘，它的低功耗优势就体现出来了——甚至比很多所谓的"专业 NAS" 系统更稳定。

至于卖家口中"运行流畅"这个说法，我是信的。

这类流通过市场的"无头机"，来源通常是海外的企业大批量退役设备。你知道的，国外大公司的 IT 资产管理很严，电脑是用个两三年就统一淘汰换新的，而不是用到报废。所以这些机器虽然外表可能有使用痕迹，但内部主板、芯片的使用强度其实很低，甚至有些还没过保。加上苹果那个年代的硬件做工真的是"坦克级"，主板覆盖件厚实，接口紧密，寿命远超同期那些大塑料壳的 Windows 笔记本。

更让人心动的是，它的可玩性不仅限于现成的配置。128GB 的硬盘确实小了点，装个系统、装个 Xcode 就红了。但这台机器的硬盘接口是标准的 NGFF 协议（虽然苹果做了特么的私有针脚定义，但现在淘宝上几十块钱的转接卡完美解决），你可以轻松把它升级成 1TB 甚至 2TB。再配合系统自带的 trimos 优化，这老机器还能再战五年。

不过，在这波"真香"安利之前，我得给各位泼一盆冷水，提几个必须注意的细节。

第一，电池还在不在？这是个玄学问题。虽然你买来是当"主机"用的，永远插着电，不需要电池供电。但如果上一任机主是因为电池严重鼓包才导致屏幕或者主板损坏，进而拆机卖件的，那你就得小心了。鼓包的电池不仅会顶坏键盘键帽，产生的酸性液体还容易腐蚀主板上的电容。下单前，务必像审问犯人一样问卖家：底壳拆过没？主板进液没？电池有没有鼓包痕迹？如果卖家支支吾吾，果断换一家。

第二，虽然是"9成新"或者"95成新"，但这毕竟是二手洋垃圾。细微的磕碰、底部的脚垫磨损、C 壳的掌托划痕，在所难免。如果你是那种追求"全新未拆封"体验的强迫症患者，这机器绝对会让你抓狂。它的A面（屏幕盖）通常是被抠掉的，甚至可能是个黑乎乎的铁壳子或者塑料挡板，颜值确实不如完整的 MBP。但只要 B 面（键盘面）和 D 面（底壳）没事，核心功能正常，这些瑕疵都可以算是"战损版勋章"。

所以，总结一下这台"无头骑士"的受众画像：如果你手头预算非常紧，比如只有几百块生活费的大学生，又想体验 macOS 的生态，不想去折腾那些不稳定的黑苹果 U 盘；或者你是一个极客，想在两台廉价机器上搭建一个小型的 Linux 集群跑代码；又或者你只是想给家里的电视配个看片神器，不想听电视那自带喇叭的嘈杂声——这台399块的机器，真的值得你闭眼入。

最后问一句，如果是你，手里捏着这不到500块钱的预算，你是会选这台饱经风霜但内核强大的苹果残次品，还是去买一台配置低得可怜的杂牌 Windows 小主机？评论区聊聊你的选择，顺便@一下你身边那个还在纠结买新还是买旧的朋友，让他看看什么叫"永远可以相信苹果的残值管理"。
