# 跌冒烟了！全新盒装锐龙5500不到500块，垃圾佬的春天又来了？

大家有没有发现，最近二手鱼里突然冒出来好多全新的AMD锐龙5500处理器，散片直接干到了479，盒装也不过499。两年前这玩意儿可是装机的香饽饽，谁敢想现在价格能被干到这个份上？


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekA8d2KcBK0D6qs8iaEaEAyEpQWiafkHtWwY1ap5x5ypbwDBwB4OyHa0rEY4tLe75fb8nsxiaMcHOK24w1P0Gg052RzwibiapysYSsA/640?wx_fmt=png)


很多人可能会嘀咕，这价格也太低了，不会是假货吧？这点你倒可以把心放回肚子里。CPU这玩意儿，堪称电脑硬件里造假难度最高的天花板。它不像内存硬盘那样容易山寨，这东西内部集成了几十亿个晶体管，全球能有能力生产的也就那么几家。所谓的假CPU，最多也就是把散片打磨了当盒装卖，或者拿旧片冒充新片，但要伪造一颗能正常点亮的处理器，目前还没那个技术。只要上机点亮，参数一认，基本就稳了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenib4YfIVzRU7v2rgDcS4wBo7wqhsQZwBYR1RWnvRqibe77kHt56phgJ89ZKW0ZDjL9mkohOeoRjySzoJ7jTXfIvUPVOVnib17iaBo/640?wx_fmt=png)


这颗5500现在是什么水平？你把它简单粗暴地理解为英特尔家当年千元级的11400那个档位。虽然它缓存比自家5600X小了点，但日常家用、玩游戏，比如吃鸡、永劫无间，甚至是带个入门级的RTX 3060或者4060，它都能稳稳地扛住。对于绝大多数预算抠搜、想把每一分钱都花在刀刃上的老铁来说，它就是把“性价比”三个字刻在了脑门上。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekmOrr5827IEFAZA2FEicVY8olzmH5icSC5ZlYVKmgWG7SqrgbfjeoLSMTQS3gM0wEBr2ibMvyKUnegwr0SWr2u1v8iaPAEUErI1c8/640?wx_fmt=png)


现在配电脑，为什么那么多人扭头就投奔AMD了？还不是因为英特尔那边从12代开始性能虽然猛，但配套的主板价格一直居高不下。反观AMD这边，一块几十块钱的A320或者百来块的B450主板，刷个BIOS就能完美支持这颗5500。省下的主板钱，直接加在显卡上，游戏帧数又能往上提一提，这账谁都会算。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCek6ArcsiaW4gXtVPkb8tEaYORUQkjfLag8nmLK0GK55hCibjljrUzARUsiaPpouCDsGia1Kcy9glILtsnBibjhqojbJz0WMF8QHnaqU/640?wx_fmt=png)


如果想用这款处理器组装一台性价比最高的主机，我在这里也给大家提供一个配置参考：

CPU ：AMD锐龙5500盒装499元 

主板：蹲一块精粤或者二手华硕的B450，成本控制在230左右。这东西只要能亮机，带5500稳稳当当，省下的钱都是肉。

内存：两根二手的DDR4，8Gx2组双通道，大概240块。游戏帧数全靠它撑着，不能省。

硬盘：二手500G的NVME固态，250块搞定。装个系统放俩常玩游戏，够用。

电源：500W的二手电源，40块随便挑个国产牌子，带这套配置绰绰有余。

机箱：鞋盒，能装进去就行。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemvmf7lFO8aPicNqWpdDXzMGUvLFqAl6vLWpeTmxPc2sPF40iafRnXCLYViauhKQv6wsNU2wWdPh0WvTrw10UBGXLnaZ5hP7Sa3po/640?wx_fmt=png)


全套下来也就一千出头，剩下的预算全砸在显卡上，比如去蹲一张二手的1660S或者RTX 2060。这套搭配玩遍主流网游，中低画质跑个3A大作，完全没问题，等以后有钱了直接换显卡都行。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelkuMDuvicJbbUyIV3LJfWwGh3qxwGucWD0MMG6GUicias8Q6L1C3HQ8Up6uxznrdrR0xhicevkZ3EiblHxYHpgXcqLbCJIKqsmKtX0/640?wx_fmt=png)


不过下单前，有两点你得自己想清楚。第一，散片和盒装那20块的差价，建议直接选盒装。不是为了那个包装盒，而是为了官方质保。万一运气不好真碰上“点不亮”的，有官方渠道兜底，不用自己瞎折腾。第二，这颗U虽然便宜，但它的接口还是AM4，属于上一个时代的平台了。这意味着你以后如果想升级更强的CPU，选择面会比较窄，基本告别了未来的新平台。所以它更适合那种打算一台电脑用个三五年，期间不打算再折腾升级的实用党。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenNN1MLqaXQbScgbFQr68f5JaAyQB0dln4O8v4Nic1p7AW3BGKwEibM7jSa1CzQB8yX7Jibib8Xb9yG2CVNUicfzfgjbYb37XcLSXgI/640?wx_fmt=png)


有人说这是AMD在清库存，也有人说这是在给新品让路。不管怎样，价格被打下来了，受益的终究是我们这帮在二手鱼里淘金的人。那么问题来了，面对这颗只要500元就能让你用上好几年的全新6核处理器，你会选择果断出手抄底，还是继续当等等党，期待它还能再跌？咱们评论区里见真章。
