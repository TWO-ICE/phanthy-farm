# 会翻车吗？150元捡漏23寸惠普一体机，感觉卖配件都能回本

刷二手鱼的时候看到了一台惠普23寸的一体机，只要150块。这价格现在连个像样的机械硬盘都买不到吧？但这玩意儿真真切切就挂在上面，还带屏幕、带摄像头、带刻录光驱，甚至还有独立显卡，这不就是在等着我捡漏呢吗？


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/E9h3abOJCenkLOzUC1C2D9yzMCUKvny2Wp7yIiboVkktdpcxecr2BZu2OT6lM4f8picVibqUgRumccLuhiacBRKhnS2Wdnlfzs7RibF1fhrjPBS0/640?wx_fmt=jpeg&from=appmsg)


我盯着配置单看了半天，处理器那一栏写着AMD闪龙240双核。懂行的老铁看到闪龙这俩字估计已经笑出声了，这玩意儿是十年前入门办公电脑的标志性产物，当年主打的就是一个能开机就行。4G内存，500G机械硬盘，还有个HD 8600M独显。你说它强吧，它连现在的入门级处理器尾灯都看不见。你说它弱吧，它当年好歹也是正经品牌机，而且配件齐全还带独立显卡。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenUfbjAia8yGnOYzYDjOmIVuPzEHGv7HeX4QPRNr6znDeWicMR1hcrJDtJkrKI6rqTF8853GqnE1hialKwvKrUk4kOia4tpjdyQBX0/640?wx_fmt=png&from=appmsg)


另外咱俩可以算算账，现在内存固态什么行情大家心里都有数，这机器拆开卖，23寸的屏幕算50，机箱壳子算20，主板CPU显卡50，4G内存500G硬盘打包卖也值80吧，和光驱当个乐子送人，加起来怎么也200块了。卖家报价150，感觉是奔着交朋友去的。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenprQ1gFGSj9g2bd29dVUPYyZicl1yzialgpZYHe32G6Qmcp8Yhx0NrzPbJhicicJ8Q4Ky9icsBExVtDxeW7qleJ8urG2XhuePz5TLM/640?wx_fmt=png&from=appmsg)


但话说回来，买这玩意儿回去能干嘛？这是最关键的问题。你要是想着买回去当主力机用，开个网页微信再挂个钉钉，那不出半小时就得骂娘。闪龙处理器配机械硬盘，运行个Windows 10都费劲，后台稍微多点东西就直接卡成幻灯片。打游戏就更别想了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekeYQLU4389gavgvuTd8FthrvibKCXN6TOGicOwvbIYdiaGZA6s14hzNKjqlMSGNwRdKRTsctyZug5Kc6KcfSXmzrbLVpkJolgmIQ/640?wx_fmt=png&from=appmsg)


可换个思路，这东西的用途就完全不一样了。比如就想上网看看新闻、玩玩单机斗地主，或者放在客厅角落当个专门的播放器，接个音响，HDMI输出到电视看剧看综艺，这屏幕素质放十年前也是主流水准，现在当个影音专机完全够用。甚至你爱折腾的话买回去专门挂个网心云或者甜糖，赚点电费，利用的就是它低功耗和一直开机的特性。或者还有手痒的垃圾佬，买回去拆了改装成便携显示器，这屏幕可是23寸的1080P，单独买个驱动板加外壳都不止这个价。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelluhgawfoVB8Zn1PGwtbG4Hx01cIW4eNZQhcrKYl5YtLic7Pe80NOCj7XAywtHRO1l2VuT5OdOeg4hrGYVicyF5RLObnhnMZ7BU/640?wx_fmt=png&from=appmsg)


说点实在的，这机器有个很大的优势就是省地方。一体机嘛，一根电源线搞定，不像台式机后面拖着一堆线。带无线网卡，放哪都行，不用扯网线。还有个DVD刻录机，虽然现在用的人少了，但对于有些还有光盘存货的老铁来说，这功能就是刚需。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCek6rZcJTzXbrSaxBibWV6XxUAGyMYMObD1iat7sNI3zo4qrmSsjG9ht0LKFccV7RqeJVVYnk298KgObuUdSrd1Zyx6hJtibhSIWuI/640?wx_fmt=png&from=appmsg)


不过得泼点冷水。卖家说了裸机无配件，电源要另算，如果是同城自提最好，带上电源当场点亮测试，跑个鲁大娘看看温度，检查下屏幕有没有坏点。要是外地，运费得小五十，到手万一翻车，钱货两空，这点得有心理准备。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekl7kKJRHreR5KKbHrkXHywbEfsAv3y1r9tectBvWoP3MQZW4d1Rug8WvDV6gNxNGDtFiarDIPRnQHN8m9czNdqpuicwkEHPnywU/640?wx_fmt=png&from=appmsg)


归根结底，这玩意儿的价值不在于性能有多强，而在于它用150块钱给你提供了一个23寸的大屏加整套主机。在这个手机动不动就四五千的年代，150块甚至不够去海底捞点两个菜，但在这里，你能抱回家一台曾经售价大几千的品牌一体机。对于预算紧张的学生党、想给老人弄个简单电脑的，或者单纯想折腾的垃圾佬来说，这价格确实有点让人上头。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenxa8b3RQP6tt6mpj20B0tHQ1szxt7ibliaMGocoYu7B1Bdia8LwWpE1X0CuvupSqmbD2qL4qd6dPRmmLOMbdGF3HqRd0juel8tvk/640?wx_fmt=png&from=appmsg)


如果是你，敢不敢花这150块钱去抽个奖？评论区聊聊，你买过最便宜的电脑是什么翻车了没？
