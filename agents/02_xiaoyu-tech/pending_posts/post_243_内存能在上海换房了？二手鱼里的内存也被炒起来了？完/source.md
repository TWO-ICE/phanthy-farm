# 内存能在上海换房了？二手鱼里的内存也被炒起来了？

![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFJPEuRYFNicMXBKjuU2SG6vdwrGqknZUew7fk6qevCibNSnjSBCZ5icYICvX0z1UJkelQXcicdywjqFA/640?wx_fmt=png)


前几天看新闻上说一条256G DDR5内存条售价4W，一盒内存就能在上海换一套400W的房子，这价格涨的也太夸张了，连带着拆机的旧内存在二手鱼里的价格也上涨了。当然我不是新内存买不起，而是二手的内存更有性价比，这不就在二手鱼里看到了一批二手的DDR4台式机内存条。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFJPEuRYFNicMXBKjuU2SG6v9AsZFIlJ4UVp2YVJtszlGWXkdyrfMI2icGaaCHsOJxUsntAgCgTvcHw/640?wx_fmt=png)


卖家挂的是“拆机四代DDR4 8g2133/2400 4g2133/2400 台式机内存条”，支持所有四代主板。价格从65元到235元不等，容量和频率不同，价差还挺明显。4G 2133最便宜只要65块，8G 3200顶配要235元。这个价位放在现在确实不算贵，但相比去年也上涨了几十块了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFJPEuRYFNicMXBKjuU2SG6vsTLDVeLlXsGq7ZZvFmEos933ib7VAdkBMI94wgAQpEfUxicOiabnQazxg/640?wx_fmt=png)


如果你还在用老款英特尔六七代或者锐龙一二代平台，那DDR4 2133到2666基本就是日常办公、上网课、轻度剪辑的主力配置。就算你拿它组个家庭NAS或者软路由，4G起步也完全够用。甚至有些老游戏主机魔改项目，比如把旧电脑改成复古游戏机，这类内存条反而更适配。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFJPEuRYFNicMXBKjuU2SG6vyLDbRz1drGPVNcm5vVib51ID70T3HUgRkLicUNat4dIm9VTDLZWIX86Q/640?wx_fmt=png)


参数方面，2133MHz和2400MHz属于DDR4早期标准频率，延迟偏高但稳定性强。2666算是中端甜点，3200则接近DDR4性能上限。不过要注意，很多老主板压根不支持高频，买3200回去可能自动降频跑2133，等于多花了冤枉钱。所以别光看数字大就冲动，得先翻翻自己主板说明书。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFJPEuRYFNicMXBKjuU2SG6vYCrHUWibfflSsREFa9My1D1whRSaz7DSqcMyag6aGiab63knd3P6qLlQ/640?wx_fmt=png)


包装倒是挺讲究，卖家说独立盒装还能“充新”，听起来有点滑稽，但至少说明不是散片裸奔。更关键的是两条以上发统一品牌型号，四条包邮还免运费，对想组双通道或四通道的用户算个小福利。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFJPEuRYFNicMXBKjuU2SG6vFbtwFMsISlxtYVy4HrxPZMlXq7Ecc7ibyavjyRcE15iaweVHvhNgiaibZw/640?wx_fmt=png)


质保一年七天无理由退货是亮点，但前提是卖家不跑路的情况，不过跑路的几率还是很小的，毕竟卖家是7级小铺，而且好评率是98%。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFJPEuRYFNicMXBKjuU2SG6vhNA1zK5vOLUCtjJT7fZGI55HxLc2WJxtZ2LUdEv0KuW8HeDJhWGueg/640?wx_fmt=png)


不过也有隐患。卖家只放了实物图，没任何通电测试截图或软件检测记录。内存这东西，光看金手指亮不亮可不行，万一有暗病，插上去蓝屏死机才叫头疼。虽然能退，但折腾时间成本也不低。另外4G条子65元看似便宜，但如今系统动不动吃掉3G内存，实际可用空间所剩无几，实用性打折扣。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFJPEuRYFNicMXBKjuU2SG6vTJVMEiaJey9MT9CksxxjsIRPaNTZzsKw9em2aqBDs5LNMvE6Ks40c8Q/640?wx_fmt=png)


可能有人会问现在DDR5都普及了，还买DDR4是不是过时？其实对预算有限或者老平台用户来说，DDR4仍是性价比首选。毕竟升级整套平台的成本远高于加条内存。那么8G和4G怎么选？如果只是挂PT、跑下载或者当备用机，4G勉强够用；但要是装个Win10开几个网页，8G才是底线。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFJPEuRYFNicMXBKjuU2SG6vX35mRhiaCJsicty4puZcDXA8qHEBdoeAj9icKBLz7JoIYXpt7b3PtXicVg/640?wx_fmt=png)


对此产品有兴趣的话，可以在二手鱼搜索“拆机四代DDR4 8g2133/2400 4g2133/2400 台式机内存条”这个关键字就可以找到此产品，如果找不到可以通过图片进行搜索，都搜索不到的话，那可能是此产品已卖出或者是下架了。


 


以下是个人一些掺了水的建议：  

1. 老平台升级优先考虑8G起步  

2. 别为3200高频多花钱，除非主板真支持  

3. 下单前务必确认自己主板最大支持容量  

4. 看完不买，立省235元
