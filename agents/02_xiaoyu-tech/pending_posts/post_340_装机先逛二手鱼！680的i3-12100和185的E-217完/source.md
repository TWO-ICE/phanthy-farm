# 装机先逛二手鱼！680的i3-12100和185的E-2174G你会怎么选？

朕没事就爱刷二手鱼，最近就挖到个冷门狠货，E-2174G这颗老U居然才185块，要知道这玩意的性能可是堪比i7-7700，现在也就一包柳如烟的钱就能拿下，这个价格还要啥自行车！


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGpZU43VVlnWfEvibE5HqJ3yIJgdTcDyzQOdybkXuia0tx7ubia3kkYVBibz3YTYgiaG2Fa7bfXwxYGRlA/640?wx_fmt=png)


这货当年可是Intel第八代至强系列的“职场精英”，专门给工作站、服务器当主力，妥妥的“老黄牛中的战斗机”。Coffee Lake架构加持，四核八线程的配置放在当年也是响当当的存在，主频3.8GHz往上能飙到4.7GHz，稳定耐操没话说。谁知道风水轮流转，就因为贴了“工作站”的标签，如今在二手鱼被低估到尘埃里，对比如今的i3-12100的680块，价差快四倍。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGpZU43VVlnWfEvibE5HqJ3yLOfiaY1mCyL50BFFiceGaq7IG4r1x6StKTlMkScYja9UAmQxRXOdlwfA/640?wx_fmt=png)


装机的坑谁踩谁知道，核心从来不是CPU本身，而是平台成本！i3-12100得配LGA1700主板，运气好淘个二手的也不便宜，再加上内存，钱包直接瘦身。但E-2174G是LGA1151平台的老伙计，随便一块二手Z370、B360主板就能搭，板U加起来才300多块，价格挺白菜。当年这平台可是装机热门，配件到处都是，如今二手生态依旧完善，DDR4内存随手能淘，换装成本低到可接受。不到一半的预算，能拿到八成的性能，这哪是性价比还行，简直是降维打击，老平台的逆袭剧本都没这么爽。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGpZU43VVlnWfEvibE5HqJ3yEZpxQrzyqYYqHdtKcicTIITW5QPq49hiaDciabRAJCdKOzk1WAF7YMSVg/640?wx_fmt=png)


别以为是老U就掉链子，当年能扛服务器压力，如今应付日常需求还不是“张飞吃豆芽——小菜一碟”。单核性能在老平台里属于第一梯队，办公多开网页、剪个短视频、看4K视频都轻松拿捏，不用怕卡顿。自带的UHD P630核显也挺给力，不用独显就能开机，做个NAS、家庭小主机或者服务器都绰绰有余。轻度游戏更是不在话下，《英雄联盟》帧率轻松上200，《CS:GO》中画质能稳190帧，《原神》1080P也能保持60帧左右，对于预算有限的玩家来说，完全够用。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGpZU43VVlnWfEvibE5HqJ3yuejrHzrZJziamMdkyxscdsgy4yf71jeQ8mnQGhuPFdyEJ1B2B3lk5Vw/640?wx_fmt=png)


这颗U的隐藏加分项还真不少，支持ECC内存，对NAS和服务器玩家来说就是“雪中送炭”，数据存储更稳定；温度控制也靠谱，实测烤机不超过75℃，普通风冷就够用，不用额外花钱升级散热；兼容性更是没话说，老主板、老系统都能hold住，装机门槛低到新手也能上手。但缺点也得实话实说，不能超频（除非上Z系列主板），没有AVX-512新指令集，14nm老架构功耗比新U略高，部分老主板可能需要改BIOS才能识别。不过话说回来，185块的价格，还想啥自行车，这些小毛病对预算党来说基本不算障碍。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGpZU43VVlnWfEvibE5HqJ3y2bwSOy2PNL6HOUltm5aRM3bx8gywwbibeKwC7C4RibYmgicJGe78zC2PQ/640?wx_fmt=png)


可能有人会问，这老U现在还能战几年？其实完全不用担心，日常办公、轻度游戏的需求它都能满足，只要不追求极致性能，用个三五年完全没问题，毕竟185块买不了吃亏买不了上当，实在不够用了再换也不心疼。那么它和i3-12100差距到底有多大？实测下来i3-12100性能也就领先10%-15%，但价格贵了三倍多，要是不执着于最新架构，E-2174G的性价比简直碾压，这就是典型的“信息差捡漏”。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGpZU43VVlnWfEvibE5HqJ3yJWibVal9t658dWa7lNSK6IPx1mlMzswJV6VIh9ukicokX85L42mU9hKw/640?wx_fmt=png)


二手鱼真是个藏龙卧虎的地方，只要有耐心慢慢淘，总能挖到这种被遗忘的好东西。E-2174G当年是工作站的香饽饽，如今成了预算党的宝贝，185块的价格能买到这样的性能，真的太香了。你们在二手鱼捡过哪些性价比爆棚的好物？或者有没有纠结过类似的装机选择？欢迎在评论区分享你的经历和看法～ 老规矩，看完不买，立省185元。
