# 别扔沟里！240元的飞牛圣体，4代处理器带500G硬盘，划算吗？

今天在二手鱼里刷到一台小主机，我看挺适合作飞牛圣体的，是一台克莱默的迷你工控主机，卖家要价240元的，配置不高但功耗非常低，带一个500G的机械硬盘，不用瞎折腾到手就能用。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemMmfEOxy5a6WGQzgkJKbysibf8WcQXLSdNII1JAunOIVCLdZRwI3KRIT5MY9MvJKYhDicAJtYXVUtCTgW9eKCa5bgBiaiaY8Ogxno/640?wx_fmt=png)


这台不是准系统，配件包含完整的主机、500G机械硬盘、电源、硬盘线和支架，而且已经刷好飞牛系统。核心是N3010处理器，双核1.4GHz，4代入门级低功耗芯片，板载4G内存和32G固态。接口倒是齐全：HDMI、VGA、USB3.0、千兆网口，还带一个硬盘位。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCem3wnfibxJXRwGFT7uPMxliaibCQ5xBFhdzvricYOGkD83OpwEBUKl7UAKPQKDbk8YNHG7gc4CDwAtuwcwzwsmoibkNoStyVyxht8ns/640?wx_fmt=png)


N3010性能确实拉胯，单核跑分比不上主流的N100的，但是对于做文件存储、局域网SMB共享、挂PT下载或者当个简单的照片备份服务器，这U完全够用。待机功耗才6W，全年开着电费不到30块。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenKg6sheaYoX9eURj1rrJsFiaFHoic1K4DKicWyv6ZkHV1niadfhlAPoPjtLobp7VVrEenlfHgqaoPibf0ibib4oc4iaiaKrKPx7ChbW0ibA/640?wx_fmt=png&from=appmsg)

当然N3010不支持硬件转码，飞牛里开视频实时会很卡。另外只有一个SATA接口，只能接一块硬盘，无法组RAID或者扩容，备份数据不够安全。内存4G跑飞牛刚好，但多开几个服务就容易爆。还有那个32G固态是系统盘，别想着往里存东西。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenLUwJY94aj9YYvrYjgfWgx3NokkSoNVmU6xRIfdHTAVtubGyDHUkS1p98tWCkCM1gcgk9jnhIUQkKERibNeJYPwClduxMAdFjk/640?wx_fmt=png)


再看看这240元花在哪。二手鱼里一个500G机械硬盘大概30到40元，一个靠谱的12V电源适配器20元，硬盘线和支架算10元，剩下170元买这台带4G内存和32G固态的小主机。同价位你能买到什么？J1900或者N3150的工控机裸机，但很少带硬盘和系统。这台的优势在于到手即用，零门槛。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemicqrJcAH9iadBUiciatHIwhcZoicP2ufNUyW8HUQ9AAcorQClwxdOTBluFXzL8yiaDYAu7r1sYIiaDXL5OickxkF7pOvsC6ZrjZTW7NA/640?wx_fmt=png)


同类价位还有大量淘汰的升腾C92、惠普T620瘦客户机，价格更低但很多不带硬盘和系统，需要自己刷黑群晖或者飞牛，折腾成本高。这台最大的价值就是省事。卖家说支持255个终端设备，那是工控机的理论值，别当真，你家设备超不过20个。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCencAibNO7UhQkTmiatPgKPWVm0ASSBfmQcrooCz7DuNfnqJ0oqL9naWtUcOFEdreD3RccuTRgf2CbiaVGd8ic8HMeOURm7aARIKRnc/640?wx_fmt=png)


所以我感觉240元并不算亏，能体验一下私有云到底适不适合自己，哪怕玩腻了转手卖200块也能回血。要我说这机器适合两种人，完全不懂NAS的小白，想低成本入门。或者家里已经有主力NAS，需要一台低功耗下载机做辅助。如果你已经有一堆4K原盘要管理，或者想搭建家庭影音中心，直接绕过它，存钱上N100或者二手白群晖。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemiaNoZRl5QE1oEd44v2Iic0KeR2B5M1FuPypwzArJqoaDia3gyxumYd8UKFp1bKvXibibnfVR2EuP6eySJqyYRS3ibw5C4DAT9CRfn4/640?wx_fmt=png)
