# 康佳也出小主机？11代CPU+8G+256G，二手鱼520元是捡漏还是接盘？

最近在二手鱼里刷到了一台康佳的小主机，型号是TD31，卖家挂价520元，配置是8G双通道DDR4内存，256G固态硬盘，11代N5105处理器，功耗只有10W，可以24小时持续工作。卖家还特意提到了建议刷飞牛或者装Linux用。这价格到底是捡漏还是接盘？我们一起来看看。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCem5QNv0cgVsDsr93fkoazCXchGOaeoJFZ0SDS0bCSiakCFxheDqoVvicOWOiaOBp05FaCORNHH6KRicnlruEYgeh7ytGhuZxV4cP1U/640?wx_fmt=png&from=appmsg&watermark=1&tp=webp)


先说说这台机器的大致情况。N5105在低功率处理器里还算不错，10nm工艺，四核四线程，TDP只有10W，如今已经停产，但二手存量挺大。接口方面，两个HDMI口、两个USB 2.0、两个USB 3.0，还有一个千兆网口，基本够用。这机器还带了WiFi和蓝牙，日常办公和看视频基本没压力。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemqDWtOjsCUTwpG69Gia62nmAv0ia0k3LQFL93S3DWzicgo5gHjBKKK5rqP9956IHDvR73JgOUnd0nB3zk2JmuurxfTWu9iaqZKEJo/640?wx_fmt=png&from=appmsg&watermark=1&tp=webp)


实际用起来怎么样？日常上网和轻办公完全没问题。拿来当副机放个电视剧或者查查资料，不会卡到让你想砸键盘。卖家说适合刷飞牛，据我所知也有玩家在ESXi 7.0底层上跑飞牛NAS，配合内网穿透把几百块的硬件改成了云服务器，玩得相当溜。所以不是不能刷，但如果你是小白，想插U盘一路下一步就搞定，可能会翻车。预算紧张还想折腾All in One的垃圾佬倒是可以试试。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemw5aRiclTujK6yAkD6GWdsJLv5lyC4SVib7iccXKKASA3O4vjLRiak5q4dwKwc58Xv3UU2wNNACREtgCnibqOkGRJianz65YwDoZg14/640?wx_fmt=png&from=appmsg&watermark=1&tp=webp)


这机器的亮点首先是可拆卸设计，卖家说了上盖一掰就能打开，内部有个2.5寸SATA硬盘位，支持加装硬盘，卖家还送硬盘线，扩展性比很多同价位迷你主机强。其次是两个HDMI接口，同时接两块屏幕炒股看行情或者搞轻办公很实用。还有就是挂架设计，可以挂在显示器后面秒变一体机，省桌面空间，这点确实良心。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenowqczwm1ehAicibkiajia9welaNpIrvGYL5o12UrzWMaqpsFZcXfn4Z9Qk0Ese1brpbBysN4LfwTgTeBJ43tia2b2zS0CR6J27ibPQ/640?wx_fmt=png&from=appmsg&watermark=1&tp=webp)


短板也得说清楚，内存是金士泰这类小众品牌，用三星颗粒自己贴牌封装，看起来有点寨。内存直接板载没法自己升级，8G跑Windows的话有点捉襟见肘。跑分对比N100平台几乎翻倍，性能差距摆在那，毕竟N5105是上一代产物。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelRqXTunCRoKl5bTNHqdv5zk7H3R1bkS5quDwbckuAHhmfwXvJ0PT9pygibmsIuazSQichY2S8hZaJ7HGqcPnqV4bDpzeia3R29HM/640?wx_fmt=png&from=appmsg&watermark=1&tp=webp)


目前二手鱼里N5105准系统小主机行情大约在300到450元之间。康佳TD31卖520元，但是它集成了8G内存和256G固态，相比之下能便宜几十块，还省去了你自己单配的麻烦，但自带的内存硬盘到底够不够用，值不值这溢价，你得自己想清楚。
