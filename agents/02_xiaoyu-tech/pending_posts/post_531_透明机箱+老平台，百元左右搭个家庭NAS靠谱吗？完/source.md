# 透明机箱+老平台，百元左右搭个家庭NAS靠谱吗？

![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXF5m18uBujIY1WBy5fmooGfhibcfvkzt75VHcg5lpPtO5sTUUg1Gc0yXllq7xgFz84IbpRDF1IYdlA/640?wx_fmt=png)


我发现最近二手鱼里流入了大量的NAS小主机，今天又刷了一款感觉性价比还不错，而且是标价59元的无锁版847plus主板，卖家吹得天花乱坠，说这玩意儿既能当NAS、又能做机顶盒，甚至还能跑轻量级服务器。听起来是不是有点玄乎？但咱也不是没玩过老硬件的人，先别急着下单，掰开揉碎看看值不值得掏这几十块钱。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXF5m18uBujIY1WBy5fmooGfftictv9maUBEWibVsKxibByzx73QxR0QMvicl12HLZRy5oaV3x1fmylFrw/640?wx_fmt=png)


先说核心配置。这块主板基于英特尔HM65芯片组，搭载的是老掉牙但还算能打的赛扬或奔腾CPU（具体型号随机），单内存插槽最大支持8G DDR3，带一个千兆网口，对家庭内网传输勉强够用。接口方面有VGA输出、两个USB 2.0口、一个SATA和一个mSATA接口，这意味着可以同时接一块2.5寸机械盘和一块固态，搞个简易存储阵列不是梦。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXF5m18uBujIY1WBy5fmooGfyfS5LcciacQV1tficvlyvfzzkX1t7WsguO8nLRqATgB1iaA8tN8K88mPw/640?wx_fmt=png)


不过要注意，它没有音频输出，想听声得另买USB声卡或者直接插USB音响。电源是6PIN接口，得配12V/10A的外置电源，光这一项就得加36元。再加上内存、硬盘、机箱、开关、DC线……一套配齐轻松破百。合着59元只是单主板的售价，但真要到手能用，少说也得120往上走。等等，120貌似也不算是贵的离谱吧。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXF5m18uBujIY1WBy5fmooGfjkhrRdn71N45sH5gbpgD0C39YqDzbwvNMQdyuhIs0kW70TwgGJtufQ/640?wx_fmt=png)


那么这东西现在还有啥用？说实话，如果你只是想搭个家庭影音中心，装个国产影视系统放本地电影，它完全够用。要是折腾飞牛OS这类轻量NAS系统，也能胜任基础文件共享、远程访问。但别指望它跑Docker、挂PT站或者硬解4K，性能真扛不住。不过对于只想低成本试水NAS的新手来说，倒是个练手的好玩具。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXF5m18uBujIY1WBy5fmooGfprib0hLwNnedHq7Shb6ibKhys9GkIcvtMth0RZC5sAib5b5S7250ZW01g/640?wx_fmt=png)


可能有人会问：现在固态硬盘价格涨得离谱，这板子支持mSATA，会不会反而更省钱？还真不一定。虽然mSATA盘确实便宜，但128G也就四五十块，和普通SATA固态差不了太多。而且老平台功耗高、速度慢，长期开着电费也不低。真要建NAS，不如加点钱上J4125这类新平台，性能翻倍还省电。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXF5m18uBujIY1WBy5fmooGf7wicZxZgHgjXAI95IF2D0PianLo5rMMibb5F1g09Nf3nuvOc13iabHcMDw/640?wx_fmt=png)


从成色来看，卖家图里的亚克力透明机箱还挺像样，至少不像拆机垃圾堆里刨出来的。但问题在于，所有配件都是“品牌随机”，内存可能是杂牌，硬盘说不定是矿盘翻新。售后条款也写得明明白白：拍下不退、开箱必须录视频、24小时后概不认账。玩老硬件本来就有风险，这种定制组装更得睁大眼睛。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXF5m18uBujIY1WBy5fmooGfPr8q8f4FBBKBIBiaxYxzpibcd3fGCmCRcibR9BpH8Twv6B3RwOlHB1BSA/640?wx_fmt=png)


对此产品有兴趣的话，可以在二手鱼搜索“几百个拆机120G 128G固态硬盘”这个关键字就可以找到此产品，如果找不到可以通过图片进行搜索，都搜索不到的话，那可能是此产品已卖出或者是下架了。


 


以下是个人一些掺了水的建议：  

1. 别只看主板59元，算清整套成本再下手。  

2. 没折腾经验的新手慎入，容易变电子垃圾。  

3. 真想玩NAS，建议对比新款低功耗主机。  

4. 看完不买，立省120元。
