# 二手鱼89块能捡漏樱桃键盘？对不起了钱包，这性价比我实在无法拒绝

只要是个稍微懂点外设的打工人，手机里肯定少不了那个蓝色的图标。没事儿就爱在上面刷两圈，看着那些被标上“毕业回血”、“老婆不让”、“搬家带不走”的数码产品，价格像是做过山车一样疯狂跳水，偶尔还真就能在垃圾堆里刨出点真香的玩意儿来。

最近这一刷，直接给我整精神了。 cherry樱桃的机械键盘，居然挂出了89元包邮的“骨折价”。

要知道，在机械键盘这个圈子里，樱桃（Cherry）那可是妥妥的“老炮儿”，甚至是祖师爷级别的存在。当年这把键盘刚上市的时候，哪怕是个最朴素的无背光版本，起步价也是要499元往上的，而且那时候这价格还得求着卖家发货。那时候谁能拥有一把原厂 cherry 轴的键盘，那在宿舍或者办公室里绝对是排面拉满。

现在倒好，二手鱼的价格直接打到了两折，甚至是“一折多”。这性价比已经不是用“高”能形容的了，简直就是把空气抽干了压缩成固态的精华。这波捡漏要是再不冲，哪怕是半夜做梦都得给自己两巴掌，亏得能让你哭到姥姥家去。

具体看了一下，这次的主角是经典的樱桃 MX Board 1.0 TKL。

先给不懂行的新手补个课，这个“TKL”的意思是“Tenkeyless”，也就是tenkeyless，简单说就是去掉了右边数字小键盘的87键布局。别小看这砍掉的这一块区域，对于桌面空间捉襟见肘的打工人或者学生党来说，这简直是“救命稻草”。没有了小键盘，鼠标右移的空间瞬间大了一圈，玩游戏时鼠标甩起来更自在，码字时肩膀也能更舒展地正对屏幕，人体工学这块算是拿捏到位了。

当然，买樱桃买的是什么？就是那颗轴。

这把键盘提供了黑、红、青、茶四大金刚轴体可选。对于咱们这种平时既要搬砖码字，晚上还要开黑打两把游戏的“万金油”用户来说，茶轴（Brown Switch）绝对是首选中的首选。它不像青轴那样敲起来噼里啪啦像在机关枪扫射，也不像红轴那样直上直下软绵绵没反馈。茶轴有着微妙的段落感，手指按下那一刻的确认感，就像咬了一口夹心巧克力，既有力度又不生硬，完美平衡了办公的静谧需求和游戏的触发快感。

这时候肯定有人要杠了：“都二手了，这键盘不会已经被上一任主人敲烂了吧？”

朋友们，这就是机械键盘和薄膜键盘最大的区别，也是为什么我们要死磕“樱桃原厂”的原因。樱桃 MX 轴体的理论寿命高达5000万次按压。这是什么概念？假设你是个狂热的文字工作者，每天疯狂敲击1万次键盘，这轴体也能陪你稳稳当当走上十三四年。就算这前任主人是个重度网瘾少年，每天没日没夜地蹂躏它，只要电路板没进水，剩下的寿命大概率也足够你再战个三年五载。机械结构的耐用性，真的不是吹出来的。

再来说说这89元的“含金量”。

卖家倒是实在，把底裤都亮出来了：这批货，实打实的二手老将。主要分为无背光和背光两个版本。这俩的区别简单说就是，晚上关了灯敲字，背光版能让你键盘发光，无背光版你得摸黑或者开台灯。不过说实话，对于咱们这种老手来说，无背光反而更有一种复古的纯粹感，盲打才是技术的象征。

成色方面，卖家也没藏着掖着，直接标注“有使用痕迹”。这你就得做好心理准备了：键帽打油是跑不了的，也就是那种常被人手指接触的键位，表面涂层磨掉了，摸上去光溜溜的，像包了一层浆；边框上没准还有几道岁月的划痕。卖家承诺的是“全键无暗病”，也就是每一个按键都能正常触发，没有连击、失灵这种硬伤，测试过后才发货。

我觉得吧，如果你单纯是想花一个国产薄膜键盘的钱，体验一下真正的机械轴手感，或者给备用机凑一套靠谱的装备，那89元买个樱桃原厂轴，这性价比简直是闭着眼冲。但如果你是那种“成色警察”，连指甲盖大小的划痕都不能忍，那咱也没必要纠结，出门左转加钱买新的，毕竟二手这东西，颜值基本得看缘分，如果你能把它当作一种“岁月的包浆”，那越用越香。

回过头来看这把樱桃 MX Board 1.0，当年它上市的时候，绝对算得上是中端价位键盘的守门员。那时候它没有花里胡哨的RGB灯效，也没有三模无线连接，但它靠着那块扎实的铝合金底板和原厂精挑轴的加持，一度被各大论坛吹成“办公游戏两不误”的神器。

如今在国产卷王键盘疯狂内卷的围攻下，现在的键盘又是热插拔又是Gasket结构，确实显得这把老樱桃有点“老腊肉”的气质，外观复古得像个上个世纪的办公设备。但你要知道，有些东西是不会过时的，那就是手感和品控。那种厚实的敲击感和德国原厂的严谨调校，依然在线。尤其对于那些预算有限，只有一张红票子（100元），却又不想碰那些不知名国产轴体，只想体验纯正原厂轴的用户来说，这把二手价直接砍到脚脖子的键盘，真的是还要啥自行车？

这时候可能又有小白要问了：“几十块买个二手键盘，会不会用两天就报废，到时候键盘没按坏我先气死了？”

这键盘虽然老了点，但樱桃轴的耐造程度，堪比“996打工人坚不可摧的意志力”。机械结构的物理特性决定了它的稳定性，只要没有人为的暴力拆解或者泼咖啡进水这种意外，全键触发测试过的键盘，日常用基本稳如老狗。不过这里也给大家一个建议：收到货后，哪怕急着打游戏，也先别急着上号，找个在线键盘测试网站，把键盘上的每一个键都按一遍，走一遍流程。发现问题立马退！别拖！这是二手交易的自我修养。

至于“选哪种轴体不容易踩雷？”这个问题，新手如果怕麻烦，听我的直接闭眼入茶轴。它有着最接近薄膜键盘的轻柔，又有着机械轴的确认感，兼顾了手感和安静，最适合在宿舍或者办公室这种公共场合使用。

如果你是个寂寞的独居党，或者就爱那种噼里啪啦的机械仪式感，那青轴绝对能让你起飞。但请务必小心，这种噪音分贝在深夜的宿舍里，不仅吵得室友睡不着，甚至可能导致你被室友拉黑，甚至引发物理冲突（别问我是怎么知道的，问就是年轻不懂事）。
