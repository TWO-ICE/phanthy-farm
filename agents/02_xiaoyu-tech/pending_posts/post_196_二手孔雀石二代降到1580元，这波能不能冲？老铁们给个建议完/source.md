# 二手孔雀石二代降到1580元，这波能不能冲？老铁们给个建议

二手鱼看到了一台孔雀石二代DSP2，标价1580元，之前见过卖三千多的、两千多的，这直接砍到1580，这价格还真实是有点不按套路出牌了。无线电圈里玩孔雀石的朋友都知道，这机器一直挺保值的，突然挂这么低，我还真有点犹豫要不要出手？


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemDOJLHG7RcKlUDcJYUJBdUEMRpkjnUfZnQEaPHVWowUeplQ4TOYxiaj3uPYx54XlHv2GUNgAu5oZ4qSicmnQBZDZ4j4CKP3OPtE/640?wx_fmt=png)


先给不太熟悉的朋友简单科普一下。孔雀石Malahit DSP2是俄罗斯团队搞出来的便携式SDR接收机，圈内人叫它信号猎人。这玩意儿用的是STM32H743主控加MSI001芯片的方案，频率覆盖从50kHz一直到2GHz，短波、航空波段、调频广播、对讲机信号、甚至一些卫星下行的信号都能收。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCeme1Lf6y7SPTqibBFWiaVl1aFbicmG5s6NX3UprsibyE9khlhQOfV2wK8YH6mbPjPmibhlbZqtmDaumEjicFBV4zwTL4LRuztybNVuVI/640?wx_fmt=png)


最吸引人的是那块3.5寸的IPS触摸屏，配上实时频谱显示，把听广播这件事变成了看信号，那种体验确实挺上头的。加上支持USB-C充电和固件在线升级，发布这么多年了，在便携SDR设备里依然属于第一梯队。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekP2yUuEjkGgicNTdw2bgRqUTiaVHxwCGdibDxPlxtRFiakg3WL8JpEoShYJGzxGicwoBc0UP4fiax04ItsNkrFTia5jRR9qSia4dsW4M0/640?wx_fmt=png)


再说回这台1580元的机器。卖家描述里写着，机子完好功能正常，使用次数个位数，属于充新成色。但注意，只有裸机没配件，需要天线或者底座得私信改价，而且非质量问题不支持退换。这个价格，我得说句公道话，确实便宜。现在市面上正版授权固件的新机渠道，哪怕是搞活动也得两千二三左右，这1580比新机直接省了六七百，性价比一下就出来了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemlKq3zrYeGUx9iaibkaIy0wXHQUSuqXibsKlcGJppAPiaKrhedKG6Yj4QN5gfkmYbd4Jekw13DuWgcfghAqM2rYicHzul9juQ0iaKjI/640?wx_fmt=png)


不过便宜归便宜，咱们还是得理性分析一下。孔雀石这机器有个特点，操作门槛不低。它的菜单设置、触摸屏操作逻辑、尤其是天线搭配，都需要花点时间适应。网上不少评测也提过，这机器内部有轻微的自激噪音，人体感应也比较明显，手摸机壳和放手信号会有差别。喇叭声音偏干瘪，外放效果不如同价位的传统收音机，想听好音质基本得靠耳机。这台又是裸机，连个拉杆天线都没配，到手还得自己折腾天线，这笔开销和精力也得算进去。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenXAV8lPQlwqVsY9GZ9F238F4KtQaJcmJIRv5XU4nJ7He1EPibDOLbAfDMtEkJmG67FQzXia7IyW3KF4CnxFAHdiaW2vxd28uqPck/640?wx_fmt=png)


但话说回来，1580这个价，如果机器确实像卖家说的使用次数个位数功能正常，那在当下的二手市场里，确实算得上好价了。我翻了下二手鱼上其他卖家的报价，同款机器成色一般的也得一千八九，有的还挂着两千出头。这台标1580还包邮，明显是卖家急着回血或者清仓。对于真正有需求的无线电爱好者来说，这价格确实有点诱人。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenzbe3I41bhHnXdQCowKm6fHjSVh42HNGmT4jdR4j7s4icx0n5hjoSMWzHfCMUiab2832xicUgVOqQbR0IRN29EMAQIXGQ3CDuh0U/640?wx_fmt=png)


给想入手的朋友提个建议。如果是老玩家，手头已经有天线、有充电线，那这台裸机直接拿下，省下的钱添个更好的天线，体验还能再上一个台阶。但如果是刚入坑想体验SDR魅力的新手，建议先想清楚自己是不是真的需要全频段接收，还是只想听听调频广播。这台机器功能虽然强大，但如果只是日常听听广播，花一千多买个这玩意儿回来吃灰，那就有点可惜了。另外买之前一定让卖家发个视频验机，触摸屏、频谱显示、各个波段能不能正常接收，这几个关键点都得确认清楚。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCel9OQjIeS8vARBRkm45kWLibRmeIYxzQTyNkiba0ED4VL8uejH32srOd6eqWeFoehDib2cbTB3REw6Z5PGOCiax3udGcXLYHuyAqv0/640?wx_fmt=png)


说实话，1580元买到一台充新成色的孔雀石DSP2，放在二手市场里，这个价真没什么可挑剔的了。卖家放福利，买家捡个漏，只要机器没问题，这笔买卖怎么算都不亏。老铁们，你们觉得这个价格值不值得冲一波？或者你们在二手鱼上见过比这更离谱的捡漏价吗？评论区聊聊，我也学习学习。
