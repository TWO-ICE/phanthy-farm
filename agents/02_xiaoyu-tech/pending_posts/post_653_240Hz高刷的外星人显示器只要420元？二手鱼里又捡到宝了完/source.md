# 240Hz高刷的外星人显示器只要420元？二手鱼里又捡到宝了？

当年卖三四千块的戴尔外星人电竞显示器，现在二手鱼里只要420块就能拿下。型号是戴尔外星人 AW2518H，24寸，1080P分辨率，240Hz刷新率。这参数放现在，除了分辨率，其他都不过时。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelYKBl3uFHb1XLyXHvxxZQzejyJEPpYBovXXWl7thj7tju8OWYbDJROhX8u2uq4CsuxibMQCE3l4wyic5P3haOnIibSCM68Mffllo/640?wx_fmt=png)


但注意，这显示器是TN面板。懂行的都知道，TN屏响应速度快，拖影控制是顶级的，但色彩和可视角度是硬伤。如果你主要打CS2、瓦罗兰特这种竞技游戏，那它就是神器。如果你要修图、看电影，效果可能就没那么牛B了，卖家说RGB色深，听听就好，别当真。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemmE4QSQLQtNqOPdpMeaibEBZwJP8Xc9NI19fhYMBkVBV0ewJIOODyiaLVtwxTGgibTodW60l0ABnOibkvKJAQNhG8CgwN7SQ0ypF4/640?wx_fmt=png)


再看看卖家描述。屏幕正常，无坏点，无维修。接口有HDMI和DP，够用了。成色有点使用痕迹，这个价格就别奢望充新了。卖家还特意说同城自提优先，为什么这么说，因为这东西的运费可不便宜。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenEJW5SjP8vLAMFhb638klxFAK4WOzXh2vYia2fKqicEIE8ibju8YIcRgEiaVB9k4ual7vTKdFicXUkibiaoffWa8Cvo5msbu54VXOVIc/640?wx_fmt=png)


据我所外星人的东西没一个是轻量级的，尤其是这台显示器，做工扎实，加上底座，毛估至少得七八公斤。卖家说顺丰到付，这意味着运费你得自己扛。从外地发过来，保价加包装，运费少说五六十，420加上运费，成本直奔500了。这时候你就要想了，五百多买个1080P的显示器，还值不值？


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemmp87xWWmGdlBJE75uURGSK9SUyP4kyHo7iaeibFX4enE7icgVPJfSAvpQQbyu35gpWGtNxbM6mHZNJDxiaKHzOMc3eFjlYYNtlhA/640?wx_fmt=png)


另外，420块这个价位差不多可以买到二线品牌的144Hz IPS屏，或者一线品牌的60Hz 4K屏。外星人强在品牌信仰和那个240Hz的超高刷，但弱在屏幕素质和色彩。如果你是FPS的死忠粉，就图那240Hz的极致响应，或者是外星人品牌的粉丝，想低成本搞一套全家桶那这台显示器还是值得出手的。但如果你是普通用户，主要用来办公看视频，那就别凑热闹了，这钱花得冤枉。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenZaO8ouR2Co2zKFJQFccaGhXL93ibuBqk2BI7K9psrK76eqSHOvcSzBQ8Xdsqonmyn46wkv0RqnqmCLpXol3Yia5aLhmvoibwiapU/640?wx_fmt=png)


还有一点要注意，这显示器没有内置音箱，接口也只有HDMI和DP。你想接PS5或者Switch，得自己配音响或者用耳机。另外240Hz对显卡要求不低，你得确保你的显卡能跑满240帧，不然那高刷就浪费了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemavI9VpmTJJ4MvdTYSBoZZEXBC3y2nnTcLc8MjYJLIiaSp65ynkDeM03RyZra8Ddn0UoNrrxjBTEiarbWX7IUPsu52icXnicv5qa4/640?wx_fmt=png)
