# 预算抠搜还乱捡垃圾？这款300多的工控机主板也许是你的菜

![封面图](https://mmbiz.qpic.cn/mmbiz_jpg/E9h3abOJCekRdxTib9ndicuZ130dQopzLVFg9pdKFXglFPriahM7icDmywxUQDZYVaYFdvsdWV5nGD2Wqpkxc92mMpS47Kiciahcibk8XU5RPcVRyQ/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/YAYzv-lwzz6tDcrXCMLmOQ

还在纠结N100迷你主机？老铁们，快我在二手鱼里发现了一块喊价366元包邮的i5 8250u工控ITX主板，这价格，是不是有点逼急了清库存那味儿了？


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemHS8nb62KZrag36Llga1DH9nda6rW51YjzEa8XTrIGyh4Hia5yMqhv68No0thhH9uREr7KibnWsCZsvakgdjskOXuRcpbzGYLJY/640?wx_fmt=png)


先别急着划走，我们掰开揉碎了看看。这是一块ITX规格的工控板，核心是i5 8250u，四核八线程的笔记本CPU。卖家直接亮出参数对比：性能超N100、N5105，甚至比i3 8100t还强。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCem87UsQJeHgoaQRUC3R7qE6GKCAV0XB1SemroNGk51KSXggpvEkcGZqWPTCXTTQ8aiazcu6NXtEanbJvsVzWnjsFNN6LCn79aoE/640?wx_fmt=png)


这话有没有水分？从纯CPU多核性能来看，8250u打打这些新一代低功耗赛扬、奔腾，还真不是吹牛。UHD620核显，应付日常解码、做个亮机卡完全没问题。双DDR4内存插槽，1个SATA，1个Msata，还留了个MINIPCIE接口给你扩展无线网卡或者其他玩意。供电是DC 12V，找个3A以上的电源适配器就能点亮。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelib0qV8wKPDW8pe5zRBLKYWibicVGOY8Kqxg7QoGOJgx19iaWIbl5W5p3Oxb2FYC0X6Cftk8PB2tXItZmqdXsX0EPCvoyCM5q48fU/640?wx_fmt=png)


最关键的是，卖家说是全新未上机的库存货，还包点亮测试拍视频。这就有意思了，等于是用“垃圾价”买了个“库存新板”，性价比这块，瞬间就拉起来了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekRYSL8OtBpox5tNU6O4icQyNSvDpT3UxriaBhEeCy0UCkDKzdjd33vrFVlibiaRNMmGdGfQcwOSxP06pSPJWia8lEzs5NAS5TGfR1w/640?wx_fmt=png)


但是，咱们“垃圾佬”捡宝，讲究的就是一个心明眼亮。这板子优势明显，短板也突出。首先，拓展性是硬伤。就一个SATA口，你想堆很多硬盘就得靠那个MINIPCIE转接，这又增加了成本和折腾难度。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenDQeH7YB93YAbev0m8OfS0dgb1UroS6VGjL4hRzGfXnwgcJVSfxdxrk5OiaSvq77TXaM9bw6Gd4CtvFA6VhYcHyvtrTggxLLwY/640?wx_fmt=png)


其次，它只是个“主板”，你需要自备内存、硬盘、电源，甚至一个合适的壳子。卖家图里那种多盘位NAS机箱，或者去二手鱼淘个DIY的3D打印外壳，都是解决方案，但这都是额外的预算和精力。最后，它的功耗和发热，肯定比纯被动散热的N100方案要高一些。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelTUo6FiblFlaYmbkvwOJq4a3sSYt6UrzEj1lJ6nSxB7iaR25DgMJ7ULMtiabkRzEnG0RS6ePV2VStlZII9yTMU4Y4Rmagvphh7sk/640?wx_fmt=png)


我觉得对于那些想 DIY 一台小型 NAS，或者对 J4125、N5105 之类性能有点疑虑的朋友特别适合，8250u 的四核八线程，做家庭影音服务器、跑跑轻量 docker 服务，性能储备会从容很多，毕竟 ITX 板型可塑性很强。366 元买一个这样的核心，剩下的按需搭配，整体预算可能比品牌迷你主机还是划算。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemibFCrGnRLcU2e1L4JqrngPDNKGvfMuBsOicR6OtLKuSJxjiaBDR7EUiauzeia9xSwrIehcutDut8T9XG0TuTF6kicsNibarwZwurNG0/640?wx_fmt=png)


如果你有三百多预算，是会选择这种需要动手的“性能老将”，还是加钱上省心的全新低功耗迷你主机呢？评论区里聊聊你的想法，或者分享你的魔改方案，给其他老哥指条明路！
