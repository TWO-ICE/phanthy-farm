# 惠普雷电3扩展坞跌至59元，二手鱼卖家这是要清仓跑路？

刚刷到惠普这个雷电3扩展坞，59到129元就能拿下全套。这批货现在大量流入二手市场，价格直接被砸穿。卖家写了支持M1到M4芯片的MacBook，Windows笔记本更是即插即用，接口非常丰富，4个USB3.0、VGA、千兆网口、两个DP、两个雷电3，还能反向60W供电。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelZaVuAeG84gZP8oTg5GMycToHCXyWicRDo9ibYsxJy2JC3W6GKibQbhbmg5aoXvvfxhiakWOPuKualsG4mhZMBKCj6t2RT6MfXtP4/640?wx_fmt=png)


129元那档给的是全套配件，包括扩展坞本体、90W电源适配器、电源线，还送一根雷电4线。59元的可能只有裸机或者缺配件，具体要看清楚描述。成色8到9新，外观有划痕磕碰，但功能正常，卖家说测试好发货。这种价格就别指望完美成色了，能用就行。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCeksy9WHiadRtibVYkS3OyGWSRgk1lnR0ns5CGZXGQAk7qDOiaTiatOVS8gNiaeseGUP4QibTJ2wyn0ujWgSENzErUwnn73o4HBccFqU8/640?wx_fmt=png)


这玩意儿适合用MacBook但接口不够的人，苹果笔记本本来就接口少，插个U盘都要转接，这个扩展坞直接让你体验什么叫接口自由。其次是Windows轻薄本用户，现在的笔记本越做越薄，USB-A口都快绝迹了，这个扩展坞能让你继续用老设备。还有搞双屏办公的，两个DP口够你接两台显示器。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCek39TtRhxDB22Tfia9ibuv0jqYWfYDgaPfYdKG3Oic8FDUbkqVmCK6h4CjicTEGtMhyO2KwbN1uJiaFyMo5mH53jDdXBNWep499BSibY/640?wx_fmt=png)


但有几个坑必须说清楚。第一，苹果电脑只支持扩展一个屏幕，不管你接几个显示器，Mac上只能多出一个屏，这是苹果系统限制，不是扩展坞的问题。第二，英特尔芯片的旧款Mac需要破解才能用，卖家说可以联系指导，但如果你不懂技术建议直接绕道。第三，雷电3毕竟是老标准，现在看速度确实不如雷电4和5，但对普通人来说完全够用，除非你天天传超大文件。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekwcrK2DL3Ab1pF8yKeWsUuiauCndbS432l3RKgysD17rpZpnSrVianV2zb4ckuss4S615rBediaJvfKiaExQ98Zy4YczamhCR81gQ/640?wx_fmt=png)


最低59能买到一个带60W反向供电的雷电3扩展坞，接口齐全，品牌可靠。同价位的USB-C扩展坞很多连供电都没有，接口还没这个多。如果说预算紧张到极致，又需要多接口办公，这玩意儿确实是个好选择。但如果追求完美成色或者最新标准，那就别碰了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekHS5WYyia17B8fwaQ9YP3qH0Gg9goFQAvpp5ePQUlvlT3EDqkgBFfrPibCjia3hBibP9Ax0icqqXO9tL7tlhWYibpR7HfHTWIv3hBoI/640?wx_fmt=png)
