# 原装木壳换成了透明亚克力，195元的锐角云主机还值得入手吗？

今天在二手鱼刷到一个挺有意思的主机，卖家195元包邮出锐角云微型主机，不过外壳被改成了DIY亚克力透明版。带原装电源，说是到手就能开机。那么这种改装的小主机到底值不值得冲？一起来看看吧！


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekLEAS6UxBCToE6mpAljPNbWUWVfLLAXDA7kiaicFfkUT16rbexPbQmMJYwlQWMiaJ7WNRjawh55xN8tCQF25UmAoBVKROyEbCib3g/640?wx_fmt=png&from=appmsg&watermark=1&tp=webp)


原版的锐角云主机其实是个三角形木制外壳，放桌面上像个小摆件，很有艺术感。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemeob1eN41NKDmrdvkxRRHEbzqr4kkiajxFyoQ4FvIiafqgpMpHuP2AwJ6OSekiaCMHnsA0LZZP6auiaemo7iacq8oTxse0Nd23uONY/640?wx_fmt=png&from=appmsg&watermark=1&tp=webp)


卖家应该是嫌散热不好，把主板拆出来，自己3D打印了一个透明的梯形亚克力外壳，接口位置都留得挺准。这种操作在二手鱼里不少见，有人觉得改了更有科技感，有人嫌破坏了原来的味道。不过透明壳确实方便看清内部电路板，散热理论上比封闭木壳要好一点。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekuTxrAxukzbqYib6IjX6MaS4u4Iau677dtcHIhkMh1YSiauVnGsHOYfuWapXW06vxVkVCE8b4VhC8p1PDR4IibsuJUJprBTC9sPs/640?wx_fmt=png&from=appmsg&watermark=1&tp=webp)


板载的Intel N3450处理器，8G内存加64G emmc硬盘。别看参数不起眼，接口给得相当全：三个USB3.0、千兆网口、千兆Wi-Fi、蓝牙全都有。它自带一个NGFF 2242规格的M.2接口，位置够大，实测能直接插2280长度的固态。重点是功耗超低，整机满载也就6W左右。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekXXvgDwuY6j2A6M7SAohGrkTGW37XCticEp8P6icVWoOf9xuAZvZkbF75Ins8gWLCv0CvFvfFFTteyjhdBCkmVQ5nAibWE395Kw0/640?wx_fmt=png&from=appmsg&watermark=1&tp=webp)


性能上N3450比J1800、J1900强出一截，单核多核都领先不少。拿它做单臂路由跑满千兆带宽完全没问题。最香的是系统兼容性，OpenWrt软路由、飞牛NAS、PVE虚拟机、甚至Win10都能装。8G内存跑PVE开两三个轻量级虚拟机绰绰有余。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekSITjEnKCqbKibqictMPCnGW7cmKgtYuhTYNgmDyncVUnmrrYBPwJg7SkQ6IAO3ydyce4Nlx1CPQf0KEsRfeItiaUezubCjPiaibwU/640?wx_fmt=png&from=appmsg&watermark=1&tp=webp)


很多人都会拿这类电脑刷飞牛，N3450的功耗控制加上三个USB3.0接口，外接两块移动硬盘做家用备份服务器很合适。飞牛系统本身对这类低功耗平台优化不错，照片备份、文件共享、Docker跑个小服务都够用。但你得接受一个现实，64G emmc装完系统剩不下多少空间，最好把那根M.2接口利用起来，插个256G或者512G的固态当数据盘。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCema9Jjj52BBmpt6PoHTmPcO3mRshibc5qGr7aE3V6Mb8UiaDweeB1sqgz8s1mLIEEV7EoLo2Fa2gOcYQhAWzFlTbYhGIFyYzOBOc/640?wx_fmt=png&from=appmsg&watermark=1&tp=webp)


如果不刷飞牛，这台小主机也适合做软路由。OpenWrt系统跑起来稳如老狗，千兆网口做单臂或者加个USB转网口都能满速，科学上网插件挂上就是一台硬路由没法比的体验。或者也可以选择做轻量级Windows远程机，挂个QQ微信、远程桌面连公司电脑，或者当个下载机挂PT都能跑起来。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelCL2aR6HAXqzD7L3Ny2SFAgkQibjK0ZZoMzDia0bqH79uzQJsY8nq6RJenHALPXOEThGt2p4AVW6BwSdxFV31L5oG3vvgWB4Fp0/640?wx_fmt=png&from=appmsg&watermark=1&tp=webp)


当然这机器也有不足的地方，64G emmc硬盘读写速度一般，大概150MB每秒左右，装完系统别指望往里头塞大文件。卖家虽然说到手即用，但建议你自己加一块M.2固态，NGFF 2242不太好买，2280尺寸得看能不能固定住。还有，注意亚克力外壳的散热开孔不够多，夏天如果长时间高负载可能会降频。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemTLqq458HWoialLFTpzicKVMWoMA6ELqD0y2zHxqzmg899Ze8aqdn45o904efzaebKuwxnAeFPMQyxj7O9Rgs9AWsTjzm3AlDJA/640?wx_fmt=png&from=appmsg&watermark=1&tp=webp)


目前二手鱼上原装的锐角云主机也非常多，成色好点的价格基本在240元左右，这款改装过了便宜了将近50块，缺点就是没有了艺术加持的外壳，感觉少了灵魂，说白了就是不好看，但优点是散热好了，显然卖家也是冲着实用性去的。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekZhFkgGxDwT8p6zPu0H9PNQoHibeQFvNKIX0WVLicHeSuwjOdVumA6cWibwWcfOBJYmYgIx3U8FCdqOO11Licc0ez2eq0eWSup6lI/640?wx_fmt=png&from=appmsg&watermark=1&tp=webp)


你们觉得这种DIY外壳的改装货值不值？你会为了便宜几十块接受非原装壳吗？还是宁愿多花45块买个完整木壳版？留言区说说你的看法，顺便聊聊你用N3450都折腾过哪些系统。
