# 昔日跑宽带的边角料，现在变成159元的飞牛圣体，接盘侠在哪？

在闲鱼的“捡漏”江湖里混久了，你会惊讶地发现，电子垃圾的归属地永远充满了魔幻现实主义。

最近在“海鲜市场”刷到了一个颇为引人注目的 listing：一台标价 159 元的飞牛（FN）主机。这玩意儿的面相我太熟悉了，不就是前两年大街小巷、运营商铺天盖地送的那个“跑宽带”的边缘计算盒子吗？那时候这东西是用来换取你家中闲置带宽的“矿机”，如今摇身一变，成了卖家口中的“飞牛圣体”。

卖家的文案写得倒是很有诱惑力：六核 A311D 处理器，4GB 内存加持，8GB 存储起步，最关键的是居然能塞进去三块 2.5 英寸的硬盘。卖家还信誓旦旦地保证配件齐全、无拆无修，系统都已经刷好，通电即用，甚至特意强调了一句——“绝不是矿渣”。这 159 元的定价，放在如今的 NAS 市场里，简直像是在做慈善，但咱们得扒开皮看看瓤，这到底是真香还是陷阱。

先来看看这颗心脏。A311D 这颗芯片，在当年的机顶盒江湖里，那绝对是 Amlogic（晶晨）的旗舰级 SoC，是妥妥的“高端货”。

如果你对数码硬件有一点点记忆，应该记得 2019 年这东西配置有多豪华。它采用了台积电的 12nm 工艺制程，在那个 ARM 架构还在发热和性能之间疯狂试探的年代，这个工艺意味着不错的能效比。核心配置更是生猛：四颗 Cortex-A73 大核，主频飙到 2.2GHz，加上两颗 Cortex-A53 小核跑在 1.8GHz。这是什么概念？A73 可是 ARM 那一代高性能架构的代表作，比电视盒子里常见的 A53 强了不止一个身位。更别提它还集成了一个算力达到 5.0 TOPS 的 NPU（神经网络处理器）。

当年玩板子的圈子都知道，大名鼎鼎的 Khadas VIM3 开发板用的就是这颗芯，那时候一块板子光裸板就要卖上千块，硬核玩家拿来跑跑轻量级 AI、做点家庭自动化，那是信仰之选。而现在，随着技术的快速迭代，这颗曾经的旗舰身价暴跌，如今被塞进这种塑料壳子里卖 159 元，感觉就像是用白菜价买到了当年的“官窑”，如果不考虑它可能经历过的“劳改”生涯，这性价比简直有点不真实。

再看这身“骨架”。这小盒子的扩展性确实有点东西。能塞三块 2.5 英寸硬盘，对于这样一个体积的设备来说，空间利用率简直堪比“东京出租屋”。这意味着你可以组一个 RAID 1 阵列，或者单纯拿来扩容，存储空间一下子就从可怜的 eMMC 变成了 TB 级别。千兆网口也没缺席，这是做 NAS 的及格线，毕竟现在谁家还没个几百兆的光纤，要是百兆网口那这机器直接可以扔垃圾站。

4GB 内存跑飞牛 OS（FN OS）基本上是稳的。飞牛这个系统虽然看着界面花哨，底层其实也是 Linux 的一套变体，对资源的需求不像群晖那么夸张，最低 2GB 内存就能勉强溜起来，4GB 则算是个比较甜点的配置。而且卖家宣称已经刷好了飞牛 ARM 版，省去了用户自己折腾 USB 线刷、短接跳线的痛苦，这对于很多只想插电即用的“懒人”来说，确实省去了不少门槛。

但是，作为一名理性的科技消费者，你必须透过这些诱人的参数，看清这台机器的“前世今生”。

卖家说这机器是“个人自用”，只跑了两三个月，很新。这话你得反着听，或者至少打五折听。这机器的真实身份，大概率就是这两年泛滥成灾的 PCDN（P2P CDN）业务淘汰设备，俗称“带宽盒子”或者“算力盒子”。前两年，这类业务野蛮生长，运营商为了降低 CDN 成本，向用户低价甚至免费投放这种盒子，利用用户家里的空闲宽带上传流量。

为什么会有这么多成色不错的“洋垃圾”流出？因为现在运营商对 PCDN 的打击力度越来越大了。特别是在山东、河南、江苏等宽带大省，运营商查得极严，一旦检测到你的上传流量异常或者长时间高位占用，直接就是停机或者封号。很多原本挂机赚电费的用户被迫“退坑”，导致大量设备被抛售到二手市场。卖家嘴里的“只跑两三个月”，很可能是“业务刚跑起来就被查封了”，或者是“矿难”之后洗出来的。

这种 PCDN 设备有个通病，就是它们在服役期间，通常是 24 小时满负载运行的。硬盘读写频繁，主板供电长期处于高压状态，虽然电子元器件不一定马上会挂，但寿命损耗肯定比你看个电视盒子要大得多。这也是为什么卖家极力撇清“矿渣”关系的原因，因为“矿渣”意味着高风险、低寿命。

除了寿命隐患，这台机器的短板也很明显，别指望它能当全能服务器。

首先是 4GB 内存。虽然跑系统够了，但如果你想在这个上面开十几个 Docker 容器，跑个 Jellyfin 电影服务器，再挂个 Home Assistant 智能家居，数据库一跑起来，内存分分钟见红。在服务器领域，4GB 真的是仅仅够用，完全没有“富裕”可言。

其次是那 8GB 的 eMMC 存储。这玩意儿装个系统就能占去一大半，剩下的空间装个 Docker 镜像或者日志一写，马上就爆仓。所以买这机器，必须得配硬盘，没硬盘它就是个刷了系统的机顶盒，当不了 NAS。而且 eMMC 的寿命和速度都远不如 SSD，把系统盘挂在这里，一旦挂了，机器就成砖了。

最让人头疼的，还是 ARM 平台的软肋。在玩 NAS 和服务器的圈子里，x86 架构才是真正的王道，软件生态丰富度极高。而 ARM 平台虽然性能上来了，但在软件兼容性上始终差了一口气。很多 Docker 镜像只提供 amd64（x86）版本，你需要找专门适配 arm64 的版本，甚至有时候需要自己编译代码。对于新手来说，这过程可能会让你学到很多 Linux 知识，也会让你掉很多头发。你想刷个 Windows？没门。你想装个特殊的虚拟机？困难重重。这东西注定只能玩玩 ARM 生态圈内的东西。

那么，这台 159 元的“飞牛圣体”到底值不值得入手？

这完全取决于你的需求定位。如果你正好缺一台低功耗的下载机，或者是用来做轻量级 NAS 存点照片、电影，这价位能买到六核 A311D 加上 4G 内存，客观地说，是真香的。哪怕是单纯拿来做个家庭媒体播放器，刷个 Android 或者 CoreELEC，这芯片的视频解码能力也是秒杀市面上几十块钱的杂牌盒子。

我们不妨做个横向对比。当年的“神机”斐讯 N1，现在二手都要卖到 80 到 130 元了。N1 那是四核 A53，性能已经有点捉急，只能勉强应付现在的轻量化服务。你再加几十块钱，就能拿到这台 A73 大核加持、性能高出一大截、还带硬盘位的机器。在电子产品价格普遍通胀的今天，这种算力贬值带来的红利，对于折腾党来说，绝对是值得入手的玩具。

至于“接盘侠”这个说法，其实也不必太介怀。电子产品本来就是消耗品，只要它能在你手里发挥余热，把废热的宽带变成你私有的数据仓库，这就不算接盘，算资源回收利用。如果你打算把它当成生产力的主力机，或者指望它跑复杂的业务，那大概率会失望；但如果你只是想花一顿火锅的钱，体验一下私有云的乐趣，这台曾经的“跑宽带边缘货”，或许真能在你机柜里焕发第二春。

还是那个老问题，面对这台 159 元的 OES（Off-Excess Stock，过剩库存）或者“矿渣”，你心里的秤怎么称？是拿它当家庭数据中心起步，还是当软路由过渡，或者干脆刷个安卓当个顶格电视盒子？
