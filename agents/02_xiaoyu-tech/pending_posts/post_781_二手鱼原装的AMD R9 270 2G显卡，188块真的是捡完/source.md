# 二手鱼原装的AMD R9 270 2G显卡，188块真的是捡漏价吗？

![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEibZuplW9qYKWAicjezfy6yjxqdw9Jib5bf5cOrLjyibL2qvhrFkPpXwOAhT0zYYapAnwFHJLBGHPtOw/640?wx_fmt=png)


今天在二手鱼刷到了AMD R9 270 2G显卡，标价188元，写的是原箱原卡，单6pin供电，接口齐全（HDMI+DP+DVI），支持多屏输出。页面显示“3万多人在线吃瓜”，先别急着下单，咱得冷静点。这卡确实是库存原装货，卖家强调“不讲价、一个起包邮”，看起来挺实在。但问题来了：2025年了，一张十年前的老卡，188元到底算不算白菜价？


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEibZuplW9qYKWAicjezfy6yjGTjpicj5nmEEJMQ0hlRWyGiaNmribQOUGHzLPcAgy8D7QfP1ZuIlXicIZQ/640?wx_fmt=png)


查了下参数：R9 270是AMD在2013年推出的中端显卡，基于GCN 1.0架构，2GB GDDR5显存，256bit位宽，TDP约150W，建议搭配400W以上电源。性能大致对标GTX 660 Ti，略强于GTX 580，但明显弱于GTX 1050——后者现在二手价也就200出头。也就是说，你花188元买到的，是一张比入门级新卡还老、功耗还高的“古董”。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEibZuplW9qYKWAicjezfy6yjE3Vr9fPzUhJiarzGLeiaSxfnSIzibVYuCogRaibP4aicXqWL7LVOJTL28xw/640?wx_fmt=png)


优点当然有：接口全、驱动成熟、即插即用，不像某些矿卡或魔改卡需要折腾；玩《英雄联盟》《CS2》《DNF》这类轻量网游完全够用，办公、看4K视频也无压力。如果你只是接个副屏、跑个CAD或者当HTPC主机，它确实比GT 1030这类亮机卡香一点。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEibZuplW9qYKWAicjezfy6yjLzvkxooXc43mvDv30StPYDiaZGwBmMueibddhjHicrlARK7Kf9dRibOIaA/640?wx_fmt=png)


但缺点也很扎眼。首先，150W功耗对小电源主机很不友好，你家要是只有300W电源，根本带不动。其次，2GB显存放在2025年已经捉襟见肘——连Win11系统都开始吃显存了，更别说开个Chrome再挂个微信。再者，这张卡不支持DX12 Ultimate，很多新游戏连最低画质都跑不了，更别提光追、FSR这些现代特性了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEibZuplW9qYKWAicjezfy6yj6jCUHiaDz3WMjz0IErZcpCuH3qoZEYaicZyibFG9VOOegIbmk2OteVEjw/640?wx_fmt=png)


最关键的是价格。翻了下最近一个月二手鱼行情，成色一般的R9 270普遍成交价在80-120元之间，带箱说全新的能到150元顶天了。188元这个数，说实话有点“情怀税”了。除非你特别迷信“原装原箱库存新”，否则真没必要多花这几十块。 


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEibZuplW9qYKWAicjezfy6yjJSNgs6ib8JUGYrJAflOiah9KcicVLHRNCSnE1MhiaFm97GXADsC77K3k6g/640?wx_fmt=png&from=appmsg)

看完觉得有用？评论区聊聊你最近在二手鱼淘到过哪些“看似捡漏实则踩雷”的玩意儿？一起避坑！最后给几点建议：

1. 办公用可考虑，但别超120元。

2. 游戏玩家绕道，1050二手更值。

3. 电源低于400W的主机别碰。

4. 看完不买，立省188元。
