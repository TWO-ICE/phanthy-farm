# 670元的5G手机还带IP69防水，外卖小哥：这才是备用机该有的样子

这两天在二手鱼里翻到了一台有意思的机子：OPPO A5 5G，8+128G的配置，卖家报价670元。这价格别说买新机了，就是去实体店也买不来一个像样的手机，但人家还带5G，最关键的是，卖家描述里写了一个很多旗舰机都没有的本事：IP69级防水。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCen8pTBT9Sr1lSdwmPNsO4t0woxoh4qadjK54w2XrCOHYAw1ZMO9hULaiaRicAxUmA7Rj4E7cdKEVK4ibJN8gpOPsl9OxPicPZia2jnQ/640?wx_fmt=png)


先说说这机子的参数，处理器用的第一代骁龙 6，日常刷抖音、回微信、开导航完全够用，屏幕是6.67英寸的LCD，支持120Hz刷新率，阳光下峰值亮度能到1000尼特，户外看清没问题。电池给到了6500毫安时，配合这颗低功耗芯片，续航非常顶，重度用一天绰绰有余。充电还是45W的快充，虽然不是百瓦快充，但在670元这个价位段算良心了。后置5000万主摄，前置800万，扫码水平，别对拍照抱期待。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekniaGUdrouOE4qVkQdDaKh8ZyTVWvaxic4Sic2LTQ2ZQP85tamkGYPcOg0AeDdhwfDhJvMaaU7ybaGf0H4xSPe6BicgC4eLibc5Mmo/640?wx_fmt=png)


重点说说这个防水。卖家写的是IP69，普通的IP68能防泡水，但IP69能扛高温高压喷水，通俗点说，就是你能拿着它对着水龙头冲，甚至扔进洗衣机里滚一圈，它都未必有事。这种防护等级通常是给三防机或者特种设备用的，出现在一台670块的手机身上，确实有点不讲武德。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCek2lGdbh19epLUUSpXoTwDYrPZ6Td5Gfb0ZNA0IzCEMibWWVjQqVrKiacJRMEr9vyxcNsIo72bQhg9259At1ethE1EicdgSRJ7kB8/640?wx_fmt=png)


二手鱼里这个卖家描述挺实在：手机在保，除了充电口磕碰，其他基本99新，功能全好，还发了360验机。670元包顺丰，能小刀。而这个价位在二手鱼里，大概能买到成色一般的红米Note系列，或者配置更低的老旗舰。那些机子要么没防水，要么续航拉胯。这台A5 5G的核心优势很明确：6000毫安大电池、耐造、有5G，防水至少不弱。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenOicB7pJdrP7SHAnEAEUVTrQJAZibeVcVIRTA49lVkag7iaZmB2BaNjgR6ISmwkPR5kyBmsKibbOvWibkSWRTguc7N81DuMgoC8GzI/640?wx_fmt=png)


如果你是外卖员、快递小哥、经常跑工地的、或者家里有老人需要一台不怕摔不怕水的备用机，那这台机子很对你的路。你可以把它挂在车把上，下雨不用收，出汗不用擦，脏了直接水洗。6000毫安的电池，送一天单都不用充电。8+128G给老人用，装微信抖音完全够。但如果你想拿来当主力机天天打游戏、对拍照有要求，那劝你绕道。这机子就是一个偏科生，偏偏在续航和防护上下了功夫。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekYu6iaBBqmib7nLmM2rsqVF2AIxwpKGNoYsMAtk0zF7gWR1qu6CvgEGRHCyubxdokRtSJ4JialdFlenCLBcE68YD2v3JIib22cqhs/640?wx_fmt=png)


从行情看，670元这个价在二手鱼里属于合理区间。卖家在保且过了360验机，对不太懂二手手机的人来说是个很好的保障。你要是想下手，建议砍到600-650之间。下单前记得让卖家拍好视频，还有再问一下磕碰的位置有没有影响防水胶。这两点搞明白了，基本不会翻车。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCeljPHrKAkHCOlyOoEAWMvRGJ7jVSpNJZu0icibjZxbfNWibkCxiauQ2hpYZMicxMTEGgWwKraI8y0gU9OGmGjYpl6NsrPT38CQk3etE/640?wx_fmt=png)


其实现在二手鱼里这种偏科的机子越来越多，很多人开始理性捡垃圾，不再一味追求参数，而是看自己到底需要什么。像这种670块还带6000毫安大电池和防水的手机，放在两年前你敢想？你会为了这个续航和防护，放弃性能和其他体验吗？或者你有在二手鱼里淘到过什么偏科的宝藏手机？评论区聊聊，我看看谁比我更会捡。
