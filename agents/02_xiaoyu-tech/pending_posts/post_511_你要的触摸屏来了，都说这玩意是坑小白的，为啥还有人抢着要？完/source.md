# 你要的触摸屏来了，都说这玩意是坑小白的，为啥还有人抢着要？

![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelRvRu1xib5iaib10RwShAXQicmOtr2Ye4dJibUib4F2D9RV9MRhGKf9nLFnuibGZszuUOtowFibulaLmkRZolesuc8pp2sxU08iaCbMMiaI/640?wx_fmt=png)


最近二手鱼上突然冒出来一大批10寸的工控触摸屏，价格直接杀到了99块，有些打包卖的甚至更便宜。这东西一出来，垃圾佬们肯定会分成两派，一派喊着真香，说这是DIY神器；另一派直接开喷，说买这玩意儿回来就是电子垃圾，纯属浪费钱。那这99块钱的触摸屏，到底是个什么来头？咱们今天就来好好盘一盘。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenMb04aNQiaXMZn6Pm49Ojficl7VCabPZYZds5vR3lZYR3xZDib9PEIhGiaw9HbdmxibJQT6QBRMGiayyAfytibQAj32e7YypibO0k58DA/640?wx_fmt=png)


10寸的屏幕，1280x800的分辨率，这个清晰度放在现在看，确实不算高，但对于一个99块钱的屏幕来说，你还能要求啥？关键是它还带触控功能，而且是USB的，插上Windows电脑就能用，不用装驱动，即插即玩。这可比那些只有显示功能的屏幕有意思多了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCeliaVKQsOaka23b9XiawQrwFLKczcHXiaZNI2lYEsDO3bTx6HJdAqvbQQwtOEVxNia4bEZq8njBeyTV08HEGMWmLq9FfMGFeqCiaTib8/640?wx_fmt=png)


不过，我得实话实说，这屏幕的接口有点“复古”，它用的是VGA。这放在十年前是标配，但现在你随便找个电脑看看，笔记本早就把VGA接口给“优化”掉了，很多台式机的主板上也只有一个HDMI和一个DP口。如果你想在家用它，大概率还得花十几块钱买个HDMI转VGA的转换器。这算是它目前最大的一个坎儿，也是很多人劝退的理由。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenH71zTK6VibXTVy9LnicOI5P89sEgQ1wnotUqmicPCv8UNOtWeiboX5icmdveyE9a9iaSz3baoYmP9uFDCIaK7AsSeMcLXHeSOvmQZA/640?wx_fmt=png)


所以，这99块钱的触摸屏，到底能干嘛？如果你指望它当电脑的主力副屏，用来修图、剪视频，那我劝你趁早打消这个念头。它的色彩、亮度和响应速度，跟现在的便携屏没法比，那个确实不太合适。但是，如果你换个思路，它的用处就大了去了。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenDDYibeXbEMSeXibUbKdofpyD3o5V3RnojCTQtoGcSSlqmcuElD5GnfcuVCyzupdwxAdakcwBOsOp55F2VZn6STaUOUC1xRscBw/640?wx_fmt=png)


比如，你可以把它当成一个专用的监控屏。家里装个监控摄像头，专门拿这个屏幕挂在墙上或者放在桌上，实时显示画面，还不占地方。或者，你是个喜欢捣鼓树莓派、NAS的爱好者，把它当成一个专属的状态监视器，实时显示CPU温度、网络流量这些信息，那逼格一下就上来了。再比如，你家里开了个小打印店，或者有个专门放服务器的角落，用它来当临时的操作显示终端，完美胜任。甚至，你手头有个吃灰的老主机，想偶尔开机看看电影，那花99块钱给它配个屏幕，也比把它扔了强。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemTD0ibZiafZhOP3ATAEKF75A6xCIPj20ibs7fcyXzGH1w01xibLQvJR6YvUgBRibwM7JZqAQudWffxt8ljXatfYXqPAk8ialO4CvbZE/640?wx_fmt=png)


如果是我的话，我不会拿它当日常屏幕用，而是会琢磨着把它改造成一个智能家居的控制面板。把屏幕嵌入到墙里，连上一个便宜的迷你主机，就可以控制全家的灯光、空调。这99块钱花下去，买到的不只是一个屏幕，更是一个充满无限可能的玩具。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekM0vlSZchFJNRichqsm4lIyUZFNvjr9CN0oBG4LmJ297z1C6v0Bkgickq2dxGjPIMtya4G1JGUT8lsK2x1HCOWYTvicVfqWxFbFM/640?wx_fmt=png)


那么问题来了，如果你在二手鱼上看到这种99块钱的触摸屏，你会考虑买回来折腾一下吗？还是觉得这玩意儿就是浪费钱的智商税？咱们评论区里好好聊聊。
