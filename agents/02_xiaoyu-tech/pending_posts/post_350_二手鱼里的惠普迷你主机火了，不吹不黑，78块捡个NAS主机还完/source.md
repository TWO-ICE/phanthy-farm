# 二手鱼里的惠普迷你主机火了，不吹不黑，78块捡个NAS主机还是挺划算的

![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHaSMuSeyias3Puv67gGrRds18ID4EWW3XMtmbvic8HSoLyEOrjy6BKibynBTXw3GCDZhOxNOKY2dBPQ/640?wx_fmt=png)


今天在二手鱼刷到了一台标价78元的飞牛NAS小主机，机器是惠普T420迷你电脑改装的，还带飞牛系统，这个价格说实在的是挺便宜的，再往下翻，发现人家清清楚楚写着“非偏远包邮”“到货即用”“9成新”，硬盘盒和WiFi网卡都要的话，再加16块，总共不到一百块就能整一套？


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHaSMuSeyias3Puv67gGrRds5ogIGvq4a8aXE8aRRwQcYNXPgBzc731PDC4KFtltuRTEdZYKjxloYw/640?wx_fmt=png)


先说说这机器的底子：原身是惠普T420商用迷你主机，搭载AMD GX-209JA双核处理器，主频1.5GHz，属于低功耗嵌入式U，板载2GB内存（焊死不能换），8GB USB 3.0接口的固态当系统盘（可自行更换）。千兆有线网口、中文BIOS、支持通电自启和定时开机，整机功耗才5瓦，静音运行，尺寸也就一本字典大小。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHaSMuSeyias3Puv67gGrRdsfib6EGHEEicc3aZWGV4e02lmnnrAkPQIlEjsPgS3GYFbIdY2V7RdsmCg/640?wx_fmt=png)


卖家说还特意录了视频，演示飞牛系统跑相册备份、文件上传、4K蓝光视频播放——35GB的片子进度条随便拖不卡顿。考虑到这配置，属实有点超出预期。毕竟飞牛系统本身对硬件要求不高，主打轻量、本地化、离线可用，这种老商务机改NAS确实算“废物利用”的典范。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHaSMuSeyias3Puv67gGrRdsk3CJUTiaWlMAwuicjPSteuj7B3w8c0f2DdAsvebZ4oOOZ7I4daMSMGIw/640?wx_fmt=png)


可能有人会问2G内存+8G存储，现在还能干啥？别指望它跑Windows了，但做个家庭NAS用来照片备份、电影库、下载机完全够用。尤其如果你家有旧移动硬盘，插上去直接变私有云，比某些百元智能盒子还稳。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHaSMuSeyias3Puv67gGrRdsw1QByIrbluF6cVOPd4k10WZGK3x85DWic0ic8LZ4ufr79PyRUzITYbPg/640?wx_fmt=png)


那么78元到底贵不贵？查了下2025年行情，同款裸机（无系统、无配件）在二手市场普遍要100–130元，还得自己折腾系统。而这位卖家不仅预装了飞牛系统（省去刷机风险），还送电源（虽非原装但实测可用）、配好启动设置，甚至附赠使用视频——这服务意识，快赶上某东自营了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHaSMuSeyias3Puv67gGrRds1aB13KYAaar1L3u3Br6f4B8icFibNKlsyIR0U7mviapXWRlibkN8qGYGkQ/640?wx_fmt=png)


当然，也得泼点冷水：2G内存确实是硬伤，未来飞牛系统若升级，可能会吃紧；8G系统盘也偏小，建议到手立刻换64G以上的USB SSD（现在32G U盘都十几块，成本不高）。另外，AMD GX-209JA性能有限，别想着转码4K HDR或者多人并发访问，它更适合“单人轻度用”。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHaSMuSeyias3Puv67gGrRdsf9BVW2sLFlDIa18vyPW8XWY2ZOCyw5MTE5ibibElISxcnYbZvbrHSib0Q/640?wx_fmt=png)


值得提一句，最近飞牛社区里不少人拿T420这类老迷你机玩“白菜价NAS”，相关帖子点赞挺高。有人调侃：“这U跑得比我家路由器还安静，电费一年省出两杯奶茶。”还有人算账：78块+10块WiFi+6块硬盘盒+30块64G U盘=124元，搞定一个能自动备份手机照片的私有云——“这个价格还要啥自行车？”


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHaSMuSeyias3Puv67gGrRdsfqbFzCDJIdHLW1eBV17ZRRdnTnWFibpc4zUw3lrow6RCiaicf3BBS6r3g/640?wx_fmt=png)


不过，理性点说，如果你已经有一台闲置的老爷机或N1盒子，那这台未必值得入手；但要是你正想低成本试水NAS，又不想折腾刷机、驱动、网络设置，那这台“开箱即用”的飞牛小主机，确实是个省心选项。尤其对学生党、租房族、或者只想给爸妈搭个照片备份设备的人来说，性价比还行，价格也挺白菜。


 


以下是个人一些掺了水的建议：

1. 别指望它高性能，但日常轻NAS任务足够。

2. 到手务必换大点的系统盘，8G太局促。

3. 若已有类似设备，不必重复上车。

4. 看完不买，立省78元。
