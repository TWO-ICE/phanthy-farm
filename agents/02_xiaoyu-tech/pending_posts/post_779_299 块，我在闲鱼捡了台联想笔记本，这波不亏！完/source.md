# 299 块，我在闲鱼捡了台联想笔记本，这波不亏！

本来想在闲鱼蹲个百元备用机，给我妹上网课用，结果手滑刷到个联想 lenove 300e 2nd gen windows 版，标价居然是299 元，我第一反应：这不是骗子吧？毕竟这型号二手价正常得五六百，299 也太离谱了，纯属偶然刷到，没忍住点进去问了句，居然真不是套路！


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHwgI60hp0CibvF4FTuicicAzJyAzlfpXvB0XSibPoNO9Rja4jztuP3dDibJQR8hZOObXoOdEKqWWf4ESg/640?wx_fmt=png)


先说这机子的屏幕和便携性。11.6 英寸的屏，比我巴掌大点儿，拿在手里也就两斤出头，我妹背着书包带学校完全不沉。不过分辨率是 1366×768，现在看确实有点糙，凑近看字儿边缘会有点模糊，这是唯一让我吐槽的点；但优势也明显，屏幕亮度够，阴天在教室也能看清，而且是雾面屏，不反光，上网课久了眼睛也不酸，这点比很多廉价平板强。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHwgI60hp0CibvF4FTuicicAzJHU71oYR1WfgjBAWk2ia0zzYFNOTwMl9JVn8jR6NLtaugQXwwyrKibjaw/640?wx_fmt=png)


再唠唠配置，毕竟是 Windows 本，配置才是关键。**Intel奔腾5030**的处理器、**4G内存**，这配置在今天看来确实有点寒酸。不过说实话，比我预想的要好多了。自带的**128G板载存储**确实小了点儿，但好在还有个**NVMe插槽**！我翻箱倒柜找了条闲置的256G NVMe固态硬盘插上去，瞬间感觉这机器能再战三年。

![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHwgI60hp0CibvF4FTuicicAzJttVwibdORGibIkR21mQ2byJ9xXwqz2iaPUc2XmgPiaeRmwsiavCe0wB2TSg/640?wx_fmt=png)


续航卖家说满电大概 4-5 小时，我拿到手实测，连续上网课 3 小时还剩 20% 电，够用一上午；要是光看视频，撑 5 小时没问题，对学生党太友好了。接口也挺全，两个 USB-A 口，能插 U 盘和鼠标，还有个 HDMI 口，以后想接显示器看课件也方便 —— 不过缺点是没有原装充电头，卖家只给了根线，我又花 15 块买了个兼容充电器，算下来 333，还是血赚。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHwgI60hp0CibvF4FTuicicAzJ5fibmhOxvQ9FibnchGczDqtGrvfd9OuasHfslEpClmC2ovgqdicoxxNFQ/640?wx_fmt=png)


我查了下资料，这款联想300e 2nd Gen当年可是面向教育市场的高端产品，坚固耐用是它的卖点，**当初发售价要三千多**呢！如今却在闲鱼上以299的价格流浪，想想也挺唏嘘的。

![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHwgI60hp0CibvF4FTuicicAzJJibRDyuN7sIg3pGh9ayt8jLMkA1O1TqyKJ4fibGJ3CZ76GtMkIoQpiaFg/640?wx_fmt=png&from=appmsg)


**花299****买到这样一台笔记本，我个人觉得是血赚的**。它当然不能和你手里几千上万的新款笔记本比，但**对于只需要处理文档、上网课、看视频的基础用户来说，绝对够用了**。现在这本已经寄到我妹手里了，除了外壳有个小划痕，其他跟新的没啥区别。家人们你们有没有在闲鱼捡漏的神操作？有没有比 299 更低价的 Windows 本？评论区聊聊，让我也吸吸你们的欧气！
