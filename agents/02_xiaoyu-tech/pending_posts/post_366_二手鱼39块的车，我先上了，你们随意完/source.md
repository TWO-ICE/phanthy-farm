# 二手鱼39块的车，我先上了，你们随意

下午刷二手鱼，看到一个小可爱，一个能显示天气、时间，还能看股票行情的桌面小电视，标价39？包邮，还送根充电线。东西很有意思，可以有很多的桌面主题可以切换，带氛围灯，可玩性也非常多。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekhHWicl18Nd6ibGl9A64beHkKgibl0jpuxJr6MialxLsruWNlgIgjLKjib0jBUxYmmUCtfF4iaibAmuSBjhhCEb2HbZDP0qxdQFYyKtc/640?wx_fmt=png)


这东西什么来头？其实就是前两年在DIY圈子里特别火的“太空人小电视”，一个开源的WiFi时钟项目。那时候自己买零件焊一个，成本也得大几十，要是找人代组装的成品，随随便便就上百了。现在倒好，成品直接跌到一包烟钱的价位了。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemCEMoepWZsjA4JZvMk2icGTBh11HFWdicic4jiaJFWuO25icrF2Lrl9o9cWDu69M1Y4upXnQkVyOia217SEkOzwDF8gIqHCf5RZwFmE/640?wx_fmt=png)


配置的是1.54寸IPS屏幕，240*240的分辨率，显示效果在这个体积下绝对够细腻。用的芯片是CH340C，支持自己刷固件玩，可玩性很高。功能上，触摸按键，天气、时钟、多表盘切换、倒计时、闹钟这些基础功能都有，最骚的是还能自定义三个股票代码实时看行情，对于股民来说，放电脑旁边瞄一眼挺方便。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCek2IbGUMsINdHcjTu5ACnMWwkVoryOI31Wf6Kk9sfg6ydvFoibPKvibY4DA1GP1Eb2WJpg3AbIDkKt9mcH6HiasC9daIgsHicef0vk/640?wx_fmt=png)


外壳有两种，便宜的是3D打印的，半透明，能看见里面的电路板，很有赛博朋克那味儿。但卖家也提前说了，打印的会有层纹和Z缝小瑕疵，完美主义者慎入。贵一点的（其实也就贵个十几块）是注塑外壳，颜色多，质感好，没那些打印痕迹。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekq8icbhyZKWFEibafhNxQGYIaw07Df3pUJXHtbudA6icQRficZkQNB40hjhdUnetG5OUuWfqvSSC6ZMgncxjib6hBFVQ7WMA0E4KgU/640?wx_fmt=png)


但我要开始说但是了。

第一，这东西必须联网才能用，而且只支持2.4G WiFi。不支持5G，不支持需要网页认证的校园网，最关键的是，卖家特别标注了不支持华硕路由器。我用的是华硕，看到这心里咯噔一下，虽然不知道具体是哪个固件有冲突，但这对于华硕用户来说就是个坑，得先问问清楚再下手。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCen0zsiao1QWchdH859Xr1krTfibSvJZCPfb4x3Evd81OxB3csJLTicFrcWN2IaAosTa8fvFVgFVUbJ5HJeUqdQan5w9dqkTKuicZPg/640?wx_fmt=png)


第二，虽然功能多，但它本质上就是一个网络信息显示器。它不能装App，不能当真正的屏幕用，所有的快乐都建立在网络稳定和服务器正常的基础上。哪天服务挂了或者固件出问题，它就是个精致的电子相框，一直循环播放默认表盘。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenMUDyuic3HaaMx2G6tgdytgYIkQg6JdhWEyxz09A2icNljNbuibgF0aKUibCEQRTibaFuLeSsaQ0Y0baDPwjgre7VIoPJ05kvwWqss/640?wx_fmt=png)


第三，这玩意儿是DIY产品，不是大厂流水线下来的。卖家用的贴片机，元器件也是正经渠道买的，质量有保障。但它没有3C认证，没有华丽的包装，售后全看卖家个人。买它，本质上是在为玩家的兴趣和手艺买单。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekjhAGH3QwjicvjK1a8lw1ENF7VJgl13VEIQM0GUkOasNWHKxMtqTtCINABIiaIom0pPK27iaMVpWjJ3YVaibSpfrhz0Cod4s90eQQ/640?wx_fmt=png)


所以我的建议是，如果你是垃圾佬，喜欢折腾，手头刚好有个闲置的充电头，那39块钱买个玩具回来刷着玩，研究研究开源固件，绝对超值。半透明外壳那种，反而更有味道。最后问一句，你们现在电脑旁边摆的都是什么？有没有玩过这个“小电视”的？评论区聊聊，看看还有多少人在坚持这份小众的快乐。
