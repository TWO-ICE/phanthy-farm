# 45元搞定NAS主板？二手鱼捡漏真能省下大几百

最近在二手鱼刷到一块标价45元的1037U主板，卖家说是ITX规格，17×17厘米，主打低功耗NAS用途。这板子其实不算新东西，是早年工控机里常见的型号，现在大量出现在二手市场，大概率是淘汰下来的库存或拆机件。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEVTOq86LYE2BCjibic8jwadc7tBiav5yryZCywWaKc3dZpOJbuyiaPxScJrh8HxjT9rvkKrOJBBicibx3w/640?wx_fmt=png)


它用的是Intel Celeron 1037U处理器，双核双线程，1.8GHz主频，22纳米工艺，TDP标称17瓦。虽然性能放今天看很弱，但跑个轻量级系统完全够用。尤其飞牛OS对这类老硬件兼容性不错，很多人拿它搭家庭NAS。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEVTOq86LYE2BCjibic8jwadc4hNvP6Mv5X8ib1FUym6SMJdXmJGawJia39dr1iczcngOyOWWCql0iabOOg/640?wx_fmt=png)


主板本身接口挺全。一个DDR3内存插槽，最大支持8GB；两个SATA口，一个mSATA，还有一个Mini PCIe插槽。显示输出有HDMI和VGA各一，四个USB口，一个千兆网口。供电用的是DC或4Pin接口，说明它原本设计就偏向低功耗嵌入式场景。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEVTOq86LYE2BCjibic8jwadcABWnfWg28ThcZZXrsulMPib0ZIEH03Ba1hdqD79v5zPPjNuzKyzV6Eg/640?wx_fmt=png)


机箱选项也多，从单盘位到六盘位都有，支持2.5寸和3.5寸硬盘混装。加厚钢板和铜柱确实比塑料支架耐用，散热和稳定性会好一些。如果自己动手能力强，甚至可以3D打印外壳，把整套做成个性小主机。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEVTOq86LYE2BCjibic8jwadc6QujzGlzYPHdHYgYFaHdYIu6OzsE5lfR64s7tU7sS1e5eIGEptRE5g/640?wx_fmt=png)


那么问题来了，45元到底贵不贵？目前全新入门NAS动辄五六百，而这块板子加上二手内存、固态、电源，整套成本压到100元内是可能的。尤其现在存储产品涨价，这种能复用旧硬盘的方案反而显出性价比。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEVTOq86LYE2BCjibic8jwadcJG2ibzcFicicI5gqzsj5TtwjTiawQcjiaOjr8KzYYHThu1GWZYkCmicMoENA/640?wx_fmt=png)


可能有人会问，1037U性能太弱，会不会卡？实测来看，做下载机、影音服务器、文件共享完全没问题。但别指望跑Docker、虚拟机或多用户高并发，它不是干这个的。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEVTOq86LYE2BCjibic8jwadcSUjBbxibHQANyhoZ3PF5nyiaNhqKZkl8bswZmriaCIoJdePNqnm3bKCSA/640?wx_fmt=png)


也可能担心买到矿渣或暗病板。确实存在风险。45元价格虽低，但得看卖家描述是否清晰、有无通电视频、是否支持验机。如果只图便宜不看成色，翻车概率不小。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEVTOq86LYE2BCjibic8jwadcZYFCT2KSoWsQLDb6sOnrSfBXREB3sPGvyODdMrcSRCGgxtxBSSkbuQ/640?wx_fmt=png)


对此产品有兴趣的话，可以在二手鱼搜索“1037U主板”这个关键字就可以找到此产品。如果找不到可以通过图片进行搜索。都搜索不到的话，那可能是此产品已卖出或者是下架了。


 


以下是个人一些掺了水的建议：

1. 适合轻度NAS用户，别对性能抱太高期待。

2. 务必确认配件兼容性和卖家信誉。

3. 自己有旧硬盘和动手能力更划算。

4. 看完不买，立省45元。
