# 把企业级路由器转为家用，原来这么香—蒲公英X5企业级千兆路由器

![封面图](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXHlFxtcQgrGj21FlMDEOsBLQB2WCNqg9xI2XnP9ws5ibRj0hIaOjHoUJBMsTjDMqhROia3jrPfExrSg/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/KwL5PHVjymoZEqOLjLDgQQ

随着物联网时代的到来，家中需要联网的设备越来越多，很多传统的路由器已经很难承载大量设备的接入，选择一款性能可靠、网络稳定的路由器是非常必要的。

一些聪明的小伙伴已经把目光瞄向了企业级的路由器，相比家用路由器，企业级路由器的性能更强，稳定性也更为可靠。

那么把企业级路由器用在家里是否合适呢？今天小编就带来了一款蒲公英推出的企业级千兆路由器，型号为X5，这款路由器不仅支持千兆的速率和更稳定快捷的WIFI
 6网络，还支持异地组网和外接存储设备，至于这款蒲公英X5企业级千兆路由器的实际体验到底如何？还是一起来看一下吧。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXHlFxtcQgrGj21FlMDEOsBLSaSRGeNBoCI4Um955PYTZSxQQ9bwdF7OYv0M1yugYkHibmia3XDvlTQQ/640?wx_fmt=jpeg)


纯黑色简洁的机身外加4根天线，这就是蒲公英X5路由器给人的第一印象，不追求精美的外观，看上去也朴实无华，这种工业式的风格很符合企业级路由器的定义，而相比市面上那些造型夸张的路由器，我还是喜欢这种中规中矩的小方盒造型，无论是挂在墙上还是放置在桌面上，都非常的美观。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXHlFxtcQgrGj21FlMDEOsBLfoGEAicVibyek4KibvJIgY7AZVPGstZPqa0cERLDThriabz9oXN1CgYGoQ/640?wx_fmt=jpeg)


蒲公英X5作为一款千兆路由器，它并不是那种减配的版本，而是配备了5个网口并且全部为千兆速率的满血版路由器，通过网口的布局可以看出，5个网口中蓝色的网口为wan口，用于网络主线的接入，其余的4个网口为lan口，用于连接局域网设备。这其中的亮点不仅仅是千兆的速率，对于我来说5个千兆网口的配置，正好能够满足我4个有线设备的连接需求，让我省下了购买千兆交换机的费用。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXHlFxtcQgrGj21FlMDEOsBLqGlq9x8gmaWibjLPbZGoyFPMBX5d5W673PRYlZcg69eibKHg5NjyPY9Q/640?wx_fmt=jpeg)


有的伙伴看到路由器只有4根天线可能会感到失望，认为天线越多路由器的无线信号越好，其实这是一个误区，路由器无线信号的好坏，并不是由天线的个数决定的，而是要看dbi功率的大小和穿墙效果的强弱，蒲公英X5作为一款面向企业级的路由器，它配备的4根天线是5dbi的双频高增益全向天线，可以覆盖更大的范围并具有更强更稳定的穿墙效果，对于一般200㎡以下的房子，可以做到全信号覆盖。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXHlFxtcQgrGj21FlMDEOsBLUN0QSkYn2Xmjc4dG7lx8YEh2nNuO6CagbI8BhpR3TyBibQ5XxS6Y3ZQ/640?wx_fmt=jpeg)


在基础配置方面，蒲公英X5搭载了双核的处理器和256M的运行内存，采用了第6代wifi协议，支持2.4G/5G双频并发，无线速率最大可以达到1800Mbps，可同时满足100台终端设备的接入，另外还配备了一个USB 3.0接口，可以外接存储设备和网卡。

相比于蒲公英X5的配置，我更看好的是这个USB 3.0接口，因为通过外接存储设备，可以让路由器摇身一变，变为一个专属于自己的私有云。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXHlFxtcQgrGj21FlMDEOsBL23vmJRpAEblOaWic065TqmciaGiafiauQZk9YYHlohibKA7uuibJqWL11e3A/640?wx_fmt=jpeg)


在初始化配置方面，蒲公英X5与传统路由器的配置方式相差无几，既支持有线连接配置，也支持无线连接配置，通过登陆路由器背面的地址，就可以进入路由器的配置界面，对于我们初级用户来说，只需要配置网络接入方式和设置wifi密码，配置完成后，重启路由器就可以愉快的上网了。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXHlFxtcQgrGj21FlMDEOsBLEBBmC1JGbLsh3FkTYbKXXzqPxFY1EMAzpIHiaDCMLMYfXkDxhSNCzWw/640?wx_fmt=jpeg)


异地组网功能，是蒲公英X5的一大亮点，对于很多公司和企业来说，也是一项刚性的需求，它可以把每个使用蒲公英路由器的用户，无论身处何处，无论是什么样的网络环境，都能够组进同一个局域网内。例如，你的家中和公司都配备了蒲公英路由器，那么通过异地组网功能，就可以把家里的电脑和公司的电脑组进同一网络中，这样就可以实现数据共享和设备共享等功能。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXHlFxtcQgrGj21FlMDEOsBL4BPmMzqMehNA6JtxMUgx3aJ6QkRWUrf8EnKto6pklYMjoJaBhV3edQ/640?wx_fmt=jpeg)


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXHlFxtcQgrGj21FlMDEOsBLyo8AjH02j38CG36EMu1y3ZiaFjIprEdjmZNicAhhWjkibAvaKfjaC8dpA/640?wx_fmt=jpeg)


具体的操作也并不复杂，首先需要打开蒲公英云管理平台进行注册和登陆，之后创建一个网络，这里要说的是，异地组网需要有两台以上的蒲公英路由器才行，只需要把多个设备放在同一个Oray账号下即可，绑定完成之后，通过电脑或是蒲公英云管理平台手机APP可以查看或者管理同一网络下的设备和成员。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXHlFxtcQgrGj21FlMDEOsBLXy2o1dovicaOReGAYia58W9USUYxNCI35sYWn7wW86jfdoiaZhNSHtYrA/640?wx_fmt=jpeg)


前面有说到，蒲公英X5通过外接USB存储设备可以组建私有云，这项功能对于我来说非常的实用，我的手机中还有电脑里有很多的图片和视频，既占用大量的空间又不舍得删除，把这些数据放在私有云中，不仅可以随时查看，还可以随时把手机中的照片上传到私有云中，私有云中的电影，通过智能电视也能随时的观看，完全可以把它作为家庭的数据存储中心，最重要的是，组建这个私有云只需要外挂一块硬盘即可，再无其他费用，相比之下，单独购买NSA则需要上千块的投入。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXHlFxtcQgrGj21FlMDEOsBLqS85qLWsahkK2RPwrPYArornrdSKFFNiaBpibAPAJOch7iaBibxbbXB8jg/640?wx_fmt=jpeg)


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXHlFxtcQgrGj21FlMDEOsBLUuq5WId9IZKOE6skhMU8Rwl4hmUtubicC4bnTYuLV4jUfwicgyA0Qfmg/640?wx_fmt=jpeg)


开启私有云功能的操作同样非常简单，登陆蒲公英云管理平台，找到《应用中心》的界面，开启里面的《文件共享》按钮就完成了，如果你安装了蒲公英云管理平台的手机APP，也可以在APP中进行开启或关闭的操作。设置完成之后，只要你的手机或者电脑安装了蒲公英软件，就可以远程登陆到私有云的磁盘中，进行数据的上传或下载。如果你家中有智能电视，也可以在网络功能中输入路由器的IP地址，这样就可以通过电视直接观看私有云文件夹中的电影了，非常的好用。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXHlFxtcQgrGj21FlMDEOsBLtRrZuJKxKRko7E0cxv9SkzU0mub74581Sib1Az5DoU0sAHVp5iarsD9Q/640?wx_fmt=jpeg)


最后要说的是，除了支持组建私有云之外，蒲公英X5还支持云打印功能，这个功能对于于办公来说，还是有一定需求的，出门在外的时候，遇到紧急情况，可以通过云打印功能，直接把自己电脑中的文件，从公司的打印机打印出来，这一点对于经常外出的伙伴还是非常实用的。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXHlFxtcQgrGj21FlMDEOsBL3tTEC2OrPaHD6pdTaDEF9IbgIYyNssjCjjiclT5NknACWd4MvSaJM5w/640?wx_fmt=jpeg)


使用了一段时间，感觉这款蒲公英X5企业级千兆路由器真的很香，我家不到100㎡的面积，可以做到全屋无死角信号覆盖，并且传输稳定，也没有出现过死机掉线的情况。在速率方面，千兆的速率和wifi
 
6的双频传输，也让我的手机和局域网内设备传输速度直接飞起。异地组网和组建私有云，更是为这款路由器锦上添花，大大增加了路由器的可玩性。如果你还不知道选购什么样的路由器才好，那么我感觉把这款蒲公英X5企业级千兆路由器转为家用，还是非常靠谱的。
