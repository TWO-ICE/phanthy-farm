# 二手鱼299元小主机，性能吊打J4125，扩展性很强还能自己换U

![封面图](https://mmbiz.qpic.cn/sz_mmbiz_jpg/E9h3abOJCenuzeGdrwXoBS4Kia1OE0AQ8VvZ6S9BfUkak96XO1Bm9XfMicVU3la7abhsRSsTrEVg93ucN0bAx85zjgDDyrg4hozV41v6CibfoA/0?wx_fmt=jpeg)

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenAcdE6AxdWstOFRVNRE8toDAedX4M7qCecCiaVLibQFG3UIsW2nWbSibRcsXWWu8dENppicfV1fdMs6EQQhbFwxiaibhbLibXdd2551Q/640?wx_fmt=png)


二手鱼里发现个有意思的小主机，标价299元，核心是英特尔酷睿i5 2540m。双核四线程，睿频能到3.1G。可能有的人会觉得参数比较低，但这得看和谁比。你要是拿它和现在主流的i3比，那肯定是找虐。但如果你把它放在小主机这个圈子里，去和J1900、N3150甚至J4120这些低功耗的兄弟们比，这哥们儿还真能挺起腰杆。性能确实比那些J系列强出一大截，日常办公、刷刷网页，甚至轻度玩玩虚拟机，它还真能扛得住。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekQ0cBh8M4B9pNONOvb52a7HAJ15echxibPGd34wys4epCZcJv9hMB6Wicyoz4Ox0vnBX4u9te5ibleAdtvdJKWI6H2s45V5ZBncE/640?wx_fmt=png)


这机器的可玩性，才是它真正值钱的地方。卖家说CPU是可更换的，这在小主机里算是个稀罕物，以后真要折腾，还能换个更好的。内存只有一个DDR3L插槽，最高能上16G。硬盘接口给得挺全，一个msata，一个标准的SATA，还留了个minipcie口。这接口就很有意思了，你可以用它扩展第二个千兆网口，直接变身软路由；或者加个无线网卡，让它摆脱网线的束缚；甚至可以转接出M.2固态，玩法相当多。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenYAqbnDtrNSoPsricmXCwVGnz26bgjRmoVLqPibx1Pmt5EX5iccicDyu3g4hH55IlHXqztN1U7b6SyGjDgfibsSH5a7H1GlaEMzIgw/640?wx_fmt=png)


外置接口方面，四个USB，一个千兆网口，HDMI和VGA双视频输出，还有个Type-C接口和SD卡槽。这个配置，基本覆盖了家用、工控、NAS的日常需求。20厘米见方的尺寸，放哪儿都不占地方。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelANFRfu4WIYTFLGGZ1vhDeoYPqlurqRRxnkIJTdmrpLiao9ewP7vrzRjUW8smBl5hJ9VmXIjtsOwUzh00H8FwFdfjTrER1SEnw/640?wx_fmt=png)


但这机器也是个老家伙了，主板上的电容、风扇的寿命，都是未知数。卖家也说了，橙色定义为一般，售后不退。这其实就是在提醒你，这玩意儿适合拿来当玩具，当备机，而不是用来当主力机供着的。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekj6SLjVeMicKQtNM8lSiaIhPKiagM0ZrNyg4AQ9TSYpGibgmseNF2eBdqxU5GbLTbiaZGIx7g8YcYiaVghyduFmmiaGSbZ9FKIhM0Ybo/640?wx_fmt=png)


卖家标价299元，给的是主机加电源，配2G内存和32G固态。说实话，这个配置能开机，但体验肯定好不到哪儿去。这其实就是个钓饵，让你觉得门槛很低，但真想用起来，加钱升级是免不了的。比如加35元把内存升到8G，再加80元把硬盘升到256G，这样一套下来，总成本大概在414元。如果还想加个无线网卡，还得再加15元。这么算下来，落地价差不多在430元左右。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelMezjeJV91tJn2x2ibMGd4EfRPhBL2oNVbSZzVngORz6lrsykx8SQCT1wQ7a9gH4QweTXNochoRGUZ2z3MC5NyBPUjkkEDHfeM/640?wx_fmt=png)


如果真要入手，我有两个建议。第一，别买最低配。2G内存和32G固态真的不够看，买回来大概率是扔在那里吃灰。直接选8G内存加256G固态的组合，省心。第二，如果准备拿它当软路由或NAS长期开机，最好自己换个新的散热风扇，老机器的风扇噪音和寿命都是隐患。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelNicWCWxtBsUGTXwMKsAWqFIc4cXSJjwhc7ibCSgXdkticaDwF1J2Zpnj9t8lZYCtoXhe5XqQjVc7APx4vNQ3yfDLsalHgzUic7N0/640?wx_fmt=png)


别把它想得太神，也别把它踩得太低。它就是一台有点意思的老机器，价格摆在这里，给了你足够的动手空间。你要是就想花几百块钱找个能折腾的玩具，或者需要一台功耗不高、又能干点正事的二奶机，那这台可以放进购物车。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelMxF3L9iaXlyND5L3j4UicXOia4W7J6ylLxQEKJ9o2VpC4te0XsBBbUzhpomibLK6tfXrKE5yzkSYsq9jIHEWbZHbXlhpoX0IG8M0/640?wx_fmt=png)


最后问问各位老铁，你觉得这台机器值这个价吗？或者你手里还有哪些更香的捡漏经历，评论区里聊聊，让大家开开眼。
