# 二手鱼里发现稀罕物！米家充气宝只要109元，是真捡漏还是智商税？

![封面图](https://mmbiz.qpic.cn/sz_mmbiz_jpg/E9h3abOJCemGg5xsCLQOtUgjBz6hicRuTA1PCSrOl4mQtuwNzOlkias23KwkOVKSoDC0hlrg1wo9LHW23OiaibQjCOaR18BJIbkxPxBAeibArN0A/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/pqe5ZnLCIBd6LAQGUXn2Jw

二手鱼里看到个米家充气宝2，卖家挂109元还包邮。描述说是拆封试用，官方质保，15天内包换。这价格确实有点东西，要知道这玩意儿首发要199块呢。卖家的文案写得挺实在，还说给米粉的福利，只求给个真实好评。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemPcyOtmgxJkQvk4XStpmESFhwlXSntzwa9cHWr7f5AEltCSwzr2W9wTmbep7ic8aRTb4HLX41DGcRN5iavia5tnLJlMJ6wQ8XSbs/640?wx_fmt=png&watermark=1&tp=webp)


先看参数，米家充气宝2可不是那种路边摊货。采用19mm高精度合金压铸缸体，充气压力可达150psi，比上一代充气速度提升了约25%。就这个参数，把市面上绝大多数便携充气泵都甩开了。支持预设压力充到即停，还有数字胎压检测功能，精度能达到±1psi，这数据比很多专业打气机都靠谱。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekDLfJLibSltbXiacYTWbDac0sKXXHQOfWwqK6lzV9fOsCVERAU8quIoPO1fVpia5RIMmUn9JYtPd3kkgm7Rlz2I38ohOgxhVAxA8/640?wx_fmt=png&watermark=1&tp=webp)


内置2000mAh高倍率锂电池，Type-C接口，满电状态下能连续给10个轮胎补气，或者充满2个完全没气的空轮胎。机身才约490克，随手一揣就能带走。自带LED照明灯，还能切SOS模式，野外应急也能派上用场。公路车、汽车、骑行车都能用，还给了法式气嘴转换头、气针、快接气嘴转换头一套配件，基本所有打气的活儿全包了。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCen3w3A6Tnm1ic0YPMX19r3tg8vgQibGRDmg7yicpQVhtSXlN6fXiaCEq2zKpWJKDlOlFkscFZBy7giaosHhYiaTmlLbPz1iaL0M6Eibq9Y/640?wx_fmt=png&watermark=1&tp=webp)


这玩意儿好在哪儿？ 那就是 无线，摆脱了点烟器的束缚，路边补气、车库维护、甚至给篮球足球充气，拎起来就能用。传统打气筒你得上上下下抽好几十下，累得够呛还看不见气压多少。米家充气宝2设置好气压数值，一键启动，充到指定值自动停机，手指头都不用动一下。两种模式切换也方便，自行车、摩托车、轿车、球类都有预设，不用自己瞎调。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemG7B0VK3Qnmxb4rh0uHIa9Wdys7S48eYzlAfTBzLmpaC5ZTEmmC43Y6lDArCzHIZ71JuqCar4ZAGBAw2OKclOViakYXF50mKFQ/640?wx_fmt=png&watermark=1&tp=webp)


不过二手鱼买东西还是得多长个心眼。卖家 说是仅 拆封试用，部分没有外包装，介意勿拍。 所以 你到手的可能是个别人退换的样品，或者运输过程中包装已经没了的库存货。建议你下单前要求卖家拍对应的机器视频和SN码，确认机身成色，看看有没有明显磕碰、划痕或者使用痕迹。质保方面，卖家承诺官方质保，有质量问题15天内包换，这比很多二手鱼卖家的售出不退要靠谱得多，但最好还是截图留证。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekqb4OF8csmh74OcWxm4VZUz3V4a8OKaqFKmdGDrEEBTFefcMtJ2P9IaMzNt8icfYKeIvPWiaytxwc6LgHPKVswEAqh0A3lCBClE/640?wx_fmt=png&watermark=1&tp=webp)


另外 米家充气宝2用的是锂离子电池，随着使用次数增加，续航肯定会缩水，这个你得有个心理准备。还有些车主表示，其实一年打不了几次气，买回来大部分时间都在吃灰。所以说，如果你经常跑长途或者户外骑行，这东西绝对是刚需；如果只是家用偶尔补一补胎压，先想清楚自己的使用频率再下手。
