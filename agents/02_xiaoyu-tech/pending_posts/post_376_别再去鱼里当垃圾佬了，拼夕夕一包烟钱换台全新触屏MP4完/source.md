# 别再去鱼里当垃圾佬了，拼夕夕一包烟钱换台全新触屏MP4

今天没去二手鱼，去拼夕夕逛了一圈，发现有人在卖支持触控的MP4，想当年省吃俭用几个月，最后花大几百甚至上千块买回来的宝贝疙瘩，那时候上课偷偷藏在袖子管里听歌，晚上躲被窝里看小说，那可是整个青春的硬通货啊！现在拼夕夕上的价格直接给我整破防了，29.8元？这简直就是对当年那些五六百块、千把块的MP4进行降维打击。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCem5X8JgicK0xNw32iaQDBRapTknfkrpAs70Nt3M8ICLhMl12vBdFdwOjNZLlIhWbYAL16aj14p7A6Pu5H2KBm5wI4UrI1ATh0UDk/640?wx_fmt=png&from=appmsg)

点进去一看29.8元的是无屏幕的按键版，支持触屏款的起售价是49.8元，险些被卖家给套路了。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCem85Rxsx0VeFTytWw0A3xcznFwumNLojiaCITX2NicHjGXT83YbmN4YjJaQjYkzdJ1PE55pchmCvIRqsQWiajSDhpq2Dic9jIvy6xU/640?wx_fmt=png&from=appmsg)

产品详情描述得挺花哨，2.4寸的IPS全面屏触摸，虽然不是现在手机那种顶级屏，但想想这个价格，还要啥自行车？重点是，这货功能还挺全乎。支持蓝牙5.2，能连无线耳机，还能插TF卡扩容，默认套餐直接送128G卡，还给你下载好200首歌和1000部小说，到手就能用，这对于预算抠搜又不想瞎折腾的人来说，简直是豁出去了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemtSgYstOibtPbF9RbKAfoT4SKNhmz1AsiahCYDCSgUClHwbib0cChlocsiaS0ttibwNibgF5U6xsdZJ9fWJOniccLbhUDLE5dq2wCpJg/640?wx_fmt=png&from=appmsg)

除了听歌，它还能看视频、看电子书，甚至有个英汉词典带朗读功能。呦西八嘎，家里有学生的，买一个当个纯粹的单词播放器或者录音笔，好像也说得过去。毕竟现在存储产品价格都在涨，这玩意儿还送卡，里外里一算，感觉那张卡都值回一半票价了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemHRgM8Dhsxibd5YrHdFiaHCmTdqlstxPiaLEzPJ0GAhLtrSsdiaibFicNzSGCoDqVagdYxicAdy76dHSd2fgapVica57xwVhOe5pKnusU/640?wx_fmt=png&from=appmsg)

当然，作为一个资深的捡漏侠，咱得说点真话，不能光看优点就冲昏了头。这货主打的就是一个性价比，性能就别指望它能拉胯成啥样了。卖家没写电池容量，这就是个坑小白的盲区。我估摸着，如果单纯听歌，可能能撑个大半天，但你要是又看视频又连蓝牙，估计就得一天两充了。所以，你要是想把它当主力播放器，天天重度使用，那还是趁早歇菜，这明显是个玩具属性大于实用属性的稀罕物。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelvZPKPEt9CPb04a7HctuibWdLg5JuibUriateJSHGqlqgezRNOvzpXxK27ibxjeM7WAKEIo1RBCSddKGf7s1juCdHNT2wTRfOILKA/640?wx_fmt=png&from=appmsg)

另一个得留个心眼的地方是系统。这种廉价播放器，系统优化往往是个玄学。虽然说是触屏，但滑动起来卡不卡，App用着顺不顺，全看运气。所以我的建议是，别把它想象成一个智能设备，就当它是一个能触摸的、功能固定的MP4，心态立马就平和了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemnibMqvz8iaAfMyq5jG9kiaX08T6to4FbByibJPlzicd3gShKPq7Px4dmhgq1mPSjVjTurz7BPo90iaTneSMtMqhJ1qumtJqicia6cfTg/640?wx_fmt=png&from=appmsg)

那么问题来了，这49.8元到底值不值得扔沟里？我觉得得分人。如果你是怀旧党，想买个便宜的小玩意儿，睡觉前听听歌，看看下载好的电子书，找回点当年上学的感觉，那这玩意儿可以果断入手，毕竟49.8元买不了吃亏买不了上当。但如果你是冲着Hifi音质去的，想把它当主力机，那还是加点钱上正经大厂的二手吧，别在这个玩具上浪费感情。
