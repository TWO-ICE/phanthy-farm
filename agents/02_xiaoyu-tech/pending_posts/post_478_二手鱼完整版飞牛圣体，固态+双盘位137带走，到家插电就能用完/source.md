# 二手鱼完整版飞牛圣体，固态+双盘位137带走，到家插电就能用，这个算捡漏吗？

![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGYFCvDCYtzTcGFD9uhrRsHTs1w3Z6FjCdvx0yibBMC8Q2gDdHhJBZUaMeSQmtjpR6psO6YuHI35zQ/640?wx_fmt=png)


群晖这类成品NAS动辄上千，实在下不去手，二手鱼一款标价137元的1037u双盘位小主机，价格还算可以接受，而且不是准系统那种，是完整的飞牛圣体。用这玩意可以搭个家庭私有云，方便备份照片和远程访问文件，但这么便宜会不会是智商税？


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGYFCvDCYtzTcGFD9uhrRsH2IV1Ppib03cAvQGIXeu7g73pXYYv8OaYYmfRCBVLYicWqe2dxic6tvhqg/640?wx_fmt=png)


这款主机搭载的是Intel Celeron 1037U处理器，双核双线程，主频1.8GHz，TDP仅17W，属于典型的低功耗入门级处理器。性能确实谈不上强，但跑个轻量级NAS系统勉强够用。内存是4GB DDR3，搭配一块30GB的mSATA固态硬盘，预装了飞牛NAS系统，界面类似群晖，对新手比较友好。主机本身有两个SATA接口，支持安装两块3.5英寸或2.5英寸硬盘，供电线和数据线都配齐了，插上就能用。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGYFCvDCYtzTcGFD9uhrRsHJ0V0rlK4SBXWG63M9JeZL5GLTHRSxvNlGSlnEXo1iaeZU71OYPYt6zw/640?wx_fmt=png)


机箱尺寸为215mm x 177mm x 90mm，体积小巧，外壳是3D打印的塑料材质，颜色随机发，有黑、白、黄、橙几种可选。散热方面，机箱预留了一个12cm风扇位和四个5cm风扇位，但默认只送一个风扇，额外加装要另付5元。电源是12V4A的外置适配器，整体功耗不高，适合长期开机。不过主板没有HDMI和USB 3.0接口，扩展性受限，而且网口只有百兆，这点显得尤为落后。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGYFCvDCYtzTcGFD9uhrRsHg5iaRPuaqtuWWMp94y3JX0J0Z0BYEmyia3cLYsCERrHTZTSUxltUIdeA/640?wx_fmt=png)


说到百兆网口，这可能是最让人犹豫的地方。如今家里宽带普遍200M起步，百兆网口理论最高传输速度仅12.5MB/s，传个大文件会明显卡顿。虽然卖家提供“升级千兆网口+10元”的选项，但加钱后总价就接近150元了。考虑到存储硬件价格普遍上涨，一块全新的2.5英寸1TB SATA硬盘都要300多元，而这款主机本身配件全是二手，137元的价格看似便宜，但若加上内存、固态、网口等升级，实际成本可能逼近200元，性价比优势就被削弱了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGYFCvDCYtzTcGFD9uhrRsHku5NH9zngPsnIplWMVu3QQvW4rF41HnbhEo7ASEVKb2icibwwU5MoR4w/640?wx_fmt=png)


可能有人会问飞牛稳定吗？能替代群晖吗？飞牛确实在国内NAS圈有一定热度，尤其适合不想折腾黑群晖的小白用户。它支持文件共享、远程访问、自动备份等基础功能，界面简洁，安装也简单。但生态和插件远不如群晖成熟，高级功能比如Docker、虚拟机基本没有，适合轻度使用。如果你只是想把手机照片自动备份到家里硬盘，它够用；但若打算跑下载、媒体库甚至监控录像，1037U的性能和百兆网口就会成为瓶颈。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGYFCvDCYtzTcGFD9uhrRsHryW8apILbu0kyodribSNlbBWibDoxgJxCHo9YLsqX4tYrib80dTudFh7A/640?wx_fmt=png)


那么，这台机器适合谁？如果你预算极低、需求简单、且愿意接受二手硬件的不确定性，那137元或许值得一试。但若你对传输速度、系统稳定性或未来扩展有要求，建议多花点钱看看其他方案。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGYFCvDCYtzTcGFD9uhrRsHIXzT5RseQhgekLecfCyibdtkNzyaodxqYeRpDeLibpibMicffdujibvVSPQ/640?wx_fmt=png)


对此产品有兴趣的话，可以在二手鱼搜索“双盘位nas”这个关键字就可以找到此产品，如果找不到可以通过图片进行搜索，都搜索不到的话，那可能是此产品已卖出或者是下架了。


 


以下是个人一些掺了水的建议：

1. 别指望它能流畅跑多媒体服务。

2. 百兆网口是硬伤，升级前先算总账。

3. 二手硬件无保修，心理预期要放低。

4. 看完不买，立省137元。
