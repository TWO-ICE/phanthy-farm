# 飞牛群晖软路由一机通吃，这台240元的技嘉N3150是不是NAS神机？

![封面图](https://mmbiz.qpic.cn/mmbiz_jpg/E9h3abOJCemaIiaUN1ShdkJdjEAaXWK665ON1rqTBPYdhP1s2BLFYeFfop5vZ8GL83Mlx1Ptut2OKoUh8399ibFaRu98eW1dCeVvgHJroyoFo/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/38TgvON2ol6MJpf_uyFN7g

刚刚在二手鱼里瞎逛，突然刷到一台技嘉的小电脑，卖家标价240元起。CPU是N3150，支持安装飞牛和黑群晖。卖家说N3150是J1900的升级版，四核四线程，最大功耗才6W，日常使用也就3W左右，用来做nas性能够用而且还省电。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCen5Lg1ol0D2QYKmRqXMUlJc8sqMmb8l2z5lgRFrAvkDb4vbN0amKVH8Dd7FzHlrndUvzw81awWvdeXQ4BmbAYBHEDDYs0icluuo/640?wx_fmt=png)


这一点卖家倒是没说错，N3150和上一代J1900对比，功耗差不多从10W降到了6W，一年下来电费能省将近80块钱。核显从4个EU单元直接堆到12个，性能大概是J1900的三倍左右。最狠的是它支持H.265 4K硬解，J1900根本做不到。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenh8MY42YCstZcib4hHwo6UMEUfjO3Zo63ibkOl6CaJm0hOZibJ9NJiayJmyJcDYwF94KsMJ13zS5p2fhk8NeXv8df2QHTmBBdzFjc/640?wx_fmt=png)


不过N3150主频只有1.6GHz，睿频也就2.08GHz，所以它仍然是个弱鸡。但这种低功耗小主机大部分人是拿来当软路由、挂NAS或者做客厅HTPC的，性能低无所谓，核显性能和硬解能力才是关键。它支持硬解4k视频，支持aes指令集，支持vt-x虚拟化功能，这个优势就非常明显了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemJTMSGETrm541X6pazztCVP8tzwp6sOyzO0NMupW46k4RVhXWf5XksElwsgm8f15IcNeTkwfFdwR24QhAnWIDplIPvjcBGX3I/640?wx_fmt=png)


再来看看接口配置。这台技嘉小电脑体积只有11.5*10.5厘米，做工确实扎实。接口方面给了4个USB3.0、HDMI和VGA各一个、千兆网口、SD卡槽，还有个音频口。内置插槽有一个DDR3笔记本内存槽，一个SATA接口可以接2.5寸硬盘，还有一个m.2无线网卡接口。m.2槽除了装无线网卡，还能扩展m.2固态硬盘。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemJrrzIAXa85HvVrCiaVict9QHMHeH2EVXBBLbmCzKrzohRm7oTNgAmiaCQ4ULX3HicWZCUChKfIuXVqJzcS23aia4RfHQRzySVPc9Y/640?wx_fmt=png)


卖家给了好几个套餐选项。标价240元是准系统加电源和2G内存，没硬盘。加装无线网卡加15元，升级到4G内存加25元，8G加60元。加120G固态45元，240G固态加100元。我个人觉得，如果你想刷飞牛或者黑群晖，选2G内存加120G固态的组合最划算，不到300块就能搞定一套NAS系统。如果你打算跑软路由或者轻量办公，建议至少4G内存起步，8G更稳妥。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemk6JazZ7UrO7cAdy9XTVkW3jX1MvG2gtarEyjMNEbS7FGibWhVib28Q6PfIwyUOkL9LUHzdSlW9RFlmVKdKKk9HxFXHT4kXBWmY/640?wx_fmt=png)


这机器我感觉适合想入坑NAS的小白，功耗一年能省不少电费，跑飞牛或者黑群晖做下载机和文件共享绰绰有余。也可以拿来做软路由，N3150跑千兆带宽完全没压力，待机功耗才4到5瓦。还可以作为客厅的HTPC，挂个硬盘放4K视频，配合4个USB3.0插U盘和外置硬盘，舒舒服服。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCem7mePK1ibQSQQIoTfqftIfS7wlfFajI9nt1KHt4bU7vR6Nc1ic9SaHibpxODOt2J9nNE4z5ynZj9bamnziaYu1xO8WG9GRribbjArk/640?wx_fmt=png)


240元能买个能做软路由、NAS、HTPC三合一的迷你主机，还带品牌做工和卖家技术支持，我觉得不算踩坑。不过要记住，这就是个入门级的垃圾佬玩具，别指望它能跑Windows打游戏或者搞大型编译。想清楚自己的需求再下手，别冲动消费。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemYHVWzYLibFMqqdHNKsRr8dHO6o2b8YXXuOAPZfh6e5HID5oBzRELKvBBw11ZXXZ8hh4PGYy3nYYTgqKbgib1n8yPeIXyn4IWmY/640?wx_fmt=png)


老铁们，你们觉得这种240块的N3150小主机值不值得买？有入过同款的来评论区说说体验呗，顺便聊聊你们都在用这种低功耗小主机折腾啥好玩的东西？
