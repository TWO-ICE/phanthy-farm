# 自带电池还配键鼠一体？这台110块的小主机才是二手鱼里的“邪修”

今天在闲鱼上“淘垃圾”的时候，真让我淘到了一件稀罕物。一台标价110块的二手迷你主机，品牌ZXK，最让人摸不着头脑的是它机身上竟然赫然印着Intel的LOGO。这年头，Intel标也不稀奇，但这玩意儿的造型和定价，透着一股浓浓的“不正经”气息。成色标的是99新，卖家拍了几张亮机图，屏幕亮着，功能看着倒是正常的。

说实话，一般人刷到这东西估计直接就划走了，毕竟既不是软路由也不是大众款的NUC。但在我们这些专门捡破烂...哦不，是专门挖掘冷门硬件的玩家眼里，这玩意儿有点意思。稍微去网线云查了一番，这其实是当年大概2021年左右的产物，刚出来的时候身价还挺硬，标价在一千块钱上下。现在才卖110块，基本上是连残值都不剩了，纯粹是卖家想回哪怕一口棺材本的钱。

这东西拿在手里第一感觉就是“轻”，整机也就巴掌大点儿，塑料壳子，摸上去那个手感嘛，虽然不是什么高级复合材料，但模具做工并没有那种山寨作坊的粗糙感，接缝处理得还算过得去。最显眼的就是正面那个大大的“Intel Inside”标识，看着挺唬人。我当时心里就犯嘀咕：这标该不会是卖家自己拿激光打印机贴上去辟邪的吧？

虽然卖家详情页里没敢细写配置，但这台机器的身底还是很透明的。它搭载的那颗U，是Intel Atom Z3735F。听到这个代号，老玩家可能要怀旧了，这是Intel当年著名的“Bay Trail”架构，一颗实打实的老古董。四核四线程，最高主频1.83GHz。这个规格放在当年，也就是勉强能比拼着PPT的赛扬扬眉吐气一下，放到现在，给它装个Windows 10，那你得做好心理准备：它能亮，能进桌面，甚至能让你点开“我的电脑”，但你要是敢在这个基础上想流畅办公？那简直是强人所难，这就好比你指望一辆老头乐在高速公路上飙车一样不现实。

再来看看接口。这方面这台ZXK倒是做得挺大方，HDMI视频输出口、两个标准的USB-A口，甚至还给到了一个Type-C接口（当然，大概率只是USB 2.0信号）、DC电源插孔。基本上你能想到的该有的外设需求，它都给配齐了。这种接口密度，拿来当个下载机的中枢或者给电视做个简单的播放源，是绰绰有余的。

但真正让这台小东西显得“邪门”的，是它的设计思路。这玩意儿居然在机身里塞进了一块7000mAh的锂电池，而且原装还附赠了一个长得像遥控器、其实是键鼠一体的小控制器。你没听错，它不像传统电脑那样必须插电才能用，它本质上更像是一个带HDMI视频输出能力的安卓盒子变种，或者说是把一台Windows平板的主板拆出来塞进了盒子里。不过大家心里也清楚，这机器大概率也是库存货，这电池放了三四年没充过电，估计内部化学物质早就“饿死”甚至鼓包了，能不能激活全看命，但这并不妨碍我们欣赏这种脑洞大开的设计。

说到这机器的硬伤，那也是肉眼可见的痛。内存只有2GB RAM，存储则是32GB的eMMC。要知道，光是装个纯净版的Windows 10系统，再加上虚拟内存和预装占位，这就得干掉一半空间，留给用户的实际可用容量估计连15GB都不到。这年头，稍微大一点的手机游戏动辄几个G，你往这机器里装什么都得精打细算。

图形性能方面，它集成的Intel HD Graphics Gen7（4EU），性能水平大概等同于十年前的低端手机GPU。如果你只是想拿来看看1080P的本地电影，它应该能勉强撑住不卡顿，但你要是想玩点哪怕是《星露谷物语》这种所谓的轻度独立游戏？那我建议你还是做个好梦比较快。至于网络模块，它用的是RTL8723，这可是著名的“螃蟹”卡中低端款，只支持2.4GHz频段的WiFi。在现在这个家家户户都有5G WiFi、穿墙路由器满天飞的环境里，连不上5G也就罢了，但这卡在2.4频段下的抗干扰能力和吞吐量，实在是不敢恭维，网速慢点你得忍着，下载大文件基本别指望。

这时候肯定有极客朋友会跳出来问：“这玩意儿能刷飞牛（FnOS）或者OpenWrt吗？”咱们从理论上分析一下，Atom Z3735F确确实实是x86架构，这比那些ARM架构的路由器刷机要通用得多。但是，很多这种2015年左右的老古董，BIOS默认都是Legacy模式，想启动第三方系统或者PE，经常得卡在引导这一步。而且这种定制板子的BIOS锁得很死，刷个第三方系统稍微不注意，大概率就是直接变砖。不过，如果你只是单纯想当个轻量级的NAS，或者挂个PT下载机，刷个精简版的Armbian或者是纯命令行的Linux倒也未尝不可——前提是你得有一颗不怕折腾、不怕翻车的耐心。

那么，放到闲鱼的大盘子里，这台110块的ZXK到底有没有竞争力呢？咱们横向对比一下。同样的预算，你可以买到J1900或者N3450这种工控小主机，这些虽然也是老家伙，但性能普遍比Z3735F强上一大截，价格通常也就是在150到250元之间晃荡。但是，J1900那种裸板通常是没有电池的，你还得自己配电源，还得找键鼠。而这款ZXK虽然性能在同类里是吊车尾的水平，但它赢在了“集成度”和“配件齐全”。自带电池（虽然可能废了）、自带键鼠，插上电视就能动，这对于想快速搭个临时环境或者给孩子放个动画片的需求来说，简直是“傻瓜式”操作。110块钱，还要啥自行车呢？

所以，我认真梳理了一下，如果你属于以下这四类人，这110块钱或许花得有点意思：

第一，你是那种一天不拆机、不刷BIOS就浑身难受的极客玩家，这玩意儿是个极好的练手玩具，坏了也不心疼；
第二，你是经常跑展会、做路演的销售或者市场人员，有时候需要在酒店电视上投个PPT或者放个宣传片，带个笔记本太沉，这玩意儿往兜里一揣就行；
第三，你是想低成本试水家庭媒体中心的小白用户，想先花几十块钱搞个概念机跑通流程，以后再换好设备；
第四，纯粹就是像我这样，喜欢收藏各种奇奇怪怪、冷门停产迷你主机的数码“拾荒党”。

最后，咱们得把丑话画在前面：千万别指望这玩意儿当你的主力办公机，哪怕是打打字、回回邮件，那卡顿的鼠标指针和慢吞吞的窗口响应都能把你逼疯。但话又说回来，110块钱，买一个能点亮1080P屏幕、能连WiFi、带全套接口的小盒子，哪怕只是当个摆件放在桌上，也是可以接受的。尤其是对比现在二手市场上那些溢价严重的J4125主机，这台ZXK赢的不是性能，而是“新奇”和“邪典”。
