# 移动专供的中兴小主机二手鱼205元包邮，能刷飞牛到底香不香？

![封面图](https://mmbiz.qpic.cn/mmbiz_jpg/E9h3abOJCelMy5zDVtBIBSTnmUhiaVsCUuzAcDS7sbvAicdicWmkicbVf5Ow1vNUrEJMlUyRia1fM8j3A1bo3GgHIVaNcibnhU8EsLzmXoq2kaJ2E/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/y7V4Ad2_2rAZnyRYFGWaPw

二手鱼里刷到一卖家挂出中国移动的小主机，型号是中兴D323，报价205元还包邮。配置是J3355双核处理器，板载3G内存加32G eMMC存储，说是能装飞牛系统或者是部署openclaw。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelBfJliayxCrZ8ZjRk6JhNAkX7lic4F5v85zxlhCU0nQicjPdMbB7gBs7uia8M8p4Lr7N5BuyCdCVFM0E1Pn0AtFIjtMDU5cELs8wA/640?wx_fmt=png)


这款中兴D323搭载的是赛扬J3355处理器，双核双线程，基础频率2.0GHz，最高能睿频到2.5GHz。TDP功耗只有10瓦，配上集成显卡HD Graphics 500，支持4K视频解码。机器三围只有11*12*2.5厘米，比一包抽纸还扁，银白色金属外壳，外观质感确实不输现在几百块的新品。卖家提到的背部M2接口支持SATA协议固态，这在瘦客户端里算是良心配置了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelzq5HvFQicFdkxwzkWLe4Ticia4fxBjM1Z0icOLEmznIKUib2zuMrAjRtiaJf6CxgGNG69NUL1VoSbIxQpGVd7RfkmT5lzYDgHcrGPA/640?wx_fmt=png)


先说说它的亮点在哪，千兆网口加上USB 3.0接口，对于需要24小时开机的玩家来说，这配置完全够用。3G内存虽然看起来寒酸，但跑轻量级飞牛NAS系统绰绰有余，装几个Docker容器挂挂PT下载、备份手机照片，绝对稳。32G的eMMC装完系统还能剩十几G，关键是有M2接口可以自己加硬盘扩容，这个扩展性才是它的核心价值。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelhL5vSJiaku43J8EFic1v9Te7Q64EmNU3gF92JK6OFctFGpdIYsoSa7qibsWXHgYiaDBiaEAYK2vUTmr9xacgsFG0aDhAJKubz5ybQ/640?wx_fmt=png)


槽点是板载内存没法自己升级，这是个硬伤。现在飞牛系统开机后就剩不到1G可用内存，想跑虚拟机或者实时转码就有点吃力了。而且这机器没有无线网卡，只能用有线网络。J3355的性能也就那样，比当年主流的J3455差了接近四核的差距，多开几个应用就会感到卡顿。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekTu0Hk2lzjLg27YsxQwXH5ia4daFcFe88DGle3cfHU2RVqE8g2dSNedsn9UeXaOj0VOeibvndJvKu71cSt8fDFoIJdiajcRCuGmw/640?wx_fmt=png)


如果你手头有闲置的SATA M2固态硬盘，预算又卡得死，买回来刷个飞牛系统当轻量级NAS是完全没问题的。建议跟卖家确认一下M2接口支持的具体协议，别买回来发现只认SATA协议而你准备的是NVMe的硬盘，那就尴尬了。另外，这类淘汰下来的企业云终端数量很大，价格还会继续往下走，不急的话可以再等等。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekr9JMdKngibnVG9Z9SZKEzsuibrY4r6cdxbb1icDS9MnQnMK4SSd6ibabNibdYlE3QbdCCsaiceY7LqUiaMuoUWzoCnPoLr84GPlItia8/640?wx_fmt=png)


这机器我感觉最适合当家庭下载机，功耗低，丢在弱电箱旁边，7*24小时挂着，一年电费也就十几二十块。或者刷个OpenWrt当旁路由，搭配家里的主路由搞搞网络分流。如果你想用它当主力办公电脑或者跑Windows系统，趁早放弃，这个配置跑Windows 10能卡到你怀疑人生。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekrcmW5ic77cDbN38hKKD9yWtY62WoNXEu8KxGrnRFqDHAS3IRypNcjBHIWfw9SJeEI5ib7WHgFGjSssqa9RKwDa07yAQIRrc3qo/640?wx_fmt=png)


跟现在动辄几百上千的N100小主机比，这机器性能确实差了一大截，但价格也确实便宜。你觉得这个价位的J3355小主机适合拿来做什么？是挂PT下载、做软路由，还是纯粹买回来吃灰？评论区聊聊你的看法，让想上车的兄弟少踩点坑。
