# 二手鱼398元可以捡漏N100小主机，3D打印外壳有点孬，但性能在线

在这个固态硬盘涨价比过山车还刺激、显卡价格依然坚挺的尴尬时期，"捡漏"这个词似乎已经从我们的字典里消失了。然而，今天我在那个被称为"闲鱼"的神奇二手市场上，竟然还真让我撞到了一个有点意思的玩意儿——一台只要398元的N100迷你主机。

这价格，放在两年前你可能连像样的主板都买不到，而现在却能抱回一台能点亮的主机。不过，这机器长得确实有点"潦草"。卖家倒是实诚，直接说了这是手搓机箱，用3D打印出来的。看那个图，表面粗糙得就像是还没打磨抛光的腻子，或者说是小孩子随手捏出来的乐高积木，每一层打印纹路都在向你诉说着"我是廉价货"的身世。但话说回来，398元还要什么自行车？隔壁那些贴牌大厂，同样配置的N100小主机，动不动就敢标到四位数，甚至摸到了五位数的高价门槛。相比之下，这个丑萌丑萌的"手搓怪"，反而透着一股贫穷但实用的亲切感。

咱们先别急着嫌弃它的颜值，毕竟搞机圈有一句至理名言："性能即正义，丑陋算个屁"。这台机器的配置单要是拆开来看，其实颇有几分当年硬件发烧友DIY清单的神韵。核心心脏是英特尔最新的N100处理器。这颗U现在可是软路由和NAS圈的当红炸子鸡，Alder Lake-N架构，虽然只有4个核心，但硬是靠超线程技术怼出了8个线程。

最关键的是它的功耗控制得极其变态，TDP（热设计功耗）只有6W，这意味着待机的时候可能还没你家路由器的灯泡费电。你别看它功耗低，性能却比那些还在用老旧赛扬或者J4125处理器的入门级笔记本要猛得多。跑个分也许不是重点，重点是它能稳稳当当跑满睿频。对于这种级别的机器，你要么是用来做个下载机，要么是做个软路由，要么就是接个电视当个轻办公机箱，N100在这些场景下绝对是"精准打击"，性能过剩的同时又不费电。

最让我惊喜的不是CPU，而是它的扩展性。这玩意儿居然设计了双盘位结构，一个M.2接口的NVMe硬盘位，加上一个标准的2.5寸SATA硬盘位。这种布局就像是那种小户型里硬塞了个双开门冰箱，虽然挤，但真能装。这意味着什么？意味着你可以把系统装在极速的NVMe固态硬盘里，然后把电影、照片全塞在便宜大碗的机械硬盘或者SATA SSD里。这对于想搭建低成本NAS（网络存储服务器）的朋友来说，简直是刚需。很多大厂出的同级别迷你主机，为了压缩体积往往只给一个M.2插槽，想存大容量数据？对不起，请去买贵得离谱的成品NAS。

接口方面，卖家倒是也没太吝啬。堆了2个USB 3.0接口和2个USB 2.0接口，虽然不算豪华，但接个鼠标键盘再插个U盘做热备份是绰绰有余了。千兆网口是标配，这对于软路由玩家来说是保命底裤，没有千兆网口的N100就是失去了灵魂的废铁。而且最骚的是，卖家连2.5寸硬盘的供电线都给配好了。懂行的都知道，DIY圈子最烦的就是买回来主板发现缺这根线那根线，还得再去淘宝单买，往往一根线邮费都比线贵。这波操作，就像是你去买奶茶，老板不仅送了吸管，还顺手给你塞了一包纸巾，虽说不值钱，但心里确实暖洋洋的。

但是，咱们既然花了398元，就得做好"一分钱一分货"的心理建设。这台机器的槽点，主要集中在那个3D打印的外壳上。卖家毕竟是手工大神，不是富士康流水线，这外壳的公差控制得确实有点随性。如果你是个强迫症患者，看到那种层纹明显的侧面，或者盖子合不严实的缝隙，可能会抓狂得想拿砂纸去磨平它。而且，这是个"准系统"，也就是说，内存和硬盘你是得自己掏腰包配的。

这里有个隐形陷阱需要给新手提个醒。现在的内存和硬盘价格虽然降了一些，但如果你没有闲配件，硬要单买DDR4笔记本内存和NVMe硬盘，算下来成本可能又要加上两三百。网上总有人调侃说："穷玩车，富玩表，屌丝玩电脑，DIY的快乐就是买完主板再买显卡，买完显卡再买散热器..." 对于这台机器，你得算好一笔账：398元的准系统 + 200元的内存 + 300元的硬盘 = 差不多900元。这个价格能不能买到二手的大品牌成色好一点的迷你主机？有时候还真不好说。

而且，现在的二手市场行情也是风云变幻。之前还有人指望能像拼多多砍价一样砍个对折出来，但在N100这种硬通货面前，想砍价太难了。这颗处理器的出货量和市场需求之间现在有点微妙，有时候比抢微信红包还要难搞到。对比其他平台，这398元的价格确实像是双十一的预售锁低价，但也仅限于"准系统"这个范畴内。

卖家还提供了一个加50块钱选配3.5寸小屏幕的选项。这玩意儿是个状态监控屏，可以显示CPU温度、内存占用之类的信息。值不值？这完全得看你的审美取向和实用主义倾向。对于一个本来就是为了省钱而生的"破烂玩意儿"，多花50元买个显示屏，就像是给五菱宏光贴了个碳纤维贴纸——看着唬人，实际上不增加马力。当然，如果你是把它放在桌面上当个摆件，有个屏幕跳动确实能增加点极客感。要我说，实用主义者不如省下这50块，等下次活动买杯奶茶喝。

关于外壳瑕疵会不会影响使用，答案是非常肯定的：完全不会。这东西又不拿去跑分，外壳丑一点又不影响内部电路板导电。N100这颗U发热量本来就不大，只要机箱留了散热孔，哪怕是用塑料盒装着也能压得住。建议那些想买NAS入门体验的小伙伴，可以去搜搜最近很火的"飞牛圣体"配置，或者是那些专门做软路由的大神店铺。这类手搓机器通常更新换代快得惊人，可能过两个月就有了新款模具，到时候这套模具可能就成绝版了。

现在的二手鱼小主机市场，简直就像是当年的奶茶市场，不仅品牌多，价格战也打得热火朝天。如果你想在这个时间段出手，建议参考以下几条"防坑指南"：

第一，N100处理器目前处于一个价格相对稳定且高性能的状态，别老等它降价。这玩意儿属于"早买早享受"的典型，现在不买，可能半年后不仅要涨价，还没货。

第二，准系统虽好，但要算好配件的预算。别以为398就是全部，很多时候"捡漏"变成了"添坑"，最后发现配齐了比直接买整机还贵，那就尴尬了。

第三，对于3D打印的外壳，千万别用艺术品的标准去要求它。它不是用来摆在博物馆里的，它的使命是保护好里面的电路板，顺便挡挡灰。有点瑕疵反而说明这是纯手工打造，独一无二。

第四，多关注那些"大神"店铺的上新提醒。这类手搓机器往往不是大规模量产的，可能每次就出个十几二十台，手慢无。它们的更新换代速度比网红明星的脸还要快，昨天还是N100，明天可能就换成N305或者N95了。

最后，虽然我把这台机器夸（或者说分析）得挺热闹，但大家还是要理性消费。毕竟，对于电子垃圾来说，最省钱的方式永远是——看完不买，立省398元。如果你家里没有现成的内存和硬盘硬盘能用，或者你没有必须要折腾NAS、软路由的需求，这台机器对你的生活不仅没有提升，反而会成为桌上的积灰神器。但如果你正好缺个便宜的小机子折腾，这398元的N100，或许真的是个不错的"电子玩具"。
