# 二手鱼398元可以捡漏N100小主机，3D打印外壳有点孬，但性能在线

今天在二手鱼刷到了N100处理器的迷你主机，398元的价格还是手搓出来的机箱，3D打印的效果像极了乐高积木拼出来的，但胜在价格够接地气，毕竟隔壁店卖同配置的都快摸到五位数门槛了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHibAMO6h0I6JjoOiciaX1ViboZZyPDhEqjHcbmesj6IhABTOD2dhhD8g3L5nFLnWvZFwfXc0Vjfb7BFg/640?wx_fmt=png)


这台机器的配置单看着像极了硬件发烧友的购物车——N100处理器自带4核8线程，功耗低得像节能灯泡，性能却比某些入门级笔记本还猛。接口方面整了个双盘位设计，M.2+2.5寸硬盘位像极了双开门冰箱，存储扩展空间直接翻倍。USB接口堆了2个3.0和2个2.0，千兆网口更是标配。最骚的是连2.5寸硬盘供电线都送了，这波操作堪比奶茶店送吸管还附赠纸巾。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHibAMO6h0I6JjoOiciaX1ViboZvGODIyQDGDMkwBE0tekZKu44utCcic2VHYkfd3tclvlV5RLfCumU9eQ/640?wx_fmt=png)


不过这玩意儿也有槽点，比如3D打印外壳的精度有点像橡皮泥捏的。内存和硬盘得自己配，这让我想起网上流行的段子："硬件玩家的快乐就是买完主板再买显卡，买完显卡再买散热器..."。对比二手鱼上同类型产品，这台机器的价格确实像双十一预售——提前锁定低价。但别指望能像拼多多砍价砍出五折，N100处理器现在比抢红包还难搞到。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHibAMO6h0I6JjoOiciaX1ViboZEQ803e5SFiaMyNcOy3P6eKAcIjQ3ElFXq62gZOp4MxOtYuJppLcgrHg/640?wx_fmt=png)


卖家说加50块配的3.5寸状态监控屏值不值？这玩意儿得看个人需求。要我说，与其多花50块不如等下次活动，毕竟监控屏这种东西，有总比没有强。那么问题来了：外壳瑕疵会影响使用吗？完全不影响性能但强迫症会痛。建议想买NAS的小伙伴先去二手鱼搜搜"飞牛圣体"，说不定能找到更合适的配置。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHibAMO6h0I6JjoOiciaX1ViboZEzeeM6eou1J3O5pKW6DKiaehWrbpc4ia1S3XLfbb8G7J1BJOfU4b30ibQ/640?wx_fmt=png)


现在二手鱼上的小主机行情像极了奶茶市场，价格战打得热火朝天。如果你想现在出手的话建议查考下面几条：

一：N100处理器别等降价，现在不买可能要后悔半年。

二：准系统要算好配件预算，别最后发现比整机贵。

三：3D打印外壳别太较真，毕竟这玩意儿不是买来当艺术品的。

四：多关注大神店铺的上新提醒，这类手搓机器更新换代比网红脸还快。


 老规矩，看完不买，立省398元。
