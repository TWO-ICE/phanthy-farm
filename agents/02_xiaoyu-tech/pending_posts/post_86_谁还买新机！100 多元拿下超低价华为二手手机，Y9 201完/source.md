# 谁还买新机！100 多元拿下超低价华为二手手机，Y9 2019 双卡双待用着真香！

![封面图](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXHwxIswcTNMsQqCnhoibyDwSAjmXhun43Rf8LQ2NTEpicbrXag4aBg4tLgQChqQ0ypLsibdpoW1zHkrg/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/3eG1mcV6aJe2-3MC7jn4NA

一直以来，我对二手手机市场都挺好奇的，总有人说 “二手手机水太深”，也有人觉得 “花小钱能淘到宝”。最近逛的时候，我发现了一个挺有意思的现象 —— 大量海外版的华为手机开始回流国内，其中有一款冷门到没多少人讨论的机型，让我忍不住想深入了解一下，它就是华为 Y9 2019。

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXHwxIswcTNMsQqCnhoibyDwSWUuMIeG58yHc9icibgA8lSh5aP3kNIGe4EbrQfUicibMia1wNnwN4ibggRzA/640?wx_fmt=jpeg)


先说说这款手机的背景吧，光看 “2019” 这个后缀就知道，它是好几年前的产品了，而 2019 年正好是华为遭遇 “卡脖子” 的第一年。我记得那时候华为在海外市场的表现其实很不错，尤其是在欧洲、东南亚等地，不少机型都很受欢迎，结果老美突然改变规则，打乱了华为的海外布局，现在这些海外版手机回流国内，也算是那段特殊时期的 “遗留产物” 吧。根据卖家的描述，这款华为 Y9 2019 是华为面向国际市场推出的机型，隶属于畅享系列，虽然在国内没怎么宣传，但在当年的海外市场，也算是一款走量的中端机。

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXHwxIswcTNMsQqCnhoibyDwS7Me7hdOMrnbcQp9LCHW2FicmyrZrp2gmGQu3IWiaVN8ghJSibkaRTAbeg/640?wx_fmt=jpeg)


出于好奇，我先研究了它的外观和屏幕。它正面采用的是 6.5 英寸的 LCD 刘海屏，分辨率达到了 2340x1080，这个屏幕尺寸在当年不算小，放到现在当备用机，看视频、刷网页也不会觉得局促。LCD 屏幕的好处是护眼，长时间使用眼睛不容易累，对我这种经常需要用备用机回复消息的人来说，这点还挺友好的。前置摄像头是 1600 万像素，日常自拍或者视频通话，画质也能满足基本需求，不会出现模糊不清的情况。

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXHwxIswcTNMsQqCnhoibyDwS2l5IKpECiaVheG8TcuaHjjZOAEe0Cic8oJ98enPG3ibSs4v2Tda9NtXhw/640?wx_fmt=jpeg)


配置方面，华为 Y9 2019 搭载的是麒麟 710 处理器，标配 6G+128G 的存储组合。麒麟 710 处理器虽然不是旗舰级芯片，但性能放在现在当备用机完全够用，日常打开微信、支付宝、浏览器这些常用 APP，基本不会有明显的卡顿。6G 内存保证了多任务运行的流畅度，就算同时开着几个 APP，切换的时候也很顺畅；128G 的存储容量更是足够用，我平时会在备用机里存一些常用的软件、离线音乐和几部电影，用了一段时间后，存储空间还剩不少，完全不用担心不够用的问题。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXHwxIswcTNMsQqCnhoibyDwSM0Whzd9dFWNUYCr3C3Y3lFduQ9dEdxicAmbljFgicBgeAiakiabpYfXmYA/640?wx_fmt=jpeg)


它内置了 4000mAh 的电池，这个电池容量在当年算是大电池了，放到现在续航表现依然不错。我做过一个小测试，充满电后，用它刷视频、聊微信、偶尔玩一会儿小游戏，一天下来还能剩下大概 30% 的电量，完全不用频繁充电，对于备用机来说，这样的续航能力已经超出了我的预期。而且我还发现，通过手机的两个 IMEI 码可以反推，它居然是双卡双待手机，这一点还挺意外的，因为很多海外版手机都是单卡设计，而这款支持双卡，对需要同时使用两张手机卡的人来说，无疑是个加分项。

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXHwxIswcTNMsQqCnhoibyDwSTickDxdQoyMlkoB1ibkguI0R89Lv6hNZ4nm36cgylkywibmiblgjy9OFaA/640?wx_fmt=jpeg)


不过由于是海外版本，它的系统和国内版有所不同。出厂时搭载的是基于安卓 8.1 的 EMUI 8.2 系统，后来可以升级到基于安卓 9 的 EMUI 9.1 系统，而且系统里自带谷歌框架和全家桶。对于需要使用谷歌服务的人来说，这是个方便之处，但如果用不到，这些预装的谷歌应用也可以卸载，不会影响日常使用。系统整体的操作逻辑和国内版 EMUI 差不多，上手很容易，就算是第一次用海外版华为手机，也能很快适应。

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXHwxIswcTNMsQqCnhoibyDwSM0Whzd9dFWNUYCr3C3Y3lFduQ9dEdxicAmbljFgicBgeAiakiabpYfXmYA/640?wx_fmt=jpeg)


外观设计上，华为 Y9 2019 采用了后置指纹设计，指纹识别的速度和准确率都还不错，解锁手机很方便。背面配备了 1600 万主摄 + 200 万景深组成的 AI 双摄模组，日常拍个风景、美食，画质还算清晰，景深镜头还能拍出虚化效果，虽然和现在的旗舰机没法比，但作为备用机偶尔记录生活，已经足够了。最让我惊喜的是，它还保留了 “极其领先” 的 3.5mm 耳机孔，我平时喜欢用有线耳机听音乐，不用额外带转接器，这点真的太贴心了。

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXHwxIswcTNMsQqCnhoibyDwSdKSsVKtXTLDlyXAJuftyqQ4YE4wXwE0dt5ZDMx5lswNTSz21ribGPxA/640?wx_fmt=jpeg)


至于大家最关心的价格，我在二手平台上搜了一下，6G+128G 版本的华为 Y9 2019，最低只要 150 元，而且很多卖家还主动写明 “价格可小刀”，也就是说，如果好好和卖家沟通，说不定还能以更低的价格入手。为了对比，我特意查了一下当年它的港版价格，4G+64G 的低配版就要港币 1442 元，换算成人民币大概 1300 多元，现在二手价 150 元，性价比真的太高了。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXHwxIswcTNMsQqCnhoibyDwSEH9Wicvop5hJZHINCib5icHibs4VpxxqPCaxzvaxCJWEs2ObWqDibnQdgqA/640?wx_fmt=jpeg)


另外，我还了解到 Y9 系列有一款采用伸缩前摄的全面屏版本，型号叫 Y9 Prime 2019，搭载的是麒麟 710F 处理器，虽然外观设计更有特色，但我在闲鱼上看了一下，这款机型卖的基本都是 4GB 小内存版本，存储容量也大多是 64G，日常使用很容易出现内存不足的情况，而且伸缩前摄用久了还可能出现故障，综合来看华而不实，所以我觉得完全可以 PASS 掉，还是 6G+128G 版本的华为 Y9 2019 更值得入手。

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXHwxIswcTNMsQqCnhoibyDwSez89LEib4brKuFgyxia3rwS5J3xscoB1VicdXhnk0tyxVYXFdw6ApZt3A/640?wx_fmt=jpeg)


总的来说，这款海外版的华为 Y9 2019 虽然是几年前的老机型，也算是二手市场里的 “洋垃圾”，但 143 元的价格能买到 6G+128G、双卡双待、续航还不错的手机，真的很划算。它特别适合作为备用机，或者给家里的老人使用，老人对手机性能要求不高，这款手机的流畅度、续航和屏幕表现，完全能满足他们的日常需求。
