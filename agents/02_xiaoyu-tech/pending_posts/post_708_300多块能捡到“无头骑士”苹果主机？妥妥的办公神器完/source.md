# 300多块能捡到“无头骑士”苹果主机？妥妥的办公神器

300多块能买到苹果电脑？还是“无头骑士”？先别划走，这可不是开玩笑。最近在二手鱼上溜达，发现一批“无头骑士”宝贝，其实就是老款MacBook Pro的A1502型号，拆掉了屏幕的上半身，只剩下带键盘、触摸板和电池的下半部分。价格嘛，从300元起步，最顶配的i7版本也不过650元。在如今存储硬件价格波动，新机售价高企的背景下，这么个玩意儿，到底是电子垃圾，还是被严重低估的办公神器？我今天就来唠点大实话。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEqCXibWNMZUJcHjwHXwN5XwdcwYrKQUvLfBGxbLiblicYicQN0l4rVJG78bOwktefs4DsiacpiagK1jOaQ/640?wx_fmt=png)


言简意赅地说，它的核心卖点就三个字：性价比。你想想，300块现在能干嘛？吃两顿像样的火锅都不够。但在这里，你能得到一个完整的、能运行的苹果电脑“主机”。它自带素质极佳的Force Touch压感触控板和剪刀脚键盘，手感秒杀一众廉价外设；内置电池，突然断电也不慌，这点比普通迷你主机强太多；甚至还有原装喇叭，听个响完全没问题。玩法就是，你只需要自备一台显示器、一个鼠标，用HDMI线一连，瞬间得到一套完整的 macOS 桌面系统。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEqCXibWNMZUJcHjwHXwN5XwicL91SgR7icQ3gUHZsZjNheKokPy00hLseejmJgWiaqPrL8GoE4Zvdgqw/640?wx_fmt=png)


从实用性来说，它最适合谁？首先是预算极其有限，但又需要一台稳定文字处理、网页浏览、在线视频机的学生党或轻度办公族。其次，是想低成本体验macOS生态和苹果工业设计的朋友。最后，是作为家里的第二台、第三台备用机，放在书房或者给孩子上网课，完全胜任。2015年的机型还能升级到macOS Catalina，常用的软件都能跑，隔空投送、接力功能都正常，融入苹果全家桶没压力。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEqCXibWNMZUJcHjwHXwN5XwQfqcVYIm4DN7m7LDVh6iauHkB3E8xiaCPWzwYEFVHRlS7jbedib9CBonw/640?wx_fmt=png)


当然，咱们得说不吹不黑。它的劣势同样明显：性能是硬伤。搭载的都是四代、五代英特尔i5/i7处理器，放在今天就是入门级水平，别想着用它剪4K视频或者玩大型游戏，老老实实处理文档、看看剧。另外，“无头骑士”顾名思义，没有屏幕，外观上也肯定有岁月痕迹和磕碰，追求完美成色的朋友可以直接绕道了。这其实就是“洋垃圾”和工厂淘汰件流入市场的典型，你可以理解为一种极致的资源再利用。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEqCXibWNMZUJcHjwHXwN5XwI5QGzCVhiaHlOImOTRwl7X5O7msWcCllF4HQlhDnCOmJuQ7FHOiaer5w/640?wx_fmt=png)


从残值来看，它已经跌到底了。300元起的价格，几乎就是拆件卖零件的身价，你买来用上一两年，再转手出去，大概率也亏不了几十块钱，这恐怕是数码产品里最低的折旧率了。相比之下，那些每年疯狂贬值的新款电子产品，是不是显得有点“虚”？


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEqCXibWNMZUJcHjwHXwN5XwrCHeM5KbVW0MCg89J8mas4Ubpsjjqlib1N7Othqb0BviapdNzdsgj8kg/640?wx_fmt=png)
