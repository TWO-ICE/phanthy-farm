# G4900 CPU 15元包邮，二手鱼上又有大漏流出了

没事就在二手鱼上溜达，这大概是我们这些数码爱好者的通病。明明家里矿卡成堆、CPU成山，手指头还是不听使唤，总想着能不能在垃圾堆里刨出点黄金来。今天刚打开APP划拉没两下，一个条目直接跳脸——G4900处理器，明晃晃地标着“15元包邮”。

这价格真是让我恍惚了一下，现在的物价难道倒退回十年前了？15块钱包邮，这甚至不如今天中午的一碗猪脚饭贵。咱们哪怕再怎么抠细节，把快递小哥那几块钱辛苦费刨除掉，这U的实际到手价也就跟大白菜差不多，甚至可以说算上邮费之后，卖家纯纯是在做慈善，倒贴都没这么狠的。我看了一眼浏览记录，目前只有6个倒霉蛋或者幸运儿刷到了这个页面，不管别的，这种“漏”必须得先下手为强，不然瞬间就没了。

咱们先来盘道盘道这颗“古董”成色。G4900，这可是英特尔在2018年左右推出的赛扬系列拳头产品，哦不对，是入门级产品。那时候大家都还在津津乐道第八代酷睿的颓势和第九代的崛起，而这颗U就是那个时代主流架构下的“残血版”。它用的是当时Intel玩得炉火纯青的14纳米工艺，虽然现在的蓝厂都已经进了Intel 7、甚至更先进的制程，但14nm在当时可是出了名的“不发热、不积热”的好工艺，虽然老了点，但在稳定性上绝对是一把好手。

放到现在2024年看这颗U，确实有点“老爷车”的感觉。双核双线程，没有超线程，这在多任务处理简直就是灾难——你一边挂着QQ，一边试图打开一个稍微大点的Excel表格，可能都会感觉到鼠标圈圈在转。基础频率3.1GHz，没有睿频加速，意味着它干活就是一膀子力气，该爆发的时候爆发不出来，该歇着的时候也不敢歇。54W的热设计功耗（TDP），倒是给现在的电源减轻了不少负担，毕竟现在随便哪个中高端CPU动不动就百瓦起步，这老头子算是很省油了。它还集成了UHD 610核显，这显卡属于是“亮机卡”里的战斗机，你要说它能玩什么大作，那纯属做梦，但要是说它连个Windows桌面都跑不动，那也是冤枉它。

用现在互联网上的黑话来说，这就是个标准的“电子垃圾”。但咱们换个角度琢磨，15块钱还包邮，还要啥自行车啊？还要啥手表啊？这价格连网吧的一小时开机费都不够，你却能带回家一颗能点亮、能计算、能显示的硅基智慧结晶。

肯定有兄弟要杠了，这老古董买回来能干啥？吃灰吗？其实这玩意儿的用途，比你想象的要广阔得多，前提是你得把它放在对的地方。我打算到手之后，直接给它装个轻量级的Linux系统，比如Debian或者OpenWrt，直接把它魔改成一个家庭下载机。现在的宽带动辄千兆，但运营商往往会屏蔽上传或者搞什么并发连接数限制，用这种X86架构的低功耗小主机跑个下载工具，7x24小时开机挂机，电费算下来一个月可能也就多出两三块钱，这比你去买个几百块的成品NAS或者整群晖，那回本周期可是短多了。

而且这U的兼容性那是相当的好。我手里正好还有一块吃灰已久的H310主板，这简直就是天作之合。既然CPU才15块，那其他的配件也不能掉链子。再去海鲜市场淘一淘，机箱算你5块钱，老一点的电源可能也就10来块，再配上DDR3 1600的内存条（现在也是白菜价），一个64G的SATA固态，再加个从公司淘汰下来的CRT显示器或者家里闲置的 VGA 屏幕配一套键鼠。好了，一台传说中的“小霸王学习机”就这么成型了。这种主机放仓库里跑个脚本、挂个QQ微信等级、或者给孩子当个打字机，那是再合适不过。

当然，咱们评价数码产品得客观，这G4900也不是没有短板，甚至可以说短板挺明显的。毕竟是赛扬系列，这就是当年的“工薪阶层”专用U。它没有超线程技术，多开几个浏览器标签页都能让你体验什么叫“卡成PPT”，三级缓存只有可怜的2MB，数据吞吐量那是相当感人。如果你指望拿它打游戏，那我劝你趁早打消这个念头，哪怕是10年前的《英雄联盟》在团战的时候估计都得给你变成幻灯片，至于什么大型3A大作，那是想都不要想。

不过话说回来，15块钱的CPU，你要求它干什么？当年它上市的时候，定位就是品牌办公机的专用U，主要用来跑跑Office套件，或者给收银台那种不需要高性能的机器用。谁能想到时过境迁，当年的“低端入门”，现在在二手市场居然找到了第二春。现在花这么点钱，就能体验一下当年英特尔主流平台（Coffee Lake架构）的滋味，想想还挺魔幻的。就像是你花顿早饭的钱，买了一辆能开的破旧桑塔纳，虽然没空调、噪音大，但它确实能动啊。

最后给想冲的兄弟们提个醒，在二手鱼淘这些东西，最重要的就是心态。千万别指望它能“战未来”，也别指望它能给你跑什么分、压什么榨。它的定位就是低成本玩票、特定用途的辅机。作为一个过渡使用，或者仅仅是为了圆一个DIY的梦，这个价格确实无可挑剔。哪怕玩两天坏了，扔了也不心疼。

快来说说，如果你手里有8500块的装机预算，最后只花15块钱上了G4900，剩下那8000多块钱你想配点什么顶级配件来拯救这颗心脏？老规矩，看完如果不买，直接立省15元，这是最大的省法。
