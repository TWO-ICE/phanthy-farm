# 89元的圆形安卓魔镜，当年卖两千现在当导航？垃圾佬的新玩具？

![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekiccyABRDxnQRRqJgIElQM3xlNPVmfCBuQLZTtH1t4K0yMpfVVRbNdog1es0QByvbRHUaAyDzpIJ1MN9McUqs6Ao4ibicj7xaNFo/640?wx_fmt=png&watermark=1&tp=webp)


二手鱼里刷到个 有意思的东西，圆形屏幕的 小熊尼奥照照乐，卖家挂89元起，这东西原本是给儿童启蒙的AR早教机，当年售价接近两千， 能识别卡片玩动物园、交通场景。 现在被大神破解了，能刷成安卓系统，可玩性大大提高，尤其是卖家展示的这几张图，有点让人眼前一亮的感觉。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekZibMFrgjyRkfOw3H37DefkNYX42gMKUhibMAViblCHQse3a9LHRyVoz0pwSnHcDtOOXKnM8dKNWnuzynlOtN0DKzy14R5HicKCqw/640?wx_fmt=png&watermark=1&tp=webp)


这玩意最大的亮点是那块直径92毫米的圆形触控屏，800x800分辨率。2+16GB内存，支持WiFi和蓝牙。卖家展示图里刷了安卓6.0.1系统后，直接变身圆形屏幕的安卓小主机。最实用的功能是当车载导航，圆形屏幕装在仪表台旁边，那叫一个有个性。你想想，别人都是方方正正的大屏，你掏出个圆形的导航界面，这在车友群里绝对是独一份的 存在 。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCen1X9Ayia7fEOGPN2uxSHeiaglR0S9oRialb8eao7H2SxkHWdT6IP4BXmXwydVUoS751rmwSeudewL4Dtib4kEITB2Ih8dkygm70D0/640?wx_fmt=png&watermark=1&tp=webp)


装APP更是随便玩，抖音刷起来虽然屏幕不大但够萌，B站看视频弹幕照样飘， 但性能就不能有啥奢望了，毕竟是台老机器，最好只专注干一件事，不然绝对会卡出翔来 。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenMQLFTQzCjibh06rs9kCOGjyvI0UbGyN4uLxYf6uqt9D73QvlpFGdj8x6kYBdhZUdMtp3rwT9jOvT7kENiaOPZGoAZkDnSdzxus/640?wx_fmt=png&watermark=1&tp=webp)


让我没想到的是，它 还可以刷成AI语音助手，自带小智AI、小度、小爱都能整，放桌上一喊就应，比那些百元智能音箱好玩多了。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekZ8MMbJpNCTAPvsZTxjSiavF5zicKsdn7b8iaClKmJbhJ00TKicVKTtAkP8knkuWtBjqZbaDFAy5K7YEGw5o0XRhhia7rXf6nBP0n4/640?wx_fmt=png&watermark=1&tp=webp)


但问题也有 ，刷机后前置摄像头失效，后置能用但画质一般，卖家也明确说了非手机配置没法比。如果你冲着拍照去，趁早打消念头。 还有 ，这玩意本质是个早教设备改装的玩具，别指望它干手机的活，处理器是联发科MT6580，性能就是够刷个抖音看个导航的水平。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemW4l7lrmWU06jKSFLg5thBliaYFIDxXa7EGbcJK9iagNbWFaRPftFCRNVTibK5AE5RgjZh3hgIyrHufVFQj8LlFmjcoL6KoEXMpY/640?wx_fmt=png&watermark=1&tp=webp)


卖家给了四个档位。85成新裸机89元，9成新99元，刷好安卓6.0系统的110元，全新未拆封128元。 很明显 刷好机的套餐最有性价比，多花20来块省得自己折腾。但如果你动手能力强，直接买89元的裸机自己刷， 卖家给了 现成的刷机包。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekzn4eQpYicQKEpCLW5icJWibUlzuLMM6yeYN4NEZzMUZQFGtBajIn12qrcgGbLIOGydP0LibobO0qhgGGgoJyFZNeHEjOoIgibbJeM/640?wx_fmt=png&watermark=1&tp=webp)


如果你只是想体验一下，直接上110元刷好系统的，到手就能装APP。如果打算长期玩导航或者当桌面时钟，就买89元裸机自己刷，省下的20块够买根好点的充电线。全新未拆128元那个反而最不推荐，原厂系统现在内容生态基本停更，买回来还得自己刷，多花钱没必要。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCem4GiaI6P1vaIFlSTctlAFmNAeASIzuvh1MLiaAEiblgljzKj2SLneZNsg8VrFSeySk4QNnCfrXeCmc63BUC9Dj0RnG7jOoYvv9Ls/640?wx_fmt=png&watermark=1&tp=webp)


89元在二手鱼里也就 能 买个普通安卓小盒子或者旧款智能手表。但照照乐这块圆形屏幕是独一份，市面上几乎没有同类产品。当年开这条圆形屏幕生产线据说就花了大价钱，现在变成垃圾佬手里的玩具，也算物尽其用。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenUd0mIXBCDefuGV70IFBpwr3lHjwvlJy70eMzU2RRndjvj2OnOvGmOIVhVRs9hA5JMtOdujYXykNjCOia3jGXNgorZUib7aHYcU/640?wx_fmt=png&watermark=1&tp=webp)


你会花89元买这台圆形小魔镜回家当导航吗？还是准备刷成语音助手放床头？或者你有更奇葩的玩法？评论区聊聊，让我看看垃圾佬们的脑洞能开到多大。
