# 惠普800G3准系统只要179？这个主板底子真不坑小白

在二手鱼里看到了这款惠普HP800g3 DM迷你小主机，准系统价格是179元。卖家描述成色 是 9新， 能上 6代7代低压带T 的处理器 ，带硬盘支架支持m2加nvme加sata双硬盘，双条DDR4笔记本内存槽，还提供了469元的整机套餐和多种配件选择。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCeklFSY1bbV1uicB2zrH9vPb1vfe9cWyotUiadz49lyraRDbPAszcN6bocJV9ZYyDeSREu8oNNOxticJjNmhrQpHib9jKfFzdonNYicQ/640?wx_fmt=png&watermark=1&tp=webp)


参数方面 可聊的只有主板 ，它采用Q170芯片组，支持LGA1151接口的6代7代酷睿T系列低压处理器，比如6100t 7100t 6500t 7500t等。内存是双DDR4笔记本插槽，最高支持32GB扩展，硬盘扩展性是亮点，同时支持M.2 NVME和SATA双硬盘，这在同价位迷你主机里很少见。接口方面有双DP口 VGA口 千兆网口和多个USB3.0接口，满足日常办公足够。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCentlABiaJrCbmjjpiar1Cd21ZYlxPbvdYELNoQGqQ8sTciaIodofEhoskXQiaGuTwNu9pG37bEWx5mGpkdksTrOfJ4t5SZWgBBVok4/640?wx_fmt=png&watermark=1&tp=webp)


主机的 优势很明显，首先是价格优势，179元的准系统门槛低，加上配件也能控制在500元内，比同配置新主机便宜一半以上。其次是扩展性强，可换CPU 、 双硬盘位 、 内存可升级，比很多不可更换配件的迷你主机灵活太多。 还有 是商用 机的 品质，惠普EliteDesk系列做工扎实，散热和稳定性经过企业市场验证，比杂牌小主机靠谱。最后是体积小巧，迷你机身不占地方，适合桌面空间有限的用户。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekjVw7iczLtTzmzhcPice8JbD2f6b58oZugrssyWkwctw6NxCHhR5iaL8T0GqGnvXibiaG3WryVzGZYdBq7HddhicI3xjnhZWUSZiaGa4/640?wx_fmt=png&watermark=1&tp=webp)


缺点 当然也有， 它只支持6代7代低压CPU，性能上限不高，玩大型游戏或做视频剪辑肯定不行，只能满足办公 、 轻娱乐等基础需求。而且是准系统出售，需要额外购买CPU 、 内存 、 硬盘 、 电源，对小白不友好，容易买错配件翻车。原装电源和WiFi模块还要另加钱，算下来整体成本会增加。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelUEWtlykC2NF7wbjoRUZ0pYibUPuqpibm71NsCwicGC4198MlsiclFnLfqFV9vKu3ocoO54GQkf8WU9FExLn4nibygAIEdN6ic8jlwc/640?wx_fmt=png&watermark=1&tp=webp)


对比同价位产品，179元能买到的迷你主机要么是性能更弱的J系列处理器机型，要么是扩展性差的一体机主板，要么是洋垃圾翻新机。惠普800g3 DM在扩展性和稳定性上有明显优势，适合有一定动手能力的用户。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekc2GFRX7ge2Mp2QXciblpRRM3vJDdTORshjU3GssAjibOU9ZyFQgjJ9LO4icibMobeZ51UicxhFOcdlRaxjujIDIFgFIribXlkzV0rc/640?wx_fmt=png&watermark=1&tp=webp)


卖家提供的 469元整机套餐 还是比较有性价比的 ，配置均衡不用瞎折腾，比自己买配件组装更稳妥， 价格也还算合理， 还能避免买错CPU或内存的麻烦。 另外，如果是自己配置的话 ，优先选7代CPU如7100t或7500t搭配16GB内存和512GB NVME硬盘，这个组合能保证流畅运行办公软件和轻度娱乐，残值也更高，后续转手更容易。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelaU7Y5Pia981uFCjrfrjdvOG9u74suNcOYgxcsWV8k79uOgdQfmENAKkP0xzuL8guL9FSCRLsDY6B5EuKEvgpG0xb1SLgOUtAI/640?wx_fmt=png&watermark=1&tp=webp)


如果你正好需要一台低功耗的办公机 、 下载机或NAS，又有一定动手能力，这款机器值得考虑。但如果你追求高性能或完全不懂硬件，还是谨慎入手，避免当接盘侠。你们觉得179元的惠普800g3 DM准系统值得买吗？你们会用它来做什么？是装NAS还是办公用？欢迎在评论区留下你的看法。
