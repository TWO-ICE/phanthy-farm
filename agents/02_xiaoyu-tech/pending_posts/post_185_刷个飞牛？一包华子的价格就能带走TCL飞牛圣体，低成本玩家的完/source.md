# 刷个飞牛？一包华子的价格就能带走TCL飞牛圣体，低成本玩家的最爱

![封面图](https://mmbiz.qpic.cn/sz_mmbiz_jpg/E9h3abOJCelnsJX4CQAHccU936fL4LpjHfVTzf9GH4BmH1RG13Ism1dQcQgbGHsrtehwXfJZoO4Pbv2GgqpibicQchaztqEn9lNGfRPqROOD4/0?wx_fmt=jpeg)

想搞一个小主机玩飞牛，但还不想多花钱，建议你看看我刷到的这台TCL小主机，型号MIX M200-1，搭载英伟达翼扬平台的Intel Atom 230处理器，原配1G内存，卖家还给加到3G，千兆网口，支持来电自启，还带一个2.5寸硬盘位。裸机不带电源和硬盘，要价65块，还不到一包华子的价格，而且还包邮。这价格，扔沟里都不心疼啊老铁们。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemnbxhAhKbmAml0QBz6QH0ooEMVn4lY4xr18xDSGY1fyM7UUnzic5SEIIWESAcx9F0OOnhRic3Z6viaWlKl3antP0jAc6AEvIDE6Q/640?wx_fmt=png)


这台小机器是当年TCL做的客厅娱乐中心，主打电视媒体播放器，低功耗，而且能硬解高清视频，Atom 230处理器虽然是单核双线程，但配上翼扬的集成显卡，播个1080p还是能打的，所以先不要嘲笑这是个垃圾，咱们玩飞牛看重的不是配置，而是实用价值和性价比。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekdiaeDrK1q47mlIlD2UZ3WboboEiaiao6EYUfRhj1jtTMaoRn0Kz2qzSvN6F5sF5YAGYDesLk4cv4UtVg6JdeerLhfVLn5nFQsDk/640?wx_fmt=png)


飞牛对硬件要求不高，正好这类小主机功耗低、体积小、价格便宜，简直就是为折腾而生的玩具。卖家自己都说了，装上飞牛测试了一下，机器非常小薄，非常静音。这不比你去买个几百块的成品NAS香多了？


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekGoxtZuU8H5FmmKRzUQE6OSyNOgiaANXqCIGvpgrn4bKpgPVU2Z9xwFeNKx9KL7hfu5QSpmQHH8zbvXcp7BaUn87FMYTOmNpWw/640?wx_fmt=png)


当然咱得说实话，Atom 230这颗处理器现在看确实是老咕噜棒子级别，性能跟如今的主流处理器没法比。3G内存也干不了重活，跑飞牛做文件共享、轻量下载、备份照片这些是够用的，别想着拿它搞虚拟机或者硬解4K，那是在为难它。板载1G加上卖家加的那根2G内存，组成不对称双通道，聊胜于无吧。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekHIbJTTb2LJNqooAZQH2crtxntu5RhVaC2QqH1HrNgJSUXl1zjB3ZW6gU1wicGgO6UsgVbJHvIvHJfickLtWXBkN7TCrgM8TjVQ/640?wx_fmt=png)


这台机器的亮点其实很明确：65元，你要啥自行车？一个千兆网口，意味着内网传输速度有保障。支持来电自启，放家里当个服务器挺方便。超级静音，功耗低，7x24小时开着也不心疼电费。有个2.5寸硬盘位，你手头有闲置笔记本硬盘就能直接用，没有的话花几十块淘个二手的也划算。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemrlhxnEndLRZibX7Jt0EEzFD6Ylr6vKd3DtBIiakU6g7a8DDMsV0eeHOcDfrc6ia9KWLMNEibUowXCocCawbSqsF4NUy1IpNePRGM/640?wx_fmt=png)


电源是个坑，卖家不配，需要自己找19V的笔记本电源。这倒不算大问题，家里有废弃笔记本电源的翻翻，大概率能通用。要是没有，买一个也就十来块钱。算下来主机加电源加硬盘，全套控制在150元以内妥妥的。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCeknvpGmjcL027D7qRibib2bqiaILJaHwVu7p3dBxC0fbL3PyW5p0KQLhbEYfpiaLHGcsV5IafjEkFanaWJcrwscfylTGj0ea00ibXQk/640?wx_fmt=png)


卖家说看好下手，售出不退不换，这个能理解，毕竟就几十块钱的东西，来回运费都比机器贵了。如果你就是想低成本体验一下飞牛OS，或者需要一个24小时开机的下载机、文件服务器，那这台小机器绝对是不用瞎折腾了的选择。但如果你指望它能流畅跑Windows办公或者当主力电脑用，那就趁早放弃，它真做不到。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemib5BmB9vSBT5QJTz7abfv1CD1Pwo4ziceMTfKlscFgqRAAeYKiaYR6f0vIibiacGpPw8MdGg2iaaeut0C55SIDDHjvbIfXcSgvkicEU/640?wx_fmt=png)


另外，我还刷到了一个同款，原装1G+160G的配置，没说不带电源，才卖50块同样包邮，个人感觉这款的性价比也挺高，相比之下等于是用2G内存换一个160硬盘，而且价格还便宜了15块，所以到底选哪个还是你们自己决定吧！


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemc19qsdBAljj1qEFly4Ic2LCtv06GcQhicB5owOThENDQ2RRL6libic5QgaO2yFOQxzSyQAoraLhTiczlEOpl2NchTotD2m6dJgtk/640?wx_fmt=png)
