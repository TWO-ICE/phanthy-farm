# 带屏幕的天猫精灵音箱46元清仓，你不来撸一个玩玩吗？

![封面图](https://mmbiz.qpic.cn/sz_mmbiz_jpg/E9h3abOJCen4bxSE2ypTmDR3LzmZ0Dnpia94qZZCzIk1KdI84RJr2LQbmiaV20ndbKCrsmCXzEpJbXtZAaR5fLWj5tPH8NVXXFicbpOLQZS29U/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/CrJ2wqAMhJ585SWRV6Usbg

最近经常刷到，有人在出这个天猫精灵CC mini带屏幕的智能音箱。价格在50块左右，成色好点的要贵个20块，但想要捡漏的话，有一个老哥卖8-9层新的46块，还包邮！这价格，说它是电子玩具都感觉有点侮辱玩具了，这简直就是白送级别的边角料啊。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCek4rRIJQTWTCcA5mKohuIic0pYpf7ywwPNszKiboibeuibOibf73tqzEfKicqS1nAYMeLrd9Bgv2cbummvJIickQC19Jm46VxjYibg2kicQ/640?wx_fmt=png)


我扒拉了一下卖家的描述，红白两色可选，带个屏幕。这个屏幕不是拿来刷抖音的，它的核心是看时间、当闹钟。想想也是，你心心念的智能生活，可能就是从早上被它用温柔的声音叫醒，而不是被手机那要命的默认闹铃吓醒开始的。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemY1xFiakPK3MJcibicAOLv2PLPoKpovwqkfc0z7JZye5UpYH9u6ZmbVP9jdqibt9nu7uiboNTdqFrck9OxDHTe4RLhdhksBmEP53VU/640?wx_fmt=png)


它支持Wi-Fi连接，用天猫精灵app绑定一下就能开工。功能上，查天气、听歌、讲故事，这些基操都没落下。卖家特意提到音质不错，对于这个体积和价位来说，能响且不破音，就算是惊喜了。当年这玩意刚出的时候，好歹也是百元级的小家电，现在价格腰斩，正好成全了咱们捡漏的垃圾佬们。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemSeN3jF3jTjNxsL5WstUGFwIibPlkMPJb5IjpjubibFj25q9O3OD6Qia9F7fWBUOcVF2Y9KI6BKibc5I3WKT0Gc0tJdstkg3ExWKk/640?wx_fmt=png)


当然，老鸟们都知道，这种几十块的东西，不可能十全十美。卖家也实诚，说了屏幕多少会有点划痕，但不影响你看时间。机子侧边还有个多余的接口，卖家自己都不知道干啥用的，说是不影响使用。我觉得这可能是当年设计时预留的某个接口，后来被砍了，算是给你留了个历史彩蛋。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemOadiauV0OIq3iaVuicvqKhHkdUNDeZoZicqtaHD1ribBkgPGWOLbqC8xfm0h9YJ2AypcU6cN4ePZn3S7dl8hGVmiaOhIibz6KKRf4QI/640?wx_fmt=png)


所以，这46块到底花得值不值？我的看法是，如果你的需求恰好是床头缺个好看又好用的闹钟，或者家里有长辈小孩，就想找个简单的语音助手问问天气听听戏，那这个东西简直是为你们量身定做的。不用瞎折腾了，买它，比你去买个几十块的普通电子钟强了不止一点半点，至少它还能跟你聊两句。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekRCxpYbTsprv1rEiccYg9ob501VU0AAjuGH7EHGfD50U5bnyK7sOAXDtgzxy5SkpT5YwiaZOxdTicugOPaRyDD5MkDRRBgfKUC1Q/640?wx_fmt=png)


最后还是那句话，下手前多问一嘴，划痕具体啥情况，问清楚了再付款。毕竟在二手鱼里，我们都是理性的垃圾佬，只捡对的，不买贵的。那么问题来了，如果是你，你会花这46块钱，给自己的生活添个能对话的电子钟吗？评论区聊聊你的看法。
