# 二手鱼卖家给11代I5主机披上一身炫酷机甲，要你个1450算不算贵？

今天在二手鱼刷到了一台标价1450元的手搓小主机，光看图就有点上头——机箱是自己3D打印的，正面还焊了两个机械键盘青轴按键当电源键，看上去很有个性。但是这玩意儿不是那种套壳ITX整机，也不是笔记本主板魔改，而是用亿联视频会议主机的主板硬生生给“手搓”成了一台桌面小主机。浏览量已经飙到32万，看来不少人都跟我一样，点进去纯粹出于好奇：“这也能卖？”


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXH7cXtFdj5dMViaopV8PYZDs9jUIw7sOsdFibibaFY5QTAhiaHWeuxbficjp9kXWswW6Z7mKNO1ZS90R0A/640?wx_fmt=png)


先说配置：CPU是Intel i5-1135G7，四核八线程，11代Tiger Lake架构，内存插了两条DDR4 8GB，共16GB，频率没写，但大概率是3200MHz左右；硬盘是M.2 NVMe协议的500GB固态，读写速度肯定比SATA快不少。整体尺寸只有165×130×55毫米，比很多路由器还小一圈，放桌上几乎不占地。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXH7cXtFdj5dMViaopV8PYZDsXkEwaC6kqmgPh0mtlP8GdIb5ImxjVDBRN7UouSm4xoTorAibKvnxD2g/640?wx_fmt=png)


但别急着喊“捡漏”——这主板来路特殊。卖家反复强调：“不是笔记本主板，也不是ITX板子，是亿联视频会议主机拆下来的。”这意味着BIOS功能极其有限，基本没法超频、调电压，甚至启动项都可能锁死。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXH7cXtFdj5dMViaopV8PYZDsmHEoclAvJM3M6qhuBrjzMP3fKZBemFHN15BUKukgUsibym6icvryPKkQ/640?wx_fmt=png)


接口方面，背面有四个USB 3.0，一个千兆网口，三个HDMI口，卖家直接坦白实测只有第一个稳定，第二个进系统前花屏，第三个干脆没反应，还有一个神秘RJ45口，插了也没用，直接被卖家盖板封了。音频输出只能靠HDMI，没有3.5mm接口，想接音箱？得另配转换器。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXH7cXtFdj5dMViaopV8PYZDsicvPFTLLTBovd3QLq9KsrNN1mTKbXQsZSHV7jIMY7ZK8iclGXnjlkibeQ/640?wx_fmt=png)


那么问题来了：1450元值不值？但从性能方面来看，目前全新i5-1135G7的迷你主机（比如零刻、铭凡）价格普遍在1800–2200元区间，带完整售后、标准接口、正规BIOS。而这款“手搓机”虽然便宜三四百，但牺牲了扩展性、稳定性和售后保障。但你可能也是和我一样，被这个炫酷的机箱外形所吸引，如果你想为这个情绪价值买单的话，这个价位还算是可接受。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXH7cXtFdj5dMViaopV8PYZDsWdqPASao84bsZh6hcCiaJD85ZJZVCc8PKSC2MH6xqm03NgRPwr2QZOw/640?wx_fmt=png)


另外还有一款黑色的，想要找到这个玩意，可以在在二手鱼搜索关键词“DIY的小主机”，大概率能刷到它。如果搜不到，试试用图片搜索功能上传卖家晒的图。要是还是找不到……那八成是已经被人“捡走”了，或者下架了。


 


以下是个人一些掺了水的建议：

1. 先想清楚用途，高价位可能只是为“炫酷”买单。

2. 能接受无售后、接口残缺再下手。

3. 同价位有全新品牌机，对比后再决定。

4. 看完不买，立省1450元。
