# 牛真香系列：联想98元小主机刷飞牛真香，我快成二手鱼的鉴宝大师了

我现在每天睡前有个雷打不动的习惯，就是刷二手交易软件。不是瞎逛，而是专门淘那种被普通用户当成“电子垃圾”卖掉的宝贝。这就跟以前老先生溜去潘家园淘旧书画一样，全凭眼力和经验。最近这一淘不要紧，还真让我挖到了个硬茬子——一台Lenovo联想Q190的小主机。

这东西的价格标得让人心里发痒：98元。

更要命的是，这还是个“准系统”，也就是说，卖家把硬盘和内存都拔走了，剩下的只有一个光秃秃的主板、电源和外壳。这价格在现在的硬件市场上，大概也就值半包好点的烟，或者两杯稍微加料一点的奶茶。对于咱们这种折腾硬件上瘾的人来说，这简直就是天上掉下来的馅饼，不仅便宜，而且吃相还特别优雅。如果不把这块“骨头”啃下来，顺便跟大伙盘道盘道，我都觉得自己这“鉴宝大师”的称号有点名不副实。

把时间轴往回拉个七八年，联想Q190刚上市那会儿，那可是迷你主机圈子里的“当家花旦”。那时候还没现在这么多软路由、NAS的概念，它的定位非常精准：给办公室文员做文档处理，或者给家里客厅做个轻度娱乐机。凭着那个只有巴掌大的小巧机身，加上接口异常齐全，它确实圈了不少粉，被誉为“桌面空间拯救者”。

那时候大家还在用笨重的大机箱，突然有这么个能立在显示器后面的小东西，确实是个降维打击。如今时过境迁，它在二手鱼里沦落成了百元内的“性价比选手”。虽然早就不是主流，甚至可以说是被时代抛弃的“前浪”，但对于想尝鲜飞牛OS（FnOS）、图个便宜又不想投入太多成本的朋友来说，这玩意儿简直就是量身定做的练手神器。

当年这机器能火，绝对不是靠忽悠，实打实是有两把刷子的。

咱们先聊聊这身板。19x15.5x2.6cm的三围，这尺寸控制得非常刁钻，迷你得就像以前那种老式DVD光驱，甚至比有些外置硬盘盒还要秀气。拿在手里轻飘飘的，随便往哪个抽屉缝隙一塞，或者架在书架的角落里，它都能安家落户，完全不占地方。比现在市面上动不动就搞得跟砖头一样大的某些所谓“迷你主机”，这机器的设计语言明显更克制、更优雅。

但这台老古董最让我惊艳的，其实是它的接口丰富度，简直是“堆料狂魔”。放在今天看，这套配置甚至比某些新出的百元级电视盒子还要良心。

它配备了VGA加HDMI的双视频输出，这意味着你不仅能接家里的4K电视看个片，甚至还能接那种十几年前的古董显示器做双屏显示，这就极大地扩展了它的使用场景——比如在公司当个测试机，或者给监控室做显示终端。

更夸张的是USB接口，居然给了整整6个！其中还是两个蓝色的USB 3.0口。要知道，现在的笔记本如果给你两个3.0接口都得算是“良心大发现”了，这机器直接上了6个。这意味着什么？意味着你不用买扩展坞，鼠标、键盘、打印机、U盘、无线网卡，甚至还要给手机充个电，它都能一口吞下，根本不需要你拔来拔去地抢接口。

除此之外，SD读卡器、音频接口、甚至那时候很多高端主板才有的SPDIF光纤输出都给配齐了。当年这配置在迷你主机里绝对算是高配，现在看依旧能打。这就是为什么说98元买不来吃亏，光这块“接口板”的价值，在电子垃圾堆里都不止这个价。

当然，咱们也不能“老王卖瓜”，得客观聊聊它的性能软肋。

这机器当年搭载的是Intel Celeron 1017处理器，双核两线程，主频1.6GHz。在2013年左右，这配置用来跑个Win7，开几个Word文档，刷刷网页，甚至看个720P的片子，那是妥妥的“够用党”福音。它的TDP热设计功耗很低，发热量极小，甚至风扇都不怎么转。

但是，放到2024年的今天，这性能确实有点不够看了。大概率和十年前的那种上网本、Atom处理器的平板电脑处于同一水平线。你千万别指望它能干什么大事，如果你脑子一热想装个Windows 11上去办公，那体验绝对会让你怀疑人生。

不过话说回来，咱们得辩证地看问题。它当年的定位从来就不是“性能怪兽”，而是一个“低功耗终端”。如今只要98元，还要啥自行车？在这个价位上，它依然是一台能点亮、能输出、能跑Linux的标准x86架构电脑。只要你不把它当游戏本用，它的性能对于跑一些特定服务来说，是完全溢出的。

这就引出了这台机器“第二春”的核心价值——飞牛OS（FnOS）。

作为捡漏这台机器的重头戏，飞牛OS和这台联想Q190的适配度，堪称是“天作之合”。当年联想出这机器的时候，压根没想过什么“个人云”、“NAS”的概念，主打的就是个便宜小巧。如今风水轮流转，它在二手市场摇身一变，成了飞牛OS的入门首选神机。

为什么这么说？因为飞牛OS对新手实在太友好了。相比黑群晖那动不动就要折腾引导盘、还要担心洗版的复杂操作，飞牛OS的安装流程简直是傻瓜式的。对于从来没接触过NAS的小白来说，这也是那种“有手就行”的操作。

手机备份照片、远程下载电影、搭建一个小型的私有网盘，这些最实用、最高频的操作，在这台老机器上跑起来毫无压力。不用像技术宅那样整天对着黑乎乎的终端窗口敲代码，图形化界面一点就会。

当然，咱们也不能盲目吹捧，得实话实说。想在这台机器上追求丝滑的4K转码，或者同时开十几个Docker容器，那纯属做梦。Celeron 1017的CPU算力在那摆着呢，多开几个软件，桌面操作肯定会有点卡顿，这是物理规律决定的。

但是，咱们换个角度想，如果你只是需要一个24小时低功耗挂机的设备，用来定时备份手机里的珍贵照片，或者当个迅雷远程下载机，这性能是绰绰有余的。特别是当你把它关在角落里，通过网页访问的时候，你根本感觉不到它的迟缓。98元的硬件成本，换来一套完善的数据备份方案，这性价比真的是没谁了。

可能很多动手能力不强的小伙伴会担心：“这老掉牙的主机，现在买回来会不会有很多兼容性问题？买回来配件插不上怎么办？”

其实这担忧完全是多余的。这机器虽然年纪大了，但标准还在。它支持最常见的DDR3笔记本内存（DDR3L低压内存更好，不过普通的一般也能带），接口是标准的SATA 2.0/3.0接口。

现在的二手市场上，这类配件属于“白菜价”。你随便花个二三十块钱，就能淘到一条4GB的DDR3内存；再花个四五十，买个120G或240G的杂牌固态硬盘。全套下来，主机98元加内存硬盘70元，总成本也就一百六七十块钱。

这就跟拼乐高一样，你只需要一把螺丝刀，五分钟就能把这台“准系统”变成一台全功能的迷你NAS。而且飞牛OS是基于Linux定制的，对老的硬件支持度非常好，不需要你去改什么BIOS设置，也不需要担心驱动找不到。我在刷机的时候特意逛了一圈相关的技术论坛，发现用这机器刷飞牛OS的大佬们反馈出奇的一致：稳定。

这机器不像现在的某些国产小主机，三天两头死机或者断网，老联想的做工底蕴在这里，供电稳，bios成熟，属于那种“买不了吃亏，买不了上当”的类型。只要你不嫌它丑，它就能在角落里给你默默打工好几年。

最后聊聊这次折腾的感悟。电子圈有一句名言：“垃圾只是放错了地方的资源。”

这台联想Q190，如果放在普通的办公场景下，它确实是一台跑不动新软件的电子垃圾，甚至连百元平板都不如。但只要我们把需求精准定位在“家庭私有云存储”这个细分领域，用飞牛OS去挖掘它的剩余价值，它立马就变成了一台极具竞争力的“神器”。

这也许就是我们这些爱逛二手鱼的人最大的乐趣吧——用最少的钱，通过合理的技术手段，去榨干硬件的最后一滴油水。

不知道各位读者朋友在二手平台上都捡到过什么好货？有没有遇到过比这98元联想Q190还香的低价宝贝？或者是那种几块钱买到顶级音响、几十块淘到绝版显卡的传奇经历？欢迎在评论区留言分享你的捡漏故事，让我也学学鉴宝技巧，争取早日从“鉴宝学徒”升级成“鉴宝大师”。

老规矩，看完不买，立省98元，毕竟折腾的乐趣也是要算成本的嘛。
