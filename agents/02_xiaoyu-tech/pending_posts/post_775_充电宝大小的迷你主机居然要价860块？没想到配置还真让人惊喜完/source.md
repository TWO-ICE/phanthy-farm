# 充电宝大小的迷你主机居然要价860块？没想到配置还真让人惊喜

今天在二手鱼刷到了一个袖珍的小主机，标价860元。第一反应是：这玩意儿比我的充电宝还小，敢要八百多？转念一想，现在的迷你主机卷得厉害，说不定真有料。点进去一看参数，好家伙，CPU用的是Intel N100，板载DDR5 12GB内存，还塞了1TB M.2固态，这配置放在新机里都得一千往上走。还真是没想到，这小东西里面居然藏着这么多大宝贝？


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHibAMO6h0I6JjoOiciaX1ViboZ5LWACA8AxNqT4zUYKreS7tTlBlZpWoTI2YJPJR1jYOHAVOYL1Qzibibg/640?wx_fmt=png)


先说说这颗N100处理器。虽然是低功耗U，但毕竟是Alder Lake架构，4核4线程，基础频率0.8GHz，睿频能到3.4GHz。日常办公、看4K视频、轻度PS完全够用。比起那些J4125、N5105的老古董，性能提升不是一星半点。而且功耗才6W，插电即用，放客厅当HTPC都安静得很。不过别指望它打游戏。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHibAMO6h0I6JjoOiciaX1ViboZpXt9bUHoe8tlXnnB4ej5XAVh8MBELE0qxwWFXOo2ytRrO95dl6NJbw/640?wx_fmt=png)


内存和存储这块也挺实在。板载12GB DDR5，虽然不能扩展，但日常使用绰绰有余。1TB M.2 NVMe固态，读写速度比SATA快不少，系统响应飞快。对比二手鱼上同价位的其他品牌迷你机，很多还在用8GB+256GB的组合，甚至有些是拆机盘。除此之外，还配了Ax201无线网卡——支持Wi-Fi 6和蓝牙5.0，这在同价位里算良心了。千兆网口+Type-C供电，出差带着也方便，一个PD充电头就能搞定。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHibAMO6h0I6JjoOiciaX1ViboZ0Xhdh38o5GtkasrnYMEAGkiamUuqNK6OoNjnia55UbaN3ujd5btLrGGA/640?wx_fmt=png)


当然，缺点也不是没有。首先，板载内存没法升级，买定离手；其次，散热全靠被动，高负载下可能会降频。不过考虑到体积只有127×127×42mm，这些妥协也能理解。毕竟“麻雀虽小，五脏俱全”，总不能指望巴掌大的机器干台式机的活吧。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHibAMO6h0I6JjoOiciaX1ViboZkpbiak6fzo6rkSYcQPlYzGQichbMrt4v5M2QuREgEcRs3ZoGf2HHGb0A/640?wx_fmt=png)


可能有人会问：这CPU N100到底够不够用？会不会用不了多久就淘汰？根据我在网上搜的信息，有用户反馈说，N100在日常办公、网页浏览和轻度娱乐中表现稳定，功耗低，电费省心。但如果你是用来玩游戏或做设计，那就不推荐了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXHibAMO6h0I6JjoOiciaX1ViboZMJjPMUWBNb0CwIDEFVVxDL3N540VOmOUP0nlx1puYDmYicKGaHiaXarQ/640?wx_fmt=png)


结合当前二手鱼上这类迷你主机的行情，我给网友们几点建议：

1. 这个产品有降价的空间，不着急可以在蹲蹲。

2. 别指望高性能，但日常使用完全可接受。

3. 注意检查是否支持你所需的接口和系统。

4. 这东西淘宝上有同款，新品价格不过超1000。

5. 看完不买，立省860元。
