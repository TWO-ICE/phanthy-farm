# 二手鱼169元捡到爱普生白色迷你主机，刷飞牛到底香不香？

在二手鱼里看到了这款爱普生ST180E 白色 迷你主机， 售价 169元，卖家标注是飞牛NAS优选机型，支持6代低标压CPU，还带双2.5寸硬盘位。 169并不是完整的主机，而是准系统的价格，那么169买一个机箱+主板到底划不划算呢？


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenIaibX7icMFQicDls20PbR9iakkDJlHwLrTUzyU6N1ElFItiaca0w1npnUrrd3ORibGYycWjRQRgHPddmOh8mvsNanLibuLk3N84BX2k/640?wx_fmt=png&watermark=1&tp=webp)


先说说核心参数，这款是商用工控机出身，体积小巧不占地方。核心亮点是支持6代Intel低功耗CPU，有2个笔记本DDR4内存插槽，2个2.5寸硬盘位，还有mini HDMI接口。默认准系统不带电源CPU内存硬盘WiFi，加双频蓝牙无线网卡30元，90W电源40元， 卖家也提供 整机，套餐从528元到838元不等。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekXGqZOdvYtE07q0dy5BIf5wW2SOIbia5lllcBqHXrOcSV11yQRw7vlnThwdDIZVib2Wa3PgqpmeGicb3j1xZ17pox1WPmtStiaecU/640?wx_fmt=png&watermark=1&tp=webp)


很多人买这种小主机基本都是用来 刷飞牛，这款机器确实有天然优势。飞牛对X86平台兼容性不错，低功耗设计很适合做NAS存储或下载机。双硬盘位刚好满足基础RAID需求，6代CPU性能足够日常文件共享和影音服务，比很多ARM架构的百元NAS性能更强。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelOjeq3cIaH8GoMch4aqhUTyWp1CumS66VoovfXHzRbc0cZHm0iaekKGPakCKsxzvibplxBQ7lgYiaQSjicFcsGNeTQCRpKqyoVNno/640?wx_fmt=png&watermark=1&tp=webp)


但它也有明显短板。作为老款机型，没有M.2接口是硬伤，只能用2.5寸硬盘，读写速度和扩展性不如新款。准系统本身不带无线网卡和电源，算上配件成本大概240元左右，虽然还是便宜，但需要额外支出。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemWX652ib96TkJ1miartSMr1hn3dXlFo1fX8ftJZAWbUnXPdtUWT4ZaCa5H6IQcEvK59xYL3u1QF7wvcCzUOV3rhChLIRvq9rTbM/640?wx_fmt=png&watermark=1&tp=webp)


从性价比来看，169元的准系统适合有闲置配件的用户，能把家里淘汰的6代CPU、笔记本内存和旧硬盘利用起来，总成本控制在300元内就能搞定一台NAS或轻办公主机。如果需要整机，648元的i3 6100T+8G+240G套餐性价比最高， 但是我感觉价格没什么优势，没有自己单配划算，但你若是懒得折腾，选卖家的套餐也并不算亏。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemwcUZSyqAPN3V21QKyQRtDJ6lZF5TA4bjEyAPichYxibk8y6LJ838ao9qDkfxbXVfasWUN5unPObwxyN1QJjjKIXIqyRZWu4ubg/640?wx_fmt=png&watermark=1&tp=webp)


另外要说的是，这批机器并不是全新的，卖家也没有说成色如何，所以对外观有要求的用户，建议和卖家提前沟通，如果你真打算下单，到手后建议要 优先检查主板供电和接口完好度，工控机可能存在长期使用后的老化问题，避免翻车。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemic08QjVEoBSuahzfMchAlqPAgKAVA1YQ7iajLgVfCVwYsH3P0QmHHKR5CN95vsVL1sjOibQ8ZfmGQuBtqB5Td0rXFr6RHiaMXbc0/640?wx_fmt=png&watermark=1&tp=webp)


你们觉得169元的准系统值得折腾吗？如果是你，会选准系统自己组装还是直接买整机套餐？有没有用这款机器刷过飞牛系统的老铁，欢迎在评论区分享使用体验，让更多垃圾佬少走弯路。
