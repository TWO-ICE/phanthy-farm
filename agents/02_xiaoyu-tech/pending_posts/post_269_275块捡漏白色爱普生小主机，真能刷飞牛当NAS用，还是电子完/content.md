# 275块捡漏白色爱普生小主机，真能刷飞牛当NAS用，还是电子垃圾？

今天在闲鱼“扫货”的时候，一条推送让我有点挪不开眼：一台标价275元的白色爱普生（Epson）迷你主机，型号是Endeavor ST190E。

说实话，这玩意儿在二手数码圈子里算是“老面孔”了，但能碰上成色还行、价格还这么香的，依然有点像在电子垃圾堆里淘金。卖家是个实在人，文案写得直白：这就是个商用办公退役下来的小主机，体积大概只有巴掌大。

虽然外壳看着像个电视盒子，但这机器的“芯子”其实挺能打。它支持英特尔的第8代或者第9代桌面级处理器，注意是桌面级，不是那些弱鸡的移动端U。这就意味着，像i3-8100、i5-9500这种经典的“神U”，它都能吞得下。

再来看扩展性，这才是这机器的灵魂所在。它给了两个DDR4内存插槽，不管是凑手头的旧内存，还是想低成本升个大容量，都很灵活。存储方面更是堆料：有一个M.2 NVMe固态硬盘位，速度起飞；同时还极其良心地给了两个2.5英寸SATA硬盘位。懂行的朋友知道，在这个体积的机器里塞进两个SATA口有多难得——这意味着你可以直接把两块机械盘塞进去做RAID或者冷存储，不用再折腾外挂USB硬盘柜了。此外，还有一个M.2 NGFF插槽，专门留给你装无线网卡，或者捡个Intel AX200吹个Wi-Fi 6。

接口方面，这台爱普生简直就是个“章鱼”精。视频输出搞了个“全家桶”：VGA、DP、HDMI齐备，这意味着你哪怕没有高级显示器，把它接在老公司的CRT显管管上或者家里的投影仪上都能亮。更有意思的是它支持三屏输出，做股票看盘或者多任务处理简直是神器。USB接口数量更是惊人，前前后后加起来居然有8个，除了常规的A口，还塞了一个Type-C，其中两个USB 3.2 Gen2接口速率能跑满10Gbps，拷贝大文件的时候这速度优势太明显了。在同体积的迷你主机里，这个扩展配置绝对算是“豪华顶配”级别。

不过，这里得给想冲的新手泼盆冷水。这275元的价格，拿到的仅仅是个“准系统”。啥叫准系统？就是除了机箱、主板、散热器这三个骨架子，剩下的能动的零件——CPU、内存、硬盘、WiFi模块，甚至连电源适配器，统统都没有。你想让它干活，得自己掏腰包填坑。

一般这种商教退役机型，电源都是专用的特殊规格。卖家这里配的是个黑色的90W圆口电源适配器，得加40块钱；如果你想装个无线网卡，大概还得再加30块钱。加上这些杂七杂八的，包邮到手可能得奔着350块去了。但即便如此，看到这配置，我脑子里还是蹦出那个经典的评价：这不是电子垃圾，这是传说中的“静音NAS圣体”。

之前在B站硬件区或者图吧贴吧，经常能看到有大佬拿ST190E或者它的黑色兄弟版JS190魔改。这机器简直就是为软路由、NAS或者All-in-One家庭服务器而生的。它的优势太明显了：功耗低、发热量小、被动散热或者低速风扇下噪音几乎不可闻，体积小到可以塞进弱电箱或者电视机柜后面。关键是，作为企业退役货，它的价格已经被压到了地板上。

如果你像我一样，抽屉里正好躺着几颗淘汰下来的8代、9代酷睿i3或者i5，再有几根闲置的DDR4笔记本内存条，那这台机器对你来说简直就是“白嫖”。只要再花几十块买个NVMe固态装系统，整机成本就被锁死在300块出头。哪怕你是一穷二白，所有配件都去买散片新的，比如i3-8100（百元价位的一代神U）、8G内存、256G固态，加起来可能也就300多，全套配齐控制在600元以内毫无压力。

600块钱能干什么？在这个价位，你想买个成色不错的二手群晖或者威联通（QNAP）？那是做梦。但DIY这台爱普生，它能跑轻量级NAS、能做OpenWrt软路由、能当24小时挂机的下载机，甚至装个Home Assistant做智能家居中枢，或者挂个轻量级的Linux桌面系统做个HTPC（家庭影院电脑），连接电视看4K电影，它都完全扛得住。

可能有人会杠：这老掉牙的架构，性能能行吗？特别是想跑最近很火的“飞牛”（FNOS）或者其他NAS系统，会不会卡成PPT？

这里得科普一下飞牛OS的胃口。飞牛这系统其实对硬件要求不算变态，官方推荐的最低门槛也就是i3-8100加8GB内存。你看，ST190E这平台刚好就卡在这条线上，简直是“精准卡位”。8代酷睿虽然老了，但它的架构性能放到现在依然能打，而且视频解码能力、虚拟化支持都还不错。

更重要的是，这机器自带两个SATA口。很多人玩小主机NAS，最头疼的就是M.2接口虽然快，但大容量SSD太贵，而SATA接口又往往只有一个或者需要转接卡，这就会遇到供电不稳或者体积装不下的问题。ST190E直接给了原生SATA，你可以直接塞两块4TB红盘进去，稳稳当当组个存储池。如果你玩NAS的需求只是搭个家庭影音库（Jellyfin/Plex）、自动备份手机照片、跑个Alist挂载网盘资源，或者偶尔BT下载点冷门电影，它完全够用，甚至性能过剩。

当然，世上没有完美的产品，尤其是这种捡垃圾级别的洋垃圾。想要入手，必须先认清这几个坑：

第一，电源是个隐形坑。这机器设计比较早，使用的是那种比较少见的圆口DC电源接口，而且必须是特定的规格。原装的90W电源还算好找，但如果你想自己配个第三方的，适配性很成问题，搞不好就电压不稳或者插头对不上。别为了省十几块钱去买不知名的电源，容易炸机。

第二，CPU的选择要有节制。虽然它支持8代9代，但机箱体积和散热模组在那摆着，TDP（热设计功耗）最高只支持到65W。你可以塞i7-8700进去，但大概率会因为散热压不住导致降频死机。最明智的选择是i3-8100这种只有65W甚至更低TDP的U，或者用T系后缀的节能版CPU，这才是它的最佳拍档。

第三，BIOS陷阱。这些商用机从公司淘汰下来，经历多手，BIOS版本可能五花八门。有些老版本的BIOS可能不支持高频内存条，或者对新步进的CPU识别有问题。如果你手头有现成的内存和U，下单前最好厚着脸皮问卖家一句：这板子BIOS刷到最新了吗？我的XX型号U能不能亮？

最后，关于价格。275元这价格，在这个时间段确实算是“好价”。之前这机器行情一直在300-350徘徊，现在跌下来可能是因为企业大规模淘汰，或者大家都在等12代酷睿的小主机。如果你遇到的卖家是新号、无实名、还没什么评价，哪怕他比市价便宜50块，也别贪。电子产品这东西，这行“宁买贵，不买当”，找个信誉好的老商家，哪怕贵二十块钱，东西到手没问题才是真的省心。

我们要理性看待这个所谓的“捡漏”。现在市面上那些全新的J4125、J5040小主机，价格还要三四百呢。虽然它们做工新、有保修，但在绝对性能面前，J4125这种“赛扬”处理器连i3-8100的尾灯都看不见。不管是跑分还是实际体验，8代酷睿吊打那种十几二十块钱的笔记本CPU是轻而易举的。

ST190E作为商用退役机，最大的优势就是它在同价位提供了最强的扩展性和稍高一档的性能门槛。275元虽然不是什么“惊天捡漏”，但在目前的二手市场行情里，绝对属于“合理好价”。

但是，我必须把丑话说在前头：这机器适合你吗？这取决于你愿不愿意折腾。如果你是一个只想要插电即用、坏了就找售后的“小白”，那我劝你放过它，去买群晖或者正儿八经的成品NAS。但如果你是个喜欢自己动手装系统、插内存、拧螺丝，看着硬盘灯闪烁会感到莫民兴奋的“垃圾佬”，那这台爱普生小主机绝对能给你带来远超275元的快乐。

想试试的朋友，现在就可以打开二手平台，搜“爱普生小主机Endeavor ST190E”。如果运气好直接搜到了，好好看看卖家描述；如果搜不到，利用平台的“拍立淘”功能，把网上这机器的照片上传去反搜。如果连图搜都找不到，那恭喜你，这玩意儿刚被其他捡漏狗秒了，这种高性价比的电子垃圾，流通速度快得惊人。

在结尾前，我再给真心想入手的朋友几点掺了干货的建议，别光听我说得热闹，真买了还得折腾：

1.  **别光看价格，先问清状态。** 收到货可能是“裸机”，一定要问卖家主板是否测试过？CMOS电池是不是漏液了？能否点亮亮机？买回来连个BIOS都进不去，那就真成纯垃圾了。
2.  **自备CPU内存前，务必功课。** 别以为只要是8代U就能上，最好去搜一下这型号的主板BIOS是否支持你的特定CPU，比如i3-8100T或者i5-8500T。别买了发现不点亮再去找卖家扯皮。
3.  **想做NAS？优先配机械盘。** 这机器的双SATA是最大亮点。建议买个NVMe固态只装系统（256G足够），资金全砸在两块大容量SATA机械盘上，组个RAID 1做备份，这才是正经NAS的用法。
4.  **最后一条定律：看完不买，立省275元。** 无论是NAS还是软路由，本质都是为了折腾。如果你家里没有挂机下载、去广告、私有云的刚需，这台机器大概率会在你买回来插电亮机的那天，在吃灰两三年后以150元的价格再次出现在闲鱼上。理性消费，按需购买。
