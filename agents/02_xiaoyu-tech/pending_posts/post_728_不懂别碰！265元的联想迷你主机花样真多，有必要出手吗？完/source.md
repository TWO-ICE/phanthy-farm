# 不懂别碰！265元的联想迷你主机花样真多，有必要出手吗？

![封面图](https://mmbiz.qpic.cn/sz_mmbiz_jpg/E9h3abOJCelrm4ATeREGSoMrk1Nu170V9WdpsZAdPTfvWeQNohXTgjUicRNEwCiauFeYcY5DwiaR4g9iaj6jPib252NibE7ANAEmuZtFzdkvAG3jg/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/PEZc6v8a63saD1HbiuQfRA

这两天刷二手鱼，看到个挺有意思的东西。联想的M910X小主机，现在被一些卖家魔改了BIOS，准系统挂265元起。让它能支持八代、九代甚至是一些魔改的至强处理器。这就很有意思了，原本只是性能平平的小盒子，一下子有了点性能小钢炮的潜质。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCektOT0dVJHLdJqZ2zW2eMqjd255YiaxygL2yuVm6aANOM6wuBibKrwFHR0fQYlUWgSCAa9TibI7BjiawODmibOPtpIicFRreQnlZtfjE/640?wx_fmt=png&from=appmsg)


从卖家给出的信息看，这主板的扩展性确实挺离谱。两个M.2插槽可以插NVME固态，两个笔记本内存插槽最大支持64G，还有个PCIe插槽。别小看这个槽，这可以塞进去一块半高刀卡，比如特斯拉P4这种计算卡，或者搞个万兆网卡当软路由，可玩性一下就上来了。接口方面，VGA、HDMI、COM口这些老古董也能通过主板上的插针扩展出来，对于需要调试老旧设备的人来说，简直是神器。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenUVtDZZSLnC4CHRdxeKucBjuYamWmQAWN4ywicTpLr15z2PWrEwQRk4nKHre1XoOtSt1NEc1qficUbR5OgibXE5fEBMqiaV16AZAI/640?wx_fmt=png&from=appmsg)


但这里面坑也不少。265元只是个准系统的起拍价，不含CPU、内存、硬盘、电源，甚至连散热器可能都是最基础的单热管。如果你想让这台小主机跑得欢，加钱是免不了的。比如换个双热管纯铜散热，加70。想要个千兆网口，加60。想要HDMI或者Type-C接口，加的钱更多。电源也得单独买，从65瓦到135瓦，价格从30涨到50。一套看下来，如果你把那些扩展接口配齐，价格翻倍是很轻松的事。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemz4vVzlWu8TeHAl3YZmEC20FqcEP8E56UV8erQeO6QztiaGEUe3HTSETlQBRGibLUib4g8dbd21WtfbbEcd4KKp1KrgVRMGaZg8o/640?wx_fmt=png&from=appmsg)


站在咱们消费者的角度，这坑得看仔细。265元只是个入场券，魔改的东西BIOS被动过，稳定性是个问好，卖家也承认满载时噪音不小。如果你是手头有闲置内存硬盘的垃圾佬，想体验组装乐趣或者搞黑苹果软路由，那这价格确实值得一玩。但小白想靠两三百配主力机趁早打消念头，配件加一圈下来价格翻倍很容易。魔改BIOS那10元必须加，不然只能装老U，性能直接被封印，买这机器的意义就少了一大半。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemtnomE4B6NCT6l8U8GiccFML1oibKd8Q7tyXTnhnWqVqMT9fh8CRDWrvbAvbibo6He45KSenJINfEn4sZteb1M99wmnDQJQjmF3A/640?wx_fmt=png&from=appmsg)


如果我自己要搞一套，我会选择265元准系统加10元魔改BIOS，散热换双热管加70，电源选90瓦加40，VGA网口这些我不需要就不花冤枉钱，总共385元。然后去二手鱼蹲个QNCT魔改U大概200多，配两根8G二手内存和128G M.2固态，总成本控制在800到900元。这套配置做NAS、软路由或者客厅4K播放机都绰绰有余，比买那些小众品牌靠谱得多。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCel1PZgibApoa0jWT8sN4Pgzx2J5yBvXjZlPoFj7NtoySu1OByX7OqPnM27U7ccOW3ibiaLNKo3G34SqMNUNFNoLIxZTmshF2C8LdE/640?wx_fmt=png&from=appmsg)
