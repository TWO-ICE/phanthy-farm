# 能刷飞牛的惠普小主机，88元准系统是捡漏还是踩雷？

今天在二手鱼刷到了惠普HP T628台式小电脑，标价88元。乍一看价格低得离谱，点进去才发现是裸机，没内存、没硬盘、也没电源。不过卖家还列了几个整机套餐，从188元到298元不等，配置不同，到手即用。这种“准系统”玩法，在二手鱼上其实不算新鲜，但配上J1900这颗老U，再加上“适合做达菲主机、旁路由、NAS”的标签，确实勾起了我的兴趣。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGjM9xITnPiaiaicUJmf8ic1PCiazvSmoTia9YbaXnphicfxrJ2ziap6scRc2xG0siaiagfMXlQrLPAOCWQ3HjQ/640?wx_fmt=png)


先说说这台机器的基本参数。处理器是英特尔J1900，四核四线程，主频2.0GHz，性能放在今天当然谈不上强，但胜在功耗低（TDP仅10W）、无风扇设计、稳定性好。机身尺寸24.5×20×5.2cm，体积比普通路由器大一圈，但比传统台式机小很多。内部有两个硬盘位：一个M.2 ，一个2.5英寸SATA位。内存插槽只有一个，支持DDR3L低压笔记本内存，最大16GB。网络方面是板载千兆网口，预留了无线网卡安装位，但需自行加装。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGjM9xITnPiaiaicUJmf8ic1PCiaErFO1icyF0oOQa4mqtY7RicDRWSFTC7iaJ0APOAaQThW9xdqfv0iaZWVCA/640?wx_fmt=png)


这类瘦客户机原本是企业用于远程桌面终端的设备，如今被极客们“废物利用”，改造成轻量级服务器。比如跑软路由、下载机，或者刷飞牛OS搭个简易NAS，都是可行的。J1900虽然不能硬解4K视频，但应付1080p转码、文件共享、Docker容器等轻负载任务，问题不大。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGjM9xITnPiaiaicUJmf8ic1PCia2gibFPOFbzLrIhqgM14WiaHvUSmhPqcXZPKD3ZK8icbUMwA6iczPWoKh8Q/640?wx_fmt=png)


不过得理性看待它的性价比。2025年存储价格普遍上涨，一条4GB DDR3L内存要45元，8GB要90元；一块128GB M.2 2242固态也要80元；电源另加30元。如果从88元裸机开始配齐，成本轻松突破200元。而对比市面上新出的国产ARM小主机（如零刻、极空间入门款），虽然性能更强、接口更全，但起售价往往在400元以上。这么看，T628在200元内确实有成本优势，前提是你愿意折腾，且对性能要求不高。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGjM9xITnPiaiaicUJmf8ic1PCiaEefs4GkotHQvoLE18OPTwTqlSv3FKjrhS4PQ1kPWtWOibs7z5kvxibzA/640?wx_fmt=png)


可能有人会问这机器能刷飞牛吗？可以，但有限制。飞牛OS官方虽未明确支持J1900，但社区已有成功案例。不过由于CPU年代久远，部分新功能可能体验不佳。更适合用来做单功能设备，比如纯文件服务器或旁路由。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGjM9xITnPiaiaicUJmf8ic1PCiabPftuxiaHUYHPk1p4PNuLCVSXq43FEibFjcaNZVoMibhHHRf9dedPyPNQ/640?wx_fmt=png)


那么88元裸机到底值不值？关键看你手头有没有闲置配件。如果你家里正好有旧笔记本拆下来的DDR3L内存、M.2固态和19V电源，那88元拿下主机本体堪称捡漏。但若全部从零配起，总成本接近250元，就要掂量值不值得了，毕竟同价位也能买到更新平台的迷你PC整机。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGjM9xITnPiaiaicUJmf8ic1PCiaJ8VMhJEvbH5o7ZFvgGpibHkAxuZFdicXnMprEzHYkg60yCx7a78FhDhA/640?wx_fmt=png)


对此产品有兴趣的话，可以在二手鱼搜索“惠普HP T628台式小电脑”这个关键字就可以找到此产品，如果找不到可以通过图片进行搜索，都搜索不到的话，那可能是此产品已卖出或者是下架了。


 


以下是个人一些掺了水的建议：

1. 仅推荐给喜欢折腾或有配件库存的用户。

2. 别指望它当主力机，用途越单一越合适。

3. 配整机套餐比单买裸机更省心，但注意邮费。

4. 看完不买，立省88元。
