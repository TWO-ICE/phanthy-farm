# 这价格有点离谱，二手鱼119元包邮的全新Z3735F上网本，值不值？

今天在二手鱼刷到了一款10寸 Z3735F 2+32的上网本，标价119元还包邮。点进去一看，差点以为自己误入了电子垃圾回收站，掌柜描述里写着“包装完好”，只是类肤涂层有点老化，摸起来略粘手，整体成色被戏称为“伊拉克成色”。说实话，这个价格简直刷新三观系列，正应了网友们那句话：“虽然，我是捡垃圾的，但是我不是什么垃圾都捡”，但这价格属实让我忍不住点开详情。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXE3vwzrmoZ5CNOvBxgqk2IMvffCxyJTqqMVoZI7NriaGZmasrwZ0rIW5LxveVfRbvRZOedIiayz6K8g/640?wx_fmt=png)


先说说这台小本的配置吧。它搭载的是Intel Atom Z3735F处理器，四核四线程，主频1.33GHz，睿频能到1.83GHz，22纳米工艺。放在2014年前后，这颗U可是不少入门级Windows平板和迷你笔记本的标配，主打一个“省电不烫手”。虽然性能没法跟现在的i3比，但应付看网页、聊微信、写个Word文档还是勉强够用的。配上2GB DDR3L内存和32GB eMMC存储，系统跑的是Win10 32位英文版（法语键盘），想要中文？自己联网下语言包去。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXE3vwzrmoZ5CNOvBxgqk2IMz81on6g0G7fA4FyBmdueIvHRGnIialjia4Ocib621m5Mz9ZaJuN7Ekbcw/640?wx_fmt=png)


屏幕是10.6英寸，分辨率1366×768，属于标准的HD屏，亮度和色彩表现嘛……只能说“能亮就行”。外壳是MPMAN品牌，没听过？正常，这牌子当年主要做出口，国内几乎没人买。现在翻出来当库存清仓，倒也算物尽其用。掌柜特别强调：“只做基础开机测试，充个电能亮屏就发货。”言外之意就是：别指望我给你测USB口通不通、WiFi稳不稳定，爱拍就拍，不拍拉倒。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXE3vwzrmoZ5CNOvBxgqk2IMia45aeicVsgkJOVVTNtaOficxWUROu26mRvzSUhSiasJcLkGXmrkYADhdw/640?wx_fmt=png)


那么问题来了：这玩意儿还能干点啥？可能有人会问：“Z3735F现在连Chrome都打不开吧？”其实不至于。轻量级浏览器比如Edge Legacy或者Firefox ESR还是能跑的，YouTube 480p也能勉强播，前提是别开太多标签页。更别说装个Office 2016轻量版，写写作业、做做PPT完全没问题。甚至有网友实测过，这U还能硬解1080p H.264视频——虽然播放器一卡一卡的，但至少不会直接蓝屏。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXE3vwzrmoZ5CNOvBxgqk2IMhYiaLsA92WsvhrJa9l1hzwCm4GFbCfAibbZ7gYibYDeKLSS84FxXyPUug/640?wx_fmt=png)


还有人可能会嘀咕：“119块买个新电脑？怕不是翻新机套壳吧？”其实从产品描述和成色来看，更像是当年滞销的出口尾货。这类机器在2015年左右海外售价大概在150美元上下，如今十年过去，仓库角落积灰，清仓甩卖也不奇怪。而且掌柜明确说是“全新库存”，连电池都没怎么充放电，反而比那些二手拆机件靠谱些。当然，你要是指望它打《原神》或者剪4K视频，那不如直接拿它垫桌脚。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXE3vwzrmoZ5CNOvBxgqk2IMpbA0hyc79aZViaW9VYQbRwZiaTofMNTzlDHusqe7V5b5VQbVYsdRnAyw/640?wx_fmt=png)


说到优势，这台小本最大的亮点就是“新”和“便宜”。119元买一台带正版Win10系统的全新笔记本，哪怕性能孱弱，也比某些百元安卓学习机强——至少它是个真正的PC。而且体积小巧，重量轻，塞书包里毫无压力。缺点也很明显：2GB内存多开两个程序就卡死，32GB存储装完系统只剩十几GB，法语键盘打字得靠猜，类肤涂层老化后还容易沾指纹和灰尘，手感像摸了层胶水。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXE3vwzrmoZ5CNOvBxgqk2IMy7SoCbbLlOlHcRbRIu9fvdx3VfHtjgspmUKB07gVicv9ZqhR9vAImug/640?wx_fmt=png)


可能有人会问：“这价格是不是有坑？会不会到手就坏？”掌柜已经提前打了预防针：“追求完美的、爱扯皮的慎拍。”说白了，这就是个“能用就行”的底线产品。如果你只是需要一台能开机、能联网、能打字的设备，比如给老人查天气、给孩子写寒假作业，或者当个数字相框循环播放家庭照片，那它性价比还挺行。这个价格还要啥自行车？总不能指望它起飞吧。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXE3vwzrmoZ5CNOvBxgqk2IMBiadJDUpeRGiaZvWpDpvCoWBoqcLKuRD9ia8FV1ib5HicsTibzUicQu1tF19Q/640?wx_fmt=png)


那么，值不值得冲？看需求。如果你手头紧、需求低、心态好，119元买个全新Win10笔记本，图个新鲜或应急，完全可以试试。但要是你对流畅度、扩展性、键盘手感有要求，建议绕道。毕竟，“虽然我是捡垃圾的，但我不是什么垃圾都捡”——这话放这儿挺应景。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXE3vwzrmoZ5CNOvBxgqk2IM8xUjqicpJatxVj0H1ojZGsgvq6Uiayte1mSVyhWpL6xpBEgWkwIsAsyA/640?wx_fmt=png)


最后留个互动：你手里有没有类似的古董设备？或者你觉得这台Z3735F还能怎么玩？装Linux？改路由器？还是拆了当电子积木？评论区聊聊呗。老规矩，看完不买，立省119元。
