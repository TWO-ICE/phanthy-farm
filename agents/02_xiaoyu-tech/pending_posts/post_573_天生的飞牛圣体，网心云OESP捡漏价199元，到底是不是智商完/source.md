# 天生的飞牛圣体，网心云OESP捡漏价199元，到底是不是智商税？

为了省点NAS的预算，我这段时间差点把二手鱼给翻烂了。你还真别说，最近让我发现了一个稀罕物，网心云的OES Plus，有人直接挂199元全国包邮，说实话，我还真有点动心了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelBZwiaVRSqBQH9lGyZ5QMXszeaNNG5Ox4DesUvOWlSDgRGL38F7BYx7fic5o28g3ubuX0iahaFD7gPxt3RAwrrh71CumbbFA2zUQ/640?wx_fmt=png)


可能很多玩NAS的朋友第一时间想到的是网心云的OECT，那玩意儿确实火过一阵子，被誉为入门神机。但这回这个OES Plus是OECT的升级版，而且是那种实打实的性能翻倍。6核CPU，性能是老款的两倍左右，带原装电源，双千兆网口，最关键的是它有三个硬盘位，两个能上9mm的盘，还有一个7mm的位置。功耗还不到10W，这玩意放家里当个下载机或者影音服务器，简直不要太合适。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCem702NoHCfFVvuf8FgUxhUX0qd71ibEEsfu8epSh7AECfEBBSUBMQzAjcTSGYnhibDNhAMqkToa5VLt4zMDibdZs92spbn65b7x18/640?wx_fmt=png)


这机器主要是给刷飞牛Nas的用户准备的，配置双网口，可以搞链路聚合，或者直接当个软路由的备胎，三个硬盘位可以不用像玩OECT那样纠结于单硬盘的局限，资料备份或者电影存放都更灵活。而且它的GPU比Oes要强一点，这对玩影音来说是个加分项，硬解起来更从容，不用瞎折腾了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemVbiaKUWicicTH8GBph2Ymwsaxgwe3XL46As8FD65YqScT9QRyer9bzwszsJowhvjqOaKTdicn8DS9WQYUGKQ36tuTpCaQm6ibERAw/640?wx_fmt=png)


当然，这玩意也不是没有槽点。USB接口给的还是2.0，这要是想外接个高速U盘或者移动硬盘倒腾数据，速度就有点捉急了。另外，虽然有三个硬盘位，但都是给2.5寸机械硬盘或者固态硬盘准备的，你要是想上大容量的3.5寸企业盘，那还得另想办法供电和固定，这就考验咱们垃圾佬的手工能力了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemNVFNH4FsNyN6V5jM2nfdsk772KxOF147iaicv37acuSWDwJw7LN96DTSd8ZB8A5dZpmB2ZWPqsQsFfC4nxU0lsZSSx9YaibCgCU/640?wx_fmt=png)


我看了眼现在的二手行情，稍微像点样的、带点品牌的成品NAS机箱，随便一个空箱子都敢要你100+。那些所谓的工控小主机，配置差不多的也得300+起步。这么一对比，OES Plus这个199元带原装电源还包邮，性价比就比较高了，这对于我们这些预算抠搜、想体验NAS又不想一上来就投入大几千的小白来说，算是比不错的选择。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekD9dVuztGYHB4I1zicMrYO2lcZV0g1KGf3qu84t1fmpGLOB1y3nGiaJArO2S35mQe05uCV7WXo6OMETIKnLoROicicCIEibKeibWRaI/640?wx_fmt=png)


要是你手里正好有几块闲置的2.5寸硬盘，又想低成本入坑飞牛，体验一下All In One的快乐，那这199元真就是一顿饭钱，买回来当个大玩具折腾，失败了也不心疼。但如果你是指望它当主力NAS，存重要数据，或者对传输速度有极致要求的，那建议你还是加点钱上正经品牌，毕竟数据无价。
