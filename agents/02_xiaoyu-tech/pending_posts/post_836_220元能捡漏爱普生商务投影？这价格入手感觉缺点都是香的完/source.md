# 220元能捡漏爱普生商务投影？这价格入手感觉缺点都是香的

![封面图](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXFJcRZpJ9mCIlj6hE6ib0Uc1YbNZ3CLD8snWsUekIcTUxE7WRrqbj3dfMZiaJSjxicknn3kFvKib250nA/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/AuTeBEb4Z4CCevvrBhqx5g

一台当年卖三四千的商务投影仪，如今在二手鱼上只要220块！不是山寨，不是翻新机，是正儿八经的爱普生EB-C30X。看到这个价格，你可能会问这玩意儿还能用吗？这价格入手是捡漏还是捡雷？


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFJcRZpJ9mCIlj6hE6ib0Uc1Mv6Xe3RVo9Wh1OnyFiaCyUtqibw7y9c6BIAwU62JBPYvu0fH9lib2v4oA/640?wx_fmt=png)


我仔细一查，发现事情没那么简单。首先可以确认的是爱普生EB-C30X这款投影是10多年前的老机子。2800流明的亮度，分辨率1024×768，虽然现在看有点Low，但放PPT、看教学视频、投个老电影完全够用。关键是，它有HDMI接口！要知道，同期很多同价位机型还在用VGA硬扛，连音频都得另接线。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFJcRZpJ9mCIlj6hE6ib0Uc1iafq2gB8E06vgBBxSmibLx5XVQXQTibuHjouWrUt85icYNxLUsGfYh8U1w/640?wx_fmt=png)


卖家说“功能正常，已测试”，但没提灯泡寿命。这是关键！爱普生这款用的是UHE冷光源灯泡，原装寿命约4000小时。如果机器用了十年，按每年200小时算，可能已经接近极限。但好消息是：换灯泡成本不高，第三方灯泡百来块就能搞定。所以，220元买整机+后续百元维护，换来一台亮度足、接口全、品牌靠谱的投影仪，值不值？


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFJcRZpJ9mCIlj6hE6ib0Uc1y2Vgge0iaLYj1J7zjuo2EmXDjsueH9Qg69nXyWibWDtiaVztdg3GBRbsQ/640?wx_fmt=png)


而且，它真的实用。即使没有幕布，用它投白墙，晚上看片字幕清清楚楚；朋友来玩Switch，接HDMI秒变大屏，延迟几乎感觉不到，毕竟不是智能系统，纯信号直通。办公更不用说，插U盘、接笔记本，开机即用，比现在那些卡成PPT的智能投影省心多了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFJcRZpJ9mCIlj6hE6ib0Uc1ngpbEcDMFaxgAP7ibsBpBMibXpicUgSghfbo3RNb7po1dYb3o6iafGMRfg/640?wx_fmt=png)


当然，缺点也有：没有自动对焦、不能无线投屏、体积偏大。但想想价格——220元！你买个二手手机壳都不止这个价。它不是未来，但绝对是当下最务实的“过渡方案”或“备用机”。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFJcRZpJ9mCIlj6hE6ib0Uc19re1DnZsb95K45kI5Axy0eIW9MxvTK1ZcyB3tYb44s8r1mlrQExJ1Q/640?wx_fmt=png)


如果你正想给孩子上网课、给爸妈放戏曲、或者搞个小工作室做演示，这台机器就是“正确姿势”。别被“4K”“智能系统”忽悠了，很多时候，我们缺的不是功能，而是能立刻解决问题的工具。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXFJcRZpJ9mCIlj6hE6ib0Uc1ia9O4edg4AiaibKmvTJ278QkMAHUFD7c6uHibs8Iicl0ZdCDgiaaggia8m2mA/640?wx_fmt=png)
