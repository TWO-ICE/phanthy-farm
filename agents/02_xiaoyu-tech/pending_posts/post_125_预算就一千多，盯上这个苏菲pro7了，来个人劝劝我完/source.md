# 预算就一千多，盯上这个苏菲pro7了，来个人劝劝我

这几天在二手鱼上刷得有点魔怔了。本来只是想找个便宜的备用机，结果越刷越上头，最后盯上了一个卖Surface Pro 7的。1250块，i5 10代处理器，8G内存，128G硬盘，卖家说成色95新以上，屏幕完美没瑕疵，无拆无修。说实话，这个价格看得我心里直痒痒。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekaIkdOOBx0EUuzkGib5gHWLUKEDeSKy6ZtfjMr9X0EsxZks9yPM8TUAFPzhf1SXkZfJycHy3GOicwR1WSYwsfu8oCh7pRWmv85s/640?wx_fmt=png)


但这个卖家吧，他搞了三个套餐，搞得我更纠结了。A套餐1250就是单机器加电源，B套餐1550带个原装99新键盘，C套餐1650再加个五代触控笔。每往上加一个套餐，就多三百、一百的，本来觉得1250挺便宜，看着看着预算就奔着一千六七去了。典型的二手鱼套路，但我还真吃这套。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekFVK0SeTbqE6E4ghnx5AytUreMY5V4Em7ict5lgyowLzLlaAicZZQaouu5pjpXhcwnEARzNMUpKVI0k1LWoMoCicI55zZufZic1Fc/640?wx_fmt=png)


我仔细研究了一下这个苏菲Pro 7。它是2019年出的，搁现在确实算老将了。但十代i5处理器，日常办公应该是够用的，我有朋友就在用这款，说开网页、写文档、看视频啥的完全不卡。而且它有C口，支持快充，这点比那些老款强太多了。屏幕是3：2的比例，据说显示效果很好，写写画画挺舒服。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelgInNQqWxCChmcYNaV5HGFPosaeGdr7EUGibT7lmdujw41JgacYS9ShT6Zicm3uGvPywYWvcl5sYLujuaQtibHmdqDxTkXUdVsG4/640?wx_fmt=png)


但我也没完全上头，清醒的时候还是会想：8G内存现在真的够用吗？我开几个网页再挂个微信再开个文档，会不会卡？128G的硬盘更是个问题，装个系统再装几个软件，空间就快见底了。扩展性基本为零，想加个内存换个硬盘，门都没有。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelgGyYNwLCYhjBEW9yNKgWU79FgNHJrZMwzpYoOAI0edIEYAO9JdjClQlhrQOxCdOsbiahsCiaRqsMoJlQbGngicMeuibgic5jdj2XU/640?wx_fmt=png)


而且苏菲的支架设计虽然好看，但我平时喜欢把电脑放腿上用，这种支架能稳吗？会不会一抖就倒了？想想也是挺纠结的。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCel7kIm5R8m7iatXUnMiaQHjKZKFmRGEwuz3tbKwKLicHqZkGAcxEM1ECIbItRt74s8piaWNc4xkzmM6Z7BicyI95u29GCFliaQhqNYPU/640?wx_fmt=png)


价格方面我也对比了一下。二手鱼上确实有更便宜的，八百九百的也有，但仔细看描述，基本都是屏幕有斑点的、触控失灵的、电池不行的，那种我是真不敢碰。这个卖家贵是贵了点，但他承诺屏幕完美，还说卖了几百台好评上千，0差评。而且支持先拍实拍图，不满意可以退，发货是顺丰到付可以验货。这种服务听起来靠谱点，至少比那些发过来就是坏的、扯皮都扯不清楚的强。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCem2lw917cIHn2DpxehHIPCP5jIB9Ic7c2Gj7UOvcZMjbDQfcC0LJcUJaoxrAKC4Ws0OCBia0Jj19ozUlOCyhGjDQNjKBa4I5RJo/640?wx_fmt=png)


我在想，如果我真要买，可能还是会选带键盘的套餐。毕竟苏菲没键盘就是个普通平板，体验差太多了。笔的话倒可以先放一放，毕竟不是刚需，一百块省下来能买好几顿外卖了。这么算下来，B套餐1550，其实也还行，至少键盘是原装的，成色99新，能省一点是一点。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelicuJbhwwusC9V3wsxaqKhFn4paqVnhdbp1hb3FKBBvPnac4SuWp7R0QRD1NLWDBRX6UyKUMqUfkGDEeicOGzW7TzK2nEA0Oibbc/640?wx_fmt=png)


但我又在想另一个问题：我买回来到底干嘛用？如果就是看看视频、偶尔处理点文档，好像一千多的安卓平板也能干，还全新有保修。但安卓平板那个生产力，确实比不了Windows。可话说回来，我真的需要多少生产力？不就是刷刷剧、回回消息吗？


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCen3WJBI0yHic7QrzFkK5WALbSpY6t0B1BriaDn5ElNPibJQJV4Iy7c1TDHZzXTHqhMhM9Rt3lQ2pdwkQtLBQQrW9RqpqqFU0aaMeI/640?wx_fmt=png)


越想越纠结。感觉这个Pro 7就像个鸡肋，食之无味弃之可惜。说它便宜吧，一千多也确实便宜，当年可是七八千的东西。说它过时吧，日常用也够。但就是怕踩坑，怕买回来发现性能不够用，或者用两天就出毛病。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelv68cHLjj1bdwiad8dPyPwGHjvu4VbpxoXnepDicVItOPRJ85hmE5Ageewo6E9BxjJZuVMhzAHib5lIN2MjmnAq295mGDZiaOWJ9w/640?wx_fmt=png)


有没有用过的老铁出来说句实话？这个Pro 7现在还能不能买？8G内存用起来卡不卡？那个支架放腿上到底稳不稳？或者有没有其他千元价位的好选择？评论区求指点，我是真下不了这个决心。
