# 比原价便宜一半还多，这台139元的有道听力宝E6，是不是智商税？

二手鱼里翻了半天，刷到个有点意思的东西。 是一款 有道听力宝E6，卖家标价139元，64G内存，描述里写着95新带充电线，功能正常，已经激活，就是裸机加线，包邮。扫了一眼这机器， 目前 京东 64G 卖 299 元 。 卖家这个虽然不是全新未拆，但比原价便宜了一半还多，感觉性价比还可以 。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemvUwRCqicEo5v7oSpAFkGia5SnXsHjibTNz01tEYXJ3kpSojcoRmIbfiak39QPiaicS3vKDJnPs96Ej2a2GbZqvOVLiaK1Xo8o5By4UY/640?wx_fmt=png&watermark=1&tp=webp)


有道听力宝E6搭载的是2.8英寸彩屏，整机只有90克，续航方面1500mAh电池，官方说能连续播放12小时，孩子出门上学或者周末出去玩带上一天基本够用。支持蓝牙和WiFi，最核心的卖点其实是它的AI功能。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekP2CMwia3zRoWribDfI9Hm1ASlVoa6HI3XJg7C3wfG04t4zdBITN8JSKJO9d3DnAEVjAFaicFWKIdiaEtvWdnW79p9QycUVxtt1NU/640?wx_fmt=png&watermark=1&tp=webp)


内置AI口语助手，可以逐句跟读纠音，还和雅思官方合作，雅思考官真人发音指导，音素级纠音，读错了能给你定位到哪个单词哪个音节出问题。对于学英语的孩子来说，这个功能算比较良心了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCel9PWmmh0Utc9lJuxmRVqK5icfWpRVPtaVB3S7pC3WbrbctM2lnwk1tPqKNLNibx1egaNMZIuVl5EJt3HCGhDQKVv6OIwnL2QNJE/640?wx_fmt=png&watermark=1&tp=webp)


这机器最大问题是功能单一。它专门做英语听力和口语，不包含其他学科内容。如果你家孩子需要的是数学辅导、语文背诵之类的东西，那E6帮不上忙。卖家描述里没有提到包装盒和原装配件，只有裸机和充电线，意味着没有原装说明书也没有保修。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemuOt1Y1UfucbuWSywVTr4xOQ64ZJkK20uTQbibjEjGdetLGuiaiarjcoiaTXze9B433bbbwOWicqPN63JiaEBfBXKxxp4H7brd4t9I8/640?wx_fmt=png&watermark=1&tp=webp)


另外机器已激活，这点需要注意，不过二手鱼里绝大多数学习机都是激活过的，只要功能正常、屏幕清晰、按键灵敏就没问题。还有一点，E6的喇叭在背面，有用户反馈声音听感有点奇怪，戴上耳机才舒服，这个对音质敏感的人可能需要留意一下。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenF75riagKBtHiaUibLMJm1iahdSDLmOAy2Err4nOMyECyk9OkbTHu7fZhHwxDvfullArCQmfV2snwOgHzxnzeuA5w2GZpztvn5PXA/640?wx_fmt=png&watermark=1&tp=webp)


如果你家孩子上小学或初中，英语听说能力偏弱，或者正准备考KET小托福这类考试，139元买这个绝对不亏。64G内存加上10TB的云空间，官方推送的主流正版教材、RAZ牛津树这些分级读物都是免费资源，AI口语教练随时能用，这个成本比请真人老师便宜太多。但如果孩子自制力差，或者你指望一台学习机能解决所有学习问题，那建议你还是多想想，毕竟学习工具只是辅助，关键看孩子用不用。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenicCVWzHdOM7l6vNiaO4umdzvsjeRK6WTbNUBIxORcoOfsMmXMspaabvGlOtianPV8zIzE3twd6XUOvJgJt51GiceFicqpDMY40w3I/640?wx_fmt=png&watermark=1&tp=webp)


除了这款139元的64G版本之外，我还刷到了一款32G的卖120元，相比之下还是64G的更合适一些，毕竟只差19元，但内存容量却翻倍增加。当然，如果你对容量没有需求的话，120元的更划算一些。
