# 用软管充当枕芯的枕头你见过吗？8H的软管枕真是让我长了见识

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/afNLf2a8eXEkhC7kHcYAXw1cibs8H7g1RDVXCs1Wfh21RMlYHtC0gibYg0DAoExwIRhH1R7UOKWUAQRu1SKvFWcw/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/XMEYvM1I9sLewJbXxtBb9Q

大家好，我是小鱼评测，今天评测的产品是来自8H品牌的可调节软管助眠枕spring。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXEkhC7kHcYAXw1cibs8H7g1RCgpUMAN3vvEDsFm82J4HPqVan37pJAypwZDrxFb5onAjgJNXAlRQIw/640?wx_fmt=jpeg)


提到枕头，相信很多人都会想起当下很流行的乳胶枕和记忆海绵枕，这两种类型的枕头各有所长，也的确受到了很多人的追捧。但最近8H品牌却推出了一款黑科技十足的枕头，居然用弹性PE软管充当枕芯。说实话，我还真是第一次见到这样的枕头，用大量的弹性PE软管代替了传统的枕芯，如此脑洞大开的设计到底实不实用呢？还是一起来看一下吧。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXEkhC7kHcYAXw1cibs8H7g1RZ197aibNZOoNaLeGzkicw1nDRRXQUK53icXOOgxwFIQjtKIkWnwsG2n3A/640?wx_fmt=jpeg)


在刚收到货时候，感觉这款8H软管助眠枕spring还真是不走寻常路，一款枕头的外包装居然会有这么大，包装的高度超过了60公分，而且还很有分量。这让我不由的感到好奇，里面到底都装了些什么东西，会用到如此大的包装盒呢？


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXEkhC7kHcYAXw1cibs8H7g1RxW3BibAsByQTKy92AViaxmCAYGIW5YZNQPYVPW2p1XPxwsAlUqDoZLww/640?wx_fmt=jpeg)


拆掉外层的包装，原来内层才是产品真正的包装盒，而且还设计的很有特色，纯白的底色搭配棕色的边框，配合正中心的LOGO，让这款8H软管助眠枕spring看上去很有档次。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXEkhC7kHcYAXw1cibs8H7g1RqHURIRpSUE7mh4ykVFxsIOktj8GpIBekiaXDsVy2Wc388kPUFrASk8g/640?wx_fmt=jpeg)


对于大多数的枕头来说，包装内基本只有一个枕头，不会有多余的配件。但这款8H软管助眠枕spring又一次的打破常规，包装内除了拥有枕头之外，还配备了一份说明、一个水洗袋和一整袋的备用软管。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXEkhC7kHcYAXw1cibs8H7g1RVibVdEQSzblAEMIKIiaTNzvKSvd9ziaxqctqhnnYqEUWBeGDPqn3mTVuA/640?wx_fmt=jpeg)


很多人一定会很好奇，充当枕芯的软管到底是什么样子的。我同样也迫不及待的想知道，第一时间就打开备用的软管袋，可以看到里面都是这种又小又透明的软管，官方给出的说明是，这些软管都是采用食品级的高分子PE材质制成，没有任何有害和刺激性的气味释放，我闻了闻确实是没闻到任何的味道。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXEkhC7kHcYAXw1cibs8H7g1RibSP6txOu3N3YcDg2gfiaytRK1TU4nwkBzrr3DQ5ic5e3Yc60fM3XibibMQ/640?wx_fmt=jpeg)


这些软管的尺寸都很平均，每根软管的直径是6mm，长度为9毫米，厚度只有0.22毫米。用手抓取一把后，会感觉到软管的弹性很不错，无论怎么挤压也不会变形，重量也非常轻，并且这些软管有着很好的排斥性，把这么多软管集中在一起，也没有出现粘连的情况。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXEkhC7kHcYAXw1cibs8H7g1RuiaBaUaDnvFD4M7qQXyOzPnMHz5dcEma53GMt2yFBuUbGyPMh8rSg9Q/640?wx_fmt=jpeg)


再来看一下我们评测的主角，8H软管助眠枕spring在设计方面与传统的枕头区别很大，最直观的就是枕头的表面并不是平整的，而是呈现出不同的凸起或是凹陷的区域，总共被划分出了5个区域，中心的凹陷部分是脑窝区，左右凸起部分是侧睡区，上下凸起的部分则是颈椎承托区。如此精准细化的分区式枕面，在同类产品中还真不多见，而这样的设计确实可以让头部与枕面更加贴合，从而达到更为舒适的睡姿。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXEkhC7kHcYAXw1cibs8H7g1ROicG0aXT6S9daFnhn69m7Ej76MmjDcIoYuz3CtIMCGmEGLc5f7Jka4Q/640?wx_fmt=jpeg)


之前有说过，这款产品的包装很大，原因就是8H软管助眠枕spring的尺寸要比一般的枕头更大一些，长宽高分别为60*35*9cm。这个尺寸要比我之前的乳胶枕还大上一圈。而大尺寸枕头的好处是不言而喻的，可以让头部有着更大的活动空间，即使在入睡时来回的翻身，头部也不会从枕头上滑落。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXEkhC7kHcYAXw1cibs8H7g1R7DDKWicIjdXebCVHBZNayKVJeEXf47yQd5yWgGWkkVUOH7rj40yOJWQ/640?wx_fmt=jpeg)


在面料方面，8H软管助眠枕spring的选材非常挑剔，表层的面料采用的是聚酯纤维、再生纤维素纤维和氨纶制成，侧边则是100%的聚酯纤维，这些纤维是甄选来自奥地利100%的兰精天丝，编织后的面料亲肤柔软，并且面料还经过了负离子的处理，会缓慢释放出对人体有益的负离子，能够起到调节神经和净化空气的效果。除此之外，枕面的面料中还添加了抗菌剂，能够抵抗多种有害细菌的滋生，为头部营造出一个健康有益的睡眠环境。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXEkhC7kHcYAXw1cibs8H7g1RsgRq8MZOiaI54Q5wpubdfVCO8eEqWBjvYmv9oTJzQicd0HRIs616cDjA/640?wx_fmt=jpeg)


背部的设计相对简单，面料是由100%的纯棉制成，中心位置是一条隐藏式的拉链，开始我觉得只要拉开拉链，就可以把枕套全部拆下来，但是实际操作后，才发现我想错了，原来这款8H软管助眠枕spring的枕套是无法拆卸下来的，拉开拉链也只是为了方便对枕芯的软管进行填充。那可能有的伙伴就会问了，无法拆卸枕套，那要怎么清洗呢？难道是把整个枕头都放进洗衣机里吗？


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXEkhC7kHcYAXw1cibs8H7g1R2RdyWcfCCvc0mqB9qjVXibPMwwQdOAM64URCXpbKSq3a8FPIapDJ4icw/640?wx_fmt=jpeg)


那你还真猜对了，事实就是如此。这款枕头在清洗时无需任何的拆卸，直接把它放进洗衣机进行清洗就可以，面料的特殊材质可以保证枕头在清洗后不松垮变形，内部的软管更不会硬化碎裂，所以清洗起来是非常方便的。同时8H还专门为这款枕头配备了清洗袋，套在袋中清洗，可以避免洗衣机缸体对面料的摩擦，延长面料的使用寿命。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXEkhC7kHcYAXw1cibs8H7g1Rm4NPUbjmgS81gLgMebibkoEmCFUJ7HjrbBqJwiaonuKZ9KKhSUdcM6nA/640?wx_fmt=jpeg)


为了方便展示，虽然枕套不能拆卸，但我把枕套全部都翻了过去，可以看到内部的枕芯也同样被划分出多个区域，每个区域都设有专用的填充口和拉链，同时我发现一个细节，就是每个填充口中的口袋都要稍许长一些，这样的设计可以保证枕芯内部的软管不会漏出来，避免了到处飞溅的问题。另外有眼神好的伙伴可能已经看到，枕芯的最下方颈椎承托的区域，里面好像并不是软管。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXEkhC7kHcYAXw1cibs8H7g1RecTyx2nhFAjcSzhk1zRfloLq86rpuRUUA4p9Fan7XUrPNLIWszMt6w/640?wx_fmt=jpeg)


这里面装的其实是高弹的抗菌Sustans®纤维，可能有人觉得和毛绒玩具内的填充物很像，但在我触摸之后，感觉这些抗菌Sustans®纤维有着很高的弹性，并且也十分的柔软，更为高级的是这些抗菌Sustans®纤维也同样具备抗菌性。至于为什么两处颈椎承托区选用了不同的承托方案，原因是为了符合不同人群的睡眠习惯，反正就是怎么舒服就怎么来。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXEkhC7kHcYAXw1cibs8H7g1RSXoJydhTichBbVic6A3Tu59T5tZ65vz0OrX60fU9aYvic2xB2OibBlmuYA/640?wx_fmt=png)


对这款8H软管助眠枕spring有了一个简单的了解之后，再来谈一谈这款枕头在实际体验中的感受。首先要说的就是头部枕上去之后的感觉。前面有说到枕面共有五个分区，在仰卧状态下，头部在枕上去之后，后脑正好处于中心凹陷部分的脑窝区，这种凹陷的设计可以紧密贴合头部的曲线，同时也增大了头部与枕头的贴合面积。而枕芯内的软管给我的感觉非常奇特，既不像荞麦皮那么硬，又不像乳胶枕那么软，柔软度和弹性都很适中，总体给我的感觉还是非常舒适的。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXEkhC7kHcYAXw1cibs8H7g1RNTgDgjFho6wzLl7PaCDwLgt8c1wk5VvFAYnJMZ2OhWmTATicQTa6f3A/640?wx_fmt=jpeg)


再来说一下颈部承托区，这款枕头的颈部承托区分为软管承托和抗菌Sustans®纤维承托，我依次对这两种承托区都进行了体验。相同的地方是，这两种不同材质的承托效果还不错，都能够与颈部很好的贴合并起到了一定的承托效果。而不同的地方是，二者所带来的触感有着些许的不同，抗菌Sustans®纤维的触感要偏软一些，软管的感觉则是弹性更好一些，对于我个人而言，还是更倾向于软管的颈部承托。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXEkhC7kHcYAXw1cibs8H7g1RbKVDVJeHXeauEN7kAdYOCADmsRDsf4cL8ERib8NSwhzwD1RLLdSss5A/640?wx_fmt=jpeg)


在侧卧的状态下，枕头两侧的侧睡区可以与头部贴合的十分紧密，颈部位置也不会因为睡姿的改变而出现缝隙，枕芯内的软管也起到了有力的承托效果。这里要说的是，这款8H软管助眠枕spring对于承托的效果并不是一层不变的，如果你是身体比较魁梧的男士，或者是身材比较娇小的女士，都可以通过增减软管的方式对枕头的高低进行调节，所以这款枕头的适用人群是非常广泛的。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXEkhC7kHcYAXw1cibs8H7g1RCcoRVibyvbMcy7sE1ssCpKdChFlFZ9ia6MUEhnFLrosLybialrmtG6fRA/640?wx_fmt=jpeg)


经过了试睡，我还发现了这款枕头的几个优势，其一就是大，说实话我太喜欢这个枕头的尺寸了，它可以让我在睡觉时尽情的翻滚；另外就是枕头的面料，这种面料非常亲肤柔软，尤其是侧卧时与脸部接触的时候，感觉特舒服。还有就是透气性非常强大，因为软管全部是中空的造型，本身就具备了强大的透气性，而在枕头的两侧还搭配了布满网孔的X-90D科技面料，所以枕在上面完全不会有憋闷的情况。至于问题也发现了一个，那就是纯白色的枕面不耐脏，对于不是很勤快的人，或者是头发爱出油的人来说，睡过一段时间之后，枕面想必会惨不忍睹，但好在这款枕头清洗起来十分的方便，无需任何拆卸直接放进洗衣机就能清洗，也算是一大亮点。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/afNLf2a8eXEkhC7kHcYAXw1cibs8H7g1R8OADPAWnyiaMnAicnicZuDn9q0OZ4UR422ejNNvs8FDOCLXEdOf3PctMA/640?wx_fmt=jpeg)


以上就是我对这款8H软管助眠枕spring的整体感受，如果你也对这款软管内芯的枕头感兴趣话，可以去亲身体验一番，同时也欢迎大家在评论区说出你的想法。
