# 二手鱼流入大量MacBookPro无头骑士，300块起售到底值不值得捡漏？

最近在二手鱼闲逛时，一股诡异的潮流引起了我的注意：大量被称为“无头骑士”的MacBook Pro下半部主机正在涌入市场。名字听着挺中二，带着一股浓浓的哥特风，但现实往往骨感得让人想笑——所谓的“无头骑士”，不过是把好好的Retina屏幕给拆了，只剩下C面底壳，集成了键盘、触控板、电池和主板，摇身一变成了所谓的“苹果迷你主机”。

看着那些挂出来的价格，从300元到650元不等，确实让人心里痒痒的。配置表上写着从2013年的i5一路跨越到2015年的i7，内存从4G到16G不等，硬盘倒是清一色的128G。卖家们一个个把“不拆件、不动件、原装机”挂在嘴边，甚至还打出了“支持4K@60Hz输出、完美隔空投送”的卖点。这究竟是捡漏天堂，还是电子垃圾回收站？咱们今天就把这台“无头骑士”放在解剖台上，把它的五脏六腑都扒拉清楚，看看这三五百块到底花得冤不冤。

首先，咱们得搞清楚这东西的底细。这批“无头骑士”的原型机无一例外，都是苹果Retina屏幕时代的13寸MacBook Pro，模具型号A1502。这是一代经典，但也确实老了。年份集中在2013到2015年，这在电子产品里简直就是“上古世纪”。处理器架构从Haswell（第四代）的i5-4258U一直跨越到Broadwell（第五代）的i7-5557U。虽然后者主频能飙到3.1GHz，但在如今14代、甚至下一代处理器满天飞的年代，这种双核四线程的低电压U，性能也就勉强能看。

更要命的是内存。A1502这代模具的内存是焊死在主板上的，不可升级。这意味着你买到4G的，它就永远是4G的残废状态；买到8G的，也就是现在的及格线水平。至于硬盘，虽然原装的是PCIe接口的SSD，读写速度吊打同期的SATA接口机械本，但容量是硬伤。128G在2013年或许够用，放在2024年，光是装个系统、Xcode、Final Cut或者几个大型游戏，硬盘空间就亮红灯了。

接口方面，这老伙计倒是保留了全功能Thunderbolt 2（雷电2），两个USB-A口，一个HDMI（部分型号需要转接头），还有3.5mm耳机孔。无线方面支持Wi-Fi 5和蓝牙4.0，算是那个时代的顶配。但操作系统是个巨大的坑：A1502官方支持的极限是macOS Catalina（10.15.7）。这意味着什么？意味着你跟最新版的macOS彻底无缘，无法使用新的Universal Control功能，Safari浏览器版本停滞，安全补丁不再更新，很多新开发的软件在启动时就会直接提示你“系统版本过低，请升级”。这就好比你开着一辆20年的老爷车上路，虽然能跑，但连个最新的导航都装不上。

卖家口中的“生态优势”确实存在，比如Handoff（接力）和AirDrop（隔空投送），在苹果全家桶里确实好用，甚至外接显示器能跑4K@60Hz。但这一切美好的前提是——性能得撑得住。

咱们来模拟一下实际使用场景。如果你手贱买了个4G内存版本（通常是i5款），那就等着体验“网页版PPT”吧。现在的网页越来越臃肿，光是微信网页版、后台挂个音乐软件，再开两三个Chrome标签页，4G内存瞬间被吃光。一旦内存爆满，系统就会疯狂读写虚拟内存（硬盘），这时候你的硬盘灯狂闪，鼠标转圈，风扇轰鸣，体验简直灾难。哪怕是8G内存版本，在macOS Catalina的臃肿体积下，也就勉强够用。开个腾讯会议、钉钉，再挂着几个Word文档，后台稍微搞点系统更新，那颗老芯就会热得发烫，风扇转得像要起飞的直升机。

至于那128G的硬盘，更是典型的“小马拉大车”。macOS系统本身就要占用20G-30G空间，再加上分页文件和休眠镜像，实际留给你的可用空间往往不到80G。在这个动辄一个游戏就80G、一部高清电影几G的时代，这点容量你需要像守财奴一样精打细算每一兆字节。想装几个Adobe全家桶？别做梦了，单一个Photoshop就能把你的剩余空间吞干抹净。

这时候有人会说了：“才300块啊！还要什么自行车？”这话没错，但得看跟谁比。在300元这个价位，二手市场其实是有很多“正常”选择的。你可以找到2018年左右的Intel NUC，或者是联想、惠普的微型主机。这些主机通常搭载的是i5-8250U（第八代）甚至更新的处理器，性能上对第四代i5是降维打击，多核性能几乎翻倍。更重要的是，它们通常标配8G内存（甚至可扩展到32G）和256G的固态硬盘。

虽然Windows 11对硬件要求不低，但i5-8250U跑Win 11轻办公是绰绰有余的。哪怕是买台二手的联想小新Air拆机件（带主板电源的那种），体验也远比这堆“无头骑士”要流畅。Windows小主机虽然没有macOS的优雅，但它胜在兼容性好，软件随便下，游戏随便玩，甚至装个Linux跑个小型服务器都比这台老Mac靠谱。

这就引出了另一个常见的幻想：“那我把它当下载机或者NAS总行了吧？功耗低，还是macOS。”

理论上可行，实际上也是坑。首先，虽然Haswell架构的功耗控制不错，但这毕竟是笔记本主板拆下来的，散热设计依赖原本的屏幕带走热量（散热模组有一部分热管是通向屏幕一侧的）。现在屏幕没了，热量全积压在C面底壳，长期满载挂机下载，硬盘老化速度会显著加快。其次，macOS并不是为无头运行设计的，很多后台服务在无交互时会自动暂停，效率远不如专门的黑群晖或者甚至是一台百元的刷了OpenWrt的老路由器。更别提那生锈的金属触点暴露在空气中，长期受潮短路的风险也不低。

还有人打歪主意想装Windows。虽然A1502确实支持Boot Camp安装Windows 10，但驱动是个大坑。苹果官方的Boot Camp支持包里，显卡、声卡可能没问题，但Wi-Fi网卡（博通家的芯片）在Windows下经常抽风，连接速度慢还容易断流。最离谱的是触控板，macOS下的Force Touch（力度触控）在Windows下驱动极其难配，经常只能当成单键鼠标用，多点触控手势全废。既然你都要外接显示器、键盘鼠标了，那你为什么不直接买个正经的Intel NUC呢？为了那个发光的苹果Logo吗？

最后，咱们来点诚恳的建议，别让这三五百块打了水漂：

第一，非Mac生态重度依赖者别碰。如果你没有iPhone、iPad需要频繁进行隔空投送，或者没有特定的macOS独占软件需求，这台机器对你来说就是一堆装着旧系统的电子垃圾。学习Linux？树莓派比它合适；看电影？电视盒子比它方便；写代码？同价位的Windows小主机配个VS Code不香吗？

第二，千万别碰4G内存版本。哪怕是当个收音机、当个摆件，4G内存在现在这个软件环境下都是一种折磨。这种配置根本无法满足任何有产出的工作流，只会让你在无尽的卡顿中怀疑人生。

第三，如果你只是想体验一下macOS，或者给家里老人找个看微信、看爱奇艺的机子，这玩意儿的维护成本（包括系统折腾、硬盘扩容、内存瓶颈）远高于买一台现成的国产平板或mini主机。

第四，也是最扎心的一条：看完不买，立省300元。这钱留着去买顿好的，或者攒攒加钱买个M1芯片的Mac mini，才是真正的“真香”定律。在这个电子垃圾横行的年代，克制住捡漏的冲动，就是一种最高级的理财。
