# 二手鱼捡漏685块的二合一笔记本，是真香还是智商税？

今天在二手鱼刷到了一台驰为13.5寸二合一平板笔记本电脑，标价685元。亮点是“12+512”的存储组合，目前内存和硬盘都开始搞“通货膨胀”，就连二手鱼里的垃圾也跟着一起涨价了，但不得不说，今天刷到的这个笔记本性价比还可以。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGkLnfVeINhqShibC1joibqZI9apW8VQxHNu4kVJ9PUv8dQTyoqIe9yfo4w8znIdqG3LpIU9QtNp5CQ/640?wx_fmt=png)


先说说这台机子的基本情况：全金属机身、9成新、键盘只有轻微使用痕迹，屏幕是13.5英寸2K分辨率（2256×1504），窄边框+触控+360度翻转，看起来确实挺像那么回事儿。更别说还带背光键盘、原装Type-C充电器，电池健康度100%——听起来简直是“白菜价捡大漏”的剧本。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGkLnfVeINhqShibC1joibqZInic3Oh4IoUe3UXia2Wicfib2MVf14xbyzrqSKPYjeu2kSSecRsUYSvkrcQ/640?wx_fmt=png)


但别急着下单，咱得扒开参数看看底裤。它用的是Intel赛扬N5100处理器，四核四线程，10nm工艺，基础频率1.1GHz，最高睿频2.8GHz，TDP只有6W。简单翻译一下：省电是真的，跑分嘛……就别指望能剪4K视频或者打游戏了。这颗U属于2021年初发布的入门级U，主打低功耗轻办公，日常写文档、刷网页、看剧没问题，但多开几个Chrome标签页可能就得喘口气。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGkLnfVeINhqShibC1joibqZIggc8YibKTgm9k5E676lxBWvvRUoFzDuqOFYCYJY357EcxgXXibS63HOg/640?wx_fmt=png)


那问题来了，685元买这样一台机器，值不值？目前全新入门级Windows笔记本，比如搭载N100/N305的机型，价格普遍在1500-2000元区间。而二手市场上，同配置的N5100机型，价格大多在500-800元浮动。所以685元这个价位，不算离谱，但也谈不上“骨折价”。只能说——价格挺白菜，但别幻想性能有多猛。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGkLnfVeINhqShibC1joibqZIbueQxdGB0ibibhpL8AuOiazlWH8diaGknfSZZwqL4WLnDApOu0aPIUI0Mg/640?wx_fmt=png)


但是这机子有个有点，就是功耗低，特别适合装飞牛系统当NAS用。TDP只有6W+512G SSD+12G内存，拿来跑轻量级服务绰绰有余。甚刷OpenWrt当软路由，或者接硬盘做家庭影音中心。如果你有折腾精神，它确实是个不错的“电子垃圾改造素材”。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGkLnfVeINhqShibC1joibqZIonvJR46kDH7AB3ELsQQIVDAMCKVGo3OVP1k3ABYjricrcfib8Atzmbuw/640?wx_fmt=png)


当然，这台机子也不是没有短板。首先，N5100的核显性能有限，4K视频硬解虽支持，但高码率可能会卡顿；其次，DDR4内存虽然是12G，但板载不可扩展；再者，驰为这个品牌售后基本等于“自求多福”，出了问题全靠自己修。另外，2K屏看着细腻，但Windows对高分屏的适配至今仍有翻车现场，尤其某些老旧软件会糊成马赛克。
