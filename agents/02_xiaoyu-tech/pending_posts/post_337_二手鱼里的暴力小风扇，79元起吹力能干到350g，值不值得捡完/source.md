# 二手鱼里的暴力小风扇，79元起吹力能干到350g，值不值得捡漏？

![封面图](https://mmbiz.qpic.cn/mmbiz_jpg/E9h3abOJCekVeLIN6hSe4RZZ4XcTxqHhRHwbG90UcdhjdGQ8IBiaS3m2KuSoq5WNByOLd11lDuaaScbgs1Bo38BCuSp75vPEJic7mdQls9XI8/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/70CbVo0dZLHLPStVc8a1Aw

在二手鱼刷到一款手持可吸尘的暴力风扇，79元起售，卖家描述说是涡轮手持吹风机，能吹风能吸尘，涵盖洗车收水、电脑除尘、车内通风等多种场景，还标了一堆参数， 那么 到底这款 暴力 风扇值不值得出手 ？


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemy0TEodZz3fjfgL4lmSdeZOseUsdteZJibaTx6TJjPIicR3avA1HM82Xic4kDK8kHqRibZDdyprVahymY40cib0AHyyYJYODR3Zke0/640?wx_fmt=png&watermark=1&tp=webp)


先看一下 参数， 核心是 29mm 的 无刷电机，13万转转速，吹力大概350g左右，工作电压5.5v到8.4v，功率180到210w，支持无极调速和一键启动。有两个版本，18650电池版本79元，标称5000毫安，21700版本89元，标称8000毫安，加9.9元还能加购吸尘套件，一套包含主机、聚风嘴、充电线等配件。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCek2TeU6EBq0ZUvI0XnZ8iceBbsGJicSmxBtjm9UkuibcXmswW6LqbEROnWE3SOmIto5M2ZibMdAD7XNslPqVW2vVzeFy4eh6QFldPY/640?wx_fmt=png&watermark=1&tp=webp)


这款暴力风扇的 优势 是 价格确实够低，79元就能拿下一套多功能设备，比全新的同类产品便宜一半以上，甚至比很多普通 DIY的 手持暴力风扇还划算。无刷电机是亮点，比有刷电机更耐用、更节能，这也是很多廉价同类产品不具备的，而且卖家承诺30天质量问题免费换新，365天免费维修，售后还算到位。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelPICbdAkNEQRVKOZPmwSvqvRvc8osdx5tGdaicsPm2rQLUibXgCty6tp7dOWrte6MiafGCSLZo7YMuwesvicVg6WVicWqNcne9OVqk/640?wx_fmt=png&watermark=1&tp=webp)


这个产品最大的卖点和噱头就是能够多场景吸尘和吹扫。不管是夏天车里暴晒后想迅速 通风 降温，还是给家里的电脑机箱清理陈年老灰，甚至是给厨房缝隙做深度清洁，都能满足。它标配一个聚风嘴和一个收纳包，整体看起来很规整。看到这里，你可能会问，这玩意看着这么牛，就没有短板吗？


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekP6RTRpPqL6BArswJibGwDiaNE2iapPd4S44pHwM2rc5cSG4eZKbicQhyoVCz9UflVjpcB2micNaDeMFyMcHsD1J88J1cGGkOaNo2o/640?wx_fmt=png&watermark=1&tp=webp)


当然是有的，首先，这类暴力风扇如果连续高强度使用，小马达会有过热的风险。卖家虽然提供了30天内质量问题免费换新和一年保修，但这更像是一个信任安慰，我们日常还是要稍微爱惜点使用。其次，大功率电机的噪音问题肯定回避不掉，我敢保证，你在屋里一开机，整个房间都能听到那个嘶吼的轰鸣声。 还有 这个价位的吸力 基本 只能处理细小灰尘，大一点的碎屑 自能在那自嗨 。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCelbZ2G1zSuAQae4uhx04eDKCtzInV8NFttNzXUQ5ysxU5uv1eavp6ricJF0J4hbHHqRe5pRvmkcXCNnk6eIw6aBt5usCWvUYHBM/640?wx_fmt=png&watermark=1&tp=webp)


还有一个大家比较关心的问题，这个79元的版本续航究竟怎么样？从实际经验来看，前面提到的品牌无刷风扇高功率下续航也仅仅只有13-14分钟。这款79元的18650版本电池容量为5000毫安，即使配合无极调速温柔着用，预计满负载运行也撑不过15分钟。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelf0Zw3kregJ3wElB9QKdmtmOvDjnCicO7MA8ym75YmHTzt29Gcjb7ecvX193rVEDLp1dQRxc9HhQ6icDic3fBiaGFHDQ2H2dapFRU/640?wx_fmt=png&watermark=1&tp=webp)


但 好在卖家提供了升级版21700电池包，再加10块钱就能升级到8000毫安，虽然贵10元，但即使电池有虚标，实际容量也大概率比18650版本高，续航更省心。吸尘套件不建议加购，除非经常需要给相机、电脑深度除尘，否则纯属浪费钱，没必要多花9.9元。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCelAOibKqH9Hu3hOIM9VhWyJl4IBYwgZoFnDY9juRnVr7XibRAhMR5cIM0iaQEsIlgAcJaic7WibpQx2KHyjaRln44XxfO63Mp0rACdA/640?wx_fmt=png&watermark=1&tp=webp)


老铁们有没有在二手鱼刷到过这款风扇，有没有入手过的，实际使用中电机吹力够不够，电池续航到底怎么样。垃圾佬们来说说，79元这个价格，是真捡漏还是交智商税 ？
