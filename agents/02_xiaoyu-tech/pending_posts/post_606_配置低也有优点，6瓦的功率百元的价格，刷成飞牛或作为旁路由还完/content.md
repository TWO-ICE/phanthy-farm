# 配置低也有优点，6瓦的功率百元的价格，刷成飞牛或作为旁路由还是挺香的！

最近这存储市场的行情，简直比过山车还刺激。固态硬盘价格狂飙，内存条也跟着凑热闹，价格一路看涨。这就导致咱们这些喜欢折腾的玩家，不得不把目光从那光鲜亮丽的新品市场上移开，转头去闲鱼、转转这些二手平台“淘金”。毕竟，攒一台像样的NAS或者远程控制终端，光是买全新的存储颗粒就得让钱包大出血。

在这个大背景下，我最近就在“垃圾堆”里刨到了一个挺好玩的宝贝——一款只要105元的小主机。这玩意儿搭载的是Intel N3010处理器，个头非常小巧，大概就巴掌大，外壳还是铝合金的，拿在手里沉甸甸的，质感竟然意外的精致。这机器当初上架的时候，卖家那是相当会打标签，直接挂上了“适合飞牛NAS”、“可装Linux”的卖点，瞬间就击中了我这种喜欢低成本折腾的软肋。

咱们先来拆解一下这台机器的底细。型号是KRAMER VIA GO，看着像个不知名的牌子，其实原本是用于会议投屏的专业设备。它的核心大脑是Intel N3010，这可是一颗非常有年代感的CPU，属于Braswell架构，早年多见于低功耗笔记本或者Mini主机上。配的是2GB DDR3L内存条（就是笔记本那种低压内存），内置存储是32GB的eMMC。说实话，这配置放在2024年简直就是“古董”，装个精简版的Windows10都得咬牙切齿，更别提跑什么大型软件了。

不过，既然是拿来折腾的，它的扩展性才是咱们关注的重点。这款小主机的主板设计还挺有意思，居然预留了一个M.2 2230插槽。更有意思的是，它内部还能通过20pin的SATA一体线，接一块2.5英寸的SATA硬盘。加上那个M.2插槽，再算上外面能通过USB扩展的，卖家号称它是“三盘位”小钢炮。虽然这在物理结构上比较勉强，你得像玩俄罗斯方块一样把硬盘塞进去，但对于想做个低成本存储柜的人来说，这空间确实有点意外惊喜。

但是，咱们得泼一盆冷水：2GB内存绝对是这台机器的“阿喀琉斯之踵”。这年头，就连几百块的安卓手机都动辄8GB内存了，2GB跑个Linux桌面都捉襟见肘。如果你想在这上面跑几个Docker容器，比如个简单的导航页或者监控程序，分分钟给你爆内存警告。如果你是想刷飞牛OS这种国产NAS系统，社区里的大佬们早就给出了血的教训：2GB内存下，系统启动都要半天，一旦进行文件传输或者索引，卡顿能让你怀疑人生。如果真要发挥余热，建议第一件事就是把这个内存条拔了，花几十块淘个8GB的DDR3笔记本内存插上去，这样才能勉强算是一台“能用的电脑”。

除了内存，这块N3010的I/O能力也让人一言难尽。它只给了一个千兆网口，对于需要链路聚合的NAS玩家来说完全不够看。USB接口倒是给了两个3.0的，勉强能凑合。最坑的是无线网卡，它居然用的是老旧的Intel AC3168。这网卡在当年就是“万金油”低端货，放到现在，速度跑不满不说，驱动的稳定性也堪忧，跟现在主流的AX200或者AX210那种WiFi6网卡比起来，简直就是一个在天上飞，一个在地下爬。

这时候肯定有朋友要问了：“105元买个这玩意儿，到底是交智商税还是真香？”咱们得算笔账。在存储颗粒价格翻倍的当下，你想买一块全新的1TB NVMe固态，没个七八百下不来；买一条全新的16GB DDR4内存，也得四五百。相比之下，这台105元的小主机，自带金属外壳、自带电源、还能塞三块盘（虽然很勉强），作为一款“拥有计算能力的硬件”，它的性价比确实显得突兀。但理性分析，它的性能天花板非常低，扩展性也就是那么回事儿。

如果你对它的定位清晰，比如只是需要一个7x24小时挂机的下载机，或者放在公司跳SSH做个中转站，甚至跑个简单的Python脚本监控，那它完全够用，而且功耗极低。但如果你指望它能替代群晖或者威联通那种正经NAS，承担起家庭多媒体中心的重任，负责4K电影的转码、多用户并发访问文件服务，那我可以负责任地告诉你：你会失望透顶。

有人专门问过我：“这机器到底能不能刷飞牛NAS？”答案是：物理上可以装上去，但体验上是灾难级的。飞牛OS虽然宣传对硬件门槛低，但那是基于现代标准说的低。让N3010配2GB内存去跑飞牛，就好比让一个刚学会走路的小孩去扛煤气罐。这机器更现实的归宿，其实是刷个OpenWrt或者iStoreOS，做个软路由。这种轻量级的网络封包转发任务，不需要太多的算力，正好能发挥它低功耗的优势。或者跑个轻量级的Web服务，做个个人的展示主页，这才是它该干的事。

要说这机器最大的优点，其实不是那可怜的性能，而是它真的“省”。虽然配置低，但低功耗就是它的杀手锏。卖家给出了实测数据，这台机器待忙功耗仅仅只有6瓦。这是什么概念？你家里的无线路由器功率大概是多少？大概也就这个数。这意味着你可以把它扔在角落里，一年365天全天候开机，一天的电费也就几分钱到几毛钱。对于那些不想让高性能主机24小时轰鸣运转的电费刺客党来说，这种6瓦的小玩具，开着心理毫无负担。

如果听了我的介绍，你对这款KRAMER VIA GO产生了兴趣，想自己也整一台玩玩，你可以去二手鱼（闲鱼）搜索关键词“N3010三盘位小主机”。运气好的话，应该还能翻到类似的listing。如果搜不到，那就用“以图搜图”的功能，把那个铝合金外壳的小方块照片传上去找。如果都搜不到，那大概率是这种电子垃圾已经被其他懂行的“捡垃圾”大神扫空了，或者卖家觉得105卖亏了涨价了。

最后，作为一个在此类垃圾山上踩过无数坑的过来人，我有几条建议，可能有点扫兴，但绝对中肯：

1.  **定位要清晰**：这玩意儿仅适合跑极简的服务，或者作为学习Linux命令行的教学机。别指望它能干重活。
2.  **别做白日梦**：千万别想着它能替代正儿八经的NAS或者高性能的主力服务器。它就是个玩具，或者是个极其低效的工具。
3.  **闲钱方可试**：如果你家里正好闲置着一些DDR3内存条或者老旧的SSD，花105块钱买个壳子玩玩，倒也无妨。如果你还需要专门去买配件来武装它，那就算了吧，边际成本太高。
4.  **省钱是王道**：看完文章，忍住不买，你就立省了100%。这才是性价比最高的选择。
