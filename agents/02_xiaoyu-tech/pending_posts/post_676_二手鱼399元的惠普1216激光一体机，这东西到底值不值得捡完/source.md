# 二手鱼399元的惠普1216激光一体机，这东西到底值不值得捡漏？

朕没事就爱刷二手鱼，翻来覆去就想淘点性价比在线的宝贝，前两天刷到一台惠普1216激光一体机，卖家标价399元，感觉这价格挺白菜，也就一包烟的钱就能带走，那么作为老牌激光一体机，它到底值不值得冲？今天就来好好扒一扒。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGFOHnzpIgQibt6bl82u7LwTibslkic4iar2oBYn98mO2rNia2bgjXWPvHNjX9qgCHV4PCx1xe7u4gNJtA/640?wx_fmt=png)


先说说这机器的“出身”，当年可是中小企业的办公标配，2012年前后上市时标价近2500元，能打印、复印、扫描、传真四合一，在功能单一的年代里，妥妥的“办公多面手”。放在现在看，虽然没有无线连接、自动双面这些花里胡哨的功能，但基础配置一点不含糊。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGFOHnzpIgQibt6bl82u7LwTgCJYOvsyOCc5waNG6FSM90q1nNGTsxclYibREIKbvYL0vp0QpbEZHQA/640?wx_fmt=png)


机身是经典的黑色设计，8.6kg的重量沉得实在，不像现在的便携款轻飘飘，用料扎实得像块砖头，不过搬起来确实费劲儿，这算是个小缺点，好在放角落基本不用动。双行液晶显示屏操作简单，老人小孩都能上手，没有复杂的菜单逻辑，这点比现在有些智能设备人性化多了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGFOHnzpIgQibt6bl82u7LwTpN2Cxy9VWQIUrTAIAVyybkZwJSkds6r7YzhaskdvYxZBiaNLQFPHB4A/640?wx_fmt=png)


打印和复印性能是核心，18页/分钟的速度不算飞快，但日常打个合同、简历、学习资料完全够用，首页8.5秒就能输出，不用等得花儿都谢了。分辨率600×600dpi，有效可达1200dpi，打印文字边缘锐利清晰，应付普通办公和家庭使用绰绰有余。复印功能和打印表现持平，25%-400%的缩放范围很实用，连续复印最多99页，不用反复开盖放纸。不过缺点也明显，只能黑白打印，而且工作时噪音略大，像小电钻在转，但是在可接受范围内。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGFOHnzpIgQibt6bl82u7LwTxArMCicR5iaey64F1KmtmG7iczcDmewbib1P0PuCiaicItkdlZyfhxKxAEPA/640?wx_fmt=png)


可能有人会问，这机器都快二十年了，会不会买回去没几天就坏？其实激光机的结构比喷墨机简单，只要没有严重磕碰和进水，核心部件很难出问题。至于耗材方面，它用的CC388A硒鼓是惠普的经典型号，市面上原装、兼容款一抓一大把，原装的500多，比打印机都贵了，所有直接买兼容的型号，二手鱼几十块就能搞定，打印质量和原装没什么区别。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGFOHnzpIgQibt6bl82u7LwT4FjUd5GzuMGf8AZDlHxnnQ9wGsbSbZibYDM3sqgquJUMAVGhARbvdbg/640?wx_fmt=png)


查资料时发现这机器2010年刚上市时要两千多，现在跌到399，贬值速度堪比比特币矿卡。但它的皮实耐用在江湖上是有传说的，至今还有很多图文店拿它当备用机，属于是电子界的五菱宏光。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXGFOHnzpIgQibt6bl82u7LwTFhxdJ1J5j041FxPrMRYT3emso3jicgfpUlvBGdn3Jssgel4HG9e8jCA/640?wx_fmt=png)


最后灵魂拷问：399到底值不值？如果你需要个不娇气、耗材便宜的基础办公设备，这价格买来绝对不亏。但要是追求无线打印、手机直连这些新功能，建议加钱买新款。老规矩，看完不买，立省399元。
