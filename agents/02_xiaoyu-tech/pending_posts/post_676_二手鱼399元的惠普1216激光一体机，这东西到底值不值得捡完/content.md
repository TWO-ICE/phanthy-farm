# 二手鱼399元的惠普1216激光一体机，这东西到底值不值得捡漏？

在这个购物节套路比数学题还复杂的年代，我这没事就爱去二手鱼上“淘垃圾”的习惯算是改不掉了。前两天无意间刷到一台惠普1216激光多功能一体机，卖家挂出的价格是399元。说实话，这价格在现在的通货膨胀率下，简直比白菜还白菜，也就一包好点烟钱或者两顿火锅钱的事儿。

但问题来了，作为一款十几年前上市的老古董，这机器现在是“真香”的性价比神机，还是“电子垃圾”回收站？咱们今天不整那些虚头巴脑的参数，就当个验尸官，好好扒一扒这台机器的皮。

先聊聊这玩意儿的“户口”和出身。把时间轴拨回2012年前后，那时候智能手机还没完全统治世界，办公设备也没现在这么花里胡哨。惠普1216当年上市的时候，那是实打实的两千多元身价，那是当时中小企业和公司文印室的标配硬通货。那时候能集打印、复印、扫描、甚至 fax（传真）这四大金刚功能于一身的设备，在只有单一打印功能的年代里，绝对是妥妥的“办公多面手”。

放到现在看，这台老机器确实显得有点“跟不上时代”。你想要 WiFi 无线连接？它没有。你想要手机扫码直连、云打印APP？它更没有。自动双面打印这种高端操作？别想了，手动翻面才是对它最大的尊重。但是，如果你只看最核心的“铁三角”——打印、复印、扫描，它的基础配置一点都没缩水。这就好比老款的诺基亚，功能少，但信号稳，砸核桃还贼顺手。

再来看看这机器的“体格”。官方数据显示它重8.6kg，但我搬起来感觉绝对不止这个数，用料扎实得像块砖头。这种沉甸甸的手感，跟现在那些为了节省物流成本而做得轻飘飘的“便携款”完全不是一个路子。这机器放桌子上稳如泰山，当然，这也意味着你想把它挪个地方或者是搬家，那绝对是个体力活，算是个不大不小的槽点。不过好在买这玩意儿通常就是找个角落落地为安，基本不用动。

它的操作面板非常复古，配备了一个双行液晶显示屏。说实话，这比现在很多厂商为了追求“极简”而砍掉屏幕、只留几个指示灯的设计要良心太多了。不需要复杂的菜单逻辑，不需要连接电脑设置，老人小孩只要按个按钮就能上手，那种物理按键反馈的清脆手感，比在触摸屏上滑来滑去不知道滑到哪里去了。

当然，买打印机核心还是看“干活”的能力。这台惠普1216的核心打印参数是18页/分钟。说实话，这个速度在现在的激光机里不算飞快，跟每分钟三四十页的企业级机器没法比，但你要知道，很多号称每分钟20页的喷墨机，打第一张都要预热半天。对于咱们普通家庭打个合同、复印个简历、给孩子打打学习资料，这个速度绝对够用，甚至可以说是绰绰有余。重点是它的首页输出时间，官方数据是8.5秒，实际使用中，从你按下打印键到纸张吐出来，基本上是转眼的功夫，不用在那儿干等着，这点体验非常加分。

至于清晰度，它标配是600×600dpi，不过通过硬件分辨率增强技术，有效分辨率能达到1200dpi。别看数值不高，激光打印的特性就是字迹边缘极其锐利，黑得纯粹。对于打印文字为主的需求，它的表现远超同价位的喷墨机——喷墨机打久了可能会洇纸、断线，但这激光机就是烤上去的碳粉，怎么弄都不掉色。复印功能跟打印表现持平，25%到400%的缩放范围非常实用，比如你要把身份证正反面印在一张纸上，或者把一个小合同放大看细节，它都能搞定。而且支持连续复印最多99页，不用反复开盖放纸，这当年可是只有大复印机才有的高级功能。

缺点也不是没有。首先，它是一台纯正的黑白激光机，想打彩色照片的朋友可以直接划走了。其次，这货工作的时候噪音略大，听起来像个小电钻在转，这是早期激光定影组件的通病，虽然声音不小，但还在人类可接受的范围内，不至于像装修队进场。

这时候可能有人会杠：“这机器都快二十年了，买回去没两天就坏，修都找不到地儿修。”

这里我要科普一个激光打印机的冷知识：激光打印机的机械结构其实比喷墨机要简单得多。它的核心就是激光头、硒鼓和定影器，没有喷墨机那么复杂的墨路系统和几千个微喷头。只要这台机器没有经历过严重的物理磕碰，或者没进过水（特别是定影组件没受潮），它的核心部件很难出问题。这就是为什么很多旧的激光机只要清清灰，换个小配件就能复活的原因。

还有一个决定性因素：耗材。这机器用的是惠普经典的CC388A硒鼓（简称38A）。这个型号在打印界的地位，堪比子弹界的AK47。市面上原装、兼容、改装、灌粉的，一抓一大把。原装硒鼓可能要五六百块，那肯定是不划算的，比打印机本身都贵。但咱们买二手图个啥？不就是图个便宜吗？直接去二手鱼或者电商平台买兼容款的38A，二三十块钱就能搞定一个。几十块钱的耗材能打印一千多张纸，算下来每张纸的成本才几分钱，这对于有打印需求的学生党或者小型家庭办公来说，简直是真香定律。

我在查资料的时候发现一个挺有意思的现象，这机器2010年刚上市的时候要两千多，现在跌到了399元，这贬值速度堪比当年的比特币矿卡，简直是垂直落地。但为什么它还能在二手市场流通？因为它的皮实耐用在江湖上是有传说的。

直到现在，你去街边的很多图文打印店，你会发现他们角落里可能还摆着这么一台老家伙当备用机。为什么？因为它不娇气。现在的智能打印机动不动就报错、卡纸、连不上网，但这老东西只要给电就能干活。它属于电子界的“五菱宏光”，虽然外表破旧，没有大屏导航，没有真皮座椅，但只要敢踩油门，它能拉货能拉人，耐造程度一流。

最后咱们来个灵魂拷问：399块买这台惠普1216，到底值不值？

我给大家总结一个购买画像：如果你是一个学生，需要经常打印论文、习题；或者你是家庭用户，偶尔打印个合同、税单；你是SOHO一族，需要一台能干活不添堵的设备。那么，这台机器在这个价位绝对是超值的选择。几百块钱买的是一个不用伺候的“老实人”，耗材便宜到让你感觉不到成本的压力。

但反过来，如果你是颜值党，追求桌面的极简美学，或者你需要用iPad、iPhone随时随地无线传图打印，还要打印彩色手账，那你千万别买。买了你也会因为连不上网、没有彩色而骂娘，那时候建议你加钱上新款的喷墨多功能一体机。

好了，评测完了。最后按照老规矩，看完不买，立省399元，这也是咱们捡党最快乐的时刻。
