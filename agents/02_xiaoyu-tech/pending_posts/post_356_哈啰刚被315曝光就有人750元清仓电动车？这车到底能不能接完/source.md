# 哈啰刚被315曝光就有人750元清仓电动车？这车到底能不能接盘？

兄弟们，这两天二手鱼那是真热闹啊。315刚点名批评完哈啰租电动车违规解除限速、套牌上路那些烂事儿，转头就有人在二手鱼上甩卖全新的哈啰电动车。价格直接干到了750块钱，还带着原封的包装箱。这不就是妥妥的时间管理大师吗？这边刚挨完板子，那边就开始清仓回血了？


![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/E9h3abOJCenf3EBtuh0GLZ0pFoZbwY7E3Q7RnFAPV7KYbdRqiah6icl2oUgFpgDCK7UibbWjRWicaVa293PNiaQlicY1KV0UKqmt8uUoW770ibWRCQ/640?wx_fmt=jpeg&from=appmsg)


说实话，我看到这玩意儿第一反应跟你们一样：这到底是不是路上那种共享单车？买到手之后，会不会我正骑着呢，被别人一扫码给刷走了？或者哪天哈啰公司后台一查，发现这车还在跑，直接派人上门给回收了？


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/E9h3abOJCek04eia4hPNTRAyBegygiat6NhExZSgPlzicdHiaUIsWialwToWmqyklarS6VQhlTIuBWZGDfpo47JBSds6eE8ZJfpwwdZVYql3nz28/640?wx_fmt=jpeg&from=appmsg)


先给大伙吃个定心丸。卖家标题写得很清楚，这是D51L和A10型号，带原包装箱，但不是路上那种随扫随走的共享电单车。那种共享车里面装的都是物联网模块和智能锁，得靠平台运营。这批货应该属于哈啰面向B端或者渠道商流出来的所谓“全新未拆封”车辆，更像是以前他们准备投放到租赁市场的库存车，或者是因为最近这波舆论压力，某些渠道商不敢压货了，加速清仓应对围剿。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCenAF1zM9hKxiby3b9zGgn81e3ZH29WXXzLJeE2yANPF6nwXAiaUUqnA0kibjneU2OcpXGH4hYAKk5iaibPoXlF1xwuL7G2hKwWQI9jc/640?wx_fmt=png&from=appmsg)


那这750块钱到底花得值不值？卖家说了，这车不带电池和充电器。这是个巨大的隐藏成本。你去打听打听，现在一组48V20Ah的品牌锂电池或者石墨烯电池，质量稍微靠谱点的，怎么也得再扔进去七八百甚至上千块。加上车钱，总成本奔着1500到1800去了。这个价格，你在二手鱼淘个个人自用的二手品牌电动车，它不香吗？人家好歹还是带了电池、充满电能跑的完整玩意儿。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCekXLuGhubYep9J7QwvR4eLHaDX0lpHwK55y6icSibGoCeiczWBEuFzlzHXXhewZicaVW5hibYuPke4XqmEtKoNW2RjAIX4Zlic6dNwz0/640?wx_fmt=png&from=appmsg)


再说说这车的出身。最近新闻铺天盖地，哈啰租电动车因为让门店违规解码提速到70码，甚至用旧合格证给新车套牌被315锤爆了。咱们得琢磨一下，这批流出来的新车，会不会就是那种“提前办了证”的擦边球产品？虽然卖家说手续齐全，但你买到手如果上牌的时候较真儿，会不会因为车架号和当初备案的“旧国标”不符被卡住？这真得打个问号。而且这车自带定位功能，虽然方便，但服务器万一哪天像之前那波2G断网一样给你来个锁车，你哭都找不着调。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemEvbdZib2T1NvQAxVVibuzkLliabYYUO4goyMtCTs0w6BQHXmaT3x35N7m3Q05nXD4gcOjicM6oCLcePibSGsE0EpvFiaTC3LA0icG6g/640?wx_fmt=png&from=appmsg)


如果你是个动手能力强，能在本地低价淘到拆车电池的老鸟，或者你买回去压根就不打算正经上路，就在自家院子、工厂里头当代步玩具，那750块的裸车价确实够便宜，毕竟这车底子不差，动力足是公认的。但如果你是普通上班族，兜里预算本来就不多，想买个省心代步工具，那我劝你还是别瞎折腾了。后期配电池的坑、手续的隐患、甚至哪天被“误伤”回收的风险，都不是那750块钱能cover住的。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCeleMKYg0NcIziakbSiaftaHcfWzpnnibZSAFZ9ibInDJpVz5kajdfGJSGSMiaf84MA0ZpicfpG0k8PiakdPibfwX47icXH3CORJzFiaCoibyo/640?wx_fmt=png&from=appmsg)


最后问大伙一句，这种来路不明但价格真香的“边角料”，换成是你，你会不会为了省这点钱去赌一把？评论区咱们唠唠。
