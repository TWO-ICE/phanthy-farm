# 内存硬盘涨上天了？看看这台298元的微星飞牛圣体，自带8G+120G

最近二手鱼里是不是都在聊飞牛？一个个都在找飞牛圣体，想把家里的旧电视利用起来，或者搞个24小时不关机的下载机。这波NAS系统热，直接把那些低功耗的小主机价格带得飞起。但我刷了一圈发现，好多人盯着那些J1900、N3160，价格也被炒得有点飘了。直到我看见这台微星，卖家报298元还包邮，感觉配置还行，也算是一台飞牛圣体。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenZODL80xkagfcdYqTTlUWjz0s4wJN6iaRC7DEf2toSvtnmqqhgFtuZgp6FFrkSJNWnYNGibb4xo35iac5C7DrMZXKyc9VrGJwYqc/640?wx_fmt=png&from=appmsg)


这是台微星的MS-B096迷你主机，用的是赛扬3205U处理器，1.5GHz的基础频率，它的优势是只有15W的功耗。最关键的是，卖家已经给你装好了8G内存和120G硬盘，这可不是准系统，是到手就能点亮玩起来的一套完整方案。就冲这价格，还带微星的牌子，我觉得可以跟兄弟们好好盘盘它到底能干啥。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemtWwao4tN9eH5Krib6Ribs4RcqCIqm49H85qEJzoZC1UFG5ncp51Or8lHvMF2Vsn6MNlCNTSNhstibGhLsd81uekYN4XQx5cvksc/640?wx_fmt=png&from=appmsg)


这小家伙巴掌大的机身，但该有的接口全给你了。四个USB3.0，一个千兆网口，MiniDP和HDMI都有，这意味着你可以接两个显示器炒股看盘，或者接电视当播放器。最让我心动的是它的扩展性，除了自带的120G硬盘，里面还能再加一个2.5英寸的机械硬盘或者固态，甚至还有一个mSATA接口。这不就是为下载机和轻量级NAS量身定做的吗？插个大容量的2.5寸盘，刷个飞牛系统，美滋滋。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCemsRyCic29MI0k8wibd1wNAghW8JH8iapnUib9pK9fTgdG8dgI9dMyHzISZw5aZe3O00mEH34T09qUXjdIZXSzd0ER1iaLY7RiaQY9eE/640?wx_fmt=png&from=appmsg)


不过也不能光捡好听的说。这赛扬3205U的性能，跟现在主流的东西肯定没法比，你要是想拿它当主力办公电脑，可能会觉得有点肉。但专门跑个下载、当个软路由、或者像我上面说的，安安静静做家里的数据存储中心。卖家的描述里也说了，外壳少一个螺丝，这点强迫症的兄弟可能得自己想办法解决一下，或者干脆无视它，毕竟这价格还要啥自行车。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCekyCzKAxG7HxC2ZtNK0pzXSOovJO7KtNBIbUcZdnhjZk5FFXsUyqKq1oxPe3dgDeibX19sUA3RO2qVbg4gXLFeQsK44OiaKuiaaZE/640?wx_fmt=png&from=appmsg)


跟同价位的那些玩意比一比，你就知道这台微星的含金量了。现在随便一个树莓派的价钱都涨到天上去了，性能还不一定比这个好。那些一百多的所谓NAS小主机，很多都是准系统，你买到手还得自己砸钱买内存硬盘。现在内存硬盘什么行情大家都知道，涨得让人头疼。这台微星直接把8G内存和120G硬盘给你备好了，虽然是DDR3L的老条子，但胜在够用，省去了你再去淘货的麻烦和冤枉钱。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/E9h3abOJCengfsB6fE8F8nDsiawwKHVmMJgU2icquHUFOARCEh7lDKzuj25uSiaPq6JvknouIfzX4knYu8hP1S3DianOvD2vJibJALfahO6MDWKg/640?wx_fmt=jpeg&from=appmsg)


所以我的建议是，如果你是刚入坑想体验飞牛的小白，或者家里缺个不占地方的PT下载机，这台298元的微星完全可以闭眼入。它的残值已经到底了，用一年半载不喜欢了，挂出去也亏不了几个钱。但如果你是冲着玩游戏或者高性能办公去的，那赶紧划走，这台小破机器满足不了你。
