# 二手鱼里翻出一款接口多到飞起的小主机，配置够用功率够低，刷飞牛正好适合

到底什么样的主机适合刷飞牛系统？其实配置用不着太高，够用就好，待机的功率越低越好，省电，就比如说今天刷到的这款标价139元的联想J1900飞牛单盘3.5寸NAS主机，卖家说“2+32配置，带4串口、2网口，VGA+HDMI双显，接口齐全”，还送原装散热器和电源，功能正常，成色有点使用痕迹。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXE7Tes4CVp8mpeeBkwmqtutWcqdgVAz8TMa1eCPQV5W5eVjficsYWDXmsnibbJib8ttxia1ickPgc0iaLKw/640?wx_fmt=png)


J1900处理器是四核四线程，基础频率2.0GHz，但功耗只有10瓦，7x24小时开着电费几乎可以忽略。内存是板载2GB，存储是32GB的eMMC闪存，虽然跑不了大型应用，但装个轻量级NAS系统绰绰有余。尤其飞牛系统对硬件要求不高，日常做文件备份、远程访问家里的照片视频、挂个下载任务完全没问题。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXE7Tes4CVp8mpeeBkwmqtutkbC4ebUYHmkEsepanEiaQh27QL7bv6NicVMbEqxtN9CRTibEmvAVCLDhA/640?wx_fmt=png)


接口方面确实挺厚道。两个千兆网口意味着可以玩双网卡绑定或者软路由分流，四个串口对普通用户可能没用，但如果你搞点智能家居中控、工业小设备调试，那就是宝藏。VGA和HDMI双输出也方便接老显示器或电视当临时终端用。卖家说“可做NAS、打印机服务器、家庭群晖NAS”，这话不算吹，这类老主机在极客圈里本来就是经典入门机型。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXE7Tes4CVp8mpeeBkwmqtutfuHuzXOM7qhsYIWghqgcfmtib35qlibUPHpUdognpKn3DdWI21XgEsdg/640?wx_fmt=png)


不过也得泼点冷水。图片里主机外壳有明显使用痕迹，而且只拍了外观，没给系统界面、没展示硬盘仓、更没提CMOS电池状态，另外2GB内存说实话有点低了，虽然跑飞牛勉强够用，但基本也没有什么冗余空间了，换成4G其实也用不了多少钱。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXE7Tes4CVp8mpeeBkwmqtutRf1ribBVgvwDkoavrFFYVWIKNnAy2amu7Wyv5gGEXjRwUQWgDfPVezw/640?wx_fmt=png)


目前市面上新NAS整机普遍三四百起步，矿渣洋垃圾也要两百上下。139元这个价，如果配件齐全、功能真如描述，确实算便宜。但它不是万能神机，性能天花板摆在这儿，别指望它转码4K或者跑虚拟机，所以刷飞牛并不要求高配置，机器够用就好。


![图片](https://mmbiz.qpic.cn/mmbiz_png/afNLf2a8eXE7Tes4CVp8mpeeBkwmqtuttfutfaw1XF6CyuoQu7wpjDJX7UHQmSqTBjIZthnGvvgkX8jKyylDKg/640?wx_fmt=png)
