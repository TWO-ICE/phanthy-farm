# 69元能买北通阿修罗3无线游戏手柄？当年300多买的后不后悔？

![封面图](https://mmbiz.qpic.cn/mmbiz_jpg/E9h3abOJCelv4hWmHeCoEExcJ9ftDGpL1VJzbgfNNCI1NLyr5CjSdpicNo0XMJvDr4loldhoKDSWlUiat6ad3fFNuoXSic4ic3ax5oozTxMDneA/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/NbyR-_IX_66AdC_q3OwM_A

二手鱼里逛到一款北通阿修罗3无线游戏手柄，黑色款标价69元包邮还支持自提，卖家说外观很新按键摇杆灵敏功能正常，带原装接收器，支持PC电视Steam平台，还有TURBO BACK SHIFT按键，适合玩原神怪物猎人艾尔登法环这些游戏，就是不退不换。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCenKYZBEYTXgdUoJsgXicYHcSSClwBibAIcWlVF65PrSTuBkjNkicU0OkWjpmr1dzWcWwDEdhCHXl1NGEIgQukhAM8eAxBuZv809Rg/640?wx_fmt=png&from=appmsg&watermark=1&tp=webp)


这款手柄当年可是北通端游电竞系列的主力，首发价300多块，主打物理变速旋钮和机械微动按键，放到现在这些配置在同价位二手手柄里依然能打。它用的是日本进口ALPS摇杆，还有防磨损摇杆结构专利，两个摇杆都能通过下方旋钮调节7档灵敏度，顺时针加档逆时针减档，玩射击游戏时调高档位瞄准更精准，玩动作游戏时调低档位操作更稳定。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCemqZAvrvnY64YG91Ro7Q1OUx2ISEVF1DGrIU0aGweVapia9bC9dY5IfklFfUhChQm6E2qQ23AMRW5rPdsOP09dxcp9kiarIRoib7c/640?wx_fmt=png&from=appmsg&watermark=1&tp=webp)


机械微动按键比传统导电胶按键触发快35%，按起来清脆利落，玩需要快速连击的游戏时优势明显。背部还有两个多功能背键，能映射其他按键或者触发宏，这功能在当年只有Xbox精英手柄才标配，北通把它下放到中端手柄里确实很厚道。三段式扳机行程锁也很实用，全档适合赛车游戏，中档适合动作游戏，短档适合射击游戏，一键切换不用额外设置。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCempvM4QS2GZk6Bl0lMhSBYiakGGq0h0pXXAseOV2LL1CA3yA41OHW1psbm9R6Xr7B5Dy2u9C4eTSicXfxsPuCd7KQtaU7VEvUCL4/640?wx_fmt=png&from=appmsg&watermark=1&tp=webp)


内置950mAh锂电池，TypeC接口充电还能有线连接，裸重250g握感扎实，手柄把手有激光晒纹防滑效果不错。无线连接靠原装接收器，插入后自动识别按logo键秒连，信号稳定延迟低，这是它和蓝牙连接最大的区别。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCel8ibLmtBI6DKFOyPxF5UdwOCXkDibMIJDqK4pPTOSEvtyASNiad6SzyHf0PKpBRleztfd70Efq1yOB5r22icSqibHP4icBGdib0vBHDc/640?wx_fmt=png&from=appmsg&watermark=1&tp=webp)


重点说价格，69元这款是带原装接收器的价格。市面上同款不带接收器的39元也能买到，而且关注的人还挺多。而且接收器单买要40元左右，算下来带接收器的版本反而更便宜。没有接收器的话也能玩，用TypeC线有线连接就行，不过这款不支持蓝牙连接，这点要注意，想无线只能用接收器。


![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/E9h3abOJCem2x2WYVl6Djgh8EGldqPUoHMHr8v3X82Gnqic4NpiaMsCLibGcRgib51vSxthsichyyvXazsM7AUWRW0icCibhTQ6g3cicwdTu6PwBal0/640?wx_fmt=png&from=appmsg&watermark=1&tp=webp)


当然也有要注意的地方，卖家标注不退不换，下单前一定要让卖家拍清晰的外观视频和功能测试视频，确认按键摇杆都没问题，避免买到有暗病的产品。另外这款是老款，没有霍尔扳机和AI震动反馈，和现在200多的新款比有差距，但69元的价格根本没法要求更多。


![图片](https://mmbiz.qpic.cn/mmbiz_png/E9h3abOJCennc4yZQlxud6s3qwVZDpCXrvM9Rw6kPHlb2Kbmht07umrPiaEqDBbjwYxFicQL1IgqRBgyw7U7upibYQkveTtN5onNxm8aLwSGUI/640?wx_fmt=png&from=appmsg&watermark=1&tp=webp)


如果你预算紧张又想玩PC游戏，这款69元带接收器的北通阿修罗3很值得入手，比买39元无接收器款再单买接收器省10块钱，还能直接无线使用。要是你只玩手游或者对震动反馈要求高，那可以看看其他支持蓝牙的新款手柄。
