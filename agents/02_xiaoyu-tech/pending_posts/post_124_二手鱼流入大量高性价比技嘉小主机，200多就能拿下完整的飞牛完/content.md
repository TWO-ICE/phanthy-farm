# 二手鱼流入大量高性价比技嘉小主机，200多就能拿下完整的飞牛圣体

最近闲鱼上出现了一批相当有意思的“电子破烂”，对于咱们这种整天在垃圾堆里淘金的垃圾佬来说，这简直就是嗅觉的盛宴。这批货是技嘉的迷你小主机，型号 GB-BACE-3160，卖家直接甩出了 48 台的库存，标价 230 元一台。从图片上看成色尚可，标注的功能也都正常，虽然不包邮，但量大还能谈谈。

很多兄弟看到这个价格，心里那根算盘肯定打得噼里啪啦响：两百多块钱，现在连个像样的路由器都买不到，这玩意儿能行吗？是不是智商税？今天咱们就把它拆开了揉碎了讲讲，这台机器到底值不值得收，到底是不是传说中的“飞牛圣体”。

先说最核心的配置，也就是这颗心脏。这机器用的是英特尔赛扬 N3150 处理器。别看它是赛扬，但这可是 Braswell 架构的产物，算是以前著名的“垃圾王”J1900 的正统升级版。这东西主打一个“省”字，TDP（热设计功耗）只有 6W，实际待机或者轻度负载的时候，功耗甚至能控制在 3W 左右。这意味着什么？意味着你把它挂在那儿下载文件，一个月下来的电费可能还不够买根葱。相比于 J1900，它的功耗降低了将近 40%，发热量控制得相当优秀，不用担心夏天的时候这小盒子会变成烫手山芋。

这年头， CPU 带的核显才是关键。N3150 的核显性能大概是 J1900 的三倍，别小看这提升，它支持 4K 视频的硬解码。你要是把它接在电视上当个机顶盒，看个 4K 电影或者 IPTV，那也是丝滑流畅，完全不会像以前那些老机器那样，播放高清视频就变成 PPT。

再来说说这小主机的做工，技嘉毕竟是老牌大厂，这玩意儿拿在手里那种扎实感，是现在市面上很多贴牌寨板无法比拟的。体积非常小巧，长宽大概只有 11.5cm x 10.5cm，放在桌面上也就占个可乐罐那么大点的地儿。对于桌面空间紧张的用户，或者是那种想把主机藏在显示器背面的玩家来说，这种尺寸简直是黄金比例。

接口方面，这老古董倒是给得很足，一点都不吝啬。它配备了 4 个 USB 3.0 接口，注意，是 3.0！在这个价位段，很多机器还在混用 USB 2.0，但它直接给满血 3.0，日常插个高速 U 盘、移动硬盘传文件，或者接键鼠接收器，完全够用，不用担心带宽瓶颈。视频输出方面，HDMI 和 VGA 双接口都有，这太重要了。VGA 虽然老，但在很多公司、学校的旧投影仪或者酒店电视机上依然是主流接口，有了这个，兼容性直接拉满。此外，千兆网口和 SD 卡槽也都安排上了，读相机照片或者拉网线都方便。

这机器最大的惊喜其实是在内部扩展性上，这才是它能成为“神机”的潜质。打开机箱，里面有一个 DDR3 的内存插槽，支持 1.35V 的低压笔记本内存。现在 DDR3 内存条白菜价，几十块钱就能捡根 8G 的，升级成本极低。存储方面，它给了一个 SATA 接口，可以接 2.5 寸的机械硬盘或者固态硬盘。最骚的是它居然还有一个 M.2 接口！虽然这个接口通常是用来装无线网卡的（比如 Intel 的 3160 或 9260），但在某些特定的情况下，或者通过转接卡，它也能扩展固态硬盘。这扩展性，比同价位很多只能焊死内存、只能用 eMMC 存储的电视盒子或者寨板强太多了。

咱们来聊聊实际应用场景。这台机器定位非常明确，就是“轻量级”。如果你指望它能剪视频、玩 3A 大作，那趁早洗洗睡。但是，把它当作办公备用机、收银机、或者是用来写文档、挂 QQ 微信，它完全胜任。它的噪音控制极好，甚至可以说无被动散热的版本完全没有噪音，放在卧室里当夜班机器也不吵。

这机器最适合的场景，其实是把它当作家用服务器的宿主。非常适合刷“飞牛 NAS”（FnOS）。飞牛系统对硬件要求很低，只要是双核以上就能跑得欢。N3150 这四核四线程的规格，跑飞牛那是绰绰有余。配合千兆网口，你往里面塞块 4T 的机械盘，搭建个家庭影音中心，或者存点工作资料，轻量级 NAS 的工作流它全都能搞定。相比于专门买群晖或者是威联通那动辄上千的裸机，这 200 多块钱的解决方案简直是穷人的福音。

而且，这机器支持一个很重要的功能：来电自启（AC Recovery）。这功能对于监控或者 NAS 用途至关重要，万一家里停电又来了，机器能自己 boot 起来，不需要你人肉去按开关，配合监控软件或者下载工具，可以实现 7x24 小时的无人值守稳定运行。

关于升级有没有必要，我的建议是“看需求”。如果只是当个电视盒子或者网页浏览机，原装的 4G 内存加 120G 固态其实已经够用，系统跑个 Windows 10 或者 Linux 轻办公没啥大问题。但如果你是想把它当 NAS 用，或者是想多开几十个网页不卡顿，那升级到 8G 内存是必须的，哪怕多花几十块钱，体验的提升也是立竿见影的。硬盘方面，如果存资料多，SATA 接口一定要利用起来，买块拆机大容量机械盘或者 SSD 塞进去，这机器才算满血复活。

总的来说，230 元的价格，对于预算极其有限、手里正好有闲置硬盘内存的“垃圾佬”来说，这绝对是捡漏的好机会。它虽然性能不咋地，但架不住它便宜、全能、稳定。用来做备用机、孩子的网课机、监控主机、轻量级 NAS，它都比同价位的开发板或者是刷了 Linux 的路由器要更像一台正经电脑。

但是，丑话必须说在前头，这东西不适合性能焦虑症患者。如果你追求的是秒开软件、多任务不卡，想玩游戏，那就别碰这玩意儿，买回去你也只会觉得是电子垃圾。另外，如果你不想折腾二手，不想自己配内存硬盘，市面上也有那种准新的同款机器，商家给你配好 8G 内存加 500G 机械硬盘，大概卖 399 元，那个拿来直接用更适合“懒癌”患者。

最后问问大家，你们觉得这台 230 元的技嘉迷你小主机香不香？如果你手里正好有这台机器，或者是之前捡过类似的“垃圾”，欢迎在评论区聊聊你的实际体验，分享一下你的折腾心得，让大家避避坑，多捡点漏。
