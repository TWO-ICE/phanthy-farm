# 皇马又输了！主帅下课？

在一个整体上波澜不惊的欧冠夜，皇马又一次成为段子手们的素材包。主场面对着近几个赛季的老冤家曼城，在姆巴佩缺阵的情况下，皇马群星全场比赛竟然只有一次射正，最终1比2败北。哈兰德的闪耀和银河战舰众将的沉沦形成鲜明的对比，人们似乎已经在讨论阿隆索下课的问题。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBRYwHscS9iallMcwgR89hWyGOXXyETO7a1OYOl9TvdYW4mMa941zgESKTldNyU4sdjpQjVBLpe0ddQ/640?wx_fmt=jpeg&from=appmsg)

皇马vs曼城的天王山之战，已经成为过去几个赛季欧冠的常规节目。2021/22赛季半决赛，本泽马超神导演了皇马的神级逆转；2022/23赛季半决赛，蓝月亮砍瓜切菜般横扫宣告王者登基；2023/24赛季1/4决赛，双方进球大战鏖战至点球，银河战舰又一次笑到最后；2024/25赛季附加赛，皇马用双杀的表现送走跌入低谷的曼城。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBRYwHscS9iallMcwgR89hWyGKlLyUxCZSaeM4PubOeUfBFWpM6mL16EP9VMp8ADHicicc8fGpaza3JrQ/640?wx_fmt=jpeg&from=appmsg)

这是皇马和曼城连续第五个赛季相遇，此前四次狭路相逢，拥有欧冠DNA的银河战舰整体上更胜一筹，如今双方则各有各的难题。曼城联赛开局不佳，但状态渐渐回暖，不知不觉距离英超领头羊阿森纳只有两分，皇马却在国家德比的胜利后突然萎靡不振，西甲积分榜上被巴萨反超，阿隆索的帅位已然不稳。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBRYwHscS9iallMcwgR89hWyGD4sxibK7ibI8eicUrMv6ed0z5wUGxcIXN27pYPA0tibAgYgiceG4XeZiap2A/640?wx_fmt=jpeg&from=appmsg)

因此，在上周末爆冷不敌塞尔塔的情况下，与曼城一战某种程度上是龙哥的救赎之战，然而在姆巴佩作壁上观的情况下，皇马豪华的攻击群却找不到一点脚感。开场三分钟，维尼修斯禁区内被努内斯放倒险些制造点球，但裁判回看VAR后取消判罚，而罗德里戈带球甚至带出了边线，场面一度变得小尴尬。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBRYwHscS9iallMcwgR89hWyGNpUaVzibynlVPHyhObsKtlVXjnRRHf0t2Q0zvN9k5t9icMHJXEqSPqYg/640?wx_fmt=jpeg&from=appmsg)

开局阶段，皇马确实踢得积极，并且还在第28分钟取得领先——贝林厄姆送出直塞，助攻罗德里戈打破进球荒，后者破门时距离皇马前锋队史1416分钟的进球荒只差一分钟。不过，皇马的领先优势并没有维持多久，第35分钟，曼城开出角球，奥赖利门前补射破门，让双方回到同一起跑线。


![图片](https://mmbiz.qpic.cn/mmbiz_gif/sAmI87QVQBRYwHscS9iallMcwgR89hWyGcJPNAMkdrIichlibvHrn8CibpDOFxJBPuR2qP9s7NsWjBJIxjelJLSl7g/640?wx_fmt=gif&from=appmsg)


![图片](https://mmbiz.qpic.cn/mmbiz_gif/sAmI87QVQBRYwHscS9iallMcwgR89hWyGUFBBqvxnjgfWRM8ZFhBguzXmwBeYGnc4cgsU3mInjiajPh1icja2DjHg/640?wx_fmt=gif&from=appmsg)

对皇马而言，噩梦还没有结束，上半场结束前，哈兰德制造点球并亲自主罚命中，打进了个人本赛季各项赛事的第34球，追平了C罗2013/14赛季同期的纪录。这也是挪威人26岁前打进的第55个欧冠进球，仅次于同期打进59球的梅西。欧冠前50场首发打进51球，则是哈兰德独自拥有的纪录。


![图片](https://mmbiz.qpic.cn/mmbiz_gif/sAmI87QVQBRYwHscS9iallMcwgR89hWyGxVeG7HWXic84A8Gfrrd4GOVGhQF1aydyttZ1XWdAJvbFnicrWXGW7QBw/640?wx_fmt=gif&from=appmsg)

事实上，要不是库尔图瓦进入更衣室前神勇化解哈兰德和谢尔基的射门，皇马将带着极端被动的局面进入下半场。而易边再战之后，皇马的锋线大将们依旧无法找到射门靴，贝林厄姆挑射压不住，罗德里戈远射偏出，反倒是曼城的进攻更具威胁，让库尔图瓦一次次高接抵挡化解险情。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBRYwHscS9iallMcwgR89hWyGrN6QvvrwymeABzmh3ecX53vOeRHYtw7XLJqSqwDrryvyan8Ag6ATDA/640?wx_fmt=jpeg&from=appmsg)

坦白说，曼城此役踢得并不算完美，奥赖利禁区线外推倒巴尔韦德险些送出点球，皇马也并非毫无机会，比如比赛尾声阶段，恩德里克的头球就击中横梁上沿弹出。整体而言，双方打出的是势均力敌的局面，只是皇马锋线的准头实在一言难尽，16次射门竟然只有1次命中球门目标，创下了欧冠有记录以来的皇马队史最差。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBRYwHscS9iallMcwgR89hWyGT6Vic7H4VU1PHAbLZ5dPygGM9MUMeMHI7GxTZwbibFo8Dcpy1XsXPEtw/640?wx_fmt=jpeg&from=appmsg)

就这样，比分定格在1比2，马德里没有想象中的狂欢，曼城成功复仇。银河战舰近两次在伯纳乌的欧冠比赛中领先后输球，都是对阵曼城，上次还是2020年的1/8决赛。本轮过后，阿森纳继续在夺冠赔率第一的大热位置，曼城升到第3位，皇马本轮告负后跌至第6，前五的还有拜仁、巴黎和巴萨。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBRYwHscS9iallMcwgR89hWyGo8696eDObMUFOPeiajMAibEjuwIrFxFjgttBaIicFTYq5Smwjics0Td0QA/640?wx_fmt=jpeg&from=appmsg)

面对近期尴尬的局面，阿隆索赛后表示：“当球队很多球员缺阵时，你会感到不够稳固，这也是对手迅速扭转局势的原因之一，因为他们是一个强大的对手。我们给对手的机会很少，但已经足够让他们进球。当事情不顺的时候……我们有机会，但没有把握住。我的未来？这不是我现在要考虑的事情，我专注于皇马的下一场比赛，这才是最重要的。”


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBRYwHscS9iallMcwgR89hWyGVn9jS3fM8PEdzS5LkrzIjmrPYOLjMrgZuwzDMv1On9qkJ09AO3cS7Q/640?wx_fmt=jpeg&from=appmsg)

据统计，阿隆索执教皇马前6场欧冠比赛输掉2场，2019年索拉里5场欧冠输掉2场之后，他是最快输掉2场欧冠比赛的皇马主帅。值得一提的是，2019年索拉里带队输给阿贾克斯6天之后，他就被齐达内取代。在本赛季的高开低走之后，风口浪尖的龙哥，接下来是会赢得信任，还是走向下课的深渊？
