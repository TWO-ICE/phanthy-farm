# 大巴黎双杀挺进决赛！阿森纳四大皆空！

对于阿森纳而言，本赛季最尴尬的事情是什么呢？答曰：利物浦拿了英超冠军，曼城在争足总杯冠军，曼联热刺在争欧联杯冠军，切尔西在争欧协联冠军，只有阿森纳四大皆空。北京时间今天凌晨，这样的担忧成为现实，欧冠半决赛次回合比赛中，枪手客场1比2不敌巴黎，以总比分1比3被双杀出局。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBT9646oiaziaMMc4IgeDoWvhJZmIiaJPqJCicrI5UcRtpOX0uKOAcQJhynH51GS30H6daEuxRa6gRz85g/640?wx_fmt=jpeg&from=appmsg)


不得不说，阿森纳的出局，在过去的一周已经埋下伏笔。首回合主场0比1败北是前奏，周末联赛三支欧冠半决赛球队都养精蓄锐派替补登场，只有阿尔特塔神奇的让全主力搏命结果还被伯恩茅斯逆转。一边是以逸待劳主场作战的大巴黎，一边是主力消耗体力舟车劳顿的阿森纳，次回合的结果可想而知。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBT9646oiaziaMMc4IgeDoWvhJECicok97axZ8zshTrM7CFWnQ1OytKaCiayBjxvVYDdIibjGUoukYhrT4A/640?wx_fmt=jpeg&from=appmsg)


即便如此，王子公园一役阿森纳还是踢得积极主动的，赖斯开场3分钟的头球攻门擦柱而出，就吹响了枪手进攻的号角，之后马丁内利的抢点打门和厄德高的二点迎球抽射都逼迫多纳鲁马做出神扑。比赛开始不到10分钟，阿森纳就已经数次威胁到巴黎的球门，只是多纳鲁马像前一个比赛日的索默一样，成为了决定比赛的关键所在。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBT9646oiaziaMMc4IgeDoWvhJDNQxKZUia6j0PRAFaylPUtv35Fmtm1YCaibzLHLP8KaMtpXMMyoeYS5g/640?wx_fmt=jpeg&from=appmsg)


当然，主场作战的巴黎不会坐以待毙，反击很快就开启。第17分钟，克瓦拉茨赫利亚在反击中内切兜射击中立柱，惊出阿森纳防线一身冷汗，第27分钟，法比安-鲁伊斯直接轰出凌空世界波，改变了场上的均势。上半场剩余的时间双方互有攻守但都没能再完成破门，巴黎带着2比0的总比分进入更衣室。


![图片](https://mmbiz.qpic.cn/mmbiz_gif/sAmI87QVQBT9646oiaziaMMc4IgeDoWvhJAnBjg14LrjibYExmyy2vLGVqIC2BuG1bdk3VR4WVUNrJ3vbiblleERdA/640?wx_fmt=gif&from=appmsg)


易边再战，双方一度陷入僵持，阿森纳再次连续制造机会，只是这个夜晚的多纳鲁马有如神助，多次用神扑粉碎枪手的梦想。于是乎，再次获得改写比分机会的还是巴黎，第69分钟，斯凯利禁区内手球送点，拉亚神勇化解维蒂尼亚的点球守住枪手希望，然而仅仅三分钟后阿什拉夫就完成了抽射破门，终结了这个系列赛的悬念。


![图片](https://mmbiz.qpic.cn/mmbiz_gif/sAmI87QVQBT9646oiaziaMMc4IgeDoWvhJFjl0dX3vUicIWMu3gZcXjL4ia3Rpd0MJ4mpXcicwLgDkfwUuHdmoV8r8g/640?wx_fmt=gif&from=appmsg)


![图片](https://mmbiz.qpic.cn/mmbiz_gif/sAmI87QVQBT9646oiaziaMMc4IgeDoWvhJXXib8ToyCoRLJv6SznR9vZEEgy1kia1npVU7FTrANznvv0rokO4ZoR0A/640?wx_fmt=gif&from=appmsg)


总比分变成了0比3，阿森纳依旧没有放弃，萨卡在第76分钟打空门得手让悬念略微回归，但面对巴黎铜墙铁壁般的防守，阿尔特塔的弟子们再无办法，只能接受被双杀出局的命运。此役阿森纳几乎所有的关键数据都占优，更是创造了4次绝佳机会，可惜他们面对的是开挂了的多纳鲁马和意志坚定的巴黎，最终被挡在决赛门外。


![图片](https://mmbiz.qpic.cn/mmbiz_gif/sAmI87QVQBT9646oiaziaMMc4IgeDoWvhJHpDONK25sl3EG5IWhry7oEBG7u6e4V4ooQbKGliaLIZD8uRoibsuDYcw/640?wx_fmt=gif&from=appmsg)


阿森纳倒在了欧冠半决赛，本赛季确定四大皆空，枪手在英超18胜13平4负积67分，距离榜首15分，已经无缘冠军；足总杯1比1（点球3-5）曼联被淘汰，止步第三轮；联赛杯两回合0比4纽卡，同样止步半决赛。对于阿尔特塔而言，无论在用人还是球队整体策略上，这都是一个遗憾且需要总结的赛季。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBT9646oiaziaMMc4IgeDoWvhJ0Q5SicfzLPwyfnd2Kzm3ndOBiclGv0IP03gDFuDC8NtjGkYtJ4ItJ6lw/640?wx_fmt=jpeg&from=appmsg)


至于时隔五年重返欧冠决赛的巴黎，他们有理由去纵情欢呼，在姆巴佩自由身离队之后，这支没有了超巨的球队反而踢出了团队足球，恩里克用丰富的经验让法甲航母蜕变，成为本赛季唯一可能拿三冠王的球队。更难能可贵的是，巴黎三轮淘汰赛先后淘汰了利物浦、维拉和阿森纳三支英超球队，无愧于英超杀手之名。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBT9646oiaziaMMc4IgeDoWvhJ629pbyAaniag7h8HddLxcuGw4b8csFgv18icSJrbAznibtx7TpI4fziayA/640?wx_fmt=jpeg&from=appmsg)


即便如此，恩里克赛后还是谦逊地进行了总结，他表示：“这场比赛令人情绪激动！阿森纳踢得很好，而我们不得不全力防守，但我们也有几次反击机会……比赛非常艰难。这不是我们想要的比赛。”有时候，教练的格局决定了一支球队的上限，巴黎确实迎来了球队向欧洲豪门蜕变的历史机遇。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBT9646oiaziaMMc4IgeDoWvhJPBNLsVk6anRkQUnKp963hScWnNUHvbKOxlZ80ojtjXT5QAud7QTrmQ/640?wx_fmt=jpeg&from=appmsg)


至此，欧冠决赛对阵已经确定，被戏谑为“农民联赛”的法甲走出了巴黎，被吐槽风光不在的意甲走出了国米，一个要为队史首个欧冠冠军而战，一个要冲击15年来的首个大耳朵杯。谁将创造历史？6月1日的慕尼黑，期待一个崭新的答案！
