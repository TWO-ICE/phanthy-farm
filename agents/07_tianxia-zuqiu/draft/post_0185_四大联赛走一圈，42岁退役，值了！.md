# 四大联赛走一圈，42岁退役，值了！

科莫是本赛季的意甲大黑马，少帅法布雷加斯有人往高处走的趋势，然而率先成为将走之人的是另一个西班牙人佩佩·雷纳，只不过他是以退役的方式与科莫分道扬镳。这不奇怪，从年龄上说，1982年出生的佩佩能出现在五大联赛的舞台上已然是奇迹，从即战力上说，自进入2025年以来，雷纳几乎一直在替补席上扮演看客。当科莫开始构建“做大做强”的梦时，早就过了不惑之年的雷纳深知自己的使命感应该告一段落了。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBTruxFX33HiaaeiabTwmb38JvkvN9nz1nIiabbWOQrnXrcw2lvAF1CZ7ct5VZrmfchIrN5hkl62uwbMQ/640?wx_fmt=jpeg&from=appmsg)

时光倒流到去年夏天，在雷纳与科莫正式签约之前，法布雷加斯就强调了前者的冠军属性和比赛经验，虽然最终只是在熟悉的亚平宁半岛上演绎了“一年游”，但雷纳的老兵风骨并未完全褪色。12场比赛丢掉14球的成绩单支撑着西班牙球星的最后逞强，并且他将自己设定为一个成功者，用他的话说：“科莫拥有我所需要的一切，还有像法布雷加斯这样有头脑的教练，他是我的朋友。”值得一提的是，雷纳早就明确了自己当教练的梦想，也许已经在法布雷加斯身边偷偷“取经”了。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBTruxFX33HiaaeiabTwmb38JvbHXULqpgDA3ObITGz5XUBXpKYmwcwAlzto8JjibdwPEsG9XfGTcYNoA/640?wx_fmt=jpeg&from=appmsg)

退役或许是一个伤感的话题，只是对于拥有25年球员生涯的雷纳而言，他知足且满足。在俱乐部层面，他在英超、西甲、意甲和德甲四大联赛缔造过光辉岁月，拥有联赛冠军和欧洲超级杯冠军，个人更是三度荣膺英超金手套奖。在国家队层面，他捧起过一次世界杯冠军和两次欧洲杯冠军，最突出的个人成绩单是为国争光的36场比赛中只丢了21球，并完成了21次零封。两条战线遍地开花，职业生涯只差一座欧冠的雷纳没有隐藏自己的骄傲：“如果我回顾过去自己所经历的一切，我会感到非常幸运。”


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBTruxFX33HiaaeiabTwmb38JvzKXBA3uTRVAE09ZdNxkEwoAwTSFcWNdC2KHL174hHxWWxFmHM9mJibQ/640?wx_fmt=jpeg&from=appmsg)

毋庸置疑，雷纳拥有令人羡慕的职业生涯，但他并不是“一口气吃成胖子”。雷纳出自拉玛西亚青训营，虽然18岁就捞到了在联盟杯半决赛露脸的资格，不过同龄人巴尔德斯的出现让巴萨拥有了对比论，最终雷纳以租借的形式告别了梦想开始的地方，事实上巴萨也只是从他身上套现了75万欧元了。


从年少成名的期望到戛然而止的失望，雷纳似乎有自暴自弃的迹象，然而他却在情歌球场完成了十三年磨一剑的成长录，最典型的英雄主义模式是9次面对点球，他居然赢下了7次，最大的成就感则是浮出水面的潜水艇跻身欧冠大舞台，这也为日后双方的二次合作埋下了伏笔。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBTruxFX33HiaaeiabTwmb38Jvc6uxiaxMEhibOaictSqvRRpmF2WyHGGLSVS9D82now8648RohVD0Tscfg/640?wx_fmt=jpeg&from=appmsg)

踢出名堂的雷纳开始扭转人生，他入选了西班牙国家队，他加盟了利物浦。600万欧元的转会费或许不值一提，但雷纳在登陆英超的头一个赛季就掀起了风浪，尤其是足总杯决赛上三扑点球的壮举让人念念不忘。


用荣誉衡量个人价值的话，在效力利物浦的8年时间内，雷纳捧起了足总杯、联赛杯、社区盾和欧洲超级杯和冠军。用数据验证的话，他在397次出场中只丢失了339粒进球，并完成了177次零封，连续三个赛季荣膺金手套奖实属不易，以至于贝尼特斯在2009年为爱徒打call：“雷纳是英超最好的守门员，也是西班牙最好的。”


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBTruxFX33HiaaeiabTwmb38Jv6M1JfR8CtVq2WicfdL3yMbHr2CCyOmypsB4zic96a5YXic0N4LeJhqL7w/640?wx_fmt=jpeg&from=appmsg)

花无百日红，雷纳在利物浦时期也曾陷入怀疑论中。比如2009年利物浦与切尔西的进球大战中，雷纳在对方主罚任意球时，居然还在指挥人墙，2010年对阵阿森纳时，连人带球一起扑进了自家球门。即便在英超有高开低走的嫌疑，但雷纳并没有分手计划，奈何致力于年轻化的罗杰斯粉碎了西班牙人的红色梦想，虽然只是以租借形式暂时离开，但主帅并没有为雷纳设定“回程票”——“雷纳租借加盟那不勒斯的时候，不是已经写了告别信吗？”


![图片](https://mmbiz.qpic.cn/mmbiz_png/sAmI87QVQBTruxFX33HiaaeiabTwmb38JvzFy8tYqCNB0mqbf2JARpUkp2h63awhneJOQTDLWVjlz9DVnwoOd3jw/640?wx_fmt=png&from=appmsg)

雷纳有与往事和解的方式，在情怀上，他声称自己“永远是利物浦的球迷”，在动力上，他并没有因为被放逐失去活力，就像当初他离开巴萨一样。果不其然，2013-14赛季在那不勒斯的成就感不仅是出场了42次，贡献了1次助攻，与恩师贝尼特斯的重逢或许是巧合，但能在32岁同时得到拜仁和AC米兰伸出的橄榄枝，已经是偶然中的必然。


幸运中也夹杂着不幸，雷纳在效力拜仁期间只能在替补席上欣赏诺伊尔的矫健身姿，准确说2014-15赛季只亮相了3次（193分钟），第一次出场居然是加盟拜仁后的第6个月，只不过当时西班牙门将并不后悔自己的选择：“我从诺伊尔和瓜迪奥拉身上学到了很多。”


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBTruxFX33HiaaeiabTwmb38JvUAXNQvGGCZw1fZGn3eUiavwbkQAdnpMQd5kfYB6QibYGXl2ueu6BScuQ/640?wx_fmt=jpeg&from=appmsg)

那不勒斯在2015年第二次给予了雷纳“找自己”的舞台，当主力门将和拿意甲亚军的经历肯定了西班牙人的选择，尤其在2016-17赛季出场时间达到了4320分钟，并完成了14次零封，考虑到200万欧元的转会费，这笔交易极具性价比，只可惜彼此没有延续合作关系。从双向奔赴到爱而不得，雷纳感慨过命运的安排：“要是没有俱乐部主席德劳伦蒂斯的话，我会在这里一直待下去。”


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBTruxFX33HiaaeiabTwmb38JvI2Kq4nrOEBZrewW1jJ5Ptia4aaVzzd7KOld3afqYDia0yniciaZ1rMXcaA/640?wx_fmt=jpeg&from=appmsg)

36岁被AC米兰签下是一种短暂的荣誉，由于多纳鲁马的存在，雷纳重复了拜仁时期枯坐板凳的窘境，牵手阿斯顿维拉，唯一的收获或许是与老东家利物浦狭路相逢，加盟拉齐奥，他的扑救成功率居然排在意甲倒数第一。三连退模式下的雷纳越来越接近退役，事实上雷纳在40岁就公开过退役的念头，为此他谢绝了续约。


但当比利亚雷亚尔伸出橄榄枝时，雷纳觉得自己应该拥有落叶归根的机会。本以为只是一次象征性的签约，但不惑之年的西班牙人却焕发了第三春，在效力的44场比赛中完成了11次零封，即便没有在这里完成球员生涯的谢幕，但他始终将比利亚雷亚尔视为“曾经是、现在是、将来也是我的家的地方”。当雷纳宣布即将结束自己的职业生涯之际，媒体提前透露了他的“诗和远方”——前往比利亚雷亚尔青年队执教。

告别总是猝不及防，只是已经将退役决定推迟四年的雷纳习惯了聚散离合，如果还有完美的谢幕机会，球迷希望法布雷加斯在科莫与国际米兰的比赛中能给予雷纳最后一舞的机会。
