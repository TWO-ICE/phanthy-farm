# 活久见，英超助攻王！

**点上方蓝字“天下足球”快速关注****最有情怀的足球尽在这里**


转会市场上风起云涌，但并不是所有的大手笔都能如愿成为意中人，但有一个人提前进入了新角色。自格拉利什加盟埃弗顿以来，俨然成为了“人挪活”的代表人物。在为新东家亮相的3场比赛中，格拉利什已经贡献了4次助攻，虽然英超助攻王的头衔只是暂时的一时之喜，但彼此都有相见恨晚的情愫在发酵，甚至延伸出来“明天更美好”的期望。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBSs01ZR1OK0DKFJXhqzM8JeS1JrHt76nCVGFPAeMzvHMxUOicibdRmR7zbmO75icInA1MjkCX9wht0UQ/640?wx_fmt=jpeg&from=appmsg)

格拉利什如释重负的感觉不言而喻，并不会因为从曼城到埃弗顿的选择陷入落差感，反而陷入了本该如此的狂喜中：“终于又能连续3场首发的感觉真棒！”这并不奇怪，要知道，他上一次连续三次首发的快感居然要追溯到整整一年前。


继续延伸选择正确性的话，他在2024-25赛季只为曼城送出了一次助攻，而在租借埃弗顿后，格拉利什只用了两轮英超就贡献了4次助攻的成绩单，准确说，他在197分钟内就完成了4次助攻。助攻或许存在意外之喜的成分，事实上英格兰人在埃弗顿的每90分钟内就能在危险三区完成26次触球，真正意义上实现了“我本如此”。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBSs01ZR1OK0DKFJXhqzM8Je82GxmWcWH4r67ZOGDxzkWpeCialmtlEbojPrsClybic1OG8NicQN3GUicA/640?wx_fmt=jpeg&from=appmsg)

埃弗顿主帅莫耶斯得之我幸的情绪没有隐藏，甚至觉得这是意料之中的事情，用他的话说：“他比我想象中的还要出色，但这一切都是关于他，而不是我。他可能需要一些关爱和关注。”虽然类似的褒奖层出不穷，但埃弗顿主帅的言论更像是一次“伸张正义”，直白地讲，瓜迪奥拉或许耽误了格拉利什的成长轨迹，毕竟换了新东家的格拉利什是本赛季五大联赛唯一助攻超过2次的球员，后知后觉？或许英格兰人也蓄势已久。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBSs01ZR1OK0DKFJXhqzM8JeMWo9yXkaAjjAcMOGKtwrgJ99EeatfdicmKer32QPIlPDLEaFNbnW7Aw/640?wx_fmt=jpeg&from=appmsg)

坦白讲，格拉利什在瓜迪奥拉麾下递减式失宠了。据统计，英格兰人在2024-25赛季只在英超捞到了715分钟的出场时间，当黄牌数（3）＞进球（1）+助攻（1）时，几乎所有的球迷都在讽刺或者挖苦昔日的大英帝星，未能入选今夏曼城世俱杯大名单一点不意外，或者说，蓝月亮提前肯定了格拉利什将走之人的身份，这被认为这是曼城完成重建的关键步骤，要知道，他的周薪高达30万英镑，当不能完成出工出力的硬性任务时，所谓的“亿元先生”的光环散落一地，甚至被认为是曼城的累赘。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBSs01ZR1OK0DKFJXhqzM8JewqRoUysIHJjwzbiahWQUqhOdiavuSLNMtibXwR6AzEopPgCXA70ic6SEyw/640?wx_fmt=jpeg&from=appmsg)

瓜迪奥拉并不会强人所难，当斯特林要寻求所谓的存在感时，他选择了成全弟子另寻他路，当格拉利什希望重塑自我时，西班牙教头也并没有设置拦路虎。或许这是弃之如敝履的直接反馈，但其实瓜迪奥拉对格拉利什的喜欢阶段性呈现过，放弃只是比较论下的一种下下策，也是各自欢喜的唯一选择，这不难理解，有危机感的曼城要收拾旧山河，格拉利什要追逐从前的自己。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBSs01ZR1OK0DKFJXhqzM8JeJmhMbGVrBhyDeTVNic3lHh1DWibgp1Ts3ZHEBxF16XNcD0dh749OLXzA/640?wx_fmt=jpeg&from=appmsg)

瓜迪奥拉在2021年坦诚第一次看见格拉利什踢球时，就进入了“非你不可”的追逐模式中，2023年当见格拉利什陷入怀疑论时，瓜迪奥拉出面协调了：“他是一名常规的首发球员，因为他场上表现非常好。我经常轮换球员，但与此同时我看到他们每场比赛的表现，你必须努力继续下去，加油！”


即使在租借埃弗顿之前，瓜迪奥拉也没有嫌弃的意思，反而很真挚地答疑解惑：“格拉利什没有上场的唯一原因是我，而不是因为他做错了其他的什么。他是一名顶级球员，但球员之间必须相互竞争。上赛季多库在很多场比赛中都表现出色，萨维尼奥在首秀赛季也取得了进步。”


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBSs01ZR1OK0DKFJXhqzM8JeLGmQuSceLCCjnPG4MBKvZCAr9FjUTgsueX7maV8IrrAXnPANm44ibcg/640?wx_fmt=jpeg&from=appmsg)

格拉利什虽然希望在曼城实现共进退，但在签约埃弗顿时，他大吐口水：“在曼城的四年时光里，我非常开心，但是我在曼城一直被告知何时呼吸、传球、突破、射门……我觉得是时候要做出改变了。”字里行间似乎是对瓜迪奥拉的不满，事实上在成为埃弗顿历史上首位连续2场英超助攻双响的球员之际，他甚至含沙射影地批评了瓜迪奥拉的用人策略。


英格兰球星有自己的反击根据地，比如在对阵狼队时，他以一己之力盘活了埃弗顿的进攻体系，全场完成了5次成功突破，贡献了3次关键传球，制造了7次犯规。现阶段的太妃糖在积分榜上高居第5位可能是短暂的美好，却不妨碍在变好的过程中自我总结，毕竟上赛季的埃弗顿在英超只位列第13位。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBSs01ZR1OK0DKFJXhqzM8JeC4xurjlNkfbL8aiaIaGMdU3yKIRSGiaqsrJ8QC7iarGfibiaibaToz0cNG2Q/640?wx_fmt=jpeg)

虽然只是租借的形式加盟，但埃弗顿承担大约25万镑的周薪，倘若双向奔赴得到延续的话，太妃糖还要掏出5000万镑的转会费，对于不差钱的曼城而言，这是打半折的瘦身几乎，对于“庙小”的埃弗顿而言，或许再续前缘的就窗口不局限在这4次助攻上。倘若格拉利什高开低走的话，反向吞噬了最初的外界期望与个人理想。


庸人自扰之？《泰晤士报》就破了一盆冷水，格拉利什效力曼城期间就经常出入高档夜店，单次消费5000英镑是习以为常的事情，并且每周至少光顾三次。倘若借着复苏的油头又在酒吧嗨起来的话，曼城彻底成为过去式，“太妃糖”也只是暂时有点甜。
