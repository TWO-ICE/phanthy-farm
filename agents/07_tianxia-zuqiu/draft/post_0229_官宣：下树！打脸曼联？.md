# 官宣：下树！打脸曼联？

![封面图](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBQpnzvPJMpZSZE38GLXZibaYVP6DoRsPaAkAluzCfpkicgibWwCC6xNJg3DgRceZwfHYLpB7qM5icafAA/0?wx_fmt=jpeg)

**点上方蓝字“天下足球”快速关注****最有情怀的足球尽在这里****


上赛季的诺丁汉森林堪称英超大黑马**，**球员身价水涨船高是自然而然的事情**，**两年前以**1500**万英镑转会费加盟诺丁汉森林的安东尼**·**埃兰加就是代表人物**，**他在今夏以**5500**万英镑的转会费牵手纽卡斯尔**。**虽然存在些许溢价购买的嫌疑**，**但**23**岁的瑞典小将确实有自己的魔力**，**据统计在过去的两个赛季**，**他在英超赛场贡献了**20**次****助攻**，**这一成绩高居****英超****第三**，**仅次于萨拉赫和沃特金斯**。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBQpnzvPJMpZSZE38GLXZibaYVAoJSATZDYAbicmerOQVicyCOFj6fF9Hj43lpyaO4jrlE3icniajHjrNJw/640?wx_fmt=jpeg&from=appmsg)

**诺丁汉森林主帅努诺曾以**“**他始终保持活跃**”**赞扬过弟子的重要性**。**抛开给外界制造惊喜的助攻数据**，**埃兰加的冲刺速度高达**34.8km/h，**每次带球的平均距离**15.2**米**，**这两个数据位居**24-25**赛季英超前茅**。**他的左右脚近乎均衡**，**据统计自出道以来**，**埃兰加右脚射门占比**55.1%，**左脚射门占比**36.4%。

****

**在诺丁汉森林习惯性演绎速度与激情习以为常**，**并且埃兰加并没有因为外界的褒奖而刻意谦虚**，**反而直白地解释了自己的生存之道**：“**关键是利用进攻空间**，**并尽可能快地到达对方球门**，**我自信****认为我是联盟中最快的球员之一**。”


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBQpnzvPJMpZSZE38GLXZibaYtVyrgLaSqAhnxA9PRurzCgCicV90mCRuuDruIP2PC0J412pIYBia4xBA/640?wx_fmt=jpeg&from=appmsg)

**就上赛季而言**，**对阵利物浦贡献了制胜助攻**，**埃兰加在赛后得到的评语是**“**不仅是一个跑得快的边锋**，**而且很聪明**”。**对阵维拉贡献了补时绝杀**，**他给自己的总结是**“**我是一名优秀的终结者**。”**对阵布莱顿上演了职业生涯第一个助攻帽子戏法**，**完成帽子戏法的队友伍德直言**“**他让我的工作每次都变得更轻松**”。**几乎每一次制造明星效应时**，**埃兰加都在重新介绍自己**，**毕竟他的身上有曼联弃将的标签**。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBQpnzvPJMpZSZE38GLXZibaY3q6yOz6CBIU3jEBulSkWiacesQbLC236jlMUQib8R2BVag1BhyvbUavA/640?wx_fmt=jpeg&from=appmsg)

**或许是**“**人挪活**”**的期望在刺激着埃兰加的爆发**，**他在上赛季第**30**轮对阵曼联时上演了惊艳的一条龙破门**（**触球**7**次**，9**秒****冲刺**85**米**，**连过**3**人**）。**虽然没有庆祝**，**但弑杀旧主以及荣膺全场最佳球员之际**，**埃兰加的发言似乎无意中在曼联的伤口里撒盐了**：“**我在曼联的时光收获了许多宝贵经验**。”**看热闹不嫌多的吃瓜群众则趁机调侃了一番曼联**：“**你们卖掉的不是边锋**，**是辆超跑**！”**后知后觉有时候也是一种痛**。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBQpnzvPJMpZSZE38GLXZibaYO2tk9cYlYR5o5ymwZetbC23iaDtgaiaM9gRmvjV9FkE25f4V8vJEYvXw/640?wx_fmt=jpeg&from=appmsg)

**埃兰加并不隐藏自己对曼联的爱**，**只是没有一个年轻人愿意在板凳席上蹉跎岁月**，**要知道他在曼联的最后一个赛季累计才亮相了**421**分钟**，1500**万英镑的转会费创造了当时曼联**U21**球员出售纪录**，**或许这是意外之喜**，**然而用时间审视的话**，**曼联的这笔买卖容易被人诟病**，**虽然不至于达到**“**拿了金钱输了未来**”**的地步**，**但在诺丁汉森林持续发光两个赛季的埃兰加确实在一定程度上打了曼联的脸**，**球迷有印象的话**，**时任曼联主帅滕哈格还曾让瑞典人客串过右后卫**。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBQpnzvPJMpZSZE38GLXZibaY7zWBicjkeNZgaRic1EFicOmiatlzbue1LDaDE9mC5Ml0AHNMmicRjsfbtew/640?wx_fmt=jpeg&from=appmsg)

**此一时彼一时**，**在曼联没有出头之日**，**在诺丁汉森林光芒四射**，**埃兰加制造了惊艳的**“**人挪活**”**效应**，**而且不止一次将**“**享受足球**”**和**“**努力进步**”**作为感谢语**。**这是诺丁汉森林的幸运**，**也是曼联的伤疤**，**事实上在回顾曼联生涯时**，**峥嵘岁月犹如零星一般**，2020**年获得吉米**·**墨菲**U18**年度最佳青年球员奖**，2022**年对阵马竞时打进了曼联队史欧冠第**500**球**，2023**年的夏天就被迫和曼联分手了**。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBQpnzvPJMpZSZE38GLXZibaYr03xrz4fRI7RbpTWGSO7GicPyfUIV3u4nass7e7YtXXVCYBG8qgnHQg/640?wx_fmt=jpeg&from=appmsg)

12**岁加入曼联**，21**岁离开曼联**，9**年时间一晃而过**，**但显然不是一句**“**爱过**”**就能轻松代替埃兰加的悲喜**，**只不过埃兰加尽量地用快乐情绪去总结过去的时光**，**比如他说过**：“**我从**C**罗身上学到的东西真是太棒了**，**他射门的方式和他的跑动都非常出色**。”

****

**事实上**，**追着光跑的瑞典球星开始以自己的方式发光了**，**在诺丁汉森林当大腿以及**5500**万镑转会纽卡斯尔都是天赋的兑现**，**不知道球迷是否记得提拔埃兰加进曼联一线队的索尔斯克亚的话**：”**他有速度**，**这是边锋所拥有的东西**，**他有我喜欢的品质**，**他很自信**，**他的左右脚很均衡**。”


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBQpnzvPJMpZSZE38GLXZibaY7WeVt5icQlPc3f9bciaF60GA4bcZ0ib4YkC5TUWGj617GQ69E7YKOGeGA/640?wx_fmt=jpeg&from=appmsg)

**曼联还在重复地寻找新的意中人**，**而自己培养的边路快马则要开启新旅程了**，**如果有聊以自慰的事情**，**那就是曼联得到了二次分成**（**大约**800**万英镑**）。**新赛季的埃兰加将与瑞典同胞伊萨克并肩作战**，**加上****左****路的戈登**，**在新三叉戟的加持下**，**纽卡斯尔未必能做到**“**喜鹊变凤凰**”，**但也许球迷好奇的是**，**埃兰加在与曼联重逢时又会制造怎样的视觉盛宴**？
