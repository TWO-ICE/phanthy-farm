# 大逆转！欧战全满贯！

阿布德的进球让皇家贝蒂斯看到欧战问鼎的曙光，但切尔西强大的团队实力让这一美好愿景化为泡影。随着恩佐、雅克松、桑乔和凯塞多在半个小时内连下四城，蓝军在欧协联决赛实现4比1的逆转。经此一役，切尔西成为欧战历史上第一支全满贯球队，在经过数年低谷之后，伦敦豪门终于守得云开见月明。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBSiaxHRoqVdWJOoyicGN67RFibh1RUucD3gBicOmqe4LhOmqpI8Nk1OibUMbmkdTEQ6XZ3zPhjxPr9b6SA/640?wx_fmt=jpeg&from=appmsg)

切尔西能够在本赛季的欧协联夺冠，其实一点也不让人意外，看看这项三级欧战的参赛球队，只有佛罗伦萨和皇家贝蒂斯少数几支球队能够造成威胁。就纸面实力而言，蓝军在欧协联可以说是断层领跑，联赛阶段六战全胜轻松锁定第一，淘汰赛也是一路砍瓜切菜，直指最终的冠军。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBSiaxHRoqVdWJOoyicGN67RFibu66tXnSbsu24RSa3Ww34HCwvGichFOdRwxtVwapMTPqzjib62scqxInw/640?wx_fmt=jpeg&from=appmsg)

不过，决赛舞台站在切尔西对面的贝蒂斯绝非软柿子，虽然这支西甲劲旅联赛阶段只排名第15，但在安东尼夏窗租借加盟之后，他们就像乘上火箭一样快速上升，一路过关斩将。尤其是半决赛淘汰意甲劲旅佛罗伦萨，安东尼和贝蒂斯发挥得都是相当精彩，曼联弃将一度被誉为“真核球王”，也让外界对他们掀翻切尔西逆袭夺冠多了一份期待。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBSiaxHRoqVdWJOoyicGN67RFib9Ypegxg26yPib0S0ZUicbl21exAlh2A1yU5xLG1PqxLk2vf8hIXGQLfA/640?wx_fmt=jpeg&from=appmsg)

在这个决赛之夜，贝蒂斯确实一度让人眼前一亮，开场仅仅9分钟，阿布德就在禁区内低射破门，为西甲劲旅取得领先。之后贝蒂斯士气大振，巴尔特拉的远射、卡多索禁区中路的抽射和阿布德精彩的突破都颇具威胁。相比之下，切尔西似乎迟迟无法进入状态，整个上半场都没有多少作为，防线风声鹤唳还成为常态。


![图片](https://mmbiz.qpic.cn/mmbiz_gif/sAmI87QVQBSiaxHRoqVdWJOoyicGN67RFibCRh27ftXviaJaXia5lPXdsIEr4BnJ5lexx58AQSL3Dq2W4Oy5E5mbB7A/640?wx_fmt=gif&from=appmsg)

易边再战，场上的局势没有多少转变，阿布德因伤被替换下场，似乎成了比赛一个小小的转折点。随着时间推移，切尔西终于逐渐把控了场上的局势，也打出了惊涛骇浪般的进球狂潮——第65分钟，帕尔默传中助攻恩佐头球破门；第70分钟，帕尔默助攻梅开二度，雅克松胸部撞击建功。


![图片](https://mmbiz.qpic.cn/mmbiz_gif/sAmI87QVQBSiaxHRoqVdWJOoyicGN67RFibltial5rafJYs0mo3tQBU1g5PAcvibB9dUvkhYTboM7ibyxTlAsDicSK2icQ/640?wx_fmt=gif&from=appmsg)


![图片](https://mmbiz.qpic.cn/mmbiz_gif/sAmI87QVQBSiaxHRoqVdWJOoyicGN67RFibVbn9AWWvyHBbYTUJyJvWn0t5Ba0stQhMIQEcUMUTAibzBQ1ZwQYm1zA/640?wx_fmt=gif&from=appmsg)

短短五分钟内，切尔西就完成了比分上的逆转，双方的气势也完全颠倒，雅克松甚至松弛到踢起了快乐足球，单刀机会直接趟大送给门将。即便如此，蓝军还是等来了杀死比赛的瞬间——第83分钟，桑乔禁区内兜射远角破门，将比分变成3比1。而在最后时刻，凯塞多禁区外远射一锤定音，为这场近乎完美的逆转划上句号。


![图片](https://mmbiz.qpic.cn/mmbiz_gif/sAmI87QVQBSiaxHRoqVdWJOoyicGN67RFibJH9Pr8vLtsCPBJe78GEHVXy3Q6O3Fvk9pZx8IR9jd4QMAHJ5sBNSwg/640?wx_fmt=gif&from=appmsg)


![图片](https://mmbiz.qpic.cn/mmbiz_gif/sAmI87QVQBSiaxHRoqVdWJOoyicGN67RFibFjmYq8yGGnN7Bxbjw24iaLzHIVriaicK6vyWvo78cTSsnKkgJkSiar6VGA/640?wx_fmt=gif&from=appmsg)

记分牌定格在4比1，安东尼痛失欧协联冠军，切尔西则创造了历史。蓝军成为历史上首支集齐欧冠冠军、欧联杯冠军、欧协联冠军和优胜者杯冠军的球队。自利物浦2001年在联盟杯决赛击败阿拉维斯之后，这是英格兰球队首次在重要欧战决赛击败西班牙球队，此前英超球队对阵西甲球队已经遭遇9连败。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBSiaxHRoqVdWJOoyicGN67RFibjevtO9ITwUGHrQLicq6gFU8BuGbmNzbQTqYHkIumWJsED6kvIvORqbg/640?wx_fmt=jpeg&from=appmsg)

此外，西班牙球队欧战决赛外战19连胜遭终结，西甲代表上一次在欧战决赛输给非西班牙球队还是2001年欧冠决赛，当时瓦伦西亚点球大战不敌拜仁。不得不说，切尔西在欧战决赛的舞台上只能用一个稳字来形容，不算欧洲超级杯，蓝军队史主要欧战决赛外战5场全胜，他们夺得7座主要欧战冠军，英格兰球队仅次于利物浦。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBSiaxHRoqVdWJOoyicGN67RFibT5bj9jgicBmIiad40FebLLrTl3odZDN57bFLa9dqTia4ic05LGqQqlESwA/640?wx_fmt=jpeg&from=appmsg)

赛后，切尔西夺冠功臣帕尔默说道：“欧协联是我们迈出的重要一步。正如主教练所说，我们参加这个赛事是因为上赛季的表现。现在我们进入了欧冠，接下来要继续向前。我认为我们正走在正确的道路上。”确实，本赛季切尔西不仅拿下伯利时代后的首个冠军，联赛也以第四的成绩重返欧冠，在经历一系列低谷之后，蓝军终于走上了正轨。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBSiaxHRoqVdWJOoyicGN67RFibEVLnUQwDvX1wPYWlhv01qQ5RO8EUWZquPGCafWia8Dib5x63jG1YQRjg/640?wx_fmt=jpeg&from=appmsg)

随着切尔西勇夺欧协联冠军，本赛季英超球队参与的所有赛事都落下帷幕，利物浦夺得英超冠军，水晶宫夺得足总杯冠军，纽卡夺得联赛杯冠军，热刺夺得欧联杯冠军，切尔西则夺得了欧会杯冠军。5支不同的英超球队夺得重要赛事冠军，这是历史首次出现如此局面。下赛季将有6支英超球队参加欧冠，英超一统江湖的时代，要正式降临了吗？
