# 拒绝曼联，高估自己了！

登贝莱在巴黎实现了“人挪活”，在伪九位置上频繁制造惊喜的巴黎大腿成为了金球奖最大热门。一家欢乐几家愁，贡萨洛·拉莫斯平均每91分钟收获1粒进球，然而在24-25赛季累计才出亮相了1630分钟。另一个中锋穆阿尼在巴黎更加感受不到浪漫，他在24-25赛季的法甲只亮相了10次，其中8次担任替补，最终在冬歇期被租借到了尤文图斯，值得一提的是，巴黎捧起欧冠冠军，他与同是外租离队的什克里尼亚尔、阿森西奥均没有资格领到冠军奖牌。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBTOZnsIK9fMibiciaZ6tWCFia5CdYCicCUnJqnsaqmHkBRvMSB8Jmub143m7GecltlDuib3ib4h59WGQeg0Q/640?wx_fmt=jpeg&from=appmsg)

穆阿尼曾是大巴黎的误以为的天选之子，不然不会在2023年的夏天花费9500万欧元签下他，法甲首秀送出助攻，欧冠对阵AC米兰斩获进球，看似开了个好头的法国国脚却没有持续性匹配期望值，加盟巴黎的第一个赛季累计只在40场比赛中贡献了9粒进球和6次助攻。


尽管主帅恩里克避重就轻：“穆阿尼对待比赛的态度是非常完美的”，但实际上穆阿尼水货的名声已经远近皆知。巴黎球迷在比赛间歇公开嫌弃自家前锋：“你该走了”，而《巴黎人报》同样没有留面子：“当初的高价引援如今变成了巴黎的负担。”


![图片](https://mmbiz.qpic.cn/mmbiz_png/sAmI87QVQBTOZnsIK9fMibiciaZ6tWCFia5C1onlKsESDrKsM1NNkEBiawLvGsP3uBnP1qIra6lFib2Ria0icbcu1It5XQ/640?wx_fmt=png&from=appmsg)

前往尤文图斯在某种程度上是一种幸运，用穆阿尼的话说：“就像做了一场梦”。初来乍到的法国人确实展示了来之即战的能力，前三场意甲打进了5粒进球，事实上在对阵那不勒斯、拉齐奥和国际米兰时，穆阿尼均用进球和助攻重新诠释自己的价值。


坦白讲，22次出场贡献10粒进球和3次助攻的数据不足以让尤文拍大腿，时任主帅莫塔却感觉得到了一场及时雨，顺便拔高了穆阿尼的形象：“现代足球需要全能型前锋，从高位压迫到持球组织都是必修课。”而继任的图多尔同样表达了欣赏：“他不仅身体对抗出色，更展现出对战术的深刻理解。”


![图片](https://mmbiz.qpic.cn/mmbiz_png/sAmI87QVQBTOZnsIK9fMibiciaZ6tWCFia5ChHXVEhCgknr1qnM3Ebsibtdl9Kv4T561AMe9SEKOKZtpJia29WpKGtvA/640?wx_fmt=png&from=appmsg)

两种评价，一种态度，尤文图斯试图和穆阿尼延续合作的意图很明显，并且已经在布局——今夏引进的乔纳森·戴维在风格上与其形成互补（一个喜欢纵深冲击，一个擅长门前终结）。值得一提的是，尤文图斯历史上出现过普拉蒂尼、齐达内和特雷泽盖等法国籍大牌，虽然穆阿尼的地位不可同日而语，但沿着前辈的路走下去是额外的动力，并且特雷泽盖在接受采访时为他打call过。最为重要的是，穆阿尼提前将都灵城视为了自己的避风港：“我在尤文图斯过得很开心，希望能继续留在那里，他们对我非常欢迎，我很享受在那里踢球。”


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBTOZnsIK9fMibiciaZ6tWCFia5Cib716GuZ6MzDbJJrjPA51iaibokMBbeecorDxRsgfRic2vwUQECFxia5ZvA/640?wx_fmt=jpeg&from=appmsg)

在努力实现双向奔赴的过程中，尤文高层频繁现身巴黎，而穆阿尼对曼联伸出的橄榄枝并无兴趣。看似这是一个理想化的阶段，然而并非皆大欢喜，甚至在一定程度上形成了对立面。巴黎咬定4000-5000万欧元的转会费不松口，试图最大化止损，而尤文图斯试图用1000万欧元的租借费说服巴黎暂时放人，并简化了强制买断条款的触发条件。处于煎熬中的法国国脚不清楚何以为家，据身边好友反应心情十分沮丧，然而巴黎俨然一副“姜太公钓鱼”的模式，事实上，纽卡斯尔和热刺就趁机坐上了谈判桌。


![图片](https://mmbiz.qpic.cn/mmbiz_png/sAmI87QVQBTOZnsIK9fMibiciaZ6tWCFia5CILibia0OvLDO2lxmPPSUoZk7dKBvC2bXZEVYdMKdHUjvp18jE0SCkQkw/640?wx_fmt=png&from=appmsg)

尤文“慢一拍”并不是偶然事件，穆阿尼在巴黎的月薪大概税前75万欧元，本身就差钱的“老妇人”自然会有心理负担，况且拿着意甲最高薪水的弗拉霍维奇一直未能被送走，换而言之，“花小钱办大事”符合自身的条件。


另一方面，在尤文短暂回暖的穆阿尼当前的身价只有3000万欧元，准确说法国人在短短两年时间内身价暴跌了5000万欧元，尤文图斯提出的续租协议某种程度上属于自我保护的范畴，换而言之，谨慎一点也是好事。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBTOZnsIK9fMibiciaZ6tWCFia5CMmqQT5CicUchgF1jd8nGI8ZRcws8Tib68teWqciccxmzTVt4CU9LR1mvQ/640?wx_fmt=jpeg&from=appmsg)

也许致力于重建工作的尤文有勇气满足大巴黎的胃口，但最怕转正的穆阿尼突然“开倒车”。法国名宿德塞利就点评过，身材上人高马大的晚辈在进攻时缺乏果断！有迹可循，卡塔尔世界杯上决赛中的单刀球被大马丁扑出，后者称之为“一生最难忘的扑救”，世俱杯对阵皇马时开场不久即浪费单刀机会，球迷调侃“还是熟悉的味道”，再延伸软脚虾的例子，就是租借尤文后的穆阿尼高开低走，一度遭遇了连续11场的进球荒。


![图片](https://mmbiz.qpic.cn/mmbiz_gif/sAmI87QVQBTOZnsIK9fMibiciaZ6tWCFia5Cq8tGvaq2JmzXCLjmYiaWJYib6tibC06xkXaX37pnVgKgbW5o7hGPuxshg/640?wx_fmt=gif&from=appmsg)

这时候球迷就会针对性地讨论穆阿尼的充满变数的职业生涯。在南特，19岁踢法甲不是新鲜事，21岁时还前往法国法丙练级，23岁时在41场比赛中贡献了13粒进球和7次助攻。在法兰克福虽然只是一年游，46场23粒进球和17次助攻的成绩单堪称豪华，最令人惊讶的是，穆阿尼在德甲的进球为“黑鹰”赢下了19个积分，身价高达8000万是个人价值的直接体现，考虑到自由身而来，“真香”的感慨来自四面八方。


![图片](https://mmbiz.qpic.cn/mmbiz_png/sAmI87QVQBTOZnsIK9fMibiciaZ6tWCFia5Chg6YDskS6QMA5pMHPBt6oOTxktmpblVg9ibnwyb9KlhQLSfahbDzPAA/640?wx_fmt=png&from=appmsg)

在巴黎的穆阿尼似乎一入豪门深似海，比枯坐板凳更惨的是曾连续无缘大名单，虽然曾以“技术原因”体面地缓解焦虑，然而在巴黎彻底看不到未来时，他说出了内心的烦恼：“转会费对我个人来说，这很难消化，这对我来说是另一种压力。”


值得一提的是，在被租借打破尤文之前，外界曾鼓励穆阿尼重返德甲进行“回炉深造”，只是法兰克福并不认为自己会第二次捡便宜，或许法国国脚的下坡路已经被提前预料到了，结合穆阿尼的意甲时光，尤文图斯的谨慎是合理的。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBTOZnsIK9fMibiciaZ6tWCFia5CqRKibDQXjyI563R44X8VgfY1Kt9CQxOVgzUdNrVwH7T8hicZOXiaR6mfg/640?wx_fmt=jpeg&from=appmsg)

“批评有助于进步，这像建议一样，都是好的。我必须正视它们，努力改进。”但愿，穆阿尼的自省会被聆听，会被验证。
