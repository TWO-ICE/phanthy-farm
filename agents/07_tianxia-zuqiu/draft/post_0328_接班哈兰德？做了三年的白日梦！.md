# 接班哈兰德？做了三年的白日梦！

习惯低买高卖的多特蒙德近几年走了冤枉路，自家青训穆科科拿了高薪出不了力，更是因为年龄造假缔造了一系列的虚假繁荣，而2022年夏天斥资3000万欧元买进的德国跑车阿德耶米也与期望值背道而驰了。在过去的三个德甲赛季中，阿德耶米单赛季的联赛进球数从未上双过，即使在上赛季各项赛事贡献了12粒进球和9次助攻，但与最初幻想的“后浪效应”相去甚远。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBRPx1WCJIuE8OrXRxVgKHaUS5Ycxjc0ictvgeJlrqwKMYzQn3qZYpwIBmXp1ibpxonBAtw6KFvFibAhQ/640?wx_fmt=jpeg&from=appmsg)

在加盟多特蒙德的第二个赛季，阿德耶米就频繁卷入了转会市场中，这或多或少反映了其成长速度慢的事实，纵然吸引了阿森纳、切尔西、纽卡斯尔和尤文图斯的兴趣，但潜在买家均是用欠缺稳定的理由主动掐断了绯闻。换而言之，即使阿德耶米具备了“00后”的年龄优势以及时速36.65公里/小时的视觉享受，既不足以晋升为多特蒙德的标准答案，也不足以支撑其挪窝儿！


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBRPx1WCJIuE8OrXRxVgKHaUaicIX2uHUibEf1zTa1VxsmH2zrF0iaA5ZREhJk6ZOngsNwH55icZbR8ickw/640?wx_fmt=jpeg&from=appmsg)

进退两难无异于陷入挣扎。要知道阿德耶米是在哈兰德确定离开的当天与多特蒙德签下了5年长约，名义上他被视为北欧神锋的接班人，可三年磨一剑的剧本没有如约而至时，丢失光环的阿德耶米容易站在风口浪尖上，甚至有人提前断定他在多特蒙德只能是一个过客。


德国媒体一度认为血气方刚的年轻人被爱情一时冲昏了头，并导致个人在足球领域走下坡路。阿德耶米则认为自己被媒体针对了，他的原话是“有些人莫名其妙地就评价一些他们并不认识的人”。坦白讲，他确实做错了一些事情，比如在2023年11月就因为拒绝德国U21的征召遭遇了名宿和足协批评。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBRPx1WCJIuE8OrXRxVgKHaUpmDiaicwpPgjsvibTtMmWsSlxiaicaHaKQKGAqHXm6wD7a4kiakpWxAghDaw/640?wx_fmt=jpeg&from=appmsg)

人往高处走时，阿德耶米的辩解毋庸置疑会得到了大众的理解，但不能及时地用天赋为“大黄蜂”保驾护航时，3000万欧元的转会费和500万欧元的年薪都变成了因爱生恨的素材，媒体甚至会抓住阿德耶米在拜仁青训营当问题少年的旧时光大做文章。


坦白讲，从得之我幸到分道扬镳的态度转变并不奇怪，试想下，当初多特蒙德曾优先给予穆科科一份年薪高达850万欧元的肥约，甚至在一定程度上压缩了罗伊斯终老于此的愿望，然而昔日的德国神童从被租借到被清洗只用了一个短短赛季的时间。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBRPx1WCJIuE8OrXRxVgKHaUXQicHKue0yD4ssWlOuGgP0ic6WYazzbE8pAFuaDW0KGoOTd3d5WhhOqQ/640?wx_fmt=jpeg&from=appmsg)

“爱情来得太快就像龙卷风”，这是歌词传达的情感善变，却也符合竞技世界“捧得高，摔得惨”的残酷。阿德耶米不止一次让多特蒙德怀疑过自己引以为傲的“鹰眼”。2024年德甲对阵斯图加特时，他浪费了一次单刀球，2024年欧冠决赛对阵皇马时，过掉库尔图瓦的他却没有能将皮球送进网窝。而在2025年对阵法国的欧国联半决赛中，假摔吃牌的阿德耶米又成为了另类的主角。重复犯错时，被质疑、被嘲讽、被惩罚，均是自食其果的结果。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBRPx1WCJIuE8OrXRxVgKHaUINTia7aXiaPQ1OGhh7gOfSbqWI4NEft1R3FOOxadfXx6wqc2xNGVFtpg/640?wx_fmt=jpeg&from=appmsg)

“就算浪费了3次机会，或者射失了点球，他还会继续下去，直到成功破门为止。”加盟多特时，曾陪伴过阿德耶米成长的青训教练点出了阿德耶米的韧劲，但屡屡挥霍机会时，“所谓的下一次”就变成了奢侈品，多特蒙德在2024年夏天引进吉拉西在一定程度上就是填窟窿。


事实上，在并肩作战的一个赛季里，吉拉西分别共享了德甲银靴奖和欧冠金靴的荣誉，而刷新多特蒙德生涯个人进球纪录的阿德耶米并没有避开舆论的对比与批评，尤其是后撤回防的次数太少了，且经常在丢失球权后“思考人生”。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBRPx1WCJIuE8OrXRxVgKHaU8C5wxxviacjgA66o0tZryT7AVKwOhiac9x0ibswTLLFWicQooEbwB5TUsg/640?wx_fmt=jpeg&from=appmsg)

多特蒙德及时止损的念头并不强烈，但不介意在转会市场上试试水，事实证明外界对5000万欧的标价并不吸引人，阿德耶米懂得知耻后勇，他在世俱杯上曾连续为吉拉西做嫁衣，后者也送过温暖：“他就是我的弟弟！”，而最近他又开始打起了感情牌：“我一直都说我热爱这个俱乐部。从小我就已经是这个俱乐部的球迷，我的家人也是。”


实事求是地讲，阿德耶米在与多特蒙德签订合同之前，他一度与巴萨走得很近，只是择其所爱后没有野蛮生长后，这些外在的保护和自我表达都会打折扣。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBRPx1WCJIuE8OrXRxVgKHaUCCZRFtQ03nWFia0jAxuz75qMqskuZaZicianK8icGVqqhSQmj56YUTYEOg/640?wx_fmt=jpeg&from=appmsg)

多特蒙德没有当断则断的勇气，况且阿德耶米并非持续狼狈。忆往昔，21-22赛季萨尔茨堡红牛与塞维利亚的欧冠小组赛中，他成为历史上首位单场欧冠上半场三次造点的球员。22-23赛季欧冠1/8决赛首回合多特蒙德对阵切尔西，他演绎了70米的一条龙破门。念当下，在科瓦奇麾下的阿德耶米有回暖的迹象，主帅也曾给他释放压力：“阿德耶米是一名顶级球员，我对他的期望是更多的冲刺跑动，因为他速度太快了，世界上没有多少球员能像他一样快。”


有意思的是，陷入转会绯闻的阿德耶米很有求生欲，他在记者面前反馈了自己的热情：“不知怎么的，在科瓦奇执教多特后，我感觉自己状态变好了。”


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBRPx1WCJIuE8OrXRxVgKHaUMyIicYXpvqlia1DYI5Q8wuUkAOaW9jYskibWuXnTtTUv7ticS7UQVVCOJQ/640?wx_fmt=jpeg&from=appmsg)

伊杜纳信号公园的天才来来往往，哈兰德和贝林厄姆顺势完成了豪门之约，穆科科则变成了一颗流星，处于缓冲区的阿德耶米并没有让多特蒙德彻底嫌弃，他有自救的空间，也有与时间赛跑的紧迫感，一旦新赛季重复犯老毛病，分手或许真的是迟到但体面的结局！
