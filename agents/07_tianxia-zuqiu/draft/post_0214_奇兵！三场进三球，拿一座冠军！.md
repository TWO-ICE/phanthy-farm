# 奇兵！三场进三球，拿一座冠军！

**

**重返罗萨里奥中央的迪马利亚用**1**粒进球诠释了回家的意义**，**但在这个夏天不止一名新援扮演了及时雨**。**若昂**·**佩德罗**，**在加盟切尔西的第**11**天就跟随新东家举起了世俱杯冠军**，**准确说**，**巴西前锋用**6**次射门**4**次射正打进**3**球****的超高效率证明了切尔西的选人眼光**，**也让**6370**万欧元的转会费得到了物有所值的评价**。**贝尔的点评相当客观**：“**不仅仅是佩德罗的进球**，**与队友的连线**、**传球和视野**，**要知道即使只是加入一支新球队**，**试图了解你的队友已经是一件困难的事情**。”


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBSNtJtkNdguQ1qcHj37A4AQWq0rNygia3tAImjTicpbf5TNNc68okZHO259iaica7NHXEs0VkIdE69e1Q/640?wx_fmt=jpeg&from=appmsg)

**在官宣佩德罗登陆斯坦福桥之际**，ESPN**对这笔交易进行了评分**，**布莱顿拿到了**B+，**而切尔西拿到了**B-，**甚至有球迷调侃蓝军习惯性从**“**对口单位进货**”，**在此之前**，**切尔西阵中的库库雷利亚**、**凯塞多**、**罗伯特**·**桑切斯均是布莱顿出品**。****

**事实上佩德罗并不是泛泛之辈**，**在为海鸥军团出场的**70**场比赛中贡献了**30**粒进球和**10**次助攻**，**纽卡斯尔在签下伊萨克之前**，**原来最先招募的对象就是佩德罗**，**时过境迁**，**纽卡斯尔没有看走眼**，**但也一定程度上成全了后知后觉的切尔西**。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBSNtJtkNdguQ1qcHj37A4AQBotYXO09sDP5fdTuP43ZibC1I1wZIFE0dHuNvDGdpGiacrbZVrgB7wcQ/640?wx_fmt=jpeg&from=appmsg)

**佩德罗堪称是前场万金油**，**能胜任中锋**、**二前锋**、**前腰和边锋**，**既擅长组织进攻**，**也习惯回撤拿球**，**英国媒体曾将其褒奖为**“**新时代全能前锋的代表**”。**只不过球迷考量前锋价值的标准始终绕不开进球**，**在这一点上巴西前锋有自己的生存之道**。

****

**在效力布莱顿的两个赛季内**，**曼联**、**切尔西**、**热刺**、**阿森纳**、**曼城**，**均成为巴西人的**“**刀下鬼**”，**突出了个人打硬仗的魄力**，**值得一提的是**，**佩德罗职业****生涯****中**19**次主罚点球只丢失了一次**，**强化了**“**大心脏**”**的印象分**。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBSNtJtkNdguQ1qcHj37A4AQZjuxRicral8GGWtptrhnACqA7ezujqXeIFjPv7aGHMXRO8AOXlRvVyQ/640?wx_fmt=jpeg&from=appmsg)

**抛开**6370**万欧元的转会费**，**切尔西求贤若渴的决心也反映在一口气与佩德罗签订了**8**年长约**，**这是一种安全感**，**似乎也是一种补救**，**同是今年夏天登陆斯坦福桥的德拉普虽然首秀献助攻**，**速度优势和无球跑动意识得到了广泛赞誉**，**但随之进入了低谷**。

****

**世俱杯对阵弗拉门戈**，**早早被替换下场**，**拿到了全场最低分**，**对阵本菲卡更加惨不忍睹**，6**项个人数据挂**0，12**次丢失球权的数据辣眼睛**，**以至于球迷调侃**“**突然想念杰克逊了**。”**事实上原来的励志少年杰克逊在世俱杯上的成绩单更拿不出手**——0**进球**、1**次助攻和**1**张红牌**。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBSNtJtkNdguQ1qcHj37A4AQF0icfDvw2v7oVDfD4VJ5VAibPaqibXoia94wFxznUKJsOvFFKOKl90h3ug/640?wx_fmt=jpeg&from=appmsg)

**与之相比**，**中途感受世俱杯氛围的佩德罗堪称神兵天降**，**半决赛对阵弗鲁米嫩塞**，2**次射正打进**2**球之余**，**他还填满了抢断**、**拦截**、**解围**、**对抗**、**争顶的数据栏**，**顺利拿下了全场最佳球员**，**对阵巴黎进球之余**，**也贡献了**1**次关键传球**，**荣膺世俱杯**MVP**的帕尔默在与佩德罗第一次合作时就感慨过新队友即插即用的能力**：“**他改变了比赛局面**，**佩德罗之前一直在度假**，**球队本来不确定他对比赛的准备情况如何**。”


![图片](https://mmbiz.qpic.cn/mmbiz_gif/sAmI87QVQBRzEMamubTIGCFJPKEhSeOgT7DjF2UFUicYx9YwicHZornqVVOUl9lCMVR7K1C8Rq71YHJQXvqMdcBA/640?wx_fmt=gif&from=appmsg)

**切尔西主帅马雷斯卡试图一碗水端平**：“**就我个人而言**，**我更喜欢所有五名球员各打进**10**到**12**球**，**而不是让一名前锋打进**40**球**。”**充当奇兵的佩德罗似乎很容易被赋予更高的期望值**，**借助完成豪门之约和捧起世俱杯的劲儿**，**巴西人坦诚**：“**和优秀的球员并肩作战自然会进步**”，**但他并没有把话说满**，**甚至解读了成功学**：“**没有捷径**，**只有苦练**，**这才能给我自信与镇定**。”


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBSNtJtkNdguQ1qcHj37A4AQNZT2gEKuhMZFFKYXU8LYlQbY14GFJOEhUdc9AmSbgZj8suXGHzSEiag/640?wx_fmt=jpeg)

24**岁嫁入豪门一点都不晚**，**只是佩德罗一直在治愈童年**。**当佩德罗还是一个婴儿时**，**父亲就因为谋杀罪蹲了大牢**，**母亲为了成全儿佩德罗的足球梦想**，**将家从圣保罗搬到里约热内卢**。**虽然弗鲁米嫩塞接纳了少年的梦**，**但佩德罗母子只能与其他人合租在一间小房子内**，**母亲甚至会忍饥挨饿**，**以便佩德罗能有个饱肚子去参加训练**。

****

**在巴西**，**贫穷是司空见惯的事情**，**其实这何尝不是最好的**“**足球养分**”**之一**，**总有源源不断的少年试图通过足球改变命运和回馈家人**，“**我的母亲对我来说一直非常重要**。**如果不是她从一开始就陪在我身边**，**我想我不可能走到今天**。”**事实上在佩德罗拿到职业生涯第一个冠军后**，**他就第一时间在电话里与母亲分享喜悦**。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBSNtJtkNdguQ1qcHj37A4AQZuxOXzYJudyENyKnSKHyRhd9utv6zBynwuXB7RibPUZKPK8WoKibFpKg/640?wx_fmt=jpeg&from=appmsg)

**凡是来之不易的东西都值得珍惜**，**从巴西到英格兰**，**从英冠到英超**，**在沃特福德拿过英冠的评分王和过人王**，**在布莱顿曾连续**7**轮英超收获进球或助攻**。**或许佩德罗的切尔西生涯未必一直光彩夺目**，**但开了一个好头的巴西前锋没有必要在追逐冠军的征途里浅尝辄止**，**别忘了**，**他在巴西度假期间依然保持着高强度的训练**，“**没有伞的孩子必须努力奔跑**”，**冠军是天道酬勤的成果**，**也是明天更美好的催化剂**！


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBSNtJtkNdguQ1qcHj37A4AQYsQfyw470l9icX8nibXW6PWN5wjA2gWEsIiaCUmgpY4OUzSGodBnVHibQw/640?wx_fmt=jpeg&from=appmsg)

**实事求是讲**，**遭遇童年创伤的佩德罗内心里也住着一头野兽**，**他有时候会成为情绪的奴隶**，**比如他曾肘击布伦特福德球员吃红牌**，**也曾因纪律问题遭遇内部禁赛**，**在世俱杯战胜巴黎后也和恩里克之间产生了摩擦**。**一旦在切尔西遭遇进球荒或者被舆论包围时**，**妥善地与自己和解似乎是一个新的考验**。

****

**踢三场球**，**进三个球**，**拿一座冠军**，**佩德罗有释放快乐的权利和享受掌声的空间**，**但**“**来日方长**”**的话题依然具备了挑战性和话题性**！
