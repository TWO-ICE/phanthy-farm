# 疯了！拒绝50万镑周薪！续约曼联？

B费在今年夏天拒绝了沙特豪门的橄榄枝**，**然而他并不是**“**孤军奋战**”，**马奎尔在最近就对利雅得胜利提供的**50**万镑周薪的肥约不为所动**。**从年龄上说**，32**岁的马奎尔坚信自己在英超联赛中有大把剩余价值**，**淘金并不在自己的计划内。****从情怀上说**，**加盟曼联**6**年的英格兰人有共进退的斗志**。**球迷有印象的话**，**他在**1**月份得到曼联的延长合同时就说过**：“**这是艰难的一年**，**作为球员**，**我们要承担责任**。”


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBTAJZVNTv6LiaAgj075EI8RqJSZEHFhFk46PTfcL8yXvNX2kBR04czRcL2LZyDtWdqWMbOkeicRy4qQ/640?wx_fmt=jpeg&from=appmsg)

**新赛季的曼联并没有如梦初醒**，**相对于锋无力的窘境**，**后防线遭遇的**“**舆论炮火**”**并不猛烈**，**甚至马奎尔时不时地扮演了遮羞布**。**比如在曼联被格林斯比爆冷的联赛杯中**，**马奎尔做到了攻守平衡**，**进攻端贡献了**1**粒进球和**2**次关键传球**，**也在点球大战中不辱使命**，**防守端贡献了**6**次成功对抗和**8**次解围**。**英超对阵切尔西时**，**他贡献了**1**次关键传球和**1**次助攻**，**英超输给布伦特福德时**，**他**6**次争夺顶成功**4**次**，5**次解围更是全场最高**，**只不过**7**次丢失球权成为媒体总结输球原因的**“**突破口**”。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBTAJZVNTv6LiaAgj075EI8Rqpic2ngPUrT4gvgXjEb4Wex5X1Cua3dQW4P57Tv9PmcHBDxBsVragN1g/640?wx_fmt=jpeg&from=appmsg)

**马奎尔并不是一个完美主义者**，**迟钝的反应和缓慢的转身是外界放大的缺陷**，**更是因为**8000**万镑的转会费和户口本的加持屡次站在风口浪尖上**。**球迷调侃他的**“**动作像慢镜头回放**”，**名宿炮轰他是**“**曼联的耻辱**”，2023**年联赛杯决赛第**88**分钟替补出场**、**足总杯决赛枯坐板凳**、**遭遇球迷嘘声**、**失去队长袖标**，**似乎都是符合心理预期的一系列惩罚形式**，**事实上马奎尔在滕哈格麾下一度沦为了第五中卫**。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBTAJZVNTv6LiaAgj075EI8RqGFdLLf94ah1cpyZicLXxU8T8PxyEpewb3boRdM2icPZ3dSNez3fY4cOQ/640?wx_fmt=jpeg&from=appmsg)

**在**23-24**赛季开打之前**，**马奎尔差一点加盟西汉姆联**，**只是后者最终并不愿意用**3000**万镑的转会费招募一个曼联失意人**。**本以为留守曼联是被深渊重新凝视**，**意外的是英格兰大块头开始知耻后勇了**。

****

23-24**赛季的马奎尔总出场时间只有**2310**分钟**，**却贡献了**4**粒进球和**2**次助攻**，**拿到过足总杯冠军**，**荣膺过英超月度最佳球员**，**值得一提的是**，**上一个做到的曼联后卫还要追溯到**2009**年的维迪奇**。**即便马奎尔并没有彻底斩断分道扬镳的绯闻**，**收敛的批评声也变相成为了一种肯定**，**至少偶尔发泄情绪的英格兰人给外界设置了缓冲地带**。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBTAJZVNTv6LiaAgj075EI8Rq5xk1RyIrnXkwndtkLiclpGGicAmWZD0L6YONCACVL64y0A9NPiag1fd7g/640?wx_fmt=jpeg&from=appmsg)

24-25**赛季的马奎尔被伤病羁绊了两个月**，**但逆流而上的属性并没有消失**，**欧联杯**、**足总杯和英超赛场上均用头球为曼联抢分过**，**尤其是在欧联杯的舞台上彻底找到了自信**——**场均成功争顶**4**次**，**场均评分拿到**7.16**分**。

****

**昔日贬低马奎尔的名宿纷纷道歉了**，**原本送出逐客令的曼联延长了合约**，**而扭转个人形象的马奎尔开始重新憧憬再续前缘的美好**，**并声称**“**曼联球迷是世界上最好的球迷**”，**即便曼联一直在招募中后卫**，**但买奎尔对尤文图斯的考察选择冷处理并不奇怪**。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBTAJZVNTv6LiaAgj075EI8RqrfTOBHgxBL5TZDxUyd1WkbuQHHib3u9AosXIeUdY0EVXEvbicmh10ibIQ/640?wx_fmt=jpeg&from=appmsg)

**拥有**“**儿魔梦**”**的马奎尔有洗刷偏见的源动力**，**值得一提的是**，**弗格森在任时就看好谢菲尔德联时期的马奎尔**，**如愿以偿的代价纵然伴随着质疑与嘲笑**，**不过也让英格兰大块头渐渐地拥有了**“**小强精神**”，**以至于他将加盟曼联的原因归结为**“**享受压力**”。

****

**抛开自我安慰**，**阿莫林的三后卫体系确实让马奎尔找到了舒适区**，**准确说他在两个禁区内都找到了价值感**，**上赛季对阵诺丁汉森林**，**替补出场客串中锋的马奎尔就在短短**7**分钟内禁区内**6**次触球**，**事实上葡萄牙少帅明确表示**“**中后卫属于球队的建设者**”，**并给马奎尔吃了定心丸**：“**在三中卫的战术体系下**，**他是我们的理想之选**，**他既有强健的体魄**，**又有冷静的心态**。”


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBTAJZVNTv6LiaAgj075EI8Rq96fFBWibJWYMESTllZvKftJSico9lKicaIPNlXyLKLicSHwr6VFibWicAdmA/640?wx_fmt=jpeg&from=appmsg)

**当下的曼联同样有**“**珍惜眼球人**”**的幸运和无奈**。**进攻端**，**马奎尔几乎是队内唯一能靠头球震慑对手的球员**，**防守端**，**英格兰中卫的身体素质远比马丁内斯**、**德里赫特和约罗**“**抗打**”，**即便诸如布兰斯韦特是曼联一直朝思暮想的猎物**，**但大价钱**≠**大回报**，**在这一点上经历宠辱的马奎尔既是选人的**“**镜子**”，**也是圆场的**“**面子**”，**费迪南德就说过**：“**马奎尔是曼联队内现阶段表现最好的后卫**。”


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBTAJZVNTv6LiaAgj075EI8RqgKGvmGz6SPXFeUlXC0Lw6SJiasJzLHYrfQuXDGb0xxHVcFduatDktiaw/640?wx_fmt=jpeg&from=appmsg)

**拒绝**50**万镑的周薪并不是一件容易的事情**，**只是缓过来的马奎尔更懂得珍惜当下**，**不仅是为了将昔日成为笑柄的自己重塑**，**也更愿意成为**“**传帮带**”**的带头人**，**他时常指导和鼓励青训球员**，**约罗刚来曼联报到时**，**他也是第一时间扮演引路人**，“**无论我是不是曼联队长**，**我都是领袖**”，**淋过雨的人要为别人撑起伞**，**这是一种勇气**。

****

**另一方面**，**沙特的养老计划并不一定能独善其身**，**亨德森早早打起了退堂鼓**，**重返英超后可圈可点**，**而亚当**·**托尼也在为世界杯名额计划重返英超**，**更三狮军团主帅图赫尔也坦诚**：“**他始终是我们阵容的重要组成部分**。”**别人的失意和主帅的信任让马奎尔不需要深思熟虑就能实现自我保护**，**当然为曼联效力的自豪感对于马奎尔而言从未消失**……
