# 大冷门！曼城要无缘欧冠？

赛季进入冲刺阶段，英超最大的悬念变成了争五，然而在这最关键的时刻，此前豪夺英超四连冠的卫冕冠军曼城掉链子了——北京时间昨夜的倒数第三轮比赛，蓝月亮客场0比0战平已经提前锁定副班长之位的南安普顿，积分榜上虽然仍然暂居第三，但形势已经变得严峻了起来。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBQBxric1yWTUleuyZkq4GOYmiaSfVfLdqx33Da64t0fPic1CzI0abc1l8bvxk6EsUVOptWuytSpyeuEQ/640?wx_fmt=jpeg&from=appmsg)


本场比赛，瓜迪奥拉派上了理论上的精兵强将，哈兰德一个半月以来伤愈复出首次登场，福登、德布劳内坐镇进攻线，科瓦契奇和B席搭档中场，还有鲁本-迪亚斯、阿坎吉、格瓦迪奥尔和里科-刘易斯在防线一字排开。放在以往，这样的曼城妥妥地轻松碾压南安普顿，但本赛季不是以往，曼城的战术被吃透，早已失去了冠军的锋芒。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBQBxric1yWTUleuyZkq4GOYmpLXhLMj3M1SCIAnPYN6aSP8eBficQYxJOolkgefMyKOD79Q6OaGicNfg/640?wx_fmt=jpeg&from=appmsg)


此役曼城确实如以往大多数时间一样，牢牢把握着控球率，射门数也是处于碾压的态势，然而却只有场面没有进球。德布劳内任意球制导，被圣徒防线极限解围，而这成了本场比赛的常态，大部分时间里，曼城能够真正制造威胁的只有德布劳内，看看哈兰德不时出现的离谱头球，你大概会有一种错觉——今夏该离开的是挪威魔人而非丁丁。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBQBxric1yWTUleuyZkq4GOYm1039mOwl1eqOiaFflEy8DriacDTdIxpc4PUiamCQ1tmrfkzcMicwUuWr0w/640?wx_fmt=jpeg&from=appmsg)


确实，德布劳内全场完成了5次射门，竟然是曼城全队最高的，此外还有4次关键传球，任何一次机会被把握住，曼城都能拿下三分。可惜的是除了丁丁之外，蓝月亮全队状态都不在线，瓜迪奥拉也只能在场边干着急。全场最佳的一次破门机会出现在第64分钟，B席的打门被斯蒂芬斯门线解围。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBQBxric1yWTUleuyZkq4GOYmjkCkRiamdicx7SdG6k63HB1PrQ0PVe2zt9Oib6UtNKsPduTsqViczbQAQQ/640?wx_fmt=jpeg&from=appmsg)


比赛尾声阶段，瓜帅大举调兵遣将，抽象的福登被换下，球队的进攻却没有实质性的进展。阿坎吉、萨维尼奥、马尔穆什和德布劳内的射门都被拉姆斯代尔化解，随着马尔穆什最后时刻劲射被横梁拒之门外，曼城只能接受0比0被副班长逼平的结局。这是一场令人失望的结局，全场能够站着离开的似乎只有德布劳内。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBQBxric1yWTUleuyZkq4GOYm8o058156BQxX2aic9M6ps8Ma2Tp6Oic42FyDewG33cXtu0rB9uYMVwYw/640?wx_fmt=jpeg&from=appmsg)


曼城当家射手哈兰德的表现大概也是球队的缩影，挪威人全场只有一次射门和17次触球，相当于隐身让蓝月亮少打一人，他不仅无法威胁到对方球门，甚至连制空权上的压制都无法做到。难怪有球迷吐槽道：曼城应该感谢哈兰德，如果不是因为他长期受伤，现在蓝月亮已经无缘欧冠了。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBQBxric1yWTUleuyZkq4GOYmiafpz4A1icZlNKxpEDFMcicxxDO1XOD6lWxVv86D83WhSAr2J5pCNLRRw/640?wx_fmt=jpeg&from=appmsg)


吐槽归吐槽，曼城的争五形势确实因为这场平局急转直下，现在他们虽然多赛一场位列第三，但身后的纽卡和切尔西都只差两分，同样少赛一场的诺丁汉森林也只差4分。唯一的好消息或许是，森林和切尔西本轮将直接对话，这至少保证了两支球队不可能同时在积分上超过曼城。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBQBxric1yWTUleuyZkq4GOYmCqz9aicWBVMVeibWCK5icnT9bHicG1RDrlJ2FOhibKsVFJxb27Q81Pz6nbg/640?wx_fmt=jpeg&from=appmsg)


但这并不意味着曼城可以高枕无忧。本赛季还有两场英超和一场足总杯，如果踢伯恩茅斯和富勒姆时继续对阵南安普顿一战的表现，丢掉欧冠资格绝不是危言耸听。于是，本赛季最极端的黑色幽默就可能是曼联喜提欧冠资格，而曼城最终要去踢欧联……对此瓜迪奥拉真的要好好想想解决办法了。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBQBxric1yWTUleuyZkq4GOYmLfubxGDbjUwWvGlNiaB3Jyo8upE6VPUKJahKzq4dbviaFMN3SrHq1G5g/640?wx_fmt=jpeg&from=appmsg)


瓜迪奥拉赛后表示：“当然，今天的结果是球队错失的一次机会，我们很清楚这一点。我们没有想到对方会这样去防守，这使我们没能找到节奏。今天我们确实有机会但没能得分，现在我们要准备接下来的比赛，首先是伯恩茅斯，然后是富勒姆。我们还有三场比赛要打，一场足总杯决赛和两场英超联赛。一个月前我就对此有所预料，球队需要战斗到最后一刻。”


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBQBxric1yWTUleuyZkq4GOYm2tV2icst0zeXYs0g2CZ6ShLy4z0Idjibma0yDgsbPgxXbkFFscBXekUA/640?wx_fmt=jpeg&from=appmsg)


上一次曼城在英超联赛中射门26次或以上却没有进球，发生在2020年7月，那一年曼城丢掉了英超冠军，这一次同样的情景出现，蓝月亮会不会丢掉欧冠资格？现在唯一可以确定的是，无论结局是喜是忧，曼城都该进行一次彻底的变革了。
