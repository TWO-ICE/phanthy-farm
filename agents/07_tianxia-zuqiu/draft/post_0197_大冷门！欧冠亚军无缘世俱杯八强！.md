# 大冷门！欧冠亚军无缘世俱杯八强！

在经过连续两个比赛日的波澜不惊之后，世俱杯第5场1/8决赛终于迎来大冷门——欧冠亚军国际米兰，在全场比赛两次击中门柱的情况下，0比2不敌巴西豪门弗鲁米嫩塞，被挡在了八强门外。事实证明，巴西球队小组赛的惊艳发挥不止是运气，而南美列强对欧洲豪门的挑战，正诠释着世俱杯的意义。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBQLoBA9RiabkF2wU3kvhbP88Qic3cz8PNib3B2w43C4kPjKDHJmIqBO0iaMozt1nxHyftSUW91umrhZEQ/640?wx_fmt=jpeg&from=appmsg)

事实上，国米此役输球在此之前已经埋下了伏笔，在经历三亚王赛季之后，蓝黑军团送走了两次带队闯入欧冠决赛的功勋主帅小因扎吉，球队的世俱杯成绩也产生了相应的波动。小组赛首战，意甲豪门就被来自墨西哥的蒙特雷逼平，让人大跌眼镜，之后赢浦和红钻和河床也不算轻松，让人质疑起欧冠亚军的含金量。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBQLoBA9RiabkF2wU3kvhbP88sEG4tqPGfsKKhicK98yMTicBkp1wGc2MqwEpBKkXpqxYdhXlvR2T9NpQ/640?wx_fmt=jpeg&from=appmsg)

反观弗鲁米嫩塞这边，虽然球队总身价不到1亿欧元，却踢出了桑巴足球特有的流畅，首场比赛战平多特堪称惊艳，之后晋级也是顺利成章。只是，考虑到末轮争排位时连马梅洛迪日落都没有踢赢，外界对这支球队还是持保留意见。毕竟，俱乐部层面欧洲和南美差距日益拉大的今天，弗鲁米嫩塞的星光璀璨程度完全无法和欧洲豪门相提并论。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBQLoBA9RiabkF2wU3kvhbP88VRkVn3JfN8X9ef3qVxuADuZRFPicp5KLE2fTIuYs4XsWYibWo1s7j4EQ/640?wx_fmt=jpeg&from=appmsg)

但，足球不是用单纯用战力衡量的棋牌游戏，世界第一运动总是要用双脚说话，这场被认为悬念不大的1/8决赛，弗鲁米嫩塞从一开场就给国米制造起麻烦。比赛第3分钟，卡诺一记头槌攻破了索默的十指关，蓝黑军团的老将们甚至身体还没有跑热，就见证了弗鲁米嫩塞将士的疯狂庆祝。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBQLoBA9RiabkF2wU3kvhbP887UK1XUFl4VtgZnykSVZwgL1MLkwUJ0g81huoYLnySbRoMEQpHUnhBA/640?wx_fmt=jpeg&from=appmsg)

丢球之后的国米发起反扑，迪马尔科多次制造出威胁，然而距离进球更近的却是弗鲁米嫩塞，上半场结束前伊格纳西奥头球破门，因为越位在先被判无效，蓝黑军团逃过一劫。之后迪马尔科有一次凶狠的踩踏犯规，结果连一张黄牌都没有吃到，这也从侧面反映出国米将士在场上的急躁。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBQLoBA9RiabkF2wU3kvhbP88zGjvuONmeqQTTnk8GiaHDxOdQtSibHh3V35X9licv3kO7MoBazwMSCE0A/640?wx_fmt=jpeg&from=appmsg)

易边再战，国米早早就做出三处换人调整，但场上的局势并未改变，若非索默飞身扑出阿里亚斯的死角兜射，比赛悬念或许会提前终结。之后的时间，甚至连运气都没有站在国米这边，德弗赖的近距离必进球打偏，劳塔罗多次做出尝试，他的射门无限接近扳平比分，可惜最终被立柱拒之门外。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBQLoBA9RiabkF2wU3kvhbP88Dyfib8z3dXTT9xa2s1dVCGmicDoUJFVlib0LcskoicNKpsibTGmxeicS653Q/640?wx_fmt=jpeg&from=appmsg)

1比0的比分就这样持续到伤停补时，弗鲁米嫩塞终于找到机会杀死比赛，只见埃尔库莱斯会心一击，彻底地锁定了胜局。之后迪马尔科搓射中框似乎是国米此役运气不佳的缩影，欧冠亚军只能接受0比2败北的命运。弗鲁米嫩塞成为第二支晋级8强的巴西球队，他们将等待曼城和利雅得新月之间的胜利者。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBQLoBA9RiabkF2wU3kvhbP88q0vp9Ml6pBQSY50BnFrlfJ8mXe2tth3Q3cXbJGOXdalYopyqYtE0GQ/640?wx_fmt=jpeg&from=appmsg)

赛后，不甘心输球的劳塔罗愤然说道：“想留下的球员，让我们为目标而战。不想留的人就走吧。我看到了很多我不喜欢的事。作为队长，我想为重要的目标而战，我们是一支重要的队伍。我们赢过，我们希望继续这样。想留下的人可以留下，不想留的人，再见了。失利的感受？我们必须重置，一个人我们哪里都去不了。”


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBQLoBA9RiabkF2wU3kvhbP888EKjCVMNjQEAFGJ4Za3g7k9pAlJiauiaAIrOkEQ2oD58RnC3LdaKGG5g/640?wx_fmt=jpeg&from=appmsg)

毫无疑问，小因扎吉离开之后，国米的更衣室出现了问题，一支内部出现矛盾的球队，向来不可能在大赛中走很远。经历了相对黄金的2-3年，被誉为意甲最强战力的国米，已然走到了换血的十字路口，老将或许会带来即战力，却无法拥有可持续发展，本届世俱杯的早早出局，就为国米敲响了警钟。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBQLoBA9RiabkF2wU3kvhbP88sfQ43NgkquXibUYOwzHPsDTAj6K315c3cIN8dz2I2EFxoTw8hsBXAicQ/640?wx_fmt=jpeg&from=appmsg)

同时，人们有无数个理由为蒂亚戈-席尔瓦领衔的弗鲁米嫩塞喝彩，他们踢出了超越身价的成熟，将来自欧洲的巨人击倒。也许随着赛程深入，欧洲列强注定会成为世俱杯的中心，但足球的多元在此刻具象化了，没有绝对的强者，也没有定义的弱者，世俱杯渐入佳境，还会带来更多冷门和惊喜吗？
