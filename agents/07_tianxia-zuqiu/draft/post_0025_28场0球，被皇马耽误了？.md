**在西甲场均评分名列前茅的安东尼没有如愿入选新一期的巴西国家队**，**与之相比**，**在皇马逐渐沦为边缘人的罗德里戈则顺利入选**，**同一个梦想**，**截然不同的待遇**。**作为**“**老好人**”**的安切洛蒂似乎陷入了任人唯亲的漩涡中**，**要知道**，**皇马**11**号曾将安切洛蒂称之为**“**导师**”**和**“**挚友**”，**而意大利教练在上任之初**，**就给弟子吃过一颗定心丸**：“**记忆是很重要的**，**我非常了解罗德里戈**，**我知道他能为球队带来很多**。”


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBQTUo17N2vmkqCokSOR4G1xDhibRR9hXcMicHySVLIe6agxzibEj5S7z8RoCWXgYdJaDCtYYgPr7B8Jw/640?wx_fmt=jpeg&from=appmsg)

**靠合作情怀支撑的罗德里戈确实反馈过被信任的热情**，**在**10**月对阵韩国的热身赛中**，**他就秀了一把**，**先是****禁区内故意漏球**，**接着****晃晕****对手**，**最终****右脚弧线球****破门**。**在打破个人在巴西****国家队**398**天****进****球荒****之际**，**也展示了巴西**10**号应有的才华**，**荣膺全场最佳球员实至名归**，**就连赛后的发言颇有大将之风**：“**稳固的防守始终很重要**，**队内每个人都能互相帮助**，**然后进攻才能逐渐奏效**。”


![图片](https://mmbiz.qpic.cn/mmbiz_png/sAmI87QVQBQTUo17N2vmkqCokSOR4G1xopUhZFCnkBuN0riaEsoCgYSEd80HicOdhenS5dzbRFvRy4dYRibfc2JUg/640?wx_fmt=png&from=appmsg)

**毋庸置疑**，**罗德里戈惊鸿一瞥的瞬间深刻了安切洛蒂的所说的**“**记忆**”，**然而巴西天才在皇马并不拥有主角光环**，**准确说他已经失去了与维尼修斯并称巴西双子星的底气**。**据统计**，**在本赛季亮相的**16**场比赛中**，**罗德里戈累计才捞到了**3**次首发机会**，**出场总时间只有**452**分钟**，**不足维尼修斯的**1/3，**个人贡献的**2**次助攻已是**“**最后的逞强**”。

****

8000**万欧元的最新身价在一定程度上为罗德里戈注入了收拾旧山河的自信**，**但用活在当下的标准去衡量得失时**，**昔日的亿元先生肯定走了下坡路**，**并且跨赛季的经历了**28**场俱乐部进球荒**。**得到安切洛蒂的欣赏与偏爱自然是好事一桩**，**但不可避免地遭遇非议**，**毕竟在皇马的上场时间和竞技状态才是名正言顺的基础条件**。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBQTUo17N2vmkqCokSOR4G1xWnLWhFqRvloricBTeIB4b3eHibdw5Dz5lC2JfoicYd4ag5VNyuQeibhcfA/640?wx_fmt=jpeg&from=appmsg)

**罗德里戈在今年夏天就是转会市场上的绯闻大牌**，**阿森纳**、**利物浦和热刺均不同程度地举起过爱的号码牌**，**奈何皇马自始自终地用高价限制过潜在买家的热情**，**最重要的是**，**巴西人以**“**只要皇马还需要我**，**我就会留在这里**”**的口吻斩断了一切绯闻**。

****

**坦白讲**，**罗德里戈有自己的**“**白色情怀**”，**他在**6**岁时就拥有了人生第一件皇马战袍**，**他在**2019**年转会皇马之前**，**与巴萨只有一步之遥**，**用他的话说**：“**我加盟巴萨的手续几乎都办完了**。”**六年时间一晃而过**，**巴西少年已经用**13**座冠军奖杯诠释了选择的正确性**，**延续美好属于本能反应**，“**留下来**”**几乎是一个不假思索的决定**。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBQTUo17N2vmkqCokSOR4G1xHNkHkunc0qkeibbQl8ZpDGPOLMzYcE1MxsibZrpFiaOJbBHntMoMmUEfA/640?wx_fmt=jpeg&from=appmsg)

**带着重建任务而来新帅阿隆索有自己的**“**棋盘**”。**他提前换下维尼修斯**，**一次告诫弟子防守端的不积极**，**但也局限在一种相对温和的惩罚范围内**，**与之相比**，**罗德里戈似乎一直不入西班牙人的法眼**，**世俱杯上最久的一次亮相是**65**分钟**。

****

**罗德里戈公开表态过**“**服从教练的安排**”，**这是一种情感示弱**，**但长期与板凳席为伍无异于蹉跎岁月**，**为此他曾明确表示希望在最擅长的左路上发挥个人价值**，**这是一种强硬对峙**，**然而习惯性惹事的维尼修斯才是阿隆索的第一选择**，**尽管他们在姆巴佩眼里都是世界级的**。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBQTUo17N2vmkqCokSOR4G1xw0TwqoQFiccFYQA5twoOuH1be3WNxTkYiaRibbyum6UZIHh5UB0fygDbw/640?wx_fmt=jpeg&from=appmsg)

**众所周知**，**两位巴西天才均在防守端存在懈怠性**，**但罗德里戈并没有真正意义上位**，**只是偶尔**“**出出头**”，**大多时间内扮演了维尼修斯的替补**，**并肩作战的机会更是少之又少**，**当维尼修斯持续性地索要**3000**万欧元的年薪时**，**上场时间仅占总时长**25%**的罗德里戈似乎只能寄希望于在皇马有球可踢**，**在替补席上****怒****摔球衣是压抑已久的**“**大动作**”。

****

**一步错**，**步步错**？**夏天的罗德里戈用**“**儿皇梦**”**说服自己留守伯纳乌**，**当下的巴西天才久连用努力感动主帅的机会都在被渐渐剥夺**，**昔日的宠儿会在冬天告别吗**？**阿隆索屡屡用**“**战术安排**”**的口吻撇清矛盾论**，**但**24**岁的罗德里戈确实等不起了**。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBQTUo17N2vmkqCokSOR4G1xbryzBcZyUNTLic6OOKUKmN6Tq4gHeJ1QPhTTXk99PU1CRd3RYtTC8dw/640?wx_fmt=jpeg&from=appmsg)

**出场时间严重碎片化的罗德里戈身价锐减和体重下降只是表面伤害**，**有束缚感的巴西人本赛季的****关键传球成功率****和****对抗成功率****严重下滑**，**场均抢断次数不足**1**次**，**长此以往必然形成恶性循环**。**要知道**，**阿隆索宁愿让巴尔****韦****德在边路客串**，18**岁的小将马斯坦托诺也短暂地拿到了出人头地的机会**，**罗德里戈被高看一眼成了一种奢求**。

****

**离开是必要的解脱**，**只是还没有坐稳帅位的阿隆索并不希望以两败俱伤的形式分手**，**况且罗德里戈在一定程度上充当了维尼修斯与皇马关系复杂的平衡点**，**一旦前者最终被沙特的淘金计划诱惑**，**罗德里戈的上位机会被动地提前了**，**甚至能被理解为一种**“**后手**”。


![图片](https://mmbiz.qpic.cn/mmbiz_png/sAmI87QVQBQTUo17N2vmkqCokSOR4G1x4DdxnJ1lOOvib2bibCvpDvzQ0xggyb0yaJscZtKrBxEP61lKW6jmCNPA/640?wx_fmt=png&from=appmsg)

**得不到的永远在骚动**，**罗德里戈还愿意在替补席上盼一个不确定的未来吗**？**也许更多的时间段内**，**他在感慨物是人非**。**罗德里戈在**18**岁时就曾在欧冠上演过帽子戏法**，**并且在羽翼渐丰的过程中**，**在同一片舞台上**，**国际米兰**、**曼城**、**切尔西**、**那不勒斯**、**马竞先后被他的天赋折服过**。**在西班牙国内赛场上**，**马竞和巴萨重复领教过巴西人的激情**，**最重要的是罗德里戈以**23**岁**344**天****年龄**，**成为了****皇马队史最年轻**13**冠球员**。

****

**与皇马续约到**2028**年是凭本事赢来的奖励**，**但如果以局外人的身份完善年少的梦**，**无异于煎熬**，**罗德里戈既不愿意成为维尼修斯的备胎**，**也不愿意在拉锯战中成为更衣室的破坏者**。**安切洛蒂的偏爱暂时是靠记忆维持的**，**新赛季西甲颗粒无收**（10**场**0**进球**0**助攻**）**的天才以入选国家队为荣**，**也需在争议中认真考虑未来的路**。
