# “白色博格巴”重回意甲？

选择在沙特养老的球员堪称“老中青三结合”，有人赚得盆满钵满，但也有人走进了误区，已经重返英超的亨德森就是一个例子，他说过：“我意识到足球流淌在我的血液中，虽然沙特联赛正在发展中，但它不适合我，我去那里是一个错误。”


效力利雅得新月的米林科维奇的合约在明夏到期，似乎会成为一个“自由者”，区别于亨德森离开时的观点，塞尔维亚球星在世俱杯期间曾为沙特联赛打call：“很多人批评我们这些加盟沙特联赛的球员，然而淘汰曼城足以说明一切，沙特联赛理应获得尊重。” 


![图片](https://mmbiz.qpic.cn/mmbiz_png/sAmI87QVQBSCvoOGVZnarPM0Jhx1HicLHso7raz0UIZnLsIUl6O0MtyicqDrPLkySvU6h95xWIg9MvfWISPs3dVA/640?wx_fmt=png&from=appmsg)

坦白讲，米林科维奇并没有辜负利雅得新月两年前4000万欧元的投资，在新赛季开打之前，他累计在96场比赛中贡献了29粒进球和25次助攻，相对于养大伤赚大钱且潇洒而去的内马尔，米林科维奇仿佛置身于主角光环中。上演过帽子戏法，贡献过任意球破门，捧起过沙特联赛、沙特国王杯和沙特超级杯冠军，荣膺过阿拉冠金球奖。


有出勤率保障，有贡献值支撑，2000万欧元的个人年薪物有所值了，准确说，米林科维奇是拿钱办事的典范，似乎对应了拉齐奥主席洛蒂托送别米林科维奇的时的话：“如果一个人想去沙特，能刺激他的只有钱了。”


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBSCvoOGVZnarPM0Jhx1HicLHZqOny0HhjEVQnib2bvdeMEicXm4OgDzvKpnsnUlNpeOHUjAbPPKTUykg/640?wx_fmt=jpeg&from=appmsg)

在沙特拿高薪&当大腿米林科维奇乐不思蜀是正常的事情，何况利雅得新月的新帅小因扎吉与其在拉齐奥时是旧相识，再续前缘的动力不言而喻。有迹可循，米林科维奇在2019年与曼联传出绯闻时，执教拉齐奥的小因扎吉公开发声挽留弟子，2023年执教国米的小因扎吉也曾希望招募旧部，然而蓝鹰将3500万欧元的标价设置成转会障碍，但并不妨碍将塞尔维亚球星形容为“一个值得关注的球员。”


![图片](https://mmbiz.qpic.cn/mmbiz_png/sAmI87QVQBSCvoOGVZnarPM0Jhx1HicLHALI8iaWeFq7MBptAiblCVXia6FtGCLpcDlwf4VRC9UMwC6yDTAPEN4UQg/640?wx_fmt=png&from=appmsg)

如今师徒二人在沙特戏剧般地重逢，“熟悉”和“信任”是彼此共同的默契与优势，利雅得新月在世俱杯上平皇马&胜曼城属于一个试探性的丰硕成果，在全队1.8亿欧元身价（亚洲第一）的支撑下，在沙特联赛当领头羊难度系数自然会降低。


但与此同时，欧洲足坛频繁接受从沙特而来的“回锅菜”，亨德森和奥巴梅杨两位老兵先后在五大联赛成功再就业，因此而立之年的米林科维奇陷入转会绯闻并不奇怪。事实上他是明年夏天转会市场上潜在的小红人，意甲北方三强已经在提前暗战，而效力八年之久的拉齐奥也在悄悄地打感情牌。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBSCvoOGVZnarPM0Jhx1HicLHDMqiaXdiaVZnQicjpmD4I3Qo5xNtrSk8vkJreJ068v11dhurCcIm5HgOg/640?wx_fmt=jpeg&from=appmsg)

从意甲到沙特，米林科维奇差点被“不思进取”的质疑声吞噬，从沙特到意甲，似乎是给自己一次自愈的机会，又或者说在沙特赚够了钞票的塞尔维亚球星开始主动怀念亚平宁半岛了，这可以理解为一种本能，而瓜迪奥拉在世俱杯上对米林科维奇的一番褒奖更像是“一次顺势而为的助攻”。


有意思的是，小因扎吉两年前点评米林科维奇登陆沙特时的话被翻出来了：“他是一名伟大的球员，他做出了选择去阿拉伯，但他有时间回到欧洲，他还年轻。”倘若塞尔维亚球星最终在小因扎吉麾下被放任自流的话，一语成谶的话题也许会被发酵成热搜。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBSCvoOGVZnarPM0Jhx1HicLHeFckvawgLjsHUJ6q8C87DGAOvnS2ZIrUoQGInVeHD8TBvhgBmjaAxg/640?wx_fmt=jpeg&from=appmsg)

一边是“师徒合力，再创辉煌”的召唤力，一边是“豪门之约，更待何时”的紧迫感，米林科维奇似乎存在犹豫的空间，至少当利雅得新月提供两年新合约时并未选择签字。坐地起价还是当真要走？值得一提的是，AC米兰新任体育总监塔雷对米林科维奇有知遇之恩，正是他在2015年将只踢了一个赛季比利时联赛的新星带到拉齐奥，并且身价在2018年飙升至9000万欧元，而现任主帅阿莱格里执教尤文时期也曾向塞尔维亚球星伸出橄榄枝。也许米林科维奇为小因扎吉踢一个赛季，然后以自由身登陆意甲，是最大化的平衡与心安。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBSCvoOGVZnarPM0Jhx1HicLHI8TBrkfTBzicoeRQ1OKLPFSBhASho9hicU0ANUQunoIjHewQTa8kR0XA/640?wx_fmt=jpeg&from=appmsg)

巅峰时的米林科维奇被媒体冠以“白色博格巴”的称谓，甚至一度被洛蒂托标价到1亿欧元。他是技术、力量、高度的结合体，进攻端有前插习惯和无球跑动，防守端有压迫感和位置感，换而言之，具备了优秀B2B中场的一切条件。

即便沙特联赛的强度远远不如五大联赛，但米林科维奇丰富球队战术套路的定位并没有改变。倘若真的愿意在明夏当“回锅肉”，在豪门拥有一席之地并非痴人说梦，来之即战的惊喜也许会超出预期，毕竟在加盟沙特之前的那个赛季中，他是在助攻次数和创造机会次数均排名意甲第一的中场，别忘了他曾说过“我更像亚亚·图雷。”


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBSCvoOGVZnarPM0Jhx1HicLHO6mOhxpOTzXrKadyIZbeggkrEyGu3doA8heic7c0Lqg1VxlDTnicGacA/640?wx_fmt=jpeg&from=appmsg)

米林科维奇虽然在利雅得新月风生水起，快乐似乎也隐藏着一种悲。他与塞尔维亚国家队渐行渐远，曾与主帅闹过矛盾，并一度扬言退出国家队，也曾因为在2024年欧洲杯上因为眼神防守导致丢球备受自家球迷指责，抛开伤病因素，缺席世预赛似乎是符合民意的惩罚。


五大联赛并不是主帅选才的唯一舞台，事实上同样在亚洲足球圈效力的米特洛维奇和马克西莫维奇等人系数入选塞尔维亚国家队，米林科维奇的竞技状态并无大碍，但换个环境赢得关注度也是合理的选择。其实无论去与留，最重要的是米林科维奇不要遗忘昔日的豪言：“我感觉自己是球队的领袖。”
