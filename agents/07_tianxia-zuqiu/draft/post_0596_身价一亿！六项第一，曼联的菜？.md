# 身价一亿！六项第一，曼联的菜？

英超新势力的亿元先生不胜枚举，布莱顿的巴莱巴，水晶宫的沃顿，都是豪门猎物，最新一个冒出来的是诺丁汉森林的埃利奥特-安德森。坦白讲，这是一个意外的名字，或者说曾被认为是造星的产物，甚至会被认为是户口本的加持，毕竟从数据上看19场1粒进球1次助攻的数据并不出彩，但是世界上没有无缘无故的“爱”，不然他不会成为豪门集体哄抢的猎物。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBTMXORB6GUhUzGu31O9nhHZSa9N2Pibz9icklEA1qwTQheTEW7tw3nicPC8TZCOKg2ca7y6iabZwhDfbg/640?wx_fmt=jpeg&from=appmsg)

在诺丁汉森林效力，安德森终究不具备吸收流量的天然条件，但能成为转会市场的宠儿并不是偶然事件。据统计，安德森是本赛季英超的六项数据里中前卫最多的球员，其中最突出的一项是111次抢回球权，127将球传到进攻三区，即使“我们进入状态太慢”是一种鸡汤式的表态，但是“金子在哪里都发光”的老话得到了真正意义上的诠释。英国媒体将他形容为“后防线和攻击线之间最稳固的桥梁。”


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBTMXORB6GUhUzGu31O9nhHZH6Lvk8icuhGadMxDgFiayI5agJpGZ2SIbiaYeXrto0I4Z1Iuh7almGwRw/640?wx_fmt=jpeg&from=appmsg)

坦白讲，安德森并非一夜成名，他曾为苏格兰U16到U21持续性效力，具备了成为后浪的潜力股，也理应拥有为苏格兰国家队效力的资格和实力。但是他也并非大红大紫，以至于在纽卡斯尔出人头地时，英足总并没有明确的“抢人”计划。但人都有知耻后勇的自觉和更近一步的动力，如安德森所言：“一旦我意识到自己足够优秀，可以为英格兰效力时，我就下定了决心，并专注于为英格兰踢球。”


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBTMXORB6GUhUzGu31O9nhHZ50ib9gnV1ZHhaxjh5WdBE3TDy526b6QLJSaoQOJkuPAyJhpWAZ9BH8A/640?wx_fmt=jpeg)

虽然接连得到了曼联，曼城和切尔西伸出的橄榄枝，但安德森也走过弯路，或者说经历过“做大做强”的轨迹。虽然为苏格兰各个国家队的梯队效力过，但是在纽卡斯尔经历过一段时间的沉淀期，至少20-21赛季只在英超亮相了1次，累计出场只有3分钟，绝大多时间只能在青年队蹉跎岁月，曾被租借到英乙球队布里斯托尔流浪者。年轻无极限？但当时没有人敢预言这个菜鸟是一位未来的炸子鸡。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBTMXORB6GUhUzGu31O9nhHZ6bS3ZFNzlf9oDydKdia0w3ZNjIZqF8TyY6mPYT7RMxmJnJlsQkCwVaw/640?wx_fmt=jpeg&from=appmsg)

这就延伸了一段成长史。安德森17岁完成职业生涯首秀，对于出生在纽卡斯尔的安德森而言，这是一种体面的圆梦。再进一步讲，安德森从22-23赛季开始了野蛮成长模式，以至于队史传奇希勒炮轰过俱乐部的不作为：“他只是没有获得常规的比赛时间，俱乐部没有完全支持埃迪-豪。”以至于他炮轰过的财务公平竞争规则：“由于规则的限制，纽卡斯尔不得不卖掉他以平衡账目。”


这种爱而不得的苦涩可想而知，从另一个角度看，效力纽卡斯尔最后一个赛季只捞到10次首发机会的安德森并不介意“向下就业”。更离谱的是，纽卡斯尔甚至在合同中没有优先回购条款或者二次转会分成。考虑到来日方长的自我期望，在舒适区稳定地踢球才是基础条件。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBTMXORB6GUhUzGu31O9nhHZ4KJsMoexAJMoaHISn7G5zAkBCruGOPFkiaWbOVkYu2ejWBMa8molbUw/640?wx_fmt=jpeg&from=appmsg)

有船厂老板支持的诺丁汉森林用4100万欧元签下了希勒的心头肉安德森，但即便如此，外界还在持续性质疑这笔溢价交易，毕竟当时的安德森身价只有1500万欧元，当诺丁汉森林上赛季演绎黑马本色时，外界被彻底打脸了。完成三狮军团首秀是意料之中的奖励，顺便为拥有福登和贝林厄姆的中场增加了甜蜜的烦恼，在这个新闻的发酵下，安德森被豪门看上是实力使然的事情，甚至比另一个亿元先生沃顿更优先的得到为国争光的机会。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBTMXORB6GUhUzGu31O9nhHZtYnHyYMNbYzXXvzgQVGHYwB1Vyf8eAibZO1xw1aZVkN6ib2fHOrEjoNg/640?wx_fmt=jpeg)

安德森有攻守兼备的属性，近两个赛季的场均精准传球成功率都超过了82%，但是防守才是他的加分项，而且有精益求精的感觉。比如场均夺回球权的次数从上赛季的5.6次狂飙到8.4次。


再做一个纵向对比的话，在过去一年欧洲五大联赛的所有中场球员中，安德森每90分钟拦截对手次数（3.69次）方面排名前1%，抢回球权次数（6.88次）方面排名前3%，55%的对抗成功率更是让人刮目相看，就连图赫尔都直言“这是英超最佳中场之一”。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBTMXORB6GUhUzGu31O9nhHZ0VnPokqZY925lTQ0R9jqxLJIxwOBgF3Dic2iaHqvqPw4c5YDoenE7fUA/640?wx_fmt=jpeg&from=appmsg)

从纽卡斯尔到诺丁汉森林，安德森实现了“人挪活”效应，或者说真正意义上做到了大丰收。他预订了2026年世界杯的席位，他被曼联视为卡塞米罗的接班人，更值得一说的是，缓过神来的纽卡斯尔有意吃回头草，并为其设定了“拖后组织核心”的角色，当然有危机感的诺丁汉森林顺势将出售安德森的底价设置为1.2亿欧元。


好的东西都贵，又或许这是狮子大开口的前兆，但相应地提供了一面镜子。要知道2023年的夏天，赖斯曾与曼联一步之遥，但是被1亿英镑的转会费推迟了进度，最终阿森纳得之后快。曼联会继续覆车继轨，还是深刻前车之鉴的道理？或许曼联这个赛季后卡塞米罗如果离开曼联，曼联会果断出手拿下安德森？


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBTMXORB6GUhUzGu31O9nhHZycibib9X4wSehAY0ichW32HLqOMP8ZTYK1eXia2k00ibDQKUYfC1HibIRb4w/640?wx_fmt=jpeg&from=appmsg)

“我的未来不是梦”，变成宠儿的安德森有宣泄梦想成真的资本，事实上他为三狮军团出场的前两场世预赛就拿到了全场最佳，并没有所谓的青涩感和生涩感，有意思的是，苏格兰足协在自我总结时，将没有在训练场保护好安德森视为人才流失的直接原因。


原来，安德森在2023年入选苏格兰代表队准备出战对塞浦路斯的欧洲杯预选赛，这场比赛本可以锁定他未来只能代表苏格兰，然而在训练中，安德森与队友发生冲撞，这让年轻的安德森深感不适。冥冥之中自有安排？或许错过是另类的收获，倘若在2026年世界杯上真的二次镀金，亿元先生或许是最简单的头衔。
