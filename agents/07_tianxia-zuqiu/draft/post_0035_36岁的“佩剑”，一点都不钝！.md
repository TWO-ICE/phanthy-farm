# 36岁的“佩剑”，一点都不钝！

去年夏天加盟的佩里西奇让埃因霍温体会到了“真香”，克罗地亚球星在35场比赛里贡献了16粒进球和11次助攻。最值得纪念的个人秀是，佩里西奇在对阵福图纳锡塔德时上演了帽子戏法，就此成为荷甲近40年来最年长的帽子戏法先生。


最值得回味的胜利果实无疑是荷甲冠军，这是彼此是双向奔赴的最佳成果，值得一提的是，佩里西奇似乎提前预料到了，在加盟埃因霍温之前，他拒绝过阿贾克斯的邀请：“埃因霍温对我来说是完美的地方，我知道教练想要什么。”


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBSbCFsGoPMNmkl2iaNaGVVO0A3T4maE8dUhLN86LadvnHWbF4w3a4OrvCa7fYs934QIPWHhyP29S1A/640?wx_fmt=jpeg&from=appmsg)

在演绎老兵不死的故事里，埃因霍温迫不及待地想要延续得之我幸的甜蜜，而五大联赛的豪门随之产生“拿来主义”的欲望。比如巴萨一度是佩里西奇当时最心动的买家，且曾与他共事过的弗里克将顺势盛赞旧部是“经验和活力的结合体”。


坦白讲，佩里西奇的万金油属性是豪门之约的关键因子，毕竟他能在左右边锋和中锋位置上做好本职工作，有迹可循，效力国米时他在意甲平均每90分钟贡献2.1脚禁区内的射门，这一数据高于任何一名意甲非前锋球员，与此同时他也能在两个边后卫上完美客串，用穆里尼奥的话说：“一般的边锋就是快和创造力，而佩里西奇在攻守两端有身体，非常强壮，争顶也很强。” 


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBSbCFsGoPMNmkl2iaNaGVVO0nFZXyz5L5wlOEgn0SYfYcYHqMAh7xJWa1yfhQOuIova53DDVjUQZ8Q/640?wx_fmt=jpeg&from=appmsg)

曼联的拉什福德和现效力拜仁的迪亚斯起初在与巴萨的绯闻上做到了“后来居上”，毕竟天赋与年龄是让巴萨心动的直接原因，并且最终成功租借到了拉什福德。福祸相倚，埃因霍温顺势得到了再续前缘的机会，稍微让人意外的是，荷甲豪门一口气送上了两年合约，既表达了“非你不可”的诚意和信任，也让佩里西奇在2026年世界杯前得到了蓄势而发的稳定平台。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBSbCFsGoPMNmkl2iaNaGVVO0ecf47G0mhgBR8B8YeZrYmnU5NuGZiaIGR1ecyHFicS4S4DxQV2st3gSg/640?wx_fmt=jpeg&from=appmsg)

如果只是靠荷甲赛场上的英雄主义，佩里西奇不会在转会市场上制造小风浪。在上赛季对阵尤文图斯的欧冠淘汰赛附加赛次回合里，克罗地亚球星是埃因霍温翻盘的功臣，首开纪录之余，他创造了3次绝佳机会，防守端上完成了3次抢断和3次拦截。


在热血未凉的剧情中，佩里西奇在攻防两端“当爹又当妈”，并且在这场以上克下的焦点战役中用纪录标榜了年轻感——他以36岁17天的年纪，成为在欧冠淘汰赛两回合比赛中进球年龄最大的球员，顺便也成为了连续在欧冠淘汰赛中进球年龄最大的球员。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBSbCFsGoPMNmkl2iaNaGVVO0f8eOggxX0lWiczWicapklNMXzmiakNPpUro4D9RuJXFhokcJqfjOJwMIQ/640?wx_fmt=jpeg&from=appmsg)

沦为背景帝的“老妇人”有似曾相识的画面感，回想2021-22赛季的意大利杯决赛，正是凭借着佩里西奇加时赛里的梅开二度才艰难战胜尤文图斯并捧杯，以至于尤文名宿拉瓦内利公正地发声：“他是国米不可或缺的人物，必须不惜一切留住他”。


事与愿违，彼此终究因为薪资待遇而分道扬镳，值得一提的是在转会热刺之前，尤文图斯就曾试图用税后600万欧元的年薪招募佩里西奇，然而有血性的克罗地亚人并没有因金钱成为效力6年国米的敌人。果不其然，即使离开亚平宁半岛，效力埃因霍温的国米旧将还在演绎“一个人的意大利国家德比”，据悉，佩里西奇在对阵尤文图斯时累计斩获了6粒进球，堪称克星。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBSbCFsGoPMNmkl2iaNaGVVO0jrAOX9ibRVTibJZGUsHqq0oq19a1wnHcZz2hMcy1lxoekdhYvj54vF4A/640?wx_fmt=jpeg&from=appmsg)

新赛季的荷甲首轮，埃因霍温轻松拿捏鹿特丹斯巴达，传射建功的佩里西奇延续了良好的竞技状态，相对于给尤文图斯的伤害，此役并不是一个值得炫耀的个人战绩，然而他的榜样力量并没有被淡化或者被转移，埃因霍温主帅就说过：“他把每一次训练当作了最后一次比赛，职业素养堪称年轻球员的教科书。”看似习以为常的褒奖，佩里西奇却是用自律的汗水换来的。效力拜仁时的克罗地亚球星连星期天都在健身房雕塑身材，如今他的体脂率维持在8.5%左右，队医更是将他的身体年龄形容为“与25岁的球员不分上下”。


![图片](https://mmbiz.qpic.cn/mmbiz_png/sAmI87QVQBSbCFsGoPMNmkl2iaNaGVVO0756KE2g4kGqu1FiaB8Y1Dps5mEhu0fHHmV6eccicLGMbL5kNT7gL67icA/640?wx_fmt=png&from=appmsg)

你甚至很难想象，佩里西奇在两年前差点因为十字韧带撕裂差点提前结束职业生涯，在老兵不死的话题被发酵之前，他经历过被热刺提前解约的无奈，在哈伊杜克的养老计划也被提前终结了，两次“球队不再需要我了”的发言充满了伤感。


时间剥夺了所谓的光环，也给予了重新出发的空间。佩里西奇在荷甲焕然一新就是一种新生，他聘请了私人教练，忘记了年龄的束缚，他增加了水中阻力训练膝关节，减轻了伤病的羁绊，他以领袖的身份发光：“我总觉得自己是一个领导者”是一种心声，主动转型为前场自由人是一种责任。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBSbCFsGoPMNmkl2iaNaGVVO0FAwctUNzO3TViavfcQsBiaqiatBjwJq9QgSfPPEMH9FCrCwu8iaJw0gzBQ/640?wx_fmt=jpeg&from=appmsg)

2022年世界杯期间，佩里西奇成为了克罗地亚国家队历史上的第二射手，当记者问是否有兴趣冲击苏克的进球纪录时，他的回答很干脆：“如果我感兴趣的话我就不会回去防守了。”于是类似的提问在荷甲被重复时，他还是习惯性冷场，先是将胜利和冠军作为唯二的“诗和远方”，接着制定了另一种老有所为的成功标准：“能把如何走向长期成功的路径传授给下一代，这会是一件非常有意义的事。”
