# 大胜变惨胜！曼城变曼联？

又到足球周末，五大联赛战火纷飞，英超率先登场的豪门曼城，就在大优局面下玩起心跳。面对升班马利兹联，哈兰德继续着低迷的状态，连续三场比赛未能进球，而曼城太子福登终于找回了自己，用时隔近两年的又一次联赛梅开二度完成证明。一场跌宕起伏的3比2，让蓝月亮终结了各项赛事两连败，只是比赛踢出了曼联的流量效果……


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBTxdXSx52cQibHQ1TzmUlXthic9DbcyFibcvNicazmrUro773LmjA7Nwu5icoUqYMl7pC3gQqyrcniadINA/640?wx_fmt=jpeg&from=appmsg)

过去一周的曼城，状态其实并不好，在欧冠和联赛连续以大比分击败多特和利物浦之后，经历了国际比赛日，蓝月亮突然状态全无。上周末的英超，瓜迪奥拉的球队被纽卡击败，周中的欧冠，他们则搞砸了主场的轮换，0比2意外不敌德甲劲旅勒沃库森。如此场景，让人想起了曼城在去年11月开始的崩盘，球迷也大骂瓜帅为何敢玩极端轮换。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBTxdXSx52cQibHQ1TzmUlXth9QEQzjfyDPxn8Rfj8ewzbk28V6AfDn60ThRz6d2rEH0m5UZsUIGqIw/640?wx_fmt=jpeg&from=appmsg)

当然，如果你看了昨夜曼城与利兹联的比赛，就会明白瓜帅的良苦用心——如果周中没有轮换让主力休息，蓝月亮还真不一定能够踢赢白玫瑰。这场在伊蒂哈德球场进行的战役，曼城拥有着完美的开局，福登开场59秒就完成破门，打进本赛季英超最快进球，之后格瓦迪奥尔又在第25分钟于角球混战中破门，帮助蓝月亮扩大优势。然而，这只是剧本的开始。


![图片](https://mmbiz.qpic.cn/mmbiz_gif/sAmI87QVQBTxdXSx52cQibHQ1TzmUlXthg9OQn8KrpqjfPKbBiaia8LKg5Dt6uVrMjymdpHqG7XW0qjZgE6CQ4ADA/640?wx_fmt=gif&from=appmsg)


![图片](https://mmbiz.qpic.cn/mmbiz_gif/sAmI87QVQBTxdXSx52cQibHQ1TzmUlXthDOPLP3fTq0Il68x2XibcqvStaEvF2wLVCs30gy88hibUKhcVg4WpLxbQ/640?wx_fmt=gif&from=appmsg)

放在两个赛季前，曼城在英超半场2比0领先，比赛基本可以提前预判结局，但现在时代变了，蓝月亮的统治力已经迅速下滑。易边再战，场上风云突变，利兹联突然觉醒，从升班马进化成战神。第49分钟，努内斯后场连续失误，勒温抓住机会抢射建功，为利兹联扳回一城；第68分钟，格瓦迪奥尔吃到黄点套餐，恩梅加点球被扑后补射扳平比分。


![图片](https://mmbiz.qpic.cn/mmbiz_gif/sAmI87QVQBTxdXSx52cQibHQ1TzmUlXthafZpw5B1b2ndZpB3GfnHWvtMGWXFAiaBTs2hRu95yGj5zexeA922jDw/640?wx_fmt=gif&from=appmsg)


![图片](https://mmbiz.qpic.cn/mmbiz_gif/sAmI87QVQBTxdXSx52cQibHQ1TzmUlXth8HsiaDs84G0U9TI6VZl0dViaqynk48ibBA0J3DLZLJrU3tB2VLVjUrEKg/640?wx_fmt=gif&from=appmsg)

下半场进行到一半，曼城的两球优势就化为乌有，此时蓝月亮显得慌乱无比，剧本眼见着就要朝着利兹联逆转的方向推进。作为蓝月亮头号前锋，哈兰德几乎全场隐身，总共只有一次射门。而关键时刻，是曾被质疑的曼城太子站了出来——第91分钟，福登横向摆脱后抽射建功，为球队实现了绝杀！


![图片](https://mmbiz.qpic.cn/mmbiz_gif/sAmI87QVQBTxdXSx52cQibHQ1TzmUlXthichZWR7ibAdjY0evz27Ee5gFBSC2u8wtX5icagb1gUMicjWZ5mKCGFCXCQ/640?wx_fmt=gif&from=appmsg)

头号射手连续三场萎靡不振，比分从2比0变成2比2再到补时打进绝杀，曼城球迷就这样体会了一次曼联拥趸一贯的心跳起伏，所幸蓝月亮最终还是有惊无险地拿下升班马。只是看过比赛内容的球迷都清楚，如果没有周中踢药厂的轮换，曼城真的未必能够拿下利兹联，难怪段子手们大呼“瓜帅具有先见之明”。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBTxdXSx52cQibHQ1TzmUlXthxkPiapO9LDQRia5M6OVr1icnRo1VRyCcUNl2AXia5nsnSZka6w31keklKA/640?wx_fmt=jpeg&from=appmsg)

数据统计显示，曼城已经连续赢得了最近六场的英超主场比赛，这也是他们自2022/23赛季在伊蒂哈德球场主场10连胜以来，在同一赛季中的英超主场最长连胜纪录。赛后蓝月亮功臣表示：“今天我对上场比赛充满渴望，我想证明自己仍然能够进球，对阵纽卡斯尔时我错失了一些机会，因此我想要在这场比赛中纠正这一点。”


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBTxdXSx52cQibHQ1TzmUlXthibH2bOybInN2oAWck2eXMTIlBNOyc3yu99uxvhnHO8icfhVHKU3BT6AQ/640?wx_fmt=jpeg&from=appmsg)

瓜迪奥拉赛后则表示：“由于我们下半场开场就丢了一球，大家都很沮丧。我们之前讨论过需要第三个进球来确保胜利，但足球就是这样充满变数。他们不断施压，我们再次丢球。但在足球比赛中，你无法像篮球那样叫暂停来调整，我们必须学会以不同的方式应对英超中的各种挑战。”


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBTxdXSx52cQibHQ1TzmUlXthL3tXrrOzfz68wNrujN5RWvNZqkRVcvJ4Zbiafb588STsKbaXELVsTlw/640?wx_fmt=jpeg&from=appmsg)

相比于阿森纳颇具统治力地拿下一场场胜利，曼城的三分来得是如此跌跌撞撞，而这样的差异最终体现在积分榜上，目前蓝月亮多赛一场依旧落后枪手4分。四连冠时期的强大防线已是过往，如今的蓝月亮正处于一个重建的时期，仅就险胜利兹联的比赛来看，曼城更现实的目标，或许只是争四而已……
