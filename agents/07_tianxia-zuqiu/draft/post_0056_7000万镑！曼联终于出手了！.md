# 7000万镑！曼联终于出手了！

**点上方蓝字“天下足球”快速关注****最有情怀的足球尽在这里****


布伦特福德有**“**神锋养成记**”**的习惯**，**沃特金斯如今成为了维拉的英超历史射手王**，**伊万**·**托尼则远赴沙特提前养老**，**两代**“**蜂王**”**的交集不仅是为三狮军团当过奇兵**，**其实也都是曼联爱而不得的猎物**。

****

**这个夏天**，**先后与二人并肩作战的姆贝乌莫以**“**后来者**”**的身份弥补了曼联的缺憾**，**随着经典的**“Here** **we** **go！”，**喀麦隆国脚正式下树**，**稍微让人意外的是**，**三度加价的红魔最终选择了溢价购买**（6500**万镑基础转会费**+500**万镑浮动条款**）。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBS6hOYsg2Et7ZLjt9mP6vEKaXdpuJjia7jDUoVJYULbhf1tfFxkZlichBrBmyJ5LCsmVEQAYuw1macg/640?wx_fmt=jpeg&from=appmsg)

**毋庸置疑**，**曼联求贤若渴的执着里夹杂着妥协的成分**，**毕竟姆贝乌莫当前的身价是**5500**万欧元**，**但他在**24-25**赛季的英超贡献了**20**粒进球和**7**次助攻**，**平均每**5**次射门贡献**1**粒进球**，**而加纳乔**、**霍伊伦和齐尔克泽的废材组合总计才贡献了**16**粒进球**。

****

**即使不用进球数作为价值参照**，**能在边锋**、**中锋和二前锋位置上切换的姆贝乌莫是典型的团队球员**，**难怪阿莫林志在必得**，**值得一提的是**，**布伦特福德主帅弗兰克在离任前就放出话来**：“**姆贝乌莫的替代者很难****找到**。”


![图片](https://mmbiz.qpic.cn/mmbiz_png/sAmI87QVQBS6hOYsg2Et7ZLjt9mP6vEKAVf32bLHu5AAzPJrQ9LONNcSkkO3LATaSp06jcEO8mNvnlo8fQibAicQ/640?wx_fmt=png&from=appmsg)

**在曼联举着爱的号码牌之前**，**阿森纳和热刺都曾试图招募过姆贝乌莫**，**前场万金油属性是其受宠的关键因素**，**但个人价值并不局限于此**。**据统计喀麦隆人上赛季的实际进球数比预期多**7**粒**，**高居英超第一**，**但他的场均射门次数只有**3.2**次**。

****

**这或许是意外之喜**，**然而姆贝乌莫单赛季**387**公里的跑动距离**、870**次冲刺跑**、1037**次无球跑动**，**则完美地反映了拼命三郎属性**，**值得一提的是**，**喀麦隆球星在上赛季亮相了**38**轮英超**，**踢满了其中的**37**场**，**堪称铁人**。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBS6hOYsg2Et7ZLjt9mP6vEKTkMNIsfKzYka8bZUDF5sKGkBgkImVwT3TaGsGyuuqXwVvmtl1zShFw/640?wx_fmt=jpeg&from=appmsg)

**位置多元**，**跑动积极**，**素质劲爆**，**长相酷似**NBA**巨星詹姆斯的姆贝乌莫变成转会市场上的**“**加钱哥**”**并不奇怪**，**费迪南德就认为喀麦隆球星是曼联的必需品**。**与此同时**，**在曼联以溢价引援的形式完成交易的背景下**，**姆贝乌莫难免会成为怀疑论的对象**，**要知道在为布伦特福德效力的四个英超赛季中**，**他只是在**24-25**赛季才完成了进球上双的**“**小目标**”，**这还得益于托尼离开后的战术倾斜**。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBS6hOYsg2Et7ZLjt9mP6vEKJdVvZ8LBf87OiaMMqMyztnrpKfuAwy5dnn1OrKIjGF0J7W3kTYKMicJA/640?wx_fmt=jpeg&from=appmsg)

**曼联有不破不立的重建态度**，**也相应地承受**“**人傻钱多**”**的质疑**，**就连葡萄牙体育的主席都忍不住看戏**：“**在我看来**，**库尼亚和姆贝乌莫的市场价值和实力都不如哲凯赖什**，**却以**7500**万欧元的价格进行谈判**。”**显然**，**这是葡萄牙体育为了最大化从自家前锋身上套现的说辞**，**然而对比论中的话题其实并不是没有道理**，**坊间在绯闻产生的第一时间就早热议过这笔交易的可能性**。

****

“**曼联当冤大头**”**的声音显然多于**“**捡漏成功**”，**别忘了姆贝乌莫与布伦特福德的合约明夏就到期了**。**对于出售型俱乐部布伦特福德而言**，**这是一笔不可错过的好买卖**，**对于忙着解决锋无力的曼联而言**，**这似乎是不得不吃的亏**，**试想下**，**奥斯梅恩和哲凯赖什都曾将欧冠资格设置为彼此合作的前提**。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBS6hOYsg2Et7ZLjt9mP6vEKyPx3XZcnlkr3kc8DghGcx74uJYBicHyORKPFGnibxB5YrcdQDjoEWwyQ/640?wx_fmt=jpeg&from=appmsg)

**外界的揣测与质疑并不妨碍姆贝乌莫进取心**。**他**16**岁就背井离乡**，19**岁虽感受了五大联赛的氛围**，**却也只是法甲出场**4**次的匆匆过客**，**在特鲁瓦的法乙时光中单赛季进球上双是容易被淡化的惊喜**，20**岁加盟英冠的布伦特福德也不足以形成转会市场上的热门话题**，**需要注意的是**，650**万欧元转会费在队史引援榜单上高居第二**。

****

22**岁完成英超首秀**，**在足总杯上完成了职业生涯第一个帽子戏法**，23**岁入选喀麦隆国家队是一种自我保护**，**毕竟挤不进人才济济的高卢雄鸡**，**并庆幸得到了征战世界杯的机遇**。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBS6hOYsg2Et7ZLjt9mP6vEKuSQ8EGuz7WDlDJz5yZvibn0bmrSXjztsRPicv34pR4VISvsBibib5Pic43w/640?wx_fmt=jpeg&from=appmsg)

**其实**“**天道酬勤**”**已经逐渐具象化**，**然而不满足给托尼做僚机的姆贝乌莫展示了自己的另一面**，**他渴望拥有更多的进攻主导权**，**他在赛后针对性练习点球**，**难怪被青训教练称之为**“**狂热的足球分子**”，**他通过国际象棋游戏训练大脑**，**甚至会在打网球和弹钢琴的动与静中培养多元化的自己**。

****

**在布伦特福德逐渐挑大梁之后**，**绯闻如期而至**，**甚至有人挖出了姆贝乌莫自小就是曼联球迷的身份**，**如今在双向奔赴的话题下**，**压力和激情一样如影随行**。**一旦无法在老特拉福德呈现布伦特福德时期的自己**，**高额的转会费会吞噬一切**，**拉什福德**、**桑乔**、**加纳乔**、**芒特**、**霍伊伦**、**奥纳纳**，**都是排在前面的**“**过来人**”。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBS6hOYsg2Et7ZLjt9mP6vEK6pXoic4ylVUpNBTl7Wnbckb2trraLKQczrXu0dj0Mz4icStb3JN5aic0Q/640?wx_fmt=jpeg&from=appmsg)

**姆贝乌莫在布伦特福德经历了英冠和英超的淬炼**，**交出了**242**场**70**粒进球**51**次助攻****的成绩单**，**也深刻了诸如双脚平衡和身体柔韧的印象分**。**在罗列其英雄主义瞬间时**，**他曾在对阵西汉姆联演绎了开场**37**秒闪电战**，**他的冲刺速度达到**36.63**公里**/**小时**，**也曾在对阵阿森纳**、**切尔西**、**纽卡斯尔**、**曼联时连续不手软**。

****

**事实上**，**姆贝乌莫在英超处子赛季就得到了克洛普的关注**，**也曾在去年被阿森纳视为帮萨卡减负的候选人**，**入选上赛季球迷票选英超的最佳阵容是布伦特福德生涯的完美总结**。**花了大价钱的曼联或许是幸运的买家**，**然而关于一入豪门深似海的话题并不会消失**，**也许这才是姆贝乌的**“**命门**”。
