# 曼联后悔了？都是命！

那不勒斯喜欢为曼联失意人“送温暖”，最近一个绯闻对象就是逐渐边缘化的梅努，而最近一个实现“人挪活”的是霍伊伦，但真正“打样”的人是2024年夏天加盟的麦克托米奈。


在个人的意甲处子赛季中，曼联旧将并没有如履薄冰的感觉，反而在34场比赛中贡献了12粒进球和4次助攻，8次首开纪录支撑其“急先锋”的角色，但最丰硕的成果是荣膺了意甲最佳球员&捧起了意甲冠军。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBRTg7EmaShjnrJ1EyGd6RP2ibHfardncA0ITLTWYEhXy0KfDgqkObia60TCNml3WlBRYPXogGZf0XEw/640?wx_fmt=jpeg&from=appmsg)

麦克托米奈将意甲之旅形容为“一场梦境”，喜欢抓素材的媒体早就将苏格兰人标注为“真香”系列之一，毕竟3050万欧元的转会费物超所值，而意大利媒体直接将这笔交易形容为“世纪抢劫”。


即便在巨星堆里属于相对的配角，然而并不会改变麦克托米奈的赢家底色，要知道，他是24-25赛季五大联赛进球最多的中场，他刷新了苏格兰球员单赛季的意甲联赛进球纪录，职业生涯首次荣膺金球奖提名被其形容为“铭记一生的美好”。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBRTg7EmaShjnrJ1EyGd6RP2pYrtkeVrmxT3unqXPFKomwZTia78JTre6BLtuIwuYooCXLFZ1z3Vbog/640?wx_fmt=jpeg)

从曼联到那不勒斯，并不单纯是距离上的跨越，而是麦克托米奈找到了新生的拐角点。作为曼联的青训精英，他在255场比赛中贡献了29粒进球和10次助攻，捧过足总杯和联赛杯冠军，也过了一把队长瘾，然而在曼联的重建计划中属于“边角料”，或者说崇尚巨星政策的红魔习惯性忽视自家人，身披那不勒斯球衣的麦克托米奈释放过怀才不遇的情绪：“我的优势是突入禁区、进球和破坏防线，但在曼联我总在6号位或中卫，这从来不是我喜欢和擅长的位置。”


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBRTg7EmaShjnrJ1EyGd6RP2rQibygHbvXUQBI2kjiaLs7qXMA2QveDia4avxUicxc425zrzia7oiamHnlUg/640?wx_fmt=jpeg&from=appmsg)

在那不勒斯，麦克托米奈被孔蒂设定为箭头人物，准确说”被定位在一个特定项目的核心位置”，数据不会说谎，24-25赛季的苏格兰人45%的时间集中在对方半场，累计117次禁区触球和场均2.8次射门机会，最大化地保障其频繁冲击禁区并保证进球。孔蒂敢为天下先？或者说麦克托米奈只差一个展示自己的平台：“他在曼联从未有过核心角色，而我们在这里给了他这个机会。”


于是乎，麦克托米奈被曼联耽误的话题在持续发酵，苏格兰人临别之前坦诚“自己是曼联永远的球迷”，这或许是刻意保留的体面，而在老特拉福德当过客的霍伊伦虽是租借之身，却没有留面子：“在那不勒斯我感觉很轻松，与曼联时期完全不同。”


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBRTg7EmaShjnrJ1EyGd6RP2rSzhDeZWDUHkXxZNuDQtHoHqgXiaoicB3IqLSCDLedZMhNk1rQvj55Lw/640?wx_fmt=jpeg)

麦克托米奈效力曼联的最后一个赛季打进了10粒进球，并成为了队史首位在英超联赛的补时阶段完成梅开二度的球员，这本是一个水到渠成的果实，要知道提拔过麦克托米奈的穆里尼奥早在2018年预言“他的成功是必然的”，并将其形容为“一名现代型中场”。


此一时彼一时，羽翼渐丰的苏格兰人被混乱中的曼联设定为高位套现的筹码，以至于另一个曼联老熟人索尔斯克亚意难平：“他们怎能卖掉这样的核心球员？”讽刺的是，阿莫林一直在寻找多元性的中场，就连莱因克尔都在抨击曼联的转会决策：“麦克托米奈正是我认为能在阿莫林体系中发挥作用的球员。”


![图片](https://mmbiz.qpic.cn/mmbiz_png/sAmI87QVQBRTg7EmaShjnrJ1EyGd6RP2fCcib6rnRkSeUTnnYYDhxicBHfr25bCmP1MicSTRBE7iahx9HA3VEWvx0A/640?wx_fmt=png&from=appmsg)

在麦克托米奈离开之前，曼联尚且用英超第8的排名眺望下一个远方，但在苏格兰人远走那不勒斯之后，曼联并没有如愿恢复元气。上赛季沦为保级球队（排名第15），本赛季至多演绎了另类的“攻守平衡”（进19球失19球）。


对比中伤害人人皆知，这倒不是托大了麦克托米奈的影响力，而是深刻了曼联的“糊涂账”，身体素质欠缺火候的芒特和技术粗糙的乌加特较麦克托米奈如何呢？至少后者具备了在压力下接球和推进，并通过身体保护球权的优势，当曼联沉迷于对巨星的“拿来主义”时，英超名宿哈曼就坚持“麦克托米奈与赖斯有相似之处”的观点。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBRTg7EmaShjnrJ1EyGd6RP2Cic1KdWY8MTy6ibT5d73KCOJXn00L4ufsIvVjDT0fMZpQ5M1s5wKTuwQ/640?wx_fmt=jpeg&from=appmsg)

曼联后悔了吗？这是一个扎心的问题，也更应该庆幸那不勒斯的“慧眼识珠”和“对症下药”，麦克托米奈的穿插跑动是锋线创造空间的关键，或许关于昙花一现的怀疑论也在零散地出现，然而新赛季的苏格兰中场依然用5粒进球和2次助攻为那不勒斯掌舵，尤其是在卢卡库和德布劳内养伤期间体现的淋漓尽致。


或许那不勒斯的卫冕之路异常艰难，但作为适配型的麦克托米奈其实已经习惯了竞争模式：“我的心态就是时刻待命，随时抓住机会。”欧冠对阵埃因霍温上演梅开二度，意甲对阵国米贡献凌空斩，都是“我准备好了”的注脚。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBRTg7EmaShjnrJ1EyGd6RP2wWoD3b6lowSwHTwg5VVGHjXCaeWqaj0MSWQFquC3ezbcM9KyEMUpVA/640?wx_fmt=jpeg&from=appmsg)

类似的成长模式其实在国家队中似曾相识，羽翼未丰时，麦克托米奈被人才济济的三狮军团忽略情有可原，但2018年得到苏格兰国家队征召的他也并非一步登天，准确说从右后卫起步的麦克托米奈一步一步地成为全民偶像。数据显示，自从2023年以来，麦克托米奈为苏格兰国家队打进了12球，进球数量至少是其他任何队内球员的两倍。


最近一次的英雄主义体现在对阵丹麦的世预赛中，苏格兰拿到了2026年世界杯资格，麦克托米奈打进了一粒美如画的倒钩，值得一提的是，他在倒钩瞬间脚尖高度达到了惊人的2.53米，超越了奥努阿楚的2.41米和C罗的2.38米，一举刷新了足球史上最高倒钩进球纪录。 


![图片](https://mmbiz.qpic.cn/mmbiz_png/sAmI87QVQBRTg7EmaShjnrJ1EyGd6RP22ics65rYLxpORHRhgKwxzeoufrHfqSsFsUAZianD7YZjj9OXCvXhdKMg/640?wx_fmt=png&from=appmsg)

从曼联青训精英到那不勒斯大腿，从俱乐部偶像到国家队英雄，时间终究为麦克托米奈提供了“平反”的机会，值得一提的是，当下的苏格兰中场身价达到了5000万欧元，创造了个人职业生涯新高，只不过他好像一直在做自己：“有时候你只需要享受足球，带着笑容踢球，放松心情。”


一次转会，雨过天晴，“当我想到苏格兰，我想到高原，麦芽和威士忌”，这是一句名言，也许自此以后，多了一个麦克托米奈！
