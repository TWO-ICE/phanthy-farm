# 活久见！曼城摆大巴！被绝平！

一边是遭遇混乱赛季希望重回正轨的曼城，一边是连续三年亚军想要登上王座的阿森纳，一场英超天王山之战，就这样在万众瞩目中于酋长球场打响。哈兰德的进球为曼城赢得开局，马丁内利的绝平让枪手在主场全身而退，一场1比1的较量，唯一的赢家似乎只有坐山观虎斗的利物浦——五连胜的红军，进一步拉开了和竞争者们的分差。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBR1Oaz1RxaQ33DuWSgOLmibOtZZKkYuTWicD2C2yLeNrRMDMib4CzJD6QW5coXPRrRwxv6e2oHSOnhUw/640?wx_fmt=jpeg&from=appmsg)

阿森纳和曼城的对决，过去几个赛季堪称“英超决赛”，两支球队都有争夺冠军的实力，只是枪手每一次都与王座失之交臂，先是坐看四连冠加冕的蓝月王朝，上赛季又目睹了利物浦的冠军复兴。只是曾经被曼城手拿把攥的阿森纳，过去两个赛季已经让形势扭转，阿尔特塔的球队面对蓝月亮已经连续五场不败。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBR1Oaz1RxaQ33DuWSgOLmibOw6wbogLjNqtF7UyMribfQSScXHgyg4EtCDG3KZ2T0icjvZl6OCzicVHVw/640?wx_fmt=jpeg&from=appmsg)

或许是阿森纳过去两个赛季过于强势，且此番又是客场作战，瓜迪奥拉在酋长球场祭出了令人匪夷所思的战术。开场仅仅9分钟，曼城的反击取得成效，赖因德斯送出助攻，哈兰德推射破门。这是哈兰德英超生涯的第91个进球，曼城队史仅次于传奇阿圭罗，同时也追平索尔斯克亚，并列成为英超进球最多的挪威球员。


![图片](https://mmbiz.qpic.cn/mmbiz_gif/sAmI87QVQBR1Oaz1RxaQ33DuWSgOLmibOgsrNoobkwJnjQxjGLY3djuqQIVu1NFMbucKQVzWV5KD4My6a8wtupw/640?wx_fmt=gif&from=appmsg)

取得领先之后，曼城并未乘胜追击，在零星进攻之后，就专注于摆起铁桶阵，随之而来的是双方逐渐激烈的拼抢，加布里埃尔球鞋被踩掉也只是成了小插曲，特罗萨德和B席的冲突散发着火药味。赖斯、马杜埃凯、卡拉菲奥里们连续威胁着曼城的球门，多纳鲁马成为了蓝月亮防线最忙碌的那一个。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBR1Oaz1RxaQ33DuWSgOLmibOOuFEUX4P7965iaicPxgs2NrfRZyFGia7KYJCTrSGE49M3FKYaK3shm3icA/640?wx_fmt=jpeg&from=appmsg)

进入下半场，比分落后的阿森纳换上萨卡和埃泽，曼城则用努内斯换下胡桑诺夫作为应对，主攻的依旧是阿森纳。埃泽和特罗萨德连番发难，场边的瓜帅也因为坐不住而吃到黄牌。或许是迟迟无法扳平比分，阿森纳踢得愈发焦躁，犯规动作频出，而裁判也多次做出值得商榷的裁决。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBR1Oaz1RxaQ33DuWSgOLmibOVSF0OfAyicThYvDI3QIvXx3ZmibaxGKbQoU0pSBl9L3iaQwkOfzxUibicVQ/640?wx_fmt=jpeg&from=appmsg)

阿森纳大兵压境，曼城的大巴摆得愈发靠后，连多纳鲁马都因为拖延时间吃到黄牌。眼见时间所剩无几，枪手的进攻变得更加疯狂，鲁本-迪亚斯和多纳鲁马在压迫下险些沟通失误送出大礼。随着常规时间逐渐耗尽，战术行将成功的瓜帅甚至兴奋得亲了第四官员一下，然而傻眼的瞬间马上到来——第93分钟，马丁内利挑射破门，阿森纳完成绝平！


![图片](https://mmbiz.qpic.cn/mmbiz_gif/sAmI87QVQBR1Oaz1RxaQ33DuWSgOLmibOvoSF351bibjeAHjv0Rec7Bhs01ENBFoZSg8vrianThO5mzhy88iaaI4mA/640?wx_fmt=gif&from=appmsg)

就这样，曼城拥有着黄金开局，阿森纳争取到刺激的结尾，只是比赛的过程让人感到错愕。此役蓝月亮控球率仅有33%，角球比更是可怜的1比11，全场射门也只有5脚。昔日以强势和控制著称的瓜迪奥拉，竟然打出了穆里尼奥式的大巴风格，这样的曼城让人陌生，瓜帅似乎也在颠覆着自己的足球哲学。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBR1Oaz1RxaQ33DuWSgOLmibOyzxLvbIBbVhEoiaQmdOTn3JfF3KCT9jfBEtbrkCCW4J3MFKhSWw7L2w/640?wx_fmt=jpeg&from=appmsg)

赛后被问到战术的话题，瓜帅的回答十分坦诚，他表示：“因为阿森纳很强，他们在大多数防守环节都做得更好。而且我们周四刚踢完对阵那不勒斯的比赛，只有三天的恢复时间，而他们有五天。他们多年来都是一支非凡的球队，但我们展现出的韧性和斗志，以及这一周——我们不会忘记，加上对阵曼联和今天的比赛，这是极其艰难的一周，而我们做得非常好。”


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBR1Oaz1RxaQ33DuWSgOLmibO5qqZzekc0H68S0JanBVWnCqlZ7w8lwsxfMuEtkYzaICIbo22iarywfQ/640?wx_fmt=jpeg&from=appmsg)

关于摆大巴，瓜帅同样给出了自己的看法，说道：“10年摆一次也不错，对吧？这很好。我必须用另一种策略再一次证明自己，现在我是一支反击型球队。”不管怎么样，人们现在看到的是一支陌生的曼城，而战术上的改变似乎并未带来好结果，因为5轮过后蓝月亮仅积7分，创下了2006/07赛季以来的最差开局。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBR1Oaz1RxaQ33DuWSgOLmibOIGWgguegfLu6woba3CEcBqXfd0vuVjgR8Vo0ENSb0Ycg85LzB12DsA/640?wx_fmt=jpeg&from=appmsg)

当然，5轮过后积10分的阿森纳也没有好到哪里去，他们已经被争冠最大竞争对手利物浦甩开5分之多。5轮过后5分领先，这种情况在历史上只出现过3次，而利物浦独占2次。且上次利物浦获得如此开局情况最终成功夺冠。OPTA也对英超各队夺冠概率进行预测，利物浦59.81%居首，阿森纳23.83%位居次席。本赛季，枪手还能实现翻盘吗？
