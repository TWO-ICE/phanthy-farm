# 重磅！39岁神锋重返意甲！

佛罗伦萨近几个意甲赛季的成绩相当稳定，“花小钱办大事”是一个关键因素。2022年用1500万欧元签下了多多，如今巴西后卫是一众豪门的目标，2024年耗费1300万欧元得到了莫伊塞·基恩，前尤文前锋在上赛季用25粒进球重新介绍自己，一度失业446天的德赫亚在上赛季完成了11次零封，享受“真香”的佛罗伦萨奉上了三年续约合同。


佛罗伦萨在2025年的夏窗计划复制类似的美好，他们将意甲老熟人哲科视为潜在猎物。据传，彼此之间的距离只有一步之遥，200万欧元的年薪和2年合约着实反映了佛罗伦萨的诚意，也顺利将竞争对手科莫和博洛尼亚PK下去了。


![图片](https://mmbiz.qpic.cn/mmbiz_png/sAmI87QVQBS51MkZvUu4CMXb0P4zHucep4kqNwF7E0ZsPEMYP9qBElNRZjOcJnzOQUMcCUJjNlrjgTH8vaDxDA/640?wx_fmt=png&from=appmsg)

亚平宁半岛一贯流行老兵不死的剧情，但1986年出生的哲科难免会陷入“尚能饭否”的怀疑论中，这并非偏见，而是惯性思维，毕竟时间经常会偷走一系列天才或者巨星的选择和骄傲。然而哲科并不是凭前意甲金靴的头衔赢得佛罗伦萨的青睐，在远离五大联赛的日子中，波黑球星累计为费内巴切出场了99次，贡献了46粒进球和18次助攻。即使未能用联赛冠军完美地总结伊斯坦布尔时光，但哲科并未辜负420万欧元的年薪，也没有让年龄因素成为“拦路虎”。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBS51MkZvUu4CMXb0P4zHuceGppbcvZ2HXV03UcbDVL63RXJv0BdichM7okCxwOaXsp1icwmsd77ic2AQ/640?wx_fmt=jpeg&from=appmsg)

球迷有印象的话，穆里尼奥在费内巴切的执教首秀差一点翻车，为新帅续命的正是上演帽子戏法的哲科。准确说在两个不完美的赛季中，波黑人在一定程度上充当了费内巴切的遮羞布，以至于穆里尼奥在送别哲科和同时离队的老将塔迪奇时真情流露：“我与许多职业球员打过交道，但我从没有能遇到过比你们更敬业的。”精神转移法？事实上费内巴切球迷持续抗议了俱乐部的逐客令，奈何致力于年轻化的土耳其豪门听不见群众的呼声！


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBS51MkZvUu4CMXb0P4zHuceucMw70wdamSeV0mExzFd5WTxETMrgmlrCoGDTG3OkAIK59P0hO8uaA/640?wx_fmt=jpeg&from=appmsg)

哲科属于全能型前锋，但并非完美的，抛开年龄和伤病因素的制约，波黑人不乏掉链子的时刻，甚至会被费内巴切的管理层放大。对阵贝西克塔斯，他挥霍了三次进球良机，拿到了全场最低分，对阵哈塔伊体育，他在补时阶段踢飞了点球，错失了“传射建功”的好戏。进一步讲，即使上赛季为费内巴切贡献了14粒联赛进球，但平均每7.6次射门换回一粒进球的效率让寻找接班人的任务持续进行时，事实上27岁的亚伯拉罕和25岁的戴维不仅具备了年龄优势。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBS51MkZvUu4CMXb0P4zHucexicwibxcwIH56DV9Aqu8I9OJ8Qic6koU94vTIUWptjjWvCE0Dc9kwJQOg/640?wx_fmt=jpeg&from=appmsg)

哲科本意是在费内巴切结束绿茵生涯，加盟之初他就表达了相见恨晚的情绪，在合约到期前还表达了从头再来的勇气，两段发言中都展示了自己的团队精神：“我不只是想取得进球，还要尽一切可能帮助我的队友。”抛开进球和助攻，哲科在本赛季场均贡献3.2次争顶，然而在成为局外人时，功劳和苦劳似乎均被抹杀了，值得一提的是，波黑人在告别信中仍将费内巴切形容为“心爱的俱乐部”，可惜土耳其豪门选择在训练基地的食堂简单地送别功勋，穆里尼奥为此炮轰了管理层的不作为。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBS51MkZvUu4CMXb0P4zHucekYNjFRjrrj0vCMvmowj57lv1lHZRDRcm3bnbwt9Jc2RWZZibmVmRORA/640?wx_fmt=jpeg&from=appmsg)

哲科并不会与往事纠缠不清，在其22年的职业生涯中不止一次经历离别和背叛，但也借此明确了“我还没有退役计划”的英雄志。意甲是熟悉的天堂口，哲科在罗马购置了房产，而他的妻子喜欢佛罗伦萨的文化，从个人履历上说，他曾在意甲亮相了268次打进了107球，效力罗马时拿到了意甲金靴，入选过意甲最佳阵容，效力国米时登上过欧冠决赛的舞台，拿过意大利杯冠军和意大利超级杯冠军。佛罗伦萨现阶段不具备昨日重现的实力，但对于哲科而言，能当“回锅肉”已经是另类的成功。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBS51MkZvUu4CMXb0P4zHuceVpGx99PxRic3kWmRYKjxghOBafLwBBKqT8sTMFwxZ16HaRjCo8kf3pg/640?wx_fmt=jpeg&from=appmsg)

靠履历和情怀显然无法迎合“紫百合绽放”的主题，然而哲科的责任感和年轻感何尝不是稀缺品。在费内巴切效力时，队医就透露波黑人的肌肉含量比25岁时还高出3%，每天加练30分钟的瑜伽，用餐精确到克数的三文鱼配藜麦，回归熟悉的意甲势必会最大化贡献自己的光和热，别忘了在最近三个赛季的俱乐部赛事里，哲科的缺勤率仅为7%。


维埃里就曾将哲科形容为“可以踢中场的前锋”，而意大利媒体早就预热了故人归来的剧情：“哲科是一名传统中锋，他能给队友做球，让比赛变得更加流畅，并且能为队友在前场开拓出空间。”昔日效力国米时，哲科与劳塔罗的组合相辅相成，莫伊塞·基恩会借助老将的剩余价值打磨最好的自己吗？这件事值得探讨和验证。
