# 被打爆了！后悔去皇马？

皇马在西甲是领头羊，隐患却与日俱增，情绪化的维尼修斯、进球荒的罗德里戈，没球踢的恩德里克，均是“行走的炸弹”，当然还有一个水土不服的阿诺德。自今年夏天登陆伯纳乌以来，英格兰球星虽然出场了13次，然而累计亮相时间只有652分钟，有沦为局外人的趋势，这是一件意料之外的事情，要知道皇马在今夏为了推动阿诺德提前加盟，为此利物浦额外支付了1000万欧元。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBTDgXrpmgD0ZU6bpORZsM82PxP5DjWXnmgU89NKoez2fLicfNicJQAk3aFFaksKOia80GlubtKqamoWg/640?wx_fmt=jpeg&from=appmsg)

在确定加盟皇马时，阿诺德就展示了“我本可以”的自信，以至于在记者的话筒面前大谈理想主义：“我可以掌控比赛节奏，决定从哪里进攻、怎么进攻，以及以什么节奏进攻。”坦白讲，这是他在利物浦时期积攒的勇气，个人英超生涯的长传成功率高达68.3%，就上赛季的英超而言，场均完成了3.2次过人，贡献了7次助攻，7500万欧元的身价并不能总结利物浦的幸福，斯洛特的话更直接：“我对阿诺德真的很满意，就像我对萨拉赫和范迪克也很满意一样。”


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBTDgXrpmgD0ZU6bpORZsM82qjlfGShtibImjcx1wmdib7Cvv06xfvyytofQ8Y576Achmh5IW9rV2GHw/640?wx_fmt=jpeg&from=appmsg)

从利物浦到皇马，这是阿诺德的心之所向的选择，用他的话说：“我是看着皇马连续赢得三座欧冠冠军长大的。”而皇马对右后卫的补充本身就是计划内的事情，毕竟卡瓦哈尔年事已高&伤病渐多，作为西甲新人的阿诺德曾在克洛普麾下短暂担任过核心组织的身份，在需要和被需要关系的发酵下，英格兰人既能替补解决隐患，似乎也具备了提供意外之喜的潜力值，西班牙媒体甚至幻想过阿诺德和姆巴佩的梦幻连线。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBTDgXrpmgD0ZU6bpORZsM82zia7BuFEiaDkDqybqFBEtezpL5gKUhEoJkNbzyeic25SibIZIaReH3TM1w/640?wx_fmt=jpeg&from=appmsg)

“如愿以偿”是一件难度颇大的事情，作为自2016-17赛季首次亮相，在五大联赛中助攻最多的后卫，阿诺德为银河战舰暂时只贡献了2次助攻，并且都集中在世俱杯的舞台上，换而言之，他远远没有进入如鱼得水的模式中，甚至颇为狼狈。


在皇马被埃尔切逼平的比赛中，久违地踢满90分钟的阿诺德全场丢失球权达到了25次，纵然贡献了18次传中，然而在平局面前远远达不到“平衡”，事实上在皇马丢球后，阿诺德就用怒踢皮球的方式发泄了情绪。


![图片](https://mmbiz.qpic.cn/mmbiz_png/sAmI87QVQBTDgXrpmgD0ZU6bpORZsM82PC5aOZ6o9GIQNyEA1yGZyn2OeauYMiasgGtl0sYu29pMbFBowZ35Sfw/640?wx_fmt=png&from=appmsg)

如果这是偶一为之，皇马球迷不必杞人忧天，可三个月前的阿诺德就是掉链子的主角。在西甲首轮对战奥萨苏纳时，相较于0射门的数据，70分钟就丢失了15次球权且只有1次成功对抗的阿诺德才是“致命的缺陷”，拿到全场最低分半点不由人。


三个月的时间一晃而过，阿诺德的防守只退不进。原本准备退位让贤的卡瓦哈尔即使避不开伤病的羁绊，却在对比下成了攻守兼备的后卫模版，并且曾面对面地向阿诺德比划过防守站位，可惜没有实现“以老带新”，更讽刺的是，阿隆索曾以为一个全新的阿诺德会在国际比赛中恢复元气，但最终重复了被深渊凝视的尴尬。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBTDgXrpmgD0ZU6bpORZsM82rJic5QRd8kSy3gZWI3egHVQ71DkG35hk3X5z1jRrudxyrNzicG7yYeGg/640?wx_fmt=jpeg&from=appmsg)

替补上场或被提前换下，阿隆索声称“这是对阿诺德的保护”，长此以往的话，这将变成惯性的惩罚，事实上从来不护犊子的皇马球迷已经用嘘声“招待”英格兰球星。坦白讲，昔日在利物浦的阿诺德就是一个漏勺，对手针对他的防守反击成功率高达43%，只不过当时的阿诺德会用精准的传球最大化“扬长避短”。


此一时彼一时，在皇马攻守两端一团糟的阿诺德已经消耗了主帅的信任，《马卡报》直接用“定时炸弹”形容他的拙劣防守，要知道，无球状态下的阿诺德平均每场丢失了5.3次对抗。库尔图瓦曾赞誉过阿诺德的脚法无可复制，但再优秀的比利时国门也无法彻彻底底为西甲菜鸟“擦屁股”。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBTDgXrpmgD0ZU6bpORZsM82CV1Z9jGbicSOzJYv9EnicTVyXpK642kywKHJxSTmrwHddQeJDx9WicxBg/640?wx_fmt=jpeg)

皇马不至于将阿诺德“一棍子打死”，姆巴佩的懒散和维尼修斯的情绪，都是让阿隆索头疼的问题，但西班牙教练总是用“精神按摩”的方式解决问题。当阿诺德被卷入风口浪尖时，阿隆索抛出了“他的防守问题需通过团队协作解决”的观点，贝林厄姆也以“我们需要适应他的节奏”的口气力挺同胞。


只是对于球迷来说，拿着28万周薪的英格兰球星似乎配不上皇马的选才标准，不由得想起法国名宿佩蒂特点评利物浦时期的话：“阿诺德的表现不像一名后卫，他很讨厌防守。”


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBTDgXrpmgD0ZU6bpORZsM82U9alLcq05G8daCxHeHAPoVPgggvibm4tpKq1YZZycOm5DNIlicVtHDJg/640?wx_fmt=jpeg&from=appmsg)

如果不离开利物浦，根正苗红的阿诺德势必会成为队史的另一个标杆，但往事已矣，甚至延伸了“爱之深，恨之切”的剧情，在以皇马球员身份与利物浦对决时，只亮相10分钟的阿诺德遭遇了6万球迷的11次嘘声。倘若能在皇马用犀利的传球稀释熟悉的陌生人头衔，阿诺德并不觉得这是一种损失，然而逐渐成为高薪累赘时，英格兰人也许失去的不止是利物浦的爱。


![图片](https://mmbiz.qpic.cn/mmbiz_png/sAmI87QVQBTDgXrpmgD0ZU6bpORZsM82lpZ421RapW4E3tiaoO1cJJ0tibJbnwdEaPM5mibiayvfTwp3LjL3lv63eA/640?wx_fmt=png&from=appmsg)

按照在皇马的竞技状态，图赫尔大概率将阿诺德排除在2026年世界杯的大名单，事实上后者只在德国教头麾下亮相了1次，他将切尔西的里斯·詹姆斯视为右后卫的首发人选，值得一提的是，图赫尔在5月份时就没有给阿诺德面子：“我看得出来，有时候他过于依赖进攻，而不注重防守纪律以及球场上的拼搏。”


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBTDgXrpmgD0ZU6bpORZsM825MDkFrrqOUwSUIibaYAvd1vt6gMurd8Y1j8aLwQA5F3v0TPktuyWaNA/640?wx_fmt=jpeg&from=appmsg)


加入皇马拿了高薪，冠军或许不会远，但利物浦的往事被珍藏，世界杯的前景会黯淡，也许阿诺德会打阶段性的一场漂亮的翻身仗，但时间才是真正的标尺。
