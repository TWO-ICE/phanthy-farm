# 皇马看走眼了！

**点上方蓝字“天下足球”快速关注****最有情怀的足球尽在这里****


这个夏天的皇马经历了剪不断理还乱的动荡**，**罗德里戈的离队绯闻和维尼修斯的续约问题就是两大核心话题**，**但并不意味着其他人就能稳坐钓鱼台**。**恩德里克在最近享受了**19**岁生日的欢喜**，**然而巴西少年在伯纳乌的明天相当模糊**，**复发的****大腿肌腱****伤势只是稍微羁绊了出头的机会**，**在世俱杯闪耀的年轻人贡萨洛**·**加西亚则迅速挤压恩德里克上位的空间**。**皇马名宿莫伦特斯就直言**：“**我希望恩德里克被外租**，**而贡萨洛接替他的角色**。”


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBSBicfMpc9dnNXf6ia21RfKbFR1cYqaKCX1BnTMuHuibOsgI39BjXpvlzeicNXFoJk2XiaULDFTaMib1iaUw/640?wx_fmt=jpeg&from=appmsg)

**皇马对恩德里克的期望毋庸置疑**，4750**万欧元的转会费相当具备分量**，**然而在巴西足坛被吹捧为**“**罗纳尔多接班人**”**的天才只能在皇马的替补席感慨一入豪门深似海**。**据统计**，**恩德里克上赛季在各项赛事中累计才捞到了**8**次首发出场的机会**，**西甲的成绩单更是惨不忍睹**——**出场**352**分钟贡献**1**粒进球**。

****

**这不奇怪**，**在姆巴佩**、**维尼修斯和罗德里戈组成的豪华锋线群中找存在感本身就是一桩难事**，况且他们在名气、**经验以及实力维度的比较中远远将后起之秀甩在身后**，**即使恩德里克的速度**、**力量和爆发得到了外界广泛的赞誉**，**但**“**长江后浪推前浪**”**的故事也存在一定的滞后性**，**甚至希望越大**，**失望越大**。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBSBicfMpc9dnNXf6ia21RfKbF8OfVa0DQR9WC6kaU4UQ0ghue5TXShdQ8lMu8AekHiapiaOTtcwcfqWmA/640?wx_fmt=jpeg)

**恩德里克是一个有上进心的少年**，**在正式加盟皇马之前就学习了几个月的西班牙语言**，**在与维尼修斯和罗德里戈一起训练时也会主动**“**取经**”，**他从巴西带来了自己的私人健身教练**，**宅在家里时就反复观看比赛录像**，**以便纠正自己的动作**。

****

“**恩德里克将时间都投入到了足球上**”，**只是兑现天赋的势头并不明显**。**安切洛蒂曾点评过他的控球欠缺稳定性**，**皇马的内部人士直言**“**他还未掌握战术职责**”。**试想下**，**即使罗德里戈也被动地离开自己擅长的舒适区**，**甚至坐在替补席上闹情绪**，**还在摸石头过河的恩德里克如何一步登天呢**？


![图片](https://mmbiz.qpic.cn/mmbiz_png/sAmI87QVQBSBicfMpc9dnNXf6ia21RfKbFDkSDQ1KtHCbG635Lb8YX3fccmsHydD1jhHqia7jny4nTcEWeuQtSjWw/640?wx_fmt=png&from=appmsg)

**能圆**“**儿皇梦**”**是一件幸福的事情**，**恩德里克在加盟皇马的新闻发布会上流泪过**，**在替补席上煎熬时**，**他也曾用**“**为皇马效力是一种荣誉和一种挑战**”**的口吻给自己打气**。**如今当皇马自家青训贡萨洛**·**加西亚被媒体誉为**“**夏季最佳引援**”**时**，**还需**8-10**周才能完全康复的恩德里克自然会有危机感**，**传闻在世俱杯期间**，**他的经纪人与皇马**CEO**探讨过今夏离开皇马的可能性**。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBSBicfMpc9dnNXf6ia21RfKbFQAZvTrtgcCUQmYPHc77yicDCu8ib90xQo4fcTf4X5NdVBXEFYSOd05mA/640?wx_fmt=jpeg&from=appmsg)

**被巨星堆压制**，**尚且有学习的欲望**，**被年轻人**“**弯道超车**”**时**，**恩德里克似乎失去了竞争的动力了**，**或者说已经明确不接受租借模式的巴西少年在皇马被需要的价值在递减**，**在这一点上**，**恩德里克很容易找到参照物**——**另一个罗纳尔多接班人罗克**。

****

**提前半年加盟巴萨的罗克累计才出场了**353**分钟**，**在哈维和弗里克两任主帅麾下都没有展示原来的自己**，**即使租借皇家贝蒂斯时回暖过**，**但最终的结局是**20**岁就落叶归根了**，**这是巴西天才的悲剧**，**也是巴萨的及时止损**，《**马卡报**》**是这样点评操作的**：“**这是一次回收成本**、**保持财政平衡的教科书操作**。”


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBSBicfMpc9dnNXf6ia21RfKbFUxT4ZpQZefDhklQyBusvOWmXK8D5FrMQHmz6rib8S8lPZw2lVtvPsng/640?wx_fmt=jpeg&from=appmsg)

**恩德里克未必会在罗克身上找相似的缓冲点**，**毕竟加盟帕尔梅拉斯的巴萨旧将并没有走出困境**，**反而在世俱杯上多了一次出丑的机会**——5**场**0**进球**0**助攻**，**对于恩德里克而言**，“**回炉深造**”**是一门技术活**，**甚至会重蹈覆辙**。

****

**皇马同样具备了二次定夺的选择权**，**新帅阿隆索已经将新宠贡萨洛形容为**“**典型的**9**号球员**”，**而因伤错过与新帅磨合的恩德里克相应地处于竞争劣势**，**虽然媒体建议将巴西人放置在右边锋的位置上**，**但罗德里戈都在牺牲的区域**，**经验尚缺的恩德里克能挑大梁吗**？


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBSBicfMpc9dnNXf6ia21RfKbFibaUElSURqH58iciaSNGecaib5QUXRWAVPx90ehyicL4tlL4Tiaqk09UfGnA/640?wx_fmt=jpeg&from=appmsg)

**前途未卜时**，**恩德里克会在旧时光中给自己找信心**。**欧冠首秀对阵斯图加特替补出场建功**，**并以1**8**岁零**58**天的****年龄超越劳尔**，**成为皇马队史正式国际比赛中最年轻的进球者**。**国王杯上与马竞神锋阿尔瓦雷斯共享赛事金靴**，**也成为了自**C**罗以**，**来第一位单赛季在西班牙国王杯至少打进**5**球的皇马球员**。**如果扩充至整个赛季**，847**分钟斩获**7**球**（**每**121**分钟**1**球**）**的效率对于西甲菜鸟而言并不差**，**毕竟间歇的上场机会和凌乱的上场时间或多或少地打乱了成长的节奏**。**


![图片](https://mmbiz.qpic.cn/mmbiz_png/sAmI87QVQBSBicfMpc9dnNXf6ia21RfKbF1iczSHIuYGbErk0bHZMm1EPYD9gXwz5G0nW2lvKGOn0peW1w3j4pWYA/640?wx_fmt=png&from=appmsg)

（曾用**10**分钟打进皇马首球**）

****

**尤文和切尔西曾释放出培养恩德里克的信号**，**然而绯闻主角不接受租借提议**，**皇马也曾坚定地将巴西人视为潜力股**，**但留守的代价是先接受更残酷的竞争**。**进退两难是现实的问题**，**但学会妥协也是一种明智**，**毕竟恩德里克的下一阶段的梦想是参加**2026**年世界杯**，**当出场时间得不到保障时**，**聚光灯并不会照在他身上**。

****

**值得一提的是**，**恩德里克在这个夏天举办婚礼和过生日是最为轰烈的两件事情**，**或许在一定程度上冲刷了昨日的悲伤和明天的不确定**，**但愿成家的巴西天才能真正意义上**“**立业**”！
