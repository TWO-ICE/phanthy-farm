# 疯了！神锋去沙特赚钱！

**点上方蓝字“天下足球”快速关注****最有情怀的足球尽在这里**


利物浦搞定德甲神锋埃基蒂克，“旧爱”伊萨克彻底成为了过去式，只是纽卡斯尔中锋并不会被何以为家的话题束缚着。主帅埃迪·豪不止一次将弟子形容为top级球员，并且在绯闻发酵之前就喊话纽卡斯尔的高层懂得珍惜当下。据悉，纽卡斯尔从一年前就开始着手加薪续约计划，然而伊萨克并不为所动，准确说他的经纪人叫停了续约谈判，瑞典人似乎内心深处拥有了自己既定的诗和远方。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBSLc2xtvg2NC3SZGNUmpXCZibADbUXTfp3FdpAlsmWEFibSl4fnOzoKNzkdiblPkMibibuEr0FM5KMBBAw/640?wx_fmt=jpeg&from=appmsg)

虽然声称“当下专注于纽卡斯尔”，但当被利物浦惦记时，伊萨克的心动指数就曾被身边的好友释放出去了，有意思的是，媒体在挖旧新闻时发现，瑞典神锋曾坦诚“自己从9岁开始就是利物浦的球迷”，并且克洛普执教期间，也曾在2022年将伊萨克视为意中人之一，只是利物浦最终押宝在努涅斯身上。


“儿军梦”连续擦肩而过时，爱而不得是被暂时隐忍的情绪，一步之遥的苦涩也只能独自消化，“我理解那些炒作和报道，这是足球的一部分”，伊萨克的口吻更像是一次自我安慰。


![图片](https://mmbiz.qpic.cn/mmbiz_png/sAmI87QVQBSLc2xtvg2NC3SZGNUmpXCZKveKFI1WLKZ1581twj4bwmibD87EwQd123GNVek6fWTTAUpwwaEDHeA/640?wx_fmt=png&from=appmsg)

坦白讲，留守纽卡斯尔并不是一件糟糕的事情。上赛季拿到了联赛杯冠军，终结了队史70年冠军荒，新赛季拿到了欧冠资格，至少具备了“喜鹊飞上天”的基础条件，希勒在点评伊萨克去留话题时就强调了这是一个关键因素。值得一提的是，纽卡斯尔的所有者——沙特阿拉伯公共投资基金不但无意出售自己的核心球员，而且为伊萨克涨薪续约的计划一直保留着，这是实至名归的奖励，也是绯闻之下最起码的条件反射。


![图片](https://mmbiz.qpic.cn/mmbiz_png/sAmI87QVQBSLc2xtvg2NC3SZGNUmpXCZtCf2AWU4hyIzkodhO0icjSUlCbiaaosX1IJefBf4qACbZIkQiaHqhK4jw/640?wx_fmt=png&from=appmsg)

纽卡斯尔在2022年夏天斥7000万欧元签下伊萨克时，外界普遍认为这是一笔冤枉钱，但经过三个英超赛季的淬炼，拾级而上的瑞典神锋已经成为名副其实的亿元先生，在个人62粒进球的集锦中，阿森纳、曼城、切尔西、利物浦、曼联，均成为了衬托伊萨克射术的背景板。


阿森纳主帅阿尔特塔曾被带伤踢比赛的瑞典人折服：“当你的锋线拥有真正高水平的球员时，就能制造差异，效率也会更高。”只可惜阿森纳和伊萨克的绯闻同样无疾而终，也许关于“这是别人家的孩子”的感慨持续进行时，别忘了伊萨克是近23年来首位单赛季两次对阵枪手均有进球的纽卡斯尔球员。


![图片](https://mmbiz.qpic.cn/mmbiz_png/sAmI87QVQBSLc2xtvg2NC3SZGNUmpXCZCWI1LosvSfSGvImlUqTSbM3vMZfaezZQ0oml3h0OaUQoBicejaGMnvQ/640?wx_fmt=png&from=appmsg)

伊萨克并不是一个闹情绪的球员，却容易被媒体放大一言一行。在纽卡斯尔对阵凯尔特人的热身赛里，他既没有出战也没有观战，这不由得引发外界的猜测，主帅埃迪·豪对外的解释是“我决定让他回家是因为围绕他的种种传闻。”


纽卡斯尔给球员建立情绪缓冲期是明智之举，只不过伊萨克未必能持续做到心如止水。利物浦1.2亿镑的报价遭到拒绝的理由是钱没有到位，但当利雅得新月挥舞着支票求购时，伊萨克仿佛看到了另一道曙光，据悉，他已经初步同意与利雅得新月开启谈判，且沙特豪门正与其经纪团队进行沟通，传闻利雅得新月愿意斥资1.2亿镑的基础转会费，并为瑞典神锋提供1500万欧元的年薪。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBSLc2xtvg2NC3SZGNUmpXCZ5EK8lWqn4Gob82ia7Z42cu4EnickXQkSVFKUC3SPeYjd4YRibiaKwTGk9Q/640?wx_fmt=jpeg&from=appmsg)

两次错过利物浦或许是伊萨克命中注定的“劫”，但纽卡斯尔和利雅得新月这两家俱乐部同属沙特公共投资基金，纽卡斯尔依然可以用“非卖品”的标签拒绝一切询价或者谈判，但彼此在名义上存在“互通有无”的可能性，事实上在埃基蒂克加盟利物浦之前，纽卡斯尔也曾将法兰克福前锋视为猎物，与伊萨克相得益彰是俱乐部假想的理想组合，但似乎避免不了纽卡斯尔提前物色替代者的话题。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBSLc2xtvg2NC3SZGNUmpXCZXWghCvJsqrQUeqmRmwbrTMxRxHURrgs4gvhA8dGmcE7pnEuP0QGveg/640?wx_fmt=jpeg&from=appmsg)

在纽卡斯尔拿联赛杯冠军、刷新个人单赛季进球数，抢欧冠资格，伊萨克在理论上已经极致地兑现了天赋，当豪门之约连续被扼杀时，赚大钱并不是寒碜的事情。在此之前，曾在纽卡斯尔效力过米特洛维奇也是在当打之年前往沙特淘金，值得一提的是，塞尔维亚大中锋在最近流露了重返五大联赛的念头，而小因扎吉也有重新洗牌的打算，或许适时地成全了伊萨克的沙特之行。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBSLc2xtvg2NC3SZGNUmpXCZYiaC4Tnib8jrQYcctHTabeSqwvMw7vDCNNYrAJDiahvkkmGr8OP3FTbdw/640?wx_fmt=jpeg&from=appmsg)

从现实主义的角度看，伊萨克是纽卡斯尔队内的顶薪之一，但也经不起“推敲”，毕竟不足15万镑的周薪并不能准确匹配个人价值，作为英超大杀器的主演之一，或多或少地陷入“我本可以”的对比论中，也很容易产生“外面世界更精彩”的念头。


值得一提的是，伊萨克虽出生在瑞典索尔纳，但来自厄立特里亚的父母经历了战乱与贫穷，足球赋予了伊萨克抚平家庭创伤的机会，不过踢好球与赚大钱并不是相互冲突的选择，甚至不排除在沙特先当过客再在英超杀回马枪的剧情。


![图片](https://mmbiz.qpic.cn/mmbiz_png/sAmI87QVQBSLc2xtvg2NC3SZGNUmpXCZU3XliaZBP0I5zNcEQGZ1DgA9Gjh95BM40JiaWM1xlMqz5KVibRp6Sic3uw/640?wx_fmt=png&from=appmsg)

选择没有绝对的对与错，尊重当下的自己就是赢家心态，当然外界更希望伊萨克在最好的年华里做最好的自己，要知道另一个瑞典人哲凯赖什为了再续英超梦，不惜与葡萄牙体育闹翻。纽卡斯尔在这个节骨眼上让伊萨克回家休息，就是为其提供冷静思考的空间……
