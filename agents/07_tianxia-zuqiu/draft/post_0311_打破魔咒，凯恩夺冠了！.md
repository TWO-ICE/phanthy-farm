# 打破魔咒，凯恩夺冠了！

人生就像一盒巧克力，你永远不知道下一颗会是什么味道——对于凯恩来说，刚刚过去的这个周末最能体会这句话的意味。拜仁与莱比锡一战，作壁上观的他一直等待着冠军，等来的却是对手的绝平，然而仅仅一天之后，勒沃库森的平局就将拜仁送上了王座，于是球星界的无冕之王，也终于有了冠军。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBRicyNlBVXKGuodVdAM7TP9ia6IhicsEr8b1GmOgABuzhbqTX1s7YaH5arH3DktZLZs21WibPj1mZVfQw/640?wx_fmt=jpeg&from=appmsg)


很难想象，作为过去十年世界足坛最具竞争力的球星之一，凯恩竟然年过三十都没有任何冠军入账，但这却又是一个残酷的事实。而这样的磨砺路程，像极了他不向命运屈服的足球生涯。在这个全世界都急着听年少成名故事的时代，凯恩用他的经历，告诉我们上山的路是一步一步走出来的。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBRicyNlBVXKGuodVdAM7TP9iaLOl3vt4mKcHP8EvV9fRGpZEXVHj0l4b2j5V87waHibGq534ib9UueC8g/640?wx_fmt=jpeg&from=appmsg)


8岁的凯恩，曾经被阿森纳青训放弃，可他没有放弃，在白鹿巷开启了另一段传奇。然而加入热刺青训后，等待他的是漫长的外租，他先后驻足莱顿东方、米尔沃尔、诺维奇城、莱斯特城，即使遭遇过伤病和进球荒，也没有放弃过。而后好不容易在热刺站稳脚跟，成为队史射手王、英超金靴，却始终与冠军无缘。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBRicyNlBVXKGuodVdAM7TP9iaicT9xuNAeLDGFwH9XZVlOiaflEdPjMybAJjjGqbSHpm6DILnnRfh486A/640?wx_fmt=jpeg&from=appmsg)


那些年里，热刺一直是英超big6之一，孙凯的王炸组合足够让任何一个对手胆寒，但就是没有一个重量级的冠军。凯恩和热刺一起打进欧冠决赛，输了，一起进入联赛杯决赛，也输了，在属于曼城和利物浦的时代，热刺似乎难以逾越两座高山，凯恩就这样一次次冲击着冠军奖杯，又一次次功亏一篑，他的背影如此让人心酸。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBRicyNlBVXKGuodVdAM7TP9iaicLZWPTTj0PG3iavkGzENyNEUMgvUXicfgEqGYjMD9KpuJmFZOzJT97ZQ/640?wx_fmt=jpeg&from=appmsg)


在国家队，命运的玩笑也相伴凯恩左右，作为大英帝星的代名词，他陪伴英格兰崛起，只是三狮军团距离至尊顶点总是差点意思。2018年的世界杯四强，2022年世界杯的八强门外，还有2021年和2024年的欧洲杯亚军，凯恩每一次都发挥出色，可惜英格兰终归捅不破那一层命运的纸。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBRicyNlBVXKGuodVdAM7TP9iaNd7iaicyibTtDY0G6RdibEnibDj9zSudFLtDcxQlibiaHRFHicYXRq67rH9NVg/640?wx_fmt=jpeg&from=appmsg)


后来的故事人们已经十分清楚，凯恩在两年前的夏天转会拜仁，对于一支长期统治德甲的球队来说，加盟拜仁就意味着有冠军入账。但离谱的是，凯恩的魔咒似乎比拜仁的统治力更强，2023/24赛季，凯恩各项赛事打出45场44球的完美数据，南大王却四大皆空。德国超级杯惨败，德甲11连冠被终结，德国杯止步第2轮，欧冠也止步半决赛。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBRicyNlBVXKGuodVdAM7TP9iaicERsIumrnb2GFpgcSK5z3xWCZZ6cP4O6dG8olSuvmfX7bxVeWURz8Q/640?wx_fmt=jpeg&from=appmsg)


“在我的职业生涯中，很多人只会讨论我还没有赢得冠军的事，如果能让这些人闭嘴就太好了。”凯恩曾如此说道。这是他的愿景，也是一个战神义无反顾踏上救赎之路的决心。于是本赛季，你可以看到一个战意浓烈的凯恩，陪伴着拜仁在德国杯和欧冠相继折戟的情况下，守住德甲冠军这个底线。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBRicyNlBVXKGuodVdAM7TP9iavLiadrVnggSQEKHB4O15ib1gNaPoHK5ezialjIC68R3gquMNUvLOauljA/640?wx_fmt=jpeg&from=appmsg)


然后人们便看到了，在这个戏剧性的周末，在经历2次欧洲杯亚军、1次欧冠亚军、1次英超亚军、2次联赛杯亚军、1次德超杯亚军之后，即将年满32岁的凯恩终于拿下了生涯首冠。事实上，就连凯恩的首冠历程都是如此波折，他因为黄牌停赛错过关键战役，本以为在看台上能够庆祝夺冠，最终却变成了在电视机前。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBRicyNlBVXKGuodVdAM7TP9ia3BpsGkmU5qOz7EjdNczZ2BsFhSpdlbAicuPtFspOZ0tDRcH2Lo9qj4Q/640?wx_fmt=jpeg&from=appmsg)


但，好事不怕晚，对于拿下金靴无数的凯恩来说，救赎不在乎年龄，在这个夜晚之后，没有人可以再拿无冠的话题来挤兑他了。或许他的故事，也是足球人生最真实的写照，拼搏的路上总是会遇到各种挫折与失败，会被人否定，也被命运捉弄，但亚军也有资格被夸奖和称赞，因为亚军从来不是贬义词。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBRicyNlBVXKGuodVdAM7TP9iaP7dPv42AdXVK0ce5NLOY2Ywo8c8xKxibZMefNs4Nv0lyxvydbSsFzYA/640?wx_fmt=jpeg&from=appmsg)


所以，在夺冠的时刻，看着凯恩在社交媒体秒发冠军奖杯的动态，你便能够体会他此刻的心境，蝴蝶终于飞过沧海，就让我们最后再调侃一次——凯恩都夺冠了，我们有什么理由不去乐观面对生活呢？
