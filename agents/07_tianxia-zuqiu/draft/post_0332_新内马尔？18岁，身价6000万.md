# 新内马尔？18岁，身价6000万

19岁的恩德里克本赛季在皇马**0**出场**，**在巴萨当过客的罗克**20**岁就落叶归根**，**关于巴西新生代名气大于实力的话题被热议**，**然而埃斯特旺的出现制造了东边不亮西边亮的惊喜**。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBTAJZVNTv6LiaAgj075EI8RqQ461KOCkaoC7Gjox6k9xF9g8gzU92OYOOFOHETlSoZyQIW6DuzOibDA/640?wx_fmt=webp&from=appmsg)

**在**17**岁完成桑巴军团首秀之前**，**他就以**5000**万欧元的身价成为巴甲的头牌**，18**岁以**3400**万欧元的固定转会费转会切尔西之后**，**他就以**18**岁**120**天****的年龄**，**迅速成为了队史英超最年轻的****助攻****者**。

****

**考虑到埃斯特旺是**2007**年出生的后起之秀**，**一直在**“**等下一个天亮**”**的巴西媒体迫不及待地将其与内马尔对比**：“**他是内马尔之后最好的巴西球员**。”**值得一提的是**，**埃斯特旺的偶像正是内马尔**。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBTAJZVNTv6LiaAgj075EI8Rq4tYt4fs2OZB9Vp3UvY6JW2a3JGq65jgQ1eQqukwogazhvicVLnvtIwg/640?wx_fmt=jpeg&from=appmsg)

**在正式登陆斯坦福桥之时**，**切尔西官网曾花大篇幅介绍过巴西天才**，**主题大意是**“**凭借其娴熟的盘带技术和迅捷的速度在南美赢得了良好的口碑**，**成为最令人兴奋的天才球员之一**，**给防守队员带来了很多麻烦**。”

****

**用数据验证的话**，17**岁的内马尔在**33**场比赛中打进了**10**球**，**一举缔造了巴甲**U17**年龄段单赛季进球和助攻纪录**，**而埃斯特旺只用了**24**场巴甲**（10**粒进球和**8**次助攻**）**就做到了青出于蓝而胜于蓝**。**事实上**，**在身穿帕尔梅拉斯战袍的**2024**赛季**，**埃斯特旺在**50**场比赛中一共贡献了**19**粒进球和**10**次助攻**，**演绎过内切的速度与激情**，**上演过任意球破门的好戏**，**当然也在**2025**年世俱杯的舞台上用传射建功的方式与梅西**“**硬碰硬**”。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBTAJZVNTv6LiaAgj075EI8RqByzYwYnviaPZAjDfiboDYqicy1shyh0YCs0udJZ5ccmqUNXNroyh9RbnQ/640?wx_fmt=jpeg&from=appmsg)

**巴西盛产天才**，**却也避免不了水土不服的尴尬**，**恩德里克和罗克两位所谓的**“**新大罗**”**就在豪门之约中迷失了自己**。**于是乎**，**关于埃斯特旺在切尔西的前景似乎蒙上了一层阴影**，**与此同时**，**埃斯特旺也在努力地与偏见和怀疑对峙着**。

****

**对阵西汉姆联**，**顶替帕尔默首发的埃斯特旺贡献了**1**次助攻和**2**次过人**，**并荣膺了全场最佳球员**，**对阵利物浦**，**替补出场的巴西天才在补时阶段贡献了绝杀**，**并以**18**岁零**163**天的年龄**，**成为了英超历史上最年轻打进制胜球的巴西籍球员**。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBTAJZVNTv6LiaAgj075EI8RqEm91nhab19cDxsADYmpgzRXDH1EQDfb9Vz7Z4E9Hr8DaMFu7abDviaA/640?wx_fmt=jpeg&from=appmsg)

**埃斯特旺在英超开了一个好头**，**有人说这是**“**新内马尔**”**的天赋在闪耀**，**要知道他在**10**岁时就与耐克潜在了合约**，**并得到了**“**梅西尼奥**”**的绰号**，**他在**17**岁时荣膺了巴甲最佳年轻球员**，**在帕尔梅拉斯的告别战中**，**他在小角度的进球让就新东家切尔西提前陷入了**“**爱之深**”**的喜悦中**。

****

**因此**，**以菜鸟身份在英超制造一系列纪录并不是突发事件**，**事实上埃斯特旺为切尔西亮相的热身赛里**，**就分别用补射和造点的方式介绍过自己**。**值得一提的是**，**边路是主要活动区域**，**但埃斯特旺在加盟之前就坦诚希望有朝一日在中路发光**，**这是年少有为的反映**，**也是自信心爆棚的表现**。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBTAJZVNTv6LiaAgj075EI8RqsDpibVfYr1RBaJbMTT5RqKHjyZa5UHVZ3zspBquY8my0t57JroBdBeA/640?wx_fmt=jpeg&from=appmsg)

**在切尔西制造流量的埃斯特旺自然得到了安切洛蒂的赏识**，**在最近巴西大胜韩国的热身赛中**，**埃斯特旺与罗德里戈双双上演了梅开二度的好戏**，**韩国媒体在总结惨败原因时点出了前者的杀伤力**：“**他的跑位让我们的防守变得松散**，**最终改变了比赛的走势**。”**值得一提的是**，**埃斯特旺上演了**7.2**米**/**秒的瞬间冲刺速度**。

****

**虽然热身赛只是练兵性质**，**但巴西媒体看好埃斯特旺成为安切洛蒂在右路的利刃**，**上个月在与智利的世预赛中**，**他就完成了一粒倒钩破门**，**相比于成为巴西国家队历史上第八年轻进球者的纪录**，**欧洲足坛的菜鸟更想飞得高一点**：“**我想和巴西国家队赢得世界杯**。”


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBTAJZVNTv6LiaAgj075EI8RqERgzMl2LfSxmHl5heBXmV7gJsGgicicxnsAAialmBy3H36ibe3M3V8L8Sw/640?wx_fmt=jpeg&from=appmsg)

**如愿以偿是一件难度系数颇高的事情**，**有时候天赋和热情并不是唯二的秘方**，**在恩德里克和罗克身上**“**照镜子**”**的埃斯特旺有自知之明**：“**我必须先在切尔西证明自己**”。**他努力学习英语课程**，**他从蒂亚戈**·**席尔瓦那**“**取经**”，**他聘请了私人训练师**，**他反复观看阿扎尔的录像**，**他甚至排斥了**“**小梅西**”**或者**“**新内马尔**”**的头衔**，**享受足球是巴西球员历来追逐的**“**本我**”，**成为巨星和实现梦想才是天才的进阶之路**，**也是大众球迷所期望的美好**。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBTAJZVNTv6LiaAgj075EI8RqWePnGXXuYJPWjEiakJsdYk0Psp7Vpoksnic6jdfygSQ30vFFp1vGADhg/640?wx_fmt=jpeg&from=appmsg)

**埃斯特旺固然实现了出名要趁早**，**但对手的针对性部署和外界接连捧杀的声音也会悄然变成拦路虎**，**他在帕尔梅拉斯时期的主帅就指出**：“**埃斯特旺的问题在于过度盘带**，**有时候不需要连续三次过掉同一个后卫**，**反复纠缠只会让对手在禁区囤积重兵**。”**球迷有印象的话**，**在对阵西汉姆联时的埃斯特旺虽然斩获了助攻**，**然而切尔西主帅马雷斯卡赛后第一时间敲打了弟子**：“**我们的丢球正是因为他做了一个花式动作**。”

****

**而巴西国家队的老将卡塞米罗的言论更像是忠告式的保华**：“**埃斯特旺是一名非常年轻的球员**，**我们不能给他施加太大的压力**，**因为我们在无数的球员身上都看到**，**如果你给他们施加太大的压力**，**他们的表现就会下滑**。”


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/sAmI87QVQBTAJZVNTv6LiaAgj075EI8RqKmr6NE7B1E6cUEelyhKkBg3XicZ77DkoibB9YTHdhMw4PHPIWqA9iaOHA/640?wx_fmt=jpeg&from=appmsg)

**从天才到巨星的转变看似一步之遥**，**但任重道远**，**总有些希望之星并不能在掌声和褒奖中将自己的心态归零**。**有些人高开低走**，**甚至沦为了昙花一现的流星**，**比如在切尔西历史上**，**曾有个号称**“**新卡卡**”**的皮亚松头一个赛季荣膺了队内最佳新秀**，**然而**9**年时间内一直在以租借方式流浪**。

****

**埃斯特旺的明星效应愈发明显**，**但成长永远是具备时间性的课题**，**当下**6000**万欧元的身价也可能是一个泡沫**！
