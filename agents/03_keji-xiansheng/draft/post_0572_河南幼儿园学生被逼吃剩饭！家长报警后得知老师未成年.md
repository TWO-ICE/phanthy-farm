# 河南幼儿园学生被逼吃剩饭！家长报警后得知老师未成年

12月19日，河南省安阳市龙安区彰武中心幼儿园家长马先生报警，称该园老师小雯（化名），打了多名小朋友，并让5岁的小雷（化名）吃剩饭。**警方介入调查时牵出幼儿园雇佣童工一事：小雯身份证上出生年份是2006年，小雯妈妈说，小雯出生于2003年。**


“8月31日和她签合同时，她说她十八九岁了，我准备让她去做骨龄鉴定。”12月29日，幼儿园园长陈先生接受上游新闻记者采访时，仍不相信小雯未成年。


陈先生称，幼儿园已开除了小雯，园方愿意承担相关责任。


**监控视频：老师罚5岁男童吃别的小朋友吃剩的饭**


马先生5岁的儿子小雷就读于彰武中心幼儿园大班。该园是彰武街道办唯一一所公办幼儿园，学生140多人，老师12人。


马先生介绍，12月18日晚，小雷睡不着觉，总嘀咕着要换幼儿园。一番追问下小雷说，幼儿园老师打了他，还让他吃剩饭。


上游新闻记者获得的多段视频显示，12月6日，小雯伸手打了一名男童的手臂。12月14日，小雯将一名穿蓝毛衣的男童拽到身前，揪了他的耳朵，接着推开。12月18日，小雯打完小雷手臂后，从饭桶里拿出了一个碗放到桌上，接着小雷端着碗，吃了起来。**惩罚完小雷后，小雯又打了另外两名男童。**


小雷妈妈杨女士称，从视频中可见，小雯打小孩时确实没有用太大的劲。这虽然令她心里难受，但勉强能接受。令她受不了的是，小雯惩罚小雷吃剩饭。


小雷班主任老师称，查看完整监控视频后，她发现小雯确实让小雷吃了别的小朋友吃剩的饭，“小朋友吃完午饭后，会按要求把碗筷装进饭桶。有的碗里有吃剩下的饭菜，小雷吃的那碗剩饭不是他先前吃的。”


**警方调查：涉事老师是未成年人 无法追责**


12月19日当天，看到监控视频后，生气的马先生报了警。


上游新闻记者从安阳市公安局彰武警务队了解到，接警后，民警先固定了监控视频。接着调取了小雯的身份信息，身份证显示其出生年份是2006年。


12岁的未成年女孩当了幼儿园老师，这令民警吃惊不已。接着，民警来到小雯家。经初步调查，小雯只有15岁，户口上晚了。


**“我们问小雯时，小雯一个劲地说自己错了。她是未成年人，按照相关规定，她可以免予行政或刑事处罚。”民警说**，基于此，他们只能在幼儿园和家长之间调解。


律师付建认为，彰武中心幼儿园招用未满16周岁的未成年人当老师，这是雇佣童工。园方存在明显过错，应当承担小雯打人的主要责任。


**园方回应：招人时审核不严 诚恳向家长道歉**


自己还是个孩子的小雯怎么当上了幼儿园老师？


小雯母亲介绍，她和丈夫都是残疾人，家中十分困难。小雯初中辍学后，为减轻家中负担，便跑到幼儿园去应聘，“我是2003年生的她。生下来时没及时上户口，上户口时就说她是2006年的。”


彰武中心幼儿园园长陈先生说，今年9月开学之前，幼儿园缺生活老师。小雯面试时自称自己十八九岁了。8月31日和她签合同时，她带来了身份证上，显示她只有12岁。园方反复问她，她说身份证写错了，她真的满18岁了，**“当时要老师要的急，就疏忽了。”**


陈先生表示，园方诚恳向马先生和杨女士道歉，愿意承担所有责任。


12月29日，小雯接受上游新闻记者采访时说：她一时心急才动手。现在已意识到错误，**她向小雯家长道歉，“让小雷吃剩饭，主要是担心他没吃饱。”**
