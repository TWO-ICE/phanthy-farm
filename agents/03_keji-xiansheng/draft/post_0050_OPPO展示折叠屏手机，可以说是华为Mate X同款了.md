# OPPO展示折叠屏手机，可以说是华为Mate X同款了

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4Yibczg3zXX1qUyovzVGnBf0IicqbwSIr2ozU2Rg4hqYIc9Q8I9yIPennV3LgO8H4sQYWja505OAIicjg/0?wx_fmt=jpeg)

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Yibczg3zXX1qUyovzVGnBf0IOaXRib4GEn5tMOEqEWLhKpiacaYUAZ94RORia459icO4iaXCrTg4u5VxxSA/640?wx_fmt=jpeg)


　　

科技先生2月25日讯，MWC2019已经正式拉开帷幕，华为在昨天正式公布了华为Mate X折叠屏手机。

　　

此前OPPO副总裁沈义人通过微博表示OPPO折叠屏手机近两三年没有任何普及的可能性，直接否定了众多网友猜测的OPPO在MWC 2019上会推出折叠屏的消息。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Yibczg3zXX1qUyovzVGnBf0ItI09a7hw2smOOKIEic0GfKt3zBw9jUgBtISjDKl8HXnDhfSZzAypNdA/640?wx_fmt=jpeg)


　　

但今天，OPPO副总裁沈义人在微博上晒出OPPO折叠屏手机，并称，“目前这个阶段看来，折叠后除了屏幕变大，和可以折叠一下，并没有带来用户体验上的巨大提升。如果真想要的请转发，看看想要的人多么?人足够多的话可以考虑是否要‘量产’。”


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Yibczg3zXX1qUyovzVGnBf0IPWSvaenWZU2OfzGE1yMS8gQGf3jhVrZib2f4SaMfq0qN1RJSzKbWElw/640?wx_fmt=jpeg)


　　

从OPPO展示的折叠屏手机来看，他们的设计跟华为的Mate X非常相似，只不过屏幕的边框可能更宽一些。也是向外折叠出前后屏的设计，闭合时一侧屏幕显示，打开时成为一块平板，左侧则是集中了摄像头等部件，也是前后摄合一的方案。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Yibczg3zXX1qUyovzVGnBf0IegJFavz1fNZ3ia6mxyibzLctpyN1LjGS7PLficXgOodic5cXianJwtA61mw/640?wx_fmt=jpeg)


　　

此外，沈义人还特别强调这款折叠屏是OPPO自研的方案，原本计划在23号OPPO 2019 创新大会发布。
