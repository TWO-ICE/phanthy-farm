# 特朗普连发两条推特：我想要5G，甚至6G！我们没有理由落后！

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4Y8lq84Bibky0FLQUv49VYticZMts7ziaI9SuIbsNHDUe7l1A4pWlFjx3J8CwWcvzlhic5MHQs8QZRXmQQ/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/5ajWcESnXWVD4KIWEqqlKA

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8lq84Bibky0FLQUv49VYticZ1g81rvpdxsVKkGtQq9joXKh3pwI7S7VpkDa2acviaTHu5dcTuZIFiaJw/640?wx_fmt=jpeg)


　　

科技先生2月22日讯，当地时间2月21日，美国总统特朗普在社交网站推特发文称，希望5G甚至6G技术能够尽快在美国实现。这种技术比现有标准更强大、更快、更聪明。**美国公司必须要加快努力，否则就只能落于人后。**


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8lq84Bibky0FLQUv49VYticZV7PWBea7tib6JjbpJ5fOJHh7MKw7BOsl19ibJV3uhSIVIVT5KyLuEmRg/640?wx_fmt=jpeg)


　　

“我们没有理由在这项如此明显的代表未来的事情上落后。**我希望美国通过竞争取胜，而不是通过封锁目前较先进的技术。**我们必须永远是我们所做事情的领导者，特别是在非常令人兴奋的技术世界。”特朗普在推文中写道。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8lq84Bibky0FLQUv49VYticZHQyZ2QO7tjFJuXBgJhTVD90ibX0eas2djZicgcAlwL3v8FZibGNfQlfwQ/640?wx_fmt=jpeg)


　　

报道称，特朗普的推文似乎指向了此前曾有媒体报道过的一项尚未签署的行政命令，该行政命令将以国家安全考虑为由阻止华为等中国电信公司进入美国5G网络。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8lq84Bibky0FLQUv49VYticZ98TaODXrNPKdoTrSKHO6JF8dZRIiaMGgPtuAA8ANnlDB6OKSzIva4icg/640?wx_fmt=jpeg)


　　

对此，**华为轮值董事长胡厚崑表示：华为已准备好，通过真正的竞争，为美国建设真正的5G网络。**


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8lq84Bibky0FLQUv49VYticZX0PEWaiaXr471JheOaN0MI5SxreAeaHAdaKo11o4jib5aVgNMc1vc3lA/640?wx_fmt=jpeg)


　　

而早就在特朗普发推特之前，他的欧洲盟友似乎已经开始抵制美国要求禁止华为部署5G网络的呼吁。

　　

**英国电信公司首席设计师尼尔·麦克雷表示，“现在只有一个真正的5G供应商，那就是华为。”**


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8lq84Bibky0FLQUv49VYticZ44Bs06HVTkQFyd18Fueyic1EYwvuf8wqKk47qXLyHZRlzoCQWs0RqFg/640?wx_fmt=jpeg)


　　

CNN也承认，“**在电信设备领域，美国没有一个华为这种级别的全球竞争对手。**”


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8lq84Bibky0FLQUv49VYticZWLLCWoCtibqB3Dlibf34naqtyWw77wH81ia9qmSgtMMPEyzh58EUU2dAQ/640?wx_fmt=jpeg)


　　

华为董事长梁华1月份参加达沃斯世界经济论坛时表示，“如果那些国家不选择华为，我们将把精力集中到选择我们的客户身上。”


![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4Y8lq84Bibky0FLQUv49VYticZWYLMm3a3j8hQcGVsFCOeiaOLBVztOaUsvzOrJsBmIemWaqkhfxz5ibkw/640?wx_fmt=png)


　　

当BBC记者问道，在美国施压下，其他国家抵制华为的影响，华为创始人任正非自信地说：**“西方不亮还有东方亮，北方不亮还有南方亮。美国不能代表世界，美国只代表世界的一部分。”**


![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4YibnyTSr5ahnLC410nkFp9Lpk4LZicdxuuBHxS3oX3Q6PmFGQqicvCxwatzBYaWu3IvRicwq07TUoJYMA/640?wx_fmt=png)
