# 送餐员平均月薪竟超“白领”！网友：别拦着！我也要去送外卖

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4YicpEJ4JGqAAIp8sDc2wNuBdpV2tWDTZLrXX6Ax6Nibaia1A8bwYMYNW6up3vEj2as5NlIAbAW0shLhg/0?wx_fmt=jpeg)

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YicpEJ4JGqAAIp8sDc2wNuBdhBzPBYvklrmomwjLU2YM0OcMyIQhUsa8hicgRteVLFibXqfTplIQ8NUA/640?wx_fmt=jpeg)


近年来，外卖行业发展迅猛，庞大的外卖市场规模，不仅为人们的日常生活带来了极大便利，有效促进了社会就业，也让送餐员这一新兴行业快速崛起。


今日，58同城招聘发布的《2018年送餐员就业报告》显示，**2018年全国送餐员平均薪资达7750元，甚至超过了行政、文员等白领岗位。**有网友调侃：别拦着我，我要去送外卖！


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YicpEJ4JGqAAIp8sDc2wNuBd72pwXRIsdYqM2YR9lWvr9tW94UuWvVz06rQkNEiaXUgoM11s3tRIIzg/640?wx_fmt=jpeg)


而送餐员企业提供薪资排名中，杭州以月薪9121元一马当先，其次是北京、南京、上海，分别为9072元、8728元和8481元。


报告称，送餐员市场求大于供，企业对外卖小哥求贤若渴。**与送餐员的期望薪资相比，送餐员实际得到的薪资更高。**


58同城招聘研究院院长李妍分析，外卖送餐员在一、二线城市覆盖率很高，并有逐步向三、四线城市下沉的趋势；与此同时，送餐场景更加丰富，送餐区域由以往的住宅、写字楼拓展到酒店、医院等，这让外卖产业“蛋糕”越做越大。
