# 生而强悍！vivo旗下iQOO手机将于3月1日发布！

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4YibtjtkTLoVCov1zvQUPhwibT4g1YScb6RBruga6ic1icMpXibaUwjFXPDcMygC8KCibhmAFjrje0nbM74g/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/dIrUo1_UYsfMGsqcx8UsIg

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YibtjtkTLoVCov1zvQUPhwibThlGxvYxJfdaw1lhvuU6O0fEcWxmeAzMU0IaRBkYxGPVYG8P6eWchQQ/640?wx_fmt=jpeg)


　　

科技先生2月20日讯，今天上午，vivo旗下手机品牌IQOO手机在微博宣布：3月1日，中国深圳， iQOO新品发布会，邀你一起来见证。届时，这款“生而强悍”的旗舰机将和我们见面。


![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4YibtjtkTLoVCov1zvQUPhwibTxIicLMmjEI19OOhQ8ZgcvbBDdNsbzY9O5JvvibflB87naC4UV9ITl7vg/640?wx_fmt=png)


　　

此前，IQOO官方公布了该机的部分细节：骁龙855旗舰平台、12G内存、256G存储、NFC、44W快充、Super HDR、Type-C、4000mAh电池、4D震感等等。

　　

在一则iQOO手机官方的说唱视频中，歌词频繁提到的“加速”、“强悍”等无一不是在暗示新iQOO手机的性能强劲。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YibtjtkTLoVCov1zvQUPhwibT0erp2CdmKAEmn0wx1KaVbvD1iazn1QUsqVadhichEfEic6k4rF7B6xrWQ/640?wx_fmt=jpeg)


　　

值得注意的是，iQOO新机支持44W快充，这可能是国产首款支持44W超级快充的骁龙855旗舰。

　　

其他方面，iQOO还提到iQOO将搭载“第六代指纹识别”，简而言之就是在NEX双屏版的指纹模块上继续更新。曝光了这么多，官方甚至还放出了视频形式的“新机外观设计曝光”。

　　

vivo旗下的几条产品线目前已经覆盖了1000元到4000元的价位，随着当前几个头部手机厂商的竞争进一步加剧，同时市场对于高端机型的需求大幅提升，vivo也极有可能是通过全新的iQOO产品冲击5000+以上的价位。

　　

不难看出，这款iQOO新机定位旗舰，而且它有可能是一款面向玩家的游戏手机。
