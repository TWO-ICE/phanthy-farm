**文 |**** 柳华芳**

**排版 | 晓月**


五月，华为推出MateView高端显示器，优雅大气，极简唯美，极致体验、智慧交互、创新模式让人眼前一亮，可谓是好评如潮。


赞许之时，网友们一致发问：MateView设计这么好，为什么不再加上主机、推出华为牌的一体机呢？


果然，9月13日，华为举办智慧办公新品发布，对外发布了首款一体机--华为MateStation X，系行业首款触控全面屏一体机，采用28.2英寸、3:2生产力、4K+超高分辨率、十点触控、92%屏占比、98%P3电影级色域的极窄边框全面屏设计，售价9999元起，一步到位，杀入高端一体机江湖。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Yib1YtfflSOKsMgA50S7l5wGYPp8g4CcTfsCOKicXLguzJ5o9VrMutvP3MtOIgrVECNVmdMX8iayPK5w/640?wx_fmt=jpeg)


华为一体机，出手即精品。华为MateStation X带来了十点触控的全面屏设计，带来了多屏协同、文件及信息流转等众多智慧交互创新，为一体机市场带来了创新想象力。


Mate家族，高端血统。华为MateStation X 定位高端一体机，一步到位，直接争夺一体机领域最有价值的万元级市场。


与此同时，华为MateStation X的发布，也让华为PC产品线更加完整，智慧办公生态越来越完善，一步步形成全场景覆盖。华为MateStation X是华为PC业务的一个新突破、新节点，也将是一体机市场走向创新加速度的产业拐点。

Mate血统，高端之作**

**Windows一体机的王牌之作**


过去的二十年里，国产手机品牌之中，只有华为把高端手机做成了。华为Mate 、P两大高端旗舰系列早已成为手机行业的创新标杆和高端代表。


华为Mate系列是最受高端商务人士信赖的产品，是技术创新、交互创新的行业标杆，也是消费者心智中的超级符号。Mate系列手机、MateBook系列笔记本、MateView显示器、MatePad平板、MateStation台式机……现在这一家族又新增了华为MateStation X高端一体机。


站在华为用户的角度，在MateView高端显示器之后，大家更加渴望看到华为在高端台式机方面的产品。华为Mate系列的用户总体高端化，偏向于社会精英阶层，有跨场景、极致体验、极简高端的一体机需求。同时，像银行、教学、编程、视频编辑、工程制图等众多场景，也拥有对高品质、高性能、支持智慧交互的大屏PC产品的刚需。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Yib1YtfflSOKsMgA50S7l5wGPiaUoicrtONibC0WkmwD31GcpGjl5hibichaicgib0ia1T9BGWxE3fJRwaf6jQ/640?wx_fmt=jpeg)


华为MateStation X的到来，满足了消费者对高端一体机的需求。从设计、性能、交互、显示、散热、工艺等众多维度来看，华为MateStation X不负众望，是年度最惊艳的一体机产品，在高端一体机领域，续写Mate产品传奇。


回顾一体机市场的历史与现状。Windows一体机市场总体偏中低端，消费者一直期待Windows世界出现可以对抗苹果iMac系列的高端一体机产品，华为MateStation X 来得正是时候。不同于高度繁荣的笔记本市场，Windows一体机市场热度没有完全点燃，老牌PC厂商们并没有拿出太有市场号召力的产品。


华为一体机的发挥空间非常大 ，有能力改变市场格局和赛道文化，正如华为MateBook一举成为轻薄本之王那样。从产品表现来看，华为MateStation X 已成为Windows一体机的王牌之作、高端标杆之作，虽然价格不菲，却大概率成为爆款级产品，有可能大大拉动消费者对一体机市场的整体关注度。

重构体验，创新破局**

**业界首款触控全面屏一体机**


华为进入新品类，绝不会“为了推新而推新”，而是用全场景智慧体验的思维方式重构产品体验，不创新毋宁死，拒绝平庸，总是会带来一些突破性的技术创新、体验创新。


华为MateStation X 也不例外，是业界首款触控全面屏一体机，为了最佳效率和体验，拒绝采用了公模屏幕，配备了非公模3:2生产力比例的28.2英寸全面屏，屏占比高达92%，比同尺寸16:9显示屏多出8%的显示面积。8%是很大的面积，试想一下，如果你的房子公摊面积增加8%，那会多出一个房间或大阳台。


3:2这个屏幕比例是华为MateBook系列开创的，已经得到了消费者认可。在这个比例之下，可以让一屏显示更多文档信息，减少翻页下拉次数，可以让视频编辑时多几条音视频轨道，大大提升PC的生产力。同时，在华为MateStation X这块支持4K+分辨率的28.2英寸大屏之上，可以拥有更好的双屏、三屏、四屏平铺显示精度，更畅快地使用Windows虚拟桌面功能。


华为MateStation X正在开启一体机的“全面屏时代”。除了上面提到过的屏占比、屏显素质等，还有更全面、多样化的屏幕交互方式——这款一体机的屏幕，新增了“十点触控”的功能，大大扩展了一体机的使用场景，比如智能画板、智能白板等等。


再加上华为PC的独门绝学——多屏互动，华为MateStation X还可以与手机、平板、耳机等产品实现全场景智慧办公的体验闭环，让一体机不再是一个硬件孤岛。例如当一体机与手机互联时，文件与信息可以在一体机与手机之间流转、共享，甚至可以双向拖拽；在一体机上，也可以调用手机端的移动APP。在华为MateStation X的屏幕支持“触控”的前提下，在大屏上使用移动APP，毫无疑问，也可以用我们日常习惯的“触控”方式进行操作。

软硬协同，智慧办公**

**高效体验满足市场需求**


作为华为在一体机市场的“首发产品”，华为MateStation X除了配备“多屏协同”功能之外，还增加了许多创新功能。


华为MateStation X配备了专门设计的智慧键盘和鼠标，一次配置，自动连接，无需反复连接蓝牙，连设备互联都做到了智能化、极简化。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Yib1YtfflSOKsMgA50S7l5wG8e5gEblziaZaE8TkK437Jz5wmI7XrzuQgXsFZ8JtuvQsy3ibdDSzNVHw/640?wx_fmt=jpeg)


同时，键盘上还内置了“智慧语音键”，一键即可唤起智慧语音功能，支持语音输入、AI字幕，通过AI技术创造不一样的交互体验。语音输入让用户快速完成语音的文字记录。AI字幕支持麦克风和媒体音声源，直接显示字幕以及翻译字幕的两种翻译模式。用户在开跨国视频会议的时候，可以打开该功能，帮助自己理解会议内容。这个功能对于职场人士而言，也可以说是“刚需”。


除了硬件的协同和智慧功能，华为MateStation X也延续了华为PC品类的软件智慧体验。它搭载了华为云空间、华为应用市场、华为浏览器等应用，当用户使用同一账号在不同终端设备上登录时，文件、照片、视频、联系人、备忘录等关键信息，都可以通过云端在多设备间同步，可随时翻阅、查找和更新。


“智慧”一直都是华为终端的标志性体验之一，也是华为PC产品口碑和销量远远领先同类产品的关键密码，通过智慧互联让跨设备交互（文件传输、屏幕共享等）变得傻瓜化、极简化，大大提升了用户操作的便捷性和效率。现在，华为将这种体验完美移植到了一体机领域。


集多屏协同、十指触控、智慧语音、智慧键鼠、指纹开机等众多创新于一身，华为MateStation X可以说是当前市场上“智慧交互”最强大的一体机产品。严格地说，其他的一体机目前根本做不到智慧交互，只能算是传统一体机，而华为MateStation X却可以称得上“智慧一体”。

**极简设计，格调美学**

**打造全新高端享受**


华为MateStation X是一款拥有高端气质的产品，这不止体现在它的大屏和智慧体验上，在产品设计方方面面的细节上，也都得以彰显。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Yib1YtfflSOKsMgA50S7l5wGuPr2icZ5gGicOdgjmCJw2ZQqQcs5GZLb9UM0ydc0zT1VESicy4nPibibnyA/640?wx_fmt=jpeg)


在设计理念中，华为MateStation X融合了康定斯基艺术思路，构造几何美学，描绘出最简约、最独特的设计，实现功能与美学统一的经典设计。


悬浮玻璃屏（几乎无边框）、金属一体化机身、专利转轴技术、分离式架构设计、隐藏式系统支架设计，众多极致工艺、技术创新于一身，华为MateStation X 做到了极薄、极美、极简的格调美学，金属质感之中亦有温润舒适，正面是显示美学，背面是性感曲线。


从外观上来看，这样一台一体机，非常适合摆放在家中的书房，或者是一间有品位的办公室里。


除了外观，音频突破也是华为MateStation X的一大亮点。传统一体机的音频质量大多数处于勉强能听的低层次水准，但是，华为MateStation X却非常重视音频体验，有华为自研Histen算法加持，还引入帝瓦雷SAM低频增强算法，再加上Push-Push对称结构设计，带来了完美的场景化音效、低音体验、影院级的律动。


极简的外观、浑然一体的“全面屏”，再加上高级质感的音效，这才是一台高端一体机该有的水准。


华为MateStation X虽是一体机市场的后来者，但可以预见的是，它正在“复制”华为MateBook系列“后来居上”的故事。


它对高端一体机市场产生的冲击，加速了市场创新，为一体机世界带来了全场景智慧办公、极简格调美学，以及“更全面的屏幕”，正在让一体机市场重燃想象力。


美是外在，智慧是内在，华为MateStation X做到了内外兼修。虽然很多人对“智慧办公”的理解还停留在SaaS、ERP等办公软件的层面，但事实上手机、PC、一体机等智能设备才是智慧办公、提高效率的“基座”。


随着华为MateStation X的发布，一体机市场格局可能发生大变。老牌PC厂商难以跟随华为的创新速度，在相当长一段时间内，华为MateStation X 会是一体机市场中兼具智慧与美的代表产品，注定会成为行业中的里程碑。


尤其是在Windows一体机市场，华为MateStation X 已然成为高端一体机的创新领跑者。而未来华为在这一赛道的表现，也更加令人期待。
