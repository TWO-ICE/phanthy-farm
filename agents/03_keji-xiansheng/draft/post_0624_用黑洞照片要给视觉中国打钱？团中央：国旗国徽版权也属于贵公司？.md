# 用黑洞照片要给视觉中国打钱？团中央：国旗国徽版权也属于贵公司？

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4YicuTH2YsficibibUiaiaY2KosWicjaYFs296DcpNn72DpKDpsZqeyfzOrb5QLWEjvJz1boJPqqiauppgtmfw/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/eEYoMiScSqxxwQUv9zszYw

4月11日，视觉中国网站上出现了昨晚公布的人类史上首张黑洞照片，并注明此图如用于商业用途，请致电或咨询客户代表。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/mcrLqJvbDOqudXLwnRqYK9WtZT0DtbVFM5C0g2AMu7uHLBLLPWxYXCLMjDlOowkVicdjlzQbm9BicIDMsAAWhe3g/640?wx_fmt=jpeg)


据悉，人类首张黑洞照片由全球8部事件视界望远镜(EHT)共同观测而成，是由200多位科研人员组成的团队完成的科研成果。这张黑洞照片会有版权吗？


![图片](https://mmbiz.qpic.cn/mmbiz_png/mcrLqJvbDOqudXLwnRqYK9WtZT0DtbVFd1MBmVU2icoBmhPzL4SOU0icgzy9CzulokiaovTvWibEOu9XDLcnsEIic4g/640?wx_fmt=png)


随后，@视觉中国影像 声明称，视觉中国通过合作伙伴获得了黑洞照片的非独家编辑类使用授权。**该图片只能用于新闻编辑传播使用，未经许可，不能作为商业类使用。**如未经版权人授权，用于商用，可能存在风险。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YicuTH2YsficibibUiaiaY2KosWicjFQ9Gkwvu6qJEYyuD9F6c5UYM9kHKnmx7IZawjkIGbUYjGSticRqP0Mw/640?wx_fmt=jpeg)


**今天下午，共青团中央官方微博向视觉中国发问：“国旗、国徽的版权也是贵公司的？”**


![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4YicuTH2YsficibibUiaiaY2KosWicjgjkWJtjOhzQt33IPHJQcoBOgy6hTqJbSeWw8SHjWGevmbmVNGhFqkw/640?wx_fmt=png)


有媒体联系到视觉中国创始人柴继军，他称，**“用此图蹭个热点用于公司广告等商业目的有风险”。**柴继军解释，任何一张照片都有版权，举决于版权人希望这张照片如何使用。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YicuTH2YsficibibUiaiaY2KosWicjNUqOgWNPbCyt7nndJnK6KTRaelmqGSHNF63bJia0sTZNcUSegwcpolA/640?wx_fmt=jpeg)


视觉中国官微晚间发布声明：经网友举报的视觉中国网站关于国旗、国徽等不合规图片，经查该图片由视觉中国签约供稿人提供，视觉中国作为平台方负有审核不严的责任，为此深表歉意！我们已对不合规图片做了下线处理，并将根据相关法律法规持续性的加强审核，避免类似情况发生。感谢广大网友的监督！
