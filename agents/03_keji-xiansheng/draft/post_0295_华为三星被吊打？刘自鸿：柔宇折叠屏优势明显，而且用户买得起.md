# 华为三星被吊打？刘自鸿：柔宇折叠屏优势明显，而且用户买得起

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4Yibczg3zXX1qUyovzVGnBf0I2dNialhL8pib5KF9peMf92eTjkRuKcM5BD9oAdWxFPlzQD3HkWN6Qv3w/0?wx_fmt=jpeg)

![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4Yibczg3zXX1qUyovzVGnBf0IpOibarTxDQC1UIELjOjJVeGorOrKVIkcsoAKPViajE2OpPTG2KhbCmSg/640?wx_fmt=png)


　　

科技先生2月25日讯，此前，三星已经发布了自家的折叠屏手机Galaxy Fold。在昨晚巴塞罗那MWC 2019上，华为5G折叠屏手机Mate X震撼发布，再一次惊艳全场。这两款手机一经推出，就受到了大量关注。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Yibczg3zXX1qUyovzVGnBf0II3EcZCOv5ib8m0w95UaA7eFtJsk3T3iaR3sw8v3fDrGEY1xXSlicKOfGA/640?wx_fmt=jpeg)


　　

今天，柔宇科技创始人刘自鸿在微博发布了一张参数对比图，对此了华为Mate X、三星Galaxy Fold与柔宇自家的柔派FlexPai，同时称这是目前全球仅有的三款消费级折叠屏手机。

　　

**他表示，作为好产品，当然最终都要回归一点，就是让用户买得到，买得起，用得好。**


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Yibczg3zXX1qUyovzVGnBf0IDboBQllj9xU0KTC7uJNFLAr0G3ibYTsJN4DK8TD8T8tw0ic3R3eR9icmw/640?wx_fmt=jpeg)


　　

在对比图中柔宇着重突出了自家产品的优势，包括全球首发、售价、双卡双待与可弯折次数。

　　

价格方面，柔派FlexPai手机的价格要比华为Mate X和三星Galaxy Fold便宜得多，而刘自鸿在微博上表示美的设计有很多种。通过加入适当的曲线缝隙设计，既能使得手机拥有钱包的手握舒适感，也增添了独有的大自然曲线美。**“直线属于人类，曲线属于上帝”，这是柔宇和高迪具有高度共鸣的设计理念所在。**作为好产品，当然最终都要回归一点，就是让用户买得到，买得起，用得好。


![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4Yibczg3zXX1qUyovzVGnBf0Ijjx6FWZemaakz3kEiaTNvD01qicvpBAc0hsvQy9rLnmTJxEuP4ib4MQibQ/640?wx_fmt=png)


　　

此前，在小米曝光全球首款双折叠屏手机时，**柔宇科技副总裁樊俊超也曾在朋友圈炮轰小米，表示小米的双折叠屏手机只是别人尚未量产的概念性柔性概念机。**
