# 腾讯yoo视频被裁撤，业务团队整合进腾讯视频

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4Y8rOeSb4eIffnClzgImo3OBrkrdgOwpTJ61Mo4nVB79YFb0NYtpunMlHZAyHg1zaANY1vibJOEGVdA/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/ble6A0D39nDauosv0l2WpA

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8rOeSb4eIffnClzgImo3OB6h5C32vfPq5Dgah33hcVVsh8HmIs7tFU0pf4n63aHlHQBmr3l530Kw/640?wx_fmt=jpeg)


　　

科技先生3月29日讯，据全天候科技消息，去年腾讯力推的短视频产品yoo视频近期被裁撤，团队并入微视和腾讯视频，包括产品总监在内的几位核心成员被调往微视。

　　

**yoo视频与内容机构的内容采买合作已于今年1月中止，转由企鹅号结算。**

　　

据腾讯PCG(平台与内容事业群)内部人士告知，PCG正在对视频与短视频业务进行调整重构。目前，yoo视频以栏目形式出现在腾讯视频APP中。

　　

**3月28日晚，腾讯方面回应称，为了更好地探索长、短视频融合发展的方向，yoo视频业务团队整合调整到腾讯视频团队，仍保持正常运营。此次调整属于公司内部正常组织架构调整。**

　　

腾讯同时表示：“短视频是我们会持续关注和投入的领域。”


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8rOeSb4eIffnClzgImo3OB7uFbybkhQwEicUt28P8vjcj05XCVDTHjex2DSTaN3LhuNlm0yvnH7ZQ/640?wx_fmt=jpeg)


　　

据悉，yoo视频于2018年8月30日上线，并在11月的腾讯全球合作伙伴大会上正式亮相发布。继微视之后，**yoo视频是腾讯力推的又一个重磅短视频应用，被认为是一款“内部期望比微视还高”的产品。**

　　

从结果来看，yoo视频的市场反响并未达到预期。根据七麦数据统计，yoo视频总下载量在90.8万左右，未达到微视单月下载量的量级。

　　

目前，yoo视频在App Store娱乐榜上排在130名开外。
