# 华为官宣全球首款5G商用手机！折叠屏+巴龙5000基带

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4Y8xXFejj4Pc3HkTxr0kEp4EQejtHm1HmNfKuNdMx1uqf5VG6vb7GwW2gCRBb0ian9lv3Gs6rDsMMgg/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/hFrWBYKMcFccJLUYaMOQQA

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8xXFejj4Pc3HkTxr0kEp4EibsNsX2HibXgC4mdwkdicKptseUbmzIOkQKlmtdRuzCGeBticjLGVrvj2A/640?wx_fmt=jpeg)


　　

科技先生1月24日讯，今天上午，华为在5G发布会上发布了巴龙5000基带芯片。华为称，**这款是全球最强的5G基带芯片，峰值可达3.2G/秒**。与此同时，华为还推出了采用巴龙5000基带的CPE(5G数据终端)。支持NSA和SA双架构、支持3G、4G和5G，同时具备能耗更低、延迟更短。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8xXFejj4Pc3HkTxr0kEp4Epl4mP9JiboYbNfVkj8eQibUYKmVYnicdlRVaxcsWo7FyokfRtaWEW8PlA/640?wx_fmt=jpeg)


　　

余承东还在现场展示了搭载Balong 5000基带的首款5G终端CPE，也就是随身Wi-Fi。支持华为智能家居协议，覆盖增强30%，同时支持最新的Wi-Fi 6标准，多设备上网速率提升约4倍，是目前速度最快的随身Wi-Fi。

　　

**虽然小米创始人林斌提前曝光了小米的折叠屏手机，但仅仅是一款工程机，商用为时尚早。**


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8xXFejj4Pc3HkTxr0kEp4El3OoxSURP18Liaic4y3fzSVyibrJby4ZYN6CWiakza53hARK8OibwuAbNcA/640?wx_fmt=jpeg)


　　

**余承东还透露，华为会在今年的MWC展会上发布首款商用5G折叠屏手机，搭载自家麒麟980芯片和Balong 5000基带芯片。**


巴龙5000是全球首款单芯片多模5G芯片，可同时支持3G、4G和5G，具备能耗更低、延迟更短、超快网络连接速度等特性，将成为2019年华为旗舰手机的标配。
