# 美国白宫官员请求延期禁华为：担忧美国公司难以承受影响

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4Y8hTyUBkSTk2H7bf6tvMw5PgEu4WUibZ4uhibWhq8Hib7QCHIgibxMvw1eRZ8IoY3GYRKBTZystc8hCRw/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/MvVuVePE730pVdwGSyBh_w

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8hTyUBkSTk2H7bf6tvMw5PJKgx8iad3rGvzqITmYu6no0zOlolqwWyUhfDbOWdP0yObc4WMVP6jjA/640?wx_fmt=jpeg)


　　

科技先生6月10日讯，据路透社6月10日报道，近日美国白宫“管理和预算办公室”代理主管沃特写信给美国国会，**要求将限制中国华为的措施延期执行，以给那些与华为有业务往来的美国政府供应商更多时间进行调整。**

　　

白宫如今提出，禁令中涉及第三方承包商不得购买华为产品的部分，还需要额外的2年时间去进一步准备实施细则，而沃德在信中表示他希望这部分禁令可以在四年后再执行。


![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4Y8hTyUBkSTk2H7bf6tvMw5PN3fVqVCWiajEBPAOuOuFjaP4yibFyowT2VdNA2oLibVGDm5mRlzHPxMHw/640?wx_fmt=png)


　　

沃特称，只有将禁令延期执行，才能让禁令更有效地实施，而不会在仓促之下伤及“国家安全”。否则，如果所有限制令都在今年实施，沃特认为这会令能向美国政府供货的承包商数量“大幅减少”。

　　

**目前，国会方面并没有对沃德的这一要求进行回应，不过华为还处在缓冲时间内，一切还都存在变数。**

　　

值得注意的是，沃特希望延期执行的禁令与美国商务部单独将华为列入“实体清单”并不是一回事，并不会影响针对华为“实体清单”相关禁令的实施的时间。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8hTyUBkSTk2H7bf6tvMw5P4ibbfeB4AM6WJn18aYicXRmDV4McfrOO5NwaQLFza56qY8icglE2W60PQ/640?wx_fmt=jpeg)


　　

**上周有消息显示，谷歌针对断供华为一事后悔了，并且正在游说特朗普政府，争取进一步延迟实施，甚至完全豁免对华为禁令。**

　　

同时被曝光的信息还显示谷歌高层直言，“禁令会促使华为开发上线自己的操作系统”。届时这些华为手机的安全风险将会倍增。原因是这些系统并不是谷歌的Android官方更新。
