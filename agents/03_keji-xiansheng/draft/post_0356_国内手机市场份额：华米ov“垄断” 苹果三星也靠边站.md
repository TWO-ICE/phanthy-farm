# 国内手机市场份额：华米ov“垄断” 苹果三星也靠边站

市场调研机构IDC、Strategy Analytics、IHS Markit都送出了2018年第三季度智能手机出货量情况，整体出货量出现连续四个季度下滑，相比三星和苹果来说，中国手机厂商表现依旧抢眼，但也仅限华为、OPPO、vivo和小米，这四家已经基本垄断国内市场。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y80U4hOCSJ8nnGdFYOic8Kl46af9ZHEDMyrlPWPP4PmGuzmqfiacs6jmsLLia2TbxKgNRlbsHfTI6C6A/640?wx_fmt=jpeg)


先来IDC的数据报告，2018年第三季度全球智能手机出货量为3.552 亿部，同比下降了6%，具体到厂商方面，三星依然是第一，出货量7220万台，市场份额占比20.3%，而华为出货量增长30%以上（本季度出货5200万部、市场份额14.6%），连续两个季度超过苹果排在第二（苹果本季度出货4690万部，市场份额13.2%），而小米排第四增长20%以上，出货3430万台，占比9.7%，；OPPO排第五出货2990万台，占比8.4%。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y80U4hOCSJ8nnGdFYOic8Kl4p6XiaspnmAFfga4n0D6UZu9UNfOdoEIC6wtFBa3OMDbbO1YobQkJTzQ/640?wx_fmt=jpeg)


再来看IHS Markit的数据报告，华为本季度出货量为5200万台，市场份额达到了14.7%，其完全拉开了与苹果的差距，后者出货量4690万部，目前市场份额是13.2%。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y80U4hOCSJ8nnGdFYOic8Kl4ZwKn4cIgIicoGC3e5EUBMWIX1uAAxZUK91XLHo9waic84DY0PKD5SSNw/640?wx_fmt=jpeg)


国产手机中，小米、OPPO和vivo以及联想（包含摩托罗拉）都上榜，本季度出货量分别是3240万部（排名第四）、3120万部（排名第五）、2890万部（排名第六）和1070万部（排名第八），其对应的市场份额分别是9.1%、8.8%、8.1%和3%。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y80U4hOCSJ8nnGdFYOic8Kl4TTic6AqG3HvJc6QdupkQM1x6RT1q7KaRHsSSLo4BeTQFFic28yZZ2nOw/640?wx_fmt=jpeg)


另外一家调研机构Strategy Analytics给出的统计统计数据基本与IDC和IHS Markit保持一致，其中他们显示目前中国国内智能手机市场份额上，华为位列第一，而OPPO、小米、vivo和苹果分列二到五位，而联想跃居第六名。

小米刚发布的MIX3

从目前情况来看，国内智能手机市场的巨头垄断市场态势已经出现，对于身处第一梯队的前四家国产手机厂商来说，基本上霸占了整个手机厂商85%以上的市场份额，而苹果虽然位列第五，但是份额也都在被前四名给侵占。本季度联想手机增势凶猛，不过基本不会对前四名构成任何威胁，反倒是会跟魅族等第二梯队厂商相互竞争。

其实放眼全球智能手机市场，发展态势也是如此，巨头垄断了头部市场，这直接导致对其他一些品牌虹吸，面对国产手机高速发展态势，即便是全球老大的三星也难以招架，比如他们现在在中国基本没有了市场，而全球市场份额也是华为、小米、OPPO和vivo给疯狂挤占（第三季度中国四大厂商海外市场全部取得10%以上的高速增长，华为、小米海外表现尤为突出，华为大增60%，小米大增83%）。

Mate 20系列

三星在中国市场已经全面失守、苹果在中国的市场份额被挤占 ，这都是国产手机逆袭的一个体现，面对整体出货量下降的态势，国产手机依然保持着高速的增长模式，这完全得益于大家在海外市场的开拓。

目前，在意大利，希腊和印度等国家，华为和小米已经成为当地智能手机品牌领导品牌。现在印度智能手机市场竞争颇为激烈，今年的第三季度，小米在印度智能手机出货量超过了1200万部，同比增长了30%，超越了三星，夺得印度手机销量冠军，而华为、一加、OPPO和vivo同样表现不差，当地市场的业务增长幅度在10%以上。

此外，欧洲市场也在悄然发生变化，昔日这里是三星和苹果独霸天下的地方，但现在国内厂商通过更加激进的产品策略以及定价策略，辅以对渠道商更加优厚的补贴，正在接近头部厂商的份额。换句话说，国产厂商的安卓机型在世界其他大部分地区，尤其是亚洲和欧洲，非常受欢迎，而按照当前的态势，完全超越苹果和三星将不是难事。
