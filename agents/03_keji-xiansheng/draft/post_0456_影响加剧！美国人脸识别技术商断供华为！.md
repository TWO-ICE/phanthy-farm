# 影响加剧！美国人脸识别技术商断供华为！

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4Y824vbtICkicBOo7N0jEEjwTgAnQz9PhgVfp7uK4qTxyW5hPXlljwRl49XxE19hlTScjANtr6GExqA/0?wx_fmt=jpeg)

![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4Y824vbtICkicBOo7N0jEEjwTjOa8xEQMFwPDL5uDwA6l4D4VuQnSojDIWOQ0mR7MtdNtwnel3osxHQ/640?wx_fmt=png)


　　

科技先生5月21日讯，据美国之音今天报导，美国人脸识别技术商、光学零件开发商鲁门特姆(Lumentum)美东时间20日证实停止向华为出货。**这是继谷歌后，又一家美国公司因川普政府的禁令停止与华为的业务往来。**

　　

据悉，华为的业务占Lumentum公司上季总收入的18%。公司称，无法预测何时能恢复发货，并将第四季度的收入预期从此前的4.05亿-4.25亿美元，下调至3.75亿-3.9亿美元。

　　

报导指出，本周稍早，谷歌已停止与华为合作切断了硬件和一些软件服务供应，但不涉及可以通过公开资源获取的服务。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y824vbtICkicBOo7N0jEEjwTRicgZXetV7pZ9y1ZZ48l9ZyCM7G44c7PP82XNewTuGpdRT26oj4RXrg/640?wx_fmt=jpeg)


　　

虽然大多数美国公司尚未就其在华为禁令上的立场发表声明，但外媒报导称，**英特尔、高通、赛灵思和博通等华为主要供应商已告知其员工，不会在另行通知前向华为供货。**

　　

华为创始人兼首席执行官任正非周六表示，由于美国的限制，华为的增长“可能会放缓，但只会略有下降”，即使高通和其他美国供应商不出售芯片，华为也会“很好”。

　　

**他还表示，华为不会被华盛顿方面左右。“我们不会像中兴那样，在美国的要求下改变我们的管理层，也不会接受监管。”**
