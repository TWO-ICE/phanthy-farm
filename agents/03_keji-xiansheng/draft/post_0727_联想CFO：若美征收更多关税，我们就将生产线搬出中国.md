# 联想CFO：若美征收更多关税，我们就将生产线搬出中国

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4Yibd6lhJpT9UqCnmcb2LkMCowcyMxbGWDJVbvjBZ5wwJ75ylbCM8nuw2g9SsOe4fibWUlE4LBSKvUuA/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/sTqOJWu0yj44f7guUDoraA

![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4Yibd6lhJpT9UqCnmcb2LkMCo1ztqowKEtqbxy7niavuVz1vSz2jU8pEKYXHWyxhEIP12DMJMVuu1PTA/640?wx_fmt=png)


据美国媒体CNBC报道，联想首席财务官黄伟民 (WONG Wai Ming) 在接收 CNBC 采访时表示，如果美国对中国征收更多关税，全球最大的个人电脑制造商之一、中国科技公司联想可以将生产转移到其他国家。


报道中写道，联想表示，它在全球拥有制造业务，如果美国政府对中国征收额外关税，它可能会将生产转移到其它地方。CFO 表示：「我们显然做好了充分准备，以防万一。(“We obviously are well-prepared in the event that it happens,”)」


![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4Yibd6lhJpT9UqCnmcb2LkMCoGkQILdzxZ7APDjrC9fVFwFnyQ0hjM0MU0E7omnZ452Of7ttEb7NYBA/640?wx_fmt=png)


他补充称:“我们绝对有能力将部分生产……从中国等受影响的国家转移到我们可以继续生产的国家，那些我们认为不受关税影响的国家。”
