# 拼多多商家不满客户投诉，呼死你，寄一叠冥币

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4Yib6tDDPPfibaNt2puUtMdkB7JxJsFPZDiaraFfbcVLE0bPbd3fPF1UhaBK4EP5Elfea2hbEic8eP1u7Q/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/9cbj46GDFvk-v2p3mWotHA

拼多多平台买家谢女士不满意卖家发来的粘毛器，遂向拼多多客服投诉。投诉之后她经历了：“呼死你”骚扰、寄冥币恐吓。


11月22日，卖家逸辉家居用品企业店经营者之一周先生回复上游新闻记者称，用“呼死你”呼谢女士，是想和谢女士沟通投诉问题，但谢女士没接电话；冥币是他朋友胖2寄的，他是授意胖2恶搞一下谢女士，但没想到胖2寄了冥币。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Yib6tDDPPfibaNt2puUtMdkB7WOBddV6py3OTriaW3QtJJUwJKclOo9cK3T30u2ZafTAZdLpmKS2I3icw/640?wx_fmt=jpeg)


谢女士花5.42元买了一个粘毛器。

11月22日，谢女士在新浪旗下的消费者服务平台“黑猫投诉”投诉了一件事情：11月6日，她支付5.42元在拼多多购买了一个粘毛器，含60张撕纸和一个手柄；11月13日，她收到了货物，她自认为撕纸少了；11月14日，她向拼多多申请退款。

申请退款之后，谢女士噩运连连。

通话记录显示，在11月14日下午2时29分至下午4时许，她遭遇“呼死你”轰炸，“电话瘫痪了，我只能通过网络向拼多多客服投诉，直到下午4点，轰炸才停下来。后来款也退了，客服代卖家向我道歉。我以为这事完了，没想到更气人的在后面。”谢女士说。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Yib6tDDPPfibaNt2puUtMdkB7aiaEa0eWS8gyBF72K0w6FhCV5EBHYWmtzmoODEoeQiaeo68kA5beHicjw/640?wx_fmt=jpeg)


谢女士遭遇“呼死你”轰炸。


11月18日中午，谢女士收到了一个快递，打开来一看里面是厚厚的一叠冥币，单张面值为10万亿元。快递单显示，冥币是石家庄的陈先生邮寄的。


陈先生介绍，他也是拼多多的卖家。11月17日晚，网名叫胖2的买家花4.8元购买了这叠冥币，收获地址是谢女士的地址。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Yib6tDDPPfibaNt2puUtMdkB7tneCPGAMLrf87SPrld1qUEzBeI0U5dEf7b8icn1sab3CBLo2adcBtOA/640?wx_fmt=jpeg)


谢女士收到一叠冥币。


经上游新闻记者调查，“呼死你”骚扰、寄冥币恐吓，均与粘毛器卖家逸辉家居用品企业店有关。


该店经营者之一周先生介绍，拼多多客服将“谢女士退款投诉”转给他后，他多次用手机与谢女士联系，但谢女士没接电话。他一气之下，用了“呼死你”呼谢女士。


“我觉得我的货没问题，和谢女士联系，她没接电话；和拼多多客服反映，转来转去的。更让我生气的是拼多多没顾及我的意见，把我的号封了3天。”周先生说。


周先生介绍，被封号3天他自觉委屈，向朋友胖2吐槽，“我是让胖2恶搞谢女士，但我没想到胖2寄了冥币。”


直至上游新闻记者发稿时，拼多多仍未向谢女士反馈“收冥币”的处理结果。
