# 苹果开通微博“Apple 支持”，评论区翻车收到大量用户投诉

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4Y8ZHdk33U2cMia2WZCHbjUz4XYZPZiadtYTfPJcfhia5084U6eG99UIU6QnQj7s2egLg5bicibzLjjsPNQ/0?wx_fmt=jpeg)

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8ZHdk33U2cMia2WZCHbjUz4DlS9MwegFf5GuQUSJQtQyqKsctXaUzB9DtBxQI3skLAznicCR2ZXxPw/640?wx_fmt=jpeg)


科技先生4月24日讯，苹果电脑贸易(上海)有限公司昨日正式开通了官方微博@Apple支持，其发布的第一条微博引来了1万多网友留言和超1.6万个点赞。


截至目前，苹果官方微博账号共发布了3条微博，一天多的时间粉丝数量已经突破13万。**然而尴尬的是，在其微博评论区却上演了大型“翻车”现场，涌入了大量用户投诉信息，以及对苹果产品的吐槽等。**


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8ZHdk33U2cMia2WZCHbjUz4AhAAe2NMGwTdlvsy0DMMIVfEqxz0UpmTTpuia3dCrHicjOhBK6211NSA/640?wx_fmt=jpeg)


在它的第一条微博下，评论显然已经被苹果产品问题困扰的大量网友占领：**“XSMAX能换高通基带吗”“信号问题到底能不能解决”“XR屏幕阴阳屏能换不”“导航失灵不解释一下吗”……**


对于这些问题。苹果给出的答复大多都非常的官方，很多评论都直接回复：“非常感谢您的反馈，Apple非常重视每一位用户的建议。我们会帮助您记录您的相关反馈，您也可以自行通过 网页链接提交相应的反溃再次感谢您的热心帮助，谢谢。”并配上Product Feedback的链接。

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8ZHdk33U2cMia2WZCHbjUz4A7bIaHaUibrjkzojE1eheCibsI1Vb1nMr16Y93fIa2RmpNI9xzUPXY5g/640?wx_fmt=jpeg)


网友普遍关注度较高的问题集中在导航失灵、信号弱、卡顿、黑屏、阴阳屏等。网友在评论区的轮番质问让刚刚开通的苹果官博场面一度“惨烈”。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8ZHdk33U2cMia2WZCHbjUz4srSWw6GiaVWtic27up3dVstNeOr7U2DCDyrDNWosX1U7HicpkQ0phlULg/640?wx_fmt=jpeg)


此前苹果与高通因专利纠纷，苹果在iPhone XS Max、iPhone XR和iPhone XS上使用了英特尔基带，好消息是本月苹果与高通达成协议，解除双方在全球范围内的所有诉讼。


和解内容包括苹果公司向高通支付一笔费用。双方还达成了一份于2019年4月1日生效的为期六年的技术许可协议，包括一个延期两年的选项以及一份多年的芯片供应协议。
