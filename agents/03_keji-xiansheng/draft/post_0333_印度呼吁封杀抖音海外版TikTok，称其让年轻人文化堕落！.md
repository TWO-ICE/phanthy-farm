# 印度呼吁封杀抖音海外版TikTok，称其让年轻人文化堕落！

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4YibXDye9NeCWoiayC6vEHXrXmJVO9IjWic29ya2UvvDibndKuvNHDTqN6hclywJdv7PMtiab9ZIj5J7H9A/0?wx_fmt=jpeg)

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YibXDye9NeCWoiayC6vEHXrXm00GxbVwn4C8ibibczCYfAJdpv6ibicWFJbsdMHtRibyibZcw2PichdDdO3nVw/640?wx_fmt=jpeg)

　　

科技先生2月14日讯，据美国科技媒体The Verge 报道，有印度立法者称，Tik Tok (抖音海外版)将导致该国青少年和年轻人“文化堕落”，呼吁政府对这一应用采取行动。

　　

在最近的一个月，印尼通信与技术部就已开始监视抖音并收到了2853封投诉信件。在网站change.org上，关于请求印尼通信与技术部封锁抖音的请愿就得到了超过12.5万人的支持。

　　

**印度泰米尔纳德邦信息技术部长曼尼坎丹(M.Manikandan)表示，当地政府将建议在泰米尔纳德邦禁用TikTok。不过，印尼通信与技术部称，如果TikTok能够尽快清理平台，禁令可能会被取消。**

　　

印度泰米尔纳德邦的议员Thamimun Ansari称，在Tiktok上出现了不少有害于法律和秩序的激烈争论，并存在色情内容。如果政府不禁止这个APP，他的团队将跟进这个问题，寻求更好的监管。

　　

《新印度快报》的一篇报道称，2018年12月，36名青少年在TikTok上遭遇网络欺凌。

　　

据报道，有人甚至在TikTok上发布被欺凌视频后自杀。

　　

印度的立法者尤其关注露骨的性内容，包括深度换脸视频，以及曾被报道的极端网络欺凌案件。据今年1月份的统计，仅印度就有2000万活跃用户。

　　

TikTok的一位代表对此表示，该公司正在印度以外招聘一名首席节点官，以便“更好地与执法机构协调”。
