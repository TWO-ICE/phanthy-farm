# 杨元庆：联想没必要做操作系统和芯片！

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4Yibd6lhJpT9UqCnmcb2LkMCoQSj5PQT9kcE9zwAtf2U3FZEClPvErEVlILsOHxic3RD3HJehvDwYOZg/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/eznxR3IWc1E6_Na_1l5VEA

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Yibd6lhJpT9UqCnmcb2LkMCo704AX59phLiaoXZibpLNug2CbDuQ2d2icGw34sKibQUd8aesicYWDQHHLlQ/640?wx_fmt=jpeg)


　　

科技先生5月24日讯，在财报会议上，联想集团董事长兼CEO杨元庆表示，相信全球化是必然的趋势，一家公司没必要做所有的事情，**所以联想并不打算做操作系统和芯片，会做好自己的角色**，与值得信任的合作伙伴合作，为用户提供最好的产品。

　　

近日网络传闻联想断供华为，联想在深夜发布紧急声明予以澄清，仅仅两个小时后造谣者就公开道歉。


![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4Yibd6lhJpT9UqCnmcb2LkMCotcKeDQISb0WVJUKSterad6KuY8S4we6aGMoceqF0qDr9kADDd5Hzbw/640?wx_fmt=png)


　　

对于华为事件，杨元庆表示：联想是一家根植于中国的全球化企业，在世界市场中我们一直是备受信赖的企业，我们从来没有合规方面的问题，我们始终尊重并遵守各国的法律，同时联想是一家非常透明的企业，管理的标准很高。**从我们的管理层和董事会的组成来看，我们可能是最具多样性的跨国企业了，所以我认为别的市场没有理由针对我们。**

　　

杨元庆表示，华为一直是个人电脑的重要客户，**联想将在尊重各地法律的前提下，和所有客户保持业务关系，这其中包括华为。**


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Yibd6lhJpT9UqCnmcb2LkMCoHbnIhVuCib23e6FCsWgWnYGeEU0W6hpmbZEIryO1RjiacykibZ4s8LVZg/640?wx_fmt=jpeg)


　　

根据财报，联想集团2018年第四季度收入790亿元人民币，同比增长10.1%，净利润7.97亿元，同比增长261%，全年收入3420亿元(首次突破500亿美元)，年增12.5%，净利润40亿元，而上年是亏损12.7亿元。

　　

同时，这是联想收购IBM x86服务器业务、摩托罗拉移动业务以来，第一次实现所有主营业务收入、利润的双双提升，其中移动业务在下半年实现盈利，PC则重返全球第一，份额达23.4%。

　　

基于此，联想集团董事长兼CEO杨元庆发表了一番讲话，他说：“今天，联想转型已经初显成效，我们的业绩显著提升，而且更重要的是，**我们建立了新的能力，多业务操作系统日臻完善，未来发展的新基石已经具备雏形。这使得我们能够自豪地说，现在是联想的最好时刻。**”
