# 分析机构：未来数月iPhone在中国将大幅降价！

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4YibTXPRPCEIWkRSNicpz1yevTSpQCWWibJ38zooIyssyjDD5AGLT7IBXxSbCne7SXrlH1pUJOCTtXsVw/0?wx_fmt=jpeg)

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YibTXPRPCEIWkRSNicpz1yevTOxfKRUTMAniaqicfSPE8zkvUwQ1Tm4qLdezzyvNa7EXsoQ0pYjSx8D1g/640?wx_fmt=jpeg)


　　

科技先生1月15日讯，由iPhone销量下滑引发的一系列多米诺效应，正逐渐将苹果拉下神坛。曾被业内评为“永不打折”的苹果(Apple)手机就传来降价消息，而且这次降价幅度很大。这其中自然也包括新发布的iPhone XR与iPhone XS。

　　

**京东平台将iPhone8/8 Plus的价格下调至3999元和4799元，较变动前分别下调了600元和800元，与苹果官网报价5099元和5999元分别相差1100元和1200元。据澎湃新闻报道，京东方面表示此次降价行为是苹果公司降价，目前看不是限时促销。**

　　

苏宁手机官方微博表示，苏宁易购已大幅下调iPhone产品售价，其中iPhone XR 128GB版本到手价5799元，相较于苹果官网6999元的价格便宜了1200元。

　　

而此前，苹果一般在新款推出后，旧款才会降价。以高端价格销售高端产品一直是苹果推崇的定价理念，但在残酷的现实面前，苹果还是妥协了。

　　

一位中关村苹果手机渠道商表示，通过渠道价格的大幅调整，能够从侧面反映苹果官方出货价格的调整，例如渠道价降幅为500元，则官方出货价则远高于这一降幅，可能达1000元。

　　

美国投行Wedbush分析师丹尼尔·艾维斯(Daniel Ives)周一在报告中称，苹果iPhone将在中国大幅降价。艾维斯认为，iPhone在中国市场即将降价，而苹果也应该这样做。**他在报告中称：“我们预计，在未来数月iPhone XR将大幅降价。苹果在中国市场正面临‘红色警报’，为iPhone XR和未来型号的iPhone制定正确的价格策略，对于苹果而言至关重要。”**

　　

艾维斯认为，苹果之所以应该在中国市场降价销售iPhone，主要有两方面原因。首先，中国智能手机市场竞争激烈。艾维斯称：**“在中国市场，苹果面临着华为和小米的严峻挑战，苹果需要确保在未来几个季度内不会流失用户。”**
