# 共享汽车PonyCar突然下架！账户余额无法使用

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4Y8xXFejj4Pc3HkTxr0kEp4EI5FFrrd3cXGN0l2DSwia7EbexRZFwbZddDHwwcujUZPtsVeia29hfiapw/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/7Ak6-7P6j5IqSb2TiwUTyw

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8xXFejj4Pc3HkTxr0kEp4EkV243avxF6MlBvfD7DBYFyudODJl1ich8PIKrQ6sppyiaPAG9UXfRyMQ/640?wx_fmt=jpeg)


　　

科技先生1月24日讯，近日，共享汽车PonyCar用户陈先生反映，PonyCar的APP里所有共享汽车突然下架，自己还有数千元充值余额未用，多位车友有数千至万元的余额未提现成功。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8xXFejj4Pc3HkTxr0kEp4EvvDY0Wa7FzWyHrH1ianC0jSOwnY5yIzib2S0Mk9cXgo94QLQ83XSpEicQ/640?wx_fmt=jpeg)


　　

对此，PonyCar客服回应称：广州地区的所有车辆已经下架，不止广州地区，像是深圳、北京等地区，PonyCar的车辆均有减少。暂无重新上架车辆的具体时间，用户可通过APP发起余额提现申请，7个工作日内审核处理用户的提现申请。

　　

近来，共享汽车行业更是受到共享单车ofo影响，同样发生大面积抢退押金的大潮。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8xXFejj4Pc3HkTxr0kEp4E4bbYic5oPCTUNrzaQe8y7yKATMHYTrsezTIW6Olk6dgFbGXwzcMbWxQ/640?wx_fmt=jpeg)


　　

本月，有消费者向媒体反映，在TOGO途歌共享汽车app上缴纳的1500元押金，在申请退款两个多月后仍未到账。微博上，北京、广州、深圳等地消费者同样遭遇了退费难的问题。名为“集体起诉途歌—全地区”的qq群目前已近500人。


**途歌北京办公室目前只剩5名员工留守，负责接待线下退款的用户。对于消费者何时能收到退款以及公司下一步的计划，员工均表示不清楚。**


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8xXFejj4Pc3HkTxr0kEp4EZVPMyOQ0pIibEpEKchpRGscHic86n3ZhYPDR1Siasgia4qj4a16ibX07qJQ/640?wx_fmt=jpeg)


　　

根据网上公开资料显示，途歌目前已在北上广深四个城市投入运营，官方宣布注册用户已接近200万人。

　　

途歌相关工作人员表示，因为用户押金由第三方公司管理，上门登记退款的每日限额为15人，退押金的优先顺序按照登记顺序来，而不是在线申请的先后顺序。

　　

假设以整数200万的注册用户计算，按照途歌总部规定每天只能保证退款15人，那么全部完成退款则需要约365年。而以每位注册用户缴纳1500元押金计算，途歌共需要退还押金款30亿元人民币。
