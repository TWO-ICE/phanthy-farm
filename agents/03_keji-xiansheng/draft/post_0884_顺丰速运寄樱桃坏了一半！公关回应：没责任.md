# 顺丰速运寄樱桃坏了一半！公关回应：没责任

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4Y8Mnc61Eb6aL116wUWMrYgPaXvpd8Z90hk2saAXNpPx1UyVATib6vZqRx2jV0kX4C6oWY13yZZq4Yw/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/ZJ0wP_sxm2G6zlB0z8JCmQ

近日，湖北的李女士向本报反映，其花费860元用顺丰快递从山东泰安邮寄了100斤樱桃，到货后却出现冰袋破损、樱桃腐烂超一半的情况。对此顺丰快递官方客服回应称生鲜物品外包装不损坏、时效内送达不予理赔。


**花860元邮费寄樱桃，到货后烂一半**


“我之前曾在山东上学，知道山东的樱桃比较出名，正好樱桃熟了的季节，就想着从当地寄一些过来，还给朋友也寄了一些。”5月23日，李女士从泰安东平县购买了100斤樱桃，快递选择的顺丰，于当天由快递员包装好后邮寄到湖北以及北京等地。

　　

“樱桃是6元一斤，100斤是600元，快递费用的话10斤是86元，所以100斤樱桃光快递费用就860元。”整个订单，李女士花了1460元。

　　

**23日下午，李女士的订单打包完成开始邮寄，25日早上，李女士与朋友便收到了邮寄到家的樱桃，不过打开包装盒之后，李女士却看到自己买的樱桃出现腐烂，腐烂的樱桃数量占到一大半。**

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8Mnc61Eb6aL116wUWMrYgPVOLJoMGDCnn7K6wzgKot7qPPU2Avkw8aicOEZXt2gkiczobWFtZ9Gfjg/640?wx_fmt=jpeg)


　　

**“不光是我，我朋友收到的樱桃也出现了腐烂，包装盒里的冰袋都是破损的，里面的冰也化成了水，冰袋里的水都变热了。”李女士向记者表述道。**

　　

李女士对于樱桃出现腐烂的情况表示十分不解，自己花了近900元邮费寄来的樱桃却出现腐烂。“此前也曾用过顺丰快递，也是因为顺丰快递的冷链物流配送比较好所以才一直选择用顺丰，没想到此次出现这样的情况。”李女士说道。

　　

**顺丰回应时效内不予理赔**　　

随即，李女士便拨打了顺丰快递的官方客服热线，在了解李女士订单情况之后对方却回复：由于李女士的订单是在订单运送时效内送到，且外包装没有出现损坏，该情况下不予理赔。

　　

“他们这样说我就十分不解了，我花了860元快递费，盒子、冰袋包装都是用的他们自己操作的，送到之后樱桃腐烂他们却不予理赔，损失要我一人承担。况且盒子里的冰袋都已经坏了，就算外包装没有损坏，那也不能担保里面的樱桃是否好坏。”对于顺丰给出的说法，李女士十分不满意。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8Mnc61Eb6aL116wUWMrYgPjevEbs3eqibXW4lRXudKxGcDXjNCmvpb86pD9ibibuPN7rrMFDTUVWXxQ/640?wx_fmt=jpeg)


　　

“说好的冷链物流配送，现在冰袋都是坏的，樱桃受高温影响也出现腐烂，当初怎么承诺的冷链配送呢？况且他们一分钱都不赔，损失要我自己承担。”无奈之下，李女士再次拨打顺丰快的官方客服。


**经过李女士再次投诉，顺丰快递承诺只赔偿李女士一箱樱桃的钱，另外出现腐烂的9箱樱桃不予理赔。“我自己承担9箱的损失，这我肯定接受不了。”李女士说道。**

　　

**多次协商同意赔偿1000元**　　

随后，李女士与顺丰快递进行了多次协商，最终，顺丰快递同意赔偿李女士1000元作为补偿。

　　

针对李女士遇到的情况，记者联系顺丰快递济南地区相关负责人，对于在时效内不予理赔的说法，该负责人表示是规定。

　　

“**邮管局规定，生鲜物品的配送在72小时时效内，外包装没有损坏的话是不予理赔的。**而对于李女士出现的情况，我们其实很难界定是什么原因导致产品出现质量问题。也有可能是运送的樱桃中有坏了的果子，运输过程中就会导致其他的果子出现腐烂的情况。”该李姓负责人表示。

　　

此外，该负责人还表示，对于李女士这种特殊情况，顺丰客服会根据实际情况给出赔偿。“遇到这种难以界定问题出现在哪里的订单，我们客服会根据客户提供的实景情况给与理赔。”该负责人说道。
