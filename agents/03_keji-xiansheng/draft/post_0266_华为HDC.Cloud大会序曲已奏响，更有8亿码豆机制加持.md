# 华为HDC.Cloud大会序曲已奏响，更有8亿码豆机制加持

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4Y9ueecoU93t7yzNWKthHLKAIwgOibicibxNtBfnribDRbsDMl2NZIyD83ficTtxFCLNJQAls7ib7RfhRUnA/0?wx_fmt=jpeg)

**文｜柳华芳**

 

一场突如其来的新冠病毒疫情，改变了生活和商业，万众瞩目的华为开发者大会2020（Cloud），延期到3月27-28日，并采用线上形式。作为全球ICT领域最重要的技术盛会，华为的一举一动备受关注，也会对行业产生深刻影响，HDC.Cloud是一届非常独特的HDC大会。


华为早已做好了直播和互动的全部准备，没有因为疫情而取消大会，而是进行了会议形态、社群活动、DevRun Live开发者沙龙的模式创新，带来了耳目一新的全新玩法，也带来了更加有趣的开发者参与体验。


这段时间以来，华为一直用自己的方式支持抗疫，为火神山医院搭建网络，华为云WeLink为政府和企业提供在线协同办公。华为HDC.Cloud大会变成线上大会，是一次华为云实力的练兵，也是企业、社群的大型线上活动的一次模式预演。


华为开发者大会2020（Cloud）将于在3月27-28日正式开启，而大会序曲却早已启动，自2月28日起，"DevRun Live"线上开发者沙龙陆续开展，一边直播，一边互动，一边前沿科技，一边应用实践。通过华为云线上直播平台，每周一期，开发者可以观看技术沙龙的高清直播，并可进行实时聊天互动。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Yic53vCIXQiaibSuXpk0ftlQGrXsWfesxQIqku6lqAKIHcIyZn1hSrHEJObqK1EfmEI7xe2xA2Zdx2JA/640?wx_fmt=jpeg)


"DevRun Live"开发者沙龙


价值连城的线上技术盛宴


华为生态的开发者伙伴已经遍布政府、金融、教育、医疗、零售、智慧城市、HMS生态等各行各业，华为云是华为技术能力开放的窗口，HDC.Cloud影响力非常大。无论是基于鲲鹏、昇腾处理器的产品系列，还是5G、IoT等解决方案，都代表了产业方向，也是科技生产力的最直接代言。


"DevRun Live"开发者沙龙很有趣，并不是简单的视频对话或教授，背后还有一个超级强大的技术平台做支撑，这个平台就是华为云旗下的软件开发云DevCloud。DevCloud平台有一站式、全场景化的先进工具，可以在线进行代码检测、编译构建、项目管理、流水线、云测、移动应用测试等等，是华为强大开发实力和工程能力的一个开放输出。


在"DevRun Live"期间，开发者们可以了解技术趋势、学习最新实践应用、获取最新开发工具，一边给大脑充电，一边提升技术生产力。在"DevRun Live"分享的嘉宾，全是顶尖技术大牛，有华为内部大牛，也有开发者生态中的大咖。

一边直播，一边码豆


华为创新机制很有趣


过去，各种线下大会一般都会安排很多有趣的小活动，作为参会者的小甜点。这一次的HDC.Cloud大会全在线上进行，小甜点却不会缺席，华为打造了一套码豆奖励机制，一边看直播，一边得码豆，而码豆可以兑换奖品，也可以用于购买华为云产品。


![图片](https://mmbiz.qpic.cn/mmbiz_png/FcorJiclTfRxO4t2qUXRnBpM0uBaniaZ3mLkkM7cM1RK7icbRbDXMopSFdBicpznouJ5IBVu16r2Wk8dmqaaeVicSQQ/640?wx_fmt=png)


这届HDC.Cloud礼品多，除了帽子、纪念衫之类的常规项目，还有智能手环、智能音箱等众多华为智能终端产品，还拿出了旗舰机华为Mate30 5G版手机作为抢答环节的奖品。


而码豆则是创新有趣的小甜点，从"DevRun Live"到大会主题演讲，长达一个月的时间里，在华为云官网看直播、做分享、写代码、做检测等等众多活动环节、实践环节都可以积攒码豆，让线上HDC.Cloud大会变得更加轻松有趣。


开发者们的每一个线上参与，都将获得码豆激励，一共将发送出8亿码豆，此时此刻，码豆像麻豆一样性感，华为不愧是国际大厂。

线上版HDC.Cloud大会


形式独特，意义深远


这一届HDC Cloud大会没法线下举办，有些遗憾，却更有惊喜，在电脑、电视、平板或手机前都可以看直播，更重要的是，开发者们可以方便地进行即时实践。无论是华为IT基础设施、AI计算，还是先进的DevCloud平台，开发者都可以顺手深度体验一下。尤其是DevCloud平台，像代码检查、移动应用测试等工具，会大大提升开发效率，降低项目开发的边际成本，建议大家好好用一用，这个平台的先进程度应该是全球最顶尖水准的。


华为是一个全球性科技巨头，员工遍布全球，开发体系的在线协同机制也非常先进和成熟。在我看来，这一届线上版的HDC.Cloud大会，不仅展示了活动演讲内容的技术分享，也展示了华为技术体系的开发协同平台能力。开发者们不仅可以用华为的计算能力，也可以用上华为技术体系的工程能力，从而实现自己和团队的能力裂变。
