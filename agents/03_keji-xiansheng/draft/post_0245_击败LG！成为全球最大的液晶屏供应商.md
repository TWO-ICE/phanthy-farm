# 击败LG！成为全球最大的液晶屏供应商

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4YibXDye9NeCWoiayC6vEHXrXm5RZg1U6N5XtZibny1TIZxxrzjzPqDv43JvCQQQZPQ0t3jRnicrOcndaQ/0?wx_fmt=jpeg)

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YibXDye9NeCWoiayC6vEHXrXm0TGw6Y7x9nia8U40qILGibZlx4e9Cl5XIvolsA7rPCZkibnK4KKdrLNXw/640?wx_fmt=jpeg)


　　

科技先生2月14日讯，就全球而言，手机显示屏厂家屈指可数，其中的代表有三星、LG、夏普、索尼。这些都是韩国和日本的企业。在我国同样有一家闻名世界的手机屏幕制造商，它就是京东方。作为国内显示面板的领头羊，京东方2018年取得的成绩是令人瞩目的。

　　

**据统计机构Sigmaintell Consulting数据，京东方已经超越LG，成为全球最大的液晶电视和显示器面板供应商。**


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YibXDye9NeCWoiayC6vEHXrXmZqG8lvSKAic6J280eZBISRPjZ1dz57TyvoIicR7R2jBHHyKZiazrLd9yQ/640?wx_fmt=jpeg)


　　

统计报告显示，京东方2018年出货5430万个电视面板和3730万个显示器面板。相比之下，LG的这一数字分别为4860万和3450万。

　　

京东方披露，2018年公司申请专利9585件，其中发明专利占比超过90%，全球累计可用专利已超7万件，覆盖美国、韩国、日本、欧洲等地，其中美国专利授权量1634件，年增16%，排名升至第17。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YibXDye9NeCWoiayC6vEHXrXm94WWkblREfibPVSzYnohhnjCwRicLia9VSlPfGjjTCkkrQEibgyvVbff8A/640?wx_fmt=jpeg)


　　

All View Consulting(AVC)统计的另一项数据显示，2018年全球显示器面板出货量增长10%，达到1.51亿台；在总出货量方面，京东方的销量最高。

　　

**根据digitime的报道，显示面板行业的竞争预计将在2019年升温。**


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YibXDye9NeCWoiayC6vEHXrXmX3MRo3ibJFzX55StnlcFvgPgPiclvoz31PEVr5LlxHfRTNS5plfQEKpQ/640?wx_fmt=jpeg)


　　

最近，三星和华为的折叠屏手机将陆续发布，两款机型的较量也被不少用户看作是三星也华为的直接比拼。从产品意义上来讲，华为折叠屏手机的推出不仅表现出了自身拥有挑战三星的实力，同时三星的市场地位很可能会就此不保。

　　

现如今在全球能生产折叠屏的，主要有三大厂商，其中有两个都是韩国的，分别是三星和LG，而第三家京东方，则是来自中国的。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YibXDye9NeCWoiayC6vEHXrXmQYW5LJJpspuxYdDGFFkwF9OAvekUcvkQI2L3dkUDPfsXpyWwulnQMQ/640?wx_fmt=jpeg)


　　

根据产业链消息显示，华为折叠屏手机将会搭载一块8英寸柔性屏。该屏幕由京东方制造，这也表示三星在高品质柔性屏生产方面不再拥有垄断地位。

　　

对于京东方近几年在市场上的强势表现你有何看法，你认为京东方真的能够取代三星么，不妨对此谈谈你的观点。
