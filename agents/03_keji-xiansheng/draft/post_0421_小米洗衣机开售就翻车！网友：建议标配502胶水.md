# 小米洗衣机开售就翻车！网友：建议标配502胶水

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YicuRZpL0NdkgolJsJjl9YY5MwziaNxnleZySZhgGILoRbAxqGYcb8dibIfxRZfO0wicicicMXHNpib6h2eg/640?wx_fmt=jpeg)


　　

科技先生1月8日讯，上个月，小米正式对外发布米家互联网洗烘一体机10kg版，这款米家互联网洗烘一体机10kg版采用BLDC变频电机、1400高转速、一级能效、以及包含智能空气洗在内的21种洗涤模式，性能强劲、功能齐全。

　　

一款10kg的滚筒外加烘干功能的洗衣机，在市场价一般在4000元左右，一些大品牌基本都是卖到七八千的价格，**而小米米家互联网洗烘一体机的首发尝鲜价仅为1999元。**

　　

让不少米粉心动不已，在开售之后，这款洗衣机也是遭到了哄抢。雷军也是宣布首次开售3分5秒就售罄。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YicuRZpL0NdkgolJsJjl9YY51QibFsAYTibNTbna1L7E77faHGc58VX177YibrR3KqoBCOdlXrOyuopXw/640?wx_fmt=jpeg)


　　

然而在购买之后，不少网友就开始吐槽，小米洗衣机的门扣太容易断裂，从网友晒出的照片来看，在洗衣机“门锁钩”的地方出现了断裂的情况。

　　

**作为洗衣机这样的耐用品来说，刚用几次就发生这样的情况，后续根本没有办法正常使用！**

在洗衣机门锁断裂之后，不少米粉都选择了退货。但是也有心比较大的米粉：**使用了502胶水将其又粘了回去继续用！**
