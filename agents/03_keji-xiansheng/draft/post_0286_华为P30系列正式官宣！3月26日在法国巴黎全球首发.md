# 华为P30系列正式官宣！3月26日在法国巴黎全球首发

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4YicEK4aAdKPLu27rYa0m1z4YySpcFZ10vlVCPu1Pd5NTfp6YdNNe5ibYBxic066UYqcECKib04Ph66X8A/0?wx_fmt=jpeg)

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YicEK4aAdKPLu27rYa0m1z4Yib3wOibyzhj6EQOCMDKCiaicjgicZOa4QUXauUAW5Co4dBDW4p2oGhNibOnQ/640?wx_fmt=jpeg)


　　

科技先生2月19日讯，华为官方已经宣布，将于本月开幕的MWC 2019发布首款5G商用折叠屏手机。但是，在此次MWC 2019上并不会有网间传闻已久的华为上半年的旗舰机型——P30系列。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YicEK4aAdKPLu27rYa0m1z4YBN1J4DQzgfsv66ia6G4iafsFB27HNPibqVDF10cjgnkFzSJKbzicguHl3A/640?wx_fmt=jpeg)


　　

今天上午，华为手机官方微博发布了一则视频，正式宣布华为P30系列定于3月26日在法国巴黎全球首发。并且与往年一样，该机同样会有P30和P30 Pro这两款，至于会不会有保时捷版，目前还没有消息，不过理论上可能性还是非常大的。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YicEK4aAdKPLu27rYa0m1z4YyrXibVS6T7GBejpoMKoSU5ZjPGKib2beGkpZxwMEmNsbUzSvGM4ZSJCw/640?wx_fmt=jpeg)


　　

从视频来看，该机的主要卖点之一是长焦拍摄，而且在变焦能力上会有更强的表现，支持10倍混合变焦。**早先有爆料称，P30系列会搭载全新的CMOS传感器，并有望搭配潜望式摄像头来实现10倍光学变焦。**同时，P30 Pro还有望搭载四摄，其中一颗为TOF 3D传感器，可实现3D人脸识别、3D建模等功能。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YicEK4aAdKPLu27rYa0m1z4YcmZyCbeqISDEcJI4qDKw2op2rYAlDYjdIBgnNUfPiaV5PdV7oh7xCqg/640?wx_fmt=jpeg)


　　

至于外形方面，已有消息爆料华为P30 Pro、P30均采用水滴屏设计，同时前置镜头(包括CMOS)预计也保持一致;两款手机或将都支持屏幕指纹技术，因为手机前后都没有物理指纹模块，这也是华为P系列首款支持屏幕指纹识别的旗舰手机。


![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4YibnyTSr5ahnLC410nkFp9Lpk4LZicdxuuBHxS3oX3Q6PmFGQqicvCxwatzBYaWu3IvRicwq07TUoJYMA/640?wx_fmt=png)
