# 小马达，大梦想，这家英国公司征服了天下女人

**文 | 柳华芳**

　　

戴森，这个名字曾经很陌生，直到某一天，我太太大大表扬了我，因为我买了一台戴森无绳吸尘器，她说这是自己用过最棒的产品。

　　

这是一家英国公司，创始人詹姆士·戴森是一位传奇人物，被誉为“英国设计之王”，当然，这里的设计是“工业设计”，而不是意大利人的服装设计。

　　

从牛顿、图灵，到贝克汉姆，英国盛产科学家，也盛产窈窕绅士，很多人以为戴森是美国品牌，却忘记了现代工业文明的开启是英国。

　　英国绅士，征服天下女人


英国有不少顶尖科技名企，比如，ARM是芯片设计领域的无冕之王，像华为海思的麒麟芯片是基于ARM构架进行设计的。而戴森，是一个征服天下女人、征服时尚圈的科技企业。


长期以来，提到戴森，人们就会想到无绳吸尘器，因为戴森改变了吸尘器的笨重形象，打造了一代代经典产品，动力强劲、多吸头、全场景、体积小，为戴森赢得了全球家庭的喜爱。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YibG48Fd8qjVOHA0tI7tPzn4VzDPbCwpfbWxP1qqGTFicLTXwMZDJ9H4Inyxg1TztQQe8VzvUfS9trQ/640?wx_fmt=jpeg)

　　

如果说戴森吸尘器是家庭之友，那么，戴森Supersonic吹风机则是时尚之友。戴森重新定义了吹风机，让吹风机更像一个艺术品，改变了人们对吹风机的产品认知，戴森Supersonic吹风机握在手里像麦克风一样小巧。一经发布，在微信朋友圈引发了刷屏狂潮，独特外形，一夜之间成为女性人群、时尚圈的新宠。

　　

一个时尚高潮接着另一个，继戴森Supersonic吹风机取得巨大成功之后，戴森的第二款高科技美发产品——戴森Airwrap美发造型器再次掀起新的时尚狂潮。无需过高温度，仅利用高速的空气流动，就能轻松营造卷发、直发，或打造顺滑、蓬松效果，同时防止过热损伤，并能避免传统加热型造型器带来的梳子缠绕头发等问题。一经发布，又成为全球女性争相追捧的新宠。

　　

华人传奇武术家李小龙曾有一句名言：“我不怕会一万种花招的人，我只怕一招走天下的对手”。千招通，不如一招精，戴森就是聚焦少数产品，却做到极致的那种公司。


终极奥秘，尽在Motor从未被超越
“打着望远镜找不到对手”，马云的这句话很适合戴森。放眼家电甚至科技世界，戴森一直是最独特的那一个，他们不搞什么横向生态，不贪多求快，却能在吸尘器、干手器至吹风机、美发造型器等领域不断颠覆行业革命，究其根本，归功于戴森品牌的核心科技——数码马达。　　

二十年不变，聚焦于数码马达，累计投入3.5亿英镑，马达技术研发团队多达数百人，从吸尘器马达，到吹风机马达，戴森的数码马达技术已经炉火纯青，成为纵横江湖的绝杀技。

　　

据极客公园报道，戴森Supersonic吹风机配备的V9数码马达研发投入非常巨大。整个开发阶段，戴森实验室一共制造并测试的马达原型数高达 4865个，每一次仿真模拟少则消耗数小时，多则连续数日。最终，小巧灵动的它可被搭载吹风机的手柄处，比传统马达转速快 8 倍，而重量只有一半，直径也只有27毫米。不仅如此，V9数码马达因创新采用十三个叶轮设计，恰好保持其发出的部分声响超过了人类可感知的听觉频率上限，可最大化减少使用过程中产生的噪音，使用感更佳。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YibG48Fd8qjVOHA0tI7tPzn4nhYdVBdFEFFAxNU4PU3TmhnHeg1uwBX2KIiaIA86Sfew1hgLOQIr9pg/640?wx_fmt=jpeg)


更让人惊叹的是，这么精巧的数码马达早已实现了全自动生产。戴森拥有新加坡与菲律宾的两大先进制造中心，每个中心各安装了2条并行生产线，使戴森数码马达的装配几乎完全自动化，每2.3 秒制造一台马达，12 秒内自动完成质检，这真的太神奇了。

　　

直径只有27毫米的V9数码马达，没有1元硬币大，每分钟转速高达11万转，每秒钟可以推动13升的空气，彻底颠覆了美发造型领域。


对于吸尘器、干手器、吹风机和美发造型器领域，戴森的数码马达技术是一骑绝尘，就像手机、电脑的芯片一样，决定了产品的档次、品位、体验。相比众多没有核心技术的家电公司，戴森是一家世界顶尖的高科技公司，在超级数码马达的基础上，才有了重塑认知的产品设计创新。

　　“我们不是苹果”


说到“改变世界”、“颠覆行业”，大家很容易想到一个人，那就是苹果公司的创始人史蒂夫·乔布斯，他有句名言“活着就要改变世界”。事实上，很多人将戴森看做家电界的苹果，的确，戴森和苹果一样，是极简美学的代表，用技术创新、设计创新来改变世界，都是伟大的科技公司。

　　

戴森的创始人詹姆士·戴森喜欢人们称他为发明家，把发明创造看的比“爵士”头衔更重要(在英国，爵士是一种超级荣耀，放眼英超，也只有曼联功勋弗格森成为爵士，贝克汉姆都不行)，总是乐于创造，更能做到惟精惟一，一直在创造和定义产品，从未被超越，这是一种很高的境界。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YibG48Fd8qjVOHA0tI7tPzn46S1hW7uKQ6IwjMH2wj3S2gcI6tJl0YJDEDzU99UicKuwOicml87qbxvw/640?wx_fmt=jpeg)


“ 我们都会因为产品性能不佳而深感失望。身为设计工程师，解决此类问题就是我们的职责所在，我们始终致力于创造和提升。”正如詹姆士•戴森爵士所说，戴森数码马达不断进化。从V1发展到V11，体积、重量不断缩小的同时，性能却在翻倍提升，以科技之力为人们的日常生活带来了更好的解决方案。

　　

你可以想象一下，戴森创始人詹姆士·戴森更看中“发明家”头衔，而不是“爵士”，他更喜欢“寻找与众不同的科技手段，更好地解决日常生活容易忽略的问题”，没有惊天地泣鬼神的豪言壮语，却用自己的实际发明创造改变了世界。

　　精益求精，耕耘未来
重视研发，精益求精，是戴森走向成功的基础价值观，无数次实验，才有不同凡响的数码马达。当年，詹姆士·戴森研发自己的第一款明星产品——双气旋真空吸尘器，经历了 5127 个失败的原型机，不妥协，专注于解决问题，最终创造了历史。后来的每一代戴森数码马达，都是在反复的模拟实验和性能测试中诞生而来。如，V8数码马达在正式量产前，工程师们对新马达的不同设计和部件进行了约50万小时的测试，V10数码马达更是经历2500多个原型才铸就了最终的成品马达。　　

惟精惟一，研发创新，戴森不断超越自己，也更加重视未来，潜心培养未来的创新人才。2017年，戴森工程技术学院在威尔特郡成立，占地67亩，模式很大胆。学生有工资，无学费，一边工作，一边学习更加贴近创新一线。

　　

戴森将支付学生们四年课程的全部学费，第一年、第二年教授工程学基础知识，第三年、第四年将教授电子和机械工程学。学生可以在戴森的全球工程团队中带薪工作，接触真实的工程项目，参与开发未来的戴森技术。

　　

詹姆士·戴森给出的校园定位是「它不应当只是平淡乏味的学生校区，而是一件运用创新技术的工程作品」。

　　

如此强于研发、精于制造的戴森，始终坚守初心，以数码马达科技之力解决人们日常生活中容易忽略的实际问题，才能正中全球女性需求的靶心，才能当之无愧被称作世界“科技巨匠”。
