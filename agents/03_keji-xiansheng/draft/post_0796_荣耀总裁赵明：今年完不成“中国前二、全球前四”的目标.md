# 荣耀总裁赵明：今年完不成“中国前二、全球前四”的目标

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4YibtlBtvd3nA0ZJCHJicZTericQ4mPTQfh4iaiaohS8LjuiafWvGJqNwUQic4de9UVicFXSfFhEMXB61YIzyQ/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/eT6EkxFJ4sibMddKMMK6tQ

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YibtlBtvd3nA0ZJCHJicZTericdicCiawb7F0vDzrZzJqvXVvPD0aXUYbFCkYHYl75bU6YkWOyicXD49Zpg/640?wx_fmt=jpeg)


　　

科技先生4月19日讯，荣耀昨日发布最新手机荣耀20i。此前华为消费者业务CEO余承东宣布了华为、荣耀双品牌发展计划：**华为单品牌未来要做到全球第一，荣耀品牌做到中国前二，全球前四。**

　　

在发布会结束后，荣耀总裁赵明接受媒体采访，回答有关荣耀20i产品策略、荣耀销量目标等一系列热点问题。


![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4YibtlBtvd3nA0ZJCHJicZTericMicibcWU1oFJ6EyEWX4KqN6ZJKzCPAUUvaxu5kZddiaMpaPGmJyR3CXhA/640?wx_fmt=png)


　　

荣耀总裁赵明强调：“在国内，荣耀就是冲击前两名，甚至做第一。在全球市场，荣耀就是和华为、三星、苹果这样的品牌竞争。”但赵明也直言，**做到“中国前二、全球前四”不是今年的目标，“累死我也完不成。****”**

　　

目前荣耀手机在国内的市场份额仍旧稳定上升中，但是依然存在不少竞争对手，小米、OPPO等各大公司纷纷推出了子品牌，这在赵明看来，对荣耀没有太多的影响，“荣耀华为定位双品牌，是面向不同的用户群体和不同的产品经营方式，荣耀就是定位走更加年轻、潮流和时尚的路线。”


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YibtlBtvd3nA0ZJCHJicZTericmMdAsGt6lommkdQSNNCdOzLviaSJpjESpyAkiaoHToEnH57fxttjicgsg/640?wx_fmt=jpeg)


　　

荣耀最初定位是互联网手机品牌，但近年来也加大了对线下市场的重视。**赵明表示，荣耀今年会针对线下渠道进行优化和发展，比如在shopping mail开店，让荣耀走向核心商圈。**

　　

赵明表示，2019年手机行业是“疾风知劲草”的一年。荣耀要用产品、创新、服务、品质赢得胜利。全球战场、全新里程，困难越大，荣耀越大！我们必须抓住机遇，用“极具竞争力”的产品让用户满意，让荣耀更加荣耀。
