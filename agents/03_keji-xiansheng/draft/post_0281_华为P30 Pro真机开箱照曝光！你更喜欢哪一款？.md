# 华为P30 Pro真机开箱照曝光！你更喜欢哪一款？

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4Y9bJQfmG8dQiameTmicUqicIXABib7TwJQcbx7LrBbvnqKScjVZdp8ULbVYAnXiamAVVWSmGuicwoahLwGw/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/6zhRGZJJk7p08Dq-m68Gtw

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y9bJQfmG8dQiameTmicUqicIXALdczXcENLPibkKUDPwLawntSiciceOvjRRBNXIQKO4WfLrCV3oO9nRibCw/640?wx_fmt=jpeg)


　　

科技先生3月26日讯，今晚，华为将在巴黎发布华为P30系列产品，目前有关于这款产品的消息已经曝光了很多，大家的关注点也越来越细致。

　　

近日P系列新机又意外出现在了新加坡的官网上，看来此次在拍照素质上将会拥有重大的提升。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y9bJQfmG8dQiameTmicUqicIXAb99vYqia7mTYiagFic6NwmuSXjJFy7X7KVicPibakyzr5Eib3ZBga5YKjH9w/640?wx_fmt=jpeg)


　　

从外观来看，华为P30比P30 Pro要矮一些，整体上也要小一圈。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y9bJQfmG8dQiameTmicUqicIXAvEjhD18znEOQicw9XZiaCpYMkX9AhQuWvDpLQpjtj8fO5hKbIQtTnmww/640?wx_fmt=jpeg)


　　

根据现有消息爆料汇总，华为P30屏幕尺寸6.1英寸，P30 Pro屏幕尺寸6.47英寸(双曲面水滴屏设计)，分辨率都是2340*1080。

　　

**处理器方面，两者都将搭载麒麟980处理器，华为P30为3650mAh电池，而华为P30 Pro则为4200mAh电池。**


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y9bJQfmG8dQiameTmicUqicIXAJXPDFKmbI7T7Nd9Pg4WnCCQAHRC3CLNFsFBjHa0sAqicYo4ibmlaQhlQ/640?wx_fmt=jpeg)


　　

相机方面，新品或将搭配4000万主摄(光圈为F/1.8)+1600万广角镜头+800万(光圈为F/2.4)三摄，支持最高5倍光学变焦，支持激光对焦，并搭配双LED闪光灯。

　　

华为P30 Pro后置四摄像头，其中一颗为TOF镜头，还拥有超强的变焦能力和夜间拍摄能力。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y9bJQfmG8dQiameTmicUqicIXATy0H4UvrggzSJDT57vFuWy71k2GlMPu9HKjQyibLgXybxml8FgQX3NA/640?wx_fmt=jpeg)


　　

机身存储方面，华为P30/P30 Pro配备8GB+128GB/256GB/512GB三种存储规格，支持NM微型存储扩展。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y9bJQfmG8dQiameTmicUqicIXAUpsFxI5ibHdg3B0LEbJrfQiak7PVJY62iatwSojiarustBE6K4MxEkIzYA/640?wx_fmt=jpeg)


　　

**此外，华为P30 Pro还将支持屏幕指纹识别，有可能是光电屏幕指纹，这是华为P系列首款支持屏幕指纹识别的旗舰。**


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y9bJQfmG8dQiameTmicUqicIXAj2U6CicWQ20GSpblicmtGvkicFTSbrMibsNnFf4lUtQl7XnpCf78KXhic8g/640?wx_fmt=jpeg)


　　

另外，在曝光的华为新加坡官网页面中可以看到，新加坡地区的用户预购华为P30系列还能免费获赠华为Watch GT Active智能手表。


![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4YibnyTSr5ahnLC410nkFp9Lpk4LZicdxuuBHxS3oX3Q6PmFGQqicvCxwatzBYaWu3IvRicwq07TUoJYMA/640?wx_fmt=png)
