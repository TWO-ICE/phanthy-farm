# 三星S10真机流出，使用全新屏幕材质，屏下指纹略尴尬

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4YibXDye9NeCWoiayC6vEHXrXm1MB5ZKic6uHmseptb2IlIxUSdPG4Fr193wJPT3qzs4xIwOibfdBzqdbg/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/pmDpzAH5Q_81Q1fYd6y2pw

![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4YibXDye9NeCWoiayC6vEHXrXmCqqkJRxEqvp8uL6iaUxh8icSqsmQ4MMHuSWYcrzJy5VRvibwrBbiaTD9Lw/640?wx_fmt=png)


　　

科技先生2月14日讯，近日，网上出现了大量的三星S10系列真机曝光，让围观群众们是过足了瘾。尽管不少规格过去已经被陆续曝光，但从最新曝光视频的环境来看，应该是三星的内部培训流出。

　　

**值得注意的是，视频中手机的屏幕贴膜在中下部有一块镂空的圆形区域，可能是用于屏下指纹。**


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YibXDye9NeCWoiayC6vEHXrXmsRAHT5ia1ibRbLKYVH5CrDUh5vgWFt6icBBHkw0W7SyRr8e7M1C2n3fjg/640?wx_fmt=jpeg)


　　

外观方面，这款三星S10+外观基本和此前曝光的一致，极窄的额头和下巴，配上双曲面全面屏、再加上“Infinity-O”挖孔屏的震撼视觉观感，前置双摄位于右上角，具有双曲面屏幕。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YibXDye9NeCWoiayC6vEHXrXmgweDWm2ribptrOicMjoicdiaJHQLPhyI4GF1bQxNnxuDGHibEvwWsAJsWXA/640?wx_fmt=jpeg)


　　

三星S10系列首次采用了Dynamic AMOLED显示屏和支持HDR+显示技术，并且三星S10和S10+的显示屏还覆盖有大猩猩六代防护玻璃，分辨率将升级至3040×1440像素和具备19:9的纵横比例，而三星S10 E则仅支持FHD+分辨率，并且是大猩猩五代防护玻璃，以及改用了侧边指纹解锁技术。


**至于三星S10和S10+则首次采用了超声波3D屏下指纹扫描技术，并且和S10 E一样提供了面部识别功能。**


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YibXDye9NeCWoiayC6vEHXrXmJKWOQDCo3K06nUw8cbgX8CvJqtmCxj98Tjly16fMrnwuOW0QWs4HDA/640?wx_fmt=jpeg)


　　

硬件方面，处理器搭载8nm Exynos 9820芯片(中美地区预计是骁龙855)，S10e提供6+128GB和8+256GB两种存储配置，有白色、绿色、黑色和黄色，厚度7.9mm，重量150g。

　　

S10提供6+128GB、8+512GB存储配置，厚度7.8mm、重157g;S10+提供6+128GB、8+512GB和12GB+1TB配置，其中1TB型号独家提供陶瓷黑和陶瓷白机身，厚度7.8mm，重175g。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YibXDye9NeCWoiayC6vEHXrXmFrNHPAfWRJL6GibbE04VQtVlia0Xc9CsD8yf5FmYckxy0j9xKFiaSjVBA/640?wx_fmt=jpeg)


　　

电池容量上，S10e为3100mAh，S10为3400mAh，S10+为4100mAh，均支持无线反向充电技术。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YibXDye9NeCWoiayC6vEHXrXm6lTciaKiccROdDpN4zr52tnXelqHzoTL2xpYPA2nclkIGtIYbyF2yTww/640?wx_fmt=jpeg)


　　

**特色功能方面，S10e为侧面指纹，S10/S10+为正面超声波屏内指纹，最高屏幕亮度800尼特，慢动作视频的录制时长比S9提升一倍。**

　　

三星已经官宣将于北京时间2月21日凌晨3点发布Galaxy S10系列和折叠屏手机，届时将确定具体配置及价格。科技先生会持续跟进报道。
