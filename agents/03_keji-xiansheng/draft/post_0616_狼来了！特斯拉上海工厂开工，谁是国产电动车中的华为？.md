# 狼来了！特斯拉上海工厂开工，谁是国产电动车中的华为？

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4YicuRZpL0NdkgolJsJjl9YY5unX72SSU3sicpjz9Q6TUSnux778vfkcGlF2J4aiafDkt0kaKYXUFu73g/0?wx_fmt=jpeg)

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/7ic2h1TgQTHNBGY1fr1QpXYopfE7u19QicrhEmlsOAM4G0p7KfiajNBTYNA8o76aNYiadeTDuiaKg64QvnxOWK76ysA/640?wx_fmt=jpeg)


2019年1月7日，经过了半年准备，特斯拉超级工厂正式开工，厂址位于在上海临港产业区，总投资约500亿元，将是上海最大的外资制造业项目。


特斯拉上海超级工厂将分阶段投产，一期年生产规模为25万辆纯电动整车，将会生产Model 3，全部完工后，年产能将达50万辆，将是集研发、制造、销售等功能于一体。


Model 3是特斯拉入门电动车，是畅销车型，特点是超长续航里程、极致驾驶体验、全方位安全保护、智能科技，中国最新公布定价为49.9万，相当于一辆宝马5系起步版的价格。一旦特斯拉上海工厂投产，Model 3的国内价格可能拉低，并推动出货量大增，不过，从马斯克的表态来看，价格可能不变。


过去的六年里，特斯拉在中国开设了60个运营场所，建立了超过1,500个超级充电桩、1,850多个目的地充电桩，已经准备充分，正是放量生产的好时节。


智能汽车媒体-吉开网创始人Rocky表示，特斯拉在中国科技精英人群中已经有了初步种子用户规模，并有良好的口碑，以技术和设计形成了全球电动汽车领袖的形象，犹如当年的iPhone，上海工厂的开工将是真正的狼来了，中国电动汽车市场将巨变，特斯拉可能抢走高端电动汽车的大量份额。


Rocky认为，国产汽车工业发展的总体不错，但在高端市场依旧不行，传统高端汽车还是处于BBA统治下，电动汽车是弯道超车的机会，也将面对高端市场的争夺，只是我们正在寻找国产电动车中的华为。


**谁是国产电动车中的华为呢？**


是王传福的比亚迪，还是腾势汽车，还是拜腾、理想智造、蔚来汽车，或是吉利、长安等呢？高端电动汽车将是电动汽车较量中的肥沃市场，而特斯拉超级工厂的到来将是电动汽车战争的真正开始。
