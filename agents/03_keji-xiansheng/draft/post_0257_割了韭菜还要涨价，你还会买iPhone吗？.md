苹果公司业绩高增长的背后，是美好前景还是浮华陷阱？


8月1日，苹果公司发布了第三季度财报。财报显示，苹果第三财季净营收为533亿美元，比去年同期的454.1亿美元增长17%；净利润为115.19亿美元，比去年同期的87.17亿美元增长32%。

 

苹果公司CEO库克称，“这是苹果连续第四个季度实现两位数的营收增长。”

 


![图片](https://mmbiz.qpic.cn/mmbiz_png/wMMnh8HEhbwtp5eowhsal44lHMQOpkbWt3iaewmjzhh3URV6l1jhsK5rhy225UFI2pQSRntfEN851O6oFgyERlA/640?wx_fmt=png)


▲苹果2018第三季度财务数据 来源：Apple官网

 

中新经纬发现，虽然苹果公司在第三季度实现了32%的利润增长，但iPhone销量增长率并不高。据外媒报道，iPhone上季度销量为4.13亿部，与去年同期相比增长不足1%。

 

**苹果手机销量被华为反超**

 

虽然苹果公司曾在许多场合表示，售价999美元起的iPhone X是上季度最畅销的苹果手机，但苹果还是没能保住全球智能手机销量第二的位置，被华为反超。

 

7月31日，IDC（International Data Corporation）发布报告称，今年第二季度，苹果公司8年来首次从全球两大智能手机公司位置上跌落，华为超越苹果成为全球第二大手机公司，苹果位居第三。


![图片](https://mmbiz.qpic.cn/mmbiz_png/wMMnh8HEhbwtp5eowhsal44lHMQOpkbW8F2cBibDwPDK9oGy6VHFjy1z9PkZ3XXnzA8r9Ac9PNwMziaJmaEZ4kjw/640?wx_fmt=png)


▲全球智能手机销量排行 来源：IDC（International Data Corporation）

 

IDC数据显示，苹果第二季度的市场份额为12.1%，较去年同期的11.8%略有上升；华为手机销量则迎来大爆发，增长了40.9%，超越了苹果3.7个百分点，坐上了全球第二大手机厂商的宝座。

 

对此，独立TMT分析师付亮在接受中新经纬采访时表示，虽然苹果手机全球销量被华为反超，但这并不代表华为真的“超过”了苹果，这主要因为两家厂商的运营策略不同。

 

“在华为手机中有大量中低端产品，能够满足不同收入水平的用户购买手机的需求，其销量超越苹果其实是迟早的事。即使销量高，大多也只是毛利。而苹果手机面向的主要是高端用户，他在整个全球智能手机产业的利润占比超过了50%。”付亮说。

 

谈及苹果销量增长的乏力，付亮表示，苹果作为主要对标高端手机市场的厂商，想要突破目前的销量水平并不容易。“现在的智能手机市场已经触及销量天花板，想要突破现有领域进行革命性的创新，进而去吸引新的用户非常难。”他说。

 

付亮还称，目前苹果面临的最严峻的考验是如何稳定用户、维持高价，甚至进一步抬高价格。

 

**苹果手机能走稳高价销路吗？**

 

iPhone第三季度的平均售价达到了724美元，高于业内分析师预测的694美元。库克表示，尽管售价999美元的iPhone X比其他机型贵出了几百美元，它仍是上季度最畅销的苹果手机，也正是它推动了苹果的营收增长。

 

不难看出，虽然苹果手机Q3销量较去年仅增长了不到1%，但苹果公司对iPhone在该季度的营收额十分满意。8月1日，苹果公司也在官网宣布，预计在下一季度实现600~620亿美元的营收和38%~38.5%的毛利率增长。

 


![图片](https://mmbiz.qpic.cn/mmbiz_png/wMMnh8HEhbwtp5eowhsal44lHMQOpkbWJQSTOktNYZPllXxEI7Qv6omibQNjUPSMJCxUlxIGxSMf7ujia2xy6O7A/640?wx_fmt=png)


▲苹果公司第四财季预测 来源：苹果官网

 

此外，华尔街分析师预测，下一款苹果手机的售价可能会比iPhone X更高。在销售量增速乏力、iPhone售价不断走高的前提下，苹果公司的第四财季目标能实现吗？

 

通信行业观察家项立刚在接受中新经纬采访时表示，iPhone X涨价后，苹果手机具备了一定的价格基础，或许有望在第四季度实现与去年同期相比两位数的营收增长。但是从长期来看，苹果公司其实处于一个比较危险的发展阶段。

 

“目前苹果的处境是：创新难、用户少。因为手机售价高、创新点少，很难吸引新的用户，只能通过涨价来维护老用户，这其实就是在割老用户的韭菜。而且现在一些苹果用户已经慢慢发现苹果手机性价比在下降，也有一些用户转向选择安卓手机。如果苹果继续维持面向老用户的高价策略，很可能慢慢的损失用户，这对苹果来说并不是一件好事。”项立刚说。

 

正如项立刚所言，很多网友对iPhone X的使用体验评价并不高，苹果用户对苹果手机的满意度也在不断降低。

 


![图片](https://mmbiz.qpic.cn/mmbiz_png/wMMnh8HEhbwtp5eowhsal44lHMQOpkbWnctMxRv5aKNdXYf9mvofGX0eWT4oCmsiaGu7CjXa7tzz6bYEibBLW1sQ/640?wx_fmt=png)


▲网友吐槽 来源：新浪微博

 

阿瑟顿研究公司副总裁兼首席分析师Jean Baptiste也曾毫不客气的评论道“iPhone X是史上最差劲的苹果手机”，并在评论中列举了诸多用户体验的倒退。

 


![图片](https://mmbiz.qpic.cn/mmbiz_png/wMMnh8HEhbwtp5eowhsal44lHMQOpkbWGJqDEJiaianIoqlCcfbFJXIibJpCLfhbZicEGVrfeLrWZxAHlict75wia5iaQ/640?wx_fmt=png)


▲Jean Baptiste Su评iPhone X是最难用的苹果手机 来源：福布斯官网

 

谈及苹果手机能否走稳高价销路时，项立刚表示，“当创新不足、口碑逐渐下降的时候，苹果若仅靠品牌影响力来维持高价，可能会走向衰败。”

 

**订阅服务领域乱象丛生**

 

财报显示，苹果应用商店营收额已达到谷歌应用店的两倍，付费订阅营收额比去年增长了60%，这体现了苹果活跃用户的增长。

 

在苹果公司CEO库克和首席财务官马埃斯特里与金融分析师举行的财报分析师电话会议中，库克表示对苹果公司的服务业发展势头感到十分满意，并计划推出新的服务来促进增长。

 

然而，中新经纬注意到，央视某栏目曾在7月31日进行过标题为“苹果官方应用商店管理存漏洞”的综合报道，内容包括Apple Store 运用过程中出现的网络彩票、马甲包、非法App等多个层面的问题。据报道，在受访人拨打苹果客服电话询问非法App是为何能够通过审核成功上线时，客服却表示Apple Store并没有相关的App上线审核部门。由于苹果对资质审核不严格，导致大量国内非法App得以发布在苹果商店。

 


![图片](https://mmbiz.qpic.cn/mmbiz_png/wMMnh8HEhbwtp5eowhsal44lHMQOpkbWiaLRtJbx5d8LG5SqwUVBTicYvzqT193EfSUPY7F14eRmO2pnBKJhWJJw/640?wx_fmt=png)


▲央视“苹果应用商店管理漏洞”专题报道 来源：央视网

 

苹果官方的监管不严也导致苹果用户被大量“黄、赌、毒”类iMessage垃圾短信骚扰。中新经纬调查发现，在iMessage垃圾信息泛滥背后，有一条成熟的产业链。不仅有商家明码标价售卖iMessage群发设备、代发iMessage垃圾信息，用户的Apple ID 也疑似遭到泄漏和贩卖。

 

此外，苹果开通的意外充值退费系统还滋生了一条“代充值、代退费灰色产业链”。据中新经纬早期报道，许多“代充代退团队”利用Apple Store退费制度漏洞为网友提供充值、退款服务牟利，而应用开发商并不知道具体的退款账户，所购买的应用服务并未取消。


而苹果客服对此行为给出的回复是，“苹果对所有的退款申请都按照特定的标准进行审核，符合标准就会通过。而对于上述恶意退款现象，公司并未上限相应的处理程序或风控系统”。

 

不难发现，在苹果公司引以为傲的订阅服务背后，竟是疏于监管滋生的种种不法现象。而对于这些不法行为，苹果公司均未推出相应的监管措施。在这项令苹果公司“十分满意”服务业背后，竟是乱象丛生。
