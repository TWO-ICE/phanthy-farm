# 突发！华为员工在波兰被拘捕，被指控从事间谍活动

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y9SmYEDaJvTvpFiclPL632FasyBTzlTj74b5ewss0avybj6YHJXI8fwFAiayWg1VicHMnacjiaamg8QTg/640?wx_fmt=jpeg)


　　

科技先生1月11日讯，据路透社引述波兰媒体报道，波兰国家安全部门在当地时间周五逮捕了一名华为的中国雇员和一名波兰公民，指控他们涉嫌从事网络间谍活动。

　　

据波兰公共电视频道TVP报道，该名华为员工为当地的销售总监，波兰国家安全部门还搜查了华为技术有限公司在当地的一个办事处，以及波兰当地电信公司Orange Polska(OPL.WA)的办公室。

　　

波兰特勤局副局长Maciej Wasik表示，这一逮捕行动已经准备了很长时间，被逮捕的中国公民是在一家大型电子公司工作，另一个波兰人从事网络商业相关行业。

　　

据悉，华为自2004年进入波兰市场，从无到有、快速发展，成为运营商客户信赖的问计对象，并迅速成长为一个波兰消费者喜爱的的中高端品牌。早在2018年4月份，华为超越三星成功成为波兰最大的手机销售公司。

　　

2018年12月，华为消费者业务CEO余承东亲自宣布，东北欧地区部首个华为高级体验店“HUAWEI WARSZAWA"在波兰首都华沙盛大开业，两天里迎来近万人参与庆典。
