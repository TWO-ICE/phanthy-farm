# 如果不自研海思麒麟，华为这些年要花多少钱购买高通芯片？

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4Y9DDfrLnEOlbB9cWRx3tUXIw1kCquhhdqzds7JdO9cp4rdqYoVyQh65ia7jWsiboy4CZ9qI7OwJdXYg/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/6a_7Vx_ArBnRzRgv8tY1_g

芯片，在各大科技行业都有至关重要的作用。手机行业也是如此，之前的手机市场上，芯片领域一直被美国高通·韩国三星以及台湾联发科把控着主要市场。原来国内的手机厂商，都需要向它们采购芯片。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y9DDfrLnEOlbB9cWRx3tUXIs9yibiahkuG9023mVJaVXMLpSiath1N1ojCugkeDOYhYWxqPohtKUUG6w/640?wx_fmt=jpeg)


高通公司

芯片作为手机的命脉，一直被国外公司垄断着。一旦不给我们使用，中国就会陷入造不出手机的尴尬境地。像原来的安卓巨头HTC，正是由于被高通和三星卡住了供应链的脖子，旗舰机发布后却迟迟不能供货，最后销量惨淡，到现在已经退出了手机市场。

而华为，早早的做好了布局，在2004年就成立了海思半导体公司，在2012年推出了第一款手机芯片K3V2，但是说实话华为的首款芯片不是很成功，搭载这款芯片的Ascend D手机，散热和性能都不如人意。同时，高通公司向他抛出了橄榄枝，说只要华为放弃自研芯片，以后华为能以一半的价格拿到他们公司的高端芯片。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y9DDfrLnEOlbB9cWRx3tUXIWe4Qg6UmBOA1uqmEib3NJz8apwCzjFlljgFknloS8mkfUzxoLJLfb4A/640?wx_fmt=jpeg)


但是华为依然拒绝了，而后麒麟900·600和700三个系列的手机芯片，产品布局和实力依然不惧任何公司。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y9DDfrLnEOlbB9cWRx3tUXIibUWUIOBYsibruia07Y6icafibg7Xlm2CrDKclEYw7iaESvACEnY4L0TicKuw/640?wx_fmt=jpeg)


海思芯片

那么如果当初华为放弃自研芯片，那么这些年将会花多少钱来买高通的芯片呢？

据统计，2016年，2017，2018这三年，华为的手机销量大约是1亿，1.5亿和2亿，再加上前几年零零总总的来看，华为这些年手机出货量在6亿以上。华为的主要市场在高端领域，所以高端芯片采用的很多。如果将华为这些年出货2亿高端手机和四亿中低端手机来算，如果采用的是销量800系列和600系列，按雷总所说骁龙800系在500元以上，600系大概200元，那么这些年华为需要2000亿来购买芯片。不得不说，着称的上是天文数字了。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y9DDfrLnEOlbB9cWRx3tUXIjf0gUjgAS2r96LZOKuYApWrG6nicKKE9FVmLEd6BqZGQG39ichZqIrLw/640?wx_fmt=jpeg)


正是华为的战略眼光，使得华为的销量节节攀升，在去年第三季度销量超过苹果。以目前的市场情况来看，今年全年销量超过苹果也势在必得。不知道什么时候能达到余总所说的，成为世界第一呢？

对于华为，各位有什么看法，欢迎在评论区留言
