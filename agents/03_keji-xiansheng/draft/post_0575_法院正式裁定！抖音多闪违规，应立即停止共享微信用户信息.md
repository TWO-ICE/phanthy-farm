# 法院正式裁定！抖音多闪违规，应立即停止共享微信用户信息

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4Y9CSnCQyfEibWq4c2T1E0XDa3Sz2Y6Rrw7cU2UBLbN6uibA4qn16icgEeGricEm96lD93e3qpobegaB2A/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/jypLX3-yu2MV3Yyv6YL3GQ

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y9CSnCQyfEibWq4c2T1E0XDaicSCKPeSnZEhibHPBoiajjsBVbf3oZ7bLKhfGPTSLeYia2tRzwzIqVvPvA/640?wx_fmt=jpeg)


　　

科技先生3月20日讯，昨天下午，头条系旗下社交软件多闪向用户发送弹窗消息称：“由于腾讯方面的要求，希望用户修改在多闪或者微信上的账户头像与昵称。”**就此，腾讯回应称，关于某APP弹窗推送的信息，纯属偷换概念的无稽之谈。**


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y9CSnCQyfEibWq4c2T1E0XDaZNiamSEM1dMUE1ibbcSWz3uYlXP4iacHFT7wMTSjXcqobRfptwcQ9LtUQ/640?wx_fmt=jpeg)


　　

多闪相关负责人则称，用户昵称和头像都是用户自身授权同步登录的，属于用户自身特征数据，平台不宜擅自修改，所以多闪提醒用户自己修改。

　　

腾讯官方则表示，抖音违反诚信原则超范围和违规使用来源于微信、QQ的用户头像、昵称等数据，并擅自将腾讯提供给抖音的微信、QQ账号授权登录服务提供给多闪使用。**更严重的是，在用户仅注册了抖音、未注册多闪的情况下，多闪仍然非法从抖音获取了用户的微信、QQ头像和昵称。**


![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4Y9CSnCQyfEibWq4c2T1E0XDaS4SIdPjWiaBLvP9ibTne1MEq3LB7KrZZ5Sox2u8sUbdEnHzOHLaJQpLA/640?wx_fmt=png)


　　

针对此事，腾讯向天津滨海法院提起诉讼并申请行为禁令，主张对微信用户账号所有权，包含用户昵称和头像等权益，要求立即停止多闪产品中与QQ、微信用户头像和昵称相同的行为。

　　

**今日，天津市滨海新区人民法院今日公布了裁定结果，要求抖音立即停止将微信/QQ开放平台授权登录服务提供给多闪使用的行为，同时多闪此前通过抖音擅自获得的微信/QQ用户头像、昵称也被勒令停用。**
