# 三星大规模更新One UI，界面美到窒息！安卓9.0已正式推送！

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4Yiblrhia6SjDoltUz7bXPcwO11lG8qBsLj8O8NXMolI8dTw8XibrrJ4PibPn0W0d2R8GQK39vxz4KEZ8w/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/6YpcRFL0Brs5GHF5JKVNIQ

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Yiblrhia6SjDoltUz7bXPcwO13NFx5yhc443DhgxMptI4U0toxia0n99NIxfvz5cZ5386Izw5ROqDFcA/640?wx_fmt=jpeg)


　　

科技先生2月13日讯，三星去年11月初推出了全新的One UI系统界面，One UI是三星在其 2018 开发者大会上发布的全新系统，主要在视觉上进行了优化，采用了全新的设计，风格也更为简洁。对于大屏幕的手机更加友好。

　　

此前，三星在官方APP Members中公布了旗下机型的升级时间表。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Yiblrhia6SjDoltUz7bXPcwO1nPIuz3cibwgMUYbp9oTz9IXibL8FfwGTTjX24YsibpN0cf69mFWZ11WbA/640?wx_fmt=jpeg)


**但如果你是国行S9/S9+的用户，在2月14日就可以收到系统推送更新。**

**Galaxy Note9用户将于2月15日收到One UI正式版的更新推送。**


![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4Yiblrhia6SjDoltUz7bXPcwO1xtNVlicPxcZZkCITeRUNibcVLSia8ZYDBMenfnE2uUZ0xSEAJxKR3Qib9g/640?wx_fmt=png)


根据来自德国的消息，当地的Galaxy Note 9已开始收获正式版Android 9更新，其更新版本为N960FXXU2CRLT，并附上了最新一月份谷歌安全性更新包。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Yiblrhia6SjDoltUz7bXPcwO1Ah64icTzaX6hgmGXrZb17WOy2I2PdtLBZj1Cxz91tVGgd1wbL3LdFWQ/640?wx_fmt=jpeg)


　　

三星Galaxy Note 9在升级到Android 9.0后手机就会获得以下Android Pie新特性：

　　**全新OneUI界面设计**

**　　全新设计设置菜单、通知栏以及系统导航。**
