# 孙宇晨，你到底是不是骗子？

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4Y9RUURskJh4s2eGnDDXvURcsGoJQMySOHAATqcVm0USQia1mEg0J5DGwRGSpqvPRVWfmJRcc2q1sAw/0?wx_fmt=jpeg)

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y9RUURskJh4s2eGnDDXvURcv2j5G7fyUCOF9DNcg7Ygaylic8xPbhD2xtOKEg2cRsUNzibGAphkVUkQ/640?wx_fmt=jpeg)


　　

6月4日凌晨，2019年巴菲特午餐的竞拍胜出者揭晓：孙宇晨。竞得价格4567888美元(456万美元，按照当前汇率折合人民币3153万元)，创下巴菲特午餐竞拍价的历史新高。

　　

孙宇晨表示，午餐会的最重要话题是希望修正巴菲特价值投资理论，目前巴菲特对比特币等加密货币有偏见，希望通过交流会可以让巴菲特了解区块链和加密货币。**目前与巴菲特约定的慈善午餐时间为三季度、地点初定为旧金山，拟邀请比特大陆吴忌寒、火币网李林、V神等共同参加。**

　　

公开资料显示，孙宇晨出生于1990年7月，本科毕业于北京大学历史系，研究生就读于美国常青藤名校宾夕法尼亚大学，头顶“90后创业领袖”，马云湖畔大学首期学员等诸多光环。**但还有更多的争议：他是所谓的“币圈大佬”，波场(TRON)创始人，TRON基金会创始人，Bittorrent CEO。围绕他“套现跑路”、“抄袭”、“空气币”的质疑声不绝，甚至有人给他冠上了“币圈贾跃亭”的称号。**

　　

除去消息宣布前“干了件大事，三天后宣布”“让子弹飞一会”的两条预热微博，算上正式宣布拍得巴菲特午餐，孙宇晨在12小时内发了7条微博。“巴菲特会说波场是老鼠屎吗?”有网友问。“请不要侮辱老鼠。”

　　

在很多业内人士看来，巴菲特的惯有立场恰是对天价拍得巴菲特午餐的孙宇晨的讽刺。
