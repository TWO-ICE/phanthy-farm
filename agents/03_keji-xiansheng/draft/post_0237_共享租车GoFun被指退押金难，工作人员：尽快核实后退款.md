# 共享租车GoFun被指退押金难，工作人员：尽快核实后退款

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4YicFXcOgCRGbZrU5gNCXsojRDicBdSszY8AEFcmiaJbIiajicLtj0RRjEiaKjcvBY5ZqS6EvulFR4wpKkZg/0?wx_fmt=jpeg)

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YicFXcOgCRGbZrU5gNCXsojRsv5rb1DTlOOQgno0LqGOky7nyhmPZwaicXu8a0tk2h9AZYUfBDJuJ0w/640?wx_fmt=jpeg)


　　

科技先生1月22日讯，近日，有消费者表示，GoFun出现退押金难的情况，“1月3日申请退的699元押金，到现在GoFun都是‘无理由不退’”。“开始他们说是系统出现问题，原路退回不了，让填写银行卡号后，还是无理由不退。”

　　

近段时间，共享行业接连爆雷，在退押金难，维权无门等问题逐一显现的情况下，用户担心其他共享出行企业出现相同问题，选择将押金退回也未尝不可。

　　

**对此，GoFun相关工作人员回应，“技术还在查微信退款不成功的原因，我们会尽快核实并退还押金。”**

　　

据悉，GoFun出行是首汽集团旗下新能源分时共享平台，整合用户碎片化的用车需求，为用户提供便捷、绿色、快速、经济、时尚的城市公共交通出行解决方案。该租车模式下车辆无人值守，用车全程App操作，以“分钟+公里”计算并提供汽车的即取即用、分时租赁服务，消费者可按个人用车需求预订车辆。

　　

就在不久前，GoFun运营中心负责人唐远茂表示，共享汽车行业商业模式日益清晰，运营模式不断优化，更多社会资本、主机厂及大型互联网企业进入市场，市场竞争激烈，一批中小运营平台将被加速淘汰。未来随着头部企业规模化扩张及抢占行业核心资源，用户及资本将逐渐向头部企业集中。
