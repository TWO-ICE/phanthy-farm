# 贝店发公开信明确店主一级分销 2019使命再升级

1月16日，贝店发布2019用户公开信，宣布贝店使命升级为“让更多人过上更好生活”，同时透露在新使命的驱动下，贝店将加大对源头供应链的投入，明确店主的自购与一级分销行为，同时倡导建设良好的社群氛围，加强对宣传推广的监管。

 

2018年，贝店快速成长为社交电商领域的黑马，2019年对于贝店来说，更是实现自身跨越式发展的重要一年。

 

在用户场景打造和社群流量创新的基础上，新的一年里，贝店将持续以消费者为中心，强化“源头供应链”的品质理念，加大在品牌正品保障、原厂地直供体系建设、扶持优秀品质工厂等领域的投入和覆盖，建立起更为严苛的货品采购和售后服务体系，持续提升消费者的极致购物体验，构筑社群电商供应链的坚实底座，真正做到“让更多人过上更好生活”。


**贝店2019店主管理办法：明确一级分销行为**


近日，贝贝集团旗下社交电商平台贝店发布2019用户公开信，宣布在新使命的驱动下新一年的两大重点工作方向:


一、加大源头供应链投入，制定更为严苛的货品采购和售后服务体系，成立“贝店好货联盟”，并推出“三赔计划”（即 “假就赔、贵就赔、慢就赔”）。


二、明确店主的自购与一级分销行为，同时倡导建设良好的社群氛围，加强对宣传推广的监管进一步规范店主管理办法。


“2018年，贝店快速成长为社交电商领域的黑马，2019年对于贝店来说，更是实现自身跨越式发展的重要一年。”其在公开信中表示，截至目前，贝店在全国已与4485万用户建立了连接，覆盖全国96%以上的县市区域，为消费者提供了16万种商品，每月产生数千万个包裹。


此外，根据此前的官方数据，贝店MAU（月活）已达到千万量级，且保持每月环比30%以上的增速。2018年第四季度，贝店产生了一亿订单量，预计2019年可触达一亿用户。
