# 微软日本将试行“上4休3”制度，并发放6000元补贴！

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4Y9tQibZZjmom6NQ3gfeiaY7QCibtsicdn3JBQSicHicZ1p6bSGLpkibxciaxUbcYsdhDpK0LbHmssNxqibwgUA/0?wx_fmt=jpeg)

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y9tQibZZjmom6NQ3gfeiaY7QC8FicpPPCO0t6marDtBQlerdialutRxPMwREjAaatQwFjguwL97hL9vdA/640?wx_fmt=jpeg)


微软日本公开宣布：从2019年8月开始面向2300名正式员工，将试行“做四天休三天”的新工作制度，即8月份的所有周五都为休息日。


另外2020年的8月也将实施该制度，届时所有办公室在周五这一天都将关闭。该制度与公司推出的“工作生活如何选择”的项目相配合，旨在创造一种环境，让每个员工根据个人情况选择灵活的工作方式。


**除了周五这一天计入“特别带薪休假”，微软表现得非常大方，还愿意向员工提供一笔高达10万日元（约合人民币6000元）的补助。**


微软表示2019年8月份的所有星期五，相当于一个月多休息了5天，员工都可以不用上班，而且这些日子全部享受带薪休假待遇。微软表示该政策不是为了全面实施“一周三休”做铺垫，而是为了测试不同的工作方式是否更加有效。


据悉，如果8月份的试行成功，那么微软将会于一年后的2020年8月份正式启动“一周三休”制度。
