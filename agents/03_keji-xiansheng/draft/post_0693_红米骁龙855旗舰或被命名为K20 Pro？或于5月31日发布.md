# 红米骁龙855旗舰或被命名为K20 Pro？或于5月31日发布

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4Y97zibHlwC6QaomsL3XJCQNRayeCnQ7q2kdSTwQhW3ibSiaRR7Q5l1EnDGn8hoQSicNtyWsLMpwAoElvA/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/qBXVf2imZNm526ZG1jO8WA

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y97zibHlwC6QaomsL3XJCQNRXyHjzWcTib6sN6l5AtDpZ8qqHRlmiaZHnJ20y17zejfbg3zryhColSNg/640?wx_fmt=jpeg)


　　

科技先生5月6日讯，目前有关红米旗舰的命名有多种传闻，其中一种名为“Redmi X”，Redmi品牌总经理卢伟冰还在微博辟谣称，新机“不叫Redmi X，会有更好的名字。”

　　

今日有网友在微博上曝光了一张名为“Redmi K20 Pro”的手机出厂贴膜。**从贴膜上显示的相关配置信息来看，该机很有可能就是小米旗下Redmi品牌的第一款骁龙855旗舰。**


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y97zibHlwC6QaomsL3XJCQNRAqkp1RgRwrhe8pqVj4Gy80iacREUnTPllfibp1FYv0mArzIQGhuib2YBw/640?wx_fmt=jpeg)


　　

图片显示，该机被命名为K20 Pro，在使用了骁龙855处理器之外，**还拥有6.39英寸AMOLED全面屏+屏幕指纹，索尼4800万超广角三摄相机+前置2000万升降式摄像头，搭配4000mAh电池以及27W的有线快充。**根据之前的报道，该机还将支持NFC，保留耳机孔。

　　

核心配置上，红米旗舰将搭载高通骁龙855旗舰平台，该平台基于7nm工艺制程打造，采用全新的三丛集八核心架构，具体由1×2.84GHz超级大核+3×2.42GHz大核+4×1.8GHz小核组成，安兔兔跑分高达38万。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y97zibHlwC6QaomsL3XJCQNRMUawQmZW1xWFEjIQN0csVowsrbTr72HyxVTgxiblNexFplEOY9fTvGw/640?wx_fmt=jpeg)


　　

卢伟冰强调，红米Redmi要向一切不合理定价宣战，Redmi就是性价比之王。**考虑到Redmi的定位，该机也很有可能成为最便宜的骁龙855手机，甚至对小米的855旗舰小米9构成威胁。**
