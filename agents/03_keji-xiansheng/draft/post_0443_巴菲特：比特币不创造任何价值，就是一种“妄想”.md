# 巴菲特：比特币不创造任何价值，就是一种“妄想”

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4Y85Ofib8Ly69gt2qFkUdoz6lrOyiccb4xJRqYB7uGXC9a4pMHuRV9Td4ZzfRC9TEuZBfSDU9ICkIr5Q/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/q3FMAUsuN6vZh6HdpMe_Tg

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y85Ofib8Ly69gt2qFkUdoz6lU6pNm9gl8BpfYYS6He2PwUIFe8wdicLTUJicENbrGIhPCDNoFx37QXgw/640?wx_fmt=jpeg)


　　

科技先生2月26日讯，2月25日，巴菲特在接受CNBC专访时表示：比特币本身没有任何实际价值，也不能产生任何价值。你一整天就盯着比特币，看它涨涨跌跌，实际就是一种幻想。

　　

早在去年1月，巴菲特在接受CNBC采访时就曾表示，他永远不会投资比特币。他说：**“对于加密数字货币，我几乎可以肯定地说，它不会有好的结局。至于这种糟糕的结局何时到来，以及究竟有多么糟糕，目前还不好判断。”**

　　

去年5月，巴菲特又称，比特币不创造任何价值，购买比特币也并不属于投资。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y85Ofib8Ly69gt2qFkUdoz6l2mQIQSObMgUvc8hibpb5b1uSia013aInflkDvPFaOqsos4mEdOSo5QrA/640?wx_fmt=jpeg)


　　

巴菲特当时说：“比特币本身并不创造任何东西，当你购买这种非生产性资产时，你唯一期待的就是，下一个人愿意出高价购买你的比特币，因为这个人也和你一样，在期待下一位愿意出更高价格的买家。”

　　

巴菲特长期以来一直是一位加密货币批评者。在伯克希尔哈撒韦公司(Berkshire Hathaway) 2018年年度股东大会召开之前，他称比特币“可能是老鼠药”。根据以往的报道，巴菲特曾用“海市蜃楼”、“非货币”和“郁金香”等负面词语来形容比特币。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y85Ofib8Ly69gt2qFkUdoz6lveKJuQlaNXqPEZtwOGHuAdRMQ1IrQWGbawJ3liblOneUl9SAePJSRpw/640?wx_fmt=jpeg)


　　

不仅是比特币，巴菲特还表示加密货币都将“结局惨淡”。在2018年1月份，巴菲特预测了加密货币的消亡。同样是在CNBC的采访中，巴菲特表示：**“总体而言，就加密货币来说，我几乎可以肯定地说，它们会有一个糟糕的结局，至于什么时候发生或如何发生等等，我并不知道。”**

　　

比特币自2017年底达到近2万美元的高点以来，已经贬值逾80%。
