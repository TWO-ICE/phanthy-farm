# 热爱90后吧，只有他们是正常人

文/柳华芳


电商SaaS企业有赞火了，不是彤彤的新年火焰，却是变相裁员、员工尊重等话题，在科技巨头裁员大潮中，强行抢戏，也惹来众人吐槽和批判。


95后一代成为话题中的人群，也意外成为有赞裁员事件中的最受伤一波人，有人说“95后不再被原谅”，有人鼓励95后要猪坚强。


虽然看起来是对95后有些同情和鼓励，却莫名其妙地再次将一代人标签化，而90后一代是讨厌别人贴标签的自由灵魂一代。


90后很不错，并非巨婴一代


在过往的各种文章中，时常见到妖魔化90后的文章，把90后描绘成不服管教、任性自我、不守规则的样子，现在这种抹黑或标签化正在来到95后一代，仅此而已。 


想想当年80后的遭遇，不也被说成垮掉的一代么，如今很多80后却拿类似的逻辑来抹黑90后一代，实在是很无聊。


无论是80 90 95， 学习、工作、乃至亲嘴的姿势都是千差万别，喜欢的音乐、明星也很大不同，每一代人没有必要否定另外一代人的精神世界。


别说一代人了，就算是同代人的人群里，也是五花八门，每个人都会认为自己是合理正确的，潜意识里会对抗别人的价值存在，这是社会心理学的问题。


过去，90后总被称为傻白甜，只关注了胶原蛋白，没有关注灵魂世界。 80们用无力的沧桑经历才积累起开自己的自信力，用父母的钱买自己的房子而心安理得，刚有了点资本而已，何必靠挪揄下一代而自证高明呢？


90后一代很不错，有想法，爱学习，敢想敢干，爱说真话，他们正在实现了不起的成长，他们不是巨婴一代，也不是脆弱的温室花朵，只是更早接触互联网的正常一代。


此处不留爷，自有留爷处


经济不好的时候，企业更愿意要即插即用的人，而没有耐心培养白纸新人，这是正常现象，大小公司都一样，跟道德高尚与否无关。


挺难的，生活在大城市，很多人都是996状态，大部分加班其实是用来对冲生活成本上升的，牛逼的企业毕竟是少数。解决方案是裁员，或者搬到便宜一点的地方，或者在技术后端做到足够牛逼。


对于90后一代，哪怕是更年轻的95后一代，微笑面对一切就好，比起屡战屡败的中国男足，一点挫折真错不了什么。


我公司一直是90员工为主体，来来往往，留用也好，裁员也罢，不代表老板就是对的，也不代表95后们不行，只是学习专业、行业等要素匹配不准确而已。


遥想当年，我数学系退学生，应聘个百度销售，人家都不要，以为我是作奸犯科之流，最后，我也踏实搞我的互联网梦想去了。阴错阳差，25岁时候已经圈子里小有名气，认识了很多大佬朋友，可惜那时候比较二，努力躲着钱，稀里糊涂地飘了很多年。


在我看来，90后一代思想挺成熟的，学习能力总体很不错，只是沟通方式需要更民主一些，不能把过去简单粗暴的落后模式当成光辉伟岸。


前几天，一位90后妹子来我家看望我太太和女儿，听说她正在规划给父母在烟台买房，感叹不已，真的了不起，这个雄心和孝心是太美好了。我像她这么大的时候，还处于草根创业的各种不确定之中，内心很二逼，远远不如这位小姐姐的心智。


90后一代已成为企业基层力量，95后的就业期不幸遇到了经济不景气，这不是他们能够决定的，也没必要要求他们拥有超越年龄的能力和成熟。


做好自己，选择热爱，此处不留爷，自有留爷处，不需要被原谅，也不需要被同情，认知规律在哪一代都一样，也不必非要像上几代人那样思考。


热爱90后吧，只有他们是正常人


可以负责任的说，过去几十年里，60 70 80经历了非常规的国家变化，在高歌猛进的时代里，机遇确实遍地是，加上童年生活艰苦的低社会预期，这三代人不是正常人。


一代人长期处于巨大压力中，潜意识里会把很多不公、苦难、甚至丑陋当成正常现象，内心深处却是压抑的灵魂。


相比之下，90后一代生活更加舒适正常，他们的灵魂不是被压抑或扭曲的，更容易地展示纯真的人性力量，也更容易展示美好真实的东西。


工具使用的熟练度，知识体系的厚度，这些都不是问题，因为很多厚度本身就是无病呻吟。就像90后不需要摇滚乐，因为没那么多怨愤和不平，没必要为赋新词强说愁。


我相信，等我女儿长大的二十年后，我们会看到更了不起一代的年轻人，进化一直在发生。我们没必要像管理动物园野兽一样看待年轻人，年轻一代总有更纯真干净的灵魂。


996工作机制，不是好东西，我不喜欢加班，不喜欢周末工作，所以，不希望员工周末工作，他们有自己的世界需要去打理。


不能成为长期伙伴的，说声抱歉，祝前程似锦，再相遇，是朋友。


德聚仁和，兼爱真诚。
