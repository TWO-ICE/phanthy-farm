# 中国电信董事长杨杰出任中国移动董事长

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4Y9zDNIjx9qYzjqvUQZCnCkREUic6WFqH9pPThe53My1zz6ZoM825UF4tLPh1Ficy8YzdOpBexrK1Xag/0?wx_fmt=jpeg)

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y9zDNIjx9qYzjqvUQZCnCkRibPHmaZ1vlO3a94TsCia0P4iaSEOE3xkdbVAC30HKQpDgQiaibVyH2T0Kjw/640?wx_fmt=jpeg)


　　

科技先生3月4日讯，今日有消息称，中国电信董事长杨杰调任中国移动，担任董事长。中国移动官方证实此消息。内部人士透露，原董事长尚冰或退休。

　　

与此同时，有运营商人士也在微信朋友圈分享了，今早在中国电信集团总部杨杰的欢送仪式。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y9zDNIjx9qYzjqvUQZCnCkRmDVrLsADeDMLhael7OHicyJh25zFm3qfyscND0GzHmibM5g6JvfHynjg/640?wx_fmt=jpeg)


　　

资料显示，杨杰，1962年7月出生，1984年8月参加工作，中共党员，教授级高级工程师，大学本科学历，硕士学位。1984年北京邮电学院无线电工程专业毕业，获得工学学士学位，2003年获挪威管理学院管理学硕士学位。

　　

历任：山西省电信公司总经理、党组书记，中国电信北方电信事业部总经理，中国电信集团公司副总经理、党组成员，中国电信集团公司总经理、党组成员等职务。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y9zDNIjx9qYzjqvUQZCnCkRv8vxhsxg0Ie6m7QwsBlKLGEWplEPyf5XKAOUic6OIxknYW21DQEibRag/640?wx_fmt=jpeg)


　　

2016年4月11日，在中国电信集团的中层以上管理人员大会上，杨杰被任命为中国电信集团公司董事长、党组书记。

　　

在2015年，中组部曾宣布，原中国移动董事长奚国华退休，当时奚国华的年龄就是64岁。时任工信部副部长的尚冰接任中国移动通信集团公司董事长、党组书记。

　　

电信业高层每三到四年轮换任职是传统。目前，尚不清楚尚冰下一步去向及杨杰的接任者。官方表示，稍后会对外公布。
