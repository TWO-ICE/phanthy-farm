# 华为Mate X发布之后，荣耀暗示旗下首款折叠屏即将发布

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4Yibczg3zXX1qUyovzVGnBf0I5wxFjrvichLNRBw3ia2fmE4eKoVJoOv7RCicBKgkuNO1I9smqIfSHcB0w/0?wx_fmt=jpeg)

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Yibczg3zXX1qUyovzVGnBf0I7Z4MNLBIk2Ad3pj2ge7ibkfEF67LXW001pibsDQ8GzWzP5nuT6fsGZhQ/640?wx_fmt=jpeg)


　　

科技先生2月25日讯，昨晚，华为在巴塞罗那推出旗下首款折叠屏5G智能手机Mate X后，有网友在知乎提问“如何评价华为在MWC2019上发布的Mate X”。

　　

对此荣耀手机官方认证帐号表示，**太亮了，眼睛都睁不开，似乎远远有一个声音在说，华为已经拥有了，荣耀还会远吗？**并配上一张图读懂华为Mate X。

　　

似乎暗示了荣耀的折叠屏手机正在研发之中，未来将会有荣耀品牌的折叠屏手机。


![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4Yibczg3zXX1qUyovzVGnBf0IgmIJHBVtxcyqab55ZwxD7eVB4MycqzCibNIdoPV1OtFMNNYaBuz6qxg/640?wx_fmt=png)


　　

华为Mate X采用独创转轴设计、鹰翼式外折方案，可实现0-180度自由翻折，开合有度;整机轻薄有质，机身单边厚度仅为5.4mm，舒适握感。

　　

该机采用柔性折叠屏，采用可折叠全面屏设计，展开时可达8英寸，无限拓款视野的边界。轻轻翻折，又能成为可单手掌控的6.6英寸屏幕，另一块屏幕尺寸则为6.38寸。此外，该机还搭载高达55W的快充。

　　

华为消费者业务手机产品线总裁何刚接受媒体采访时表示，**华为Mate X是量产机，而不是概念产品，发布会上已经公布了发售时间(2019年年中)，但具体有多少，要看市场反馈。**
