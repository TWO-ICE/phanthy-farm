# 华为发布5G折叠屏手机Mate X，合上无缝隙 整整研发3年！

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4YibrExb2afZqia8AoujmQPwfM6BxOmnc7tb62x8zxn0bdRibunlHzuMPA0liaZhWhFY95TO8m9Cia7gH7A/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/xrgqtoEcsXKUmqhd0PvAmg

![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4YibrExb2afZqia8AoujmQPwfMYmTuOuS3N6U5dkMck6gvXlzCFPatTgeDnwNbib2MoB13PcMNWSiaR7Zg/640?wx_fmt=png)


　　

科技先生2月24日讯，在MWC2019上，华为正式发布5G折叠屏手机Mate X，这是继续三星之后，全球第二家推出折叠手机的厂家。

　　

华为消费者业务CEO余承东透露，与其他折叠手机不同的是，Mate X 合起来时不会在中间留个缝隙。**余承东说，为了让合起来无缝隙，工程师研究了整整3年才解决这个问题，“这个折叠链条里，有超过100个零件”。**


![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4YibrExb2afZqia8AoujmQPwfMo4ZZESz0dScaArNOh7ONE96tSeQQNJ2UZ51K35WibwlR9ghBSwEF1IA/640?wx_fmt=png)


　　

华为Mate X拥有一个8英寸的柔性可折叠OLED显示屏，使用鹰翼式外折方案，机身中间采用可折叠铰链，实现背对背折叠，中间没有缝隙。**折叠时紧密贴合，在展开时平坦自然。折叠起来厚度只有11毫米，远远小于市面上的可折叠手机。**


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YibrExb2afZqia8AoujmQPwfMSavVtbzKFqY39x8Rrl9X8SyUqnJ2BUxUutz0wIGAuYPla6PsVephFw/640?wx_fmt=jpeg)


　　

电池方面，支持55W超级快充，内置4500mAh电池。**配备双卡设计，分别支持4G和5G网路。**另外，华为Mate X搭载华为首款7nm 5G多模芯片巴龙5000+麒麟980。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YibrExb2afZqia8AoujmQPwfMKqes3uylUXFQvOeIbMn4sOOLqVic1Y4gsR4UCiakdIYasicVcibJ1NGTeg/640?wx_fmt=jpeg)


　　

当设备折叠时，你将拥有一个双屏手机，你可以像使用vivo nex双屏版一样用主摄像头自拍或者与另一个人分享屏幕上的内容。而将屏幕展开时你将获得一个几乎为正方形的平板电脑。


![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4YibrExb2afZqia8AoujmQPwfMibseJxQMbB3MLico1oOPqibHyj2ftqVgowvGiaJnjWTfOffaSAIcMNyDEA/640?wx_fmt=png)


　　

华为在Mate X上内置了自家的巴龙5000 5G调制解调器，并且升级了55W的快速充电器。**能在30分钟内将4500毫安时的Mate X充至85%，指纹识别传感器则在侧面的电源键上。**

　　

最快能达到4.6Gbps峰值下载速率，3秒下载1GB电影;同时支持NSA/SA两种 5G组网，实现5G手机一“部”到位！


![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4YibrExb2afZqia8AoujmQPwfMC2sg5iaiahLgBz6QeWflJMiaJwj8X8uH4EP4zpCdGReNqFkRficg2uViaGg/640?wx_fmt=png)


　　

售价方面，8GB+512GB版售价2299欧元，折合人民币约17500元，将于2019年年中发售。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YibrExb2afZqia8AoujmQPwfMnyG4uHW8th8N9NoyUJKDYIVPjAXwAzrMGqjicSVulPKf2GgSSRZWgkg/640?wx_fmt=jpeg)


华为终端手机产品线总裁何刚在专访环节中讲到：**相信Mate X远远好于友商产品，有些友商说折叠屏手机不成熟，而华为却做出了成熟可量产化的产品，这正是华为领先的机会所在。**
