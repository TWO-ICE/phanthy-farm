# 苏宁年货节：高端五粮液，38万一坛，“猫狗双全”成年轻人标配

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4YibSdJUscTsicxcMyBv6V63WRSMMCWaBsLRs4SHUCEuGEfKWiaRPUjKHCZuCicHAQvfbrNkHPITaql1dg/0?wx_fmt=jpeg)

12月27日，苏宁易购正式开启2019年货节。苏宁易购总裁侯恩龙宣布，此次年货节聚焦“三好”，通过“好年货、好价格、好服务”让消费者过一个放心年。

海外洋味、中华老字号、苏福定制年货、春节膨胀红包、福气小镇等诸多货品玩法、全新年味，将在苏宁年货节期间一一亮相。

随着年货节的开启，2018年智慧零售大开发战略、大快消战略等一系列大动作，迎来用户检验。 家宴清单：38万五粮液、海外生鲜、家乡农特   记者从苏宁年货节发布会获悉，春节期间，一系列特色商品集中上线，满足消费者采买需求。阿拉斯加帝王蟹、法国蓝龙虾、吉拉多生蚝、阿根廷牛腩、智利车厘子、澳洲鲜奶……大家足不出户，就能尝遍全球“洋味”。这得益于苏宁在大快消领域的持续发力，尤其是对2018年3月发布的大快消战略的落地推进，苏宁生鲜供应链建设成效已现。发布会上，苏宁易购总裁侯恩龙表示，针对进口生鲜，苏宁采取全球直采购买制，与海外大农场或农产品供应商直接合作，跨境直采，让中国消费者买到全球优质生鲜。

一边利用跨境购优势，广采“洋货”，一边从原产地挖掘中华特色美食。稻香村、韩复兴、广州酒家等老字号带来新年味，常熟鸭血糯、开江大豆笋、中宁黑枸杞等非物质文化遗产，再上春节家宴清单。无法回家过年的人们，则有家乡味道以解乡愁，如盘县火腿、大理野菌子、宾川拉乌核桃等。

![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4YibSdJUscTsicxcMyBv6V63WRzVKpPPV5YVrfrobfFyjXChaqOdowPMviatxUicChIEhW7AgUPaVe43fw/640?wx_fmt=png)

 定制新年福袋添好彩头。苏宁与联合利华、青岛啤酒、好时、洽洽等TOP品牌联手，甄选好年货，独家首发苏福年货礼盒。                  

![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4YibSdJUscTsicxcMyBv6V63WRkuqNia2w962TTHsICZFz4W6144pqmlVf9BCYMFlcBicCat4SGan1z63g/640?wx_fmt=png)


想喝比利时福佳白、罗斯福8号等世界各国精酿啤酒，想品味苏酒三强、川酒六金花、徽酒三杰等传统佳酿，苏宁易购一站购齐。此外，更有38万元一坛的五粮液九龙坛高端定制酒，女性独爱的意大利之花甜型起泡葡萄酒、 法国妮可香槟葡萄酒等名庄气质“小甜水”。

随着苏宁酒类业务的发展，酒类物流能力也在升级。侯恩龙强调，苏宁易购平台的酒品全部保真，自营物流极速配送，放心又安全，杜绝调包事件。 **年货消费新趋势：颜值、宠物、直男、养生** 新生代有了新的消费主张。年货节发布会现场，侯恩龙分享了一组“TA经济”大数据，这组数据显示，颜值经济、直男经济、养生经济、宠物经济，或将成为今年年货节的消费新热点。                               

![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4YibSdJUscTsicxcMyBv6V63WRXXPyJAYD3RMM11Ynm1E1U6q6HKGYzh7z8DHZ7Cbgzu43CF7VjiaibicXQ/640?wx_fmt=png)


应运而生的颜值经济带动起相关产业商品与商业模式的迅速发展。苏宁易购大数据显示，今年双十一美容仪关键词搜索同比增长252%，轻松借“颜”上位。

男性消费意识觉醒，让直男经济成为新风口。近几年苏宁大数据显示，95后男性用户平均换手机周期不足19个月。

随着养生观念的普及，更多的年轻人成为“保健养生”的追随者。他们舍得为自己的身体投资，更容易尝试新鲜的事物。据今年苏宁双十一数据，养生经济成为一大亮点，保温杯+枸杞销量增长240% ，其中90后用户占57%。

每月花费上千、智能陪护、宠物共享……宠物经济火热的背后是喂养理念的改变。苏宁大数据显示，今年双十一宠物食品销量同比增速1683%。

年轻人正成为新增养宠人群的主力军，宠物们纷纷迎来吃喝玩乐的“消费新升级”。紧盯这一机遇，今年苏宁易购战略签约中宠，剑指千亿宠物经济市场。                  

![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4YibSdJUscTsicxcMyBv6V63WRhZwuPnSnpZHOFOP7oKL4uXeeL0IDffEXzUduka8RYkb2fpUXlyia9LA/640?wx_fmt=png)


今年春节，颜值、宠物、直男、养生牵引的消费热潮，将成为新的市场增长点。记者了解到，苏宁年货节顺势推出KIKO小黑管、小佩宠物智能温控窝、任天堂 SWITCH 游戏机皮卡丘限定版、北鼎养生壶等超级新品，进一步挖掘新生代年轻消费力。 手脚并用：逛福气小镇，抢膨胀红包 苏宁此次年货节带来怎样的新玩法？侯恩龙透露，苏宁多产业联合在全国推出消费新场景——福气小镇。在南京、北京、上海、杭州、广州等全国43座福气小镇里，土洋年货聚集，结合不同的场景和年货需求，为用户挑选最好的年货，堪称升级版的年货大集。                     

![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4YibSdJUscTsicxcMyBv6V63WRaAMUCPRZ2llnmOlY70Beuzv975WOTIfmSQXgJcjND9IE5hhjicfBpug/640?wx_fmt=png)


视频购、达人购、直播购，让福气小镇变身沉浸式体验年货街。老字号、洋礼盒、新奇特年货应有尽有，用户线上买，线下就能提货走，好年货看得见。                     

![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4YibSdJUscTsicxcMyBv6V63WRgdzYicYHG7yqssSTxSLYnjvK8S9ZdeY6zbibkFLLPLASeibQs9pNCVQiaQ/640?wx_fmt=png)


腊八和小年是苏宁年货节的核心爆发节点,同时1月8日、1月10日、1月11日安排有三大主题日，这些日子购物很划算。针对春节吃玩宅乐等场景,1月14日到1月28日推出四大苏福周。此外，超1亿购物补贴、3000万分期免息助力任性剁手，享价保贵就赔更为消费者吃下定心丸。


![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4YibSdJUscTsicxcMyBv6V63WRywAZDRe0NLCwSpF5PiaVfVF0MJROLIZibl8bzic9wPqgiaYkg4BeRhFQUQ/640?wx_fmt=png)

 红包大战已成春节营销标配。2019年1月28日再次上线的“膨胀红包”，让现场参会嘉宾充满期待。记者了解到，升级版膨胀红包玩法简单更有趣，包含趣味图片送祝福等形式，膨胀倍数也比去年更大。 服务六字真经：不放假、不涨价  每逢春节，快递、家政保洁就进入涨价模式。侯恩龙现场承诺，年货节期间，苏宁服务不放假、不涨价，包括物流运费、家政保洁、家电维修等。                  

![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4YibSdJUscTsicxcMyBv6V63WRfnS28elib4QyetyEUGZLbRqd4W8lkKwlxuVunDPIPmkq0fhsgaTuhQA/640?wx_fmt=png)


临近年底，网购生鲜也成为不少家庭的选择。从田间地头到餐桌，新鲜如何保证？目前，苏宁全国冷链仓已达45座，全国179座城市都能享受生鲜速达，未来还将辐射全国300余城。                   

![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4YibSdJUscTsicxcMyBv6V63WRh359AXJZ7UTZc71F8BNLCXHDVcKDE3LhzddoLCIUsPvTaop7mtUGtQ/640?wx_fmt=png)


只要在苏宁易购下单，最快半日即可收到新鲜的生鲜产品，方便又快捷。同时，在保证稳定的运输时效下，从第一公里到最后一公里全链路专业冷链物流服务，各环节严把服务质量保障商品品质。

火箭哥是最后一公里的守护者，年货节期间，快递下乡，村里人也能和城里人一样，准时收到包裹。

每逢春节，总有一些人因为坚守岗位无法与家人团聚，苏宁精心准备4000桌年夜饭，向奋战在一线的工作者致敬。此外，苏宁物流为广州、北京、成都等城市的返乡人群发放10万张免邮券。
