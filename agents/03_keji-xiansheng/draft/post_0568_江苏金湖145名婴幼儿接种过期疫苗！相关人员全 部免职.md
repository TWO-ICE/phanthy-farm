# 江苏金湖145名婴幼儿接种过期疫苗！相关人员全 部免职

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4Y9SmYEDaJvTvpFiclPL632Faibvvepa6UQAIUY2Fg6kdXTNCcsY1xJm0qhfTndqOiaqLMwKBZGpNqrFQ/0?wx_fmt=jpeg)

> 原文链接：https://mp.weixin.qq.com/s/v9nCWRQNydxM_PanOBpoQQ

近日，有媒体报道，上百名婴幼儿在江苏淮安市金湖县的黎城卫生院接种（口服）了过期疫苗。多位家长也向媒体反映称，接种过期疫苗后，孩子出现不良反应。


当地政府发布通报称，通过对接种儿童家长的逐一电话排查，截至9日下午4点，金湖县共计145名儿童接种了过期脊灰疫苗。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y9SmYEDaJvTvpFiclPL632FaPbxYPjC1VzGe5VQhrlzqug8uTFK9iaP9diasa3VOIyTeEOJE6ZRc82sA/640?wx_fmt=jpeg)


1月10日，金湖县委宣传部相关负责人通报称，此次出现的过期脊灰疫苗系2017年5月9日由淮安市疾控中心冷链配送至金湖县疾控中心，金湖县疾控中心于当年5月18日冷链配送至黎城卫生院。


通报还称，**2018年12月27日，金湖县疾控中心通知要求各接种单位将过期疫苗送至县疾控中心，集中送市疾控中心统一销毁。但黎城卫生院却没有报送“过期疫苗”，县疾控中心也未继续催报。**


对服用过期疫苗后出现身体不适的儿童，县医院集团负责免费就诊。对因接种过期疫苗产生的不良后果，县医院集团承担一切赔偿责任，由县政府确保落实到位。此外，对以往儿童接种疫苗有疑问的家长，可向金湖县有关部门登记反映。


![图片](https://mmbiz.qpic.cn/mmbiz_png/P3SqL3Qw4Y9SmYEDaJvTvpFiclPL632Fa9L7DUKnpzd4katiaURsRIIGLrbK6T4VbDKdcja9lfwJuMPauPicyniaTg/640?wx_fmt=png)


据悉，过期脊灰疫苗批号为201612158，生产企业是北京北生研生物制品有限公司，有效期至2018年12月11日。但直到该批疫苗有效期满后一个月，也就是2019年1月7日，仍有儿童在服用该批次脊灰疫苗。


专家在答疑现场表示，卫生院不应在长时间内出现多种批号疫苗混用情况，“这样容易造成混乱，应当尽快查清楚各批号启用时间、混用时间”。


![图片](https://mmbiz.qpic.cn/mmbiz_png/qoxI9NQQfn50QwgLf93N5NTZkv4riaW6jU0RJC6hr71u4WJ3r6DEeVxxAPbRHBvjPc4uNLWHlRvDz0GlNFek4LA/640?wx_fmt=png)


针对淮安市金湖县黎城卫生院接种过期脊灰疫苗事件，江苏省卫生健康委迅速派出由委相关负责人带队，省疾控中心、南京市儿童医院专家等联合组成的督导组，于1月8日赴当地督促指导相关工作，责成当地认真核实，查明原因，立即整改，依法依规依纪严肃处理。督导组指导当地做好对接种儿童的咨询服务、医学观察和疫苗补种工作，同时要求保障正常医疗秩序。
