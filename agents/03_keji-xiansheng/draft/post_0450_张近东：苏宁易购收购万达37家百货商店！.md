# 张近东：苏宁易购收购万达37家百货商店！

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4Y8jZbXPsZiaVZomc7icAr3K3feoMb5oArMXSGeTzFDWNzia4icGI5ic1bzNjqicX57JLY3ssNoqknWvuMBA/0?wx_fmt=jpeg)

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8jZbXPsZiaVZomc7icAr3K3fcW5rjfmwpoIBFWewBGoLlYAichJoicyOf2FASwsHtkS97InGkL8sVJ9w/640?wx_fmt=jpeg)


科技先生2月12日讯，苏宁易购董事长张近东在新春团拜会上宣布，**苏宁易购正式收购万达百货有限公司下属全部37家百货门店**，构建线上线下到店到手全场景的百货零售业态，为用户提供更丰富的数字化、场景化购物体验。


万达百货原名万千百货，2007年5月8日成立，跟随着万达广场进行布局。鼎盛时期，万达百货每年以开店15到20家的速度在增长，全国门店总数一度达到110个。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8jZbXPsZiaVZomc7icAr3K3f3e4kmGicUSERd5ib1oIL2IvgV60I18wkLxCl8uYHPX978c2kECwuTicDA/640?wx_fmt=jpeg)


不过，从2015年开始，万达百货开始大调整，频频关店，**去年3月就有消息称，万达百货有易主打算，当时网传银泰有意收购，但是双方都否认了此事。**


过去几年，苏宁不断创新业态场景，打造全场景的零售生活方式体验，推出“苏宁极物”、“苏鲜生”、“苏宁小店”、“苏宁零售云”等丰富业态，品类从家电、3C逐步拓展至超市快消、母婴、家居等领域。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8jZbXPsZiaVZomc7icAr3K3fpECc4shrMf4X1s4icUC1E059trqHJkmoibtia8xZCyiaiciaZMwBn8WzPgbQ/640?wx_fmt=jpeg)


**苏宁方面表示，这次收购是业态融合创新的全新探索，将突破传统百货概念，从数字化和体验两方面改造供应链，打造全新的百货核心竞争力。**


公开资料显示，截至目前，万达百货在全国有37家门店，其中大多位于一、二线城市，会员数量超400万人。近两年，万达百货销售规模稳中有升，净利润水平持续提升。
