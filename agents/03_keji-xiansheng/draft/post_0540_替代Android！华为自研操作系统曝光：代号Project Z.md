# 替代Android！华为自研操作系统曝光：代号Project Z

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Yicekp6tunw2VTAaNzcbj4180Q7CUicwOG0Qy3rhkS5xibHLFkddMqO1uTr62dsC3r4n0e8tmnEL6Ulw/640?wx_fmt=jpeg)


　　

科技先生5月23日讯，此前华为消费者业务CEO余承东曾透露，华为自主研发的操作系统最快将在今年秋天、最晚到明年春天上线。现在该系统的消息也被曝光。

　　

**据Digitimes报道，华为自主研发的操作系统在内部称之为“Project Z”，报道称华为开发Project Z已经有几年时间了。**

　　

报道指出，Project Z的重点是中国大陆市场，**华为希望手机、车载、可穿戴设备及智能家电等都能搭载该操作系统。**

　　

另外，消息还称华为Project Z在开发中遇到很多阻碍，距离该系统准备就绪仍需要一些时日。当然Project Z也面临着生态建设的问题，比如第三方APP的开发等，这些对于Project Z而言依旧是需要面临的巨大挑战，特别是海外市场。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Yicekp6tunw2VTAaNzcbj418eFnP04WariaZQicmn8e6NfZ9VfhiajGYKdrD8nbkJpVKzzqJMPibp9dqicQ/640?wx_fmt=jpeg)


　　

余承东透露，华为自主操作系统打通了手机、电脑、平板、电视、汽车、智能穿戴等各个领域，还将兼容安卓应用和所有Web应用。**而且如果安卓应用重新编译，在该系统的运行性能提升会超过60%。**

　　

余承东表示，我们愿意继续使用谷歌和微软，但没有办法，被逼上梁山！塞翁失马，焉知非福。
