# 惊呆！美国电商份额：苹果比沃尔玛还多，京东要警惕小米？

原标题：美国电商份额让人惊讶：苹果比沃尔玛还多

via 网易科技

7月14日消息，据TechCrunch报道，电商巨头亚马逊已经被美国白宫盯上，且受到反垄断调查的威胁，但市场研究机构eMarketer的研究人员发现，这不足以阻止亚马逊的扩张步伐。eMarketer的数据显示，亚马逊2018年在美国的零售收入将达2582.2亿美元，这一数字将占到美国所有在线零售支出的49.1%，占零售总额的5%。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YibBXunJZjDCoDWVpfOmmRCn7FoquTfANmeFPSicIoialGWBjRtf8kYnjvHZB9EJUib9Me6x2Wa5SOYYQ/640?wx_fmt=jpeg)


亚马逊最初只是一家在线书店，但如今它在电子商务的所有领域都成为庞然大物，这得益于强大的第三方卖家市场Marketplace，其经营的杂货、时尚商品范围不断扩大，还有非常受欢迎的Prime会员计划。现在，亚马逊正快速接近一个临界点，与其他所有零售商相比，更多的人将在亚马逊上花钱。

亚马逊紧随其后的竞争对手是eBay，它以占美国电子商务市场6.6%的份额远远落后于亚马逊，苹果（3.9%）位居第三。全球最大的实体店零售商沃尔玛(Walmart)在电子商务领域的表现还不够好，在美国在线销售中仅占比3.7%，甚至落后于苹果。这些数据之所以引人注目，不是因为它们的多少，而是因为亚马逊的扩张速度依然没有减慢。亚马逊的销售额比一年前增长了29.2%，当时它占据了电子商务零售总额的43%。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YibBXunJZjDCoDWVpfOmmRCnrKcXavzAaN6LzjYujHYpstCbYbvJiaqicaOZIRv0NFTYJgGuwOqJCbng/640?wx_fmt=jpeg)


驱动亚马逊目前增长的“火箭船”是Marketplace，即亚马逊允许第三方卖家使用的零售平台，可以帮助它们将商品卖给亚马逊的消费者。据eMarketer预测，到今年年底，Marketplace的市场份额将超过亚马逊自有销售额的两倍。目前，Marketplace的销售额为1760亿美元，占亚马逊零售总额的68%，而亚马逊的直接销售占比为32%。

难怪许多其他在线商务企业都在追求Marketplace模式，这种模式实质上为平台运营商创造了两方面的交易，从而提高了不直接销售商品可能带来的利润率。eMarketer首席分析师安德鲁·利普斯曼（Andrew Lipsman）指出:“亚马逊Marketplace的持续增长在很多层面上都是合理的。更多的买家更频繁地在亚马逊上交易，自然会吸引第三方卖家。但由于第三方交易的利润也更高，亚马逊完全有动力让平台上的销售人员尽可能无缝地完成交易。”

就热门产品类别而言，消费电子产品和科技产品仍然是领先的产品类别。eMarketer预计它们的销售额为658.2亿美元，约占亚马逊总营业额的四分之一。其次是服装和配饰，这可为亚马逊带来398.8亿美元的营收。2018年排名第三位的是医疗、个人护理和美容，总销售额为160亿美元。第四是食品和饮料，其销售额仅为47.5亿美元。所有这些就已经比一年前增长了38%以上，但最值得注意的或许是，亚马逊如何在每个类别中直接发挥作用。

在科技领域，它有kindle、Fire平板电脑、Fire TV，当然还有广受欢迎的Alexa支持的Echo设备，以及许多其他产品。在公司的自有品牌努力中，服装正被大力推广。就在前一周，亚马逊宣布将斥资10亿美元收购在线药品销售商PillPack，这将成为其更广泛的健康产品和服务战略的主要杠杆。最后，亚马逊还收购了全食超市(Whole Foods)，并围绕膳食包和无服务器实体店进行更广泛的经营。eMarketer认为，实体业务将帮助亚马逊在这一领域增长中发挥重要作用。

eMarketer高级分析师帕特里夏·奥尔西尼（Patricia Orsini）在报告中指出:“在某些方面，亚马逊的食品和饮料战略与图书战略没有什么不同，都在占据主导地位。然而，食品杂货行业的电子商务仍是挑战。出于许多原因，大多数人更喜欢在实体店购买食品，所以这类在线销售的份额很低。亚马逊有个优势，因为它的顾客群对网上购物很满意。除了收集有关全食超市购物者的见解之外，亚马逊很可能最有可能将实体店的采购商转变为网上采购商。”

所有这些举措不仅会促进亚马逊自身的直接销售，还会帮助创造一个环境，让人们来到亚马逊，以超常规的价格购买这些产品，或者购买其他品牌的替代品。到目前为止，人们认为亚马逊不太可能遭到反垄断调查，因为电子商务仍是所有商业活动的一小部分，5%的零售销售额就证明了这一点。然而，仅从电子商务的角度考虑，亚马逊的主导地位是显而易见的。
