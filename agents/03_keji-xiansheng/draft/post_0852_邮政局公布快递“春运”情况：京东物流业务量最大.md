# 邮政局公布快递“春运”情况：京东物流业务量最大

![封面图](https://mmbiz.qlogo.cn/mmbiz_jpg/P3SqL3Qw4Y8jZbXPsZiaVZomc7icAr3K3ficmhaAXU8Mvj7gnDK4icsxqRk6ROAEsY10XR5g1iaSIibSCMZf1nV5koAg/0?wx_fmt=jpeg)

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4Y8jZbXPsZiaVZomc7icAr3K3f9err4iaLVAqicuOoK5QOMo70doibgKdJibAyjhhg9QHRYVycq9nTWP5ePw/640?wx_fmt=jpeg)


据国家邮政局最新公布数据，2月4日至10日，全行业共完成邮件快件业务量6887万件，京东物流、中国邮政、顺丰、EMS、品骏等5家企业承担了90%以上的市场份额。其中京东物流占比最大。

　　

另外，京东方面表示，春节期间，20个超大型智能物流园区“亚洲一号”全面投用，全面提升了运营效率，保障春节期间订单履约时效。

　　

此前，国家邮政局宣布2018年中国快递年业务量突破500亿件，“收寄快递”已成为国民“新开门七件事”。**2018年，京东物流实现从企业物流向物流企业的全面转型，业务同比增长超100%，服务客户总数超过20万家。**


京东推出京东供应链、京东快递、京东快运、京东冷链、京东跨境、京东云仓六大产品体系，并将无人科技全面开放。
