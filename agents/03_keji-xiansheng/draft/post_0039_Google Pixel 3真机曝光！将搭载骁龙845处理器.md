　　科技先生10月8日讯，此前谷歌宣布，将在10月9日在纽约举行活动，**不出意外谷歌Pixel 3系列将在大会上发布**。在过去几年里，随着谷歌继续进军各个硬件领域，10月份的发布会已成为该公司越来越重要的发布平台。


　　距离谷歌旗下的Pixel3和Pixel 3 XL智能手机发布的时间越来越近，被曝光的信息也越来越多。近日有人甚至在香港上手了Pixel 3 XL。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YicF9TBiaDI5Kib5386YjjHSdlIcsawOG75zOn1zFRBv1YsD0Tg5ZJDzI4S4mOM0RpjVnqaWLAlpFkGg/640?wx_fmt=jpeg)


　　谷歌Pixel3系列的配置基本都已曝光，在配置上，谷歌Pixel 3 XL采用6.7英寸“刘海”屏幕，搭载高通骁龙845处理器，配备4GB RAM，电池容量为3430mAh，后置1200万像素单摄像头。


　　而谷歌Pixel 3则会采用5.5英寸的18:9显示屏，分辨率为2160 x 1080。谷歌Pixel 3没有刘海，但保留了双800万像素自拍相机和立体声扬声器。此外谷歌Pixel 3将和Pixel 3 XL一样搭载骁龙845和4GB RAM，其电池容量为2915mAh。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YicF9TBiaDI5Kib5386YjjHSdlSC91MSqiaQUoXtQeNQze3zGIqzibSgCfibNcmmnf3UVByvtqh9b6Pgmmw/640?wx_fmt=jpeg)


　　另外值得一提的是，谷歌这两款机型均采用了前置双摄，有消息称两款摄像头均是800万像素，而且采用了f/1.8光圈、f/1.8 和f/2.2光圈。


![图片](https://mmbiz.qpic.cn/mmbiz_jpg/P3SqL3Qw4YicF9TBiaDI5Kib5386YjjHSdl9IzaNVc8YK1TZpwiarMF482wtttFEr2G1ibyTk5p8aWFI76zNV88L6TQ/640?wx_fmt=jpeg)


　　据了解，在谷歌Pixel 3上面将会采用的全新配色为薄荷绿和淡粉色，但是谷歌现在还没有公布其正式的配色命名，但是根据此前Google Pixel系列机型的都很直白命名方式来看，新配色的命名应该不会有什么太大新意。


　　功能上，将支持Active Edge。这个功能与HTC的Edge Sense基本相同，可以通过挤压手机来执行某些操作，例如切换Google 智能助理和静音，但是能够自定义的功能比较少。


　**　目前加拿大航空公司Freedom Mobile在其官方网站上列出了即将推出的谷歌手机并提供了它们的价格、颜色和规格。**Pixel 3 64 GB：999 CAD(约5303人民币);Pixel 3 128 GB：1129 CAD(约5994人民币);Pixel 3XL 64 GB：1129 CAD(约5994人民币);Pixel 3XL 128 GB：1259 CAD(约6683人民币)。
