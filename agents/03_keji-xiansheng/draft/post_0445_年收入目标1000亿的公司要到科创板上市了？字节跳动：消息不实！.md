# 年收入目标1000亿的公司要到科创板上市了？字节跳动：消息不实！

科技先生2月22日讯，有消息人士表示，抖音运营商字节跳动或将在上海证券交易所科创板上市，相关部门已经联系了该公司，希望其在科创板上市。

　　

知情人士称，选择在科创板上市之前，字节跳动曾考虑在纽约或香港上市。不过，字节跳动上市的计划不像去年年底那么紧迫。消息人士拒绝透露姓名，因为这些信息是保密的。


**对于“字节跳动或将在科创板上市”的消息，字节跳动方面回应称“消息不实”。**

　　

去年有媒体报道，2018年10月字节跳动完成了Pre-IPO轮融资，融资金额可能达到40亿美元，估值达750亿美元，成为世界上最有价值的独角兽之一，并超过了Uber。字节跳动对融资金额和估值未予以评论。
